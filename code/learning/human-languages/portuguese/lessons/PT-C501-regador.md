## You'll want to know: o regador
<!-- hl-knowledge: introduces=[PT-LEX-C501-JARDIM-04]; assesses=[] -->

**o regador** — "watering can".

> Encho o regador na torneira do quintal.
>
> *I fill the watering can at the tap in the yard.*

Built on *regar* with *-dor*, the ending for a tool.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*regador* is built on *regar* "to water", inherited from Latin *rigāre* (EtymDB).
