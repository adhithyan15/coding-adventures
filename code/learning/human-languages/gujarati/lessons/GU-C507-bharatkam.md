# ભરતકામ (bharatkām) — embroidery

## You'll want to know: ભરતકામ
<!-- hl-knowledge: introduces=[GU-LEX-C507-BHARAT507-05]; assesses=[] -->

**ભરતકામ** — *bharatkām* — "embroidery".

> મારી માસી સુંદર ભરતકામ કરે છે.
>
> *mārī māsī sundar bharatkām kare che.*
>
> My aunt does beautiful embroidery.

A neuter noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ભરતકામ** (*bharatkām*) is built from *bharat*, "filling in", from **ભરવું**, "to fill" (CDIAL 9397), and **કામ**, "work": thread fills in the pattern.

## What you've built
