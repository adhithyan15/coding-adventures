## You'll want to know: estrear
<!-- hl-knowledge: introduces=[PT-LEX-C520-TEATRO-05]; assesses=[] -->

**estrear** — "to premiere, to open; to use for the first time".

> O teatro estreia uma peça nova esta semana.
>
> *The theatre opens a new play this week.*

Also to wear something for the first time: *estreei os sapatos*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*estrear* is inherited from Old Portuguese *estrẽar* (EtymDB), built like *estreia* on Latin *strēna* "an omen, a lucky gift".
