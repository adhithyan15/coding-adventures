## You'll want to know: خصص
<!-- hl-knowledge: introduces=[AR-LEX-C384-TANMIYA384-02]; assesses=[] -->

**خصص** — *khaṣṣaṣa* — "to allocate".

> خصصت المدرسة غرفة للموسيقى.
>
> *khaṣṣaṣat al-madrasa ghurfa li-l-mūsīqā.*
>
> The school set aside a room for music.

Present: يخصص, *yukhaṣṣiṣ*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**خصص** (*khaṣṣaṣa*) is built on the native Arabic root *kh-ṣ-ṣ*, "to single out" (Lane). It is Form II, to single out for one purpose: to allocate, to set aside.
