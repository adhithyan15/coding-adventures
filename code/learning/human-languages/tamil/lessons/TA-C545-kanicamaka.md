# கணிசமாக (kaṇicamāka) — considerably

## You'll want to know: கணிசமாக
<!-- hl-knowledge: introduces=[TA-LEX-C545-PANKU545-04]; assesses=[] -->

**கணிசமாக** — *kaṇicamāka* — "considerably".

> இந்த ஆண்டு விற்பனை கணிசமாக அதிகரித்தது.
>
> *inta āṇṭu viṟpaṉai kaṇicamāka atikarittatu.*
>
> This year sales went up considerably.

An adverb in -ஆக; before a noun it is கணிசமான: கணிசமான தொகை, a sizeable sum.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

The origin of **கணிசமாக** (*kaṇicamāka*) is not settled: it is the -ஆக adverb of கணிசம் (*kaṇicam*), "a considerable amount", whose source is unclear.
