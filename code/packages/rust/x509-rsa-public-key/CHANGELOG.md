# Changelog

All notable changes to this package will be documented in this file.

## [0.1.0] - 2026-10-18

### Added

- Exact `rsaEncryption` algorithm and PKCS #1 `RSAPublicKey` decoding.
- Caller-defined inclusive modulus-size and public-exponent allowlist policy.
- Borrowed, unforgeable validated-key evidence and redacted local-offset
  errors.
- Boundary, malformed-input, limit-exhaustion, and redaction tests.
