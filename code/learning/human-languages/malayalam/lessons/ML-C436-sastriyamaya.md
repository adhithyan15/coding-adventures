## You'll want to know: ശാസ്ത്രീയമായ
<!-- hl-knowledge: introduces=[ML-LEX-C436-PARIKSANAM436-05]; assesses=[] -->

**ശാസ്ത്രീയമായ** — *śāstrīyamāya* — "scientific".

> അവർ ശാസ്ത്രീയമായ രീതിയിൽ കൃഷി ചെയ്യുന്നു.
>
> *avar śāstrīyamāya rītiyil kṛṣi ceyyunnu.*
>
> They farm in a scientific way.

The adverb is ശാസ്ത്രീയമായി, scientifically.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ശാസ്ത്രീയമായ** (*śāstrīyamāya*) is built from Sanskrit *śāstrīya*, "taught in the treatises" (Monier-Williams), with the adjective ending -ആയ.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
