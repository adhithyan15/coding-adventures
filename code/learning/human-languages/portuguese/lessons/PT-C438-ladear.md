## You'll want to know: ladear
<!-- hl-knowledge: introduces=[PT-LEX-C438-SUBIDA-04]; assesses=[] -->

**ladear** — "to run alongside, to flank".

> Árvores altas ladeiam a avenida.
>
> *Tall trees line the avenue.*

Also to avoid something: *ladear uma pergunta*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*ladear* is built on *lado* 'side', which is inherited from Latin *latus* 'side, flank' (EtymDB).
