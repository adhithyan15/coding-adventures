## You'll want to know: o peão
<!-- hl-knowledge: introduces=[PT-LEX-C408-PEOES-01]; assesses=[] -->

**o peão** — "the pedestrian; the pawn (in chess)".

> Esta rua é só para peões.
>
> *This street is only for pedestrians.*

In Brazil: *o pedestre*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*peão* is inherited from Late Latin *pedō, pedōnis* 'foot soldier', built on *pēs* 'foot' (EtymDB), which also lists Spanish *peón* and French *pion* as its cousins.
