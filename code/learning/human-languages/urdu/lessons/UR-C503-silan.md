## You'll want to know: سیلن
<!-- hl-knowledge: introduces=[UR-LEX-C503-SILAN503-01]; assesses=[] -->

**سیلن** — *sīlan* — "damp (in a wall)".

> برسات میں دیواروں میں سیلن آ جاتی ہے۔
>
> *barsāt meṅ dīvāroṅ meṅ sīlan ā jātī hai.*
>
> In the rainy season damp gets into the walls.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**سیلن** (*sīlan*) is built on *sīl*, "cool, moist", which CDIAL lists under Sanskrit *sītala*, "cold" (CDIAL 12487).
