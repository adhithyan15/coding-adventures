# ন — write it with the model covered

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[BN-SCRIPT-NA-01] -->

Look at **ন** once and say *nô*. Then cover it.

## Writing — delayed copy
<!-- hl-knowledge: introduces=[]; assesses=[BN-SCRIPT-NA-01] -->
<!-- hl-writing-stage: delayed-copy -->

With the model covered, wait ten seconds, then write **ন** once from memory —
body first, bar last.

Ten seconds is long enough that your hand cannot be tracing a shape it can still
see, and short enough that a letter you met a minute ago is still there.

Only after the letter is finished, uncover the model and compare. Repair **one**
thing, the first that differs, and leave the rest.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[BN-SCRIPT-NA-01] -->

Check the bar's **width** before you check the body at all.

A hand writing from memory remembers to put the bar there and draws it only as
wide as the body underneath. In running text it has to reach the full width of
the letter, because the next letter's bar will meet it — so a short bar is the
one mistake that looks completely right on a single letter and falls apart the
moment there are two.
