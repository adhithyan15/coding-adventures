# A later correction stays on another page

The earlier timed form remains the first-attempt evidence. This little return
practises only one known line and its later repair; it is not another scored
form or a complete A1 mock.

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-A1-FORM-TIMED-01] -->

Cover the earlier answer. [PAUSE 4s] Read the familiar label **ਨਾਂ** and
remember the A · ਕ card value. No new card or person is being introduced.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-A1-FORM-TIMED-01, PA-A1-TIMED-REPAIR-01] -->

Set a 45-second *practice* clock. Write the one known line in Gurmukhi, then
stop when the clock ends:

> ਨਾਂ (A · ਕ): ______

After stopping, check **ਨਾਂ: ਅਮਨ**. If the value or spelling slipped, write
one corrected line on a second page. Keep the first practice line and the
earlier timed form visible and unchanged. Say which is the later correction;
it cannot replace either first attempt.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[PA-A1-TIMED-REPAIR-01] -->

Cover the check. [PAUSE 4s] Recall the order: first attempt, stop, inspect,
then repair separately. The repair helps learning but never raises the first
attempt's score.
