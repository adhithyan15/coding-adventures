## You'll want to know: ترسناک
<!-- hl-knowledge: introduces=[FA-LEX-C530-STORIES-03]; assesses=[] -->

**ترسناک** (*tarsnâk*) — "scary, frightening".

> دیشب یک فیلم ترسناک دیدیم.
>
> *dishab yek film-e tarsnâk didim.*
>
> Last night we watched a scary film.

*tars* 'fear' + *-nâk* 'full of'.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*tarsnâk* is built on native Persian *tars*, 'fear', from inherited *tarsidan*, 'to fear', with the ending *-nâk*, 'full of'.
