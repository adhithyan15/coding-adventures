# Saying no to a sentence, all together

## Warm-up
<!-- hl-knowledge: introduces=[PA-PERFORMANCE-NEG-FIVE-01]; assesses=[PA-NEG-CLAUSE-01] -->

[PAUSE 3s] No new words. One run through what this chapter added.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[PA-NEG-CLAUSE-01, PA-NEG-NOT-UNDERSTOOD-01, PA-LEX-PATA-01, PA-SCRIPT-NAHIN-01, PA-LEX-HAAN-NAHIN-01] -->

- **ਨਹੀਂ** directly before the verb, and nothing else moving.
- **ਮੈਨੂੰ ਸਮਝ ਨਹੀਂ ਆਈ** — I did not follow you.
- **ਮੈਨੂੰ ਨਹੀਂ ਪਤਾ** — I do not have the fact.
- **ਨਹੀਂ** on the page, bindi and all.

**ਨਹੀਂ** has been in this book since its first chapter and could only ever be a
whole answer. It can now be put inside a sentence, which means every statement
you meet can be contradicted and every statement you make can be denied.
