## You'll want to know: il bagagliaio
<!-- hl-knowledge: introduces=[IT-LEX-C411-COFANO-02]; assesses=[] -->

**il bagagliaio** — "the boot (of a car)".

> Metti le valigie nel bagagliaio.
>
> *Put the suitcases in the boot.*

In American English, the trunk. *Il bagaglio* is luggage.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*bagagliaio* is built on *bagaglio* 'luggage', which came from French *bagage*, built on Old French *bague* 'bundle'; where that word comes from is not settled.
