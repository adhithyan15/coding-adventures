# പ്രതിനിധി (pratinidhi) — a representative

## You'll want to know: പ്രതിനിധി
<!-- hl-knowledge: introduces=[ML-LEX-C422-SABHA422-03]; assesses=[] -->

**പ്രതിനിധി** — *pratinidhi* — "a representative".

> ഓരോ ക്ലാസിൽ നിന്നും ഒരു പ്രതിനിധി യോഗത്തിന് വന്നു.
>
> *ōrō klāsil ninnuṁ oru pratinidhi yōgattinŭ vannu.*
>
> A representative came to the meeting from each class.

Plural: പ്രതിനിധികൾ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**പ്രതിനിധി** (*pratinidhi*) is borrowed from Sanskrit *pratinidhi*, "a substitute, a representative" (Monier-Williams): one put in the place of another.
