## You'll want to know: le choc
<!-- hl-knowledge: introduces=[FR-LEX-C298-CHOC-03]; assesses=[] -->

**le choc** — "the shock, the crash".

> Le choc a été très violent.
>
> *The crash was very violent.*

*Être en état de choc* — to be in shock.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*choc* is built on *choquer* "to strike against", which is usually traced to Middle Dutch *schokken* "to jolt" (EtymDB lists no parent).
