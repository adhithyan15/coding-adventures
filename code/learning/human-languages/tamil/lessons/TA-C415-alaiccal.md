# அலைச்சல் (alaiccal) — running around; a weary chase

## You'll want to know: அலைச்சல்
<!-- hl-knowledge: introduces=[TA-LEX-C415-AVANAM415-03]; assesses=[] -->

**அலைச்சல்** — *alaiccal* — "running around; a weary chase".

> அந்தச் சான்றிதழுக்காக எனக்கு ஒரு வாரம் அலைச்சல் இருந்தது.
>
> *antac cāṉṟitaḻukkāka eṉakku oru vāram alaiccal iruntatu.*
>
> Getting that certificate meant a week of running around for me.

Built on அலை, to wander; வீண் அலைச்சல் is running around for nothing.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**அலைச்சல்** (*alaiccal*) is native Dravidian: DEDR 240 lists it, "wandering", beside the verb அலை, "to move about".
