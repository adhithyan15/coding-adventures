## You'll want to know: અજમાયશ
<!-- hl-knowledge: introduces=[GU-LEX-C545-AASAN545-04]; assesses=[] -->

**અજમાયશ** — *ajmāyaś* — "a try-out".

> જો અજમાયશમાં મશીન બરાબર ચાલશે તો અમે તે ખરીદીશું.
>
> *jo ajmāyaśmā̃ maśīn barābar cālśe to ame te kharīdīśũ.*
>
> If the machine runs properly in the trial, we'll buy it.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**અજમાયશ** (*ajmāyaś*) is usually traced to Persian *āzmāyish*, "a trial, a test"; the verb **અજમાવવું**, to try out, belongs with it.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
