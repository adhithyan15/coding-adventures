## [0.8.0] - 2026-11-24

### Security

- `ANDn`/`ORn`/`XORn` are capped at `MaxInputs = 65536` (checked before any
  work) and snapshot the caller's slice once; validation and computation both
  use the private copy, removing the validate-then-reread TOCTOU. The
  `*InvalidBitError` still names `inputs[i]`.
- `Counter` returns an output slice that no longer aliases the returned state.

### Added

- `MaxInputs`.
- LG02 wide-integer rows (2^31, 2^31+1, 2^32, 2^32+1, 2^53+1, MaxInt64,
  MinInt64, -1) on all 11 gates in every position and the n-ary gates, so a
  truncating `int32(v)` validator fails the suite.
- Concurrency, input-cap, no-mutation and Counter-aliasing tests.

### Changed

- BUILD now runs `go test -race`, `go vet ./...` and a `gofmt -l` check. BUILD_windows (one `cmd /C` per line, no POSIX syntax) runs `go test -cover` and `go vet ./...`; `-race` stays POSIX-only because it needs cgo.
