# ಕಟ್ಟುನಿಟ್ಟು (kaṭṭuniṭṭu) — strictness

## You'll want to know: ಕಟ್ಟುನಿಟ್ಟು
<!-- hl-knowledge: introduces=[KA-LEX-C414-GARISHTHA414-01]; assesses=[] -->

**ಕಟ್ಟುನಿಟ್ಟು** — *kaṭṭuniṭṭu* — "strictness".

> ಪರೀಕ್ಷೆಯ ಸಮಯದಲ್ಲಿ ನಿಯಮಗಳು ಕಟ್ಟುನಿಟ್ಟಾಗಿ ಇರುತ್ತವೆ.
>
> *parīkṣeya samayadalli niyamagaḷu kaṭṭuniṭṭāgi iruttave.*
>
> During exams the rules are strict.

ಕಟ್ಟುನಿಟ್ಟಾದ, strict; ಕಟ್ಟುನಿಟ್ಟಾಗಿ, strictly.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಕಟ್ಟುನಿಟ್ಟು** (*kaṭṭuniṭṭu*) is native Kannada, a pair-word built on *kaṭṭu*, "to bind, a restraint" (DEDR 1147); the second half, *niṭṭu*, is not settled.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
