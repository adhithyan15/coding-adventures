# ബഹുമതി (bahumati) — an honour

## You'll want to know: ബഹുമതി
<!-- hl-knowledge: introduces=[ML-LEX-C396-PURASKARAM396-02]; assesses=[] -->

**ബഹുമതി** — *bahumati* — "an honour".

> അത് ഞങ്ങൾക്ക് ഒരു വലിയ ബഹുമതി ആണ്.
>
> *atŭ ñaṅṅaḷkkŭ oru valiya bahumati āṇŭ.*
>
> That is a great honour for us.

Also a title or a decoration given by a government.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ബഹുമതി** (*bahumati*) is borrowed from Sanskrit *bahumati*, "high opinion, esteem" (Monier-Williams), from *bahu*, "much", and *mati*, "thought".
