# Sanskrit pre-A1 mock 2 — confidential examiner and recording script

Do not give this file to the learner. Before administration, a trained speaker
of the living spoken register records each listening and dictation stimulus as
its named audio file. Use one documented pronunciation tradition consistently.
Record at 70–90 words per minute without translating or spelling the stimulus.
During the assessment, play every named file twice and leave an eight-second
answer pause after each play. A technical restart replaces the affected play;
it does not add a third play.

## Speaking — live interlocutor

1. Say **शुभप्रभातम्।** The learner returns the greeting.
2. Ask **तव नाम किम् अस्ति?** The learner states a chosen identity.
3. Ask **त्वम् कथम् असि?**
4. Ask **त्वम् कुत्र वससि?**
5. Ask **किम् त्वम् संस्कृतम् वदसि?**
6. Give this support-language situation without a Sanskrit answer model: “You
   want a book. Make one short polite request in Sanskrit.”

The interlocutor may repeat each prompt once slowly. Record the speaking paper
for independent scoring under the assessment specification.
