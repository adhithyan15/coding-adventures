# અત્યારે — hear now

## Warm-up
<!-- hl-knowledge: introduces=[GU-LEX-ATYAARE-01]; assesses=[GU-LEX-AAJ-01, GU-SCRIPT-AAJ-01, GU-LEX-MAHINO-01] -->

[PAUSE 3s] Say **today**, name the two signs that write it, then say **month**.
Now listen twice: **atyāre**. It means **now**.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[GU-LEX-ATYAARE-01, GU-LEX-AAJ-01, GU-LEX-MAHINO-01] -->

Three widths of time, narrowing:

- *mahino* — many days together
- *āj* — this one whole day
- *atyāre* — this moment inside it

[PAUSE 1s]
- [YOU SAY: "atyāre"]
- [YOU SAY: the three in narrowing order — *mahino*, *āj*, *atyāre*]
