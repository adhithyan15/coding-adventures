# Hear *nām* — name

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MW-LEX-MHARO-01, MW-SCRIPT-MHARO-01, MW-DIALOGUE-GREETING-01, MW-PERFORMANCE-PAANI-FOUR-SKILL-01] -->

[PAUSE 25s] Hear **राम-राम सा** and answer it. Retrieve **पाणी**
once by ear, voice, eye, and writing. Then hear *mhāro*, say **my**, and read
**म्हारो** once.

## You'll want to know
<!-- hl-knowledge: introduces=[MW-LEX-NAAM-01]; assesses=[] -->

> *nām* — name

Listen twice, then say it once. Marwadi *nām*, Sanskrit *nāman*, and English
*name* are distant members of the same old word family. That history is a
memory hook; today's task is only sound and meaning.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[MW-LEX-NAAM-01, MW-LEX-MHARO-01] -->

Touch your name on a card when you hear *nām*. Touch yourself when you hear
*mhāro*. Change the order once.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[MW-LEX-NAAM-01] -->

Say *mhāro nām* and give the two-word meaning: **my name**.
