## You'll want to know: அகழ்வாராய்ச்சி
<!-- hl-knowledge: introduces=[TA-LEX-C341-AGAZHVU341-01]; assesses=[] -->

**அகழ்வாராய்ச்சி** — *akaḻvārāycci* — "an excavation".

> அகழ்வாராய்ச்சியில் பழைய நாணயங்கள் கிடைத்தன.
>
> *akaḻvārāycciyil paḻaiya nāṇayaṅkaḷ kiṭaittaṉa.*
>
> Old coins were found in the excavation.

A dig made to learn about the past; அகழ், to dig, is in it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**அகழ்வாராய்ச்சி** (*akaḻvārāycci*) is a Tamil compound built from அகழ்வு, "digging", from அகழ் (DEDR 11), and ஆராய்ச்சி, "research" (DEDR 377).
