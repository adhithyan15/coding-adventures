# വിനിമയം (vinimayaṁ) — exchange

## You'll want to know: വിനിമയം
<!-- hl-knowledge: introduces=[ML-LEX-C489-PANAM489-02]; assesses=[] -->

**വിനിമയം** — *vinimayaṁ* — "exchange".

> കറൻസി വിനിമയം ബാങ്കിൽ ചെയ്യാം.
>
> *kaṟansi vinimayaṁ bāṅkil ceyyāṁ.*
>
> Currency exchange can be done at the bank.

The exchange rate is the വിനിമയ നിരക്ക്.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**വിനിമയം** (*vinimayaṁ*) is borrowed from Sanskrit *vinimaya*, "exchange, barter" (Monier-Williams).
