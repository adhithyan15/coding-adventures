# The three round amounts

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MW-LEX-TOTAL-QUESTION-01, MW-LEX-PRICE-NUMBER-01, MW-LEX-COUNTER-OFFER-01] -->

[PAUSE 20s] Ask how much altogether, hear twenty, and offer ten.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[MW-LEX-DAS-01, MW-LEX-BEES-01, MW-LEX-SO-01, MW-SCRIPT-DAS-01, MW-SCRIPT-BEES-01, MW-SCRIPT-SO-01, MW-LEX-NO-NINE-01, MW-LEX-DO-TWO-01, MW-SCRIPT-NO-NINE-01, MW-SCRIPT-DO-TWO-01, MW-LEX-EK-01, MW-LEX-TEEN-01, MW-LEX-CHAAR-01, MW-LEX-PAANCH-01, MW-LEX-CHHA-SIX-01, MW-LEX-SAAT-01, MW-LEX-AATH-01, MW-SCRIPT-EK-01, MW-SCRIPT-TEEN-01, MW-SCRIPT-CHAAR-01, MW-SCRIPT-PAANCH-01, MW-SCRIPT-CHHA-SIX-01, MW-SCRIPT-SAAT-01, MW-SCRIPT-AATH-01] -->
<!-- hl-writing-stage: dictation-transcription -->

1. Hear **दस**, **बीस**, **सो** in any order and say each.
2. Say which two share a closing sign, and which two share a vowel mark.
3. Write the three-way column **दो**, **नो**, **सो** and read it back.
4. Write **दस**, **बीस**, **सो** from dictation, given out of order.

Then run four counter-offers: hear a price, halve it, and say the offer.
