## You'll want to know: পরিশ্রম
<!-- hl-knowledge: introduces=[BN-LEX-C376-LOKKHYO376-03]; assesses=[] -->

**পরিশ্রম** — *pôrishrôm* — "hard work; effort".

> পরিশ্রম করলে তুমি ফল পাবে।
>
> *pôrishrôm kôrle tumi phôl pābe.*
>
> If you work hard, you will see results.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**পরিশ্রম** (*pôrishrôm*) is Sanskrit *pariśrama*, exertion or labour (Monier-Williams). The taught পরিশ্রমী, hard-working, is built on it.
