# విరాళం (virāḷaṁ) — a donation

## You'll want to know: విరాళం
<!-- hl-knowledge: introduces=[TE-LEX-C410-SEVA410-02]; assesses=[] -->

**విరాళం** — *virāḷaṁ* — "a donation".

> అతను ఆసుపత్రికి పెద్ద విరాళం ఇచ్చాడు.
>
> *atanu āsupatriki pedda virāḷaṁ iccāḍu.*
>
> He gave a big donation to the hospital.

Plural: విరాళాలు, *virāḷālu*.

విరాళం ఇచ్చు, to donate.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**విరాళం** (*virāḷaṁ*) is a Telugu word whose origin is not settled; neither DEDR nor CDIAL lists it.
