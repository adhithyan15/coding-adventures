# വർദ്ധിപ്പിക്കുക (varddhippikkuka) — to increase; to raise

## You'll want to know: വർദ്ധിപ്പിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C449-VARDDHANA449-03]; assesses=[] -->

**വർദ്ധിപ്പിക്കുക** — *varddhippikkuka* — "to increase; to raise".

> കമ്പനി ശമ്പളം പത്ത് ശതമാനം വർദ്ധിപ്പിച്ചു.
>
> *kampani śampaḷaṁ pattŭ śatamānaṁ varddhippiccu.*
>
> The company raised salaries by ten per cent.

Past: വർദ്ധിപ്പിച്ചു, *varddhippiccu*.

The causative of വർദ്ധിക്കുക: to make a thing grow.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**വർദ്ധിപ്പിക്കുക** (*varddhippikkuka*) is built from Sanskrit *vardhayati*, "makes grow, increases" (CDIAL 11382), with the Malayalam causative verb ending -ിപ്പിക്കുക.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
