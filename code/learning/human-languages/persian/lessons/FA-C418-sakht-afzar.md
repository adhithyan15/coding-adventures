## You'll want to know: سخت افزار
<!-- hl-knowledge: introduces=[FA-LEX-C418-NARMAFZAR-02]; assesses=[] -->

**سخت افزار** (*sakht afzâr*) — "hardware".

> کامپیوتر من سخت افزار قدیمی دارد.
>
> *kâmpyuter-e man sakht afzâr-e qadimi dârad.*
>
> My computer has old hardware.

*Sakht* "hard" + *afzâr* "tool".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**سخت افزار** is a modern native calque of English *hardware*, built from *sakht* "hard", which EtymDB traces to Middle Persian, + *afzâr* "tool".
