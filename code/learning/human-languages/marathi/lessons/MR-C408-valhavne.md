## You'll want to know: वल्हवणे
<!-- hl-knowledge: introduces=[MR-LEX-C408-NAVADI408-03]; assesses=[] -->

**वल्हवणे** — *valhavṇe* — "to row".

> नावाडी हळूहळू होडी वल्हवत होता.
>
> *nāvāḍī haḷūhaḷū hoḍī valhavat hotā.*
>
> The boatman was slowly rowing the boat.

Past, with -ने (he …): त्याने वल्हवलं, *tyāne valhavlaṁ*.

Built on वल्हे, an oar: होडी वल्हवणे, to row a boat.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**वल्हवणे** (*valhavṇe*) is a Marathi verb built on **वल्हे**, "an oar", with the ending -वणे; the origin of the noun is not settled.
