# ੰ — the nasal mark inside ਪੰਜਾਬੀ

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-SCRIPT-PA-01] -->

Write **ਪ** once. Today adds only the nasal mark that sits above it.

## Script — one tiny step
<!-- hl-knowledge: introduces=[PA-SCRIPT-TIPPI-WRITING-01]; assesses=[PA-SCRIPT-PA-01] -->

Place **ੰ** above **ਪ** to make **ਪੰ**. This is *ṭippī*, not the final-position bindi from **ਹਾਂ**.
