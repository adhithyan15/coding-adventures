# ಪ್ರಚೋದಿಸು (pracōdisu) — to incite

## You'll want to know: ಪ್ರಚೋದಿಸು
<!-- hl-knowledge: introduces=[KA-LEX-C405-SANDHANA405-05]; assesses=[] -->

**ಪ್ರಚೋದಿಸು** — *pracōdisu* — "to incite".

> ಯಾರೋ ಜನರನ್ನು ಜಗಳಕ್ಕೆ ಪ್ರಚೋದಿಸಿದರು.
>
> *yārō janarannu jagaḷakke pracōdisidaru.*
>
> Someone incited the people to fight.

Past (I …): ಪ್ರಚೋದಿಸಿದೆ, *pracōdiside*.

The person takes -ಅನ್ನು, the aim -ಗೆ. ಪ್ರಚೋದನೆ, provocation.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಪ್ರಚೋದಿಸು** (*pracōdisu*) is built on Sanskrit *pracodana*, "instigating, urging" (Monier-Williams), with the Kannada verb ending -*isu*.

One more word for giving reasons and opinions.
