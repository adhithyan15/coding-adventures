# સ્થિર (sthir) — steady

## You'll want to know: સ્થિર
<!-- hl-knowledge: introduces=[GU-LEX-C377-DASHA377-02]; assesses=[] -->

**સ્થિર** — *sthir* — "steady".

> જો ભાવ સ્થિર રહેશે તો વેપારીઓ ખુશ થશે.
>
> *jo bhāv sthir raheśe to vepārīo khuś thaśe.*
>
> If prices stay steady, the traders will be happy.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**સ્થિર** (*sthir*) is a tatsama, borrowed from Sanskrit *sthira*, "firm, hard, steady" (Monier-Williams).
