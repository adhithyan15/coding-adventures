## You'll want to know: случайность
<!-- hl-knowledge: introduces=[RU-LEX-C355-SLUCHAYNO-02]; assesses=[] -->

**случайность** (*slucháynost*) — "chance, an accident".

> Это не случайность, а план.
>
> *Éto ne slucháynost, a plan.*
>
> This is not chance but a plan.

Feminine. *По случайности* — by chance.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**случайность** is built on *случайный* with the abstract suffix *-ость*; the root is *случай*, from Proto-Slavic *\*sŭlučajĭ* (EtymDB).
