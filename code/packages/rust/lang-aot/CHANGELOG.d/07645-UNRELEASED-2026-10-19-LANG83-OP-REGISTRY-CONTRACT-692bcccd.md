## 0.581.0 (UNRELEASED)

- LANG83 PR1a — the standard-operation contract. New `lang_aot::Backend` (the nine columns `X86_64`, `Aarch64`, `Llvm`, `Wasm`, `Jvm`, `Clr`, `Beam`, `Vm`, `Jit`, each mapped to its crate's `op_support` declaration) and `check_module_for(backend, &IIRModule)`, which returns a typed `UnsupportedOps { backend, refusals }` naming every refused `(function, op)` and the backend's reason; `LangAotError::UnsupportedOps` carries it. Every code-generation path now runs the check first, through new IIR-level entry points `compile_iir_to_llvm`, `compile_iir_to_wasm`, `compile_iir_to_jvm_class`, `compile_iir_to_cil_artifact`, `compile_iir_to_cil_text`, `compile_iir_to_beam` and `compile_iir_to_host_executable` (each `compile_source_to_*` / `compile_file_to_*_executable` is now the frontend plus one of them; behaviour is otherwise unchanged). New `tests/op_conformance.rs` (4 tests) builds an IIR case for every registry op: every `Lowered` case compiles on LLVM/WASM/JVM/CLR/BEAM/native and runs with the expected output on WASM, VM, JIT (asserting `main` is genuinely JIT-compiled), LLVM and native; every `Refused` case is rejected by `check_module_for` and by the backend's own entry point; `Expect::StdoutThenTrap` and a stdout-carrying `RunResult::Trapped` are ready for PR1b. The matrix WASM `PrintHost` and the VM/JIT runners now write `print_i64` (decimal + newline), `putchar` and `print_str` into one ordered buffer instead of dropping integers whenever any byte output existed, proven by the new `mixed_print_i64_and_print_str_output_is_one_ordered_stream_on_every_available_backend` ALGOL row (previously `ABC` on WASM/VM/JIT, now `A1\nB-2\nC` everywhere). Both new tests are listed in `BUILD`. Adds direct `x86_64-backend`/`aarch64-backend` dependencies.
