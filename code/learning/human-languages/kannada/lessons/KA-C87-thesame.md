# ಅದೇ (adē) — the same one, that very one

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C87-REPLIES-03, KA-LEX-C87-REPLIES-04] -->

[PAUSE 2s] Before the new one: say the Kannada for oh no, then the Kannada for is that so.

## You'll want to know: ಅದೇ
<!-- hl-knowledge: introduces=[KA-LEX-C87-REPLIES-05]; assesses=[] -->

**ಅದೇ** (*adē*) — "that very one, the same". It is **ಅದು** (*adu*), "that", with the
emphatic **‑ಏ**.

**ಅದೇ!** — "that's it! exactly that one!"

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

That, made emphatic.
