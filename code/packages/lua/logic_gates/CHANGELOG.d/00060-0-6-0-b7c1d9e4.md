## [0.6.0] - 2026-11-24

LGE-LUA-HARDEN.

### Changed (BREAKING)

- Table arguments are strict snapshots. `Register`, `ShiftRegister`,
  `Counter` and `DFlipFlop` now require PLAIN tables (no metatable) whose keys
  are exactly `1..n`. `Register({1,nil,1}, 1)` and `{[1]=1,[3]=1}` used to be
  silently truncated to a border; they now raise `INVALID_SHAPE`. Tables with a
  metatable (including a faked `__metatable`) raise `INVALID_SHAPE` without
  running any metamethod. More than 65536 entries raises `INVALID_WIDTH`
  (entries are counted with `next`, stopping at the cap).
- `ANDn` / `ORn` accept at most `MAX_INPUTS` (65536) inputs; the cap is checked
  on `select("#", ...)` before any copy. Fewer than 2 or more than the cap
  raise the structured `INVALID_ARITY` error (previously a bare string).
  Note: Lua itself rejects vararg calls of several hundred thousand arguments
  with a VM `stack overflow` before package code runs.
- Genuine errors are now identified by registry identity, not shape. A forged
  table reusing the metatable or fields is no longer accepted by
  `is_invalid_*`; a genuine error stays genuine if tampered with. Error
  objects are read-only proxies (`err.code = x` raises, metatable locked);
  `err.code / err.param / err.value` still read as before, but `pairs(err)` is
  empty and `rawget(err, "code")` is nil.
- `err.value` descriptions are fixed text: `float`, `string`, `table`,
  `integer N` (small) or `integer (large magnitude)`. Strings and floats are no
  longer echoed.
- The seven CMOS-failure branches raise a structured `INTERNAL` error (new
  `is_internal`) with fixed text instead of a bare string built with `tostring`.
- Public modules (`logic_gates`, `.gates`, `.sequential`) are read-only
  proxies: assigning an export raises. `gates.raise_invalid_width`,
  `gates.raise_invalid_shape`, `gates.validate_bit`, `gates.describe` are no
  longer public; error minting lives in the private `internal` module whose kit
  is claimable once per consumer.

### Fixed

- Composite gates (`NAND_AND`, `ANDn`, the sequential circuits) call captured
  local upvalues, so rebinding an export cannot change their behaviour.
- Every standard-library function the package uses is captured at load time,
  so replacing `_G.error`, `string.format`, `ipairs`, ... later can no longer
  make validation fail open.

### Added

- `MAX_INPUTS`, `is_internal`, `tests/test_lua_hardening.lua`.
- luacov configuration (`.luacov`, `tests/check_coverage.lua`, 95% threshold)
  matching sibling Lua packages.

### Packaging

- Rockspec renamed to `coding-adventures-logic-gates-0.6.0-1.rockspec`; module
  `coding_adventures.logic_gates.internal` added. Dependents' BUILD files
  (`fpga`, `arm1_gatelevel`, `intel4004_gatelevel`) updated. `VERSION` is now
  `"0.6.0"`.
