# પાટિયું (pāṭiyũ) — signboard, plank

## You'll want to know: પાટિયું
<!-- hl-knowledge: introduces=[GU-LEX-C198-SIGNS198-01]; assesses=[] -->

**પાટિયું** — *pāṭiyũ* — "signboard, plank".

> **દુકાનનું પાટિયું નવું છે.** — *dukānnũ pāṭiyũ navũ che* — "The shop's signboard is new."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**પાટિયું** (*pāṭiyũ*) is a tadbhava. CDIAL lists it, glossed "plank", under Sanskrit *paṭṭa*, "slab, tablet" (CDIAL 7699).
