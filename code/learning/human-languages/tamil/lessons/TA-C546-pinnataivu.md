# பின்னடைவு (piṉṉaṭaivu) — a setback

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TA-LEX-C545-PANKU545-04, TA-LEX-C545-PANKU545-05] -->

[PAUSE 2s] Before the new one: say the Tamil for considerably, then the Tamil for a model.

## You'll want to know: பின்னடைவு
<!-- hl-knowledge: introduces=[TA-LEX-C546-THADANGAL546-01]; assesses=[] -->

**பின்னடைவு** — *piṉṉaṭaivu* — "a setback".

> மழை பெய்தால் கட்டட வேலைக்குப் பின்னடைவு ஏற்படும்.
>
> *maḻai peytāl kaṭṭaṭa vēlaikkup piṉṉaṭaivu ēṟpaṭum.*
>
> If it rains, the building work will suffer a setback.

What suffers it takes -க்கு: வேலைக்குப் பின்னடைவு.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**பின்னடைவு** (*piṉṉaṭaivu*) is a native compound: பின் (*piṉ*), "back, behind" (DEDR 4205), and அடைவு (*aṭaivu*), "reaching, getting": a going back.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
