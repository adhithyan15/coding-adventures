## You'll want to know: das Freibad
<!-- hl-knowledge: introduces=[GE-LEX-C511-WASSERSPORT-01]; assesses=[] -->

**das Freibad** — "open-air pool".

> Im Sommer gehen wir jeden Tag ins Freibad.
>
> *In summer we go to the open-air pool every day.*

Plural: *die Freibäder*. An indoor pool is *das Hallenbad*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*Freibad* is built on *frei* "free, open" and *Bad* "bath", inherited from Old High German *bad*, from Proto-Germanic *baþą* (EtymDB).
