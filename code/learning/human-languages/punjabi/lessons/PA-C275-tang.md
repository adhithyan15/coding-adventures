## You'll want to know: ਤੰਗ
<!-- hl-knowledge: introduces=[PA-LEX-C275-FIT275-02]; assesses=[] -->

**ਤੰਗ** — *taṅg* — "tight".

> ਇਹ ਜੁੱਤੀ ਬਹੁਤ ਤੰਗ ਹੈ।
>
> *eh juttī bahut taṅg hai.*
>
> This shoe is very tight.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ਤੰਗ** (*taṅg*) is a loan, usually traced to Persian *tang*, "narrow, tight".
