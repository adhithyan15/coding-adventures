## You'll want to know: the walk-away is the move, not the exit
<!-- hl-knowledge: introduces=[]; assesses=[MW-PERFORMANCE-REFUSAL-FOUR-SKILL-01, MW-LEX-KONI-01] -->

The three-turn shape you built has not changed. What changes is the number, and
a bargain you can only run at one price is not one you can run:

> — **पंदरा करो।** — *Pandrā karo.* — Make it fifteen.
> — **कोनी।** — *Konī.* — No.
> — **पाछे मिलसू।** — *Pāchhe milsū.* — We'll meet later.

**पाछे मिलसू** is doing the same work it did the first time: it says the bargain
is paused rather than finished, and it is what lets the seller call you back.
Said as a real goodbye it ends the conversation; said here it keeps it alive.
One line, two jobs, and the market decides which.

## Guided Practice

<!-- hl-writing-stage: dictation-transcription -->

The same four skills, on a figure you have not rehearsed.

1. **Listen.** Hear an offer and a refusal; say the figure that was named.
2. **Speak.** Run the three turns with your own number in the first line.
3. **Read.** Read the refusal printed above and say the walk-away without looking.
4. **Write.** Write **कोनी।** and **पाछे मिलसू।** from the sound alone, with the
   page covered.

[PAUSE 8s] Which of the two lines refuses, and which leaves? (**कोनी।**
refuses; **पाछे मिलसू।** leaves.) What does the leaving line do that merely
walking off does not? (**It keeps the bargain open** — the seller can still call
you back.) And where did you first meet it? (**As a goodbye**, long before any
bargaining.)
