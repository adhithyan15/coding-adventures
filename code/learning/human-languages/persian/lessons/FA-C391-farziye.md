## You'll want to know: فرضیه
<!-- hl-knowledge: introduces=[FA-LEX-C391-FARZ-02]; assesses=[] -->

**فرضیه** (*farziye*) — "a hypothesis".

> دانشمندها این فرضیه را آزمایش کردند.
>
> *dâneshmandhâ in farziye râ âzmâyesh kardand.*
>
> The scientists tested this hypothesis.

*Farz* "assumption" + *-iye*. Plural *farziyehâ*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**فرضیه** is built on *farz* "assumption", from Arabic *farḍ* (EtymDB), with the ending *-iye*, as in *nazariye* "theory".
