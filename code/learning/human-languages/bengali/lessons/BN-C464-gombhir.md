## You'll want to know: গম্ভীর
<!-- hl-knowledge: introduces=[BN-LEX-C464-GOMBHIR464-01]; assesses=[] -->

**গম্ভীর** — *gômbhīr* — "grave; serious".

> খবরটা শুনে বাবা গম্ভীর হয়ে গেলেন।
>
> *khôbôrṭā shune bābā gômbhīr hôye gelen.*
>
> Father went grave when he heard the news.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**গম্ভীর** (*gômbhīr*) is a tatsama, Sanskrit *gambhīra*, "deep" (CDIAL 4031), which Monier-Williams gives as a form of *gabhīra*, the source of গভীর (taught), deep; Bengali uses it for a deep, serious manner.
