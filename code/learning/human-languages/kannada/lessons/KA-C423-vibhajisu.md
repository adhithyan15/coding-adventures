# ವಿಭಜಿಸು (vibhajisu) — to divide; to split

## You'll want to know: ವಿಭಜಿಸು
<!-- hl-knowledge: introduces=[KA-LEX-C423-HANTA423-05]; assesses=[] -->

**ವಿಭಜಿಸು** — *vibhajisu* — "to divide; to split".

> ಶಿಕ್ಷಕರು ತರಗತಿಯನ್ನು ನಾಲ್ಕು ಗುಂಪುಗಳಾಗಿ ವಿಭಜಿಸಿದರು.
>
> *śikṣakaru taragatiyannu nālku gumpugaḷāgi vibhajisidaru.*
>
> The teacher divided the class into four groups.

Past (I …): ವಿಭಜಿಸಿದೆ, *vibhajiside*.

Into what: -ಆಗಿ, as in ಗುಂಪುಗಳಾಗಿ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ವಿಭಜಿಸು** (*vibhajisu*) is built on Sanskrit *vibhajana*, "separation, distinction" (Monier-Williams), with the Kannada verb ending -*isu*.
