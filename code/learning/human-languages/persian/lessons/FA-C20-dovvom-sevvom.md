# دوم and سوم — second, third, and one ending

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[FA-LEX-AVVAL, FA-LEX-DO, FA-LEX-SE] -->

[PAUSE 2s] Say **avval**, and where it came from. Then say **do** and **se**.

## You'll want to know first — two words and a rule
<!-- hl-knowledge: introduces=[FA-LEX-DOVVOM, FA-LEX-SEVVOM, FA-MORPH-ORDINAL-OM]; assesses=[FA-LEX-DO, FA-LEX-SE, FA-SCRIPT-SIN-01, FA-SCRIPT-VAV-01, FA-SCRIPT-MIM-01] -->

> **دوم** — *dovvom* — **second**
>
> **سوم** — *sevvom* — **third**

**The rule is one ending: ـم, *-om*, on the cardinal.** *do* + *-om* →
*dovvom*; *se* + *-om* → *sevvom*. The consonant doubles at the join, which is
the only thing you have to hear.

**سوم** is written **س**، **و**، **م** — three letters, all yours from the script
chapter. That makes it the fourth word in this book you can write unaided, after
*se*, *noh* and *avval*, whose written forms the script chapter already gave.
