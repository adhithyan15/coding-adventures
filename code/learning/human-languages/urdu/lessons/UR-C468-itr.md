## You'll want to know: عطر
<!-- hl-knowledge: introduces=[UR-LEX-C468-SMELL468-02]; assesses=[] -->

**عطر** — *itr* — "perfume; attar".

> اس عطر کی خوشبو بڑی اچھی ہے۔
>
> *is itr kī khushbū baṛī achchhī hai.*
>
> This perfume smells lovely.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**عطر** (*itr*) is usually traced, through Persian, to Arabic *ʿiṭr*, "perfume".
