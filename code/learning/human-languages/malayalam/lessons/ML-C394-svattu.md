# സ്വത്ത് (svattŭ) — property; possessions

## You'll want to know: സ്വത്ത്
<!-- hl-knowledge: introduces=[ML-LEX-C394-SVATHTHU394-01]; assesses=[] -->

**സ്വത്ത്** — *svattŭ* — "property; possessions".

> മുത്തച്ഛന്റെ സ്വത്ത് മക്കൾക്ക് കിട്ടി.
>
> *muttacchanṟe svattŭ makkaḷkkŭ kiṭṭi.*
>
> The children got grandfather's property.

Land, a house, money: everything one owns. സമ്പത്ത് is wealth in general.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**സ്വത്ത്** (*svattŭ*) is usually traced to Sanskrit *svatva*, "proprietary right, property" (Monier-Williams), from *sva*, "own".
