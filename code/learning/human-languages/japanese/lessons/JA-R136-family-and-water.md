[PAUSE 2s each] Read each one aloud and say what it means.

- [YOU READ: **かぞく** — a family]
- [YOU READ: **かぞえる** — to count]
- [YOU READ: **みず** — water]
- [YOU READ: **すずしい** — cool]
- [YOU READ: **かぜ** — a wind; a cold]

Each of these words holds one of the three signs this chapter wrote. With
them, the book writes every sign of the *z* row, **ざ じ ず ぜ ぞ**.
