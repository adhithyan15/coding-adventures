## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**مزعج** (*muzʿij*) is built on the native Arabic root *z-ʿ-j*, "to disquiet" (Lane). *Muzʿij* is the Form IV participle, "disquieting".
