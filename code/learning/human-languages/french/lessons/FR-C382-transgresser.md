## You'll want to know: transgresser
<!-- hl-knowledge: introduces=[FR-LEX-C382-INFRACTION-03]; assesses=[] -->

**transgresser** — "to transgress, to break (a rule)".

> Les adolescents aiment transgresser les règles.
>
> *Teenagers like to break the rules.*

Formal, a little literary.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*transgresser* is built on Latin *trānsgressus*, from *trānsgredī* "to step across" (Lewis & Short), built on *gradī* "to step".
