# கைவினை (kaiviṉai) — a craft; handicraft

## You'll want to know: கைவினை
<!-- hl-knowledge: introduces=[TA-LEX-C556-POTTI556-03]; assesses=[] -->

**கைவினை** — *kaiviṉai* — "a craft; handicraft".

> கைவினைப் பொருட்களைப் போட்டிக்கு அனுப்பினால் பரிசு கிடைக்கலாம்.
>
> *kaiviṉaip poruṭkaḷaip pōṭṭikku aṉuppiṉāl paricu kiṭaikkalām.*
>
> If you send craftwork to the contest, you may win a prize.

Craftwork is கைவினைப் பொருட்கள்: கை "hand" + வினை "work".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**கைவினை** (*kaiviṉai*) is a native compound: கை (*kai*), "a hand", and வினை (*viṉai*), "action, work" (DEDR 5445).
