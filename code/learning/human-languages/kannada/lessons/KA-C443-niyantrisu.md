## You'll want to know: ನಿಯಂತ್ರಿಸು
<!-- hl-knowledge: introduces=[KA-LEX-C443-SANCHARA443-05]; assesses=[] -->

**ನಿಯಂತ್ರಿಸು** — *niyantrisu* — "to control; to regulate".

> ಒಬ್ಬ ಪೊಲೀಸ್ ಸಂಚಾರವನ್ನು ನಿಯಂತ್ರಿಸುತ್ತಿದ್ದನು.
>
> *obba polīs sañcāravannu niyantrisuttiddanu.*
>
> A policeman was controlling the traffic.

Past (I …): ನಿಯಂತ್ರಿಸಿದೆ, *niyantriside*.

What is controlled takes -ಅನ್ನು; ನಿಯಂತ್ರಣ is control.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ನಿಯಂತ್ರಿಸು** (*niyantrisu*) is built from Sanskrit *niyantraṇa*, "restraining, checking, governing" (Monier-Williams), with the verb ending -*isu*.
