# വോട്ട് (vōṭṭŭ) — a vote

## You'll want to know: വോട്ട്
<!-- hl-knowledge: introduces=[ML-LEX-C419-VOTTU419-02]; assesses=[] -->

**വോട്ട്** — *vōṭṭŭ* — "a vote".

> എന്റെ വോട്ട് വളരെ പ്രധാനമാണ്.
>
> *enṟe vōṭṭŭ vaḷare pradhānamāṇŭ.*
>
> My vote is very important.

Plural: വോട്ടുകൾ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**വോട്ട്** (*vōṭṭŭ*) was borrowed from English *vote*.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
