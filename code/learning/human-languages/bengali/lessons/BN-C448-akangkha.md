# আকাঙ্ক্ষা (ākāngkhā) — a yearning; a deep desire

## You'll want to know: আকাঙ্ক্ষা
<!-- hl-knowledge: introduces=[BN-LEX-C448-BIROHO448-02]; assesses=[] -->

**আকাঙ্ক্ষা** — *ākāngkhā* — "a yearning; a deep desire".

> বড় শিল্পী হওয়াই মীরার আকাঙ্ক্ষা।
>
> *bôṛo shilpī hôoyāi mīrār ākāngkhā.*
>
> To become a great artist is Mira's deepest desire.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**আকাঙ্ক্ষা** (*ākāngkhā*) is a tatsama, Sanskrit *ākāṅkṣā*, "desire, wish" (Monier-Williams).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
