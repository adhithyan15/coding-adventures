# लीजिए (lījie) — please take; here you are

## You'll want to know: लीजिए
<!-- hl-knowledge: introduces=[HI-LEX-C115-COMEIN-03]; assesses=[] -->

**लीजिए** (*lījie*) — "please take", "here you are", as you hand something over.

It is **लेना**, "to take", with the respectful ending of **बोलिए**. **चाय लीजिए** — "have some tea".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

An offer as you hand it over.
