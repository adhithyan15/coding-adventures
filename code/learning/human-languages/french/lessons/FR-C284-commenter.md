## You'll want to know: commenter
<!-- hl-knowledge: introduces=[FR-LEX-C284-RAPPORTER-05]; assesses=[] -->

**commenter** — "to comment on".

> Il commente les matchs à la radio.
>
> *He commentates on matches on the radio.*

No *sur* after it: *commenter un match*; with the noun, *faire un commentaire sur*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*commenter* is a learned borrowing from Latin *commentārī* "to think over, to write notes on" (Lewis & Short), which is linked to the root of *mēns* "mind".
