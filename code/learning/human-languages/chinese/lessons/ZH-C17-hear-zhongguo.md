# Hear *zhōngguó* — China

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ZH-LEX-ZHONGWEN-01, ZH-LEX-QING] -->

[PAUSE 10s] Say **please**, then say **Chinese language** as *zhōngwén*.

## You'll want to know
<!-- hl-knowledge: introduces=[ZH-LEX-ZHONGGUO-01]; assesses=[] -->

> *zhōngguó* — **China**

The first syllable stays *zhōng*. Change the rising ending: *wén* names writing
or language; *guó* names a country. The new written ending waits one lesson.
