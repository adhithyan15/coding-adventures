## You'll want to know: ठिणगी
<!-- hl-knowledge: introduces=[MR-LEX-C292-AAG292-01]; assesses=[] -->

**ठिणगी** — *ṭhiṇgī* — "a spark".

> एक ठिणगी पडल्यास सगळं गवत पेटेल.
>
> *ek ṭhiṇgī paḍalyās sagḷaṁ gavat peṭel.*
>
> Should a single spark fall, all the grass will catch fire.

Feminine. Plural: ठिणग्या, *ṭhiṇagyā*.

पडल्यास, should it fall, says जर … पडली तर in one word; plural ठिणग्या.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ठिणगी** (*ṭhiṇgī*) is the everyday Marathi word for a spark; its origin is not settled.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
