## You'll want to know: محض
<!-- hl-knowledge: introduces=[UR-LEX-C367-QAIDA367-01]; assesses=[] -->

**محض** — *mahz* — "mere; merely".

> اگر یہ محض غلط فہمی ہے تو کوئی بات نہیں۔
>
> *agar yih mahz ghalat-fahmī hai to koī bāt nahīṅ.*
>
> If this is a mere misunderstanding, it does not matter.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**محض** (*mahz*) is usually traced, through Persian, to Arabic *maḥḍ*, "pure, sheer".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->
