# Changelog

All notable changes to this package will be documented in this file.

## [0.1.0] - 2026-10-29

### Added

- Bounded decoding of the shared RFC 8446 `SignatureSchemeList` wire shape.
- Borrowed exact-input retention and ordered iteration over opaque scheme IDs.
- Payload-free failures, identifier-redacted diagnostics, and caller limits.
