## You'll want to know: മരുമകൻ
<!-- hl-knowledge: introduces=[ML-LEX-C125-KIN-05]; assesses=[] -->

**മരുമകൻ** (*marumakan*) — "a nephew", and also "a son-in-law". It contains **മകൻ**
(*makan*), "son".

## What you've built
