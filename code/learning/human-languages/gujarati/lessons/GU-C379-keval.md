## You'll want to know: કેવળ
<!-- hl-knowledge: introduces=[GU-LEX-C379-ATYANT379-05]; assesses=[] -->

**કેવળ** — *kevaḷ* — "solely".

> જો તમે કેવળ પૈસા માટે કામ કરશો તો ખુશ નહીં રહો.
>
> *jo tame kevaḷ paisā māṭe kām karśo to khuś nahī̃ raho.*
>
> If you work only for money, you will not be happy.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**કેવળ** (*kevaḷ*) is a tatsama, borrowed from Sanskrit *kevala*, "alone, exclusive, entire" (Monier-Williams).
