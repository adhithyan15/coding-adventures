# مسألة (masʾala) — a matter

## You'll want to know: مسألة
<!-- hl-knowledge: introduces=[AR-LEX-C361-QADIYYA361-02]; assesses=[] -->

**مسألة** — *masʾala* — "a matter".

> هذه مسألة صعبة.
>
> *hādhihi masʾala ṣaʿba.*
>
> This is a difficult matter.

Also a problem in arithmetic: مسألة حساب.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**مسألة** (*masʾala*) is built on the native Arabic root *s-ʾ-l*, "to ask" (Lane). A *masʾala* is a thing asked about: a question to settle, a matter.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
