## You'll want to know: блуждать
<!-- hl-knowledge: introduces=[RU-LEX-C437-ZABLUDITSYA-03]; assesses=[] -->

**блуждать** (*bluzhdát*) — "to roam, to wander".

> Мы два часа блуждали по лесу.
>
> *My dva chasá bluzhdáli po lésu.*
>
> We wandered around the forest for two hours.

Imperfective; takes *по* + dative. Present *блуждаю*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*блуждать* is built on *блуд* (EtymDB), from Proto-Slavic *blǫdŭ*; the same root gives *заблудиться* 'to get lost'.
