# बोलिए — the ending you have been saying for eighty chapters

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[HI-CONCEPT-C09-MAAF-KIJIYE-01] -->

[PAUSE 2s] Say *māf kījiye*. You learned it as one lump meaning "sorry." Say it
again and listen to the end of the second word.

## You'll want to know: बोलिए
<!-- hl-knowledge: introduces=[HI-LEX-C85-IMP-02]; assesses=[] -->

**बोलिए** (*boliye*) — "please speak," said to somebody you would call **आप**.

The ending is **-iye**, on the same stem as before:

> *bolnā* → **bol** → **boliye**

And now the lump comes apart. **कीजिए** is *karnā*, "to do," with this same
ending: *kar* + *-iye*. *Māf kījiye* is literally **"please do forgiveness."**
You have been giving a respectful command since the ninth chapter without
knowing it was one.

## Grammar Lens: politeness is built in, not added on
<!-- hl-knowledge: introduces=[]; assesses=[HI-LEX-C85-IMP-02, HI-LEX-C85-IMP-01] -->

| | command | how politeness is carried |
|---|---|---|
| English | speak | by adding *please* |
| Hindi तुम | बोलो | by the ending |
| Hindi आप | बोलिए | by the ending |

**बोलिए** already contains the respect, so it needs no *kṛpayā*. Adding one is
not wrong — it is warmer, the way *would you mind* is warmer than *please* — but
the bare form is complete and polite on its own.

A stem ending in a vowel lengthens slightly before **-iye**: *karnā* gives
**kījiye**, not *kariye*, and *denā* gives **dījiye**. Those two are the ones you
will meet most, and you already had the first.
