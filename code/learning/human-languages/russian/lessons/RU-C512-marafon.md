## You'll want to know: марафон
<!-- hl-knowledge: introduces=[RU-LEX-C512-RACE-01]; assesses=[] -->

**марафон** (*marafón*) — "a marathon".

> Мой брат пробежал свой первый марафон.
>
> *Moy brat probezhál svoy pérvyy marafón.*
>
> My brother has run his first marathon.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*марафон* was borrowed from Greek *Marathṓn* (EtymDB), a place name built on *márathon* 'fennel'.
