# दोबारा (dobārā) — again, a second time

## You'll want to know: दोबारा
<!-- hl-knowledge: introduces=[HI-LEX-C110-AGAIN-01]; assesses=[] -->

**दोबारा** (*dobārā*) — "again, a second time".

**दोबारा बोलिए** — "please say it again". It is **दो**, "two", and **बार**, "a time".
