## You'll want to know: o carteirista
<!-- hl-knowledge: introduces=[PT-LEX-C287-ROUBO-04]; assesses=[] -->

**o carteirista** — "the pickpocket".

> Um carteirista tirou-me o telemóvel no elétrico.
>
> *A pickpocket took my mobile on the tram.*

Built on *carteira* ‘wallet’. In Brazil: *o batedor de carteira*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*carteirista* is built on *carteira* "wallet", from *carta*, which comes from Latin *charta* "paper" (EtymDB), with *-ista* for the person.
