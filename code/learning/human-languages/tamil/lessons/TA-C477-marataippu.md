# மாரடைப்பு (māraṭaippu) — a heart attack

## You'll want to know: மாரடைப்பு
<!-- hl-knowledge: introduces=[TA-LEX-C477-NOYKAL477-01]; assesses=[] -->

**மாரடைப்பு** — *māraṭaippu* — "a heart attack".

> தாத்தாவுக்கு மாரடைப்பு வந்ததால் மருத்துவமனைக்குப் போனோம்.
>
> *tāttāvukku māraṭaippu vantatāl maruttuvamaṉaikkup pōṉōm.*
>
> We went to the hospital because grandfather had a heart attack.

மார் "chest" + *aṭaippu* "a blockage": the heart's vessels close.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**மாரடைப்பு** (*māraṭaippu*) is a native compound built from மார் *mār*, "breast, chest" (DEDR 4818), and *aṭaippu*, "a blockage".
