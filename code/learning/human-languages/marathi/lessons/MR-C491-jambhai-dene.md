# जांभई देणे (jāmbhaī deṇe) — to yawn

## You'll want to know: जांभई देणे
<!-- hl-knowledge: introduces=[MR-LEX-C491-ZOP491-03]; assesses=[] -->

**जांभई देणे** — *jāmbhaī deṇe* — "to yawn".

> कंटाळवाण्या भाषणात सगळे जांभई देत होते.
>
> *kaṇṭāḷvāṇyā bhāṣṇāt sagḷe jāmbhaī det hote.*
>
> Everyone was yawning through the boring speech.

Past, with -ने (he …): त्याने जांभई दिली, *tyāne jāmbhaī dilī*.

जांभई, a yawn; जांभई येणे, to feel a yawn coming, with the dative.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**जांभई देणे** (*jāmbhaī deṇe*) is a Marathi phrase built on जांभई, "a yawn", which is inherited: CDIAL lists Old Marathi *jāmbhaī*, "yawning", under *\*jṛmbhāyita* (CDIAL 5266); देणे, "to give", is the light verb.
