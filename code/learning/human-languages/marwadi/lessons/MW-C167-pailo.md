## You'll want to know: पैलो
<!-- hl-knowledge: introduces=[MW-LEX-C167-KAM167-02]; assesses=[] -->

**पैलो** — *pailo* — "first".

> पैलो काम घणो दोरो है।
>
> *pailo kām ghaṇo doro hai.*
>
> The first job is very hard.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**पैलो** (*pailo*) is inherited from a reconstructed *\*prathila*, "first"; CDIAL lists Old Marwari *pahalo* (CDIAL 8652). It agrees like an adjective: **पैली रोटी**, the first roti.
