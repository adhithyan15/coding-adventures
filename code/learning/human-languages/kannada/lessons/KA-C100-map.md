## You'll want to know: ನಕ್ಷೆ
<!-- hl-knowledge: introduces=[KA-LEX-C100-FIND-01]; assesses=[] -->

**ನಕ್ಷೆ** (*nakṣe*) — "a map". The **ಕ್ಷ** is *k* and *ṣ* joined, the same pair as
in **ಕ್ಷಮಿಸಿ**.

**ನಕ್ಷೆ ತೋರಿಸಿ** (*nakṣe tōrisi*) — "please show me the map".
