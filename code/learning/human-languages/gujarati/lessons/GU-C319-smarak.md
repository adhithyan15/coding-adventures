## You'll want to know: સ્મારક
<!-- hl-knowledge: introduces=[GU-LEX-C319-KILLO319-03]; assesses=[] -->

**સ્મારક** — *smārak* — "a memorial".

> ગામના લોકોએ ત્યાં એક સ્મારક બનાવ્યું.
>
> *gāmnā lokoe tyā̃ ek smārak banāvyũ.*
>
> The villagers built a memorial there.

A neuter noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**સ્મારક** (*smārak*) is a tatsama, Sanskrit *smāraka*, "recalling, reminding of" (Monier-Williams): a thing put up so that people remember.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
