## You'll want to know: embarcar
<!-- hl-knowledge: introduces=[ES-LEX-C653-EMBARQUE-01]; assesses=[] -->

**embarcar** — "to board; to embark".

> Los pasajeros ya pueden embarcar.
>
> *Passengers can now board.*

Used for planes as well as ships.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*embarcar* is built on *barca* "boat", which is inherited from Late Latin *barca* (EtymDB). Getting on a plane is still getting on a boat.
