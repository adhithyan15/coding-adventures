# زبردست (zabardast) — tremendous; terrific

## You'll want to know: زبردست
<!-- hl-knowledge: introduces=[UR-LEX-C375-BAHUT375-04]; assesses=[] -->

**زبردست** — *zabardast* — "tremendous; terrific".

> اگر یہ فلم زبردست ہوئی تو ہم پھر دیکھیں گے۔
>
> *agar yih film zabardast huī to ham phir dekheṅ ge.*
>
> If this film is terrific, we will watch it again.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**زبردست** (*zabardast*) is usually traced to Persian *zabardast*, "having the upper hand": *zabar*, "above", and *dast*, "a hand".
