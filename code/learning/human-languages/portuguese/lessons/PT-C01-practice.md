## What you've built — the day of greetings
<!-- hl-knowledge: introduces=[]; assesses=[PT-PHONO-OLA-01, PT-ETYMON-OLA-02, PT-PRAGMATIC-OLA-03, PT-SOUND-BOM-02, PT-ETYMON-BOM-03, PT-GRAMMAR-BOM-04, PT-ETYMON-O-A-02, PT-GRAMMAR-O-A-03, PT-ETYMON-DIA-02, PT-GRAMMAR-DIA-03, PT-LEX-BOM-DIA-02, PT-PRAGMATIC-BOM-DIA-03, PT-ETYMON-TARDE-02, PT-ETYMON-NOITE-02, PT-LEX-NOITE-03, PT-SOUND-OBRIGADO-02, PT-ETYMON-OBRIGADO-03, PT-GRAMMAR-OBRIGADO-04] -->

| Portuguese | English |
|---|---|
| *olá* | hi |
| *bom dia* | good morning |
| *boa tarde* | good afternoon |
| *boa noite* | good night |
| *obrigado / obrigada* | thank you |

Every piece traced:

- **bom** ← *bonus*
- **dia** ← *dies* (masculine, despite the *-a*)
- **tarde** ← *tardus* ("late"; English *tardy*)
- **noite** ← *noctem*, via *-ct-* → *-it-* (like French *nuit*)
- **obrigado** ← *obligātus* ("obliged"; English *obligated*)

And two Portuguese habits: the article eroded to a single vowel (**o / a**), and
"thank you" agrees with the **speaker** (*obrigado* m. / *obrigada* f.).
