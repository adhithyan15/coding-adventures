# విభేదించు (vibhēdiñcu) — to disagree

## You'll want to know: విభేదించు
<!-- hl-knowledge: introduces=[TE-LEX-C386-ABHYANTARAM386-01]; assesses=[] -->

**విభేదించు** — *vibhēdiñcu* — "to disagree".

> ఆ విషయంలో నేను మీతో విభేదిస్తాను.
>
> *ā viṣayaṁlō nēnu mītō vibhēdistānu.*
>
> On that matter I disagree with you.

Past (I …): విభేదించాను, *vibhēdiñcānu*.

Like ఏకీభవించు, it takes -తో: మీతో విభేదిస్తాను.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**విభేదించు** (*vibhēdiñcu*) is built on Sanskrit *vibheda*, "a breaking asunder, a division" (Monier-Williams), with the Telugu verb ending -ఇంచు.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
