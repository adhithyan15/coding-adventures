# coding_adventures_trig

Pure Dart implementation of the PHY00 trigonometry contract. The package
computes its numeric results from first principles and does not delegate to
`dart:math` trigonometric functions.

## What it provides

- `pi`, `twoPi`, and `halfPi` angle constants;
- `sin` and `cos` by the PHY00a reference algorithm (TRIG-REF-1): Cody-Waite
  range reduction and Horner-evaluated Maclaurin kernels, within 3 ulp, NaN
  beyond `2^29` radians;
- `radians` and `degrees` as one multiply each, within 1 ulp;
- `sqrt` using power-of-four-normalized Newton iteration with explicit
  negative-input rejection, signed-zero preservation, and infinity handling;
- `tan`, `atan`, and four-quadrant `atan2` built on the local primitives.

For `|x| <= 2^-27`, `atan` returns `x` unchanged before any half-angle
reduction. That exact binary64 identity preserves negative zero and both signs
of the minimum subnormal, as required by the shared PHY00 fixtures.

## Bit-exact on the Dart VM, not on the web

Results are bit for bit those of `code/specs/PHY00a-trig-convergence.md`
(TRIG-REF-1), verified against the 62,154 shared vectors in
`code/specs/fixtures/trig-reference-v1` under the Dart VM, JIT and AOT. **This is
a claim about the Dart VM only.** Under dart2js numbers are JavaScript numbers and
nothing has been run there, so no bit-exactness is claimed on the web, and the
conformance test is `@TestOn('vm')`. `tan`, `sqrt`, `atan` and `atan2` are pinned
conventions and legacy algorithms that make no accuracy claim.

The PHY00 tolerance corpus (`1e-10`) is still consumed too, including tiny normal
and subnormal square roots.
Tangent returns the exact signed finite sentinel `1e308` within `1e-15` of a
pole, matching the cross-language contract.

## Usage

```dart
import 'package:coding_adventures_trig/trig.dart' as trig;

void main() {
  final angle = trig.radians(45.0);
  print(trig.sin(angle));
  print(trig.atan2(1.0, -1.0));
}
```

## How it fits in the stack

This is the dependency-free PHY00 numeric leaf. The PHY01 `wave` package uses
its `pi` constant and `sin` implementation.

## Running the tests

This package declares no filesystem capability, so no test reads a file. The
PHY00 cases and the TRIG-REF-1 vectors are decoded from generated Dart source
(`../../../specs/fixtures/phy00-phy01-v1/dart/` and `test/generated/`, the latter
regenerated by `code/scripts/generate_trig_reference_dart_fixtures.py`) by
validating loaders.

```sh
dart pub get
dart analyze
dart test
dart test --compiler exe   # the same suite, AOT-compiled
```
