## You'll want to know: безопасность
<!-- hl-knowledge: introduces=[RU-LEX-C400-BEZOPASNOST-02]; assesses=[] -->

**безопасность** (*bezopásnost*) — "safety, security".

> Безопасность детей — главное.
>
> *Bezopásnost detéy — glávnoye.*
>
> Children’s safety comes first.

Feminine. *В безопасности* — safe. Built on *опасный*, dangerous.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**безопасность** is built from *без* "without" and *опасность* "danger", from *опасный*, which is built on *опасаться* "to be wary", from *пасти* "to guard".
