# ਅਮਨ — one new piece, two old pieces

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-SCRIPT-INDEPENDENT-A-01, PA-SCRIPT-MA-01, PA-SCRIPT-NA-01] -->

Read the three separate pieces: **ਅ · ਮ · ਨ**.

## Script — assemble the practice name
<!-- hl-knowledge: introduces=[PA-FORM-NAME-AMAN-01]; assesses=[PA-SCRIPT-INDEPENDENT-A-01, PA-SCRIPT-MA-01, PA-SCRIPT-NA-01] -->

> **ਅ** + **ਮ** + **ਨ** → **ਅਮਨ**

This book uses **ਅਮਨ** as one closed-bank practice identity. It is not asking
you to spell your own name yet.

## Writing — guided copy
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-NAME-AMAN-01] -->

Keep **ਅਮਨ** visible. Copy it once, saying each piece as your hand reaches it.
Compare left to right. Repair only the first differing piece.
