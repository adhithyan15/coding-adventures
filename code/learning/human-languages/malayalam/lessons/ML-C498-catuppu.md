# ചതുപ്പ് (catuppŭ) — a swamp; a marsh

## You'll want to know: ചതുപ്പ്
<!-- hl-knowledge: introduces=[ML-LEX-C498-KANTAL498-02]; assesses=[] -->

**ചതുപ്പ്** — *catuppŭ* — "a swamp; a marsh".

> ആ ചതുപ്പിൽ ധാരാളം പക്ഷികൾ ഉണ്ട്.
>
> *ā catuppil dhārāḷaṁ pakṣikaḷ uṇṭŭ.*
>
> There are many birds in that swamp.

Wet land where your feet sink: ചതുപ്പുനിലം.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ചതുപ്പ്** (*catuppŭ*) is native Dravidian, "a marsh, boggy ground" (DEDR 2326).
