# ਕਮਰੇ — room in one location phrase

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-PLACE-THAAN-LOCATION-01, PA-LEX-C71-HOME71-01] -->

[PAUSE 2s] Say **ਉਸ ਥਾਂ**, then the old room word **ਕਮਰਾ**.

## Grammar Lens: one room phrase
<!-- hl-knowledge: introduces=[PA-PLACE-KAMRE-ROOM-01]; assesses=[PA-LEX-C71-HOME71-01, PA-POSTPOSITION-VICH-01] -->

> **ਕਮਰਾ** — *kamrā* — a room (the old word)

> **ਕਮਰੇ ਵਿੱਚ** — *kamre vic* — in the room

The ending changes inside this one location phrase. Use this model first; do not infer every possible room ending from it.
