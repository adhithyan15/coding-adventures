## You'll want to know: संसर्ग
<!-- hl-knowledge: introduces=[MR-LEX-C484-ROG484-02]; assesses=[] -->

**संसर्ग** — *saṁsarga* — "an infection; contagion".

> जखमेत संसर्ग होऊ नये म्हणून मलम लावलं.
>
> *jakhmet saṁsarga hoū naye mhaṇūn malam lāvlaṁ.*
>
> We put ointment on the wound so that it would not get infected.

Masculine.

संसर्ग होणे, to get infected; संसर्गजन्य, contagious.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**संसर्ग** (*saṁsarga*) is a tatsama, taken from Sanskrit *saṁsarga*, "mixture, intercourse", that is, contact (CDIAL 13033).
