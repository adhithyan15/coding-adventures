# ઊંચકવું (ū̃cakvũ) — to lift, to carry

[PAUSE 2s] Before the new one: say the Gujarati for permit, then the Gujarati for to load.

## You'll want to know: ઊંચકવું
<!-- hl-knowledge: introduces=[GU-LEX-C210-PAPERS210-05]; assesses=[] -->

**ઊંચકવું** — *ū̃cakvũ* — "to lift, to carry".

> **તેણે ભારે થેલી ઊંચકી.** — *teṇe bhāre thelī ū̃cakī* — "She lifted the heavy bag."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ઊંચકવું** (*ū̃cakvũ*) is a tadbhava. CDIAL lists it, glossed "to raise", under Sanskrit *ucca*, "tall, lofty", built with the suffix *-akka-* (CDIAL 1634).
