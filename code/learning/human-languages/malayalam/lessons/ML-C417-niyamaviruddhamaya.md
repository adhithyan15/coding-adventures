# നിയമവിരുദ്ധമായ (niyamaviruddhamāya) — illegal

## Warm-up

[PAUSE 2s] Before the new one: say the Malayalam for to obey, then the Malayalam for legal.

## You'll want to know: നിയമവിരുദ്ധമായ
<!-- hl-knowledge: introduces=[ML-LEX-C417-CATTAM417-05]; assesses=[] -->

**നിയമവിരുദ്ധമായ** — *niyamaviruddhamāya* — "illegal".

> അവിടെ പാർക്ക് ചെയ്യുന്നത് നിയമവിരുദ്ധമാണ്.
>
> *aviṭe pārkkŭ ceyyunnatŭ niyamaviruddhamāṇŭ.*
>
> Parking there is illegal.

The opposite of നിയമപരമായ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**നിയമവിരുദ്ധമായ** (*niyamaviruddhamāya*) is built from Sanskrit *niyama*, "a fixed law" (CDIAL 7250), and *viruddha*, "opposed, hindered" (CDIAL 11864), with the adjective ending -ആയ: against the law.

## What you've built
