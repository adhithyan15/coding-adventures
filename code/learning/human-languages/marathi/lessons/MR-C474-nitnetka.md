# नीटनेटका (nīṭneṭkā) — tidy; neat

## You'll want to know: नीटनेटका
<!-- hl-knowledge: introduces=[MR-LEX-C474-SHISTA474-01]; assesses=[] -->

**नीटनेटका** — *nīṭneṭkā* — "tidy; neat".

> तिची खोली नेहमी नीटनेटकी असते.
>
> *ticī kholī nehmī nīṭneṭkī aste.*
>
> Her room is always neat and tidy.

Agrees: नीटनेटका, नीटनेटकी, नीटनेटकं.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**नीटनेटका** (*nīṭneṭkā*) is a Marathi pair-word, नीट, "properly", with नेटका, "trim"; the origin of each part is not settled.
