# இல்லையேல் (illaiyēl) — or else; otherwise

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TA-LEX-C383-CATTIYAM383-03, TA-LEX-C383-CATTIYAM383-04] -->

[PAUSE 2s] Before the new one: say the Tamil for probably, then the Tamil for an occasion.

## You'll want to know: இல்லையேல்
<!-- hl-knowledge: introduces=[TA-LEX-C383-CATTIYAM383-05]; assesses=[] -->

**இல்லையேல்** — *illaiyēl* — "or else; otherwise".

> நாம் சீக்கிரம் புறப்பட வேண்டும், இல்லையேல் பேருந்தைத் தவறவிடுவோம்.
>
> *nām cīkkiram puṟappaṭa vēṇṭum, illaiyēl pēruntait tavaṟaviṭuvōm.*
>
> We must leave early, or else we will miss the bus.

A formal written word; the everyday one is இல்லாவிட்டால்.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**இல்லையேல்** (*illaiyēl*) is native: *illai*, "it is not" (DEDR 2559), with the old conditional ending -ஏல், "if": "if it is not so".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
