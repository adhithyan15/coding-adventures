## You'll want to know: மொழி
<!-- hl-knowledge: introduces=[TA-LEX-C104-ABOUT-01]; assesses=[] -->

**மொழி** (*moḻi*) — "a language".

**தமிழ் என் மொழி** — "Tamil is my language". **தாய்மொழி** is "mother tongue".
