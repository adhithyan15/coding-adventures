# معاوضہ (muāvazā) — compensation (for a loss or for work)

## You'll want to know: معاوضہ
<!-- hl-knowledge: introduces=[UR-LEX-C540-GHATA540-03]; assesses=[] -->

**معاوضہ** — *muāvazā* — "compensation (for a loss or for work)".

> اگر آپ نے یہ کام کیا تو معاوضہ ملے گا۔
>
> *agar āp ne yih kām kiyā to muāvazā mile gā.*
>
> If you do this job, you will be paid for it.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**معاوضہ** (*muāvazā*) is usually traced, through Persian, to Arabic *muʿāwaḍa*, "an exchange, a giving in return".
