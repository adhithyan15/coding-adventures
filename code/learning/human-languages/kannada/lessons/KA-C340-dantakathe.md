# ದಂತಕಥೆ (dantakathe) — a legend

## You'll want to know: ದಂತಕಥೆ
<!-- hl-knowledge: introduces=[KA-LEX-C340-DANTAKATHE340-01]; assesses=[] -->

**ದಂತಕಥೆ** — *dantakathe* — "a legend".

> ಈ ಕೋಟೆಯ ಬಗ್ಗೆ ಒಂದು ದಂತಕಥೆ ಇದೆ.
>
> *ī kōṭeya bagge ondu dantakathe ide.*
>
> There is a legend about this fort.

Plural: ದಂತಕಥೆಗಳು, *dantakathegaḷu*.

A story told from one generation to the next, partly history and partly not.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ದಂತಕಥೆ** (*dantakathe*) is a Kannada compound whose second part is ಕಥೆ, "a story", from Sanskrit *kathā* (CDIAL 2704); the origin of the first part is not settled.
