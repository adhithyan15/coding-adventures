# അധ്വാനിക്കുക (adhvānikkuka) — to toil; to labour

## You'll want to know: അധ്വാനിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C551-ADHVANAM551-05]; assesses=[] -->

**അധ്വാനിക്കുക** — *adhvānikkuka* — "to toil; to labour".

> കുടുംബത്തിന് വേണ്ടി അച്ഛൻ രാവും പകലും അധ്വാനിച്ചു.
>
> *kuṭumbattinŭ vēṇṭi acchan rāvuṁ pakaluṁ adhvāniccu.*
>
> Father toiled day and night for the family.

Past: അധ്വാനിച്ചു, *adhvāniccu*.

The noun is അധ്വാനം, toil; കഠിനാധ്വാനി holds it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**അധ്വാനിക്കുക** (*adhvānikkuka*) is built on അധ്വാനം, "toil", with the Malayalam verb ending -ിക്കുക; where അധ്വാനം itself comes from is not settled.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
