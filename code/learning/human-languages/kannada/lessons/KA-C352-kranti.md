# ಕ್ರಾಂತಿ (krānti) — a revolution

## You'll want to know: ಕ್ರಾಂತಿ
<!-- hl-knowledge: introduces=[KA-LEX-C352-DANGE352-02]; assesses=[] -->

**ಕ್ರಾಂತಿ** — *krānti* — "a revolution".

> ಆ ಕ್ರಾಂತಿ ದೇಶದ ಇತಿಹಾಸವನ್ನೇ ಬದಲಿಸಿತು.
>
> *ā krānti dēśada itihāsavannē badalisitu.*
>
> That revolution changed the country's history.

Plural: ಕ್ರಾಂತಿಗಳು, *krāntigaḷu*.

Also a great change: ಹಸಿರು ಕ್ರಾಂತಿ, the green revolution in farming.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಕ್ರಾಂತಿ** (*krānti*) is borrowed from Sanskrit *krānti*, "going, proceeding, a step", and "overcoming" (Monier-Williams); "a revolution" is a modern sense.

## What you've built
