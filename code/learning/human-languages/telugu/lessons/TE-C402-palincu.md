# పాలించు (pāliñcu) — to govern; to rule

## You'll want to know: పాలించు
<!-- hl-knowledge: introduces=[TE-LEX-C402-MANTRI402-04]; assesses=[] -->

**పాలించు** — *pāliñcu* — "to govern; to rule".

> ఆ కుటుంబం ఆ ప్రాంతాన్ని చాలా కాలం పాలించింది.
>
> *ā kuṭumbaṁ ā prāntānni cālā kālaṁ pāliñcindi.*
>
> That family ruled the region for a long time.

Past (I …): పాలించాను, *pāliñcānu*.

The noun is పాలన, rule.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**పాలించు** (*pāliñcu*) is built on Sanskrit *pālana*, "protecting, nourishing" (CDIAL 8128), with the Telugu verb ending -ఇంచు; Telugu uses it for ruling and governing.
