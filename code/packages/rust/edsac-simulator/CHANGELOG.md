# Changelog

All notable changes to this package will be documented in this file.

## [0.1.0] - 2026-10-24

### Added

- Complete source-backed 1949 EDSAC order execution over 1024 short storage
  locations with exact 17/35-bit packing and Cambridge tank-slice arithmetic.
- Paper-tape input, teleprinter output and verification, serial shifts,
  multiplication, collation, signed control flow, rounding, and halt.
- Strict transport, complete snapshots, checked restoration, typed atomic
  faults, canonical traces, and transactional bounded execution.
