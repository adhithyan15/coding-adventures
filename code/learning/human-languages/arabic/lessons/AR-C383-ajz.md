## You'll want to know: عجز
<!-- hl-knowledge: introduces=[AR-LEX-C383-IQTISAD383-03]; assesses=[] -->

**عجز** — *ʿajz* — "a deficit".

> عند الدولة عجز كبير هذه السنة.
>
> *ʿinda ad-dawla ʿajz kabīr hādhihi as-sana.*
>
> The state has a big deficit this year.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**عجز** (*ʿajz*) is built on the native Arabic root *ʿ-j-z*, "to be unable, weak" (Lane). *ʿAjz* is inability, falling short: a deficit.
