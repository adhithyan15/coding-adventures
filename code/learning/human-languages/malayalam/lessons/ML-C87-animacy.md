# പുസ്തകം വായിക്കുന്നു — the ending a book does not take

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-GRAMMAR-C87-ACCUSATIVE-01, ML-LEX-C46-ASK-05] -->

[PAUSE 2s] Say *I see the teacher*, and say which word carried the ending. Then
say the word for a book.

## Grammar Lens: what kind of thing the object is
<!-- hl-knowledge: introduces=[ML-GRAMMAR-C87-ANIMACY-01]; assesses=[] -->

You might expect every object to take the ending. **It does not work that way.**

| | |
|---|---|
| **ഞാൻ കുട്ടിയെ കാണുന്നു** | I see the child — **ending** |
| **ഞാൻ പുസ്തകം വായിക്കുന്നു** | I read the book — **no ending** |

Both are objects. Both come before the verb. **One is a person and the other is
a thing, and that is the whole of it.**

**A living thing being acted on takes -എ. A lifeless thing ordinarily does
not.** So the question the language asks before marking an object is not *is
this the object* but **what kind of thing is this** — and no European language
the reader is likely to know asks it in quite that way.

Look at what the ending does to each noun:

| | |
|---|---|
| **കുട്ടി** → **കുട്ടിയെ** | a **-യ-** joins, because the word ends in **ഇ** |
| **അധ്യാപകൻ** → **അധ്യാപകനെ** | the final chillu opens back into a plain consonant |

**The joining rule is the one you already know.** It is the same choice the
owner-ending made, decided by the same thing — **the last sound of the noun** —
so there is nothing new to learn about attaching it.

Now a verb that only takes people: **സഹായിക്കുക**, to help. You cannot help a
book, so its object is **always** marked.
