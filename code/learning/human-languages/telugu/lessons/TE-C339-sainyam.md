# సైన్యం (sainyaṁ) — an army

## You'll want to know: సైన్యం
<!-- hl-knowledge: introduces=[TE-LEX-C339-SAINYAM339-01]; assesses=[] -->

**సైన్యం** — *sainyaṁ* — "an army".

> శత్రువు సైన్యం కోట దగ్గరకు వచ్చింది.
>
> *śatruvu sainyaṁ kōṭa daggaraku vaccindi.*
>
> The enemy army came near the fort.

Plural: సైన్యాలు, *sainyālu*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**సైన్యం** (*sainyaṁ*) is borrowed from Sanskrit *sainya*, "belonging to an army; an army" (CDIAL 13602), built on *senā*, "an army".
