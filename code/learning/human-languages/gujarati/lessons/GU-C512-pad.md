# પદ (pad) — a job post

## You'll want to know: પદ
<!-- hl-knowledge: introduces=[GU-LEX-C512-NOKRI512-01]; assesses=[] -->

**પદ** — *pad* — "a job post".

> આ પદ માટે ઘણી અરજીઓ આવી.
>
> *ā pad māṭe ghaṇī arjīo āvī.*
>
> Many applications came in for this post.

A neuter noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**પદ** (*pad*) is a tatsama, taken from Sanskrit *pada*, "a step, a footing; a position" (Monier-Williams); in an office it is a post one is appointed to.
