## You'll want to know: o estereótipo
<!-- hl-knowledge: introduces=[PT-LEX-C365-JUSTICA-05]; assesses=[] -->

**o estereótipo** — "the stereotype".

> Muitos filmes repetem o mesmo estereótipo.
>
> *Many films repeat the same stereotype.*

First a printing plate cast in one solid piece.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*estereótipo* is built from Greek *stereós* "solid" and *tipo* "type" (EtymDB), probably through French *stéréotype*; it first named a printing plate cast in one solid piece.
