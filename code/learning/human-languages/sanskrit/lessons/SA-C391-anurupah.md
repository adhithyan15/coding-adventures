# अनुरूपः (anurūpaḥ) — in keeping with; suitable

## You'll want to know: अनुरूपः
<!-- hl-knowledge: introduces=[SA-LEX-C391-PARAMA391-03]; assesses=[] -->

**अनुरूपः** — *anurūpaḥ* — "in keeping with; suitable".

> यदि वेतनं कार्यस्य अनुरूपम्, तर्हि कर्मकरः तुष्यति।
>
> *yadi vetanaṃ kāryasya anurūpam, tarhi karmakaraḥ tuṣyati.*
>
> If the wage fits the work, the worker is content.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**अनुरूपः** (*anurūpaḥ*) is built from *anu*, "after", and *rūpa*, "form"; MW gives *anu-rūpa* "following the form, conformable, corresponding, fit, suitable" (MW).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
