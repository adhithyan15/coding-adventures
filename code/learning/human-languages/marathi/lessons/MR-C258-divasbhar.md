## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**दिवसभर** (*divasbhar*) is *divas*, "day", from Sanskrit *divasa* (CDIAL 6333), with *-bhar*, "full", from *bharṇẽ*, "to fill" (CDIAL 9397).
