# સુખ (sukh) — contentment, happiness

## You'll want to know: સુખ
<!-- hl-knowledge: introduces=[GU-LEX-C266-FEELINGS266-02]; assesses=[] -->

**સુખ** — *sukh* — "contentment, happiness".

> **શું પૈસામાં સુખ છે?** — *śũ paisāmā̃ sukh che?* — "Is there happiness in money?"

A neuter noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**સુખ** (*sukh*) is Sanskrit *sukhá*, "pleasant; comfort, happiness", taken over as a tatsama (CDIAL 13451). The same entry lists the inherited *sahelũ*, "easy".
