# சராசரி (carācari) — an average

## You'll want to know: சராசரி
<!-- hl-knowledge: introduces=[TA-LEX-C363-PULLIVIVARAM363-03]; assesses=[] -->

**சராசரி** — *carācari* — "an average".

> இந்த வகுப்பின் சராசரி மதிப்பெண் எழுபது.
>
> *inta vakuppiṉ carācari matippeṇ eḻupatu.*
>
> The average mark in this class is seventy.

சராசரியாக, on average.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**சராசரி** (*carācari*) is usually traced to Persian *sarāsar*, "from end to end, throughout", which reached Tamil through Hindustani: a figure taken across the whole.
