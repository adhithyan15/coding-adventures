## You'll want to know: نصب
<!-- hl-knowledge: introduces=[AR-LEX-C439-MANZAR439-03]; assesses=[] -->

**نصب** — *nuṣb* — "a monument".

> زرنا النصب في ساحة المدينة.
>
> *zurnā an-nuṣb fī sāḥat al-madīna.*
>
> We visited the monument in the city square.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**نصب** (*nuṣb*) is built on the native Arabic root *n-ṣ-b*, "to set up, to erect" (Lane). A *nuṣb* is a thing set upright.
