## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**bottiglia** ← French *bouteille*, "bottle" — borrowed; the French word goes back to Medieval Latin *butticula*, "little cask". (EtymDB 2.1)
