# ಷರತ್ತು (ṣarattu) — a condition; a term

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C410-HIGAGI410-04, KA-LEX-C410-HIGAGI410-05] -->

[PAUSE 2s] Before the new one: say the Kannada for above all, then the Kannada for not only that.

## You'll want to know: ಷರತ್ತು
<!-- hl-knowledge: introduces=[KA-LEX-C411-SHARATTU411-01]; assesses=[] -->

**ಷರತ್ತು** — *ṣarattu* — "a condition; a term".

> ಒಂದು ಷರತ್ತಿನ ಮೇಲೆ ನಾನು ಒಪ್ಪುತ್ತೇನೆ.
>
> *ondu ṣarattina mēle nānu opputtēne.*
>
> I agree on one condition.

ಷರತ್ತಿನ ಮೇಲೆ, on condition. ಷರತ್ತುಗಳು, terms.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಷರತ್ತು** (*ṣarattu*) is a loan from Arabic *sharṭ*, "a condition", which reached Kannada through Hindustani.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
