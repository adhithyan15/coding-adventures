# આશ્વાસન (āśvāsan) — comfort; consolation

## You'll want to know: આશ્વાસન
<!-- hl-knowledge: introduces=[GU-LEX-C298-MRUTYU298-04]; assesses=[] -->

**આશ્વાસન** — *āśvāsan* — "comfort; consolation".

> પડોશીઓએ કુટુંબને આશ્વાસન આપ્યું.
>
> *paḍośīoe kuṭumbne āśvāsan āpyũ.*
>
> The neighbours comforted the family.

A neuter noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**આશ્વાસન** (*āśvāsan*) is a tatsama, Sanskrit *āśvāsana*, "reviving, consoling" (Monier-Williams). It is given: **આશ્વાસન આપ્યું**, offered comfort.
