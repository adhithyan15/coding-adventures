# la batería — the ending that is not one

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ES-LEX-C432-CASA-04, ES-LEX-C434-MAQ-03] -->

[PAUSE 2s] Say *la tubería*. You learned that **-ería** collects. Here is a word
that ends the same way. Guess what it collects, then read on.

## You'll want to know: la batería
<!-- hl-knowledge: introduces=[ES-LEX-C434-MAQ-04]; assesses=[] -->

**la batería** — the battery. The one in a car, a phone, a torch.

It also names a **drum kit**, which is the same idea of *a set of things acting
together*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[ES-LEX-C434-MAQ-04, ES-LEX-C432-CASA-04] -->

**Here the guess fails, and it is worth knowing why.**

There is no Spanish word *bate* that *batería* collects. The word arrived whole
from French **batterie**, where it had been built from *battre*, to beat — a
battery of guns, a set of things striking together.

| word | where the building happened |
|---|---|
| la tubería | in Spanish, from *tubo* |
| la estantería | in Spanish, from *estante* |
| la batería | in French, from *battre* |

So the resemblance is real but it is **inherited**, not made here. That is the
honest shape of the rule you have been building for three chapters: look for
the join, and accept that sometimes the join happened in another language and
the pieces never entered this one.

A guess that fails costs you nothing. Not guessing costs you every word you
could have read.
