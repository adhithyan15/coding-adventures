# रुकिए (rukie) — please wait, please stop

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[HI-LEX-C110-AGAIN-02, HI-LEX-C110-AGAIN-03] -->

## You'll want to know: रुकिए
<!-- hl-knowledge: introduces=[HI-LEX-C110-AGAIN-04]; assesses=[] -->

**रुकिए** (*rukie*) — "please wait", "please stop".

It is **रुकना**, "to stop", with the respectful ending of **बोलिए**. **रुकिए, एक मिनट** — "wait,
one minute".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

Wait, one minute, again, louder.
