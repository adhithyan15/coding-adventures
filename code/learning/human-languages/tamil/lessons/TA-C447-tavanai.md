# தவணை (tavaṇai) — an instalment; a fixed term

## You'll want to know: தவணை
<!-- hl-knowledge: introduces=[TA-LEX-C447-THAVANAI447-02]; assesses=[] -->

**தவணை** — *tavaṇai* — "an instalment; a fixed term".

> நான் கைப்பேசியை மாதத் தவணையில் வாங்கினேன்.
>
> *nāṉ kaippēciyai mātat tavaṇaiyil vāṅkiṉēṉ.*
>
> I bought the mobile phone in monthly instalments.

மாதத் தவணை is a monthly instalment.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**தவணை** (*tavaṇai*) is native Dravidian (DEDR 3108), "a fixed term for payment, an instalment".
