# ಪರ್ಯಾಯ (paryāya) — an alternative

## You'll want to know: ಪರ್ಯಾಯ
<!-- hl-knowledge: introduces=[KA-LEX-C418-PARYAYA418-01]; assesses=[] -->

**ಪರ್ಯಾಯ** — *paryāya* — "an alternative".

> ಬಸ್ ಇಲ್ಲದಿದ್ದರೆ ಬೇರೆ ಪರ್ಯಾಯ ಇಲ್ಲ.
>
> *bas illadiddare bēre paryāya illa.*
>
> If there is no bus, there is no other option.

ಪರ್ಯಾಯವಾಗಿ, as an alternative.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಪರ್ಯಾಯ** (*paryāya*) is borrowed from Sanskrit *paryāya*, "going round, succession, turn" (Monier-Williams).
