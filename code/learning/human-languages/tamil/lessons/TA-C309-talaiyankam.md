# தலையங்கம் (talaiyaṅkam) — an editorial

## You'll want to know: தலையங்கம்
<!-- hl-knowledge: introduces=[TA-LEX-C309-VASAKAR309-03]; assesses=[] -->

**தலையங்கம்** — *talaiyaṅkam* — "an editorial".

> இன்றைய தலையங்கம் விபத்துகள் பற்றியது.
>
> *iṉṟaiya talaiyaṅkam vipattukaḷ paṟṟiyatu.*
>
> Today's editorial is about accidents.

தலை, head + அங்கம், part: the leading piece.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**தலையங்கம்** (*talaiyaṅkam*) joins native தலை, "head" (DEDR 3103), and அங்கம், "a limb, a part", borrowed from Sanskrit *aṅga* (CDIAL 114).
