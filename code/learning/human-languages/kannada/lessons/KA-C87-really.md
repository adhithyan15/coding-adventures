# ನಿಜವಾಗಲೂ (nijavāgalū) — really?

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C86-WAIT-04, KA-LEX-C86-WAIT-05] -->

[PAUSE 2s] Before the new one: say the Kannada for I didn't hear, then the Kannada for I didn't understand.

## You'll want to know: ನಿಜವಾಗಲೂ
<!-- hl-knowledge: introduces=[KA-LEX-C87-REPLIES-01]; assesses=[] -->

**ನಿಜವಾಗಲೂ?** (*nijavāgalū?*) — "really?", built on **ನಿಜ** (*nija*), "true".

Said with rising voice it is surprise; said flat, it is "truly".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

True, turned into a question.
