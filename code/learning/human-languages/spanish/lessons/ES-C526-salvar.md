## You'll want to know: salvar
<!-- hl-knowledge: introduces=[ES-LEX-C526-RESCATE-03]; assesses=[] -->

**salvar** — "to save (a life)".

> El médico le salvó la vida.
>
> *The doctor saved his life.*

To save money is *ahorrar*, not *salvar*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*salvar* is inherited from Late Latin *salvāre* 'to save' (EtymDB), built on *salvus* 'safe, unharmed'.
