# ف (fe) — the letter inside حافظ

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[UR-SCRIPT-C36-DO-CHASHMI-HE-01, UR-SCRIPT-C36-GAF-01] -->

[PAUSE 2s] Before the new one: write ھ and گ once each, and name them.

[PAUSE 2s] Now say **حافظ** (*hāfiz*), "guardian".
You have read it for a long time. This lesson takes one letter out of it and puts
it in your hand.

## Script you'll notice: ف
<!-- hl-knowledge: introduces=[UR-SCRIPT-C37-FE-01]; assesses=[] -->

**ف** — *fe*, the sound *f*.

It is inside **حافظ** (*hāfiz*). A small round **head** on a shallow tail, with
**one dot above**.

## Writing: ف
<!-- hl-knowledge: introduces=[]; assesses=[UR-SCRIPT-C37-FE-01] -->

- **1.** start here: loop clockwise around the rounded head above the main line
- **2.** continue left through the shallow curved tail without lifting
- **3.** lift once, then place the upper dot last — and only now lift

**Pen lifts: 1.**

> Stroke order is one attested teaching order; hands and teachers vary.
> Source: Zer o Zabar, Fe, qāf, ṭe, ḍāl, and ṛe, independent ف calligraphic and handwriting animations and Fe instructions (Northwestern University Libraries Open Textbook, 2026).
