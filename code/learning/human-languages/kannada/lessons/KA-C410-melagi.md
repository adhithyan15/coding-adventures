# ಮೇಲಾಗಿ (mēlāgi) — above all; moreover

## Warm-up

## You'll want to know: ಮೇಲಾಗಿ
<!-- hl-knowledge: introduces=[KA-LEX-C410-HIGAGI410-04]; assesses=[] -->

**ಮೇಲಾಗಿ** — *mēlāgi* — "above all; moreover".

> ಈ ಮನೆ ದೊಡ್ಡದು, ಮೇಲಾಗಿ ಬಾಡಿಗೆ ಕಡಿಮೆ.
>
> *ī mane doḍḍadu, mēlāgi bāḍige kaḍime.*
>
> This house is big; moreover the rent is low.

ಮೇಲೆ (above) + ಆಗಿ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಮೇಲಾಗಿ** (*mēlāgi*) is native Dravidian: *mēl*, "what is above" (DEDR 5086), with *āgi*, "being" (DEDR 333).
