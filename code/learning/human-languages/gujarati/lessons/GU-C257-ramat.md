## You'll want to know: રમત
<!-- hl-knowledge: introduces=[GU-LEX-C257-TEAM257-01]; assesses=[] -->

**રમત** — *ramat* — "game".

> **અમે મેદાનમાં નવી રમત રમ્યા.** — *ame medānmā̃ navī ramat ramyā* — "We played a new game in the field."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**રમત** (*ramat*) is built on the taught *ramvũ*, "to play", with *-at*. CDIAL derives *ramvũ* from Sanskrit *rámatē*, "takes pleasure in" (CDIAL 10628).
