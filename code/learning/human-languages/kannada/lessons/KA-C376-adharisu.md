## You'll want to know: ಆಧರಿಸು
<!-- hl-knowledge: introduces=[KA-LEX-C376-PURAVE376-05]; assesses=[] -->

**ಆಧರಿಸು** — *ādharisu* — "to base on".

> ಈ ಸಿನಿಮಾ ಒಂದು ನಿಜ ಘಟನೆಯನ್ನು ಆಧರಿಸಿದೆ.
>
> *ī sinimā ondu nija ghaṭaneyannu ādhariside.*
>
> This film is based on a true incident.

Past (I …): ಆಧರಿಸಿದೆ, *ādhariside*.

What it rests on takes -ಅನ್ನು: ಘಟನೆಯನ್ನು ಆಧರಿಸಿ, based on an incident.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಆಧರಿಸು** (*ādharisu*) is built on Sanskrit *ādhāra*, "a support, a basis" (CDIAL 1165), with the Kannada ending -*isu* that turns a Sanskrit noun into a verb.
