## You'll want to know: காரியம்
<!-- hl-knowledge: introduces=[TA-LEX-C399-EPPATIYUM399-05]; assesses=[] -->

**காரியம்** — *kāriyam* — "a task; an affair".

> இந்தக் காரியம் முடிந்தால் நாம் வீட்டுக்குப் போகலாம்.
>
> *intak kāriyam muṭintāl nām vīṭṭukkup pōkalām.*
>
> If this task is done, we can go home.

காரியம் ஆனது, it worked, the job got done.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**காரியம்** (*kāriyam*) is borrowed from Sanskrit *kārya*, "to be done; business" (CDIAL 3078). Tamil breaks the cluster ry with a vowel, as Pali *kāriya* does.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
