## You'll want to know: yáncháng
<!-- hl-knowledge: introduces=[ZH-LEX-C400-ADJUST400-02]; assesses=[] -->

*yáncháng* — "to extend (in time)".

> *yàoshi nǐ xǐhuan zhèr wǒmen kěyǐ yáncháng jiàqī* — If you like it here, we can make the holiday longer.

Its characters come later; for now it is a word for the ear.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*yáncháng* is built from *yán* 'to stretch' and 长 'long', both inherited from Middle Chinese, *yen* and *drjang* (Guangyun, in Baxter's transcription), which glosses the first 'far' and 'to lengthen'.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what would happen.
