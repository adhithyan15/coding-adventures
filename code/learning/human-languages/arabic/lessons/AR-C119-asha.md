## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**عشاء** (*ʿashāʾ*) is built on the native Arabic root *ʿ-sh-w*, "the evening" (Lane). *ʿAshāʾ* is the evening meal.
