## You'll want to know: el criterio
<!-- hl-knowledge: introduces=[ES-LEX-C617-DECIDE-05]; assesses=[] -->

**el criterio** — "the criterion; judgement".

> ¿Con qué criterio eliges?
>
> *On what basis do you choose?*

*Tener criterio* — to have good judgement.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*criterio* is a learned borrowing from Greek *kritērion* 'a test, a means for judging', built on *krinein* 'to judge'; EtymDB does not list it, but it gives the same root for *crítico*.
