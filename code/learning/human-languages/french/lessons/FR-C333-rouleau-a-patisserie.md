## You'll want to know: le rouleau à pâtisserie
<!-- hl-knowledge: introduces=[FR-LEX-C333-PETRIR-03]; assesses=[] -->

**le rouleau à pâtisserie** — "the rolling pin".

> Le rouleau à pâtisserie est dans le tiroir.
>
> *The rolling pin is in the drawer.*

*Un rouleau* alone is a roll: *un rouleau de papier*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*rouleau* is built on *rôle* "a roll", from Latin *rotulus* "a little wheel", built on *rota* (Lewis & Short); *pâtisserie* is built on *pâte*.
