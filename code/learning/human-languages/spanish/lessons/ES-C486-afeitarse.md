## You'll want to know: afeitarse
<!-- hl-knowledge: introduces=[ES-LEX-C486-MEDICO-01]; assesses=[] -->

**afeitarse** — "to shave".

> Mi padre se afeita cada mañana.
>
> *My father shaves every morning.*

Reflexive, because you shave yourself.
