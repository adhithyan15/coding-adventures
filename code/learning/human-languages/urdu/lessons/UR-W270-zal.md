# ذ (zāl) — the letter that opens ذرا

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[UR-SCRIPT-C268-GHAIN-01, UR-LEX-C270-ZARA-01] -->

[PAUSE 2s] Before the new one: write غ once, and name it. (*ghain*.)

[PAUSE 2s] Now say **ذرا** (*zarā*), "a little". This lesson takes one letter out of it and puts it in your hand.

## Script you'll notice: ذ
<!-- hl-knowledge: introduces=[UR-SCRIPT-C270-ZAL-01]; assesses=[] -->

**ذ** — *zāl*, the sound *z*.

It opens **ذرا** (*zarā*). You already write **د**: **ذ** is that shape with **one dot** above it. Like **د**, it does not join the letter after it. It is one more way Urdu writes *z*, beside **ز**, **ض** and **ظ**, and it comes in words from Arabic.

## Writing: ذ
<!-- hl-knowledge: introduces=[]; assesses=[UR-SCRIPT-C270-ZAL-01] -->

Put your pen on ذ and follow its line. Copy the shape you can see — slowly, and larger than it is printed.

> This book does not yet tell you **where to start this letter or which way to
> travel**. It is not written down here until it can be written down with a
> source. Copying what is in front of you needs no such source, and it is how the
> shape gets into your hand in the meantime.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[UR-SCRIPT-C270-ZAL-01] -->

[PAUSE 3s] Which letter is this — ذ? (**zāl**, *z*.) What tells it from د? (The dot.) Which word did it come from? (**ذرا**, *zarā*, "a little".)
