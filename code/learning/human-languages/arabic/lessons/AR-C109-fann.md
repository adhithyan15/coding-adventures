## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**فن** (*fann*) is built on the native Arabic root *f-n-n*, "a kind, a sort" (Lane). Lane's *fann* is a kind or species of a thing; "art" is a later sense.
