# पुख़्ता (pukhtā) — firm, conclusive

## You'll want to know: पुख़्ता
<!-- hl-knowledge: introduces=[HI-LEX-C348-PRAMAN348-04]; assesses=[] -->

**पुख़्ता** — *pukhtā* — "firm, conclusive".

> पुलिस को पुख़्ता प्रमाण चाहिए।
>
> *pulis ko pukhtā pramāṇ cāhiye.*
>
> The police need conclusive proof.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**पुख़्ता** (*pukhtā*) is usually traced to Persian *pukhta*, "cooked, ripe; firm".

## What you've built

One more word for giving reasons and opinions.
