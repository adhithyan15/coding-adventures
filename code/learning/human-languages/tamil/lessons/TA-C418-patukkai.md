# படுக்கை (paṭukkai) — bedding; a bed

## You'll want to know: படுக்கை
<!-- hl-knowledge: introduces=[TA-LEX-C418-VIDUTHI418-04]; assesses=[] -->

**படுக்கை** — *paṭukkai* — "bedding; a bed".

> அறையில் இரண்டு படுக்கைகள் இருந்தன.
>
> *aṟaiyil iraṇṭu paṭukkaikaḷ iruntaṉa.*
>
> There were two beds in the room.

படுக்கையறை, a bedroom, is built on it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**படுக்கை** (*paṭukkai*) is native Dravidian (DEDR 3852), from படு, "to lie down".
