# പട്ടിണി (paṭṭiṇi) — starvation; hunger

## You'll want to know: പട്ടിണി
<!-- hl-knowledge: introduces=[ML-LEX-C427-DARIDRYAM427-03]; assesses=[] -->

**പട്ടിണി** — *paṭṭiṇi* — "starvation; hunger".

> ജോലി ഇല്ലാതെ ആ കുടുംബം പട്ടിണിയിലായി.
>
> *jōli illāte ā kuṭumbaṁ paṭṭiṇiyilāyi.*
>
> Without work, that family fell into hunger.

To go hungry is പട്ടിണി കിടക്കുക, to lie in hunger.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**പട്ടിണി** (*paṭṭiṇi*) is native Dravidian: DEDR 3872 lists Malayalam *paṭṭiṇi*, "privation of food, starvation", with Tamil *paṭṭiṉi*, "fasting".
