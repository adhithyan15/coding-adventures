# конечная (konéchnaya) — the last stop, the terminus

## You'll want to know: конечная
<!-- hl-knowledge: introduces=[RU-LEX-C418-PERESADKA-02]; assesses=[] -->

**конечная** (*konéchnaya*) — "the last stop, the terminus".

> Мы едем до конечной.
>
> *My yédem do konéchnoy.*
>
> We are going to the last stop.

Short for *конечная остановка*; an adjective used as a noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*конечная* is short for *конечная остановка* 'the final stop'. *Конечный* is built on *конец* 'an end', which is inherited from Proto-Slavic *konĭcĭ* 'an end' (EtymDB).
