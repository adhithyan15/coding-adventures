# تہہ خانہ (tah khānā) — a basement; a cellar

## You'll want to know: تہہ خانہ
<!-- hl-knowledge: introduces=[UR-LEX-C411-DHALAN411-04]; assesses=[] -->

**تہہ خانہ** — *tah khānā* — "a basement; a cellar".

> پرانی عمارت میں ایک تہہ خانہ ہے۔
>
> *purānī imārat meṅ ek tah khānā hai.*
>
> The old building has a basement.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**تہہ خانہ** (*tah khānā*) is built from Persian *tah*, "the bottom", and *khāna*, "a room": it is usually traced to Persian *tahkhāna*.
