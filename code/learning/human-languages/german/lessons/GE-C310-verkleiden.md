## You'll want to know: verkleiden
<!-- hl-knowledge: introduces=[GE-LEX-C310-KARNEVAL-04]; assesses=[] -->

**verkleiden** — "to dress up (as); mostly reflexive: sich verkleiden".

> Mein Bruder verkleidete sich als Löwe.
>
> *My brother dressed up as a lion.*

*Sich als etwas verkleiden*. *Die Verkleidung* — the disguise.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*verkleiden* is built on *Kleid* "dress", an inherited Germanic word with the Dutch cousin *kleed* (EtymDB), with *ver-*.
