## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**طفل** (*ṭifl*) is built on the native Arabic root *ṭ-f-l*, "a child, an infant" (Lane). *Ṭifl* is Lane's word for a young child.
