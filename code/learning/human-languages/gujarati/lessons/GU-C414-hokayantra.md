# હોકાયંત્ર (hokāyantra) — a compass

## You'll want to know: હોકાયંત્ર
<!-- hl-knowledge: introduces=[GU-LEX-C414-EAST414-05]; assesses=[] -->

**હોકાયંત્ર** — *hokāyantra* — "a compass".

> હોકાયંત્રની સોય ઉત્તર બતાવે છે.
>
> *hokāyantranī soy uttar batāve che.*
>
> The compass needle shows north.

A neuter noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**હોકાયંત્ર** (*hokāyantra*) is built on Sanskrit *yantra*, "an instrument, a device" (Monier-Williams); where its first part comes from is not settled.
