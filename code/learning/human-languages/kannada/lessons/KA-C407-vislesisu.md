# ವಿಶ್ಲೇಷಿಸು (viślēṣisu) — to analyse

## You'll want to know: ವಿಶ್ಲೇಷಿಸು
<!-- hl-knowledge: introduces=[KA-LEX-C407-SAMSHODHANE407-04]; assesses=[] -->

**ವಿಶ್ಲೇಷಿಸು** — *viślēṣisu* — "to analyse".

> ನಾನು ಪರೀಕ್ಷೆಯ ಫಲಿತಾಂಶಗಳನ್ನು ವಿಶ್ಲೇಷಿಸಿದೆ.
>
> *nānu parīkṣeya phalitāṃśagaḷannu viślēṣiside.*
>
> I analysed the exam results.

Past (I …): ವಿಶ್ಲೇಷಿಸಿದೆ, *viślēṣiside*.

ವಿಶ್ಲೇಷಣೆ, an analysis.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ವಿಶ್ಲೇಷಿಸು** (*viślēṣisu*) is built on Sanskrit *viśleṣa*, "loosening, separation" (Monier-Williams), with the Kannada verb ending -*isu*: to take apart.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
