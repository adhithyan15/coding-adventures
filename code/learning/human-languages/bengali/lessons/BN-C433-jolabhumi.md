# জলাভূমি (jôlābhūmi) — a wetland; marshland

## You'll want to know: জলাভূমি
<!-- hl-knowledge: introduces=[BN-LEX-C433-JHIL433-03]; assesses=[] -->

**জলাভূমি** — *jôlābhūmi* — "a wetland; marshland".

> জলাভূমিতে অনেক পাখি বাসা বাঁধে।
>
> *jôlābhūmite ônek pākhi bāsā bā̃dhe.*
>
> Many birds nest in the wetland.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**জলাভূমি** (*jôlābhūmi*) joins জলা, which CDIAL lists as Bengali *jalā*, "a marsh", beside *jal*, water (CDIAL 5155), to *bhūmi*, "land" (Monier-Williams).
