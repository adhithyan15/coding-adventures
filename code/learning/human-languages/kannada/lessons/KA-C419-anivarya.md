# ಅನಿವಾರ್ಯ (anivārya) — unavoidable

## You'll want to know: ಅನಿವಾರ್ಯ
<!-- hl-knowledge: introduces=[KA-LEX-C419-VIPHALA419-05]; assesses=[] -->

**ಅನಿವಾರ್ಯ** — *anivārya* — "unavoidable".

> ಮಳೆ ಬಂದರೆ ಪಂದ್ಯ ಮುಂದೂಡುವುದು ಅನಿವಾರ್ಯ.
>
> *maḷe bandare pandya mundūḍuvudu anivārya.*
>
> If it rains, putting off the match is unavoidable.

ಅನಿವಾರ್ಯವಾಗಿ, of necessity.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಅನಿವಾರ್ಯ** (*anivārya*) is borrowed from Sanskrit *anivārya*, "not to be warded off, unavoidable" (Monier-Williams).
