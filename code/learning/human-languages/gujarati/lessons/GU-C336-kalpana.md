# કલ્પના (kalpanā) — imagination

## You'll want to know: કલ્પના
<!-- hl-knowledge: introduces=[GU-LEX-C336-LEKHAK336-05]; assesses=[] -->

**કલ્પના** — *kalpanā* — "imagination".

> લેખકની કલ્પના ખૂબ સુંદર છે.
>
> *lekhaknī kalpanā khūb sundar che.*
>
> The author has a wonderful imagination.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**કલ્પના** (*kalpanā*) is a tatsama, Sanskrit *kalpanā*, "making, forming" (Monier-Williams); in Gujarati it is forming pictures in the mind.
