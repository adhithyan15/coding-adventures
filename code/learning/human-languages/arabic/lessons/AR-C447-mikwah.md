## You'll want to know: مكواة
<!-- hl-knowledge: introduces=[AR-LEX-C447-DUSH447-02]; assesses=[] -->

**مكواة** — *mikwāh* — "a clothes iron".

> طلبت مكواة من الاستقبال.
>
> *ṭalabtu mikwāh min al-istiqbāl.*
>
> I asked reception for an iron.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**مكواة** (*mikwāh*) is built on the native Arabic root *k-w-y*, "to burn with a hot iron" (Lane). The tool pattern *mifʿala* names the thing one irons with, beside *kawā*, "to iron".
