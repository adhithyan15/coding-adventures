# बींधणो (bī̃dhṇo) — to pierce (a bead)

## You'll want to know: बींधणो
<!-- hl-knowledge: introduces=[MW-LEX-C283-MOTI283-02]; assesses=[] -->

**बींधणो** — *bī̃dhṇo* — "to pierce (a bead)".

> मां मोती बींधै है।
>
> *mā̃ motī bī̃dhai hai.*
>
> Mother pierces the pearls.

Past (I …): म्हैं मोती बींध्यो, *mhaĩ motī bī̃dhyo*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**बींधणो** (*bī̃dhṇo*) is inherited from Sanskrit *viddha*, "pierced"; CDIAL lists Old Marwari *abīdha*, "unpierced", and Hindi *bīdhnā*, "to pierce" (CDIAL 11739).
