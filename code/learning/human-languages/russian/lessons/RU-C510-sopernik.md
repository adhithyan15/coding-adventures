## You'll want to know: соперник
<!-- hl-knowledge: introduces=[RU-LEX-C510-RESULTS-03]; assesses=[] -->

**соперник** (*sopérnik*) — "a rival, an opponent".

> Сегодня у нас очень сильный соперник.
>
> *Segódnya u nas óchen sílnyy sopérnik.*
>
> Today we have a very strong opponent.

Masculine; feminine соперница.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*соперник* is inherited from Old East Slavic *sъpьrьnikъ*, built with the prefix that EtymDB traces to Proto-Slavic *sǫ-* 'together'.
