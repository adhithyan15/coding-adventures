## You'll want to know: экскурсовод
<!-- hl-knowledge: introduces=[RU-LEX-C442-EKSKURSIYA-02]; assesses=[] -->

**экскурсовод** (*ekskursovód*) — "a tour guide".

> Экскурсовод рассказывал о старых домах.
>
> *Ekskursovód rasskázyval o stárykh domákh.*
>
> The guide talked about the old houses.

Masculine, for a woman too. Also *гид*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*экскурсовод* is built from *экскурсия* 'a tour' and *-вод*, from *водить* 'to lead'. *Экскурсия* goes back to Latin *excursiō* and *водить* to Proto-Slavic *voditi* (EtymDB).
