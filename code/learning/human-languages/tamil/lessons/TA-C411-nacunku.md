# நசுங்கு (nacuṅku) — to get dented; to be crushed

## You'll want to know: நசுங்கு
<!-- hl-knowledge: introduces=[TA-LEX-C411-KOLARU411-03]; assesses=[] -->

**நசுங்கு** — *nacuṅku* — "to get dented; to be crushed".

> விபத்தில் காரின் கதவு நசுங்கியது.
>
> *vipattil kāriṉ katavu nacuṅkiyatu.*
>
> The car's door got dented in the accident.

Past (it …): நசுங்கியது, *nacuṅkiyatu*.

Of fruit or a can: to be squashed.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**நசுங்கு** (*nacuṅku*) is native Dravidian (DEDR 3574), "to be mashed, to be crushed".
