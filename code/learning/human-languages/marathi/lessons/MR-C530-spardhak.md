## You'll want to know: स्पर्धक
<!-- hl-knowledge: introduces=[MR-LEX-C530-PADAK530-04]; assesses=[] -->

**स्पर्धक** — *spardhak* — "a contestant".

> या स्पर्धेत वीस स्पर्धक आहेत.
>
> *yā spardhet vīs spardhak āhet.*
>
> There are twenty contestants in this competition.

Masculine.

Built on स्पर्धा, a competition.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**स्पर्धक** (*spardhak*) is built on स्पर्धा, "a competition", from Sanskrit *spardhā*, "rivalry" (Monier-Williams), with the agent ending -क.
