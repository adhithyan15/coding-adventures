## You'll want to know: અવસાન
<!-- hl-knowledge: introduces=[GU-LEX-C499-MARAN499-02]; assesses=[] -->

**અવસાન** — *avsān* — "a passing away".

> ગયા મહિને મારા મામાનું અવસાન થયું.
>
> *gayā mahine mārā māmānũ avsān thayũ.*
>
> My uncle passed away last month.

A neuter noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**અવસાન** (*avsān*) is a tatsama, Sanskrit *avasāna*, which Monier-Williams lists under *ava-so* as "conclusion, termination" and also as "death"; Gujarati uses it as the polite word for a death.
