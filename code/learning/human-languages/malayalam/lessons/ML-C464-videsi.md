## You'll want to know: വിദേശി
<!-- hl-knowledge: introduces=[ML-LEX-C464-ATIRTTI464-05]; assesses=[] -->

**വിദേശി** — *vidēśi* — "a foreigner".

> ആ ഹോട്ടലിൽ ധാരാളം വിദേശികൾ താമസിക്കുന്നു.
>
> *ā hōṭṭalil dhārāḷaṁ vidēśikaḷ tāmasikkunnu.*
>
> Many foreigners stay at that hotel.

Plural: വിദേശികൾ, *vidēśikaḷ*.

Built on വിദേശം, abroad: the -ഇ ending names a person from there.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**വിദേശി** (*vidēśi*) is built from Sanskrit *videśa*, "another country, abroad" (Monier-Williams), with the ending -ഇ for a person of that place.
