## You'll want to know: загрязнять
<!-- hl-knowledge: introduces=[RU-LEX-C369-EKOLOGIYA-03]; assesses=[] -->

**загрязнять** (*zagryaznyát*) — "to pollute".

> Машины загрязняют воздух.
>
> *Mashíny zagryaznyáyut vózdukh.*
>
> Cars pollute the air.

Imperfective; perfective *загрязнить*. It takes the accusative.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**загрязнять** is built from *за-* and *грязь* "dirt, mud", the root of *грязный*: to make a thing dirty.
