# ನಿವಾರಿಸು (nivārisu) — to ward off; to relieve

## You'll want to know: ನಿವಾರಿಸು
<!-- hl-knowledge: introduces=[KA-LEX-C412-APAYA412-05]; assesses=[] -->

**ನಿವಾರಿಸು** — *nivārisu* — "to ward off; to relieve".

> ವೈದ್ಯರು ನನ್ನ ನೋವನ್ನು ನಿವಾರಿಸಿದರು.
>
> *vaidyaru nanna nōvannu nivārisidaru.*
>
> The doctor relieved my pain.

Past (I …): ನಿವಾರಿಸಿದೆ, *nivāriside*.

What is removed takes -ಅನ್ನು. ನಿವಾರಣೆ, removal.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ನಿವಾರಿಸು** (*nivārisu*) is built on Sanskrit *nivāraṇa*, "keeping off, warding off" (CDIAL 7418), with the Kannada verb ending -*isu*.
