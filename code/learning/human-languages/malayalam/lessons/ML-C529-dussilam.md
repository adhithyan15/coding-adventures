# ദുശ്ശീലം (duśśīlaṁ) — a bad habit

## You'll want to know: ദുശ്ശീലം
<!-- hl-knowledge: introduces=[ML-LEX-C529-VIVEKAM529-04]; assesses=[] -->

**ദുശ്ശീലം** — *duśśīlaṁ* — "a bad habit".

> പുകവലി ഒരു ദുശ്ശീലമാണ്.
>
> *pukavali oru duśśīlamāṇŭ.*
>
> Smoking is a bad habit.

ദു- bad + ശീലം, a habit, the word already familiar.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ദുശ്ശീലം** (*duśśīlaṁ*) is borrowed from Sanskrit *duḥśīla*, "ill-behaved" (CDIAL 6384), built from *duṣ-*, "bad", and *śīla*, "habit, nature".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
