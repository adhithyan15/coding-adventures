# Changelog

## 0.1.0

- Initial release of `coding_adventures_verilog_parser`.
- Pure Dart grammar-driven parser for Verilog (IEEE 1364-1995, IEEE 1364-2001, IEEE 1364-2005).
- Integrated precompiled grammars for Verilog editions.
- Bounded token count and combined delimiter/keyword/prefix nesting depth defense (64).
- 100% compliance with Standing Rule #20 (centralized localizable diagnostics, sealed exception hierarchy, payload blindness).
