## You'll want to know: दृष्टिकोन
<!-- hl-knowledge: introduces=[MR-LEX-C344-MATBHED344-05]; assesses=[] -->

**दृष्टिकोन** — *dṛṣṭikon* — "a standpoint; an outlook".

> प्रत्येकाचा दृष्टिकोन वेगळा असतो.
>
> *pratyekācā dṛṣṭikon vegḷā asto.*
>
> Everyone's outlook is different.

Masculine.

दृष्टी + कोन, sight + angle: the angle one looks from.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**दृष्टिकोन** (*dṛṣṭikon*) is a learned compound built from Sanskrit *dṛṣṭi*, "sight, view", and *koṇa*, "corner, angle" (Monier-Williams).
