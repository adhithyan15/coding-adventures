## Fixed — Gujarati nav and navũ use separate root slugs for "nine" and "new"

- **GU-C39-nav** moves from `sanskrit-nava` to `sanskrit-nava-nine`. *Nav* "nine" is *náva²* "nine" (CDIAL 6984), not *náva¹* "new" (CDIAL 6983).
- **GU-C73-new** moves from `sanskrit-nava` to `sanskrit-nava-new`, the slug the Punjabi and Sanskrit "new" lessons use. No lesson uses bare `sanskrit-nava` any more.
