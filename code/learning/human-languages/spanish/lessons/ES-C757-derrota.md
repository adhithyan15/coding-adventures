## You'll want to know: la derrota
<!-- hl-knowledge: introduces=[ES-LEX-C757-CAMPEON-04]; assesses=[] -->

**la derrota** — "defeat".

> Fue una derrota dura.
>
> *It was a hard defeat.*

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*derrota* is built on old *derromper* "to break up" (EtymDB), which is inherited from Latin *dīrumpere*, from *rumpere* "to break": an army broken and scattered.
