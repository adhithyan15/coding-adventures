# Talking it through — a second pass

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C85-SLOWLY-01, KA-LEX-C85-SLOWLY-02] -->

[PAUSE 3s] Someone speaks too fast. Ask them to speak slowly, and to say it once more.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C85-SLOWLY-01, KA-LEX-C85-SLOWLY-02, KA-LEX-C85-SLOWLY-03, KA-LEX-C85-SLOWLY-04, KA-LEX-C85-SLOWLY-05, KA-LEX-C86-WAIT-01, KA-LEX-C86-WAIT-02, KA-LEX-C86-WAIT-03, KA-LEX-C86-WAIT-04, KA-LEX-C86-WAIT-05, KA-LEX-C87-REPLIES-01, KA-LEX-C87-REPLIES-02, KA-LEX-C87-REPLIES-03, KA-LEX-C87-REPLIES-04, KA-LEX-C87-REPLIES-05, KA-LEX-C88-WELCOME-01, KA-LEX-C88-WELCOME-02, KA-LEX-C88-WELCOME-03, KA-LEX-C88-WELCOME-04, KA-LEX-C88-WELCOME-05, KA-LEX-C89-CARE-01, KA-LEX-C89-CARE-02, KA-LEX-C89-CARE-03, KA-LEX-C89-CARE-04, KA-LEX-C89-CARE-05] -->

[PAUSE 2s each]
- [YOU SAY: a little louder; what is the meaning of this?; please write it down]
- [YOU SAY: one minute; please wait; please show me the way]
- [YOU SAY: I didn't hear; I didn't understand]
- [YOU SAY: really?; nothing; oh no!; is that so?; that's the one!]
- [YOU SAY: congratulations; an invitation for you; a gift for you; please come in; welcome]
- [YOU SAY: take care; go safely; it's late; let's go; tomorrow is a holiday]

Meaning? (**ಅರ್ಥ**.) Write it down? (**ಬರೆದು ಕೊಡಿ**.) One minute? (**ಒಂದು ನಿಮಿಷ**.)
