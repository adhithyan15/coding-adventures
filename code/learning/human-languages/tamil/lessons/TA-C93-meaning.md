## You'll want to know: அர்த்தம்
<!-- hl-knowledge: introduces=[TA-LEX-C93-ASK-01]; assesses=[] -->

**அர்த்தம்** (*arttam*) — "meaning".

**இதன் அர்த்தம் என்ன?** — "what does this mean?", the question that turns anyone into a teacher.
