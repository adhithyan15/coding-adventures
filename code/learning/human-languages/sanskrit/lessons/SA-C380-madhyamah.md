## You'll want to know: मध्यमः
<!-- hl-knowledge: introduces=[SA-LEX-C380-MATRA380-03]; assesses=[] -->

**मध्यमः** — *madhyamaḥ* — "moderate; middling".

> यदि व्यायामः मध्यमः, तर्हि देहः स्वस्थः भवति।
>
> *yadi vyāyāmaḥ madhyamaḥ, tarhi dehaḥ svasthaḥ bhavati.*
>
> If exercise is moderate, the body stays healthy.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**मध्यमः** (*madhyamaḥ*) is built on *madhya*, "middle", with the superlative ending *-ma*; MW gives *madhyama* "middle, middlemost, intermediate" (MW).
