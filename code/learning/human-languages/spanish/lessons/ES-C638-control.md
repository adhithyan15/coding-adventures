## You'll want to know: el control
<!-- hl-knowledge: introduces=[ES-LEX-C638-LIMITE-03]; assesses=[] -->

**el control** — "the control; the check".

> Hay un control de seguridad.
>
> *There is a security check.*

*El control de pasaportes* — passport control.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*control* was borrowed from French *contrôle* 'a check', from Old French *contrerole*, a second roll kept to check the first, from Medieval Latin *contrarotulum*, built from *contra* and *rotulus* 'roll' (EtymDB).
