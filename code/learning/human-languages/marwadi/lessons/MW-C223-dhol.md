## You'll want to know: ढोल
<!-- hl-knowledge: introduces=[MW-LEX-C223-FAIR223-03]; assesses=[] -->

**ढोल** — *ḍhol* — "a big drum".

> म्हैं ढोल सुण्यो।
>
> *mhaĩ ḍhol suṇyo.*
>
> I heard the drum.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ढोल** (*ḍhol*) is inherited from Sanskrit *ḍhōla*, "a large drum" (CDIAL 5608, which lists Marwari *ḍhol*).
