## You'll want to know: विशेषतः
<!-- hl-knowledge: introduces=[SA-LEX-C381-VISHESHATAH381-02]; assesses=[] -->

**विशेषतः** — *viśeṣataḥ* — "especially".

> यदि मार्गः आर्द्रः, तर्हि विशेषतः मन्दं चलतु।
>
> *yadi mārgaḥ ārdraḥ, tarhi viśeṣataḥ mandaṃ calatu.*
>
> If the road is wet, walk especially slowly.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**विशेषतः** (*viśeṣataḥ*) is built on *viśeṣa*, "a distinction", with the ending *-tas*; MW gives *viśeṣa-tas* "especially, particularly, above all" (MW).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
