## You'll want to know: o avançado
<!-- hl-knowledge: introduces=[PT-LEX-C509-BALIZA-03]; assesses=[] -->

**o avançado** — "forward, striker".

> O avançado marcou dois golos.
>
> *The striker scored two goals.*

In Brazil: *o atacante*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*avançado* is built on *avançar* "to move forward", which goes back to Vulgar Latin *abanteāre* (EtymDB), built on *ab ante* "from in front".
