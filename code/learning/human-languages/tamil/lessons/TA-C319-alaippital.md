# அழைப்பிதழ் (aḻaippitaḻ) — an invitation card

## You'll want to know: அழைப்பிதழ்
<!-- hl-knowledge: introduces=[TA-LEX-C319-AANDU319-05]; assesses=[] -->

**அழைப்பிதழ்** — *aḻaippitaḻ* — "an invitation card".

> திருமண அழைப்பிதழ் தபாலில் வந்தது.
>
> *tirumaṇa aḻaippitaḻ tapālil vantatu.*
>
> The wedding invitation card came by post.

அழை, to invite + இதழ், leaf: a written invitation.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**அழைப்பிதழ்** (*aḻaippitaḻ*) is a Tamil compound built from அழைப்பு, "a call, an invitation", from அழை, "to call, summon" (DEDR 282), and இதழ், "a leaf" (DEDR 459).
