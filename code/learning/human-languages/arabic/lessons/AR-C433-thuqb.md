# ثقب (thuqb) — a hole; a puncture

## You'll want to know: ثقب
<!-- hl-knowledge: introduces=[AR-LEX-C433-AJALA433-03]; assesses=[] -->

**ثقب** — *thuqb* — "a hole; a puncture".

> وجد العامل ثقبا صغيرا في الإطار.
>
> *wajada al-ʿāmil thuqban ṣaghīran fī al-iṭār.*
>
> The worker found a small hole in the tyre.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ثقب** (*thuqb*) is built on the native Arabic root *th-q-b*, "to pierce" (Lane).
