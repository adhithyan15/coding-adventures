## You'll want to know: காட்டுங்கள்
<!-- hl-knowledge: introduces=[TA-LEX-C93-ASK-04]; assesses=[] -->

**காட்டுங்கள்** (*kāṭṭuṅkaḷ*) — "please show me".

When a word will not come, point and say **காட்டுங்கள்**.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

A request for when words run out.
