# തപാൽ — the post

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C110-LETTER-01] -->

[PAUSE 2s] Say the word for a letter.

[PAUSE 2s] Then ask yourself what carries it.

## You'll want to know
<!-- hl-knowledge: introduces=[ML-LEX-C110-POST-01]; assesses=[ML-LEX-C110-LETTER-01] -->

**തപാൽ** (*tapāl*) — **the post**: the service, and the word printed on the box
you drop a letter into.

| | |
|---|---|
| **കത്ത്** | the thing you write |
| **തപാൽ** | the thing that carries it |

**The ending is one you can already read.** **ൽ** is the chillu you have met
closing other words — a bare *l* with no vowel after it.
