# ادھورا (adhūrā) — unfinished; incomplete

## You'll want to know: ادھورا
<!-- hl-knowledge: introduces=[UR-LEX-C373-BIKHARNA373-05]; assesses=[] -->

**ادھورا** — *adhūrā* — "unfinished; incomplete".

> اگر کام ادھورا رہا تو پیسے نہیں ملیں گے۔
>
> *agar kām adhūrā rahā to paise nahīṅ mileṅ ge.*
>
> If the work is left unfinished, there will be no pay.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ادھورا** (*adhūrā*) is inherited: CDIAL lists the Hindi cousin *adhūrā*, "half-done", under *\*ardhapūraka*, "half-full", a form it reconstructs (CDIAL 664).
