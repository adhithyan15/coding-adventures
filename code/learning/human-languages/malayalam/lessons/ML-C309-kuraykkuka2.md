## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**കുറയ്ക്കുക** (*kuṟaykkuka*) is native Dravidian, the causative of the verb "to dwindle": "make less"; DEDR 1851 lists the root with Tamil *kuṟu*.
