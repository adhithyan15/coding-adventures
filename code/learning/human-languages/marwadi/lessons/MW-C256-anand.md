## You'll want to know: आणंद
<!-- hl-knowledge: introduces=[MW-LEX-C256-DAR256-04]; assesses=[] -->

**आणंद** — *āṇand* — "joy; delight".

> ब्याव मांय घणो आणंद है।
>
> *byāv mā̃y ghaṇo āṇand hai.*
>
> There is great joy at the wedding.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**आणंद** (*āṇand*) is inherited from Sanskrit *ānanda*, "happiness". CDIAL gives no Marwari form in this entry; it lists Gujarati *āṇãd*, "joy", with the same ण (CDIAL 1172).
