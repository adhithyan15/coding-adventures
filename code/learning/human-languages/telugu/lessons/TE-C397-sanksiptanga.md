# సంక్షిప్తంగా (saṅkṣiptaṅgā) — in short; briefly

## You'll want to know: సంక్షిప్తంగా
<!-- hl-knowledge: introduces=[TE-LEX-C397-SANKSIPTAM397-03]; assesses=[] -->

**సంక్షిప్తంగా** — *saṅkṣiptaṅgā* — "in short; briefly".

> సంక్షిప్తంగా చెప్పాలంటే, మా దగ్గర డబ్బు లేదు.
>
> *saṅkṣiptaṅgā ceppālaṇṭē, mā daggara ḍabbu lēdu.*
>
> To put it briefly, we have no money.

సంక్షిప్తంగా చెప్పాలంటే, to put it in a few words.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**సంక్షిప్తంగా** (*saṅkṣiptaṅgā*) is built on Sanskrit *saṁkṣipta*, "abbreviated, contracted, condensed" (Monier-Williams), with the Telugu adverb ending -గా.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
