# అలాగా (alāgā) — is that so? I see

## You'll want to know: అలాగా
<!-- hl-knowledge: introduces=[TE-LEX-C87-ANSWER-04]; assesses=[] -->

**అలాగా** (*alāgā*) — "is that so?", "I see".

It sits one vowel away from **అలాగే**, "alright then". *Alāgā* receives news;
*alāgē* agrees to a plan. Say both and hear the difference in the last vowel.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

A way to show you are listening.
