## You'll want to know: उदास
<!-- hl-knowledge: introduces=[HI-LEX-C108-FEEL-03]; assesses=[] -->

**उदास** (*udās*) — "sad".

**मैं उदास हूँ** — "I am sad". Like **बीमार**, it describes you, so it takes **मैं ... हूँ**.
