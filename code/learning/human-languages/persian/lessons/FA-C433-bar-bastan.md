## You'll want to know: بار بستن
<!-- hl-knowledge: introduces=[FA-LEX-C433-SAK-02]; assesses=[] -->

**بار بستن** (*bâr bastan*) — "to pack (for a journey)".

> شب قبل از سفر بار بستیم.
>
> *Shab-e qabl az safar bâr bastim.*
>
> We packed the night before the trip.

*bâr* 'load' + *bastan* 'to tie'. Present stem *band-*: *bâr mibandim*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*bâr bastan* is built from native *bâr* 'load', which EtymDB lists, and *bastan* 'to tie, to bind', which EtymDB traces to the PIE root *bʰendʰ-* 'to bind'. Loads were once tied onto pack animals.
