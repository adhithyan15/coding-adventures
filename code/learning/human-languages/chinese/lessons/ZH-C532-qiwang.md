## You'll want to know: 期望
<!-- hl-knowledge: introduces=[ZH-LEX-C532-HOPE532-03]; assesses=[] -->

**期望** — *qīwàng* — "to expect much of someone; expectations".

> *yàoshi nǐ qīwàng tài gāo jiù huì shīwàng* — If you expect too much, you'll be disappointed.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**期望** (*qīwàng*) is built from 期 'a set time' and 望 'to look out for', both inherited from Middle Chinese, *gi* and *mjangH* (Guangyun, in Baxter's transcription), which glosses the first 'a time agreed on'.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what would happen.
