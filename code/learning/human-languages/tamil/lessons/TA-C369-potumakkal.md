# பொதுமக்கள் (potumakkaḷ) — the public

## You'll want to know: பொதுமக்கள்
<!-- hl-knowledge: introduces=[TA-LEX-C369-CAMUKAM369-02]; assesses=[] -->

**பொதுமக்கள்** — *potumakkaḷ* — "the public".

> இந்தப் பூங்கா பொதுமக்களுக்குத் திறந்திருக்கிறது.
>
> *intap pūṅkā potumakkaḷukkut tiṟantirukkiṟatu.*
>
> This park is open to the public.

பொது, common + மக்கள், people.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**பொதுமக்கள்** (*potumakkaḷ*) is native: *potu*, "common, general, public" (DEDR 4507), and *makkaḷ*, "human beings, people" (DEDR 4616).
