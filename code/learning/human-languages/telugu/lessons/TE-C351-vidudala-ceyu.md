# విడుదల చేయు (viḍudala cēyu) — to release; to set free

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TE-LEX-C351-BANDI351-02, TE-LEX-C351-BANDI351-03] -->

[PAUSE 2s] Before the new one: say the Telugu for to detain, then the Telugu for to capture.

## You'll want to know: విడుదల చేయు
<!-- hl-knowledge: introduces=[TE-LEX-C351-BANDI351-04]; assesses=[] -->

**విడుదల చేయు** — *viḍudala cēyu* — "to release; to set free".

> పోలీసులు బందీలను విడుదల చేశారు.
>
> *pōlīsulu bandīlanu viḍudala cēśāru.*
>
> The police released the captives.

Past (I …): విడుదల చేశాను, *viḍudala cēśānu*.

విడుదల is also the release of a film or a book: సినిమా విడుదల.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**విడుదల చేయు** (*viḍudala cēyu*) is a native phrase: *viḍudala*, "release", built on *viḍu*, "to loosen, let go" (DEDR 5393), with *cēyu*, "to do".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
