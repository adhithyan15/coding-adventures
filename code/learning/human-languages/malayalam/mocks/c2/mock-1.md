# Malayalam C2 mock 1 — learner paper and examiner script

Administration: Reading 90 minutes, Listening 60 minutes, Writing 90 minutes,
and Speaking 25 minutes with 15 minutes preparation. Play each listening text
once at 165–200 words per minute. Each form uses a documented regional Malayalam voice:
the rapid discussion uses central Travancore Malayalam, and the media extract uses
North Malabar Malayalam. Malayalam stimuli contain no romanization.

## Reading — 90 minutes

### Stylistically marked specialist argument — items 1–10

**അളക്കാനാകുന്നതിനെ ഭരണത്തിന്റെ കണ്ണ് എന്നു വിളിക്കുമ്പോൾ, കണ്ണ് കാണുന്നതെല്ലാം
യാഥാർഥ്യമാണെന്ന ചെറിയൊരു വഞ്ചന കൂടി വാക്യത്തിനുള്ളിൽ കടന്നുവരുന്നു. നഗരത്തിലെ
തണൽ അളക്കാൻ മരങ്ങളുടെ എണ്ണം എടുത്താൽ കണക്കു സുതാര്യമാണ്; എന്നാൽ പകൽ മുഴുവൻ
നടക്കുന്ന തൊഴിലാളിക്ക് കിട്ടുന്ന തുടർച്ചയായ തണലും, മതിലിന് അകത്തെ സ്വകാര്യ
തോട്ടവും ഒരേ കോളത്തിൽ നിൽക്കും. ഇതിന് പരിഹാരം കൂടുതൽ സൂചികകൾ മാത്രമാണെന്ന്
പറയുന്നത് പഴയ ഭൂപടത്തിന് കൂടുതൽ നിറം ചേർക്കുന്നതുപോലെ: വിശദാംശം കൂടും,
ഭൂപടം വരച്ചവന്റെ ദൃഷ്ടികോണം മാറണമെന്നില്ല.

അതുകൊണ്ട് കണക്ക് ഉപേക്ഷിക്കണമെന്നല്ല എന്റെ വാദം. കണക്കില്ലാത്ത അധികാരം സ്വന്തം
അനുഭവത്തെ പൊതുസത്യമാക്കും. പക്ഷേ അളവിനെ തീരുമാനത്തിന് മുമ്പിലുള്ള നിഷ്പക്ഷ
വിവരമെന്നു കാണാതെ, തീരുമാനം എടുക്കുന്ന സ്ഥാപനവുമായി ചേർന്ന് നിർമ്മിക്കപ്പെടുന്ന
വാദമെന്നു കാണണം. “തണൽ” എന്ന വിഭാഗം ആരാണ് നിർവചിച്ചത്, ഏത് സമയത്താണ് അളന്നത്,
അത് ലഭിക്കാത്തവന് എതിർപ്പു രേഖപ്പെടുത്താൻ വഴി ഉണ്ടോ—ഈ ചോദ്യങ്ങളും ഡാറ്റയുടെ
ഭാഗമാണ്. സംഖ്യയ്ക്ക് അടിക്കുറിപ്പായി അവയെ ഒതുക്കുന്നത് മതിയാകില്ല; സംഖ്യ
എന്തിന് അധികാരം നൽകുന്നു എന്നതിന്റെ പാത പിന്തുടരണം.

ഒരു പരീക്ഷണത്തിൽ നഗരസഭ താപനില സെൻസറുകൾ സ്ഥാപിച്ചു. ഉപകരണം ഏറ്റവും ചൂടുള്ള
വഴി കണ്ടെത്തി; പക്ഷേ രാത്രിപ്പണി കഴിഞ്ഞ് ബസ് കാത്തുനിൽക്കുന്ന സ്ത്രീകൾ പറഞ്ഞ
അസുരക്ഷ അതിൽ വന്നില്ല. തുടർന്ന് “അനുഭവം” എന്ന മറ്റൊരു സ്കോർ ചേർത്തപ്പോൾ,
അതേ സ്ത്രീകൾക്ക് വീണ്ടും വീണ്ടും സർവേ പൂരിപ്പിക്കേണ്ടിവന്നു. പങ്കാളിത്തം ഇവിടെ
അധികാരം പങ്കിടലല്ല, ഭരണകൂടത്തിന്റെ കാണാനാകാത്ത ഭാഗം സൗജന്യമായി വിവർത്തനം
ചെയ്യുന്ന അധ്വാനമായി. അവരുടെ മൊഴിക്ക് പദ്ധതിയെ നിർത്താനുള്ള ശക്തി നൽകിയപ്പോഴാണ്
പങ്കാളിത്തം രീതിശാസ്ത്രത്തെ മാറ്റിയത്.

ഇതിൽ നിന്ന് കിട്ടുന്ന നിഗമനം വിനയമുള്ളതെങ്കിലും സൗകര്യപ്രദമല്ല: നല്ല സൂചിക
പിശകില്ലാത്ത കണ്ണാടി അല്ല; അതിന്റെ അപൂർണത ആരെ ബാധിക്കുന്നു എന്ന് വെളിപ്പെടുത്തി,
ബാധിക്കപ്പെടുന്നവർക്ക് തിരുത്താനും തടയാനും കഴിയുന്ന ഒരു പൊതുകരാറാണ്. അത്തരമൊരു
കരാർ വേഗം കുറയ്ക്കും. എന്നാൽ തെറ്റായ വേഗത്തെ കാര്യക്ഷമത എന്നു വിളിക്കുന്നതിനെക്കാൾ
ആ വൈകൽ ഭരണത്തിന്റെ ചെലവായി അംഗീകരിക്കുന്നതാണ് കൃത്യത.**

1. ആദ്യവാക്യത്തിലെ “ചെറിയൊരു വഞ്ചന” എന്ത്? A കണക്ക് ഒരിക്കലും ഉപയോഗിക്കരുത് / B അളക്കുന്നത് മുഴുവൻ യാഥാർഥ്യത്തെയും പ്രതിനിധീകരിക്കുന്നു / C നഗരത്തിൽ മരങ്ങൾ കുറവാണ്
2. ഭൂപടത്തിന്റെ ഉപമ സൂചിപ്പിക്കുന്നത് എന്ത്? A കൂടുതൽ സൂചികകൾ അടിസ്ഥാന ദൃഷ്ടികോണം സ്വയം മാറ്റില്ല / B എല്ലാ നിറവും തെറ്റാണ് / C ഭൂപടം ഡാറ്റയെക്കാൾ ശ്രേഷ്ഠമാണ്
3. എഴുത്തുകാരന്റെ കേന്ദ്രവാദം ഏത്? A അനുഭവം മാത്രം മതിയാകും / B സെൻസർ നിരോധിക്കണം / C അളവ് സ്ഥാപനാധികാരവുമായി ചേർന്ന് നിർമ്മിക്കുന്ന വാദമാണ്
4. “അടിക്കുറിപ്പ്” എന്ന പരാമർശത്തിന്റെ ഫലം എന്ത്? A ചരിത്രവിവരം പ്രശംസിക്കുന്നു / B നിർണായക അധികാരചോദ്യങ്ങളെ അനുബന്ധമാക്കുന്നതിനെ വിമർശിക്കുന്നു / C റിപ്പോർട്ട് ചുരുക്കാൻ പറയുന്നു
5. ആദ്യ പരീക്ഷണത്തിലെ പ്രധാന വിടവ് ഏത്? A താപനില തെറ്റായി അളന്നു / B സുരക്ഷയുടെ ജീവിച്ച അനുഭവം രേഖപ്പെട്ടില്ല / C ബസ് സമയം ലഭ്യമല്ലായിരുന്നു
6. സർവേയെ അധ്വാനം എന്ന് വിളിക്കുന്നത് എന്തുകൊണ്ട്? A ബാധിക്കപ്പെട്ടവർ സ്ഥാപനത്തിന്റെ വിടവ് വീണ്ടും വിവർത്തനം ചെയ്തു / B ചോദ്യങ്ങൾ വളരെ എളുപ്പമായിരുന്നു / C ഉദ്യോഗസ്ഥർ മറുപടി എഴുതി
7. പങ്കാളിത്തം യഥാർഥമായി രീതിയെ മാറ്റിയത് എപ്പോൾ? A സർവേയുടെ നിറം മാറ്റിയപ്പോൾ / B കൂടുതൽ സെൻസർ വെച്ചപ്പോൾ / C മൊഴിക്ക് പദ്ധതി തടയാനുള്ള അധികാരം കിട്ടിയപ്പോൾ
8. അവസാന ഭാഗത്തെ “വിനയം” എന്താണ്? A തീരുമാനമില്ലായ്മ / B സൂചികയുടെ പരിധിയും ബാധിതരുടെ തിരുത്തൽശക്തിയും അംഗീകരിക്കൽ / C വേഗത്തെ മാത്രം മുൻഗണിക്കൽ
9. വൈകലിനെക്കുറിച്ചുള്ള എഴുത്തുകാരന്റെ നിലപാട്? A ഉത്തരവാദിത്തത്തിനാവശ്യമായ ചെലവാകാം / B എല്ലായ്പ്പോഴും പരാജയമാണ് / C കണക്കിലൂടെ പൂർണമായി ഒഴിവാക്കാം
10. ലേഖനത്തിന്റെ ശൈലി എങ്ങനെ മുന്നേറുന്നു? A കണക്കിനെ പരിഹസിച്ച് കഥയിലേക്ക് മാറുന്നു / B പൊതുവായ അവകാശവാദം, ഉദാഹരണം, സ്ഥാപനപരമായ നിഗമനം / C രണ്ടു അസംബന്ധ നിലപാടുകൾ മാത്രം നിരത്തുന്നു

### Varied public discourse with competing voices — items 11–20

**പഴയ ചന്തയുടെ നവീകരണയോഗത്തിൽ നാലു ശബ്ദങ്ങൾ ഒരേ “സംരക്ഷണം” എന്ന വാക്ക്
ഉപയോഗിച്ചു. വ്യാപാരി രമണി പറഞ്ഞു: “മഴ വന്നാൽ മേൽക്കൂര ചോരും; പൈതൃകത്തിന്റെ
പേരിൽ ഞങ്ങളെ ബക്കറ്റുമായി ഇരുത്തരുത്.” വാസ്തുശില്പി ആദിൽ മറുപടി നൽകി:
“ചോർച്ച നന്നാക്കുന്നതിനെ ആരും എതിർക്കുന്നില്ല. എന്നാൽ മുഴുവൻ കെട്ടിടവും ഗ്ലാസ്
മുഖപ്പോടെ മാറ്റി പഴയ പേരുപലക മാത്രം തൂക്കുന്നത് ഓർമ്മയെ ലോഗോയാക്കും.”

നഗരസഭാ കുറിപ്പിൽ “സജീവ പൈതൃകം” എന്ന് ആവർത്തിച്ചു. അതിന്റെ ചിത്രത്തിൽ പക്ഷേ
കടകൾക്ക് പകരം കഫേ മേശകളും നടുവിൽ പരിപാടിവേദിയും. മീൻവ്യാപാരി സൈനബ ചോദിച്ചു:
“ചിത്രത്തിൽ മണം ഇല്ലാത്തതെന്ത്? ഞങ്ങളുടെ ജോലി കാണാതാകുമ്പോൾ കെട്ടിടം മാത്രം
ജീവിക്കുന്നതെങ്ങനെ?” യോഗാധ്യക്ഷൻ അതിനെ വികാരപരമായ ചോദ്യം എന്ന് വിളിച്ചു;
പിന്നീട് സന്ദർശകാനുഭവത്തിന്റെ “പ്രാമാണികത”യെക്കുറിച്ച് പതിനഞ്ചു മിനിറ്റ് സംസാരിച്ചു.

വിദ്യാർത്ഥി നിവേദിന്റെ കുറിപ്പ് വേറൊരു വിരോധം ചൂണ്ടി. ഇപ്പോഴത്തെ ചന്തയിൽ
വീൽചെയറിന് പ്രവേശനം മോശമാണ്; അതിനെ “പഴയ രൂപത്തിന്റെ സ്വഭാവം” എന്നു കാത്തുസൂക്ഷിക്കാൻ
കഴിയില്ല. എന്നാൽ പ്രവേശനപാതയ്ക്കായി പിന്നിലെ കുറഞ്ഞവിലക്കടകൾ നീക്കുമെന്ന രൂപരേഖ,
സൗകര്യത്തെ കുടിയൊഴിപ്പിക്കലിന്റെ ന്യായമായി മാറ്റുന്നു. “പടി നിലനിർത്തണോ കട
നിലനിർത്തണോ” എന്ന തിരഞ്ഞെടുപ്പ് തെറ്റായി നിർമ്മിച്ചതാണെന്ന് അവൻ പറഞ്ഞു; മറ്റൊരു
വാതിലും ലിഫ്റ്റും പരിശോധിച്ചിട്ടില്ല.

യോഗാവസാനത്തിൽ രമണി പറഞ്ഞു: “എനിക്ക് പഴയ മതിലിനോട് സ്നേഹമുണ്ട്; പക്ഷേ സ്നേഹം
മേൽക്കൂരയാകില്ല.” ആദിൽ ചേർത്തു: “ശരി; പുതിയ മേൽക്കൂര ചരിത്രം മായ്ക്കേണ്ടതുമില്ല.”
ആ ചെറുസമ്മതം ഔദ്യോഗിക മിനിറ്റ്സിൽ “എല്ലാവരും നവീകരണത്തെ പിന്തുണച്ചു” ആയി.

ഭൂപടം ഡിജിറ്റൽ ശേഖരത്തിലേക്ക് നൽകാൻ ഉദ്യോഗസ്ഥ വന്നു. പേപ്പറിന്റെ അരികിലെ
മുത്തച്ഛന്റെ കുറിപ്പുകൾ അവൾക്ക് തടസ്സമായി: “അളവ് വ്യക്തമല്ല”, “ഇവിടെ ഒരിക്കൽ

വഴി തിരഞ്ഞെടുത്തു. അന്ന് മുത്തച്ഛന്റെ വാക്ക് വീണ്ടും മനസ്സിലായെന്ന് കരുതി.

തെളിവ്, ഏത് ഭാഗം ഓർമ്മ, ഏത് ഭാഗം മറ്റൊരാളുടെ വാക്ക് മുത്തച്ഛന്റെ ജ്ഞാനമായി
ഞാൻ പുനർവായിച്ചതെന്ന് വേർതിരിക്കാൻ കഴിയുന്നില്ല. അതുകൊണ്ട് ഒന്നും നൽകാതിരിക്കണോ?

### Extended specialist argument — items 9–16

**പ്രഭാഷകൻ:** നയരേഖയിൽ നിശ്ശബ്ദതയെ “വിവരം ലഭ്യമല്ല” എന്ന് അടയാളപ്പെടുത്തുന്നത്
സുരക്ഷിതമെന്നു തോന്നാം. പക്ഷേ ലഭ്യമല്ലാത്തതും ചോദിക്കപ്പെടാത്തതും പറയാൻ കഴിയാത്തതും
ഒന്നല്ല. തൊഴിൽസ്ഥല പീഡന സർവേയിൽ പരാതി കുറവാണെങ്കിൽ അന്തരീക്ഷം നല്ലതാകാം;
അല്ലെങ്കിൽ പരാതി നൽകിയവൻ ജോലി നഷ്ടപ്പെട്ട പഴയ കഥ എല്ലാവർക്കും അറിയാം. സംഖ്യ
ഒരേത്, കാരണഘടന വിരുദ്ധം.

ഇതിന് ചിലർ കൂടുതൽ രഹസ്യ സർവേ നിർദേശിക്കും. അത് ആവശ്യമാണ്, പര്യാപ്തമല്ല. ചോദ്യം
സ്ഥാപനം തന്നെ നിർവചിക്കുന്നു. “കഴിഞ്ഞ പന്ത്രണ്ടു മാസത്തിൽ സംഭവം ഉണ്ടായോ?” എന്നത്
പേര് നൽകാൻ കഴിയാത്ത സൂക്ഷ്മ പ്രതികാരത്തെ പുറത്താക്കാം. തുറന്ന മൊഴി ചേർത്താൽ ശബ്ദം
കിട്ടും; പക്ഷേ അത് വായിച്ച് വർഗ്ഗമാക്കുന്ന ഗവേഷകൻ വീണ്ടും അർത്ഥത്തിന് കവാടമാകും.

അതുകൊണ്ട് മൂന്ന് നില വേണം. ഒന്നാമത്, രേഖപ്പെട്ട സംഭവം. രണ്ടാമത്, മറുപടി പറയാതിരിക്കാൻ
ഉള്ള സാഹചര്യങ്ങളുടെ സ്വതന്ത്ര പഠനം. മൂന്നാമത്, നയത്തിന് എതിർതെളിവ് കണ്ടെത്താനുള്ള
മുൻകൂട്ടിയുള്ള ബാധ്യത. അവസാനത്തേതാണ് സാധാരണ നഷ്ടമാകുന്നത്. സ്ഥാപനം മെച്ചപ്പെട്ടു
എന്ന് തെളിയിക്കാൻ ഡാറ്റ ഉപയോഗിക്കുമ്പോൾ, മെച്ചപ്പെട്ടിട്ടില്ലെന്ന് കാണിക്കുന്ന ഏത്
സൂചന വന്നാൽ നയം മാറ്റുമെന്ന് മുമ്പേ പറയണം. ഇല്ലെങ്കിൽ “വിവരം ലഭ്യമല്ല” എന്നത്
അജ്ഞതയുടെ അടയാളമല്ല; സംശയത്തെ ഭരണസൗകര്യമായി മാറ്റുന്ന മുദ്രയാണ്.

### Stylistically complex oral essay — items 17–24

**വായനക്കാരൻ:** വീട്ടിൽ ഉണ്ടായിരുന്ന ഒരു കറുത്ത കുടയെ എല്ലാവരും “അച്ഛന്റെ കുട”
എന്നു വിളിച്ചു. അച്ഛൻ അത് വാങ്ങിയിട്ടില്ല; റെയിൽവേ സ്റ്റേഷനിൽ ആരോ മറന്നത്
മഴയുള്ള രാത്രി വീട്ടിലെത്തിച്ചു. “നാളെ തിരികെ കൊടുക്കാം” എന്ന് പറഞ്ഞ നാളെ
ഇരുപത്തഞ്ചു വർഷം നീണ്ടു. അതിനിടെ കുടയുടെ ഒരു കമ്പി അമ്മ മാറ്റി, തുണി ഞാൻ
തുന്നി, പിടി സഹോദരി പുതുക്കി. ഉടമസ്ഥത മാത്രം അച്ഛന്റേതായി തുടരുകയായിരുന്നു.

അച്ഛൻ മരിച്ചശേഷം കുട സ്റ്റേഷനിലെ നഷ്ടവസ്തു ഓഫീസിൽ നൽകണമെന്ന് എനിക്ക് തോന്നി.
സഹോദരി ചിരിച്ചു: “അവർക്കു പഴയ ഉടമയെ കണ്ടെത്താമോ, പുതിയ ഓർമ്മയെ നഷ്ടപ്പെടുത്താമോ?”
ഞാൻ അത് വാക്കുകളിലെ കളിയെന്നു കരുതി. ഓഫീസിലെ യുവാവ് രജിസ്റ്റർ തുറന്ന് വസ്തുവിന്റെ
വയസ് ചോദിച്ചു; ഞാൻ “കുറഞ്ഞത് ഇരുപത്തഞ്ച്” എന്നു പറഞ്ഞു. അവൻ കുട തുറന്നു.
അകത്ത് അമ്മയുടെ നീല നൂലും എന്റെ മോശം തുന്നലും. “ഇത് നിങ്ങൾ നഷ്ടപ്പെടുത്തിയതല്ലേ?”

കുട തിരികെ വീട്ടിലെത്തി. മഴയില്ലാത്ത ദിവസം ഞാൻ അത് വരാന്തയിൽ തുറന്നുവച്ചു.
നിഴൽ വട്ടമായിരുന്നില്ല; ഓരോ അറ്റവും മറ്റൊരു കാലത്തിന്റെ അറ്റകുറ്റപ്പണി. അച്ഛന്റെ
കുട എന്ന പേര് ഞാൻ മാറ്റിയില്ല. പക്ഷേ ഇനി പേര് ഉടമസ്ഥതയല്ല, കടത്തിന്റെ ഓർമ്മയാണ്.
