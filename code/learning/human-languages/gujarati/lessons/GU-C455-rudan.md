# રુદન (rudan) — weeping; wailing

## You'll want to know: રુદન
<!-- hl-knowledge: introduces=[GU-LEX-C455-GAMGIN455-05]; assesses=[] -->

**રુદન** — *rudan* — "weeping; wailing".

> બાળકનું રુદન આખી રાત ચાલ્યું.
>
> *bāḷaknũ rudan ākhī rāt cālyũ.*
>
> The child's crying went on all night.

A neuter noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**રુદન** (*rudan*) is a tatsama, Sanskrit *rudana*, "the act of crying, weeping, lamentation", as Monier-Williams records it.
