# ಸಂಕಷ್ಟ (saṅkaṣṭa) — hardship; distress

## You'll want to know: ಸಂಕಷ್ಟ
<!-- hl-knowledge: introduces=[KA-LEX-C412-APAYA412-04]; assesses=[] -->

**ಸಂಕಷ್ಟ** — *saṅkaṣṭa* — "hardship; distress".

> ಪ್ರವಾಹದ ನಂತರ ಹಳ್ಳಿಯ ಜನರು ಸಂಕಷ್ಟದಲ್ಲಿ ಇದ್ದರು.
>
> *pravāhada nantara haḷḷiya janaru saṅkaṣṭadalli iddaru.*
>
> After the flood the villagers were in distress.

ಕಷ್ಟ with ಸಂ-: a heavy trouble.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಸಂಕಷ್ಟ** (*saṅkaṣṭa*) is borrowed from Sanskrit *saṃkaṣṭa*, "distress, trouble" (Monier-Williams), built on *kaṣṭa*, "hardship" (CDIAL 2978).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
