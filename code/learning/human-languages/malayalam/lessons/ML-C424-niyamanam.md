# നിയമനം (niyamanaṁ) — an appointment (to a post)

## You'll want to know: നിയമനം
<!-- hl-knowledge: introduces=[ML-LEX-C424-ADHIKARAM424-02]; assesses=[] -->

**നിയമനം** — *niyamanaṁ* — "an appointment (to a post)".

> പുതിയ അധ്യാപകരുടെ നിയമനം അടുത്ത മാസം നടക്കും.
>
> *putiya adhyāpakaruṭe niyamanaṁ aṭutta māsaṁ naṭakkuṁ.*
>
> The appointment of the new teachers will take place next month.

A post filled by an official order; a meeting time is a different word.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**നിയമനം** (*niyamanaṁ*) is borrowed from Sanskrit *niyamana*, "subduing, restraining" (Monier-Williams), from the same root as നിയമം (CDIAL 7250); Malayalam uses it for fixing a person in a post.
