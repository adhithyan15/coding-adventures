# நேயர் (nēyar) — a listener; a viewer

## You'll want to know: நேயர்
<!-- hl-knowledge: introduces=[TA-LEX-C309-VASAKAR309-02]; assesses=[] -->

**நேயர்** — *nēyar* — "a listener; a viewer".

> வானொலி நேயர்கள் பாடல்களை விரும்பிக் கேட்டார்கள்.
>
> *vāṉoli nēyarkaḷ pāṭalkaḷai virumpik kēṭṭārkaḷ.*
>
> The radio listeners enjoyed the songs.

For radio listeners and television viewers: அன்பான நேயர்களே, dear listeners.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**நேயர்** (*nēyar*) is built on நேயம், "affection", usually traced to Sanskrit *snēha*, "love, fondness" (CDIAL 13802): a listener is a well-wisher.
