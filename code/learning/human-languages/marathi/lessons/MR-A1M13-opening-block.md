# Order the opening block

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MR-A1-MESSAGE-LINE-GREETING, MR-A1-MESSAGE-LINE-NAME, MR-A1-MESSAGE-LINE-MEETING] -->

Retrieve the three opening jobs: greet Mira, name Arun, acknowledge the
meeting. Each job already has one practised line.

## Writing — controlled composition
<!-- hl-knowledge: introduces=[]; assesses=[MR-A1-MESSAGE-LINE-GREETING, MR-A1-MESSAGE-LINE-NAME, MR-A1-MESSAGE-LINE-MEETING] -->
<!-- hl-writing-stage: controlled-composition -->

Put these known line cards in message order, then write them as three lines:

- **भेटून आनंद झाला.**
- **नमस्कार मीरा.**
- **माझं नाव अरुण आहे.**

Choose the order from the three jobs. Do not change any words.
