# এলোমেলো (elomelo) — messy; in disorder

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[BN-LEX-C462-OLOS462-01, BN-LEX-C462-OLOS462-02] -->

[PAUSE 2s] Before the new one: say the Bengali for lazy, then the Bengali for industrious.

## You'll want to know: এলোমেলো
<!-- hl-knowledge: introduces=[BN-LEX-C462-OLOS462-03]; assesses=[] -->

**এলোমেলো** — *elomelo* — "messy; in disorder".

> অরুণের টেবিলটা সবসময় এলোমেলো থাকে।
>
> *ôruner ṭebilṭā sôbsômôy elomelo thāke.*
>
> Arun's desk is always in a mess.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**এলোমেলো** (*elomelo*) is a rhyming doubling that paints things scattered every which way; its origin is not settled.
