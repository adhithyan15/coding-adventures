## You'll want to know: نرم افزار
<!-- hl-knowledge: introduces=[FA-LEX-C418-NARMAFZAR-01]; assesses=[] -->

**نرم افزار** (*narm afzâr*) — "software".

> این نرم افزار رایگان است.
>
> *in narm afzâr râygân ast.*
>
> This software is free.

*Narm* "soft" + *afzâr* "tool". Also an app.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**نرم افزار** is a modern native calque of English *software*, built from *narm* "soft" + *afzâr* "tool, equipment".
