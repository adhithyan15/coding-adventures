## You'll want to know: el rescate
<!-- hl-knowledge: introduces=[ES-LEX-C526-RESCATE-02]; assesses=[] -->

**el rescate** — "the rescue; the ransom".

> El rescate duró toda la noche.
>
> *The rescue lasted all night.*

It is also the money asked for a hostage: *pedir un rescate*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*rescate* is built on *rescatar* 'to rescue' (EtymDB), which goes back to spoken Latin *\*reexcaptāre*, from *captāre* 'to try to catch'.
