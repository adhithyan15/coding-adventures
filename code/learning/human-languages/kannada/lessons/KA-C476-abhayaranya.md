# ಅಭಯಾರಣ್ಯ (abhayāraṇya) — a sanctuary; a wildlife reserve

## You'll want to know: ಅಭಯಾರಣ್ಯ
<!-- hl-knowledge: introduces=[KA-LEX-C476-VANYAJIVI476-02]; assesses=[] -->

**ಅಭಯಾರಣ್ಯ** — *abhayāraṇya* — "a sanctuary; a wildlife reserve".

> ಅಭಯಾರಣ್ಯದಲ್ಲಿ ಮರ ಕಡಿಯುವುದು ನಿಷೇಧ.
>
> *abhayāraṇyadalli mara kaḍiyuvudu niṣēdha.*
>
> Cutting trees in a sanctuary is banned.

ಅಭಯ, safety, plus ಅರಣ್ಯ, forest: a safe forest.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಅಭಯಾರಣ್ಯ** (*abhayāraṇya*) is a modern compound built from Sanskrit words: *abhaya*, "fearless; safety" (CDIAL 507), and *araṇya*, "a forest" (CDIAL 600).
