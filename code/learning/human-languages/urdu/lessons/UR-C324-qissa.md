## You'll want to know: قصہ
<!-- hl-knowledge: introduces=[UR-LEX-C324-DASTAN324-03]; assesses=[] -->

**قصہ** — *qissā* — "a tale; an anecdote".

> یہ قصہ سب جانتے ہیں۔
>
> *yih qissā sab jānte haiṅ.*
>
> Everyone knows this story.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

is usually traced, through Persian, to Arabic *qiṣṣa*, "a story". A **قصہ** is short; a **داستان** is long.
