# విశ్లేషణ (viślēṣaṇa) — an analysis

## You'll want to know: విశ్లేషణ
<!-- hl-knowledge: introduces=[TE-LEX-C389-VISLESANA389-02]; assesses=[] -->

**విశ్లేషణ** — *viślēṣaṇa* — "an analysis".

> అతని విశ్లేషణ చాలా స్పష్టంగా ఉంది.
>
> *atani viślēṣaṇa cālā spaṣṭaṅgā undi.*
>
> His analysis is very clear.

From the same word as విశ్లేషించు.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**విశ్లేషణ** (*viślēṣaṇa*) is borrowed from Sanskrit *viśleṣaṇa*, "separation, dissolution" (Monier-Williams); Telugu uses it for taking a question apart, an analysis.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
