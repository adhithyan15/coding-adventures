# ter que — to have to

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[] -->

[PAUSE 2s] You know **tenho**, “I have.” Add **que** and a verb to express one
obligation.

## You'll want to know: One reusable frame
<!-- hl-knowledge: introduces=[PT-GRAMMAR-TER-QUE-04]; assesses=[] -->

> **Tenho que falar.** — I have to speak.

Build it in three pieces:

1. **tenho** — I have
2. **que** — the link
3. **falar** — to speak

Only **ter** changes with the person. The following action stays in its
dictionary form: **temos que falar**, “we have to speak.”
