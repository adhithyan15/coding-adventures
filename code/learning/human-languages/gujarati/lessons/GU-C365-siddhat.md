# સિદ્ધાંત (siddhā̃t) — a principle (a theory)

## You'll want to know: સિદ્ધાંત
<!-- hl-knowledge: introduces=[GU-LEX-C365-SIDDHANT365-01]; assesses=[] -->

**સિદ્ધાંત** — *siddhā̃t* — "a principle (a theory)".

> આ સિદ્ધાંત કાગળ પર સારો છે.
>
> *ā siddhā̃t kāgaḷ par sāro che.*
>
> This theory looks good on paper.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**સિદ્ધાંત** (*siddhā̃t*) is a tatsama, borrowed from Sanskrit *siddhānta*, "an established end, a settled doctrine" (Monier-Williams).
