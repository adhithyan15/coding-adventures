# DELE A2 mock 2 — answer key and item provenance

Paper: `mock-2-paper.md`. Scoring and pass rule: `rubric.md`.

Every row carries a **`requires`** column: the lexemes and grammar a candidate
must hold to answer that item. Per `rubric.md` §6, an item is scored correct in
a book-bounded sitting **only if every entry in `requires` is taught at or below
A2**. Lexemes are written as citation forms (infinitives, bare singular nouns);
a `!` prefix marks a grammar point rather than a lexeme and is not checked
against the vocabulary.

This mock samples the **same lexical range** as mock 1 by design. Two papers at
one level should test one vocabulary, not two, so teaching the mock-1 gap
largely closes this one too.
