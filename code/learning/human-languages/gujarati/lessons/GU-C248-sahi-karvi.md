# સહી કરવી (sahī karvī) — to sign

## You'll want to know: સહી કરવી
<!-- hl-knowledge: introduces=[GU-LEX-C248-OFFICE248-03]; assesses=[] -->

**સહી કરવી** — *sahī karvī* — "to sign".

> **સાહેબ સાંજે બધા કાગળમાં સહી કરે છે.** — *sāheb sā̃je badhā kāgaḷmā̃ sahī kare che* — "The boss signs all the papers in the evening."

**સહી**, *sahī*, alone means a signature.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**સહી કરવી** (*sahī karvī*) is built from *sahī*, "signature", and *karvī*, "to do". *Sahī* is usually traced to Arabic *ṣaḥīḥ*, "sound, correct", through Persian; its Arabic root is *ṣ-ḥ-ḥ* (Lane).
