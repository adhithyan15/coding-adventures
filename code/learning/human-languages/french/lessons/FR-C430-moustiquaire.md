## You'll want to know: la moustiquaire
<!-- hl-knowledge: introduces=[FR-LEX-C430-BESTIOLES-03]; assesses=[] -->

**la moustiquaire** — "the mosquito net; the fly screen".

> La fenêtre a une moustiquaire, alors nous dormons bien.
>
> *The window has a fly screen, so we sleep well.*

Built on *le moustique*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*moustiquaire* is built on *moustique* 'mosquito', from Spanish *mosquito* 'little fly', which goes back to Latin *musca* 'fly' (Lewis & Short).
