# కప్పిపుచ్చు (kappipuccu) — to cover up; to hush up

## You'll want to know: కప్పిపుచ్చు
<!-- hl-knowledge: introduces=[TE-LEX-C354-KUTRA354-04]; assesses=[] -->

**కప్పిపుచ్చు** — *kappipuccu* — "to cover up; to hush up".

> అధికారులు ఆ తప్పును కప్పిపుచ్చారు.
>
> *adhikārulu ā tappunu kappipuccāru.*
>
> The officials covered up the mistake.

Past (I …): కప్పిపుచ్చాను, *kappipuccānu*.

Built on కప్పు, to cover.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**కప్పిపుచ్చు** (*kappipuccu*) is a native compound built on *kappu*, "to cover, conceal" (DEDR 1221), which also gives కప్పు, a roof.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
