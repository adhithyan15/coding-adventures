# سوتیلا (sautelā) — step- (related by remarriage)

## You'll want to know: سوتیلا
<!-- hl-knowledge: introduces=[UR-LEX-C490-STEP490-03]; assesses=[] -->

**سوتیلا** — *sautelā* — "step- (related by remarriage)".

> اس کی سوتیلی ماں بڑی مہربان ہے۔
>
> *us kī sautelī māṅ baṛī mehrbān hai.*
>
> His stepmother is very kind.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**سوتیلا** (*sautelā*) is inherited: it is built on *saut*, "a co-wife", which CDIAL lists under Sanskrit *sapátnī*, "co-wife" (CDIAL 13130).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
