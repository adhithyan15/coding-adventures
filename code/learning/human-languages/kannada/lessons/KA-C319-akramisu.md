# ಆಕ್ರಮಿಸು (ākramisu) — to invade; to attack

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C319-YUDDHA319-01, KA-LEX-C319-YUDDHA319-02] -->

[PAUSE 2s] Before the new one: say the Kannada for a war, then the Kannada for a soldier.

## You'll want to know: ಆಕ್ರಮಿಸು
<!-- hl-knowledge: introduces=[KA-LEX-C319-YUDDHA319-03]; assesses=[] -->

**ಆಕ್ರಮಿಸು** — *ākramisu* — "to invade; to attack".

> ಸೈನಿಕರು ಆ ದೇಶವನ್ನು ಆಕ್ರಮಿಸಿದರು.
>
> *sainikaru ā dēśavannu ākramisidaru.*
>
> The soldiers invaded that country.

Past (I …): ಆಕ್ರಮಿಸಿದೆ, *ākramiside*.

What is attacked takes -ಅನ್ನು: ದೇಶವನ್ನು ಆಕ್ರಮಿಸು, to invade a country.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಆಕ್ರಮಿಸು** (*ākramisu*) is built from Sanskrit *ākramaṇa*, "stepping on, an advance" (CDIAL 1016), from *ā-* "towards" and *kram* "to step", with the Kannada ending -*isu* that turns a Sanskrit noun into a verb.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
