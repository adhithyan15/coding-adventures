## You'll want to know: نفوذ
<!-- hl-knowledge: introduces=[AR-LEX-C389-NUFUDH389-01]; assesses=[] -->

**نفوذ** — *nufūdh* — "influence".

> لهذا الرجل نفوذ كبير في المدينة.
>
> *li-hādhā ar-rajul nufūdh kabīr fī al-madīna.*
>
> This man has great influence in the city.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**نفوذ** (*nufūdh*) is built on the native Arabic root *n-f-dh*, "to pass through, to pierce" (Lane). *Nufūdh* is passing through: the power to make things happen, influence.
