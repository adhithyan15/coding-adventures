# கிளம்பலாமா? (kiḷampalāmā?) — shall we leave?

<!-- hl-knowledge: introduces=[]; assesses=[TA-LEX-C106-CARE-05, TA-LEX-C107-LEAVE-01] -->

[PAUSE 2s] Before the new one: say the Tamil for a holiday, then the Tamil for I take my leave.

## You'll want to know: கிளம்பலாமா?
<!-- hl-knowledge: introduces=[TA-LEX-C107-LEAVE-02]; assesses=[] -->

**கிளம்பலாமா?** (*kiḷampalāmā?*) — "shall we leave?".

**கிளம்பு** is "to set out"; **-லாமா** asks "shall we?".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**கிளம்பலாமா?** (*kiḷampalāmā?*) is native Dravidian. DEDR 1583 lists Malayalam *kiḷampuka*, "to rise". The entry lists *kiḷampu*, "to rise, to start up": to leave is to get up and go.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

A gentle nudge to go.
