## You'll want to know: bèiyòng
<!-- hl-knowledge: introduces=[ZH-LEX-C389-INCASE389-01]; assesses=[] -->

*bèiyòng* — "spare (kept for when needed)".

> *wànyī yàoshi diū le wǒmen hái yǒu bèiyòng de* — If the keys get lost, we've still got a spare.

Its characters come later; for now it is a word for the ear.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*bèiyòng* is built from *bèi* 'to provide against' and 用 'to use', both inherited from Middle Chinese, *bijH* and *yowngH* (Guangyun, in Baxter's transcription), which glosses the first 'complete' and 'to guard against'.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what would happen.
