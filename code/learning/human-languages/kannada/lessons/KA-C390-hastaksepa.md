# ಹಸ್ತಕ್ಷೇಪ (hastakṣēpa) — interference

## You'll want to know: ಹಸ್ತಕ್ಷೇಪ
<!-- hl-knowledge: introduces=[KA-LEX-C390-KANUNU390-05]; assesses=[] -->

**ಹಸ್ತಕ್ಷೇಪ** — *hastakṣēpa* — "interference".

> ನಮ್ಮ ಮನೆಯ ವಿಷಯದಲ್ಲಿ ಬೇರೆಯವರ ಹಸ್ತಕ್ಷೇಪ ಬೇಡ.
>
> *namma maneya viṣayadalli bēreyavara hastakṣēpa bēḍa.*
>
> We want no outside interference in our family's matters.

Word by word it is throwing in a hand: ಹಸ್ತ + ಕ್ಷೇಪ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಹಸ್ತಕ್ಷೇಪ** (*hastakṣēpa*) is built from Sanskrit *hasta*, "a hand" (CDIAL 14024), and *kṣepa*, "a throw, a cast" (Monier-Williams).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
