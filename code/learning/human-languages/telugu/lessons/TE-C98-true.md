# నిజమే (nijamē) — that's true

## You'll want to know: నిజమే
<!-- hl-knowledge: introduces=[TE-LEX-C98-REPLY-04]; assesses=[] -->

**నిజమే** (*nijamē*) — "that's true", "quite right".

It is **నిజం** with **-ఏ**, the ending that says *exactly this*. Where **నిజంగా?** asks, **నిజమే**
agrees.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

Agreement, from the word for truth.
