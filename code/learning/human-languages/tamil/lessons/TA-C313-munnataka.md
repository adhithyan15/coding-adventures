# முன்னதாக (muṉṉatāka) — earlier; beforehand

## You'll want to know: முன்னதாக
<!-- hl-knowledge: introduces=[TA-LEX-C313-NERAM313-05]; assesses=[] -->

**முன்னதாக** — *muṉṉatāka* — "earlier; beforehand".

> விழா ஒரு மணி நேரம் முன்னதாகத் தொடங்கியது.
>
> *viḻā oru maṇi nēram muṉṉatākat toṭaṅkiyatu.*
>
> The ceremony started an hour earlier.

Also beforehand: முன்னதாகவே சொன்னேன், I said so in advance.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**முன்னதாக** (*muṉṉatāka*) is built on native முன், "in front, before" (DEDR 5020), with the adverb ending -ஆக.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
