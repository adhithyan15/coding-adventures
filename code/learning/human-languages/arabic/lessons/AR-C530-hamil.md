# حامل (ḥāmil) — pregnant

## You'll want to know: حامل
<!-- hl-knowledge: introduces=[AR-LEX-C530-ATFAL530-01]; assesses=[] -->

**حامل** — *ḥāmil* — "pregnant".

> زوجة أخي حامل بطفلها الأول.
>
> *zawjat akhī ḥāmil bi-ṭiflihā al-awwal.*
>
> My brother's wife is pregnant with her first child.

It has no feminine ending, since only a woman is حامل.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**حامل** (*ḥāmil*) is built on the native Arabic root *ḥ-m-l*, "to carry" (Lane). Ḥamala, to carry, which you know, is from the same root.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
