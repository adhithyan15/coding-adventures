## You'll want to know: actual
<!-- hl-knowledge: introduces=[ES-LEX-C508-CUALIDAD-04]; assesses=[] -->

**actual** — "current, present-day".

> El precio actual es de diez euros.
>
> *The current price is ten euros.*

A false friend: actual in English is *real*.
