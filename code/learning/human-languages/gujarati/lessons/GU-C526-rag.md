## You'll want to know: રાગ
<!-- hl-knowledge: introduces=[GU-LEX-C526-SUR526-04]; assesses=[] -->

**રાગ** — *rāg* — "a raga (a melodic mode)".

> ગાયકે સાંજે એક જૂનો રાગ ગાયો.
>
> *gāyke sā̃je ek jūno rāg gāyo.*
>
> In the evening the singer sang an old raga.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**રાગ** (*rāg*) is a tatsama, taken from Sanskrit *rāga*, "colouring", which Monier-Williams also gives for a musical mode (Monier-Williams).
