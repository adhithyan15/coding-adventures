Arabic, chapter 226: To set off, To charge, To apologise, To inform, To agree.
5 lessons. All 5 can be done entirely by ear.


Lesson 1 of 5.
انطلق (inṭalaqa) — to set off.

Warm-up.
[pause 2 seconds]
Before the new one: say the Arabic for to use, then the Arabic for to bring.

You'll want to know: انطلق.
انطلق — inṭalaqa — "to set off".

The word, taken apart.
انطلق (inṭalaqa) is built on the native Arabic root ṭ-l-q, "to be free, to be let go" (Lane). Inṭalaqa is Form VII, "to be let loose", to set off.
