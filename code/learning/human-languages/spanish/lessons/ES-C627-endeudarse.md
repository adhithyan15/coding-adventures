## You'll want to know: endeudarse
<!-- hl-knowledge: introduces=[ES-LEX-C627-GASTO-04]; assesses=[] -->

**endeudarse** — "to get into debt".

> Se endeudó para comprar un coche.
>
> *He got into debt to buy a car.*

Built on *la deuda*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*endeudarse* is built on *deuda* 'debt', inherited from Latin *debita* 'things owed', from *debere* 'to owe' (EtymDB).
