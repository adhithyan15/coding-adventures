## You'll want to know: капризный
<!-- hl-knowledge: introduces=[RU-LEX-C478-STUBBORN-03]; assesses=[] -->

**капризный** (*kapríznyy*) — "fussy, capricious".

> Капризный ребёнок плачет из-за каждой мелочи.
>
> *Kapríznyy rebyónok pláchet iz-za kázhdoy mélochi.*
>
> The fussy child cries over every little thing.

Built on *каприз* — a whim.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*капризный* is built on *каприз* 'whim', which was borrowed from French *caprice*, itself from Italian *capriccio* (EtymDB).
