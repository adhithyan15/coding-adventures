# जर … तर … (jar … tar …) — if

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MR-GRAMMAR-C277-FUTURE-PERSON-01, MR-GRAMMAR-C276-PAST-PERSON-01, MR-GRAMMAR-C285-FROM-UNTIL-01] -->

[PAUSE 2s] Say "it will rain" and "it rained". (*pāūs paḍel*, *pāūs paḍlā*.) Then "it rained all day". (*divasbhar pāūs paḍat hotā*.)

## You'll want to know: जर … तर
<!-- hl-knowledge: introduces=[MR-GRAMMAR-C286-JAR-TAR-01]; assesses=[MR-LEX-C99-NATURE99-01, MR-LEX-C84-VERBS84-04, MR-LEX-RAHNE, MR-GRAMMAR-C277-FUTURE-STEMS-01] -->

> **जर उद्या पाऊस पडला, तर मी घरी राहीन.**
>
> *jar udyā pāūs paḍlā, tar mī gharī rāhīn.* — "If it rains tomorrow, I will stay at home."

**जर** (*jar*) opens the condition, **तर** (*tar*) opens the result. The condition takes the **past** form, **पडला**, though it looks ahead; the result is in the future, **राहीन**. **जर** can go: **पाऊस पडला तर मी घरी राहीन** (*pāūs paḍlā tar mī gharī rāhīn*). **तर** stays.

## You'll want to know: if it is
<!-- hl-knowledge: introduces=[MR-GRAMMAR-C286-IF-ASEL-01]; assesses=[MR-LEX-C111-TIME111-05, MR-LEX-YENE] -->

> **जर तुम्हाला वेळ असेल, तर या.**
>
> *jar tumhālā veḷ asel, tar yā.* — "If you have time, come."

For a state, the condition takes the future of "to be", **असेल**; the result can be a request. **या**, "come", is the polite form of **येणे**.
