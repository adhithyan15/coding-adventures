# ધૂંધળું (dhū̃dhḷũ) — hazy; misty

## You'll want to know: ધૂંધળું
<!-- hl-knowledge: introduces=[GU-LEX-C438-DUSK438-04]; assesses=[] -->

**ધૂંધળું** — *dhū̃dhḷũ* — "hazy; misty".

> ધુમ્મસમાં બધું ધૂંધળું લાગે છે.
>
> *dhummasmā̃ badhũ dhū̃dhḷũ lāge che.*
>
> In the fog everything looks hazy.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ધૂંધળું** (*dhū̃dhḷũ*) goes back to *\*dhūmāndha*, "blinded by smoke", a form CDIAL reconstructs; CDIAL lists the Gujarati word, "misty" (CDIAL 6858).
