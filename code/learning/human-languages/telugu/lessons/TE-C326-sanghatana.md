# సంఘటన (saṅghaṭana) — an incident; an event

## You'll want to know: సంఘటన
<!-- hl-knowledge: introduces=[TE-LEX-C326-SANGHATANA326-03]; assesses=[] -->

**సంఘటన** — *saṅghaṭana* — "an incident; an event".

> నిన్న రాత్రి ఒక వింత సంఘటన జరిగింది.
>
> *ninna rātri oka vinta saṅghaṭana jarigindi.*
>
> A strange incident happened last night.

It goes with జరుగు, to happen: సంఘటన జరిగింది, the incident happened.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**సంఘటన** (*saṅghaṭana*) is borrowed from Sanskrit *saṁghaṭana*, "union, a coming together" (Monier-Williams), built from *sam-* "together" and *ghaṭ* "to join". In Telugu the things that come together make an event, an incident.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
