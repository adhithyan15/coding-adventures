# ಬೋರ್ಡಿಂಗ್ ಪಾಸ್ (bōrḍiṅg pās) — a boarding pass

## You'll want to know: ಬೋರ್ಡಿಂಗ್ ಪಾಸ್
<!-- hl-knowledge: introduces=[KA-LEX-C437-VIMANA437-03]; assesses=[] -->

**ಬೋರ್ಡಿಂಗ್ ಪಾಸ್** — *bōrḍiṅg pās* — "a boarding pass".

> ಬೋರ್ಡಿಂಗ್ ಪಾಸ್ ಇಲ್ಲದೆ ಒಳಗೆ ಹೋಗಲು ಆಗುವುದಿಲ್ಲ.
>
> *bōrḍiṅg pās illade oḷage hōgalu āguvudilla.*
>
> Without a boarding pass nobody can go in.

ಪಾಸ್ alone is any pass or permit card.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಬೋರ್ಡಿಂಗ್ ಪಾಸ್** (*bōrḍiṅg pās*) is a loan from English *boarding pass*, taken over whole.
