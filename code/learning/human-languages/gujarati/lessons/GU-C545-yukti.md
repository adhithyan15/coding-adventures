## You'll want to know: યુક્તિ
<!-- hl-knowledge: introduces=[GU-LEX-C545-AASAN545-05]; assesses=[] -->

**યુક્તિ** — *yukti* — "a clever trick".

> જો આ યુક્તિ કામ કરશે તો આપણે ઘણો સમય બચાવીશું.
>
> *jo ā yukti kām karśe to āpaṇe ghaṇo samay bacāvīśũ.*
>
> If this trick works, we'll save a lot of time.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**યુક્તિ** (*yukti*) is a tatsama, taken from Sanskrit *yukti*, "union, joining; a contrivance" (Monier-Williams).

One more word for saying what happens if.
