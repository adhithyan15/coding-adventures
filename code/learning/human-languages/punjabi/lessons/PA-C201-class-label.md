# Put the new school noun into one identity frame

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-CLASS-201, PA-DEM-EH-01, PA-LEX-HAI-02] -->

[PAUSE 2s] Retrieve **ਇਹ**, then the new school noun, then **ਹੈ**.

## Grammar Lens
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-CLASS-201, PA-DEM-EH-01, PA-LEX-HAI-02, PA-GRAMMAR-VERB-LAST-02] -->

> **ਇਹ ਕਲਾਸ ਹੈ** — *eh kalās hai* — this is a class

Keep the new whole noun between familiar **ਇਹ** and **ਹੈ**. Familiar **ਹੈ**
stays last in the already-owned identity frame. This chapter teaches only this
one school label; it does not add a form rule or a wider construction.
