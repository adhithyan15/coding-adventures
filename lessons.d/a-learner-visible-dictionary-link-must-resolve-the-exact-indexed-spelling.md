# A learner-visible dictionary link must resolve the exact indexed spelling

A source can index a Punjabi headword with a Unicode compatibility letter even
when the curriculum intentionally authors the modern decomposed spelling. A
domain-only test will accept a query URL that returns “Match Not Found,” and a
search-result snippet is not proof that the exact learner-visible link works.

Before committing a lexical source note, open the exact encoded URL and verify
that it resolves the intended record. Pin that full URL in the focused test,
state any spelling-normalization boundary without leaking the alternate form
before its owner, and limit borrowing history to the route the cited source
actually states.
