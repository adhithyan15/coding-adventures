# ചിത്രകാരൻ (citrakāran) — a painter

## You'll want to know: ചിത്രകാരൻ
<!-- hl-knowledge: introduces=[ML-LEX-C565-KALAKARAN565-01]; assesses=[] -->

**ചിത്രകാരൻ** — *citrakāran* — "a painter".

> ആ ചിത്രകാരന്റെ ചിത്രങ്ങൾ പ്രദർശനത്തിൽ ഉണ്ടായിരുന്നു.
>
> *ā citrakāranṟe citraṅṅaḷ pradarśanattil uṇṭāyirunnu.*
>
> That painter's pictures were in the exhibition.

A woman painter is ചിത്രകാരി.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ചിത്രകാരൻ** (*citrakāran*) is borrowed from Sanskrit *citrakāra*, "a painter" (CDIAL 4807), *citra*, "a picture", and *kāra*, "a maker".
