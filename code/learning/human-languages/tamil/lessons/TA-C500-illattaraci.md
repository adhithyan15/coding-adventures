# இல்லத்தரசி (illattaraci) — a homemaker; a housewife

## You'll want to know: இல்லத்தரசி
<!-- hl-knowledge: introduces=[TA-LEX-C500-VITU500-02]; assesses=[] -->

**இல்லத்தரசி** — *illattaraci* — "a homemaker; a housewife".

> என் அம்மா ஒரு இல்லத்தரசி.
>
> *eṉ ammā oru illattaraci.*
>
> My mother is a homemaker.

இல்லம் "home" + அரசி "queen".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**இல்லத்தரசி** (*illattaraci*) is a compound of native இல்லம் *illam*, "home" (DEDR 494), and அரசி *araci*, "queen", the feminine of அரசன் "king", which DEDR 201 traces to Sanskrit *rājan*.
