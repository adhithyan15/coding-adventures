## You'll want to know: el juguete
<!-- hl-knowledge: introduces=[ES-LEX-C506-REGALO-03]; assesses=[] -->

**el juguete** — "the toy".

> El niño tiene muchos juguetes.
>
> *The child has a lot of toys.*

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**juguete** is built on *juego*, "a game", with the small-ending *-ete*. *Juego* is Latin *iocus*, "a joke, a jest".
