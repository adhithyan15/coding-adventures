## You'll want to know: مجاز
<!-- hl-knowledge: introduces=[FA-LEX-C404-MOQARRARAT-03]; assesses=[] -->

**مجاز** (*mojâz*) — "allowed, permitted".

> استفاده از موبایل در کلاس مجاز نیست.
>
> *estefâde az mobâyl dar kelâs mojâz nist.*
>
> Using mobile phones in class is not allowed.

The opposite is *gheyr-e mojâz*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**مجاز** "allowed" is usually traced to Arabic *mujāz* "permitted".
