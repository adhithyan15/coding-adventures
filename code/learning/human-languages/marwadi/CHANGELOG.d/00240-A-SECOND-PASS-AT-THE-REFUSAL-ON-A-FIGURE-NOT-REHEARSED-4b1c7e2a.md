## A second pass at the refusal, on a figure not rehearsed

One `review` lesson, `MW-R39-refusal-second-pass`. The four-skill refusal atom
had been revisited exactly once — by nothing since chapter 39's own closing
lesson — and the pre-A1 gate wants two.

The lesson keeps the three-turn shape and changes the number, because a bargain
you can only run at one price is not one you can run. The point it makes twice
is about **पाछे मिलसू।**: learned as a goodbye, used here it says the bargain is
paused rather than finished, and it is what lets the seller call you back. One
line, two jobs, and the market decides which.

The writing step is dictation with the page covered, so the track's pre-A1
writing ramp gains a rung at the stage it already proves.

No new word and no new atom — `review` is outside `CONTENT_TYPES`, so the
vocabulary count is unchanged by design. `marwadi: reinforcement 1 -> 0`, which
leaves this track and Telugu as the only two whose pre-A1 rung is down to a
single criterion.
