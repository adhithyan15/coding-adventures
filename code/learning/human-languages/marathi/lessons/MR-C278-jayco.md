# मी जायचो (mī jāyco) — what used to happen

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MR-GRAMMAR-C278-ASTANA-01, MR-LEX-C159-PAS159-02] -->

[PAUSE 2s] Say "when (I was) small". (*lahān astānā*.) Then "formerly". (*pūrvī*.)

## You'll want to know: -ायचो, 'used to'
<!-- hl-knowledge: introduces=[MR-GRAMMAR-C278-HABITUAL-PAST-01]; assesses=[MR-LEX-C96-NATURE96-05, MR-LEX-LAHAAN, MR-LEX-JANE, MR-LEX-RAHNE] -->

> **लहान असताना मी रोज नदीवर जायचो.**
>
> *lahān astānā mī roj nadīvar jāyco.* — "When I was small, I used to go to the river every day."

Take **-णे** off and put **-ायच-** on, then the endings of **गेलो**:

- **मी** **जायचो** (*jāyco*) — I used to go; a woman says **जायचे** (*jāyce*)
- **तो** **जायचा** (*jāycā*), **ती** **जायची** (*jāycī*) — he, she used to go
- **आम्ही** **जायचो**, **ते** **जायचे** — we, they used to go

**करणे** → **करायचो** (*karāyco*); **राहणे** → **राहायचो** (*rāhāyco*): **पूर्वी मी पुण्यात राहायचो** (*pūrvī mī puṇyāt rāhāyco*), "I used to live in Pune". With an object it follows the doer: **मी पुस्तक वाचायचो** (*mī pustak vācāyco*).
