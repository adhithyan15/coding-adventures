## You'll want to know: মিতব্যয়ী
<!-- hl-knowledge: introduces=[BN-LEX-C545-SADHYO545-04]; assesses=[] -->

**মিতব্যয়ী** — *mitôbyôyī* — "thrifty".

> মিতব্যয়ী হলে তুমি টাকা জমাতে পারবে।
>
> *Mitôbyôyī hôle tumi ṭākā jômāte pārbe.*
>
> If you're thrifty, you'll be able to save money.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**মিতব্যয়ী** (*mitôbyôyī*) is a tatsama, Sanskrit *mitavyayin*, "spending little, frugal" (Monier-Williams): *mita*, "measured", and *vyaya*, "spending".
