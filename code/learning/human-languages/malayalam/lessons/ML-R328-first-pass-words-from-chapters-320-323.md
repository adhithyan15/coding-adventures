(**അടിപൊളി**, *aṭipoḷi*.) Spotted? (**പുള്ളിയുള്ള**, *puḷḷiyuḷḷa*.) Fragrant? (**സുഗന്ധമുള്ള**, *sugandhamuḷḷa*.) Smelly? (**നാറുന്ന**, *nāṟunna*.) Noisy? (**ബഹളമുള്ള**, *bahaḷamuḷḷa*.) Honest?
