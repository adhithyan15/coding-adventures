## You'll want to know: a chupeta
<!-- hl-knowledge: introduces=[PT-LEX-C494-BEBE-03]; assesses=[] -->

**a chupeta** — "dummy, pacifier".

> O bebé só adormece com a chupeta.
>
> *The baby only falls asleep with the dummy.*

Built on *chupar* "to suck".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*chupeta* is built on *chupar* "to suck" (EtymDB); the verb is usually taken to imitate the sound of sucking.
