## You'll want to know: शादीशुदा
<!-- hl-knowledge: introduces=[HI-LEX-C119-ABOUT-04]; assesses=[] -->

**शादीशुदा** (*śādīśudā*) — "married".

It is **शादी** with **-शुदा**, "having been done". **क्या आप शादीशुदा हैं?** — "are you married?".
