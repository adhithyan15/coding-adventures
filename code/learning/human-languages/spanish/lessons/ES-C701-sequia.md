## You'll want to know: la sequía
<!-- hl-knowledge: introduces=[ES-LEX-C701-CALOR-04]; assesses=[] -->

**la sequía** — "the drought".

> Este año hay sequía y no llueve.
>
> *There is a drought this year and it does not rain.*

Built on *seco*, dry.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*sequía* is built on *seco* "dry" (EtymDB), which is inherited from Latin *siccus* "dry".
