## You'll want to know: chéngshú
<!-- hl-knowledge: introduces=[ZH-LEX-C516-TREES516-05]; assesses=[] -->

*chéngshú* — "to ripen; to be ripe".

> *zhèxiē píngguǒ hái méiyǒu chéngshú* — These apples aren't ripe yet.

Its characters come later; for now it is a word for the ear.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*chéngshú* is built from 成 'to complete' and *shú*, both inherited from Middle Chinese, *dzyeng* and *dzyuwk* (Guangyun, in Baxter's transcription), which glosses the first 'finished' and the second with the first: done, as fruit is done when it is ripe.
