# تخييم (takhyīm) — camping

## You'll want to know: تخييم
<!-- hl-knowledge: introduces=[AR-LEX-C537-HIWAYA537-01]; assesses=[] -->

**تخييم** — *takhyīm* — "camping".

> نحب التخييم في الصحراء.
>
> *nuḥibbu at-takhyīm fī aṣ-ṣaḥrāʾ.*
>
> We love camping in the desert.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**تخييم** (*takhyīm*) is built on the native Arabic root *kh-y-m*, "a tent" (Lane). Khayma, a tent, which you know, is from the same root.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
