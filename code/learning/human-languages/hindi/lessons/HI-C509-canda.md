## You'll want to know: चंदा
<!-- hl-knowledge: introduces=[HI-LEX-C509-HADTAL509-03]; assesses=[] -->

**चंदा** — *candā* — "a contribution; a collection (of money)".

> मज़दूरों ने एक बीमार साथी के लिए चंदा दिया।
>
> *Mazdūroṁ ne ek bīmār sāthī ke liye candā diyā.*
>
> The workers chipped in money for a sick companion.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**चंदा** (*candā*) is usually traced to Persian *chanda*, "a contribution", built on *chand*, "how many, how much": what each person puts in. It is not the *candā*, "moon", that CDIAL derives from Sanskrit *candra* (CDIAL 4661).
