# Latin Roadmap

Same shape as the other tracks: deep one-word lessons in themed chapters.
Slug-identified; order lives in the book and
[`session-map.md`](./session-map.md). See
[`HL00`](../../../specs/HL00-human-language-curriculum-framework.md).

Grounding: English + the Romance tracks (Spanish, French, Italian, Portuguese),
with Proto-Indo-European drawn in where the trail is clear. The recurring thread
is Latin as **taproot** — nearly every word has both English and Romance
descendants, traced in the lessons. Grammar (Latin's meaning-in-endings, its
dropped pronouns, its cases) is introduced **inline**, one piece where a real
phrase needs it, never as a front-loaded table.

## Authored

- **Ch. 1 — Greetings**: salvē → avē → valē → grātiās agō → ita/nōn → practice.
  Each greeting an etymological hub for English and the Romance children; the
  *-ē/-ēte* imperative ending and the *-ō* = "I" ending introduced.

## Planned

| Chapter | Theme |
|---|---|
| 2 | Introducing yourself: *quis es?* ("who are you?"), *nōmen mihi est…* ("my name is…"), the first-person verb endings |
| 3 | *sum, es, est* ("I am / you are / is") — the verb *esse*, ancestor of Romance *ser/essere/être*; numbers I–X |
| 4 | The first case contrast (nominative vs. accusative) through a real sentence; *ego / tū* when Latin *does* use pronouns |
| 5+ | The declensions and conjugations, each introduced where a phrase demands it — always tracing the form into English and Romance |

Note: Latin has no articles and (in the classical scheme) no word for "yes" —
both are used as teaching moments rather than smoothed over. The track leans on
the four Romance tracks already built, showing Latin as the shared parent.
