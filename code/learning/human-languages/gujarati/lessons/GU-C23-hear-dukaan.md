# દુકાન — hear shop first

## Warm-up
<!-- hl-knowledge: introduces=[GU-LEX-DUKAAN-01]; assesses=[] -->

Listen twice: **dukān**. It means **shop**. Hear the short *u* before the long
final *ā*.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[GU-LEX-DUKAAN-01] -->

Point to the shop when you hear *dukān*, then say *dukān* from the meaning.
