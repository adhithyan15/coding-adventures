## You'll want to know: आरम्भः
<!-- hl-knowledge: introduces=[SA-LEX-C554-BHAVI554-05]; assesses=[] -->

**आरम्भः** — *ārambhaḥ* — "a start".

> यदि आरम्भः उत्तमः अस्ति, तर्हि फलम् अपि उत्तमं भविष्यति।
>
> *yadi ārambhaḥ uttamaḥ asti, tarhi phalam api uttamaṃ bhaviṣyati.*
>
> If the start is good, the result will be good too.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**आरम्भः** (*ārambhaḥ*) is built on *ā* and the root √rabh, "to take hold of", which also gives *ārabhate*, "begins"; MW gives *ārambha* as undertaking, beginning (MW).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
