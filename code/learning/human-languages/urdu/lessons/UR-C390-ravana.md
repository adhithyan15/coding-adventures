## You'll want to know: روانہ
<!-- hl-knowledge: introduces=[UR-LEX-C390-RAVANA390-02]; assesses=[] -->

**روانہ** — *ravānā* — "setting off; on its way".

> گاڑی صبح سات بجے روانہ ہوئی۔
>
> *gāṛī subah sāt baje ravānā huī.*
>
> The train set off at seven in the morning.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**روانہ** (*ravānā*) is usually traced to Persian *ravāna*, "going, setting out"; with **ہونا** it means to set off.
