## You'll want to know: அமைதி
<!-- hl-knowledge: introduces=[TA-LEX-C89-FEEL-04]; assesses=[] -->

**அமைதி** (*amaiti*) — "calm, peace", and "quiet".

**அமைதியாக இருங்கள்** — "please stay calm", or in a library, "please be quiet".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

Calm, and a polite request for it.
