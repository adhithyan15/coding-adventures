# സ്ഥാപിക്കുക (sthāpikkuka) — to establish; to found

## You'll want to know: സ്ഥാപിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C457-ASUTRANAM457-04]; assesses=[] -->

**സ്ഥാപിക്കുക** — *sthāpikkuka* — "to establish; to found".

> അവന്റെ മുത്തച്ഛൻ ആ കട സ്ഥാപിച്ചു.
>
> *avanṟe muttacchan ā kaṭa sthāpiccu.*
>
> His grandfather founded that shop.

Past: സ്ഥാപിച്ചു, *sthāpiccu*.

Also to set up a thing in a place: പ്രതിമ സ്ഥാപിച്ചു, they set up a statue.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**സ്ഥാപിക്കുക** (*sthāpikkuka*) is built from Sanskrit *sthāpana*, "causing to stand" (CDIAL 13755), with the Malayalam verb ending -ിക്കുക: to make a thing stand.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
