# ಓಡಿಹೋಗು (ōḍihōgu) — to run away; to escape

## You'll want to know: ಓಡಿಹೋಗು
<!-- hl-knowledge: introduces=[KA-LEX-C319-YUDDHA319-05]; assesses=[] -->

**ಓಡಿಹೋಗು** — *ōḍihōgu* — "to run away; to escape".

> ಪೊಲೀಸರನ್ನು ನೋಡಿ ಕಳ್ಳ ಓಡಿಹೋದನು.
>
> *polīsarannu nōḍi kaḷḷa ōḍihōdanu.*
>
> Seeing the police, the thief ran away.

Past (I …): ಓಡಿಹೋದೆ, *ōḍihōde*.

ಓಡಿ is ಓಡು, to run, as "having run"; ಹೋಗು adds "away". Run and go make one verb.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಓಡಿಹೋಗು** (*ōḍihōgu*) is a native Dravidian compound: *ōḍu* "to run" (DEDR 1041) and *hōgu* "to go" (DEDR 4572).
