# மறுசுழற்சி செய் (maṟucuḻaṟci cey) — to recycle

## You'll want to know: மறுசுழற்சி செய்
<!-- hl-knowledge: introduces=[TA-LEX-C441-KUPPAI441-04]; assesses=[] -->

**மறுசுழற்சி செய்** — *maṟucuḻaṟci cey* — "to recycle".

> நாங்கள் பழைய காகிதத்தை மறுசுழற்சி செய்கிறோம்.
>
> *nāṅkaḷ paḻaiya kākitattai maṟucuḻaṟci ceykiṟōm.*
>
> We recycle old paper.

Past (I …): மறுசுழற்சி செய்தேன், *maṟucuḻaṟci ceytēṉ*.

மறுசுழற்சி, recycling, is the noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**மறுசுழற்சி செய்** (*maṟucuḻaṟci cey*) is built from மறு, "again", and சுழற்சி, "a turning", from சுழல், "to spin" (DEDR 2698), with செய், "to do".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for getting around.
