# ਨਹੀਂ reaches the page

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-NEG-CLAUSE-01, PA-LEX-HAAN-NAHIN-01] -->

[PAUSE 3s] Say where **ਨਹੀਂ** stands in a sentence before anything is uncovered.

## Script — four pieces, none new
<!-- hl-knowledge: introduces=[PA-SCRIPT-NAHIN-01]; assesses=[] -->

Uncover **ਨਹੀਂ** and name it in order:

> **ਨ** — *na* · **ਹ** — *ha* · the **ੀ** stroke · the **ਂ** above

The last of those is the bindi, and it is doing real work: it puts the vowel
through the nose. A **ਨਹੀ** without it is not this word.

This is the first of seven chapters, and it is worth saying now what holds for
almost all of them: the words this book most needed were already writable. Every
sign here was taught long ago.

## Writing — guided copy, model in view
<!-- hl-knowledge: introduces=[]; assesses=[PA-SCRIPT-NAHIN-01] -->
<!-- hl-writing-stage: guided-copy -->

Keep the model in view and copy **ਨਹੀਂ** once. Check the bindi is there.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[PA-SCRIPT-NAHIN-01] -->

[PAUSE 3s] Write **ਨਹੀਂ** from memory, then uncover and compare. Which mark
would change the word if you left it off? (The **ਂ** above.)
