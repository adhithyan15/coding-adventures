# A first style read can expose previously invisible degradation debt

Qt's degradation recorder reports unread properties only after an emitter asks
about that part. Adding a Board drop-target minimum-height read exposed existing
display, flex-direction, and gap debt, failing release CI although geometry
tests passed. Restrict the bridge to targets that author the minimum, preserve
the newly visible diagnostics, and track their lowering explicitly. Measure
both themes and pin exact counts with tests rejecting further increases; never
silence the recorder or describe a baseline change as unchanged diagnostics.
