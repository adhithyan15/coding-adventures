# Review — asking the way

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C310-SVACCHA-01, KA-SCRIPT-RECOG-174, KA-GRAMMAR-C312-OBLIGATIVE-01] -->

[PAUSE 2s] Read **ಸ್ವಚ್ಛ** aloud, and name its small letter. (*svaccha*; **ಛ**.) Then "You should see a doctor." (*nīvu vaidyarannu nōḍabēku*.)

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[KA-GRAMMAR-C313-ASK-WAY-01, KA-GRAMMAR-C313-HOW-FAR-01, KA-GRAMMAR-C313-GIVE-WAY-01, KA-GRAMMAR-C313-LANDMARK-01, KA-GRAMMAR-C312-PROHIBITIVE-01, KA-GRAMMAR-C312-REASON-ORDER-01, KA-LEX-C55-ROAD-05] -->

[PAUSE 2s each]
- [YOU SAY: Excuse me, where is the station? How far is it from here?]
- [YOU SAY: It's near. Go straight on, then go right at the first turn.]
- [YOU SAY: The hotel is on the left, next to the hospital.]
- [YOU SAY: You must not go that way, because there is no path.]
- [YOU SAY: ask the way to a shop, then give the answer yourself]
