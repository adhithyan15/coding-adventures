# தொடர்ச்சியாக (toṭarcciyāka) — continuously

## You'll want to know: தொடர்ச்சியாக
<!-- hl-knowledge: introduces=[TA-LEX-C317-MURAI317-03]; assesses=[] -->

**தொடர்ச்சியாக** — *toṭarcciyāka* — "continuously".

> மூன்று நாள் தொடர்ச்சியாக மழை பெய்தது.
>
> *mūṉṟu nāḷ toṭarcciyāka maḻai peytatu.*
>
> It rained for three days without a break.

From தொடர், to continue.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**தொடர்ச்சியாக** (*toṭarcciyāka*) is built on தொடர்ச்சி, "continuation", from native தொடர், "to follow uninterruptedly" (DEDR 3480), with -ஆக.
