# હવામાન (havāmān) — weather, climate

## You'll want to know: હવામાન
<!-- hl-knowledge: introduces=[GU-LEX-C213-WEATHER213-01]; assesses=[] -->

**હવામાન** — *havāmān* — "weather, climate".

> **કાલે હવામાન સારું હશે.** — *kāle havāmān sārũ haśe* — "The weather will be good tomorrow."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**હવામાન** (*havāmān*) is built from two older words: *havā*, "air", a loan from Arabic *hawā'*, which reached Gujarati through Persian (Lane, under the root *h-w-y*), and *mān*, "measure", from Sanskrit *māna*. CDIAL has no entry for the compound.
