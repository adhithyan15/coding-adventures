# ક્રૂર (krūr) — cruel

## You'll want to know: ક્રૂર
<!-- hl-knowledge: introduces=[GU-LEX-C459-KOMAL459-03]; assesses=[] -->

**ક્રૂર** — *krūr* — "cruel".

> પ્રાણીઓને મારવું ક્રૂર કામ છે.
>
> *prāṇīone mārvũ krūr kām che.*
>
> Beating animals is a cruel thing to do.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ક્રૂર** (*krūr*) is a tatsama, Sanskrit *krūra*, "bloody, raw" and "cruel, pitiless", as Monier-Williams records it.
