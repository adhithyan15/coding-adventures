# पद (pad) — a post, a position

## You'll want to know: पद
<!-- hl-knowledge: introduces=[HI-LEX-C394-INAAM394-03]; assesses=[] -->

**पद** — *pad* — "a post, a position".

> अगर वह चुनाव जीत गया तो उसे मंत्री का पद मिलेगा।
>
> *agar vah cunāv jīt gayā to use mantrī kā pad milegā.*
>
> If he wins the election, he'll get a minister's post.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**पद** (*pad*) is a tatsama, borrowed from Sanskrit *pada*, "a step, a footing" (Monier-Williams).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
