## You'll want to know: exsultō, exsultāre
<!-- hl-knowledge: introduces=[LA-LEX-C489-GAUD-04]; assesses=[] -->

**exsultō, exsultāre** — "to leap for joy, rejoice greatly".

> Puerī in hortō exsultant, quod hodiē fēriae sunt.
>
> *The boys leap for joy in the garden, because today is a holiday.*

*exsultō, exsultāre, exsultāvī, exsultātum*. First to leap up, then to be overjoyed. English *exult*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**exsultō** is built on *ex-* "out, up" and *saltō* "to jump, dance", the frequentative of *saliō* "to leap" (Lewis & Short). English *exult* comes from it.
