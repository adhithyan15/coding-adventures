## You'll want to know: приправа
<!-- hl-knowledge: introduces=[RU-LEX-C333-SOLIT-04]; assesses=[] -->

**приправа** (*pripráva*) — "a seasoning".

> Эта приправа очень острая.
>
> *Éta pripráva óchen óstraya.*
>
> This seasoning is very hot.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*приправа* is built on *приправить* "to season", from *при-* and *править* "to set right", from *правый* "right": what puts a dish right. EtymDB lists no parent.
