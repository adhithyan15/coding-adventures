## You'll want to know: عدوى
<!-- hl-knowledge: introduces=[AR-LEX-C509-ADWA509-01]; assesses=[] -->

**عدوى** — *ʿadwā* — "an infection, contagion".

> انتقلت العدوى من طفل إلى طفل.
>
> *intaqalat al-ʿadwā min ṭifl ilā ṭifl.*
>
> The infection passed from child to child.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**عدوى** (*ʿadwā*) is built on the native Arabic root *ʿ-d-w*, "to run, to pass beyond" (Lane). ʿAdwā is a thing that runs from one person to another.
