# ഉത്പാദിപ്പിക്കുക (utpādippikkuka) — to manufacture; to produce

## You'll want to know: ഉത്പാദിപ്പിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C459-NIKUTI459-03]; assesses=[] -->

**ഉത്പാദിപ്പിക്കുക** — *utpādippikkuka* — "to manufacture; to produce".

> ആ ഫാക്ടറി ദിവസവും ആയിരം സൈക്കിളുകൾ ഉത്പാദിപ്പിക്കുന്നു.
>
> *ā phākṭaṟi divasavuṁ āyiraṁ saikkiḷukaḷ utpādippikkunnu.*
>
> That factory produces a thousand bicycles every day.

Past: ഉത്പാദിപ്പിച്ചു, *utpādippiccu*.

The noun is ഉത്പാദനം, production.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ഉത്പാദിപ്പിക്കുക** (*utpādippikkuka*) is built from Sanskrit *utpādana*, "bringing forth, producing" (Monier-Williams), with the Malayalam verb ending -ിപ്പിക്കുക.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
