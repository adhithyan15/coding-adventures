## Writing

Task 1 must address the named editor, identify the incorrect time, explain its
effect, request a correction, and ask how future updates should be submitted in
50–70 independently produced Sanskrit words. Task 2 must address younger
learners, narrate the first opinion and new evidence, describe the response,
and state a useful lesson in 130–170 words. Apply the shared rubric's external-
sandhi and Devanagari criteria; copied prompt language is not independent
production.

## Speaking

Use all five interview prompts, the three-minute account, the collaborative
planning brief, and all four follow-up questions. Score the candidate's own
contribution, development, interaction and repair, organisation, Sanskrit
vocabulary and grammar, and pronunciation and fluency in the declared
pronunciation tradition. Keyword notes are allowed only for the prepared and
planning parts. Examiner rephrasing beyond one same-pace repeat must be
reflected in interaction scoring.
