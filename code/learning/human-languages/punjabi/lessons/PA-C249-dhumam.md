# ਧੂੰਆਂ (dhūṁāṁ) — smoke

## You'll want to know: ਧੂੰਆਂ
<!-- hl-knowledge: introduces=[PA-LEX-C249-GHR249-03]; assesses=[] -->

**ਧੂੰਆਂ** — *dhūṁāṁ* — "smoke".

> ਗਿੱਲੀ ਲੱਕੜ ਨਾਲ ਬਹੁਤ ਧੂੰਆਂ ਹੁੰਦਾ ਹੈ।
>
> *gillī lakkaṛ nāl bahut dhūṁāṁ hundā hai.*
>
> Wet wood makes a lot of smoke.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ਧੂੰਆਂ** (*dhūṁāṁ*) is inherited from Sanskrit *dhūma*, "smoke, vapour"; CDIAL lists Punjabi *dhūā̃*, "smoke" (CDIAL 6849).
