## You'll want to know: नवजात
<!-- hl-knowledge: introduces=[HI-LEX-C497-JANM497-04]; assesses=[] -->

**नवजात** — *navjāt* — "newborn".

> नवजात बच्चा दिन भर सोता है।
>
> *navjāt baccā din bhar sotā hai.*
>
> A newborn baby sleeps all day long.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**नवजात** (*navjāt*) is a tatsama, borrowed from Sanskrit *nava-jāta*, "newly born", built on *nava*, "new", and *jāta*, "born" (Monier-Williams).
