# കാൽപ്പാട് (kālppāṭŭ) — a footprint

## You'll want to know: കാൽപ്പാട്
<!-- hl-knowledge: introduces=[ML-LEX-C366-SUCHANA366-03]; assesses=[] -->

**കാൽപ്പാട്** — *kālppāṭŭ* — "a footprint".

> മണലിൽ കള്ളന്റെ കാൽപ്പാടുകൾ ഉണ്ടായിരുന്നു.
>
> *maṇalil kaḷḷanṟe kālppāṭukaḷ uṇṭāyirunnu.*
>
> The thief's footprints were in the sand.

Plural: കാൽപ്പാടുകൾ, *kālppāṭukaḷ*.

കാൽ, foot, + പാട്, a mark, a trace.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**കാൽപ്പാട്** (*kālppāṭŭ*) is a native Dravidian compound of കാൽ (*kāl*), "leg, foot" (DEDR 1479), and പാട്, "a mark, a trace": the mark a foot leaves.
