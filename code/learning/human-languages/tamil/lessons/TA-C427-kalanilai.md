# காலநிலை (kālanilai) — climate

## You'll want to know: காலநிலை
<!-- hl-knowledge: introduces=[TA-LEX-C427-VEPPAM427-01]; assesses=[] -->

**காலநிலை** — *kālanilai* — "climate".

> இந்த ஊரின் காலநிலை எனக்குப் பிடிக்கும்.
>
> *inta ūriṉ kālanilai eṉakkup piṭikkum.*
>
> I like the climate of this town.

காலம், a season, + நிலை, a state.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**காலநிலை** (*kālanilai*) is built from காலம், "time, a season", borrowed from Sanskrit *kāla* (CDIAL 3084), and நிலை, "a state, a standing" (DEDR 3675).
