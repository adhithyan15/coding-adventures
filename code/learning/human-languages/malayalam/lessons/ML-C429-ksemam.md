# ക്ഷേമം (kṣēmaṁ) — welfare; well-being

## You'll want to know: ക്ഷേമം
<!-- hl-knowledge: introduces=[ML-LEX-C429-KSEMAM429-01]; assesses=[] -->

**ക്ഷേമം** — *kṣēmaṁ* — "welfare; well-being".

> തൊഴിലാളികളുടെ ക്ഷേമത്തിന് പുതിയ പദ്ധതി വന്നു.
>
> *toḻilāḷikaḷuṭe kṣēmattinŭ putiya paddhati vannu.*
>
> A new scheme has come for the workers' welfare.

As a greeting in letters: ക്ഷേമം തന്നെയല്ലേ, all well, I hope.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ക്ഷേമം** (*kṣēmaṁ*) is borrowed from Sanskrit *kṣema*, "giving rest or ease; safety, well-being" (Monier-Williams).
