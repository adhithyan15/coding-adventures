# ಮುನ್ನೆಚ್ಚರಿಕೆ (munneccarike) — a precaution

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C411-SHARATTU411-05, KA-LEX-C412-APAYA412-01] -->

[PAUSE 2s] Before the new one: say the Kannada for an obligation, then the Kannada for a danger.

## You'll want to know: ಮುನ್ನೆಚ್ಚರಿಕೆ
<!-- hl-knowledge: introduces=[KA-LEX-C412-APAYA412-02]; assesses=[] -->

**ಮುನ್ನೆಚ್ಚರಿಕೆ** — *munneccarike* — "a precaution".

> ಮುನ್ನೆಚ್ಚರಿಕೆಯಾಗಿ ನಾನು ಕೊಡೆ ತೆಗೆದುಕೊಂಡು ಹೋದೆ.
>
> *munneccarikeyāgi nānu koḍe tegedukoṇḍu hōde.*
>
> I took an umbrella as a precaution.

ಮುನ್ (before) + ಎಚ್ಚರಿಕೆ (warning).

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಮುನ್ನೆಚ್ಚರಿಕೆ** (*munneccarike*) is native Dravidian, built from *mun*, "before" (DEDR 5020), and *eccaṟike*, "a warning, watchfulness" (DEDR 851).
