# ડિસેમ્બર (ḍisembar) — December

## You'll want to know: ડિસેમ્બર
<!-- hl-knowledge: introduces=[GU-LEX-C174-MONTH174-02]; assesses=[] -->

**ડિસેમ્બર** — *ḍisembar* — "December".

> **ડિસેમ્બરમાં શિયાળો હશે.** — *ḍisembarmā̃ śiyāḷo haśe* — "It will be winter in December."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ડિસેમ્બર** (*ḍisembar*) is a loan from English *December*, the name of the twelfth month.
