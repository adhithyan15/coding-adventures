# കുടിയേറുക (kuṭiyēṟuka) — to migrate; to settle in a new land

[PAUSE 2s] Before the new one: say the Malayalam for a honeymoon, then the Malayalam for to settle.

## You'll want to know: കുടിയേറുക
<!-- hl-knowledge: introduces=[ML-LEX-C389-GRIHAM389-05]; assesses=[] -->

**കുടിയേറുക** — *kuṭiyēṟuka* — "to migrate; to settle in a new land".

> പണ്ട് ഒരുപാട് കുടുംബങ്ങൾ വിദേശത്തേക്ക് കുടിയേറി.
>
> *paṇṭŭ orupāṭŭ kuṭumbaṅṅaḷ vidēśattēkkŭ kuṭiyēṟi.*
>
> Long ago many families migrated abroad.

Past: കുടിയേറി, *kuṭiyēṟi*.

കുടി, a home, + ഏറുക, to climb in: to set up home in a new place.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**കുടിയേറുക** (*kuṭiyēṟuka*) is a native Dravidian compound of കുടി, "a house, a hut, a family" (DEDR 1655), and ഏറുക, "to climb, to go up into".
