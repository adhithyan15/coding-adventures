# ರಾಜಕುಮಾರ (rājakumāra) — a prince

## You'll want to know: ರಾಜಕುಮಾರ
<!-- hl-knowledge: introduces=[KA-LEX-C354-SAMRAJYA354-05]; assesses=[] -->

**ರಾಜಕುಮಾರ** — *rājakumāra* — "a prince".

> ರಾಜಕುಮಾರ ಕುದುರೆ ಏರಿ ಕಾಡಿಗೆ ಹೋದನು.
>
> *rājakumāra kudure ēri kāḍige hōdanu.*
>
> The prince rode a horse to the forest.

Plural: ರಾಜಕುಮಾರರು, *rājakumāraru*.

A princess is a ರಾಜಕುಮಾರಿ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ರಾಜಕುಮಾರ** (*rājakumāra*) is borrowed from Sanskrit *rājakumāra*, "a king's son, a prince" (Monier-Williams), from *rāja* "king" and *kumāra* "a boy, a son".
