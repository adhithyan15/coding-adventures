## You'll want to know: la patinoire
<!-- hl-knowledge: introduces=[FR-LEX-C510-GLACE-04]; assesses=[] -->

**la patinoire** — "ice rink".

> Le samedi, la patinoire est pleine de monde.
>
> *On Saturdays the ice rink is crowded.*

Informally, a very icy road: *la route est une patinoire*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*la patinoire* is built on *patiner* "to skate" with *-oire*, the ending for a place.
