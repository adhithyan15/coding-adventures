## You'll want to know: тонуть
<!-- hl-knowledge: introduces=[RU-LEX-C427-MAYAK-05]; assesses=[] -->

**тонуть** (*tonút*) — "to sink; to drown".

> Старая лодка медленно тонет.
>
> *Stáraya lódka médlenno tónet.*
>
> The old boat is slowly sinking.

Imperfective; perfective *утонуть* (of a person) or *затонуть* (of a ship). Present *тону, тонешь*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*тонуть* is usually traced to the same root as *топить* 'to drown, to sink', which EtymDB takes from Proto-Slavic *topiti*. EtymDB lists *тонуть* itself without a source.
