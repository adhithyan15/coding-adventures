# గాయం (gāyaṁ) — a wound, an injury

## You'll want to know: గాయం
<!-- hl-knowledge: introduces=[TE-LEX-C92-DOCTOR-04]; assesses=[] -->

**గాయం** (*gāyaṁ*) — "a wound, an injury".

**గాయం అయింది** — "I have been hurt", literally "a wound has happened". Like a wedding, an
injury is something that happens.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

A way to say you are hurt.
