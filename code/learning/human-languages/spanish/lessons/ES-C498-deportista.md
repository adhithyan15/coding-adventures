## You'll want to know: el deportista
<!-- hl-knowledge: introduces=[ES-LEX-C498-DEPORTE-02]; assesses=[] -->

**el deportista** — "the sportsperson, the athlete".

> Es una deportista muy conocida.
>
> *She is a very well-known athlete.*

The same form for a woman: *la deportista*.
