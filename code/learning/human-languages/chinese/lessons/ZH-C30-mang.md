## Sounds you'll need
<!-- hl-knowledge: introduces=[ZH-LEX-MANG-01]; assesses=[] -->

*máng* — **second tone**, rising, like a surprised "huh?". Its character comes
later; this chapter keeps it to the ear.

## Grammar Lens: the same shape as 我很好
<!-- hl-knowledge: introduces=[]; assesses=[ZH-LEX-MANG-01, ZH-LEX-HEN-01, ZH-LEX-ZAOSHANG] -->

*máng* is an adjective, so it works exactly like 好: no 是, a plain 很 in front.

> *wǒ hěn máng* — I'm busy.
> *zǎoshang wǒ hěn máng* — I'm busy in the mornings.

*zǎoshang* goes first, before the person: the time is what the sentence is
about, then comes what happens in it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*máng* is probably inherited from Middle Chinese *mang* (Guangyun, in Baxter's
transcription), where it is glossed "afraid". Flustered becoming busy is a likely
path for the sense, but it is not settled.
