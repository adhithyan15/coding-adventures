# ഭരിക്കുക (bharikkuka) — to govern; to rule

[PAUSE 2s] Before the new one: say the Malayalam for to win, then the Malayalam for administration.

## You'll want to know: ഭരിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C421-BHARANAM421-02]; assesses=[] -->

**ഭരിക്കുക** — *bharikkuka* — "to govern; to rule".

> ആ രാജാവ് നാൽപത് വർഷം നാട് ഭരിച്ചു.
>
> *ā rājāvŭ nālpatŭ varṣaṁ nāṭŭ bhariccu.*
>
> That king ruled the land for forty years.

Past: ഭരിച്ചു, *bhariccu*.

The verb of ഭരണം. What is ruled stays unmarked: നാട് ഭരിക്കുക.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ഭരിക്കുക** (*bharikkuka*) is built from the Sanskrit root *bhṛ*, "to bear, to maintain", as in *bharaṇa* (CDIAL 9395), with the Malayalam verb ending -ിക്കുക.

## What you've built
