## You'll want to know: la vitrine
<!-- hl-knowledge: introduces=[FR-LEX-C442-FACADES-02]; assesses=[] -->

**la vitrine** — "the shop window; the display case".

> Elle regarde les chaussures dans la vitrine.
>
> *She looks at the shoes in the shop window.*

*Faire du lèche-vitrines* — to go window-shopping.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*vitrine* is built on *vitre* 'pane of glass' (EtymDB), which goes back to Latin *vitrum* 'glass'.
