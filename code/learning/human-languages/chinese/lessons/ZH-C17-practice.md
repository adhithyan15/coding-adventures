# Payoff — five identity words

Keep four scores. Repair one missed skill without erasing the other passes.

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ZH-SCRIPT-WEN-01, ZH-SCRIPT-GUO-01, ZH-SCRIPT-JIA-01] -->

[PAUSE 20s] Write 家, 文, and 国 without a model, then name each aloud.

## Guided Practice
<!-- hl-knowledge: introduces=[ZH-PERFORMANCE-LANGUAGE-IDENTITY-FIVE-FOUR-SKILL-01]; assesses=[ZH-PERFORMANCE-LANGUAGE-IDENTITY-THREE-FOUR-SKILL-01, ZH-LEX-ZI-02, ZH-LEX-HANZI-01, ZH-LEX-HANYU-01, ZH-LEX-ZHONGWEN-01, ZH-LEX-ZHONGGUO-01, ZH-ORTHO-HANZI-01, ZH-ORTHO-HANYU-01, ZH-ORTHO-ZHONGWEN-01, ZH-ORTHO-ZHONGGUO-01] -->
<!-- hl-writing-stage: dictation-transcription -->

1. **Listening, /5:** hear all five words in mixed order and choose each meaning.
2. **Speaking, /5:** produce all five from meaning cards, with tones audible.
3. **Reading, /5:** read **中国, 汉语, 字, 中文, 汉字** cold, without pinyin.
4. **Writing, /5:** hear all five meanings and write each form without a model.

Pass each skill separately. A miss in one column does not cancel the other
three. For repair, revisit only the missed form and retry that skill.
