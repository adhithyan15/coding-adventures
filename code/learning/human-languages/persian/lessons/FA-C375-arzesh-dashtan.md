## You'll want to know: ارزش داشتن
<!-- hl-knowledge: introduces=[FA-LEX-C375-MAZIYYAT-04]; assesses=[] -->

**ارزش داشتن** (*arzesh dâshtan*) — "to be worth it, to be worth".

> این فیلم ارزش دیدن دارد.
>
> *in film arzesh-e didan dârad.*
>
> This film is worth seeing.

*Arzesh* "value" + *dâshtan* (stem *dâr-*), with an ezafe: *arzesh-e … dârad*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ارزش داشتن** is native Persian, built from *arzesh* "value", itself built on *arz-*, the present stem of *arzidan* "to be worth", and *dâshtan* "to have", the inherited verb.
