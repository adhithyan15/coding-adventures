# مساء الخير (masāʾ al-khayr) — "evening of goodness"

## Warm-up

[PAUSE 2s] If you have *ṣabāḥ al-khayr*, this is free — swap morning for
evening.

## You'll want to know first

- [مساء (masāʾ)](./AR-C01-masa.md) · [خير (khayr)](./AR-C01-khayr.md)

## The word, taken apart — by assembling it

**مساء الخير** = **masāʾ** ("evening") + **al-khayr** ("the goodness") =
"evening of goodness," the standard "good evening." Same "X of the-Y" build as
*ṣabāḥ al-khayr*, same moon-letter *al-khayr* (no assimilation).

And the same graceful reply: **مساء النور** (*masāʾ an-nūr*) — "evening of the
light."

So your day of greetings has a clean shape:
- morning → **ṣabāḥ al-khayr** (reply: *ṣabāḥ an-nūr*)
- evening → **masāʾ al-khayr** (reply: *masāʾ an-nūr*)
- any time → **as-salāmu ʿalaykum** (peace) or **marḥaban** (casual welcome)
