## The word, taken apart — where the trail runs out
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-SUNEHA-198] -->

Punjabi University's Punjabipedia defines this exact word as information given
from one party to another. It supports only the present-day message sense taught
here. Source: [Punjabi University Punjabipedia](https://punjabipedia.org/topic.aspx?txt=%E0%A8%B8%E0%A9%81%E0%A8%A8%E0%A9%87%E0%A8%B9%E0%A8%BE).

The exact history of modern written **ਸੁਨੇਹਾ** remains unresolved in the
sources used here. For a historical comparison only, Turner's CDIAL entry
12904 groups Punjabi *sanehā̃* with Sanskrit *saṁdēśa*, “message,
information.” The source does not document the intermediate changes into this
modern spelling. This historical comparison is not a letter-by-letter
derivation and does not create a productive Punjabi rule: keep the present-day
Punjabi noun whole. Source: [Turner, CDIAL 12904](https://dsal.uchicago.edu/cgi-bin/app/soas_query.py?qs=sa%E1%B9%81d%C4%93%C5%9Ba&searchhws=yes&matchtype=exact).
