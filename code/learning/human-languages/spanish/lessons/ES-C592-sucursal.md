## You'll want to know: la sucursal
<!-- hl-knowledge: introduces=[ES-LEX-C592-EMPRESA-05]; assesses=[] -->

**la sucursal** — "the branch".

> El banco tiene una sucursal en mi barrio.
>
> *The bank has a branch in my neighbourhood.*

A branch of a bank or a shop.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*sucursal* was borrowed from French *succursale*, which goes back to Medieval Latin *succursus* 'help' (EtymDB links the Spanish word to *succursus*), from *succurrere* 'to run to help', built on *currere* 'to run'.
