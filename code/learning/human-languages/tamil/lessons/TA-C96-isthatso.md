# அப்படியா? (appaṭiyā?) — is that so?

[PAUSE 2s] Before the new one: say the Tamil for the same, then the Tamil for not at all.

## You'll want to know: அப்படியா?
<!-- hl-knowledge: introduces=[TA-LEX-C96-NOTATALL-02]; assesses=[] -->

**அப்படியா?** (*appaṭiyā?*) — "is that so?", "oh, really?".

**அப்படி** is "like that", and **-ஆ** makes it a question.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

A way to show you are listening.
