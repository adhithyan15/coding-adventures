## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**écrivain** ← Old French *escrivain* ← Vulgar Latin *\*scribanem*, from Latin *scriba*, "a clerk", from *scribere*, the Latin of *écrire* — inherited. (EtymDB 2.1)
