## You'll want to know: o sobrevivente
<!-- hl-knowledge: introduces=[PT-LEX-C306-RESGATE-05]; assesses=[] -->

**o sobrevivente** — "the survivor".

> O único sobrevivente contou tudo à polícia.
>
> *The only survivor told the police everything.*

The same form for a woman: *a sobrevivente*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*sobrevivente* is built on *sobreviver* "to survive", from Latin *supervīvere* (EtymDB), with the ending *-ente*.

<!-- hl-knowledge: introduces=[]; assesses=[] -->
