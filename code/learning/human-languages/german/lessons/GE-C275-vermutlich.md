## You'll want to know: vermutlich
<!-- hl-knowledge: introduces=[GE-LEX-C275-ANGEBLICH-05]; assesses=[] -->

**vermutlich** — "presumably".

> Der Zug kommt vermutlich zu spät.
>
> *The train will presumably be late.*

Close to *wahrscheinlich*. Built on *vermuten*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*vermutlich* is built on *vermuten* "to suspect", which rests on *Mut* "mind", from Proto-Germanic *mōdaz* (EtymDB).
