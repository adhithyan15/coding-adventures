## You'll want to know: چاقی
<!-- hl-knowledge: introduces=[FA-LEX-C498-WEIGHT-05]; assesses=[] -->

**چاقی** (*châqi*) — "being overweight; obesity".

> چاقی برای قلب خوب نیست.
>
> *châqi barâ-ye qalb khub nist.*
>
> Being overweight is bad for the heart.

The noun from *châq* 'fat' with *-i*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*châqi* is built on *châq*, 'fat', with the native noun ending *-i*. The origin of *châq* is not settled.
