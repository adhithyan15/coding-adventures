# தாக்கம் (tākkam) — an impact; an influence

## You'll want to know: தாக்கம்
<!-- hl-knowledge: introduces=[TA-LEX-C352-ERPATUTTU352-02]; assesses=[] -->

**தாக்கம்** — *tākkam* — "an impact; an influence".

> இந்தப் புத்தகம் என் மீது பெரிய தாக்கத்தை ஏற்படுத்தியது.
>
> *intap puttakam eṉ mītu periya tākkattai ēṟpaṭuttiyatu.*
>
> This book had a big impact on me.

X மீது தாக்கம், an impact on X.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**தாக்கம்** (*tākkam*) is native Dravidian: DEDR 3150 lists Tamil *tākku*, "to collide, strike against", and *tākkam*, "a striking", the noun that now means "impact".
