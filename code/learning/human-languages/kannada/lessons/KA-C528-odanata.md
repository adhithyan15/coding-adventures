# ಒಡನಾಟ (oḍanāṭa) — companionship

## You'll want to know: ಒಡನಾಟ
<!-- hl-knowledge: introduces=[KA-LEX-C528-SNEHA528-03]; assesses=[] -->

**ಒಡನಾಟ** — *oḍanāṭa* — "companionship".

> ಅಜ್ಜನ ಒಡನಾಟದಲ್ಲಿ ನಾನು ತುಂಬಾ ಕಲಿತೆ.
>
> *ajjana oḍanāṭadalli nānu tumbā kalite.*
>
> In grandfather's company I learned a great deal.

Built on ಒಡನೆ, together with.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಒಡನಾಟ** (*oḍanāṭa*) is native Dravidian, built on Kannada *oḍan*, "union, together, with" (DEDR 945).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
