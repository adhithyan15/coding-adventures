# One frame, four sentences

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MR-GRAMMAR-DATIVE-KNOWLEDGE, MR-GRAMMAR-DATIVE-LIKING] -->

[PAUSE 5s] **मला** is where things arrive. Say the two oldest ones:
**मला माहीत आहे**, **मला मराठी आवडते**.
