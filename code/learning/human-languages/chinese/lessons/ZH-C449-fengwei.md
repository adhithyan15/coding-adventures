## You'll want to know: 风味
<!-- hl-knowledge: introduces=[ZH-LEX-C449-TASTE449-03]; assesses=[] -->

**风味** — *fēngwèi* — "local flavour; distinctive taste".

> **我想吃这个岛的风味小吃** *wǒ xiǎng chī zhège dǎo de fēngwèi xiǎochī* — I'd like to try this island's local snacks.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**风味** (*fēngwèi*) is built from 风 'a custom' and 味 'a flavour', both inherited from Middle Chinese, *pjuwng* and *mj+jH* (Guangyun, in Baxter's transcription); the sense 'a local custom' for the first is not given there.
