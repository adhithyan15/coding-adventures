## You'll want to know: a olaria
<!-- hl-knowledge: introduces=[PT-LEX-C504-OLARIA-05]; assesses=[] -->

**a olaria** — "pottery".

> Na aldeia ainda há uma olaria antiga.
>
> *There is still an old pottery in the village.*

The potter is *o oleiro*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*olaria* is built on *oleiro* "potter", which goes back to Latin *olla* "a pot" (Lewis & Short).
