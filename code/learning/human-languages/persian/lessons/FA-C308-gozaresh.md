## You'll want to know: گزارش
<!-- hl-knowledge: introduces=[FA-LEX-C308-GOZARESH-01]; assesses=[] -->

**گزارش** (*gozâresh*) — "a report".

> گزارش او درباره مدرسه های روستا بود.
>
> *Gozâresh-e u darbâre-ye madrese-hâ-ye rustâ bud.*
>
> Her report was about the village schools.

Plural *gozâresh-hâ*. Built on *gozâr-*, the stem of *gozârdan* "to set out, to render".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*gozâresh* is a native Persian noun: the stem *gozâr-* "to set out, to render" with the noun suffix *-esh*. EtymDB lists no entry.
