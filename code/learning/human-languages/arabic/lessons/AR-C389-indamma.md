# انضم (inḍamma) — to join

## You'll want to know: انضم
<!-- hl-knowledge: introduces=[AR-LEX-C389-NUFUDH389-03]; assesses=[] -->

**انضم** — *inḍamma* — "to join".

> انضم أخي إلى فريق المدرسة.
>
> *inḍamma akhī ilā farīq al-madrasa.*
>
> My brother joined the school team.

Present: ينضم, *yanḍamm*.

It takes إلى: انضم إلى ….

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**انضم** (*inḍamma*) is built on the native Arabic root *ḍ-m-m*, "to draw together" (Lane). It is Form VII, to be drawn in with others: to join.
