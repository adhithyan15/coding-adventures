## Grammar Lens
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-SUNEHA-198, PA-DEM-EH-01, PA-LEX-HAI-02, PA-GRAMMAR-VERB-LAST-02] -->

> **ਇਹ ਸੁਨੇਹਾ ਹੈ** — *eh sunehā hai* — this is a message

Keep the new whole noun between familiar **ਇਹ** and **ਹੈ**. Familiar **ਹੈ**
stays last in the already-owned identity frame. This chapter teaches only this
one label; it does not add an inflection rule or a send-message construction.
