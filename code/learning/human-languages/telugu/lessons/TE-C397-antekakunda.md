# అంతేకాకుండా (antēkākuṇḍā) — not only that; moreover

## You'll want to know: అంతేకాకుండా
<!-- hl-knowledge: introduces=[TE-LEX-C397-SANKSIPTAM397-01]; assesses=[] -->

**అంతేకాకుండా** — *antēkākuṇḍā* — "not only that; moreover".

> ఆ ఇల్లు పెద్దది, అంతేకాకుండా చౌక కూడా.
>
> *ā illu peddadi, antēkākuṇḍā cauka kūḍā.*
>
> That house is big; not only that, it is cheap too.

అంతే, only that, + కాకుండా, without being: not only that.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**అంతేకాకుండా** (*antēkākuṇḍā*) is a native Telugu phrase: *antē*, "only that", on the far-pointing base *a-* (DEDR 1), and *kākuṇḍā*, "without being", a form of *avu*, "to be" (DEDR 333).
