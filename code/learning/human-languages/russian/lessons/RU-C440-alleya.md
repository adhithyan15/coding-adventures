## You'll want to know: аллея
<!-- hl-knowledge: introduces=[RU-LEX-C440-PEREKHOD-05]; assesses=[] -->

**аллея** (*alléya*) — "an avenue (of trees), a path in a park".

> Мы шли по длинной аллее.
>
> *My shli po dlínnoy alléye.*
>
> We walked along a long avenue of trees.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*аллея* is usually traced to French *allée* 'a path', which EtymDB derives from Old French *aler* 'to go'. EtymDB does not list the Russian word.
