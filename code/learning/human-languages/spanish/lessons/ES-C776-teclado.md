## You'll want to know: el teclado
<!-- hl-knowledge: introduces=[ES-LEX-C776-CLAVE-05]; assesses=[] -->

**el teclado** — "the keyboard".

> Si el teclado no funciona, prueba con otro.
>
> *If the keyboard doesn't work, try another one.*

*Una tecla* is a key.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*teclado* is built on *tecla* 'a key' with the ending *-ado* (EtymDB). The origin of *tecla* itself is not settled.
