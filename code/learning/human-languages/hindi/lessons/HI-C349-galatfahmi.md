# ग़लतफ़हमी (ġalatfahmī) — a misunderstanding

## You'll want to know: ग़लतफ़हमी
<!-- hl-knowledge: introduces=[HI-LEX-C349-INKAR349-05]; assesses=[] -->

**ग़लतफ़हमी** — *ġalatfahmī* — "a misunderstanding".

> यह बहस एक ग़लतफ़हमी की वजह से हुई।
>
> *yah bahas ek ġalatfahmī kī vajah se huī.*
>
> This argument happened because of a misunderstanding.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ग़लतफ़हमी** (*ġalatfahmī*) is usually traced to Persian *ġalat-fahmī*, "mistaken understanding". Both parts are Arabic words that Persian put together.
