# تفاقم (tafāqama) — to worsen

## You'll want to know: تفاقم
<!-- hl-knowledge: introduces=[AR-LEX-C413-TATAWWUR413-03]; assesses=[] -->

**تفاقم** — *tafāqama* — "to worsen".

> تفاقمت المشكلة بعد المطر.
>
> *tafāqamat al-mushkila baʿda al-maṭar.*
>
> The problem worsened after the rain.

Present: يتفاقم, *yatafāqam*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**تفاقم** (*tafāqama*) is built on the native Arabic root *f-q-m*, "to be full" (Lane). It is Form VI, to swell up more and more: to worsen, to grow serious.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
