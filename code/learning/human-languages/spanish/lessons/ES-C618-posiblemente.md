## You'll want to know: posiblemente
<!-- hl-knowledge: introduces=[ES-LEX-C618-SUPONE-04]; assesses=[] -->

**posiblemente** — "possibly".

> Posiblemente llegue mañana.
>
> *He will possibly arrive tomorrow.*

Often with the subjunctive.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*posiblemente* is built on *posible*, a learned borrowing from Latin *possibilis*, built on *posse* 'to be able', with the ending *-mente* (EtymDB).
