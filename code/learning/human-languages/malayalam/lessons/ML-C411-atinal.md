## You'll want to know: അതിനാൽ
<!-- hl-knowledge: introduces=[ML-LEX-C411-KARANAM411-01]; assesses=[] -->

**അതിനാൽ** — *atināl* — "therefore; so".

> മഴ പെയ്തു, അതിനാൽ കളി നിർത്തി.
>
> *maḻa peytu, atināl kaḷi nirtti.*
>
> It rained, so the game was stopped.

A written, formal word beside the everyday അതുകൊണ്ട്.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**അതിനാൽ** (*atināl*) is a native Malayalam formation: അത്, "that" (DEDR 1), with -ഇനാൽ, the instrumental ending: "by that".

## What you've built

One more word for giving reasons and opinions.
