## You'll want to know: متحفظ
<!-- hl-knowledge: introduces=[AR-LEX-C502-THARTHAR502-02]; assesses=[] -->

**متحفظ** — *mutaḥaffiẓ* — "reserved".

> زوج خالتي رجل متحفظ ولا يتكلم كثيرا.
>
> *zawj khālatī rajul mutaḥaffiẓ wa-lā yatakallamu kathīran.*
>
> My aunt's husband is a reserved man and does not talk much.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**متحفظ** (*mutaḥaffiẓ*) is built on the native Arabic root *ḥ-f-ẓ*, "to keep, to guard" (Lane). Ḥafiẓa, to keep, which you know, is from the same root; mutaḥaffiẓ is one who keeps himself to himself.
