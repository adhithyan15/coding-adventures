## You'll want to know: ಆಸ್ಪತ್ರೆ
<!-- hl-knowledge: introduces=[KA-LEX-C84-BODY-04]; assesses=[] -->

**ಆಸ್ಪತ್ರೆ** (*āspatre*) — "hospital".

**ಆಸ್ಪತ್ರೆ ಎಲ್ಲಿ?** (*āspatre elli?*) — "where is the hospital?", with **ಎಲ್ಲಿ**,
"where", which you already know.
