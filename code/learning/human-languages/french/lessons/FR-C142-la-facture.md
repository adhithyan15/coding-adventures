## You'll want to know: la facture
<!-- hl-knowledge: introduces=[FR-LEX-C142-LIRE142-05]; assesses=[] -->

**la facture** — "a bill, an invoice". Read the bill: **Facture : loyer, 400 euros. À payer avant lundi.** Pay it before Monday.
