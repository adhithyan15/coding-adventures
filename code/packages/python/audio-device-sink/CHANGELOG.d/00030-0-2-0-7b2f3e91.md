## 0.2.0

- Added local `audio_device_sink.warrant` and verified `required_capabilities.json` against the closed capability taxonomy.
- Hardened `src/lib.rs` (Rust C-API FFI bridge): added `std::panic::catch_unwind` at `extern "C"` boundaries, explicit NULL pointer checks on all CPython handles (CWE-476), checked integer/slice length caps with O(1) `PyObject_Size` pre-flight check (CWE-190 / CWE-400), `PyLong_FromUnsignedLongLong` for `u64`/`usize` returns, and O(1) bounded error messages.
- Hardened Python wrapper (`__init__.py`): added `OverflowError` handling for huge `Real` values, O(1) `_format_bounded_int` error formatting, O(1) `Sized` pre-flight bounds and `str`/`bytes` rejection, `bit_depth` validation in `play_pcm_buffer`, and finite duration check on native reports.
- Updated `pyproject.toml` with `--cov-fail-under=95` and Ruff configuration while keeping `[tool.uv.sources]` free of workspace members.
- Added `tests/test_hostile_inputs.py` and `tests/test_pbt.py` (SplitMix64).
