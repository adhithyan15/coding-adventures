# pueda · puedas · pueda — one more known stem change

## Warm-up
<!-- hl-knowledge: introduces=[ES-GRAMMAR-PODER-SUBJUNCTIVE-SINGULAR]; assesses=[ES-LEX-PODER, ES-GRAMMAR-PODER-PRESENT-SINGULAR, ES-GRAMMAR-SUBJUNCTIVE-YO-STEM-VOWEL-SWAP] -->

[PAUSE 2s] Present **puedo** already carries **o → ue**. Remove **-o** to get
**pued-**, then add the same **a** row:

| person | present subjunctive |
|---|---|
| yo | pued**a** |
| tú | pued**as** |
| él / ella / usted | pued**a** |

Say **pueda · puedas · pueda**. No other **poder** forms enter today.

## Grammar Lens: use it immediately
<!-- hl-knowledge: introduces=[]; assesses=[ES-GRAMMAR-WANT-ONE-TWO-SUBJECT-CONTRAST, ES-GRAMMAR-PODER-SUBJUNCTIVE-SINGULAR, ES-LEX-HABLAR, ES-LEX-ESPANOL] -->

**Quiero que puedas hablar español** means “I want you to be able to speak
Spanish.” Every word was already known except the single form **puedas**. This
is the gentle pattern: learn one row, then spend it in the next sentence.
