## You'll want to know: فرق
<!-- hl-knowledge: introduces=[UR-LEX-C385-DAKHILA385-02]; assesses=[] -->

**فرق** — *farq* — "a difference".

> اگر دونوں میں فرق نہیں تو سستا خریدیے۔
>
> *agar donoṅ meṅ farq nahīṅ to sastā kharīdiye.*
>
> If there is no difference between them, buy the cheaper one.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**فرق** (*farq*) is usually traced, through Persian, to Arabic *farq*, "separating, a parting".
