## You'll want to know: ميز
<!-- hl-knowledge: introduces=[AR-LEX-C364-TAHLIL364-05]; assesses=[] -->

**ميز** — *mayyaza* — "to distinguish".

> لا يميز الطفل بين الألوان بعد.
>
> *lā yumayyizu aṭ-ṭifl bayna al-alwān baʿd.*
>
> The child cannot tell the colours apart yet.

Present: يميز, *yumayyiz*.

Often with بين: ميز بين … و …, told … from ….

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ميز** (*mayyaza*) is built on the native Arabic root *m-y-z*, "to separate, to set apart" (Lane). It is Form II, to set apart: to tell one thing from another.
