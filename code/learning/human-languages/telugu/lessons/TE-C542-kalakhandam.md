# కళాఖండం (kaḷākhaṇḍaṁ) — a masterpiece

## You'll want to know: కళాఖండం
<!-- hl-knowledge: introduces=[TE-LEX-C542-SILPAM542-05]; assesses=[] -->

**కళాఖండం** — *kaḷākhaṇḍaṁ* — "a masterpiece".

> ఆ పాత ఆలయం ఒక కళాఖండం.
>
> *ā pāta ālayaṁ oka kaḷākhaṇḍaṁ.*
>
> That old temple is a masterpiece.

కళ, art, + ఖండం, piece.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**కళాఖండం** (*kaḷākhaṇḍaṁ*) is a learned compound built from Sanskrit *kalā*, "any practical art" (CDIAL 2927), and *khaṇḍa*, "a piece, a fragment" (CDIAL 3792).
