## You'll want to know: la asociación
<!-- hl-knowledge: introduces=[ES-LEX-C606-SOLIDAR-03]; assesses=[] -->

**la asociación** — "the association, the society".

> Es miembro de una asociación de vecinos.
>
> *She is a member of a residents' association.*

*Asociarse* — to join together.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*asociación* is built on *asociar*, a learned borrowing from Latin *associare* 'to join to', built on *socius* 'companion' (EtymDB).
