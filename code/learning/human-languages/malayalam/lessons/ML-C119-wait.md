# കാത്തിരിക്കൂ (kāttirikkū) — please wait

## You'll want to know: കാത്തിരിക്കൂ
<!-- hl-knowledge: introduces=[ML-LEX-C119-SLOWLY-05]; assesses=[] -->

**കാത്തിരിക്കൂ** (*kāttirikkū*) — "please wait". The ending **‑ഊ** (*-ū*) makes a polite
request, as in **പറയൂ**.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

A polite request ending you know.
