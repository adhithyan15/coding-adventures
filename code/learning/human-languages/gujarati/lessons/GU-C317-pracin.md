# પ્રાચીન (prācīn) — ancient

## You'll want to know: પ્રાચીન
<!-- hl-knowledge: introduces=[GU-LEX-C317-ITIHAS317-03]; assesses=[] -->

**પ્રાચીન** — *prācīn* — "ancient".

> આ ગામમાં એક પ્રાચીન કૂવો છે.
>
> *ā gāmmā̃ ek prācīn kūvo che.*
>
> There is an ancient well in this village.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**પ્રાચીન** (*prācīn*) is a tatsama, Sanskrit *prācīna*, "turned to the east", and so "former, ancient" (Monier-Williams). It is for things of long ago; **જૂનું** is old in the everyday sense.
