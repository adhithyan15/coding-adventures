# Punjabi Roadmap

Same shape as the other tracks: deep one-word lessons in themed chapters.
Slug-identified; order lives in the book and
[`session-map.md`](./session-map.md). See
[`HL00`](../../../specs/HL00-human-language-curriculum-framework.md).

Grounding: English + Sanskrit + Persian/Arabic, with the wider Indo-European
family drawn in where it reaches. The recurring thread is Punjab's **two
vocabularies** (Sanskritic and Perso-Arabic) and the **Gurmukhi** script, taught
**inline**, never as a gated reading course.
