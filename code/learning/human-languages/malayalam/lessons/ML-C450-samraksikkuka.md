# സംരക്ഷിക്കുക (saṁrakṣikkuka) — to protect; to preserve

[PAUSE 2s] Before the new one: say the Malayalam for to lower, then the Malayalam for to ensure.

## You'll want to know: സംരക്ഷിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C450-SAMRAKSANAM450-03]; assesses=[] -->

**സംരക്ഷിക്കുക** — *saṁrakṣikkuka* — "to protect; to preserve".

> നാട്ടുകാർ ആ പഴയ കുളം സംരക്ഷിച്ചു.
>
> *nāṭṭukār ā paḻaya kuḷaṁ saṁrakṣiccu.*
>
> The local people preserved that old pond.

Past: സംരക്ഷിച്ചു, *saṁrakṣiccu*.

The noun is സംരക്ഷണം, protection.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**സംരക്ഷിക്കുക** (*saṁrakṣikkuka*) is built from Sanskrit *saṁrakṣaṇa*, "guarding, preservation, protection" (Monier-Williams), with the Malayalam verb ending -ിക്കുക.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
