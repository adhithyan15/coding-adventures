## You'll want to know: reencaminhar
<!-- hl-knowledge: introduces=[PT-LEX-C400-PUBLICAR-04]; assesses=[] -->

**reencaminhar** — "to forward (a message)".

> Reencaminhei a mensagem para a minha irmã.
>
> *I forwarded the message to my sister.*

European Portuguese; in Brazil *encaminhar*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*reencaminhar* is built from *re-*, *en-* and *caminho* "way", which is inherited from Late Latin *cammīnus* "way" (EtymDB), usually traced to a Celtic word.
