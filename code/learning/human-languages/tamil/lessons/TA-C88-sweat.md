## You'll want to know: வியர்வை
<!-- hl-knowledge: introduces=[TA-LEX-C88-DOCTOR-05]; assesses=[] -->

**வியர்வை** (*viyarvai*) — "sweat".

**வியர்வை வருகிறது** — "I am sweating", literally "sweat is coming", like **வாந்தி**.
