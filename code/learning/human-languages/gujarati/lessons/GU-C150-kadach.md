# કદાચ (kadāc) — perhaps

## You'll want to know: કદાચ
<!-- hl-knowledge: introduces=[GU-LEX-C150-FUT150-01]; assesses=[GU-GRAMMAR-C149-SHE-01, GU-GRAMMAR-C147-E-TIME-01] -->

**કદાચ** (*kadāc*) — "perhaps".

A plan is sure; a guess is not. **કદાચ** usually stands at the front, and it
pairs easily with the future:

> **કદાચ તે આવશે.** — *kadāc te āvśe.* — Perhaps she'll come.
> **કદાચ આજે વરસાદ આવશે.** — *kadāc āje varsād āvśe.* — Maybe it will rain today.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**કદાચ** (*kadāc*) is usually traced to Sanskrit *kadācit*, "at some time,
once", built on *kadā*, "when". Sanskrit already let *kadācit* lean towards
"perhaps", and that is the sense Gujarati kept.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word: the future can now be sure, planned, or only possible.
