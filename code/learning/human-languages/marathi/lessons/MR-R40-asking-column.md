# Ask your own message six questions

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MR-QUESTION-KON, MR-QUESTION-KITI, MR-QUESTION-KUTHE, MR-QUESTION-KADHI] -->

[PAUSE 5s] Six asking words are now yours: **काय**, **कसा**, **कोण**, **किती**,
**कुठे**, **कधी**. Name them, then name the one letter they all begin with.

You wrote a message about yourself many chapters ago and could not question a
line of it. Now you can. Take each line and turn it into the question it answers,
changing one word and moving nothing.


[PAUSE 1s]
- [YOU SAY: *tumchaṁ nāv kāy āhe?* — and answer it]
- [YOU SAY: *tumhī kase āhāt?* — and answer it]
- [YOU SAY: *tumhī kuṭhe rāhtā?* — and answer it]
- [YOU RECALL: say the line of your message that means *I read Marathi*]
- [YOU RECALL: write **इथे**, then **तिथे**, and check which one needed a whole vowel letter]
