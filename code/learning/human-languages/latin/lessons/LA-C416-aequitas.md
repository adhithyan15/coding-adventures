# aequitās, aequitātis — fairness, equity

## You'll want to know: aequitās, aequitātis
<!-- hl-knowledge: introduces=[LA-LEX-C416-IUSTITIA-02]; assesses=[] -->

**aequitās, aequitātis** — "fairness, equity".

> Iūdex magnā aequitāte iūdicāvit.
>
> *The judge gave judgement with great fairness.*

*aequitās, aequitātis* f., built on *aequus*, level, fair. English *equity*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*aequitās* is built on *aequus* "level, fair" (Lewis & Short), with the ending *-tās* that makes a quality. English *equity* comes from it.
