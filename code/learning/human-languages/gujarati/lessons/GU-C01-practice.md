# Chapter 1 — The greetings

## Warm-up

## How to answer — rapid recall
<!-- hl-knowledge: introduces=[GU-CONCEPT-C01-PRACTICE-01]; assesses=[GU-CONCEPT-C01-AABHAAR-01, GU-CONCEPT-C01-AAVJO-01, GU-CONCEPT-C01-HAANAA-01, GU-CONCEPT-C01-NAMASTE-01, GU-CONCEPT-C01-SAARUN-01] -->

[PAUSE 1s each]
- [YOU SAY: hello / goodbye — *namaste*]
- [YOU SAY: thank you — *ābhār*]
- [YOU SAY: yes and no — *hā* / *nā*]
- [YOU SAY: good / okay — *sārũ*]
- [YOU SAY: the "come again" goodbye — *āvjo*]

## Script — the script and the language
<!-- hl-knowledge: introduces=[]; assesses=[GU-CONCEPT-C01-AABHAAR-01, GU-CONCEPT-C01-AAVJO-01, GU-CONCEPT-C01-HAANAA-01, GU-CONCEPT-C01-NAMASTE-01, GU-CONCEPT-C01-PRACTICE-01, GU-CONCEPT-C01-SAARUN-01] -->

[PAUSE 2s]
- [YOU SAY: the one visible thing that sets Gujarati apart from Devanagari (no top line)]
- [YOU SAY: how many genders Gujarati keeps (three — *sāro/sārī/sārũ*)]

## What you've built — roots you now carry
<!-- hl-knowledge: introduces=[]; assesses=[GU-CONCEPT-C01-AABHAAR-01, GU-CONCEPT-C01-AAVJO-01, GU-CONCEPT-C01-HAANAA-01, GU-CONCEPT-C01-NAMASTE-01, GU-CONCEPT-C01-PRACTICE-01, GU-CONCEPT-C01-SAARUN-01] -->

[PAUSE 2s]
- *namaste* = *namas* "a bow" + *te* "to you"
- *ābhār* ← *ā* + *bhṛ* "to bear" → an obligation borne (cousin of English *bear*)
- *nā* ("no") ← PIE *\*ne* → English *no/not/none*
- *āvjo* ("goodbye") = "come [again]," from *āvvũ* "to come"

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[GU-CONCEPT-C01-AABHAAR-01, GU-CONCEPT-C01-AAVJO-01, GU-CONCEPT-C01-HAANAA-01, GU-CONCEPT-C01-NAMASTE-01, GU-CONCEPT-C01-PRACTICE-01, GU-CONCEPT-C01-SAARUN-01] -->

[PAUSE 3s] Someone thanks you and turns to leave. Answer their thanks and send
them off the Gujarati way. (*Sārũ* — and *āvjo*, "come again.")
