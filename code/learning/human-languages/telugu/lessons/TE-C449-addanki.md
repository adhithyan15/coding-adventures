# అడ్డంకి (aḍḍaṅki) — an obstacle; a hindrance

## You'll want to know: అడ్డంకి
<!-- hl-knowledge: introduces=[TE-LEX-C449-ADDANKI449-01]; assesses=[] -->

**అడ్డంకి** — *aḍḍaṅki* — "an obstacle; a hindrance".

> రోడ్డు మీద పడిన చెట్టు పెద్ద అడ్డంకి అయింది.
>
> *rōḍḍu mīda paḍina ceṭṭu pedda aḍḍaṅki ayindi.*
>
> The tree that fell on the road became a big obstacle.

అడ్డు, a hindrance, + -ంకి. It goes with plans too: పనికి అడ్డంకి, an obstacle to the work.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**అడ్డంకి** (*aḍḍaṅki*) is native Dravidian, built on అడ్డు, "to hinder; a hindrance, a cross-bar" (DEDR 83), with Tamil *aṭai*, "to block".
