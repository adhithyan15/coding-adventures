# ಬಾಣ (bāṇa) — an arrow

## You'll want to know: ಬಾಣ
<!-- hl-knowledge: introduces=[KA-LEX-C349-KHADGA349-02]; assesses=[] -->

**ಬಾಣ** — *bāṇa* — "an arrow".

> ಬೇಟೆಗಾರನ ಬಾಣ ಮರಕ್ಕೆ ತಾಗಿತು.
>
> *bēṭegārana bāṇa marakke tāgitu.*
>
> The hunter's arrow hit the tree.

Plural: ಬಾಣಗಳು, *bāṇagaḷu*.

A bow is ಬಿಲ್ಲು; arrows are shot: ಬಾಣ ಬಿಡು.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಬಾಣ** (*bāṇa*) is borrowed from Sanskrit *bāṇa*, "a reed shaft, an arrow" (CDIAL 9203).
