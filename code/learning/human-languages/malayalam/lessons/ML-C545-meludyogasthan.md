# മേലുദ്യോഗസ്ഥൻ (mēludyōgasthan) — a superior; a senior officer

## You'll want to know: മേലുദ്യോഗസ്ഥൻ
<!-- hl-knowledge: introduces=[ML-LEX-C545-CUMATALA545-01]; assesses=[] -->

**മേലുദ്യോഗസ്ഥൻ** — *mēludyōgasthan* — "a superior; a senior officer".

> മേലുദ്യോഗസ്ഥൻ എന്റെ റിപ്പോർട്ട് പരിശോധിച്ചു.
>
> *mēludyōgasthan enṟe ṟippōrṭṭŭ pariśōdhiccu.*
>
> My superior checked my report.

മേൽ above + ഉദ്യോഗസ്ഥൻ an official.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**മേലുദ്യോഗസ്ഥൻ** (*mēludyōgasthan*) is a Malayalam compound built from മേൽ, "above", which is native (DEDR 5086), and ഉദ്യോഗസ്ഥൻ, "an official", from Sanskrit *udyoga* (Monier-Williams).

## What you've built

One more word for describing what you lived and felt.
