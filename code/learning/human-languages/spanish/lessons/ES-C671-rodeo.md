## You'll want to know: el rodeo
<!-- hl-knowledge: introduces=[ES-LEX-C671-LEJOS-05]; assesses=[] -->

**el rodeo** — "the detour, the long way round; the rodeo".

> Si vamos por el puente, damos un rodeo.
>
> *If we go over the bridge, we go the long way round.*

*Sin rodeos* — without beating about the bush.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*rodeo* is built on *rodear* "to go round", from *rueda* "wheel", which is inherited from Latin *rota*.

## What you've built
