## You'll want to know: ಸವಾಲು
<!-- hl-knowledge: introduces=[KA-LEX-C387-SAVALU387-01]; assesses=[] -->

**ಸವಾಲು** — *savālu* — "a challenge".

> ಹೊಸ ಊರಿನಲ್ಲಿ ಕೆಲಸ ಹುಡುಕುವುದು ದೊಡ್ಡ ಸವಾಲು.
>
> *hosa ūrinalli kelasa huḍukuvudu doḍḍa savālu.*
>
> Finding work in a new town is a big challenge.

ಸವಾಲು ಹಾಕು, to throw down a challenge.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಸವಾಲು** (*savālu*) is a loan from Hindustani *savāl*, which comes from Arabic *suʾāl*, "a question"; Kannada uses it for a challenge.
