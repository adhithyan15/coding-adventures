## You'll want to know: કર્મચારી
<!-- hl-knowledge: introduces=[GU-LEX-C247-LIVING247-02]; assesses=[] -->

**કર્મચારી** — *karmacārī* — "employee".

> **આ કારખાનામાં સો કર્મચારી કામ કરે છે.** — *ā kārkhānāmā̃ so karmacārī kām kare che* — "A hundred employees work in this factory."

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**કર્મચારી** (*karmacārī*) is a learned compound built from two Sanskrit words, a tatsama: *karman*, "act, work" (CDIAL 2892), and *cārin*, "moving about" (CDIAL 4765).
