# पूर्तता करणे (pūrtatā karṇe) — to fulfil (a condition)

## You'll want to know: पूर्तता करणे
<!-- hl-knowledge: introduces=[MR-LEX-C378-ATI378-05]; assesses=[] -->

**पूर्तता करणे** — *pūrtatā karṇe* — "to fulfil (a condition)".

> सगळ्या अटींची पूर्तता केल्यास प्रवेश मिळेल.
>
> *sagaḷyā aṭīñcī pūrtatā kelyās praveś miḷel.*
>
> If all the conditions are fulfilled, you will get admission.

Past, with -ने (he …): त्याने पूर्तता केली, *tyāne pūrtatā kelī*.

What is fulfilled takes -ची: अटींची पूर्तता.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**पूर्तता करणे** (*pūrtatā karṇe*) joins पूर्तता, a learned noun built on Sanskrit *pūrti*, "filling, completion" (Monier-Williams), to करणे, "to do".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
