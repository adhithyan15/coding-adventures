# ઠેકાણું (ṭhekāṇũ) — whereabouts, place

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[GU-LEX-C195-LOST195-02, GU-LEX-C195-LOST195-03] -->

[PAUSE 2s] Before the new one: say the Gujarati for to roam, then the Gujarati for to show.

## You'll want to know: ઠેકાણું
<!-- hl-knowledge: introduces=[GU-LEX-C195-LOST195-04]; assesses=[] -->

**ઠેકાણું** — *ṭhekāṇũ* — "whereabouts, place".

> **આ દુકાનનું ઠેકાણું શું છે?** — *ā dukānnũ ṭhekāṇũ śũ che?* — "Where exactly is this shop?"

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ઠેકાણું** (*ṭhekāṇũ*) is a tadbhava. CDIAL lists it, glossed "station", under *\*ṭhēkk*, "fix", a reconstructed form (CDIAL 5509).
