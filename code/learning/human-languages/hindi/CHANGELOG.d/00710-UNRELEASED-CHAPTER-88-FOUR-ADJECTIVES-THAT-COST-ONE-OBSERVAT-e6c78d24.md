### Why the two points share a chapter

All four words land on the same side of a rule the track already owns. Chapter
41 taught that a Hindi adjective agrees with its noun; chapter 11 contrasted
काला (Sanskrit, ends in -आ, bends) with सफ़ेद (Persian loan, invariant). Every
adjective added here is consonant-final, so none of them bends:

| adjective | origin | changes ending? |
|---|---|---|
| काला | Sanskrit, ends in -आ | yes |
| सफ़ेद | Persian loan | no |
| आसान | Persian loan | no |
| मुश्किल | Arabic loan | no |
| सुंदर | Sanskrit | no |
| बदसूरत | Persian + Arabic | no |

The chapter teaches **no new grammar**. Four A1 adjectives cost the learner one
observation — *look at the ending* — rather than four memorisations.

### What the etymology buys

**मुश्किल** is Arabic, from the root ش-ك-ل (*sh-k-l*), which is about form and
shape. A *mushkil* thing is one whose outline you cannot make out. Hindi's
"difficult" is not "heavy" but **"hard to make out"** — a different metaphor
from the English one.

**सुंदर** opens with Sanskrit सु-, the same prefix already met in **सुप्रभात**
("good dawn"). Beauty arrives as a prefix the learner owns.

**बदसूरत** is Persian बद ("bad") plus Arabic सूरत ("face") — literally
*bad-faced*. The lesson flags, and refuses to build on, the famous coincidence
that बद and English *bad* resemble each other without being related.

So the pair is built from opposite halves of the vocabulary: सुंदर inherited,
बदसूरत borrowed. That is an accident of history rather than a judgement, but it
tells a learner which dictionary each word's relatives live in.
