## You'll want to know: सांडपाणी
<!-- hl-knowledge: introduces=[MR-LEX-C448-DURGANDHI448-01]; assesses=[] -->

**सांडपाणी** — *sāṇḍpāṇī* — "waste water; sewage".

> सांडपाणी नदीत सोडू नये.
>
> *sāṇḍpāṇī nadīt soḍū naye.*
>
> Waste water should not be let into the river.

Neuter.

Used water from homes and factories, which should be cleaned before it reaches a river.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**सांडपाणी** (*sāṇḍpāṇī*) is built from *sāṇḍ-*, "spilt, let go", and **पाणी**, "water", inherited from Sanskrit *pānīya* (CDIAL 8082); the first part is not settled.
