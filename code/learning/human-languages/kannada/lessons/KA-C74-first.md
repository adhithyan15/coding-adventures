## You'll want to know: ಮೊದಲನೆಯ
<!-- hl-knowledge: introduces=[KA-LEX-C74-ORDINAL-04]; assesses=[KA-GRAMMAR-C74-ORDINAL-02, KA-LEX-C07-ONDU-01] -->

**ಮೊದಲನೆಯ** (*modalaneya*) — "**first**".

The ending is the one you already have. What is new is the word underneath it,
because there is no **ಒಂದು** anywhere in *modalaneya* — and there was never going
to be.

| cardinal | ordinal |
|---|---|
| **ಒಂದು** (*ondu*) | **ಮೊದಲನೆಯ** (*modalaneya*) |
| **ಎರಡು** (*eraḍu*) | **ಎರಡನೆಯ** (*eraḍaneya*) |
| **ಮೂರು** (*mūru*) | **ಮೂರನೆಯ** (*mūraneya*) |

**ಮೊದಲನೆಯ ದಿನ** (*modalaneya dina*), the first day. **ಮೊದಲನೆಯ ದಾರಿ**
(*modalaneya dāri*), the first road.

## Across the family: ಮೊದಲು, "a beginning"
<!-- hl-knowledge: introduces=[KA-ETYMON-C74-ORDINAL-05]; assesses=[] -->

Under it sits **ಮೊದಲು** (*modalu*), "**a beginning**" — so the word means "of the
beginning", not "one-th".

| language | "one" | "first" is built on |
|---|---|---|
| Kannada | *ondu* | **ಮೊದಲು** *modalu*, a beginning |
| Tamil | *oṉṟu* | **முதல்** *mudal*, a beginning |
| Telugu | *okaṭi* | **మొదలు** *modalu*, a beginning |

Three sisters, three different words for **one**, and the *same* word for the
start of a line. Counting and ordering were never the same idea in this family,
and *first* is where the seam shows.

Note what is and is not irregular here. The **ending** is perfectly regular —
*modalu* drops its final **-ು** and takes **-ಅನೆಯ** exactly like *eraḍu* did. It
is only the **stem** that is a surprise. Kannada asks you to learn one extra
word, not one extra rule.
