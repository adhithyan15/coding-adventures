# निष्ठीवति (niṣṭhīvati) — spits

## You'll want to know: निष्ठीवति
<!-- hl-knowledge: introduces=[SA-LEX-C472-TALU472-04]; assesses=[] -->

**निष्ठीवति** — *niṣṭhīvati* — "spits".

> मार्गे न निष्ठीवेत्।
>
> *mārge na niṣṭhīvet.*
>
> One should not spit on the road.

Past (he …): सः मार्गे निष्ठ्यूतवान्, *saḥ mārge niṣṭhyūtavān*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**निष्ठीवति** (*niṣṭhīvati*) is built from *ni*, "down", and the root √ṣṭhiv, "to spit"; MW's ppp *niṣṭhyūta* is "spit out" (MW).

## What you've built
