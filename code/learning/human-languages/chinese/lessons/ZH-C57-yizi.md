## You'll want to know: yǐzi
<!-- hl-knowledge: introduces=[ZH-LEX-C57-HOME57-04]; assesses=[] -->

*yǐzi* — "chair".

> *zhè shì háizi de yǐzi* — This is the child's chair.

Its characters come later; for now it is a word for the ear.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*yǐzi* is built from yǐ and the noun ending zi. The Guangyun records the first character as *'jeX* (Guangyun, in Baxter's transcription), and in a second reading as the name of a tree; the chair sense is not given there, so how it got it is not settled.
