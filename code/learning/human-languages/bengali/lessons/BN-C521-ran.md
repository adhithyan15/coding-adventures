## You'll want to know: রান
<!-- hl-knowledge: introduces=[BN-LEX-C521-BAT521-03]; assesses=[] -->

**রান** — *rān* — "a run in cricket".

> জিততে আমাদের দশ রান দরকার।
>
> *Jitte āmāder dôsh rān dôrkār.*
>
> We need ten runs to win.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**রান** (*rān*) is borrowed from English *run*, used only for the scoring run in cricket.
