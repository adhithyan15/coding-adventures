## You'll want to know: প্রতিযোগী
<!-- hl-knowledge: introduces=[BN-LEX-C520-PODOK520-04]; assesses=[] -->

**প্রতিযোগী** — *prôtijogī* — "a contestant; a competitor".

> প্রতিযোগিতায় দশজন প্রতিযোগী ছিল।
>
> *Prôtijogitāy dôshjôn prôtijogī chhilô.*
>
> There were ten contestants in the competition.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**প্রতিযোগী** (*prôtijogī*) is Sanskrit *pratiyogin*, "one who is set against another" (Monier-Williams); প্রতিযোগিতা, a competition, is built on it.
