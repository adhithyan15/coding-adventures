## You'll want to know: پیش گوئی
<!-- hl-knowledge: introduces=[UR-LEX-C543-ATKAL543-02]; assesses=[] -->

**پیش گوئی** — *pesh goī* — "a prediction".

> اگر پیش گوئی ٹھیک ہے تو کل بارش ہو گی۔
>
> *agar pesh goī ṭhīk hai to kal bārish ho gī.*
>
> If the forecast is right, it will rain tomorrow.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**پیش گوئی** (*pesh goī*) is usually traced to Persian *pēshgōī*, "a prediction", built from *pēsh*, "before", and *gō-*, "to say", with the noun ending *-ī*: saying a thing before it happens.
