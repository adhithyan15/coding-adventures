Warm-up.
This is a gentle return to fictional practice values, not a request for personal information or a scored A1 mock.
Keep this old model visible: ਕ chooses A in all three banks; ਖ chooses B in all three banks. Age A/B are ੧੫ / ੨੫; phone A/B are ੦੧੨ ੨੫੧ / ੦੨੫ ੧੨੫; date A/B are ੧੫/੦੧/੨੦੨੫ / ੨੫/੦੨/੨੦੨੫. Point to the matching bank letter for each field before writing anything.

Guided Practice.
With the model still visible, use ਕ to copy its three A values after these printed labels. Look back at the bank before each value. Keep the card mark out of the form.
ਉਮਰ: ______ ਫ਼ੋਨ: ______ ਤਾਰੀਖ਼: ______.

Wrap-up Recall.
Cover the bank for five seconds. The card is now ਖ. On a fresh copy of the same three printed labels, write the familiar B values from memory. Uncover the bank and compare one value at a time. If a value differs, correct only that value with the model visible again. This brief recall is practice, not independent timed writing or mock credit.
