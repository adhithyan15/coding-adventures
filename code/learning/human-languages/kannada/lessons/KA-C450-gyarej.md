# ಗ್ಯಾರೇಜ್ (gyārēj) — a garage; a workshop

## You'll want to know: ಗ್ಯಾರೇಜ್
<!-- hl-knowledge: introduces=[KA-LEX-C450-GARAGE450-02]; assesses=[] -->

**ಗ್ಯಾರೇಜ್** — *gyārēj* — "a garage; a workshop".

> ನಮ್ಮ ಬೀದಿಯ ಕೊನೆಯಲ್ಲಿ ಒಂದು ಗ್ಯಾರೇಜ್ ಇದೆ.
>
> *namma bīdiya koneyalli ondu gyārēj ide.*
>
> There is a garage at the end of our street.

In India mostly a repair workshop for vehicles.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಗ್ಯಾರೇಜ್** (*gyārēj*) is a loan from English *garage*.
