# உடன்படிக்கை (uṭaṉpaṭikkai) — a treaty; a pact

## You'll want to know: உடன்படிக்கை
<!-- hl-knowledge: introduces=[TA-LEX-C387-OPPANTAM387-02]; assesses=[] -->

**உடன்படிக்கை** — *uṭaṉpaṭikkai* — "a treaty; a pact".

> இரண்டு நாடுகளும் அமைதி உடன்படிக்கை செய்தன.
>
> *iraṇṭu nāṭukaḷum amaiti uṭaṉpaṭikkai ceytaṉa.*
>
> The two countries made a peace treaty.

Between countries; ஒப்பந்தம் is the general word.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**உடன்படிக்கை** (*uṭaṉpaṭikkai*) is native, built on *uṭaṉ*, "together", which DEDR 945 lists with *uṭaṉ-paṭu*, "to agree, yield": a written agreeing.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
