# શરૂ કરવું (śarū karvũ) — to start, to begin

## You'll want to know: શરૂ કરવું
<!-- hl-knowledge: introduces=[GU-LEX-C178-START178-01]; assesses=[] -->

**શરૂ કરવું** — *śarū karvũ* — "to start, to begin".

> **હું કાલે નવું કામ શરૂ કરીશ.** — *hũ kāle navũ kām śarū karīś* — "I will start a new job tomorrow."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**શરૂ કરવું** (*śarū karvũ*) is built from *śarū*, "begun", and the inherited *karvũ*, "to do". *Śarū* is a loan from Arabic *shurūʿ*, "a beginning", through Persian, the word behind *śarūāt* (Lane).
