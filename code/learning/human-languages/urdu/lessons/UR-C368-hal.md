# حل (hal) — a solution

## You'll want to know: حل
<!-- hl-knowledge: introduces=[UR-LEX-C368-HAL368-03]; assesses=[] -->

**حل** — *hal* — "a solution".

> اگر حل نہیں ملا تو ہم ماہر سے پوچھیں گے۔
>
> *agar hal nahīṅ milā to ham māhir se pūchheṅ ge.*
>
> If we find no solution, we will ask an expert.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**حل** (*hal*) is usually traced, through Persian, to Arabic *ḥall*, "loosening, solving": untying a knot.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
