## You'll want to know: aufbauen
<!-- hl-knowledge: introduces=[GE-LEX-C425-CAMPING-04]; assesses=[] -->

**aufbauen** — "to put up, to set up".

> Am Abend bauen sie einen Tisch und Stühle vor dem Wohnwagen auf.
>
> *In the evening they set up a table and chairs in front of the caravan.*

Separable: *wir bauen auf*, *wir haben aufgebaut*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*aufbauen* is built from *auf* 'up' and *bauen* 'to build', inherited from Proto-Germanic *būaną* (EtymDB).
