# വികസിപ്പിക്കുക (vikasippikkuka) — to develop

## You'll want to know: വികസിപ്പിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C431-VIKASANAM431-02]; assesses=[] -->

**വികസിപ്പിക്കുക** — *vikasippikkuka* — "to develop".

> അവർ ഒരു പുതിയ ആപ്പ് വികസിപ്പിച്ചു.
>
> *avar oru putiya āppŭ vikasippiccu.*
>
> They developed a new app.

Past: വികസിപ്പിച്ചു, *vikasippiccu*.

Its intransitive partner is വികസിക്കുക, to grow, to expand.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**വികസിപ്പിക്കുക** (*vikasippikkuka*) is built from the Sanskrit root *vi-kas*, "to open, to expand" (Monier-Williams), with the Malayalam causative verb ending -ിപ്പിക്കുക: to make a thing grow.
