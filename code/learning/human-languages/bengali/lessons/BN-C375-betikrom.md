# ব্যতিক্রম (bætikrôm) — an exception

## You'll want to know: ব্যতিক্রম
<!-- hl-knowledge: introduces=[BN-LEX-C375-ONUMOTI375-03]; assesses=[] -->

**ব্যতিক্রম** — *bætikrôm* — "an exception".

> জরুরি কাজ থাকলে ব্যতিক্রম হতে পারে।
>
> *jôruri kāj thākle bætikrôm hôte pāre.*
>
> Exceptions can be made if there is urgent work.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ব্যতিক্রম** (*bætikrôm*) is Sanskrit *vyatikrama*, an overstepping or a reversal of order (Monier-Williams). Bengali uses it for a case that steps outside the rule, an exception.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
