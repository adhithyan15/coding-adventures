## You'll want to know: тёрка
<!-- hl-knowledge: introduces=[RU-LEX-C328-NAREZAT-05]; assesses=[] -->

**тёрка** (*tyórka*) — "a grater".

> Тёрка лежит рядом с раковиной.
>
> *Tyórka lezhít ryádom s rákovinoy.*
>
> The grater is next to the sink.

Feminine; genitive plural *тёрок* (*tyórok*).

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*тёрка* is built on *тереть* "to rub", inherited from Proto-Slavic *terti*, PIE *terh₁-* (EtymDB), with the ending *-ка* for a tool.
