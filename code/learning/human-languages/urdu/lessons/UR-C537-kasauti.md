## You'll want to know: کسوٹی
<!-- hl-knowledge: introduces=[UR-LEX-C537-MUTABADIL537-04]; assesses=[] -->

**کسوٹی** — *kasauṭī* — "a touchstone; a real test".

> اگر دوست مشکل میں ساتھ رہا تو یہی کسوٹی ہے۔
>
> *agar dost mushkil meṅ sāth rahā to yihī kasauṭī hai.*
>
> If a friend stands by you in trouble, that is the real test.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**کسوٹی** (*kasauṭī*) is inherited from Sanskrit *kaṣapaṭṭikā*, "a touchstone", the stone gold is rubbed on to test it (CDIAL 2973).
