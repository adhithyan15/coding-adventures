# অথচ (ôthôch) — and yet; even so

## You'll want to know: অথচ
<!-- hl-knowledge: introduces=[BN-LEX-C332-SUTORANG332-03]; assesses=[] -->

**অথচ** — *ôthôch* — "and yet; even so".

> মীরা অনেক পড়ল, অথচ পাস করল না।
>
> *mīrā ônek pôṛlô, ôthôch pās kôrlô nā.*
>
> Mira studied a lot, and yet she did not pass.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**অথচ** (*ôthôch*) is Sanskrit *atha ca*, 'and moreover' (Monier-Williams). The Bengali sense, 'and yet', which links a result you would not expect, is not one the dictionary gives.
