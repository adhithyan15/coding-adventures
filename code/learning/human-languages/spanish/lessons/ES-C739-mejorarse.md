## You'll want to know: mejorarse
<!-- hl-knowledge: introduces=[ES-LEX-C739-CURAR-02]; assesses=[] -->

**mejorarse** — "to get better".

> ¡Que te mejores pronto!
>
> *Get well soon!*

*¡Que te mejores!* takes the subjunctive.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*mejorarse* is built on *mejor* "better" (EtymDB), which is inherited from Latin *melior*.

## What you've built
