## You'll want to know: ડાયરી
<!-- hl-knowledge: introduces=[GU-LEX-C528-YOJVU528-04]; assesses=[] -->

**ડાયરી** — *ḍāyrī* — "a diary".

> જો તમે ડાયરીમાં લખશો તો તમને બધી તારીખો યાદ રહેશે.
>
> *jo tame ḍāyrīmā̃ lakhśo to tamne badhī tārīkho yād raheśe.*
>
> If you write it in a diary, you will remember all the dates.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ડાયરી** (*ḍāyrī*) is borrowed from English *diary*.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
