## You'll want to know: vadimōnium, vadimōniī
<!-- hl-knowledge: introduces=[LA-LEX-C411-TRIBUNAL-04]; assesses=[] -->

**vadimōnium, vadimōniī** — "a promise to appear in court, bail".

> Reus vadimōnium prōmīsit.
>
> *The accused gave bail to appear.*

*vadimōnium, vadimōniī* n., built on *vas, vadis*, a surety: a promise, backed by money, to appear in court on a set day.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*vadimōnium* is built on *vas, vadis* "a surety, a bail" (EtymDB; Lewis & Short), with the ending *-mōnium*; it is a different word from *vās* "a vessel".
