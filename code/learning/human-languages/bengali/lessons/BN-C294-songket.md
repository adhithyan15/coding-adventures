# সংকেত (sôngket) — a signal; a warning sign

## You'll want to know: সংকেত
<!-- hl-knowledge: introduces=[BN-LEX-C294-SOTORKO294-03]; assesses=[] -->

**সংকেত** — *sôngket* — "a signal; a warning sign".

> বন্দরে বিপদের সংকেত দেখে জেলেরা সমুদ্রে গেল না।
>
> *bôndôre bipôder sôngket dekhe jelerā sômudre gelô nā.*
>
> When they saw the danger signal at the port, the fishermen didn't go to sea.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**সংকেত** (*sôngket*) is Sanskrit *saṃketa*, 'an agreement, a convention' (Monier-Williams); a storm signal is a sign everyone has agreed to read the same way.
