# صبح (subah) — the morning

## You'll want to know: صبح
<!-- hl-knowledge: introduces=[UR-LEX-C273-SUBAH-01]; assesses=[UR-LEX-BARISH, UR-LEX-C77-TIME77-03, UR-LEX-C47-VERBS47-03] -->

**صبح** — *subah* — "the morning". It is feminine.

> **صبح بارش ہوئی۔**
>
> *subah bārish huī.* — "It rained in the morning."

> **میں صبح جلدی اٹھتا ہوں۔**
>
> *maiṅ subah jaldī uṭhtā hūṅ.* — "I get up early in the morning."

Like **شام** (*shām*), it can stand alone as a time: "in the morning".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**صبح** (*subah*) is usually traced, through Persian, to Arabic *ṣubḥ*, "morning, dawn". Its first letter is new to your hand; the next lesson takes it out.
