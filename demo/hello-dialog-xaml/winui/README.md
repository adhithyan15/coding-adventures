# HelloDialog — WinUI 3 host project

Auto-generated by `mosaic-compile --backend xaml --emit-project`.

This project hosts a Mosaic-authored **dialog component** (HelloDialog).
The MainWindow contains a button — click it to display the dialog
(a `<ContentDialog>` underneath).

## Prerequisites

1. **.NET 9.0 SDK** — `dotnet --list-sdks` should list one matching `9.0.*`.
2. The Windows App Runtime bundles into the build output
(`<WindowsAppSDKSelfContained>true</WindowsAppSDKSelfContained>`), so
you don't need a system-wide install. If you switch to
framework-dependent, run `winget install Microsoft.WindowsAppRuntime.1.7`.
3. Optional but recommended: Visual Studio Build Tools 2022 with the UWP /
WinUI workload. Without it, `dotnet build` emits one cosmetic MSB4062
error from the AppxPackage MSBuild tasks — the .exe and dependencies
still build correctly.

## Build

```powershell
.\build.ps1            # builds
.\build.ps1 -Run       # builds + runs
.\build.ps1 -Clean     # deletes bin/ + obj/
```

The build emits a fully self-contained .exe at
`bin\Debug\net9.0-windows10.0.19041.0\HelloDialog.exe`. The native
WindowsAppRuntime DLLs are auto-flattened next to the .exe by an
MSBuild post-build target (see the project's `.csproj`).
