## HL-C121 — Japanese hiragana se closes the crossed-stem gap

After hiragana **み** landed, Japanese hiragana **せ** led the measured queue at
**3 affected realizations**.

Sirgazil's CC0 33-frame Wikimedia Commons animation supplies the three-run
order: draw the long horizontal left to right, lift for the left stem and its
rightward base curve, then lift again for the right stem and leftward hook. The
learner filmstrip fits that order to the bundled Noto Sans JP outline without
presenting print geometry as an independent handwriting source.

This closes all 3 affected realizations for **せ** and reranks Japanese hiragana
**て** first at **3**.
