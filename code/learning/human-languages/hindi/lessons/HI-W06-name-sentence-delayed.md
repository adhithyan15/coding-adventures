# Hide the sentence; keep the order

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[HI-CONCEPT-C02-MERANAAMHAI-01] -->

Look for five seconds:

> **मेरा नाम मीरा है।**

Point to the four word groups and the final stop. Do not write while the model
is visible.

## Writing — delayed sentence production
<!-- hl-knowledge: introduces=[]; assesses=[HI-CONCEPT-C02-MERANAAMHAI-01] -->
<!-- hl-writing-stage: controlled-composition -->

Cover the model. Wait ten seconds. From the meaning cue **"My name is Mira"**,
write the whole Hindi sentence with no visible answer and no romanization.

Uncover it only after writing. Compare in this order: word order, spaces,
spelling, then **।**. Circle one differing dimension and repair only that one.
