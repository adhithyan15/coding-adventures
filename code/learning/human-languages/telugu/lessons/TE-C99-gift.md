# బహుమతి (bahumati) — a gift, a prize

## You'll want to know: బహుమతి
<!-- hl-knowledge: introduces=[TE-LEX-C99-WELCOME-04]; assesses=[] -->

**బహుమతి** (*bahumati*) — "a gift", and "a prize".

**మీకు ఒక బహుమతి** — "a gift for you", with the dative **మీకు**.
