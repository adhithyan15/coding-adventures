## 0.1.0

- Initial Python lane runner for the `warrant-corpus-v1` evidence corpus
  (VER04i, WD-101): corpus loader, in-lane domain enumeration, model-IR
  evaluator, `warrant-stream-v1` digests cross-checked against the corpus,

  example, exhaustive and negative-control suites, the
  `warrant-lane-evidence-v1` manifest writer and drift check, and a
  structural manifest validator.
