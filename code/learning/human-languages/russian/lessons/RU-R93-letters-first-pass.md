# (two letters) — From the letter to the word — a first pass

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[RU-SCRIPT-C93-E-01, RU-SCRIPT-C93-SHCHA-01] -->

[PAUSE 3s] Say **этот** (*étot*), then write the letter it gave you.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[RU-SCRIPT-C93-E-01, RU-SCRIPT-C93-SHCHA-01] -->

| letter | name | the word it came from |
|---|---|---|
| э | *e* | **этот** *étot* |
| щ | *shcha* | **площадь** *plóshchad* |

[PAUSE 2s each]
- [YOU WRITE: each letter in the table from memory, then check it]
- [YOU SAY: the word each one came from]
- [YOU READ: each word in the table aloud, and point at its letter]

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[RU-SCRIPT-C93-E-01, RU-SCRIPT-C93-SHCHA-01] -->

[PAUSE 3s] Which word did each letter come from? (**э** from **этот**; **щ** from **площадь**.)
