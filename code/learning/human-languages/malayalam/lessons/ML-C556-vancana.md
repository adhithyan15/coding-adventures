## You'll want to know: വഞ്ചന
<!-- hl-knowledge: introduces=[ML-LEX-C556-VANCANA556-03]; assesses=[] -->

**വഞ്ചന** — *vañcana* — "betrayal; deceit".

> പണം എടുത്ത് ഓടിപ്പോയത് വലിയ വഞ്ചനയായിരുന്നു.
>
> *paṇaṁ eṭuttŭ ōṭippōyatŭ valiya vañcanayāyirunnu.*
>
> Running off with the money was a great betrayal.

Formal; വഞ്ചിക്കുക is to deceive.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**വഞ്ചന** (*vañcana*) is borrowed from Sanskrit *vañcana*, "cheating, deception, fraud" (Monier-Williams).
