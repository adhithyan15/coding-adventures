# だ — voice the known base

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[JA-SCRIPT-TA-01, JA-SCRIPT-DAKUTEN-01, JA-LEX-ITTE-KUDASAI] -->

[PAUSE 12s] Write **た**, then add the two-stroke dakuten without changing the
base. Say the *da* in *kudasai*.

## Script — the change
<!-- hl-knowledge: introduces=[JA-SCRIPT-DA-01]; assesses=[] -->

> **た** + dakuten → **だ** — *ta* → *da*

The voicing mark does the same job it did before. This is transfer, not a new
complex shape.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[JA-SCRIPT-DA-01, JA-LEX-ITTE-KUDASAI] -->

1. Write **た** once.
2. Add dakuten to make **だ**.
3. Point to **だ** while saying the middle of *kudasai*.
