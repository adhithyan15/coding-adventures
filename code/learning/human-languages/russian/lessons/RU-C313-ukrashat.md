## You'll want to know: украшать
<!-- hl-knowledge: introduces=[RU-LEX-C313-YOLKA-03]; assesses=[] -->

**украшать** (*ukrashát*) — "to decorate".

> Дети украшали ёлку весь вечер.
>
> *Déti ukrasháli yólku ves vécher.*
>
> The children decorated the tree all evening.

Imperfective; perfective *украсить* (*ukrásit*), *украшу*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*украшать* is built on *у-* and *краса* "beauty", an inherited Slavic word, in the shape *-краш-*: to make beautiful. EtymDB lists no parent.
