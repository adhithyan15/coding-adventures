## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[MW-LEX-SOLA-01, MW-LEX-SATARA-01, MW-LEX-ATHARA-01, MW-LEX-UGHANIS-01, MW-SCRIPT-SOLA-01, MW-SCRIPT-SATARA-01, MW-SCRIPT-ATHARA-01, MW-SCRIPT-UGHANIS-01, MW-LEX-IGYAARA-01, MW-LEX-BAARA-01, MW-LEX-TERA-01, MW-LEX-CHAUDA-01, MW-LEX-PANDARA-01, MW-LEX-BEES-01, MW-PERFORMANCE-COUNT-TEN-FOUR-SKILL-01, MW-SCRIPT-LLA-01, MW-SCRIPT-A-INDEPENDENT-01, MW-SCRIPT-U-INDEPENDENT-01, MW-SCRIPT-I-INDEPENDENT-01] -->
<!-- hl-writing-stage: dictation-transcription -->

The count is complete for the first time. Run it four ways.

1. Say one to twenty straight through, out loud, once slowly and once fast.
2. Hear six of the twenty named out of order; say each back and say the one
   above it.
3. Write four of the nine teens from dictation.
4. Write the four signs this run of numbers added — **इ**, **ळ**, **अ**, **उ** —
   and beside each write the number that needed it.

Then answer aloud: which of the twenty is not built on a smaller number, and
what is it built on instead?
