## You'll want to know: સહકાર
<!-- hl-knowledge: introduces=[GU-LEX-C358-SEVA358-04]; assesses=[] -->

**સહકાર** — *sahkār* — "cooperation".

> બધાના સહકારથી અમે કામ સમયસર પતાવ્યું.
>
> *badhānā sahkārthī ame kām samaysar patāvyũ.*
>
> With everyone's cooperation we finished the work on time.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**સહકાર** (*sahkār*) is a tatsama, borrowed from Sanskrit *sahakāra*, "acting with, cooperation" (Monier-Williams).
