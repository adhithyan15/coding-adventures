## HL-C180 — frequency ranking turns the Hindi report into a review queue

The first glossed-not-taught report was reproducible but alphabetical. That put
one-off Sanskrit ancestors before forms repeated across many lessons, which is
the wrong order for a review queue. Candidates now sort by descending occurrence
count, with lexical order only as the stable tie-breaker.

The first Hindi page was then read rather than mechanically rejected. Its top
rows split into three useful classes:

| disposition | rows | evidence |
|---|---|---|
| discard: script or morphology fragment | **ना, स्, ते, ट, क्, मे, ता, रा** | syllable-building, conjunct, matra, or inflection demonstrations; not silently glossed standalone words |
| discard: already covered inside its owning lesson | **मेरी, बच्ची, उन्नीस** | feminine possessive in `HI-C02-meraa`, feminine child in `HI-C39-baccha`, and 19 in the `HI-C22-gyarah-bees` number table |
| discard: authoring metalanguage | **विराम** | names the stop/virama idea in writing lessons rather than adding a communicative lexical target |
| keep for promotion review | **मुझे, साँझ, ऋतु, काम** | each is given learner-facing meaning as a real word or form, but never appears in a headword token |

This is the explicit discard evidence HL-C179 asked for. It also proves why the
report cannot become a gate: the highest-frequency row, **ना**, is mostly the
infinitive ending and the syllable inside **नाम**, while lower rows include real
lexical teaching debt.

The next tranche should compare the four retained rows against the Hindi path
and promote the one with the largest prerequisite payoff. **मुझे** is the early
grammar candidate; **साँझ** is the cleanest independent lexical candidate.
