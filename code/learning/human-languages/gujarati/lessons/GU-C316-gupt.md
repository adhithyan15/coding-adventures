## You'll want to know: ગુપ્ત
<!-- hl-knowledge: introduces=[GU-LEX-C316-MUJAB316-04]; assesses=[] -->

**ગુપ્ત** — *gupt* — "secret".

> પોલીસે આ માહિતી ગુપ્ત રાખી.
>
> *polīse ā māhitī gupt rākhī.*
>
> The police kept this information secret.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ગુપ્ત** (*gupt*) is a tatsama, Sanskrit *gupta*, "protected, guarded", and so "hidden" (Monier-Williams). A thing is kept secret with **રાખવું**: **ગુપ્ત રાખી**.
