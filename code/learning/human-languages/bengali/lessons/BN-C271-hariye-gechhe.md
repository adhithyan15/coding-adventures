# আমার ব্যাগ হারিয়ে গেছে (āmār byāg hāriye gechhe) — when something goes wrong

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[BN-GRAMMAR-C271-TICKET-ASK-01, BN-GRAMMAR-C271-FARE-TIME-01, BN-LEX-C241-ACT241-01] -->

[PAUSE 2s] Ask "When does the train leave?" (*ṭren kôkhôn chhāṛbe?*) Then say **হারিয়ে যাওয়া**, "to get lost", which you know.

## You'll want to know: something is lost
<!-- hl-knowledge: introduces=[BN-GRAMMAR-C271-LOST-01]; assesses=[BN-LEX-C241-ACT241-01, BN-LEX-C129-THINGS129-05, BN-LEX-C130-THINGS130-01, BN-LEX-C84-TOWN84-01, BN-LEX-C241-ACT241-04] -->

> **আমার মানিব্যাগ হারিয়ে গেছে।**
>
> *āmār mānibyāg hāriye gechhe.* — "My wallet has gone missing."

**গেছে** is a form of **যাওয়া** that says something happened and still matters now: the wallet went, and it is still gone. This book teaches it only in these set phrases. Whose it is goes in the **-র** form: **আমার ব্যাগ**, **মীরার পাসপোর্ট**. Then what you will do: **পুলিশকে জানাব** (*pulishke jānābô*), "I'll tell the police".

## You'll want to know: the train has left
<!-- hl-knowledge: introduces=[BN-GRAMMAR-C271-MISSED-01]; assesses=[BN-LEX-C53-VERBS53-02, BN-LEX-C128-THINGS128-04, BN-LEX-C247-GUN247-01, BN-GRAMMAR-C271-FARE-TIME-01] -->

**ছাড়া**, "to leave", which you know, makes the same phrase: **ছেড়ে গেছে**, "has left".

> **আমার ট্রেন ছেড়ে গেছে। পরের ট্রেন কখন?**
>
> *āmār ṭren chheṛe gechhe. pôrer ṭren kôkhôn?* — "My train has left. When is the next train?"

[PAUSE 1s]
- [YOU SAY: "My passport has gone missing" — *āmār pāsporṭ hāriye gechhe*]
- [YOU SAY: "I'll tell the police" — *pulishke jānābô*]
- [YOU SAY: "My train has left. When is the next train?" — *āmār ṭren chheṛe gechhe. pôrer ṭren kôkhôn?*]
