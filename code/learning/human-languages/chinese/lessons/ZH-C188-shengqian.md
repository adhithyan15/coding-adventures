## You'll want to know: shěngqián
<!-- hl-knowledge: introduces=[ZH-LEX-C188-MONEY188-04]; assesses=[] -->

*shěngqián* — "to spend less; to save money".

> *wǒ xiǎng shěngqián suǒyǐ bú qù fàndiàn* — I want to save money, so I'm not going to restaurants.

Its characters come later; for now it is a word for the ear.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*shěngqián* is built from *shěng* and 钱 'money', both inherited from Middle Chinese, *srjaengX* and *dzjen* (Guangyun, in Baxter's transcription). The dictionary glosses the first as a government office; the sense 'to use less' is not given there, so how it came is not settled.
