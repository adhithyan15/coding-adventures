## You'll want to know: حكيم
<!-- hl-knowledge: introduces=[AR-LEX-C501-HIKMA501-01]; assesses=[] -->

**حكيم** — *ḥakīm* — "wise".

> جدتي امرأة حكيمة.
>
> *jaddatī imraʾa ḥakīma.*
>
> My grandmother is a wise woman.

In some spoken dialects حكيم is also a doctor (colloquial).

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**حكيم** (*ḥakīm*) is built on the native Arabic root *ḥ-k-m*, "to judge, to restrain" (Lane). The noun ḥikma is wisdom.
