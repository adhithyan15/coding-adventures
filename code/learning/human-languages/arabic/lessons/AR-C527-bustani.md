## You'll want to know: بستاني
<!-- hl-knowledge: introduces=[AR-LEX-C527-MAL527-02]; assesses=[] -->

**بستاني** — *bustānī* — "a gardener".

> يسقي البستاني الورد كل صباح.
>
> *yasqī al-bustānī al-ward kull ṣabāḥ.*
>
> The gardener waters the roses every morning.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**بستاني** (*bustānī*) is built on *bustān*, "an orchard", which you know, with the ending *-ī*: the orchard man. *Bustān* is usually traced to Persian.
