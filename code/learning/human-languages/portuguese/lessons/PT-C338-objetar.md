## You'll want to know: objetar
<!-- hl-knowledge: introduces=[PT-LEX-C338-DESACORDO-03]; assesses=[] -->

**objetar** — "to object".

> Ninguém objetou quando ela propôs uma pausa.
>
> *Nobody objected when she suggested a break.*

*Objetar que…* — to object that… Formal; AO90 spelling, older *objectar*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*objetar* is a learned borrowing from Latin *obiectāre* "to throw before or against, to set against" (Lewis & Short), formed on *obicere*, built from *ob* "against" and *iacere* "to throw".
