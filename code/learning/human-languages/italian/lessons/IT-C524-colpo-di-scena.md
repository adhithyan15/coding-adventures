## You'll want to know: il colpo di scena
<!-- hl-knowledge: introduces=[IT-LEX-C524-ROMANZO-04]; assesses=[] -->

**il colpo di scena** — "twist (in a story)".

> Alla fine c'è un colpo di scena incredibile.
>
> *At the end there is an incredible twist.*

Literally "a blow of the stage".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*colpo di scena* is built from *colpo* "blow", inherited from Vulgar Latin *colpus*, from Latin *colaphus* "a punch" (EtymDB), and *scena* "scene", from Latin *scaena*, from Greek *skēnḗ* "a stage" (EtymDB).
