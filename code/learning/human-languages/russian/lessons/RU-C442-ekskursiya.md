## You'll want to know: экскурсия
<!-- hl-knowledge: introduces=[RU-LEX-C442-EKSKURSIYA-01]; assesses=[] -->

**экскурсия** (*ekskúrsiya*) — "a guided tour, an excursion".

> В субботу у нас экскурсия по городу.
>
> *V subbótu u nas ekskúrsiya po górodu.*
>
> On Saturday we have a guided tour of the town.

Feminine. *Экскурсия по музею* — a tour of the museum.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*экскурсия* goes back to Latin *excursiō* 'a running out, a setting out' (EtymDB), from *excurrere* 'to run out'.
