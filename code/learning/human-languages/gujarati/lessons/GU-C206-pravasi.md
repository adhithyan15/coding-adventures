# પ્રવાસી (pravāsī) — tourist, traveller

## You'll want to know: પ્રવાસી
<!-- hl-knowledge: introduces=[GU-LEX-C206-ARRIVE206-03]; assesses=[] -->

**પ્રવાસી** — *pravāsī* — "tourist, traveller".

> **ગામમાં ઘણા પ્રવાસી આવ્યા.** — *gāmmā̃ ghaṇā pravāsī āvyā* — "Many tourists came to the village."

Built on **પ્રવાસ**, *pravās*, 'trip'.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**પ્રવાસી** (*pravāsī*) is Sanskrit *pravāsin*, "one who is away from home", built on *pravāsa*, "a journey", and taken over as a learned loan, a tatsama. CDIAL has no entry for it.
