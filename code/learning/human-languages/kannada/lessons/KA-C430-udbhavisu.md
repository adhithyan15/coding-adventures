# ಉದ್ಭವಿಸು (udbhavisu) — to arise; to spring up

## You'll want to know: ಉದ್ಭವಿಸು
<!-- hl-knowledge: introduces=[KA-LEX-C430-SANDARBHA430-03]; assesses=[] -->

**ಉದ್ಭವಿಸು** — *udbhavisu* — "to arise; to spring up".

> ಹೊಸ ಮನೆಯಲ್ಲಿ ನೀರಿನ ಸಮಸ್ಯೆ ಉದ್ಭವಿಸಿತು.
>
> *hosa maneyalli nīrina samasye udbhavisitu.*
>
> A water problem arose in the new house.

Past (it …): ಉದ್ಭವಿಸಿತು, *udbhavisitu*.

Of problems and questions.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಉದ್ಭವಿಸು** (*udbhavisu*) is built on Sanskrit *udbhava*, "existence, origin, production" (CDIAL 2039), with the Kannada verb ending -*isu*.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
