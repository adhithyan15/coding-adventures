## Grammar Lens: a mark Romans did not need
<!-- hl-knowledge: introduces=[]; assesses=[LA-SKILL-READ-WORDS] -->

[PAUSE 2s] The line over a vowel is a **macron**. Ancient Romans normally did
not write one. This book does because vowel length can distinguish words and
because a beginning reader deserves to see what a careful speaker says.

[PAUSE 2s] So the mark is not decoration and it is not an accent. In **salvē**
and **valē**, it asks you to hold the final vowel. In **grātiās**, it does the
same job twice.
