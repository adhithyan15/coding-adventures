## You'll want to know: ശരിക്കും
<!-- hl-knowledge: introduces=[ML-LEX-C122-REPLIES-01]; assesses=[] -->

**ശരിക്കും** (*śarikkuṁ*) — "really, truly", built on **ശരി** (*śari*), "right, okay".
**ശരിക്കും?** — "really?".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

Okay, turned into really.
