# போர்வீரர் (pōrvīrar) — a soldier; a warrior

## You'll want to know: போர்வீரர்
<!-- hl-knowledge: introduces=[TA-LEX-C333-KALAM333-02]; assesses=[] -->

**போர்வீரர்** — *pōrvīrar* — "a soldier; a warrior".

> போர்வீரர்கள் வரிசையாக நின்றார்கள்.
>
> *pōrvīrarkaḷ varicaiyāka niṉṟārkaḷ.*
>
> The soldiers stood in rows.

Plural போர்வீரர்கள்.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**போர்வீரர்** (*pōrvīrar*) joins native போர், "battle" (DEDR 4540), with வீரர், from Sanskrit *vīra*, "man, hero" (CDIAL 12056).
