# ಕುರುಹು (kuruhu) — a trace; a clue

## You'll want to know: ಕುರುಹು
<!-- hl-knowledge: introduces=[KA-LEX-C326-KANE326-03]; assesses=[] -->

**ಕುರುಹು** — *kuruhu* — "a trace; a clue".

> ಕಳ್ಳ ಯಾವ ಕುರುಹೂ ಬಿಡಲಿಲ್ಲ.
>
> *kaḷḷa yāva kuruhū biḍalilla.*
>
> The thief left no trace.

ಕುರುಹು ಬಿಡು, to leave a trace; ಕುರುಹು ಸಿಗು, to find a clue.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಕುರುಹು** (*kuruhu*) is native Dravidian: DEDR 1847 lists Kannada *kuṟuhu*, "a mark, a sign, a token", beside *kuṟi*, "a mark, an aim". The verb ಗುರುತಿಸು belongs to the same root.
