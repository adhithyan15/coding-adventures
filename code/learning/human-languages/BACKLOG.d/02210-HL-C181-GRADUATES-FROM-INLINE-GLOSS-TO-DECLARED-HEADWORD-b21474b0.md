## HL-C181 — साँझ graduates from inline gloss to declared headword

The ranked Hindi review kept four learner-facing candidates. **साँझ** was the
cleanest first repair because no new prose or concept was needed: chapter 32
already defines it as the tadbhava doublet of **संध्या**, contrasts its register,
asks the learner to say it, and assesses the distinction under
`HI-CONCEPT-C32-SHUBH-SANDHYA-02`.

The defect was metadata. The lesson headword named only **शुभ संध्या**, so the
new report truthfully saw **साँझ** seven times in learner-facing text and never
in a declared headword. The headword now reads **शुभ संध्या / साँझ**. This is a
promotion into the declared teaching surface, not a duplicate lesson.

The next tranche should compare **मुझे**, **ऋतु**, and **काम** the same way:
first ask whether the owning lesson already teaches and assesses the form, then
repair metadata when that is the whole gap or add a lesson only when it is not.
