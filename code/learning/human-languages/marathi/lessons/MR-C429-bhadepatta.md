# भाडेपट्टा (bhāḍepaṭṭā) — a lease

## You'll want to know: भाडेपट्टा
<!-- hl-knowledge: introduces=[MR-LEX-C429-LILAV429-05]; assesses=[] -->

**भाडेपट्टा** — *bhāḍepaṭṭā* — "a lease".

> त्यांनी जमीन दहा वर्षांच्या भाडेपट्ट्याने दिली.
>
> *tyānnī jamīn dahā varṣāñcyā bhāḍepaṭṭyāne dilī.*
>
> They gave the land on a ten-year lease.

Masculine.

भाडेपट्ट्याने, on lease; पट्टा here is a written deed.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**भाडेपट्टा** (*bhāḍepaṭṭā*) is built from **भाडे**, "rent", and *paṭṭā*, "a strip; a written deed"; the origin of भाडे is not settled.
