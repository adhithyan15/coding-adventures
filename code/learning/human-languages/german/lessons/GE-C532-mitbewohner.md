## You'll want to know: der Mitbewohner
<!-- hl-knowledge: introduces=[GE-LEX-C532-WG-02]; assesses=[] -->

**der Mitbewohner** — "flatmate".

> Mein Mitbewohner kocht jeden Abend Nudeln.
>
> *My flatmate cooks pasta every evening.*

Plural: *die Mitbewohner*. A woman is *die Mitbewohnerin*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*Mitbewohner* is built on *mit* "with" and *Bewohner* "resident", from *bewohnen* "to live in" (EtymDB), built on *wohnen*.
