## You'll want to know: el capítulo
<!-- hl-knowledge: introduces=[ES-LEX-C565-ESCENA-03]; assesses=[] -->

**el capítulo** — "the chapter; the episode".

> Leí el último capítulo anoche.
>
> *I read the last chapter last night.*

On television it is an episode: *el primer capítulo*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*capítulo* is a learned borrowing from Late Latin *capitulum* 'a little head, a heading' (EtymDB), from *caput* 'head'.
