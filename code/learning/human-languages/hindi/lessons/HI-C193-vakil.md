**वकील** — *vakīl* — "a lawyer".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**वकील** (*vakīl*) is a loan from Arabic *wakīl*, "an agent, a representative", which reached Hindi through Persian. Its Arabic root is *w-k-l* (Lane).
