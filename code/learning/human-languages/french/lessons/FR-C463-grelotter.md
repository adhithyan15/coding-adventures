## You'll want to know: grelotter
<!-- hl-knowledge: introduces=[FR-LEX-C463-FROID-05]; assesses=[] -->

**grelotter** — "to shiver (with cold)".

> Sans manteau, le garçon grelotte à l'arrêt de bus.
>
> *Without a coat the boy is shivering at the bus stop.*

Only from cold.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*grelotter* is built on *grelot* 'small round bell' (EtymDB), usually explained by an old phrase about teeth that rattle like a little bell.
