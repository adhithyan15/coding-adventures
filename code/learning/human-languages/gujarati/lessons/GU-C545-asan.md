# આસાન (āsān) — effortless

## You'll want to know: આસાન
<!-- hl-knowledge: introduces=[GU-LEX-C545-AASAN545-01]; assesses=[] -->

**આસાન** — *āsān* — "effortless".

> જો તમે આ રીત વાપરશો તો કામ આસાન બનશે.
>
> *jo tame ā rīt vāparśo to kām āsān banśe.*
>
> If you use this method, the work will become easy.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**આસાન** (*āsān*) is usually traced to Persian *āsān*, "easy"; the everyday Gujarati word beside it is **સહેલું**.
