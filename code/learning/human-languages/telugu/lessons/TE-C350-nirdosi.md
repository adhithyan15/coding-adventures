# నిర్దోషి (nirdōṣi) — an innocent person

## You'll want to know: నిర్దోషి
<!-- hl-knowledge: introduces=[TE-LEX-C350-NERAM350-04]; assesses=[] -->

**నిర్దోషి** — *nirdōṣi* — "an innocent person".

> చివరికి అతను నిర్దోషి అని తేలింది.
>
> *civariki atanu nirdōṣi ani tēlindi.*
>
> In the end he turned out to be innocent.

నిర్-, without, and దోషి: one without fault.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**నిర్దోషి** (*nirdōṣi*) is built on Sanskrit *nirdoṣa*, "faultless, guiltless, innocent" (Monier-Williams), in the shape of దోషి.
