## You'll want to know: 可见
<!-- hl-knowledge: introduces=[ZH-LEX-C365-YESBUT365-03]; assesses=[] -->

**可见** — *kějiàn* — "which goes to show; so it is clear that".

> **他每天都准时来可见他很喜欢这儿** *tā měitiān dōu zhǔnshí lái kějiàn tā hěn xǐhuan zhèr* — He turns up on time every day, which shows he really likes it here.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**可见** (*kějiàn*) is built from 可 'can' and 见 'to see', both inherited from Middle Chinese, *khaX* and *kenH* (Guangyun, in Baxter's transcription), which glosses the first 'to permit' and the second 'to see'.
