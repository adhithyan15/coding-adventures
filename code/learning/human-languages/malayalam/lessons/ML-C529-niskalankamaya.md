## You'll want to know: നിഷ്കളങ്കമായ
<!-- hl-knowledge: introduces=[ML-LEX-C529-VIVEKAM529-03]; assesses=[] -->

**നിഷ്കളങ്കമായ** — *niṣkaḷaṅkamāya* — "guileless; innocent".

> കുഞ്ഞിന്റെ നിഷ്കളങ്കമായ ചിരി എല്ലാവർക്കും ഇഷ്ടപ്പെട്ടു.
>
> *kuññinṟe niṣkaḷaṅkamāya ciri ellāvarkkuṁ iṣṭappeṭṭu.*
>
> Everyone loved the baby's innocent smile.

നിഷ്- without + കളങ്കം a stain: without a stain, guileless.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**നിഷ്കളങ്കമായ** (*niṣkaḷaṅkamāya*) is built from Sanskrit *niṣkalaṅka*, "stainless, spotless" (Monier-Williams), with the Malayalam adjective ending -ആയ.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
