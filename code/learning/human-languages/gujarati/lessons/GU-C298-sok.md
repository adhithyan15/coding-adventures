# શોક (śok) — mourning; grief

## You'll want to know: શોક
<!-- hl-knowledge: introduces=[GU-LEX-C298-MRUTYU298-02]; assesses=[] -->

**શોક** — *śok* — "mourning; grief".

> આખા ગામમાં શોક છે.
>
> *ākhā gāmmā̃ śok che.*
>
> The whole village is in mourning.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**શોક** (*śok*) is a tatsama, Sanskrit *śoka*, "burning, sorrow" (Monier-Williams). It is grief that is shared and shown: **શોક પાળવો**, to keep mourning.
