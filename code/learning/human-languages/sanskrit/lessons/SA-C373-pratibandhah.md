# प्रतिबन्धः (pratibandhaḥ) — a restriction; an impediment

## You'll want to know: प्रतिबन्धः
<!-- hl-knowledge: introduces=[SA-LEX-C373-ANUMATI373-03]; assesses=[] -->

**प्रतिबन्धः** — *pratibandhaḥ* — "a restriction; an impediment".

> यदि प्रतिबन्धः अस्ति, तर्हि कः अपि न प्रविशतु।
>
> *yadi pratibandhaḥ asti, tarhi kaḥ api na praviśatu.*
>
> If there is a restriction, let no one go in.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**प्रतिबन्धः** (*pratibandhaḥ*) is built on *prati* and the root √bandh, "to bind"; MW gives *prati-bandha* "an obstacle, a hindrance, an impediment", and "a restriction" is how modern Sanskrit uses it (MW).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
