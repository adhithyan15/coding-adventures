## You'll want to know: नैतिकता
<!-- hl-knowledge: introduces=[MR-LEX-C366-MULYA366-02]; assesses=[] -->

**नैतिकता** — *naitiktā* — "morality; ethics".

> व्यापारातही नैतिकता पाळली पाहिजे.
>
> *vyāpārāthī naitiktā pāḷlī pāhije.*
>
> Ethics should be observed in trade too.

Feminine.

नैतिक, moral, + -ता.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**नैतिकता** (*naitiktā*) is a learned word built on Sanskrit *nīti*, "conduct, guidance" (CDIAL 7546), through the adjective नैतिक, "moral", with *-tā*, "-ness".
