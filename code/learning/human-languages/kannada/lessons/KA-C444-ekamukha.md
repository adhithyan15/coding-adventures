# ಏಕಮುಖ (ēkamukha) — one-way

## You'll want to know: ಏಕಮುಖ
<!-- hl-knowledge: introduces=[KA-LEX-C444-NIYAMA444-05]; assesses=[] -->

**ಏಕಮುಖ** — *ēkamukha* — "one-way".

> ಇದು ಏಕಮುಖ ರಸ್ತೆ, ಆ ಕಡೆಯಿಂದ ಬರಬಾರದು.
>
> *idu ēkamukha raste, ā kaḍeyinda barabāradu.*
>
> This is a one-way road; nobody may come from that side.

ಏಕ, one, plus ಮುಖ, face: facing one way.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಏಕಮುಖ** (*ēkamukha*) is built from two Sanskrit words: *ēka*, "one" (CDIAL 2462), and *mukha*, "mouth, face, entrance" (CDIAL 10158).
