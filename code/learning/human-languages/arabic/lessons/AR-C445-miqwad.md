## You'll want to know: مقود
<!-- hl-knowledge: introduces=[AR-LEX-C445-TRAM445-03]; assesses=[] -->

**مقود** — *miqwad* — "a steering wheel".

> أمسك أبي المقود بقوة.
>
> *amsaka abī al-miqwad bi-quwwa.*
>
> My father held the steering wheel tightly.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**مقود** (*miqwad*) is built on the native Arabic root *q-w-d*, "to lead" (Lane). The tool pattern *mifʿal* makes it the thing one steers with.
