## You'll want to know: relampejar
<!-- hl-knowledge: introduces=[PT-LEX-C463-TROVOADA-03]; assesses=[] -->

**relampejar** — "to flash with lightning".

> Relampeja muito longe, no mar.
>
> *There is lightning far away, over the sea.*

Built on *o relâmpago*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*relampejar* is built on *relâmpago* 'lightning', which goes back to Latin *lampas* 'torch, light' (EtymDB).
