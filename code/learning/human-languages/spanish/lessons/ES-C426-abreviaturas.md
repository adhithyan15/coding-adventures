# las abreviaturas — the short forms a letter opens with

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ES-ORTH-C424-08] -->

[PAUSE 2s] You know that **c/** on an address is *calle*. Say it. That slash was
your first abbreviation; this lesson gives you the rest of the set.

## The word, taken apart
<!-- hl-knowledge: introduces=[ES-ORTH-C426-03]; assesses=[] -->

**una abreviatura** — "an abbreviation": a word written short, and **always
closed with a point**.

The forms of address are the ones an A1 paper prints:

| short | full | |
|---|---|---|
| Sr. | señor | Mr |
| Sra. | señora | Mrs |
| Srta. | señorita | Miss |
| D. | don | a courtesy title before a first name |
| Dña. | doña | its feminine |
| Dr. | doctor | |

The point is not decoration. **Sr** without it is an error, because the point is
what marks the word as shortened.

## Grammar Lens: don and señor are not the same word
<!-- hl-knowledge: introduces=[]; assesses=[ES-ORTH-C426-03, ES-ORTH-C426-02] -->

The distinction is one an English speaker has no equivalent for:

| | goes before | example |
|---|---|---|
| señor | the **surname** | el Sr. García |
| don | the **first name** | D. Pedro |

*Don Pedro* is respectful and warm; *Señor García* is respectful and formal.
Putting them the wrong way round — *don García* — sounds wrong to a Spanish ear
in the way *Mr. Peter* does to an English one.

Two more an address prints, both of which you can now read: **c/** for *calle*
and **n.º** for *número*.
