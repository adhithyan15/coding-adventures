## You'll want to know: chuánrǎn
<!-- hl-knowledge: introduces=[ZH-LEX-C245-MASK245-02]; assesses=[] -->

*chuánrǎn* — "to pass on (an illness); to be catching".

> *yīnwèi gǎnmào huì chuánrǎn suǒyǐ wǒ bú qù shàngbān* — Colds are catching, so I'm not going in to work.

Its characters come later; for now it is a word for the ear.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*chuánrǎn* is built from *chuán* 'to pass on' and *rǎn* 'to dye', both inherited from Middle Chinese, *drjwen* and *nyemX* (Guangyun, in Baxter's transcription), which glosses the first 'to turn' and the second 'to dye'.
