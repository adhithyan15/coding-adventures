# അടയുക (aṭayuka) — to get blocked; to be shut

## You'll want to know: അടയുക
<!-- hl-knowledge: introduces=[ML-LEX-C516-TATASSAM516-03]; assesses=[] -->

**അടയുക** — *aṭayuka* — "to get blocked; to be shut".

> ചവറ് കാരണം തോടുകൾ അടഞ്ഞു.
>
> *cavaṟŭ kāraṇaṁ tōṭukaḷ aṭaññu.*
>
> Because of the litter, the streams got blocked.

Past: അടഞ്ഞു, *aṭaññu*.

The intransitive partner of അടയ്ക്കുക, to close: a road, a drain or a nose gets blocked.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**അടയുക** (*aṭayuka*) is native Dravidian, "to be shut, to be blocked up" (DEDR 83).
