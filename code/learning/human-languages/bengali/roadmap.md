# Bengali Roadmap

Same shape as the other tracks: deep one-word lessons in themed chapters.
Slug-identified; order lives in the book and
[`session-map.md`](./session-map.md). See
[`HL00`](../../../specs/HL00-human-language-curriculum-framework.md).

Grounding: English + Sanskrit, with the wider Indo-European family drawn in where
it reaches. The recurring thread is Bengali's **sound-fingerprint** — inherent
vowel **ô** (not "a"), *s→sh*, *v→b* — which disguises familiar Sanskrit words;
the learner is taught to un-shift them. The script is taught **inline**, never as
a gated reading course.

## Authored

- **Ch. 1 — Greetings**: nômoshkar → dhônyobad → hyã/nā → āchchhā → āshi →
  practice. Bengali script introduced through the words; the sound-fingerprint
  foregrounded.

## Planned

| Chapter | Theme |
|---|---|
| 2 | Introducing yourself: *āmār nām…* ("my name"), *tumi* / *āpni* (familiar / respectful "you"), and *tui* (intimate) — Bengali's three-way "you" |
| 3 | Responding: *kemon āchho?* ("how are you"), *bhālo āchhi* ("I'm well"), the verb *āchhā* ("to be / to exist") |
| 4 | Postpositions, numbers 1–10, the vowel-harmony that colours Bengali verbs |
| 5+ | Verbs without gender (a Bengali simplification), family, food — always tracing the sound-shift back to Sanskrit |

Note: Bengali marks "you" **three** ways by register — *tui* (intimate) / *tumi*
(familiar) / *āpni* (respectful) — a finer distinction than the two-way split of
the Romance and other Indo-Aryan tracks. Introduced in Chapter 2.
