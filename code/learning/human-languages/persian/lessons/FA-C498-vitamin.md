## You'll want to know: ویتامین
<!-- hl-knowledge: introduces=[FA-LEX-C498-WEIGHT-04]; assesses=[] -->

**ویتامین** (*vitâmin*) — "a vitamin".

> پرتقال ویتامین زیادی دارد.
>
> *porteqâl vitâmin-e ziyâdi dârad.*
>
> Oranges have a lot of vitamins.

Plural *vitâminhâ*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*vitâmin* is a modern loan, usually traced to French *vitamine*. EtymDB has no entry for the Persian word.
