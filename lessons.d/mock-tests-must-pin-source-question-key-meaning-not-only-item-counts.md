# Mock tests must pin source-question-key meaning, not only item counts and label diversity

The first Sanskrit B1 mock test verified item counts, source-length bands, key
numbering, and a balanced spread of A/B/C labels, yet four listening keys still
contradicted their question options and recording masters. Those structural
checks could prove that every slot existed, but not that a learner who understood
the source would receive the mark. Correct each key from the source evidence and
add fail-closed regression assertions that pin the exact question, the decisive
source phrase, and the expected keyed label together. Future mock tests should
cover representative or review-discovered source-question-key triples explicitly;
label distributions are only a secondary guard and never semantic validation.
