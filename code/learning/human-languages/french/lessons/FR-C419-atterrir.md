## You'll want to know: atterrir
<!-- hl-knowledge: introduces=[FR-LEX-C419-DECOLLAGE-04]; assesses=[] -->

**atterrir** — "to land".

> Nous avons atterri sous la pluie.
>
> *We landed in the rain.*

Conjugated like *finir*: *nous atterrissons*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*atterrir* is built from *à* and *terre* 'land', which is inherited from Latin *terra* (Lewis & Short); EtymDB lists the verb without a source.
