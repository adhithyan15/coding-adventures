# أحزن (aḥzana) — to sadden

## You'll want to know: أحزن
<!-- hl-knowledge: introduces=[AR-LEX-C498-ATHAR498-02]; assesses=[] -->

**أحزن** — *aḥzana* — "to sadden".

> أحزن الفيلم كل الناس.
>
> *aḥzana al-fīlm kull an-nās.*
>
> The film saddened everyone.

Present: يحزن, *yuḥzin*.

Read the present يحزن as yuḥzin here, yaḥzan for to be sad.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**أحزن** (*aḥzana*) is built on the native Arabic root *ḥ-z-n*, "grief, sadness" (Lane). It is Form IV: to cause grief.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
