## You'll want to know: واکنش
<!-- hl-knowledge: introduces=[FA-LEX-C372-TASIR-05]; assesses=[] -->

**واکنش** (*vâkonesh*) — "a reaction".

> واکنش مادرم به این خبر جالب بود.
>
> *vâkonesh-e mâdaram be in khabar jâleb bud.*
>
> My mother's reaction to this news was interesting.

A modern Persian coinage: *vâ-* "back" + *konesh* "action". *Vâkonesh neshân dâdan* — to react.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**واکنش** is a modern native coinage built from *vâ-* "back, again" + *konesh* "action", built on *kon-*, the present stem of *kardan* "to do". A reaction is an action back.
