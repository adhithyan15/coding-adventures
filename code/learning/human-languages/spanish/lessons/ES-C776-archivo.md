## You'll want to know: el archivo
<!-- hl-knowledge: introduces=[ES-LEX-C776-CLAVE-02]; assesses=[] -->

**el archivo** — "the file; the archive".

> Si el archivo es muy grande, no se puede enviar.
>
> *If the file is very big, it can't be sent.*

*Un archivo adjunto* — an attachment.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*archivo* is a learned borrowing from Late Latin *archīvum* 'the archives' (Lewis & Short), which comes from Greek *archeîon* 'a town hall' (EtymDB).
