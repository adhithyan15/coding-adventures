# ஆணையிடு (āṇaiyiṭu) — to command; to order

## You'll want to know: ஆணையிடு
<!-- hl-knowledge: introduces=[TA-LEX-C384-AVACIYAM384-05]; assesses=[] -->

**ஆணையிடு** — *āṇaiyiṭu* — "to command; to order".

> நீதிபதி அவரை விடுதலை செய்யுமாறு ஆணையிட்டார்.
>
> *nītipati avarai viṭutalai ceyyumāṟu āṇaiyiṭṭār.*
>
> The judge ordered him to be set free.

Past (I …): ஆணையிட்டேன், *āṇaiyiṭṭēṉ*.

The action takes -உமாறு: செல்லுமாறு ஆணையிடு, to order someone to go.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ஆணையிடு** (*āṇaiyiṭu*) is built from *āṇai*, "command", borrowed from Sanskrit *ājñā* (CDIAL 1095), whose Prakrit form is *āṇā*, and native *iṭu*, "to put" (DEDR 442).
