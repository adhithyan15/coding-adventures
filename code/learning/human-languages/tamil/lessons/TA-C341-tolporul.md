# தொல்பொருள் (tolporuḷ) — an antiquity; an ancient object

## You'll want to know: தொல்பொருள்
<!-- hl-knowledge: introduces=[TA-LEX-C341-AGAZHVU341-02]; assesses=[] -->

**தொல்பொருள்** — *tolporuḷ* — "an antiquity; an ancient object".

> அருங்காட்சியகத்தில் பல தொல்பொருள்கள் இருக்கின்றன.
>
> *aruṅkāṭciyakattil pala tolporuḷkaḷ irukkiṉṟaṉa.*
>
> There are many antiquities in the museum.

தொல், ancient + பொருள், thing.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**தொல்பொருள்** (*tolporuḷ*) is a Tamil compound built from தொல், "old, ancient" (DEDR 3516), and பொருள், "thing" (DEDR 4544).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
