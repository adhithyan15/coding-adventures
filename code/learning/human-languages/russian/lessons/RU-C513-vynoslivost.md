## You'll want to know: выносливость
<!-- hl-knowledge: introduces=[RU-LEX-C513-TRAINING-05]; assesses=[] -->

**выносливость** (*vynóslivost*) — "stamina, endurance".

> Для марафона нужна выносливость.
>
> *Dlya marafóna nuzhná vynóslivost.*
>
> You need stamina for a marathon.

Feminine. Built on *выносливый* — tough, hardy.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*выносливость* is built on *выносливый* 'hardy', from *выносить* 'to bear, to endure' and *носить* 'to carry'; EtymDB has no entry.
