# കല്യാണം (kalyāṇaṁ) — wedding

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C125-KIN-05, ML-LEX-C126-ABOUTYOU-01] -->

[PAUSE 2s] Before the new one: say the Malayalam for a nephew, then the Malayalam for address.

## You'll want to know: കല്യാണം
<!-- hl-knowledge: introduces=[ML-LEX-C126-ABOUTYOU-02]; assesses=[] -->

**കല്യാണം** (*kalyāṇaṁ*) — "wedding". **കല്യാണത്തിന് ക്ഷണം** — "an invitation to a wedding",
with **ക്ഷണം** from the welcome chapter.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**കല്യാണം** (*kalyāṇaṁ*) ← Sanskrit *kalyāṇa*, "beautiful, auspicious", taken over whole as a tatsama, with Malayalam's noun ending *-ṁ* (CDIAL 2952). An auspicious event became the name of the wedding.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

The biggest invitation of all.
