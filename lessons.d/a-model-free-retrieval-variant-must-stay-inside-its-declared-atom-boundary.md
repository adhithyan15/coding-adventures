# A model-free retrieval variant must stay inside its declared atom boundary

A terminal retrieval asked the learner to understand “one hundred rupees” to
vary an earlier twenty-rupee exchange, but the lesson declared only the atom
for twenty. Because the test derived its expected atoms from the same narrow
list, the prompt crossed the knowledge boundary without failing locally.

Variation in an independent prompt must come from already declared atoms. If a
new number, noun, or inflection is pedagogically necessary, add its atom to the
lesson boundary and pin it independently; otherwise vary only the scenario and
keep the language inside the owned set.
