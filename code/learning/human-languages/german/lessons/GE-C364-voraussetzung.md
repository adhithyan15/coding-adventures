## You'll want to know: die Voraussetzung
<!-- hl-knowledge: introduces=[GE-LEX-C364-BEDINGUNG-02]; assesses=[] -->

**die Voraussetzung** — "the precondition, the requirement".

> Gute Deutschkenntnisse sind eine Voraussetzung für die Stelle.
>
> *A good knowledge of German is a requirement for the job.*

Plural: *die Voraussetzungen*. *Unter der Voraussetzung, dass …* — provided that …

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*Voraussetzung* is the noun of *voraussetzen*, built from *voraus* "ahead" and *setzen* "to set", Proto-Germanic *satjaną* (EtymDB): what is set in place beforehand.
