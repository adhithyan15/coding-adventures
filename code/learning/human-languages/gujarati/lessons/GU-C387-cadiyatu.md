# ચડિયાતું (caḍiyātũ) — superior

## You'll want to know: ચડિયાતું
<!-- hl-knowledge: introduces=[GU-LEX-C387-BAHETAR387-03]; assesses=[] -->

**ચડિયાતું** — *caḍiyātũ* — "superior".

> જો તમે રોજ કસરત કરશો તો તમે બીજા ખેલાડીઓ કરતાં ચડિયાતા થશો.
>
> *jo tame roj kasrat karśo to tame bījā khelāḍīo kartā̃ caḍiyātā thaśo.*
>
> If you exercise every day, you will be better than the other players.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ચડિયાતું** (*caḍiyātũ*) is built on *caḍvũ*, "to climb, to rise", the same verb as **ચઢવું** (*caḍhvũ*), from a reconstructed *caḍhati*, "rises" (CDIAL 4578): one who has climbed higher.
