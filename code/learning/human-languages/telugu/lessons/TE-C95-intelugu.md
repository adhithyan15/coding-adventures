## You'll want to know: తెలుగులో
<!-- hl-knowledge: introduces=[TE-LEX-C95-ASK-01]; assesses=[] -->

**తెలుగులో** (*telugulō*) — "in Telugu".

It is **తెలుగు** with **-లో**, "in", the ending you met on **ఉండు**. Any language takes it:
**ఇంగ్లీషులో**, "in English".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

A way to name the language you want an answer in.
