# பேரழிவு (pēraḻivu) — a disaster

## You'll want to know: பேரழிவு
<!-- hl-knowledge: introduces=[TA-LEX-C302-AZHIVU302-01]; assesses=[] -->

**பேரழிவு** — *pēraḻivu* — "a disaster".

> வெள்ளம் ஒரு பேரழிவாக மாறியது.
>
> *veḷḷam oru pēraḻivāka māṟiyatu.*
>
> The flood turned into a disaster.

பேர்- before a noun means great.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**பேரழிவு** (*pēraḻivu*) is a Tamil compound built from பேர், "great" (DEDR 4411), and அழிவு, "destruction, ruin" (DEDR 277).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
