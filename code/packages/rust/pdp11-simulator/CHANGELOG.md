# Changelog

## 0.1.0 — 2026-08-27

- Add a complete Rust functional simulator for the repository's DEC PDP-11
  Spec 07o surface.
- Support all eight addressing modes, word and byte ALU families, 15 branch
  conditions, JSR/RTS/RTI, SOB, HALT, and NOP.
- Add typed failures, bounded execution, immutable snapshots, encoders, and
  Python-oracle conformance vectors.
