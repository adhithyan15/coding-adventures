# ਚ — the quiet twin of ਛ

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-SCRIPT-CHHA-01, PA-LEX-CHANGA, PA-SCRIPT-RECOG-CHA-01] -->

[PAUSE 2s] Write **ਛ** once from memory and say *chha*, with the puff of
breath. Then say *changā* aloud. The first sound of *changā* is the same
mouth-shape with the puff taken away.

## Script — one letter
<!-- hl-knowledge: introduces=[PA-SCRIPT-CHA-01]; assesses=[PA-SCRIPT-CHHA-01] -->

Trace **ਚ** twice and say *cha*. Set it beside **ਛ** once and look at what
separates them: Gurmukhi writes the breath as an extra stroke, so a heavier
shape means a heavier puff of air.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-SCRIPT-CHA-01, PA-SCRIPT-CHHA-01] -->
<!-- hl-writing-stage: observe-trace -->

Cover both models. Write **ਚ**, then **ਛ**. Compare only which one carries the
extra stroke.
