# பிரச்சாரம் (piraccāram) — a campaign

## You'll want to know: பிரச்சாரம்
<!-- hl-knowledge: introduces=[TA-LEX-C374-TERTAL374-05]; assesses=[] -->

**பிரச்சாரம்** — *piraccāram* — "a campaign".

> வேட்பாளர்கள் வீடு வீடாகப் பிரச்சாரம் செய்தார்கள்.
>
> *vēṭpāḷarkaḷ vīṭu vīṭākap piraccāram ceytārkaḷ.*
>
> The candidates campaigned from house to house.

பிரச்சாரம் செய், to campaign.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**பிரச்சாரம்** (*piraccāram*) is borrowed from Sanskrit *pracāra*, "coming forth, currency, prevalence" (Monier-Williams): spreading a message about.

## What you've built
