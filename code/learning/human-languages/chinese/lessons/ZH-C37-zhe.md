# 这 (zhè) — this

## You'll want to know: 这
<!-- hl-knowledge: introduces=[ZH-LEX-C37-THIS37-01]; assesses=[] -->

**这** — *zhè* — "this".

> **这是我的书** *zhè shì wǒ de shū* — This is my book.

The new character, in pieces: 这 — 文, from 中文, and a walking piece that runs under it from the left. The next lesson puts it in your hand.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**这** (*zhè*) is written with an old character that the Guangyun records as *ngjenH* (Guangyun, in Baxter's transcription), glossed 'to meet'. That is a different word: *ngjenH* would not become zhè. How the character came to write the word for this is not settled.
