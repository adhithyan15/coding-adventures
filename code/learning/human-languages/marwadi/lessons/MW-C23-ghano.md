# घणो — very, on the page

## Warm-up
<!-- hl-knowledge: introduces=[MW-SCRIPT-GHANO-01]; assesses=[MW-LEX-GHANO-01, MW-SCRIPT-GHAR-01, MW-LEX-GHEE-01, MW-SCRIPT-GHEE-01] -->

[PAUSE 20s] Say *very*, then write home and clarified butter.

## You'll want to know
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-GHA-01, MW-SCRIPT-NNA-01, MW-SCRIPT-O-MATRA-01, MW-SCRIPT-KITNO-01] -->

> **घ** + **णो** → **घणो** — *ghaṇo* — very

Three signs, none of them new. Write **घर**, **घी**, and **घणो** one under the
other: the same **घ** opens all three. Then write **कितणो** beside **घणो** and
check the **णो** at the end is drawn the same way in both.
