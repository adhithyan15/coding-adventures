## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**صحة** (*ṣiḥḥa*) is built on the native Arabic root *ṣ-ḥ-ḥ*, "to be sound, healthy" (Lane). *Ṣiḥḥa* is soundness, health.
