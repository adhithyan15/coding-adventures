# ೩ — the digit for mūru

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-SCRIPT-RECOG-141] -->

[PAUSE 1s] Before the new shape: **೨** — which number is it?

[PAUSE 2s] One digit this time, and you already know its name.

## Script you'll notice: ೩
<!-- hl-knowledge: introduces=[KA-SCRIPT-RECOG-142]; assesses=[] -->

**೩** — **3**, the digit for **ಮೂರು** (*mūru*), "three".

The digits behave exactly like the ones you grew up with: ten shapes, and
place value doing the rest.

## Writing: ೩ — copy what you see
<!-- hl-knowledge: introduces=[]; assesses=[KA-SCRIPT-RECOG-142] -->

Put your pen on ೩ and follow its line. Copy the shape in front of you —
slowly, and larger than it is printed.

> This book does not yet tell you **where to start the character or which way to
> travel**. That is taught with real variation from school to school, and it is
> not written down here until it can be written down with a source. Copying what
> you can see needs no such source.
