# Hear *mandir* — temple

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MW-LEX-GHAR-01, MW-LEX-BAJAR-01, MW-SCRIPT-JA-01, MW-SCRIPT-NNA-01, MW-LEX-NANI-01] -->

retroflex **ण**.

## You'll want to know
<!-- hl-knowledge: introduces=[MW-LEX-MANDIR-01]; assesses=[] -->

> *mandir* — **temple**

Say the three short sound groups. The complete spelling uses only earned signs,
but meaning stays first.
