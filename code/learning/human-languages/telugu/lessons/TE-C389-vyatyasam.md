# వ్యత్యాసం (vyatyāsaṁ) — a distinction; a contrast

## You'll want to know: వ్యత్యాసం
<!-- hl-knowledge: introduces=[TE-LEX-C389-VISLESANA389-05]; assesses=[] -->

**వ్యత్యాసం** — *vyatyāsaṁ* — "a distinction; a contrast".

> రెండు ధరల మధ్య పెద్ద వ్యత్యాసం ఉంది.
>
> *reṇḍu dharala madhya pedda vyatyāsaṁ undi.*
>
> There is a big difference between the two prices.

Formal beside తేడా, which you know.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**వ్యత్యాసం** (*vyatyāsaṁ*) is borrowed from Sanskrit *vyatyāsa*, "exchange; change, inverted order" (Monier-Williams). Telugu uses it for the difference between two things.
