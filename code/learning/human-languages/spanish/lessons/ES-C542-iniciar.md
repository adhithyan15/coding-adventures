## You'll want to know: iniciar
<!-- hl-knowledge: introduces=[ES-LEX-C542-COMIENZO-02]; assesses=[] -->

**iniciar** — "to launch, to start, to begin".

> La policía inició una investigación.
>
> *The police started an investigation.*

Formal; common in the news. *Iniciar sesión* — to log in.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*iniciar* is a learned borrowing from Latin *initiāre* 'to begin, to initiate' (EtymDB), built on *initium* 'a going in, a beginning'.
