## You'll want to know: نزلہ
<!-- hl-knowledge: introduces=[UR-LEX-C469-THROAT469-05]; assesses=[] -->

**نزلہ** — *nazlā* — "catarrh; a running cold".

> سردی میں اسے نزلہ ہو گیا۔
>
> *sardī meṅ use nazlā ho gayā.*
>
> In the cold weather she caught a streaming cold.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**نزلہ** (*nazlā*) is usually traced, through Persian, to Arabic *nazla*, "a flowing down", and so a running cold.
