## You'll want to know: ಸಹಾಯಕ
<!-- hl-knowledge: introduces=[KA-LEX-C519-HANAKASU519-03]; assesses=[] -->

**ಸಹಾಯಕ** — *sahāyaka* — "an assistant; a helper".

> ವೈದ್ಯರ ಸಹಾಯಕ ನನ್ನ ಹೆಸರು ಕೇಳಿದನು.
>
> *vaidyara sahāyaka nanna hesaru kēḷidanu.*
>
> The doctor's assistant asked my name.

Plural: ಸಹಾಯಕರು, *sahāyakaru*.

Built on ಸಹಾಯ, help, as in ಸಹಾಯ ಮಾಡು.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಸಹಾಯಕ** (*sahāyaka*) is borrowed from Sanskrit *sahāyaka*, the same as *sahāya*, "companion, helper" (CDIAL 13309).
