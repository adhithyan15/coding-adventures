# అదేవిధంగా (adēvidhaṅgā) — likewise; in the same way

## You'll want to know: అదేవిధంగా
<!-- hl-knowledge: introduces=[TE-LEX-C396-VIRUDDHAM396-05]; assesses=[] -->

**అదేవిధంగా** — *adēvidhaṅgā* — "likewise; in the same way".

> అన్న బాగా చదివాడు, అదేవిధంగా చెల్లి కూడా.
>
> *anna bāgā cadivāḍu, adēvidhaṅgā celli kūḍā.*
>
> The elder brother studied hard, and likewise the younger sister.

అదే, that very, + విధం, a way, + -గా.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**అదేవిధంగా** (*adēvidhaṅgā*) is built from native *adē*, "that very", on the far-pointing base *a-* (DEDR 1), and *vidhaṁ*, "a manner", from Sanskrit *vidha* (Monier-Williams), with the adverb ending -గా.
