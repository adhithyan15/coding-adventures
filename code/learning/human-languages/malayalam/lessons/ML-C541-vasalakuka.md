# വഷളാകുക (vaṣaḷākuka) — to get worse; to worsen

## You'll want to know: വഷളാകുക
<!-- hl-knowledge: introduces=[ML-LEX-C541-DAHANAM541-02]; assesses=[] -->

**വഷളാകുക** — *vaṣaḷākuka* — "to get worse; to worsen".

> ചികിത്സ വൈകിയതുകൊണ്ട് രോഗം വഷളായി.
>
> *cikitsa vaikiyatukoṇṭŭ rōgaṁ vaṣaḷāyi.*
>
> The illness got worse because treatment was late.

Past: വഷളായി, *vaṣaḷāyi*.

വഷളാക്കുക is to make worse, or to spoil a child.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**വഷളാകുക** (*vaṣaḷākuka*) is an everyday word; no source we can open explains it, so its origin is not settled.
