## You'll want to know: സുഖമില്ല
<!-- hl-knowledge: introduces=[ML-LEX-C115-UNWELL-05]; assesses=[] -->

**സുഖമില്ല** (*sukhamilla*) — "(I'm) not well", **സുഖം** (*sukhaṁ*), "well-being",
with **ഇല്ല** (*illa*), "there isn't". It answers **സുഖമാണോ?**, "are you well?".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

The honest answer to sukhamāṇō.
