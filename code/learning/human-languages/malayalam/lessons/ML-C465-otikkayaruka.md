# ഓടിക്കയറുക (ōṭikkayaṟuka) — to run and board

## You'll want to know: ഓടിക്കയറുക
<!-- hl-knowledge: introduces=[ML-LEX-C465-VARAVU465-05]; assesses=[] -->

**ഓടിക്കയറുക** — *ōṭikkayaṟuka* — "to run and board".

> തീവണ്ടി നീങ്ങുന്നതിന് മുൻപ് അവൻ ഓടിക്കയറി.
>
> *tīvaṇṭi nīṅṅunnatinŭ munpŭ avan ōṭikkayaṟi.*
>
> He ran and got on before the train moved off.

Past: ഓടിക്കയറി, *ōṭikkayaṟi*.

ഓടി, having run, plus കയറുക, to get in. The vehicle takes -ഇൽ: ബസിൽ ഓടിക്കയറി.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ഓടിക്കയറുക** (*ōṭikkayaṟuka*) is a native Dravidian compound of ഓടുക, to run (DEDR 1041), and കയറുക, to climb in (DEDR 1255).
