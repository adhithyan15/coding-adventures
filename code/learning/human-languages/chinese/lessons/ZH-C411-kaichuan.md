## You'll want to know: 开船
<!-- hl-knowledge: introduces=[ZH-LEX-C411-FERRY411-03]; assesses=[] -->

**开船** — *kāichuán* — "to set sail".

> **船长说十点开船** *chuánzhǎng shuō shí diǎn kāichuán* — The captain says we sail at ten.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**开船** (*kāichuán*) is built from 开 'to start off' and 船 'a boat', both inherited from Middle Chinese, *khoj* and *zywen* (Guangyun, in Baxter's transcription), which glosses the first 'to open'.
