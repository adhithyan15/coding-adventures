# കള്ളം (kaḷḷaṁ) — a lie; a falsehood

## You'll want to know: കള്ളം
<!-- hl-knowledge: introduces=[ML-LEX-C370-MOZHI370-03]; assesses=[] -->

**കള്ളം** — *kaḷḷaṁ* — "a lie; a falsehood".

> സാക്ഷി കോടതിയിൽ കള്ളം പറഞ്ഞു.
>
> *sākṣi kōṭatiyil kaḷḷaṁ paṟaññu.*
>
> The witness told a lie in court.

To lie is കള്ളം പറയുക, the same as നുണ പറയുക. കള്ളൻ, a thief, comes from the same root.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**കള്ളം** (*kaḷḷaṁ*) is native Dravidian: DEDR 1372 lists Malayalam *kaḷḷam*, "theft, untruth, false", from the root that also gives കള്ളൻ (*kaḷḷan*), "a thief".
