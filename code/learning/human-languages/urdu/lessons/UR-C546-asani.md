## You'll want to know: آسانی
<!-- hl-knowledge: introduces=[UR-LEX-C546-MASHAQQAT546-03]; assesses=[] -->

**آسانی** — *āsānī* — "ease".

> اگر نقشہ ہوتا تو ہم آسانی سے پہنچ جاتے۔
>
> *agar naqshā hotā to ham āsānī se pahuṅch jāte.*
>
> If we had a map, we would get there easily.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**آسانی** (*āsānī*) is usually traced to Persian *āsānī*, "ease", built on *āsān*, "easy".
