# ഒന്നുകൂടി (onnukūṭi) — once more

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C118-WEATHER-05, ML-LEX-C119-SLOWLY-01] -->

[PAUSE 2s] Before the new one: say the Malayalam for thunder and lightning, then the Malayalam for slowly.

## You'll want to know: ഒന്നുകൂടി
<!-- hl-knowledge: introduces=[ML-LEX-C119-SLOWLY-02]; assesses=[] -->

**ഒന്നുകൂടി** (*onnukūṭi*) — "once more", **ഒന്ന്** (*onnŭ*), "one", with **കൂടി**,
"also, more". **ഒന്നുകൂടി പറയൂ** — "say it once more".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One, and more.
