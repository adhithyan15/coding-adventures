## You'll want to know: लौहम्

**लौहम्** — *lauham* — "iron".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*lauha* is built from *loha* "red; copper; iron" with the first vowel strengthened (CDIAL 11172a): "made of metal", and so "iron". MW connects *loha* with a lost root meaning "be red", and CDIAL 11158 does too; *loha* lives on as Hindi *lohā* "iron".
