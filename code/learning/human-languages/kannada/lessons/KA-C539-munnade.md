# ಮುನ್ನಡೆ (munnaḍe) — a lead; an advance

## You'll want to know: ಮುನ್ನಡೆ
<!-- hl-knowledge: introduces=[KA-LEX-C539-SPARDHE539-04]; assesses=[] -->

**ಮುನ್ನಡೆ** — *munnaḍe* — "a lead; an advance".

> ಮೊದಲ ಅರ್ಧದಲ್ಲಿ ನಮ್ಮ ತಂಡ ಮುನ್ನಡೆ ಪಡೆಯಿತು.
>
> *modala ardhadalli namma taṇḍa munnaḍe paḍeyitu.*
>
> In the first half our team took the lead.

ಮುನ್, ahead + ನಡೆ, going.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಮುನ್ನಡೆ** (*munnaḍe*) is a native Dravidian compound: *mun*, "that which is in front" (DEDR 5020), and *naḍe*, "to walk, go" (DEDR 3582).
