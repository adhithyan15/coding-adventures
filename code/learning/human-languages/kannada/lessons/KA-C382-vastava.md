# ವಾಸ್ತವ (vāstava) — reality

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C381-PARIGANISU381-05, KA-LEX-C382-VASTAVA382-01] -->

[PAUSE 2s] Before the new one: say the Kannada for intellect, then the Kannada for a fact.

## You'll want to know: ವಾಸ್ತವ
<!-- hl-knowledge: introduces=[KA-LEX-C382-VASTAVA382-02]; assesses=[] -->

**ವಾಸ್ತವ** — *vāstava* — "reality".

> ಕನಸು ಬೇರೆ, ವಾಸ್ತವ ಬೇರೆ.
>
> *kanasu bēre, vāstava bēre.*
>
> Dreams are one thing, reality another.

ವಾಸ್ತವವಾಗಿ, in fact.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ವಾಸ್ತವ** (*vāstava*) is borrowed from Sanskrit *vāstava*, "substantial, real, true" (Monier-Williams), from *vastu*, "a thing".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
