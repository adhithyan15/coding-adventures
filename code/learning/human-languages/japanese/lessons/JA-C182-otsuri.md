## You'll want to know: おつり
<!-- hl-knowledge: introduces=[JA-LEX-C182-PAY182-02]; assesses=[] -->

**おつり** — *otsuri* — "change (money back)".

> **おつりは じゅうえんです。** — *otsuri wa jūen desu* — "The change is ten yen."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**おつり** (*otsuri*) is built from polite *o-* and native *tsuri*, written with the same kanji as *tsuri*, "fishing"; how the money sense arose is not settled (JMdict, KANJIDIC2).
