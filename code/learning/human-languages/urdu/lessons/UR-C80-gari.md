## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**گاڑی** (*gāṛī*) goes back to a reconstructed *\*gāḍḍa*, "cart", which CDIAL links, tentatively, with Sanskrit *garta*, "seat of a chariot" (CDIAL 4116).
