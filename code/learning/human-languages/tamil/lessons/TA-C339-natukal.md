## You'll want to know: நடுகல்
<!-- hl-knowledge: introduces=[TA-LEX-C339-VEERAM339-05]; assesses=[] -->

**நடுகல்** — *naṭukal* — "a hero stone".

> ஊருக்கு வெளியே ஒரு பழைய நடுகல் இருக்கிறது.
>
> *ūrukku veḷiyē oru paḻaiya naṭukal irukkiṟatu.*
>
> There is an old hero stone outside the village.

A stone set up for a fallen hero, often carved with his figure.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**நடுகல்** (*naṭukal*) is a Tamil compound built from நடு, "to set up, plant" (DEDR 3583), and கல், "stone" (DEDR 1298).
