## You'll want to know: आवश्यक
<!-- hl-knowledge: introduces=[HI-LEX-C378-ZARURAT378-01]; assesses=[] -->

**आवश्यक** — *āvaśyak* — "essential, required (formal)".

> अगर बीमारी गंभीर है तो आराम आवश्यक है।
>
> *agar bīmārī gambhīr hai to ārām āvaśyak hai.*
>
> If the illness is serious, rest is essential.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**आवश्यक** (*āvaśyak*) is a tatsama, borrowed from Sanskrit *āvaśyaka*, "necessary, inevitable" (Monier-Williams).
