## You'll want to know: статуя
<!-- hl-knowledge: introduces=[RU-LEX-C522-SCULPTURE-04]; assesses=[] -->

**статуя** (*státuya*) — "a statue".

> В парке стоит статуя из бронзы.
>
> *V párke stoít státuya iz brónzy.*
>
> There is a bronze statue in the park.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*статуя* is a learned borrowing from Latin *statua* 'an image, a statue', which Lewis & Short derive from *statuere* 'to set up'; EtymDB has no entry.
