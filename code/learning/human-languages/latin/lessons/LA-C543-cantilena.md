## You'll want to know: cantilēna, cantilēnae
<!-- hl-knowledge: introduces=[LA-LEX-C543-CANT-03]; assesses=[] -->

**cantilēna, cantilēnae** — "an old song, the same old tune".

> Avia eandem cantilēnam semper canit.
>
> *Grandmother always sings the same old song.*

Feminine, first declension. *Cantilēnam eandem canis* — you sing the same old tune: you keep repeating yourself.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**cantilēna** is built on *cantillō* "to hum", a diminutive of *cantō* "to sing" (Lewis & Short).
