## You'll want to know: маловероятный
<!-- hl-knowledge: introduces=[RU-LEX-C372-VEROYATNO-03]; assesses=[] -->

**маловероятный** (*maloveroyátnyy*) — "unlikely".

> Это маловероятно, но возможно.
>
> *Éto maloveroyátno, no vozmózhno.*
>
> It is unlikely, but possible.

Built from *мало*, little, and *вероятный*, likely. *Маловероятно* — it is unlikely.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**маловероятный** is built from *мало* "little", from Proto-Slavic *\*malŭ* "small" (EtymDB), and *вероятный* "likely", built on *вера* "belief".
