## You'll want to know: سرائے
<!-- hl-knowledge: introduces=[UR-LEX-C403-SARAE403-01]; assesses=[] -->

**سرائے** — *sarāe* — "an inn".

> پرانے شہر میں ایک سرائے ہے۔
>
> *purāne shahr meṅ ek sarāe hai.*
>
> There is an inn in the old city.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**سرائے** (*sarāe*) is usually traced to Persian *sarāy*, "a house, a palace"; in Urdu it is an inn where travellers stop for the night.
