## You'll want to know: اقتلع
<!-- hl-knowledge: introduces=[AR-LEX-C469-TURBA469-05]; assesses=[] -->

**اقتلع** — *iqtalaʿa* — "to uproot".

> اقتلعت الريح شجرة كبيرة.
>
> *iqtalaʿat ar-rīḥ shajara kabīra.*
>
> The wind uprooted a big tree.

Present: يقتلع, *yaqtaliʿ*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**اقتلع** (*iqtalaʿa*) is built on the native Arabic root *q-l-ʿ*, "to pull up, to uproot" (Lane). It is Form VIII.
