## You'll want to know: محصول
<!-- hl-knowledge: introduces=[AR-LEX-C469-TURBA469-03]; assesses=[] -->

**محصول** — *maḥṣūl* — "a crop; a harvest".

> كان محصول القمح كبيرا.
>
> *kāna maḥṣūl al-qamḥ kabīran.*
>
> The wheat crop was large.

Plural: محاصيل, *maḥāṣīl*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**محصول** (*maḥṣūl*) is built on the native Arabic root *ḥ-ṣ-l*, "to remain, to be obtained" (Lane). It is a passive participle: what is obtained.
