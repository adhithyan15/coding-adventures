# রক্ষা পাওয়া (rôkkhā pāoyā) — to be spared; to escape harm

[PAUSE 2s] Before the new one: say the Bengali for luckily, then the Bengali for missing.

## You'll want to know: রক্ষা পাওয়া
<!-- hl-knowledge: introduces=[BN-LEX-C281-BHAGYO281-03]; assesses=[] -->

**রক্ষা পাওয়া** — *rôkkhā pāoyā* — "to be spared; to escape harm".

> ভাগ্যক্রমে নৌকার সবাই রক্ষা পেল।
>
> *bhāgyôkrôme noukār sôbāi rôkkhā pelô.*
>
> Luckily everyone on the boat was spared.

Past (he/she …): সেই শিশু রক্ষা পেল, *sei shishu rôkkhā pelô*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**রক্ষা পাওয়া** (*rôkkhā pāoyā*) puts Sanskrit *rakṣā*, 'protection, care' (Monier-Williams), before **পাওয়া**: to get protection, to come through unharmed.
