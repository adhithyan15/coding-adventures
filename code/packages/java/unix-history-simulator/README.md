# Unix History Simulator (Java)

The [HOS00](../../../specs/HOS00-historical-os-simulator.md) library exposes
a filesystem, descriptor table and kernel from
`codingadventures.unixhistory.UnixHistory`.

With JDK 21 and Python 3 available, run `bash BUILD` to compile and replay
the shared cases, then `java -cp build codingadventures.unixhistory.Cli cat /hello`.
