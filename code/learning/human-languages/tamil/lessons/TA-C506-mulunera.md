# முழுநேர (muḻunēra) — full-time

## You'll want to know: முழுநேர
<!-- hl-knowledge: introduces=[TA-LEX-C506-VELAI506-04]; assesses=[] -->

**முழுநேர** — *muḻunēra* — "full-time".

> என் அக்கா ஒரு முழுநேர வேலை தேடுகிறாள்.
>
> *eṉ akkā oru muḻunēra vēlai tēṭukiṟāḷ.*
>
> My elder sister is looking for a full-time job.

It stands before a noun, like பெரிய (*periya*): முழுநேர வேலை, முழுநேர மாணவன்.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**முழுநேர** (*muḻunēra*) is a native compound: முழு (*muḻu*), "whole, entire" (DEDR 4992), and நேரம் (*nēram*), "time" (DEDR 3774), in the shape a noun takes before another noun.
