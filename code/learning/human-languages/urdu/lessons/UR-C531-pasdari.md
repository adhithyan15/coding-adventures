## You'll want to know: پاسداری
<!-- hl-knowledge: introduces=[UR-LEX-C531-QAUL531-03]; assesses=[] -->

**پاسداری** — *pāsdārī* — "keeping to (a rule or a promise); honouring".

> اگر سب قانون کی پاسداری کرتے تو حادثے کم ہوتے۔
>
> *agar sab qānūn kī pāsdārī karte to hādse kam hote.*
>
> If everyone kept to the law, there would be fewer accidents.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**پاسداری** (*pāsdārī*) is usually traced to Persian *pāsdārī*, "guarding, keeping", built from *pās*, "watch, regard", *-dār*, "holding", and the noun ending *-ī*.
