## 0.1.1

### Fixed
- `_validate_bit` now uses an exact-type check (`type(value) is int`) instead of
  `isinstance`. Previously any `int` subclass (e.g. `class MyInt(int)`, or one
  overriding `__eq__`) was accepted as a bit. Such values now raise `TypeError`.
  Contract: non-`int` (incl. `bool` and subclasses) -> `TypeError`; genuine `int`
  outside {0, 1} -> `ValueError`.

### Added
- `tests/test_gates_exhaustive.py`: literal truth tables for NOT, AND, OR, XOR,
  NAND, NOR, XNOR, nand_not/and/or/xor; NAND-built == direct; rejection of
  every int in -1024..1024 except 0/1 plus 2**31, 2**63, 2**64, 10**100 (and
  negatives) at every argument position; a 24-value type-confusion matrix at
  every argument position; valid inputs never raise and return exact `int`.
