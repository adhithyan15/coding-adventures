## You'll want to know: گیت
<!-- hl-knowledge: introduces=[FA-LEX-C432-GIT-01]; assesses=[] -->

**گیت** (*git*) — "a gate (at an airport)".

> مسافران جلوی گیت شماره پنج صف کشیدند.
>
> *Mosâferân jolow-ye git-e shomâre-ye panj saf keshidand.*
>
> The passengers queued in front of gate number five.

Also the security gate you walk through.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*git* was borrowed from English and is usually traced to English *gate*. EtymDB does not list the Persian word.
