## You'll want to know: અદ્ભુત
<!-- hl-knowledge: introduces=[GU-LEX-C338-CHAPAV338-05]; assesses=[] -->

**અદ્ભુત** — *adbhut* — "wonderful".

> આ નવલકથા અદ્ભુત છે.
>
> *ā navalkathā adbhut che.*
>
> This novel is wonderful.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**અદ્ભુત** (*adbhut*) is a tatsama, Sanskrit *adbhuta*, "wonderful, marvellous" (CDIAL 240). It does not change for gender: **અદ્ભુત નવલકથા**, **અદ્ભુત ગીત**.
