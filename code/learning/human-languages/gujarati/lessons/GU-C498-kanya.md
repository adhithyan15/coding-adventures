# કન્યા (kanyā) — a bride; a girl

## You'll want to know: કન્યા
<!-- hl-knowledge: introduces=[GU-LEX-C498-VIDAY498-02]; assesses=[] -->

**કન્યા** — *kanyā* — "a bride; a girl".

> લાલ સાડી પહેરીને કન્યા બહાર આવી.
>
> *lāl sāḍī paherīne kanyā bahār āvī.*
>
> Dressed in a red sari, the bride came out.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**કન્યા** (*kanyā*) is a tatsama, Sanskrit *kanyā*, "a girl, a daughter", as Monier-Williams records it.
