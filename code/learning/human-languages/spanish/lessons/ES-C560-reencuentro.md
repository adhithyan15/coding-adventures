## You'll want to know: el reencuentro
<!-- hl-knowledge: introduces=[ES-LEX-C560-ENCUENTRO-05]; assesses=[] -->

**el reencuentro** — "the reunion".

> El reencuentro de los hermanos fue muy bonito.
>
> *The brothers' reunion was lovely.*

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*reencuentro* is built on *encuentro* with *re-* 'again'. *Encuentro* comes from *encontrar*, which EtymDB traces to Latin *in contrā* 'facing'.
