## You'll want to know: le bijoutier
<!-- hl-knowledge: introduces=[FR-LEX-C448-OPTICIEN-05]; assesses=[] -->

**le bijoutier** — "the jeweller".

> Il a acheté une bague chez le bijoutier.
>
> *He bought a ring at the jeweller's.*

*La bijouterie* — the jeweller's shop.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*bijoutier* is built on *bijou* 'jewel' (EtymDB lists it), which was borrowed from Breton *bizou* 'ring', from *biz* 'finger'.
