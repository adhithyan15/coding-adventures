## Fixed — Malayalam root slugs name one etymon each

- **ML-C56-vessel** moves from `sanskrit-patra` to `sanskrit-patra-vessel`. *Pātraṁ* is *pātra* "vessel" (CDIAL 8055); `sanskrit-patra` is *pattra* "leaf" (CDIAL 7733).
- **ML-C100-saari** moves from `sanskrit-shata` ("hundred") to `sanskrit-shati`, the slug every other sari lesson uses. Its hook already cites *śāṭī* under CDIAL 12381, which is correct: that entry is *śāṭa* with the feminine *śāṭī*.
- **ML-C180-samayappattika** moves from `sanskrit-patta` to `sanskrit-pattika`, the slug Kannada and Sanskrit use. *Paṭṭikā* "tablet" is under *paṭṭa¹* "slab" (CDIAL 7699); `sanskrit-patta` is *paṭṭa²* "cloth" (CDIAL 7700).
- **ML-C258-caturam** moves from `sanskrit-catura` to `sanskrit-catura-square`. CDIAL 4595 is *catura²* "square", a different word from *caturá¹* "quick, clever" (CDIAL 4594, `sanskrit-catura-clever`).
- **ML-C212-kala**, **ML-C262-kalakaran** and **ML-C299-sarvakalasala** move from `sanskrit-kala` to `sanskrit-kala-art` (*kalā*, CDIAL 2927), the slug every other track's "art" lessons use.
