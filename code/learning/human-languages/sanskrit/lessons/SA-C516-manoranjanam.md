## You'll want to know: मनोरञ्जनम्
<!-- hl-knowledge: introduces=[SA-LEX-C516-AVAKASA516-01]; assesses=[] -->

**मनोरञ्जनम्** — *manorañjanam* — "entertainment".

> रविवासरे वयं मनोरञ्जनाय उद्यानं गच्छामः।
>
> *ravivāsare vayaṃ manorañjanāya udyānaṃ gacchāmaḥ.*
>
> On Sunday we go to the park for some fun.

A neuter noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**मनोरञ्जनम्** (*manorañjanam*) is built from *manas*, "the mind", and *rañjana*, "colouring, delighting", from the root √rañj, "to be coloured, to be pleased"; MW records *manorañjana* only as the title of a book, so "entertainment" is the modern sense (MW).
