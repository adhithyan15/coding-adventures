# tres formas cortas — and the point tells you which is which

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ES-ORTH-C426-03, ES-ORTH-C426-05] -->

[PAUSE 2s] Name the three kinds of short form before reading on, and say which
one takes a point.

## Grammar Lens: one test separates all three
<!-- hl-knowledge: introduces=[]; assesses=[ES-ORTH-C426-03, ES-ORTH-C426-05, ES-ORTH-C426-06] -->

| kind | example | point? |
|---|---|---|
| abreviatura | Sr., Dña., n.º | **yes** |
| sigla | DNI, ONU, UE | no |
| símbolo | €, km, N | no |

The reason is worth more than the table. An **abreviatura** is a Spanish word
cut short, and the point marks the cut. A **sigla** is not a cut word but a set
of initials. A **símbolo** is not Spanish at all — it is an international sign
that happens to appear in a Spanish sentence.

Only something that was cut needs a mark showing where.

## Grammar Lens: the capitals, gathered
<!-- hl-knowledge: introduces=[]; assesses=[ES-ORTH-C426-01, ES-ORTH-C426-02, ES-ORTH-C426-04] -->

| lower-case in Spanish | capitalised |
|---|---|
| lunes, enero | España, Madrid |
| español, católico | Pedro, García |
| el rey, el doctor | De la Cruz, with no forename |

One idea covers the whole left column: **a category is not a name.** Days,
months, languages, nationalities, religions and titles all describe a kind of
thing rather than naming a particular one.

And the raised letters: **º** for a masculine word, **ª** for a feminine one,
with the point **before** — 1.º, 1.ª, Sr.ª.
