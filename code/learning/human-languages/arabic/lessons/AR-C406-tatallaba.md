## You'll want to know: تطلب
<!-- hl-knowledge: introduces=[AR-LEX-C406-TATALLUB406-01]; assesses=[] -->

**تطلب** — *taṭallaba* — "to require".

> يتطلب هذا العمل صبرا كبيرا.
>
> *yataṭallabu hādhā al-ʿamal ṣabran kabīran.*
>
> This work requires great patience.

Present: يتطلب, *yataṭallab*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**تطلب** (*taṭallaba*) is built on the native Arabic root *ṭ-l-b*, "to seek, to ask for" (Lane). It is Form V, to seek a thing again and again: to call for, to require.
