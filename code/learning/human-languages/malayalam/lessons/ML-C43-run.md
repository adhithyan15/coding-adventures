## You'll want to know: ഓടൂ
<!-- hl-knowledge: introduces=[ML-LEX-RUN]; assesses=[] -->

**ഓടൂ** (*ōṭū*) — "run".

The long final *ū* softens a command into an invitation — Malayalam marks courtesy in the verb ending itself.
