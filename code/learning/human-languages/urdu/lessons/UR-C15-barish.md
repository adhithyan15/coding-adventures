# بارش — "rain," and why you'd wear the last chapter's coat

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[UR-LEX-KOAT, UR-REGISTER-ENGLISH-LAYER] -->

[PAUSE 2s] Recall **کوٹ**, the modern English loan that closed the last
chapter. This chapter gives you a reason to wear it: four words for
weather, the small talk that follows almost any "how are you."

## You'll want to know first — one word
<!-- hl-knowledge: introduces=[UR-LEX-BARISH]; assesses=[] -->

> **بارش** — *bārish* — **rain**

> **بارش ہو رہی ہے۔** — *bārish ho rahī hai.* — "It's raining."

**بارش** is feminine.

## The word, taken apart — a load, given an ending
<!-- hl-knowledge: introduces=[UR-ETYMON-BARISH-PERSIAN]; assesses=[UR-LEX-BARISH] -->

**بارش** is borrowed from Classical Persian **bāriš**, itself built from
**bār**, "load, downpour," plus the ending **-eš** that turns a verb or
noun stem into an action noun. No further Proto-Indo-European root is
documented behind that Persian base — an honest dead end, the same shape
as **لال**'s.
