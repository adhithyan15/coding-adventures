# 国 — copy with the frame open

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ZH-SCRIPT-GUO-01, ZH-LEX-REN-01, ZH-SCRIPT-HAN-01] -->

[PAUSE 14s] Say the meaning of 人 and write **汉** once from memory. Then say
**frame, inside, close**.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[ZH-SCRIPT-GUO-01] -->
<!-- hl-writing-stage: guided-copy -->

Copy **国** twice beside the model. On the second copy, pause after the inner
dot. Check that the outer bottom is still open; then close it with stroke eight.

## Guided Practice — Spaced Return
<!-- hl-knowledge: introduces=[]; assesses=[ZH-LEX-REN-01, ZH-SCRIPT-HAN-01] -->
<!-- hl-writing-stage: dictation-transcription -->
