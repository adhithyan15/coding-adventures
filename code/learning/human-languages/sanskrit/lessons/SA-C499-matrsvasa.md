# मातृष्वसा (mātṛṣvasā) — a mother's sister

## You'll want to know: मातृष्वसा
<!-- hl-knowledge: introduces=[SA-LEX-C499-SVASR499-02]; assesses=[] -->

**मातृष्वसा** — *mātṛṣvasā* — "a mother's sister".

> मातृष्वसा मह्यं मोदकान् ददाति।
>
> *mātṛṣvasā mahyaṃ modakān dadāti.*
>
> My mother's sister gives me sweets.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**मातृष्वसा** (*mātṛṣvasā*) is built from *mātṛ*, "mother" (**माता**), and *svasṛ*, "sister" (MW); CDIAL 10001 lists it beside *mātuḥṣvasṛ*, which lives on as Hindi *mausī* (CDIAL 10001).
