# વિકલ્પ (vikalp) — an alternative

## You'll want to know: વિકલ્પ
<!-- hl-knowledge: introduces=[GU-LEX-C373-UPAY373-03]; assesses=[] -->

**વિકલ્પ** — *vikalp* — "an alternative".

> જો ટ્રેન રદ થશે તો બસ એક વિકલ્પ છે.
>
> *jo ṭren rad thaśe to bas ek vikalp che.*
>
> If the train is cancelled, the bus is an alternative.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**વિકલ્પ** (*vikalp*) is a tatsama, borrowed from Sanskrit *vikalpa*, "an alternative, an option" (Monier-Williams).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
