# Name the meal or make the order

## Warm-up

<!-- hl-knowledge: introduces=[]; assesses=[SA-LEX-C248-THG248-01, SA-GRAMMAR-C260-SINGULAR-OBJECTS-03] -->

[PAUSE 2s] Say “treasury,” then explain the choice between **माम्** and
**त्वाम्**: is the one person used as object the speaker or the addressee?

## Grammar Lens: name or request

<!-- hl-knowledge: introduces=[]; assesses=[SA-LEX-C160-THG160-01, SA-LEX-C29-COURTESY-01, SA-PRON-DATIVE-ME-01, SA-GRAMMAR-C265-DADATU-01, SA-PATTERN-C265-POLITE-ORDER-02] -->

**भोजनम्** names a meal. It does not itself order anything. Put the courtesy
word before the frame when you make the request:

> **कृपया मह्यम् अन्नं ददातु।**
>
> *Kṛpayā mahyam annaṃ dadātu.*
>
> Please give me food.
