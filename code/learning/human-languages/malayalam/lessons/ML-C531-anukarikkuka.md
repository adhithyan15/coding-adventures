# അനുകരിക്കുക (anukarikkuka) — to imitate; to mimic

## You'll want to know: അനുകരിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C531-PERUMATTAM531-03]; assesses=[] -->

**അനുകരിക്കുക** — *anukarikkuka* — "to imitate; to mimic".

> കുട്ടി അച്ഛന്റെ നടത്തം അനുകരിച്ചു.
>
> *kuṭṭi acchanṟe naṭattaṁ anukariccu.*
>
> The child mimicked his father's walk.

Past: അനുകരിച്ചു, *anukariccu*.

The noun is അനുകരണം, imitation; the one imitated takes -എ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**അനുകരിക്കുക** (*anukarikkuka*) is built from Sanskrit *anukaraṇa*, "imitation, following an example" (Monier-Williams), with the Malayalam verb ending -ിക്കുക.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
