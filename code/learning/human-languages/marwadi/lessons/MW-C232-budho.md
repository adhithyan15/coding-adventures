# बूढो (būḍho) — elderly; old (of a person)

## You'll want to know: बूढो
<!-- hl-knowledge: introduces=[MW-LEX-C232-EARTH232-01]; assesses=[] -->

**बूढो** — *būḍho* — "elderly; old (of a person)".

> दादा बूढो है।
>
> *dādā būḍho hai.*
>
> Grandfather is old.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

is inherited from a reconstructed *\*buḍḍha*, "old"; CDIAL lists Old Marwari *būḍhaü*, "old" (CDIAL 9271). **जूनो** is old for things; **बूढो** is old for people and animals.
