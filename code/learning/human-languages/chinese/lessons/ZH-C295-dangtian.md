## You'll want to know: 当天
<!-- hl-knowledge: introduces=[ZH-LEX-C295-AGAIN295-03]; assesses=[] -->

**当天** — *dàngtiān* — "that same day; on that very day".

> **他当天就回来了** *tā dàngtiān jiù huílái le* — He came back that same day.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**当天** (*dàngtiān*) is built from 当 and 天 'a day', both inherited from Middle Chinese, *tangH* and *then* (Guangyun, in Baxter's transcription), which glosses the first, in this departing-tone reading, 'to be in charge'; how it came to mean 'that very (day)' is not settled. Read *tang*, the same character gives dāng.
