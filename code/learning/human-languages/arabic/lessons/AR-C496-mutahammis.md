# متحمس (mutaḥammis) — excited, keen

## You'll want to know: متحمس
<!-- hl-knowledge: introduces=[AR-LEX-C496-HAMAS496-01]; assesses=[] -->

**متحمس** — *mutaḥammis* — "excited, keen".

> ابني متحمس للرحلة إلى البحر.
>
> *ibnī mutaḥammis li-r-riḥla ilā al-baḥr.*
>
> My son is excited about the trip to the sea.

It takes لـ for what you look forward to.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**متحمس** (*mutaḥammis*) is built on the native Arabic root *ḥ-m-s*, "to be hard, firm, vehement" (Lane). Ḥamās, enthusiasm, which you know, is from the same root.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
