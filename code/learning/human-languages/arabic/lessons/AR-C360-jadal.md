## You'll want to know: جدل
<!-- hl-knowledge: introduces=[AR-LEX-C360-JADAL360-05]; assesses=[] -->

**جدل** — *jadal* — "a controversy".

> كان هناك جدل كبير حول الفيلم.
>
> *kāna hunāka jadal kabīr ḥawla al-film.*
>
> There was a big controversy about the film.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**جدل** (*jadal*) is built on the native Arabic root *j-d-l*, "to twist firmly" (Lane). *Jadal* is a verbal noun of the same root: arguing, and so a controversy.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
