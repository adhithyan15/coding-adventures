## You'll want to know: disminuir
<!-- hl-knowledge: introduces=[ES-LEX-C608-AUMENTA-02]; assesses=[] -->

**disminuir** — "to decrease, to go down".

> El paro disminuyó en verano.
>
> *Unemployment went down in summer.*

Like *construir*: *disminuye, disminuyó*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*disminuir* is a learned borrowing from Latin *diminuere* 'to make smaller', built on *minuere* 'to lessen' (EtymDB).
