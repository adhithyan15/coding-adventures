## Fixed — point cues name what to point at

The book prints `[YOU POINT: …]` as "*Point to:* …", so a cue that opened with
its own preposition printed it twice: "Point to: at the gol he that closes
**شکریہ**". The leading "at"/"to" is dropped from seven cues, which now name
the thing pointed at (the narration's "point: …" reads the same way):
UR-C03-aap-ka-naam-kya-hai, UR-W02-alef, UR-W05-he, UR-W06-nun-ghunna,
UR-W07-alif-madda, UR-W07-pe and UR-W08-vao. Only the cue wording changes;
modality, drivability and assessment are unchanged.
