# Marathi Roadmap

Same shape as the other tracks: deep one-word lessons in themed chapters.
Slug-identified; order lives in the book and
[`session-map.md`](./session-map.md). See
[`HL00`](../../../specs/HL00-human-language-curriculum-framework.md).

Grounding: English + Sanskrit, with the wider Indo-European family drawn in where
it reaches. The recurring thread is what distinguishes Marathi from Hindi despite
the shared Devanagari script — *namaskār*, three genders, gender on the verb, the
extra letter ळ, and a Dravidian-flavoured everyday grammar. The script is taught
**inline**, never as a gated reading course.

Coverage note: canonical lessons now continue through Chapter 557 (the B1
core in chapters 276–287 and the 1,350-word B1 vocabulary in chapters
288–557; Marathi attains B1 on the level gate), while the sections below
still describe chapters 30–59 and the planned table the opening chapters
only.
