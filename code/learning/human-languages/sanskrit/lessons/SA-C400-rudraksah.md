# रुद्राक्षः (rudrākṣaḥ) — a rudraksha bead

## You'll want to know: रुद्राक्षः
<!-- hl-knowledge: introduces=[SA-LEX-C400-PARIKRAMA400-03]; assesses=[] -->

**रुद्राक्षः** — *rudrākṣaḥ* — "a rudraksha bead".

> जपमालायां रुद्राक्षाः सन्ति।
>
> *japamālāyāṃ rudrākṣāḥ santi.*
>
> There are rudraksha beads on the string of prayer beads.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**रुद्राक्षः** (*rudrākṣaḥ*) is built from *Rudra*, a name of Śiva, and *akṣa*, "an eye": MW gives it as "Rudra-eyed", a tree whose berries are strung into rosaries (MW).
