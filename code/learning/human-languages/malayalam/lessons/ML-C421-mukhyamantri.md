# മുഖ്യമന്ത്രി (mukhyamantri) — a chief minister

## You'll want to know: മുഖ്യമന്ത്രി
<!-- hl-knowledge: introduces=[ML-LEX-C421-BHARANAM421-04]; assesses=[] -->

**മുഖ്യമന്ത്രി** — *mukhyamantri* — "a chief minister".

> മുഖ്യമന്ത്രി പുതിയ ആശുപത്രി തുറന്നു.
>
> *mukhyamantri putiya āśupatri tuṟannu.*
>
> The chief minister opened the new hospital.

മുഖ്യ-, chief, also makes മുഖ്യ കാരണം, the main reason.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**മുഖ്യമന്ത്രി** (*mukhyamantri*) is built from Sanskrit *mukhya*, "of the face; chief" (CDIAL 10174), and *mantrin*, "a counsellor" (CDIAL 9838).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
