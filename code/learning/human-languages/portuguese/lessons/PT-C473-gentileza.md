## You'll want to know: a gentileza
<!-- hl-knowledge: introduces=[PT-LEX-C473-MANEIRAS-01]; assesses=[] -->

**a gentileza** — "kindness, courtesy".

> Foi uma gentileza do vizinho ajudar-nos com as malas.
>
> *It was kind of the neighbour to help us with the cases.*

*Por gentileza* — please, kindly (a little formal).

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*gentileza* is built on *gentil* "kind, courteous", from Latin *gentīlis* "of the same clan" (Lewis & Short), built on *gēns* "a clan, a family".
