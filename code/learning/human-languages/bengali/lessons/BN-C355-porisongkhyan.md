## You'll want to know: পরিসংখ্যান
<!-- hl-knowledge: introduces=[BN-LEX-C355-NOMUNA355-01]; assesses=[] -->

**পরিসংখ্যান** — *pôrisôngkhyān* — "statistics".

> পরিসংখ্যানটা আমাকে দেখাও।
>
> *pôrisôngkhyānṭā āmāke dekhāo.*
>
> Show me the statistics.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**পরিসংখ্যান** (*pôrisôngkhyān*) is Sanskrit *parisaṃkhyāna*, a full count (Monier-Williams). Modern Bengali uses it for statistics.
