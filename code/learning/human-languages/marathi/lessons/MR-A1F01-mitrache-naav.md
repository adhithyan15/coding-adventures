# मित्राचे नाव — friend's name

## Warm-up
<!-- hl-knowledge: introduces=[MR-A1-FORM-LABEL-MITRACHE-NAAV, MR-A1-FORM-POSSESSIVE-NEUTER]; assesses=[] -->

You know **मित्र**, friend, and **नाव**, name. Marathi links them as
**मित्राचे नाव**, “the friend's name.” The **-चे** form agrees with neuter
**नाव**. The familiar practice answer is **अरुण**.

## Writing — observe and trace one pair
<!-- hl-knowledge: introduces=[]; assesses=[MR-A1-FORM-LABEL-MITRACHE-NAAV, MR-A1-FORM-POSSESSIVE-NEUTER] -->
<!-- hl-writing-stage: observe-trace -->

Trace **मित्राचे नाव: अरुण** once. Circle **-चे** and stop; no possessive table
is needed for this form.
