# পূর্বাভাস (pūrbābhās) — a forecast

## You'll want to know: পূর্বাভাস
<!-- hl-knowledge: introduces=[BN-LEX-C532-BHOBITOBBO532-04]; assesses=[] -->

**পূর্বাভাস** — *pūrbābhās* — "a forecast".

> পূর্বাভাস ভালো হলে আমরা কাল নৌকায় নদী পার হব।
>
> *Pūrbābhās bhālo hôle āmrā kāl noukāy nôdī pār hôbô.*
>
> If the forecast is good, we'll cross the river by boat tomorrow.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**পূর্বাভাস** (*pūrbābhās*) joins Sanskrit *pūrva*, "before, earlier", and *ābhāsa*, "light, appearance" (Monier-Williams): a first glimpse of what is coming.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
