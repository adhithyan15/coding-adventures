# صفحہ (safhā) — a page

## You'll want to know: صفحہ
<!-- hl-knowledge: introduces=[UR-LEX-C330-SAFHA330-01]; assesses=[] -->

**صفحہ** — *safhā* — "a page".

> اس کتاب میں سو صفحے ہیں۔
>
> *is kitāb meṅ sau safhe haiṅ.*
>
> This book has a hundred pages.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**صفحہ** (*safhā*) is usually traced, through Persian, to Arabic *ṣafḥa*, "a flat surface, a page". The plural is **صفحے**.
