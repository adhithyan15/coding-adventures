## You'll want to know: réagir
<!-- hl-knowledge: introduces=[FR-LEX-C351-REACTION-01]; assesses=[] -->

**réagir** — "to react".

> Comment as-tu réagi quand tu as appris la nouvelle ?
>
> *How did you react when you heard the news?*

*Réagir à quelque chose*. A *-ir* verb like *finir*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*réagir* is built from *ré-* "back" and *agir* "to act", which comes from Latin *agere* "to do, to drive" (Lewis & Short).
