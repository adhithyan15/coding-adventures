# வெளிச்சம் (veḷiccam) — brightness; light

## You'll want to know: வெளிச்சம்
<!-- hl-knowledge: introduces=[TA-LEX-C430-VANAM430-02]; assesses=[] -->

**வெளிச்சம்** — *veḷiccam* — "brightness; light".

> சன்னல் வழியாக வெளிச்சம் உள்ளே வந்தது.
>
> *caṉṉal vaḻiyāka veḷiccam uḷḷē vantatu.*
>
> Light came in through the window.

The opposite is இருட்டு, darkness.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**வெளிச்சம்** (*veḷiccam*) is native Dravidian (DEDR 5496), "light, clearness", from the root of வெள், "white, bright".
