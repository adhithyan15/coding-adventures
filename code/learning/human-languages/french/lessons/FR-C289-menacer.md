## You'll want to know: menacer
<!-- hl-knowledge: introduces=[FR-LEX-C289-AGRESSION-04]; assesses=[] -->

**menacer** — "to threaten".

> Il a menacé le vendeur avec un couteau.
>
> *He threatened the shop assistant with a knife.*

*Menacer de* + infinitive: *il a menacé de partir*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*menacer* is inherited from Vulgar Latin *mināciāre* "to threaten" (EtymDB), built on Latin *mināx* "threatening".
