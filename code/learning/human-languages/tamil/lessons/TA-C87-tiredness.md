# களைப்பு (kaḷaippu) — tiredness

## You'll want to know: களைப்பு
<!-- hl-knowledge: introduces=[TA-LEX-C87-UNWELL-01]; assesses=[] -->

**களைப்பு** (*kaḷaippu*) — "tiredness".

**எனக்குக் களைப்பாக இருக்கிறது** — "I feel tired", literally "to me it is tired-ly". The person
sits in **எனக்கு**, "to me".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

A first word for how the body feels.
