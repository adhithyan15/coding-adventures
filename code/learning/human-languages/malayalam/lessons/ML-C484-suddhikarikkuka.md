# ശുദ്ധീകരിക്കുക (śuddhīkarikkuka) — to purify

## You'll want to know: ശുദ്ധീകരിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C484-VELLAM484-03]; assesses=[] -->

**ശുദ്ധീകരിക്കുക** — *śuddhīkarikkuka* — "to purify".

> ആ യന്ത്രം കിണറ്റിലെ വെള്ളം ശുദ്ധീകരിക്കുന്നു.
>
> *ā yantraṁ kiṇaṟṟile veḷḷaṁ śuddhīkarikkunnu.*
>
> That machine purifies the well water.

Past: ശുദ്ധീകരിച്ചു, *śuddhīkariccu*.

ശുദ്ധം, pure, plus -ീകരിക്കുക, to make: the same ending makes many formal verbs.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ശുദ്ധീകരിക്കുക** (*śuddhīkarikkuka*) is built from Sanskrit *śuddha*, "clean, pure" (Monier-Williams), with *-īkaraṇa*, making into, and the Malayalam verb ending.
