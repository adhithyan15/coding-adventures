# Changelog — SkipList (Swift)

All notable changes to this package are documented here.

## 0.1.0 — Initial release

- Add a real span-augmented skip-list tower with comparator-defined identity.
- Add caller-controlled node levels without ambient entropy.
- Add bounded insertion, update, deletion, lookup, zero-based rank/selection,
  endpoint-controlled ranges, and ordered snapshots.
- Add package-native invariant and reference-model tests, native build fronts,
  stable failures, documentation, and an empty capability profile.
