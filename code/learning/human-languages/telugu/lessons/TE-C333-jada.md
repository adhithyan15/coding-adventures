## You'll want to know: జాడ
<!-- hl-knowledge: introduces=[TE-LEX-C333-KESU333-04]; assesses=[] -->

**జాడ** — *jāḍa* — "a trace; a sign".

> దొంగ జాడ ఎక్కడా దొరకలేదు.
>
> *doṅga jāḍa ekkaḍā dorakalēdu.*
>
> No trace of the thief was found anywhere.

జాడ తెలియదు, the trace is not known: nobody knows where someone went.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**జాడ** (*jāḍa*) is native Dravidian: DEDR 2442 lists Telugu *jāḍa*, "a sign, trace, track", with Tamil *cāṭai*, "a hint, a feature".
