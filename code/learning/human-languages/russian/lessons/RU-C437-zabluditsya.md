## You'll want to know: заблудиться
<!-- hl-knowledge: introduces=[RU-LEX-C437-ZABLUDITSYA-01]; assesses=[] -->

**заблудиться** (*zabludítsya*) — "to get lost".

> В старом городе мы быстро заблудились.
>
> *V stárom górode my býstro zabludílis.*
>
> We quickly got lost in the old town.

Perfective. Future *заблужусь, заблудишься*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*заблудиться* is built from *за-*, *блудить* 'to wander, to stray' and *-ся*; EtymDB lists it with the sense 'to get lost'. The root is Proto-Slavic *blǫdŭ* (EtymDB), the same root as in *блуждать* 'to wander'.
