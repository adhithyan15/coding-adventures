# அழைப்பு (aḻaippu) — an invitation, a call

<!-- hl-knowledge: introduces=[]; assesses=[TA-LEX-C97-SURE-03, TA-LEX-C98-WELCOME-01] -->

[PAUSE 2s] Before the new one: say the Tamil for why not, then the Tamil for congratulations.

## You'll want to know: அழைப்பு
<!-- hl-knowledge: introduces=[TA-LEX-C98-WELCOME-02]; assesses=[] -->

**அழைப்பு** (*aḻaippu*) — "an invitation", and "a call".

**அழைப்புக்கு நன்றி** — "thank you for the invitation", with the **நன்றி** you know.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

An invitation, and thanks for it.
