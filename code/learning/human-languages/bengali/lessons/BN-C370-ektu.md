# একটু (ekṭu) — a little; a bit

## You'll want to know: একটু
<!-- hl-knowledge: introduces=[BN-LEX-C370-KHUB370-05]; assesses=[] -->

**একটু** — *ekṭu* — "a little; a bit".

> একটু আস্তে বললে আমি বুঝব।
>
> *ekṭu āste bôlle āmi bujhbô.*
>
> If you speak a bit more slowly, I'll understand.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**একটু** (*ekṭu*) is এক, one (CDIAL 2462 lists Bengali ek), probably with a small-making ending: 'one little bit'. It softens a request: একটু বসো, do sit down.
