## You'll want to know: جعلی
<!-- hl-knowledge: introduces=[UR-LEX-C281-THAG281-05]; assesses=[] -->

**جعلی** — *jālī* — "forged; counterfeit".

> یہ نوٹ جعلی ہے۔
>
> *yih noṭ jālī hai.*
>
> This banknote is forged.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

is usually traced, through Persian, to Arabic *jaʿl*, "a making, a fabrication", with the adjective ending *-ī*. **نقلی** is any copy; a **جعلی** note is one made to pass as real.
