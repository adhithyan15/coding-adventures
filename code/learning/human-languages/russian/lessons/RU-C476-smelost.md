## You'll want to know: смелость
<!-- hl-knowledge: introduces=[RU-LEX-C476-FRIGHT-05]; assesses=[] -->

**смелость** (*smélost*) — "courage, boldness".

> Нужно много смелости, чтобы петь на сцене.
>
> *Núzhno mnógo smélosti, chtóby pet na stséne.*
>
> It takes a lot of courage to sing on stage.

Feminine. Built on *смелый* — bold, brave.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*смелость* is built on *смелый* 'bold' with *-ость* (EtymDB); *смелый* is inherited from Old East Slavic *sъmělъ* (EtymDB).
