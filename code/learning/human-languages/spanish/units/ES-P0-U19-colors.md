# Unit 19: Colors

## Warm-up

[PAUSE 2s] Say "el libro alto" and "la casa alta." Colors are adjectives —
today's set puts the agreement rule from Unit 18 into practice with real
vocabulary.

## New Material

**rojo / roja** — red ← Latin *russus*.
**azul** — blue ← Arabic *lāzaward* (the source of English *azure* too —
both Spanish and English borrowed this one from the same Arabic root,
independently, another entry in Spanish's Arabic thread from Chapter 1's
*cero*).
**verde** — green ← Latin *viridis* (→ English *verdant*).
**amarillo / amarilla** — yellow ← Latin *amarus* ("bitter" — an odd shift
in meaning some etymologists connect to bile/jaundice color associations).
**negro / negra** — black ← Latin *niger* (→ English *denigrate*,
literally "to blacken").
