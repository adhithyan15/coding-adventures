# (one letter) — From the letter to the word — a first pass

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-C43-MA-01] -->

[PAUSE 3s] Say **राम** (*rām*), then write the letter it gave you.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-C43-MA-01] -->

| letter | name | the word it came from |
|---|---|---|
| म | *ma* | **राम** *rām* |

[PAUSE 2s each]
- [YOU WRITE: each letter in the table from memory, then check it]
- [YOU SAY: the word each one came from]
- [YOU READ: each word in the table aloud, and point at its letter]
