# ಪ್ರತಿಜ್ಞೆ (pratijñe) — a vow; a pledge

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C415-AMANATU415-05, KA-LEX-C416-PRATIJNE416-01] -->

[PAUSE 2s] Before the new one: say the Kannada for an official order, then the Kannada for a written undertaking.

## You'll want to know: ಪ್ರತಿಜ್ಞೆ
<!-- hl-knowledge: introduces=[KA-LEX-C416-PRATIJNE416-02]; assesses=[] -->

**ಪ್ರತಿಜ್ಞೆ** — *pratijñe* — "a vow; a pledge".

> ಇನ್ನು ಮುಂದೆ ಸಿಗರೇಟು ಸೇದುವುದಿಲ್ಲ ಅಂತ ಅಪ್ಪ ಪ್ರತಿಜ್ಞೆ ಮಾಡಿದರು.
>
> *innu munde sigarēṭu sēduvudilla anta appa pratijñe māḍidaru.*
>
> Father vowed never to smoke again.

ಪ್ರತಿಜ್ಞೆ ಮಾಡು, to vow.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಪ್ರತಿಜ್ಞೆ** (*pratijñe*) is borrowed from Sanskrit *pratijñā*, "admission, promise, vow" (CDIAL 8563).
