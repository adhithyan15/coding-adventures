# પાક (pāk) — a crop

## You'll want to know: પાક
<!-- hl-knowledge: introduces=[GU-LEX-C390-PAK390-01]; assesses=[] -->

**પાક** — *pāk* — "a crop".

> જો સમયસર વરસાદ પડશે તો આ વરસે પાક સારો થશે.
>
> *jo samaysar varsād paḍśe to ā varse pāk sāro thaśe.*
>
> If the rain comes on time, the crop will be good this year.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**પાક** (*pāk*) shares its source with **પાકવું** (*pākvũ*), "to ripen": CDIAL traces both to Sanskrit *pakvá*, "cooked, ripe", which in the Atharvaveda already meant "ripe corn" (CDIAL 7621). CDIAL glosses the Gujarati noun only as "sugar boiled for conserves", so "a crop" is a sense it does not give.
