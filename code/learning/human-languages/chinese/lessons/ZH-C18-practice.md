# Payoff — looking and reading

Keep four scores. Repair one missed skill without erasing the other passes.

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ZH-SCRIPT-KAN-01, ZH-SCRIPT-SHU-01] -->

[PAUSE 15s] Write 看 and 书 without a model, then name each aloud.

## Guided Practice
<!-- hl-knowledge: introduces=[ZH-PERFORMANCE-LOOKING-READING-FIVE-FOUR-SKILL-01]; assesses=[ZH-LEX-KAN-01, ZH-SCRIPT-KAN-01, ZH-LEX-KANJIAN-01, ZH-ORTHO-KANJIAN-01, ZH-LEX-HAOKAN-01, ZH-ORTHO-HAOKAN-01, ZH-LEX-SHU-01, ZH-SCRIPT-SHU-01, ZH-LEX-KANSHU-01, ZH-ORTHO-KANSHU-01] -->
<!-- hl-writing-stage: dictation-transcription -->

1. **Listening, /5:** hear all five forms in mixed order and choose each meaning.
2. **Speaking, /5:** produce all five from meaning cards, with tones audible.
3. **Reading, /5:** read **看书, 好看, 书, 看见, 看** cold, without pinyin.
4. **Writing, /5:** hear all five meanings and write each form without a model.

Pass each skill separately. Repair only a missed form in the missed skill, then
retry that column without cancelling the other three scores.
