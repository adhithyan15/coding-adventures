# അസാധ്യമായ (asādhyamāya) — impossible

## You'll want to know: അസാധ്യമായ
<!-- hl-knowledge: introduces=[ML-LEX-C441-SADHYAM441-02]; assesses=[] -->

**അസാധ്യമായ** — *asādhyamāya* — "impossible".

> അവന് അസാധ്യമായ ഒന്നുമില്ല.
>
> *avanŭ asādhyamāya onnumilla.*
>
> Nothing is impossible for him.

As a predicate: അത് അസാധ്യമാണ്.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**അസാധ്യമായ** (*asādhyamāya*) is built from Sanskrit *asādhya*, "not to be accomplished" (Monier-Williams), with the adjective ending -ആയ.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
