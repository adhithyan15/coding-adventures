# धर्मशाळा (dharmaśāḷā) — a rest house; a pilgrims’ lodge

## You'll want to know: धर्मशाळा
<!-- hl-knowledge: introduces=[MR-LEX-C413-NIVAS413-02]; assesses=[] -->

**धर्मशाळा** — *dharmaśāḷā* — "a rest house; a pilgrims’ lodge".

> मंदिराजवळ एक धर्मशाळा आहे.
>
> *mandirājavaḷ ek dharmaśāḷā āhe.*
>
> There is a rest house near the temple.

Feminine.

Often near a temple; a bed there is cheap or free.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**धर्मशाळा** (*dharmaśāḷā*) is a tatsama, taken from Sanskrit *dharmaśālā*, built from *dharma*, "duty, charity", and *śālā*, "a hall" (Monier-Williams): a hall kept open as a good deed.
