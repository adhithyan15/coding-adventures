Spanish, chapter 622: Las reglas.
5 lessons. All 5 can be done entirely by ear.


Lesson 1 of 5.
la normativa — the set of rules, the regulations.

Warm-up.
[pause 2 seconds]
Before the new one: say the Spanish for exempt, then the Spanish for forbidden.

You'll want to know: la normativa.
la normativa — "the set of rules, the regulations".
La nueva normativa empieza en enero. The new rules start in January.
Rules made by an authority for a whole area.

The word, taken apart.
normativa is built on norma, which comes from Latin norma 'a carpenter's square, a rule' (EtymDB).

What you've built.

Lee el reglamento antes de empezar. Read the regulations before you start.
The written set of rules of a club, a building or a game.

The word, taken apart.
reglamento is built on reglar, a learned borrowing from Latin regulare 'to direct', from regula 'rule' (EtymDB).

Lesson 4 of 5.
obligar — to force, to oblige.

Warm-up.
[pause 2 seconds]
Before the new one: say the Spanish for the regulations, then the Spanish for the ban.

You'll want to know: obligar.
obligar — "to force, to oblige".
Nadie te obliga a venir. Nobody is forcing you to come.
Obligar a alguien a + infinitive. Spelling: obligué.

The word, taken apart.
obligar is a learned borrowing from Latin obligare 'to bind, to put under a duty', built on ligare 'to tie' (EtymDB).
