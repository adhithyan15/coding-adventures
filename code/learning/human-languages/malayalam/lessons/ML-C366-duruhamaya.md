## You'll want to know: ദുരൂഹമായ
<!-- hl-knowledge: introduces=[ML-LEX-C366-SUCHANA366-05]; assesses=[] -->

**ദുരൂഹമായ** — *durūhamāya* — "mysterious".

> ആ കത്ത് വളരെ ദുരൂഹമായിരുന്നു.
>
> *ā kattŭ vaḷare durūhamāyirunnu.*
>
> That letter was very mysterious.

The noun is ദുരൂഹത, a mystery.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ദുരൂഹമായ** (*durūhamāya*) is built from Sanskrit *durūha*, "hard to infer or understand" (Monier-Williams), with the Malayalam adjective ending -ആയ: a mysterious thing is one nobody can work out.
