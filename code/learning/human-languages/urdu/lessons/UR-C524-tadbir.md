## You'll want to know: تدبیر
<!-- hl-knowledge: introduces=[UR-LEX-C524-FEHRIST524-04]; assesses=[] -->

**تدبیر** — *tadbīr* — "a way out (of a difficulty)".

> اگر کوئی تدبیر نہیں ملی تو ہم رک جائیں گے۔
>
> *agar koī tadbīr nahīṅ milī to ham ruk jāeṅ ge.*
>
> If we find no way out, we will stop.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**تدبیر** (*tadbīr*) is usually traced, through Persian, to Arabic *tadbīr*, "arranging, managing".
