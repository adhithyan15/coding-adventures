# கஷாயம் (kaṣāyam) — a herbal decoction

## You'll want to know: கஷாயம்
<!-- hl-knowledge: introduces=[TA-LEX-C485-MARUNTU485-01]; assesses=[] -->

**கஷாயம்** — *kaṣāyam* — "a herbal decoction".

> சளிக்குப் பாட்டி கஷாயம் செய்து கொடுத்தாள்.
>
> *caḷikkup pāṭṭi kaṣāyam ceytu koṭuttāḷ.*
>
> Grandmother made a decoction for the cold.

Written with the grantha ஷ, as Tamil writes it today.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**கஷாயம்** (*kaṣāyam*) is borrowed from Sanskrit *kaṣāya*, "astringent; an astringent juice" (CDIAL 2974).
