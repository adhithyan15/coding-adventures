## You'll want to know: la bruine
<!-- hl-knowledge: introduces=[FR-LEX-C461-BRUINE-01]; assesses=[] -->

**la bruine** — "the drizzle".

> Une bruine fine tombe depuis ce matin.
>
> *A fine drizzle has been falling since this morning.*

Very light rain.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*bruine* is usually traced to Latin *pruīna* 'hoarfrost' (Lewis & Short), but the path is not settled, and EtymDB does not list it.
