## You'll want to know: la enfermedad
<!-- hl-knowledge: introduces=[ES-LEX-C732-SALUD-03]; assesses=[] -->

**la enfermedad** — "illness, disease".

> Es una enfermedad muy rara.
>
> *It is a very rare disease.*

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*enfermedad* is inherited from Latin *īnfirmitās* "weakness" (EtymDB), built on *īnfirmus* "not firm, weak".
