## You'll want to know: पर्याप्तः
<!-- hl-knowledge: introduces=[SA-LEX-C379-ADHIKA379-02]; assesses=[] -->

**पर्याप्तः** — *paryāptaḥ* — "sufficient".

> यदि अन्नं पर्याप्तम्, तर्हि अतिथिः अपि खादिष्यति।
>
> *yadi annaṃ paryāptam, tarhi atithiḥ api khādiṣyati.*
>
> If there is enough food, the guest will eat too.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**पर्याप्तः** (*paryāptaḥ*) is built on *pari*, "around", and the root √āp, "to reach, to obtain"; MW gives *pary-āpta* "sufficient for" (MW).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
