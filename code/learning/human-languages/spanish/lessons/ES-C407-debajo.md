# debajo — underneath

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ES-LEX-C310-ASK-03] -->

[PAUSE 2s] Recall **la mesa**. Something lower than the tabletop can be
**debajo de la mesa**.

## The word, taken apart
<!-- hl-knowledge: introduces=[ES-LEX-DEBAJO]; assesses=[] -->

The history is visible: **de + bajo**. **Bajo** is low; **debajo** names the
lower position. The DLE defines it as a place below another higher one.

## Grammar Lens: debajo de
<!-- hl-knowledge: introduces=[]; assesses=[ES-LEX-DEBAJO, ES-LEX-C310-ASK-03] -->

Before a reference object, use **debajo de**: **debajo de la mesa**. With no
object stated, **está debajo** is complete.
