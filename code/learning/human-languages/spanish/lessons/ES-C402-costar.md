# costar — when the price stands settled

## Sounds you'll need
<!-- hl-knowledge: introduces=[]; assesses=[] -->

- *cos-TAR*: keep the first *s* clear. **Costar** differs from **contar** only
  in that middle consonant: *cos-tar*, not *con-tar*.

## The word, taken apart
<!-- hl-knowledge: introduces=[ES-LEX-COSTAR]; assesses=[] -->

**costar** — "to cost."

It descends from Latin **constare**, "to stand together" and then "to be
settled or established." A settled price is what an item **costs**. English
**cost** reached the same Latin family through French.

Use the third-person question for one item: **¿Cuánto cuesta?** — "How much
does it cost?" The answer can be **Cuesta diez euros**.
