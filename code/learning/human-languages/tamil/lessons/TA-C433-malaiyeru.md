# மலையேறு (malaiyēṟu) — to trek; to climb mountains

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TA-LEX-C432-NEER432-05, TA-LEX-C433-SIKARAM433-01] -->

[PAUSE 2s] Before the new one: say the Tamil for to slosh, then the Tamil for a peak.

## You'll want to know: மலையேறு
<!-- hl-knowledge: introduces=[TA-LEX-C433-SIKARAM433-02]; assesses=[] -->

**மலையேறு** — *malaiyēṟu* — "to trek; to climb mountains".

> விடுமுறையில் நான் நண்பர்களுடன் மலையேறினேன்.
>
> *viṭumuṟaiyil nāṉ naṇparkaḷuṭaṉ malaiyēṟiṉēṉ.*
>
> In the holidays I went trekking with friends.

Past (I …): மலையேறினேன், *malaiyēṟiṉēṉ*.

மலை, a hill, + ஏறு, to climb, written as one word.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**மலையேறு** (*malaiyēṟu*) is built from மலை, "a hill, a mountain" (DEDR 4742), and ஏறு, "to climb" (DEDR 916).
