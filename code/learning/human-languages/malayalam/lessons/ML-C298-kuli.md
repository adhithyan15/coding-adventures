## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**കൂലി** (*kūli*) is native Dravidian, one word with Tamil *kūli*, Kannada *kūli* and Telugu *kūli* (DEDR 1905). English *coolie* goes back to this word.
