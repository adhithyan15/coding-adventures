# ವಿಶ್ರಾಂತಿ (viśrānti) — rest

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C82-UNWELL-03, KA-LEX-C82-UNWELL-04] -->

[PAUSE 2s] Before the new one: say the Kannada for a cough, then the Kannada for a headache.

## You'll want to know: ವಿಶ್ರಾಂತಿ
<!-- hl-knowledge: introduces=[KA-LEX-C82-UNWELL-05]; assesses=[] -->

**ವಿಶ್ರಾಂತಿ** (*viśrānti*) — "rest".

**ವಿಶ್ರಾಂತಿ ತೆಗೆದುಕೊಳ್ಳಿ** (*viśrānti tegedukoḷḷi*) — "please take rest", what
you say to a friend who is unwell. The verb is **ತೆಗೆದುಕೊ**, "take", which you
already know.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

The answer to tiredness, a cold and a headache.
