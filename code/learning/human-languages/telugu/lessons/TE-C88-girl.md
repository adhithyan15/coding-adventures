# అమ్మాయి (ammāyi) — a girl; a daughter

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TE-LEX-C88-PEOPLE-01, TE-LEX-C88-PEOPLE-02] -->

[PAUSE 2s] Before the new one: say the Telugu for children, then the Telugu for a boy.

## You'll want to know: అమ్మాయి
<!-- hl-knowledge: introduces=[TE-LEX-C88-PEOPLE-03]; assesses=[] -->

**అమ్మాయి** (*ammāyi*) — "a girl", and in a family, "a daughter".

It is built like **అబ్బాయి**, and it opens on the same sound as **అమ్మ**, "mother".
**మా అమ్మాయి** — "our girl", "my daughter".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

Boy and girl as a pair, each also a word for a child of the family.
