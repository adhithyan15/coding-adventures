# मेघः (meghaḥ) — a cloud

## You'll want to know: मेघः
<!-- hl-knowledge: introduces=[SA-LEX-C301-CAKRAVATA301-01]; assesses=[] -->

**मेघः** — *meghaḥ* — "a cloud".

> आकाशे कृष्णाः मेघाः सन्ति।
>
> *ākāśe kṛṣṇāḥ meghāḥ santi.*
>
> There are dark clouds in the sky.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**मेघः** (*meghaḥ*) comes from the root √mih (MW writes it √migh here), "to sprinkle": MW explains *megha* as the sprinkler, a cloud (MW).
