## You'll want to know: جفف
<!-- hl-knowledge: introduces=[AR-LEX-C552-TARMIM552-04]; assesses=[] -->

**جفف** — *jaffafa* — "to dry off".

> جففت أمي الأطباق بمنشفة.
>
> *jaffafat ummī al-aṭbāq bi-minshafa.*
>
> My mother dried the plates with a towel.

Present: يجفف, *yujaffif*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**جفف** (*jaffafa*) is built on the native Arabic root *j-f-f*, "to be dry" (Lane). Jāff, dry, which you know, is from the same root; Form II jaffafa is to make dry.
