# દાઢ (dāḍh) — molar, back tooth

## You'll want to know: દાઢ
<!-- hl-knowledge: introduces=[GU-LEX-C230-TOOTH230-01]; assesses=[] -->

**દાઢ** — *dāḍh* — "molar, back tooth".

> **મારી દાઢ હવે નથી દુખતી.** — *mārī dāḍh have nathī dukhtī* — "My back tooth doesn't hurt any more."

Not **દાઢી**, a beard.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**દાઢ** (*dāḍh*) is a tadbhava. It comes from *\*dāṁṣṭra*, "fang, tusk", beside Sanskrit *daṁṣṭra*, "tusk, fang"; CDIAL glosses the Gujarati word "molar" (CDIAL 6250).
