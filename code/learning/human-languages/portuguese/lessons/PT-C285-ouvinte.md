## You'll want to know: o ouvinte
<!-- hl-knowledge: introduces=[PT-LEX-C285-OUVINTE-03]; assesses=[] -->

**o ouvinte** — "the listener".

> Um ouvinte telefonou para a rádio.
>
> *A listener phoned the radio station.*

The same form for a woman: *a ouvinte*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*ouvinte* is inherited from Latin *audiēns* "hearing, a hearer" (EtymDB), from *audīre* "to hear".
