# One letter tells you the job

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[HI-JOIN-KAB-01, HI-JOIN-JAB-TAB-01, HI-GRAMMAR-C40-DEIXIS-SYSTEM] -->

name the other pair in the book built the same way.
