# ನ — write it with the model covered

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-SCRIPT-RECOG-01] -->

Look at **ನ** once and say *na*. Then cover it, and every other **ನ** on
the page.

## Writing — delayed copy
<!-- hl-knowledge: introduces=[]; assesses=[KA-SCRIPT-RECOG-01] -->
<!-- hl-writing-stage: delayed-copy -->

With the model covered, wait ten seconds, then write **ನ** once from memory.

Ten seconds is not long and is not meant to be. It is long enough that your hand
cannot be tracing a shape it can still see, and short enough that a letter you
met a minute ago is still there to be found.

Only after the letter is finished, uncover the model and compare. Repair **one**
thing — the first that differs — and leave the rest.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[KA-SCRIPT-RECOG-01] -->

The thing to look at is not whether your letter is beautiful. It is whether it is
the **same letter**, and in this script that usually comes down to one curve
closing where the model's closes, or staying open where the model's stays open.
A hand drawing from memory rounds off what it is unsure about.
