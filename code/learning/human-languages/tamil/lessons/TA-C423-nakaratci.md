# நகராட்சி (nakarāṭci) — a municipality

## You'll want to know: நகராட்சி
<!-- hl-knowledge: introduces=[TA-LEX-C423-NAKAR423-01]; assesses=[] -->

**நகராட்சி** — *nakarāṭci* — "a municipality".

> நகராட்சி புதிய பூங்காவைத் திறந்தது.
>
> *nakarāṭci putiya pūṅkāvait tiṟantatu.*
>
> The municipality opened a new park.

நகர், town, + ஆட்சி, rule.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**நகராட்சி** (*nakarāṭci*) is built from நகர், "a town" (DEDR 3568), and ஆட்சி, "rule, government" (DEDR 5157).
