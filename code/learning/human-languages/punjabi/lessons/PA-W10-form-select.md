# One card chooses three already-known values

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-AGE-FIFTEEN-01, PA-FORM-AGE-TWENTY-FIVE-01, PA-FORM-PHONE-A-01, PA-FORM-PHONE-B-01, PA-FORM-DATE-A-01, PA-FORM-DATE-B-01] -->

The old closed banks are visible again. Age A is **੧੫**, B is **੨੫**. Phone A
is **੦੧੨ ੨੫੧**, B is **੦੨੫ ੧੨੫**. Date A is **੧੫/੦੧/੨੦੨੫**, B is
**੨੫/੦੨/੨੦੨੫**. These are fictional practice values, not personal data.

## You'll want to know — a single shared cue
<!-- hl-knowledge: introduces=[PA-FORM-AGE-PHONE-DATE-CUE-01]; assesses=[PA-FORM-AGE-PHONE-DATE-ORDER-01] -->

On this practice card **ਕ** chooses A from *each* bank; **ਖ** chooses B from
*each* bank. You already met these shapes in phone and date. For age, the
card now points to its old A or B bank too. The card mark is never copied
into a form field.

## Guided Practice — select before writing
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-AGE-PHONE-DATE-CUE-01] -->

Point to **ਕ**. Point to the A value in each bank, top to bottom: age, phone,
date. Do not write yet. Repeat for **ਖ** and its B values. Check selection
before checking any digits.
