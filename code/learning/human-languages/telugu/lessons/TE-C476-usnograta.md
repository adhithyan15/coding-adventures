# ఉష్ణోగ్రత (uṣṇōgrata) — temperature

## You'll want to know: ఉష్ణోగ్రత
<!-- hl-knowledge: introduces=[TE-LEX-C476-USHNOGRATA476-02]; assesses=[] -->

**ఉష్ణోగ్రత** — *uṣṇōgrata* — "temperature".

> ఇవాళ ఉష్ణోగ్రత నలభై డిగ్రీలు దాటింది.
>
> *ivāḷa uṣṇōgrata nalabhai ḍigrīlu dāṭindi.*
>
> Today the temperature went above forty degrees.

ఉష్ణ, heat, + ఉగ్రత, fierceness: how fierce the heat is.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ఉష్ణోగ్రత** (*uṣṇōgrata*) is built from Sanskrit *uṣṇa*, "hot, heat" (CDIAL 2389), and *ugratā*, "fierceness" (Monier-Williams).
