# ಆರ್ದ್ರತೆ (ārdrate) — humidity

## You'll want to know: ಆರ್ದ್ರತೆ
<!-- hl-knowledge: introduces=[KA-LEX-C484-TAPAMANA484-02]; assesses=[] -->

**ಆರ್ದ್ರತೆ** — *ārdrate* — "humidity".

> ಕರಾವಳಿಯಲ್ಲಿ ಆರ್ದ್ರತೆ ಹೆಚ್ಚು, ಅದಕ್ಕೇ ಸೆಕೆ ಆಗುತ್ತದೆ.
>
> *karāvaḷiyalli ārdrate heccu, adakkē seke āguttade.*
>
> Humidity is high on the coast, and that is why it feels sticky.

Weather reports give it in per cent.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಆರ್ದ್ರತೆ** (*ārdrate*) is built from Sanskrit *ārdra*, "wet" (CDIAL 1340), with the noun ending -*tā*, "-ness": wetness.
