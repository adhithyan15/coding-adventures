## You'll want to know: روزگار
<!-- hl-knowledge: introduces=[UR-LEX-C494-ROZGAR494-02]; assesses=[] -->

**روزگار** — *rozgār* — "employment; a livelihood".

> اس شہر میں روزگار کم ہے۔
>
> *is shahr meṅ rozgār kam hai.*
>
> There is little work to be had in this city.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**روزگار** (*rozgār*) is usually traced to Persian *rōzgār*, "the days, the times", built on *rōz*, "a day"; the sense "a livelihood" is the one Urdu uses.
