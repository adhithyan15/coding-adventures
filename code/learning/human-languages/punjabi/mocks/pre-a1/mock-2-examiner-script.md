# Punjabi pre-A1 mock 2 — confidential examiner and recording script

Do not give this file to the learner. Before administration, a qualified
Punjabi speaker records each listening and dictation stimulus as its named
audio file. Use one documented pronunciation variety consistently. Record at
70–90 words per minute without translating or spelling the stimulus. Play every
named file twice and leave an eight-second answer pause after each play. A
technical restart replaces the affected play; it does not add a third play.
File duration is measured from the start to the end of the audio file,
including natural silence. Pad a short stimulus with silence; do not stretch,
repeat, or slow its spoken form unnaturally. Reject and rerecord any file
outside its part's published band.

## Writing prompt master

Show each delayed-recall card for ten seconds, then remove it completely before
the learner writes. Produce the dictation files under the same recording rules
as the listening files and play each twice. Every dictation file must last 2–5
seconds, including any natural-silence padding.

1. Card W1: **ਪਿਤਾ**
2. Card W2: **ਮਾਤਾ**
3. `mock-2-w03`: **ਕਲਮ**
4. `mock-2-w04`: **ਮੇਜ਼**
5. `mock-2-w05`: **ਬਸਤਾ**
6. `mock-2-w06`: **ਫੁੱਲ**

## Speaking — live interlocutor

1. Say **ਨਮਸਤੇ।** The learner returns an appropriate greeting.
2. Ask **ਤੁਹਾਡਾ ਨਾਂ ਕੀ ਹੈ?** The learner states a chosen identity.
3. Ask **ਤੁਸੀਂ ਕਿਵੇਂ ਹੋ?**
4. In the support language say: “Tell me one language you speak in Punjabi.”
5. In the support language say: “Tell me one place where you live in Punjabi.”
6. Show a picture of bread. In the support language say: “Ask for this politely
   in Punjabi.” A suitable response is **ਰੋਟੀ, ਮਿਹਰਬਾਨੀ ਕਰਕੇ।** Do not show or
   speak that answer model to the learner.

The interlocutor may repeat each prompt once slowly. Record the speaking paper
for independent scoring under the assessment specification.
