## You'll want to know: സിലബസ്
<!-- hl-knowledge: introduces=[ML-LEX-C433-PRAVESANAM433-05]; assesses=[] -->

**സിലബസ്** — *silabasŭ* — "a syllabus".

> ഇത്തവണ സിലബസ് വളരെ വലുതാണ്.
>
> *ittavaṇa silabasŭ vaḷare valutāṇŭ.*
>
> This time the syllabus is very long.

Plural: സിലബസുകൾ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**സിലബസ്** (*silabasŭ*) was borrowed from English *syllabus*.
