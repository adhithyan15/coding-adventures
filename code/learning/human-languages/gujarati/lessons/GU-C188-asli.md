## You'll want to know: અસલી
<!-- hl-knowledge: introduces=[GU-LEX-C188-GOODS188-03]; assesses=[] -->

**અસલી** — *aslī* — "genuine, real".

> **શું આ નોટ અસલી છે?** — *śũ ā noṭ aslī che?* — "Is this note genuine?"

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**અસલી** (*aslī*) is built on *asal*, "original", a loan from Arabic *aṣl*, "root, origin", which reached Gujarati through Persian; the ending *-ī* makes the adjective. Its Arabic root is *ʾ-ṣ-l* (Lane).
