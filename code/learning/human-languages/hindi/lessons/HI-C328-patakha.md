## You'll want to know: पटाख़ा
<!-- hl-knowledge: introduces=[HI-LEX-C328-ROSHNI328-04]; assesses=[] -->

**पटाख़ा** — *paṭākhā* — "a firecracker".

> बच्चों ने रात भर पटाख़े चलाए।
>
> *baccoṁ ne rāt bhar paṭākhe calāe.*
>
> The children set off firecrackers all night.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**पटाख़ा** (*paṭākhā*) is probably imitative, built on *paṭ*, the sound of a sharp crack. You **पटाख़े चलाते हो**: you set them off.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
