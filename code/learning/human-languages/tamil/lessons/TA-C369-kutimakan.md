# குடிமகன் (kuṭimakaṉ) — a citizen

[PAUSE 2s] Before the new one: say the Tamil for the public, then the Tamil for population.

## You'll want to know: குடிமகன்
<!-- hl-knowledge: introduces=[TA-LEX-C369-CAMUKAM369-04]; assesses=[] -->

**குடிமகன்** — *kuṭimakaṉ* — "a citizen".

> ஒவ்வொரு குடிமகனுக்கும் சில கடமைகள் இருக்கின்றன.
>
> *ovvoru kuṭimakaṉukkum cila kaṭamaikaḷ irukkiṉṟaṉa.*
>
> Every citizen has some duties.

Plural: குடிமக்கள், *kuṭimakkaḷ*.

Plural குடிமக்கள்; a woman citizen is குடிமகள்.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**குடிமகன்** (*kuṭimakaṉ*) is native: *kuṭi*, "house, family, town" (DEDR 1655), and *makaṉ*, "son, person" (DEDR 4616): a son of the town.
