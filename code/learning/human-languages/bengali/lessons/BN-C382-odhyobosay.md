# অধ্যবসায় (ôdhyôbôsāy) — perseverance

## You'll want to know: অধ্যবসায়
<!-- hl-knowledge: introduces=[BN-LEX-C382-NISHTHA382-02]; assesses=[] -->

**অধ্যবসায়** — *ôdhyôbôsāy* — "perseverance".

> অধ্যবসায় থাকলে সাফল্য আসবেই।
>
> *ôdhyôbôsāy thākle sāphôlyô āsbei.*
>
> If you persevere, success will surely come.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**অধ্যবসায়** (*ôdhyôbôsāy*) is Sanskrit *adhyavasāya*, resolve or effort of mind (Monier-Williams). Bengali uses it for the patience to keep trying.
