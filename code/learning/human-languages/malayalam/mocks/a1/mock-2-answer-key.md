## Writing

1. Accept any six relevant, comprehensible personal entries in Malayalam script.
2. Award content for a reason, new day, time, place, and polite close. A
   scorer-only reference response is:

   **നമസ്കാരം മോഹൻ. ഇന്ന് എനിക്ക് ജോലി ഉള്ളതിനാൽ വരാൻ കഴിയില്ല. നമുക്ക് നാളെ
   വൈകുന്നേരം ആറു മണിക്ക് സ്റ്റേഷനടുത്ത് കാണാമോ? ദയവായി അറിയിക്കൂ. വീണ്ടും
   കാണാം.**

Do not show the reference response to the learner or require identical wording.

## Speaking

The interview must answer all five prompts. The description must sustain a
coherent routine for about one minute. The station role-play must ask departure
time and platform, confirm the answer, and close with thanks. Apply the rubric;
do not reward a memorized answer unrelated to the interlocutor's response.
