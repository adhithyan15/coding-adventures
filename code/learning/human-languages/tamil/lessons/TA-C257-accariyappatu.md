## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ஆச்சரியப்படு** (*āccariyappaṭu*) is *āccariyam*, "wonder", from Sanskrit *āścarya*, "wonderful" (CDIAL 1464), with native *paṭu*, "to undergo" (DEDR 3853): "undergo wonder".
