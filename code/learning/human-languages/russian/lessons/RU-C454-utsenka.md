## You'll want to know: уценка
<!-- hl-knowledge: introduces=[RU-LEX-C454-RASPRODAZHA-02]; assesses=[] -->

**уценка** (*utsénka*) — "a markdown, a price reduction".

> На эту куртку большая уценка.
>
> *Na étu kúrtku bolsháya utsénka.*
>
> This jacket has a big markdown.

Feminine. *Товар по уценке* — reduced goods.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*уценка* is built from *у-* 'off' and *цена* 'a price', which is inherited from Proto-Slavic *cěna* (EtymDB).
