# ஏற்றுமதி (ēṟṟumati) — exports

## You'll want to know: ஏற்றுமதி
<!-- hl-knowledge: introduces=[TA-LEX-C511-VANIKAM511-01]; assesses=[] -->

**ஏற்றுமதி** — *ēṟṟumati* — "exports".

> தேயிலை இந்த மாவட்டத்தின் முக்கியமான ஏற்றுமதி.
>
> *tēyilai inta māvaṭṭattiṉ mukkiyamāṉa ēṟṟumati.*
>
> Tea is the main export of this district.

With செய் (*cey*) it becomes a verb: ஏற்றுமதி செய், to export.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ஏற்றுமதி** (*ēṟṟumati*) is built on the native ஏற்று (*ēṟṟu*), "to load, to put on board"; the origin of the second part, -மதி, is not settled.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
