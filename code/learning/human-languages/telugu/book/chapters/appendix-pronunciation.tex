Not to be read before the lessons --- they teach reading through real words,
each letter introduced as a word needs it. This page just gathers the system.

\section*{The three facts}

\begin{enumerate}
  \item \textbf{Consonants carry a built-in ``a.''} \te{క} = ka, \te{మ} = ma,
    \te{ర} = ra. (Many wear the \emph{talakaṭṭu}, a small check-mark hat.)
  \item \textbf{A vowel sign changes that built-in vowel.} \te{కా} = kā,
    \te{కి} = ki, \te{కీ} = kī, \te{కు} = ku, \te{కూ} = kū, \te{కె} = ke,
    \te{కే} = kē, \te{కొ} = ko, \te{కో} = kō.
  \item \textbf{A \emph{virama} strips the vowel, and the bare consonant
    \emph{stacks below} the next as a conjunct.} \te{స} + \te{క} $\to$
    \te{స్క} (ska), \te{న} + \te{య} $\to$ \te{న్య} (nya). A dot
    \textbf{anusvāra} \te{ం} adds a final nasal.
\end{enumerate}

\section*{Worth flagging}

\begin{itemize}
  \item \textbf{Aspiration is written.} \te{క} k / \te{ఖ} kh, \te{ద} d /
    \te{ధ} dh --- the ``h'' is a real puff. Like Kannada (and unlike Tamil),
    Telugu keeps the Sanskrit aspirates and voiced stops as separate letters,
    because it borrowed so many Sanskrit words.
  \item \textbf{Round, looping forms.} Telugu and Kannada are script-sisters,
    shaped for palm-leaf writing; the two look far more like each other than
    like Tamil.
\end{itemize}

\section*{Telugu in the Dravidian family}

\textbf{Dravidian} is a family entirely separate from Indo-European (English,
Latin, Sanskrit). Telugu shares grammar and native vocabulary with Tamil,
Kannada, and Malayalam --- but, like Kannada and unlike Tamil, it borrowed
\emph{heavily} from Sanskrit. It also shows the family is not uniform: where
its sisters say ``no'' with a word from the root \emph{il-}, Telugu uses its
own \emph{lēdu} / \emph{kādu}. The lessons trace, word by word, what is
home-grown and what is borrowed.
