## You'll want to know: کفایت
<!-- hl-knowledge: introduces=[UR-LEX-C420-AAMDANI420-03]; assesses=[] -->

**کفایت** — *kifāyat* — "thrift; economy".

> ہمیں کفایت سے خرچ کرنا چاہیے۔
>
> *hameṅ kifāyat se kharch karnā chāhiye.*
>
> We should spend carefully.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**کفایت** (*kifāyat*) is usually traced, through Persian, to Arabic *kifāya*, "sufficiency, enough"; **کفایت سے** is "thriftily".
