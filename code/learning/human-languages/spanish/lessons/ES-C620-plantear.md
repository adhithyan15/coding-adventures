## You'll want to know: plantear
<!-- hl-knowledge: introduces=[ES-LEX-C620-SOLUCION-05]; assesses=[] -->

**plantear** — "to raise, to bring up; to pose".

> Quiero plantear una pregunta.
>
> *I want to raise a question.*

*Plantear un problema* — to raise a problem. *Plantearse* — to think about doing.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*plantear* is built on *planta* 'sole of the foot; ground plan', a learned borrowing from Latin *planta* (EtymDB): to set something down so all can see it.
