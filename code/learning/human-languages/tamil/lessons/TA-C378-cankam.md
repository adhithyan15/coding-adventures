# சங்கம் (caṅkam) — an association; a union

## You'll want to know: சங்கம்
<!-- hl-knowledge: introduces=[TA-LEX-C378-AMAIPPU378-02]; assesses=[] -->

**சங்கம்** — *caṅkam* — "an association; a union".

> என் அப்பா ஒரு விவசாயிகள் சங்கத்தில் இருக்கிறார்.
>
> *eṉ appā oru vivacāyikaḷ caṅkattil irukkiṟār.*
>
> My father belongs to a farmers' association.

சங்கத்தில் சேர், to join an association.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**சங்கம்** (*caṅkam*) is borrowed from Sanskrit *saṃgha*, "multitude; a society, association, community" (Monier-Williams).
