# அமைப்பு (amaippu) — an organisation; a structure

## You'll want to know: அமைப்பு
<!-- hl-knowledge: introduces=[TA-LEX-C378-AMAIPPU378-01]; assesses=[] -->

**அமைப்பு** — *amaippu* — "an organisation; a structure".

> இந்த அமைப்பு ஏழைக் குழந்தைகளுக்கு உதவுகிறது.
>
> *inta amaippu ēḻaik kuḻantaikaḷukku utavukiṟatu.*
>
> This organisation helps poor children.

Also a structure: உடலின் அமைப்பு, the structure of the body.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**அமைப்பு** (*amaippu*) is native Dravidian: DEDR 162 lists Tamil *amai*, "to be close, attached, joined, settled", and *amaippu*: what is put together.
