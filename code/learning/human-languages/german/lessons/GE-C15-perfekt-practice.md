# Practice — the Perfekt, all four persons

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[GE-GRAMMAR-PERFEKT-HABEN-01] -->

[PAUSE 2s] No new words. Each of the four slots below has had a lesson of its
own, so this is the first place it is safe to set them out together.

## Grammar Lens: the four slots, assembled
<!-- hl-knowledge: introduces=[]; assesses=[GE-GRAMMAR-PERFEKT-ICH-01, GE-GRAMMAR-PERFEKT-DU-01, GE-GRAMMAR-PERFEKT-ER-01, GE-GRAMMAR-PERFEKT-WIR-01, GE-LEX-GESAGT-01] -->

| German | English |
|---|---|
| ich **habe** gesagt | I said |
| du **hast** gesagt | you said |
| er **hat** gesagt | he said |
| wir **haben** gesagt | we said |

One half of the sentence moves and the other does not. Run the four aloud and
hear that *gesagt* never budges.

## The exchange
<!-- hl-knowledge: introduces=[]; assesses=[GE-GRAMMAR-PARTIZIP-FINAL-01, GE-LEX-GESTERN-01, GE-LEX-GELERNT-01, GE-GRAMMAR-PERFEKT-ALS-VERGANGENHEIT-01] -->

| German | English |
|---|---|
| *Was hast du gestern gemacht?* | What did you do yesterday? |
| *Ich habe Deutsch gelernt.* | I learned German. |
| *Und du?* | And you? |
| *Wir haben das auch gemacht.* | We did that too. |
| *Gut gemacht!* | Well done! |

Two joining words slip in without lessons of their own, because the translation
carries them: **was** ("what") and **auch** ("too"). And the last line is
already an idiom — *gut gemacht* is exactly English *well done*, participle and
all.
