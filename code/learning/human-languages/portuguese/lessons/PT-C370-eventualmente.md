## You'll want to know: eventualmente
<!-- hl-knowledge: introduces=[PT-LEX-C370-SENAO-05]; assesses=[] -->

**eventualmente** — "possibly, if need be".

> Eventualmente, podemos jantar mais tarde.
>
> *If need be, we can have dinner later.*

A false friend: eventually is *finalmente* or *por fim*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*eventualmente* is built on *eventual* "possible" with the adverb ending *-mente*; *eventual* rests on Latin *ēventus* "an occurrence" (Lewis & Short).
