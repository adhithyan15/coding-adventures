## You'll want to know: la tragedia
<!-- hl-knowledge: introduces=[ES-LEX-C528-DESASTRE-03]; assesses=[] -->

**la tragedia** — "the tragedy".

> El accidente fue una tragedia para el pueblo.
>
> *The accident was a tragedy for the town.*

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*tragedia* is a learned borrowing from Latin *tragoedia*, which comes from Greek *tragōidía*, built on *trágos* 'goat' and *ōidḗ* 'song' (EtymDB).
