## You'll want to know: ധാർമ്മികമായ
<!-- hl-knowledge: introduces=[ML-LEX-C455-BAHUMANAM455-04]; assesses=[] -->

**ധാർമ്മികമായ** — *dhārmmikamāya* — "ethical; moral".

> അത് ധാർമ്മികമായ ഒരു തീരുമാനമായിരുന്നില്ല.
>
> *atŭ dhārmmikamāya oru tīrumānamāyirunnilla.*
>
> That was not a moral decision.

The noun is ധാർമ്മികത, morality.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ധാർമ്മികമായ** (*dhārmmikamāya*) is built from Sanskrit *dhārmika*, "righteous" (CDIAL 6798), made from *dharma*, "right conduct", with the adjective ending -ആയ.
