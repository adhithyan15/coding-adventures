## You'll want to know: पाहुणचार
<!-- hl-knowledge: introduces=[MR-LEX-C321-PANGAT321-02]; assesses=[] -->

**पाहुणचार** — *pāhuṇcār* — "hosting guests; hospitality".

> त्या गावातल्या लोकांचा पाहुणचार आम्ही कधीच विसरणार नाही.
>
> *tyā gāvātalyā lokāñcā pāhuṇcār āmhī kadhīc visarṇār nāhī.*
>
> We will never forget the hospitality of the people of that village.

Masculine.

Built on पाहुणा, a guest.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**पाहुणचार** (*pāhuṇcār*) is built on *pāhuṇā*, 'a guest', inherited from Sanskrit *prāhuṇa* (CDIAL 8973), with the ending *-cār*.
