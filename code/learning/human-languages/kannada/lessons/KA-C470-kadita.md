# ಕಡಿತ (kaḍita) — a power cut; a cut

## You'll want to know: ಕಡಿತ
<!-- hl-knowledge: introduces=[KA-LEX-C470-KAMAGARI470-03]; assesses=[] -->

**ಕಡಿತ** — *kaḍita* — "a power cut; a cut".

> ಬೇಸಿಗೆಯಲ್ಲಿ ಪ್ರತಿದಿನ ಎರಡು ಗಂಟೆ ಕರೆಂಟ್ ಕಡಿತ ಇರುತ್ತದೆ.
>
> *bēsigeyalli pratidina eraḍu gaṇṭe kareṇṭ kaḍita iruttade.*
>
> In summer there is a two-hour power cut every day.

ಕರೆಂಟ್ ಕಡಿತ, a power cut; ಸಂಬಳ ಕಡಿತ, a pay cut.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಕಡಿತ** (*kaḍita*) is native Dravidian: DEDR 1125 lists Kannada *kaḍi*, "to cut, to chop", with the noun *kaḍita*, "a cut, a portion cut off".
