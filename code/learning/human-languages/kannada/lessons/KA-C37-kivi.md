# ಕಿವಿ (kivi) — "ear," where Tamil's everyday word actually diverges

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C37-KANNU-01, KA-ETYMON-C37-KANNU-02] -->

[PAUSE 2s] *Kaṇṇu* matched all three sisters closely. This one is honest
about matching only some of them.

## You'll want to know: ಕಿವಿ
<!-- hl-knowledge: introduces=[KA-LEX-C37-KIVI-01]; assesses=[] -->

> **ಕಿವಿ** — *kivi* — **ear**

> **ನನ್ನ ಕಿವಿ.** — *nanna kivi.* — "My ear."

## The word, taken apart: a literary cousin, not an everyday one
<!-- hl-knowledge: introduces=[KA-ETYMON-C37-KIVI-02]; assesses=[] -->

**ಕಿವಿ** continues Proto-Dravidian **\*kewi**, "ear." Telugu's everyday word
**చెవి** (*cevi*) is the same root, and so is Tamil's — but only in its
**literary** register: **செவி** (*cevi*) shows up in poetry and formal
speech, while ordinary spoken Tamil reaches for an unrelated word instead,
**காது** (*kātu*). It is the same honest split Chapter 34 found in
**கேள்**/*kēḷ* against Telugu's *vinu* and *aḍugu*: a shared root can go on
living in one register of a language while everyday speech moves on to
something else.
