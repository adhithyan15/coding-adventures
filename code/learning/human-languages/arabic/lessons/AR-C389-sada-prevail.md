## You'll want to know: ساد
<!-- hl-knowledge: introduces=[AR-LEX-C389-NUFUDH389-02]; assesses=[] -->

**ساد** — *sāda* — "to prevail".

> ساد الخوف في المدينة.
>
> *sāda al-khawf fī al-madīna.*
>
> Fear prevailed in the city.

Present: يسود, *yasūd*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ساد** (*sāda*) is built on the native Arabic root *s-w-d*, "to be lord, to be chief" (Lane). *Sāda* is a Form I verb, to be master: to rule, to prevail. سيد, a lord, is from the same root.
