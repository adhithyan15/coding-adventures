# خلاف (khilāf) — against (کے خلاف)

## You'll want to know: خلاف
<!-- hl-knowledge: introduces=[UR-LEX-C335-HIMAYAT335-01]; assesses=[] -->

**خلاف** — *khilāf* — "against (کے خلاف)".

> شہری اس نئے قانون کے خلاف ہیں۔
>
> *shahrī is naye qānūn ke khilāf haiṅ.*
>
> The citizens are against this new law.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**خلاف** (*khilāf*) is usually traced, through Persian, to Arabic *khilāf*, "opposition, the contrary".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
