## You'll want to know: a candidatura
<!-- hl-knowledge: introduces=[PT-LEX-C355-CANDIDATURA-03]; assesses=[] -->

**a candidatura** — "the application (for a job); the candidacy".

> Fiz a candidatura ontem à noite.
>
> *I put in the application last night.*

*Apresentar uma candidatura* — to submit an application.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*candidatura* is built on *candidato* "candidate", from Latin *candidātus* "clothed in white" (Lewis & Short), on *candidus* "shining white".
