# ചാറ്റൽമഴ (cāṟṟalmaḻa) — a light drizzle

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C507-MAZHA507-03, ML-LEX-C507-MAZHA507-04] -->

[PAUSE 2s] Before the new one: say the Malayalam for the northeast monsoon, then the Malayalam for to stop raining.

## You'll want to know: ചാറ്റൽമഴ
<!-- hl-knowledge: introduces=[ML-LEX-C507-MAZHA507-05]; assesses=[] -->

**ചാറ്റൽമഴ** — *cāṟṟalmaḻa* — "a light drizzle".

> രാവിലെ മുതൽ ചാറ്റൽമഴ ഉണ്ട്.
>
> *rāvile mutal cāṟṟalmaḻa uṇṭŭ.*
>
> There has been a light drizzle since morning.

ചാറ്റൽ, drizzling, plus മഴ, rain.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ചാറ്റൽമഴ** (*cāṟṟalmaḻa*) is a native Dravidian compound of ചാറ്റൽ, drizzling (DEDR 2482), and മഴ, rain (DEDR 4753).
