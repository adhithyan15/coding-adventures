## You'll want to know: مرجع
<!-- hl-knowledge: introduces=[AR-LEX-C395-MARJI395-01]; assesses=[] -->

**مرجع** — *marjiʿ* — "a reference".

> هذا القاموس مرجع مهم.
>
> *hādhā al-qāmūs marjiʿ muhimm.*
>
> This dictionary is an important reference.

Plural: مراجع, *marājiʿ*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**مرجع** (*marjiʿ*) is built on the native Arabic root *r-j-ʿ*, "to return, to go back" (Lane). *Marjiʿ* is a noun of place, a place one goes back to: a reference.
