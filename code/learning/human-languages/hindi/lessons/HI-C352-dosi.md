# दोषी (doṣī) — guilty

## You'll want to know: दोषी
<!-- hl-knowledge: introduces=[HI-LEX-C352-ADALAT352-04]; assesses=[] -->

**दोषी** — *doṣī* — "guilty".

> अदालत ने उसे दोषी माना।
>
> *adālat ne use doṣī mānā.*
>
> The court found him guilty.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**दोषी** (*doṣī*) is a tatsama, borrowed from Sanskrit *doṣin*, "guilty of an offence" (Monier-Williams).
