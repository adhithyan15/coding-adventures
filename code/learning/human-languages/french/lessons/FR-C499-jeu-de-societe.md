## You'll want to know: le jeu de société
<!-- hl-knowledge: introduces=[FR-LEX-C499-JEUX-01]; assesses=[] -->

**le jeu de société** — "board game".

> Le soir, nous jouons à un jeu de société.
>
> *In the evening we play a board game.*

Plural *des jeux de société*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*le jeu de société* is "a game for company": *jeu* is inherited from Latin *iocus* "a joke, play", and *société* from Latin *societās*, built on *socius* "companion" (Lewis & Short).
