## You'll want to know: bedrohen
<!-- hl-knowledge: introduces=[GE-LEX-C282-UEBERFALL-04]; assesses=[] -->

**bedrohen** — "to threaten".

> Er bedrohte den Verkäufer mit einem Messer.
>
> *He threatened the shop assistant with a knife.*

*Jemanden mit etwas bedrohen*. The plain verb *drohen* takes the dative: *er drohte ihm*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*bedrohen* is built on *drohen* "to threaten", from Old High German *drouwen* (EtymDB), with the prefix *be-*.
