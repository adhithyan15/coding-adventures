# Changelog

All notable changes to this package will be documented in this file.

## [0.1.0] - 2026-09-26

### Added

- Bounded decoding for the generic RFC 5280 Extension shape.
- Opaque process-backed values, shared caller limits, exact local offsets,
  opaque extension bytes, and payload-blind stable errors.
- The complete 48-case neutral suite, native forgery and redaction checks, a
  95 percent production line-coverage gate, Mix metadata, Unix and Windows
  build fronts, and an empty capability manifest.
