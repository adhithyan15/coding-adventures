## You'll want to know: ரொக்கம்
<!-- hl-knowledge: introduces=[TA-LEX-C446-VANKI446-05]; assesses=[] -->

**ரொக்கம்** — *rokkam* — "cash".

> இந்தக் கடையில் ரொக்கமாக மட்டும் பணம் வாங்குகிறார்கள்.
>
> *intak kaṭaiyil rokkamāka maṭṭum paṇam vāṅkukiṟārkaḷ.*
>
> This shop takes payment only in cash.

ரொக்கமாக is in cash.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ரொக்கம்** (*rokkam*), "cash, ready money", is a word whose origin is not settled.
