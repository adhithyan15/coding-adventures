# l'allenamento — training, practice

## You'll want to know: l'allenamento
<!-- hl-knowledge: introduces=[IT-LEX-C508-PALESTRA-02]; assesses=[] -->

**l'allenamento** — "training, practice".

> L'allenamento di oggi è stato durissimo.
>
> *Today's training was really hard.*

*Saltare l'allenamento* — to skip training.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*allenamento* is built on *allenare* "to train", from *lena* "vigour, breath", with *-mento* for the action; the origin of *lena* is not settled.
