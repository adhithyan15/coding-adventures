## You'll want to know: துரு
<!-- hl-knowledge: introduces=[TA-LEX-C445-MINVETTU445-03]; assesses=[] -->

**துரு** — *turu* — "rust".

> பழைய இரும்புக் கதவில் துரு பிடித்திருக்கிறது.
>
> *paḻaiya irumpuk katavil turu piṭittirukkiṟatu.*
>
> The old iron gate has rusted.

துரு பிடி is to rust.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**துரு** (*turu*) is native Dravidian (DEDR 3343), "rust, verdigris".
