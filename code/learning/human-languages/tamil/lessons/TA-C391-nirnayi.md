# நிர்ணயி (nirṇayi) — to fix; to set

## You'll want to know: நிர்ணயி
<!-- hl-knowledge: introduces=[TA-LEX-C391-PORULATARAM391-05]; assesses=[] -->

**நிர்ணயி** — *nirṇayi* — "to fix; to set".

> அரசு அரிசியின் விலையை நிர்ணயித்தது.
>
> *aracu ariciyiṉ vilaiyai nirṇayittatu.*
>
> The government fixed the price of rice.

Past (I …): நிர்ணயித்தேன், *nirṇayittēṉ*.

What is fixed takes -ஐ: விலையை நிர்ணயி. The noun is நிர்ணயம்.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**நிர்ணயி** (*nirṇayi*) is a verb built on Sanskrit *nirṇaya*, "complete ascertainment, decision, settlement" (Monier-Williams), with the loan-verb ending -இ.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
