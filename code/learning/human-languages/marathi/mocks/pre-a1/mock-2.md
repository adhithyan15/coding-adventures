# Marathi pre-A1 mock 2 — learner paper

Give this paper to the learner. Keep
[`mock-2-examiner-script.md`](mock-2-examiner-script.md) separate. Total
administration is 32 written minutes plus 8 speaking minutes. Support-language
directions may explain the action but may not translate answer-bearing Marathi.

## Reading — 10 minutes

Choose the English meaning or situation.

<!-- mock-part:prea1-reading-signs-and-words -->
1. **दूध** — A milk / B tea / C water
2. **चहा** — A home / B tea / C school
3. **भाकरी** — A greeting / B name / C flatbread
4. **मित्र** — A friend / B book / C city
5. **मराठी** — A water / B Marathi / C thanks
6. **कृपया** — A please / B tomorrow / C home
<!-- /mock-part:prea1-reading-signs-and-words -->
<!-- mock-part:prea1-reading-phrases-and-notices -->
7. **नमस्कार.** — A greeting / B a request for milk / C a city
8. **पाणी द्या, कृपया.** — A Give water, please. / B Bring tea, please. / C Sit, please.
9. **चहा आणा, कृपया.** — A Write your name. / B Bring tea, please. / C See you tomorrow.
10. **भेटून आनंद झाला.** — A I live in Pune. / B My name is Arun. / C Pleased to meet you.
<!-- /mock-part:prea1-reading-phrases-and-notices -->
<!-- mock-part:prea1-reading-personal-details -->
11. **माझं नाव अरुण आहे.** — A The name is Arun. / B The city is Arun. / C Arun is at school.
12. **मी मराठी बोलतो.** — A I write Marathi. / B I speak Marathi. / C I want Marathi.
13. **मी बरी आहे.** — A I am well. / B I am Mira. / C I am at home.
14. Form field **नाव: सारा** — A city Sara / B language Sara / C name Sara
<!-- /mock-part:prea1-reading-personal-details -->

## Listening — 10 minutes

Listen to each numbered item twice. Choose A, B, or C. The examiner's Marathi
lines stay in the separate script.

1. A water / B milk / C tea
2. A tea / B book / C home
3. A flatbread / B greeting / C school
4. A city / B friend / C name
5. A thanks / B Marathi / C water
6. A tomorrow / B please / C goodbye

7. A return the greeting / B name a city / C ask for milk
8. A introduce yourself / B acknowledge the meeting / C request water
9. A ask for tea politely / B state a name / C say goodbye
10. A return the tomorrow farewell / B ask how someone is / C say thanks
<!-- /mock-part:prea1-listening-greeting-responses -->
<!-- mock-part:prea1-listening-personal-details -->

13. A name Mira / B city Pune / C language Marathi
14. A is well / B is at home / C is at school
<!-- /mock-part:prea1-listening-personal-details -->

## Writing — 12 minutes

<!-- mock-part:prea1-writing-delayed-recall -->
1. Look at the examiner's first word card for ten seconds. After it is covered,
   write the word once: ____________________
2. Look at the second word card for ten seconds. After it is covered, write the
   word once: ____________________
<!-- /mock-part:prea1-writing-delayed-recall -->
<!-- mock-part:prea1-writing-dictation -->
3. Listen to item W3 twice and write the word: ____________________
4. Listen to item W4 twice and write the word: ____________________
5. Listen to item W5 twice and write the word: ____________________
6. Listen to item W6 twice and write the word: ____________________
<!-- /mock-part:prea1-writing-dictation -->
<!-- mock-part:prea1-writing-bounded-production -->
7. Write one Marathi word for a drink shown by the nonverbal cue. No answer
   model is shown.
8. Write one Marathi farewell appropriate for seeing someone tomorrow. No
   answer model is shown.
<!-- /mock-part:prea1-writing-bounded-production -->

## Speaking — 8 minutes

Answer each prompt in Marathi. The examiner may repeat each prompt once slowly.
The spoken prompts stay in the separate script.

<!-- mock-part:prea1-speaking-greeting-and-identity -->
1. Return the examiner's greeting.
2. State your chosen identity.
<!-- /mock-part:prea1-speaking-greeting-and-identity -->
<!-- mock-part:prea1-speaking-familiar-questions -->
3. Answer a familiar question about your preferred drink.
4. Answer a familiar question about knowing Marathi.
5. Answer a familiar question about your home or city.
<!-- /mock-part:prea1-speaking-familiar-questions -->
<!-- mock-part:prea1-speaking-short-request -->
6. Make one short polite request for tea in the situation the examiner gives.
<!-- /mock-part:prea1-speaking-short-request -->

No written answer script, dictionary, translator, or coaching is allowed.
