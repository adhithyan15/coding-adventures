## You'll want to know: تحليل
<!-- hl-knowledge: introduces=[AR-LEX-C510-TASHKHIS510-02]; assesses=[] -->

**تحليل** — *taḥlīl* — "a lab test; an analysis".

> طلب الطبيب تحليل دم.
>
> *ṭalaba aṭ-ṭabīb taḥlīl dam.*
>
> The doctor asked for a blood test.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**تحليل** (*taḥlīl*) is built on the native Arabic root *ḥ-l-l*, "to untie, to loosen" (Lane). Ḥall, a solution, which you know, is from the same root: taḥlīl takes a thing apart.

## What you've built

One more word for describing what you lived and felt.
