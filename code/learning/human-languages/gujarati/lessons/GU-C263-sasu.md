# સાસુ (sāsu) — mother-in-law

## You'll want to know: સાસુ
<!-- hl-knowledge: introduces=[GU-LEX-C263-INLAWS263-04]; assesses=[] -->

**સાસુ** — *sāsu* — "mother-in-law".

> **તેની સાસુ ગુસ્સો નથી કરતી.** — *tenī sāsu gusso nathī kartī* — "Her mother-in-law does not get angry."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**સાસુ** (*sāsu*) is a tadbhava. It comes from Sanskrit *śvaśrū́*, "husband's or wife's mother" (CDIAL 12759).
