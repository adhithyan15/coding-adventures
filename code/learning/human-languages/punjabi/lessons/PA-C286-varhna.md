# ਵਰ੍ਹਨਾ (varhnā) — to pour down; to rain hard

## You'll want to know: ਵਰ੍ਹਨਾ
<!-- hl-knowledge: introduces=[PA-LEX-C286-STORM286-03]; assesses=[] -->

**ਵਰ੍ਹਨਾ** — *varhnā* — "to pour down; to rain hard".

> ਕੱਲ੍ਹ ਬਹੁਤ ਮੀਂਹ ਵਰ੍ਹੇਗਾ।
>
> *kall bahut mīṁh varhegā.*
>
> Tomorrow a lot of rain will pour down.

Past (it …): ਉਹ ਮੀਂਹ ਵਰ੍ਹਿਆ, *oh mīṁh varhiā*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ਵਰ੍ਹਨਾ** (*varhnā*) is inherited from Sanskrit *varṣati*, "it rains"; CDIAL lists Punjabi *varhṇā*, "to rain", under it (CDIAL 11394).
