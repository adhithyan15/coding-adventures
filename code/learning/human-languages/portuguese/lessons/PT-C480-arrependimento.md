## You'll want to know: o arrependimento
<!-- hl-knowledge: introduces=[PT-LEX-C480-REMORSO-02]; assesses=[] -->

**o arrependimento** — "regret".

> Sente arrependimento pelo que disse.
>
> *He feels regret for what he said.*

Built on *arrepender* with *-imento*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*arrependimento* is built on *arrepender* "to regret", which goes back to Latin *paenitēre* "to cause regret" (EtymDB).
