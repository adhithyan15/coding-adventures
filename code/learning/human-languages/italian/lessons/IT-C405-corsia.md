## You'll want to know: la corsia
<!-- hl-knowledge: introduces=[IT-LEX-C405-AUTOSTRADA-02]; assesses=[] -->

**la corsia** — "the lane (of a road); the ward (in a hospital)".

> Resta nella corsia di destra.
>
> *Stay in the right-hand lane.*

*La corsia di emergenza* is the hard shoulder; in a hospital, *la corsia* is a ward.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*corsia* is built on *corsa* 'run, course', which goes back to Latin *currere* 'to run' (Lewis & Short): a lane is a strip to run along. The words are inherited from Latin.
