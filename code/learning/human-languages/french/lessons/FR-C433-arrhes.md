## You'll want to know: les arrhes
<!-- hl-knowledge: introduces=[FR-LEX-C433-DEDOMMAGEMENT-02]; assesses=[] -->

**les arrhes** — "the deposit (that is not refunded)".

> Si vous annulez, vous perdez les arrhes.
>
> *If you cancel, you lose the deposit.*

Feminine plural: *des arrhes*. The *h* is silent.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*arrhes* is a learned borrowing from Latin *arrha* 'pledge' (EtymDB), which came from Greek *arrhabṓn*.
