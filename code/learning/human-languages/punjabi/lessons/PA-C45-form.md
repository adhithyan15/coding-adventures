# (reading) — a form somebody else filled in

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-SKILL-READ-LABELS] -->

[PAUSE 2s] The last lesson gave you the labels alone. Here each one has an
answer beside it.

[PAUSE 1s] Every value below is one you have written yourself.

## Reading
<!-- hl-knowledge: introduces=[PA-SKILL-READ-FORM]; assesses=[PA-FORM-WORK-JOB-01, PA-FORM-RESIDENCE-CITY-01] -->

> ਨਾਂ: ਅਮਨ
> ਉਮਰ: ੨੫
> ਕੰਮ: ਨੌਕਰੀ
> ਰਿਹਾਇਸ਼: ਸ਼ਹਿਰ
> ਭਾਸ਼ਾ: ਪੰਜਾਬੀ
> ਫ਼ੋਨ: ੦੧੨ ੨੫੧

[PAUSE 3s] Read it through once, without stopping.

[PAUSE 3s] Now answer without looking back: what does this person do?

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[PA-SKILL-READ-FORM] -->

[PAUSE 2s] A form is the first real thing a beginner can read end to end,
because it is built to be read fast and gives you the label before the value
every time.

[PAUSE 2s] Notice the colon does the work a verb would do in a sentence. There
is no **ਹੈ** anywhere on this page, and nothing is missing.

[PAUSE 2s] Six lines, and you now know six things about somebody you have never
met.
