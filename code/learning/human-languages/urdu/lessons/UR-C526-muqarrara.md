## You'll want to know: مقررہ
<!-- hl-knowledge: introduces=[UR-LEX-C526-MIAD526-02]; assesses=[] -->

**مقررہ** — *muqarrarā* — "fixed in advance; set (of a time)".

> اگر میچ مقررہ وقت پر ہوا تو ہم جائیں گے۔
>
> *agar maich muqarrarā vaqt par huā to ham jāeṅ ge.*
>
> If the match is held at the set time, we will go.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**مقررہ** (*muqarrarā*) is usually traced, through Persian, to Arabic *muqarrara*, "fixed, settled".
