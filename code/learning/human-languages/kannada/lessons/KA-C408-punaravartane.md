## You'll want to know: ಪುನರಾವರ್ತನೆ
<!-- hl-knowledge: introduces=[KA-LEX-C408-PATHYAKRAMA408-05]; assesses=[] -->

**ಪುನರಾವರ್ತನೆ** — *punarāvartane* — "revision; repetition".

> ಪರೀಕ್ಷೆಗೆ ಮೊದಲು ಪುನರಾವರ್ತನೆ ಮುಖ್ಯ.
>
> *parīkṣege modalu punarāvartane mukhya.*
>
> Revision is important before an exam.

ಪುನರ್ (again) + ಆವರ್ತನೆ (turning round).

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಪುನರಾವರ್ತನೆ** (*punarāvartane*) is built from Sanskrit *punar*, "again", and *āvartana*, "turning round, revolving" (Monier-Williams).
