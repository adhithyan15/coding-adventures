# നവീകരിക്കുക (navīkarikkuka) — to modernise; to renovate

## You'll want to know: നവീകരിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C431-VIKASANAM431-03]; assesses=[] -->

**നവീകരിക്കുക** — *navīkarikkuka* — "to modernise; to renovate".

> പഞ്ചായത്ത് പഴയ ലൈബ്രറി നവീകരിച്ചു.
>
> *pañcāyattŭ paḻaya laibraṟi navīkariccu.*
>
> The panchayat renovated the old library.

Past: നവീകരിച്ചു, *navīkariccu*.

The noun is നവീകരണം, renovation.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**നവീകരിക്കുക** (*navīkarikkuka*) is built from Sanskrit *nava*, "new, young" (CDIAL 6983), with -ീകരിക്കുക, "to make into": to make a thing new.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
