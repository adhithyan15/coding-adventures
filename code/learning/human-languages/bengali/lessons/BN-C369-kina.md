# কিনা (kinā) — whether (or not)

## You'll want to know: কিনা
<!-- hl-knowledge: introduces=[BN-LEX-C369-KINA369-01]; assesses=[] -->

**কিনা** — *kinā* — "whether (or not)".

> অরুণ আসবে কিনা জানি না; এলে আমরা একসঙ্গে খাব।
>
> *ôrun āsbe kinā jāni nā; ele āmrā eksôngge khābô.*
>
> I don't know whether Arun will come; if he does, we'll eat together.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**কিনা** (*kinā*) is কি, 'what, whether' (CDIAL 3164 lists Bengali ki), with না, 'not': 'whether or not'. It comes after the verb it questions: আসবে কিনা.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
