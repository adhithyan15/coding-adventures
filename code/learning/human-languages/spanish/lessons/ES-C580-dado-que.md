## You'll want to know: dado que
<!-- hl-knowledge: introduces=[ES-LEX-C580-MOTIVO-05]; assesses=[] -->

**dado que** — "given that".

> Dado que no hay dinero, esperamos.
>
> *Given that there is no money, we wait.*

Formal, like *puesto que*; it is followed by the indicative.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*dado que* is built on *dado*, inherited from Latin *datus* 'given', the participle of *dare* 'to give' (EtymDB).
