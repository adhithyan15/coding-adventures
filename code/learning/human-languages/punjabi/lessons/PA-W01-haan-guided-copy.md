# ਹਾਂ — one supported copy

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-SCRIPT-HA-01, PA-SCRIPT-AA-MATRA-01, PA-SCRIPT-BINDI-01, PA-SCRIPT-HAAN-01] -->

Keep **ਹਾਂ** visible. Point to **ਹ**, then attached **ਾ**, then the bindi **ਂ**.
Read the known answer *hā̃*, “yes.”

## Writing — guided copy
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-HAAN-NAHIN-01, PA-SCRIPT-HA-01, PA-SCRIPT-AA-MATRA-01, PA-SCRIPT-BINDI-01, PA-SCRIPT-HAAN-01] -->
<!-- hl-writing-stage: guided-copy -->

Copy **ਹਾਂ** once beside the model. Look back after every piece if you need to.
Touch the three pieces in your copy and read *hā̃*. Large and slow is correct;
memory is not being tested yet.
