# inmediatamente — immediately

## You'll want to know: inmediatamente
<!-- hl-knowledge: introduces=[ES-LEX-C534-PRONTO-03]; assesses=[] -->

**inmediatamente** — "immediately".

> Llamé inmediatamente a la policía.
>
> *I immediately called the police.*

*Enseguida* is a more everyday word for it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*inmediatamente* is built on *inmediato* and the ending *-mente* (EtymDB). *Inmediato* is a learned word from Latin *immediātus* 'with nothing in the middle', from *medius* 'middle'.
