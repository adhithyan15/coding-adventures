## You'll want to know: غریبه
<!-- hl-knowledge: introduces=[FA-LEX-C504-FRIENDS-04]; assesses=[] -->

**غریبه** (*gharibe*) — "a stranger".

> بچه ها با غریبه ها حرف نمیزنند.
>
> *bachchehâ bâ gharibehâ harf nemizanand.*
>
> The children don't talk to strangers.

Built on *gharib* 'strange, foreign' with *-e*. Plural *gharibehâ*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*gharibe* is built in Persian on *gharib*, 'strange', which was borrowed from Arabic *ġarīb*, 'outsider, foreigner' (EtymDB), with the native ending *-e*.
