# હિંમત (himmat) — courage

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[GU-LEX-C271-MANNERS271-04, GU-LEX-C271-MANNERS271-05] -->

[PAUSE 2s] Before the new one: say the Gujarati for foolish, then the Gujarati for stubborn.

## You'll want to know: હિંમત
<!-- hl-knowledge: introduces=[GU-LEX-C272-PROMISE272-01]; assesses=[] -->

**હિંમત** — *himmat* — "courage".

> **મારામાં બોલવાની હિંમત નથી.** — *mārāmā̃ bolvānī himmat nathī* — "I do not have the courage to speak."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**હિંમત** (*himmat*) is a loan from Arabic *himma*, "resolve, aspiration", which reached Gujarati through Persian. Its Arabic root is *h-m-m*, "to intend" (Lane).
