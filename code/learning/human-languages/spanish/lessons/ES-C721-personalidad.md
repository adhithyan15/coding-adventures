## You'll want to know: la personalidad
<!-- hl-knowledge: introduces=[ES-LEX-C721-CARACTER-02]; assesses=[] -->

**la personalidad** — "personality".

> Tiene una personalidad muy fuerte.
>
> *She has a very strong personality.*

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*personalidad* is a learned borrowing from Late Latin *persōnālitās* (EtymDB), built on *persōna* "an actor's mask, a role", the source of *persona*.
