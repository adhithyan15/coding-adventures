# சுற்றுவழி (cuṟṟuvaḻi) — a detour; a roundabout way

## You'll want to know: சுற்றுவழி
<!-- hl-knowledge: introduces=[TA-LEX-C403-SALAI403-03]; assesses=[] -->

**சுற்றுவழி** — *cuṟṟuvaḻi* — "a detour; a roundabout way".

> பாலம் மூடியிருந்ததால் சுற்றுவழியில் போனோம்.
>
> *pālam mūṭiyiruntatāl cuṟṟuvaḻiyil pōṉōm.*
>
> Because the bridge was closed, we went by a detour.

சுற்று, to go around, + வழி, way: the long way round.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**சுற்றுவழி** (*cuṟṟuvaḻi*) is built from சுற்று, "to go around" (DEDR 2715), and வழி, "a way" (DEDR 5297).
