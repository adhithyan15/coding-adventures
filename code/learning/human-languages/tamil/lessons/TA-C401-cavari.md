## You'll want to know: சவாரி
<!-- hl-knowledge: introduces=[TA-LEX-C401-PERUNTU401-05]; assesses=[] -->

**சவாரி** — *cavāri* — "a ride".

> குழந்தைகள் யானைச் சவாரி செய்தார்கள்.
>
> *kuḻantaikaḷ yāṉaic cavāri ceytārkaḷ.*
>
> The children went for an elephant ride.

சவாரி செய் is to go for a ride; யானைச் சவாரி, an elephant ride.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**சவாரி** (*cavāri*) is a loan from Persian *savārī*, "riding, a mount", which reached Tamil through Hindustani.
