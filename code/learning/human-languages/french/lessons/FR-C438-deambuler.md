## You'll want to know: déambuler
<!-- hl-knowledge: introduces=[FR-LEX-C438-FLANER-03]; assesses=[] -->

**déambuler** — "to walk about, to wander".

> Les touristes déambulent entre les boutiques.
>
> *The tourists wander about between the shops.*

A bit literary.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*déambuler* is a learned borrowing from Latin *deambulāre* 'to walk about', from *dē-* and *ambulāre* 'to walk' (EtymDB).
