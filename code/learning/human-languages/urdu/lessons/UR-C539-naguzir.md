## You'll want to know: ناگزیر
<!-- hl-knowledge: introduces=[UR-LEX-C539-MUKHTAR539-03]; assesses=[] -->

**ناگزیر** — *nāguzīr* — "unavoidable".

> اگر سفر ناگزیر ہے تو صبح جلدی نکلیے۔
>
> *agar safar nāguzīr hai to subah jaldī nikliye.*
>
> If the journey can't be avoided, set off early in the morning.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ناگزیر** (*nāguzīr*) is usually traced to Persian *nāguzīr*, "with no way out", built from *nā*, "not", and *guzīr*, "escape".
