# ಪ್ರವಾಸೋದ್ಯಮ (pravāsōdyama) — tourism; the tourist trade

## You'll want to know: ಪ್ರವಾಸೋದ್ಯಮ
<!-- hl-knowledge: introduces=[KA-LEX-C455-PRAVASA455-01]; assesses=[] -->

**ಪ್ರವಾಸೋದ್ಯಮ** — *pravāsōdyama* — "tourism; the tourist trade".

> ಈ ಜಿಲ್ಲೆಯಲ್ಲಿ ಪ್ರವಾಸೋದ್ಯಮ ತುಂಬಾ ಬೆಳೆದಿದೆ.
>
> *ī jilleyalli pravāsōdyama tumbā beḷedide.*
>
> Tourism has grown a lot in this district.

ಪ್ರವಾಸ, a trip, plus ಉದ್ಯಮ, an industry; ಪ್ರವಾಸಿ is a tourist.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಪ್ರವಾಸೋದ್ಯಮ** (*pravāsōdyama*) is a modern compound built from Sanskrit words: *pravāsa*, "dwelling abroad, a journey" (CDIAL 8802), and *udyama*, "an undertaking, effort" (CDIAL 2048).
