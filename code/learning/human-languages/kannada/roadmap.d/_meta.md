# Kannada Roadmap

Same shape as the other tracks: deep one-word lessons in themed chapters.
Slug-identified; order lives in the book and
[`session-map.md`](./session-map.md). See
[`HL00`](../../../specs/HL00-human-language-curriculum-framework.md).

Grounding: English + the **Dravidian family** (Tamil the anchor, plus Telugu
and Malayalam) + Sanskrit/Hindi. The recurring thread is Kannada's heavy
Sanskrit borrowing set against the native Dravidian core it still keeps. The
Kannada script is taught **inline**, inside the word lessons, never as a gated
reading course. Grammar is introduced piece by piece, on the first word that
needs it.

Coverage note: canonical lessons now continue through Chapter 73, while the
narrative sequence below is complete only through Chapter 6. `HL-M03` tracks
bringing this roadmap and the session map up to the canonical prerequisite
order; `HL-B24` tracks publishing Chapters 6–31 from the same source.
