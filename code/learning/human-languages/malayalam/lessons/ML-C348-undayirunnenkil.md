# ഉണ്ടായിരുന്നെങ്കിൽ (uṇṭāyirunneṅkil) — if there had been: the unreal condition

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-GRAMMAR-C339-PAST-HABITUAL-01, ML-GRAMMAR-C347-ENKIL-VERB-01, ML-GRAMMAR-C339-UNDAYIRUNNU-01] -->

[PAUSE 2s] Say "I used to go". (*ñān pōkumāyirunnu*.) Then "there was". (*uṇṭāyirunnu*.) Then "if
there is". (*uṇṭeṅkil*.)

## Grammar Lens: -ഇരുന്നെങ്കിൽ, if only it had been so
<!-- hl-knowledge: introduces=[ML-GRAMMAR-C348-UNREAL-IF-01]; assesses=[ML-GRAMMAR-C339-UNDAYIRUNNU-01, ML-GRAMMAR-C347-ENKIL-VERB-01, ML-LEX-C91-MONEY-02, ML-CONCEPT-C32-ARIYUKA-01] -->

For something that is not so, or was not, put **ഇരുന്നെങ്കിൽ** after the past form: **വന്നു** →
**വന്നിരുന്നെങ്കിൽ**, "if (he) had come"; **അറിഞ്ഞു** → **അറിഞ്ഞിരുന്നെങ്കിൽ**, "if (I) had known";
**ഉണ്ടായി** → **ഉണ്ടായിരുന്നെങ്കിൽ**, "if there had been", "if (I) had".

## Grammar Lens: -ഉമായിരുന്നു, would
<!-- hl-knowledge: introduces=[ML-GRAMMAR-C348-WOULD-01]; assesses=[ML-GRAMMAR-C339-PAST-HABITUAL-01, ML-LEX-C91-MONEY-02, ML-LEX-C183-KRIYA183-04, ML-LEX-C121-TRAVEL-03, ML-LEX-C172-ACT172-04] -->

The other half is the **-ഉമായിരുന്നു** from the start of this core, now with its second job: "would", "would
have".

> **പണം ഉണ്ടായിരുന്നെങ്കിൽ ഞാൻ പോകുമായിരുന്നു.**
>
> *paṇaṁ uṇṭāyirunneṅkil ñān pōkumāyirunnu.* — "If I had money, I would go."

The same sentence also says "if I had had money, I would have gone"; the context decides which.

> **നീ നേരത്തെ വന്നിരുന്നെങ്കിൽ നമുക്ക് ബസ് കിട്ടുമായിരുന്നു.**
>
> *nī nēratte vannirunneṅkil namukkŭ basŭ kiṭṭumāyirunnu.* — "If you had come earlier, we would have caught the bus."

> **അറിഞ്ഞിരുന്നെങ്കിൽ ഞാൻ വിളിക്കുമായിരുന്നു.**
>
> *aṟiññirunneṅkil ñān viḷikkumāyirunnu.* — "If I had known, I would have called."

With **-അണം** it is regret: **ഞാൻ പോകണമായിരുന്നു** (*ñān pōkaṇamāyirunnu*), "I should have gone".
