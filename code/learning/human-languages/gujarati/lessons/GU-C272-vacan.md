# વચન (vacan) — promise, word

<!-- hl-knowledge: introduces=[]; assesses=[GU-LEX-C271-MANNERS271-05, GU-LEX-C272-PROMISE272-01] -->

[PAUSE 2s] Before the new one: say the Gujarati for stubborn, then the Gujarati for courage.

## You'll want to know: વચન
<!-- hl-knowledge: introduces=[GU-LEX-C272-PROMISE272-02]; assesses=[] -->

**વચન** — *vacan* — "promise, word".

> **શું તમે વચન આપો છો?** — *śũ tame vacan āpo cho?* — "Do you promise?"

A neuter noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**વચન** (*vacan*) is Sanskrit *vacaná*, "speaking, statement", taken over as a tatsama. CDIAL also lists the inherited Gujarati *veṇ*, "word, promise", from the same word (CDIAL 11199).
