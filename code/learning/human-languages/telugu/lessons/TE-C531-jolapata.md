## You'll want to know: జోలపాట
<!-- hl-knowledge: introduces=[TE-LEX-C531-SANTANAM531-05]; assesses=[] -->

**జోలపాట** — *jōlapāṭa* — "a lullaby".

> అమ్మ జోలపాట పాడగానే పాప నిద్రపోయింది.
>
> *amma jōlapāṭa pāḍagānē pāpa nidrapōyindi.*
>
> As soon as mum sang a lullaby, the baby fell asleep.

జోల, rocking, + పాట, song.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**జోలపాట** (*jōlapāṭa*) is native Dravidian: DEDR 2889 lists Telugu *jōla*, "lullaby, cradle song", beside Kannada *jōl*, "to swing"; పాట is "song" (DEDR 4065).
