## You'll want to know: следователь
<!-- hl-knowledge: introduces=[RU-LEX-C291-SLEDOVATEL-01]; assesses=[] -->

**следователь** (*slédovatel*) — "an investigator, a detective".

> Следователь долго говорил со свидетелем.
>
> *Slédovatel dólgo govoríl so svidételem.*
>
> The investigator talked with the witness for a long time.

Genitive *следователя*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*следователь* is built on *следовать* "to follow", from *след* "a track, a trail" (EtymDB): one who follows the footsteps.
