## You'll want to know: கோலி
<!-- hl-knowledge: introduces=[TA-LEX-C530-KUZHANTHAI530-03]; assesses=[] -->

**கோலி** — *kōli* — "marbles".

> சிறுவர்கள் மண்ணில் கோலி விளையாடினார்கள்.
>
> *ciṟuvarkaḷ maṇṇil kōli viḷaiyāṭiṉārkaḷ.*
>
> The boys played marbles in the dirt.

One marble is a கோலிக்குண்டு.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

The origin of **கோலி** (*kōli*) is not settled: no dictionary we can check gives it.
