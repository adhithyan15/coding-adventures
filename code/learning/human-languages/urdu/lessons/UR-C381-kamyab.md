# کامیاب (kāmyāb) — successful

## You'll want to know: کامیاب
<!-- hl-knowledge: introduces=[UR-LEX-C381-KAMYAB381-01]; assesses=[] -->

**کامیاب** — *kāmyāb* — "successful".

> اگر تم محنت کرو گے تو کامیاب ہو گے۔
>
> *agar tum mehnat karo ge to kāmyāb ho ge.*
>
> If you work hard, you will succeed.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**کامیاب** (*kāmyāb*) is usually traced to Persian *kāmyāb*, "attaining one's wish"; **کامیابی**, "success", is built on it.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
