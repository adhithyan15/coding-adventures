# વાછરડું (vācharḍũ) — calf

## Warm-up

[PAUSE 2s] Before the new one: say the Gujarati for ox, then the Gujarati for to plough.

## You'll want to know: વાછરડું
<!-- hl-knowledge: introduces=[GU-LEX-C234-MILK234-01]; assesses=[] -->

**વાછરડું** — *vācharḍũ* — "calf".

> **વાછરડું ગાય પાસે ગયું.** — *vācharḍũ gāy pāse gayũ* — "The calf went to the cow."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**વાછરડું** (*vācharḍũ*) is a tadbhava. It comes from Sanskrit *vatsatara*, "young bull or goat before weaning", built on *vatsa*, "calf" (CDIAL 11241).
