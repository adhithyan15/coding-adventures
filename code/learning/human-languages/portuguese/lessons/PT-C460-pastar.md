## You'll want to know: pastar
<!-- hl-knowledge: introduces=[PT-LEX-C460-SELVAGENS-05]; assesses=[] -->

**pastar** — "to graze".

> As vacas pastam no prado.
>
> *The cows graze in the meadow.*

*O pasto* — the pasture.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*pastar* is built on *pasto* 'pasture' (EtymDB), which is inherited from Latin *pāstus* 'feeding, pasture', from *pāscere* 'to feed'.
