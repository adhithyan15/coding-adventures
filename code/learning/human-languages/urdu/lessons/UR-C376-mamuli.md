## You'll want to know: معمولی
<!-- hl-knowledge: introduces=[UR-LEX-C376-MIQDAR376-03]; assesses=[] -->

**معمولی** — *māmūlī* — "minor; ordinary".

> اگر چوٹ معمولی ہے تو ہسپتال جانے کی ضرورت نہیں۔
>
> *agar choṭ māmūlī hai to haspatāl jāne kī zarūrat nahīṅ.*
>
> If the injury is minor, there is no need to go to hospital.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**معمولی** (*māmūlī*) is built on *māmūl*, usually traced, through Persian, to Arabic *maʿmūl*, "customary, done as usual", with the ending *-ī*.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->
