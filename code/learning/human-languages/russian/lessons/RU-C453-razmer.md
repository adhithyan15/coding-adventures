## You'll want to know: размер
<!-- hl-knowledge: introduces=[RU-LEX-C453-PRIMERKA-03]; assesses=[] -->

**размер** (*razmér*) — "a size".

> Эти брюки мне не подошли по размеру.
>
> *Éti bryúki mne ne podoshlí po razméru.*
>
> These trousers were not my size.

Masculine. *Какой у вас размер?* — what size are you?

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*размер* is built from *раз-* and *мера* 'a measure'. EtymDB lists *размер* without a deeper source.
