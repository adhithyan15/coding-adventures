# A valid generic graph does not prove dense compact indexing preconditions

The first D3a shape-validator contract inferred compact dense allocation from
validate_graph success. Independent review found that controlled hierarchical
CVLog values can also validate: allocation coverage is conditional on compact
mode. An indexed borrowed inventory table therefore lacked an explicit premise.

Require canonical compact IDs, equality with entry IDs and an in-range sequence
for every unique record before reserving/indexing. Unique canonical keys in the
record-count range establish dense coverage. Test a valid hierarchical generic
log as a negative. Generic validation also permits journal absence; a shape gate
may validate present chronology but cannot invent complete history from absence.
