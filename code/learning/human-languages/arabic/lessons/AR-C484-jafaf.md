## You'll want to know: جفاف
<!-- hl-knowledge: introduces=[AR-LEX-C484-HARR484-04]; assesses=[] -->

**جفاف** — *jafāf* — "drought; dryness".

> ذبل الزرع بسبب الجفاف.
>
> *dhabala az-zarʿ bi-sabab al-jafāf.*
>
> The crops wilted because of the drought.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**جفاف** (*jafāf*) is built on the native Arabic root *j-f-f*, "to be dry" (Lane). It is the noun beside *jāff*, "dry".
