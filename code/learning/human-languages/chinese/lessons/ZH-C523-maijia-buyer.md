## You'll want to know: 买家
<!-- hl-knowledge: introduces=[ZH-LEX-C523-TRADE523-04]; assesses=[] -->

**买家** — *mǎijiā* — "buyer".

> **买家都觉得这个卖家很好** *mǎijiā dōu juéde zhège màijiā hěn hǎo* — The buyers all think this seller is very good.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**买家** (*mǎijiā*) is built from 买 'to buy' and 家, both inherited from Middle Chinese, *meaX* and *kae* (Guangyun, in Baxter's transcription), which glosses the second 'a dwelling'.
