# し — one falling curve

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[JA-LEX-SUKOSHI, JA-SCRIPT-SU-01, JA-SCRIPT-KO-01, JA-SCRIPT-MI-01] -->

[PAUSE 12s] Say *sukoshi*. Write **す**, **こ**, and review **み**.

## Script — the shape
<!-- hl-knowledge: introduces=[JA-SCRIPT-SHI-01]; assesses=[] -->

> **し** — *shi*

One stroke. Begin high, descend almost vertically, then curve gently up and to
the right. Do not add a second stroke or close the curve.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[JA-SCRIPT-SHI-01, JA-LEX-SUKOSHI] -->

1. Trace **し** once.
2. Hide it and write the single curve.
3. Join **す | こ | し** and read the three morae.
