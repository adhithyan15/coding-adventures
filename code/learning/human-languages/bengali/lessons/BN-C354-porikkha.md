# পরীক্ষা (pôrīkkhā) — a test; an experiment; an exam

## You'll want to know: পরীক্ষা
<!-- hl-knowledge: introduces=[BN-LEX-C354-GOBESHONA354-02]; assesses=[] -->

**পরীক্ষা** — *pôrīkkhā* — "a test; an experiment; an exam".

> বিজ্ঞানীরা একটা নতুন পরীক্ষা করলেন।
>
> *bigyānīrā ekṭā nôtun pôrīkkhā kôrlen.*
>
> The scientists carried out a new experiment.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**পরীক্ষা** (*pôrīkkhā*) is Sanskrit *parīkṣā*, looking all round, inspection or test (Monier-Williams). The same word serves for a school exam and a laboratory experiment.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
