## You'll want to know: fondamentale
<!-- hl-knowledge: introduces=[IT-LEX-C371-RILEVANTE-04]; assesses=[] -->

**fondamentale** — "fundamental, vital".

> Per questo lavoro l'inglese è fondamentale.
>
> *For this job English is vital.*

Very frequent in speech: *è fondamentale che* + subjunctive.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*fondamentale* is built on *fondamento* "foundation", inherited from Latin *fundāmentum* "a foundation" (Lewis & Short), from *fundus* "bottom, ground".
