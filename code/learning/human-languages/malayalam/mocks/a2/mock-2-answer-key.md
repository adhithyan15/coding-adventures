## Writing

Task 1 must address Seema, identify the desired subject, state when the book is
needed, and ask for it to be held in 25–35 independently produced Malayalam
words. Task 2 must be a connected 70–90-word account that covers all six cues.
Do not reward copied prompt language as independent writing.

## Speaking

Use unfamiliar follow-up questions in the interview. In part 2 reveal the
picture sequence only at the start of preparation and allow keyword notes only.
In part 3 the interlocutor should require the learner to repair or confirm one
detail. Score the complete recording against the shared criteria.
