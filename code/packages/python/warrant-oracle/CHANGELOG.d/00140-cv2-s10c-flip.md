## 0.5.0 - CV2-S10c: the atomic flip, `faults.IMPLEMENTED` opens to `ir.fixed` and `ir.tuple`

The oracle half of the one atomic PR of VER04r section 13 "S10c (flip)" and [D29], with `warrant-corpus-gen` 0.6.0.

### Changed

- `faults.IMPLEMENTED` is `("ir.core", "ir.fixed", "ir.tuple")` (was `("ir.core",)`); docstrings follow. `derive`,
  `derive_controls` and `verify-v2` default to it, so a corpus that records `{"deferred": "ir.fixed"}` or
  `{"deferred": "ir.tuple"}` is now a `controls` mismatch. The closed gate stays reachable through
  `implemented=("ir.core",)`. Version 0.4.0 to 0.5.0.
- Every `--expect-generator warrant-corpus-gen@0.5.0` pin (`BUILD`, `BUILD_windows`, the README example), the pin in
  `tests/test_verify_v2.py` and the `GENERATOR` of `tests/fixtures/omit-example-v2/make_fixture.py` move to 0.6.0;
  the `synth-v2`, `accept-blind-v2` and `omit-example-v2` corpora are regenerated (see the generator's changelog for the
  observed diffs).
- Tests asserting "the shipped gate is closed" now assert it is open and keep an explicit closed-gate assertion
  (`test_fixed_faults.py`, `test_tuple_faults.py`, `test_fixed_verify.py`); `test_verify_v2.py` expects the synth-v2
  `bump/xor-lsb` control as a chunk witness.

### Added

- Negative test `test_a_preflip_ct_compare_corpus_with_a_stale_deferred_witness_fails_verify_v2` and its fixture
  `tests/fixtures/ct-compare-v2-preflip/corpus.json` (the pre-flip ct-compare corpus), plus
  `test_a_stale_deferred_witness_for_an_implemented_level_fails` and
  `test_a_closed_gate_corpus_fails_verify_v2_under_the_shipped_gate`.
