# ചാറുക (cāṟuka) — to drizzle

<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C507-MAZHA507-04, ML-LEX-C507-MAZHA507-05] -->

## You'll want to know: ചാറുക
<!-- hl-knowledge: introduces=[ML-LEX-C508-CARRAL508-01]; assesses=[] -->

**ചാറുക** — *cāṟuka* — "to drizzle".

> പുറത്ത് മഴ ചാറുന്നു.
>
> *puṟattŭ maḻa cāṟunnu.*
>
> It is drizzling outside.

Past: ചാറി, *cāṟi*.

The subject is the rain: മഴ ചാറുന്നു, the rain drizzles.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ചാറുക** (*cāṟuka*) is native Dravidian, "to run off; to drizzle" (DEDR 2482).
