# పేదరికం (pēdarikaṁ) — poverty

## You'll want to know: పేదరికం
<!-- hl-knowledge: introduces=[TE-LEX-C404-PEDARIKAM404-01]; assesses=[] -->

**పేదరికం** — *pēdarikaṁ* — "poverty".

> పేదరికం వల్ల చాలా మంది పిల్లలు చదువుకోలేరు.
>
> *pēdarikaṁ valla cālā mandi pillalu caduvukōlēru.*
>
> Because of poverty many children cannot go to school.

పేద, poor, which you know, + -రికం.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**పేదరికం** (*pēdarikaṁ*) is native Dravidian: DEDR 4437 lists Telugu *pēda*, "poor", and *pēdaṟikamu*, "poverty".
