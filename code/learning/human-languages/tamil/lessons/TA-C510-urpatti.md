# உற்பத்தி (uṟpatti) — production; output

## You'll want to know: உற்பத்தி
<!-- hl-knowledge: introduces=[TA-LEX-C510-THOZHIRSALAI510-01]; assesses=[] -->

**உற்பத்தி** — *uṟpatti* — "production; output".

> இந்தத் தொழிற்சாலையில் உற்பத்தி இரண்டு மடங்கு அதிகரித்தது.
>
> *intat toḻiṟcālaiyil uṟpatti iraṇṭu maṭaṅku atikarittatu.*
>
> Production in this factory doubled.

With செய் (*cey*) it becomes a verb: உற்பத்தி செய், to produce.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**உற்பத்தி** (*uṟpatti*) is borrowed from Sanskrit *utpatti*, "origin, birth", later also "profit" (CDIAL 1812). Tamil writes the cluster *tp* as ற்ப.
