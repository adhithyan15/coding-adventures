## You'll want to know: நேரமாகிவிட்டது
<!-- hl-knowledge: introduces=[TA-LEX-C106-CARE-03]; assesses=[] -->

**நேரமாகிவிட்டது** (*nēramākiviṭṭatu*) — "it has got late", literally "it has become time".

**நேரம்** is "time". The first reason to leave.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

A reason to go.
