## You'll want to know: ponerse a
<!-- hl-knowledge: introduces=[ES-LEX-C562-VOLVER-03]; assesses=[] -->

**ponerse a** — "to start (doing), to set about".

> Se puso a llover de repente.
>
> *It suddenly started to rain.*

*Ponerse a* + infinitive: *Me puse a estudiar.*

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*ponerse a* is built on *poner* 'to put', which is inherited from Latin *pōnere* 'to put, to place' (Lewis & Short). To start something is to put yourself to it.
