# दर्शनीयः (darśanīyaḥ) — worth seeing

## You'll want to know: दर्शनीयः
<!-- hl-knowledge: introduces=[SA-LEX-C424-PARYATANA424-02]; assesses=[] -->

**दर्शनीयः** — *darśanīyaḥ* — "worth seeing".

> नगरस्य प्राचीनः प्रासादः दर्शनीयः अस्ति।
>
> *nagarasya prācīnaḥ prāsādaḥ darśanīyaḥ asti.*
>
> The city's old palace is worth seeing.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**दर्शनीयः** (*darśanīyaḥ*) is built on the root √dṛś, "to see", with the ending *-anīya*, "to be done": to be seen; MW gives *darśanīya* as worthy of being seen, beautiful (MW).
