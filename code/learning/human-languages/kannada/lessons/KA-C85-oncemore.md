# ಮತ್ತೊಮ್ಮೆ (mattomme) — once more

## You'll want to know: ಮತ್ತೊಮ್ಮೆ
<!-- hl-knowledge: introduces=[KA-LEX-C85-SLOWLY-02]; assesses=[] -->

**ಮತ್ತೊಮ್ಮೆ** (*mattomme*) — "once more, one more time".

**ಮತ್ತೊಮ್ಮೆ ಹೇಳಿ** (*mattomme hēḷi*) — "please say it once more", with **ಹೇಳಿ**,
"please tell", which you already know.
