## You'll want to know: la hausse
<!-- hl-knowledge: introduces=[FR-LEX-C286-CHIFFRES-03]; assesses=[] -->

**la hausse** — "the rise, the increase".

> Les prix sont en hausse.
>
> *Prices are going up.*

*En hausse* — going up.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*hausse* is built on *hausser* "to raise" (EtymDB), which is inherited from Vulgar Latin *altiāre*, built on Latin *altus* "high".
