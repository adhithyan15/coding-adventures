# ജോലിസ്ഥലം (jōlisthalaṁ) — a workplace

## You'll want to know: ജോലിസ്ഥലം
<!-- hl-knowledge: introduces=[ML-LEX-C550-NETTAM550-01]; assesses=[] -->

**ജോലിസ്ഥലം** — *jōlisthalaṁ* — "a workplace".

> അവളുടെ ജോലിസ്ഥലം വീട്ടിൽ നിന്ന് ദൂരെയാണ്.
>
> *avaḷuṭe jōlisthalaṁ vīṭṭil ninnŭ dūreyāṇŭ.*
>
> Her workplace is far from home.

ജോലി work + സ്ഥലം a place.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ജോലിസ്ഥലം** (*jōlisthalaṁ*) is a Malayalam compound built from ജോലി, "work", and സ്ഥലം, from Sanskrit *sthala*, "ground, a place" (CDIAL 13744).
