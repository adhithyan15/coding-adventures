# ਰਿਹਾਇਸ਼ — assemble the residence label

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-SCRIPT-RA-01, PA-SCRIPT-INDEPENDENT-I-01, PA-SCRIPT-SIHARI-01, PA-SCRIPT-AA-MATRA-01, PA-SCRIPT-SHA-01] -->

Touch the pieces in order: **ਰਿ**, **ਹਾ**, **ਇ**, **ਸ਼**.

## Script — one label
<!-- hl-knowledge: introduces=[PA-FORM-LABEL-RESIDENCE-01]; assesses=[PA-SCRIPT-RA-01, PA-SCRIPT-INDEPENDENT-I-01, PA-SCRIPT-SIHARI-01, PA-SCRIPT-AA-MATRA-01, PA-SCRIPT-SHA-01] -->

Join **ਰਿ + ਹਾ + ਇ + ਸ਼ = ਰਿਹਾਇਸ਼**. On a form, **ਰਿਹਾਇਸ਼** labels the residence line. Copy the label once and leave its answer blank.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-LABEL-RESIDENCE-01] -->

Point to the label and say what information belongs there. Do not add a value yet.
