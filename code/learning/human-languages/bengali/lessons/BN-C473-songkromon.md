## You'll want to know: সংক্রমণ
<!-- hl-knowledge: introduces=[BN-LEX-C473-SONGKROMON473-01]; assesses=[] -->

**সংক্রমণ** — *sôngkrômôn* — "an infection".

> কাটা জায়গায় সংক্রমণ হলে জ্বর আসে।
>
> *kāṭā jāygāy sôngkrômôn hôle jbôr āse.*
>
> If a cut gets infected, a fever follows.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**সংক্রমণ** (*sôngkrômôn*) is a tatsama, Sanskrit *saṃkramaṇa*, "going together, transference" (Monier-Williams); Bengali uses it for a disease passing from one body to another.
