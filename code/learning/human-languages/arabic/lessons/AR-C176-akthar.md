## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**أكثر** (*akthar*) is built on the native Arabic root *k-th-r*, "to be many" (Lane). *Akthar* is the *afʿal* comparative, "more".
