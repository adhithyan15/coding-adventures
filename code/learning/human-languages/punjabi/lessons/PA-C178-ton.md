# ਘਰ ਤੋਂ ਸਕੂਲ ਜਾਣਾ — name where a route starts

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-ADV-BAHUT-DEGREE-01, PA-GRAMMAR-MULTIWORD-NP-01, PA-LEX-C67-FOOD67-03, PA-LEX-C71-HOME71-05, PA-LEX-JANA] -->

[PAUSE 2s] First retrieve **ਇਹ ਬਹੁਤ ਚੰਗੀ ਕੁੜੀ ਹੈ** once. Then recall **ਘਰ**,
**ਸਕੂਲ**, and **ਜਾਣਾ**. Keep the route in that
meaning order: home, then school, then go.

## Grammar Lens: ਤੋਂ follows the source
<!-- hl-knowledge: introduces=[PA-POSTPOSITION-TON-SOURCE-01]; assesses=[PA-LEX-C67-FOOD67-03, PA-LEX-C71-HOME71-05, PA-LEX-JANA] -->

> **ਘਰ ਤੋਂ ਸਕੂਲ ਜਾਣਾ** — *ghar tõ sakūl jāṇā* — to go from home to school

Punjabi uses a postposition: **ਤੋਂ** comes after its noun. In this bounded
route, **ਘਰ** is the source, so the pair is **ਘਰ ਤੋਂ**. Do not move **ਤੋਂ**
before **ਘਰ** as English moves *from*.
