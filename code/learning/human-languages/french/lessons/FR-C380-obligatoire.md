## You'll want to know: obligatoire
<!-- hl-knowledge: introduces=[FR-LEX-C380-NORME-03]; assesses=[] -->

**obligatoire** — "compulsory, mandatory".

> Le port du casque est obligatoire sur le chantier.
>
> *Wearing a helmet is compulsory on the building site.*

One form for both genders.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*obligatoire* is a learned borrowing from Late Latin *obligātōrius* "binding" (EtymDB), from *obligāre* "to bind", built on *ligāre* "to tie" (Lewis & Short).
