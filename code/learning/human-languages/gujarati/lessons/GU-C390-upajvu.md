# ઊપજવું (ūpajvũ) — to be produced (as a crop)

## You'll want to know: ઊપજવું
<!-- hl-knowledge: introduces=[GU-LEX-C390-PAK390-05]; assesses=[] -->

**ઊપજવું** — *ūpajvũ* — "to be produced (as a crop)".

> જો ખેતરમાં પૂરતું પાણી હશે તો ઘણા ઘઉં ઊપજશે.
>
> *jo khetarmā̃ pūrtũ pāṇī haśe to ghaṇā ghaũ ūpajśe.*
>
> If the field has enough water, it will yield a lot of wheat.

Past (it …): તે ખેતરમાં બાજરી ઊપજી, *te khetarmā̃ bājrī ūpjī*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ઊપજવું** (*ūpajvũ*) is inherited from Sanskrit *útpadyatē*, "arises, originates"; CDIAL lists the Gujarati verb, "is produced" (CDIAL 1814).
