# நேரலை (nēralai) — a live broadcast

## You'll want to know: நேரலை
<!-- hl-knowledge: introduces=[TA-LEX-C305-NERALAI305-02]; assesses=[] -->

**நேரலை** — *nēralai* — "a live broadcast".

> தொலைக்காட்சியில் போட்டியை நேரலையில் பார்த்தோம்.
>
> *tolaikkāṭciyil pōṭṭiyai nēralaiyil pārttōm.*
>
> We watched the match live on television.

நேரலையில், live (on air).

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**நேரலை** (*nēralai*) is a Tamil compound built from நேர், "straightness, directness" (DEDR 3772), and அலை, "a wave".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
