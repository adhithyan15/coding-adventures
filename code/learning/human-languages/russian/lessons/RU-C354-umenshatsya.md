# уменьшаться (umenshátsya) — to decrease, to get smaller

## You'll want to know: уменьшаться
<!-- hl-knowledge: introduces=[RU-LEX-C354-BOLSHE-03]; assesses=[] -->

**уменьшаться** (*umenshátsya*) — "to decrease, to get smaller".

> Боль постепенно уменьшается.
>
> *Bol postepénno umensháyetsya.*
>
> The pain is gradually decreasing.

Imperfective; perfective *уменьшиться*. Built on *меньше*, less.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**уменьшаться** is built from *у-* and *меньше* "less", an old comparative Russian inherited from Proto-Slavic; it is not built on *малый*, which has a different root.
