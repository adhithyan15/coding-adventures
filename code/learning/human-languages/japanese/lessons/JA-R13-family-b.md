# Family retrieval B

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[JA-LEX-IMOUTO] -->

can carry word-specific readings. Then hear “younger sister,” say **いもうと**,
read **ちち・はは**, and write all three.
