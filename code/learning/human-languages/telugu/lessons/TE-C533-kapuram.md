# కాపురం (kāpuraṁ) — married life; a household

## You'll want to know: కాపురం
<!-- hl-knowledge: introduces=[TE-LEX-C533-SAMSARAM533-01]; assesses=[] -->

**కాపురం** — *kāpuraṁ* — "married life; a household".

> వాళ్ళ కాపురం సంతోషంగా సాగుతోంది.
>
> *vāḷḷa kāpuraṁ santōṣaṅgā sāgutōndi.*
>
> Their married life is going happily.

కాపురం పెట్టు, to set up house.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**కాపురం** (*kāpuraṁ*) is native Dravidian: DEDR 1456 lists Telugu *kāpuramu*, "dwelling, residence", beside *kāpu*, "a cultivator".
