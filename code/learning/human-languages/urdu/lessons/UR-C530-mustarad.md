# مسترد (mustarad) — rejected; turned down

## You'll want to know: مسترد
<!-- hl-knowledge: introduces=[UR-LEX-C530-MARZI530-04]; assesses=[] -->

**مسترد** — *mustarad* — "rejected; turned down".

> اگر یہ خط مسترد ہوا تو پھر لکھوں گا۔
>
> *agar yih khat mustarad huā to phir likhūṅ gā.*
>
> If this letter is turned down, I'll write again.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**مسترد** (*mustarad*) is usually traced, through Persian, to Arabic *mustaradd*, "taken back, returned".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
