## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**മാമ്പഴം** (*māmpaḻaṁ*) is native Dravidian, "mango fruit": *mā*, "mango tree" (DEDR 4782, with Tamil *mā*), and *paḻaṁ*, "ripe fruit" (DEDR 4004). DEDR 4782 compares Sanskrit *mākanda*. DEDR 4004 compares Sanskrit *phala*.
