## You'll want to know: చిరునామా
<!-- hl-knowledge: introduces=[TE-LEX-C89-ABOUT-05]; assesses=[] -->

**చిరునామా** (*cirunāmā*) — "an address".

**మీ చిరునామా ఏమిటి?** — "what is your address?". The same frame as the name and the job:
**మీ ... ఏమిటి?**
