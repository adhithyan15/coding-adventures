## You'll want to know: أهدر
<!-- hl-knowledge: introduces=[AR-LEX-C467-MAHMIYYA467-05]; assesses=[] -->

**أهدر** — *ahdara* — "to squander; to waste".

> أهدر المصنع ماء كثيرا.
>
> *ahdara al-maṣnaʿ māʾan kathīran.*
>
> The factory wasted a lot of water.

Present: يهدر, *yuhdir*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**أهدر** (*ahdara*) is built on the native Arabic root *h-d-r*, "to be of no account" (Lane). It is Form IV, "to treat as worthless".
