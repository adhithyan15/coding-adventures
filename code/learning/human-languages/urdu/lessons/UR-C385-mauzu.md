## You'll want to know: موضوع
<!-- hl-knowledge: introduces=[UR-LEX-C385-DAKHILA385-03]; assesses=[] -->

**موضوع** — *mauzū* — "a topic; a subject (of study)".

> اگر یہ موضوع مشکل ہے تو دوسرا چنیے۔
>
> *agar yih mauzū mushkil hai to dūsrā chuniye.*
>
> If this topic is hard, choose another.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**موضوع** (*mauzū*) is usually traced, through Persian, to Arabic *mawḍūʿ*, "something laid down": the matter set before you.
