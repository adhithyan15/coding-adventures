## Fixed — Punjabi root slugs name one etymon each

- **PA-C70-darvaza** moves from `persian-dar` to `persian-dar-door`, the slug Persian's *darvâze* uses; `persian-dar` also named *-dār* "holder" and *dar* "in".
- **PA-C84-pila** moves from `sanskrit-pita-drunk` to `sanskrit-pitala`. Its block derives *pīlā* from *pītala* "yellow" (CDIAL 8233), the slug the Gujarati, Marwadi and Urdu yellow lessons use.
- **PA-C84-kala** moves from `sanskrit-kala` to `sanskrit-kala-black`. `sanskrit-kala` also named *kalā* "art" (CDIAL 2927); *kālā* is *kāla* "black" (CDIAL 3083).
- **PA-C35-mainu** drops `sanskrit-lagna-nu`. The slug implied *nū̃* comes from *lagna*, but the block says its origin is not settled and CDIAL 10893 has no *nū̃*.
