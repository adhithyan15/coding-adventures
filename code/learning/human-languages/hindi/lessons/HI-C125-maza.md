# मज़ा (mazā) — fun, enjoyment

## You'll want to know: मज़ा
<!-- hl-knowledge: introduces=[HI-LEX-C125-CALM-05]; assesses=[] -->

**मज़ा** (*mazā*) — "fun, enjoyment".

**मज़ा आया** — "I enjoyed it", literally "fun came". It comes to you, like laughter.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

Calm, nervous, restless, not in the mood, and fun.
