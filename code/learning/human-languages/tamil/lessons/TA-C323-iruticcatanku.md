# இறுதிச்சடங்கு (iṟuticcaṭaṅku) — a funeral

## You'll want to know: இறுதிச்சடங்கு
<!-- hl-knowledge: introduces=[TA-LEX-C323-IRUTHI323-01]; assesses=[] -->

**இறுதிச்சடங்கு** — *iṟuticcaṭaṅku* — "a funeral".

> அவருடைய இறுதிச்சடங்கில் ஊரே கலந்துகொண்டது.
>
> *avaruṭaiya iṟuticcaṭaṅkil ūrē kalantukoṇṭatu.*
>
> The whole village attended his funeral.

இறுதி, end + சடங்கு, rite.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**இறுதிச்சடங்கு** (*iṟuticcaṭaṅku*) is a Tamil compound built from இறுதி, "end, death" (DEDR 514), and சடங்கு, "a rite".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
