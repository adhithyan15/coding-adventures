# आभार — formal thanks, built from known signs

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-SAA-01, MW-SCRIPT-AA-INDEPENDENT-01, MW-SCRIPT-BHA-01, MW-SCRIPT-AA-MATRA-01, MW-SCRIPT-RA-01] -->

[PAUSE 5s] Write **सा** from memory. Then read these four pieces:
**आ · भ · ा · र**.

## Script — build the word
<!-- hl-knowledge: introduces=[MW-SCRIPT-AABHAAR-01, MW-LEX-AABHAAR-01]; assesses=[] -->

Join only signs you already know:

> **आ** + **भ** + **ा** + **र** = **आभार**
>
> *ābhār* — formal thanks; gratitude

Rajasthan Sahitya Akademi's *Jāgtī Jot* uses **आभार** when expressing gratitude
in Rajasthani prose. It is a formal, Sanskrit-derived word. This lesson keeps
that register visible rather than pretending every kind of thanks sounds the
same.

## Writing — from guided to delayed copy
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-AABHAAR-01, MW-LEX-AABHAAR-01] -->
<!-- hl-writing-stage: delayed-copy -->

1. copy **आभार** once while looking
2. point to **भा** and say *bhā*
3. hide the word for ten seconds
4. write **आभार** from memory
5. compare one sign at a time

If one sign stalls, practise only that sign before trying the word again.
