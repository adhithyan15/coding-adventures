# ഇടിമിന്നൽ (iṭiminnal) — thunder and lightning

## You'll want to know: ഇടിമിന്നൽ
<!-- hl-knowledge: introduces=[ML-LEX-C118-WEATHER-05]; assesses=[] -->

**ഇടിമിന്നൽ** (*iṭiminnal*) — "thunder and lightning": **ഇടി** (*iṭi*), "thunder", and
**മിന്നൽ** (*minnal*), "lightning". The monsoon brings both.
