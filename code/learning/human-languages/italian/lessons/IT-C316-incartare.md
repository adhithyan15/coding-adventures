## You'll want to know: incartare
<!-- hl-knowledge: introduces=[IT-LEX-C316-CANDELINE-03]; assesses=[] -->

**incartare** — "to wrap (in paper)".

> Può incartare il regalo, per favore?
>
> *Could you wrap the present, please?*

Built on *carta*, ‘paper’.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*incartare* is built on *carta* "paper", from Latin *charta* (Lewis & Short).
