# ಅನಿಶ್ಚಿತ (aniścita) — uncertain

## You'll want to know: ಅನಿಶ್ಚಿತ
<!-- hl-knowledge: introduces=[KA-LEX-C420-ALUKU420-04]; assesses=[] -->

**ಅನಿಶ್ಚಿತ** — *aniścita* — "uncertain".

> ನಾಳೆಯ ಪಂದ್ಯ ಇನ್ನೂ ಅನಿಶ್ಚಿತ.
>
> *nāḷeya pandya innū aniścita.*
>
> Tomorrow's match is still uncertain.

ಅನಿಶ್ಚಿತತೆ, uncertainty.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಅನಿಶ್ಚಿತ** (*aniścita*) is borrowed from Sanskrit *aniścita*, "unascertained, not certain" (Monier-Williams).

## What you've built
