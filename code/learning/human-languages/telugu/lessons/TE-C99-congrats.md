# అభినందనలు (abhinandanalu) — congratulations, compliments

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TE-LEX-C99-WELCOME-01, TE-LEX-C99-WELCOME-02] -->

[PAUSE 2s] Before the new one: say the Telugu for namaste, then the Telugu for delight.

## You'll want to know: అభినందనలు
<!-- hl-knowledge: introduces=[TE-LEX-C99-WELCOME-03]; assesses=[] -->

**అభినందనలు** (*abhinandanalu*) — "congratulations", "compliments" on something done well.

**శుభాకాంక్షలు** wishes someone well for what is coming; **అభినందనలు** praises what they have
done. A passed exam gets both.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

Praise for what is done, beside wishes for what comes.
