## You'll want to know: بیانیه
<!-- hl-knowledge: introduces=[FA-LEX-C309-SOKHANGU-02]; assesses=[] -->

**بیانیه** (*bayâniye*) — "a statement, a communiqué".

> شرکت دیروز یک بیانیه کوتاه داد.
>
> *Sherkat diruz yek bayâniye-ye kutâh dâd.*
>
> Yesterday the company issued a short statement.

Formal; *bayâniye dâdan* "to issue a statement". Built on *bayân* "expression".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*bayâniye* is built on *bayân* "expression, statement", which is borrowed from Arabic *bayān* (EtymDB lists both words), with the noun ending *-iye*.
