## You'll want to know: विपुलः
<!-- hl-knowledge: introduces=[SA-LEX-C379-ADHIKA379-04]; assesses=[] -->

**विपुलः** — *vipulaḥ* — "ample; abundant".

> यदि धनं विपुलम्, तर्हि ग्रामः सुखी भविष्यति।
>
> *yadi dhanaṃ vipulam, tarhi grāmaḥ sukhī bhaviṣyati.*
>
> If there is ample money, the village will be happy.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**विपुलः** (*vipulaḥ*) is built on *vi* and *pula*, which MW takes to be probably the same as *pura*, "full"; MW gives *vi-pula* "large, extensive, abundant" (MW).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
