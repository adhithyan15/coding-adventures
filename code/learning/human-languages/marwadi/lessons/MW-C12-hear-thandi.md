# Hear *ṭhaṇḍī* — cold

## You'll want to know
<!-- hl-knowledge: introduces=[MW-LEX-THANDI-01]; assesses=[] -->

> *ṭhaṇḍī* — **cold; cold weather**

The source also groups this form with winter. Keep the narrow cold meaning for
now and contrast it with heat.
