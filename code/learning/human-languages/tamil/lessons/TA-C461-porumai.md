# பொறுமை (poṟumai) — patience

## You'll want to know: பொறுமை
<!-- hl-knowledge: introduces=[TA-LEX-C461-PORUMAI461-01]; assesses=[] -->

**பொறுமை** — *poṟumai* — "patience".

> குழந்தைகளிடம் ஆசிரியருக்குப் பொறுமை வேண்டும்.
>
> *kuḻantaikaḷiṭam āciriyarukkup poṟumai vēṇṭum.*
>
> A teacher needs patience with children.

பொறுமையாக இரு, to be patient.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**பொறுமை** (*poṟumai*) is native Dravidian, a noun from பொறு *poṟu*, "to bear, to endure, to be patient" (DEDR 4565).
