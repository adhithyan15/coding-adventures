# છોડવું (choḍvũ) — to drop off, to let go

## You'll want to know: છોડવું
<!-- hl-knowledge: introduces=[GU-LEX-C203-TRIP203-04]; assesses=[] -->

**છોડવું** — *choḍvũ* — "to drop off, to let go".

> **પિતાએ મને સ્ટેશને છોડ્યો.** — *pitāe mane sṭeśane choḍyo* — "My father dropped me at the station."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**છોડવું** (*choḍvũ*) is a tadbhava. CDIAL lists it, glossed "to let go", under Sanskrit *kṣōṭayati*, "throws" (CDIAL 3747).
