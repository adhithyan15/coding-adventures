## You'll want to know: नुकसान
<!-- hl-knowledge: introduces=[MR-LEX-C295-SANKAT295-01]; assesses=[] -->

**नुकसान** — *nuksān* — "damage; a loss".

> जर नुकसान मोठं असेल, तर गावाला मदत मिळेल.
>
> *jar nuksān moṭhaṁ asel, tar gāvālā madat miḷel.*
>
> If the damage is great, the village will get help.

Neuter.

नुकसान होणे, a loss is suffered; जर … असेल तर, if it is, for a state.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**नुकसान** (*nuksān*) is a loan from Persian *nuqsān*, usually traced to Arabic *nuqṣān*, 'a shortfall, a deficit'.
