## You'll want to know: دروازه بان
<!-- hl-knowledge: introduces=[FA-LEX-C514-BALL-05]; assesses=[] -->

**دروازه بان** (*darvâzebân*) — "a goalkeeper".

> دروازه بان توپ را گرفت.
>
> *darvâzebân tup râ gereft.*
>
> The goalkeeper caught the ball.

*darvâze* 'gate, goal' + *-bân* 'keeper'.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*darvâzebân* is built on native Persian parts: *darvâze*, 'gate', usually linked with *dar*, 'door', and the ending *-bân*, 'keeper', as in *bâghbân*. EtymDB has no entry for it.
