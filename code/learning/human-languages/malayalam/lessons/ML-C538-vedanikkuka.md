# വേദനിക്കുക (vēdanikkuka) — to hurt; to be painful

## You'll want to know: വേദനിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C538-PARIKKU538-04]; assesses=[] -->

**വേദനിക്കുക** — *vēdanikkuka* — "to hurt; to be painful".

> ഇന്നലെ കളിച്ചതുകൊണ്ട് കാൽ വേദനിക്കുന്നു.
>
> *innale kaḷiccatukoṇṭŭ kāl vēdanikkunnu.*
>
> My leg hurts because I played yesterday.

Past: വേദനിച്ചു, *vēdaniccu*.

The part that hurts is the subject: തല വേദനിക്കുന്നു, my head hurts.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**വേദനിക്കുക** (*vēdanikkuka*) is built from വേദന, "pain", from Sanskrit *vedanā*, "pain, agony" (Monier-Williams), with the Malayalam verb ending -ിക്കുക.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
