# बीमार (bīmār) — ill, sick

## You'll want to know: बीमार
<!-- hl-knowledge: introduces=[HI-LEX-C106-UNWELL-04]; assesses=[] -->

**बीमार** (*bīmār*) — "ill, sick".

**मैं बीमार हूँ** — "I am ill". This one describes you, so it takes **मैं ... हूँ**, not **मुझे**.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

The difference between having an illness and being ill.
