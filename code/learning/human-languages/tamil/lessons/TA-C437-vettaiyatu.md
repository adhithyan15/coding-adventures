# வேட்டையாடு (vēṭṭaiyāṭu) — to hunt

## You'll want to know: வேட்டையாடு
<!-- hl-knowledge: introduces=[TA-LEX-C437-VILANKU437-04]; assesses=[] -->

**வேட்டையாடு** — *vēṭṭaiyāṭu* — "to hunt".

> புலி இரவில் வேட்டையாடுகிறது.
>
> *puli iravil vēṭṭaiyāṭukiṟatu.*
>
> The tiger hunts at night.

Past (I …): வேட்டையாடினேன், *vēṭṭaiyāṭiṉēṉ*.

வேட்டை, hunting, + ஆடு, a verb-making second part.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**வேட்டையாடு** (*vēṭṭaiyāṭu*) is built from வேட்டை, "hunting, the chase" (DEDR 5527), and ஆடு, "to move, to play" (DEDR 347).
