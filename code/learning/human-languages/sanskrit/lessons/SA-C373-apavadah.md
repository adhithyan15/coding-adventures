## You'll want to know: अपवादः
<!-- hl-knowledge: introduces=[SA-LEX-C373-ANUMATI373-04]; assesses=[] -->

**अपवादः** — *apavādaḥ* — "an exception".

> यदि नियमः अस्ति, तर्हि अपवादः अपि भवति।
>
> *yadi niyamaḥ asti, tarhi apavādaḥ api bhavati.*
>
> If there is a rule, there is also an exception.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**अपवादः** (*apavādaḥ*) is built on *apa*, "away", and the root √vad, "to speak"; MW gives *apa-vāda* "a special rule setting aside a general one, an exception" (MW).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
