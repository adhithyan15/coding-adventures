# പട്ടാഭിഷേകം (paṭṭābhiṣēkaṁ) — a coronation

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C398-SIMHASANAM398-01, ML-LEX-C398-SIMHASANAM398-02] -->

[PAUSE 2s] Before the new one: say the Malayalam for a throne, then the Malayalam for a crown.

## You'll want to know: പട്ടാഭിഷേകം
<!-- hl-knowledge: introduces=[ML-LEX-C398-SIMHASANAM398-03]; assesses=[] -->

**പട്ടാഭിഷേകം** — *paṭṭābhiṣēkaṁ* — "a coronation".

> പുതിയ രാജാവിന്റെ പട്ടാഭിഷേകം ഒരു വലിയ ഉത്സവം ആയിരുന്നു.
>
> *putiya rājāvinṟe paṭṭābhiṣēkaṁ oru valiya utsavaṁ āyirunnu.*
>
> The new king's coronation was a great festival.

പട്ടം, a royal band, + അഭിഷേകം, an anointing.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**പട്ടാഭിഷേകം** (*paṭṭābhiṣēkaṁ*) is built from Sanskrit *paṭṭa*, "cloth; a fillet, a diadem" (CDIAL 7700), and *abhiṣeka*, "anointing; the inauguration of a king" (Monier-Williams).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
