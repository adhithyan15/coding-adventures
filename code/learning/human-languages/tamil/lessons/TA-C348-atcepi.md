# ஆட்சேபி (āṭcēpi) — to object

## You'll want to know: ஆட்சேபி
<!-- hl-knowledge: introduces=[TA-LEX-C348-ETIR348-02]; assesses=[] -->

**ஆட்சேபி** — *āṭcēpi* — "to object".

> அந்த முடிவை யாரும் ஆட்சேபிக்கவில்லை.
>
> *anta muṭivai yārum āṭcēpikkavillai.*
>
> Nobody objected to that decision.

Past (I …): ஆட்சேபித்தேன், *āṭcēpittēṉ*.

What is objected to takes -ஐ: முடிவை ஆட்சேபி. The noun is ஆட்சேபனை, an objection.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ஆட்சேபி** (*āṭcēpi*) is a verb built on Sanskrit *ākṣepa*, "objection" (CDIAL 1032). Tamil writes the Sanskrit kṣ as ட்ச, as in சாட்சி from *sākṣin*.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
