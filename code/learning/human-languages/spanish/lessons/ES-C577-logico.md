## You'll want to know: lógico
<!-- hl-knowledge: introduces=[ES-LEX-C577-DEFIENDE-05]; assesses=[] -->

**lógico** — "logical; natural, to be expected".

> Es lógico que estés cansado.
>
> *It is natural that you are tired.*

*Es lógico que* + subjunctive: it makes sense that...

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*lógico* is a learned borrowing from Latin *logicus*, taken from Greek *logikos* 'of reasoning', built on *logos* 'word, reason' (EtymDB).
