## You'll want to know: ઉડાઉ
<!-- hl-knowledge: introduces=[GU-LEX-C461-KRUPAN461-02]; assesses=[] -->

**ઉડાઉ** — *uḍāu* — "wasteful with money".

> ઉડાઉ દીકરાએ બધા પૈસા વેડફ્યા.
>
> *uḍāu dīkrāe badhā paisā veḍaphyā.*
>
> The spendthrift son wasted all the money.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ઉડાઉ** (*uḍāu*) is probably built on the stem of **ઉડાડવું** (*uḍāḍvũ*), "to make fly", which CDIAL also glosses "to squander" (CDIAL 1697), with the adjective ending *-u*: someone who squanders. That verb goes back to Sanskrit *uḍḍīyatē*, "flies up"; CDIAL does not list *uḍāu* itself, so the link is probable, not recorded.
