## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**మసి** (*masi*) is native Dravidian. DEDR 5101 lists *masi*, "soot, blackness, ink", with Kannada *masi*, "soot", and Tamil *mai*, "ink, black". DEDR compares Sanskrit *maṣi*, "lampblack, ink" (CDIAL 9920), which CDIAL takes from Dravidian.
