## You'll want to know: моросить
<!-- hl-knowledge: introduces=[RU-LEX-C465-LIVEN-02]; assesses=[] -->

**моросить** (*morosít*) — "to drizzle".

> С утра моросит мелкий дождь.
>
> *S utrá morosít mélkiy dozhd.*
>
> A fine rain has been drizzling since morning.

Imperfective; mostly impersonal: *моросит* — it is drizzling.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*моросить* is built on *морось* 'drizzle, fine rain'. EtymDB lists neither word, so its deeper origin is left open.
