# Hear *kànshū* — read a book

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ZH-LEX-KAN-01, ZH-LEX-SHU-01] -->

[PAUSE 10s] Say **look or watch**, then say **book**.

## You'll want to know
<!-- hl-knowledge: introduces=[ZH-LEX-KANSHU-01]; assesses=[] -->

> *kànshū* — **read a book; read books**

Let *kàn* fall and keep *shū* level. Mandarin says **look-at + book** for the
activity **read**. Keep the characters hidden for one more tiny step.
