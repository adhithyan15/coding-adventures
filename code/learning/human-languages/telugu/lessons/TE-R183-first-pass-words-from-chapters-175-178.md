[PAUSE 3s] A crowd? (**గుంపు**, *gumpu*.) The world? (**ప్రపంచం**, *prapañcaṁ*.) An earthquake? (**భూకంపం**, *bhūkampaṁ*.) Dust? (**దుమ్ము**, *dummu*.) Smoke? (**పొగ**, *poga*.) Otherwise? (**లేకపోతే**, *lēkapōtē*.) Even so? (**అయినా**, *ayinā*.) Through? (**ద్వారా**, *dvārā*.) About? (**గురించి**, *guriñci*.) Without? (**లేకుండా**, *lēkuṇḍā*.) If by chance? (**ఒకవేళ**, *okavēḷa*.) Instead of? (**బదులు**, *badulu*.) According to? (**ప్రకారం**, *prakāraṁ*.) Actually? (**అసలు**, *asalu*.) Anyway? (**ఏదేమైనా**, *ēdēmainā*.) On purpose? (**కావాలని**, *kāvālani*.) By mistake? (**పొరపాటున**, *porapāṭuna*.) Never mind? (**పోనీ**, *pōnī*.) A condition? (**షరతు**, *ṣaratu*.) An excuse? (**సాకు**, *sāku*.)
