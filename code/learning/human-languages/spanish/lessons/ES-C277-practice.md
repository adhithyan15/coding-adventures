# Read two, say one

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ES-LEX-SEGUN, ES-LEX-EN-RESUMEN] -->

[PAUSE 2s] The last exercise in the book, and it uses all four moves in the order
you would actually need them.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[ES-LEX-SEGUN, ES-SEMANTIC-ATTRIBUTION, ES-LEX-ES-DECIR, ES-SEMANTIC-PARAPHRASE, ES-LEX-POR-UN-LADO, ES-SEMANTIC-SYNTHESIS, ES-LEX-EN-RESUMEN, ES-SEMANTIC-COMPRESSION] -->

[PAUSE 1s] Find two things that disagree — two people, two articles, two friends.
Then run the four moves.

- [YOU SAY: *según* the first one, what it claims. You have credited it and not
  agreed with it.]
- [YOU SAY: *es decir*, and the same claim in words the first source did not use.
  If you cannot, you have not understood it yet.]
- [YOU SAY: *por un lado… por otro*, putting both inside one sentence so the
  disagreement is visible rather than merely present.]
- [YOU SAY: *en resumen*, and one sentence that covers both.]

[PAUSE 2s]
- [YOU SAY: what you left out of the summary, and why it was safe to lose]
- [YOU SAY: whether your summary favours one of the two. Check honestly — this is
  where a summary quietly becomes an argument.]

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[ES-SEMANTIC-ATTRIBUTION, ES-SEMANTIC-PARAPHRASE, ES-SEMANTIC-SYNTHESIS, ES-SEMANTIC-COMPRESSION] -->

[PAUSE 3s] Name the four moves: credit it, restate it, hold both, compress. Which
one proves you understood the source? (The paraphrase.) Which one requires you to
throw something away? (The summary.)
