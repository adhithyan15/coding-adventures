[PAUSE 2s each]
- [YOU SAY: If I have time, I will see a film.]
- [YOU SAY: If it is cold, I will stay home.]
- [YOU SAY: Once I get to the station, I will buy a ticket.]
- [YOU SAY: If it snows, what will you do?]
- [YOU SAY: If it is fine, I will go to the mountains.]
- [YOU SAY: It takes about two hours to the mountains.]
- [YOU SAY: If I lose my wallet, I will go to the police box.]
