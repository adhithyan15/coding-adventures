## You'll want to know: refūtō, refūtāre
<!-- hl-knowledge: introduces=[LA-LEX-C362-REFELLO-02]; assesses=[] -->

**refūtō, refūtāre** — "to refute; to drive back".

> Hanc opīniōnem nōn difficile est refūtāre.
>
> *This opinion is not hard to refute.*

*refūtō, refūtāre, refūtāvī, refūtātum*. First to beat back an attack, then an argument. English *refute*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*refūtō* is built from *re-* "back" and an old verb *fūtō*, which EtymDB glosses "to beat"; Lewis & Short connect it instead with *fundō* "to pour", so its deeper origin is not settled. English *refute* comes from it.
