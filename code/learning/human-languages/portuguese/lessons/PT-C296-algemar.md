## You'll want to know: algemar
<!-- hl-knowledge: introduces=[PT-LEX-C296-ALGEMAS-02]; assesses=[] -->

**algemar** — "to handcuff".

> Algemaram o homem dentro do carro.
>
> *They handcuffed the man inside the car.*

Built on *as algemas*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*algemar* is built on *algema* "a handcuff", which comes from Arabic *al-jāmiʿa* "the fetter" (EtymDB, under *algema*).
