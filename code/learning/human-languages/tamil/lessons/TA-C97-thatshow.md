## You'll want to know: அப்படித்தான்
<!-- hl-knowledge: introduces=[TA-LEX-C97-SURE-02]; assesses=[] -->

**அப்படித்தான்** (*appaṭittāṉ*) — "that's how it is", "quite so".

**அப்படி**, "like that", with **-தான்**, the same "that and no other" as **சரிதான்**.
