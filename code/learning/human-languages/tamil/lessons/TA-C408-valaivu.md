# வளைவு (vaḷaivu) — a curve; a bend

## You'll want to know: வளைவு
<!-- hl-knowledge: introduces=[TA-LEX-C408-VALAIVU408-01]; assesses=[] -->

**வளைவு** — *vaḷaivu* — "a curve; a bend".

> இந்த மலைச் சாலையில் நிறைய வளைவுகள் இருக்கின்றன.
>
> *inta malaic cālaiyil niṟaiya vaḷaivukaḷ irukkiṉṟaṉa.*
>
> There are many bends on this hill road.

Plural: வளைவுகள், *vaḷaivukaḷ*.

From வளை, to bend, + the noun ending -வு.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**வளைவு** (*vaḷaivu*) is built from வளை, "to bend, to become crooked" (DEDR 5314), with the noun ending *-vu*.
