## You'll want to know: le patrimoine
<!-- hl-knowledge: introduces=[FR-LEX-C325-PASSE-03]; assesses=[] -->

**le patrimoine** — "heritage; an estate".

> Ce château fait partie du patrimoine du pays.
>
> *This castle is part of the country's heritage.*

*Le patrimoine culturel* — cultural heritage.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*patrimoine* is a learned borrowing from Latin *patrimōnium* "an inheritance from a father" (EtymDB), built on *pater* "father".
