## You'll want to know: разыскивать
<!-- hl-knowledge: introduces=[RU-LEX-C441-PROKHOZHIY-04]; assesses=[] -->

**разыскивать** (*razýskivat*) — "to search for, to track down".

> Мы долго разыскивали эту улицу.
>
> *My dólgo razýskivali étu úlitsu.*
>
> We searched for this street for a long time.

Imperfective; perfective *разыскать* (*разыщу, разыщешь*).

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*разыскивать* is built from *раз-* and *-ыскивать*, from *искать* 'to seek', which is inherited from Proto-Slavic *jĭskati* (EtymDB).
