## HL-C443: the last cold letter gets a word first

Gentle writing asks for every letter to be taken from a word the reader
already says. One Tamil letter lesson came before any such word: short-o சொ,
in chapter 8.

**சொந்தம்** (*sontham*, "one's own; a relative") now opens chapter 8, before
the letter lesson. The letter lesson and the copy lesson after it each revisit
the word.

    tamil cold letter lessons   1  ->  0 (ceiling ratcheted)
