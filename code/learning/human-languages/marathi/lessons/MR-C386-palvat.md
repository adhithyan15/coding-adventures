## You'll want to know: पळवाट
<!-- hl-knowledge: introduces=[MR-LEX-C386-PRATIBANDH386-05]; assesses=[] -->

**पळवाट** — *paḷvāṭ* — "a loophole; an escape route".

> या नियमात एक पळवाट आहे.
>
> *yā niymāt ek paḷvāṭ āhe.*
>
> There is a loophole in this rule.

Feminine.

पळ + वाट, flight + path; पळवाट काढणे, to find a way out.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**पळवाट** (*paḷvāṭ*) is a Marathi compound built from the stem of पळणे, "to run away", inherited from Sanskrit *palāyate*, "flees" (CDIAL 7955), and वाट, "path", inherited from Sanskrit *vartman*, "track of a wheel, path" (CDIAL 11366): a path to run by.
