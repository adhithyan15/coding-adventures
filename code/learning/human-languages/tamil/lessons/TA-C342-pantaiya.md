# பண்டைய (paṇṭaiya) — ancient

## You'll want to know: பண்டைய
<!-- hl-knowledge: introduces=[TA-LEX-C342-PANDAIYA342-03]; assesses=[] -->

**பண்டைய** — *paṇṭaiya* — "ancient".

> இது ஒரு பண்டைய நகரம்.
>
> *itu oru paṇṭaiya nakaram.*
>
> This is an ancient city.

Only before a noun; from பண்டு, former times.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**பண்டைய** (*paṇṭaiya*) is native Dravidian: from பண்டை, பண்டு, "antiquity, former time" (DEDR 3999).
