**lächeln** — "to smile".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**lächeln** is *lachen*, "to laugh", with the ending *-eln*, which makes an action small: a little laugh. *lachen* ← Proto-Germanic *\*hlahjaną*, English *laugh*. (EtymDB 2.1)
