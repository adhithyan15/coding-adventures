# Review — if, then, or else

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[UR-GRAMMAR-C273-COMPARISON-01, UR-GRAMMAR-C273-COMPARISON-02, UR-GRAMMAR-C273-DURATION-02, UR-GRAMMAR-C273-DURATION-01] -->

[PAUSE 2s] Say "the bus is cheaper than a taxi" and "this is the best". (*bas ṭaiksī se sastī hai*, *yih sab se achchhā hai*.) Then "I've lived here for two years". (*maiṅ do sāl se yahāṅ rahtā hūṅ*.)

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[UR-GRAMMAR-C274-IF-01, UR-GRAMMAR-C274-IF-02, UR-GRAMMAR-C274-REAL-01, UR-GRAMMAR-C274-REAL-02, UR-LEX-C274-SHART-01, UR-LEX-C271-CHHUTNA-01, UR-GRAMMAR-C272-AMBITION-02] -->

[PAUSE 2s each]
- [YOU SAY: I hope she'll come. If she comes tomorrow, we'll go to the market.]
- [YOU SAY: If you have time, come.]
- [YOU SAY: Hurry, or we'll miss the train.]
- [YOU SAY: If it rains, we'll stay at home.]
- [YOU SAY: If we miss the train, we'll go by bus.]
- [YOU SAY: I'll come on one condition.]

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[UR-GRAMMAR-C274-IF-01, UR-GRAMMAR-C274-IF-02, UR-GRAMMAR-C274-REAL-01, UR-GRAMMAR-C274-REAL-02] -->

[PAUSE 3s] "If it rains"? (**اگر بارش ہوئی**.) Now the other way round: what does **ورنہ** warn about? (What will happen if you don't.) In **اگر وہ کل آئے گی**, which time is the verb in? (The future.)
