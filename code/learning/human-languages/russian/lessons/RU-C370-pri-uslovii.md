## You'll want to know: при условии
<!-- hl-knowledge: introduces=[RU-LEX-C370-USLOVIYE-02]; assesses=[] -->

**при условии** (*pri uslóvii*) — "on condition, provided (that)".

> Я пойду при условии, что ты пойдёшь со мной.
>
> *Ya poydú pri uslóvii, chto ty poydyósh so mnoy.*
>
> I will go on condition that you come with me.

*При условии, что…* takes an ordinary indicative clause. With a noun it takes the genitive: *при условии оплаты*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**при условии** is *при* "at, under" with the prepositional of *условие* "a condition", which is built on *слово* "word", Proto-Slavic *\*slovo* (EtymDB).
