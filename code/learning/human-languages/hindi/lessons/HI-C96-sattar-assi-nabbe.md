# सत्तर अस्सी नब्बे — the last three rungs

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[HI-LEX-C96-TENS-03, HI-LEX-C96-TENS-04] -->

[PAUSE 2s] Say **पचास** and **साठ**. One of them kept the old ending and one
dropped it.

## You'll want to know: सत्तर, अस्सी, नब्बे
<!-- hl-knowledge: introduces=[HI-LEX-C96-TENS-05, HI-LEX-C96-TENS-06, HI-LEX-C96-TENS-07]; assesses=[] -->

**सत्तर** (*sattar*) — seventy.

**अस्सी** (*assī*) — eighty.

**नब्बे** (*nabbe*) — ninety.

## Grammar Lens: each one leans on a number you already count
<!-- hl-knowledge: introduces=[]; assesses=[HI-LEX-C96-TENS-05, HI-LEX-C96-TENS-06, HI-LEX-C96-TENS-07] -->

| small number | ten times it |
|---|---|
| सात | सत्तर |
| आठ | अस्सी |
| नौ | नब्बे |

Read that table down the left and you are counting seven, eight, nine — which
you have done since early on. Read it down the right and you are counting
seventy, eighty, ninety.

**The opening consonant survives in all three**, and that is the whole of the
help on offer. Beyond the first sound, each word has been worn into its own
shape and has to be met as a word.

Say the pairs across, one after another: *sāt, sattar. āṭh, assī. nau, nabbe.*
Hearing them together is what makes them stick.
