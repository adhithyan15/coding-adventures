# खुलो (khulo) — open

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MW-LEX-C54-VERBS54-01, MW-SCRIPT-GHAR-01, MW-SCRIPT-DUKAN-01] -->

[PAUSE 2s] Before the new one: say *to open*, **खोलणो**. Then *a house* and *a
shop*.

## You'll want to know: खुलो
<!-- hl-knowledge: introduces=[MW-LEX-C164-NOTICE164-01]; assesses=[MW-GRAMMAR-C153-BE-HAI-01, MW-SCRIPT-GHAR-01] -->

**खुलो** — *khulo* — "open".

> **घर खुलो है।**
>
> *ghar khulo hai.* — The house is open.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[MW-LEX-C54-VERBS54-01] -->

**खुलो** (*khulo*) is inherited: CDIAL lists Old Marwari *khulo*, "open", in the
same entry as **खोलणो**, under a reconstructed *khōll*, "to open" (CDIAL 3945).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[MW-LEX-C164-NOTICE164-01, MW-GRAMMAR-C156-POSS-AGREE-01] -->

**खुलो** ends like **छोरो** and changes the same way, to agree with what is open:
**घर खुलो है।**, but **दुकान खुली है।** (*dukān khulī hai.*), the shop is open.

## Guided Practice
