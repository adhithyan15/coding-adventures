## Guided Practice

- [YOU HEAR: *Aman ghar vich sii*; YOU SAY: **ਅਮਨ ਘਰ ਵਿੱਚ ਸੀ**]
- [YOU HEAR: *phull laal san*; YOU SAY: **ਫੁੱਲ ਲਾਲ ਸਨ**]
- [YOU HEAR: *oh kamm karde san*; YOU SAY: **ਉਹ ਕੰਮ ਕਰਦੇ ਸਨ**]
- [YOU WRITE: cover the lines and write **ਸੀ, ਸਨ**]

One singular description takes **ਸੀ**. Both plural frames take **ਸਨ**.
