# പോഷകാഹാരം (pōṣakāhāraṁ) — nutritious food; nutrition

## You'll want to know: പോഷകാഹാരം
<!-- hl-knowledge: introduces=[ML-LEX-C539-AHARAM539-05]; assesses=[] -->

**പോഷകാഹാരം** — *pōṣakāhāraṁ* — "nutritious food; nutrition".

> കുട്ടികൾക്ക് പോഷകാഹാരം കിട്ടണം.
>
> *kuṭṭikaḷkkŭ pōṣakāhāraṁ kiṭṭaṇaṁ.*
>
> Children must get nutritious food.

പോഷകം nourishing + ആഹാരം food, joined into one long ആ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**പോഷകാഹാരം** (*pōṣakāhāraṁ*) is a learned compound built from Sanskrit *poṣaka*, "nourishing" (Monier-Williams), and *āhāra*, "taking food, food" (CDIAL 1544).

## What you've built
