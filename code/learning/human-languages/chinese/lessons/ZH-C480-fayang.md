## You'll want to know: fāyǎng
<!-- hl-knowledge: introduces=[ZH-LEX-C480-SYMPTOM480-02]; assesses=[] -->

*fāyǎng* — "to itch".

> *shāngkǒu yǒudiǎnr fāyǎng* — The wound is a bit itchy.

Its characters come later; for now it is a word for the ear.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*fāyǎng* is built from 发 'to set going' and *yǎng* 'itchy', both inherited from Middle Chinese, *pjot* and *yangX* (Guangyun, in Baxter's transcription), which glosses the second as itchy skin.
