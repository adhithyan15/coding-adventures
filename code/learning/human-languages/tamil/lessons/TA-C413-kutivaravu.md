# குடிவரவு (kuṭivaravu) — immigration

## Warm-up

[PAUSE 2s] Before the new one: say the Tamil for a wing, then the Tamil for customs.

## You'll want to know: குடிவரவு
<!-- hl-knowledge: introduces=[TA-LEX-C413-VIMANI413-05]; assesses=[] -->

**குடிவரவு** — *kuṭivaravu* — "immigration".

> குடிவரவு வரிசையில் ஒரு மணி நேரம் நின்றோம்.
>
> *kuṭivaravu varicaiyil oru maṇi nēram niṉṟōm.*
>
> We stood in the immigration queue for an hour.

குடி, a home, + வரவு, coming: coming to live.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**குடிவரவு** (*kuṭivaravu*) is built from குடி, "a house, a home" (DEDR 1655), and வரவு, "coming" (DEDR 5270).
