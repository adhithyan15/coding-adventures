## You'll want to know: कृतघ्नः
<!-- hl-knowledge: introduces=[SA-LEX-C361-SHRADDHA361-04]; assesses=[] -->

**कृतघ्नः** — *kṛtaghnaḥ* — "ungrateful".

> कृतघ्नः जनः उपकारं विस्मरति।
>
> *kṛtaghnaḥ janaḥ upakāraṃ vismarati.*
>
> An ungrateful person forgets a kindness.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**कृतघ्नः** (*kṛtaghnaḥ*) is built from *kṛta*, "what has been done", and the root √han, "to strike, to destroy"; MW explains it as "destroying past services", that is "ungrateful" (MW).
