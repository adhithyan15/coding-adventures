# Use an exact known lessons.py category rather than guessing a short category name

I guessed `workflow` as a lesson category, but `lessons.py` accepts only the repository's canonical category names. When creating a lesson, copy the exact category from `_meta.md` or from the command's reported known-category list; for process mistakes, use `Repo policy / workflow reminders`.
