## You'll want to know: orgulloso
<!-- hl-knowledge: introduces=[ES-LEX-C705-ORGULLO-02]; assesses=[] -->

**orgulloso** — "proud".

> Estoy orgulloso de ti.
>
> *I am proud of you.*

*Estar orgulloso de* — to be proud of. Feminine *orgullosa*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*orgulloso* is built on *orgullo* "pride" with the ending *-oso*, which makes adjectives; *orgullo* was borrowed from Catalan *orgull*, from Frankish *urgōli* (EtymDB).
