# છટકબારી (chaṭakbārī) — a loophole

## You'll want to know: છટકબારી
<!-- hl-knowledge: introduces=[GU-LEX-C541-SHAPATH541-04]; assesses=[] -->

**છટકબારી** — *chaṭakbārī* — "a loophole".

> જો નિયમમાં કોઈ છટકબારી હશે તો કોઈ તે નિયમ નહીં પાળે.
>
> *jo niyammā̃ koī chaṭakbārī haśe to koī te niyam nahī̃ pāḷe.*
>
> If there is a loophole in the rule, nobody will keep it.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**છટકબારી** (*chaṭakbārī*) is built from **છટકવું**, "to slip away", which CDIAL files under *\*chaṭṭ* (CDIAL 4968), and **બારી**, "a window": a window to slip out through.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
