# नमस्ते — look, hide, write, compare

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[HI-CONCEPT-W05-WRITE-NAMASTE-01, HI-CONCEPT-W05-WRITE-NAMASTE-02] -->

Look at **नमस्ते** for five seconds. Point to **न**, **म**, **स्**, and **ते**.
Do not copy while the model is visible.

## Writing — delayed copy
<!-- hl-knowledge: introduces=[]; assesses=[HI-CONCEPT-W05-WRITE-NAMASTE-01, HI-CONCEPT-W05-WRITE-NAMASTE-02] -->
<!-- hl-writing-stage: delayed-copy -->

- cover **नमस्ते**
- wait five seconds
- write it once from memory
- uncover the model and compare the four known pieces

If one piece differs, circle it and repair only that place. Repair is part of
the exercise, not a failure. There is no tracing and no romanized answer model.

## Wrap-up recall
<!-- hl-knowledge: introduces=[]; assesses=[HI-CONCEPT-W05-WRITE-NAMASTE-01, HI-CONCEPT-W05-WRITE-NAMASTE-02] -->
<!-- hl-activity: {"id":"HI-W05-namaste-delayed-copy-check","kind":"text","assesses":["HI-CONCEPT-W05-WRITE-NAMASTE-01","HI-CONCEPT-W05-WRITE-NAMASTE-02"],"prompt":"After hiding the model for five seconds, write the familiar Hindi greeting and then compare it.","answer":"नमस्ते","accepted":[],"feedback":{"correct":"नमस्ते — the four known pieces are in place.","incorrect":"Uncover नमस्ते, repair only the differing piece, and stop after one memory attempt."},"response_seconds":20} -->

Read your repaired word aloud and remember its literal sense: **a bow to you**.
Stop after one memory attempt.
