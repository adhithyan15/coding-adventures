## You'll want to know: यंत्र
<!-- hl-knowledge: introduces=[MR-LEX-C518-YANTRA518-01]; assesses=[] -->

**यंत्र** — *yantra* — "a machine".

> हे यंत्र विजेवर चालतं.
>
> *he yantra vijevar cāltaṁ.*
>
> This machine runs on electricity.

Neuter.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**यंत्र** (*yantra*) is a tatsama, taken from Sanskrit *yantra*, "an instrument, a machine" (Monier-Williams).
