## You'll want to know: வருடு
<!-- hl-knowledge: introduces=[TA-LEX-C502-NERUKKAM502-04]; assesses=[] -->

**வருடு** — *varuṭu* — "to stroke; to caress".

> அம்மா என் தலையை அன்போடு வருடினாள்.
>
> *ammā eṉ talaiyai aṉpōṭu varuṭiṉāḷ.*
>
> Mother stroked my head lovingly.

Past (I …): வருடினேன், *varuṭiṉēṉ*.

Gently, with the hand.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**வருடு** (*varuṭu*) is a native Tamil verb whose origin is not settled; DEDR has no entry for it that we can point to.
