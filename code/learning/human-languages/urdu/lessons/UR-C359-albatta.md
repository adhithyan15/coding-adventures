# البتہ (albattā) — however; mind you

## You'll want to know: البتہ
<!-- hl-knowledge: introduces=[UR-LEX-C359-BAVUJUD359-04]; assesses=[] -->

**البتہ** — *albattā* — "however; mind you".

> کام مشکل ہے، البتہ ناممکن نہیں۔
>
> *kām mushkil hai, albattā nāmumkin nahīṅ.*
>
> The work is hard; it is not impossible, though.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**البتہ** (*albattā*) is usually traced, through Persian, to Arabic *al-battata*, "decidedly, by all means"; in Urdu it brings in a reservation.

## What you've built
