## You'll want to know: پشتیبانی
<!-- hl-knowledge: introduces=[FA-LEX-C418-NARMAFZAR-05]; assesses=[] -->

**پشتیبانی** (*poshtibâni*) — "technical support; backing".

> پشتیبانی شرکت مشکل را حل کرد.
>
> *poshtibâni-ye sherkat moshkel râ hal kard.*
>
> The company's support team solved the problem.

*Posht* "back" + *-bân* "keeper" + *-i*. *Poshtibâni kardan* — to support.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**پشتیبانی** is native Persian, built from *posht* "back", usually traced to Middle Persian *pušt*, + *-bân* "keeper" + *-i*. Support is keeping someone's back.
