## You'll want to know: проясняться
<!-- hl-knowledge: introduces=[RU-LEX-C464-PROGNOZ-05]; assesses=[] -->

**проясняться** (*proyasnyátsya*) — "to clear up (of the weather)".

> К вечеру небо проясняется.
>
> *K vécheru nébo proyasnyáyetsya.*
>
> Towards evening the sky clears up.

Imperfective; perfective *проясниться*. Built on *ясный* — clear.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*проясняться* is built from *про-*, *ясный* 'clear, bright' and *-ся*. EtymDB does not list the verb.
