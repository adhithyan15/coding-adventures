# ઉન્નતિ (unnati) — advancement

## You'll want to know: ઉન્નતિ
<!-- hl-knowledge: introduces=[GU-LEX-C384-SAFAL384-02]; assesses=[] -->

**ઉન્નતિ** — *unnati* — "advancement".

> જો ગામમાં શાળા અને દવાખાનું હશે તો ગામની ઉન્નતિ થશે.
>
> *jo gāmmā̃ śāḷā ane davākhānũ haśe to gāmnī unnati thaśe.*
>
> If the village has a school and a clinic, it will move ahead.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ઉન્નતિ** (*unnati*) is a tatsama, borrowed from Sanskrit *unnati*, "rising, ascending" (Monier-Williams).
