## You'll want to know: die Einschaltquote
<!-- hl-knowledge: introduces=[GE-LEX-C523-FERNSEHEN-05]; assesses=[] -->

**die Einschaltquote** — "ratings, viewing figures".

> Die Show hatte eine hohe Einschaltquote.
>
> *The show had high ratings.*

Plural: *die Einschaltquoten*. Built on *einschalten* — to switch on.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*Einschaltquote* is built on *einschalten* "to switch on" and *Quote* "share", which goes back to Latin *quotus* "how many" (EtymDB).
