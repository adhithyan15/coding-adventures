# comiendo · viviendo — two families, one ending

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ES-GRAMMAR-GERUND-AR, ES-GRAMMAR-GERUND-MEANING] -->

[PAUSE 2s] *Hablar* gave *hablando*. Now the other two families.

## Grammar Lens: -iendo, for both
<!-- hl-knowledge: introduces=[ES-GRAMMAR-GERUND-ER-IR]; assesses=[ES-LEX-COMER, ES-LEX-VIVIR] -->

| | |
|---|---|
| *comer* | ***comiendo*** |
| *beber* | ***bebiendo*** |
| *vivir* | ***viviendo*** |
| *escribir* | ***escribiendo*** |

[PAUSE 2s] One ending for both. Not *-endo* for *-er* and something else for
*-ir* — the same *-iendo*, every time.

## Why it's said this way
<!-- hl-knowledge: introduces=[ES-GRAMMAR-GERUND-TWO-ENDINGS]; assesses=[ES-GRAMMAR-ER-IR-PRETERITE-CONVERGENCE] -->

[PAUSE 2s] You have watched this happen before. In the preterite, the *-er* and
*-ir* endings turned out to be identical, and the two families you had learned
separately quietly became one.

[PAUSE 2s] Here it happens again, and more completely: there is not even a
difference to notice. So the whole gerund is **two endings for three verb
families**:

| | |
|---|---|
| *-ar* verbs | ***-ando*** |
| everything else | ***-iendo*** |

[PAUSE 2s] Two endings, no agreement, no persons. It is the smallest thing this
book has asked you to learn, and it unlocks the next chapter entirely.
