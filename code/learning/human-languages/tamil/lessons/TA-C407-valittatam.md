# வழித்தடம் (vaḻittaṭam) — a route

## You'll want to know: வழித்தடம்
<!-- hl-knowledge: introduces=[TA-LEX-C407-URIMAM407-04]; assesses=[] -->

**வழித்தடம்** — *vaḻittaṭam* — "a route".

> இந்தப் பேருந்தின் வழித்தடம் மாறியிருக்கிறது.
>
> *intap pēruntiṉ vaḻittaṭam māṟiyirukkiṟatu.*
>
> This bus's route has changed.

தடம் alone is a track or a footprint; வழி doubles the த்.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**வழித்தடம்** (*vaḻittaṭam*) is built from வழி, "a way" (DEDR 5297), and தடம், "a path, a route" (DEDR 3024).
