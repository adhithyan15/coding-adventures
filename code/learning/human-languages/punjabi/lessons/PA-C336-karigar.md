## You'll want to know: ਕਾਰੀਗਰ
<!-- hl-knowledge: introduces=[PA-LEX-C336-TRADE336-01]; assesses=[] -->

**ਕਾਰੀਗਰ** — *kārīgar* — "a craftsman".

> ਇਹ ਕਾਰੀਗਰ ਲੱਕੜ ਦਾ ਕੰਮ ਕਰਦਾ ਹੈ।
>
> *eh kārīgar lakkaṛ dā kamm kardā hai.*
>
> This craftsman does woodwork.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ਕਾਰੀਗਰ** (*kārīgar*) is a loan, usually traced to Persian *kārīgar*, "a craftsman".
