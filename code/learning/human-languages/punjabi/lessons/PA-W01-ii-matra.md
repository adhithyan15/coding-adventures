## Script
<!-- hl-knowledge: introduces=[PA-SCRIPT-II-MATRA-01]; assesses=[PA-SCRIPT-HA-01, PA-SCRIPT-AA-MATRA-01, PA-SCRIPT-BINDI-01, PA-SCRIPT-NA-01] -->

> ੀ

**ī**, the long *ee* of English *see*. Like the first mātrā it stands to the
right, but it carries a curve that rises and **hooks back over the head-line**.

Now build with everything you have:

> **ਨ** + **ਹ** + **ੀ** + **ਂ** → **ਨਹੀਂ**

**na-hīṁ** — **no**. Two consonants, one mātrā, one nasal dot.

Both answers to a yes-or-no question are now readable:

> **ਹਾਂ**   **ਨਹੀਂ**

That is the arithmetic of an abugida: consonants and mātrās **multiply**, so a
handful of pieces reaches a large number of syllables very quickly.
