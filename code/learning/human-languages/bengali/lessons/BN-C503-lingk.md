## You'll want to know: লিংক
<!-- hl-knowledge: introduces=[BN-LEX-C503-ONLINE503-02]; assesses=[] -->

**লিংক** — *lingk* — "a link online; a web link".

> আমি বন্ধুকে ভিডিওর লিংক পাঠালাম।
>
> *Āmi bôndhuke bhiḍior lingk pāṭhālām.*
>
> I sent my friend the link to the video.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**লিংক** (*lingk*) is borrowed from English *link*.
