## You'll want to know: कुतूहल
<!-- hl-knowledge: introduces=[MR-LEX-C465-NAVAL465-02]; assesses=[] -->

**कुतूहल** — *kutūhal* — "curiosity".

> नव्या खेळण्याबद्दल बाळाला खूप कुतूहल होतं.
>
> *navyā kheḷṇyābaddal bāḷālā khūp kutūhal hotaṁ.*
>
> The baby was very curious about the new toy.

Neuter.

कुतूहल वाटणे, with the dative; beside उत्सुक, curious.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**कुतूहल** (*kutūhal*) is a tatsama, taken from Sanskrit *kutūhala*, "curiosity, interest in anything extraordinary" (Monier-Williams).
