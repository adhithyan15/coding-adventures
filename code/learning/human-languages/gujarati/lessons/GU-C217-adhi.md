## You'll want to know: આંધી
<!-- hl-knowledge: introduces=[GU-LEX-C217-WIND217-03]; assesses=[] -->

**આંધી** — *ā̃dhī* — "dust storm".

> **બપોરે રણમાં આંધી આવશે.** — *bapore raṇmā̃ ā̃dhī āvśe* — "A dust storm will come in the desert at midday."

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**આંધી** (*ā̃dhī*) is a tadbhava. CDIAL lists it, glossed "duststorm", under Sanskrit *andhikā*, "night", built on *andha*, "blind", so the storm is one that brings darkness (CDIAL 390).
