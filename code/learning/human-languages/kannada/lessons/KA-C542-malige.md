# ಮಾಳಿಗೆ (māḷige) — an upper storey; a flat roof

## You'll want to know: ಮಾಳಿಗೆ
<!-- hl-knowledge: introduces=[KA-LEX-C542-MANE542-01]; assesses=[] -->

**ಮಾಳಿಗೆ** — *māḷige* — "an upper storey; a flat roof".

> ಮಕ್ಕಳು ಮಾಳಿಗೆಯ ಮೇಲೆ ಗಾಳಿಪಟ ಹಾರಿಸಿದರು.
>
> *makkaḷu māḷigeya mēle gāḷipaṭa hārisidaru.*
>
> The children flew kites on the roof.

ಮಾಳಿಗೆ ಮನೆ, a house with an upper floor.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಮಾಳಿಗೆ** (*māḷige*) is native Dravidian: DEDR 4796 lists Kannada *māḍa*, *māḷa* and *māḷige*, "a large building, an upstair house".
