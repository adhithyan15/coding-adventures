## You'll want to know: उत्कर्षः
<!-- hl-knowledge: introduces=[SA-LEX-C385-SPARDHA385-05]; assesses=[] -->

**उत्कर्षः** — *utkarṣaḥ* — "excellence".

> यदि नित्यम् अभ्यासं करोति, तर्हि उत्कर्षः निश्चितः।
>
> *yadi nityam abhyāsaṃ karoti, tarhi utkarṣaḥ niścitaḥ.*
>
> If one practises constantly, excellence is certain.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**उत्कर्षः** (*utkarṣaḥ*) is built on *ut*, "up", and the root √kṛṣ, "to draw"; MW gives *ut-karṣa* "excellence, eminence" (MW).
