## You'll want to know: bǎitān
<!-- hl-knowledge: introduces=[ZH-LEX-C448-MARKET448-05]; assesses=[] -->

*bǎitān* — "to set up a street stall".

> *tā měitiān zài shìchǎng bǎitān* — He runs a stall at the market every day.

Its characters come later; for now it is a word for the ear.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*bǎitān* is built from *bǎi* 'to set out' and *tān* 'to spread out', both inherited from Middle Chinese, *peaX* and *than* (Guangyun, in Baxter's transcription), which glosses the first 'to push aside' and the second 'to open out'; the sense 'to set out goods' for the first is not given there.
