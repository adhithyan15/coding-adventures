# ० १ २ — the first three digits

## Warm-up

[PAUSE 20s] Recall the numbered-price payoff, then write ten, twenty and a
hundred in words.

## Script — the first three figures
<!-- hl-knowledge: introduces=[MW-SCRIPT-DIGIT-ZERO-01, MW-SCRIPT-DIGIT-ONE-01, MW-SCRIPT-DIGIT-TWO-01]; assesses=[] -->

Everything this chapter has written so far has been a number in words. A
Rajasthani stall does not label anything in words. It writes figures, and
Devanagari has its own ten.

> **०** — zero  **१** — one  **२** — two

Look at where the ink sits. Each of these hangs from a stroke along the top,
the same head-line that carries **क** and **न** and every other letter in this
book. That is the quickest way to tell a Devanagari digit from a Latin one on a
mixed sign.

and third as you write them.
