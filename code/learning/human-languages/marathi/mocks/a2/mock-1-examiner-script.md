# Marathi A2 mock 1 — examiner script

Keep this file away from the learner. It supplies examiner-read listening and
speaking prompts; it is not recording-provenance evidence and does not imply a
qualified speaker or trained rater.

Deliver each complete listening part at 110–130 words per minute with two plays.
The announcement must occupy exactly 90 seconds per play; the conversation and
connected account must each occupy exactly 120 seconds per play. Start the timer
with the first word and, after the final word, keep silence until the exact
90-second or 120-second window ends. Preserve the words, order, pace, and silence
on the second play. Do not add answer-bearing words or a learner-selected third
play. A technical restart replaces the affected play.

## Listening

### Announcements — items 1–7

Read as one announcement:

**प्रवाशांनी कृपया लक्ष द्यावे. पुण्याला जाणारी सकाळची रेल्वे वीस मिनिटे
उशिरा येत आहे. ही रेल्वे नेहमीच्या तिसऱ्या फलाटाऐवजी पाचव्या फलाटावरून
जाईल. प्रवाशांना नवे तिकीट घ्यायची गरज नाही; आजचे तिकीटच चालेल. पाचव्या
फलाटावरील पाण्याचे यंत्र सध्या चालत नाही. पाणी पहिल्या फलाटावरील दुकानात
मिळेल. वृद्ध किंवा मदत हवी असलेल्या प्रवाशांसाठी चौकशी कक्षाजवळ रेल्वेचे
कर्मचारी असतील. रेल्वे रद्द झालेली नाही. कृपया पाचव्या फलाटावर जा आणि
तिथे थांबा.**

### Everyday conversation — items 8–14

Read as one conversation:

**मीरा: अरुण, आपल्या सहलीची बस सात वाजता सुटणार होती. ती आता आठ वाजता
सुटणार आहे. आपण सात वाजता बसस्थानकावर पोहोचू या. अरुण: बरोबर. मी कालच दोन तिकिटं
घेतली आहेत. दोन्ही जागा खिडकीजवळ आहेत. मीरा: छान. बस मध्ये कुठे थांबेल?
अरुण: अकरा वाजता एका गावात वीस मिनिटे थांबेल. तिथे चहा आणि नाश्ता मिळेल.
मीरा: हवामान थंड असू शकतं. मी छत्री आणि गरम कपडे आणते. अरुण: बरोबर. आपण
संध्याकाळी सहा वाजण्यापूर्वी गावात पोहोचू. उशीर झाला तर मी घरी संदेश
पाठवेन.**

### Connected account — items 15–20

Read as one account:

**मागच्या रविवारी मी माझी मैत्रीण मीराबरोबर पहिल्यांदा लांब सायकलफेरीला
गेलो. आम्ही सकाळी सहा वाजता घरातून निघालो. मुख्य रस्त्यावर गाड्या खूप होत्या,
म्हणून आम्ही गावातून जाणारा छोटा रस्ता निवडला. थोड्या वेळाने माझी पिशवी
हरवली. मला काळजी वाटली, पण मीराने मला शोधायला मदत केली. पिशवी आम्ही चहा
घेतलेल्या दुकानाजवळ होती. त्या दुकानातून आम्ही फळं आणि पाणी घेतलं.
डोंगराजवळ पोहोचलो तेव्हा हलका पाऊस सुरू झाला, म्हणून आम्ही थोडा वेळ
झाडाखाली थांबलो. परत आल्यावर मी थकलो होतो, तरी पुढच्या महिन्यात पुन्हा
सायकलने जाण्याचं ठरवलं.**

## Speaking

Allow five-minute preparation before the speaking paper. Read the six interview
questions in one 10–45-second stimulus window and allow one combined 120–180-second response window.
Use the learner's keyword notes only for the prepared account,
whose response window is 90–120 seconds. Deliver the role-play card in one
20–40-word stimulus and allow a 120–180-second response window. Do not provide
an answer model, translation, or coaching.

### Personal interview

1. **तुमच्या घराजवळ कोणती जागा तुम्हाला आवडते? का?**
2. **तुम्ही सध्या काय शिकता किंवा कोणते काम करता?**
3. **तुम्ही नेहमी कुठे आणि कसे प्रवास करता?**
4. **काल किंवा परवा तुम्ही काय केले?**
5. **तुम्हाला शहरात राहणे आवडते की गावात? एक कारण सांगा.**
6. **पुढच्या आठवड्यात तुम्ही काय करणार आहात?**

### Prepared account

Show only this card: **तुम्ही भेट दिलेली एक जागा सांगा: ती कुठे आहे,
तुम्ही कधी आणि कोणाबरोबर गेलात, प्रवासात काय झालं, तिथे काय केलं आणि
तुम्हाला कसं वाटलं?**

### Information-exchange role-play

Show and read only this Marathi card: **तुम्हाला गावाला जाण्यासाठी परतीचं
बसचं तिकीट हवं आहे. गाव आणि प्रवासाचा दिवस सांगा. जाण्याची आणि परत येण्याची
वेळ विचारा. माहिती पूर्ण नसेल तर पुन्हा विचारा, तिकीट मागा आणि शेवटी धन्यवाद द्या.**
Reply **परतीची बस संध्याकाळी आहे** without giving a time so the learner must
clarify. Do not supply an answer model.
