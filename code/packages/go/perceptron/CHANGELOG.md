# Changelog

All notable changes to the Go perceptron package will be documented in this
file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2026-09-30

### Added

- Direct tests for constructor state, prediction before training, learned AND
  behavior, prediction thresholds, and trained weight shape.
- Repository BUILD front with measured package coverage.
- Package documentation with a complete training example.

## [0.1.0] - 2026-03-20

### Added

- Initial sigmoid perceptron with batch-gradient training and prediction.
