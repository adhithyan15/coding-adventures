## You'll want to know: jahrelang
<!-- hl-knowledge: introduces=[GE-LEX-C269-JAHRZEHNT-04]; assesses=[] -->

**jahrelang** — "for years".

> Er arbeitete jahrelang in einer Fabrik.
>
> *He worked in a factory for years.*

Built the same way: *tagelang*, *wochenlang*, *monatelang* — for days, weeks, months.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*jahrelang* joins *Jahre* "years" and *lang* "long", both inherited Germanic words (EtymDB).
