## You'll want to know: ਅਸਲੀ
<!-- hl-knowledge: introduces=[PA-LEX-C279-SWAP279-03]; assesses=[] -->

**ਅਸਲੀ** — *aslī* — "genuine; real".

> ਕੀ ਇਹ ਸ਼ਹਿਦ ਅਸਲੀ ਹੈ?
>
> *kī eh shahid aslī hai?*
>
> Is this honey genuine?

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ਅਸਲੀ** (*aslī*) is a loan, usually traced through Persian to Arabic *aslī*, "original".
