# Changelog

All notable changes to the `pif-prelude` package are documented in this directory, one file per release.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## Layout

Files are named `NNNNN-SLUG-HEX8.md` (rank, uppercase slug, 8-hex digest); rank order is chronological. `_meta.md` is this entry point.
