## You'll want to know: histórico
<!-- hl-knowledge: introduces=[ES-LEX-C568-REY-01]; assesses=[] -->

**histórico** — "historic; historical".

> Fue un día histórico para el país.
>
> *It was a historic day for the country.*

*El centro histórico* — the old town.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*histórico* is a learned borrowing from Latin *historicus*, which comes from Greek *historikós* 'of history' (EtymDB), built on *historía* 'an inquiry'.
