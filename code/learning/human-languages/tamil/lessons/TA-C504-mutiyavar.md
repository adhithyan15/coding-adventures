# முதியவர் (mutiyavar) — an elderly person

## You'll want to know: முதியவர்
<!-- hl-knowledge: introduces=[TA-LEX-C504-MUTUMAI504-02]; assesses=[] -->

**முதியவர்** — *mutiyavar* — "an elderly person".

> பேருந்தில் நின்ற முதியவருக்கு நான் இடம் கொடுத்தேன்.
>
> *pēruntil niṉṟa mutiyavarukku nāṉ iṭam koṭuttēṉ.*
>
> I gave my place on the bus to an elderly man who was standing.

Plural: முதியவர்கள், *mutiyavarkaḷ*.

Respectful -அர்; plural முதியவர்கள்.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**முதியவர்** (*mutiyavar*) is native Dravidian, built on முது *mutu*, "old" (DEDR 4954), with the respectful -அவர்.
