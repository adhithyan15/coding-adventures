# காரணி (kāraṇi) — a factor

## You'll want to know: காரணி
<!-- hl-knowledge: introduces=[TA-LEX-C352-ERPATUTTU352-03]; assesses=[] -->

**காரணி** — *kāraṇi* — "a factor".

> விலை உயர்வுக்குப் பல காரணிகள் இருக்கின்றன.
>
> *vilai uyarvukkup pala kāraṇikaḷ irukkiṉṟaṉa.*
>
> There are many factors behind the rise in prices.

Plural: காரணிகள், *kāraṇikaḷ*.

X-க்குக் காரணி, a factor in X. The plural is காரணிகள்.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**காரணி** (*kāraṇi*) is built on Sanskrit *kāraṇa*, "cause" (CDIAL 3057), the source of காரணம், with the ending -இ: "that which acts as a cause", the word for a factor.
