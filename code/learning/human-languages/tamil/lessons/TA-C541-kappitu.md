# காப்பீடு (kāppīṭu) — insurance

## You'll want to know: காப்பீடு
<!-- hl-knowledge: introduces=[TA-LEX-C541-KAPPEEDU541-01]; assesses=[] -->

**காப்பீடு** — *kāppīṭu* — "insurance".

> வீட்டுக்குக் காப்பீடு இருந்தால் கவலை இல்லை.
>
> *vīṭṭukkuk kāppīṭu iruntāl kavalai illai.*
>
> If the house is insured, there is no worry.

What is insured takes -க்கு: வீட்டுக்குக் காப்பீடு. In speech people also say இன்சூரன்ஸ்.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**காப்பீடு** (*kāppīṭu*) is a modern native compound: காப்பு (*kāppu*), "protection", from கா (*kā*), "to guard" (DEDR 1416), and a second part *-īṭu*, whose exact sense here is not settled.
