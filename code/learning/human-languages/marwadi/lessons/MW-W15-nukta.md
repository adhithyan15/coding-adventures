# ड़ — one dot under familiar ड

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MW-LEX-KAPDA-01, MW-SCRIPT-DDA-01, MW-LEX-DADI-01, MW-SCRIPT-DADI-01, MW-SCRIPT-SAMAAN-01] -->

[PAUSE 20s] Say clothes, then write familiar **ड**, paternal grandmother,
and goods.

## Script — one mark
<!-- hl-knowledge: introduces=[MW-SCRIPT-NUKTA-01, MW-SCRIPT-RRA-01]; assesses=[] -->

> **ड** + **़** → **ड़**

The dot below is called a nukta. Here it marks the quick curled sound in
*kapṛā*.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-NUKTA-01, MW-SCRIPT-RRA-01] -->
<!-- hl-writing-stage: observe-trace -->

Trace **ड़** once. Copy it once. Cover it, wait five seconds, and write **ड़**
from the sound cue.
