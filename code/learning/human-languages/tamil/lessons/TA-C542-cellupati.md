# செல்லுபடி (cellupaṭi) — validity

## You'll want to know: செல்லுபடி
<!-- hl-knowledge: introduces=[TA-LEX-C542-UTHTHARAVATHAM542-02]; assesses=[] -->

**செல்லுபடி** — *cellupaṭi* — "validity".

> உங்கள் சீட்டு இன்று வரை மட்டுமே செல்லுபடி ஆகும்.
>
> *uṅkaḷ cīṭṭu iṉṟu varai maṭṭumē cellupaṭi ākum.*
>
> Your ticket is valid only until today.

With ஆகு (*āku*) it says something is valid: செல்லுபடி ஆகும்.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**செல்லுபடி** (*cellupaṭi*) is a native compound: செல்லு, from செல் (*cel*), "to go, to pass as coin, to be acceptable" (DEDR 2781), and படி, "a measure, a way".
