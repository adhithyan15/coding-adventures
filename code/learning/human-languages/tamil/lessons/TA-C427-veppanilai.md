# வெப்பநிலை (veppanilai) — temperature

## You'll want to know: வெப்பநிலை
<!-- hl-knowledge: introduces=[TA-LEX-C427-VEPPAM427-03]; assesses=[] -->

**வெப்பநிலை** — *veppanilai* — "temperature".

> மதியம் வெப்பநிலை மிக அதிகமாக இருந்தது.
>
> *matiyam veppanilai mika atikamāka iruntatu.*
>
> At noon the temperature was very high.

வெப்பம், heat, + நிலை, a state: the ம் drops.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**வெப்பநிலை** (*veppanilai*) is built from வெப்பம், "heat" (DEDR 5517), and நிலை, "a state" (DEDR 3675).
