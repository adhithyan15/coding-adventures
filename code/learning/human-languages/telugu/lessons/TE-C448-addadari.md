# అడ్డదారి (aḍḍadāri) — a shortcut

## You'll want to know: అడ్డదారి
<!-- hl-knowledge: introduces=[TE-LEX-C448-DISA448-05]; assesses=[] -->

**అడ్డదారి** — *aḍḍadāri* — "a shortcut".

> అడ్డదారిలో వెళ్తే పది నిమిషాలు ముందు చేరతాం.
>
> *aḍḍadārilō veḷtē padi nimiṣālu mundu cēratāṁ.*
>
> If we take the shortcut we will get there ten minutes earlier.

అడ్డ, across, + దారి, a way: a way that cuts across. It also means a dishonest shortcut.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**అడ్డదారి** (*aḍḍadāri*) is native Dravidian: అడ్డ, "crosswise, across" (DEDR 83), and దారి, "a way" (DEDR 3170).
