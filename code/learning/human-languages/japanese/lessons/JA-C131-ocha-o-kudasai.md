## You'll want to know: おちゃを ください
<!-- hl-knowledge: introduces=[JA-GRAMMAR-OBJECT-WO]; assesses=[JA-LEX-ANCHOR-OCHA, JA-LEX-ITTE-KUDASAI] -->

**おちゃを ください** — *ocha o kudasai* — "tea, please".

You know both words already: *ocha*, tea, and *kudasai*, the polite request at
the end of *itte kudasai*. What is new is the small word between them, said *o*.

It marks **the thing the request is about**: tea is what you are asking for. Put
any thing you can name in front of it and the request works the same way.

That word is spelled with a sign you have not written yet. It is said *o*, the
same as **お**, but it is a different sign, and the next lesson writes it.
