## You'll want to know: કાગડો
<!-- hl-knowledge: introduces=[GU-LEX-C237-WINGS237-01]; assesses=[] -->

**કાગડો** — *kāgḍo* — "crow".

> **ગઈકાલે એક કાગડો ઘરમાં આવ્યો.** — *gaīkāle ek kāgḍo gharmā̃ āvyo* — "Yesterday a crow came into the house."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**કાગડો** (*kāgḍo*) is usually traced to Sanskrit *kāka*, "crow", an imitative word that CDIAL says took various suffixes, with *-k-* or *-g-*, in the modern languages. CDIAL lists only Gujarati *kāu*, "crow", there, so the path to *kāgḍo* is not spelled out (CDIAL 2993).
