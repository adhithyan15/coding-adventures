# तारांबळ (tārāmbaḷ) — a scramble; a frantic hurry

## You'll want to know: तारांबळ
<!-- hl-knowledge: introduces=[MR-LEX-C555-GHAI555-05]; assesses=[] -->

**तारांबळ** — *tārāmbaḷ* — "a scramble; a frantic hurry".

> पाहुणे लवकर आले, म्हणून आमची तारांबळ उडाली.
>
> *pāhuṇe lavkar āle, mhaṇūn āmcī tārāmbaḷ uḍālī.*
>
> The guests came early, so we were thrown into a scramble.

Feminine.

तारांबळ उडणे, to be thrown into a scramble.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**तारांबळ** (*tārāmbaḷ*) is a Marathi word for a frantic scramble; its origin is not settled.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
