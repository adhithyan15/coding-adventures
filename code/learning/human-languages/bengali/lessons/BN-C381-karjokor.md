# কার্যকর (kārjôkôr) — effective

## You'll want to know: কার্যকর
<!-- hl-knowledge: introduces=[BN-LEX-C381-BYOBOSTHA381-02]; assesses=[] -->

**কার্যকর** — *kārjôkôr* — "effective".

> এই পদ্ধতি কার্যকর হলে আমরা সবাই এটা ব্যবহার করব।
>
> *ei pôddhôti kārjôkôr hôle āmrā sôbāi eṭā bæbôhār kôrbô.*
>
> If this method works, we'll all use it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**কার্যকর** (*kārjôkôr*) is Sanskrit *kāryakara*, 'work-doing', efficacious (Monier-Williams): a method or a law that does its job.
