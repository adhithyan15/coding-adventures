# ਆਖ਼ਰੀ (ākhrī) — last; final

## You'll want to know: ਆਖ਼ਰੀ
<!-- hl-knowledge: introduces=[PA-LEX-C284-OFF284-04]; assesses=[] -->

**ਆਖ਼ਰੀ** — *ākhrī* — "last; final".

> ਇਹ ਆਖ਼ਰੀ ਸਟੇਸ਼ਨ ਹੈ।
>
> *eh ākhrī saṭeshan hai.*
>
> This is the last station.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ਆਖ਼ਰੀ** (*ākhrī*) is a loan, usually traced through Persian to Arabic *ākhir*, "last", with the ending *-ī*.
