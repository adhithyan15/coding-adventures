## Added — मम prints a filmstrip: both letter bodies, then one headline

The three मम writing lessons (SA-W03-mama-guided-copy, -delayed-copy and
-dictation) now print a stroke-order strip: the body of each म in turn, then
one śirorekhā drawn left to right across the word. Most native writers leave
the headline for last (HP Labs India's native-writer data, 82% of consonant
samples); some draw it first, and the strip says the order is attested, not
standardised. Filmstrip lessons 48 -> 51.

- **Rewritten:** SA-W03-mama-guided-copy told the learner to copy each म with
  its own headline stroke and let the two meet. It now points at the strip:
  both bodies first, then one headline across both.
