## You'll want to know: atterrare
<!-- hl-knowledge: introduces=[IT-LEX-C428-VOLO-02]; assesses=[] -->

**atterrare** — "to land (of a plane)".

> Siamo atterrati in orario.
>
> *We landed on time.*

*L'atterraggio* — the landing. Built on *terra*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*atterrare* is built from *a-* 'to' and *terra* 'ground', which is inherited from Latin *terra* (EtymDB).
