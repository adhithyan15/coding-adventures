## You'll want to know: zēngjiā
<!-- hl-knowledge: introduces=[ZH-LEX-C384-BECOME384-05]; assesses=[] -->

*zēngjiā* — "to increase".

> *yīnwèi rénkǒu zēngjiā le suǒyǐ fángzi hěn guì* — The population has grown, so houses are expensive.

Its characters come later; for now it is a word for the ear.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*zēngjiā* is built from *zēng* and *jiā*, both inherited from Middle Chinese, *tsong* and *kae* (Guangyun, in Baxter's transcription), which glosses each with the other: 'to add'.
