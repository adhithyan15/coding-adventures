## You'll want to know: ميزان

**ميزان** — *mīzān* — "scales".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ميزان** (*mīzān*) is built on the native Arabic root *w-z-n*, "to weigh" (Lane). *Mīzān* is an instrument noun, "a thing to weigh with".
