## You'll want to know: સફર
<!-- hl-knowledge: introduces=[GU-LEX-C408-ROUNDS408-01]; assesses=[] -->

**સફર** — *saphar* — "a voyage; a long journey".

> દરિયાની સફર મને ઘણી ગમી.
>
> *dariyānī saphar mane ghaṇī gamī.*
>
> I really enjoyed the sea voyage.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**સફર** (*saphar*) is usually traced to Arabic *safar*, "a journey", which came through Persian; મુસાફર, a traveller, is built on the same word.
