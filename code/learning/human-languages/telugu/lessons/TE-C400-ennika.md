# ఎన్నిక (ennika) — an election

## You'll want to know: ఎన్నిక
<!-- hl-knowledge: introduces=[TE-LEX-C400-ENNIKA400-01]; assesses=[] -->

**ఎన్నిక** — *ennika* — "an election".

> వచ్చే నెలలో మా రాష్ట్రంలో ఎన్నికలు జరుగుతాయి.
>
> *vaccē nelalō mā rāṣṭraṁlō ennikalu jarugutāyi.*
>
> Elections will be held in our state next month.

Plural: ఎన్నికలు, *ennikalu*.

Mostly plural: ఎన్నికలు, the elections. It is built on ఎన్ను, to count, to reckon.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ఎన్నిక** (*ennika*) is native Dravidian: DEDR 793 lists Telugu *ennika*, "counting, number, esteem", beside *ennu*, "to count, to reckon, to think"; Telugu now uses it for an election, a choosing by count.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
