## You'll want to know: benevolentia, benevolentiae
<!-- hl-knowledge: introduces=[LA-LEX-C505-CLEM-05]; assesses=[] -->

**benevolentia, benevolentiae** — "goodwill, kindness".

> Sine benevolentiā nūlla amīcitia est.
>
> *Without goodwill there is no friendship.*

Feminine, first declension, from *benevolus*. English *benevolence*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**benevolentia** is built on *benevolus* "kindly, well-wishing" (Lewis & Short). English *benevolence* comes from it.
