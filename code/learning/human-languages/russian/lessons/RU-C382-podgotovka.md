## You'll want to know: подготовка
<!-- hl-knowledge: introduces=[RU-LEX-C382-EKZAMEN-04]; assesses=[] -->

**подготовка** (*podgotóvka*) — "preparation".

> Подготовка к экзамену занимает много времени.
>
> *Podgotóvka k ekzámenu zanimáyet mnógo vrémeni.*
>
> Preparing for an exam takes a lot of time.

Feminine. *Подготовка к* + dative.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**подготовка** is built on *подготовить* "to prepare", from *готовый* "ready", inherited from Proto-Slavic *\*gotovŭ*.
