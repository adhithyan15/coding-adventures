## You'll want to know: उपयुक्त
<!-- hl-knowledge: introduces=[MR-LEX-C395-UPAYUKTA395-01]; assesses=[] -->

**उपयुक्त** — *upyukta* — "useful".

> हे पुस्तक परीक्षेसाठी खूप उपयुक्त आहे.
>
> *he pustak parīkṣesāṭhī khūp upyukta āhe.*
>
> This book is very useful for the exam.

Invariable; X साठी उपयुक्त, useful for X.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**उपयुक्त** (*upyukta*) is a tatsama, taken from Sanskrit *upayukta*, "fit, suitable, useful" (Monier-Williams).
