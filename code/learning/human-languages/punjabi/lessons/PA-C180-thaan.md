# ਥਾਂ — one place word

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-PLACE-US-THAT-01, PA-PLACE-LOK-PEOPLE-01] -->

[PAUSE 2s] Retrieve **ਉਸ** and **ਲੋਕ** by ear.

## Grammar Lens: one location noun
<!-- hl-knowledge: introduces=[PA-PLACE-THAAN-LOCATION-01]; assesses=[PA-PLACE-US-THAT-01] -->

> **ਥਾਂ** — *thā̃* — place

> **ਉਸ ਥਾਂ** — *us thā̃* — that place

Keep this as a two-word pointing phrase, not a new rule for every location noun.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-PLACE-THAAN-LOCATION-01, PA-PLACE-US-THAT-01, PA-PLACE-LOK-PEOPLE-01] -->

## Wrap-up Recall
