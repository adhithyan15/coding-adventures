## You'll want to know: il valico
<!-- hl-knowledge: introduces=[IT-LEX-C427-DOGANA-05]; assesses=[] -->

**il valico** — "the pass (in the mountains), the border crossing".

> Il valico è chiuso per la neve.
>
> *The pass is closed because of the snow.*

*Il valico di frontiera* — the border crossing.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*valico* is built on *valicare* 'to cross over', which is inherited from Latin *vāricāre* 'to stand with legs apart, to straddle' (EtymDB).
