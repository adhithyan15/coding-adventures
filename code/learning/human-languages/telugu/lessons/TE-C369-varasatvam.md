# వారసత్వం (vārasatvaṁ) — heritage; inheritance

## You'll want to know: వారసత్వం
<!-- hl-knowledge: introduces=[TE-LEX-C369-RAJABHAVANAM369-03]; assesses=[] -->

**వారసత్వం** — *vārasatvaṁ* — "heritage; inheritance".

> ఆ పురాతన కట్టడాలు మన వారసత్వం.
>
> *ā purātana kaṭṭaḍālu mana vārasatvaṁ.*
>
> Those ancient buildings are our heritage.

వారసత్వంగా, by inheritance: వారసత్వంగా వచ్చిన ఇల్లు, an inherited house.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**వారసత్వం** (*vārasatvaṁ*) is built with the Sanskrit ending *-tva*, "-ness", on *vārasu*, "an heir"; the origin of *vārasu* is not settled.
