## You'll want to know: うちあげる
<!-- hl-knowledge: introduces=[JA-LEX-C293-HANABI293-02]; assesses=[] -->

**うちあげる** — *uchiageru* — "to set off (fireworks); to launch".

> **かわの うえで はなびを うちあげます。** — *kawa no ue de hanabi o uchiagemasu* — "They set off fireworks over the river."

Polite **うちあげます**, *uchiagemasu*; an ichidan verb. Past (polite): **まちが はなびを うちあげました。**, *machi ga hanabi o uchiagemashita*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**うちあげる** (*uchiageru*) is a native Japanese word (wago), inherited rather than borrowed from Chinese, built from *uchi*, "striking" (from *utsu*), and *ageru*, "to raise" (JMdict, KANJIDIC2).
