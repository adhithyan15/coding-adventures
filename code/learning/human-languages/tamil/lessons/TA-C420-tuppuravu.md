# துப்புரவு (tuppuravu) — cleaning; cleanliness

## You'll want to know: துப்புரவு
<!-- hl-knowledge: introduces=[TA-LEX-C420-SEVAI420-05]; assesses=[] -->

**துப்புரவு** — *tuppuravu* — "cleaning; cleanliness".

> தினமும் காலையில் அறைகளில் துப்புரவு வேலை நடக்கிறது.
>
> *tiṉamum kālaiyil aṟaikaḷil tuppuravu vēlai naṭakkiṟatu.*
>
> Every morning the rooms are cleaned.

துப்புரவுப் பணி is cleaning work.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**துப்புரவு** (*tuppuravu*), "cleaning, cleanliness", is a Tamil word whose origin is not settled.
