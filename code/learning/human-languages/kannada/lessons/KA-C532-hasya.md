## You'll want to know: ಹಾಸ್ಯ
<!-- hl-knowledge: introduces=[KA-LEX-C532-GITA532-03]; assesses=[] -->

**ಹಾಸ್ಯ** — *hāsya* — "humour; comedy".

> ಆ ಸಿನಿಮಾದಲ್ಲಿ ತುಂಬಾ ಹಾಸ್ಯ ಇದೆ.
>
> *ā sinimādalli tumbā hāsya ide.*
>
> There is a lot of humour in that film.

ಹಾಸ್ಯಗಾರ, a comedian.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಹಾಸ್ಯ** (*hāsya*) is borrowed from Sanskrit *hāsya*, "laughable, funny; laughter" (CDIAL 14071).
