# సమన్వయం (samanvayaṁ) — coordination

## You'll want to know: సమన్వయం
<!-- hl-knowledge: introduces=[TE-LEX-C403-PARIPALANA403-03]; assesses=[] -->

**సమన్వయం** — *samanvayaṁ* — "coordination".

> రెండు శాఖల మధ్య సమన్వయం లేదు.
>
> *reṇḍu śākhala madhya samanvayaṁ lēdu.*
>
> There is no coordination between the two departments.

సమన్వయం చేయు, to coordinate.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**సమన్వయం** (*samanvayaṁ*) is borrowed from Sanskrit *samanvaya*, "regular succession, connected sequence, conjunction" (Monier-Williams).
