# استغاث (istaghātha) — to call for help

## You'll want to know: استغاث
<!-- hl-knowledge: introduces=[AR-LEX-C310-NAJDA310-01]; assesses=[] -->

**استغاث** — *istaghātha* — "to call for help".

> استغاثت المرأة من نافذة البيت.
>
> *istaghāthat al-marʾa min nāfidhat al-bayt.*
>
> The woman called for help from the window of the house.

Present: يستغيث, *yastaghīth*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**استغاث** (*istaghātha*) is built on the native Arabic root *gh-w-th* (Lane), where *ghawth* is help given to one in distress. It is Form X, "to ask for help".
