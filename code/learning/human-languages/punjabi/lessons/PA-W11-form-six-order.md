# Six old labels, one gentle order

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-LABEL-NAME-01, PA-FORM-LABEL-LANGUAGE-01, PA-FORM-LABEL-RESIDENCE-01, PA-FORM-LABEL-WORK-01, PA-FORM-LABEL-AGE-01, PA-FORM-LABEL-PHONE-01] -->

Point to each familiar label. The first four were practised with names and
words; the last two with Gurmukhi digits. Date is an already practised
seventh field, but it is not part of this six-line rehearsal.

## Writing — labels before values
<!-- hl-knowledge: introduces=[PA-FORM-SIX-ORDER-01]; assesses=[PA-FORM-LABEL-NAME-01, PA-FORM-LABEL-LANGUAGE-01, PA-FORM-LABEL-RESIDENCE-01, PA-FORM-LABEL-WORK-01, PA-FORM-LABEL-AGE-01, PA-FORM-LABEL-PHONE-01] -->
<!-- hl-writing-stage: guided-copy -->

Copy only the labels in this order. Leave every value blank. The order is
name, language, residence, work, age, phone. Pause after line three.

> ਨਾਂ: ______
>
> ਭਾਸ਼ਾ: ______
>
> ਰਿਹਾਇਸ਼: ______
>
> ਕੰਮ: ______
>
> ਉਮਰ: ______
>
> ਫ਼ੋਨ: ______

## Guided Practice — cover and point
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-SIX-ORDER-01] -->

Cover the labels. Point to six empty lines and recall only which label
belongs on each. Uncover them and repair one misplaced label, if needed.
