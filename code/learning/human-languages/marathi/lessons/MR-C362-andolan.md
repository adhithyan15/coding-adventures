## You'll want to know: आंदोलन
<!-- hl-knowledge: introduces=[MR-LEX-C362-ANDOLAN362-01]; assesses=[] -->

**आंदोलन** — *āndolan* — "a movement; an agitation".

> पाण्यासाठी गावात मोठं आंदोलन झालं.
>
> *pāṇyāsāṭhī gāvāt moṭhaṁ āndolan jhālaṁ.*
>
> There was a big agitation in the village for water.

Neuter.

आंदोलन करणे, to agitate; आंदोलक, an agitator.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**आंदोलन** (*āndolan*) is a tatsama, taken from Sanskrit *āndolana*, "swinging, oscillation" (Monier-Williams). Marathi uses it for a movement that stirs people.
