# நிரந்தர (nirantara) — permanent

## You'll want to know: நிரந்தர
<!-- hl-knowledge: introduces=[TA-LEX-C553-THARKALIKAM553-02]; assesses=[] -->

**நிரந்தர** — *nirantara* — "permanent".

> அவருக்கு அரசு அலுவலகத்தில் நிரந்தர வேலை கிடைத்தது.
>
> *avarukku aracu aluvalakattil nirantara vēlai kiṭaittatu.*
>
> He got a permanent job in a government office.

It stands before a noun, like தற்காலிக (*taṟkālika*). As an adverb: நிரந்தரமாக.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**நிரந்தர** (*nirantara*) is borrowed from Sanskrit *nirantara*, "having no interval, uninterrupted, constant" (Monier-Williams).
