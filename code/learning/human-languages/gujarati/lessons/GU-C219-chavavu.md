# છવાવું (chavāvũ) — to cloud over, to spread over

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[GU-LEX-C219-THUNDER219-01, GU-LEX-C219-THUNDER219-02] -->

[PAUSE 2s] Before the new one: say the Gujarati for to thunder, then the Gujarati for to shine.

## You'll want to know: છવાવું
<!-- hl-knowledge: introduces=[GU-LEX-C219-THUNDER219-03]; assesses=[] -->

**છવાવું** — *chavāvũ* — "to cloud over, to spread over".

> **સાંજે આકાશમાં વાદળ છવાશે.** — *sā̃je ākāśmā̃ vādaḷ chavāśe* — "Clouds will cover the sky in the evening."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**છવાવું** (*chavāvũ*) is built on *chāvũ*, "to cover, to thatch", with the *-ā-* of a thing that happens by itself. CDIAL lists *chāvũ*, "to thatch", under Sanskrit *chādayati*, "covers, veils" (CDIAL 5018).
