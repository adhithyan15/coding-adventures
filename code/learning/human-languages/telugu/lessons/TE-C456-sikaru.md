# షికారు (ṣikāru) — a jaunt; an outing

## You'll want to know: షికారు
<!-- hl-knowledge: introduces=[TE-LEX-C456-SHIKARU456-01]; assesses=[] -->

**షికారు** — *ṣikāru* — "a jaunt; an outing".

> సాయంత్రం మేము సముద్రం దగ్గర షికారుకు వెళ్ళాం.
>
> *sāyantraṁ mēmu samudraṁ daggara ṣikāruku veḷḷāṁ.*
>
> In the evening we went for a stroll by the sea.

షికారుకు వెళ్ళు, to go for an outing. An outing with no aim but pleasure.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**షికారు** (*ṣikāru*) is a loan from Persian *shikār*, "hunting, the chase", which reached Telugu through Hindustani; a hunting trip became any trip for pleasure.
