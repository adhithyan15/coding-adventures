## You'll want to know: ટપાલી
<!-- hl-knowledge: introduces=[GU-LEX-C200-POST200-01]; assesses=[] -->

**ટપાલી** — *ṭapālī* — "postman".

> **ટપાલી સવારે ટપાલ લાવે છે.** — *ṭapālī savāre ṭapāl lāve che* — "The postman brings the post in the morning."

Built on **ટપાલ**, *ṭapāl*, 'post'.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ટપાલી** (*ṭapālī*) is built on *ṭapāl*, "post, mail", with the agent ending *-ī*. The origin of *ṭapāl* is not settled: neither CDIAL nor DEDR has an entry for it.
