# సమాధి (samādhi) — a grave; a tomb

## You'll want to know: సమాధి
<!-- hl-knowledge: introduces=[TE-LEX-C345-SMRTI345-02]; assesses=[] -->

**సమాధి** — *samādhi* — "a grave; a tomb".

> ఆ పాత సమాధి దగ్గర ఒక చెట్టు ఉంది.
>
> *ā pāta samādhi daggara oka ceṭṭu undi.*
>
> There is a tree near that old tomb.

Plural: సమాధులు, *samādhulu*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**సమాధి** (*samādhi*) is borrowed from Sanskrit *samādhi* (Monier-Williams), whose first sense is "putting together, joining"; in Telugu it names a tomb.
