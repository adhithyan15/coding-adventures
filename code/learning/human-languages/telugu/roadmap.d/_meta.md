# Telugu Roadmap

Same shape as the other tracks: deep one-word lessons in themed chapters.
Slug-identified; order lives in the book and
[`session-map.md`](./session-map.md). See
[`HL00`](../../../specs/HL00-human-language-curriculum-framework.md).

Grounding: English + the **Dravidian family** (Tamil the anchor, plus Kannada
and Malayalam) + Sanskrit/Hindi. Threads: Telugu's heavy Sanskrit borrowing,
and its independence from its sisters (e.g. *lēdu* for "no"). The Telugu script
is taught **inline**, never as a gated reading course; grammar is introduced
piece by piece, on the first word that needs it.

Coverage note: canonical lessons now continue through Chapter 80, while the
narrative sequence below is complete only through Chapter 6. `HL-M02` tracks
bringing this roadmap and the session map up to the canonical prerequisite
order; `HL-B22` tracks publishing Chapters 6–31 from the same source.
