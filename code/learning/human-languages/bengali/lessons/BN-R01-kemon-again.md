# কেমন, and the whole exchange

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[BN-CONCEPT-C03-KEMON-01] -->

[PAUSE 5s] Say *how*.

## Guided Practice — the distant band
<!-- hl-knowledge: introduces=[]; assesses=[BN-CONCEPT-C03-KEMON-01, BN-CONCEPT-C03-TUMIKEMONACHHO-01, BN-CONCEPT-C01-ACHCHHA-01] -->

- [YOU SAY: *how* — *kēmon*]
- [YOU SAY: "how are you?" to a friend — *tumi kēmon āchho?*]
- [YOU SAY: the same to a stranger — *āpni kēmon āchhen?*]
- [YOU SAY: "okay / I see / go on" — *āchchhā*]

Two of those four change one ending and nothing else. If the respectful form did
not come, it is because the familiar one is the one you have practised, and a
question you can only ask a friend is half a question.

Run the exchange with yourself, both sides, twice.

## Writing — from sound
<!-- hl-knowledge: introduces=[]; assesses=[BN-SCRIPT-KEMON-READ-01] -->

Cover every model. Write *how* from the sound alone.

- [YOU WRITE: কেমন]
