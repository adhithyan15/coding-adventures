# ಸಿಲುಕು (siluku) — to be caught; to be trapped

## You'll want to know: ಸಿಲುಕು
<!-- hl-knowledge: introduces=[KA-LEX-C332-VIPATTU332-02]; assesses=[] -->

**ಸಿಲುಕು** — *siluku* — "to be caught; to be trapped".

> ಪ್ರವಾಹದಲ್ಲಿ ನೂರು ಜನ ಸಿಲುಕಿದರು.
>
> *pravāhadalli nūru jana silukidaru.*
>
> A hundred people were trapped in the flood.

Past (I …): ಸಿಲುಕಿದೆ, *silukide*.

Where one is trapped takes -ಅಲ್ಲಿ: ಮನೆಯಲ್ಲಿ ಸಿಲುಕು.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಸಿಲುಕು** (*siluku*) is native Dravidian: DEDR 2498 lists Kannada *siluku* beside Tamil *cikku*, "to be entangled, caught, ensnared".
