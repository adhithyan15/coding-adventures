# ઘવાવું (ghavāvũ) — to be wounded

## You'll want to know: ઘવાવું
<!-- hl-knowledge: introduces=[GU-LEX-C481-KAPAVU481-03]; assesses=[] -->

**ઘવાવું** — *ghavāvũ* — "to be wounded".

> ગાડી અથડાઈ ત્યારે ડ્રાઈવર ઘવાયો.
>
> *gāḍī athḍāī tyāre ḍrāīvar ghavāyo.*
>
> When the car crashed, the driver was injured.

Past (he …): તે ઘવાયો, *te ghavāyo*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ઘવાવું** (*ghavāvũ*) is built on **ઘા** (*ghā*), "a wound", which goes back to Sanskrit *ghāta*, "blow, bruise" (CDIAL 4460), with the verb ending *-vāvũ*.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
