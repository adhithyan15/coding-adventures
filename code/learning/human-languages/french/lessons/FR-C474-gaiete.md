## You'll want to know: la gaieté
<!-- hl-knowledge: introduces=[FR-LEX-C474-GAIETE-01]; assesses=[] -->

**la gaieté** — "cheerfulness".

> Sa gaieté met tout le monde de bonne humeur.
>
> *Her cheerfulness puts everyone in a good mood.*

Also spelt *la gaîté*. Built on *gai* "cheerful".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*la gaieté* is built on *gai* "cheerful" (EtymDB), which came into French from Old Occitan *gai*; it is usually traced further back to a Germanic word.
