## You'll want to know: بودجه
<!-- hl-knowledge: introduces=[FA-LEX-C398-AMALI-03]; assesses=[] -->

**بودجه** (*budje*) — "a budget".

> بودجه این پروژه تمام شده است.
>
> *budje-ye in prozhe tamâm shode ast.*
>
> The budget for this project has run out.

A European loan. Plural *budjehâ*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**بودجه** is a modern loan, usually traced to French *budget*.
