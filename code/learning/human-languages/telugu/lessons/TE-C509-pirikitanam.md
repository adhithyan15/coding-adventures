# పిరికితనం (pirikitanaṁ) — cowardice

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TE-LEX-C508-DHAIRYAM508-04, TE-LEX-C508-DHAIRYAM508-05] -->

[PAUSE 2s] Before the new one: say the Telugu for daring, then the Telugu for timid.

## You'll want to know: పిరికితనం
<!-- hl-knowledge: introduces=[TE-LEX-C509-MANISHI509-01]; assesses=[] -->

**పిరికితనం** — *pirikitanaṁ* — "cowardice".

> నిజం చెప్పకపోవడం పిరికితనం.
>
> *nijaṁ ceppakapōvaḍaṁ pirikitanaṁ.*
>
> Not telling the truth is cowardice.

పిరికి, timid, + -తనం.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**పిరికితనం** (*pirikitanaṁ*) is native Dravidian: *piṟiki*, "timid, cowardly" (DEDR 4200), with -తనం, the ending that makes abstract nouns.
