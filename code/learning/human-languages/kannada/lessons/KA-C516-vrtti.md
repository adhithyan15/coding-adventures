# ವೃತ್ತಿ (vṛtti) — a profession; a career

## You'll want to know: ವೃತ್ತಿ
<!-- hl-knowledge: introduces=[KA-LEX-C516-VRITTI516-01]; assesses=[] -->

**ವೃತ್ತಿ** — *vṛtti* — "a profession; a career".

> ಅವನು ಶಿಕ್ಷಕ ವೃತ್ತಿಯನ್ನು ಆರಿಸಿದನು.
>
> *avanu śikṣaka vṛttiyannu ārisidanu.*
>
> He chose the teaching profession.

ವೃತ್ತಿಪರ, professional.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ವೃತ್ತಿ** (*vṛtti*) is borrowed from Sanskrit *vṛtti*, "rolling, course; mode of life, livelihood" (Monier-Williams), from the root *vṛt*, "to turn".
