## You'll want to know: সার্থক
<!-- hl-knowledge: introduces=[BN-LEX-C383-SARTHOK383-01]; assesses=[] -->

**সার্থক** — *sārthôk* — "worthwhile; fruitful".

> তুমি পাস করলে আমার সব পরিশ্রম সার্থক হবে।
>
> *tumi pās kôrle āmār sôb pôrishrôm sārthôk hôbe.*
>
> If you pass, all my hard work will have been worth it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**সার্থক** (*sārthôk*) is Sanskrit *sārthaka*, 'with meaning', significant (Monier-Williams). Bengali uses it for an effort that turned out to have a point.
