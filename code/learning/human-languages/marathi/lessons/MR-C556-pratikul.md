# प्रतिकूल (pratikūl) — unfavourable; adverse

## You'll want to know: प्रतिकूल
<!-- hl-knowledge: introduces=[MR-LEX-C556-ANUKUL556-02]; assesses=[] -->

**प्रतिकूल** — *pratikūl* — "unfavourable; adverse".

> प्रतिकूल परिस्थितीतही ती शिकत राहिली.
>
> *pratikūl paristhitīthī tī śikat rāhilī.*
>
> Even in adverse circumstances she kept on studying.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**प्रतिकूल** (*pratikūl*) is a tatsama, taken from Sanskrit *pratikūla*, "against the bank, adverse" (Monier-Williams).
