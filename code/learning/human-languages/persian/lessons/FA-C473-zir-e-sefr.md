## You'll want to know: زیر صفر
<!-- hl-knowledge: introduces=[FA-LEX-C473-HAVASHENASI-05]; assesses=[] -->

**زیر صفر** (*zir-e sefr*) — "below zero (of temperature)".

> دیشب دما ده درجه زیر صفر بود.
>
> *Dishab damâ dah daraje zir-e sefr bud.*
>
> Last night it was ten degrees below zero.

*zir* 'under' + *sefr* 'zero'.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*zir-e sefr* is built from native *zir* 'under' and *sefr* 'zero', borrowed from Arabic *ṣifr* 'nothing, cipher' (EtymDB). EtymDB traces English *zero* to the same Arabic word.
