# ഒടുക്കം (oṭukkaṁ) — in the end; the end

## You'll want to know: ഒടുക്കം
<!-- hl-knowledge: introduces=[ML-LEX-C359-VAIKATHE359-02]; assesses=[] -->

**ഒടുക്കം** — *oṭukkaṁ* — "in the end; the end".

> ഒടുക്കം അവർ ഒരു പരിഹാരം കണ്ടെത്തി.
>
> *oṭukkaṁ avar oru parihāraṁ kaṇṭetti.*
>
> In the end they found a solution.

Also a noun: കഥയുടെ ഒടുക്കം, the end of the story.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ഒടുക്കം** (*oṭukkaṁ*) is native Dravidian: DEDR 954 lists Malayalam *oṭukkam*, "the end; finally", beside ഒടുങ്ങുക, "to come to an end". ഒടുവിൽ, "at last", comes from the same root.
