# മോഷ്ടിക്കുക (mōṣṭikkuka) — to steal

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C364-KALLAN364-02, ML-LEX-C364-KALLAN364-03] -->

[PAUSE 2s] Before the new one: say the Malayalam for a theft, then the Malayalam for a robbery.

## You'll want to know: മോഷ്ടിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C364-KALLAN364-04]; assesses=[] -->

**മോഷ്ടിക്കുക** — *mōṣṭikkuka* — "to steal".

> കള്ളൻ അമ്മയുടെ സ്വർണ്ണം മോഷ്ടിച്ചു.
>
> *kaḷḷan ammayuṭe svarṇṇaṁ mōṣṭiccu.*
>
> The thief stole mother's gold.

Past: മോഷ്ടിച്ചു, *mōṣṭiccu*.

What is stolen is the plain object; from whom takes -ഇൽ നിന്ന്.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**മോഷ്ടിക്കുക** (*mōṣṭikkuka*) is built from the same Sanskrit verb as മോഷണം, *muṣ*, "to rob", whose noun *moṣaṇa* means "robbing" (Monier-Williams), with the Malayalam verb ending -ിക്കുക.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
