# குறித்து (kuṟittu) — about; concerning

## You'll want to know: குறித்து
<!-- hl-knowledge: introduces=[TA-LEX-C394-ORUTALAIPPAT394-05]; assesses=[] -->

**குறித்து** — *kuṟittu* — "about; concerning".

> இது குறித்துக் கேள்வி இருந்தால் ஆசிரியரிடம் கேட்கலாம்.
>
> *itu kuṟittuk kēḷvi iruntāl āciriyariṭam kēṭkalām.*
>
> If you have questions about this, you can ask the teacher.

A written word for பற்றி: X குறித்து, about X.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**குறித்து** (*kuṟittu*) is native: the verbal participle of *kuṟi*, "to aim at, intend, point to" (DEDR 1847): "having aimed at", so "concerning".
