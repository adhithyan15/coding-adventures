## You'll want to know: अत्यंत
<!-- hl-knowledge: introduces=[HI-LEX-C387-BEHAD387-02]; assesses=[] -->

**अत्यंत** — *atyant* — "extremely (formal)".

> अगर रोगी की हालत अत्यंत गंभीर होगी तो उसे अस्पताल ले जाना पड़ेगा।
>
> *agar rogī kī hālat atyant gambhīr hogī to use aspatāl le jānā paṛegā.*
>
> If the patient's condition is extremely serious, he will have to be taken to hospital.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**अत्यंत** (*atyant*) is a tatsama, borrowed from Sanskrit *atyanta*, "excessive, very great" (Monier-Williams).
