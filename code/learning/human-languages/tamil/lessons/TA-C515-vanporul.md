# வன்பொருள் (vaṉporuḷ) — hardware

## You'll want to know: வன்பொருள்
<!-- hl-knowledge: introduces=[TA-LEX-C515-KANINI515-03]; assesses=[] -->

**வன்பொருள்** — *vaṉporuḷ* — "hardware".

> பிரச்சினை மென்பொருளில் இல்லை, வன்பொருளில் இருக்கிறது.
>
> *piracciṉai meṉporuḷil illai, vaṉporuḷil irukkiṟatu.*
>
> The problem is not in the software, it is in the hardware.

The pair of மென்பொருள் (*meṉporuḷ*): வன் "hard" + பொருள் "a thing".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**வன்பொருள்** (*vaṉporuḷ*) is built from native parts to match English *hardware*: வன் (*vaṉ*), "hard, strong" (DEDR 5276), and பொருள் (*poruḷ*), "a thing".
