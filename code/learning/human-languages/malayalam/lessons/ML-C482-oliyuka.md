# ഒഴിയുക (oḻiyuka) — to vacate; to become empty

## You'll want to know: ഒഴിയുക
<!-- hl-knowledge: introduces=[ML-LEX-C482-VATAKA482-03]; assesses=[] -->

**ഒഴിയുക** — *oḻiyuka* — "to vacate; to become empty".

> രാവിലെ പത്ത് മണിക്ക് മുൻപ് മുറി ഒഴിയണം.
>
> *rāvile pattŭ maṇikkŭ munpŭ muṟi oḻiyaṇaṁ.*
>
> You must vacate the room before ten in the morning.

Past: ഒഴിഞ്ഞു, *oḻiññu*.

The place takes no ending: മുറി ഒഴിയുക. An empty seat is an ഒഴിഞ്ഞ സീറ്റ്.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ഒഴിയുക** (*oḻiyuka*) is native Dravidian, "to leave off, to be free of, to be empty" (DEDR 1009). ഒഴിവ്, a vacancy, comes from the same root.
