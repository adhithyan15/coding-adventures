## You'll want to know: ദാഹം
<!-- hl-knowledge: introduces=[ML-LEX-C117-BODY-01]; assesses=[] -->

**ദാഹം** (*dāhaṁ*) — "thirst". **എനിക്ക് ദാഹമുണ്ട്** — "I am thirsty", built like
**എനിക്ക് വിശപ്പുണ്ട്**, "I am hungry".
