# விடுதலை (viṭutalai) — liberation; freedom; release

## You'll want to know: விடுதலை
<!-- hl-knowledge: introduces=[TA-LEX-C338-VIDUTHALAI338-02]; assesses=[] -->

**விடுதலை** — *viṭutalai* — "liberation; freedom; release".

> நீண்ட போராட்டத்துக்குப் பிறகு நாட்டுக்கு விடுதலை கிடைத்தது.
>
> *nīṇṭa pōrāṭṭattukkup piṟaku nāṭṭukku viṭutalai kiṭaittatu.*
>
> After a long struggle the country gained its freedom.

Also release from prison: கைதிக்கு விடுதலை.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**விடுதலை** (*viṭutalai*) is native Dravidian: a noun from விடு, "to leave, let go" (DEDR 5393).
