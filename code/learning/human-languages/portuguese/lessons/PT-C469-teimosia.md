## You'll want to know: a teimosia
<!-- hl-knowledge: introduces=[PT-LEX-C469-TEIMOSIA-02]; assesses=[] -->

**a teimosia** — "stubbornness".

> Por teimosia, ele não quis pedir ajuda.
>
> *Out of stubbornness, he did not want to ask for help.*

Built on *teimoso*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*teimosia* is built on *teimoso* "stubborn", from *teima* "obstinacy", which is usually traced to Latin *thema* "a theme" (EtymDB); that origin is not fully settled.
