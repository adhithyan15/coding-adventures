# ಸಹಾಯವಾಣಿ (sahāyavāṇi) — a helpline

## You'll want to know: ಸಹಾಯವಾಣಿ
<!-- hl-knowledge: introduces=[KA-LEX-C472-HALU472-05]; assesses=[] -->

**ಸಹಾಯವಾಣಿ** — *sahāyavāṇi* — "a helpline".

> ಚೀಲ ಸಿಗದಿದ್ದಾಗ ನಾವು ಸಹಾಯವಾಣಿಗೆ ಫೋನ್ ಮಾಡಿದೆವು.
>
> *cīla sigadiddāga nāvu sahāyavāṇige phōn māḍidevu.*
>
> When we could not find the bag we rang the helpline.

ಸಹಾಯ, help, plus ವಾಣಿ, voice.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಸಹಾಯವಾಣಿ** (*sahāyavāṇi*) is a modern compound built from Sanskrit words: *sahāya*, "a companion, a helper" (CDIAL 13309), and *vāṇī*, "voice" (CDIAL 11490).
