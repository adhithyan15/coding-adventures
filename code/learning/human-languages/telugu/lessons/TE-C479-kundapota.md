# కుండపోత (kuṇḍapōta) — a torrential rain

## You'll want to know: కుండపోత
<!-- hl-knowledge: introduces=[TE-LEX-C479-PIDUGU479-02]; assesses=[] -->

**కుండపోత** — *kuṇḍapōta* — "a torrential rain".

> సాయంత్రం కుండపోత వర్షం కురిసింది.
>
> *sāyantraṁ kuṇḍapōta varṣaṁ kurisindi.*
>
> In the evening it poured with rain.

కుండ, a pot, + పోత, pouring: rain as if poured from a pot. Mostly కుండపోత వర్షం.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**కుండపోత** (*kuṇḍapōta*) is a Telugu compound built from కుండ, "a pot", and పోత, "pouring", the noun of పోయు, "to pour" (DEDR 4407).
