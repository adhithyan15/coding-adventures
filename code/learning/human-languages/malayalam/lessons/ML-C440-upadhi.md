# ഉപാധി (upādhi) — a proviso; a condition

## You'll want to know: ഉപാധി
<!-- hl-knowledge: introduces=[ML-LEX-C440-VYAVASTHA440-03]; assesses=[] -->

**ഉപാധി** — *upādhi* — "a proviso; a condition".

> ഉപാധികൾ ഒന്നുമില്ലാതെ അവർ സഹായം നൽകി.
>
> *upādhikaḷ onnumillāte avar sahāyaṁ nalki.*
>
> They gave help without any conditions.

Unconditional is ഉപാധികളില്ലാത്ത.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ഉപാധി** (*upādhi*) is borrowed from Sanskrit *upādhi*, "a point of view, an aim" (CDIAL 2299), and in Monier-Williams "that which is put in place of another thing".
