# ਉੱਠਦਾ — he gets up

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-C57-VERBS57-01, PA-FORM-KARDA-183] -->

[PAUSE 2s] Recall *utthnaa*, “to get up,” then **ਕਰਦਾ**.

## Grammar Lens: move the same ending
<!-- hl-knowledge: introduces=[PA-FORM-UTTHDA-183]; assesses=[] -->

> **ਉੱਠਦਾ** — *utthdaa* — gets up, for one masculine subject

The infinitive was learned long ago. Keep its stem and use the same ending you saw in **ਕਰਦਾ**. A tiny complete sentence is **ਉਹ ਉੱਠਦਾ ਹੈ** — “He gets up.”
