# ஆண்டு நிறைவு (āṇṭu niṟaivu) — an anniversary

## You'll want to know: ஆண்டு நிறைவு
<!-- hl-knowledge: introduces=[TA-LEX-C319-AANDU319-01]; assesses=[] -->

**ஆண்டு நிறைவு** — *āṇṭu niṟaivu* — "an anniversary".

> எங்கள் பள்ளியின் ஐம்பதாம் ஆண்டு நிறைவு அடுத்த மாதம்.
>
> *eṅkaḷ paḷḷiyiṉ aimpatām āṇṭu niṟaivu aṭutta mātam.*
>
> Our school's fiftieth anniversary is next month.

With an ordinal: பத்தாம் ஆண்டு நிறைவு, the tenth anniversary.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ஆண்டு நிறைவு** (*āṇṭu niṟaivu*) joins native ஆண்டு, "year" (DEDR 5153), and நிறைவு, "fullness, completion", from நிறை, "to become full" (DEDR 3682).
