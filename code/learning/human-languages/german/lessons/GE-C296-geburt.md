## You'll want to know: die Geburt
<!-- hl-knowledge: introduces=[GE-LEX-C296-GEBURT-01]; assesses=[] -->

**die Geburt** — "the birth".

> Bei der Geburt wog das Baby drei Kilo.
>
> *At birth the baby weighed three kilos.*

Plural: *die Geburten*. *Geburtstag* — birthday — is built on it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*Geburt* is inherited from Old High German *giburt*, from Proto-Germanic *gaburþiz*, built on *beraną* "to carry, to bear" (EtymDB).
