# Unit 20: Family Vocabulary

## Warm-up

[PAUSE 2s] Say *el hermano* — wait, you don't know that yet. Say *la casa
grande* instead. Today's words are the one place gender lines up with
biological sex, not just grammar.

## New Material

**la madre** (fem.) — mother ← Latin *mater* (→ English *maternal*,
*matrix*, *matter* — all from the same root).

**el padre** (masc.) — father ← Latin *pater* (→ English *paternal*,
*patriarch*, *patron*).

**el hermano / la hermana** — brother / sister ← Latin *germanus*
("full-blood sibling" — the same root, oddly, as the country name
*Germania*/*Alemania*'s neighbor-language "German" is unrelated; this
*germanus* is about shared parentage, not geography).

**el hijo / la hija** — son / daughter ← Latin *filius/filia* (→ English
*filial*, *affiliate*).

## Grammar Lens

Family words are the one vocabulary set where Spanish's grammatical gender
and real-world sex line up directly — *el padre* is masculine because
fathers are male, not because of an *-o/-a* spelling rule (in fact *padre*
ends in *-e*, outside the default pattern entirely, and gets its gender
from meaning, not spelling). This is worth noticing precisely because it's
the exception to Unit 17's whole point: most Spanish nouns (*la mesa*,
"table") have grammatical gender with zero connection to real-world sex —
family terms are a small, meaning-driven island inside a mostly arbitrary
system.
