# எழுச்சி (eḻucci) — an uprising; an upsurge

## You'll want to know: எழுச்சி
<!-- hl-knowledge: introduces=[TA-LEX-C311-MUZHAKKAM311-04]; assesses=[] -->

**எழுச்சி** — *eḻucci* — "an uprising; an upsurge".

> நாடு முழுவதும் ஒரு பெரிய எழுச்சி நடந்தது.
>
> *nāṭu muḻuvatum oru periya eḻucci naṭantatu.*
>
> A great uprising took place across the country.

From எழு, to rise.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**எழுச்சி** (*eḻucci*) is native Dravidian: a noun from எழு, "to rise, be aroused" (DEDR 851).
