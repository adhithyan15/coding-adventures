## You'll want to know: l'abonnement
<!-- hl-knowledge: introduces=[FR-LEX-C390-BUDGET-03]; assesses=[] -->

**l'abonnement** — "the subscription; the season ticket".

> J'ai un abonnement de bus pour l'année.
>
> *I have a bus pass for the year.*

*S'abonner à* — to subscribe to. Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*abonnement* is built on *abonner* "to subscribe" (EtymDB), usually traced to Old French *bonne* "a boundary, a limit"; first, fixing a set sum in advance.
