# దత్తత (dattata) — adoption

## You'll want to know: దత్తత
<!-- hl-knowledge: introduces=[TE-LEX-C356-UTSAVAM356-05]; assesses=[] -->

**దత్తత** — *dattata* — "adoption".

> వాళ్ళు ఒక పాపను దత్తత తీసుకున్నారు.
>
> *vāḷḷu oka pāpanu dattata tīsukunnāru.*
>
> They adopted a baby girl.

దత్తత తీసుకో, to adopt.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**దత్తత** (*dattata*) is built on Sanskrit *datta*, "given" (CDIAL 6140): a child given into a new family.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
