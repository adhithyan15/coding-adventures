# सारीखो (sārīkho) — alike; the same as

## You'll want to know: सारीखो
<!-- hl-knowledge: introduces=[MW-LEX-C214-RETURN214-02]; assesses=[] -->

**सारीखो** — *sārīkho* — "alike; the same as".

> ये दो कुरता सारीखा है।
>
> *ye do kurtā sārīkhā hai.*
>
> These two kurtas are alike.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**सारीखो** (*sārīkho*) is inherited from Sanskrit *sadṛkṣa*, "like"; CDIAL lists Old Marwari *sārikho*, "like" (CDIAL 13119).
