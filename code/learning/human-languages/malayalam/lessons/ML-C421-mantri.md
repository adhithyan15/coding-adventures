# മന്ത്രി (mantri) — a minister

## You'll want to know: മന്ത്രി
<!-- hl-knowledge: introduces=[ML-LEX-C421-BHARANAM421-03]; assesses=[] -->

**മന്ത്രി** — *mantri* — "a minister".

> മന്ത്രി ഇന്ന് ഗ്രാമം സന്ദർശിച്ചു.
>
> *mantri innŭ grāmaṁ sandarśiccu.*
>
> The minister visited the village today.

Plural: മന്ത്രിമാർ, *mantrimār*.

Plural: മന്ത്രിമാർ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**മന്ത്രി** (*mantri*) is borrowed from Sanskrit *mantrin*, "wise, eloquent; a counsellor" (CDIAL 9838), from *mantra*, "counsel".
