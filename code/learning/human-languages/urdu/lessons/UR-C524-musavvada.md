## You'll want to know: مسودہ
<!-- hl-knowledge: introduces=[UR-LEX-C524-FEHRIST524-02]; assesses=[] -->

**مسودہ** — *musavvadā* — "a draft (of a text)".

> اگر مسودہ ٹھیک ہے تو ہم اسے چھاپیں گے۔
>
> *agar musavvadā ṭhīk hai to ham use chhāpeṅ ge.*
>
> If the draft is all right, we will print it.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**مسودہ** (*musavvadā*) is usually traced, through Persian, to Arabic *musawwada*, "a rough copy".
