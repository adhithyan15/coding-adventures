# innocēns, innocentis — innocent, harmless

## You'll want to know: innocēns, innocentis
<!-- hl-knowledge: introduces=[LA-LEX-C311-DAMNO-04]; assesses=[] -->

**innocēns, innocentis** — "innocent, harmless".

> Omnēs scīvērunt eum innocentem esse.
>
> *Everyone knew that he was innocent.*

One ending, genitive *innocentis*: *in-* 'not' + *nocēns*. English *innocent*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**innocēns** joins *in-*, "not", and *nocēns*, "harmful, guilty" (EtymDB): doing no harm. English *innocent* comes from it.
