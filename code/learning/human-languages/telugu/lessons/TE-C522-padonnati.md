# పదోన్నతి (padōnnati) — a promotion

## You'll want to know: పదోన్నతి
<!-- hl-knowledge: introduces=[TE-LEX-C522-VRTTI522-04]; assesses=[] -->

**పదోన్నతి** — *padōnnati* — "a promotion".

> కష్టపడి పనిచేసినందుకు ఆమెకు పదోన్నతి వచ్చింది.
>
> *kaṣṭapaḍi panicēsinanduku āmeku padōnnati vaccindi.*
>
> She got a promotion for working hard.

Formal; in speech many say ప్రమోషను.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**పదోన్నతి** (*padōnnati*) is a learned compound built from Sanskrit *pada*, "step, position", and *unnati*, "rising, advancement" (Monier-Williams).
