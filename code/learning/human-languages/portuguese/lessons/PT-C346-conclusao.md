## You'll want to know: a conclusão
<!-- hl-knowledge: introduces=[PT-LEX-C346-RACIOCINIO-04]; assesses=[] -->

**a conclusão** — "the conclusion".

> Chegámos todos à mesma conclusão.
>
> *We all reached the same conclusion.*

*Em conclusão* — in conclusion.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*conclusão* is a learned borrowing from Latin *conclūsiō* "a shutting up, a conclusion" (EtymDB), from *conclūdere*, built on *claudere* "to shut".
