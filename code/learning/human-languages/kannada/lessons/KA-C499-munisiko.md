# ಮುನಿಸಿಕೊ (munisiko) — to sulk

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C498-NAMBIKE498-04, KA-LEX-C498-NAMBIKE498-05] -->

[PAUSE 2s] Before the new one: say the Kannada for compassion, then the Kannada for sympathy.

## You'll want to know: ಮುನಿಸಿಕೊ
<!-- hl-knowledge: introduces=[KA-LEX-C499-MANASTHITI499-01]; assesses=[] -->

**ಮುನಿಸಿಕೊ** — *munisiko* — "to sulk".

> ತಿಂಡಿ ಸಿಗಲಿಲ್ಲ ಅಂತ ತಂಗಿ ಮುನಿಸಿಕೊಂಡಳು.
>
> *tiṇḍi sigalilla anta taṅgi munisikoṇḍaḷu.*
>
> My little sister sulked because she did not get a snack.

Past (I …): ಮುನಿಸಿಕೊಂಡೆ, *munisikoṇḍe*.

With whom: … ಮೇಲೆ ಮುನಿಸಿಕೊ. ಮುನಿಸು is a sulk.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಮುನಿಸಿಕೊ** (*munisiko*) is native Dravidian: DEDR 5021 lists Kannada *muni*, "to become angry", and *munisu*, "anger"; -*ko* adds "for oneself", so the anger is turned inward.

## What you've built
