## You'll want to know: বিরল
<!-- hl-knowledge: introduces=[BN-LEX-C366-SOMBHABONA366-04]; assesses=[] -->

**বিরল** — *birôl* — "rare".

> এই পাখিটা বিরল, দেখতে পেলে ছবি তুলবে।
>
> *ei pākhiṭā birôl, dekhte pele chhôbi tulbe.*
>
> This bird is rare, so if you get to see it, take a photo.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**বিরল** (*birôl*) is Sanskrit *virala*, rare or thinly scattered (Monier-Williams).
