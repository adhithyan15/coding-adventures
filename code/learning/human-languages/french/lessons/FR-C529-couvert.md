## You'll want to know: le couvert
<!-- hl-knowledge: introduces=[FR-LEX-C529-TABLE-02]; assesses=[] -->

**le couvert** — "place setting; cutlery".

> Les enfants mettent le couvert avant le dîner.
>
> *The children set out the plates and cutlery before dinner.*

*Mettre le couvert* — to set out plates and cutlery for a meal. *Les couverts* — the cutlery.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*le couvert* is the participle of *couvrir* "to cover" (EtymDB), inherited from Latin *cooperīre* "to cover completely" (Lewis & Short).
