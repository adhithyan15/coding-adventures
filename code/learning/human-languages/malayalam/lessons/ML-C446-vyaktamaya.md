# വ്യക്തമായ (vyaktamāya) — evident; clear

## You'll want to know: വ്യക്തമായ
<!-- hl-knowledge: introduces=[ML-LEX-C446-VYAKTAM446-01]; assesses=[] -->

**വ്യക്തമായ** — *vyaktamāya* — "evident; clear".

> അവൻ വ്യക്തമായ ഒരു ഉത്തരം നൽകി.
>
> *avan vyaktamāya oru uttaraṁ nalki.*
>
> He gave a clear answer.

The adverb is വ്യക്തമായി, clearly.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**വ്യക്തമായ** (*vyaktamāya*) is built from Sanskrit *vyakta*, "adorned; manifest, evident" (CDIAL 12156; Monier-Williams), with the adjective ending -ആയ.
