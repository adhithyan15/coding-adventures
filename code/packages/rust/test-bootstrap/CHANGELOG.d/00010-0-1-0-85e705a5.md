## 0.1.0

Initial release: the L0 bootstrap harness of TF01, the first step of the
VER26 `ct-compare` verification pilot.

- `tfv`: a strict parser for TFV v1, the corpus line format. It rejects
  every non-canonical spelling (uppercase hex, `I007`, `I-0`, wrong counts,
  double spaces, duplicate fields, record ids or map keys, invalid UTF-8,
  carriage returns) and nesting deeper than 64. `values_equal` implements
  TF01 deep equality: NaN equals NaN, `-0` is not `+0`, kinds never mix,
  map order is ignored.
- `verdict`: the pure core, `deep_equal` and `error_is`, returning
  `Pass` or `Fail(failure_id, message)`.
- `prng`: SplitMix64, FNV-1a 64, the unbiased `bounded` draw, the
  sort-then-Fisher–Yates `shuffled`, and per-test `sub_seed`.
- `run`: `Suite` registration (bad or duplicate ids bail out before any
  test runs), seeded shuffled runs, panics caught as `Fail("panic")`
  without echoing the panic message, TAP v14 output with `# tf-lane` and
  `# tf-seed`, `--seed` and `--sabotage always-pass`.
- `tests/self_corpus.rs`: runs `code/specs/fixtures/test-bootstrap-v1`
  (68 cases) on the harness itself; the BUILD also runs it sabotaged and
  checks with grep that failures are reported.
