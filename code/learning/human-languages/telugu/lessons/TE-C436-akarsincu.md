# ఆకర్షించు (ākarṣiñcu) — to attract

## You'll want to know: ఆకర్షించు
<!-- hl-knowledge: introduces=[TE-LEX-C436-PALGONU436-04]; assesses=[] -->

**ఆకర్షించు** — *ākarṣiñcu* — "to attract".

> ఆ కొత్త పథకం చాలా మందిని ఆకర్షించింది.
>
> *ā kotta pathakaṁ cālā mandini ākarṣiñcindi.*
>
> That new scheme attracted many people.

Past (I …): ఆకర్షించాను, *ākarṣiñcānu*.

The noun is ఆకర్షణ, attraction.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ఆకర్షించు** (*ākarṣiñcu*) is built on Sanskrit *ākarṣaṇa*, "pulling, drawing near, attracting" (Monier-Williams), with the Telugu verb ending -ఇంచు.

## What you've built
