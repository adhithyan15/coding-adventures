## You'll want to know: شایعه
<!-- hl-knowledge: introduces=[FA-LEX-C364-VAQEIYYAT-04]; assesses=[] -->

**شایعه** (*shâye'e*) — "a rumour".

> این فقط یک شایعه است.
>
> *in faqat yek shâye'e ast.*
>
> This is only a rumour.

Plural *shâye'ât* or *shâye'ehâ*. *Shâye'e dorost kardan* — to start a rumour.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**شایعه** was borrowed from Arabic *shā'i'a* "hearsay, rumour" (EtymDB), literally something that spreads.
