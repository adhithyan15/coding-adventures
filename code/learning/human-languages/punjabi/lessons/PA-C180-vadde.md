# ਵੱਡੇ — big in one room phrase

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-PLACE-KAMRE-ROOM-01, PA-LEX-C79-ANIMALS79-02] -->

[PAUSE 2s] Say the old **ਵੱਡਾ**, then **ਕਮਰੇ ਵਿੱਚ**.

## Grammar Lens: one agreeing phrase
<!-- hl-knowledge: introduces=[PA-PLACE-VADDE-BIG-01]; assesses=[PA-PLACE-KAMRE-ROOM-01, PA-POSTPOSITION-VICH-01] -->

> **ਵੱਡੇ ਕਮਰੇ ਵਿੱਚ** — *vaḍḍe kamre vic* — in the big room

This is one bounded location phrase. Notice **ਵੱਡੇ** beside **ਕਮਰੇ**; a full adjective-agreement table comes later, not here.
