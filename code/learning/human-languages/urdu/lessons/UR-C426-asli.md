## You'll want to know: اصلی
<!-- hl-knowledge: introduces=[UR-LEX-C426-KHALIS426-02]; assesses=[] -->

**اصلی** — *aslī* — "authentic; real".

> یہ اصلی سونا ہے، نقلی نہیں۔
>
> *yih aslī sonā hai, naqlī nahīṅ.*
>
> This is real gold, not fake.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**اصلی** (*aslī*) is built on *asl*, "the origin, the real thing", usually traced, through Persian, to Arabic *aṣl*, "a root", with the ending *-ī*.
