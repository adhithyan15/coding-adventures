# નિર્ણય (nirṇay) — a decision

## You'll want to know: નિર્ણય
<!-- hl-knowledge: introduces=[GU-LEX-C389-NIRNAY389-01]; assesses=[] -->

**નિર્ણય** — *nirṇay* — "a decision".

> જો તમે ઉતાવળમાં નિર્ણય લેશો તો પછી પસ્તાશો.
>
> *jo tame utāvaḷmā̃ nirṇay leśo to pachī pastāśo.*
>
> If you decide in a hurry, you will regret it later.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**નિર્ણય** (*nirṇay*) is a tatsama, borrowed from Sanskrit *nirṇaya*, "taking off, settling, a decision" (Monier-Williams).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
