# The old two-card selector

Stop before looking at or marking the printed cards. This is a short return
to the familiar fictional bank, not a real personal date or a scored A1 mock.

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-DATE-CUE-MAP-01] -->

Look at the two old cards: A **੧੫/੦੧/੨੦੨੫** and B **੨੫/੦੨/੨੦੨੫**. The mark
**ਕ** asks for A; **ਖ** asks for B. These marks are selectors, not month names.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-DATE-CUE-MAP-01] -->
<!-- hl-writing-stage: guided-copy -->

Keep both cards and the selector map visible. Point to **ਖ**, then to B. Write
the letter B beside **ਖ**. Do the same for **ਕ** and A. Compare each link with
the printed map before trying the pair once more with the map covered. If one
link differs, uncover the map and repair that link. No new date is needed.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-DATE-CUE-MAP-01] -->

Cover the map for a few seconds. Point to the card requested by **ਕ**, then
the card requested by **ਖ**. Uncover the map and check A, then B. The bank
remains available for a gentle repair; this is not independent scored writing.
