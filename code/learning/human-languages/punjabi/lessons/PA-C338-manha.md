# ਮਨ੍ਹਾ (manhā) — forbidden; not allowed

## You'll want to know: ਮਨ੍ਹਾ
<!-- hl-knowledge: introduces=[PA-LEX-C338-PERM338-02]; assesses=[] -->

**ਮਨ੍ਹਾ** — *manhā* — "forbidden; not allowed".

> ਕੀ ਬਾਗ਼ ਵਿੱਚ ਖੇਡਣਾ ਮਨ੍ਹਾ ਹੈ?
>
> *kī bāgh vich kheḍṇā manhā hai?*
>
> Is playing in the park forbidden?

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ਮਨ੍ਹਾ** (*manhā*) is a loan, usually traced through Persian to Arabic *manʿ*, "prevention".
