## You'll want to know: 可笑
<!-- hl-knowledge: introduces=[ZH-LEX-C367-SEE367-05]; assesses=[] -->

**可笑** — *kěxiào* — "ridiculous; laughable".

> **我觉得这个问题很可笑** *wǒ juéde zhège wèntí hěn kěxiào* — I think that question is ridiculous.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**可笑** (*kěxiào*) is built from 可 'can' and 笑 'to laugh', both inherited from Middle Chinese, *khaX* and *sjewH* (Guangyun, in Baxter's transcription), which glosses the first 'to permit' and the second 'glad'.
