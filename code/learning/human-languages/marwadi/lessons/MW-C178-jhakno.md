# झांकणो (jhā̃kṇo) — to peep

## You'll want to know: झांकणो
<!-- hl-knowledge: introduces=[MW-LEX-C178-UNGH178-02]; assesses=[] -->

**झांकणो** — *jhā̃kṇo* — "to peep".

> बिल्ली खिड़की सूं झांकै है।
>
> *billī khiṛkī sū̃ jhā̃kai hai.*
>
> The cat peeps in through the window.

Past (he …): वो खिड़की सूं झांक्यो, *vo khiṛkī sū̃ jhā̃kyo*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**झांकणो** (*jhā̃kṇo*) comes from a reconstructed *\*jhaṅkh*, "peep"; CDIAL lists Old Marwari *jhākaï*, "peeps at" (CDIAL 5325).
