## You'll want to know: ગીત
<!-- hl-knowledge: introduces=[GU-LEX-C254-MUSIC254-02]; assesses=[] -->

**ગીત** — *gīt* — "song".

> **તેણે એક સુંદર ગીત ગાયું.** — *teṇe ek sundar gīt gāyũ* — "She sang a beautiful song."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ગીત** (*gīt*) is Sanskrit *gītá*, "singing, song", taken over as a tatsama (CDIAL 4167). The taught *gāvũ*, "to sing", comes from the same root.
