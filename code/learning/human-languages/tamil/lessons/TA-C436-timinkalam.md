# திமிங்கலம் (timiṅkalam) — a whale

## You'll want to know: திமிங்கலம்
<!-- hl-knowledge: introduces=[TA-LEX-C436-KATAL436-01]; assesses=[] -->

**திமிங்கலம்** — *timiṅkalam* — "a whale".

> படகிலிருந்து ஒரு திமிங்கலத்தைப் பார்த்தோம்.
>
> *paṭakiliruntu oru timiṅkalattaip pārttōm.*
>
> We saw a whale from the boat.

A -அம் noun: திமிங்கலத்தை, the whale (object).

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**திமிங்கலம்** (*timiṅkalam*) is borrowed from Sanskrit *timiṃgila*, "a large fabulous fish" (Monier-Williams).
