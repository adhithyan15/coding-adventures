## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**شیشہ** (*shīshā*) is a loan, usually traced to Persian *shīsha*, "glass". It is a different word from *sīsā*, "lead", which comes from Sanskrit *sīsa* (CDIAL 13445).
