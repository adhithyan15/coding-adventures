## You'll want to know: ثانوي
<!-- hl-knowledge: introduces=[AR-LEX-C419-IJABI419-04]; assesses=[] -->

**ثانوي** — *thānawī* — "secondary".

> هذه مسألة ثانوية.
>
> *hādhihi masʾala thānawiyya.*
>
> This is a secondary matter.

مدرسة ثانوية, a secondary school.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ثانوي** (*thānawī*) is built on the native Arabic root *th-n-y*, "to fold; to make two" (Lane). *Thānawī* is a modern adjective from *thānī*, second: secondary.
