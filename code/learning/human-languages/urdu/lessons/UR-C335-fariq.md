## You'll want to know: فریق
<!-- hl-knowledge: introduces=[UR-LEX-C335-HIMAYAT335-05]; assesses=[] -->

**فریق** — *farīq* — "a side in a dispute".

> دونوں فریق ایک دوسرے سے ناراض ہیں۔
>
> *donoṅ farīq ek dūsre se nārāz haiṅ.*
>
> Both sides are angry with each other.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**فریق** (*farīq*) is usually traced, through Persian, to Arabic *farīq*, "a party, a group".
