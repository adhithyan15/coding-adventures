# ತಿದ್ದುಪಡಿ (tiddupaḍi) — an amendment

## You'll want to know: ತಿದ್ದುಪಡಿ
<!-- hl-knowledge: introduces=[KA-LEX-C396-MASUDE396-03]; assesses=[] -->

**ತಿದ್ದುಪಡಿ** — *tiddupaḍi* — "an amendment".

> ಕಾನೂನಿಗೆ ಒಂದು ತಿದ್ದುಪಡಿ ಬೇಕು.
>
> *kānūnige ondu tiddupaḍi bēku.*
>
> The law needs an amendment.

From ತಿದ್ದು, to correct. ತಿದ್ದುಪಡಿ ತರು, to bring an amendment.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ತಿದ್ದುಪಡಿ** (*tiddupaḍi*) is native Dravidian, built on *tiddu*, "to make straight, to correct" (DEDR 3251).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
