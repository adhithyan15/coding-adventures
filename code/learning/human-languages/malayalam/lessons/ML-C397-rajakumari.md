# രാജകുമാരി (rājakumāri) — a princess

## You'll want to know: രാജകുമാരി
<!-- hl-knowledge: introduces=[ML-LEX-C397-RAJAVU397-04]; assesses=[] -->

**രാജകുമാരി** — *rājakumāri* — "a princess".

> രാജകുമാരി പൂന്തോട്ടത്തിൽ പാട്ട് പാടി.
>
> *rājakumāri pūntōṭṭattil pāṭṭŭ pāṭi.*
>
> The princess sang in the garden.

The feminine of രാജകുമാരൻ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**രാജകുമാരി** (*rājakumāri*) is built from Sanskrit *rāja-*, "king" (CDIAL 10679), and *kumārī*, "a girl, a princess" (CDIAL 3303).
