# ಗ್ರಹಿಸು (grahisu) — to grasp; to comprehend

## You'll want to know: ಗ್ರಹಿಸು
<!-- hl-knowledge: introduces=[KA-LEX-C384-GRAHISU384-01]; assesses=[] -->

**ಗ್ರಹಿಸು** — *grahisu* — "to grasp; to comprehend".

> ಮಗು ಪಾಠವನ್ನು ಬೇಗ ಗ್ರಹಿಸಿತು.
>
> *magu pāṭhavannu bēga grahisitu.*
>
> The child grasped the lesson quickly.

Past (I …): ಗ್ರಹಿಸಿದೆ, *grahiside*.

ಗ್ರಹಿಕೆ, understanding.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಗ್ರಹಿಸು** (*grahisu*) is built on Sanskrit *grahaṇa*, "seizing, grasping" (CDIAL 4364), with the Kannada verb ending -*isu*.
