# cinco lugares — five places, sorted by what their names describe

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ES-LEX-C420-ARTS-01, ES-LEX-C354-WHERE-28] -->

[PAUSE 2s] Name the five places you can now go to. Say them out loud before
reading the list.

## Grammar Lens: what each name is actually about
<!-- hl-knowledge: introduces=[]; assesses=[ES-LEX-C420-ARTS-01, ES-LEX-C420-ARTS-02, ES-LEX-C420-ARTS-03, ES-LEX-C354-WHERE-28, ES-LEX-C353-WHERE-25] -->

Every one of these buildings is named after something different, and once you
sort them that way they stop being a list to memorise:

| place | named after | the thing itself |
|---|---|---|
| el teatro | the audience | a looking-place |
| el cine | the machine | a movement-writer |
| el museo | the Muses | a seat of the arts |
| la exposición | the act | a putting-out |
| el circo | the floor | a ring |

Two are named for **people** (the audience, the Muses), one for a **machine**,
one for an **action**, and one for a **shape**. Not one of them is named for the
art that happens inside it.
