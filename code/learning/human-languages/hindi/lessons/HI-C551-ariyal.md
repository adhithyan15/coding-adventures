# अड़ियल (aṛiyal) — stubborn; obstinate

## You'll want to know: अड़ियल
<!-- hl-knowledge: introduces=[HI-LEX-C551-MAJBUR551-04]; assesses=[] -->

**अड़ियल** — *aṛiyal* — "stubborn; obstinate".

> मेरा गधा बहुत अड़ियल है।
>
> *Merā gadhā bahut aṛiyal hai.*
>
> My donkey is very stubborn.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**अड़ियल** (*aṛiyal*) is built on *aṛnā*, "to come to a stop, to dig one's heels in", which CDIAL files under *\*aḍ*, "obstruct, stop" (CDIAL 187), with the ending -iyal for someone given to it.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
