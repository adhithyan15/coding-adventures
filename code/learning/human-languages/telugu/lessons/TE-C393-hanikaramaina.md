# హానికరమైన (hānikaramaina) — harmful

## You'll want to know: హానికరమైన
<!-- hl-knowledge: introduces=[TE-LEX-C393-PRAYOJANAM393-04]; assesses=[] -->

**హానికరమైన** — *hānikaramaina* — "harmful".

> పొగ తాగడం ఆరోగ్యానికి హానికరమైన అలవాటు.
>
> *poga tāgaḍaṁ ārōgyāniki hānikaramaina alavāṭu.*
>
> Smoking is a habit that harms your health.

హాని, harm, + -కర, causing, + -మైన.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**హానికరమైన** (*hānikaramaina*) is built on Sanskrit *hānikara*, "injurious, detrimental" (Monier-Williams), from *hāni*, "loss, decrease", with Telugu -మైన for an adjective.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
