# ఇంటిపేరు (iṇṭipēru) — a surname, the family name

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TE-LEX-C95-ASK-04, TE-LEX-C95-ASK-05] -->

[PAUSE 2s] Before the new one: say the Telugu for please show me, then the Telugu for I could not hear it.

## You'll want to know: ఇంటిపేరు
<!-- hl-knowledge: introduces=[TE-LEX-C96-NAMES-01]; assesses=[] -->

**ఇంటిపేరు** (*iṇṭipēru*) — "a surname", literally "the house name".

It is **ఇంటి**, "of the house", and **పేరు**, "name". In Telugu the house name comes FIRST, before
the given name, so a form that asks for a first name is asking the wrong question.
