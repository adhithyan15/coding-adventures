## You'll want to know: ಹೋಗೋಣ
<!-- hl-knowledge: introduces=[KA-LEX-C89-CARE-04]; assesses=[] -->

**ಹೋಗೋಣ** (*hōgōṇa*) — "let's go". The ending **‑ಓಣ** (*-ōṇa*) means "let's", the
same one you know from **ಸಿಗೋಣ** (*sigōṇa*), "let's meet".
