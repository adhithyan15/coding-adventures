## You'll want to know: sbucciare
<!-- hl-knowledge: introduces=[IT-LEX-C332-TAGLIERE-04]; assesses=[] -->

**sbucciare** — "to peel".

> Ho sbucciato le patate.
>
> *I peeled the potatoes.*

Built on *buccia*, ‘peel, skin’.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*sbucciare* is *s-* with *buccia* "peel", whose origin is not settled (EtymDB has no entry).
