# கல்லறை (kallaṟai) — a grave; a tomb

## You'll want to know: கல்லறை
<!-- hl-knowledge: introduces=[TA-LEX-C323-IRUTHI323-05]; assesses=[] -->

**கல்லறை** — *kallaṟai* — "a grave; a tomb".

> அவருடைய கல்லறை ஊருக்கு வெளியே இருக்கிறது.
>
> *avaruṭaiya kallaṟai ūrukku veḷiyē irukkiṟatu.*
>
> His grave is outside the village.

கல், stone + அறை, chamber.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**கல்லறை** (*kallaṟai*) is a Tamil compound built from கல், "stone" (DEDR 1298), and அறை, "a room, a chamber".
