# దండెత్తు (daṇḍettu) — to march against; to invade

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TE-LEX-C339-SAINYAM339-03, TE-LEX-C339-SAINYAM339-04] -->

[PAUSE 2s] Before the new one: say the Telugu for a commander, then the Telugu for a march.

## You'll want to know: దండెత్తు
<!-- hl-knowledge: introduces=[TE-LEX-C339-SAINYAM339-05]; assesses=[] -->

**దండెత్తు** — *daṇḍettu* — "to march against; to invade".

> ఆ రాజు పొరుగు రాజ్యం మీద దండెత్తాడు.
>
> *ā rāju porugu rājyaṁ mīda daṇḍettāḍu.*
>
> That king marched against the neighbouring kingdom.

Past (I …): దండెత్తాను, *daṇḍettānu*.

The target takes మీద: X మీద దండెత్తు.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**దండెత్తు** (*daṇḍettu*) is a native compound: *daṇḍu*, "an army, a host" (DEDR 3055), and *ettu*, "to lift, raise; to set out" (DEDR 796): to raise an army against someone.
