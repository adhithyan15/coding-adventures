## You'll want to know: حتمی
<!-- hl-knowledge: introduces=[UR-LEX-C545-MUSTAQIL545-03]; assesses=[] -->

**حتمی** — *hatmī* — "final; definite".

> اگر یہ تاریخ حتمی ہے تو میں ٹکٹ خریدوں گا۔
>
> *agar yih tārīkh hatmī hai to maiṅ ṭikaṭ kharīdūṅ gā.*
>
> If this date is final, I'll buy the ticket.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**حتمی** (*hatmī*) is usually traced, through Persian, to Arabic *ḥatmī*, "decisive", built on *ḥatm*, "deciding finally".
