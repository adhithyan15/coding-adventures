# मत — don't

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-LAVO-01, MW-SCRIPT-CHAAY-01, MW-GRAMMAR-C157-KONI-VERB-01] -->

[PAUSE 2s] Ask for tea: **चाय लावो।** Then say *I don't drink tea*.

## Grammar Lens: मत before a request
<!-- hl-knowledge: introduces=[MW-GRAMMAR-C157-MAT-01]; assesses=[MW-SCRIPT-LAVO-01, MW-LEX-C51-VERBS51-02] -->

**मत** in front of a request makes it *don't*:

> **मत जावो।**
>
> *mat jāvo.* — Don't go.

> **चाय मत लावो।**
>
> *chāy mat lāvo.* — Don't bring tea.

**कोनी** says what is not so; **मत** asks someone not to. Old Marwari had *mati*
in the same use (CDIAL 9981).

<!-- hl-knowledge: introduces=[]; assesses=[MW-GRAMMAR-C157-MAT-01, MW-LEX-C79-TIME79-05, MW-LEX-C55-VERBS55-03, MW-GRAMMAR-C157-KONI-VERB-01] -->

[PAUSE 1s]
- [YOU SAY: **अबार मत जावो।** — *abār mat jāvo.* — Don't go now.]
- [YOU SAY: **मत भूलो।** — *mat bhūlo.* — Don't forget.]
- [YOU SAY: **हूं चाय कोनी पीऊं। चाय मत लावो।** — *hū̃ chāy konī pīū̃. chāy mat lāvo.* — I don't drink tea. Don't bring tea.]
