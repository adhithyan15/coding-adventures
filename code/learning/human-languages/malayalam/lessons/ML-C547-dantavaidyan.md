## You'll want to know: ദന്തവൈദ്യൻ
<!-- hl-knowledge: introduces=[ML-LEX-C547-PROFESSION547-02]; assesses=[] -->

**ദന്തവൈദ്യൻ** — *dantavaidyan* — "a dentist".

> പല്ലുവേദന കാരണം ഞാൻ ദന്തവൈദ്യനെ കണ്ടു.
>
> *palluvēdana kāraṇaṁ ñān dantavaidyane kaṇṭu.*
>
> I saw the dentist because of a toothache.

ദന്തം a tooth + വൈദ്യൻ a doctor.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ദന്തവൈദ്യൻ** (*dantavaidyan*) is a learned compound built from Sanskrit *danta*, "a tooth" (CDIAL 6152), and *vaidya*, "a physician" (CDIAL 12140).
