## You'll want to know: l'égratignure
<!-- hl-knowledge: introduces=[FR-LEX-C479-BLESSURES-03]; assesses=[] -->

**l'égratignure** — "scratch, graze".

> Le chat m'a fait une égratignure sur le bras.
>
> *The cat gave me a scratch on my arm.*

Feminine. Lighter than *une coupure*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*l'égratignure* is built on *égratigner* "to scratch", itself built on *gratter* "to scratch", which comes from a Germanic word, Frankish *krattōn*.
