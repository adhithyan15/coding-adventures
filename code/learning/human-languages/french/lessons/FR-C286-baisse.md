## You'll want to know: la baisse
<!-- hl-knowledge: introduces=[FR-LEX-C286-CHIFFRES-04]; assesses=[] -->

**la baisse** — "the drop, the fall".

> Le nombre de touristes est en baisse.
>
> *The number of tourists is falling.*

*En baisse* — going down; the verb is *baisser*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*baisse* is built on *baisser* "to lower", inherited from Vulgar Latin *bassiāre*, built on Late Latin *bassus* "low" (EtymDB).
