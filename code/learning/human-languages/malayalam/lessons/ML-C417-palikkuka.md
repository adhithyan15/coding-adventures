# പാലിക്കുക (pālikkuka) — to abide by; to keep (a rule)

## You'll want to know: പാലിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C417-CATTAM417-02]; assesses=[] -->

**പാലിക്കുക** — *pālikkuka* — "to abide by; to keep (a rule)".

> എല്ലാവരും ട്രാഫിക് നിയമങ്ങൾ പാലിക്കണം.
>
> *ellāvaruṁ ṭrāphikŭ niyamaṅṅaḷ pālikkaṇaṁ.*
>
> Everyone must keep the traffic rules.

Past: പാലിച്ചു, *pāliccu*.

A promise is also പാലിക്കുക: വാക്ക് പാലിക്കുക, to keep one's word.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**പാലിക്കുക** (*pālikkuka*) is built from Sanskrit *pālana*, "protecting, keeping" (CDIAL 8128), with the Malayalam verb ending -ിക്കുക. To keep a rule is to guard it.
