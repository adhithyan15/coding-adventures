# चीथड़ो (chīthṛo) — a rag

## You'll want to know: चीथड़ो
<!-- hl-knowledge: introduces=[MW-LEX-C171-BASAN171-02]; assesses=[] -->

**चीथड़ो** — *chīthṛo* — "a rag".

> चीथड़ो मैलो है।
>
> *chīthṛo mailo hai.*
>
> The rag is dirty.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**चीथड़ो** (*chīthṛo*) comes from a reconstructed *\*citth*, "pound, tear"; CDIAL lists Hindi *cīthṛā* and Sindhi *cīthaṛo*, both masculine, for a rag or old torn clothes (CDIAL 4802). CDIAL gives no Marwari form in this entry.
