# പരീക്ഷ — an exam

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C103-LESSON-01, ML-CONCEPT-C09-KSHAMIKKANAM-01] -->

[PAUSE 2s] Say *a lesson*. Then say the apology you have had since early on —
and listen for the **ക്ഷ** that opens it.

## You'll want to know
<!-- hl-knowledge: introduces=[ML-LEX-C103-EXAM-01]; assesses=[ML-CONCEPT-C09-KSHAMIKKANAM-01] -->

**പരീക്ഷ** (*parīkṣa*) — **an exam**.

**You can already write the hard part.** The **ക്ഷ** is not a new shape — but
look at **where it sits**. It **opens** that apology, and here it **closes** the
word.

You have seen it close a word before: **അപേക്ഷ**, the request, ends in exactly
this.

The Sanskrit behind it is *pari-* (**around**) plus a root meaning **to look**.
An examination is a **looking all around** something.

## Grammar Lens: this one does not end in -ം
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C103-EXAM-01, ML-LEX-C103-LESSON-01] -->

The word before this one ended in **-ം** and told you what it would do. This one
ends in **അ**, and it does not join the same family:

| | | |
|---|---|---|
| **പാഠം** | *pāṭhaṁ* | ends in **-ം** |
| **പരീക്ഷ** | *parīkṣa* | ends in **അ** |

**Two words from the same chapter, in the same subject, behaving differently.**
That is worth noticing rather than smoothing over: what a Malayalam word does
when something attaches to it is decided by **how it ends**, not by what it
means.
