# ലിഫ്റ്റ് (liphṟṟŭ) — a lift

## You'll want to know: ലിഫ്റ്റ്
<!-- hl-knowledge: introduces=[ML-LEX-C485-KAVATAM485-01]; assesses=[] -->

**ലിഫ്റ്റ്** — *liphṟṟŭ* — "a lift".

> ലിഫ്റ്റ് കേടായതുകൊണ്ട് ഞങ്ങൾ നടന്നു കയറി.
>
> *liphṟṟŭ kēṭāyatukoṇṭŭ ñaṅṅaḷ naṭannu kayaṟi.*
>
> Because the lift had broken down, we walked up.

British usage: Malayalam says ലിഫ്റ്റ്, not elevator.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ലിഫ്റ്റ്** (*liphṟṟŭ*) was borrowed from English *lift*, a moving box that carries people between floors.
