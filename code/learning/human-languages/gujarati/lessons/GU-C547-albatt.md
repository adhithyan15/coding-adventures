# અલબત્ત (albatt) — of course (granted)

## You'll want to know: અલબત્ત
<!-- hl-knowledge: introduces=[GU-LEX-C547-CHATA547-01]; assesses=[] -->

**અલબત્ત** — *albatt* — "of course (granted)".

> જો તમે બોલાવશો તો અલબત્ત હું આવીશ.
>
> *jo tame bolāvśo to albatt hũ āvīś.*
>
> If you invite me, of course I'll come.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**અલબત્ત** (*albatt*) is usually traced to Persian *albatta*, "certainly", a word Persian took from Arabic.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
