## You'll want to know: el choque
<!-- hl-knowledge: introduces=[ES-LEX-C527-CHOQUE-02]; assesses=[] -->

**el choque** — "the crash, the collision; the shock".

> El choque fue muy fuerte.
>
> *The crash was very violent.*

*Un choque cultural* — a culture shock.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*choque* is built on the verb *chocar* (EtymDB), whose own origin is not settled; it is often treated as a sound word.
