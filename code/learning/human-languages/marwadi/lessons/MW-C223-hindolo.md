# हिंडोळो (hiṇḍoḷo) — a big swing; a swing cradle

## You'll want to know: हिंडोळो
<!-- hl-knowledge: introduces=[MW-LEX-C223-FAIR223-02]; assesses=[] -->

**हिंडोळो** — *hiṇḍoḷo* — "a big swing; a swing cradle".

> हिंडोळो घणो बड़ो है।
>
> *hiṇḍoḷo ghaṇo baṛo hai.*
>
> The swing is very big.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**हिंडोळो** (*hiṇḍoḷo*) is inherited from Sanskrit *hindola*, "a swing, a swing cradle"; CDIAL lists an Old Marwari word for a revolving swing under it (CDIAL 14094).
