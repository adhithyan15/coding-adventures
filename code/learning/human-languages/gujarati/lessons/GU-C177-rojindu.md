## You'll want to know: રોજિંદું
<!-- hl-knowledge: introduces=[GU-LEX-C177-OFTEN177-05]; assesses=[] -->

**રોજિંદું** — *rojindũ* — "everyday, daily".

> **હું રોજિંદું કામ સવારે કરીશ.** — *hũ rojindũ kām savāre karīś* — "I will do the everyday work in the morning."

Built on **રોજ**, *roj*, every day.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**રોજિંદું** (*rojindũ*) is built on the taught *roj*, "every day", which is usually traced to Persian *rōz*, "day".
