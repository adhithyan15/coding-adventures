## You'll want to know: अन्तर्जालम्

<!-- hl-knowledge: introduces=[SA-LEX-C269-MEDIA-02]; assesses=[] -->

**अन्तर्जालम्** — *antarjālam* — “the internet.” The modern computing term is
explicitly attested in the [Kosha Sanskrit Today internet
entry](https://kosha.sanskrit.today/word/en/Internet) and its [Computer —
Internet glossary](https://kosha.sanskrit.today/glossary/computer-internet).
This lesson owns only that sourced modern meaning.

## The word, taken apart

<!-- hl-knowledge: introduces=[]; assesses=[SA-LEX-C269-MEDIA-02] -->

**अन्तर्** gives the idea “between” or “inter-,” and **जाल** means “net.” The
transparent “inter-net” shape is a memory hook, not a lesson in using the
internet.
