## You'll want to know: o senhorio
<!-- hl-knowledge: introduces=[PT-LEX-C530-SENHORIO-01]; assesses=[] -->

**o senhorio** — "landlord".

> O senhorio aumentou a renda.
>
> *The landlord put up the rent.*

*A senhoria* — landlady.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*senhorio* is inherited from Old Portuguese *sennorio* "lordship" (EtymDB), built on *senhor*, from Latin *senior* "older".
