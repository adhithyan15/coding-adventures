## You'll want to know: справка
<!-- hl-knowledge: introduces=[RU-LEX-C450-SPRAVKA-01]; assesses=[] -->

**справка** (*správka*) — "a certificate, an official note; information".

> Для визы нужна справка с работы.
>
> *Dlya vízy nuzhná správka s rabóty.*
>
> For the visa you need a letter from your employer.

Feminine. *Справочное бюро* — an information desk.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*справка* is built on *справиться* 'to inquire', from *править* 'to set right, to put in order'. EtymDB lists *справка* without a deeper source.
