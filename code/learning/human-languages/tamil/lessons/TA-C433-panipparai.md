# பனிப்பாறை (paṉippāṟai) — a glacier; an iceberg

## You'll want to know: பனிப்பாறை
<!-- hl-knowledge: introduces=[TA-LEX-C433-SIKARAM433-04]; assesses=[] -->

**பனிப்பாறை** — *paṉippāṟai* — "a glacier; an iceberg".

> பனிப்பாறைகள் மெதுவாக உருகுகின்றன.
>
> *paṉippāṟaikaḷ metuvāka urukukiṉṟaṉa.*
>
> The glaciers are slowly melting.

பனி, snow, + பாறை, a rock, with the ப் doubled.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**பனிப்பாறை** (*paṉippāṟai*) is built from பனி, "dew, snow" (DEDR 4035), and பாறை, "a rock" (DEDR 4121).
