## You'll want to know: fīniō, fīnīre
<!-- hl-knowledge: introduces=[LA-LEX-C297-INCIPIO-03]; assesses=[] -->

**fīniō, fīnīre** — "to finish; to set limits".

> Hōrā nōnā labōrem fīnīvimus.
>
> *We finished the work at the ninth hour.*

*fīniō, fīnīre, fīnīvī, fīnītum*. From *fīnis* (taught): first 'to mark a boundary', then 'to end'. English *finish*, *finite*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**fīniō** is built on *fīnis*, "end, boundary" (EtymDB): to set an end. English *finish* comes from it through French, and *finite* from its participle.
