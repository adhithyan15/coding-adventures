## Writing

1. **जलम्**
2. **गृहम्**
3. **नमः**
4. **विद्यालयः**
5. **पुस्तकम्**
6. **धन्यवादः**
7. Accept an independently written recognizable Devanagari place name; do not
   require **उज्जयिनी**.
8. Accept an independently written Sanskrit thanks expression such as
   **धन्यवादः**. Do not accept a romanized or visibly copied answer.

## Speaking

1. Accept **शुभप्रभातम्**, **नमस्ते**, or an equally appropriate response.
2. Accept a chosen identity in a comprehensible frame such as
   **मम नाम … अस्ति।**
3. Accept a relevant state such as **अहं कुशली अस्मि।**
4. Accept a comprehensible place response.
5. Accept a relevant yes/no response or a short Sanskrit-speaking frame.
6. Accept a comprehensible polite request containing **पुस्तकम्** and a request
   signal such as **कृपया**.

Apply the speaking rubric to the whole part. These examples are not scripts the
learner must reproduce word for word. Consistent taught pronunciation variants
remain acceptable.
