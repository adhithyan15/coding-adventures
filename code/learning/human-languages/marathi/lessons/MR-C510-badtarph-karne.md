# बडतर्फ करणे (baḍtarph karṇe) — to dismiss

## You'll want to know: बडतर्फ करणे
<!-- hl-knowledge: introduces=[MR-LEX-C510-SODNE510-05]; assesses=[] -->

**बडतर्फ करणे** — *baḍtarph karṇe* — "to dismiss".

> चोरीमुळे मालकाने त्या कामगाराला बडतर्फ केलं.
>
> *corīmuḷe mālkāne tyā kāmgārālā baḍtarph kelaṁ.*
>
> The owner dismissed that worker because of the theft.

Past, with -ने (he …): त्याने कामगाराला बडतर्फ केलं, *tyāne kāmgārālā baḍtarph kelaṁ*.

The person dismissed takes -ला: कामगाराला बडतर्फ करणे.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**बडतर्फ करणे** (*baḍtarph karṇe*) is बडतर्फ, a loan from Persian *bar-taraf*, "set aside, removed", with करणे.
