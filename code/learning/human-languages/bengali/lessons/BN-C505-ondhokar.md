## You'll want to know: অন্ধকার
<!-- hl-knowledge: introduces=[BN-LEX-C505-ALO505-01]; assesses=[] -->

**অন্ধকার** — *ôndhôkār* — "darkness; dark".

> রাতে গলিটা অন্ধকার।
>
> *Rāte gôliṭā ôndhôkār.*
>
> The lane is dark at night.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**অন্ধকার** (*ôndhôkār*) is a tatsama, Sanskrit *andhakāra*, "darkness" (Monier-Williams), built on *andha*, "blind".
