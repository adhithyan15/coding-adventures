# விமர்சனம் (vimarcaṉam) — a review; criticism

## You'll want to know: விமர்சனம்
<!-- hl-knowledge: introduces=[TA-LEX-C555-VIRUTHU555-04]; assesses=[] -->

**விமர்சனம்** — *vimarcaṉam* — "a review; criticism".

> நல்ல விமர்சனம் வந்தால் படம் வெற்றி பெறும்.
>
> *nalla vimarcaṉam vantāl paṭam veṟṟi peṟum.*
>
> If good reviews come, the film will be a success.

A critic is a விமர்சகர். A -அம் noun: விமர்சனத்தை.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**விமர்சனம்** (*vimarcaṉam*) is borrowed from Sanskrit *vimarśana*, "discussion, investigation" (Monier-Williams).
