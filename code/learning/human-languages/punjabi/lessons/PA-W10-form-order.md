# Three known labels, one gentle order

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-LABEL-AGE-01, PA-FORM-LABEL-PHONE-01, PA-FORM-LABEL-DATE-01] -->

Point to the three labels you have already written: **ਉਮਰ:**, **ਫ਼ੋਨ:**,
**ਤਾਰੀਖ਼:**. No new field or value is added here.

## Writing — first labels, then values
<!-- hl-knowledge: introduces=[PA-FORM-AGE-PHONE-DATE-ORDER-01]; assesses=[PA-FORM-LABEL-AGE-01, PA-FORM-LABEL-PHONE-01, PA-FORM-LABEL-DATE-01] -->
<!-- hl-writing-stage: guided-copy -->

This little fictional form puts age on the first line, phone on the second,
and date on the third. Copy only the three labels in that order, with one
empty space after each colon. Leave the values blank for now.

> ਉਮਰ: ______
>
> ਫ਼ੋਨ: ______
>
> ਤਾਰੀਖ਼: ______

## Guided Practice — cover and point
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-AGE-PHONE-DATE-ORDER-01] -->

Cover the form. Point to three empty lines and say which known field belongs
on each. Uncover it to check only the line order, not any digits.
