# થનગનવું (thanganvũ) — to be itching to dance

## You'll want to know: થનગનવું
<!-- hl-knowledge: introduces=[GU-LEX-C553-NAGARU553-05]; assesses=[] -->

**થનગનવું** — *thanganvũ* — "to be itching to dance".

> જો ગરબાનું સંગીત શરૂ થશે તો બાળકો થનગનશે.
>
> *jo garbānũ sangīt śarū thaśe to bāḷko thanganśe.*
>
> If the garba music starts, the children will be itching to dance.

Past (he …): તે થનગન્યો, *te thanganyo*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**થનગનવું** (*thanganvũ*) is imitative, the tapping of eager feet. No dictionary we use records an older form, so its history is not settled.
