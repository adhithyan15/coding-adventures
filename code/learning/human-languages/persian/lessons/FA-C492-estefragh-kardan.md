# استفراغ کردن (estefrâgh kardan) — to vomit, to be sick

## You'll want to know: استفراغ کردن
<!-- hl-knowledge: introduces=[FA-LEX-C492-UNWELL-02]; assesses=[] -->

**استفراغ کردن** (*estefrâgh kardan*) — "to vomit, to be sick".

> بچه در اتوبوس استفراغ کرد.
>
> *bachche dar otobus estefrâgh kard.*
>
> The child was sick on the bus.

*estefrâgh* 'vomiting' + *kardan*. More medical than *bâlâ âvardan*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*estefrâgh* is a loan, usually traced to Arabic *istifrāġ*, 'emptying out'. EtymDB has no entry for it. *kardan*, 'to do', is inherited Persian.
