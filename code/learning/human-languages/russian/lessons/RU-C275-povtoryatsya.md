## You'll want to know: повторяться
<!-- hl-knowledge: introduces=[RU-LEX-C275-ZATYAGIVATSYA-04]; assesses=[] -->

**повторяться** (*povtoryátsya*) — "to happen again, to recur".

> Такая история больше не повторится.
>
> *Takáya istóriya bólshe ne povtorítsya.*
>
> A story like this will not happen again.

Imperfective; perfective *повториться* (*povtorítsya*). *Повторять* is to repeat something; with *-ся* the event itself comes back.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*повторяться* is built on *по-* and *второй* "second", which is inherited from Proto-Slavic *vŭtorŭ* "second" (EtymDB): to happen a second time.
