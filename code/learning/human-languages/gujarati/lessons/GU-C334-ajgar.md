## You'll want to know: અજગર
<!-- hl-knowledge: introduces=[GU-LEX-C334-KHAJANO334-02]; assesses=[] -->

**અજગર** — *ajgar* — "a python".

> ખજાના પાસે એક મોટો અજગર બેઠો હતો.
>
> *khajānā pāse ek moṭo ajgar beṭho hato.*
>
> A huge python lay beside the treasure.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**અજગર** (*ajgar*) is a tatsama, Sanskrit *ajagara*, "a goat-swallower", a large snake (Monier-Williams). In stories it guards treasure.
