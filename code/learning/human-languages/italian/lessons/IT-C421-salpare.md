## You'll want to know: salpare
<!-- hl-knowledge: introduces=[IT-LEX-C421-PORTO-05]; assesses=[] -->

**salpare** — "to set sail, to weigh anchor".

> La nave salpa all'alba.
>
> *The ship sets sail at dawn.*

*Salpare l'ancora* — to weigh anchor.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

The origin of *salpare* is not settled: some trace it to a Greek sailors' word, others to Catalan.
