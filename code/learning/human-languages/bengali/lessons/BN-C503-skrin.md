## You'll want to know: স্ক্রিন
<!-- hl-knowledge: introduces=[BN-LEX-C503-ONLINE503-04]; assesses=[] -->

**স্ক্রিন** — *skrin* — "a screen".

> ল্যাপটপের স্ক্রিনটা বড়।
>
> *Læpṭôper skrinṭā bôṛo.*
>
> The laptop's screen is big.
