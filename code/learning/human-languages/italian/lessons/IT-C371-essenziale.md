## You'll want to know: essenziale
<!-- hl-knowledge: introduces=[IT-LEX-C371-RILEVANTE-03]; assesses=[] -->

**essenziale** — "essential".

> L'acqua è essenziale per la vita.
>
> *Water is essential for life.*

*L'essenziale* — the main thing. *Uno stile essenziale* — a plain style.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*essenziale* is a learned borrowing from Late Latin *essentiālis* "of the essence" (EtymDB), from *essentia* "being, essence", built on *esse* "to be".
