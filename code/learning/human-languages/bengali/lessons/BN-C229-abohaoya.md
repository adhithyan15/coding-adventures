## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**আবহাওয়া** (*ābôhāoyā*) is a loan, usually traced to Persian *āb-o-havā*, "water and air; climate". It is Persian *āb*, "water", + *o*, "and", + *havā*, "air", which is itself Arabic.
