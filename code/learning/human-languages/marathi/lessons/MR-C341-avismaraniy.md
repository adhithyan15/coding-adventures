## You'll want to know: अविस्मरणीय
<!-- hl-knowledge: introduces=[MR-LEX-C341-KADAMBARI341-04]; assesses=[] -->

**अविस्मरणीय** — *avismaraṇīy* — "unforgettable".

> ती सहल माझ्यासाठी अविस्मरणीय होती.
>
> *tī sahal mājhyāsāṭhī avismaraṇīy hotī.*
>
> That trip was unforgettable for me.

अविस्मरणीय keeps one form; अ-, not, + विस्मरणीय, to be forgotten.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**अविस्मरणीय** (*avismaraṇīy*) is built from the Sanskrit prefix *a-*, 'not', and *vismaraṇīya*, 'to be forgotten' (Monier-Williams).
