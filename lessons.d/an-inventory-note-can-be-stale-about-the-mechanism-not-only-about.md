# An inventory note can be stale about the MECHANISM, not only about the coverage

The staleness already written down is the coverage kind: a note says a word is
untaught and the word has since been taught. `ML-A1-TIME-10` was stale in a
different way, and the difference matters because the two are found by different
checks.

Its note read: *"Requires the **locative** on a time word, which is not taught.
The parts are all present — days, hours, the **-il** suffix — and are never
assembled."*

**The coverage half was accurate.** The parts really were all present and really
were never assembled; that half survived verification unchanged.

**The grammar half named the wrong case.** Malayalam fixes a clock time with the
**dative** — *raṇṭŭ maṇikku* — and there is no form in **-il** anywhere near it.
The dative had been taught since sequence **320**, eleven lessons into the book.
A headword sweep for the words the note names finds nothing wrong: the words are
all there or all absent exactly as it says. The defect is in the sentence
explaining *why* the point is open, and the only thing that finds it is knowing
the language.

The practical consequence was large and in the cheap direction. Scoped from the
note, the point looked blocked on an untaught suffix. Scoped from the language,
it needed **one joint** and **no new vocabulary at all**, and the chapter that
closed it introduced zero new words.

**What to do.** When a note explains an open point by naming a *construction*
rather than a *word* — a case, a tense, an agreement rule — check that claim
separately from the vocabulary claim. Ask what the language actually uses for
the function the point describes, and only then grep for it. A note can pass
every word-level check it makes and still be pointing at the wrong machine.

**The cheap tell**: a note that names a construction the corpus *does* teach,
and says it is not taught, is wrong about one or the other. Both `ML-A1-TIME-10`
("the locative is not taught" — the locative is taught; it is not the case
this point needs) and the wrong-case error itself are visible from that one question.
