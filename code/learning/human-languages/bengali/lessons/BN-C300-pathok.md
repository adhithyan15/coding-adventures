## You'll want to know: পাঠক
<!-- hl-knowledge: introduces=[BN-LEX-C300-PATHOK300-01]; assesses=[] -->

**পাঠক** — *pāṭhôk* — "a reader".

> এই পত্রিকার অনেক পাঠক গ্রামে থাকেন।
>
> *ei pôtrikār ônek pāṭhôk grāme thāken.*
>
> Many of this magazine's readers live in villages.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**পাঠক** (*pāṭhôk*) is Sanskrit *pāṭhaka*, 'a reciter, a reader' (Monier-Williams), from the same root as **পড়া**, to read.
