# ನಿಲ್ಲಿಸಿ (nillisi) — please stop

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C101-OPEN-01, KA-LEX-C101-OPEN-02] -->

[PAUSE 2s] Before the new one: say the Kannada for please open, then the Kannada for please close.

## You'll want to know: ನಿಲ್ಲಿಸಿ
<!-- hl-knowledge: introduces=[KA-LEX-C101-OPEN-03]; assesses=[] -->

**ನಿಲ್ಲಿಸಿ** (*nillisi*) — "please stop (it)", said to a driver or about a machine.
It comes from **ನಿಲ್ಲು**, "to stop, to stand".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

The request on a bus or in a taxi.
