## You'll want to know: مزلاج
<!-- hl-knowledge: introduces=[AR-LEX-C549-BAB549-04]; assesses=[] -->

**مزلاج** — *mizlāj* — "a bolt, a latch".

> أغلقت الباب بالمزلاج.
>
> *aghlaqtu al-bāb bi-l-mizlāj.*
>
> I shut the door with the bolt.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**مزلاج** (*mizlāj*) is built on the native Arabic root *z-l-j*, "to slide, to slip" (Lane). Lane gives azlaja al-bāb as to make a door fast with the mizlāj. The pattern mifʿāl names a tool.
