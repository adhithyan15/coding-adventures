## You'll want to know: برمج
<!-- hl-knowledge: introduces=[AR-LEX-C525-TASMIM525-04]; assesses=[] -->

**برمج** — *barmaja* — "to program (a computer)".

> برمج أخي لعبة على الحاسوب.
>
> *barmaja akhī luʿba ʿalā al-ḥāsūb.*
>
> My brother programmed a game on the computer.

Present: يبرمج, *yubarmij*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**برمج** (*barmaja*) is a modern Arabic verb built from *barnāmaj*, "a programme", which you know; *barnāmaj* is usually traced to Persian *barnāma*. Arabic made a new four-letter root *b-r-m-j* from it.
