# Changelog

All notable changes to this package will be documented in this file.

## [0.1.0] - 2026-09-19

### Added

- Complete PDP-8/E base-processor memory-reference and Group 1/2 operate
  instruction execution over a 4K-word, 12-bit core memory.
- Current-page, indirect, and auto-index addressing; CPU-control IOTs;
  interrupt entry; front-panel switch register; and external IOT events.
- Transactional typed faults, bounded execution, complete owned snapshots,
  checked state restoration, canonical traces, and strict program transport.
