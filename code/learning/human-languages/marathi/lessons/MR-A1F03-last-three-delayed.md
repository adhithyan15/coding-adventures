# Hide, wait, write the last three labels

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MR-A1-FORM-LABEL-AVDATE-PEY, MR-A1-FORM-AGREEMENT-NEUTER, MR-A1-FORM-LABEL-AVADTI-KRUTI, MR-A1-FORM-AGREEMENT-FEMININE, MR-A1-FORM-LABEL-MITRACHE-NAAV, MR-A1-FORM-POSSESSIVE-NEUTER] -->

Close the copy lesson. Say favorite drink, favorite activity, friend's name
once, then start the ten-second delay.

## Writing — delayed copy
<!-- hl-knowledge: introduces=[]; assesses=[MR-A1-FORM-LABEL-AVDATE-PEY, MR-A1-FORM-AGREEMENT-NEUTER, MR-A1-FORM-LABEL-AVADTI-KRUTI, MR-A1-FORM-AGREEMENT-FEMININE, MR-A1-FORM-LABEL-MITRACHE-NAAV, MR-A1-FORM-POSSESSIVE-NEUTER] -->
<!-- hl-writing-stage: delayed-copy -->

Close the copy lesson and wait ten seconds. From **favorite drink · favorite
activity · friend's name**, write the three Marathi labels without a model or
romanization.

Then compare in two bounded passes: first **-ते / -ती**, then **-चे**. If the
first pass differs, repair it and stop; leave the second pass for tomorrow.
