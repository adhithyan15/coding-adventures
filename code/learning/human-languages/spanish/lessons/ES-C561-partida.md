## You'll want to know: la partida
<!-- hl-knowledge: introduces=[ES-LEX-C561-PARTIDA-03]; assesses=[] -->

**la partida** — "the departure; the game".

> La partida del tren se retrasó.
>
> *The train's departure was delayed.*

*Una partida de cartas* is a game of cards. *Un partido* is a match.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*partida* is built on the participle of *partir*, which is inherited from Latin *partīre* 'to divide' (EtymDB).
