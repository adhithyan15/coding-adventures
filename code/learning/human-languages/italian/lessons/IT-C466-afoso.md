## You'll want to know: afoso
<!-- hl-knowledge: introduces=[IT-LEX-C466-AFA-02]; assesses=[] -->

**afoso** — "sultry, muggy".

> Oggi è una giornata afosa.
>
> *Today is a muggy day.*

*Un'estate afosa* — a sticky summer.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*afoso* is built on *afa* 'sultry heat' with the ending *-oso* 'full of'. The origin of *afa* is not settled.
