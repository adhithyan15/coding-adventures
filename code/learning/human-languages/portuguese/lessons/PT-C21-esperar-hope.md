# espero que sim — I hope so

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[] -->

[PAUSE 2s] **Espero** first meant “I hope.” Learn that meaning in one useful
answer: **Espero que sim**, “I hope so.”

## You'll want to know: Bank the whole answer
<!-- hl-knowledge: introduces=[PT-GRAMMAR-ESPERAR-HOPE-04]; assesses=[] -->

> — Vai chover? — Is it going to rain?
> — **Espero que sim.** — I hope so.

You do not need to take the answer apart yet. Hear and say the four beats:
**es-pe-ro que sim**.

The earlier meaning, “wait,” is still available. The sentence around **esperar**
selects the meaning.
