# Marwadi pre-A1 mock 2 — confidential examiner and recording script

Do not give this file to the learner. Keep the form-2 answer key and shared
rubric confidential too. A qualified Marwadi speaker must review the variety,
record every named file, and confirm the short form-field readings before use.
Document the pronunciation variety and use it consistently. Speak at 70–90
words per minute without translation, spelling, or coaching. Play each file
twice with an eight-second answer pause after each play. A technical restart
replaces the affected play; it does not authorize a third play.

Measure each audio file from start to end, including natural silence. Pad a
short stimulus with silence rather than stretching or repeating speech.
Reject and rerecord any file outside its part's duration band. Give only the
current skill packet: collect Reading before Listening, Listening before
Writing, and Writing before Speaking. Never return a collected packet.

## Speaking — live interlocutor

Use 2–8 seconds for each prompt and allow 2–15 seconds for each response.
The interlocutor may repeat a prompt once slowly, without giving an answer.

1. Say **राम-राम सा।** The learner returns an appropriate greeting.
2. Ask **थारो नाम कांई है?** The learner supplies a chosen name.
3. Ask **आप कैसो हो?** The learner answers how they are.
4. In the declared support language ask for one family member in Marwadi.
5. In the declared support language ask for one familiar kind of place where
   the learner lives, in Marwadi. A village or city is acceptable.
6. Show an unlabeled picture of water. In the declared support language ask
   the learner to request it in Marwadi. **पाणी लावो** is an example target
   assembled from taught words; never show or say that model to the learner.

Record the speaking paper for independent scoring. This file specifies a
structural form, not examiner calibration or readiness. No recording or
qualified-speaker sign-off is claimed by this source packet.
