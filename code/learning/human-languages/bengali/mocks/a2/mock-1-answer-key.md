## Writing

Task 1 must address Anup, explain the delay, give an arrival time, and ask how
to recover the missed work in 25–35 independently produced Bengali words. Task
2 must form a connected 70–90-word account covering the six requested points.
Do not reward copied prompt language as independent writing.

## Speaking

Use unfamiliar follow-up questions in the interview. In part 2 allow only
keyword notes made during preparation. In part 3 the interlocutor should give
one initially incomplete answer so the learner must clarify it. Score the
recorded performance, not examiner impressions from outside the recording.
