# सावधानः (sāvadhānaḥ) — careful

## You'll want to know: सावधानः
<!-- hl-knowledge: introduces=[SA-LEX-C299-GHOSHANA299-03]; assesses=[] -->

**सावधानः** — *sāvadhānaḥ* — "careful".

> भवान् सावधानः भवतु।
>
> *bhavān sāvadhānaḥ bhavatu.*
>
> Please be careful.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**सावधानः** (*sāvadhānaḥ*) is built from *sa*, "with", and *avadhāna*, "attention"; MW gives *sāvadhāna* as attentive, heedful, careful (MW).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->
