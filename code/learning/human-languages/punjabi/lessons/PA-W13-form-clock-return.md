# Return to two familiar form lines

This is a short, unscored return to the form you already tried. Keep the
original timed form unchanged. A new practice line cannot replace its evidence.

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-A1-FORM-MIXED-CUES-01, PA-A1-FORM-TIMED-01] -->

Close the old A · ਕ and B · ਖ value banks. Read each mark before recalling its
value. Set a one-minute practice timer; it is not an A1 paper score.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-A1-FORM-MIXED-CUES-01, PA-A1-FORM-TIMED-01, PA-A1-TIMED-REPAIR-01] -->

Start the practice timer. Write these two known lines in Gurmukhi. Stop when
the minute ends, even if a line is unfinished.

> ਨਾਂ (A · ਕ): ______
>
> ਭਾਸ਼ਾ (B · ਖ): ______

Only after stopping, check the old values: **ਨਾਂ: ਅਮਨ** and **ਭਾਸ਼ਾ: ਹਿੰਦੀ**.
On a separate page, repair one missed value or one Gurmukhi spelling. Leave
both the first practice lines and the earlier six-field timed form untouched.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[PA-A1-FORM-MIXED-CUES-01, PA-A1-FORM-TIMED-01, PA-A1-TIMED-REPAIR-01] -->

Cover the checks. [PAUSE 4s] Recall the order: read each card mark, write
under the short practice clock, stop, then repair on another page. This return
does not count as a complete form-and-message mock.
