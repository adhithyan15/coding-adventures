# ஆவியாகு (āviyāku) — to evaporate

## You'll want to know: ஆவியாகு
<!-- hl-knowledge: introduces=[TA-LEX-C431-VARATCHI431-03]; assesses=[] -->

**ஆவியாகு** — *āviyāku* — "to evaporate".

> வெயிலில் தண்ணீர் ஆவியானது.
>
> *veyilil taṇṇīr āviyāṉatu.*
>
> The water evaporated in the sun.

Past (it …): ஆவியானது, *āviyāṉatu*.

ஆவி, steam, + ஆகு, to become.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ஆவியாகு** (*āviyāku*) is built from ஆவி, "breath, steam" (DEDR 393), and ஆகு, "to become".
