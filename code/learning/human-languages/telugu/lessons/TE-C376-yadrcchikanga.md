## You'll want to know: యాదృచ్ఛికంగా
<!-- hl-knowledge: introduces=[TE-LEX-C376-SPANDANA376-05]; assesses=[] -->

**యాదృచ్ఛికంగా** — *yādṛcchikaṅgā* — "by chance".

> మేము యాదృచ్ఛికంగా ఒకే రైలులో కలిశాము.
>
> *mēmu yādṛcchikaṅgā okē railulō kaliśāmu.*
>
> We met by chance on the same train.

A bookish word; అనుకోకుండా says much the same in speech.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**యాదృచ్ఛికంగా** (*yādṛcchikaṅgā*) is built on Sanskrit *yādṛcchika*, "spontaneous, accidental" (Monier-Williams), with the Telugu adverb ending *-gā*.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
