## You'll want to know: discutível
<!-- hl-knowledge: introduces=[PT-LEX-C340-DUVIDA-05]; assesses=[] -->

**discutível** — "debatable, questionable".

> Essa decisão foi discutível.
>
> *That decision was debatable.*

Built on *discutir* + *-ível*: something you can argue about.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*discutível* is built on *discutir* "to discuss" with the suffix *-ível*; *discutir* comes from Latin *discutere* "to strike asunder, to shatter" (Lewis & Short), which later meant "to examine".
