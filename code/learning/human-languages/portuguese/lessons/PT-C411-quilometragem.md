## You'll want to know: a quilometragem
<!-- hl-knowledge: introduces=[PT-LEX-C411-ALUGUER-04]; assesses=[] -->

**a quilometragem** — "the mileage (in kilometres)".

> Neste aluguer, a quilometragem é ilimitada.
>
> *With this hire, the mileage is unlimited.*

Built on *o quilómetro*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*quilometragem* is built on *quilómetro* with *-agem*. *Quilómetro* is a learned coinage from Greek *khílioi* 'a thousand' and *métron* 'measure'; EtymDB has no entry for *quilómetro*.
