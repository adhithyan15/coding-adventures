# ચાકડો (cākḍo) — a potter's wheel

## You'll want to know: ચાકડો
<!-- hl-knowledge: introduces=[GU-LEX-C504-KUMBHAR504-02]; assesses=[] -->

**ચાકડો** — *cākḍo* — "a potter's wheel".

> કુંભાર ચાકડા પર માટીનું માટલું બનાવે છે.
>
> *kumbhār cākḍā par māṭīnũ māṭlũ banāve che.*
>
> The potter makes a clay pot on the wheel.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

is built on *cāk*, "a wheel, a potter's wheel", which CDIAL lists under Sanskrit *cakrá*, "a wheel" (CDIAL 4538); **ચાકડો** adds the ending *-ḍo*.
