# அன்றைய (aṉṟaiya) — of that day; that day's

## You'll want to know: அன்றைய
<!-- hl-knowledge: introduces=[TA-LEX-C316-ANNAAL316-02]; assesses=[] -->

**அன்றைய** — *aṉṟaiya* — "of that day; that day's".

> அன்றைய நாளிதழில் அந்தச் செய்தி வந்தது.
>
> *aṉṟaiya nāḷitaḻil antac ceyti vantatu.*
>
> That news appeared in that day's newspaper.

Like இன்றைய, today's, and நேற்றைய, yesterday's; only before a noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**அன்றைய** (*aṉṟaiya*) is native Dravidian: DEDR 1 lists அன்று and அன்றை, "that day", built on the far-pointing அ-.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
