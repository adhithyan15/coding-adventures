# Fill one field with the bank visible

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[HI-FORM-LABEL-NAME-01, HI-FORM-NAME-CUE-MAP-01] -->

Read the label **नाम**. Recall the visible bank: **A मीरा · B अरुण**.

## Guided Practice — supported entry
<!-- hl-knowledge: introduces=[HI-FORM-NAME-SUPPORTED-ENTRY-01]; assesses=[HI-FORM-LABEL-NAME-01, HI-FORM-NAME-MIRA-01, HI-FORM-NAME-CUE-MAP-01] -->
<!-- hl-writing-stage: guided-copy -->

Keep the bank visible. Card A requests its known value:

> A — **नाम: __________**

Select **मीरा** and copy it on the line. Read the completed field from label to
value. This is supported entry, not independent writing evidence.

## Writing — separate spelling and placement passes
<!-- hl-knowledge: introduces=[]; assesses=[HI-FORM-NAME-SUPPORTED-ENTRY-01] -->

First check only spelling: **मी | रा**. Then check one ordinary space after the
colon. If one dimension differs, repair that dimension and stop.
