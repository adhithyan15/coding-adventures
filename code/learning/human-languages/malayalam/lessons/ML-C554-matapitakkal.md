# മാതാപിതാക്കൾ (mātāpitākkaḷ) — parents

## You'll want to know: മാതാപിതാക്കൾ
<!-- hl-knowledge: introduces=[ML-LEX-C554-MATAPITA554-02]; assesses=[] -->

**മാതാപിതാക്കൾ** — *mātāpitākkaḷ* — "parents".

> എന്റെ മാതാപിതാക്കൾ ഗ്രാമത്തിലാണ് താമസിക്കുന്നത്.
>
> *enṟe mātāpitākkaḷ grāmattilāṇŭ tāmasikkunnatŭ.*
>
> My parents live in the village.

മാതാവ് mother + പിതാവ് father, with the plural -ക്കൾ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**മാതാപിതാക്കൾ** (*mātāpitākkaḷ*) is a Malayalam compound built from Sanskrit *mātṛ*, "mother", and *pitṛ*, "father" (Monier-Williams), with the plural ending -ക്കൾ.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
