# Six words, one small field

## Warm-up

<!-- hl-knowledge: introduces=[]; assesses=[SA-LEX-C269-MEDIA-01, SA-LEX-C269-MEDIA-02] -->

[PAUSE 2s each] Say “radio,” then “internet.”

## Guided Practice

<!-- hl-knowledge: introduces=[]; assesses=[SA-LEX-C222-THG222-05, SA-LEX-C104-THINGS104-05, SA-LEX-C269-MEDIA-01, SA-LEX-C105-THINGS105-01, SA-LEX-C269-MEDIA-02, SA-LEX-C120-THINGS120-03] -->

[PAUSE 3s each] Retrieve each word before checking:

- press: **पत्रिका** — *patrikā*
- telephone: **दूरभाषः** — *dūrabhāṣaḥ*
- radio: **आकाशवाणी** — *ākāśavāṇī*
- television: **दूरदर्शनम्** — *dūradarśanam*
- internet: **अन्तर्जालम्** — *antarjālam*
- letter or article: **लेखः** — *lekhaḥ*

## What you've built

<!-- hl-knowledge: introduces=[]; assesses=[SA-LEX-C222-THG222-05, SA-LEX-C104-THINGS104-05, SA-LEX-C269-MEDIA-01, SA-LEX-C105-THINGS105-01, SA-LEX-C269-MEDIA-02, SA-LEX-C120-THINGS120-03] -->

You can now distinguish six meanings in one compact lexical field. This is
word retrieval, not evidence that you can use devices, follow news, write
correspondence, broadcast, or navigate online.
