# ஞாபகம் (ñāpakam) — memory; recollection

## You'll want to know: ஞாபகம்
<!-- hl-knowledge: introduces=[TA-LEX-C504-MUTUMAI504-03]; assesses=[] -->

**ஞாபகம்** — *ñāpakam* — "memory; recollection".

> தாத்தாவுக்கு இப்போது ஞாபகம் குறைந்துவிட்டது.
>
> *tāttāvukku ippōtu ñāpakam kuṟaintuviṭṭatu.*
>
> Grandfather’s memory has weakened now.

ஞாபகம் இருக்கிறது, I remember.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ஞாபகம்** (*ñāpakam*) is borrowed from Sanskrit *jñāpaka*, "causing to know, informing" (Monier-Williams); Tamil writes *jñ* as ஞ.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
