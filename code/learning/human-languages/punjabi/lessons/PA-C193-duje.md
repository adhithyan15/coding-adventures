## Grammar Lens: direct owner
<!-- hl-knowledge: introduces=[PA-FORM-DUJE-ORDINAL-193]; assesses=[PA-LEX-DUJA-01, PA-LEX-C71-HOME71-01, PA-PLACE-KAMRE-ROOM-01, PA-POSTPOSITION-VICH-01] -->

> **ਦੂਜਾ ਕਮਰਾ** — *dūjā kamrā* — the second room

> **ਦੂਜੇ ਕਮਰੇ ਵਿੱਚ** — *dūje kamre vicc* — in the second room

The boundary stays narrow: the familiar direct ordinal changes from final
*-aa* to *-e* in this same masculine singular oblique room frame.
