# تحمل (taḥammala) — to put up with

## You'll want to know: تحمل
<!-- hl-knowledge: introduces=[AR-LEX-C495-INZIAJ495-04]; assesses=[] -->

**تحمل** — *taḥammala* — "to put up with".

> لا يتحمل أبي الحر.
>
> *lā yataḥammalu abī al-ḥarr.*
>
> My father cannot stand the heat.

Present: يتحمل, *yataḥammal*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**تحمل** (*taḥammala*) is built on the native Arabic root *ḥ-m-l*, "to carry" (Lane). Ḥamala, to carry, which you know, is from the same root; Form V is to carry a weight oneself.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
