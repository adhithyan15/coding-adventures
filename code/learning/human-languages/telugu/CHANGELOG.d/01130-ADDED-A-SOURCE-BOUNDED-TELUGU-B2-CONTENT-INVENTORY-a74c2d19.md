## Added — a source-bounded Telugu B2 content inventory

- Published 36 reviewable Telugu B2 content demands across communicative
  functions, grammar and register, script/sound/orthography, and lexicon and
  genre domains.
- Kept every dimension `partial` and all 36 complete demands unmapped. Existing
  foundation atoms are not promoted to complete B2 performances, so the
  inventory exposes work instead of manufacturing readiness.
- Bounded each claim to the source that can support it: the CEFR Companion
  Volume for generic B2 descriptors, CIIL intermediate Telugu L2 materials for
  a practice-and-testing boundary, Unicode for script encoding, official
  LDC-IL corpora for domains and documented speech collection, and the
  project-owned task shape for the assessment envelope.
- Added a level-owned five-test contract for source boundaries, stable IDs,
  four-dimension balance, task-genre coverage, and the conservative 0/36 first
  coverage measurement.

This inventory is not an external Telugu qualification, a finite Telugu B2
grammar or word list, a complete mock, calibration evidence, or a learner
attainment claim.
