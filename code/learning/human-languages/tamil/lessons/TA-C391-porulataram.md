# பொருளாதாரம் (poruḷātāram) — the economy

## You'll want to know: பொருளாதாரம்
<!-- hl-knowledge: introduces=[TA-LEX-C391-PORULATARAM391-01]; assesses=[] -->

**பொருளாதாரம்** — *poruḷātāram* — "the economy".

> மழை பெய்யாவிட்டால் நாட்டின் பொருளாதாரம் பாதிக்கப்படும்.
>
> *maḻai peyyāviṭṭāl nāṭṭiṉ poruḷātāram pātikkappaṭum.*
>
> If it does not rain, the country's economy will suffer.

பொருளாதார, economic, before a noun: பொருளாதார வளர்ச்சி, economic growth.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**பொருளாதாரம்** (*poruḷātāram*) is built from native *poruḷ*, "thing, wealth" (DEDR 4544), and *ātāram*, "support, basis", borrowed from Sanskrit *ādhāra* (CDIAL 1165): what wealth rests on.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
