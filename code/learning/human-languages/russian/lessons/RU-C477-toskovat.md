## You'll want to know: тосковать
<!-- hl-knowledge: introduces=[RU-LEX-C477-LONGING-02]; assesses=[] -->

**тосковать** (*toskovát*) — "to pine, to miss".

> Бабушка тоскует по деревне.
>
> *Bábushka toskúyet po derévne.*
>
> Grandma misses the village.

Imperfective; present тоскую, тоскуешь. *Тосковать по* + dative.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*тосковать* is built on *тоска* 'longing' with *-овать*; *тоска* is inherited from Proto-Slavic *tъska* (EtymDB).
