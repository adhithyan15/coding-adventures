## You'll want to know: le pétard
<!-- hl-knowledge: introduces=[FR-LEX-C318-ARTIFICE-02]; assesses=[] -->

**le pétard** — "the firecracker, the banger".

> Les enfants ont lancé des pétards dans la rue.
>
> *The children set off bangers in the street.*

Informal: *être en pétard* — to be furious.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*pétard* is built on *péter* "to go bang, to break wind" with the suffix *-ard* (EtymDB).
