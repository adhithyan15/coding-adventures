# आइए (āie) — please come (in)

## You'll want to know: आइए
<!-- hl-knowledge: introduces=[HI-LEX-C115-COMEIN-01]; assesses=[] -->

**आइए** (*āie*) — "please come", "come in".

It is **आना**, "to come", with the respectful **-इए**. **आइए, आइए!** — doubled, it is a
warm welcome at the door.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

A welcome at the door.
