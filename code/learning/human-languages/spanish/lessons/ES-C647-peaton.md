## You'll want to know: el peatón
<!-- hl-knowledge: introduces=[ES-LEX-C647-CRUZAR-04]; assesses=[] -->

**el peatón** — "the pedestrian".

> Los peatones tienen prioridad.
>
> *Pedestrians have priority.*

*El paso de peatones* — the pedestrian crossing.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*peatón* was borrowed from French *piéton* (EtymDB), built on *pied* "foot", which comes from Latin *pēs, pedis*.
