# పెట్టుబడి (peṭṭubaḍi) — an investment; capital

## You'll want to know: పెట్టుబడి
<!-- hl-knowledge: introduces=[TE-LEX-C405-ARTHIKA405-03]; assesses=[] -->

**పెట్టుబడి** — *peṭṭubaḍi* — "an investment; capital".

> అతను కొత్త దుకాణంలో పెట్టుబడి పెట్టాడు.
>
> *atanu kotta dukāṇaṁlō peṭṭubaḍi peṭṭāḍu.*
>
> He invested in a new shop.

పెట్టుబడి పెట్టు, to invest; the first part is పెట్టు, to put.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**పెట్టుబడి** (*peṭṭubaḍi*) is native Telugu, built on *peṭṭu*, "to put, to place"; the origin of the second part, -బడి, is uncertain.
