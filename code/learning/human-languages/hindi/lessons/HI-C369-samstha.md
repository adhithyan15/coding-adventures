## You'll want to know: संस्था
<!-- hl-knowledge: introduces=[HI-LEX-C369-SANSTHA369-03]; assesses=[] -->

**संस्था** — *saṁsthā* — "an institution, an organisation".

> यह संस्था ग़रीब बच्चों को पढ़ाती है।
>
> *yah saṁsthā ġarīb baccoṁ ko paṛhātī hai.*
>
> This organisation teaches poor children.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**संस्था** (*saṁsthā*) is a tatsama, borrowed from Sanskrit *saṃsthā*, "a standing; an establishment" (Monier-Williams).
