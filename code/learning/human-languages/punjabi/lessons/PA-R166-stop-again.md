# An old word for stopping

First retrieve **to stop** alone. Then hear three familiar actions in a small
shuffled mix. Pause before each model. This is not a scored mock.

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-C152-ACT152-03] -->

Hear **to stop**. [PAUSE 4s] Recall **ਰੁਕਣਾ** (*rukṇā*).

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-C152-ACT152-01, PA-LEX-C152-ACT152-02, PA-LEX-C152-ACT152-03] -->

Pause after each familiar meaning, then hear its model:

- **to wander, to go around** — [PAUSE 4s] **ਘੁੰਮਣਾ** (*ghummṇā*).
- **to stop** — [PAUSE 4s] **ਰੁਕਣਾ** (*rukṇā*).
- **to run** — [PAUSE 4s] **ਭੱਜਣਾ** (*bhajjṇā*).

Only the order of these old words has changed.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-C152-ACT152-01, PA-LEX-C152-ACT152-02, PA-LEX-C152-ACT152-03] -->

Hear **to stop**, **to run**, then **to wander**. Pause after each cue and
recall its Punjabi word before the model: **ਰੁਕਣਾ**, **ਭੱਜਣਾ**, **ਘੁੰਮਣਾ**.
Revisit only the old word you missed.
