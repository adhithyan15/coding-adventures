# ਬੰਨ੍ਹਣਾ (bannhṇā) — to tie

## You'll want to know: ਬੰਨ੍ਹਣਾ
<!-- hl-knowledge: introduces=[PA-LEX-C229-DIN229-02]; assesses=[] -->

**ਬੰਨ੍ਹਣਾ** — *bannhṇā* — "to tie".

> ਮੈਂ ਰੱਸੀ ਨਾਲ ਡੱਬਾ ਬੰਨ੍ਹਦੀ ਹਾਂ।
>
> *maiṁ rassī nāl ḍabbā bannhdī hāṁ.*
>
> I tie up the box with a rope.

Past (I …): ਮੈਂ ਗੰਢ ਬੰਨ੍ਹੀ, *maiṁ gaṇḍh bannhī*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ਬੰਨ੍ਹਣਾ** (*bannhṇā*) is inherited from Sanskrit *bandhati*, "binds"; CDIAL lists Punjabi *bannhṇā*, "to tie, bind" (CDIAL 9139).
