# উৎসব (utsôb) — a festival

## You'll want to know: উৎসব
<!-- hl-knowledge: introduces=[BN-LEX-C304-UTSOB304-01]; assesses=[] -->

**উৎসব** — *utsôb* — "a festival".

> এই গ্রামে বসন্তে একটা বড় উৎসব হয়।
>
> *ei grāme bôsônte ekṭā bôṛo utsôb hôy.*
>
> There is a big festival in this village in spring.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**উৎসব** (*utsôb*) is Sanskrit *utsava*, first 'an undertaking, a beginning' and then 'a festival' (Monier-Williams).
