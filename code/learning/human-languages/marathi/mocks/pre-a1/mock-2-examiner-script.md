# Marathi pre-A1 mock 2 — examiner script

Keep this file away from the learner. It supplies word cards, listening lines,
and speaking prompts; it is not evidence that a recording or qualified speaker
exists. Read every listening item twice at 70–90 words per minute, then leave
an eight-second answer pause. A technical restart replaces the affected item;
it does not create a learner-selected third play.

Use a timed stimulus window for every rendition. For listening items 1–6, put
the naturally spoken word inside one 2–5 second window; silence may complete
the window, but do not repeat the word within it. For listening items 7–14,
put the naturally spoken phrase inside one 2–8 second window. For dictation
items W3–W6, use one 2–5 second window per rendition under the same rule. In
speaking, deliver each prompt in 2–8 seconds and allow a 2–15 second response
window; close the window when a completed response has lasted at least two
seconds, or at fifteen seconds. One slow prompt repetition is the single replay
declared by the task shape.

## Listening

Read only the bold Marathi for the numbered item.

1. **दूध**
2. **चहा**
3. **भाकरी**
4. **मित्र**
5. **मराठी**
6. **कृपया**
7. **नमस्कार.**
8. **भेटून आनंद झाला.**
9. **चहा, कृपया.**
10. **उद्या भेटू.**
11. **माझं नाव अरुण आहे.**
12. **मी मराठी बोलतो.**
13. **माझं नाव मीरा आहे.**
14. **मी बरी आहे.**

## Writing

Show each delayed-recall card for ten seconds, cover it fully, and only then
allow the learner to write. Read each dictation item twice without showing it.

1. Card: **पुस्तक**
2. Card: **शाळा**
3. Dictation W3: **दूध**
4. Dictation W4: **चहा**
5. Dictation W5: **मित्र**
6. Dictation W6: **कृपया**
7. Show one nonverbal drink cue for water, tea, or milk. Record which cue was
   used; do not supply a Marathi word model.
8. Give the nonverbal tomorrow-farewell cue; do not supply a Marathi model.

## Speaking

Read each prompt once. One slow repetition is allowed after a request.

1. **नमस्कार.**
2. **तुमचं नाव काय आहे?**
3. Show tea and milk cues and ask: **चहा की दूध?**
4. **तुम्हाला मराठी येते का?**
5. **तुम्ही कुठे राहता?**
6. Show the nonverbal tea cue and say in the support language only: “Ask for
   this politely in Marathi.” Do not supply a Marathi answer model.
