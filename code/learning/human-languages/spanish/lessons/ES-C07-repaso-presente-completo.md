# Review — the whole thing, at last

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ES-GRAMMAR-AR-PRESENT-1PL, ES-GRAMMAR-AR-PRESENT-3PL] -->

[PAUSE 2s] Nothing new in this chapter. Say "we speak", then "they speak."

## Grammar Lens: the table this book has been withholding
<!-- hl-knowledge: introduces=[ES-GRAMMAR-AR-PRESENT-COMPLETE]; assesses=[ES-GRAMMAR-AR-PRESENT-SINGULAR, ES-GRAMMAR-AR-PRESENT-1PL, ES-GRAMMAR-AR-PRESENT-2PL, ES-GRAMMAR-AR-PRESENT-3PL, ES-LEX-VOSOTROS, ES-LEX-USTEDES] -->

Six forms. Every one of them built separately, on its own, in its own lesson.

| who | *hablar* → |
|---|---|
| yo | **hablo** |
| tú | **hablas** |
| él · ella · usted | **habla** |
| nosotros | **hablamos** |
| vosotros *(Spain)* | **habláis** |
| ellos · ellas · ustedes | **hablan** |

Most Spanish courses open with this table. This one has spent thirty-two
chapters refusing to show it, because a table you cannot yet fill is a picture
of work still to do, and a table you can fill is a picture of ground you hold.

Read it now and there should be no surprises in it. That is the point.

**And it is not one verb.** Every regular *-ar* verb in Spanish — thousands of
them — runs on these six endings, so this table is the present tense of a large
part of the language.

## Wrap-up Recall
