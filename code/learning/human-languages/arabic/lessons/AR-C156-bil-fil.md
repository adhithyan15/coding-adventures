## You'll want to know: بالفعل
<!-- hl-knowledge: introduces=[AR-LEX-C156-MADI156-02]; assesses=[] -->

**بالفعل** — *bi-l-fiʿl* — "already; indeed". With the past: **أكلت بالفعل** — *akaltu bi-l-fiʿl* — "I have already eaten."
