# குத்துவிளக்கு (kuttuviḷakku) — a standing lamp

## You'll want to know: குத்துவிளக்கு
<!-- hl-knowledge: introduces=[TA-LEX-C318-VIZHA318-02]; assesses=[] -->

**குத்துவிளக்கு** — *kuttuviḷakku* — "a standing lamp".

> விழா குத்துவிளக்கு ஏற்றித் தொடங்கியது.
>
> *viḻā kuttuviḷakku ēṟṟit toṭaṅkiyatu.*
>
> The ceremony began with the lighting of the standing lamp.

குத்துவிளக்கு ஏற்று, to light the lamp, opens many functions.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**குத்துவிளக்கு** (*kuttuviḷakku*) is a Tamil compound built from குத்து, "to set upright, fix in the ground" (DEDR 1720), and விளக்கு, "a lamp".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
