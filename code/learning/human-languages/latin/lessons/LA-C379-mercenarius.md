## You'll want to know: mercēnārius, mercēnāriī
<!-- hl-knowledge: introduces=[LA-LEX-C379-QUAESTUS-03]; assesses=[] -->

**mercēnārius, mercēnāriī** — "a hired worker; a mercenary".

> Mercēnāriī prō mercēde labōrant.
>
> *Hired men work for a wage.*

*mercēnārius, mercēnāriī* m. (also spelled *mercennārius*), built on *mercēs*, a wage. As an adjective, hired. English *mercenary*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*mercēnārius* is built on *mercēs, mercēdis* "wages, hire" (Lewis & Short), which belongs with *merx* "goods". English *mercenary* comes from it.
