# Changelog

All notable changes to this package will be documented in this file.

## [0.1.0] - 2026-10-29

### Added

- Bounded construction and prefix decoding for one borrowed TLS 1.3
  `KeyShareEntry`.
- Failure-atomic encoding of exact group, length, and key-exchange bytes.
- Caller-selected payload limits, opaque diagnostics, and zero external
  effects.
