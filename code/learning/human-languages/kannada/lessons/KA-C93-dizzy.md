# ತಲೆಸುತ್ತು (talesuttu) — dizziness

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C92-WORK-04, KA-LEX-C92-WORK-05] -->

[PAUSE 2s] Before the new one: say the Kannada for a job, then the Kannada for English.

## You'll want to know: ತಲೆಸುತ್ತು
<!-- hl-knowledge: introduces=[KA-LEX-C93-WEATHER-01]; assesses=[] -->

**ತಲೆಸುತ್ತು** (*talesuttu*) — "dizziness", literally "head-spinning": **ತಲೆ**
(*tale*), "head", with **ಸುತ್ತು** (*suttu*), "to go round".

**ನನಗೆ ತಲೆಸುತ್ತು** (*nanage talesuttu*) — "I feel dizzy", built like **ನನಗೆ ತಲೆನೋವು**.
