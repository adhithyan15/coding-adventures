## You'll want to know: 前往
<!-- hl-knowledge: introduces=[ZH-LEX-C428-MOVEON428-02]; assesses=[] -->

**前往** — *qiánwǎng* — "to set out for a place".

> **前往机场的旅客请上车** *qiánwǎng jīchǎng de lǚkè qǐng shàng chē* — Passengers for the airport, please get on.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**前往** (*qiánwǎng*) is built from 前 'forward' and 往 'to go', both inherited from Middle Chinese, *dzen* and *hjwangX* (Guangyun, in Baxter's transcription), which glosses the first 'before'.
