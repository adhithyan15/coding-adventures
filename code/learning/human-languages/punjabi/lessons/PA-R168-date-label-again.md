# The old date label, once more

This is a gentle return to one familiar field on a fictional form. No real
personal date is needed, and this is not a scored writing mock.

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-LABEL-DATE-01] -->

Look at **ਤਾਰੀਖ਼:** (*tārīkh*). Recall that it labels the **date** line, not
an age or phone line. The blank after it is for a date.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-LABEL-DATE-01] -->
<!-- hl-writing-stage: guided-copy -->

Trace **ਤਾਰੀਖ਼:** with a finger, then copy only the label and its colon once.
Leave the value blank. Compare one mark at a time with the visible model.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-LABEL-DATE-01] -->

Cover the model. Which familiar label asks for a date? Write **ਤਾਰੀਖ਼:**,
then uncover and repair one mark if needed. This is retrieval practice,
not a scored form submission.
