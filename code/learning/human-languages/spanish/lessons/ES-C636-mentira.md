## You'll want to know: la mentira
<!-- hl-knowledge: introduces=[ES-LEX-C636-VERDAD-02]; assesses=[] -->

**la mentira** — "the lie".

> Eso es mentira.
>
> *That is a lie.*

*Parece mentira* — it is hard to believe.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*mentira* is built on *mentir*, inherited from Latin *mentiri* 'to lie' (EtymDB).
