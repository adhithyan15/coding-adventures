# सन्तुष्टः (santuṣṭaḥ) — satisfied; contented

## You'll want to know: सन्तुष्टः
<!-- hl-knowledge: introduces=[SA-LEX-C546-VIPAKA546-01]; assesses=[] -->

**सन्तुष्टः** — *santuṣṭaḥ* — "satisfied; contented".

> यदि परिणामः शुभः अस्ति, तर्हि पिता सन्तुष्टः भवति।
>
> *yadi pariṇāmaḥ śubhaḥ asti, tarhi pitā santuṣṭaḥ bhavati.*
>
> If the result is good, father is satisfied.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**सन्तुष्टः** (*santuṣṭaḥ*) is built on *sam*, "fully", and *tuṣṭa*, "pleased", the past participle of the root √tuṣ, "to be pleased", which also gives *tuṣyati*; MW gives *saṃtuṣṭa* as quite satisfied, contented, well pleased (MW).
