## You'll want to know: el comienzo
<!-- hl-knowledge: introduces=[ES-LEX-C542-COMIENZO-03]; assesses=[] -->

**el comienzo** — "the beginning, the start".

> El comienzo del libro es muy lento.
>
> *The beginning of the book is very slow.*

*Al comienzo* — at the beginning.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*comienzo* is built on *comenzar* (EtymDB), which comes from spoken Latin *\*cominitiāre*, from *initium* 'a beginning'.
