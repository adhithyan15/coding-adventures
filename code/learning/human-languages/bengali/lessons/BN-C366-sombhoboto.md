# সম্ভবত (sômbhôbôtô) — probably

## You'll want to know: সম্ভবত
<!-- hl-knowledge: introduces=[BN-LEX-C366-SOMBHABONA366-02]; assesses=[] -->

**সম্ভবত** — *sômbhôbôtô* — "probably".

> অরুণ যদি বাস না পায়, তাহলে সম্ভবত দেরি করবে।
>
> *ôrun jôdi bās nā pāy, tāhôle sômbhôbôtô deri kôrbe.*
>
> If Arun doesn't get a bus, he will probably be late.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**সম্ভবত** (*sômbhôbôtô*) is Sanskrit *sambhava*, arising or possible (Monier-Williams), with the adverb ending *-tas*, in its Bengali form: 'in all likelihood'. It sits beside the taught সম্ভব.
