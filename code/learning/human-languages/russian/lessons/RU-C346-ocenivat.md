## You'll want to know: оценивать
<!-- hl-knowledge: introduces=[RU-LEX-C346-PLYUSY-05]; assesses=[] -->

**оценивать** (*otsénivat*) — "to assess, to evaluate".

> Учитель оценивает работу каждого ученика.
>
> *Uchítel otsénivayet rabótu kázhdogo ucheniká.*
>
> The teacher assesses each pupil’s work.

Imperfective; perfective *оценить*. Built on *цена*, price: to put a price on.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**оценивать** is built from *о-* and *цена* "price", inherited from Proto-Slavic *\*cěna*; to assess a thing is to put a price on it.
