# दस — ten on the page

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-KHA-01, MW-SCRIPT-NO-NINE-01] -->

[PAUSE 16s] Write **ख**, then write nine.

## You'll want to know
<!-- hl-knowledge: introduces=[MW-SCRIPT-DAS-01]; assesses=[MW-SCRIPT-DA-01, MW-SCRIPT-SA-01, MW-SCRIPT-DO-TWO-01, MW-SCRIPT-SAAT-01, MW-LEX-DAS-01] -->

> **द** + **स** → **दस** — *das* — ten

Bare consonants. No mark rides above the line and none hangs below it, because
the vowel between them is the short *a* that every Devanagari consonant carries
without being told.

The **द** is two's; the **स** is seven's. Ten is written out of pieces the hand
already made for other numbers.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-DAS-01, MW-SCRIPT-DO-TWO-01] -->
<!-- hl-writing-stage: delayed-copy -->

Look at **दस**, cover it, wait five seconds, write it. Then write **दो** beside
it and say what the mark on the second one does to the vowel.
