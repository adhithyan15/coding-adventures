# शुभकामनाएँ (śubhkāmnāẽ) — good wishes

## You'll want to know: शुभकामनाएँ
<!-- hl-knowledge: introduces=[HI-LEX-C114-SORRY-04]; assesses=[] -->

**शुभकामनाएँ** (*śubhkāmnāẽ*) — "good wishes".

It opens on the **शुभ** of **शुभ रात्रि**, "auspicious". **आपको शुभकामनाएँ** — "good wishes to
you".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

Wishes for what is coming, beside congratulations for what is done.
