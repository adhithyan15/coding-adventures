# ಒಮ್ಮತ (ommata) — a consensus

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C379-OMMATA379-01, KA-LEX-C379-OMMATA379-02] -->

[PAUSE 2s] Before the new one: say the Kannada for to consent, then the Kannada for a difference of opinion.

## You'll want to know: ಒಮ್ಮತ
<!-- hl-knowledge: introduces=[KA-LEX-C379-OMMATA379-03]; assesses=[] -->

**ಒಮ್ಮತ** — *ommata* — "a consensus".

> ಕೊನೆಗೆ ಎಲ್ಲರಲ್ಲೂ ಒಮ್ಮತ ಮೂಡಿತು.
>
> *konege ellarallū ommata mūḍitu.*
>
> At last a consensus formed among everyone.

ಒಮ್ಮತದಿಂದ, unanimously.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಒಮ್ಮತ** (*ommata*) is built from the native base for "one", *or-* / *om-* (DEDR 990), joined to Sanskrit *mata*, "an opinion" (Monier-Williams): one opinion.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
