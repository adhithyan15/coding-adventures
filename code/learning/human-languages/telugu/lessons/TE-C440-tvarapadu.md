# త్వరపడు (tvarapaḍu) — to hurry up

## You'll want to know: త్వరపడు
<!-- hl-knowledge: introduces=[TE-LEX-C440-ALASYAM440-05]; assesses=[] -->

**త్వరపడు** — *tvarapaḍu* — "to hurry up".

> బస్సు వస్తోందని మేము త్వరపడ్డాం.
>
> *bassu vastōndani mēmu tvarapaḍḍāṁ.*
>
> Hearing that the bus was coming, we hurried.

Past (I …): త్వరపడ్డాను, *tvarapaḍḍānu*.

త్వరగా, quickly, holds the same Sanskrit word. తొందరపడు is its everyday native twin.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**త్వరపడు** (*tvarapaḍu*) is a Telugu compound: Sanskrit *tvarā*, "haste" (Monier-Williams), with the native verb పడు, "to fall into, to undergo" (DEDR 3853).
