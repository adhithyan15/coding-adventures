# ಶ್ರದ್ಧೆ (śraddhe) — dedication; devotion

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C504-MATU504-04, KA-LEX-C504-MATU504-05] -->

[PAUSE 2s] Before the new one: say the Kannada for a coward, then the Kannada for a stammer.

## You'll want to know: ಶ್ರದ್ಧೆ
<!-- hl-knowledge: introduces=[KA-LEX-C505-SHRADDHE505-01]; assesses=[] -->

**ಶ್ರದ್ಧೆ** — *śraddhe* — "dedication; devotion".

> ಅವಳು ಶ್ರದ್ಧೆಯಿಂದ ಸಂಗೀತ ಕಲಿಯುತ್ತಾಳೆ.
>
> *avaḷu śraddheyinda saṅgīta kaliyuttāḷe.*
>
> She learns music with dedication.

ಶ್ರದ್ಧೆಯಿಂದ, wholeheartedly.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಶ್ರದ್ಧೆ** (*śraddhe*) is borrowed from Sanskrit *śraddhā*, "trust, faith" (CDIAL 12678); in Kannada it is steady devotion to a task.
