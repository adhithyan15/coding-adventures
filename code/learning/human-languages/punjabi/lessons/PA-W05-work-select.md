# Select one known work value

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-LABEL-WORK-01, PA-FORM-WORK-FARMING-01, PA-FORM-WORK-JOB-01] -->

Read the closed practice bank once:

> A — **ਖੇਤੀ**
>
> B — **ਨੌਕਰੀ**

## Script — attach one cue to each value
<!-- hl-knowledge: introduces=[PA-FORM-WORK-CUE-MAP-01]; assesses=[PA-FORM-WORK-FARMING-01, PA-FORM-WORK-JOB-01] -->

Point to A, then **ਖੇਤੀ**. Point to B, then **ਨੌਕਰੀ**. Cover the bank and say which value B requests. Selection is separate from spelling.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-WORK-CUE-MAP-01] -->

Reveal, point, cover, and select once more. Do not write the form line yet.
