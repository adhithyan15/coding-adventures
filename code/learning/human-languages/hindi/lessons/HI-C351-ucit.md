# उचित (ucit) — proper, fitting

## You'll want to know: उचित
<!-- hl-knowledge: introduces=[HI-LEX-C351-ADHIKAR351-04]; assesses=[] -->

**उचित** — *ucit* — "proper, fitting".

> यह सवाल पूछना उचित नहीं है।
>
> *yah savāl pūchnā ucit nahīṃ hai.*
>
> It isn't proper to ask this question.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**उचित** (*ucit*) is a tatsama, borrowed from Sanskrit *ucita*, "suitable, proper" (Monier-Williams).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
