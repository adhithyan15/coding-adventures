# ಸಬಲೀಕರಣ (sabalīkaraṇa) — empowerment

## You'll want to know: ಸಬಲೀಕರಣ
<!-- hl-knowledge: introduces=[KA-LEX-C391-SAMANATE391-04]; assesses=[] -->

**ಸಬಲೀಕರಣ** — *sabalīkaraṇa* — "empowerment".

> ಮಹಿಳೆಯರ ಸಬಲೀಕರಣಕ್ಕೆ ಶಿಕ್ಷಣ ಮುಖ್ಯ.
>
> *mahiḷeyara sabalīkaraṇakke śikṣaṇa mukhya.*
>
> Education is key to women's empowerment.

ಸಬಲ (strong) + -ಈಕರಣ (making).

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಸಬಲೀಕರಣ** (*sabalīkaraṇa*) is a modern word built on Sanskrit *sabala*, "powerful, strong" (Monier-Williams), with -*īkaraṇa*, "making into": making strong.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
