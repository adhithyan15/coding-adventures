# ಸಿಗುತ್ತೇನೆ (siguttēne) — I'll see you

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C106-SOON-03, KA-LEX-C106-SOON-04] -->

[PAUSE 2s] Before the new one: say the Kannada for later, then the Kannada for please phone.

## You'll want to know: ಸಿಗುತ್ತೇನೆ
<!-- hl-knowledge: introduces=[KA-LEX-C106-SOON-05]; assesses=[] -->

**ಸಿಗುತ್ತೇನೆ** (*siguttēne*) — "I'll see you", literally "I will be met". It is the
same verb as **ಸಿಗೋಣ** (*sigōṇa*), "let's meet".

**ನಾಳೆ ಸಿಗುತ್ತೇನೆ** (*nāḷe siguttēne*) — "I'll see you tomorrow".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

The last word of the tranche: a promise to meet.
