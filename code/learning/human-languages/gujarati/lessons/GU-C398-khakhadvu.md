# ખખડવું (khakhaḍvũ) — to rattle

## You'll want to know: ખખડવું
<!-- hl-knowledge: introduces=[GU-LEX-C398-DOZE398-05]; assesses=[] -->

**ખખડવું** — *khakhaḍvũ* — "to rattle".

> જૂની બારી આખો દિવસ ખખડતી હતી.
>
> *jūnī bārī ākho divas khakhaḍtī hatī.*
>
> The old window rattled all day.

Past (it …): તે બારી ખખડી, *te bārī khakhḍī*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ખખડવું** (*khakhaḍvũ*) sounds like the noise it names. CDIAL lists a Gujarati verb of the same kind, *khaṛkhaṛvũ*, "to rattle", under Sanskrit *khaṭakhaṭāyatē*, "crackles" (CDIAL 3771), beside Hindi *khaṛkhaṛānā* and Marathi *khaḍkhaḍṇẽ*; it gives no form for ખખડવું itself, so the link is hedged.
