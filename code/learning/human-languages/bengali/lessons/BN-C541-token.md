# টোকেন (ṭoken) — a queue token

## You'll want to know: টোকেন
<!-- hl-knowledge: introduces=[BN-LEX-C541-PROTIKSHA541-04]; assesses=[] -->

**টোকেন** — *ṭoken* — "a queue token".

> টোকেন না নিলে ব্যাংকে কেউ তোমাকে ডাকবে না।
>
> *Ṭoken nā nile bængke keu tomāke ḍākbe nā.*
>
> If you don't take a token, no one at the bank will call you.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**টোকেন** (*ṭoken*) is borrowed from English *token*.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
