# Changelog

All notable changes to `ias-simulator` are documented here.

## 0.1.0 — 2026-10-24

- Added the complete 21-operation IAS order set and the documented stop order.
- Added 4,096 checked 40-bit words, paired left/right order fetch, buffered
  self-modification behavior, complement arithmetic, signed multiply/divide,
  partial address stores, shifts, and conditional control transfer.
- Added five-byte big-endian transport, deep snapshots, checked restoration,
  typed atomic faults, transactional bounded execution, and complete traces.
