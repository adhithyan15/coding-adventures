## You'll want to know: മിനിറ്റ്
<!-- hl-knowledge: introduces=[ML-LEX-C139-TIME-02]; assesses=[] -->

**മിനിറ്റ്** (*miniṟṟŭ*) — "a minute", from English. **ഒരു മിനിറ്റ്** — "one minute",
said with a raised hand.

## What you've built

The polite way to ask for a moment.
