# Changelog

All notable changes to this package will be documented here.

## [0.1.0] - 2026-11-28

### Added

- ISO C++17, standard-library-only implementations of HTTP/0.9 request
  encoding/parsing and ASCII response decoding.
- An HTML Tags 1992 scanner with UTF-8 validation, archived entity decoding,
  implied end tags, raw text, comments, and deterministic malformed-markup
  recovery.
- A flat index-linked HTML arena with owning strings, ordered attributes,
  typed profile errors, and iterative construction/destruction.
- Documentation that compares the 1992 archive with XML's explicit tag rules
  and the repository's WHATWG-oriented HTML builder.
