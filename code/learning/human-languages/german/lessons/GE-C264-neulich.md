## You'll want to know: neulich
<!-- hl-knowledge: introduces=[GE-LEX-C264-DAMALS-03]; assesses=[] -->

**neulich** — "the other day, recently".

> Neulich habe ich meine alte Freundin getroffen.
>
> *The other day I met my old friend.*

Conversational; for one event a short time ago, usually with the *Perfekt*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*neulich* is built on *neu* "new", an inherited Germanic word, with the ending *-lich*: newly, lately. EtymDB lists no parent for the adverb itself.
