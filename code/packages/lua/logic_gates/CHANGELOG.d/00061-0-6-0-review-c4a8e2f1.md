## [0.6.0] - review follow-up

### Fixed

- The private kit is unreachable: `internal.lua` is now a factory (each call
  builds an unrelated kit with its own registry); `gates.lua` builds one kit,
  hands it once to the `sequential_impl` factory, and every consumer binds
  helpers and constants to load-time locals. `claim` is gone.
  `coding_adventures.logic_gates.sequential` now returns the instance built by
  `gates.lua`.
- CMOS `evaluate_digital` functions are captured at load and called through a
  captured `pcall`; errors, error returns and results other than integer 0/1
  raise a structured `INTERNAL` error.

### Documented

- The `transistors` package remains inside the trust boundary; use
  `error_code()` / `is_*` (rawset can shadow `err.code`).
- BUILD pins luacov 0.17.0.
