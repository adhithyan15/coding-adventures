# புரியவில்லை (puriyavillai) — I don't understand

## You'll want to know: புரியவில்லை
<!-- hl-knowledge: introduces=[TA-LEX-C94-LOST-01]; assesses=[] -->

**புரியவில்லை** (*puriyavillai*) — "I don't understand", literally "it did not become clear".

The most useful sentence a learner owns. It also ends in **இல்லை**.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

The honest sentence every learner needs.
