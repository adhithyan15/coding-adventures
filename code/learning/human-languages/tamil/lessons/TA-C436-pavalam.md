# பவளம் (pavaḷam) — coral

## You'll want to know: பவளம்
<!-- hl-knowledge: introduces=[TA-LEX-C436-KATAL436-05]; assesses=[] -->

**பவளம்** — *pavaḷam* — "coral".

> கடலுக்கு அடியில் பவளப் பாறைகள் இருக்கின்றன.
>
> *kaṭalukku aṭiyil pavaḷap pāṟaikaḷ irukkiṉṟaṉa.*
>
> There are coral reefs under the sea.

பவளப் பாறை is a coral reef.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**பவளம்** (*pavaḷam*) is native Dravidian (DEDR 3998), "red coral".
