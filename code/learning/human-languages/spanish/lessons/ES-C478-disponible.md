## You'll want to know: disponible
<!-- hl-knowledge: introduces=[ES-LEX-C478-MALETA-05]; assesses=[] -->

**disponible** — "available".

> La habitación está disponible desde el lunes.
>
> *The room is available from Monday.*

Used with *estar*.
