## You'll want to know: تبادل
<!-- hl-knowledge: introduces=[AR-LEX-C479-TAZALLUJ479-04]; assesses=[] -->

**تبادل** — *tabādala* — "to exchange (with each other)".

> تبادلنا العناوين في نهاية الرحلة.
>
> *tabādalnā al-ʿanāwīn fī nihāyat ar-riḥla.*
>
> We exchanged addresses at the end of the trip.

Present: يتبادل, *yatabādal*.

Form VI makes the action mutual: each gives to the other.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**تبادل** (*tabādala*) is built on the native Arabic root *b-d-l*, "to change, to replace" (Lane). It is Form VI.
