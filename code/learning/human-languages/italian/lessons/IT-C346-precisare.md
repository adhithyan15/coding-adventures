## You'll want to know: precisare
<!-- hl-knowledge: introduces=[IT-LEX-C346-MALINTESO-04]; assesses=[] -->

**precisare** — "to specify, to make clear (a detail)".

> Voglio precisare che non è colpa mia.
>
> *I want to make clear that it is not my fault.*

*Ci tengo a precisare che* — I want to point out that. Built on *preciso* "precise".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*precisare* is built on *preciso* "precise", a learned borrowing from Latin *praecīsus* "cut off, abrupt" (Lewis & Short), from *praecīdere* "to cut off in front", built on *caedere* "to cut": what is left after cutting away the extra.
