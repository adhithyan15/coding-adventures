## 0.1.0 - pbt-v1 conformance

First release of the Go test-bootstrap module (spec:
`code/specs/VER05d-go-pbt-engine.md`). Go previously had no test bootstrap,
property engine or fuzz engine.

### Added
- `prng`: `SplitMix64`, `Bounded` (rejection sampling; `Bounded(1)` consumes one
  word), `BoundedBig` (k-word rejection for spans above 2^64), `FNV1a64`,
  `SubSeed` (VER05 section 2.3, with the final `NextU64` scramble). Pinned
  against vectors from the independent Python reference. Shared by the fuzz
  engine and TF01 runner that will follow.
- `pbt`: generator algebra with Go generics (`Gen[T]`, `Map`, `Filter`/`FilterN`,
  `FlatMap`, `OneOf`, `Frequency`, `List`, `Tuple2`/`Tuple3`, `Bool`, `U8`, `U64`,
  `I128`, `Int`, `Int64`, `Bytes`, `Constant`); integrated shrinking
  (`ShrinkInt`, `ShrinkList`, `ShrinkBytes`) returning `(minimal, steps)` that
  match the corpus exactly; `SimulateReplay`.
- `pbt.CheckProperty` with VER05 7.1 verdict honesty (zero cases is
  `property-exhausted`; the shrunk witness is re-verified; generator error or
  panic is exhausted; property panic is `property-panic`), the closed failure
  vocabulary (`IsPBTFailureID`), CI redaction (default on, `CIFromLookup` pure
  helper, no environment access), and a total, depth- and node-bounded witness
  encoder `Canon`.
- Integers are `*big.Int` (no native 128-bit integer), correct over the full
  i128 range and beyond.
- `pbt.ParseCorpus` / `EvaluateCorpus`: strict JSON decoding (duplicate keys,
  trailing data, depth refused), canonical ints and lowercase hex, CWE-400 caps,
  non-string ids as problems, and a case-count gate (25).
- `tfv`: strict TFV v1 validator so `corpus_reject` cases are checked by a real
  parser.
- `tools/covergate`: per-package coverage gate (95%) usable on Windows.
- Tests: all 25 `pbt-v1` cases from the committed fixture, negative controls for
  every op (corrupted steps, minimals, outputs, failure ids, accepted reject
  text), truncated and unknown-op corpora, hostile sizes, engine sabotage
  through unexported hooks, lying and panicking shrinkers, CI redaction, hostile
  witnesses, 1-minimality over 341 lists, and monotone-threshold shrinking for
  every threshold 1..120 in both signs.
