## You'll want to know: मुमकिन
<!-- hl-knowledge: introduces=[HI-LEX-C373-MUMKIN373-01]; assesses=[] -->

**मुमकिन** — *mumkin* — "possible".

> अगर हम जल्दी निकलेंगे तो दोपहर तक पहुँचना मुमकिन है।
>
> *agar ham jaldī nikleṅge to dopahar tak pahũcnā mumkin hai.*
>
> If we leave early, we can get there by noon.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**मुमकिन** (*mumkin*) is usually traced to Arabic *mumkin*, "possible", which reached Hindi through Persian.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
