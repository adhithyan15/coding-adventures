# എണ്ണിനോക്കുക (eṇṇinōkkuka) — to count and check

## You'll want to know: എണ്ണിനോക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C494-BILL494-04]; assesses=[] -->

**എണ്ണിനോക്കുക** — *eṇṇinōkkuka* — "to count and check".

> കടക്കാരൻ തന്ന ബാക്കി ഞാൻ എണ്ണിനോക്കി.
>
> *kaṭakkāran tanna bākki ñān eṇṇinōkki.*
>
> I counted the change the shopkeeper gave me.

Past: എണ്ണിനോക്കി, *eṇṇinōkki*.

എണ്ണി, having counted, plus നോക്കുക: to count to make sure.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**എണ്ണിനോക്കുക** (*eṇṇinōkkuka*) is a native Dravidian compound of എണ്ണുക, to count (DEDR 793), and നോക്കുക, to look (DEDR 3794).
