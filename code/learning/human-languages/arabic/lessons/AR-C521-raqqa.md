## You'll want to know: رقى
<!-- hl-knowledge: introduces=[AR-LEX-C521-MUKAFAA521-04]; assesses=[] -->

**رقى** — *raqqā* — "to promote".

> رقى المدير زميلي.
>
> *raqqā al-mudīr zamīlī.*
>
> The manager promoted my colleague.

Present: يرقي, *yuraqqī*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**رقى** (*raqqā*) is built on the native Arabic root *r-q-y*, "to go up, to climb" (Lane). Form II raqqā is to make someone go up.
