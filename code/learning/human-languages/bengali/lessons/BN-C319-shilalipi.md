# শিলালিপি (shilālipi) — an inscription (on stone)

## You'll want to know: শিলালিপি
<!-- hl-knowledge: introduces=[BN-LEX-C319-PURATON319-04]; assesses=[] -->

**শিলালিপি** — *shilālipi* — "an inscription (on stone)".

> শিলালিপিটা পড়ে বিজ্ঞানীরা রাজার নাম জানলেন।
>
> *shilālipiṭā pôṛe bigyānīrā rājār nām jānlen.*
>
> By reading the inscription the scientists learned the king's name.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**শিলালিপি** (*shilālipi*) joins Sanskrit *śilā*, 'a stone, a rock', to *lipi*, 'writing, a script' (Monier-Williams): writing cut in stone.
