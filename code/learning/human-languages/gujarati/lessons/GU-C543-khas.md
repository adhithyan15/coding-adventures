# ખાસ (khās) — special

## You'll want to know: ખાસ
<!-- hl-knowledge: introduces=[GU-LEX-C543-APVAD543-05]; assesses=[] -->

**ખાસ** — *khās* — "special".

> જો કોઈ ખાસ કારણ હશે તો જ તમને રજા મળશે.
>
> *jo koī khās kāraṇ haśe to ja tamne rajā maḷśe.*
>
> You'll get leave only if there is a special reason.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ખાસ** (*khās*) is usually traced to Arabic *khāṣṣ*, "particular, special", through Persian.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
