## You'll want to know: liberare
<!-- hl-knowledge: introduces=[IT-LEX-C329-RIVOLTA-05]; assesses=[] -->

**liberare** — "to free, to set free".

> Alla fine hanno liberato i prigionieri.
>
> *In the end they freed the prisoners.*

Also to clear: *liberare la stanza*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*liberare* is inherited from Latin *līberāre* "to set free" (EtymDB), from *līber* "free".
