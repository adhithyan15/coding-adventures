# ಪೀಠೋಪಕರಣ (pīṭhōpakaraṇa) — furniture

## You'll want to know: ಪೀಠೋಪಕರಣ
<!-- hl-knowledge: introduces=[KA-LEX-C543-GRHA543-04]; assesses=[] -->

**ಪೀಠೋಪಕರಣ** — *pīṭhōpakaraṇa* — "furniture".

> ಹೊಸ ಮನೆಗೆ ನಾವು ಹೊಸ ಪೀಠೋಪಕರಣ ತಂದೆವು.
>
> *hosa manege nāvu hosa pīṭhōpakaraṇa tandevu.*
>
> We brought new furniture for the new house.

ಪೀಠ, a seat + ಉಪಕರಣ, an implement.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಪೀಠೋಪಕರಣ** (*pīṭhōpakaraṇa*) is a modern learned compound built from Sanskrit *pīṭha*, "a stool, a bench" (CDIAL 8222), and *upakaraṇa*, "an implement" (CDIAL 2138).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
