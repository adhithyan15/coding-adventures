# கொளுத்து (koḷuttu) — to scorch; to set alight

## You'll want to know: கொளுத்து
<!-- hl-knowledge: introduces=[TA-LEX-C427-VEPPAM427-04]; assesses=[] -->

**கொளுத்து** — *koḷuttu* — "to scorch; to set alight".

> மதியம் வெயில் கொளுத்தியது.
>
> *matiyam veyil koḷuttiyatu.*
>
> At noon the sun was scorching.

Past (I …): கொளுத்தினேன், *koḷuttiṉēṉ*.

With an object, to light: விளக்கைக் கொளுத்து, to light a lamp.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**கொளுத்து** (*koḷuttu*) is native Dravidian (DEDR 2158), "to kindle, to set on fire".
