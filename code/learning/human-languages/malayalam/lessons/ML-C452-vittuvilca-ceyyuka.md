# വിട്ടുവീഴ്ച ചെയ്യുക (viṭṭuvīḻca ceyyuka) — to compromise

## You'll want to know: വിട്ടുവീഴ്ച ചെയ്യുക
<!-- hl-knowledge: introduces=[ML-LEX-C452-SAMADHANAM452-01]; assesses=[] -->

**വിട്ടുവീഴ്ച ചെയ്യുക** — *viṭṭuvīḻca ceyyuka* — "to compromise".

> രണ്ട് കൂട്ടരും കുറച്ച് വിട്ടുവീഴ്ച ചെയ്തു.
>
> *raṇṭŭ kūṭṭaruṁ kuṟaccŭ viṭṭuvīḻca ceytu.*
>
> Both sides compromised a little.

Past: വിട്ടുവീഴ്ച ചെയ്തു, *viṭṭuvīḻca ceytu*.

The noun വിട്ടുവീഴ്ച is a compromise.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**വിട്ടുവീഴ്ച ചെയ്യുക** (*viṭṭuvīḻca ceyyuka*) is a phrase verb on a native Malayalam compound: വിടുക, "to let go" (DEDR 5393), and വീഴ്ച, "a fall", from വീഴുക (DEDR 5430), with ചെയ്യുക, "to do": letting go and giving way.

## What you've built
