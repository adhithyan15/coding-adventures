# സമർപ്പിക്കുക (samarppikkuka) — to submit

## You'll want to know: സമർപ്പിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C426-NIVEDANAM426-04]; assesses=[] -->

**സമർപ്പിക്കുക** — *samarppikkuka* — "to submit".

> അവൾ അപേക്ഷ ഇന്നലെ സമർപ്പിച്ചു.
>
> *avaḷ apēkṣa innale samarppiccu.*
>
> She submitted the application yesterday.

Past: സമർപ്പിച്ചു, *samarppiccu*.

Also to dedicate: പുസ്തകം അമ്മയ്ക്ക് സമർപ്പിച്ചു, he dedicated the book to his mother.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**സമർപ്പിക്കുക** (*samarppikkuka*) is built from Sanskrit *samarpaṇa*, "placing upon; delivering over" (CDIAL 13191), with the Malayalam verb ending -ിക്കുക.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
