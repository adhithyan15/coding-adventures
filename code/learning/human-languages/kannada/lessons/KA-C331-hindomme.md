# ಹಿಂದೊಮ್ಮೆ (hindomme) — once before

## You'll want to know: ಹಿಂದೊಮ್ಮೆ
<!-- hl-knowledge: introduces=[KA-LEX-C331-HINDE331-01]; assesses=[] -->

**ಹಿಂದೊಮ್ಮೆ** — *hindomme* — "once before".

> ನಾನು ಹಿಂದೊಮ್ಮೆ ಈ ಕೋಟೆಯನ್ನು ನೋಡಿದ್ದೆ.
>
> *nānu hindomme ī kōṭeyannu nōḍidde.*
>
> I had seen this fort once before.

ಹಿಂದೆ, before, and ಒಮ್ಮೆ, once.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಹಿಂದೊಮ್ಮೆ** (*hindomme*) is a native Dravidian compound: *hinde*, "behind, in the past", from *pin* (DEDR 4205), and ಒಮ್ಮೆ, "once".
