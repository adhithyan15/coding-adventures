## You'll want to know: el ahorro
<!-- hl-knowledge: introduces=[ES-LEX-C477-DINERO-01]; assesses=[] -->

**el ahorro** — "the saving; savings".

> Tengo unos ahorros para el verano.
>
> *I have some savings for the summer.*

In the plural, *los ahorros* is the money you have put aside.
