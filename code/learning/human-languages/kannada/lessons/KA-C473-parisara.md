# ಪರಿಸರ (parisara) — the environment; surroundings

## You'll want to know: ಪರಿಸರ
<!-- hl-knowledge: introduces=[KA-LEX-C473-PARISARA473-01]; assesses=[] -->

**ಪರಿಸರ** — *parisara* — "the environment; surroundings".

> ಪ್ಲಾಸ್ಟಿಕ್ ಪರಿಸರಕ್ಕೆ ಒಳ್ಳೆಯದಲ್ಲ.
>
> *plāsṭik parisarakke oḷḷeyadalla.*
>
> Plastic is not good for the environment.

ಪರಿಸರ ದಿನ, environment day.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಪರಿಸರ** (*parisara*) is borrowed from Sanskrit *parisara*, "adjacent, lying around" (Monier-Williams); modern Kannada uses it for the environment.
