## You'll want to know: assurdo
<!-- hl-knowledge: introduces=[IT-LEX-C343-DUBBIO-04]; assesses=[] -->

**assurdo** — "absurd".

> È assurdo pagare così tanto per un caffè.
>
> *It is absurd to pay so much for a coffee.*

*Ma è assurdo!* — that is ridiculous! Feminine *assurda*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*assurdo* is a learned borrowing from Latin *absurdus* "out of tune, incongruous" (EtymDB), built from *ab* "away from" and *surdus* "deaf, dull-sounding": a note that does not fit the tune.
