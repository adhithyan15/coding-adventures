# છીંકવું (chī̃kvũ) — to sneeze

## You'll want to know: છીંકવું
<!-- hl-knowledge: introduces=[GU-LEX-C223-FEEL223-05]; assesses=[] -->

**છીંકવું** — *chī̃kvũ* — "to sneeze".

> **હું આજે નથી છીંકતો.** — *hũ āje nathī chī̃kto* — "I am not sneezing today."

The sneeze is **છીંક**, *chī̃k*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**છીંકવું** (*chī̃kvũ*) is inherited, built on an imitative word for the sound. CDIAL lists Gujarati *chī̃k* and *chī̃kvũ* under Sanskrit *chikkā*, "sneeze" (CDIAL 5032).
