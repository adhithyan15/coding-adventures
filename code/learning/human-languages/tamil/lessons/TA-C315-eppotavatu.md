# எப்போதாவது (eppōtāvatu) — once in a while; ever

## You'll want to know: எப்போதாவது
<!-- hl-knowledge: introduces=[TA-LEX-C315-NADAIPERU315-05]; assesses=[] -->

**எப்போதாவது** — *eppōtāvatu* — "once in a while; ever".

> நான் எப்போதாவது வானொலியில் செய்தி கேட்பேன்.
>
> *nāṉ eppōtāvatu vāṉoliyil ceyti kēṭpēṉ.*
>
> Once in a while I listen to the news on the radio.

In a question it means ever: எப்போதாவது பார்த்திருக்கிறாயா?

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**எப்போதாவது** (*eppōtāvatu*) is built from எப்போது, "when", on native போது, "time" (DEDR 4559), with ஆவது, "at least, any".

One more word for telling what happened.
