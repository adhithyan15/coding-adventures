## You'll want to know: продолжаться
<!-- hl-knowledge: introduces=[RU-LEX-C273-PROISKHODIT-02]; assesses=[] -->

**продолжаться** (*prodolzhátsya*) — "to go on, to continue".

> Дождь продолжался три дня.
>
> *Dozhd prodolzhálsya tri dnya.*
>
> The rain went on for three days.

Imperfective; perfective *продолжиться* (*prodólzhitsya*). Without *-ся*, *продолжать* takes an object: to continue something.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*продолжаться* is built on *про-* and *долгий* "long", which is inherited from Proto-Slavic *dĭlgŭ* "long" (EtymDB): to be made longer.
