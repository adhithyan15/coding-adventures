# hablábamos — the imperfect gets its plural

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ES-GRAMMAR-AR-IMPERFECT-SINGULAR, ES-GRAMMAR-IMPERFECT-ONGOING-HABITUAL] -->

[PAUSE 2s] *Hablaba* — I used to speak, or I was speaking. The tense for what
was going on.

[PAUSE 1s] Until now you have had only its singular.

## Grammar Lens: the three that were missing
<!-- hl-knowledge: introduces=[ES-GRAMMAR-AR-IMPERFECT-PLURAL]; assesses=[ES-GRAMMAR-AR-PRESENT-2PL] -->

[PAUSE 2s] Say them: *nosotros* ***hablábamos***. *Vosotros* ***hablabais***.
*Ellos* ***hablaban***.

[PAUSE 2s] The *-aba-* runs all the way through. The endings on top of it are
the ordinary plural ones you have used since the present tense: *-mos*, *-is*,
*-n*.

## Why it's said this way
<!-- hl-knowledge: introduces=[ES-ORTHOGRAPHY-IMPERFECT-ACCENT]; assesses=[ES-GRAMMAR-DEFAULT-STRESS, ES-SCRIPT-ACUTE-ACCENT] -->

Now look at the accent on ***hablábamos***, because it is the only one in the
set and it is doing real work.

[PAUSE 2s] The word ends in *-s*, so Spanish's default would put the stress on
the **next-to-last** syllable: *habla-BA-mos*. But the stress actually falls a
syllable earlier, on the *-BA-*... which is not where the default lands, so the
accent has to say so.

[PAUSE 2s] Without it you would read *hablabamos* with the wrong beat. The mark
is not decoration; it is the difference between the word being a past tense and
being nothing at all.

[PAUSE 2s] None of the other five needs one, because in each of those the
default already lands where the stress is.
