## You'll want to know: завидовать
<!-- hl-knowledge: introduces=[RU-LEX-C469-JEALOUSY-05]; assesses=[] -->

**завидовать** (*zavídovat*) — "to envy".

> Я не завидую богатым людям.
>
> *Ya ne zavíduyu bogátym lyúdyam.*
>
> I don't envy rich people.

Imperfective; the present is завидую, завидуешь. Takes the dative: *завидовать брату*. Perfective позавидовать.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*завидовать* is built on the same *за-* and *вид-* as *зависть* 'envy'; the root is that of *видеть* 'to see', inherited from Proto-Slavic *viděti* (EtymDB).
