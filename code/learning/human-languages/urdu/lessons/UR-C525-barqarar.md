## You'll want to know: برقرار
<!-- hl-knowledge: introduces=[UR-LEX-C525-MOHLAT525-04]; assesses=[] -->

**برقرار** — *barqarār* — "still standing; unchanged".

> اگر موسم ٹھیک رہا تو پروگرام برقرار رہے گا۔
>
> *agar mausam ṭhīk rahā to progrām barqarār rahe gā.*
>
> If the weather stays fine, the plan will stand.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**برقرار** (*barqarār*) is usually traced to Persian *barqarār*, "firm, established", built from *bar*, "on", and Arabic *qarār*, "rest, firmness".
