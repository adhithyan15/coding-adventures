## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**coraggioso** — built from the word for "courage" with *-oso*, "full of". That word ← Old Provençal *coratge*, built on Latin *cor*, "heart" — borrowed. (EtymDB 2.1)
