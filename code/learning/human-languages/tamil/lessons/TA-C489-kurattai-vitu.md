# குறட்டை விடு (kuṟaṭṭai viṭu) — to snore

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TA-LEX-C488-EDAI488-05, TA-LEX-C489-TUKKAM489-01] -->

[PAUSE 2s] Before the new one: say the Tamil for starvation, then the Tamil for to slumber.

## You'll want to know: குறட்டை விடு
<!-- hl-knowledge: introduces=[TA-LEX-C489-TUKKAM489-02]; assesses=[] -->

**குறட்டை விடு** — *kuṟaṭṭai viṭu* — "to snore".

> அப்பா இரவு முழுவதும் குறட்டை விட்டார்.
>
> *appā iravu muḻuvatum kuṟaṭṭai viṭṭār.*
>
> Father snored all night.

Past (I …): குறட்டை விட்டேன், *kuṟaṭṭai viṭṭēṉ*.

குறட்டை "snoring" + விடு "to let out".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**குறட்டை விடு** (*kuṟaṭṭai viṭu*) is native: குறட்டை *kuṟaṭṭai*, "snoring" (DEDR 1852), with விடு "to let out".
