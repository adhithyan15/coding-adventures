## You'll want to know: اضطراب
<!-- hl-knowledge: introduces=[FA-LEX-C485-WORRY-01]; assesses=[] -->

**اضطراب** (*ezterâb*) — "anxiety".

> قبل از امتحان اضطراب دارم.
>
> *qabl az emtehân ezterâb dâram.*
>
> I feel anxious before an exam.

*ezterâb dâshtan* — to be anxious. Formal; in speech *esteres* is more usual.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*ezterâb* is a loan, usually traced to Arabic *iḍṭirāb*, 'agitation, unrest'. EtymDB has no entry for it.
