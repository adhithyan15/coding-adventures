## You'll want to know: संदर्भ
<!-- hl-knowledge: introduces=[MR-LEX-C348-SAMBANDH348-03]; assesses=[] -->

**संदर्भ** — *sandarbha* — "a context; a reference".

> संदर्भ समजल्याशिवाय या वाक्याचा अर्थ कळत नाही.
>
> *sandarbha samjalyāśivāy yā vākyācā artha kaḷat nāhī.*
>
> Without the context, the meaning of this sentence is not clear.

Masculine.

संदर्भात, regarding: या संदर्भात, in this connection.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**संदर्भ** (*sandarbha*) is a tatsama, taken from Sanskrit *saṁdarbha*, "stringing together, composition" (Monier-Williams).
