## You'll want to know: el electricista
<!-- hl-knowledge: introduces=[ES-LEX-C769-GOTERA-05]; assesses=[] -->

**el electricista** — "the electrician".

> Llamamos a un electricista porque no había luz.
>
> *We called an electrician because there was no power.*

The same form for a woman: *la electricista*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*electricista* is built on *eléctrico* with the ending *-ista*. *Eléctrico* goes back to Greek *ḗlektron* 'amber' (Lewis & Short, under *electrum*), because rubbed amber pulls in light things.
