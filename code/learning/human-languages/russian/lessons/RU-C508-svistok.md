## You'll want to know: свисток
<!-- hl-knowledge: introduces=[RU-LEX-C508-FANS-03]; assesses=[] -->

**свисток** (*svistók*) — "a whistle".

> После свистка судьи игра закончилась.
>
> *Pósle svistká sudí igrá zakónchilas.*
>
> After the referee's whistle the game ended.

Masculine; genitive свистка.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*свисток* is built on *свистеть* 'to whistle', an imitative root; EtymDB lists *свисток* without a source.
