# செல்வாக்கு (celvākku) — influence

## You'll want to know: செல்வாக்கு
<!-- hl-knowledge: introduces=[TA-LEX-C375-KATCI375-04]; assesses=[] -->

**செல்வாக்கு** — *celvākku* — "influence".

> அவருக்கு இந்த ஊரில் நிறையச் செல்வாக்கு இருக்கிறது.
>
> *avarukku inta ūril niṟaiyac celvākku irukkiṟatu.*
>
> He has a lot of influence in this town.

X-இன் மீது செல்வாக்கு, influence over X.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**செல்வாக்கு** (*celvākku*) is usually read as native *cel*, "to go, pass, be current" (DEDR 2781), and *vākku*, "word": a word that carries. The analysis is not settled.
