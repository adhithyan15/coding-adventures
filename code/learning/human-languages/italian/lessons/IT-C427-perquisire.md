## You'll want to know: perquisire
<!-- hl-knowledge: introduces=[IT-LEX-C427-DOGANA-03]; assesses=[] -->

**perquisire** — "to search (a person or a place)".

> Al controllo mi hanno perquisito.
>
> *At security they searched me.*

Conjugated like *finire*: *perquisisco*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*perquisire* is a learned borrowing from Latin *perquīrere* 'to search everywhere', built on *quaerere* 'to seek' (Lewis & Short).
