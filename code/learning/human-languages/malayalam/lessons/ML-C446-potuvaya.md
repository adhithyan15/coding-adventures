# പൊതുവായ (potuvāya) — common; shared

## You'll want to know: പൊതുവായ
<!-- hl-knowledge: introduces=[ML-LEX-C446-VYAKTAM446-02]; assesses=[] -->

**പൊതുവായ** — *potuvāya* — "common; shared".

> രണ്ട് ഭാഷകൾക്കും പൊതുവായ പല വാക്കുകളും ഉണ്ട്.
>
> *raṇṭŭ bhāṣakaḷkkuṁ potuvāya pala vākkukaḷuṁ uṇṭŭ.*
>
> The two languages have many words in common.

Common to two things: -ക്കും പൊതുവായ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**പൊതുവായ** (*potuvāya*) is native Dravidian: പൊതു, "common, general" (DEDR 4507), with the adjective ending -ആയ.
