# بشرط أن (bi-sharṭi an) — provided that

## You'll want to know: بشرط أن
<!-- hl-knowledge: introduces=[AR-LEX-C399-SHART399-03]; assesses=[] -->

**بشرط أن** — *bi-sharṭi an* — "provided that".

> سأساعدك بشرط أن تساعدني.
>
> *sa-usāʿiduka bi-sharṭi an tusāʿidanī.*
>
> I will help you provided that you help me.

The verb after أن takes the subjunctive: أن تساعدني.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**بشرط أن** (*bi-sharṭi an*) joins *bi-*, "with", *sharṭ*, "a condition", built on the native Arabic root *sh-r-ṭ*, "to set a mark, to stipulate" (Lane), and *an*, "that": on condition that.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
