# Review — which way to the station

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[JA-GRAMMAR-C256-DIRECTION-01, JA-LEX-C256-MAI-01] -->

[PAUSE 2s] Ask "where is the station?" (*eki wa doko desu ka*.) Then say "two tickets, please". (*kippu o nimai kudasai*.)
