# ਅਮਨ ਨਾਲ ਕੰਮ ਕਰੋ — name one companion

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-NAME-AMAN-01, PA-LEX-KAMM-05, PA-LEX-KARNA-05] -->

[PAUSE 2s] Recall the practice name **ਅਮਨ**, the familiar work word **ਕੰਮ**,
and polite **ਕਰੋ**. Keep all three unchanged.

## Grammar Lens: ਨਾਲ follows the companion noun
<!-- hl-knowledge: introduces=[PA-POSTPOSITION-NAAL-COMITATIVE-01]; assesses=[PA-FORM-NAME-AMAN-01, PA-LEX-KAMM-05, PA-LEX-KARNA-05] -->

> **ਅਮਨ ਨਾਲ ਕੰਮ ਕਰੋ।**
>
> *Aman nāl kamm karo.*
>
> Work with Aman.

As with the last two forms, the postposition comes after its noun. The
companion is **ਅਮਨ**, so the pair is **ਅਮਨ ਨਾਲ**. This lesson teaches only
the companion meaning of **ਨਾਲ** in this polite instruction.
