## [0.2.0] — 2026-11-24

### Added
- `InvalidBitException(parameter, value)`, a subclass of `IllegalArgumentException`, thrown for every non-0/1 argument.
- `LogicGatesExhaustiveTest`: literal truth tables for all 11 gates, NAND-built equals direct, and rejection of every Int in [-1024, 1024] (except 0/1) plus Int extremes in every argument position.
- JaCoCo 0.8.12 with a 0.95 line-coverage gate enforced by `gradle test`.

### Fixed
- `nandNOT`/`nandAND`/`nandOR`/`nandXOR` now validate their own arguments and report the first invalid parameter by their own names.

### Notes
- Type confusion (Long/Char/Boolean/Double) is a compile-time error in Kotlin; documented in source.
