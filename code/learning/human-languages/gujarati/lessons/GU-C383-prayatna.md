# પ્રયત્ન (prayatna) — an attempt

## You'll want to know: પ્રયત્ન
<!-- hl-knowledge: introduces=[GU-LEX-C383-PRAYATNA383-01]; assesses=[] -->

**પ્રયત્ન** — *prayatna* — "an attempt".

> જો પહેલા પ્રયત્નમાં તમે હારશો તો ફરી પ્રયત્ન કરો.
>
> *jo pahelā prayatnamā̃ tame hārśo to pharī prayatna karo.*
>
> If you lose at the first attempt, try again.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**પ્રયત્ન** (*prayatna*) is a tatsama, borrowed from Sanskrit *prayatna*, "persevering effort, exertion" (Monier-Williams).
