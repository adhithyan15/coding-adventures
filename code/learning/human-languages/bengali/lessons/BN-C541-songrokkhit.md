# সংরক্ষিত (sôngrôkkhit) — reserved; kept aside

## You'll want to know: সংরক্ষিত
<!-- hl-knowledge: introduces=[BN-LEX-C541-PROTIKSHA541-03]; assesses=[] -->

**সংরক্ষিত** — *sôngrôkkhit* — "reserved; kept aside".

> ট্রেনের এই আসনগুলো মহিলাদের জন্য সংরক্ষিত।
>
> *Ṭrener ei āsôngulo môhilāder jônyô sôngrôkkhit.*
>
> These seats on the train are reserved for women.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**সংরক্ষিত** (*sôngrôkkhit*) is a tatsama, Sanskrit *saṃrakṣita*, "protected, kept safe" (Monier-Williams): kept aside for someone.
