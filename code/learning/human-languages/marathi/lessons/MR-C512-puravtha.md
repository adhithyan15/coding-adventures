## You'll want to know: पुरवठा
<!-- hl-knowledge: introduces=[MR-LEX-C512-KARKHANA512-04]; assesses=[] -->

**पुरवठा** — *puravṭhā* — "a supply".

> कारखान्याला कच्च्या मालाचा पुरवठा कमी पडला.
>
> *kārkhānyālā kaccyā mālācā puravṭhā kamī paḍlā.*
>
> The factory ran short of raw materials.

Masculine.

पुरवठा कमी पडणे, to run short.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**पुरवठा** (*puravṭhā*) is built on पुरवणे, "to provide", the causative of पुरणे, "to suffice", inherited from Sanskrit *pūrayati*, "fills" (CDIAL 8335).
