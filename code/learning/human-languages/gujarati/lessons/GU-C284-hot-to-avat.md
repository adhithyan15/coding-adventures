# જો … હોત, તો … આવત (jo … hot, to … āvat) — what would have been

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[GU-GRAMMAR-C283-IF-FUTURE-01, GU-GRAMMAR-C284-PAR-ADHAR-01, GU-GRAMMAR-C284-DEPENDS-ANSWER-01, GU-LEX-C102-CAN102-02, GU-LEX-C79-WEEK2-05] -->

[PAUSE 2s] Say "it depends on the rain: if it doesn't rain, we'll go". (*te varsād par ādhār rākhe che: jo varsād nahī̃ paḍe, to ame jaīśũ*.) Then "I have time", the A2 way. (**મારી પાસે સમય છે**.)

## Grammar Lens: the -ત form
<!-- hl-knowledge: introduces=[GU-GRAMMAR-C284-T-COUNTERFACTUAL-01]; assesses=[GU-LEX-HOVU, GU-LEX-AAVVU, GU-GRAMMAR-C145-NA-01] -->

> **જો મારી પાસે સમય હોત, તો હું આવત.**
>
> *jo mārī pāse samay hot, to hũ āvat.* — "If I had had time, I would have come."

The stem with **-ત** (*-t*) is "would": the condition did not hold, so the result did not happen. Both halves take it: **હોત**, from **હોવું**, and **આવત**, from **આવવું**. It can also be about now, a thing that is not so: "if I had time, I would come".

"If not" puts **ન** before it: **જો ટ્રેન મોડી ન હોત, તો અમે વહેલા પહોંચત** (*jo ṭren moḍī na hot, to ame vahelā pahõcat*), "if the train hadn't been late, we would have arrived early".

## You'll want to know: one form for everyone
<!-- hl-knowledge: introduces=[GU-GRAMMAR-C284-T-FORMS-01]; assesses=[GU-LEX-JAVU, GU-CONCEPT-C05-KAAMKARVUN-01, GU-LEX-C142-ACT142-01] -->

**-ત** stays the same for every person, man or woman: **હું જાત**, **તે જાત**, **અમે જાત**, with the same *jāt* each time. It is no past, so a verb with an object keeps a plain doer, with no **-એ**:

| plain past | would have |
|---|---|
| **મેં કામ કર્યું** | **હું કામ કરત** |
| **તેણે કહ્યું** | **તે કહેત** |
