# परेशान (pareśān) — troubled, bothered

## You'll want to know: परेशान
<!-- hl-knowledge: introduces=[HI-LEX-C108-FEEL-04]; assesses=[] -->

**परेशान** (*pareśān*) — "troubled, bothered, upset".

**आप परेशान क्यों हैं?** — "why are you upset?", with the **क्यों** you know.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

A question to ask a friend who looks upset.
