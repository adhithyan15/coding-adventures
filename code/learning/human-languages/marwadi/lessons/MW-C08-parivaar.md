# परिवार — family on the page

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MW-LEX-PARIVAAR-01, MW-SCRIPT-VA-01, MW-SCRIPT-PA-01, MW-SCRIPT-RA-01, MW-SCRIPT-I-MATRA-01, MW-SCRIPT-AA-MATRA-01, MW-LEX-DADI-01, MW-SCRIPT-DADA-01, MW-SCRIPT-LA-01] -->

[PAUSE 22s] Write **प**, **रि**, **व**, and **ार** as four small units. Write
paternal grandfather and **ल**, then say paternal grandmother.

## You'll want to know
<!-- hl-knowledge: introduces=[MW-SCRIPT-PARIVAAR-01]; assesses=[MW-LEX-PARIVAAR-01, MW-SCRIPT-VA-01, MW-SCRIPT-PA-01, MW-SCRIPT-RA-01, MW-SCRIPT-I-MATRA-01, MW-SCRIPT-AA-MATRA-01] -->

> **प** + **रि** + **वा** + **र** → **परिवार** — *parivār* — family

Remember that **ि** is written before **र** but read after it: *ri*.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[MW-LEX-PARIVAAR-01, MW-SCRIPT-PARIVAAR-01] -->
<!-- hl-writing-stage: delayed-copy -->

Look at **परिवार**, cover it, wait eight seconds, and write the four chunks.
Uncover and check **रि** and **व** separately.
