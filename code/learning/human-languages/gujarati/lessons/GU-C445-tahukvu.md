# ટહુકવું (ṭahukvũ) — to call (of a bird)

## You'll want to know: ટહુકવું
<!-- hl-knowledge: introduces=[GU-LEX-C445-BIRDS445-04]; assesses=[] -->

**ટહુકવું** — *ṭahukvũ* — "to call (of a bird)".

> ચોમાસામાં મોર ટહુકે છે.
>
> *comāsāmā̃ mor ṭahuke che.*
>
> In the monsoon the peacock calls.

Past (it …): તે મોર ટહુક્યો, *te mor ṭahukyo*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ટહુકવું** (*ṭahukvũ*) sounds like the call it names. No dictionary we use records an older form, so its history is not settled.
