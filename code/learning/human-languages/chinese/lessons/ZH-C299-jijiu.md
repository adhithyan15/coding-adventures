## You'll want to know: jíjiù
<!-- hl-knowledge: introduces=[ZH-LEX-C299-RESCUE299-03]; assesses=[] -->

*jíjiù* — "first aid".

> *wǒ xué guo jíjiù* — I've done a first-aid course.

Its characters come later; for now it is a word for the ear.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*jíjiù* is built from *jí* 'urgent' and 救 'to save', both inherited from Middle Chinese, *kip* and *kjuwH* (Guangyun, in Baxter's transcription), which glosses the first 'hurried'.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
