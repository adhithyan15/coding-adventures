## Fixed — Urdu root slugs unified and the ānā atom renamed

- **One slug per etymon.** UR-C02-mera-naam and UR-C04-main-hun move from `indo-aryan-main` to `ma-first-person`, the slug UR-C19-nahin-verb, Hindi and Punjabi use for the base *ma-* (CDIAL 9691). UR-C06-bolna drops `indo-aryan-bolla` and keeps `bol-speak`. UR-C07-parhna's `arabic-hfz` becomes `arabic-h-f-z`, as in UR-C05-hafiz and Persian. UR-C151-tayyar-karna already used `arabic-tayyar`.
- **`sanskrit-kala` split.** UR-C13-kala and UR-C207-kali-mirch move to `sanskrit-kala-black`, since `sanskrit-kala` also named *kalā* "art" (CDIAL 2927) and *kālā* is *kāla* "black" (CDIAL 3083).
- **`UR-ETYMON-ANA-TOWARD-GO` is now `UR-ETYMON-ANA-APAYATI`** in UR-C06-ana, UR-C08-pasand and UR-C09-bhai. The block already says *ānā* is filed under *āpayati* (CDIAL 1200), not *ā-* "toward" plus *yā-* "go", so the old name said the opposite of what it teaches.
