# गृहप्रवेश (gṛhapraveś) — a housewarming

## You'll want to know: गृहप्रवेश
<!-- hl-knowledge: introduces=[MR-LEX-C323-NIROP323-03]; assesses=[] -->

**गृहप्रवेश** — *gṛhapraveś* — "a housewarming".

> नव्या घराचा गृहप्रवेश रविवारी झाला.
>
> *navyā gharācā gṛhapraveś ravivārī jhālā.*
>
> The housewarming of the new house was on Sunday.

Masculine.

गृह, a house, + प्रवेश, an entry.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**गृहप्रवेश** (*gṛhapraveś*) is a tatsama, taken from Sanskrit *gṛhapraveśa*, 'a solemn entrance into a house' (Monier-Williams).
