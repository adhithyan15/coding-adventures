# ese — pointing at what is by you

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ES-GRAMMAR-DEMONSTRATIVE-ESTE, ES-ETYMON-ESTE-ISTE, ES-GRAMMAR-DEMONSTRATIVE-BEFORE-NOUN] -->

[PAUSE 2s] *Este libro* is the one in my hand.

[PAUSE 1s] Remember where *este* came from: it used to point at **you**. So
when it moved to me, something had to take over the job it left behind.

## The word, taken apart: ese
<!-- hl-knowledge: introduces=[ES-GRAMMAR-DEMONSTRATIVE-ESE, ES-ETYMON-ESE-IPSE]; assesses=[] -->

**ese libro** — *that book*, the one near **you**.

| | |
|---|---|
| ***ese*** *libro* | that book, by you |
| ***esa*** *casa* | that house, by you |
| ***esos*** *libros* | those books |
| ***esas*** *casas* | those houses |

[PAUSE 2s] The word that stepped in was Latin ***ipse***, which meant **self** —
the same *ipse* in the Latin phrase *ipso facto*, "by the fact itself".

[PAUSE 2s] You can feel how it got the job. *That very one*, *that one itself*
— an emphasiser that keeps insisting on a particular thing eventually stops
emphasising and simply **points**.

## Why it's said this way
<!-- hl-knowledge: introduces=[]; assesses=[ES-GRAMMAR-DEMONSTRATIVE-ESE, ES-GRAMMAR-DEMONSTRATIVE-ESTE] -->

So the difference between *este* and *ese* is not distance in metres. It is
**whose side the thing is on**.

> *Este libro* — mine, here.
> *Ese libro* — yours, there.

[PAUSE 2s] Two people sitting at one small table will still say *este* and *ese*
about books a hand's width apart, because the question was never how far away
the book is. It is which of us it belongs to in this moment.
