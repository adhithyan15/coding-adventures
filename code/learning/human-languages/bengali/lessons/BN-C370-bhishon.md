# ভীষণ (bhīshôn) — terribly; extremely

## You'll want to know: ভীষণ
<!-- hl-knowledge: introduces=[BN-LEX-C370-KHUB370-02]; assesses=[] -->

**ভীষণ** — *bhīshôn* — "terribly; extremely".

> রাস্তায় ভীষণ ভিড় থাকলে আমরা হেঁটে যাব।
>
> *rāstāy bhīshôn bhiṛ thākle āmrā hẽṭe jābô.*
>
> If the streets are terribly crowded, we'll walk.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ভীষণ** (*bhīshôn*) is Sanskrit *bhīṣaṇa*, terrifying (Monier-Williams). Bengali speech uses it as English uses 'terribly', for anything extreme, good or bad.
