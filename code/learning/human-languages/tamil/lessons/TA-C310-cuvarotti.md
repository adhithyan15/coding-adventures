# சுவரொட்டி (cuvaroṭṭi) — a poster

## You'll want to know: சுவரொட்டி
<!-- hl-knowledge: introduces=[TA-LEX-C310-OODAKAM310-02]; assesses=[] -->

**சுவரொட்டி** — *cuvaroṭṭi* — "a poster".

> சுவர்களில் புதிய படத்தின் சுவரொட்டிகள் இருந்தன.
>
> *cuvarkaḷil putiya paṭattiṉ cuvaroṭṭikaḷ iruntaṉa.*
>
> There were posters for the new film on the walls.

Plural: சுவரொட்டிகள், *cuvaroṭṭikaḷ*.

சுவர், wall + ஒட்டி, a thing stuck on.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**சுவரொட்டி** (*cuvaroṭṭi*) is a Tamil compound built from சுவர், "wall" (DEDR 1975), and ஒட்டு, "to stick, glue on" (DEDR 958).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
