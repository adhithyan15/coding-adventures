# അവലംബം (avalambaṁ) — a reference; a support

## You'll want to know: അവലംബം
<!-- hl-knowledge: introduces=[ML-LEX-C439-GRANTHAM439-04]; assesses=[] -->

**അവലംബം** — *avalambaṁ* — "a reference; a support".

> ലേഖനത്തിന്റെ അവസാനം അവലംബം കൊടുത്തിട്ടുണ്ട്.
>
> *lēkhanattinṟe avasānaṁ avalambaṁ koṭuttiṭṭuṇṭŭ.*
>
> The references are given at the end of the article.

It is first a support, something to lean on.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**അവലംബം** (*avalambaṁ*) is borrowed from Sanskrit *avalamba*, "hanging down; a stay, a support" (CDIAL 826). A reference is what a writer leans on.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
