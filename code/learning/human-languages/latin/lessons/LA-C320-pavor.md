## You'll want to know: pavor, pavōris
<!-- hl-knowledge: introduces=[LA-LEX-C320-PAVOR-01]; assesses=[] -->

**pavor, pavōris** — "panic, terror".

> Pavor omnēs cīvēs cēpit.
>
> *Panic seized all the citizens.*

Masculine, 3rd declension. A sudden fear that shakes the body.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**pavor** is built on *paveō*, "to tremble with fear" (EtymDB): the trembling itself.
