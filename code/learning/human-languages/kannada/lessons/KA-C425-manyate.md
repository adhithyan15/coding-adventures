# ಮಾನ್ಯತೆ (mānyate) — recognition; validity

## You'll want to know: ಮಾನ್ಯತೆ
<!-- hl-knowledge: introduces=[KA-LEX-C425-SVIKARISU425-05]; assesses=[] -->

**ಮಾನ್ಯತೆ** — *mānyate* — "recognition; validity".

> ಈ ಕಾಲೇಜಿಗೆ ಸರ್ಕಾರದ ಮಾನ್ಯತೆ ಇದೆ.
>
> *ī kālējige sarkārada mānyate ide.*
>
> This college is recognised by the government.

ಮಾನ್ಯ, recognised, honoured.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಮಾನ್ಯತೆ** (*mānyate*) is built on Sanskrit *mānya*, "to be respected or honoured" (Monier-Williams), with -*tā*, "-ness".
