## You'll want to know: درست
<!-- hl-knowledge: introduces=[UR-LEX-C543-ATKAL543-05]; assesses=[] -->

**درست** — *durust* — "correct; right".

> اگر یہ جواب درست ہے تو آپ جیت گئے۔
>
> *agar yih javāb durust hai to āp jīt gae.*
>
> If this answer is correct, you've won.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**درست** (*durust*) is usually traced to Persian *durust*, "whole, sound, right".
