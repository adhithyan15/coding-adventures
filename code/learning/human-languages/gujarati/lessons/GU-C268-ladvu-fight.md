# લડવું (laḍvũ) — to quarrel, to fight

## You'll want to know: લડવું
<!-- hl-knowledge: introduces=[GU-LEX-C268-QUARREL268-01]; assesses=[] -->

**લડવું** — *laḍvũ* — "to quarrel, to fight".

> **અમે ક્યારેય નથી લડતા.** — *ame kyārey nathī laḍtā* — "We never quarrel."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**લડવું** (*laḍvũ*) is a tadbhava. It comes from *\*laḍ*, "fight", a reconstructed form; CDIAL glosses the Gujarati verb "to fight" (CDIAL 10920).
