# ഫലപ്രദമായ (phalapradamāya) — effective

## You'll want to know: ഫലപ്രദമായ
<!-- hl-knowledge: introduces=[ML-LEX-C446-VYAKTAM446-03]; assesses=[] -->

**ഫലപ്രദമായ** — *phalapradamāya* — "effective".

> ആ മരുന്ന് വളരെ ഫലപ്രദമായിരുന്നു.
>
> *ā marunnŭ vaḷare phalapradamāyirunnu.*
>
> That medicine was very effective.

ഫലം, a result, and -പ്രദ, giving: giving results.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ഫലപ്രദമായ** (*phalapradamāya*) is built from Sanskrit *phala*, "fruit, result" (CDIAL 9051), and *prada*, "giving, yielding" (Monier-Williams), with the adjective ending -ആയ: yielding fruit.
