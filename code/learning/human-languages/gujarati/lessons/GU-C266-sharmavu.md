# શરમાવું (śarmāvũ) — to feel shy, to be embarrassed

## You'll want to know: શરમાવું
<!-- hl-knowledge: introduces=[GU-LEX-C266-FEELINGS266-05]; assesses=[] -->

**શરમાવું** — *śarmāvũ* — "to feel shy, to be embarrassed".

> **નાની છોકરી શરમાતી નથી.** — *nānī chokrī śarmātī nathī* — "The little girl is not shy."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**શરમાવું** (*śarmāvũ*) is built on *śaram*, "shame, shyness", with *-ā-*. *Śaram* is a loan usually traced to Persian *sharm*, "shame"; CDIAL has no entry for it.
