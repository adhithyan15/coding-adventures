## You'll want to know: la colección
<!-- hl-knowledge: introduces=[ES-LEX-C751-AFICION-04]; assesses=[] -->

**la colección** — "the collection".

> Tiene una colección de monedas antiguas.
>
> *He has a collection of old coins.*

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*colección* was borrowed from Latin *collēctiō* "a gathering together" (EtymDB), from *colligere*, built on *legere* "to gather".
