# અનિવાર્ય (anivārya) — unavoidable

## You'll want to know: અનિવાર્ય
<!-- hl-knowledge: introduces=[GU-LEX-C375-JARURI375-02]; assesses=[] -->

**અનિવાર્ય** — *anivārya* — "unavoidable".

> જો પેટ્રોલનો ભાવ વધશે તો બસનું ભાડું વધવું અનિવાર્ય છે.
>
> *jo peṭrolno bhāv vadhśe to basnũ bhāḍũ vadhvũ anivārya che.*
>
> If the price of petrol goes up, a rise in bus fares is unavoidable.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**અનિવાર્ય** (*anivārya*) is a tatsama, borrowed from Sanskrit *anivārya*, "not to be warded off, unavoidable" (Monier-Williams). It is built on the same root as **નિવારવું** (*nivārvũ*), "to avert", with *a-*, "not".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
