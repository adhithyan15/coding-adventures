## You'll want to know: separar
<!-- hl-knowledge: introduces=[PT-LEX-C497-SEPARACAO-02]; assesses=[] -->

**separar** — "to separate; to split up (separar-se)".

> Os pais dele separaram-se no ano passado.
>
> *His parents split up last year.*

*Separar o lixo* — to sort the rubbish.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*separar* is a learned borrowing from Latin *sēparāre* "to separate" (EtymDB), built on *sē-* "apart" and *parāre* "to prepare".
