# નિશાન (niśān) — a target

## You'll want to know: નિશાન
<!-- hl-knowledge: introduces=[GU-LEX-C550-NISHAN550-02]; assesses=[] -->

**નિશાન** — *niśān* — "a target".

> જો તમારું તીર નિશાન પર લાગશે તો તમે જીતશો.
>
> *jo tamārũ tīr niśān par lāgśe to tame jītśo.*
>
> If your arrow hits the target, you'll win.

A neuter noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**નિશાન** (*niśān*) is usually traced to Persian *nishān*, "a mark, a sign"; the mark one aims at is a target.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
