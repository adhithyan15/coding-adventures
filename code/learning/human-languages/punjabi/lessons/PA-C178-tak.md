# ਅੱਠ ਵਜੇ ਤੋਂ ਦਸ ਵਜੇ ਤੱਕ — give both ends of one time span

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-TIME-VAJE-01, PA-POSTPOSITION-TON-SOURCE-01, PA-LEX-C95-NUMBERS95-02, PA-LEX-C95-NUMBERS95-04] -->

[PAUSE 2s] Say **ਅੱਠ ਵਜੇ**, then **ਦਸ ਵਜੇ**. Put familiar **ਤੋਂ** after the
starting time: **ਅੱਠ ਵਜੇ ਤੋਂ**.

## Grammar Lens: ਤੱਕ follows the end limit
<!-- hl-knowledge: introduces=[PA-POSTPOSITION-TAK-LIMIT-01]; assesses=[PA-TIME-VAJE-01, PA-POSTPOSITION-TON-SOURCE-01, PA-LEX-C95-NUMBERS95-02, PA-LEX-C95-NUMBERS95-04] -->

> **ਅੱਠ ਵਜੇ ਤੋਂ ਦਸ ਵਜੇ ਤੱਕ**
>
> *aṭṭh vaje tõ das vaje takk*
>
> from eight o'clock until ten o'clock

The start is followed by **ਤੋਂ**; the end limit is followed by **ਤੱਕ**. Both
are postpositions and each comes after the words it relates to. This step owns
only the bounded from-until time frame.
