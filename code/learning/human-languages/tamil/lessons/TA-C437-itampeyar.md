# இடம்பெயர் (iṭampeyar) — to migrate; to move away

## You'll want to know: இடம்பெயர்
<!-- hl-knowledge: introduces=[TA-LEX-C437-VILANKU437-03]; assesses=[] -->

**இடம்பெயர்** — *iṭampeyar* — "to migrate; to move away".

> குளிர் காலத்தில் இந்தப் பறவைகள் தெற்கே இடம்பெயர்கின்றன.
>
> *kuḷir kālattil intap paṟavaikaḷ teṟkē iṭampeyarkiṉṟaṉa.*
>
> In winter these birds migrate south.

Past (I …): இடம்பெயர்ந்தேன், *iṭampeyarntēṉ*.

இடம், a place, + பெயர், to move.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**இடம்பெயர்** (*iṭampeyar*) is built from இடம், "a place" (DEDR 434), and பெயர், "to move, to depart" (DEDR 4409).
