## You'll want to know: أبحر
<!-- hl-knowledge: introduces=[AR-LEX-C429-QARIB429-04]; assesses=[] -->

**أبحر** — *abḥara* — "to sail; to set sail".

> أبحرت السفينة مع الفجر.
>
> *abḥarat as-safīna maʿa al-fajr.*
>
> The ship set sail at dawn.

Present: يبحر, *yubḥir*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**أبحر** (*abḥara*) is built on the native Arabic root *b-ḥ-r*, "the sea" (Lane). It is Form IV, "to go out to sea".
