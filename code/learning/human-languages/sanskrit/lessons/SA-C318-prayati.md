## You'll want to know: प्रयाति
<!-- hl-knowledge: introduces=[SA-LEX-C318-SENA318-04]; assesses=[] -->

**प्रयाति** — *prayāti* — "sets out".

> प्रातः सेना युद्धाय प्रयाति।
>
> *prātaḥ senā yuddhāya prayāti.*
>
> In the morning the army sets out for battle.

Past (it …): सेना प्रातः प्रयातवती, *senā prātaḥ prayātavatī*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**प्रयाति** (*prayāti*) is built from *pra*, "forth", and the root √yā, "to go"; MW gives *pra-yā* as to go forth, set out, advance (MW).
