## You'll want to know: ಅವಶ್ಯಕತೆ
<!-- hl-knowledge: introduces=[KA-LEX-C430-SANDARBHA430-05]; assesses=[] -->

**ಅವಶ್ಯಕತೆ** — *avaśyakate* — "a requirement; a need".

> ಊರಿಗೆ ಒಂದು ಆಸ್ಪತ್ರೆಯ ಅವಶ್ಯಕತೆ ಇದೆ.
>
> *ūrige ondu āspatreya avaśyakate ide.*
>
> The town needs a hospital.

What is needed takes -ದ / -ಯ before it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಅವಶ್ಯಕತೆ** (*avaśyakate*) is built on Sanskrit *āvaśyaka*, "necessary, inevitable" (Monier-Williams), with -*tā*, "-ness".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
