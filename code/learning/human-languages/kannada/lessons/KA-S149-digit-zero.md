# ೦ — the digit for hattu

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-SCRIPT-RECOG-148] -->

[PAUSE 1s] Before the new shape: **೯** — which number is it?

[PAUSE 2s] One digit this time, and you already know its name.

## Script you'll notice: ೦
<!-- hl-knowledge: introduces=[KA-SCRIPT-RECOG-149]; assesses=[] -->

**೦** — **0**, the digit for **ಹತ್ತು** (*hattu*), "zero".

Zero. On its own it is nothing; behind another digit it multiplies by ten,
which is how ಹತ್ತು is written **೧೦** — a ೧ and a ೦, exactly as *10* is.

## Writing: ೦ — copy what you see
<!-- hl-knowledge: introduces=[]; assesses=[KA-SCRIPT-RECOG-149] -->

Put your pen on ೦ and follow its line. Copy the shape in front of you —
slowly, and larger than it is printed.

> This book does not yet tell you **where to start the character or which way to
> travel**. That is taught with real variation from school to school, and it is
> not written down here until it can be written down with a source. Copying what
> you can see needs no such source.
