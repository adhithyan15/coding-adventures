## You'll want to know: أظلم
<!-- hl-knowledge: introduces=[AR-LEX-C485-SAMA485-05]; assesses=[] -->

**أظلم** — *aẓlama* — "to grow dark".

> أظلمت السماء قبل العاصفة.
>
> *aẓlamat as-samāʾ qabla al-ʿāṣifa.*
>
> The sky grew dark before the storm.

Present: يظلم, *yuẓlim*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**أظلم** (*aẓlama*) is built on the native Arabic root *ẓ-l-m*, "darkness" (Lane). It is Form IV; *ẓalām*, "darkness", shares the root.
