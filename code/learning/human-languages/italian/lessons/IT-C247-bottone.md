## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**bottone** ← Old French *boton*, "a bud, a button" — borrowed. EtymDB 2.1 has no row for *bottone*; it builds the French word on *bouter*, "to push".
