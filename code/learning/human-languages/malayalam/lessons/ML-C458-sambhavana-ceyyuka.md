# സംഭാവന ചെയ്യുക (sambhāvana ceyyuka) — to donate; to contribute

## You'll want to know: സംഭാവന ചെയ്യുക
<!-- hl-knowledge: introduces=[ML-LEX-C458-VAYPA458-05]; assesses=[] -->

**സംഭാവന ചെയ്യുക** — *sambhāvana ceyyuka* — "to donate; to contribute".

> നാട്ടുകാർ ആശുപത്രിക്ക് പണം സംഭാവന ചെയ്തു.
>
> *nāṭṭukār āśupatrikkŭ paṇaṁ sambhāvana ceytu.*
>
> The local people donated money to the hospital.

Past: സംഭാവന ചെയ്തു, *sambhāvana ceytu*.

The noun സംഭാവന is a donation, a contribution.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**സംഭാവന ചെയ്യുക** (*sambhāvana ceyyuka*) is a phrase verb built on സംഭാവന, "a donation", from Sanskrit *saṁbhāvanā*, "bringing together; honour, respect" (Monier-Williams), with ചെയ്യുക, "to do".
