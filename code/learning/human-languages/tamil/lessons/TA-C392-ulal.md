# ஊழல் (ūḻal) — corruption

## You'll want to know: ஊழல்
<!-- hl-knowledge: introduces=[TA-LEX-C392-ULAL392-01]; assesses=[] -->

**ஊழல்** — *ūḻal* — "corruption".

> ஊழல் இருந்தால் மக்களுக்கு அரசின் மீது நம்பிக்கை போய்விடும்.
>
> *ūḻal iruntāl makkaḷukku araciṉ mītu nampikkai pōyviṭum.*
>
> If there is corruption, people lose faith in the government.

ஊழல் செய், to be corrupt; ஊழல்வாதி, a corrupt person.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ஊழல்** (*ūḻal*) is native Dravidian: DEDR 756 lists Tamil *ūḻal*, "dirt, mire, that which is putrid, decayed, spoiled": corruption is rot.
