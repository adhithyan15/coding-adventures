# дорожать (dorozhát) — to go up in price

## You'll want to know: дорожать
<!-- hl-knowledge: introduces=[RU-LEX-C396-TSENY-01]; assesses=[] -->

**дорожать** (*dorozhát*) — "to go up in price".

> Хлеб опять дорожает.
>
> *Khleb opyát dorozháyet.*
>
> Bread is going up in price again.

Imperfective; perfective *подорожать*: *всё подорожало* — everything has gone up.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**дорожать** is built on *дорогой* "dear, expensive", inherited from Proto-Slavic *\*dorgŭ* "dear": to become dear.
