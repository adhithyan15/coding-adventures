## You'll want to know: 这儿
<!-- hl-knowledge: introduces=[ZH-LEX-C57-HOME57-05]; assesses=[] -->

**这儿** — *zhèr* — "here".

> **你想来这儿吗** *nǐ xiǎng lái zhèr ma* — Would you like to come here?

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**这儿** (*zhèr*) is built from 这 'this' and 儿, the ending that runs into the syllable before it as an r.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word about people.
