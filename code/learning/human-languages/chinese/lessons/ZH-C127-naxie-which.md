## You'll want to know: 哪些
<!-- hl-knowledge: introduces=[ZH-LEX-C127-THESE127-03]; assesses=[] -->

**哪些** — *nǎxiē* — "which ones".

> **你喜欢哪些书** *nǐ xǐhuan nǎxiē shū* — Which books do you like?

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**哪些** (*nǎxiē*) is built from 哪 'which' and 些 'a few'. The second is inherited from Middle Chinese *sjae* (Guangyun, in Baxter's transcription); no dictionary we use records an older form of the first, so its history is not settled.
