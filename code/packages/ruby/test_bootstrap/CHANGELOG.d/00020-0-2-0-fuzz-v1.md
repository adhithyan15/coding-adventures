## 0.2.0 - coverage-guided fuzz engine (VER06i, PT-RB-FUZZ)

### Added
- `Fuzz` module: the VER06 mutator algebra (`Mutate`: flips by parity via one
  little-endian integer, O(len) for any count; arithmetic and boundary widths
  1/2/4/8 in both endiannesses; block delete, insert, duplicate; splice;
  `mutate_sequence` with a `max_len` growth bound and a charged work cap).
- `Bitmap` (65,536 edges), `corpus_admit`, `calculate_energy` (half away from zero).
- Deterministic `Fuzz.run` / `Fuzz.run_outcomes` campaign meeting every VER06 section
  9.1 contract, with CWE-400 caps (seeds, crashes, input length, retained bytes 256 MiB
  with counted drops, campaign-wide minimisation budget that counts rejected candidates).
- Real in-process coverage: `CoverageSource` over the stdlib `Coverage` module with
  branch coverage; edge = `fnv1a64("basename:branch:target") mod 65536`; only target
  code measured; never touches a `Coverage` run it did not start (falls back to
  caller-reported edges under SimpleCov); tiers `ruby-coverage-branches`,
  `caller-reported`, `black-box-uninstrumented`.
- Hardened executor: any exception is a crash except `NoMemoryError` (OOM) and the
  process-owned ones; kind read through bound `Kernel#class`/`Module#name`, frames
  through bound `backtrace_locations`, the message never read; sticky shared budget
  exhaustion judged after the target returns or raises; a fresh `Handle` per execution
  retired in `ensure`, mutated under a Mutex; sentinels carry a campaign token and an
  epoch (`stale-budget-sentinel`); the input is `dup.b` copied outside the guarded region.
- Inert `Report`/`CrashRecord` (no bytes or seed in `inspect`/`to_s`, frozen copies);
  `format_tap_failure` (closed ids, target truncated before encoding, control characters
  replaced) and `tap_failures`.
- `Fuzz::Corpus` runner for fuzz-v1 (25 cases) with aggregate work cap, escaped case ids,
  and `Fuzz::Hooks` sabotage seams.
- Tests: whole-corpus replay, per-op corruption controls, 820 Go reference vectors,
  pinned sig_hash/energy/interest/delta/splice values, campaign and handle-lifetime
  tests, real-Coverage subprocess tests.
- Spec `VER06i-ruby-fuzz-engine.md`.
