## You'll want to know: hacher
<!-- hl-knowledge: introduces=[FR-LEX-C328-COUPER-03]; assesses=[] -->

**hacher** — "to chop, to mince".

> Elle hache les oignons très fin.
>
> *She chops the onions very finely.*

*La viande hachée* — minced meat; *un steak haché* — a burger patty.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*hacher* is built on *hache* "axe", which comes from a Frankish word *hapja* (EtymDB).
