## You'll want to know: برنامه ریزی کردن
<!-- hl-knowledge: introduces=[FA-LEX-C382-PROZHE-03]; assesses=[] -->

**برنامه ریزی کردن** (*barnâme rizi kardan*) — "to plan, to schedule".

> ما برای تعطیلات تابستان برنامه ریزی کردیم.
>
> *mâ barâye ta'tilât-e tâbestân barnâme rizi kardim.*
>
> We made plans for the summer holidays.

*Barnâme* "programme" + *rizi* "pouring", from *rikhtan* "to pour", + *kardan*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**برنامه ریزی کردن** is native Persian, built from *barnâme* "programme", which EtymDB traces to Middle Persian *barnāmag*, + *rizi*, built on *riz-*, the present stem of *rikhtan* "to pour", + *kardan*. To plan is to pour out a programme.
