## You'll want to know: esforzarse
<!-- hl-knowledge: introduces=[ES-LEX-C598-SABER-04]; assesses=[] -->

**esforzarse** — "to make an effort, to try hard".

> Me esfuerzo mucho en clase.
>
> *I try very hard in class.*

Stem change o→ue: *me esfuerzo*. Spelling: *me esforcé*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*esforzarse* is built on *fuerza* 'strength', inherited from Late Latin *fortia*, from *fortis* 'strong' (EtymDB).
