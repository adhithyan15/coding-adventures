# 看到 — 没看到: a verb and its result

## Warm-up

## Grammar Lens: a verb, then what came of it
<!-- hl-knowledge: introduces=[ZH-GRAMMAR-RESULT-COMPLEMENT-01]; assesses=[ZH-LEX-C151-KANDAO-01, ZH-LEX-KANJIAN-01, ZH-GRAMMAR-BU-MEI-01, ZH-LEX-KAN-01] -->

> **A second word straight after a verb can say how it turned out. 看 is looking; 看到 is looking that reached something.**

> **我看了 没看到** *wǒ kàn le, méi kàndào* — I looked, but I didn't spot it.

The negative is 没, because the result did not come about:

> **我没看到他** *wǒ méi kàndào tā* — I didn't see him.
> **你看到了吗** *nǐ kàndào le ma* — Did you see it?

看见 is made the same way, 看 and its result 见. The next four lessons add four more pairs like these, each a verb and how it ended.
