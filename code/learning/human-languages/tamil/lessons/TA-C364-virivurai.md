# விரிவுரை (virivurai) — a lecture

## You'll want to know: விரிவுரை
<!-- hl-knowledge: introduces=[TA-LEX-C364-PERACIRIYAR364-02]; assesses=[] -->

**விரிவுரை** — *virivurai* — "a lecture".

> இன்று காலை ஒரு சுவாரசியமான விரிவுரை கேட்டேன்.
>
> *iṉṟu kālai oru cuvāraciyamāṉa virivurai kēṭṭēṉ.*
>
> This morning I heard an interesting lecture.

விரிவுரையாளர், a lecturer: -ஆளர், the one who.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**விரிவுரை** (*virivurai*) is native: *virivu*, "expansion", from *viri*, "to spread out, unfold" (DEDR 5411), and *urai*, "speech" (DEDR 648): a talk that unfolds a subject.
