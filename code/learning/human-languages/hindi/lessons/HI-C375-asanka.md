# आशंका (āśaṅkā) — an apprehension, a fear (that something will happen)

## You'll want to know: आशंका
<!-- hl-knowledge: introduces=[HI-LEX-C375-ASHA375-02]; assesses=[] -->

**आशंका** — *āśaṅkā* — "an apprehension, a fear (that something will happen)".

> आशंका है कि अगर बाढ़ आई तो पुल टूट जाएगा।
>
> *āśaṅkā hai ki agar bāṛh āī to pul ṭūṭ jāegā.*
>
> There are fears that if the flood comes, the bridge will collapse.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**आशंका** (*āśaṅkā*) is a tatsama, borrowed from Sanskrit *āśaṅkā*, "a doubt, a fear" (Monier-Williams).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
