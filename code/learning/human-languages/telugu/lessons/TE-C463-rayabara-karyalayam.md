# రాయబార కార్యాలయం (rāyabāra kāryālayaṁ) — an embassy

## You'll want to know: రాయబార కార్యాలయం
<!-- hl-knowledge: introduces=[TE-LEX-C463-RAYABARI463-01]; assesses=[] -->

**రాయబార కార్యాలయం** — *rāyabāra kāryālayaṁ* — "an embassy".

> వీసా కోసం రాయబార కార్యాలయానికి వెళ్ళాను.
>
> *vīsā kōsaṁ rāyabāra kāryālayāniki veḷḷānu.*
>
> I went to the embassy for a visa.

రాయబారం, an embassy or a mission, + కార్యాలయం, an office.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**రాయబార కార్యాలయం** (*rāyabāra kāryālayaṁ*) is a Telugu phrase: రాయబార, "of an envoy", whose origin is not settled, and కార్యాలయం, "an office", built from Sanskrit *kārya*, "work", and *ālaya*, "a house" (Monier-Williams).
