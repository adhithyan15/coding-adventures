# ضريح (ḍarīḥ) — a tomb, a mausoleum

## You'll want to know: ضريح
<!-- hl-knowledge: introduces=[AR-LEX-C338-MAWTA338-02]; assesses=[] -->

**ضريح** — *ḍarīḥ* — "a tomb, a mausoleum".

> زار السياح ضريح الملك القديم.
>
> *zāra as-suyyāḥ ḍarīḥ al-malik al-qadīm.*
>
> The tourists visited the old king’s tomb.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ضريح** (*ḍarīḥ*) is built on the native Arabic root *ḍ-r-ḥ* (Lane), "to dig a trench for the dead"; a *ḍarīḥ* is first that grave, then a built tomb.
