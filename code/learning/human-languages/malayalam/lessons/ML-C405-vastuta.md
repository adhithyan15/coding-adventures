## You'll want to know: വസ്തുത
<!-- hl-knowledge: introduces=[ML-LEX-C405-VADAM405-03]; assesses=[] -->

**വസ്തുത** — *vastuta* — "a fact".

> ഇത് ഒരു വസ്തുതയാണ്, അഭിപ്രായമല്ല.
>
> *itŭ oru vastutayāṇŭ, abhiprāyamalla.*
>
> This is a fact, not an opinion.

Plural: വസ്തുതകൾ, *vastutakaḷ*.

Plural: വസ്തുതകൾ, the facts of a case.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**വസ്തുത** (*vastuta*) is built on Sanskrit *vastu*, "a thing that exists; an affair" (CDIAL 11449), with the abstract ending -ത; Sanskrit itself has *vastutā* (Monier-Williams). A fact is what a thing really is.
