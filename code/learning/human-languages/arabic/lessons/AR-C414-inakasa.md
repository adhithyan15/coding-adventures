# انعكس (inʿakasa) — to be reflected

## You'll want to know: انعكس
<!-- hl-knowledge: introduces=[AR-LEX-C414-NATIJA414-03]; assesses=[] -->

**انعكس** — *inʿakasa* — "to be reflected".

> انعكس التوتر على صحته.
>
> *inʿakasa at-tawattur ʿalā ṣiḥḥatih.*
>
> The stress was reflected in his health.

Present: ينعكس, *yanʿakis*.

It takes على: انعكس على ….

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**انعكس** (*inʿakasa*) is built on the native Arabic root *ʿ-k-s*, "to reverse, to turn back" (Lane). It is Form VII, to be turned back: to be reflected, like light from a mirror.
