## You'll want to know: épousseter
<!-- hl-knowledge: introduces=[FR-LEX-C528-MENAGE-02]; assesses=[] -->

**épousseter** — "to dust".

> Elle époussette les meubles du salon.
>
> *She dusts the furniture in the living room.*

Spelling: *j'époussette*. Built on *la poussière*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*épousseter* is built on an old word *pousse* "dust", which goes back to Latin *pulvis* "dust" (Lewis & Short); *la poussière* has the same source.
