# Add one writing line

## Warm-up
<!-- hl-knowledge: introduces=[MR-A1-MESSAGE-LINE-WRITE-NAME]; assesses=[MR-LEX-LIHINE, MR-GRAMMAR-PRESENT-GENDER] -->

Read the old sentence **मी माझं नाव लिहितो.** The middle names the object; the
last word carries Arun's masculine ending.

## Writing — delayed copy
<!-- hl-knowledge: introduces=[]; assesses=[MR-LEX-LIHINE, MR-GRAMMAR-PRESENT-GENDER, MR-A1-MESSAGE-LINE-WRITE-NAME] -->
<!-- hl-writing-stage: delayed-copy -->

Study the line, hide it, and wait eight seconds. Write it from memory. Compare
in two passes: first **माझं नाव**, then **लिहितो**. Repair only one pass today.
