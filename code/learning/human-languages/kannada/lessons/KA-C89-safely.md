## You'll want to know: ಜೋಪಾನ

**ಜೋಪಾನ** (*jōpāna*) — "carefully, safely".

**ಜೋಪಾನವಾಗಿ ಹೋಗಿ** (*jōpānavāgi hōgi*) — "go safely", with the same **‑ಆಗಿ**
