## You'll want to know: струна
<!-- hl-knowledge: introduces=[RU-LEX-C515-INSTRUMENTS-04]; assesses=[] -->

**струна** (*struná*) — "a string (of an instrument)".

> На гитаре порвалась струна.
>
> *Na gitáre porvalás struná.*
>
> A string has broken on the guitar.

Feminine; plural струны.
