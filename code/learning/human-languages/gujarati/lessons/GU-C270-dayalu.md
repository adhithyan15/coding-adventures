# દયાળુ (dayāḷu) — kind, compassionate

## You'll want to know: દયાળુ
<!-- hl-knowledge: introduces=[GU-LEX-C270-NATURE270-02]; assesses=[] -->

**દયાળુ** — *dayāḷu* — "kind, compassionate".

> **શું તમારા સાહેબ દયાળુ છે?** — *śũ tamārā sāheb dayāḷu che?* — "Is your boss kind?"

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**દયાળુ** (*dayāḷu*) is built on *dayā*, Sanskrit *dayā́*, "sympathy" (CDIAL 6185), with the adjective suffix *-āḷu*, "full of".
