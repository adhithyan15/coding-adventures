# ಠೇವಣಿ (ṭhēvaṇi) — a security deposit; a deposit

## You'll want to know: ಠೇವಣಿ
<!-- hl-knowledge: introduces=[KA-LEX-C461-ATITHI461-03]; assesses=[] -->

**ಠೇವಣಿ** — *ṭhēvaṇi* — "a security deposit; a deposit".

> ಮನೆಯ ಬಾಡಿಗೆಗೆ ಅವರು ಹತ್ತು ತಿಂಗಳ ಠೇವಣಿ ಕೇಳಿದರು.
>
> *maneya bāḍigege avaru hattu tiṅgaḷa ṭhēvaṇi kēḷidaru.*
>
> For renting the house they asked for ten months as a deposit.

ಠೇವಣಿ ಇಡು, to make a deposit; ಮುಂಗಡ is an advance.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಠೇವಣಿ** (*ṭhēvaṇi*) is usually traced to Marathi *ṭhevṇī*, "a thing placed, a deposit", from a verb meaning "to put, to keep"; the path into Kannada is not settled.
