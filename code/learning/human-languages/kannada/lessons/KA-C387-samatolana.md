## You'll want to know: ಸಮತೋಲನ
<!-- hl-knowledge: introduces=[KA-LEX-C387-SAVALU387-03]; assesses=[] -->

**ಸಮತೋಲನ** — *samatōlana* — "balance".

> ಕೆಲಸ ಮತ್ತು ಮನೆಯ ನಡುವೆ ಸಮತೋಲನ ಬೇಕು.
>
> *kelasa mattu maneya naḍuve samatōlana bēku.*
>
> We need a balance between work and home.

ಸಮ (even) + ತೋಲನ (weighing).

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಸಮತೋಲನ** (*samatōlana*) is built from Sanskrit *sama*, "even, equal", and *tolana*, "weighing" (Monier-Williams).
