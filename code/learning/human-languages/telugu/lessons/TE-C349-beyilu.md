# బెయిలు (beyilu) — bail

## You'll want to know: బెయిలు
<!-- hl-knowledge: introduces=[TE-LEX-C349-NYAYAM349-05]; assesses=[] -->

**బెయిలు** — *beyilu* — "bail".

> నిందితుడికి బెయిలు దొరికింది.
>
> *nindituḍiki beyilu dorikindi.*
>
> The accused got bail.

బెయిలు మీద విడుదల, release on bail.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**బెయిలు** (*beyilu*) is a loan from English *bail*, with the final -ఉ.

<!-- hl-knowledge: introduces=[]; assesses=[] -->
