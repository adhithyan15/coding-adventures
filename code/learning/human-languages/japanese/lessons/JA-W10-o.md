# お — the respectful opening sign

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[JA-LEX-ONEGAI-SHIMASU, JA-SCRIPT-SE-01, JA-LEX-YOKU] -->

[PAUSE 12s] Say *onegaishimasu*, write **せ**, then retrieve *yoku* as “well.”

## Script — the shape
<!-- hl-knowledge: introduces=[JA-SCRIPT-O-01]; assesses=[] -->

> **お** — *o*

Three strokes. Write the short top horizontal, then the long central stroke that
curves left and loops right. Finish with the small separate mark at upper right.
