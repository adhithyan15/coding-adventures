# Changelog

## 0.1.0

- Added complete MC6809 programmer-visible state and checked 64 KiB memory.
- Added every documented base, page-2, and page-3 opcode classification.
- Added all 217 legal indexed-postbyte forms, including indirect and
  PC-relative addressing.
- Added dual-stack operations, transfers, software interrupts, exact traces,
  typed atomic faults, and bounded transactional execution.
