## You'll want to know: a pousada
<!-- hl-knowledge: introduces=[PT-LEX-C425-DORMIR-02]; assesses=[] -->

**a pousada** — "the country inn; the hotel in a historic building".

> Dormimos numa pousada num castelo antigo.
>
> *We slept in an inn in an old castle.*

*A pousada de juventude* — the youth hostel.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*pousada* is built on *pousar* 'to set down, to rest', which is inherited from Latin *pausāre* 'to halt, to rest' (EtymDB).
