# કાશ (kāś) — if only

## You'll want to know: કાશ
<!-- hl-knowledge: introduces=[GU-LEX-C381-PASTAVO381-03]; assesses=[] -->

**કાશ** — *kāś* — "if only".

> કાશ મારી પાસે વધારે સમય હોત!
>
> *kāś mārī pāse vadhāre samay hot!*
>
> If only I had more time!

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**કાશ** (*kāś*) is usually traced to Persian *kāsh*, "would that"; in Gujarati it opens a wish that did not come true.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
