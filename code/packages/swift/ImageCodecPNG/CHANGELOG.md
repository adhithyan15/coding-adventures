# Changelog

## 0.1.0 - 2026-08-20

- Add a native Swift IC18 PNG encoder and bounded decoder.
- Reuse the repository Swift ZIP package for raw RFC 1951 and CRC-32.
- Consume all 85 language-neutral PNG fixtures through public APIs.
- Add deterministic filtering, exact inflate-consumption checks, APNG refusal,
  stable payload-blind errors, resource ceilings, coverage, an independent
  Python decoder, and real platform ImageIO/WIC decoder evidence.
