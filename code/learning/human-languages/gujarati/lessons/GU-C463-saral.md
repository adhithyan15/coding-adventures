# સરળ (saraḷ) — straightforward (of a person)

## You'll want to know: સરળ
<!-- hl-knowledge: introduces=[GU-LEX-C463-VACAL463-01]; assesses=[] -->

**સરળ** — *saraḷ* — "straightforward (of a person)".

> મારી બહેનપણી સરળ સ્વભાવની છે.
>
> *mārī bahenpaṇī saraḷ svabhāvnī che.*
>
> My friend has a straightforward nature.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**સરળ** (*saraḷ*) is a tatsama, Sanskrit *sarala*, "straight, not crooked", as Monier-Williams records it.
