## You'll want to know: हँसी
<!-- hl-knowledge: introduces=[HI-LEX-C109-MOOD-01]; assesses=[] -->

**हँसी** (*hãsī*) — "laughter". It is feminine.

**मुझे हँसी आ गई** — "I burst out laughing", literally "laughter came to me", like anger.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

Laughter, which comes to you like anger does.
