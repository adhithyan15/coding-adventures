## You'll want to know: ലിപി
<!-- hl-knowledge: introduces=[ML-LEX-C404-CHARITHRAM404-04]; assesses=[] -->

**ലിപി** — *lipi* — "a script; writing".

> മലയാള ലിപിയിൽ ഒരുപാട് അക്ഷരങ്ങൾ ഉണ്ട്.
>
> *malayāḷa lipiyil orupāṭŭ akṣaraṅṅaḷ uṇṭŭ.*
>
> The Malayalam script has many letters.

Also any system of writing.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ലിപി** (*lipi*) is borrowed from Sanskrit *lipi*, "writing" (CDIAL 11058); CDIAL traces the Sanskrit word itself to Old Persian *dipi*, "an inscription".
