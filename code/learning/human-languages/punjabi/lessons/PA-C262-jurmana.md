# ਜੁਰਮਾਨਾ (jurmānā) — a fine; a penalty

## You'll want to know: ਜੁਰਮਾਨਾ
<!-- hl-knowledge: introduces=[PA-LEX-C262-FEE262-03]; assesses=[] -->

**ਜੁਰਮਾਨਾ** — *jurmānā* — "a fine; a penalty".

> ਜੇ ਤੁਹਾਡੇ ਕੋਲ ਟਿਕਟ ਨਹੀਂ ਹੈ ਤਾਂ ਤੁਸੀਂ ਜੁਰਮਾਨਾ ਭਰੋਗੇ।
>
> *je tuhāḍe kol ṭikaṭ nahīṁ hai tāṁ tusī̃ jurmānā bharoge.*
>
> If you have no ticket, you will pay a fine.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ਜੁਰਮਾਨਾ** (*jurmānā*) is a loan, usually traced to Persian *jurmāna*, "a fine".
