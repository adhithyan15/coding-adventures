## You'll want to know: fiscalizar
<!-- hl-knowledge: introduces=[PT-LEX-C408-PEOES-05]; assesses=[] -->

**fiscalizar** — "to inspect, to check (officially)".

> A polícia fiscaliza a velocidade nesta estrada.
>
> *The police check speeds on this road.*

*A fiscalização* — the inspection, the checks.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*fiscalizar* is built on *fiscal* 'inspector', from *fisco* 'treasury', which goes back to Latin *fiscus* 'basket; treasury' (EtymDB).
