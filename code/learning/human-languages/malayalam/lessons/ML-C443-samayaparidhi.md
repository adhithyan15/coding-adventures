# സമയപരിധി (samayaparidhi) — a deadline; a time limit

## You'll want to know: സമയപരിധി
<!-- hl-knowledge: introduces=[ML-LEX-C443-PARIDHI443-05]; assesses=[] -->

**സമയപരിധി** — *samayaparidhi* — "a deadline; a time limit".

> അപേക്ഷ നൽകാനുള്ള സമയപരിധി നാളെ തീരും.
>
> *apēkṣa nalkānuḷḷa samayaparidhi nāḷe tīruṁ.*
>
> The deadline for applying ends tomorrow.

സമയം, time, and പരിധി, a limit.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**സമയപരിധി** (*samayaparidhi*) is a Malayalam compound built from Sanskrit *samaya*, "a meeting; an appointed time" (CDIAL 13185), and *paridhi*, "an enclosure" (Monier-Williams): the fence round a stretch of time.
