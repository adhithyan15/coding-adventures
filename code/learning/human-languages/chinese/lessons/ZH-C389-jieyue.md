## You'll want to know: 节约
<!-- hl-knowledge: introduces=[ZH-LEX-C389-INCASE389-02]; assesses=[] -->

**节约** — *jiéyuē* — "to economise; to use sparingly".

> *rúguǒ dàjiā dōu jiéyuē yòng shuǐ jiù néng shěngqián* — If everyone uses water sparingly, we can all save money.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**节约** (*jiéyuē*) is built from 节 'to restrain' and 约 'sparing', both inherited from Middle Chinese, *tset* and *'jak* (Guangyun, in Baxter's transcription), which glosses the first 'to hold back' and the second 'thrifty'.
