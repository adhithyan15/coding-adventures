## You'll want to know: мошенник
<!-- hl-knowledge: introduces=[RU-LEX-C290-MOSHENNIK-01]; assesses=[] -->

**мошенник** (*moshénnik*) — "a swindler, a fraudster".

> Мошенник позвонил бабушке.
>
> *Moshénnik pozvoníl bábushke.*
>
> A swindler phoned Grandma.

*Мошенничество* — fraud.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*мошенник* is usually traced to the old word *мошна* "a purse", so first "a cutpurse"; EtymDB lists no parent.
