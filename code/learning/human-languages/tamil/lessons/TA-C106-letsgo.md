## You'll want to know: போகலாம்
<!-- hl-knowledge: introduces=[TA-LEX-C106-CARE-04]; assesses=[] -->

**போகலாம்** (*pōkalām*) — "let's go", "we can go".

It is **போ**, "go", with **-லாம்**, "may, let us".
