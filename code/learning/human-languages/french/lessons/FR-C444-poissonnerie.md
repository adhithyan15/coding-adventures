## You'll want to know: la poissonnerie
<!-- hl-knowledge: introduces=[FR-LEX-C444-COMMERCES-02]; assesses=[] -->

**la poissonnerie** — "the fishmonger’s, the fish shop".

> Le vendredi, il y a la queue devant la poissonnerie.
>
> *On Fridays there is a queue outside the fish shop.*

*Le poissonnier* — the fishmonger.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*poissonnerie* is built on *poisson* 'fish', which goes back to Latin *piscis* (Lewis & Short). EtymDB does not list the shop name.
