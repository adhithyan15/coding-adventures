# માન્ય (mānya) — valid; accepted

## You'll want to know: માન્ય
<!-- hl-knowledge: introduces=[GU-LEX-C356-BANDHARAN356-04]; assesses=[] -->

**માન્ય** — *mānya* — "valid; accepted".

> આ પરવાનો ફક્ત એક વરસ માટે માન્ય છે.
>
> *ā parvāno phakt ek varas māṭe mānya che.*
>
> This licence is valid for one year only.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**માન્ય** (*mānya*) is a tatsama, borrowed from Sanskrit *mānya*, "to be respected, to be honoured" (Monier-Williams); Gujarati uses it for what an office accepts as valid.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
