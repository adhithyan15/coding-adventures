# Copying an assessment template must preserve each track's script aids and source dates

Marwadi and Punjabi B1 task-shape inventories began from the comparable Marathi
B1 envelope. A security review found that the generic template omitted the
Marwadi ban on Hindi replacement, the Punjabi ban on Shahmukhi substitution,
and romanization from listening aids, even though the same tracks' A2
inventories already forbade them. The copied source records also retained
Marathi's old access date, and Marwadi's authored specification had a
different version date. Before publishing a derived inventory, compare its
aid restrictions with the track's prior rung and its source dates with the
actual authored contracts; pin both in per-track tests.
