## You'll want to know: கோல்
<!-- hl-knowledge: introduces=[TA-LEX-C535-AADUKALAM535-03]; assesses=[] -->

**கோல்** — *kōl* — "a goal in sport".

> கடைசி நிமிடத்தில் அவன் ஒரு கோல் போட்டான்.
>
> *kaṭaici nimiṭattil avaṉ oru kōl pōṭṭāṉ.*
>
> In the last minute he scored a goal.

One scores with போடு (*pōṭu*) or அடி: கோல் போடு. It sounds like the native கோல், a stick.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**கோல்** (*kōl*) in the sense "a goal" is a loan from English *goal*; it sounds the same as the native கோல் (*kōl*), "a stick, a rod", a different word.
