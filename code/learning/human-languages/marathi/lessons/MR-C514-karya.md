## You'll want to know: कार्य
<!-- hl-knowledge: introduces=[MR-LEX-C514-KAMKAJ514-01]; assesses=[] -->

**कार्य** — *kārya* — "a task; a function".

> हे कार्य आज संध्याकाळपर्यंत पूर्ण झालं.
>
> *he kārya āj sandhyākāḷparyant pūrṇa jhālaṁ.*
>
> This task was finished by this evening.

Neuter.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**कार्य** (*kārya*) is a tatsama, taken from Sanskrit *kārya*, "what is to be done, work" (Monier-Williams).
