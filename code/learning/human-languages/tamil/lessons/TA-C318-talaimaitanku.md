# தலைமைதாங்கு (talaimaitāṅku) — to preside

[PAUSE 2s] Before the new one: say the Tamil for a standing lamp, then the Tamil for a chief guest.

## You'll want to know: தலைமைதாங்கு
<!-- hl-knowledge: introduces=[TA-LEX-C318-VIZHA318-04]; assesses=[] -->

**தலைமைதாங்கு** — *talaimaitāṅku* — "to preside".

> ஊர்ப் பெரியவர் விழாவுக்குத் தலைமைதாங்கினார்.
>
> *ūrp periyavar viḻāvukkut talaimaitāṅkiṉār.*
>
> A village elder presided over the ceremony.

Past (I …): தலைமைதாங்கினேன், *talaimaitāṅkiṉēṉ*.

The event takes -க்கு: விழாவுக்குத் தலைமைதாங்கு.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**தலைமைதாங்கு** (*talaimaitāṅku*) is a Tamil compound built from தலைமை, "leadership" (DEDR 3103), and தாங்கு, "to bear, support" (DEDR 3153): to bear the lead.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
