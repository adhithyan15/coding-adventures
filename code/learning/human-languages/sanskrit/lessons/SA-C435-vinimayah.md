## You'll want to know: विनिमयः
<!-- hl-knowledge: introduces=[SA-LEX-C435-DINARA435-04]; assesses=[] -->

**विनिमयः** — *vinimayaḥ* — "barter; exchange".

> पूर्वं ग्रामेषु धान्यस्य विनिमयः भवति स्म।
>
> *pūrvaṃ grāmeṣu dhānyasya vinimayaḥ bhavati sma.*
>
> Long ago grain used to be bartered in the villages.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**विनिमयः** (*vinimayaḥ*) is built from *vi*, *ni* and the root √me, "to exchange"; MW gives *vinimaya* as exchange, barter (MW).
