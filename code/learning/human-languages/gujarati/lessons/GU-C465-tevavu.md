# ટેવાવું (ṭevāvũ) — to get used to

## You'll want to know: ટેવાવું
<!-- hl-knowledge: introduces=[GU-LEX-C465-SAKHAT465-05]; assesses=[] -->

**ટેવાવું** — *ṭevāvũ* — "to get used to".

> નવા ઘરમાં બાળકો જલદી ટેવાઈ ગયાં.
>
> *navā gharmā̃ bāḷko jaldī ṭevāī gayā̃.*
>
> The children quickly got used to the new house.

Past (he …): તે ટેવાઈ ગયો, *te ṭevāī gayo*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ટેવાવું** (*ṭevāvũ*) is built on **ટેવ** (*ṭev*), "a habit", which CDIAL traces to a reconstructed *\*ṭēv-*, "appoint, fix" (CDIAL 5475), with the verb ending *-āvũ*.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
