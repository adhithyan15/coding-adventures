## [0.1.0] - 2026-11-16

### Added

- `TokenizeLine(line)`: tokenizes one strace line with the grammar in
  `code/grammars/strace/strace.tokens`, compiled once at package load with
  `lexer.Compile`. Total (an `ERR_*` token marks what the grammar refuses),
  case-sensitive, and with every rule on the fast byte matchers
  (`SlowRules()` is empty; a test asserts it).
- `FirstError`, `IsErrToken`, `Ambiguous` to find a refused line and classify it
  as an ambiguous path or an unparsable line, like the old scanner.
- `DecodeString` and `DecodeAnnotation`: strict decoding of the escapes in a
  quoted string or a `-y` annotation, with the grammar in
  `code/grammars/strace/strace-string.tokens`.
- `AnnotationBody` and `QuotedBody` helpers; `Compiled` and `StringCompiled`
  expose the compiled grammars.
- Tests: grammar drift against the `.tokens` files, case sensitivity, no slow
  rules, no token named `*STRING*`, every token shape, the refusal shapes,
  totality over random and fuzzed input, the corpus of lines from kiln's tests.
