# તું / તમે (tũ / tame) — "you," familiar and respectful

## Warm-up

[PAUSE 2s] To ask a name you need "you" — and Gujarati grades respect the way
French does.

## The letters in this word

**તું** (*tũ*): **ત** (*ta*) + the *u*-sign + nasal. **તમે** (*tame*): **ત** +
**મ** + **ે**.

## The word, taken apart

**તું** (*tũ*, familiar "you") ← Sanskrit *tvam*, from PIE **\*tū** — the same
root as English archaic **thou**, Latin *tū*, French *tu*, and Hindi *tū*. **તમે**
(*tame*, respectful "you") is grammatically plural — courtesy-by-plural, like
French *vous* and Hindi *āp*. For a first meeting, use **તમે**; it takes the
plural copula *chho* (*tame … chho*).
