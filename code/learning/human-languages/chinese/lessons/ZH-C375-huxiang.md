## You'll want to know: hùxiāng
<!-- hl-knowledge: introduces=[ZH-LEX-C375-HELP375-05]; assesses=[] -->

*hùxiāng* — "each other; mutually".

> *dàjiā yīnggāi hùxiāng bāngmáng* — Everyone should help each other.

Its characters come later; for now it is a word for the ear.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*hùxiāng* is built from *hù* and *xiāng*, both inherited from Middle Chinese, *huH* and *sjang* (Guangyun, in Baxter's transcription), which glosses the first 'interlocking' and the second 'together'.
