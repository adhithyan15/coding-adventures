# las letras voladitas — the little letters that sit above the line

## Warm-up

## The word, taken apart
<!-- hl-knowledge: introduces=[ES-ORTH-C426-04]; assesses=[] -->

**las letras voladitas** — "the flown letters," raised above the line. Spanish
uses exactly two of them, **º** and **ª**, and which one you use is decided by
gender.

Their commonest job is the **ordinal indicator**:

| written | read |
|---|---|
| 1.º | primero |
| 1.ª | primera |
| 2.º | segundo |
| n.º | número |

English writes *1st* and *2nd*, changing the ending with the number. Spanish
writes the same raised letter every time and changes it only for **gender**:
**º** for a masculine word, **ª** for a feminine one.

## Grammar Lens: the point goes before the raised letter
<!-- hl-knowledge: introduces=[]; assesses=[ES-ORTH-C426-04, ES-ORTH-C426-03] -->

| correct | wrong |
|---|---|
| 1.º | 1º |
| Sr.ª | Srª |

The Academy's recommendation puts the **point first and the raised letter
after**, because the point is the abbreviation mark and the raised letter is
the ending. You will see the pointless form printed everywhere; the one with the
point is the one to write.

A warning about the shape. **º** is a raised letter **o**, not a degree sign,
even though the two look nearly identical. A temperature uses the degree sign;
an ordinal uses the letter.
