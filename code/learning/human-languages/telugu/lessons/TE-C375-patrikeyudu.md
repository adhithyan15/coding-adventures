## You'll want to know: పాత్రికేయుడు
<!-- hl-knowledge: introduces=[TE-LEX-C375-PATRIKEYUDU375-01]; assesses=[] -->

**పాత్రికేయుడు** — *pātrikēyuḍu* — "a journalist".

> ఆ పాత్రికేయుడు ముప్పై ఏళ్ళు పని చేశాడు.
>
> *ā pātrikēyuḍu muppai ēḷḷu pani cēśāḍu.*
>
> That journalist worked for thirty years.

Plural: పాత్రికేయులు, *pātrikēyulu*.

Built on పత్రిక, a periodical.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**పాత్రికేయుడు** (*pātrikēyuḍu*) is a modern word built on Sanskrit *pattrikā*, "a letter, a document" (Monier-Williams), the source of పత్రిక.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
