# ಕರೆಯಿರಿ (kareyiri) — please call

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C101-OPEN-02, KA-LEX-C101-OPEN-03] -->

[PAUSE 2s] Before the new one: say the Kannada for please close, then the Kannada for please stop.

## You'll want to know: ಕರೆಯಿರಿ
<!-- hl-knowledge: introduces=[KA-LEX-C101-OPEN-04]; assesses=[] -->

**ಕರೆಯಿರಿ** (*kareyiri*) — "please call (someone)".

**ವೈದ್ಯರನ್ನು ಕರೆಯಿರಿ** (*vaidyarannu kareyiri*) — "please call the doctor".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

The request when help is needed.
