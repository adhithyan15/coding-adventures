## Chapter 2 — the pre-A1 writing ladder, and the head-line that belongs to the word

Bengali had **no writing-stage evidence at all**: seventy-four script lessons and
not one directive. All four stages now sit on **ন**, the first letter the book
teaches, and three of the four are about the same thing — the **মাত্রা**, the bar
across the top.

- **observe-trace** — finger-trace the letter, model visible, saying *nô* each
  time, and leave the bar **for last** every time. Where each curve of the body
  starts is still not written down, because Bengali handwriting varies from
  school to school and this book does not assert a ductus it cannot cite. The
  bar is the exception, and not on stylistic grounds: the মাত্রা joins up across
  a whole word, so it cannot be the first thing drawn on a letter that is about
  to have neighbours.
- **guided-copy** — copy **ন** once, then **twice side by side**, drawing both
  bodies first and finishing with **one single bar running across both**. That
  one continuous line is the lesson. In Bengali the bar is not a mark belonging
  to a letter; it is a line belonging to the **word**, which a reader's eye
  follows to find where one word stops. A hand that gives each letter its own
  short bar has written two words where it meant one.
- **delayed-copy** — model covered, ten seconds, write from memory. Check the
  bar's **width** before the body. A hand writing from memory remembers to put
  the bar there and draws it only as wide as the body underneath — which looks
  completely right on a single letter and falls apart the moment there are two.
- **dictation-transcription** — write it from *nô*, **not** *na*. This is the
  place that fact matters: a reader coming from Hindi or Sanskrit hears *na*,
  writes the same shape, and has learned the letter with the wrong vowel
  attached. The shape is shared across the family; the default vowel is not, and
  dictation is the only stage that can catch it, because it is the only one
  where the sound comes first.
