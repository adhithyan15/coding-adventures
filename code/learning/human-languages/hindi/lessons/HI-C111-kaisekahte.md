# कैसे कहते हैं? (kaise kahte haiṁ?) — how do you say it?

## You'll want to know: कैसे कहते हैं?
<!-- hl-knowledge: introduces=[HI-LEX-C111-ASK-02]; assesses=[] -->

**कैसे कहते हैं?** (*kaise kahte haiṁ?*) — "how does one say it?".

**हिंदी में 'book' कैसे कहते हैं?** — "how do you say 'book' in Hindi?". **कहना** is "to say".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

The one question that lets you learn from anyone.
