# ತಿರಸ್ಕರಿಸು (tiraskarisu) — to reject

## You'll want to know: ತಿರಸ್ಕರಿಸು
<!-- hl-knowledge: introduces=[KA-LEX-C425-SVIKARISU425-02]; assesses=[] -->

**ತಿರಸ್ಕರಿಸು** — *tiraskarisu* — "to reject".

> ಸಂಸ್ಥೆ ನನ್ನ ಅರ್ಜಿಯನ್ನು ತಿರಸ್ಕರಿಸಿತು.
>
> *saṃsthe nanna arjiyannu tiraskarisitu.*
>
> The organisation rejected my application.

Past (I …): ತಿರಸ್ಕರಿಸಿದೆ, *tiraskariside*.

ತಿರಸ್ಕಾರ, contempt or rejection.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ತಿರಸ್ಕರಿಸು** (*tiraskarisu*) is built on Sanskrit *tiraskāra*, "placing aside; contempt" (Monier-Williams), with the Kannada verb ending -*isu*.
