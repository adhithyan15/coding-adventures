## You'll want to know: королева
<!-- hl-knowledge: introduces=[RU-LEX-C321-KOROL-02]; assesses=[] -->

**королева** (*koroléva*) — "a queen".

> Королева улыбалась и махала рукой.
>
> *Koroléva ulybálas i makhála rukóy.*
>
> The queen smiled and waved.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*королева* is built on *король* "king", inherited from Proto-Slavic *korľĭ* (EtymDB), with the feminine ending *-ева*.
