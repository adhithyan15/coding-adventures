# একগুঁয়ে (ekgũye) — obstinate; pig-headed

<!-- hl-knowledge: introduces=[]; assesses=[BN-LEX-C460-NISHTHUR460-05, BN-LEX-C461-JEDI461-01] -->

## You'll want to know: একগুঁয়ে
<!-- hl-knowledge: introduces=[BN-LEX-C461-JEDI461-02]; assesses=[] -->

**একগুঁয়ে** — *ekgũye* — "obstinate; pig-headed".

> একগুঁয়ে ছেলেটা ডাক্তারের কাছে যেতে রাজি হল না।
>
> *ekgũye chheleṭā ḍāktārer kāchhe jete rāji hôlô nā.*
>
> The obstinate boy would not agree to go to the doctor.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**একগুঁয়ে** (*ekgũye*) begins with এক, one, as if set on one thing only; the origin of the second part is not settled.
