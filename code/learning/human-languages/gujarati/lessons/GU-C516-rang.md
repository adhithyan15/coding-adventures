## You'll want to know: રંગ
<!-- hl-knowledge: introduces=[GU-LEX-C516-CHUNO516-03]; assesses=[] -->

**રંગ** — *rang* — "a colour".

> તમને કયો રંગ ગમે છે?
>
> *tamne kayo rang game che?*
>
> Which colour do you like?

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**રંગ** (*rang*) is a tatsama, taken from Sanskrit *raṅga*, "colour, paint, dye" (Monier-Williams). It also means paint: **લીલો રંગ**, green paint.
