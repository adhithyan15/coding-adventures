## You'll want to know: avariar
<!-- hl-knowledge: introduces=[PT-LEX-C406-AVARIA-02]; assesses=[] -->

**avariar** — "to break down".

> A máquina de café avariou outra vez.
>
> *The coffee machine broke down again.*

Mostly for machines: *o elevador avariou*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*avariar* is built on *avaria* 'fault', which came through Italian from Arabic *ʿawāriyya* 'damaged goods' (EtymDB).
