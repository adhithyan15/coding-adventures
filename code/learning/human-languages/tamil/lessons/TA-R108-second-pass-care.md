# Leaving well — a second pass

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TA-LEX-C106-CARE-03, TA-LEX-C106-CARE-04] -->

[PAUSE 3s] It has got late. Say so, and suggest you all go.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[TA-LEX-C106-CARE-01, TA-LEX-C106-CARE-02, TA-LEX-C106-CARE-03, TA-LEX-C106-CARE-04, TA-LEX-C106-CARE-05, TA-LEX-C108-GREET-04, TA-LEX-C108-GREET-05] -->

[PAUSE 2s each]
- [YOU SAY: tell your host to take care; they tell you to go safely]
- [YOU SAY: say tomorrow is a holiday]
- [YOU SAY: next week, greet the same host: are you well? how are you?]
