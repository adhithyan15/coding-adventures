# مہرہ (mohrā) — a piece (in a board game)

## You'll want to know: مہرہ
<!-- hl-knowledge: introduces=[UR-LEX-C534-BISAT534-02]; assesses=[] -->

**مہرہ** — *mohrā* — "a piece (in a board game)".

> اگر ایک مہرہ کھو گیا تو کھیل رک جائے گا۔
>
> *agar ek mohrā kho gayā to khel ruk jāe gā.*
>
> If a piece goes missing, the game will stop.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**مہرہ** (*mohrā*) is usually traced to Persian *muhra*, "a bead; a piece in a game".
