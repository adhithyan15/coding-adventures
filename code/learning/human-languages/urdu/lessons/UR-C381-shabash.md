# شاباش (shābāsh) — well done!

## You'll want to know: شاباش
<!-- hl-knowledge: introduces=[UR-LEX-C381-KAMYAB381-05]; assesses=[] -->

**شاباش** — *shābāsh* — "well done!".

> اگر تم جیتے تو سب تمہیں شاباش دیں گے۔
>
> *agar tum jīte to sab tumheṅ shābāsh deṅ ge.*
>
> If you win, everyone will say well done.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**شاباش** (*shābāsh*) is usually traced to Persian *shād bāsh*, "be happy", run together into one cry of praise.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
