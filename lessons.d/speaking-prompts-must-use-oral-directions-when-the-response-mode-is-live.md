# Speaking prompts must use oral directions when the response mode is live speech

A collaborative speaking brief instructed the learners to write their joint
decision even though the task shape requires live spoken integration and bans
a prepared written answer. Productive-task checks looked only for timings and
source bands, so the contradiction passed. Use oral verbs in live-speech
directions and make the owned test reject writing instructions inside speaking
sections.
