# ശ്വാസംമുട്ട് (śvāsaṁmuṭṭŭ) — breathlessness; wheezing

## You'll want to know: ശ്വാസംമുട്ട്
<!-- hl-knowledge: introduces=[ML-LEX-C533-VAKSIN533-05]; assesses=[] -->

**ശ്വാസംമുട്ട്** — *śvāsaṁmuṭṭŭ* — "breathlessness; wheezing".

> പുക കാരണം അവന് ശ്വാസംമുട്ട് ഉണ്ടായി.
>
> *puka kāraṇaṁ avanŭ śvāsaṁmuṭṭŭ uṇṭāyi.*
>
> The smoke made him breathless.

ശ്വാസം breath + മുട്ട് a blockage.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ശ്വാസംമുട്ട്** (*śvāsaṁmuṭṭŭ*) is a Malayalam compound built from ശ്വാസം, from Sanskrit *śvāsa*, "breath" (CDIAL 12769), and മുട്ട്, "a stoppage", which is native (DEDR 4933).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
