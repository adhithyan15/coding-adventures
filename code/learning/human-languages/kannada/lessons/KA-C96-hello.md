## You'll want to know: ಹಲೋ
<!-- hl-knowledge: introduces=[KA-LEX-C96-HELLO-04]; assesses=[] -->

**ಹಲೋ** (*halō*) — "hello", borrowed from English and used above all when
answering the phone. Face to face, **ನಮಸ್ಕಾರ** is still the greeting.
