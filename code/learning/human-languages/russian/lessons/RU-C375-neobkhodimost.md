## You'll want to know: необходимость
<!-- hl-knowledge: introduces=[RU-LEX-C375-NEOBKHODIMO-04]; assesses=[] -->

**необходимость** (*neobkhodímost*) — "necessity, need".

> В этом нет необходимости.
>
> *V étom net neobkhodímosti.*
>
> There is no need for that.

Feminine. *В случае необходимости* — if need be.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**необходимость** is built on *необходимый* "necessary" with the abstract suffix *-ость*; the root is *ходить* "to go".
