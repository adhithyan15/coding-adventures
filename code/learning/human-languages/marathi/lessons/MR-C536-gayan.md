## You'll want to know: गायन
<!-- hl-knowledge: introduces=[MR-LEX-C536-GAYAN536-01]; assesses=[] -->

**गायन** — *gāyan* — "singing as an art".

> संध्याकाळी शाळेत गायनाचा कार्यक्रम आहे.
>
> *sandhyākāḷī śāḷet gāyanācā kāryakram āhe.*
>
> There is a singing programme at school this evening.

Neuter.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**गायन** (*gāyan*) is a tatsama, taken from Sanskrit *gāyana*, "a singer, singing" (Monier-Williams).
