## HL-C443: nine cold letters get words first

Gentle writing asks for every letter to be taken from a word the reader
already says. Nine Malayalam letter lessons came before any word holding their
letter. Each now follows a short word lesson that holds it:

| letter | word placed just before it |
|---|---|
| ു | **പുലി** (*puli*, a tiger) |
| ൺ | **പെൺകുട്ടി** (*peṇkuṭṭi*, a girl) |
| ഓ | **ഓല** (*ōla*, a palm leaf) |
| ൂ | **കൂട്** (*kūṭŭ*, a nest) |
| ൊ | **കൊടി** (*koṭi*, a flag) |
| ൽ | **തൂവൽ** (*tūval*, a feather) |
| ഹ | **ഹംസം** (*haṃsam*, a swan) |
| ഊ | **ഊഞ്ഞാൽ** (*ūññāl*, a swing) |
| ഗ | **ഗാനം** (*gānam*, a song) |

Each word is revisited by its letter lesson and by the lesson after it.

Three stay cold:

- **ഉ**: its chapter has no free reading position before the letter.
- **ഒ**: its anchor word would have opened the numbers chapter, which
  deliberately starts with the numbers themselves.
- **ഏ ഴ**: the script data file has no stroke data for **ഏ** yet, so no
  headword may use it.
