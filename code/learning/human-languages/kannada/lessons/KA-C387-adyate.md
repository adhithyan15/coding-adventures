# ಆದ್ಯತೆ (ādyate) — a priority

## You'll want to know: ಆದ್ಯತೆ
<!-- hl-knowledge: introduces=[KA-LEX-C387-SAVALU387-04]; assesses=[] -->

**ಆದ್ಯತೆ** — *ādyate* — "a priority".

> ನನ್ನ ಮೊದಲ ಆದ್ಯತೆ ಮಕ್ಕಳ ಓದು.
>
> *nanna modala ādyate makkaḷa ōdu.*
>
> My first priority is the children's studies.

ಆದ್ಯತೆ ಕೊಡು, to give priority.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಆದ್ಯತೆ** (*ādyate*) is built on Sanskrit *ādya*, "being at the beginning, first" (Monier-Williams), with -*tā*, "-ness": firstness.
