## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[GU-SCRIPT-C45-GHA-01, GU-SCRIPT-C45-AI-SIGN-01] -->

[PAUSE 3s] Say **ઘર** (*ghar*), then write the letter it gave you.

|---|---|---|
| ઘ | *gha* | **ઘર** *ghar* |
| ૈ | *ai sign* | **પૈસા** *paisā* |

[PAUSE 2s each]
- [YOU WRITE: each letter in the table from memory, then check it]

- [YOU READ: each word in the table aloud, and point at its letter]
