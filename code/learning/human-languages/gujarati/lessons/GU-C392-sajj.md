# સજ્જ (sajj) — fully equipped; ready

## You'll want to know: સજ્જ
<!-- hl-knowledge: introduces=[GU-LEX-C392-SAJJ392-01]; assesses=[] -->

**સજ્જ** — *sajj* — "fully equipped; ready".

> જો તોફાન આવશે તો પણ અમે સજ્જ છીએ.
>
> *jo tophān āvśe to paṇ ame sajj chīe.*
>
> Even if a storm comes, we are ready.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**સજ્જ** (*sajj*) is a tatsama, borrowed from Sanskrit *sajja*, "fixed, prepared, equipped" (Monier-Williams).
