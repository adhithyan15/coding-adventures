## You'll want to know: சாலை
<!-- hl-knowledge: introduces=[TA-LEX-C69-GOING-04]; assesses=[] -->

**சாலை** (*sālai*) — "a road".

A made road, wide enough for a வண்டி to go down.

Set it beside பாதை (*pātai*), the path you already have. A பாதை is walked; a சாலை is driven.
The difference is not size so much as what it was made for.

Both end in the same **ை**, which by now you have read four times.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

Four, and the vehicles have somewhere to run.
