# An old word for saying

First retrieve **to say** alone. Then hear three familiar actions in a
small shuffled mix. Pause before each model. This is not scored A1 writing
or a complete mock.

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-C151-ACT151-01] -->

Hear **to say**. [PAUSE 4s] Recall **ਕਹਿਣਾ** (*kahiṇā*).

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-C150-ACT150-04, PA-LEX-C150-ACT150-05, PA-LEX-C151-ACT151-01] -->

Pause after each familiar meaning, then hear its model:

- **to drive** — [PAUSE 4s] **ਚਲਾਉਣਾ** (*calāuṇā*).
- **to say** — [PAUSE 4s] **ਕਹਿਣਾ** (*kahiṇā*).
- **to wake up** — [PAUSE 4s] **ਜਾਗਣਾ** (*jāgṇā*).

Only the order of these old words has changed.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-C150-ACT150-04, PA-LEX-C150-ACT150-05, PA-LEX-C151-ACT151-01] -->

Hear **to wake up**, **to say**, then **to drive**. Pause after each cue
and recall its Punjabi word before the model: **ਜਾਗਣਾ**, **ਕਹਿਣਾ**,
**ਚਲਾਉਣਾ**. Revisit only the old word you missed.
