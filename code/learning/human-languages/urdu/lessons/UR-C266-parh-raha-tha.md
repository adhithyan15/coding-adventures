# پڑھ رہا تھا (paṛh rahā thā) — what was going on

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[UR-GRAMMAR-C264-WAS-02, UR-GRAMMAR-C264-WAS-01, UR-LEX-PARHNA] -->

[PAUSE 2s] Say "I used to read". (*maiṅ paṛhtā thā*.) That is a habit. This lesson is one moment in the past, with something still going on.

## Grammar Lens: was doing
<!-- hl-knowledge: introduces=[UR-GRAMMAR-C266-ONGOING-PAST-01]; assesses=[UR-LEX-C47-VERBS47-02, UR-LEX-C113-THINGS113-03, UR-LEX-LIKHNA, UR-LEX-C46-FAMILY46-02] -->

> **سو رہی تھی۔**
>
> *so rahī thī.* — "She was sleeping."

Ask what Sara was doing last night, and the answer is three words: the stem **سو** (*so*), then **رہی** (*rahī*), then **تھی** (*thī*). Both follow Sara:

> **سارا سو رہی تھی۔**
>
> *Sārā so rahī thī.* — "Sara was sleeping."

> **میں خط لکھ رہا تھا۔**
>
> *maiṅ khat likh rahā thā.* — "I was writing a letter."

A verb with an object takes no **نے** (*ne*) here: the writing was still going on.

> **ہم کھانا کھا رہے تھے۔**
>
> *ham khānā khā rahe the.* — "We were eating."

| who | was doing |
|---|---|
| a man | **رہا تھا** (*rahā thā*) |
| a woman | **رہی تھی** (*rahī thī*) |
| men; **ہم**; **آپ** | **رہے تھے** (*rahe the*) |
| women | **رہی تھیں** (*rahī thīṅ*) |

## You'll want to know: the scene and the event
<!-- hl-knowledge: introduces=[UR-GRAMMAR-C266-ONGOING-PAST-02]; assesses=[UR-LEX-BARISH, UR-LEX-C78-TIME78-05, UR-LEX-C96-TIME96-02, UR-GRAMMAR-C264-PAST-01] -->

> **باہر بارش ہو رہی تھی۔**
>
> *bāhar bārish ho rahī thī.* — "It was raining outside."

That is a scene: going on, with no edge. Drop an event into it with **جب** (*jab*), "when", and **تو** (*to*), "then":

> **جب میں گھر آیا،**
>
> *jab maiṅ ghar āyā,*
>
> **تو سارا سو رہی تھی۔**
>
> *to Sārā so rahī thī.* — "When I came home, Sara was sleeping."

This **تو** is *to*, "then", not **تو** *tū*, "you": the romanization tells them apart. **آیا** (*āyā*) is the event, over in a moment. **سو رہی تھی** is the scene it cut into.
