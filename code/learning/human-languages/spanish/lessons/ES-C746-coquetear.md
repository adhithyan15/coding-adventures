## You'll want to know: coquetear
<!-- hl-knowledge: introduces=[ES-LEX-C746-ENGANO-04]; assesses=[] -->

**coquetear** — "to flirt".

> Coquetea con todo el mundo.
>
> *She flirts with everyone.*

*Coqueto* — flirtatious; also vain about one's looks.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*coquetear* is built on *coqueta*, borrowed from French *coquette* (EtymDB), from *coq* "cockerel": showing off like a strutting cock.
