## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ತರು** (*taru*) is native Dravidian, one word with Tamil *taru* and Malayalam *taruka* (DEDR 3098). DEDR lists *tar*, *tā*, "to bring, give".
