# One word can be a full line

## Warm-up
<!-- hl-knowledge: introduces=[MR-A1-MESSAGE-LINE-THANKS]; assesses=[MR-LEX-DHANYAVAD-01, MR-SCRIPT-DHANYAVAD-WRITE-01] -->

Write **धन्यवाद** from memory. It is already durable; the only message habit
today is closing the one-word sentence.

## Writing — delayed copy

Look once at **धन्यवाद.**, cover it, wait ten seconds, and write it. If the word
is correct but the full stop is missing, repair only the boundary.
