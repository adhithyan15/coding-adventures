## You'll want to know: auslösen
<!-- hl-knowledge: introduces=[GE-LEX-C342-WIRKUNG-04]; assesses=[] -->

**auslösen** — "to trigger, to set off".

> Seine Bemerkung hat einen großen Streit ausgelöst.
>
> *His remark set off a big argument.*

Separable: *es löst aus*, *es hat ausgelöst*. Also of machines: *den Alarm auslösen* — to set off the alarm.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*auslösen* is built from *aus* "out" and *lösen* "to loosen, to release", inherited from Old High German *lōsen* and Proto-Germanic *lausijaną*, from *lausaz* "loose" (EtymDB): you release something that then runs by itself.
