## You'll want to know: گوشہ
<!-- hl-knowledge: introduces=[UR-LEX-C409-JANIB409-04]; assesses=[] -->

**گوشہ** — *goshā* — "a nook; a corner".

> کمرے کے ایک گوشے میں میز ہے۔
>
> *kamre ke ek goshe meṅ mez hai.*
>
> There is a table in one corner of the room.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**گوشہ** (*goshā*) is usually traced to Persian *gosha*, "a corner"; it is a more literary word than **کونا**.
