# Review — a story, told in order

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[LA-GRAMMAR-C282-ORDO-01, LA-GRAMMAR-C281-PERFECTUM-01] -->

[PAUSE 2s] Say Caesar's three words. (*Vēnī, vīdī, vīcī.*) Then the four
rungs. (*Prīmum, deinde, tum, postrēmō.*)

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[LA-LEX-C282-DUM-01, LA-GRAMMAR-C282-DUM-PRAESENS-02, LA-SKILL-READ-NARRATIVE-01, LA-LEX-C99-VERBA5-03] -->

Two chapters, and you can **nārrāre**, tell a story. The scene in the
imperfect, *erat*, *pluēbat*, *sedēbat*. The events in the perfect, one per
rung, from *prīmum* to *postrēmō*. And **dum** with a present for the
stretch an event happened in.

> *Dum in forō ambulō, amīcum vīdī. Prīmum nōn clāmāvī, quia fessus eram.*
> — While I was walking in the forum, I saw a friend. At first I did not
> call out, because I was tired.

[PAUSE 2s] In that last sentence the event is negative, *nōn clāmāvī*, and
it is still an event; the tiredness around it is scene, *fessus eram*.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[LA-GRAMMAR-C282-ORDO-01, LA-LEX-C282-DUM-01, LA-GRAMMAR-C281-PERFECTUM-01] -->

[PAUSE 3s] Which rung comes last? (***Postrēmō.***) Which tense follows *dum*
in a past story? (The **present**.) Which tense goes on each rung? (The
**perfect**.) And what did Marcus do first, when his friend called? (**He
did not want to come**: *nōn volēbat*.)
