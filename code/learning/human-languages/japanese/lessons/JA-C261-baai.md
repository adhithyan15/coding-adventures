# ばあい (baai) — a case; an occasion

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[JA-GRAMMAR-C261-DEPENDS-01, JA-GRAMMAR-C261-DEPENDS-02, JA-LEX-C167-DONE167-05] -->

## You'll want to know: ばあい
<!-- hl-knowledge: introduces=[JA-LEX-C261-BAAI-01]; assesses=[JA-LEX-C44-NATURE44-05, JA-LEX-C63-WORLD63-02] -->

**ばあい** — *baai* — "a case", "an occasion": what is done when something happens. A noun before it takes **の**:

> **あめの ばあいは、ちゅうしです。**
>
> *ame no baai wa, chūshi desu.* — "In case of rain, it is called off."

> **あめの ばあいは、まつりは ちゅうしです。**
>
> *ame no baai wa, matsuri wa chūshi desu.* — "In case of rain, the festival is called off."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ばあい** (*baai*) is a native Japanese word (wago), inherited rather than borrowed from Chinese. JMdict writes it with two kanji that KANJIDIC2 reads the native way: ば, "place", and あ(う), "to fit, to meet", so it is usually explained as "the place where things meet". JMdict glosses it "case; occasion; situation" (JMdict, KANJIDIC2).
