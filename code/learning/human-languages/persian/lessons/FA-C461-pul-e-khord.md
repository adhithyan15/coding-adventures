## You'll want to know: پول خرد
<!-- hl-knowledge: introduces=[FA-LEX-C461-KARTKHAN-04]; assesses=[] -->

**پول خرد** (*pul-e khord*) — "small change, coins".

> راننده تاکسی پول خرد نداشت.
>
> *Rânande-ye tâksi pul-e khord nadâsht.*
>
> The taxi driver didn't have any change.

*pul* 'money' + *khord* 'small'.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*pul-e khord* is built from *pul* 'money', which EtymDB glosses 'change, small money', and native *khord* 'small, broken', usually traced to Middle Persian *xward*.
