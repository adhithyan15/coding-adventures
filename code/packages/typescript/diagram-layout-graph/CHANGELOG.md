# Changelog

All notable changes to this project will be documented in this file.

## [0.2.0] - 2026-08-13

### Fixed

- Keep mixed-width nodes in the same rank from overlapping.

## [0.1.0] - 2026-04-23

### Added

- Deterministic layered layout for graph diagrams
- Longest-path rank assignment for DAGs
- Stable fallback layout for cyclic graphs
- Node sizing from label length
- Straight edge routing plus explicit self-loop routing
