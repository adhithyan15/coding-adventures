# புறநகர் (puṟanakar) — a suburb

## You'll want to know: புறநகர்
<!-- hl-knowledge: introduces=[TA-LEX-C423-NAKAR423-02]; assesses=[] -->

**புறநகர்** — *puṟanakar* — "a suburb".

> என் அண்ணன் புறநகரில் வாழ்கிறான்.
>
> *eṉ aṇṇaṉ puṟanakaril vāḻkiṟāṉ.*
>
> My elder brother lives in a suburb.

புறம், the outside, + நகர், town.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**புறநகர்** (*puṟanakar*) is built from புறம், "the outside" (DEDR 4333), and நகர், "a town" (DEDR 3568).
