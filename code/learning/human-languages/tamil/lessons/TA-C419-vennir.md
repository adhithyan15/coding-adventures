# வெந்நீர் (vennīr) — hot water

## You'll want to know: வெந்நீர்
<!-- hl-knowledge: introduces=[TA-LEX-C419-ARAI419-02]; assesses=[] -->

**வெந்நீர்** — *vennīr* — "hot water".

> குளிப்பதற்கு வெந்நீர் இல்லை.
>
> *kuḷippataṟku vennīr illai.*
>
> There is no hot water for bathing.

வெம், hot, + நீர், water: the ம் becomes ந் before ந.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**வெந்நீர்** (*vennīr*) is native Dravidian: DEDR 5517 lists it, "hot water", from the root வே, "to burn, to be hot", + நீர், "water".
