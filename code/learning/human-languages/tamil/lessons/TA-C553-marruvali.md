# மாற்றுவழி (māṟṟuvaḻi) — an alternative; a way round

## You'll want to know: மாற்றுவழி
<!-- hl-knowledge: introduces=[TA-LEX-C553-THARKALIKAM553-04]; assesses=[] -->

**மாற்றுவழி** — *māṟṟuvaḻi* — "an alternative; a way round".

> சாலை மூடப்பட்டால் மாற்றுவழியில் போகலாம்.
>
> *cālai mūṭappaṭṭāl māṟṟuvaḻiyil pōkalām.*
>
> If the road is closed, we can take another route.

Word for word "a change-way": மாற்று (*māṟṟu*) + வழி (*vaḻi*).

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**மாற்றுவழி** (*māṟṟuvaḻi*) is a native compound: மாற்று (*māṟṟu*), "a change, a substitute", from மாறு (DEDR 4834), and வழி (*vaḻi*), "a way".
