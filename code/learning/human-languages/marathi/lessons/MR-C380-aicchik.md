## You'll want to know: ऐच्छिक
<!-- hl-knowledge: introduces=[MR-LEX-C380-ANIVARYA380-02]; assesses=[] -->

**ऐच्छिक** — *aicchik* — "optional".

> हा विषय ऐच्छिक आहे, तो घेतला नाही तरी चालेल.
>
> *hā viṣay aicchik āhe, to ghetlā nāhī tarī cālel.*
>
> This subject is optional; it is fine if you don't take it.

Built on इच्छा, wish: by choice.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ऐच्छिक** (*aicchik*) is a tatsama, taken from Sanskrit *aicchika*, "optional, at will" (Monier-Williams). It is built on *icchā*, "wish".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
