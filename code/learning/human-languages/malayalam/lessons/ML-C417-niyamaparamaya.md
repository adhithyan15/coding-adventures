# നിയമപരമായ (niyamaparamāya) — legal; lawful

## You'll want to know: നിയമപരമായ
<!-- hl-knowledge: introduces=[ML-LEX-C417-CATTAM417-04]; assesses=[] -->

**നിയമപരമായ** — *niyamaparamāya* — "legal; lawful".

> ഇത് പൂർണ്ണമായും നിയമപരമായ ഒരു കരാറാണ്.
>
> *itŭ pūrṇṇamāyuṁ niyamaparamāya oru karāṟāṇŭ.*
>
> This is a fully legal contract.

-പരമായ, concerned with, makes adjectives from nouns: നിയമപരമായ, to do with the law.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**നിയമപരമായ** (*niyamaparamāya*) is built on നിയമം, "a law", from Sanskrit *niyama*, "restraint; a fixed law" (CDIAL 7250), with -പരമായ, from Sanskrit *para*, which at the end of a compound means "devoted to, concerned with" (Monier-Williams).
