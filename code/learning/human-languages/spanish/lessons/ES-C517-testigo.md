## You'll want to know: el testigo
<!-- hl-knowledge: introduces=[ES-LEX-C517-TESTIGO-01]; assesses=[] -->

**el testigo** — "the witness".

> Un testigo llamó a la policía.
>
> *A witness called the police.*

The same form for a woman: *la testigo*. *Ser testigo de algo* is to witness it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*testigo* comes from old Spanish *testiguar* 'to bear witness' (EtymDB), which goes back to Latin *testificārī*, built on *testis* 'a witness'.
