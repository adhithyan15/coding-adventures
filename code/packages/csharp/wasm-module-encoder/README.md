# CodingAdventures.WasmModuleEncoder

A pure C# encoder for the WebAssembly 1.0 binary module format. It serializes
the shared `WasmModule` IR into canonical section order, groups adjacent local
types, emits unsigned LEB128 lengths and indices, and validates import
descriptors before writing bytes.

```csharp
using CodingAdventures.WasmModuleEncoder;
using CodingAdventures.WasmTypes;

var module = new WasmModule();
module.Types.Add(new FuncType([], []));
module.Functions.Add(0);
module.Code.Add(new FunctionBody([], [0x0B]));

byte[] binary = WasmModuleEncoder.EncodeModule(module);
```

The package depends only on the sibling pure-C# `wasm-leb128` and
`wasm-types` packages. Tests round-trip the generated bytes through the sibling
`wasm-module-parser` package.
