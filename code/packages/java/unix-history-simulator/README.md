# Unix History Simulator (Java)

The [HOS00](../../../specs/HOS00-historical-os-simulator.md) library exposes
a filesystem, descriptor table and kernel from
`codingadventures.unixhistory.UnixHistory`.

This package ships the reusable Java API only. With JDK 21 and Python 3
available, run `bash BUILD` to compile the component checks and replay the
shared cases through a temporary fixture adapter stored outside the package.
