## You'll want to know: el desafío
<!-- hl-knowledge: introduces=[ES-LEX-C609-PROGRESO-03]; assesses=[] -->

**el desafío** — "the challenge".

> Aprender un idioma es un desafío.
>
> *Learning a language is a challenge.*

The verb is *desafiar* (*desafío, desafías*).

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*desafío* is built on *desafiar*, which is *des-* + *afiar* (EtymDB), an old verb for pledging faith, from *fiar*, inherited from spoken Latin *fidare*, from *fidere* 'to trust'.
