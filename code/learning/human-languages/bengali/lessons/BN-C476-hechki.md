# হেঁচকি (hẽchki) — a hiccup; hiccups

## You'll want to know: হেঁচকি
<!-- hl-knowledge: introduces=[BN-LEX-C476-DOM476-02]; assesses=[] -->

**হেঁচকি** — *hẽchki* — "a hiccup; hiccups".

> তাড়াতাড়ি খেলে আমার হেঁচকি হয়।
>
> *tāṛātāṛi khele āmār hẽchki hôy.*
>
> If I eat too fast I get hiccups.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**হেঁচকি** (*hẽchki*) is an imitative word, its sound standing for the catch of a hiccup. No dictionary we use records an older form, so its history is not settled.
