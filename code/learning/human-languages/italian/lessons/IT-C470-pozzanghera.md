## You'll want to know: la pozzanghera
<!-- hl-knowledge: introduces=[IT-LEX-C470-PIOGGIA-03]; assesses=[] -->

**la pozzanghera** — "the puddle".

> Il bambino salta nelle pozzanghere.
>
> *The child jumps in the puddles.*

Built on *la pozza*, a pool.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*pozzanghera* is built on *pozza* 'pool', from *pozzo* 'well', which is inherited from Latin *puteus* (EtymDB).
