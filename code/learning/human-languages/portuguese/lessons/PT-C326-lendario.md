## You'll want to know: lendário
<!-- hl-knowledge: introduces=[PT-LEX-C326-LENDA-02]; assesses=[] -->

**lendário** — "legendary".

> Aquele cantor é lendário na região.
>
> *That singer is legendary in the region.*

Built on *lenda*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*lendário* is built on *lenda* "a legend", from Medieval Latin *legenda* (EtymDB), with the ending *-ário*.
