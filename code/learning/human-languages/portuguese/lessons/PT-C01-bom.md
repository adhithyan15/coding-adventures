# bom / boa — "good"

## Warm-up

[PAUSE 2s] The word that starts *bom dia*, *boa tarde*, *boa noite*.

## Sounds you'll need

- **bom** is **nasal**: *bõ*, the *m* not fully closed, the vowel through the
  nose. **boa** (feminine) is a clear *BOH-ah*.

## The word, taken apart

**bom / boa** ("good") ← Latin **bonus / bona** → English **bon**us,
**bon**anza. Spanish, another daughter of Latin, made *bueno / buena*;
Portuguese wore *bonus* down further, to the little nasal *bom*.

## Grammar Lens: it agrees with the noun

**bom / boa** changes to match its noun: *bom* (m.), *boa* (f.), *bons / boas*
(pl.) — Latin's adjective agreement, alive across the Romance family. So it's
*bom dia* (m.) but *boa tarde* (f.).
