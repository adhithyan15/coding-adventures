## You'll want to know: el sufrimiento
<!-- hl-knowledge: introduces=[ES-LEX-C717-SUFRIR-03]; assesses=[] -->

**el sufrimiento** — "suffering".

> La guerra causa mucho sufrimiento.
>
> *War causes a lot of suffering.*

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*sufrimiento* is built on *sufrir* with the ending *-miento*; *sufrir* is usually traced to Latin *sufferre* "to bear up under".
