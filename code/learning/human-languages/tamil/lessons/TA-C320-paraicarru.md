# பறைசாற்று (paṟaicāṟṟu) — to proclaim

## You'll want to know: பறைசாற்று
<!-- hl-knowledge: introduces=[TA-LEX-C320-KODI320-05]; assesses=[] -->

**பறைசாற்று** — *paṟaicāṟṟu* — "to proclaim".

> இந்தக் கோயில் பழைய கலையின் பெருமையைப் பறைசாற்றுகிறது.
>
> *intak kōyil paḻaiya kalaiyiṉ perumaiyaip paṟaicāṟṟukiṟatu.*
>
> This temple proclaims the glory of the old art.

Past (I …): பறைசாற்றினேன், *paṟaicāṟṟiṉēṉ*.

பறை, drum + சாற்று, to announce: once by drum, now any loud proof.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**பறைசாற்று** (*paṟaicāṟṟu*) is a Tamil compound built from பறை, "drum" (DEDR 4032), and சாற்று, "to publish, announce, beat as a drum" (DEDR 2486).

## What you've built

One more word for telling what happened.
