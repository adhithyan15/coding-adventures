## You'll want to know: పగడం
<!-- hl-knowledge: introduces=[TE-LEX-C473-DVIPAM473-03]; assesses=[] -->

**పగడం** — *pagaḍaṁ* — "coral".

> ఆ ద్వీపం చుట్టూ పగడాల దిబ్బలు ఉన్నాయి.
>
> *ā dvīpaṁ cuṭṭū pagaḍāla dibbalu unnāyi.*
>
> There are coral reefs round that island.

పగడాల దిబ్బ, a coral reef. Red coral is set in jewellery too.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**పగడం** (*pagaḍaṁ*) is listed in DEDR as Telugu *pagaḍamu*, "red coral" (DEDR 3998), beside Tamil *pavaḷam*; DEDR compares Sanskrit *pravāla*, and which side borrowed is not settled.
