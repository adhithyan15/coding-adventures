## You'll want to know: نعامة
<!-- hl-knowledge: introduces=[AR-LEX-C474-SAQR474-02]; assesses=[] -->

**نعامة** — *naʿāma* — "an ostrich".

> تركض النعامة بسرعة كبيرة.
>
> *tarkuḍu an-naʿāma bi-surʿa kabīra.*
>
> The ostrich runs very fast.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**نعامة** (*naʿāma*) is an old Arabic name for the ostrich; the origin is not settled.
