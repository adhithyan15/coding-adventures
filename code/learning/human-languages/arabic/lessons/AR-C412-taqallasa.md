# تقلص (taqallaṣa) — to shrink

## You'll want to know: تقلص
<!-- hl-knowledge: introduces=[AR-LEX-C412-IZDIYAD412-02]; assesses=[] -->

**تقلص** — *taqallaṣa* — "to shrink".

> تقلص عدد الطلاب.
>
> *taqallaṣa ʿadad aṭ-ṭullāb.*
>
> The number of students shrank.

Present: يتقلص, *yataqallaṣ*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**تقلص** (*taqallaṣa*) is built on the native Arabic root *q-l-ṣ*, "to contract, to shrink" (Lane). It is Form V, to draw itself in: to shrink.
