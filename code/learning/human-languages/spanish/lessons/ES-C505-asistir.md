## You'll want to know: asistir
<!-- hl-knowledge: introduces=[ES-LEX-C505-ESTUDIO-02]; assesses=[] -->

**asistir** — "to attend".

> Asisto a clase todos los días.
>
> *I attend class every day.*

A false friend: *asistir a* means to attend; to help is usually *ayudar*.
