## You'll want to know: అమర్చు
<!-- hl-knowledge: introduces=[TE-LEX-C549-GRHAM549-01]; assesses=[] -->

**అమర్చు** — *amarcu* — "to set up; to arrange".

> కొత్త ఇంట్లో మేము సామాను అమర్చాము.
>
> *kotta iṇṭlō mēmu sāmānu amarcāmu.*
>
> We set up our things in the new house.

Past (I …): అమర్చాను, *amarcānu*.

Putting things where they belong.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**అమర్చు** (*amarcu*) is native Dravidian: DEDR 162 lists Telugu *amaru*, "to suit, to be fit", and *amar(u)cu*, "to fit, to arrange", with Tamil *amar*.
