## You'll want to know: خلاقیت
<!-- hl-knowledge: introduces=[FA-LEX-C527-TALENT-02]; assesses=[] -->

**خلاقیت** (*khallâqiyat*) — "creativity".

> این کار خلاقیت زیادی میخواهد.
>
> *in kâr khallâqiyat-e ziyâdi mikhâhad.*
>
> This work takes a lot of creativity.

Built on *khallâq* 'creative'.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*khallâqiyat* is built in Persian on *khallâq*, 'creative', a loan usually traced to Arabic *ḫallāq*, 'creator', with an abstract ending. EtymDB has no entry for it.
