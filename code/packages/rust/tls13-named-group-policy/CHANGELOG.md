# Changelog

All notable changes to this package will be documented in this file.

## [0.1.0] - 2026-10-29

### Added

- Immutable X25519 and secp256r1 wire, routing, key-exchange, and shared-secret
  parameters.
- Non-empty, duplicate-free caller allowlists with fail-closed selection.
- Exact selected-group length validation and stable redacted failures.
