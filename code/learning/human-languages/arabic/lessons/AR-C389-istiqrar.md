## You'll want to know: استقرار
<!-- hl-knowledge: introduces=[AR-LEX-C389-NUFUDH389-05]; assesses=[] -->

**استقرار** — *istiqrār* — "stability".

> يحتاج الأطفال إلى الاستقرار.
>
> *yaḥtāju al-aṭfāl ilā al-istiqrār.*
>
> Children need stability.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**استقرار** (*istiqrār*) is built on the native Arabic root *q-r-r*, "to settle, to be still" (Lane). *Istiqrār* is the Form X verbal noun, settling in place: stability.
