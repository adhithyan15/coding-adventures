## You'll want to know: முதன்முறையாக
<!-- hl-knowledge: introduces=[TA-LEX-C317-MURAI317-01]; assesses=[] -->

**முதன்முறையாக** — *mutaṉmuṟaiyāka* — "for the first time".

> நான் முதன்முறையாக விமானத்தில் பயணம் செய்தேன்.
>
> *nāṉ mutaṉmuṟaiyāka vimāṉattil payaṇam ceytēṉ.*
>
> I travelled by plane for the first time.

முதல் + முறை; ல் turns to ன் before ம.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**முதன்முறையாக** (*mutaṉmuṟaiyāka*) is built from native முதல், "first" (DEDR 4950), and முறை, "order, turn, time" (DEDR 5015), with the adverb ending -ஆக.

## What you've built
