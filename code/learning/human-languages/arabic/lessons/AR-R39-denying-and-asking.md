# Denying, and asking

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[AR-GRAMMAR-C39-LAYSA-01, AR-GRAMMAR-C39-MA-01, AR-GRAMMAR-C39-HAL-01] -->

[PAUSE 4s] Arabic has three negators and each one owns a different kind of
sentence. Name all three, and say what each one denies.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[AR-GRAMMAR-C39-LAYSA-01, AR-GRAMMAR-C39-MA-01, AR-GRAMMAR-C39-LA-WALA-01, AR-GRAMMAR-C39-HAL-01, AR-CONCEPT-C05-LA-02, AR-GRAMMAR-C37-PRESENT-I-01, AR-FUNC-C37-LA-AFHAM-01, AR-CONCEPT-C02-ISMII-01, AR-CONCEPT-C31-KATABA-01, AR-FUNC-C38-HASANAN-01, AR-LEX-C38-WA-01] -->

[PAUSE 1s]
- [YOU SAY: the verbless sentence denied — *ismī laysa Ḥasan*]
- [YOU SAY: the past denied — *mā kataba*]
- [YOU SAY: the present denied — *lā aktub*, and *lā afham*]
- [YOU SAY: both refused at once — *lā shāy wa-lā ḥalīb*]
- [YOU SAY: each of those asked back — put *hal* in front and change nothing else]
- [YOU RECALL: six lessons back, the word that accepts what was said — *ḥasanan*]

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[AR-GRAMMAR-C39-HAL-01, AR-GRAMMAR-C39-LAYSA-01, AR-GRAMMAR-C39-MA-01] -->

[PAUSE 3s] Which negator would you use for **اسمي حسن**, which for **كتب**, and
which for **أكتب**? (**ليس**, then **ما**, then **لا**.) What does **هل** ask of
the sentence it fronts? (**Nothing at all** — it only marks it.)
