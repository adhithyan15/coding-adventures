## You'll want to know: ફાળવવું
<!-- hl-knowledge: introduces=[GU-LEX-C427-SAVE427-05]; assesses=[] -->

**ફાળવવું** — *phāḷavvũ* — "to set aside (money); to allot".

> મેં પગારમાંથી બચત માટે પૈસા ફાળવ્યા.
>
> *mẽ pagārmā̃thī bacat māṭe paisā phāḷavyā.*
>
> I set aside money from my salary for savings.

Past, with તેણે (he or she …): તેણે પૈસા ફાળવ્યા, *teṇe paisā phāḷavyā*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ફાળવવું** (*phāḷavvũ*) is built on ફાળો, a share, which goes back to *\*phāla*, a form CDIAL reconstructs and lists for the Gujarati word (CDIAL 9073): to give each thing its share.
