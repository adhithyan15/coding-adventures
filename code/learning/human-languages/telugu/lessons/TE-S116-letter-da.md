# ద — one character, met inside words you already say

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TE-SCRIPT-RECOG-115] -->

[PAUSE 1s] Before the new one: ◌ె — what does it do?

[PAUSE 2s] One character this time. Just one — and you have been saying it
for pages without knowing which mark on the page it was.

## Script you'll notice: ద
<!-- hl-knowledge: introduces=[TE-SCRIPT-RECOG-116]; assesses=[] -->

**ద** — *da*.

It is a **consonant**, and in this script a consonant is never bare: it comes with an *a* already in it. So it is not *d*, it is **da**.

You already say these, and every one of them has ద somewhere inside it:

- **ధన్యవాదములు** *dhanyavādamulu* — thank you (dhanyavādamulu — "utterances of 'worthy'")
- **లేదు** *lēdu* — no / there isn't (lēdu)
- **పరవాలేదు** *paravālēdu* — it's okay / no problem / you're welcome
- **రేపు కలుద్దాం** *rēpu kaluddām* — see you tomorrow

## Writing: ద — copy what you see
<!-- hl-knowledge: introduces=[]; assesses=[TE-SCRIPT-RECOG-116] -->

Put your pen on ద and follow its line. Copy the shape you can see — slowly,
and larger than it is printed.

> This book does not yet tell you **where to start the character or which way to
> travel**. That is a real thing, taught with real variation from school to
> school, and it is not written down here until it can be written down with a
> source. Copying what is in front of you needs no such source, and it is how the
> shape gets into your hand in the meantime.
