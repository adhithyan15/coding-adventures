## You'll want to know: ограничение
<!-- hl-knowledge: introduces=[RU-LEX-C391-ZAKONODATELSTVO-05]; assesses=[] -->

**ограничение** (*ogranichéniye*) — "a restriction, a limit".

> Есть ограничения по возрасту.
>
> *Yest ogranichéniya po vózrastu.*
>
> There are age restrictions.

Neuter. *Ограничение скорости* — a speed limit.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ограничение** is built on *ограничить* "to restrict", from *граница* "a border", which is built on *грань* "an edge": to restrict is to draw a border round a thing.
