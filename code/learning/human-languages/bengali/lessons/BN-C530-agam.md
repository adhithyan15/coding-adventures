# আগাম (āgām) — in advance; an advance

## You'll want to know: আগাম
<!-- hl-knowledge: introduces=[BN-LEX-C530-BATIL530-03]; assesses=[] -->

**আগাম** — *āgām* — "in advance; an advance".

> আগাম টাকা দিলে হোটেল আমাদের জন্য ঘর রাখবে।
>
> *Āgām ṭākā dile hoṭel āmāder jônyô ghôr rākhbe.*
>
> If we pay in advance, the hotel will keep a room for us.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**আগাম** (*āgām*) is built on আগ, "the front", from Sanskrit *agra* (CDIAL 68), the root of আগে, "before"; how the ending arose is not settled.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
