# આક્રમણ (ākramaṇ) — an invasion; an attack

## You'll want to know: આક્રમણ
<!-- hl-knowledge: introduces=[GU-LEX-C320-YUDDH320-05]; assesses=[] -->

**આક્રમણ** — *ākramaṇ* — "an invasion; an attack".

> દુશ્મને સવારે આક્રમણ કર્યું.
>
> *duśmane savāre ākramaṇ karyũ.*
>
> The enemy invaded in the morning.

A neuter noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**આક્રમણ** (*ākramaṇ*) is a tatsama, Sanskrit *ākramaṇa*, "stepping upon" (CDIAL 1016), and so marching into another's land. It is done: **આક્રમણ કર્યું**.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
