## You'll want to know: ingombrare
<!-- hl-knowledge: introduces=[IT-LEX-C448-ARREDO-05]; assesses=[] -->

**ingombrare** — "to clutter, to block (a space)".

> Le biciclette ingombrano il marciapiede.
>
> *The bikes are blocking the pavement.*

*Ingombrante* — bulky.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*ingombrare* is built from *in-* and an old word for a heap or an obstacle; the origin of that word is not settled.
