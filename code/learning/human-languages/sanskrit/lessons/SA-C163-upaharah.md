## You'll want to know: उपहारः
<!-- hl-knowledge: introduces=[SA-LEX-C163-THG163-05]; assesses=[] -->

**उपहारः** — *upahāraḥ* — "a gift".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*upahāra* comes from *upa-√hṛ* "bring near, offer", the root √hṛ "carry" with *upa* "near" (MW): "an offering", and so "a gift". It is built like *āhāra* "food", from the same root.
