## You'll want to know: báifèi
<!-- hl-knowledge: introduces=[ZH-LEX-C394-TRY394-04]; assesses=[] -->

*báifèi* — "to be wasted (of effort)".

> *yàoshi nǐ xiànzài bú zuò yǐqián de nǔlì jiù báifèi le* — If you don't do it now, all your work so far will be wasted.

Its characters come later; for now it is a word for the ear.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*báifèi* is built from 白 'white, blank' and *fèi* 'to use up', both inherited from Middle Chinese, *baek* and *phj+jH* (Guangyun, in Baxter's transcription), which glosses the first 'the colour of the west'. 白 for 'in vain' is not given there.
