# ಯಾತ್ರೆ (yātre) — a pilgrimage; a long journey

## You'll want to know: ಯಾತ್ರೆ
<!-- hl-knowledge: introduces=[KA-LEX-C458-YATRE458-01]; assesses=[] -->

**ಯಾತ್ರೆ** — *yātre* — "a pilgrimage; a long journey".

> ಅಜ್ಜಿ ಪ್ರತಿ ವರ್ಷ ಯಾತ್ರೆಗೆ ಹೋಗುತ್ತಾರೆ.
>
> *ajji prati varṣa yātrege hōguttāre.*
>
> Grandmother goes on a pilgrimage every year.

ಯಾತ್ರೆ alone can be any long journey; ಯಾತ್ರಿಕ is a pilgrim.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಯಾತ್ರೆ** (*yātre*) is borrowed from Sanskrit *yātrā*, "a journey, a festival procession" (CDIAL 10456), from *yā*, "to go".
