# ಬಂದರೆ (bandare) — if

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C67-LINK-03, KA-LEX-C64-JOIN-05, KA-LEX-C176-KARANA176-02, KA-GRAMMAR-C316-SPAN-INDA-01] -->

[PAUSE 2s] Say "but" (*ādare*), "in that case" (*hāgādare*) and "otherwise" (*illadiddare*). Then "I have been learning Kannada for two months." (*nānu eraḍu tiṅgaḷinda kannaḍa kaliyuttiddēne*.)

[PAUSE 1s] Those three words share an ending. This lesson takes it out.

## You'll want to know: the -ಅರೆ form
<!-- hl-knowledge: introduces=[KA-GRAMMAR-C317-ARE-CONDITIONAL-01]; assesses=[KA-LEX-C252-KARANA252-05, KA-LEX-C40-OOTA-01, KA-LEX-C04-NAALE-SIGONA-01, KA-LEX-C115-WHY115-04, KA-GRAMMAR-C309-PAST-STEMS-01] -->

> **ನೀನು ಬಂದರೆ ನಾವು ಒಟ್ಟಿಗೆ ಊಟ ಮಾಡೋಣ.**
>
> *nīnu bandare nāvu oṭṭige ūṭa māḍōṇa.* — "If you come, let's eat together."

**ಬಂದರೆ** is the past without its ending, **ಬಂದ-**, with **-ಅರೆ**: "if (you) come". It stays the same for every person: **ನಾನು ಬಂದರೆ**, **ಅವಳು ಬಂದರೆ**, **ನಾವು ಬಂದರೆ**. Though it is built on the past, it points ahead: "if you come (tomorrow)". The same build on other verbs: **ಮಾಡಿದ-** → **ಮಾಡಿದರೆ**, **ಹೋದ-** → **ಹೋದರೆ**, **ಇದ್ದ-** → **ಇದ್ದರೆ**, **ಆದ-** → **ಆದರೆ**.

**ಮಾಡೋಣ**, "let's do", has the ending of **ನಾಳೆ ಸಿಗೋಣ**.

Now the three words. **ಆದರೆ** is "if it becomes so", and Kannada uses it for "but". **ಹಾಗಾದರೆ** is **ಹಾಗೆ** + **ಆದರೆ**, "if it is that way": "in that case". **ಇಲ್ಲದಿದ್ದರೆ** is "if it is not": "otherwise". Even **ಯಾಕೆಂದರೆ** holds one: "if (you) say why", so "because".

## You'll want to know: ಒಂದು ವೇಳೆ, if by chance
<!-- hl-knowledge: introduces=[KA-GRAMMAR-C317-ONDU-VELE-01]; assesses=[KA-LEX-C176-KARANA176-04, KA-LEX-C100-FIND-03, KA-LEX-C106-SOON-04] -->

> **ಒಂದು ವೇಳೆ ಬಸ್ ತಡವಾದರೆ, ನನಗೆ ಫೋನ್ ಮಾಡಿ.**
>
> *ondu vēḷe bas taḍavādare, nanage phōn māḍi.* — "If by chance the bus is late, phone me."

**ಒಂದು ವೇಳೆ**, "in case, if by chance", opens the clause; **-ಅರೆ** still closes it. **ತಡವಾದರೆ** is **ತಡ** (*taḍa*, "delay") + **ಆದರೆ**: "if it becomes late". **ಒಂದು ವೇಳೆ** says you do not expect it, but you are ready for it.
