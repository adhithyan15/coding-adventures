# இன்பம் (iṉpam) — pleasure; delight

## You'll want to know: இன்பம்
<!-- hl-knowledge: introduces=[TA-LEX-C459-MAKIZHCCI459-02]; assesses=[] -->

**இன்பம்** — *iṉpam* — "pleasure; delight".

> தோட்ட வேலை எனக்கு இன்பம் தருகிறது.
>
> *tōṭṭa vēlai eṉakku iṉpam tarukiṟatu.*
>
> Garden work gives me pleasure.

இன் "sweet" + -பம்; இனிமையான "pleasant" comes from the same root.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**இன்பம்** (*iṉpam*) is native Dravidian, built on இன் *iṉ*, "sweet, pleasant" (DEDR 530).

## What you've built

One more word for describing what you lived and felt.
