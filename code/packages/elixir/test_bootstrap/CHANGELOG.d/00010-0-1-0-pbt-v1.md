## 0.1.0

- Elixir PBT engine conforming to pbt-v1 (VER05m): SplitMix64 and FNV-1a with
  explicit 64-bit masking, generator algebra with integrated shrinking, a
  hierarchical shrink-budget tree (process dictionary plus `:atomics`, bounded
  fail-closed spin lock, explicit handle carriers for spawned processes), honest
  runner (`true`-only properties, raise/throw/exit as property-panic, witness
  re-verification, CI redaction), hand-written strict JSON, total structural
  canonical rendering (no `inspect`), strict TFV validator and the corpus runner.
