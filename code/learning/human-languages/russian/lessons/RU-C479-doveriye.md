## You'll want to know: доверие
<!-- hl-knowledge: introduces=[RU-LEX-C479-TRUST-01]; assesses=[] -->

**доверие** (*dovériye*) — "trust".

> Между нами полное доверие.
>
> *Mézhdu námi pólnoye dovériye.*
>
> There is complete trust between us.

Neuter.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*доверие* is built on *до-* and *вера* 'faith', which is inherited from Proto-Slavic *věra* 'faith, belief' (EtymDB).
