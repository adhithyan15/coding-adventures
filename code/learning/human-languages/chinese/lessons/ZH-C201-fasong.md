# fāsòng — to send electronically; to send a message or an email

## You'll want to know: fāsòng
<!-- hl-knowledge: introduces=[ZH-LEX-C201-POST201-04]; assesses=[] -->

*fāsòng* — "to send electronically; to send a message or an email".

> *wǒ yǐjīng fāsòngle yóujiàn* — I've already sent the email.

Its characters come later; for now it is a word for the ear.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*fāsòng* is built from *fā* 'to send out' and *sòng* 'to send off', both inherited from Middle Chinese, *pjot* and *suwngH* (Guangyun, in Baxter's transcription), which glosses the first 'to start' and 'to open out', and the second 'to send away'.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for reading notices and messages.
