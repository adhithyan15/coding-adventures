## You'll want to know: प्रत्याशा
<!-- hl-knowledge: introduces=[SA-LEX-C390-LAKSHANA390-02]; assesses=[] -->

**प्रत्याशा** — *pratyāśā* — "an expectation; a hope".

> यदि प्रत्याशा अधिका, तर्हि दुःखम् अपि अधिकं भवति।
>
> *yadi pratyāśā adhikā, tarhi duḥkham api adhikaṃ bhavati.*
>
> If expectation is great, sorrow is great too.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**प्रत्याशा** (*pratyāśā*) is built from *prati*, "towards", and *āśā*, "hope"; MW gives *praty-āśā* "confidence, trust, hope, expectation" (MW).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
