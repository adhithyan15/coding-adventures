## You'll want to know: evidente
<!-- hl-knowledge: introduces=[ES-LEX-C587-EVIDENTE-02]; assesses=[] -->

**evidente** — "evident, obvious".

> Es evidente que está cansado.
>
> *It is obvious that he is tired.*

*Es evidente que* + indicative.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*evidente* is a learned borrowing from Latin *evidens* 'clearly visible', built from *ex* and *videre* 'to see' (EtymDB).
