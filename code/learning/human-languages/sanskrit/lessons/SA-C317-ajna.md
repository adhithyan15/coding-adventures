## You'll want to know: आज्ञा
<!-- hl-knowledge: introduces=[SA-LEX-C317-DUTA317-02]; assesses=[] -->

**आज्ञा** — *ājñā* — "an order; a command".

> सैनिकाः सेनापतेः आज्ञां पालयन्ति।
>
> *sainikāḥ senāpateḥ ājñāṃ pālayanti.*
>
> The soldiers obey the general's order.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**आज्ञा** (*ājñā*) is built from *ā* and the root √jñā, "to know"; MW gives *ājñā* as an order or command (MW).
