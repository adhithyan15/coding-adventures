# முடிந்தவரை (muṭintavarai) — as far as possible

## You'll want to know: முடிந்தவரை
<!-- hl-knowledge: introduces=[TA-LEX-C554-VARAIRUTHI554-02]; assesses=[] -->

**முடிந்தவரை** — *muṭintavarai* — "as far as possible".

> முடிந்தவரை சீக்கிரம் கிளம்புவோம்.
>
> *muṭintavarai cīkkiram kiḷampuvōm.*
>
> We will set off as early as possible.

Word for word "up to what is possible": முடிந்த + வரை (*varai*).

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**முடிந்தவரை** (*muṭintavarai*) is a native phrase grown into one word: முடிந்த (*muṭinta*), "that has been possible", from முடி, "to end, to be accomplished" (DEDR 4922), and வரை (*varai*), "up to".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
