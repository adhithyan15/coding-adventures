## You'll want to know: आदेश
<!-- hl-knowledge: introduces=[MR-LEX-C513-KARYASHALA513-02]; assesses=[] -->

**आदेश** — *ādeś* — "a command; an order".

> व्यवस्थापकाने नवीन आदेश दिला.
>
> *vyavasthāpakāne navīn ādeś dilā.*
>
> The manager gave a new order.

Masculine.

आदेश देणे, to order.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**आदेश** (*ādeś*) is a tatsama, taken from Sanskrit *ādeśa*, "advice, instruction" (Monier-Williams).
