## You'll want to know: প্রতিবেদন
<!-- hl-knowledge: introduces=[BN-LEX-C296-SONGBAD296-03]; assesses=[] -->

**প্রতিবেদন** — *prôtibedôn* — "a report".

> সাংবাদিক বন্যার ওপর একটা লম্বা প্রতিবেদন লিখলেন।
>
> *sāngbādik bônyār opôr ekṭā lômbā prôtibedôn likhlen.*
>
> The journalist wrote a long report on the flood.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**প্রতিবেদন** (*prôtibedôn*) is a learned word built from Sanskrit *prati-*, 'back, in return', and *vedana*, 'making known' (Monier-Williams): an account carried back to the reader.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
