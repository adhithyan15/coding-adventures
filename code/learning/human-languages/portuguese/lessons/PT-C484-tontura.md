## You'll want to know: a tontura
<!-- hl-knowledge: introduces=[PT-LEX-C484-ENXAQUECA-03]; assesses=[] -->

**a tontura** — "dizziness".

> Levantei-me depressa e senti uma tontura.
>
> *I stood up quickly and felt dizzy.*

Built on *tonto*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*tontura* is built on *tonto* "dizzy" with *-ura* (EtymDB); *tonto* is inherited from Latin *attonitus* "stunned".
