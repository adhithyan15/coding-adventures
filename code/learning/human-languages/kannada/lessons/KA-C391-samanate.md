# ಸಮಾನತೆ (samānate) — equality

## You'll want to know: ಸಮಾನತೆ
<!-- hl-knowledge: introduces=[KA-LEX-C391-SAMANATE391-01]; assesses=[] -->

**ಸಮಾನತೆ** — *samānate* — "equality".

> ಗಂಡು ಹೆಣ್ಣಿನ ನಡುವೆ ಸಮಾನತೆ ಇರಬೇಕು.
>
> *gaṇḍu heṇṇina naḍuve samānate irabēku.*
>
> There must be equality between men and women.

ಸಮಾನ, equal, + -ತೆ, -ness.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಸಮಾನತೆ** (*samānate*) is borrowed from Sanskrit *samānatā*, "equality" (Monier-Williams), from *samāna*, "equal".
