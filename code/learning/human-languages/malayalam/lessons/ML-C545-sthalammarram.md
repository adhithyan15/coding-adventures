# സ്ഥലംമാറ്റം (sthalaṁmāṟṟaṁ) — a job transfer

## You'll want to know: സ്ഥലംമാറ്റം
<!-- hl-knowledge: introduces=[ML-LEX-C545-CUMATALA545-03]; assesses=[] -->

**സ്ഥലംമാറ്റം** — *sthalaṁmāṟṟaṁ* — "a job transfer".

> അച്ഛന് വടക്കൻ ജില്ലയിലേക്ക് സ്ഥലംമാറ്റം കിട്ടി.
>
> *acchanŭ vaṭakkan jillayilēkkŭ sthalaṁmāṟṟaṁ kiṭṭi.*
>
> Father got a transfer to a northern district.

സ്ഥലം a place + മാറ്റം a change; common for government staff.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**സ്ഥലംമാറ്റം** (*sthalaṁmāṟṟaṁ*) is a Malayalam compound built from സ്ഥലം, from Sanskrit *sthala*, "ground, a place" (CDIAL 13744), and മാറ്റം, "a change", which is native (DEDR 4834).

## What you've built

One more word for describing what you lived and felt.
