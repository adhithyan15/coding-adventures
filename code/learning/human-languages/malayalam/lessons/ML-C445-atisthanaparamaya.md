# അടിസ്ഥാനപരമായ (aṭisthānaparamāya) — fundamental; basic

## You'll want to know: അടിസ്ഥാനപരമായ
<!-- hl-knowledge: introduces=[ML-LEX-C445-GAURAVAM445-03]; assesses=[] -->

**അടിസ്ഥാനപരമായ** — *aṭisthānaparamāya* — "fundamental; basic".

> അവർ തമ്മിൽ അടിസ്ഥാനപരമായ ഒരു വ്യത്യാസം ഉണ്ട്.
>
> *avar tammil aṭisthānaparamāya oru vyatyāsaṁ uṇṭŭ.*
>
> There is a fundamental difference between them.

Built on അടിസ്ഥാനം, a basis, with -പരമായ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**അടിസ്ഥാനപരമായ** (*aṭisthānaparamāya*) is built on അടിസ്ഥാനം, "a basis", which joins native *aṭi*, "sole, bottom" (DEDR 72), to Sanskrit *sthāna*, "place" (CDIAL 13753), with -പരമായ, "concerned with".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
