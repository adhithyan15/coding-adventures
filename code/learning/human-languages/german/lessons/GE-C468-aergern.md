## You'll want to know: ärgern
<!-- hl-knowledge: introduces=[GE-LEX-C468-WUT-03]; assesses=[] -->

**ärgern** — "to annoy; to be annoyed (sich ärgern)".

> Ich ärgere mich über den Lärm der Nachbarn.
>
> *I'm annoyed about the neighbours' noise.*

*Sich ärgern über* + accusative — to be annoyed about. Without *sich*: *Du ärgerst mich!* — You're annoying me!

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*ärgern* is inherited from Old High German *argerōn* "to make worse" (EtymDB), built on *arg* "bad", from Proto-Germanic *argaz*.
