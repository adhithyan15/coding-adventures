# An old word for jumping

First retrieve **to jump** on its own. Then mix just the four
earlier action words, with pauses and models. This is not a new
sentence pattern or a scored mock.

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-C148-ACT148-05] -->

Hear **to jump**. [PAUSE 4s] Say the old Punjabi word before the
model: **ਟੱਪਣਾ** (*ṭappṇā*).

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-C148-ACT148-02, PA-LEX-C148-ACT148-03, PA-LEX-C148-ACT148-04, PA-LEX-C148-ACT148-05] -->

Pause after each familiar meaning, then listen to the old word:

- **to lift** — [PAUSE 4s] **ਚੁੱਕਣਾ** (*cukkṇā*).
- **to fall** — [PAUSE 4s] **ਡਿੱਗਣਾ** (*ḍiggṇā*).
- **to jump** — [PAUSE 4s] **ਟੱਪਣਾ** (*ṭappṇā*).
- **to teach** — [PAUSE 4s] **ਸਿਖਾਉਣਾ** (*sikhāuṇā*).

The shuffled order is the only new part of this practice.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-C148-ACT148-02, PA-LEX-C148-ACT148-03, PA-LEX-C148-ACT148-04, PA-LEX-C148-ACT148-05] -->

Hear **to teach**, **to jump**, **to fall**, then **to lift**.
Pause after each cue and recall its Punjabi word before the model:
**ਸਿਖਾਉਣਾ**, **ਟੱਪਣਾ**, **ਡਿੱਗਣਾ**, **ਚੁੱਕਣਾ**.
Revisit only the old word you missed.
