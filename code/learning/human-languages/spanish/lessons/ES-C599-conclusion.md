## You'll want to know: la conclusión
<!-- hl-knowledge: introduces=[ES-LEX-C599-INVESTIGA-04]; assesses=[] -->

**la conclusión** — "the conclusion".

> Llegamos a una conclusión.
>
> *We reached a conclusion.*

*En conclusión* — in conclusion.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*conclusión* is a learned borrowing from Latin *conclusio* 'a closing, an end', built on *concludere* and *claudere* 'to shut' (EtymDB).
