# நுழைவாயில் (nuḻaivāyil) — an entrance; a gateway

## You'll want to know: நுழைவாயில்
<!-- hl-knowledge: introduces=[TA-LEX-C414-ELLAI414-04]; assesses=[] -->

**நுழைவாயில்** — *nuḻaivāyil* — "an entrance; a gateway".

> நுழைவாயிலில் காவலர்கள் நின்றார்கள்.
>
> *nuḻaivāyilil kāvalarkaḷ niṉṟārkaḷ.*
>
> Guards stood at the entrance.

நுழை, to enter, + வாயில், a doorway.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**நுழைவாயில்** (*nuḻaivāyil*) is built from நுழை, "to enter" (DEDR 3714), and வாயில், "a doorway, a gate" (DEDR 5354).
