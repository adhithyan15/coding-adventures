## You'll want to know: नेमणे
<!-- hl-knowledge: introduces=[MR-LEX-C357-SHASAN357-05]; assesses=[] -->

**नेमणे** — *nemṇe* — "to appoint".

> कंपनीने नवा व्यवस्थापक नेमला.
>
> *kampnīne navā vyavasthāpak nemlā.*
>
> The company appointed a new manager.

Past, with -ने (he …): त्याने नेमलं, *tyāne nemlaṁ*.

X म्हणून नेमणे, to appoint as X; नेमणूक, an appointment.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**नेमणे** (*nemṇe*) is built on नेम, "a fixed rule, an aim", usually traced to Sanskrit *niyama*, "restraint, fixed rule" (Monier-Williams).
