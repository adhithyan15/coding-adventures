# Urdu A1 writing paper 1 — examiner rubric

Keep this file separate from the
[learner sheet](writing-paper-1.md). This is a writing-only practice paper
against [the A1 task-shape inventory](../../task-shapes/a1.json), not one of
the two complete timed four-skill mocks required by the assessment contract.
It cannot alone establish A1 readiness. The 20-minute clock is continuous:
Task 1 takes the first 7 minutes and Task 2 the remaining 13. Never put this
paper inside a five-minute lesson or count it as a completed full mock.

## Scoring — 100 points

Score each task in four dimensions, **0–5 per dimension**, then multiply the
20-point sum by **2** for Task 1 (40 points) or **3** for Task 2 (60 points).
An omitted task earns zero. Use these dimensions consistently:

1. Task fulfilment and relevant content: seven independent reading-circle
   form responses, or a message to Sara with an introduction, proposed day,
   time, place, book preference, possible companion, question, and polite close.
2. Comprehensibility and organisation: usable form details, or a message that
   Sara can follow and answer.
3. Urdu vocabulary, grammar, and register: independently chosen contemporary
   standard Urdu appropriate to an everyday A1 exchange. Polite **آپ** is a
   safe default for a first encounter; do not require advanced literary style.
4. Urdu orthographic control: intended letters, dots, joins and non-joins,
   right-to-left word boundaries, and legibility. Ordinary handwriting is
   sufficient; Nastaliq calligraphic ligatures and slope are not scored.

For each dimension, use **0** for no assessable evidence, **1** for isolated
fragments that rarely communicate, **2** for partial communication with major
losses, **3** for understandable basic performance with some errors, **4** for
clear performance with minor errors, and **5** for complete clear performance
within the A1 task. The 30–40-word band is the intended scope, not a reason
to discard an otherwise intelligible 29- or 41-word message; reflect
meaningful under- or over-response in task fulfilment. No copyable model
response is provided here.

At A1, penalise a dot, joining, or spelling error only when it obscures the
intended word or the task directly tests that contrast. Unwritten short vowels
and optional diacritics receive neither bonus nor penalty unless a tested
meaning-changing contrast depends on them. For typed accommodations,
normalise equivalent Urdu grapheme sequences after submission. Record any
accessibility accommodation without changing the construct. Documented
regional forms used consistently may receive credit; a qualified Urdu
reviewer adjudicates unfamiliar forms.

Accept safe invented names, places, and preferences; do not require personal
data or one preferred cultural choice. Roman Urdu, Devanagari, a traced
model, or another language is not independent Urdu-script writing evidence.
A support-language instruction is not an answer model.

Record the four dimension marks for each task, both scaled task totals, and
the 100-point writing score. The provisional project threshold is **60/100
for writing independently**; a four-skill pass additionally requires at least
60/100 in each of reading, listening, and speaking in the same administration.
Two complete timed mock passes and human validation remain separate gaps.
