## 0.1.0 - pbt-v1 conformance

First release of the C test-bootstrap package (spec:
`code/specs/VER05i-c-pbt-engine.md`). C previously had no test bootstrap,
property engine or fuzz engine.

### Added
- `pbt_rng`: SplitMix64, `pbt_rng_bounded` (rejection threshold `(0 - n) % n` on
  `uint64_t`, correct by unsigned wraparound; `bounded(1)` consumes a word),
  `pbt_rng_bounded_big` (k-word rejection above 2^64), `pbt_fnv1a64`,
  `pbt_sub_seed` (VER05 section 2.3). Pinned against the independent Python
  reference.
- `pbt_big`: a fixed-limb sign-magnitude bignum (36 `uint32_t` limbs, 1000-bit
  and 300-digit caps, overflow reported, never wrapped) because `unsigned
  __int128` is not ISO C.
- Tagged values (`pbt_val`), deep clone/equality/weight, and the total canonical
  renderer `pbt_canon` (depth 16, 10k nodes, 1 MiB, escapes control bytes).
- The generator algebra with function pointers and `void *` contexts: `bool`,
  `u8`, `u64`, `i128`, `int`, `bytes`, `constant`, `map`, `filter`, `flat_map`,
  `one_of`, `frequency`, `list`, `tuple`, `custom`; reference counted; `NULL`
  propagates.
- Integrated shrinking (integer walk, in-place no-copy sequence shrinker) that
  matches the corpus minimals and step counts exactly.
- The VER05e 4.1 hierarchical shrink-budget tree as an explicit context
  parameter (single-threaded, no ambient state): all-or-nothing `take`, depth cap
  64, public entries open child scopes, nested checks pay at entry / per case /
  per sampled size / per filter retry, starvation is never a pass, a refused
  re-verification keeps the original witness.
- `pbt_check`: verdict honesty (zero cases, generator error, property error,
  re-verified witness), the closed failure vocabulary, CI redaction that fails
  closed (`PBT_CI_UNSET` redacts; `pbt_ci_from_value` is pure).
- Strict JSON reader (depth 64, 8 MiB, 200k nodes, duplicate keys, invalid
  UTF-8, leading zeros, trailing data; numbers kept as text), strict TFV
  validator, and `pbt_corpus_evaluate` with CWE-400 caps and clipped problems.
- Test seams (`pbt_hooks.h`): sabotage function pointers and an allocator with a
  live-allocation counter and N-th-allocation failure injection.
- Tests: the committed pbt-v1 corpus 25/25 (outputs, minimals and step counts),
  per-case per-op corruption (each must fail and name exactly that case), every
  field of every case wrong-typed, dropped/truncated corpora, sabotage hooks, a
  forced rejection draw (inverted SplitMix64 finalizer), the `2^63+1` threshold,
  both bisection halves, the Java `ShrinkBudgetTest` set minus thread tests, a
  bignum suite, strict JSON/TFV suites, and an exhaustive allocation-failure
  sweep (no crash, no leak, no false success).
- `tools/run.sh` builds and runs everything under every available C compiler in
  strict ISO mode (`-std=c17 -pedantic-errors -Wall -Wextra -Werror`) and then
  under AddressSanitizer + UndefinedBehaviorSanitizer; `tools/run.ps1` for MSVC;
  `tools/coverage.sh` is an on-demand llvm-cov report (the C lane has no coverage
  gate, so none is added to BUILD): 94.8% of lines, 95.4% of regions, 99.6% of
  functions of `src/` at release.
