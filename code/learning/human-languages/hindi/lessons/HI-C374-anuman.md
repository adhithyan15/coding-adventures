## You'll want to know: अनुमान
<!-- hl-knowledge: introduces=[HI-LEX-C374-ANDAZA374-02]; assesses=[] -->

**अनुमान** — *anumān* — "an estimate, a forecast".

> अनुमान के अनुसार अगर ऐसी गर्मी रहेगी तो पानी कम पड़ेगा।
>
> *anumān ke anusār agar aisī garmī rahegī to pānī kam paṛegā.*
>
> According to the forecast, if the heat goes on like this, water will run short.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**अनुमान** (*anumān*) is a tatsama, borrowed from Sanskrit *anumāna*, "inferring, a conclusion" (Monier-Williams).
