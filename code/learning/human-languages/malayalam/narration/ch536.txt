Malayalam, chapter 536: Blood Tests and Muscles.
5 lessons. All 5 can be done entirely by ear.


Lesson 1 of 5.
രക്തപരിശോധന (raktapariśōdhana) — a blood test.

Warm-up.
[pause 2 seconds]
Before the new one: say the Malayalam for rheumatism, then the Malayalam for to throw up.

You'll want to know: രക്തപരിശോധന.
രക്തപരിശോധന — raktapariśōdhana — "a blood test".
രാവിലെ ഒന്നും കഴിക്കാതെ രക്തപരിശോധന നടത്തണം. rāvile onnuṁ kaḻikkāte raktapariśōdhana naṭattaṇaṁ. The blood test has to be done in the morning before eating.
രക്തം blood + പരിശോധന a check; the verb പരിശോധിക്കുക is already familiar.

The word, taken apart.
രക്തപരിശോധന (raktapariśōdhana) is a learned compound built from Sanskrit rakta, "red; blood" (CDIAL 10539), and pariśodhana, "cleaning, purifying" (Monier-Williams), which Malayalam uses for a check.

പുകവലി ശ്വാസകോശത്തിന് ദോഷമാണ്. pukavali śvāsakōśattinŭ dōṣamāṇŭ. Smoking is bad for the lungs.
ശ്വാസം breath + കോശം a vessel, a store.

The word, taken apart.
ശ്വാസകോശം (śvāsakōśaṁ) is a learned compound built from Sanskrit śvāsa, "breath" (CDIAL 12769), and kośa, "a cask, a vessel" (Monier-Williams): the store of breath.

ഉച്ചയ്ക്ക് ശേഷം മുത്തച്ഛൻ കുറച്ച് നേരം വിശ്രമിക്കും. uccaykkŭ śēṣaṁ muttacchan kuṟaccŭ nēraṁ viśramikkuṁ. After noon grandfather rests for a while.

The noun വിശ്രമം, rest, is already familiar.

The word, taken apart.
വിശ്രമിക്കുക (viśramikkuka) is built from Sanskrit viśrama, "rest" (CDIAL 11947), with the Malayalam verb ending -ിക്കുക.
