## You'll want to know: अनृतम्
<!-- hl-knowledge: introduces=[SA-LEX-C312-NIRAKARANA312-04]; assesses=[] -->

**अनृतम्** — *anṛtam* — "a lie; an untruth".

> सः आरोपः अनृतम् अस्ति।
>
> *saḥ āropaḥ anṛtam asti.*
>
> That allegation is a lie.

A neuter noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**अनृतम्** (*anṛtam*) is built from *an*, "not", and *ṛta*, "right, true"; MW gives *anṛta* as not true and, as a noun, falsehood, lying (MW).
