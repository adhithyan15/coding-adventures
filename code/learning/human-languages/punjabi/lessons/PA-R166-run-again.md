# An old word for running

Hear one familiar meaning, pause, and retrieve its Punjabi word before the
model. This is a gentle return, not a new word or a scored mock.

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-C152-ACT152-01] -->

Hear **to run**. [PAUSE 4s] Recall **ਭੱਜਣਾ** (*bhajjṇā*).

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-C152-ACT152-01] -->

Hear **ਭੱਜਣਾ**. [PAUSE 4s] Recall **to run**.
Then hear **to run** again. [PAUSE 4s] Say **ਭੱਜਣਾ** before the model.
Only this old word is needed.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-C152-ACT152-01] -->

One last cue: **to run**. [PAUSE 4s] Recall **ਭੱਜਣਾ**.
Listen and retry once if it does not come back.
