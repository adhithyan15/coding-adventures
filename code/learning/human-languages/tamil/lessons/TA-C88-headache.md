# தலைவலி (talaivali) — a headache

## You'll want to know: தலைவலி
<!-- hl-knowledge: introduces=[TA-LEX-C88-DOCTOR-03]; assesses=[] -->

**தலைவலி** (*talaivali*) — "a headache".

It is **தலை**, "head", and **வலி**, "pain", written as one word. **எனக்குத் தலைவலி** — "I have a
headache".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

Head and pain, joined.
