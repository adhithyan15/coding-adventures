# અનુકૂળ (anukūḷ) — convenient

<!-- hl-knowledge: introduces=[]; assesses=[GU-LEX-C532-POSAVU532-02, GU-LEX-C532-POSAVU532-03] -->

## You'll want to know: અનુકૂળ
<!-- hl-knowledge: introduces=[GU-LEX-C532-POSAVU532-04]; assesses=[] -->

**અનુકૂળ** — *anukūḷ* — "convenient".

> જો તમને રવિવાર અનુકૂળ હશે તો આપણે ત્યારે મળીશું.
>
> *jo tamne ravivār anukūḷ haśe to āpaṇe tyāre maḷīśũ.*
>
> If Sunday suits you, we will meet then.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**અનુકૂળ** (*anukūḷ*) is a tatsama, taken from Sanskrit *anukūla*, "following the slope of the bank", and so "favourable, suitable" (Monier-Williams).

One more word for saying what happens if.
