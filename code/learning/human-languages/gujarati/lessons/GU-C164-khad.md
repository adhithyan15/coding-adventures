# ખાંડ (khā̃ḍ) — sugar

## You'll want to know: ખાંડ
<!-- hl-knowledge: introduces=[GU-LEX-C164-SPICE164-02]; assesses=[] -->

**ખાંડ** — *khā̃ḍ* — "sugar".

> **ડબ્બામાં ખાંડ નથી.** — *ḍabbāmā̃ khā̃ḍ nathī* — "There is no sugar in the tin."

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ખાંડ** (*khā̃ḍ*) is a tadbhava. It comes from Sanskrit *khaṇḍa*, *khaṇḍu*, "sugar; partially dried molasses", and CDIAL glosses the Gujarati word "coarse sugar" (CDIAL 3800).
