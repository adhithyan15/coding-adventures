# துடுப்பு (tuṭuppu) — an oar; a paddle

## You'll want to know: துடுப்பு
<!-- hl-knowledge: introduces=[TA-LEX-C416-PATAKU416-02]; assesses=[] -->

**துடுப்பு** — *tuṭuppu* — "an oar; a paddle".

> துடுப்பு இல்லாமல் படகு நகராது.
>
> *tuṭuppu illāmal paṭaku nakarātu.*
>
> Without an oar the boat will not move.

Also a ladle or a flat spoon for stirring.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**துடுப்பு** (*tuṭuppu*) is native Dravidian (DEDR 3299), "a ladle, a spatula, an oar".
