# ಆಕ್ಷೇಪಿಸು (ākṣēpisu) — to object

## You'll want to know: ಆಕ್ಷೇಪಿಸು
<!-- hl-knowledge: introduces=[KA-LEX-C377-TARKA377-04]; assesses=[] -->

**ಆಕ್ಷೇಪಿಸು** — *ākṣēpisu* — "to object".

> ಊರಿನ ಜನರು ಹೊಸ ಕಾರ್ಖಾನೆಗೆ ಆಕ್ಷೇಪಿಸಿದರು.
>
> *ūrina janaru hosa kārkhānege ākṣēpisidaru.*
>
> The villagers objected to the new factory.

Past (I …): ಆಕ್ಷೇಪಿಸಿದೆ, *ākṣēpiside*.

What you object to takes -ಗೆ. ಆಕ್ಷೇಪ, an objection.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಆಕ್ಷೇಪಿಸು** (*ākṣēpisu*) is built on Sanskrit *ākṣepa*, which among other senses means "an objection" and "a reproach" (Monier-Williams), with the verb ending -*isu*.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
