## You'll want to know: libérer
<!-- hl-knowledge: introduces=[FR-LEX-C326-LIBERATION-01]; assesses=[] -->

**libérer** — "to free, to set free".

> Les soldats ont libéré la ville.
>
> *The soldiers freed the town.*

Also of a room: *libérer la chambre* — to check out.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*libérer* is a learned borrowing from Latin *līberāre* "to set free" (EtymDB), built on *līber* "free".
