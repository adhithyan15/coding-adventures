### Changed — Hindi's forward-reference pin falls from 57 to 33

- **`FORWARD_REFERENCE_CEILINGS` pins Hindi at 33**, down from the 57 it was
  pinned at when the table was introduced. The Hindi lessons were reworded so
  they stop leaning on words a later lesson teaches (see the Hindi changelog).
- **The ceiling comment now names a second shape.** Besides phrases taught
  whole and unpacked later, Hindi has bundles: separate words taught under one
  headword (पानी रोटी, the six seasons, दोपहर आधी रात). A multi-word headword
  owns no single token, so each earlier use counts as borrowing the word the
  later lesson teaches alone. The table's comments name each one.
