# ಮುಂಗೋಪಿ (muṅgōpi) — short-tempered

## You'll want to know: ಮುಂಗೋಪಿ
<!-- hl-knowledge: introduces=[KA-LEX-C504-MATU504-03]; assesses=[] -->

**ಮುಂಗೋಪಿ** — *muṅgōpi* — "short-tempered".

> ನಮ್ಮ ಮೇಲಧಿಕಾರಿ ಮುಂಗೋಪಿ, ಬೇಗ ಕೋಪಗೊಳ್ಳುತ್ತಾರೆ.
>
> *namma mēladhikāri muṅgōpi, bēga kōpagoḷḷuttāre.*
>
> Our boss is short-tempered; he gets angry quickly.

ಮುನ್, before + ಕೋಪ, anger: angry before anything has happened.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಮುಂಗೋಪಿ** (*muṅgōpi*) is a Kannada compound: native *mun*, "before, in front" (DEDR 5020), and *kōpa*, "anger", borrowed from Sanskrit (CDIAL 3516), with -*i* for the person.
