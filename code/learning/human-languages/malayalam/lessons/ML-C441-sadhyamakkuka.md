# സാധ്യമാക്കുക (sādhyamākkuka) — to make possible

## You'll want to know: സാധ്യമാക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C441-SADHYAM441-03]; assesses=[] -->

**സാധ്യമാക്കുക** — *sādhyamākkuka* — "to make possible".

> നാട്ടുകാരുടെ സഹായം ആ പാലം സാധ്യമാക്കി.
>
> *nāṭṭukāruṭe sahāyaṁ ā pālaṁ sādhyamākki.*
>
> The local people's help made that bridge possible.

Past: സാധ്യമാക്കി, *sādhyamākki*.

ആക്കുക, to make, turns an adjective into a verb.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**സാധ്യമാക്കുക** (*sādhyamākkuka*) is built from Sanskrit *sādhya*, "to be accomplished" (Monier-Williams), with ആക്കുക, "to make", native Dravidian (DEDR 333).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
