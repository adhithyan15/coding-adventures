## You'll want to know: der Deckel
<!-- hl-knowledge: introduces=[GE-LEX-C327-KOECHELN-05]; assesses=[] -->

**der Deckel** — "the lid".

> Er legte den Deckel auf den Topf.
>
> *He put the lid on the pot.*

Plural: *die Deckel*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*Deckel* is built on *decken* "to cover", from Proto-Germanic *þakjaną*, which EtymDB builds on *þaką* "thatch, roof".
