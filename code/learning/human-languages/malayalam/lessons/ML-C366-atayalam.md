# അടയാളം (aṭayāḷaṁ) — a mark; a sign

## You'll want to know: അടയാളം
<!-- hl-knowledge: introduces=[ML-LEX-C366-SUCHANA366-02]; assesses=[] -->

**അടയാളം** — *aṭayāḷaṁ* — "a mark; a sign".

> കള്ളൻ ഭിത്തിയിൽ ഒരു അടയാളം ഇട്ടു.
>
> *kaḷḷan bhittiyil oru aṭayāḷaṁ iṭṭu.*
>
> The thief left a mark on the wall.

Also a symbol or a landmark.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**അടയാളം** (*aṭayāḷaṁ*) is native Dravidian: DEDR 89 lists Malayalam *aṭayāḷam*, "mark, sign", beside Tamil *aṭaiyāḷam*, "mark, symbol, seal".
