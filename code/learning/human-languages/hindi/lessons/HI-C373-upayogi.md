## You'll want to know: उपयोगी
<!-- hl-knowledge: introduces=[HI-LEX-C373-MUMKIN373-05]; assesses=[] -->

**उपयोगी** — *upayogī* — "useful".

> अगर तुम यह किताब पढ़ोगे तो यह बहुत उपयोगी होगी।
>
> *agar tum yah kitāb paṛhoge to yah bahut upayogī hogī.*
>
> If you read this book, you will find it very useful.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**उपयोगी** (*upayogī*) is a tatsama, borrowed from Sanskrit *upayogin*, "serviceable, useful" (Monier-Williams).
