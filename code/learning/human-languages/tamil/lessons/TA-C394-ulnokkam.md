# உள்நோக்கம் (uḷnōkkam) — a hidden motive

## You'll want to know: உள்நோக்கம்
<!-- hl-knowledge: introduces=[TA-LEX-C394-ORUTALAIPPAT394-02]; assesses=[] -->

**உள்நோக்கம்** — *uḷnōkkam* — "a hidden motive".

> அவருடைய உதவிக்குப் பின்னால் ஒரு உள்நோக்கம் இருக்கிறது என்று நினைக்கிறேன்.
>
> *avaruṭaiya utavikkup piṉṉāl oru uḷnōkkam irukkiṟatu eṉṟu niṉaikkiṟēṉ.*
>
> I think there is a hidden motive behind his help.

உள், inner + நோக்கம், aim: an aim kept inside.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**உள்நோக்கம்** (*uḷnōkkam*) is native: *uḷ*, "inside, mind" (DEDR 698), and *nōkkam*, "aim, purpose", from *nōkku*, "to look" (DEDR 3794): an aim the eye does not see.
