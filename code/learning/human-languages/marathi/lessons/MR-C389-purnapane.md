# पूर्णपणे (pūrṇapaṇe) — completely

## You'll want to know: पूर्णपणे
<!-- hl-knowledge: introduces=[MR-LEX-C389-PRAMANE389-02]; assesses=[] -->

**पूर्णपणे** — *pūrṇapaṇe* — "completely".

> पावसामुळे रस्ता पूर्णपणे बंद झाला.
>
> *pāvsāmuḷe rastā pūrṇapaṇe band jhālā.*
>
> Because of the rain the road was completely closed.

पूर्ण, full, + -पणे, the adverb ending.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**पूर्णपणे** (*pūrṇapaṇe*) is built from पूर्ण, "full", a tatsama from Sanskrit *pūrṇa*, "filled, full" (CDIAL 8339), with the adverb ending -पणे.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
