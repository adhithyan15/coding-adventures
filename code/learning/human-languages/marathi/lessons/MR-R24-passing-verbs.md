# Four things that pass between two people

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MR-LEX-SANGNE, MR-LEX-MHANNE, MR-LEX-SHIKNE, MR-LEX-MILNE] -->

[PAUSE 5s] Say the four in order: *sāṅgṇe*, then **म्हणणे, शिकणे, मिळणे**.
Three of them you can also write; one is still owed a letter.
