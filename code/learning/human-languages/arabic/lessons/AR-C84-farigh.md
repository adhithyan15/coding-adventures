## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**فارغ** (*fārigh*) is built on the native Arabic root *f-r-gh*, "to be empty, to be free" (Lane). *Fārigh* is the active participle, "empty, vacant".
