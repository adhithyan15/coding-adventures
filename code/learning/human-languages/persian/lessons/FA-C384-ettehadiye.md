## You'll want to know: اتحادیه
<!-- hl-knowledge: introduces=[FA-LEX-C384-ETESAB-02]; assesses=[] -->

**اتحادیه** (*ettehâdiye*) — "a union, an association".

> اتحادیه کارگران با مدیرها مذاکره کرد.
>
> *ettehâdiye-ye kârgarân bâ modirhâ mozâkere kard.*
>
> The workers' union negotiated with the managers.

*Ettehâd* "unity" + *-iye*. *Ettehâdiye-ye kârgari* — a trade union.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**اتحادیه** is built on *ettehâd* "unity", usually traced to Arabic *ittiḥād* "becoming one", with the ending *-iye*.
