# ば — は, voiced to ba

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[JA-LEX-ANCHOR-KABAN, JA-LEX-C132-SORE, JA-LEX-C122-QUAL122-02] -->

[PAUSE 15s] Three recalls, then the sign.

- [YOU RECALL: say *a bag*, the one you carry to work — **R1**, one lesson back]
- [YOU RECALL: say *that*, a thing near the listener — **R3**, twenty lessons back]
- [YOU RECALL: say *precious* — **R4**, eighty lessons back]

## Script — the change
<!-- hl-knowledge: introduces=[JA-SCRIPT-BA-01]; assesses=[JA-SCRIPT-HA-01, JA-SCRIPT-DAKUTEN-01] -->

> **は** *ha* + **゛** → **ば** *ba*

Write **は** in full, in the order you learned it. Then add the two short
strokes of the voicing mark at the upper right, the left one first.

Here the mark does something you have met only once: on an *h* sign it makes
a *b*, so *ha* becomes *ba*. You saw it on **ほ** for **ぼ**, in **さんぼん**.

With **か** in front and **ん** after it, you can now write the word from the
last lesson: **かばん**, *kaban*, a bag.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[JA-SCRIPT-BA-01, JA-SCRIPT-HA-01, JA-SCRIPT-DAKUTEN-01, JA-LEX-ANCHOR-KABAN] -->

1. Write **は**, then **ば**, and say *ha*, *ba*.
2. Write **ほ ぼ** and **は ば** in pairs, and say each one.
3. Write **かばん** from memory and say *kaban*.
