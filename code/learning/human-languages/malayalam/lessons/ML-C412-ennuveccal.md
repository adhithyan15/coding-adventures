# എന്നുവെച്ചാൽ (ennuveccāl) — that means; that is

## Warm-up

[PAUSE 2s] Before the new one: say the Malayalam for or, then the Malayalam for generally.

## You'll want to know: എന്നുവെച്ചാൽ
<!-- hl-knowledge: introduces=[ML-LEX-C412-CURUKKAM412-05]; assesses=[] -->

**എന്നുവെച്ചാൽ** — *ennuveccāl* — "that means; that is".

> നാളെ അവധിയാണ്, എന്നുവെച്ചാൽ ക്ലാസ് ഇല്ല.
>
> *nāḷe avadhiyāṇŭ, ennuveccāl klāsŭ illa.*
>
> Tomorrow is a holiday, which means there is no class.

In speech often എന്നു പറഞ്ഞാൽ, if one says so.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**എന്നുവെച്ചാൽ** (*ennuveccāl*) is a native Malayalam compound: എന്ന്, "thus (said)" (DEDR 868), and വെച്ചാൽ, "if one puts", from വെക്കുക, "to put" (DEDR 5549): "if one puts it that way".
