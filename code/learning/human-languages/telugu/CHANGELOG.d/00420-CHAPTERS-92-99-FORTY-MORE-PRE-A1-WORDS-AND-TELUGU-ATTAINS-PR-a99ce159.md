What this claims and what it does not: pre-A1 is a statement about the CORPUS

been scored against Telugu, so nothing here says a learner can pass anything.
The next rung, A1, has five blockers (vocabulary 248, verb-vocabulary 30,
reinforcement 19, spine-nodes 6, writing-stage 2).
