# അകലെ (akale) — far away

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C81-DISTANCE-01, ML-GRAMMAR-C41-DEIXIS-SYSTEM] -->

[PAUSE 2s] Say the word for *near*. Then say the three-way pattern the pointing
words are built on.

## You'll want to know: അകലെ
<!-- hl-knowledge: introduces=[ML-LEX-C81-DISTANCE-02]; assesses=[] -->

**അകലെ** — *akale* — far away.

The scale now has both ends:

| | |
|---|---|
| **അടുത്ത്** *aṭuttŭ* | near |
| **അകലെ** *akale* | far |

Between them you can place anything, and **അവിടെ** stops having to do a job it
was never built for.

## Why it's said this way: a shape that is not the pattern
<!-- hl-knowledge: introduces=[]; assesses=[ML-GRAMMAR-C41-DEIXIS-SYSTEM, ML-LEX-C41-DEIXIS-04] -->

Look at **അകലെ** and **അവിടെ** side by side. Both open with **അ**, and the
pointing pattern you learned says that **അ-** is the *away* one — *aviṭe*,
*that place*, over there.

**Resist that.** The **അ** in *akale* is **part of the word**, not the pointing
prefix stuck on the front of it. The pattern is real and this is not an instance
of it; the two only look alike.

This is worth a page of its own because the habit it trains is the useful one.
**A pattern you have learned will start finding matches everywhere, including
where there are none.** The test is never how the word looks — it is whether the
other members of the set exist. There is no *ikale* meaning *near* and no *ekale*
meaning *how far*, so there is no set, so there is no pattern here.
