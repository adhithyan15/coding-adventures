# Review — it depends, and what would happen

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[JA-GRAMMAR-C261-DEPENDS-01, JA-LEX-C261-BAAI-01] -->

[PAUSE 2s] Say "it depends on the weather". (*tenki ni yorimasu*.) Then "in case of rain, it is called off". (*ame no baai wa, chūshi desu*.)

[PAUSE 2s each]
- [YOU SAY: That depends on the time.]
- [YOU SAY: In case of snow, the festival is called off.]
- [YOU SAY: If I had time, I think I would go.]
- [YOU SAY: If she had time, my mother would come.]
- [YOU SAY: If it is fine, I will go.]
- [YOU SAY: If it snows, what will you do?]
- [YOU SAY: It depends on the time. I work from nine to five.]
