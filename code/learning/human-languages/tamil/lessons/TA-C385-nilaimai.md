# நிலைமை (nilaimai) — the situation; the state of things

## You'll want to know: நிலைமை
<!-- hl-knowledge: introduces=[TA-LEX-C385-CULNILAI385-02]; assesses=[] -->

**நிலைமை** — *nilaimai* — "the situation; the state of things".

> மழை நின்றால் நிலைமை சரியாகும்.
>
> *maḻai niṉṟāl nilaimai cariyākum.*
>
> If the rain stops, the situation will improve.

நிலைமை மோசமாக இருக்கிறது, the situation is bad.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**நிலைமை** (*nilaimai*) is native Dravidian: DEDR 3675 lists Tamil *nil*, "to stand, stay", and *nilaimai*, "state, condition".
