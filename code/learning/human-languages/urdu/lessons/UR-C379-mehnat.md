## You'll want to know: محنت
<!-- hl-knowledge: introduces=[UR-LEX-C379-MEHNAT379-01]; assesses=[] -->

**محنت** — *mehnat* — "hard work; effort".

> اگر تم نے محنت کی تو نتیجہ اچھا ہو گا۔
>
> *agar tum ne mehnat kī to natījā achchhā ho gā.*
>
> If you work hard, the result will be good.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**محنت** (*mehnat*) is usually traced, through Persian, to Arabic *miḥna*, "a trial, a hardship"; **محنتی**, "hardworking", is built on it.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
