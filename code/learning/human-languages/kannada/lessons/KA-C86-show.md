# ತೋರಿಸಿ (tōrisi) — please show me

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C86-WAIT-01, KA-LEX-C86-WAIT-02] -->

[PAUSE 2s] Before the new one: say the Kannada for one minute, then the Kannada for please wait.

## You'll want to know: ತೋರಿಸಿ
<!-- hl-knowledge: introduces=[KA-LEX-C86-WAIT-03]; assesses=[] -->

**ತೋರಿಸಿ** (*tōrisi*) — "please show (me)".

**ದಾರಿ ತೋರಿಸಿ** (*dāri tōrisi*) — "please show me the way", with **ದಾರಿ**,
"way, road".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

When words fail, ask to be shown.
