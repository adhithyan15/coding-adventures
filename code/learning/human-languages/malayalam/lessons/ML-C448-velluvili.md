# വെല്ലുവിളി (velluviḷi) — a challenge

[PAUSE 2s] Before the new one: say the Malayalam for efficiency, then the Malayalam for a crisis.

## You'll want to know: വെല്ലുവിളി
<!-- hl-knowledge: introduces=[ML-LEX-C448-PRATISANDHI448-02]; assesses=[] -->

**വെല്ലുവിളി** — *velluviḷi* — "a challenge".

> പുതിയ ജോലി ഒരു വലിയ വെല്ലുവിളിയാണ്.
>
> *putiya jōli oru valiya velluviḷiyāṇŭ.*
>
> The new job is a big challenge.

To challenge is വെല്ലുവിളിക്കുക.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**വെല്ലുവിളി** (*velluviḷi*) is a native Malayalam compound: വെല്ലുക, "to overcome, to surpass" (DEDR 5493), and വിളി, "a call" (DEDR 5433): a call to see who wins.
