## You'll want to know: el estreno
<!-- hl-knowledge: introduces=[ES-LEX-C760-PERSONAJE-04]; assesses=[] -->

**el estreno** — "the premiere, the first showing".

> Fuimos al estreno de la película.
>
> *We went to the premiere of the film.*

*Estrenar* — to show for the first time, to wear for the first time.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*estreno* is built on *estrenar*, which is usually traced to Latin *strēna* "an omen; a New Year gift" (Lewis & Short): using something new for the first time.
