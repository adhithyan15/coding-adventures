# ಒಂದೊಮ್ಮೆ (ondomme) — if ever; should it happen

## You'll want to know: ಒಂದೊಮ್ಮೆ
<!-- hl-knowledge: introduces=[KA-LEX-C428-ONDOMME428-01]; assesses=[] -->

**ಒಂದೊಮ್ಮೆ** — *ondomme* — "if ever; should it happen".

> ಒಂದೊಮ್ಮೆ ಬಸ್ ತಪ್ಪಿದರೆ ನಾನು ಆಟೋದಲ್ಲಿ ಬರುತ್ತೇನೆ.
>
> *ondomme bas tappidare nānu āṭōdalli baruttēne.*
>
> Should I miss the bus, I will come by auto.

It goes with a verb in -ದರೆ, as ಒಂದು ವೇಳೆ does.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಒಂದೊಮ್ಮೆ** (*ondomme*) is native Dravidian: *ondu*, "one", and *omme*, "once" (DEDR 990): at some one time.
