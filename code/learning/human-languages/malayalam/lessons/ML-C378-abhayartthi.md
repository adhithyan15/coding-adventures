# അഭയാർത്ഥി (abhayārtthi) — a refugee

## You'll want to know: അഭയാർത്ഥി
<!-- hl-knowledge: introduces=[ML-LEX-C378-ABHAYAM378-02]; assesses=[] -->

**അഭയാർത്ഥി** — *abhayārtthi* — "a refugee".

> യുദ്ധം കാരണം ഒരുപാട് അഭയാർത്ഥികൾ അതിർത്തി കടന്നു.
>
> *yuddhaṁ kāraṇaṁ orupāṭŭ abhayārtthikaḷ atirtti kaṭannu.*
>
> Because of the war many refugees crossed the border.

Plural: അഭയാർത്ഥികൾ, *abhayārtthikaḷ*.

അഭയം, refuge, + അർത്ഥി, one who seeks, as in വിദ്യാർത്ഥി.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**അഭയാർത്ഥി** (*abhayārtthi*) is built from Sanskrit *abhaya*, "safety" (CDIAL 507), and *arthin*, "desiring, one who seeks" (CDIAL 640), the same ending as in വിദ്യാർത്ഥി, "a student".
