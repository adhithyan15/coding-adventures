# An old word for sowing

First retrieve **to sow** alone. Then hear four familiar actions in a small
shuffled mix. Pause before each model. This is not a scored mock.

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-C151-ACT151-05] -->

Hear **to sow**. [PAUSE 4s] Recall **ਬੀਜਣਾ** (*bījṇā*).

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-C151-ACT151-02, PA-LEX-C151-ACT151-03, PA-LEX-C151-ACT151-04, PA-LEX-C151-ACT151-05] -->

Pause after each familiar meaning, then hear its model:

- **to save** — [PAUSE 4s] **ਬਚਾਉਣਾ** (*bacāuṇā*).
- **to live** — [PAUSE 4s] **ਜੀਉਣਾ** (*jīuṇā*).
- **to sow** — [PAUSE 4s] **ਬੀਜਣਾ** (*bījṇā*).
- **to spend** — [PAUSE 4s] **ਖ਼ਰਚਣਾ** (*kharcṇā*).

Only the order of these old words has changed.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-C151-ACT151-02, PA-LEX-C151-ACT151-03, PA-LEX-C151-ACT151-04, PA-LEX-C151-ACT151-05] -->

Hear **to sow**, **to spend**, **to live**, then **to save**. Pause after each
cue and recall its Punjabi word before the model: **ਬੀਜਣਾ**, **ਖ਼ਰਚਣਾ**,
**ਜੀਉਣਾ**, **ਬਚਾਉਣਾ**. Revisit only the old word you missed.
