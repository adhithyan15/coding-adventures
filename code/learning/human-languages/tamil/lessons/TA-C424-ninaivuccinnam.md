# நினைவுச்சின்னம் (niṉaivucciṉṉam) — a monument; a memorial

## You'll want to know: நினைவுச்சின்னம்
<!-- hl-knowledge: introduces=[TA-LEX-C424-SILAI424-03]; assesses=[] -->

**நினைவுச்சின்னம்** — *niṉaivucciṉṉam* — "a monument; a memorial".

> இந்த நினைவுச்சின்னம் நூறு ஆண்டுகள் பழையது.
>
> *inta niṉaivucciṉṉam nūṟu āṇṭukaḷ paḻaiyatu.*
>
> This monument is a hundred years old.

Two words joined, with the ச் doubled: நினைவு + சின்னம்.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**நினைவுச்சின்னம்** (*niṉaivucciṉṉam*) is built from *niṉaivu*, "remembrance" (DEDR 3683), and சின்னம், "a sign", borrowed from Sanskrit *cihna*, "a mark" (CDIAL 4833).
