# இவ்வாறு (ivvāṟu) — in this way

## You'll want to know: இவ்வாறு
<!-- hl-knowledge: introduces=[TA-LEX-C346-MUDIVU346-04]; assesses=[] -->

**இவ்வாறு** — *ivvāṟu* — "in this way".

> இவ்வாறு கதை முடிந்தது.
>
> *ivvāṟu katai muṭintatu.*
>
> In this way the story ended.

இ, this + ஆறு, way; அவ்வாறு, in that way.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**இவ்வாறு** (*ivvāṟu*) is built from the near-pointing இ-, "this", and native ஆறு, "way, manner" (DEDR 405).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
