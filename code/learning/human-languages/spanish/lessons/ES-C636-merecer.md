## You'll want to know: merecer
<!-- hl-knowledge: introduces=[ES-LEX-C636-VERDAD-05]; assesses=[] -->

**merecer** — "to deserve".

> Mereces unas vacaciones.
>
> *You deserve a holiday.*

Like *conocer*: *merezco*. *Merecer la pena* — to be worth it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*merecer* is inherited from spoken Latin *merescere*, built on *merere* 'to earn, to deserve' (EtymDB).
