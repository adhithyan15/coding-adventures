## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[KA-GRAMMAR-C317-ARE-CONDITIONAL-01, KA-GRAMMAR-C317-ONDU-VELE-01, KA-GRAMMAR-C317-REAL-CONDITION-01, KA-GRAMMAR-C317-NEGATIVE-CONDITION-01, KA-GRAMMAR-C316-KINTA-01, KA-GRAMMAR-C312-OBLIGATIVE-01, KA-LEX-C314-AUSADHA-01, KA-LEX-C176-KARANA176-02, KA-GRAMMAR-C316-MOST-01, KA-LEX-C48-ROLE-05, KA-GRAMMAR-C315-BECOME-01, KA-GRAMMAR-C315-WISH-BEKU-ANTA-01] -->

[PAUSE 2s each]
- [YOU SAY: If you come tomorrow, let's go to the cinema.]
- [YOU SAY: If by chance it rains, phone me.]
- [YOU SAY: If it rains, I will stay at home. Otherwise I will come at six.]
- [YOU SAY: If you don't take this medicine, you must go to the hospital.]
- [YOU SAY: If the train is faster than the bus, we must go by train.]
- [YOU SAY: This is the smallest room. If the guests come, I will sleep here.]
- [YOU SAY: If you want to become a doctor, you must study.]
