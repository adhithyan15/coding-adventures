# முன்னறிவிப்பு (muṉṉaṟivippu) — a forecast; advance notice

## You'll want to know: முன்னறிவிப்பு
<!-- hl-knowledge: introduces=[TA-LEX-C429-PUYAL429-01]; assesses=[] -->

**முன்னறிவிப்பு** — *muṉṉaṟivippu* — "a forecast; advance notice".

> வானிலை முன்னறிவிப்பில் புயல் வரும் என்று சொன்னார்கள்.
>
> *vāṉilai muṉṉaṟivippil puyal varum eṉṟu coṉṉārkaḷ.*
>
> In the weather forecast they said a storm would come.

முன், before, + அறிவிப்பு, an announcement.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**முன்னறிவிப்பு** (*muṉṉaṟivippu*) is built from முன், "before" (DEDR 5020), and அறிவிப்பு, "an announcement", from அறிவி, "to make known" (DEDR 314).
