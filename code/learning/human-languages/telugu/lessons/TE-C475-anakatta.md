# ఆనకట్ట (ānakaṭṭa) — a dam; a weir

## You'll want to know: ఆనకట్ట
<!-- hl-knowledge: introduces=[TE-LEX-C475-ANAKATTA475-02]; assesses=[] -->

**ఆనకట్ట** — *ānakaṭṭa* — "a dam; a weir".

> నది మీద కొత్త ఆనకట్ట కట్టారు.
>
> *nadi mīda kotta ānakaṭṭa kaṭṭāru.*
>
> They built a new dam on the river.

ఆన, a bank, + కట్ట, a bund. ఆనకట్ట కట్టు, to build a dam.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ఆనకట్ట** (*ānakaṭṭa*) is native Dravidian: ఆన, "a bank, a dam", which DEDR 122 lists as Telugu *ana* with a query, and కట్ట, "a bund, an embankment", from కట్టు, "to tie, to build" (DEDR 1147).
