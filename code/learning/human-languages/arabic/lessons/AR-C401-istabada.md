## You'll want to know: استبعد
<!-- hl-knowledge: introduces=[AR-LEX-C401-IHTIMAL401-05]; assesses=[] -->

**استبعد** — *istabʿada* — "to rule out".

> استبعد المدير هذا الاحتمال.
>
> *istabʿada al-mudīr hādhā al-iḥtimāl.*
>
> The manager ruled out this possibility.

Present: يستبعد, *yastabʿid*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**استبعد** (*istabʿada*) is built on the native Arabic root *b-ʿ-d*, "to be far" (Lane). It is Form X, to hold a thing to be far off: to rule it out. بعيد, far, is from the same root.
