# सूंपणो (sū̃pṇo) — to hand over

## You'll want to know: सूंपणो
<!-- hl-knowledge: introduces=[MW-LEX-C178-UNGH178-05]; assesses=[] -->

**सूंपणो** — *sū̃pṇo* — "to hand over".

> चाबी सूंपो।
>
> *chābī sū̃po.*
>
> Hand over the key, please.

Past (I …): म्हैं चाबी सूंपी, *mhaĩ chābī sū̃pī*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**सूंपणो** (*sū̃pṇo*) is inherited from Sanskrit *samarpayati*, "delivers over"; CDIAL lists Old Marwari *sopaï*, "hands over" (CDIAL 13192).
