# Review — feelings and hopes

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[BN-GRAMMAR-C272-FEELING-GENITIVE-01, BN-GRAMMAR-C272-WANT-TO-BE-01] -->

## Guided Practice

[PAUSE 2s each]
- [YOU SAY: I'm enjoying it here, because the people are kind.]
- [YOU SAY: Yesterday I was scared in the storm.]
- [YOU SAY: I had a new experience in the city.]
- [YOU SAY: Mira wants to be a doctor. Arun wants to see the sea.]
- [YOU SAY: I'd like to go to the mountains one more time.]
- [YOU WRITE: **অভিজ্ঞতা**, then **অরুণ**]
