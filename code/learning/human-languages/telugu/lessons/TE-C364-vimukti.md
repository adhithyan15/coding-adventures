# విముక్తి (vimukti) — liberation; release

## You'll want to know: విముక్తి
<!-- hl-knowledge: introduces=[TE-LEX-C364-VIMUKTI364-02]; assesses=[] -->

**విముక్తి** — *vimukti* — "liberation; release".

> బానిసలకు చివరికి విముక్తి లభించింది.
>
> *bānisalaku civariki vimukti labhiñcindi.*
>
> At last the slaves won their freedom.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**విముక్తి** (*vimukti*) is borrowed from Sanskrit *vimukti*, "giving up; release" (Monier-Williams), from *vi-muc*, "to set loose".
