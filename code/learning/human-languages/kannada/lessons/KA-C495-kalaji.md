# ಕಾಳಜಿ (kāḷaji) — care; concern

## You'll want to know: ಕಾಳಜಿ
<!-- hl-knowledge: introduces=[KA-LEX-C495-MAMATE495-05]; assesses=[] -->

**ಕಾಳಜಿ** — *kāḷaji* — "care; concern".

> ದಾದಿಗೆ ರೋಗಿಗಳ ಬಗ್ಗೆ ತುಂಬಾ ಕಾಳಜಿ ಇದೆ.
>
> *dādige rōgigaḷa bagge tumbā kāḷaji ide.*
>
> The nurse cares a great deal about the patients.

Care for someone: … ಬಗ್ಗೆ ಕಾಳಜಿ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಕಾಳಜಿ** (*kāḷaji*) is usually traced to Marathi *kāḷjī*, "care, anxious concern"; its earlier history is not settled.
