## You'll want to know: درخواست کردن
<!-- hl-knowledge: introduces=[FA-LEX-C441-DARKHAST-01]; assesses=[] -->

**درخواست کردن** (*darkhâst kardan*) — "to request, to ask for (formally)".

> از مدیر هتل یک اتاق دیگر درخواست کردیم.
>
> *Az modir-e hotel yek otâq-e digar darkhâst kardim.*
>
> We asked the hotel manager for another room.

*darkhâst* 'a request' + *kardan*. The person asked takes *az*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*darkhâst kardan* is built from *darkhâst* 'a request', which EtymDB lists and which is built on *khâstan* 'to want', and *kardan* 'to do', inherited from Middle Persian *kardan* (EtymDB).
