## You'll want to know: స్పష్టత
<!-- hl-knowledge: introduces=[TE-LEX-C394-VIVARANA394-02]; assesses=[] -->

**స్పష్టత** — *spaṣṭata* — "clarity".

> ఆ నియమం గురించి ఇంకా స్పష్టత రాలేదు.
>
> *ā niyamaṁ guriñci iṅkā spaṣṭata rālēdu.*
>
> There is still no clarity about that rule.

స్పష్టం, clear, + -త: the same family as స్పష్టమైన, which you know.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**స్పష్టత** (*spaṣṭata*) is built on Sanskrit *spaṣṭa*, "clearly perceived, distinct, plain" (Monier-Williams), with the abstract ending -త.
