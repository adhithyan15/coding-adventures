# పచ్చదనం (paccadanaṁ) — greenery

## You'll want to know: పచ్చదనం
<!-- hl-knowledge: introduces=[TE-LEX-C471-PARYAVARANAM471-02]; assesses=[] -->

**పచ్చదనం** — *paccadanaṁ* — "greenery".

> వర్షాల తరువాత పొలాల్లో పచ్చదనం కనిపిస్తోంది.
>
> *varṣāla taruvāta polāllō paccadanaṁ kanipistōndi.*
>
> After the rains greenery is showing in the fields.

పచ్చ, green, + -దనం, the ending of an abstract noun: greenness.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**పచ్చదనం** (*paccadanaṁ*) is native Dravidian: పచ్చ, "green" (DEDR 3821), with the abstract ending -దనం.
