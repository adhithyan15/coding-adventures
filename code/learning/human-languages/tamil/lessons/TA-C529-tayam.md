## You'll want to know: தாயம்
<!-- hl-knowledge: introduces=[TA-LEX-C529-VILAIYATTU529-03]; assesses=[] -->

**தாயம்** — *tāyam* — "a dice board game".

> விடுமுறையில் நாங்கள் தாயம் விளையாடினோம்.
>
> *viṭumuṟaiyil nāṅkaḷ tāyam viḷaiyāṭiṉōm.*
>
> In the holidays we played the dice game.

A board game played with dice; the game takes விளையாடு (*viḷaiyāṭu*) like any other.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

The origin of **தாயம்** (*tāyam*) is not settled; one suggestion is Sanskrit *dāya*, "a share, a portion" (CDIAL 6288).
