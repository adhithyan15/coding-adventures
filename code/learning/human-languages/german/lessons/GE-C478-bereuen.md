## You'll want to know: bereuen
<!-- hl-knowledge: introduces=[GE-LEX-C478-REUE-02]; assesses=[] -->

**bereuen** — "to regret".

> Sie bereut, dass sie so wenig gelernt hat.
>
> *She regrets studying so little.*

Inseparable: *hat bereut*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*bereuen* is built on *be-* and the old verb *reuen* "to cause sorrow", from the same source as *Reue*, Proto-Germanic *hrewwō* "pain, regret" (EtymDB).
