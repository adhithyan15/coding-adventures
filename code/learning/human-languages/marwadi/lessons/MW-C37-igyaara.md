# इग्यारा — eleven on the page

## You'll want to know
<!-- hl-knowledge: introduces=[MW-SCRIPT-IGYAARA-01]; assesses=[MW-SCRIPT-I-INDEPENDENT-01] -->

> **इ** + **ग्या** + **रा** → **इग्यारा** — *igyārā* — eleven

Three pieces, and only the first is new. **ग्या** is **ग** with its upright
stem cut away and **या** joined on behind it — the same virama **्** you have
been writing since chapter 4, doing the job it exists for: two consonants, one
breath, no vowel between them.

**रा** is chapter 1's **र** with the **ा** you have written more often than any
other mark in this book.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-IGYAARA-01, MW-SCRIPT-I-INDEPENDENT-01] -->
<!-- hl-writing-stage: guided-copy -->

Copy **इग्यारा** once while looking. Then write the three pieces apart —
**इ**, **ग्या**, **रा** — and point at the stem that **ग** gave up.
