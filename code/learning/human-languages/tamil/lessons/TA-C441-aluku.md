# அழுகு (aḻuku) — to rot

## You'll want to know: அழுகு
<!-- hl-knowledge: introduces=[TA-LEX-C441-KUPPAI441-01]; assesses=[] -->

**அழுகு** — *aḻuku* — "to rot".

> சந்தையில் தக்காளிகள் அழுகின.
>
> *cantaiyil takkāḷikaḷ aḻukiṉa.*
>
> The tomatoes rotted in the market.

Past (it …): அழுகியது, *aḻukiyatu*.

அழுகிய பழம் is a rotten fruit.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**அழுகு** (*aḻuku*) is native Dravidian (DEDR 284), "to rot, to decompose".
