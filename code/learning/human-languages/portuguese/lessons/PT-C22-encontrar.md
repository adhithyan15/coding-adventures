# encontrar — to find

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[] -->

[PAUSE 2s] Today **encontrar** has one job: “to find.”

## You'll want to know: The present tense
<!-- hl-knowledge: introduces=[PT-LEX-ENCONTRAR-02, PT-GRAMMAR-ENCONTRAR-04]; assesses=[] -->

| | |
|---|---|
| eu **encontro** | nós **encontramos** |
| tu **encontras** | vocês/eles **encontram** |
| ele/ela/você **encontra** | |

> **Encontro o livro.** — I find the book.
> **Encontramos o café.** — We find the café.

Keep the object directly after the verb, as in English.

## The word, taken apart
<!-- hl-knowledge: introduces=[PT-ETYMON-ENCONTRAR-03]; assesses=[] -->

**Encontrar** grew from *in* plus Latin ***contrā***, “facing” or “opposite.” To
find something is to come face to face with it. English **encounter** belongs to
the same family.
