# جان لیوا (jān-levā) — deadly; fatal

## You'll want to know: جان لیوا
<!-- hl-knowledge: introduces=[UR-LEX-C371-BUHRAN371-03]; assesses=[] -->

**جان لیوا** — *jān-levā* — "deadly; fatal".

> اگر یہ زہر ہے تو جان لیوا ہو سکتا ہے۔
>
> *agar yih zahr hai to jān-levā ho saktā hai.*
>
> If this is poison, it could be deadly.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**جان لیوا** (*jān-levā*) is built from *jān*, "life", usually traced to Persian *jān*, "life, soul", and *levā*, "taking", made on **لینا**, "to take". Life-taking.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
