# لولا (lawlā) — if not for

## You'll want to know: لولا
<!-- hl-knowledge: introduces=[AR-LEX-C400-KULLAMA400-01]; assesses=[] -->

**لولا** — *lawlā* — "if not for".

> لولا المطر لذهبنا إلى البحر.
>
> *lawlā al-maṭar la-dhahabnā ilā al-baḥr.*
>
> If not for the rain, we would have gone to the sea.

The result takes لـ, as after لو: لولا … لـ ….

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**لولا** (*lawlā*) is built from the native Arabic *law*, "if", and *lā*, "not": if it were not for. The deeper origin of such particles is not settled.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
