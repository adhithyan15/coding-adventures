# साधारण (sādhāraṇ) — roughly; ordinary

## You'll want to know: साधारण
<!-- hl-knowledge: introduces=[MR-LEX-C554-VEL554-05]; assesses=[] -->

**साधारण** — *sādhāraṇ* — "roughly; ordinary".

> बस साधारण दहा मिनिटांनी येईल.
>
> *bas sādhāraṇ dahā miniṭānnī yeīl.*
>
> The bus will come in roughly ten minutes.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**साधारण** (*sādhāraṇ*) is a tatsama, taken from Sanskrit *sādhāraṇa*, "common to all, general" (Monier-Williams).
