## You'll want to know: భయం
<!-- hl-knowledge: introduces=[TE-LEX-C85-FEEL-03]; assesses=[] -->

**భయం** (*bhayaṁ*) — "fear".

**నాకు భయంగా ఉంది** — "I am afraid". The frame that carried tiredness and cold now carries a
feeling, with nothing else changed.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

The first feeling, in a frame you can already build.
