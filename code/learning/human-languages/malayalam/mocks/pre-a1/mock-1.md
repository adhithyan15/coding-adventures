# Malayalam pre-A1 mock 1 — learner paper and examiner script

Use support-language directions only to explain the action. Never translate an
answer-bearing Malayalam stimulus. Total administration: 32 written minutes
plus 8 speaking minutes. Remove all visible models before writing begins.

## Reading — 10 minutes

Choose the English meaning or situation.

1. **പേര്** — A name / B tea / C bus
2. **വെള്ളം** — A school / B water / C home
3. **ചായ** — A tea / B no / C Malayalam
4. **വീട്** — A bus / B home / C thanks
5. **ബസ്** — A water / B name / C bus
6. **സ്കൂൾ** — A school / B tea / C yes
7. **നമസ്കാരം** — A greeting / B refusal / C request for water
8. **നന്ദി** — A thanks / B name question / C goodbye
9. **ദയവായി ഇരിക്കൂ.** — A Please sit. / B Please speak. / C Please leave.
10. **നാളെ കാണാം.** — A See you tomorrow. / B I am fine. / C What is your name?
11. **എന്റെ പേര് മീര ആണ്.** — A The name is Mira. / B The name is Tara. / C The city is Mira.
12. **ഞാൻ കൊച്ചിയിൽ താമസിക്കുന്നു.** — A I live in Kochi. / B I am leaving Kochi. / C I speak Kochi.
13. **എനിക്ക് സുഖമാണ്.** — A I am fine. / B I am Mira. / C I am at home.
14. Form field **പേര്: രവി** — A age Ravi / B name Ravi / C city Ravi

## Listening — 10 minutes

The examiner reads each numbered line twice. Pause eight seconds after each
play. The learner chooses A, B, or C from the printed choices.

1. Script: **പേര്**. A name / B water / C tea
2. Script: **വെള്ളം**. A tea / B home / C water
3. Script: **ചായ**. A tea / B bus / C school
4. Script: **വീട്**. A school / B home / C Malayalam
5. Script: **അതെ**. A yes / B no / C thanks
6. Script: **ഇല്ല**. A name / B yes / C no
7. Script: **നമസ്കാരം.** A നമസ്കാരം. / B വെള്ളം. / C ഇല്ല.
8. Script: **നന്ദി.** A എന്റെ പേര്. / B സാരമില്ല. / C ബസ്.
9. Script: **സുഖമാണോ?** A എനിക്ക് സുഖമാണ്. / B എന്റെ പേര് രവി ആണ്. / C വെള്ളം.
10. Script: **നാളെ കാണാം.** A നമസ്കാരം. / B നാളെ കാണാം. / C എന്റെ പേര്.
11. Script: **എന്റെ പേര് സീമ ആണ്.** A name Sima / B city Sima / C language Sima
12. Script: **ഞാൻ കൊച്ചിയിൽ താമസിക്കുന്നു.** A lives in Kochi / B going to Kochi / C named Kochi
13. Script: **ഞാൻ മലയാളം സംസാരിക്കുന്നു.** A speaks Malayalam / B reads a name / C wants tea
14. Script: **എനിക്ക് സുഖമാണ്.** A is fine / B is at school / C says no

## Writing — 12 minutes

1. Look at **നമസ്കാരം** for ten seconds. The examiner covers it. Write it once.
2. Look at **പേര്** for ten seconds. The examiner covers it. Write it once.
3. Dictation, twice: **ഞാൻ**.
4. Dictation, twice: **വീട്**.
5. Dictation, twice: **മലയാളം**.
6. Dictation, twice: **നന്ദി**.
7. Write your own name in Malayalam script after the nonverbal person cue. No answer model is shown.
8. Write one Malayalam greeting appropriate for meeting a person. No answer model is shown.

## Speaking — 8 minutes

1. Interlocutor: **നമസ്കാരം.** Learner returns a greeting.
2. Interlocutor: **നിന്റെ പേര് എന്താണ്?** Learner states a chosen identity.
3. Interlocutor: **സുഖമാണോ?**
4. Interlocutor: **നിങ്ങൾ എവിടെ താമസിക്കുന്നു?**
5. Interlocutor: **നിങ്ങൾ മലയാളം സംസാരിക്കുമോ?**
6. Situation: you want water. Make one short polite request in Malayalam.

The interlocutor may repeat each prompt once slowly. No written answer script,
romanization, dictionary, translator, or coaching is allowed.
