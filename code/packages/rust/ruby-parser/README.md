# coding-adventures-ruby-parser

A Ruby parser for the coding-adventures project. This crate parses Ruby source code into an Abstract Syntax Tree (AST) using the grammar-driven parser from the `parser` crate.

## How it works

The legacy API feeds the unversioned `ruby.grammar`, with tokens from the hand-written `ruby-lexer` crate, to the generic `GrammarParser`. The release API (below) uses a release's own `.tokens` and `.grammar` instead. The grammar file defines Ruby's syntactic structure in a declarative EBNF format.

## How it fits in the stack

```
ruby.tokens      (grammar file)
       |
       v
ruby-lexer       (tokenizes Ruby source → Vec<Token>)
       |
       v
ruby.grammar     (grammar file)
       |
       v
parser           (GrammarParser: builds AST from tokens + grammar)
       |
       v
ruby-parser      (THIS CRATE: wires everything together for Ruby)
```

## Usage

```rust
use coding_adventures_ruby_parser::{create_ruby_parser, parse_ruby};

// Quick parsing — returns a GrammarASTNode
let ast = parse_ruby("x = 1 + 2");
assert_eq!(ast.rule_name, "program");

// Or get the parser object for more control
let mut parser = create_ruby_parser("def add(a, b)\n  a + b\nend");
let ast = parser.parse().expect("parse failed");
```

`try_create_ruby_parser(source)` provides the same parser and recursion guard
while returning lexical errors to the caller. Native execution frontends use
this entry point for source they cannot assume is well formed.

## Grammar rules

The Ruby grammar covers:

- **program** — the top-level rule, a sequence of statements
- **statement** — assignments, expression statements, method definitions, class definitions, control flow
- **expression** — arithmetic, comparison, logical, method calls, member access
- **def_statement** — method definitions with parameters and body, terminated by `end`
- **class_statement** — class definitions with methods and body, terminated by `end`
- **if_statement** / **while_statement** — control flow with `end` terminators

## Release-selected parsing (LANG84)

LANG84 gives every tagged Ruby release its own grammar pair,
`code/grammars/ruby/ruby<release>.tokens` and `.grammar`. The release API runs
the generic `GrammarLexer` and `GrammarParser` over exactly one of them; no
hand-written lexer is involved:

```rust
use coding_adventures_ruby_parser::{parse_ruby_at, FrontendBudgets, RubyFrontendError};

let parsed = parse_ruby_at("puts(1 + 2)", Some("3.3.6"), &FrontendBudgets::default())?;
assert_eq!(parsed.release, "3.3.6");
assert_eq!(parsed.ast.rule_name, "program");

// No fallback: a release without a pair, an unknown ID, or "" is an error.
assert!(matches!(
    parse_ruby_at("puts 1", Some("2.7.8"), &FrontendBudgets::default()),
    Err(RubyFrontendError::ReleaseNotAvailable { .. })
));
```

- `None` selects `DEFAULT_RELEASE` (`3.3.6`); `Some("")` is an
  `UnknownRelease` error, as is a line shorthand like `"3.3"` (the error lists
  up to five inventory IDs sharing the longest prefix).
- `FrontendBudgets::default()` limits source to 64 KiB (checked before
  lexing; trusted callers may raise it to 16 MiB) and the parser to its
  measured depth cap of 180, which cannot be raised.
- Errors (`RubyFrontendError`) carry the release and a 1-based line and
  column: `Lex`, `Parse`, `Budget`, `UnknownRelease`, `ReleaseNotAvailable`.
- `tokenize_ruby_at` stops after lexing; `supported_releases()` lists the
  releases with a pair; `grammar_classes(release)` names the deduplicated
  table modules a release compiles to.

Today the pairs cover LANG84 slice R0 (numbers, names, variables, keywords,
operators, comments, separators) and the `rb-int-puts` grammar subset for
releases 0.49, 0.50 and 3.3.5–3.3.7. See `code/grammars/ruby/README.md`.

## Generated tables

`src/_grammar.rs` is generated — never edit it by hand. It holds one module
per distinct release grammar plus the unversioned `ruby.grammar` (used by the
legacy API). Regenerate it after changing any Ruby `.grammar` file or
`releases.csv`:

```sh
cd code/programs/rust/grammar-tools && cargo build --release
./target/release/grammar-tools generate-rust-compiled-grammars ruby
```

(The old `regen_grammars` binary, which only knew the unversioned grammar,
is gone.)

  both sides, and every documented R0 divergence.
