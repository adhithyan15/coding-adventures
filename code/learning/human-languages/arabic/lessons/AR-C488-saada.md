# سعادة (saʿāda) — happiness

## You'll want to know: سعادة
<!-- hl-knowledge: introduces=[AR-LEX-C488-MAZAJ488-01]; assesses=[] -->

**سعادة** — *saʿāda* — "happiness".

> شعرت بسعادة كبيرة في العيد.
>
> *shaʿartu bi-saʿāda kabīra fī al-ʿīd.*
>
> I felt great happiness at the feast.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**سعادة** (*saʿāda*) is built on the native Arabic root *s-a-d*, "to be lucky, to be happy" (Lane). Saʿāda is the state of being saʿīd, happy, a word you already know from the same root.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
