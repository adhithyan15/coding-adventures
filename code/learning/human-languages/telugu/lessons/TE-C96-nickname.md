# ముద్దుపేరు (muddupēru) — a nickname, a pet name

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TE-LEX-C95-ASK-05, TE-LEX-C96-NAMES-01] -->

[PAUSE 2s] Before the new one: say the Telugu for I could not hear it, then the Telugu for a surname.

## You'll want to know: ముద్దుపేరు
<!-- hl-knowledge: introduces=[TE-LEX-C96-NAMES-02]; assesses=[] -->

**ముద్దుపేరు** (*muddupēru*) — "a nickname, a pet name".

**ముద్దు** is "a kiss, affection", so a nickname is an *affection name*: the one family uses.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

The name the family uses.
