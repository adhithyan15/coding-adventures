## You'll want to know: राखीव
<!-- hl-knowledge: introduces=[MR-LEX-C551-YADI551-04]; assesses=[] -->

**राखीव** — *rākhīv* — "reserved; kept aside".

> ही खुर्ची वृद्धांसाठी राखीव आहे.
>
> *hī khurcī vṛddhāṁsāṭhī rākhīv āhe.*
>
> This chair is reserved for the elderly.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**राखीव** (*rākhīv*) is built on राखणे, "to keep", inherited from Sanskrit *rakṣati*, "guards" (CDIAL 10547).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
