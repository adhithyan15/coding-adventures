# An old word for driving

Retrieve the familiar driving action. The learner only
needs the familiar word, not a sentence, a new meaning, or an A1 mock.

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-C150-ACT150-05] -->

Hear **to drive**. [PAUSE 4s] Say **ਚਲਾਉਣਾ** (*calāuṇā*) before the model.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-C150-ACT150-05] -->

Hear **ਚਲਾਉਣਾ**. [PAUSE 4s] Recall **to drive**.
Then hear **to drive** again. [PAUSE 4s] Recall **ਚਲਾਉਣਾ**.
Only this old meaning and word are needed.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-C150-ACT150-05] -->

Hear **to drive** once more. [PAUSE 4s] Say **ਚਲਾਉਣਾ**.
If needed, listen to the model and try again once.
