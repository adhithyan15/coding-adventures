## You'll want to know: مخارج
<!-- hl-knowledge: introduces=[FA-LEX-C415-MAKHAREJ-01]; assesses=[] -->

**مخارج** (*makhârej*) — "expenses, costs".

> مخارج زندگی هر سال بیشتر میشود.
>
> *makhârej-e zendegi har sâl bishtar mishavad.*
>
> The cost of living goes up every year.

A plural built in the Arabic way beside *kharj* "expense".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**مخارج** is an Arabic-style plural that Persian uses beside *kharj* "expense"; it is usually traced to an Arabic plural from the same family.
