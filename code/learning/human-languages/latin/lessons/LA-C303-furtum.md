## You'll want to know: fūrtum, fūrtī
<!-- hl-knowledge: introduces=[LA-LEX-C303-FURTUM-01]; assesses=[] -->

**fūrtum, fūrtī** — "a theft".

> Fūrtum in balneō factum est.
>
> *A theft was committed at the baths.*

Neuter, built on *fūr*, 'thief', which is taught. The ablative *fūrtō* means 'by stealth'.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**fūrtum** is built on *fūr*, "thief" (EtymDB), which is inherited from Proto-Italic *\*fōr*.
