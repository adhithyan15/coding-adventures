## You'll want to know: सामना
<!-- hl-knowledge: introduces=[MR-LEX-C529-SAMNA529-01]; assesses=[] -->

**सामना** — *sāmnā* — "a match; a contest".

> काल क्रिकेटचा सामना खूप रंगला.
>
> *kāl krikeṭcā sāmnā khūp raṅglā.*
>
> Yesterday's cricket match was very exciting.

Masculine.

The oblique is सामन्या-: सामन्यात.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**सामना** (*sāmnā*) is usually linked with Hindi *sāmnā*, "a facing, a confrontation". CDIAL sets the words for facing and in front under Sanskrit *saṁmukha*, "facing" (CDIAL 12982), but lists no सामना, so the path is not settled.
