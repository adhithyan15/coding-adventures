## You'll want to know: разминка
<!-- hl-knowledge: introduces=[RU-LEX-C513-TRAINING-01]; assesses=[] -->

**разминка** (*razmínka*) — "a warm-up".

> Перед бегом обязательно нужна разминка.
>
> *Péred bégom obyazátelno nuzhná razmínka.*
>
> A warm-up is essential before a run.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*разминка* is built on *размять* 'to loosen, to knead', from *мять* 'to crumple'; EtymDB has no entry.
