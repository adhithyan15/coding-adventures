# ઝરવું (jharvũ) — to ooze; to trickle

## You'll want to know: ઝરવું
<!-- hl-knowledge: introduces=[GU-LEX-C481-KAPAVU481-04]; assesses=[] -->

**ઝરવું** — *jharvũ* — "to ooze; to trickle".

> ઘામાંથી હજી લોહી ઝરે છે.
>
> *ghāmā̃thī hajī lohī jhare che.*
>
> Blood is still oozing from the wound.

Past (it …): તે લોહી ધીમે ઝર્યું, *te lohī dhīme jharyũ*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ઝરવું** (*jharvũ*) goes back to a reconstructed *\*jharati*; CDIAL lists the Gujarati verb, "to ooze, drip, shed, melt" (CDIAL 5346).
