# પશ્ચિમ (paścim) — the west

## You'll want to know: પશ્ચિમ
<!-- hl-knowledge: introduces=[GU-LEX-C414-EAST414-02]; assesses=[] -->

**પશ્ચિમ** — *paścim* — "the west".

> સૂરજ પશ્ચિમમાં આથમે છે.
>
> *sūraj paścimmā̃ āthme che.*
>
> The sun sets in the west.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**પશ્ચિમ** (*paścim*) is a tatsama, Sanskrit *paścima*, "behind, last", and so "western" (Monier-Williams): facing the sunrise, the west is behind you.
