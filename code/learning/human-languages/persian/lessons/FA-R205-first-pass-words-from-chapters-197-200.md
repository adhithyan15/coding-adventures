An idea? (**ایده**, *ide*.) A difference? (**فرق**, *farq*.) An example? (**نمونه**, *nemune*.) Success? (**موفقیت**, *movaffaqiyat*.) Polluted? (**آلوده**, *âlude*.) Greasy? (**چرب**, *charb*.)
