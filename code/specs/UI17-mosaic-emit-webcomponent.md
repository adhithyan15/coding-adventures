# UI17 — mosaic-emit-webcomponent: Web Component Backend

**Status:** Implemented  
**Layer:** UI  
**Depends on:** UI01 (mosaic-vm), UI00 (mosaic-analyzer)

---

## 1. Purpose

`mosaic-emit-webcomponent` is the Web Components backend for the Mosaic compiler.
It implements the `MosaicRenderer` trait (from `mosaic-vm`) and is driven by
`MosaicVM`. The output is a JavaScript file containing a single Custom Element
class that can be registered with `customElements.define`.

The Custom Element is **self-contained**: no client-side runtime, no React, no
framework. The Shadow DOM template is rebuilt by a `_render()` method that writes
a JavaScript template literal string directly to `shadowRoot.innerHTML`. Conditional
(`when`) and iterative (`each`) blocks become JavaScript ternary expressions and
`.map()` calls *inside* that template literal — not HTML `<template>` tags.

```text
.mosaic source
     │
     ▼
mosaic-analyzer  →  MosaicFile (IR)
     │
     ▼
MosaicVM  (drives MosaicRenderer callbacks)
     │
     ▼
WebComponentRenderer  →  MyComponent.js
```

## 2. Output Structure

```javascript
// Auto-generated by mosaic-emit-webcomponent. Do not edit.

class ProfileCard extends HTMLElement {
  // Only primitive scalar slots (text, number, bool, image, color) become
  // observed attributes. List and node slots use JS setters instead.
  static get observedAttributes() { return ['avatar-url', 'display-name']; }

  constructor() {
    super();
    this.attachShadow({ mode: 'open' });
    // Backing fields for every slot — initial values match the slot's type.
    this._avatarUrl = '';      // text / image slot
    this._displayName = '';   // text slot
    this._items = [];          // list<T> slot — array, not attribute
  }

  connectedCallback() { this._render(); }

  // attributeChangedCallback updates the camelCase backing field and re-renders.
  attributeChangedCallback(name, _oldVal, newVal) {
    this[`_${this._toCamel(name)}`] = newVal ?? '';
    this._render();
  }

  // Setter for list and node slots (not in observedAttributes).
  set items(val) { this._items = val ?? []; this._render(); }

  _render() {
    this.shadowRoot.innerHTML = `
      <div style="display:flex;flex-direction:column">
        <span>${this._displayName}</span>
      </div>
    `;
  }

  // HTML-escape a value before embedding it in the template string.
  _escape(s) {
    return String(s)
      .replace(/&/g, '&amp;')
      .replace(/</g, '&lt;')
      .replace(/>/g, '&gt;')
      .replace(/"/g, '&quot;');
  }
}
customElements.define('profile-card', ProfileCard);
```

## 3. Architecture

### 3.1 `WebComponentRenderer` struct

```rust
pub struct WebComponentRenderer {
    component_name: String,
    slots: Vec<MosaicSlot>,
    /// Stack of open element frames while the VM traverses nodes depth-first.
    stack: Vec<HtmlFrame>,
    /// HTML fragments accumulated at the root level (outside any open frame).
    root_lines: Vec<String>,
}
```

Each `HtmlFrame` records the close tag and any child HTML accumulated so far:

```rust
struct HtmlFrame {
    close_tag: String,
    inner: Vec<String>,
}
```

When a node opens (`begin_node`), a new `HtmlFrame` is pushed. When it closes
(`end_node`), the frame is popped; its inner content + close tag are flushed into
the parent frame (or `root_lines` if the stack is empty).

### 3.2 Slot backing-field helpers

```rust
/// Convert a kebab-case slot name to camelCase for backing field names.
/// Examples: "avatar-url" → "avatarUrl", "display-name" → "displayName".
fn to_camel_case(kebab: &str) -> String { … }
```

## 4. Primitive → HTML Element Mapping

| Mosaic element | HTML tag / output                                                 |
|----------------|-------------------------------------------------------------------|
| `Box`          | `<div>` (with inline style from props)                            |
| `Column`       | `<div style="display:flex;flex-direction:column">`                |
| `Row`          | `<div style="display:flex;flex-direction:row">`                   |
| `Text`         | `<span>` (with `content` prop as text body)                       |
| `Image`        | `<img src="…" alt="…">` (self-closing, no close tag)             |
| `Spacer`       | `<div style="flex:1">`                                            |
| `Scroll`       | `<div style="overflow:auto">`                                     |
| `Divider`      | `<hr>` (self-closing, no close tag)                               |
| `Stack`        | `<div style="position:relative">`                                 |
| `Icon`         | `<span class="icon">`                                             |
| `Grid`         | `<table>` with slot-driven `<thead>` and `<tbody>` (see §5)      |
| any other      | Custom element tag derived from PascalCase → kebab-case           |

### 4.1 Style and class attributes

- Non-semantic properties (padding, background, etc.) become inline `style="…"`.
- `style: namespace.member` enum values become `class="mosaic-namespace-member"`.
- Accessibility props (`a11y-label`, `a11y-role`, `a11y-hidden`) become
  `aria-label`, `role`, `aria-hidden` attributes.

## 5. Grid Slot Protocol

`Grid` is a special primitive: its visual content comes entirely from list slots,
not from nested child nodes. The `Grid` node is expected to have two props:

| Prop name            | Meaning                                    |
|----------------------|--------------------------------------------|
| `headers` (or `column-headers`) | A `SlotRef` pointing to a `list<text>` slot containing column header labels |
| `rows` (or `viewport-rows`)     | A `SlotRef` pointing to a `list<text>` slot containing row data |

The emitted HTML for Grid uses template literal expressions inside `_render()`:

```html
<table>
  <thead>
    <tr>${this._headers.map(h => `<th>${this._escape(h)}</th>`).join('')}</tr>
  </thead>
  <tbody>
    ${this._rows.map(r => `<tr><td>${this._escape(r)}</td></tr>`).join('')}
  </tbody>
</table>
```

Because the table is self-contained (no child nodes visit its interior), `Grid`
returns an empty close tag from `primitive_open` — the full element is emitted
as the open string.

## 6. `observedAttributes` — Scalar Primitives Only

Only slots whose type is `MosaicType::Primitive(_)` (i.e., `text`, `number`,
`bool`, `image`, `color`) appear in `observedAttributes`. The Custom Element
receives their values via HTML attributes and reflects them in `attributeChangedCallback`.

`MosaicType::List(_)` and `MosaicType::Component(_)` slots are **not** observed
attributes — they are far too rich for an attribute string. Instead, the host
sets them via JavaScript property setters:

```javascript
set items(val) { this._items = val ?? []; this._render(); }
```

This distinction is critical: including list slots in `observedAttributes` would
cause the browser to stringify them and break `_render()`.

---

## 7. `when` Blocks — JavaScript Ternaries

`when @show { ... }` must emit a JavaScript ternary inside the template literal,
**not** an HTML `<template data-when>` tag. The `<template>` approach requires a
client runtime to interpret — the self-contained target has no such runtime.

The `_render()` template literal body for:

```
when @show {
  Text { content: "Hello"; }
}
```

becomes:

```javascript
`${this._show ? `<span>Hello</span>` : ''}`
```

Implementation: the renderer accumulates **fragments** rather than raw strings.
`WhenOpen(slot)` and `WhenClose` fragments bracket the children; during `emit()`
serialization, the fragment list is flattened into the final string.

---

## 8. `each` Blocks — JavaScript `.map()` Calls

`each @items as item { ... }` emits a `.map()` call inside the template literal:

```javascript
`${this._items.map(item => `<li>${item}</li>`).join('')}`
```

`EachOpen(slot, item_name)` and `EachClose` fragments bracket the children;
child slot refs that use the loop variable `item` resolve to bare `${item}` (no
`this._` prefix) because they are loop variables, not component slots.

---

## 9. `_escape(s)` Security Method

Every emitted Custom Element includes an `_escape(s)` method:

```javascript
_escape(s) {
    return String(s)
        .replace(/&/g, '&amp;')
        .replace(/</g, '&lt;')
        .replace(/>/g, '&gt;')
        .replace(/"/g, '&quot;');
}
```

This method is called whenever a slot value is interpolated into a context where
HTML characters could be interpreted — principally Grid cell/header values.
Simple `text` slots assigned to `content:` properties are interpolated as
`${this._title}` (without `_escape`) because the browser's template literal
assignment to `innerHTML` does not parse child text as HTML entities; however,
attribute values and table cell contents do need escaping.

---

## 10. Constructor: Backing Fields

The constructor initializes a backing field for every slot so that `_render()`
always has a valid value even before any attribute or setter is called:

| Slot type                    | Initial value | Storage     |
|------------------------------|---------------|-------------|
| `text`, `image`, `color`     | `''`          | attribute   |
| `number`                     | `0`           | attribute   |
| `bool`                       | `false`       | attribute   |
| `list<T>`                    | `[]`          | JS setter   |
| `node`, component type       | `null`        | JS setter   |

---

## 11. PascalCase → kebab-case Conversion

Component names are converted for both the custom element tag and backing field names:

```
ProfileCard  →  profile-card     (element tag)
avatarUrl    →  avatar-url       (attribute name, inverse direction)
avatar-url   →  _avatarUrl       (backing field name)
```

## 12. Testing Strategy

Each test uses `analyze(src)` + `MosaicVM::new(file)` + `vm.run(WebComponentRenderer::new())`.

| Test | What it covers |
|------|----------------|
| `test_class_declaration` | Output contains `class X extends HTMLElement` |
| `test_custom_elements_define` | kebab-case tag in `customElements.define` |
| `test_observed_attributes` | Scalar slot appears in `observedAttributes` |
| `test_shadow_dom` | `attachShadow` present |
| `test_render_method` | `_render()` and `shadowRoot.innerHTML` present |
| `test_column_style` | Column → flex-direction:column |
| `test_row_style` | Row → flex-direction:row |
| `test_slot_child_element` | Node slot renders `<slot name="…">` |
| `test_when_ternary` | `when` block emits JS ternary, not `<template>` |
| `test_each_map` | `each` block emits `.map()`, not `<template>` |
| `test_grid_table` | Grid emits `<table>` with `.map()` header/row expressions |
| `test_observed_excludes_list` | List slot absent from `observedAttributes` |
| `test_backing_fields` | Constructor initializes backing fields for all slots |
| `test_escape_method` | `_escape` is present in emitted class body |
| `test_list_setter` | List slot has JS setter `set items(val)` |
