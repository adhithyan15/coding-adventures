# Sanskrit pre-A1 mock 1 — learner paper

Give this paper to the learner. Keep
[`mock-1-examiner-script.md`](mock-1-examiner-script.md) separate. Total
administration is 32 written minutes plus 8 speaking minutes. Pre-A1 Sanskrit
remains unjoined at word boundaries; correct external sandhi is accepted but
never required.

## Reading — 10 minutes

Choose the English meaning or situation.

1. **नाम** — A name / B water / C book
2. **जलम्** — A school / B water / C home
3. **पुस्तकम्** — A book / B greeting / C name
4. **गृहम्** — A water / B home / C school
5. **विद्यालयः** — A teacher / B book / C school
6. **नमः** — A greeting / B refusal / C place
7. **नमस्ते।** — A greeting / B request for water / C goodbye
8. **धन्यवादः।** — A thanks / B a name / C a question
9. **कृपया उपविशतु।** — A Please sit. / B Please speak. / C Please leave.
10. **पुनः मिलामः।** — A We meet again. / B I am well. / C What is your name?
11. **मम नाम मीरा अस्ति।** — A The name is Mira. / B The city is Mira. / C Mira wants water.
12. **अहं दिल्ली-नगरात् आगच्छामि।** — A I come from Delhi. / B I am going to Delhi. / C My name is Delhi.
13. **अहं कुशली अस्मि।** — A I am well. / B I am Mira. / C I am at home.
14. Form field **नगरम्: काशी** — A name Kashi / B city Kashi / C school Kashi

## Listening — 10 minutes

Listen to each numbered recording twice. Choose A, B, or C. The recording is
not printed here.

### Part 1 — sounds and words

1. A name / B water / C book
2. A book / B home / C water
3. A book / B school / C greeting
4. A water / B home / C name
5. A school / B teacher / C city
6. A name / B greeting / C water

### Part 2 — greeting responses

7. A return the greeting / B request water / C state a place
8. A say “you are welcome” / B state a name / C ask for a book
9. A state a name / B state how you are / C request water
10. A return the farewell / B introduce yourself / C ask a question

### Part 3 — personal details

11. A name Sima / B city Sima / C school Sima
12. A from Agra / B going to Agra / C named Agra
13. A speaks Sanskrit / B reads a name / C wants water
14. A is well / B is at school / C says no

## Speaking — 8 minutes

The interlocutor gives six prompts. Answer each in Sanskrit. The interlocutor
may repeat each prompt once slowly. No written answer script, romanization,
dictionary, translator, or coaching is allowed.
