## You'll want to know: मदद
<!-- hl-knowledge: introduces=[MW-LEX-C266-HAJAR266-02]; assesses=[] -->

**मदद** — *madad* — "help".

> आप म्हारी मदद करो सा।
>
> *āp mhārī madad karo sā.*
>
> Please help me.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**मदद** (*madad*) is usually traced to Persian *madad*, "help". It is feminine: **म्हारी मदद**, my help.
