## You'll want to know: مناسب
<!-- hl-knowledge: introduces=[UR-LEX-C339-IKHTIYAR339-03]; assesses=[] -->

**مناسب** — *munāsib* — "suitable; proper".

> یہ وقت بات کے لیے مناسب نہیں ہے۔
>
> *yih vaqt bāt ke liye munāsib nahīṅ hai.*
>
> This is not a suitable time to talk.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**مناسب** (*munāsib*) is usually traced, through Persian, to Arabic *munāsib*, "fitting, suitable".

<!-- hl-knowledge: introduces=[]; assesses=[] -->
