## You'll want to know: محمية
<!-- hl-knowledge: introduces=[AR-LEX-C467-MAHMIYYA467-01]; assesses=[] -->

**محمية** — *maḥmiyya* — "a nature reserve".

> زرنا محمية للطيور على الساحل.
>
> *zurnā maḥmiyya li-ṭ-ṭuyūr ʿalā as-sāḥil.*
>
> We visited a bird reserve on the coast.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**محمية** (*maḥmiyya*) is built on the native Arabic root *ḥ-m-y*, "to protect, to defend" (Lane). It is a passive participle: a protected place.
