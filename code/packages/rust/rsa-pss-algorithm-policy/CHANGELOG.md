# Changelog

All notable changes to this package will be documented in this file.

## [0.1.0] - 2026-10-29

### Added

- Explicit SHA-256, SHA-384, and SHA-512 PSS digest identifiers.
- Caller-owned exact message-hash, MGF1-hash, and salt profile allowlists.
- Trailer-field and salt-work policy validation with non-copyable evidence.
- Independent boundary coverage, standalone build fronts, and a schema-v1
  zero-capability declaration.
