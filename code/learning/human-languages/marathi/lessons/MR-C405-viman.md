## You'll want to know: विमान
<!-- hl-knowledge: introduces=[MR-LEX-C405-VIMAN405-01]; assesses=[] -->

**विमान** — *vimān* — "an aeroplane".

> आमचं विमान वेळेवर उतरलं.
>
> *āmcaṁ vimān veḷevar utarlaṁ.*
>
> Our plane landed on time.

Neuter.

विमानाने, by plane; विमानतळ, the airport, is built on it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**विमान** (*vimān*) is a tatsama, taken from Sanskrit *vimāna*, which names the flying chariot of the old stories (Monier-Williams).
