# ரொம்ப நாளாச்சு (rompa nāḷāccu) — it's been a long time

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TA-LEX-C107-LEAVE-05, TA-LEX-C108-GREET-01] -->

[PAUSE 2s] Before the new one: say the Tamil for come again, then the Tamil for have you eaten.

## You'll want to know: ரொம்ப நாளாச்சு
<!-- hl-knowledge: introduces=[TA-LEX-C108-GREET-02]; assesses=[] -->

**ரொம்ப நாளாச்சு** (*rompa nāḷāccu*) — "it's been a long time", in everyday speech.

**ரொம்ப** is spoken "very"; **நாள்** is "day".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

A greeting for someone you have not seen.
