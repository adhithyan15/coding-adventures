# ಮೆಕ್ಯಾನಿಕ್ (mekyānik) — a mechanic

## You'll want to know: ಮೆಕ್ಯಾನಿಕ್
<!-- hl-knowledge: introduces=[KA-LEX-C450-GARAGE450-01]; assesses=[] -->

**ಮೆಕ್ಯಾನಿಕ್** — *mekyānik* — "a mechanic".

> ಮೆಕ್ಯಾನಿಕ್ ಬ್ರೇಕನ್ನು ಸರಿಪಡಿಸಿದನು.
>
> *mekyānik brēkannu saripaḍisidanu.*
>
> The mechanic fixed the brake.

The plural takes -ಗಳು: ಮೆಕ್ಯಾನಿಕ್ಗಳು.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಮೆಕ್ಯಾನಿಕ್** (*mekyānik*) is a loan from English *mechanic*.
