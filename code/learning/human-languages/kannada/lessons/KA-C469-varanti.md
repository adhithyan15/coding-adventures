# ವಾರಂಟಿ (vāraṇṭi) — a warranty

## You'll want to know: ವಾರಂಟಿ
<!-- hl-knowledge: introduces=[KA-LEX-C469-VARANTI469-03]; assesses=[] -->

**ವಾರಂಟಿ** — *vāraṇṭi* — "a warranty".

> ಹೊಸ ಫೋನಿಗೆ ಒಂದು ವರ್ಷದ ವಾರಂಟಿ ಇದೆ.
>
> *hosa phōnige ondu varṣada vāraṇṭi ide.*
>
> The new phone has a one-year warranty.

Shops say ವಾರಂಟಿ for goods; ಖಾತರಿ is the wider word.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ವಾರಂಟಿ** (*vāraṇṭi*) is a loan from English *warranty*.
