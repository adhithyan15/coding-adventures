## You'll want to know: korrigieren
<!-- hl-knowledge: introduces=[GE-LEX-C379-BEWERTUNG-05]; assesses=[] -->

**korrigieren** — "to correct".

> Die Lehrerin korrigiert jeden Abend Hefte.
>
> *The teacher corrects exercise books every evening.*

Perfekt: *hat korrigiert*. *Sich korrigieren* — to correct yourself.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*korrigieren* is a learned borrowing from Latin *corrigere* "to make straight, to set right" (Lewis & Short), built from *con-* and *regere* "to guide, to rule".
