## You'll want to know: قيم
<!-- hl-knowledge: introduces=[AR-LEX-C393-TAQYIM393-05]; assesses=[] -->

**قيم** — *qayyama* — "to evaluate".

> قيم المعلم عمل كل طالب.
>
> *qayyama al-muʿallim ʿamal kulli ṭālib.*
>
> The teacher evaluated each student's work.

Present: يقيم, *yuqayyim*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**قيم** (*qayyama*) is built on the native Arabic root *q-w-m*, "to stand, to rise" (Lane). It is Form II, to set a value on a thing: to evaluate. قيمة, a value, is from the same root.

One more word for giving reasons and opinions.
