## You'll want to know: ગોતવું
<!-- hl-knowledge: introduces=[GU-LEX-C415-LANDMARK415-05]; assesses=[] -->

**ગોતવું** — *gotvũ* — "to hunt for; to search (everyday)".

> અમે અડધો કલાક સરનામું ગોત્યું.
>
> *ame aḍdho kalāk sarnāmũ gotyũ.*
>
> We hunted for the address for half an hour.

Past, with તેણે (he or she …): તેણે ઘર ગોત્યું, *teṇe ghar gotyũ*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ગોતવું** (*gotvũ*) No dictionary we use records an older form, so its history is not settled.
