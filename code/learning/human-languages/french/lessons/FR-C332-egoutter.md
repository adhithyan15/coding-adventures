## You'll want to know: égoutter
<!-- hl-knowledge: introduces=[FR-LEX-C332-ASSAISONNER-02]; assesses=[] -->

**égoutter** — "to drain".

> Elle égoutte les pâtes.
>
> *She drains the pasta.*

*Laisser égoutter* — to leave to drain.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*égoutter* is built on *goutte* "a drop", which is inherited from Latin *gutta* "a drop" (Lewis & Short).
