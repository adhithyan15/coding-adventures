# Three old form labels in their old order

Stop before marking the page. This is a short return to an old fictional
form, not a request for personal information or a scored A1 mock.

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-AGE-PHONE-DATE-ORDER-01] -->

The familiar model stays visible. The first line is **ਉਮਰ:** (age), the
second **ਫ਼ੋਨ:** (phone), and the third **ਤਾਰੀਖ਼:** (date). Point down the
three lines once. There is no new label or value here.

> ਉਮਰ: ______
>
> ਫ਼ੋਨ: ______
>
> ਤਾਰੀਖ਼: ______

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-AGE-PHONE-DATE-ORDER-01] -->
<!-- hl-writing-stage: guided-copy -->

Keep the model visible. Copy only those three labels onto three empty lines,
in the same order. Leave every value blank. Check the first label before
copying the second, then check the second before copying the third. If one
line is misplaced, move that label only; do not invent a value.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-AGE-PHONE-DATE-ORDER-01] -->

Cover the model for five seconds. Point to where age, phone, and date belong
on three empty lines; then uncover and compare. The visible model remains
available for another gentle try. This is not independent timed writing.
