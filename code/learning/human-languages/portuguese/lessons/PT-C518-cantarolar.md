## You'll want to know: cantarolar
<!-- hl-knowledge: introduces=[PT-LEX-C518-CORO-04]; assesses=[] -->

**cantarolar** — "to hum, to sing softly".

> A minha mãe cantarola enquanto cozinha.
>
> *My mother hums while she cooks.*

Built on *cantar*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*cantarolar* is built on *cantar* "to sing" (EtymDB), which is inherited from Latin *cantāre* "to sing".
