# நாள் குறி (nāḷ kuṟi) — to fix a date

## You'll want to know: நாள் குறி
<!-- hl-knowledge: introduces=[TA-LEX-C547-KAIKOODU547-05]; assesses=[] -->

**நாள் குறி** — *nāḷ kuṟi* — "to fix a date".

> இரு குடும்பங்களும் திருமணத்துக்கு நாள் குறித்தார்கள்.
>
> *iru kuṭumpaṅkaḷum tirumaṇattukku nāḷ kuṟittārkaḷ.*
>
> The two families fixed a date for the wedding.

Past (I …): நாள் குறித்தேன், *nāḷ kuṟittēṉ*.

The event takes -க்கு: திருமணத்துக்கு நாள் குறி.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**நாள் குறி** (*nāḷ kuṟi*) joins the native நாள் (*nāḷ*), "a day" (DEDR 3656), and குறி (*kuṟi*), "to mark, to fix" (DEDR 1847).
