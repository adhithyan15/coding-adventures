## You'll want to know: مخمصہ
<!-- hl-knowledge: introduces=[UR-LEX-C529-JHAMELA529-02]; assesses=[] -->

**مخمصہ** — *makhmasā* — "a quandary; a fix".

> اگر دونوں دوست کل آئے تو مخمصہ ہو گا۔
>
> *agar donoṅ dost kal āe to makhmasā ho gā.*
>
> If both friends come tomorrow, I'll be in a fix.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**مخمصہ** (*makhmasā*) is usually traced, through Persian, to Arabic *makhmaṣa*, "hunger, a hard plight"; the sense "a quandary" came later, and the sources we use do not show how it arose.
