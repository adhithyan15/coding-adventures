## You'll want to know: le buisson
<!-- hl-knowledge: introduces=[FR-LEX-C457-BOIS-02]; assesses=[] -->

**le buisson** — "the bush".

> Un lapin se cache dans le buisson.
>
> *A rabbit is hiding in the bush.*

*Tourner autour du pot* means to beat about the bush.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*buisson* is built on *bois* 'wood', which is usually traced to a Germanic word for 'bush' (EtymDB lists Germanic cousins).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling, explaining and describing at B1.
