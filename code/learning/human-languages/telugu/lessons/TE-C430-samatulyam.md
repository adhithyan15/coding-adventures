# సమతుల్యం (samatulyaṁ) — balance; equilibrium

## Warm-up

## You'll want to know: సమతుల్యం
<!-- hl-knowledge: introduces=[TE-LEX-C430-SAMATULYAM430-03]; assesses=[] -->

**సమతుల్యం** — *samatulyaṁ* — "balance; equilibrium".

> పనికి, కుటుంబానికి మధ్య సమతుల్యం ఉండాలి.
>
> *paniki, kuṭumbāniki madhya samatulyaṁ uṇḍāli.*
>
> There should be a balance between work and family.

సమతుల్య ఆహారం, a balanced diet.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**సమతుల్యం** (*samatulyaṁ*) is built from Sanskrit *sama*, "same, even", and *tulya*, "equal to, like" (CDIAL 5888).
