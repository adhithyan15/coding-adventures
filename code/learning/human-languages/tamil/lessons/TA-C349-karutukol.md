# கருதுகோள் (karutukōḷ) — a hypothesis

## You'll want to know: கருதுகோள்
<!-- hl-knowledge: introduces=[TA-LEX-C349-CINTI349-04]; assesses=[] -->

**கருதுகோள்** — *karutukōḷ* — "a hypothesis".

> விஞ்ஞானி ஒரு புதிய கருதுகோளை முன்வைத்தார்.
>
> *viññāṉi oru putiya karutukōḷai muṉvaittār.*
>
> The scientist put forward a new hypothesis.

கருதுகோள் முன்வை, to put forward a hypothesis.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**கருதுகோள்** (*karutukōḷ*) is a modern Tamil coinage built from native *karutu*, "to intend, suppose, consider" (DEDR 1283), and *kōḷ*, "taking, opinion, tenet", the noun of கொள்: "what is supposed".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
