## You'll want to know: جبيرة
<!-- hl-knowledge: introduces=[AR-LEX-C511-JURA511-04]; assesses=[] -->

**جبيرة** — *jabīra* — "a splint, a plaster cast".

> وضع الطبيب ذراعي في جبيرة.
>
> *waḍaʿa aṭ-ṭabīb dhirāʿī fī jabīra.*
>
> The doctor put my arm in a cast.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**جبيرة** (*jabīra*) is built on the native Arabic root *j-b-r*, "to set a broken bone" (Lane). A jabīra holds the set bone in place.
