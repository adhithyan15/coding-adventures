## You'll want to know: لائن
<!-- hl-knowledge: introduces=[UR-LEX-C386-DABBA386-03]; assesses=[] -->

**لائن** — *lāin* — "a railway line; a line".

> یہ لائن لاہور تک جاتی ہے۔
>
> *yih lāin lāhaur tak jātī hai.*
>
> This line runs as far as Lahore.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**لائن** (*lāin*) is borrowed from English *line*; Urdu uses it for a railway line and for a telephone line.
