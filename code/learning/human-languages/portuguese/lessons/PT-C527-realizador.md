## You'll want to know: o realizador
<!-- hl-knowledge: introduces=[PT-LEX-C527-FILMAR-01]; assesses=[] -->

**o realizador** — "(film) director".

> O realizador ganhou um prémio pelo filme.
>
> *The director won a prize for the film.*

In Brazil: *o diretor*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*realizador* is built on *realizar* "to carry out, to make", which is usually traced to *real* "real" and so to Latin *rēs* "a thing".
