## You'll want to know: fatiar
<!-- hl-knowledge: introduces=[PT-LEX-C450-MERCEARIA-05]; assesses=[] -->

**fatiar** — "to slice".

> O senhor fatia o fiambre muito fino.
>
> *The man slices the ham very thin.*

Built on *a fatia*, the slice.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*fatiar* is built on *fatia* 'slice', which EtymDB traces to Arabic *futāt* 'crumbs, pieces'.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling, explaining and describing at B1.
