# Unit 25: Negation

## Warm-up

[PAUSE 2s] Say *tengo hambre*. Now flip it: *no tengo hambre* — today's
whole unit in one word.

## New Material

**no** — no / not ← Latin *non*. Placed directly before the verb: *no
tengo, no soy, no hay*.

**nunca** — never ← Latin *numquam*.
**nada** — nothing ← Latin *(res) nata*, "(a thing) born" — worn down
over centuries into "not a single thing," an odd but real semantic drift.
**nadie** — nobody ← Latin *nati* ("born ones," same root as *nada*).

## Grammar Lens

Spanish allows — actually **requires** — **double negatives**, which
English grammar rules explicitly forbid: *"No tengo nada"* (literally "I
don't have nothing") is the *correct*, mandatory way to say "I don't have
anything." Dropping the *no* (*"Tengo nada"*) doesn't fix it — it
actually breaks the sentence in the other direction, since *nada* alone
before the verb already negates it. This is one of the most-corrected
"mistakes" English speakers make in Spanish, precisely because it's
correct in Spanish and wrong in English — worth stating as its own rule
rather than something to unlearn quietly.
