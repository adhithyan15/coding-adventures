## You'll want to know: غياب
<!-- hl-knowledge: introduces=[AR-LEX-C422-MAWDUI422-04]; assesses=[] -->

**غياب** — *ghiyāb* — "absence".

> لاحظ المعلم غياب الطالب.
>
> *lāḥaẓa al-muʿallim ghiyāb aṭ-ṭālib.*
>
> The teacher noticed the student's absence.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**غياب** (*ghiyāb*) is built on the native Arabic root *gh-y-b*, "to be absent, hidden" (Lane). *Ghiyāb* is a verbal noun: being away, absence.
