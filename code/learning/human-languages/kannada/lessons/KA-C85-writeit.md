# ಬರೆದು ಕೊಡಿ (baredu koḍi) — please write it down

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C85-SLOWLY-03, KA-LEX-C85-SLOWLY-04] -->

[PAUSE 2s] Before the new one: say the Kannada for loudly, then the Kannada for meaning.

## You'll want to know: ಬರೆದು ಕೊಡಿ
<!-- hl-knowledge: introduces=[KA-LEX-C85-SLOWLY-05]; assesses=[] -->

**ಬರೆದು ಕೊಡಿ** (*baredu koḍi*) — "please write it down (for me)", literally
"having written, give". Both verbs are ones you know: **ಬರೆ**, "write", and
**ಕೊಡು**, "give".

When a word will not stay in the ear, ask for it on paper.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

Two known verbs make one request.
