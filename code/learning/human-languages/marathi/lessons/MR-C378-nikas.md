## You'll want to know: निकष
<!-- hl-knowledge: introduces=[MR-LEX-C378-ATI378-04]; assesses=[] -->

**निकष** — *nikaṣ* — "a criterion; a yardstick".

> शिष्यवृत्तीचे निकष या वर्षी बदलले.
>
> *śiṣyavṛttīce nikaṣ yā varṣī badalle.*
>
> The criteria for the scholarship changed this year.

Masculine.

Plural निकष; X चा निकष, the test for X.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**निकष** (*nikaṣ*) is a tatsama, taken from Sanskrit *nikaṣa*, "roller; touchstone" (CDIAL 7139): the stone gold is tested on.
