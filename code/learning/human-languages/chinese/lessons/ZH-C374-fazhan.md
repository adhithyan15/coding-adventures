## You'll want to know: fāzhǎn
<!-- hl-knowledge: introduces=[ZH-LEX-C374-SOCIETY374-05]; assesses=[] -->

*fāzhǎn* — "to develop; to expand".

> *zhège chéngshì fāzhǎn de hěn kuài suǒyǐ fángzi hěn guì* — This city is growing fast, so houses are expensive.

Its characters come later; for now it is a word for the ear.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*fāzhǎn* is built from *fā* 'to set going' and *zhǎn* 'to open out', both inherited from Middle Chinese, *pjot* and *trjenX* (Guangyun, in Baxter's transcription), which glosses each with the same word, 'to unfold'.
