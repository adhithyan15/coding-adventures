# ضمن (ḍamina) — to ensure; to guarantee

## You'll want to know: ضمن
<!-- hl-knowledge: introduces=[AR-LEX-C404-SHART404-05]; assesses=[] -->

**ضمن** — *ḍamina* — "to ensure; to guarantee".

> ضمن الأب مستقبل ابنه.
>
> *ḍamina al-ab mustaqbal ibnih.*
>
> The father secured his son's future.

Present: يضمن, *yaḍman*.

Followed by أن: ضمن أن …, made sure that ….

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ضمن** (*ḍamina*) is built on the native Arabic root *ḍ-m-n*, "to be surety for" (Lane). *Ḍamina* is a Form I verb, to stand surety: to guarantee, to ensure.
