## You'll want to know: возражение
<!-- hl-knowledge: introduces=[RU-LEX-C340-SOGLASIYE-05]; assesses=[] -->

**возражение** (*vozrazhéniye*) — "an objection".

> Возражения есть? Нет? Тогда решили.
>
> *Vozrazhéniya yest? Net? Togdá reshíli.*
>
> Any objections? No? Then it is decided.

Neuter. *Без возражений* — without objection.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**возражение** is built on *возразить* "to object" with the noun suffix *-ение*; the root is that of *разить* "to strike" (EtymDB).
