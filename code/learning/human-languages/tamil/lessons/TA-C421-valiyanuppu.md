# வழியனுப்பு (vaḻiyaṉuppu) — to see off

[PAUSE 2s] Before the new one: say the Tamil for to show around, then the Tamil for to visit.

## You'll want to know: வழியனுப்பு
<!-- hl-knowledge: introduces=[TA-LEX-C421-VAZHIKATTI421-05]; assesses=[] -->

**வழியனுப்பு** — *vaḻiyaṉuppu* — "to see off".

> நாங்கள் தாத்தாவை ரயில் நிலையத்தில் வழியனுப்பினோம்.
>
> *nāṅkaḷ tāttāvai rayil nilaiyattil vaḻiyaṉuppiṉōm.*
>
> We saw grandfather off at the railway station.

Past (I …): வழியனுப்பினேன், *vaḻiyaṉuppiṉēṉ*.

The person seen off takes -ஐ: தாத்தாவை வழியனுப்பு.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**வழியனுப்பு** (*vaḻiyaṉuppu*) is built from வழி, "a way" (DEDR 5297), and அனுப்பு, "to send; to go a little way with someone" (DEDR 329).

One more word for getting around.
