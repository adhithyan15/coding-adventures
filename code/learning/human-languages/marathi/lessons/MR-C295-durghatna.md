## You'll want to know: दुर्घटना
<!-- hl-knowledge: introduces=[MR-LEX-C295-SANKAT295-02]; assesses=[] -->

**दुर्घटना** — *durghaṭnā* — "a disaster; a terrible accident".

> त्या दुर्घटनेत अनेक घरं वाहून गेली.
>
> *tyā durghaṭnet anek gharaṁ vāhūn gelī.*
>
> Many houses were swept away in that disaster.

Feminine.

Built from दुर्-, ill, and घटना, an event.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**दुर्घटना** (*durghaṭnā*) is a learned compound built from the Sanskrit prefix *dur-*, 'bad, ill', and *ghaṭanā*, 'a happening' (Monier-Williams).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
