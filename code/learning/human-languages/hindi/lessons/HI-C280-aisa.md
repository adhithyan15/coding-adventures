# ऐसा (aisā) — like this, such

## Warm-up

## You'll want to know: ऐसा
<!-- hl-knowledge: introduces=[HI-LEX-C280-AISA-01]; assesses=[HI-CONCEPT-C03-KAISE-01, HI-LEX-C85-IMP-04, HI-LEX-C280-LAGNA-01, HI-CONCEPT-C34-LIKHNA-01] -->

**ऐसा** — *aisā* — "like this, such; so".

> **मुझे ऐसा लगता है।**
>
> *mujhe aisā lagtā hai.* — "I think so."

Word for word, "it seems so to me". **ऐसा** agrees, as **कैसा** does: **ऐसा**, **ऐसी**, **ऐसे** (*aisā*, *aisī*, *aise*).

> **ऐसा मत करो।**
>
> *aisā mat karo.* — "Don't do that."

- **ऐसी बात** (*aisī bāt*) — such a thing; **बात** is feminine
- **ऐसे लिखिए।** (*aise likhiye.*) — Write it like this.

Its first letter is new to you: **ऐ**. The next lesson is about it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ऐसा** (*aisā*) is a tadbhava, worn down from Sanskrit *īdṛśa*, "such, like this" (CDIAL 1611). Its question partner has the same history: **कैसा** goes back to *kīdṛśa*, "of what kind?" (CDIAL 3197).
