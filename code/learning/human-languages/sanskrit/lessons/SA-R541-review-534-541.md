(**गणकः**, *gaṇakaḥ*.) Draws near? (**उपतिष्ठते**, *upatiṣṭhate*.) Heedful? (**अप्रमत्तः**, *apramattaḥ*.) Inattention? (**अनवधानम्**, *anavadhānam*.) Watchful? (**जागरूकः**, *jāgarūkaḥ*.) Suspects?
