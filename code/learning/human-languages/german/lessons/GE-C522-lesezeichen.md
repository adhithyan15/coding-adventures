## You'll want to know: das Lesezeichen
<!-- hl-knowledge: introduces=[GE-LEX-C522-VERLAG-03]; assesses=[] -->

**das Lesezeichen** — "bookmark".

> Als Lesezeichen nimmt er eine alte Fahrkarte.
>
> *He uses an old ticket as a bookmark.*

Plural: *die Lesezeichen*. Also a bookmark in a web browser.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*Lesezeichen* is built on *lesen* "to read" and *Zeichen* "sign", inherited from Old High German *zeihhan*, from Proto-Germanic *taikną* (EtymDB).
