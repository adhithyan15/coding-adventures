## You'll want to know: پیش آمدن
<!-- hl-knowledge: introduces=[FA-LEX-C397-EHTIYAT-04]; assesses=[] -->

**پیش آمدن** (*pish âmadan*) — "to come up, to crop up".

> یک مشکل کوچک پیش آمد.
>
> *yek moshkel-e kuchek pish âmad.*
>
> A small problem came up.

*Pish* "forward" + *âmadan* "to come" (present stem *â-*).

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**پیش آمدن** is native Persian, built from *pish* "forward, before" + *âmadan* "to come", which EtymDB traces to PIE *gʷem-* "to step". A problem steps forward.
