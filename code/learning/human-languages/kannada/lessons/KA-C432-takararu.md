# ತಕರಾರು (takarāru) — an objection; a dispute

## You'll want to know: ತಕರಾರು
<!-- hl-knowledge: introduces=[KA-LEX-C432-HATTIKKU432-03]; assesses=[] -->

**ತಕರಾರು** — *takarāru* — "an objection; a dispute".

> ಈ ಹೊಸ ಯೋಜನೆಗೆ ಯಾರಿಗೂ ತಕರಾರು ಇಲ್ಲ.
>
> *ī hosa yōjanege yārigū takarāru illa.*
>
> No one has any objection to this new scheme.

ತಕರಾರು ಮಾಡು, to raise objections.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ತಕರಾರು** (*takarāru*) is usually traced to Arabic *takrār*, "repetition, altercation", through Hindustani.
