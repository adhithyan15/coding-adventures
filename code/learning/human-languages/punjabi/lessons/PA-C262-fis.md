# ਫ਼ੀਸ (fīs) — a fee

## You'll want to know: ਫ਼ੀਸ
<!-- hl-knowledge: introduces=[PA-LEX-C262-FEE262-01]; assesses=[] -->

**ਫ਼ੀਸ** — *fīs* — "a fee".

> ਲਾਇਬ੍ਰੇਰੀ ਦੀ ਫ਼ੀਸ ਬਹੁਤ ਘੱਟ ਹੈ।
>
> *lāibrerī dī fīs bahut ghaṭṭ hai.*
>
> The library fee is very low.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ਫ਼ੀਸ** (*fīs*) is borrowed from English *fees*, the plural of *fee*.
