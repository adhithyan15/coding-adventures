## You'll want to know: આજકાલ
<!-- hl-knowledge: introduces=[GU-LEX-C182-NOW182-01]; assesses=[] -->

**આજકાલ** — *ājkāl* — "these days, nowadays".

> **આજકાલ હું વહેલો ઉઠું છું.** — *ājkāl hũ vahelo uṭhũ chũ* — "These days I get up early."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**આજકાલ** (*ājkāl*) is built from two taught words, *āj*, "today", and *kāl*, "tomorrow, yesterday", so it means about now.
