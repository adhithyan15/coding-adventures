# Session Map — Sanskrit Chapter 1 (Greetings)

Same spaced-repetition schedule as the other tracks (a word from session *N*
resurfaces at *N+1, N+3, N+7, N+15*). Lessons named by slug; this map is the
authoritative order.

**There is no reading course.** Devanagari is learned *through* the words: each
lesson's *"The letters in this word"* section introduces exactly the letters —
and the Sanskrit-specific marks (visarga, conjuncts) — that word needs.

## Chapter 1 — Greetings

| Session | Lesson | Word | Root / hook |
|---|---|---|---|
| 1 | namaste | नमस्ते | "a bow to you" ← *namas* (√nam) + *te*; *te* ↔ *thee* |
| 2 | namaskara | नमस्कारः | "the making of a bow" ← *namas* + *kāra* (√kṛ); the visarga |
| 3 | dhanyavada | धन्यवादः | "thank you" ← *dhanya* + *vāda*; source of the Indo-Aryan thanks |
| 4 | svagatam | स्वागतम् | "welcome" ← *su* + *āgata*; *su-*↔*eu-*, √gam↔*come*; sandhi |
| 5 | am-na | आम् / न | "yes / no"; *na* ← PIE *ne ↔ Latin *nōn* ↔ English *no* |
| 6 | practice | (recap) | the greetings + the taproot's east-and-west cognates |
