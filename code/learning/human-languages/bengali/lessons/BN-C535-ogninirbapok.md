# অগ্নিনির্বাপক (ôgninirbāpôk) — a fire extinguisher

## You'll want to know: অগ্নিনির্বাপক
<!-- hl-knowledge: introduces=[BN-LEX-C535-SURAKSHA535-05]; assesses=[] -->

**অগ্নিনির্বাপক** — *ôgninirbāpôk* — "a fire extinguisher".

> আগুন লাগলে আমরা অগ্নিনির্বাপক দিয়ে আগুন নেভাব।
>
> *Āgun lāgle āmrā ôgninirbāpôk diye āgun nebhābô.*
>
> If a fire breaks out, we'll put it out with the extinguisher.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**অগ্নিনির্বাপক** (*ôgninirbāpôk*) joins Sanskrit *agni*, "fire", and *nirvāpaka*, "putting out" (Monier-Williams).
