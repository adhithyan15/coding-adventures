# வேண்டுமானால் (vēṇṭumāṉāl) — if need be; if you like

## You'll want to know: வேண்டுமானால்
<!-- hl-knowledge: introduces=[TA-LEX-C382-NIPANTANAI382-05]; assesses=[] -->

**வேண்டுமானால்** — *vēṇṭumāṉāl* — "if need be; if you like".

> வேண்டுமானால் நீ என் கைப்பேசியைப் பயன்படுத்தலாம்.
>
> *vēṇṭumāṉāl nī eṉ kaippēciyaip payaṉpaṭuttalām.*
>
> If you like, you can use my phone.

வேண்டும், want, + ஆனால், if it is: the conditional of வேண்டும்.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**வேண்டுமானால்** (*vēṇṭumāṉāl*) is native: *vēṇṭum*, "it is wanted", from *vēṇṭu* (DEDR 5528), and *āṉāl*, "if it becomes", the conditional of *āku* (DEDR 333).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
