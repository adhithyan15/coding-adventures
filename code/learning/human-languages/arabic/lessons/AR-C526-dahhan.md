# دهان (dahhān) — a house painter

## You'll want to know: دهان
<!-- hl-knowledge: introduces=[AR-LEX-C526-HIRAF526-03]; assesses=[] -->

**دهان** — *dahhān* — "a house painter".

> دهن الدهان جدران الغرفة.
>
> *dahana ad-dahhān judrān al-ghurfa.*
>
> The painter painted the walls of the room.

The pattern faʿʿāl names a trade.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**دهان** (*dahhān*) is built on the native Arabic root *d-h-n*, "oil, grease; to anoint" (Lane). Dahana, to paint a wall, which you know, is from the same root.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
