## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**أحس** (*aḥassa*) is built on the native Arabic root *ḥ-s-s*, "to perceive" (Lane). *Aḥassa* is Form IV, "to perceive, to feel".
