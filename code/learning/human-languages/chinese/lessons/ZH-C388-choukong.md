## You'll want to know: chōukòng
<!-- hl-knowledge: introduces=[ZH-LEX-C388-DATE388-01]; assesses=[] -->

*chōukòng* — "to find time (for something)".

> *yàoshi nǐ néng chōukòng lái kàn wǒ wǒ huì hěn gāoxìng* — If you can find time to come and see me, I'll be really pleased.

Its characters come later; for now it is a word for the ear.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*chōukòng* is built from *chōu* 'to pull out' and *kòng* 'a gap', both inherited from Middle Chinese, *trhjuw* and *khuwngH* (Guangyun, in Baxter's transcription), which glosses the first 'to draw out' and the second 'a gap'.
