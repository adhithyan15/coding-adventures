# Return to the familiar message purpose

The earlier named-reader message remains the scored short checkpoint. This
return practises its known jobs without adding a new task or a new word.

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-A1-MESSAGE-PACING-01, PA-A1-MESSAGE-TIMED-01] -->

On a blank page, recall the order: Manan as reader, a greeting and wellbeing
question, the familiar water detail, a meeting invitation, then a close.
Keep earlier models closed.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-A1-MESSAGE-PACING-01, PA-A1-MESSAGE-TIMED-01] -->

Set a two-minute practice timer. As Aman, write a 30–40-word Gurmukhi message
to Manan with those already taught details. Stop when the timer ends, even if
the word band is unfinished. This is an unscored retrieval, not a full A1
paper or a replacement for the earlier independent checkpoint.

After stopping, record the word count. Check the named reader, water detail,
meeting purpose, and close one at a time. Keep the clocked page unchanged;
if needed, repair one line on another page and name what changed.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[PA-A1-MESSAGE-PACING-01, PA-A1-MESSAGE-TIMED-01] -->

Cover both pages. [PAUSE 4s] Recall the opening and purpose in order. Later
full twenty-minute form-and-message mocks, followed by human review, are
still required before a durable A1 writing claim.
