# கிட்டார் (kiṭṭār) — a guitar

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TA-LEX-C557-KAMPALI557-02, TA-LEX-C557-KAMPALI557-03] -->

[PAUSE 2s] Before the new one: say the Tamil for wool, then the Tamil for a dye.

## You'll want to know: கிட்டார்
<!-- hl-knowledge: introduces=[TA-LEX-C557-KAMPALI557-04]; assesses=[] -->

**கிட்டார்** — *kiṭṭār* — "a guitar".

> நீ கிட்டார் கற்றுக்கொண்டால் நாம் சேர்ந்து பாடலாம்.
>
> *nī kiṭṭār kaṟṟukkoṇṭāl nām cērntu pāṭalām.*
>
> If you learn the guitar, we can sing together.

Played with வாசி: கிட்டார் வாசி.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**கிட்டார்** (*kiṭṭār*) is a loan from English *guitar*.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
