# પચવું (pacvũ) — to digest, to be digested

## You'll want to know: પચવું
<!-- hl-knowledge: introduces=[GU-LEX-C225-UNWELL225-03]; assesses=[] -->

**પચવું** — *pacvũ* — "to digest, to be digested".

> **મને દૂધ પચતું નથી.** — *mane dūdh pactũ nathī* — "Milk does not agree with me."

Word for word, milk is not digested to me.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**પચવું** (*pacvũ*) is a tadbhava, a word inherited from Sanskrit and reshaped by sound change. It comes from *pacyate*, "is cooked, is digested" (CDIAL 7654).
