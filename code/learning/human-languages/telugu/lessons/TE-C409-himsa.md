# హింస (hiṁsa) — violence

## You'll want to know: హింస
<!-- hl-knowledge: introduces=[TE-LEX-C409-AIKYATA409-01]; assesses=[] -->

**హింస** — *hiṁsa* — "violence".

> హింస ఏ సమస్యకూ పరిష్కారం కాదు.
>
> *hiṁsa ē samasyakū pariṣkāraṁ kādu.*
>
> Violence is no solution to any problem.

అహింస, non-violence.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**హింస** (*hiṁsa*) is borrowed from Sanskrit *hiṁsā*, "injury, harm, hurt" (Monier-Williams).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
