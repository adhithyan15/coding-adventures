## You'll want to know: acampar
<!-- hl-knowledge: introduces=[PT-LEX-C426-TENDA-01]; assesses=[] -->

**acampar** — "to camp".

> Acampámos perto de um lago.
>
> *We camped near a lake.*

*Acampar* in the wild is not allowed everywhere.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*acampar* was borrowed from Italian *accampare* 'to set up camp' (EtymDB), built on *campo* 'field', from Latin *campus*.
