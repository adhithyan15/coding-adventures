Live custom element. The <mos-formula-bar> above is a real Web Component registered by build/FormulaBar.js (compiled from FormulaBar.mil/.mll/.msl via mosaic-compile --backend webcomponent). It uses shadow DOM, observed attributes, and fires mosaic:formulaChange / mosaic:commit / mosaic:cancel CustomEvents on user input — visible in the log above. The Grid is still hand-written until the WebComponent emitter learns the Grid primitive.
