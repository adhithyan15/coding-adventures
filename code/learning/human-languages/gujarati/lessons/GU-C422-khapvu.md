# ખપવું (khapvũ) — to sell well; to be used up

## You'll want to know: ખપવું
<!-- hl-knowledge: introduces=[GU-LEX-C422-STALL422-05]; assesses=[] -->

**ખપવું** — *khapvũ* — "to sell well; to be used up".

> ગરમીમાં લીંબુ ઘણાં ખપે છે.
>
> *garmīmā̃ lī̃bu ghaṇā̃ khape che.*
>
> In the hot weather lemons sell well.

Past (it …): તે માલ ખપી ગયો, *te māl khapī gayo*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ખપવું** (*khapvũ*) is a tadbhava of Sanskrit *kṣapyatē*, "is wasted, is destroyed"; CDIAL lists the Gujarati verb, "to be consumed" (CDIAL 3655): goods that are used up have sold.
