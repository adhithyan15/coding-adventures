## You'll want to know: el atardecer
<!-- hl-knowledge: introduces=[ES-LEX-C703-ANOCHECER-01]; assesses=[] -->

**el atardecer** — "dusk, sunset".

> El atardecer en la playa es precioso.
>
> *Sunset on the beach is beautiful.*

Also a verb: *atardece* — evening is falling.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*atardecer* is built on *tarde* "afternoon, late", which is inherited from Latin *tardē* "late" (EtymDB), from *tardus* "slow".
