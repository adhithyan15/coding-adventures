## You'll want to know: सीप
<!-- hl-knowledge: introduces=[HI-LEX-C445-KISHTI445-05]; assesses=[] -->

**सीप** — *sīp* — "a shell (of an oyster or a mussel)".

> मीरा को किनारे पर एक सुंदर सीप मिली।
>
> *Mīrā ko kināre par ek sundar sīp milī.*
>
> Mira found a pretty shell on the shore.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**सीप** (*sīp*) goes back to *\*sippī*, "a bivalve shell", a form CDIAL reconstructs (CDIAL 13417), which lists Hindi *sīp*: the shell in which a pearl grows.
