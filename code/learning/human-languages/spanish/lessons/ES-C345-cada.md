## The word, taken apart
<!-- hl-knowledge: introduces=[ES-LEX-C345-REF-02]; assesses=[] -->

**cada** — "each," "every."

A very small, very common word, and it is Greek.

Greek **katá** meant *down, along, by*. It entered late spoken Latin in the
phrase **cata ūnum** — *one by one* — which is exactly the sense *cada*
still carries: not the whole heap at once, but taken one at a time.

That is the difference between *cada* and **todo**, which you have. *Todo* is
the whole thing together; *cada* walks through it item by item.

Greek *katá* is at the front of a row of English words. A **catalogue** lists
things down the page. A **catastrophe** is a *down-turning*, the moment a play
overturns. A **cathedral** is where a bishop sits **down**. **Catalyst**,
**category** and **catapult** all start the same way.

So the everyday **cada día**, *each day*, opens with the same syllable as
*catastrophe*.
