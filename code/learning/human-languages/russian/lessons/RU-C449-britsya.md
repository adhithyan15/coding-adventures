## You'll want to know: бриться
<!-- hl-knowledge: introduces=[RU-LEX-C449-STRIZHKA-04]; assesses=[] -->

**бриться** (*brítsya*) — "to shave".

> Отец бреется каждое утро.
>
> *Otéts bréyetsya kázhdoye útro.*
>
> Father shaves every morning.

Imperfective; perfective *побриться*. Present *бреюсь, бреешься*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*бриться* is *брить* 'to shave' with *-ся* 'oneself'. *Брить* is inherited from Proto-Slavic *briti* (EtymDB).
