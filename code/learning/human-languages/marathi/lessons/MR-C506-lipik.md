## You'll want to know: लिपिक
<!-- hl-knowledge: introduces=[MR-LEX-C506-KACHERI506-01]; assesses=[] -->

**लिपिक** — *lipik* — "a clerk".

> लिपिकाने माझा अर्ज वाचला.
>
> *lipikāne mājhā arja vāclā.*
>
> The clerk read my application.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**लिपिक** (*lipik*) is a tatsama, taken from Sanskrit *lipika*, "a scribe, a clerk" (Monier-Williams), built on *lipi*, "writing".
