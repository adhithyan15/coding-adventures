# మందు (mandu) — medicine

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TE-LEX-C91-GREET-05, TE-LEX-C92-DOCTOR-01] -->

[PAUSE 2s] Before the new one: say the Telugu for have you eaten, then the Telugu for a cold.

## You'll want to know: మందు
<!-- hl-knowledge: introduces=[TE-LEX-C92-DOCTOR-02]; assesses=[] -->

**మందు** (*mandu*) — "medicine".

**మందు వేసుకోండి** — "please take the medicine". Telugu *puts on* a medicine, where English
*takes* it.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

The cure, and the verb Telugu uses for taking it.
