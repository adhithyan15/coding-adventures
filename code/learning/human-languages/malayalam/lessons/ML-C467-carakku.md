## You'll want to know: ചരക്ക്
<!-- hl-knowledge: introduces=[ML-LEX-C467-CARAKKU467-01]; assesses=[] -->

**ചരക്ക്** — *carakkŭ* — "goods; cargo".

> തുറമുഖത്ത് ധാരാളം ചരക്ക് ഉണ്ടായിരുന്നു.
>
> *tuṟamukhattŭ dhārāḷaṁ carakkŭ uṇṭāyirunnu.*
>
> There was a lot of cargo at the port.

You met it inside പലചരക്ക്, groceries: many goods.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ചരക്ക്** (*carakkŭ*) is native Dravidian, "merchandise, cargo" (DEDR 2353). The same word sits inside പലചരക്ക്, groceries.
