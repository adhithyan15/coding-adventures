## You'll want to know: пособие
<!-- hl-knowledge: introduces=[RU-LEX-C368-POMOSHCH-03]; assesses=[] -->

**пособие** (*posóbiye*) — "a benefit, an allowance; a study guide".

> Он получает пособие по безработице.
>
> *On polucháyet posóbiye po bezrabótitse.*
>
> He receives unemployment benefit.

A neuter noun. *Пособие по безработице* — unemployment benefit. *Учебное пособие* — a study guide.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**пособие** is built on the old verb *пособить* "to help". The origin of the root is not settled.
