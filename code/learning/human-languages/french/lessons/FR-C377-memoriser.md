## You'll want to know: mémoriser
<!-- hl-knowledge: introduces=[FR-LEX-C377-REVISION-03]; assesses=[] -->

**mémoriser** — "to memorise".

> J'ai mémorisé tous les verbes.
>
> *I memorised all the verbs.*

From *mémoire*, memory.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*mémoriser* is built on *mémoire* "memory", from Latin *memoria* "memory", from *memor* "mindful" (Lewis & Short).
