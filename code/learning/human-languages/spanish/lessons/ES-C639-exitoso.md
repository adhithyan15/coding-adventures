## You'll want to know: exitoso
<!-- hl-knowledge: introduces=[ES-LEX-C639-FINAL-05]; assesses=[] -->

**exitoso** — "successful".

> Fue un año muy exitoso.
>
> *It was a very successful year.*

Built on *el éxito*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*exitoso* is built on *éxito* with *-oso* (EtymDB); *éxito* is a learned borrowing from Latin *exitus* 'a going out, an outcome'.
