## You'll want to know: tuttora
<!-- hl-knowledge: introduces=[IT-LEX-C280-FINORA-03]; assesses=[] -->

**tuttora** — "still, to this day".

> Mio nonno abita tuttora nella stessa casa.
>
> *My grandfather still lives in the same house.*

Stronger than *ancora*: true then and true now.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*tuttora* fuses *tutta* "all" and *ora* "hour, now", from Latin *hōra* (EtymDB): all the hours up to now.
