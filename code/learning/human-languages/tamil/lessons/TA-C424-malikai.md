# மாளிகை (māḷikai) — a mansion; a palace

## You'll want to know: மாளிகை
<!-- hl-knowledge: introduces=[TA-LEX-C424-SILAI424-04]; assesses=[] -->

**மாளிகை** — *māḷikai* — "a mansion; a palace".

> அந்தப் பழைய மாளிகை இப்போது அருங்காட்சியகம்.
>
> *antap paḻaiya māḷikai ippōtu aruṅkāṭciyakam.*
>
> That old mansion is now a museum.

The plural is மாளிகைகள்.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**மாளிகை** (*māḷikai*) is borrowed from Sanskrit *mālikā*, which the Sanskrit lexicographers use for a tall house with an upper storey (Monier-Williams).
