## You'll want to know: ادارہ
<!-- hl-knowledge: introduces=[UR-LEX-C357-BADUNVANI357-02]; assesses=[] -->

**ادارہ** — *idārā* — "an institution; an organisation".

> یہ ادارہ بچوں کی مدد کرتا ہے۔
>
> *yih idārā bachchoṅ kī madad kartā hai.*
>
> This organisation helps children.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ادارہ** (*idārā*) is usually traced, through Persian, to Arabic *idāra*, "administration, running (a thing)".
