## You'll want to know: nuageux
<!-- hl-knowledge: introduces=[FR-LEX-C460-METEO-03]; assesses=[] -->

**nuageux** — "cloudy".

> Le ciel est nuageux, mais il ne pleut pas.
>
> *The sky is cloudy, but it is not raining.*

Feminine *nuageuse*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*nuageux* is built on *nuage* 'cloud' (EtymDB lists it), from the old word *nue* 'cloud', which goes back to Latin *nūbēs*.
