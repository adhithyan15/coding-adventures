# उ — short *u* standing on its own

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[] -->

You already hang a short *u* under a consonant. What happens when there is no consonant to hang it on?

## Script
<!-- hl-knowledge: introduces=[MR-SCRIPT-U-INDEPENDENT-01]; assesses=[MR-SCRIPT-SSA-01, MR-SCRIPT-U-MATRA-01] -->

> उ

Then you write **उ**, the independent short *u* — the same vowel given its own
full letter for the start of a word.

Devanagari does this for every vowel: a **mark** when something carries it, a
**letter** when nothing does. You have already seen the pair once, with **अ** and
its mark. **उ** opens *udyā*, "tomorrow", in the farewell this book taught you
chapters ago.

## Writing — guided copy
<!-- hl-knowledge: introduces=[]; assesses=[MR-SCRIPT-U-INDEPENDENT-01] -->
<!-- hl-writing-stage: guided-copy -->

Copy **उ** twice with the model visible. Then write the short-*u* mark beside it
and say aloud which of the two needs a consonant to lean on.
