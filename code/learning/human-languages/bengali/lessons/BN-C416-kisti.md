# কিস্তি (kisti) — an instalment

## You'll want to know: কিস্তি
<!-- hl-knowledge: introduces=[BN-LEX-C416-KISTI416-01]; assesses=[] -->

**কিস্তি** — *kisti* — "an instalment".

> অরুণ সাইকেলটা কিস্তিতে কিনল।
>
> *ôrun sāikelṭā kistite kinlô.*
>
> Arun bought the bicycle in instalments.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**কিস্তি** (*kisti*) is usually traced to Arabic *qisṭ*, "a share, a portion", through Persian *qist*, "an instalment".
