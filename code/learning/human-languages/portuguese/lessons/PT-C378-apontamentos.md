## You'll want to know: os apontamentos
<!-- hl-knowledge: introduces=[PT-LEX-C378-REVER-02]; assesses=[] -->

**os apontamentos** — "the class notes".

> Emprestei os meus apontamentos a uma colega.
>
> *I lent my notes to a classmate.*

European Portuguese; in Brazil *as anotações*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*apontamento* is built on *apontar* "to note down, to point", on *ponto* "point", inherited from Latin *punctum* "a point" (Lewis & Short).
