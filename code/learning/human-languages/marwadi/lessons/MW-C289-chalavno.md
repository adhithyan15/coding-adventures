## You'll want to know: चलावणो
<!-- hl-knowledge: introduces=[MW-LEX-C289-MASIN289-02]; assesses=[] -->

**चलावणो** — *chalāvṇo* — "to drive; to run (a machine)".

> भाई मसीन चलावै है।
>
> *bhāī masīn chalāvai hai.*
>
> My brother runs the machine.

Past (I …): म्हैं गाड़ी चलाई, *mhaĩ gāṛī chalāī*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**चलावणो** (*chalāvṇo*) is built on **चालणो**, to walk, as its causative: "to make go". CDIAL lists Old Marwari *calaï*, "goes", under Sanskrit *calati* (CDIAL 4715).
