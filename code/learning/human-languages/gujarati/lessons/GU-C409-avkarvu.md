## You'll want to know: આવકારવું
<!-- hl-knowledge: introduces=[GU-LEX-C409-LODGE409-05]; assesses=[] -->

**આવકારવું** — *āvkārvũ* — "to welcome (a guest)".

> મેનેજર દરેક મહેમાનને હસીને આવકારે છે.
>
> *menejar darek mahemānne hasīne āvkāre che.*
>
> The manager welcomes every guest with a smile.

Past, with તેણે (he or she …): તેણે મહેમાનને આવકાર્યો, *teṇe mahemānne āvkāryo*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**આવકારવું** (*āvkārvũ*) is built on આવકાર, "a welcome", which seems to go with આવવું, to come. No dictionary we use records an older form, so its history is not settled.
