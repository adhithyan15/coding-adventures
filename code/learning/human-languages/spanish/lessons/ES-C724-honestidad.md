## You'll want to know: la honestidad
<!-- hl-knowledge: introduces=[ES-LEX-C724-MENTIRA-05]; assesses=[] -->

**la honestidad** — "honesty".

> Valoro la honestidad de mis amigos.
>
> *I value my friends' honesty.*

*Honradez* is a close synonym.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*honestidad* is built on *honesto*, which comes from Latin *honestus* "honourable" (EtymDB), itself built on *honōs* "honour".
