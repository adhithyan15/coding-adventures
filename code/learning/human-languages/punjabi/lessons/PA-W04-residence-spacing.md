# Give the residence value its own space

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-LABEL-RESIDENCE-01, PA-FORM-RESIDENCE-VILLAGE-01] -->

Read **ਰਿਹਾਇਸ਼: ਪਿੰਡ**. Point once to the label and once to the value.

## Writing — one spacing pass
<!-- hl-knowledge: introduces=[PA-FORM-RESIDENCE-SPACING-01]; assesses=[PA-FORM-LABEL-RESIDENCE-01, PA-FORM-RESIDENCE-VILLAGE-01] -->

Copy **ਰਿਹਾਇਸ਼:**, leave a clear space, then copy **ਪਿੰਡ**. Judge only the boundary after the colon.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-RESIDENCE-SPACING-01] -->

Cover the model and repeat once. If the boundary is unclear, repair only the space.
