# బలవంతం (balavantaṁ) — force; compulsion

## You'll want to know: బలవంతం
<!-- hl-knowledge: introduces=[TE-LEX-C424-OTTIDI424-02]; assesses=[] -->

**బలవంతం** — *balavantaṁ* — "force; compulsion".

> ఎవరినీ బలవంతంగా పనిలో పెట్టకూడదు.
>
> *evarinī balavantaṅgā panilō peṭṭakūḍadu.*
>
> No one should be forced into work.

బలవంతంగా, by force; బలవంతం చేయు, to force.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**బలవంతం** (*balavantaṁ*) is built on Sanskrit *balavant*, "strong" (CDIAL 9166), from *bala*, "strength", the word in బలం.
