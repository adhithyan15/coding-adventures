# कोनी — no, on the page

## You'll want to know
<!-- hl-knowledge: introduces=[MW-SCRIPT-KONI-01]; assesses=[MW-SCRIPT-KA-01, MW-SCRIPT-O-MATRA-01, MW-SCRIPT-NA-01, MW-SCRIPT-II-MATRA-01] -->

> **को** + **नी** → **कोनी** — *konī* — no

Two pieces, four signs, and not one of them is new. **क** and **ो** you have
written since chapter 5; **न** since chapter 5; **ी** since chapter 4.

That is worth saying plainly, because it means this word cost the hand nothing
and was missing anyway. The gap was never a writing problem.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-KONI-01, MW-SCRIPT-HAAN-01] -->
<!-- hl-writing-stage: guided-copy -->

Copy **कोनी** once while looking. Then write **हां सा** above it and **कोनी**
below, so the yes and the no sit one over the other on the page for the first
time in this book.
