## You'll want to know: સફળ
<!-- hl-knowledge: introduces=[GU-LEX-C384-SAFAL384-01]; assesses=[] -->

**સફળ** — *saphaḷ* — "successful".

> જો આ યોજના સફળ થશે તો આખા ગામને ફાયદો થશે.
>
> *jo ā yojnā saphaḷ thaśe to ākhā gāmne phāydo thaśe.*
>
> If this plan succeeds, the whole village will benefit.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**સફળ** (*saphaḷ*) is a tatsama, borrowed from Sanskrit *saphala*, "having fruit, fruitful" (Monier-Williams).
