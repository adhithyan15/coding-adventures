# કિલોમીટર (kilomīṭar) — a kilometre

## Warm-up

## You'll want to know: કિલોમીટર
<!-- hl-knowledge: introduces=[GU-LEX-C403-HIGHWAY403-03]; assesses=[] -->

**કિલોમીટર** — *kilomīṭar* — "a kilometre".

> રોજ હું પાંચ કિલોમીટર ચાલું છું.
>
> *roj hũ pā̃c kilomīṭar cālũ chũ.*
>
> I walk five kilometres every day.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**કિલોમીટર** (*kilomīṭar*) is borrowed from English *kilometre*.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->
