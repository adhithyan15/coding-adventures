# Bengali pre-A1 mock 2 — learner paper and examiner script

This is a parallel paper, not a practice copy of mock 1. Administer reading for
10 minutes, listening for 10, writing for 12, and speaking for 8. Support-language
directions may explain the action but may not translate Bengali stimuli. Give
learners only the learner-facing sections. Keep the examiner-only script and
model cards at the end out of view. Read each listening item twice at 70–90
words per minute and allow an eight-second answer pause. No transcript,
romanization, dictionary, or coaching is allowed.
Print Reading, Listening, and Writing as separate skill sheets; never hand out
this combined source file. Collect each completed sheet before giving the next
one. In particular, remove the Reading and Listening sheets before Writing, so
earlier Bengali words cannot serve as copyable spelling models. Give Speaking
prompts orally, without returning any earlier sheet.

## Reading — 10 minutes

Choose A, B, or C. The first six prompts are single Bengali words.

### Signs and words — items 1–6

1. **বাংলা** — A Bengali / B book / C tea
2. **বই** — A name / B book / C bus
3. **চা** — A tea / B water / C home
4. **বাস** — A good / B yes / C bus
5. **ভালো** — A name / B good / C thanks
6. **আবার** — A again / B no / C school

### Phrases and notices — items 7–10

7. **আমার নাম অনিকা।** — A I want to meet Anika. / B My name is Anika. / C Anika speaks Bengali.
8. **আপনি কেমন আছেন?** — A How are you? / B What is your name? / C Where do you live?
9. **দয়া করে বসুন।** — A Please leave. / B Please speak. / C Please sit.
10. **আবার দেখা হবে।** — A See you again. / B I am well. / C Thank you.

### Personal details — items 11–14

11. Form field **নাম: আরিফ** — A language Arif / B name Arif / C city Arif
12. Form field **বয়স: ১০** — A ten years old / B ten books / C name Ten
13. Form field **শহর: কলকাতা** — A language Kolkata / B name Kolkata / C city Kolkata
14. Form field **ভাষা: বাংলা** — A age Bengali / B language Bengali / C city Bengali

## Listening — 10 minutes

The examiner reads script L1–L14 below twice each. Learners see these choices
but never the spoken-script text. Choose A, B, or C.

### Sounds and words — items 1–6

1. A Bengali / B book / C bus
2. A tea / B book / C name
3. A tea / B house / C thanks
4. A name / B no / C bus
5. A greeting / B good / C thank you
6. A again / B now / C no

### Greeting responses — items 7–10

7. A না। / B চা। / C নমস্কার।
8. A আমি ভালো আছি। / B আমার নাম আরিফ। / C আবার দেখা হবে।
9. A কোনো ব্যাপার না। / B আমার নাম অনিকা। / C বাস।
10. A ধন্যবাদ। / B না। / C আবার দেখা হবে।

### Personal details — items 11–14

11. A Arif is a city / B the speaker is named Arif / C the speaker wants tea
12. A the speaker lives in Kolkata / B the speaker is leaving Kolkata / C the speaker speaks Kolkata
13. A the speaker owns ten books / B the speaker lives in Ten / C the speaker is ten years old
14. A the speaker wants a book / B the speaker wants tea / C the speaker says no

## Writing — 12 minutes

Show each model card for ten seconds, remove it completely, and only then ask
for written recall. Read each dictation word twice without showing its spelling.
No copyable answer remains in view during independent production.

### Delayed recall — items 1–2

1. View examiner card W1 for ten seconds. After it is removed, write the word.
2. View examiner card W2 for ten seconds. After it is removed, write the word.

### Dictation — items 3–6

3. Write the word read from examiner card D3.
4. Write the word read from examiner card D4.
5. Write the word read from examiner card D5.
6. Write the word read from examiner card D6.

### Independent production — items 7–8

7. Beside a nonverbal map-pin picture, write one chosen place name in Bengali script.
8. Beside a nonverbal picture of a person receiving help, write a Bengali thanks expression.

## Speaking — 8 minutes

The interlocutor may repeat a prompt once slowly. No written answer script is
shown to the learner.

1. Interlocutor: **নমস্কার।** Return a greeting.
2. Interlocutor: **আপনার নাম কী?** Give a chosen name.
3. Interlocutor: **আপনি কোথায় থাকেন?** Give a place.
4. Interlocutor: **আপনি বাংলা বলেন?** Give a relevant yes/no answer.
5. Interlocutor: **আপনি কেমন আছেন?** Give a short relevant answer.
6. Situation: you want tea. Make a short polite request in Bengali.
