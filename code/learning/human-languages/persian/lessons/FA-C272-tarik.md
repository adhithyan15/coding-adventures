**تاریک** — *târik* — "dark".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*târik* is a native Persian word, inherited rather than borrowed; it is usually traced to Middle Persian *tārīk*, "dark".
