<!-- hl-writing-stage: dictation-transcription -->

Five signs, alone, from spoken cues and with no word around them: **ए**,
**४**, **५**, **७**, **८**.

Then put each back to work once. **ए** opens **एक** and its mark rides over
the second spelling of six;
the four figures write four of this slice's twelve amounts. Write those six
things and check each sign against the model only after writing it.
