## You'll want to know: પ્રસ્તાવ
<!-- hl-knowledge: introduces=[GU-LEX-C541-SHAPATH541-05]; assesses=[] -->

**પ્રસ્તાવ** — *prastāv* — "a proposal".

> જો તમને મારો પ્રસ્તાવ ગમશે તો આપણે સાથે કામ કરીશું.
>
> *jo tamne māro prastāv gamśe to āpaṇe sāthe kām karīśũ.*
>
> If you like my proposal, we'll work together.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**પ્રસ્તાવ** (*prastāv*) is a tatsama, taken from Sanskrit *prastāva*, "an introduction, a prelude" (Monier-Williams); in Gujarati it is a proposal put forward.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
