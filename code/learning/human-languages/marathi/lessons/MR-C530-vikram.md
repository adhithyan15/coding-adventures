## You'll want to know: विक्रम
<!-- hl-knowledge: introduces=[MR-LEX-C530-PADAK530-03]; assesses=[] -->

**विक्रम** — *vikram* — "a sporting best; a record".

> तिने धावण्यात नवा विक्रम केला.
>
> *tine dhāvaṇyāt navā vikram kelā.*
>
> She set a new record in running.

Masculine.

विक्रम करणे, to set a record; विक्रम मोडणे, to break one.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**विक्रम** (*vikram*) is a tatsama, taken from Sanskrit *vikrama*, "a stride, valour" (Monier-Williams).
