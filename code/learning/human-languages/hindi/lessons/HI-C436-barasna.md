## You'll want to know: बरसना
<!-- hl-knowledge: introduces=[HI-LEX-C436-BUND436-05]; assesses=[] -->

**बरसना** — *barasnā* — "to pour (of rain); to rain down".

> रात भर बादल बरसे।
>
> *rāt bhar bādal barse.*
>
> It poured all night long.

Past (it …): वह बादल ज़ोर से बरसा, *vah bādal zor se barsā*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**बरसना** (*barasnā*) is a tadbhava of Sanskrit *varṣati*, "it rains" (CDIAL 11394), which lists Hindi *barasnā*; वर्षा, rain, is the same root.
