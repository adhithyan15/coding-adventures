# बहुशः (bahuśaḥ) — often; repeatedly

## You'll want to know: बहुशः
<!-- hl-knowledge: introduces=[SA-LEX-C381-VISHESHATAH381-04]; assesses=[] -->

**बहुशः** — *bahuśaḥ* — "often; repeatedly".

> यदि भवान् बहुशः अभ्यस्यति, तर्हि कुशलः भविष्यति।
>
> *yadi bhavān bahuśaḥ abhyasyati, tarhi kuśalaḥ bhaviṣyati.*
>
> If you practise often, you will become skilled.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**बहुशः** (*bahuśaḥ*) is built on *bahu*, "much, many", with the ending *-śas*; MW gives *bahu-śas* "manifoldly, repeatedly, much, often" (MW).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
