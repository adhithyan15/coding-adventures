## You'll want to know: ವಿಳಾಸ
<!-- hl-knowledge: introduces=[KA-LEX-C91-ABOUTYOU-01]; assesses=[] -->

**ವಿಳಾಸ** (*viḷāsa*) — "address".

**ನಿಮ್ಮ ವಿಳಾಸ ಏನು?** (*nimma viḷāsa ēnu?*) — "what is your address?", built like
**ನಿಮ್ಮ ಹೆಸರು ಏನು?** from the start of the book.

## What you've built

The name question, asked about a place.
