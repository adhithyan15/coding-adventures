## You'll want to know: ничья
<!-- hl-knowledge: introduces=[RU-LEX-C510-RESULTS-02]; assesses=[] -->

**ничья** (*nichyá*) — "a tie (in a game)".

> Ничья устроила обе команды.
>
> *Nichyá ustróila óbe komándy.*
>
> The tie suited both teams.

Feminine, declined like an adjective. *Сыграть вничью* — to end level.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*ничья* comes from *ничья игра* 'nobody's game' (EtymDB), built on *ничей* 'nobody's'.
