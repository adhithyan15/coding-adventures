## You'll want to know: la madurez
<!-- hl-knowledge: introduces=[ES-LEX-C731-MADUREZ-02]; assesses=[] -->

**la madurez** — "maturity".

> Actuó con madurez.
>
> *She acted with maturity.*

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*madurez* is built on *maduro* with the ending *-ez*; *maduro* is inherited from Latin *mātūrus* (EtymDB).
