## You'll want to know: synchronisieren
<!-- hl-knowledge: introduces=[GE-LEX-C524-FILM-05]; assesses=[] -->

**synchronisieren** — "to dub; to synchronise".

> Bei uns werden fast alle Filme synchronisiert.
>
> *Here almost all films are dubbed.*

Regular, Perfekt without *ge-*. Also to sync two devices.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*synchronisieren* is built on *synchron* "at the same time", a learned word from Greek *sýnchronos*, built on *khrónos* "time"; EtymDB has no entry for it.
