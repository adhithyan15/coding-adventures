# நண்டு (naṇṭu) — a crab

## You'll want to know: நண்டு
<!-- hl-knowledge: introduces=[TA-LEX-C436-KATAL436-03]; assesses=[] -->

**நண்டு** — *naṇṭu* — "a crab".

> மணலில் நண்டுகள் ஓடின.
>
> *maṇalil naṇṭukaḷ ōṭiṉa.*
>
> Crabs ran across the sand.

The plural is நண்டுகள்.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**நண்டு** (*naṇṭu*) is native Dravidian (DEDR 2901), "a crab, a lobster".
