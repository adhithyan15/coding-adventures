## You'll want to know: тоска
<!-- hl-knowledge: introduces=[RU-LEX-C477-LONGING-01]; assesses=[] -->

**тоска** (*toská*) — "longing; melancholy".

> Она чувствует тоску по родине.
>
> *Oná chúvstvuyet toskú po ródine.*
>
> She feels homesick.

Feminine. *Тоска по* + dative — longing for.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*тоска* is inherited from Proto-Slavic *tъska* (EtymDB), which EtymDB glosses 'emptiness'.
