# സംരംഭകൻ (saṁrambhakan) — an entrepreneur

## You'll want to know: സംരംഭകൻ
<!-- hl-knowledge: introduces=[ML-LEX-C544-SAMRAMBHAM544-03]; assesses=[] -->

**സംരംഭകൻ** — *saṁrambhakan* — "an entrepreneur".

> ആ സംരംഭകൻ ഗ്രാമത്തിലെ പത്ത് പേർക്ക് ജോലി കൊടുത്തു.
>
> *ā saṁrambhakan grāmattile pattŭ pērkkŭ jōli koṭuttu.*
>
> That entrepreneur gave jobs to ten people in the village.

A woman is സംരംഭക. -അകൻ marks the one who does something.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**സംരംഭകൻ** (*saṁrambhakan*) is built on സംരംഭം, from Sanskrit *saṁrambha* (CDIAL 12993), with the agent ending -അകൻ.
