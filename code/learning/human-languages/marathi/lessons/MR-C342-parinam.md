## You'll want to know: परिणाम
<!-- hl-knowledge: introduces=[MR-LEX-C342-HETU342-03]; assesses=[] -->

**परिणाम** — *pariṇām* — "a consequence; an effect".

> पावसाचा परिणाम भाजीच्या दरावर झाला.
>
> *pāvsācā pariṇām bhājīcyā darāvar jhālā.*
>
> The rain had an effect on vegetable prices.

Masculine.

X चा परिणाम Y वर होतो: X has an effect on Y.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**परिणाम** (*pariṇām*) is a tatsama, taken from Sanskrit *pariṇāma*, "change, development, result" (Monier-Williams).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
