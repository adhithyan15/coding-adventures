# കടപുഴകുക (kaṭapuḻakuka) — to be uprooted

## You'll want to know: കടപുഴകുക
<!-- hl-knowledge: introduces=[ML-LEX-C513-CAMP513-04]; assesses=[] -->

**കടപുഴകുക** — *kaṭapuḻakuka* — "to be uprooted".

> കാറ്റിൽ വഴിയോരത്തെ ഒരു വലിയ മരം കടപുഴകി.
>
> *kāṟṟil vaḻiyōratte oru valiya maraṁ kaṭapuḻaki.*
>
> In the wind a big tree by the roadside was uprooted.

Past: കടപുഴകി, *kaṭapuḻaki*.

Only for trees torn out by the roots: മരം കടപുഴകി, the tree came down roots and all.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**കടപുഴകുക** (*kaṭapuḻakuka*) is a Malayalam verb for a tree torn up by the roots; its origin is not settled.
