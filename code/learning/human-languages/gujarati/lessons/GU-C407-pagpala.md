# પગપાળા (pagpāḷā) — on foot

## You'll want to know: પગપાળા
<!-- hl-knowledge: introduces=[GU-LEX-C407-ABROAD407-04]; assesses=[] -->

**પગપાળા** — *pagpāḷā* — "on foot".

> અમે સ્ટેશન સુધી પગપાળા ગયા.
>
> *ame sṭeśan sudhī pagpāḷā gayā.*
>
> We went to the station on foot.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**પગપાળા** (*pagpāḷā*) is built from પગ, a foot, and *pāḷũ*, "on foot", which CDIAL lists for Gujarati under *\*pādala*, "belonging to the feet", a form it reconstructs (CDIAL 8066).
