## You'll want to know: costeggiare
<!-- hl-knowledge: introduces=[IT-LEX-C442-SALITA-03]; assesses=[] -->

**costeggiare** — "to run along, to skirt (a coast or a river)".

> La strada costeggia il lago.
>
> *The road runs along the lake.*

*La costa* — the coast.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*costeggiare* is built on *costa* 'coast', which is inherited from Latin *costa* 'rib, side' (EtymDB).
