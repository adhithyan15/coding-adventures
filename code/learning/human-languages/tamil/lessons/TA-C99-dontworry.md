# கவலைப்படாதீர்கள் (kavalaippaṭātīrkaḷ) — don't worry

## Warm-up

[PAUSE 2s] Before the new one: say the Tamil for a formal welcome, then the Tamil for please forgive me.

## You'll want to know: கவலைப்படாதீர்கள்
<!-- hl-knowledge: introduces=[TA-LEX-C99-HOST-05]; assesses=[] -->

**கவலைப்படாதீர்கள்** (*kavalaippaṭātīrkaḷ*) — "please don't worry".

It is **கவலை**, "worry", with **படு**, "to suffer", and the respectful don't.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

Drink, a present, a welcome, forgiveness, and don't worry.
