## You'll want to know: guardar
<!-- hl-knowledge: introduces=[PT-LEX-C398-FICHEIRO-03]; assesses=[] -->

**guardar** — "to save (a file); to keep; to put away".

> Guardei o ficheiro antes de desligar o computador.
>
> *I saved the file before switching off the computer.*

*Guardar um segredo* — to keep a secret.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*guardar* is inherited from Medieval Latin *wardāre*, which took it from Frankish *wardōn* "to keep, to guard, to save" (EtymDB).
