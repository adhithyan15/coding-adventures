# অবশেষে (ôbôsheshe) — at last; finally

## You'll want to know: অবশেষে
<!-- hl-knowledge: introduces=[BN-LEX-C281-BHAGYO281-05]; assesses=[] -->

**অবশেষে** — *ôbôsheshe* — "at last; finally".

> অনেক খোঁজার পরে অবশেষে পুলিশ শিশুটিকে খুঁজে পেল।
>
> *ônek khõjār pôre ôbôsheshe pulish shishuṭike khũje pelô.*
>
> After a long search the police finally found the child.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**অবশেষে** (*ôbôsheshe*) is Sanskrit *avaśeṣa*, 'what is left over' (Monier-Williams), in the -e form: 'at what remains', at the very end.
