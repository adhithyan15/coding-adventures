# திறப்புவிழா (tiṟappuviḻā) — an opening ceremony

## You'll want to know: திறப்புவிழா
<!-- hl-knowledge: introduces=[TA-LEX-C318-VIZHA318-01]; assesses=[] -->

**திறப்புவிழா** — *tiṟappuviḻā* — "an opening ceremony".

> புதிய நூலகத்தின் திறப்புவிழா இன்று நடந்தது.
>
> *putiya nūlakattiṉ tiṟappuviḻā iṉṟu naṭantatu.*
>
> The opening ceremony of the new library took place today.

திறப்பு, opening + விழா, festival.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**திறப்புவிழா** (*tiṟappuviḻā*) is a Tamil compound built from திறப்பு, "opening", from திற, "to open" (DEDR 3259), and விழா, "festival" (DEDR 5427).
