## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[MR-GRAMMAR-KUTUMB-NEUTER] -->

Marathi treats **कुटुंब** as **neuter**. Hindi assigns the same borrowed word
masculine gender. Retrieve the Marathi choice, not a universal rule.
