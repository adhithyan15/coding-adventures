## You'll want to know: yǎnyuán
<!-- hl-knowledge: introduces=[ZH-LEX-C267-FILM267-01]; assesses=[] -->

*yǎnyuán* — "actor; performer".

> *tā shì yí ge hěn hǎo de yǎnyuán* — He's a very good actor.

Its characters come later; for now it is a word for the ear.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*yǎnyuán* is built from *yǎn* and *yuán*, both inherited from Middle Chinese, *yenX* and *hjwen* (Guangyun, in Baxter's transcription), which glosses the first 'wide' and quotes an older dictionary for the second, 'a number of things'. The senses 'to perform' and 'a member' are not given there, so how the pair came is not settled.
