## You'll want to know: উপযোগী
<!-- hl-knowledge: introduces=[BN-LEX-C331-UDDESHYO331-05]; assesses=[] -->

**উপযোগী** — *upôjogī* — "useful; serviceable".

> এই বইটা ছাত্রদের জন্য উপযোগী।
>
> *ei bôiṭā chhātrôder jônyô upôjogī.*
>
> This book is useful for students.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**উপযোগী** (*upôjogī*) is Sanskrit *upayogin*, serving a use (Monier-Williams), from *upayoga*, use. What it is useful for takes -এর জন্য: ছাত্রদের জন্য উপযোগী.
