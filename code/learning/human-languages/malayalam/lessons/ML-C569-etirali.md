# എതിരാളി (etirāḷi) — an opponent; a rival

## You'll want to know: എതിരാളി
<!-- hl-knowledge: introduces=[ML-LEX-C569-VIJAYAM569-02]; assesses=[] -->

**എതിരാളി** — *etirāḷi* — "an opponent; a rival".

> അവസാന കളിയിൽ ഞങ്ങളുടെ എതിരാളി ശക്തമായ ടീമായിരുന്നു.
>
> *avasāna kaḷiyil ñaṅṅaḷuṭe etirāḷi śaktamāya ṭīmāyirunnu.*
>
> In the last match our opponents were a strong team.

എതിർ opposite + ആൾ a person; എതിരെ, against, is already familiar.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**എതിരാളി** (*etirāḷi*) is native Dravidian, a compound of എതിർ, "opposite, adverse" (DEDR 795), and ആൾ, "a person" (DEDR 399).
