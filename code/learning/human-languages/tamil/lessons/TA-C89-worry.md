## You'll want to know: கவலை
<!-- hl-knowledge: introduces=[TA-LEX-C89-FEEL-02]; assesses=[] -->

**கவலை** (*kavalai*) — "worry".

**கவலை வேண்டாம்** — "no need to worry", literally "worry is not wanted".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

A worry, and a way to wave it off.
