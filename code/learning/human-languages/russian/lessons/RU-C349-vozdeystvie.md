## You'll want to know: воздействие
<!-- hl-knowledge: introduces=[RU-LEX-C349-VLIYANIYE-05]; assesses=[] -->

**воздействие** (*vozdéystviye*) — "an impact, an effect".

> Это лекарство оказывает сильное воздействие.
>
> *Éto lekárstvo okázyvayet sílnoye vozdéystviye.*
>
> This medicine has a strong effect.

Neuter. *Оказывать воздействие на* + accusative — to have an effect on. Bookish.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**воздействие** is built from *воз-* and *действие* "action", from *действовать* "to act"; the root is usually traced to the old verb *деять* "to do".
