## You'll want to know: ഇംഗ്ലീഷ്
<!-- hl-knowledge: introduces=[ML-LEX-C126-ABOUTYOU-04]; assesses=[] -->

**ഇംഗ്ലീഷ്** (*iṁglīṣ*) — "English". **എനിക്ക് ഇംഗ്ലീഷ് അറിയാം** — "I know English", built
like **എനിക്ക് മലയാളം അറിയാം**.
