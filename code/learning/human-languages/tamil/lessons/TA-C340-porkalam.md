# பொற்காலம் (poṟkālam) — a golden age

## You'll want to know: பொற்காலம்
<!-- hl-knowledge: introduces=[TA-LEX-C340-VEEZHCHI340-04]; assesses=[] -->

**பொற்காலம்** — *poṟkālam* — "a golden age".

> அது தமிழ் இலக்கியத்தின் பொற்காலம்.
>
> *atu tamiḻ ilakkiyattiṉ poṟkālam.*
>
> That was the golden age of Tamil literature.

பொன், gold + காலம்; ன் turns to ற் before க.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**பொற்காலம்** (*poṟkālam*) joins native பொன், "gold" (DEDR 4570), with காலம், "time", from Sanskrit *kāla* (CDIAL 3084).
