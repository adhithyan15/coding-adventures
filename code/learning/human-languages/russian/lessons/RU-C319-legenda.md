## You'll want to know: легенда
<!-- hl-knowledge: introduces=[RU-LEX-C319-LEGENDA-01]; assesses=[] -->

**легенда** (*legénda*) — "a legend".

> Об этом озере есть красивая легенда.
>
> *Ob étom ózere yest krasívaya legénda.*
>
> There is a beautiful legend about this lake.

Feminine. *По легенде* — according to legend.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*легенда* goes back to Medieval Latin *legenda* "things to be read", from *legere* "to gather, to read" (Lewis & Short); EtymDB lists no parent for the Russian word.
