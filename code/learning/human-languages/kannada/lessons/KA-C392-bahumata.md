# ಬಹುಮತ (bahumata) — a majority

## You'll want to know: ಬಹುಮತ
<!-- hl-knowledge: introduces=[KA-LEX-C392-CHUNAVANE392-03]; assesses=[] -->

**ಬಹುಮತ** — *bahumata* — "a majority".

> ಚುನಾವಣೆಯಲ್ಲಿ ಅವರಿಗೆ ಬಹುಮತ ಸಿಕ್ಕಿತು.
>
> *cunāvaṇeyalli avarige bahumata sikkitu.*
>
> They won a majority in the election.

ಬಹು (many) + ಮತ (votes).

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಬಹುಮತ** (*bahumata*) is built from Sanskrit *bahu*, "many", and *mata*, "opinion" (Monier-Williams); the sense "majority" is modern.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
