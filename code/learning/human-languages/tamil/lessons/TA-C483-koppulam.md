# கொப்புளம் (koppuḷam) — a blister

## You'll want to know: கொப்புளம்
<!-- hl-knowledge: introduces=[TA-LEX-C483-TOL483-02]; assesses=[] -->

**கொப்புளம்** — *koppuḷam* — "a blister".

> சூடான பாத்திரம் பட்டுக் கையில் கொப்புளம் வந்தது.
>
> *cūṭāṉa pāttiram paṭṭuk kaiyil koppuḷam vantatu.*
>
> A hot pot touched my hand and it blistered.

Its first sense is a bubble.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**கொப்புளம்** (*koppuḷam*) is native Dravidian (DEDR 2106): a bubble on the skin.
