# Connect the four known blocks

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MR-A1-MESSAGE-LINE-GREETING, MR-A1-MESSAGE-LINE-NAME, MR-A1-MESSAGE-LINE-MEETING, MR-A1-MESSAGE-LINE-KNOW-MARATHI, MR-A1-MESSAGE-LINE-READ-MARATHI, MR-A1-MESSAGE-LINE-WRITE-NAME, MR-A1-MESSAGE-LINE-SPEAK, MR-A1-MESSAGE-LINE-THINK, MR-A1-MESSAGE-LINE-UNDERSTAND-MARATHI, MR-A1-MESSAGE-LINE-THANKS, MR-A1-MESSAGE-LINE-SEE-AGAIN, MR-A1-MESSAGE-LINE-SEE-TOMORROW] -->

Name the four blocks without writing: opening, first skills, second skills,
closing. No block contains new Marathi.

## Writing — connected composition
<!-- hl-knowledge: introduces=[]; assesses=[MR-A1-MESSAGE-LINE-GREETING, MR-A1-MESSAGE-LINE-NAME, MR-A1-MESSAGE-LINE-MEETING, MR-A1-MESSAGE-LINE-KNOW-MARATHI, MR-A1-MESSAGE-LINE-READ-MARATHI, MR-A1-MESSAGE-LINE-WRITE-NAME, MR-A1-MESSAGE-LINE-SPEAK, MR-A1-MESSAGE-LINE-THINK, MR-A1-MESSAGE-LINE-UNDERSTAND-MARATHI, MR-A1-MESSAGE-LINE-THANKS, MR-A1-MESSAGE-LINE-SEE-AGAIN, MR-A1-MESSAGE-LINE-SEE-TOMORROW] -->
<!-- hl-writing-stage: connected-composition -->

Use the four completed block lessons as cards. Put the cards in purpose order
and write the message. Afterward, count words by spaces: the result has **32
words**, inside the A1 target of 30–40.

Repair in four passes: block order, sentence boundaries, verb frames, spelling.
Stop after the first pass that finds a problem.
