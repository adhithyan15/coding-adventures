# ভোটার (bhoṭār) — a voter

## You'll want to know: ভোটার
<!-- hl-knowledge: introduces=[BN-LEX-C346-PRARTHI346-03]; assesses=[] -->

**ভোটার** — *bhoṭār* — "a voter".

> এই গ্রামে দুই হাজার ভোটার আছে।
>
> *ei grāme dui hājār bhoṭār āchhe.*
>
> There are two thousand voters in this village.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ভোটার** (*bhoṭār*) is English *voter*, beside ভোট from English *vote*; Bengali has no v, so it is heard as bh.
