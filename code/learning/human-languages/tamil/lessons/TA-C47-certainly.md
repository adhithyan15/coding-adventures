## You'll want to know: நிச்சயமாக
<!-- hl-knowledge: introduces=[TA-LEX-C47-REPLY-03]; assesses=[] -->

**நிச்சயமாக** (*niccayamāka*) — "certainly".

Sanskrit *niścaya*, 'a settled thing', plus *-āka*, the ending Tamil adds when a word is to describe how something is done. *niccayam* on its own is the certainty; *niccayamāka* is doing the thing certainly.

That same *-āka* is inside *nalamāka*, from the answer about being well, so the shape is already in your ear.
