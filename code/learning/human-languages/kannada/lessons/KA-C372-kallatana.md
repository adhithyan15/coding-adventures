# ಕಳ್ಳತನ (kaḷḷatana) — theft

## You'll want to know: ಕಳ್ಳತನ
<!-- hl-knowledge: introduces=[KA-LEX-C372-VANAVASA372-05]; assesses=[] -->

**ಕಳ್ಳತನ** — *kaḷḷatana* — "theft".

> ಊರಿನಲ್ಲಿ ಕಳ್ಳತನ ಹೆಚ್ಚಾದಾಗ ಪೊಲೀಸರು ಗಸ್ತು ಶುರು ಮಾಡಿದರು.
>
> *ūrinalli kaḷḷatana heccādāga polīsaru gastu śuru māḍidaru.*
>
> When thefts increased in the town, the police began patrols.

ಕಳ್ಳ, a thief, with -ತನ, "-ness, the doing of": ಕಳ್ಳತನ ಮಾಡು, to steal.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಕಳ್ಳತನ** (*kaḷḷatana*) is a native Dravidian noun: *kaḷḷa*, "a thief" (DEDR 1372), with the abstract ending -*tana*.
