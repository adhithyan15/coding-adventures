# Choose the first three answers

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MR-A1-FORM-LABEL-NAAV, MR-A1-FORM-LABEL-SHAHAR, MR-A1-FORM-LABEL-BHASHA] -->

Read three known labels: **नाव**, **शहर**, **भाषा**. Today you choose what each
row asks for; you do not yet write the whole form.

## Guided practice — one profile, three choices
<!-- hl-knowledge: introduces=[]; assesses=[MR-A1-FORM-LABEL-NAAV, MR-A1-FORM-LABEL-SHAHAR, MR-A1-FORM-LABEL-BHASHA] -->

Profile A says in the support language: **name Arun; city Pune; language
Marathi**. Point to the matching detail when each Marathi label is shown. Keep
the profile card open. There is no Marathi answer bank to copy.
