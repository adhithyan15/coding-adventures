## You'll want to know: le piéton
<!-- hl-knowledge: introduces=[FR-LEX-C411-ACCIDENT-03]; assesses=[] -->

**le piéton** — "the pedestrian".

> Les voitures s'arrêtent pour laisser passer les piétons.
>
> *The cars stop to let the pedestrians cross.*

*Une rue piétonne* — a pedestrian street.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*piéton* is built on *pied* 'foot' (EtymDB), which is inherited from Latin *pēs* 'foot'.
