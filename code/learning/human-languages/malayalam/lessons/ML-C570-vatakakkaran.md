# വാടകക്കാരൻ (vāṭakakkāran) — a tenant

## You'll want to know: വാടകക്കാരൻ
<!-- hl-knowledge: introduces=[ML-LEX-C570-VITTUPAKARANAM570-03]; assesses=[] -->

**വാടകക്കാരൻ** — *vāṭakakkāran* — "a tenant".

> മുകളിലെ നിലയിൽ ഒരു പുതിയ വാടകക്കാരൻ വന്നു.
>
> *mukaḷile nilayil oru putiya vāṭakakkāran vannu.*
>
> A new tenant has come to the upper floor.

വാടക rent + -ക്കാരൻ, one who pays it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**വാടകക്കാരൻ** (*vāṭakakkāran*) is built from വാടക, "rent", usually traced to Sanskrit *bhāṭaka*, "hire" (Monier-Williams), with the ending -ക്കാരൻ.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
