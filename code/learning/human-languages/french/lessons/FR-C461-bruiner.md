## You'll want to know: bruiner
<!-- hl-knowledge: introduces=[FR-LEX-C461-BRUINE-02]; assesses=[] -->

**bruiner** — "to drizzle".

> Il bruine, mais nous sortons quand même.
>
> *It is drizzling, but we are going out anyway.*

Only with *il*: *il bruine*.
