# దర్యాప్తు (daryāptu) — an investigation

[PAUSE 2s] Before the new one: say the Telugu for a police station, then the Telugu for a case.

## You'll want to know: దర్యాప్తు
<!-- hl-knowledge: introduces=[TE-LEX-C333-KESU333-03]; assesses=[] -->

**దర్యాప్తు** — *daryāptu* — "an investigation".

> పోలీసులు ఆ సంఘటనపై దర్యాప్తు మొదలుపెట్టారు.
>
> *pōlīsulu ā saṅghaṭanapai daryāptu modalupeṭṭāru.*
>
> The police began an investigation into the incident.

దర్యాప్తు చేయు, to investigate.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**దర్యాప్తు** (*daryāptu*) is a loan from Persian *daryāft*, "finding out, inquiry".
