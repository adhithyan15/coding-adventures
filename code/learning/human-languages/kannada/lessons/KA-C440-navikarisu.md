# ನವೀಕರಿಸು (navīkarisu) — to renew

## You'll want to know: ನವೀಕರಿಸು
<!-- hl-knowledge: introduces=[KA-LEX-C440-PARAVANAGI440-02]; assesses=[] -->

**ನವೀಕರಿಸು** — *navīkarisu* — "to renew".

> ನಾನು ನನ್ನ ಪಾಸ್ಪೋರ್ಟನ್ನು ಕಳೆದ ತಿಂಗಳು ನವೀಕರಿಸಿದೆ.
>
> *nānu nanna pāspōrṭannu kaḷeda tiṅgaḷu navīkariside.*
>
> I renewed my passport last month.

Past (I …): ನವೀಕರಿಸಿದೆ, *navīkariside*.

What is renewed takes -ಅನ್ನು: ಪರವಾನಗಿಯನ್ನು ನವೀಕರಿಸು.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ನವೀಕರಿಸು** (*navīkarisu*) is built from Sanskrit *navīkaraṇa*, "making new, renewing" (Monier-Williams), on *nava*, "new" (CDIAL 6983), with the verb ending -*isu*.
