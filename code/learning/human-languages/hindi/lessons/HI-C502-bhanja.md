# भांजा (bhāñjā) — a nephew (a sister's son)

## You'll want to know: भांजा
<!-- hl-knowledge: introduces=[HI-LEX-C502-POTA502-03]; assesses=[] -->

**भांजा** — *bhāñjā* — "a nephew (a sister's son)".

> मेरा भांजा अगले साल स्कूल जाएगा।
>
> *merā bhāñjā agle sāl skūl jāegā.*
>
> My nephew will start school next year.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**भांजा** (*bhāñjā*) is a tadbhava: CDIAL lists Hindi *bhā̃jā*, "sister's son", under Sanskrit *bhāginēya*, "sister's son" (CDIAL 9433), from *bhaginī*, "sister". A brother's son is *bhatījā*.
