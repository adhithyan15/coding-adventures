# રાતવાસો (rātvāso) — a night's stay

## You'll want to know: રાતવાસો
<!-- hl-knowledge: introduces=[GU-LEX-C412-CAMP412-03]; assesses=[] -->

**રાતવાસો** — *rātvāso* — "a night's stay".

> અમે ધર્મશાળામાં રાતવાસો કર્યો.
>
> *ame dharmaśāḷāmā̃ rātvāso karyo.*
>
> We stayed the night at the rest house.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**રાતવાસો** (*rātvāso*) is built from રાત, night, and વાસો, a stay, from Sanskrit *vāsa*, "a dwelling, an abode" (Monier-Williams): a roof for one night.
