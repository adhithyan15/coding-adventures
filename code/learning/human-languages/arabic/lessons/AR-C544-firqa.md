## You'll want to know: فرقة
<!-- hl-knowledge: introduces=[AR-LEX-C544-ALAT544-05]; assesses=[] -->

**فرقة** — *firqa* — "a band, a troupe".

> غنت فرقة موسيقية في الحفلة.
>
> *ghannat firqa mūsīqiyya fī al-ḥafla.*
>
> A band sang at the party.

Plural: فرق, *firaq*.

It names any group: فرقة مسرحية, a theatre troupe.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**فرقة** (*firqa*) is built on the native Arabic root *f-r-q*, "to separate, to divide" (Lane). Farq, a difference, which you know, is from the same root: a firqa is a part set apart.
