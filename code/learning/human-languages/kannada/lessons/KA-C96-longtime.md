## You'll want to know: ತುಂಬಾ ದಿನ ಆಯ್ತು
<!-- hl-knowledge: introduces=[KA-LEX-C96-HELLO-03]; assesses=[] -->

**ತುಂಬಾ ದಿನ ಆಯ್ತು** (*tumbā dina āytu*) — "it's been a long time", literally
"many days have happened": **ತುಂಬಾ**, "very, many"; **ದಿನ**, "day".
