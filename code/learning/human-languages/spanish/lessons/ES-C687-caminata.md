## You'll want to know: la caminata
<!-- hl-knowledge: introduces=[ES-LEX-C687-EXCURSION-02]; assesses=[] -->

**la caminata** — "the long walk, the hike".

> Fue una caminata de cinco horas.
>
> *It was a five-hour hike.*

*Hacer una caminata* — to go for a long walk.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*caminata* is built on *caminar* "to walk", from *camino* "road", which came into Late Latin from Celtic.
