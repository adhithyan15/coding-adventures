## You'll want to know: کیلومتر
<!-- hl-knowledge: introduces=[FA-LEX-C446-JAHAT-03]; assesses=[] -->

**کیلومتر** (*kilometr*) — "a kilometre".

> تا شهر بعدی صد کیلومتر راه است.
>
> *Tâ shahr-e ba'di sad kilometr râh ast.*
>
> It is a hundred kilometres to the next town.

Speed is *kilometr dar sâ'at*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*kilometr* was borrowed from French *kilomètre* (EtymDB), which was built from Greek *khílioi* 'a thousand' and *métron* 'measure'.

## What you've built
