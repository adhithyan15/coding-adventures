# ജാഗ്രത (jāgrata) — vigilance; an alert

## You'll want to know: ജാഗ്രത
<!-- hl-knowledge: introduces=[ML-LEX-C511-PRAVACANAM511-02]; assesses=[] -->

**ജാഗ്രത** — *jāgrata* — "vigilance; an alert".

> മഴ കാരണം തീരദേശത്ത് ജാഗ്രത വേണം.
>
> *maḻa kāraṇaṁ tīradēśattŭ jāgrata vēṇaṁ.*
>
> Because of the rain, the coast must stay alert.

Weather offices give a ജാഗ്രതാ നിർദ്ദേശം, an alert notice.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ജാഗ്രത** (*jāgrata*) is borrowed from Sanskrit *jāgrat*, "being awake" (Monier-Williams).
