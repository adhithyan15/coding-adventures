## You'll want to know: विकल्पः
<!-- hl-knowledge: introduces=[SA-LEX-C371-VIKALPA371-01]; assesses=[] -->

**विकल्पः** — *vikalpaḥ* — "an option; an alternative".

> यदि धूमयानं न अस्ति, तर्हि लोकयानं विकल्पः अस्ति।
>
> *yadi dhūmayānaṃ na asti, tarhi lokayānaṃ vikalpaḥ asti.*
>
> If there is no train, the bus is an option.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**विकल्पः** (*vikalpaḥ*) is built on *vi*, "apart", and the root √kḷp, "to be fit, to arrange"; MW gives *vi-kalpa* "alternation, alternative, option" (MW).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
