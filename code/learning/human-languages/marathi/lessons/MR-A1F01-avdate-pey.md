# आवडते पेय — favorite drink

## Warm-up
<!-- hl-knowledge: introduces=[MR-A1-FORM-LABEL-AVDATE-PEY, MR-A1-FORM-AGREEMENT-NEUTER]; assesses=[] -->

The known drink is **चहा**. The label **आवडते पेय** means “favorite drink.”
**पेय** is neuter, so the describing word takes neuter **-ते**: **आवडते**.

## Writing — observe and trace one pair
<!-- hl-knowledge: introduces=[]; assesses=[MR-A1-FORM-LABEL-AVDATE-PEY, MR-A1-FORM-AGREEMENT-NEUTER] -->
<!-- hl-writing-stage: observe-trace -->

Trace **आवडते पेय: चहा** once. Box only the ending **-ते**. The next lesson will
change that ending for a feminine label; do not learn both today.
