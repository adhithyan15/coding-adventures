# കുറിപ്പടി (kuṟippaṭi) — a prescription

## You'll want to know: കുറിപ്പടി
<!-- hl-knowledge: introduces=[ML-LEX-C533-VAKSIN533-03]; assesses=[] -->

**കുറിപ്പടി** — *kuṟippaṭi* — "a prescription".

> വൈദ്യൻ എഴുതിയ കുറിപ്പടിയുമായി ഞാൻ മരുന്നുകടയിൽ പോയി.
>
> *vaidyan eḻutiya kuṟippaṭiyumāyi ñān marunnukaṭayil pōyi.*
>
> I went to the pharmacy with the doctor's prescription.

Built on കുറിപ്പ്, a note, the word already familiar.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**കുറിപ്പടി** (*kuṟippaṭi*) is built on കുറിപ്പ്, "a note", a native word (DEDR 1847); how the ending -അടി joined it is not settled.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
