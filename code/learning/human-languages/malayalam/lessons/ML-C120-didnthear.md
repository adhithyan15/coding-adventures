# കേട്ടില്ല (kēṭṭilla) — I didn't hear

## You'll want to know: കേട്ടില്ല
<!-- hl-knowledge: introduces=[ML-LEX-C120-HELP-02]; assesses=[] -->

**കേട്ടില്ല** (*kēṭṭilla*) — "(I) didn't hear", **കേട്ടു**, "heard", with **ഇല്ല**,
"not". Follow it with **ഒന്നുകൂടി പറയൂ**.
