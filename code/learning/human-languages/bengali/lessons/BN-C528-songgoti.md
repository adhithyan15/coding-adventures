## You'll want to know: সঙ্গতি
<!-- hl-knowledge: introduces=[BN-LEX-C528-UPAY528-01]; assesses=[] -->

**সঙ্গতি** — *sônggôti* — "financial means".

> যদি সঙ্গতি থাকত, তাহলে আমরা একটা বড় বাড়ি কিনতাম।
>
> *Jôdi sônggôti thāktô, tāhôle āmrā ekṭā bôṛo bāṛi kintām.*
>
> If we had the means, we would buy a big house.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**সঙ্গতি** (*sônggôti*) is Sanskrit *saṃgati*, "coming together, meeting" (Monier-Williams); the sense "what one can afford" is Bengali's own.
