## Grammar Lens
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-SHURU-196, PA-LEX-KAMM-05, PA-LEX-KARNA-05, PA-GRAMMAR-NOUN-PLUS-KARNA-05] -->

> **ਕੰਮ ਸ਼ੁਰੂ ਕਰੋ** — *kamm shurū karo* — start the work

Keep the new noun whole between familiar **ਕੰਮ** and **ਕਰੋ**. Familiar **ਕਰੋ**
carries the polite command in the already-owned noun-plus-**ਕਰਨਾ** pattern.
Gill and Gleason describe such noun/adjective-plus-verb conjuncts as
conventional combinations: this chapter teaches only this one instruction,
not every possible combination, tense, or function. Source: Harjeet Singh Gill
and Henry A. Gleason, Jr., *A Reference Grammar of Punjabi* (1969), pp. 122 and
124, [conjunct verbs](https://pt.learnpunjabi.org/assets/A%20Reference%20Grammar_Final.pdf).
