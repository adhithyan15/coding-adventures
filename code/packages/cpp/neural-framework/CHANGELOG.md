# Changelog

## 0.1.0 — NN51 (in progress)

- Independent native C++17 dense forward/backpropagation, reproducible seeded
  initialization, full-batch MSE and transactional SGD with finite candidate loss.
- Copied typed/JSON checkpoints, strict shared V1 corpus, signed-zero/extreme
  serialization, closed errors and bounded architecture/batch/epoch counts.
- Native fresh/resume XOR command and full-state validation for each compiler's
  binary through steps 3001/3002; seven-native exchange remains separate.
- Shared ISO BUILD fronts, real allocation-failure sweep, multi-TU tests and
  self-contained CMake installation with a standalone consumer fixture.
