# அலட்சியம் (alaṭciyam) — negligence; indifference

## You'll want to know: அலட்சியம்
<!-- hl-knowledge: introduces=[TA-LEX-C471-KUNAM471-05]; assesses=[] -->

**அலட்சியம்** — *alaṭciyam* — "negligence; indifference".

> உடல்நலத்தில் அலட்சியம் கூடாது.
>
> *uṭalnalattil alaṭciyam kūṭātu.*
>
> One must not be careless about one’s health.

அலட்சியமாக, carelessly.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**அலட்சியம்** (*alaṭciyam*) is borrowed from Sanskrit *alakṣya*, "invisible, unnoticed" (CDIAL 698); Tamil writes *kṣ* as ட்ச.

## What you've built
