## You'll want to know: beschädigen
<!-- hl-knowledge: introduces=[GE-LEX-C295-PANNE-04]; assesses=[] -->

**beschädigen** — "to damage".

> Der Ball beschädigte das Fenster.
>
> *The ball damaged the window.*

Regular: *hat beschädigt*. Built on *der Schaden*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*beschädigen* is built on *Schaden* "damage", which is usually traced to Old High German *scado* "damage", from Proto-Germanic *skaþô* (EtymDB).
