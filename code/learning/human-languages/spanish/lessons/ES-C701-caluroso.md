## You'll want to know: caluroso
<!-- hl-knowledge: introduces=[ES-LEX-C701-CALOR-01]; assesses=[] -->

**caluroso** — "hot (weather); warm (welcome)".

> Fue un verano muy caluroso.
>
> *It was a very hot summer.*

*Un caluroso saludo* — a warm greeting.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*caluroso* is built on *calor* "heat", which is inherited from Latin *calor* (EtymDB).
