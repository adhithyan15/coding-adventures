# ९ — the tenth digit

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MW-LEX-THODU-01, MW-SCRIPT-DIGIT-SEVEN-01, MW-SCRIPT-DIGIT-EIGHT-01] -->

[PAUSE 18s] Say a little, then write the digits for seven and eight.

## Script — the tenth figure
<!-- hl-knowledge: introduces=[MW-SCRIPT-DIGIT-NINE-01]; assesses=[MW-SCRIPT-NO-NINE-01, MW-LEX-NO-NINE-01] -->

> **९** — nine — *no*

Like **३** and **६**, this one a Latin eye can very nearly guess, and unlike
**७** the guess is right.

With **९** the set is closed. Ten digit signs, taught across four lessons, and
the eye can now read any figure a stall prints as far as the words go.

Write **९** and **नो** side by side. The figure and the word for nine share
nothing at all — which is the whole reason the figures had to be taught
separately.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-DIGIT-NINE-01, MW-SCRIPT-NO-NINE-01, MW-SCRIPT-DIGIT-ZERO-01] -->
<!-- hl-writing-stage: observe-trace -->

Trace **९** three times. Then write the whole run **० १ २ ३ ४ ५ ६ ७ ८ ९** once,
slowly, saying the Marwadi word for each from one onward.
