# झडती घेणे (jhaḍtī gheṇe) — to search a place

## You'll want to know: झडती घेणे
<!-- hl-knowledge: introduces=[MR-LEX-C299-TAPAS299-01]; assesses=[] -->

**झडती घेणे** — *jhaḍtī gheṇe* — "to search a place".

> पोलिसांनी संशयिताच्या घराची झडती घेतली.
>
> *polisānnī saṁśayitācyā gharācī jhaḍtī ghetlī.*
>
> The police searched the suspect's house.

Past, with -ने (he …): त्याने झडती घेतली, *tyāne jhaḍtī ghetlī*.

What is searched takes -ची: घराची झडती घेणे. झडती is feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**झडती घेणे** (*jhaḍtī gheṇe*) joins *jhaḍtī*, 'a search', to *gheṇe*, 'to take'; the origin of *jhaḍtī* is not settled.
