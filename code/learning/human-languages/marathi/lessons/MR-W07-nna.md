# ण — the nasal with the tongue curled back

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[] -->

Every row in this alphabet ends with its own nasal. The curled row is no exception.

## Script
<!-- hl-knowledge: introduces=[MR-SCRIPT-NNA-01]; assesses=[MR-SCRIPT-DDA-01, MR-SCRIPT-TTA-01] -->

> ण

**ण** is *ṇa*: the tongue curled back, the air through the nose. Set it against
**न**, the dental nasal you learned in your first chapter, and the difference is
the same one you made a moment ago for *ta* and *ṭa*.

This is the single most useful letter in this chapter. It ends every Marathi
infinitive this book teaches — *bolṇe*, *khāṇe*, *jāṇe*, *sāṅgṇe* — so once it
is yours, the shape of "to do something" is readable.

## Writing — guided copy
<!-- hl-knowledge: introduces=[]; assesses=[MR-SCRIPT-NNA-01] -->
<!-- hl-writing-stage: guided-copy -->

Copy **ण** twice with the model visible. Then write **न** once beside it and say
both aloud, curling the tongue only for the first.
