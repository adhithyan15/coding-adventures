## You'll want to know: abusivo
<!-- hl-knowledge: introduces=[IT-LEX-C390-LEGALE-05]; assesses=[] -->

**abusivo** — "unauthorised, unlicensed".

> Questa casa è abusiva: non ha i permessi.
>
> *This house is unauthorised: it has no permits.*

*Un parcheggiatore abusivo* — an unlicensed parking attendant.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*abusivo* comes from Latin *abūsīvus* "misapplied, improper" (EtymDB), from *abūsus* "misuse", built on *abūtī* "to use up, to misuse" and *ūtī* "to use".
