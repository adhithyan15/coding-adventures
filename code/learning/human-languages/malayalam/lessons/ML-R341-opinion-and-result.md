# Review — what I think, and so

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C341-VICARIKKUKA-01, ML-LEX-C341-AIKYAM-01, ML-SCRIPT-C341-AI-01] -->

[PAUSE 2s] Say "to think, to suppose" and "unity". (*vicārikkuka*, *aikyaṁ*.) Write **ഐ** once
from memory.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C341-VICARIKKUKA-01, ML-GRAMMAR-C341-THINK-THAT-01, ML-GRAMMAR-C341-TONNUNNU-01, ML-LEX-C341-AIKYAM-01, ML-SCRIPT-C341-AI-01, ML-GRAMMAR-C341-SO-RESULT-01, ML-GRAMMAR-C341-ATHUKONDANU-01] -->

[PAUSE 2s each]
- [YOU SAY: "I thought he would come."]
- [YOU SAY: "I think this is good", first with *vicārikkunnu*, then with *karutunnu*]
- [YOU SAY: "It seems to me this is good."]
- [YOU SAY: "In my opinion, this is a good decision."]
- [YOU SAY: "There is real unity in our village."]
- [YOU SAY: "I had a fever. So I did not come." Then: "That is why I was late."]
- [YOU WRITE: **ഐക്യം**]

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C341-VICARIKKUKA-01, ML-GRAMMAR-C341-THINK-THAT-01, ML-GRAMMAR-C341-TONNUNNU-01, ML-LEX-C341-AIKYAM-01, ML-SCRIPT-C341-AI-01, ML-GRAMMAR-C341-SO-RESULT-01, ML-GRAMMAR-C341-ATHUKONDANU-01] -->

[PAUSE 3s] "I thought (wrongly) he would come"? (***avan varuṁ ennŭ ñān vicāriccu.***) The softest
"I think"? (***enikkŭ … ennŭ tōnnunnu.***) Reason first, then result: which word? (**അതുകൊണ്ട്**.)
"Unity"? (**ഐക്യം**, which opens with **ഐ**.)
