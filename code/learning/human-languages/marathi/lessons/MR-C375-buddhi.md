## You'll want to know: बुद्धी
<!-- hl-knowledge: introduces=[MR-LEX-C375-BUDDHI375-01]; assesses=[] -->

**बुद्धी** — *buddhī* — "intellect; intelligence".

> हा खेळ बुद्धीचा आहे, ताकदीचा नाही.
>
> *hā kheḷ buddhīcā āhe, tākdīcā nāhī.*
>
> This game is one of brains, not strength.

Feminine.

बुद्धीचा खेळ, a game of wits.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**बुद्धी** (*buddhī*) is a tatsama, taken from Sanskrit *buddhi*, "intelligence, discernment" (CDIAL 9277).
