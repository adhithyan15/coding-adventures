# পরোপকারী (pôropôkārī) — helpful to others; kind-hearted

## You'll want to know: পরোপকারী
<!-- hl-knowledge: introduces=[BN-LEX-C457-UDAR457-04]; assesses=[] -->

**পরোপকারী** — *pôropôkārī* — "helpful to others; kind-hearted".

> পরোপকারী ছেলেটা সবসময় বুড়োদের সাহায্য করে।
>
> *pôropôkārī chheleṭā sôbsômôy buṛoder sāhājjô kôre.*
>
> The kind-hearted boy always helps old people.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**পরোপকারী** (*pôropôkārī*) is a tatsama, Sanskrit *paropakārin*, "assisting others, beneficent" (Monier-Williams): *para* "another" with *upakāra* "help".
