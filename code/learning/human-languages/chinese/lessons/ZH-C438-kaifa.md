## You'll want to know: 开发
<!-- hl-knowledge: introduces=[ZH-LEX-C438-NORTH438-01]; assesses=[] -->

**开发** — *kāifā* — "to open up land for use".

> **这个山区还没有开发** *zhège shānqū hái méiyǒu kāifā* — This mountain area hasn't been developed yet.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**开发** (*kāifā*) is built from 开 'to open' and 发 'to set going', both inherited from Middle Chinese, *khoj* and *pjot* (Guangyun, in Baxter's transcription), which glosses the second 'to start' and 'to raise'.
