# ج (jīm) — the letter that opens جی

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[UR-SCRIPT-C34-TE-01, UR-SCRIPT-C34-TTE-01] -->

[PAUSE 2s] Before the new one: write ت and ٹ once each, and name them.

[PAUSE 2s] Now say **جی ہاں** (*jī hā̃*), "yes".
You have read it for a long time. This lesson takes one letter out of it and puts
it in your hand.

## Script you'll notice: ج
<!-- hl-knowledge: introduces=[UR-SCRIPT-C35-JIM-01]; assesses=[] -->

**ج** — *jīm*, the sound *j*.

It opens **جی** (*jī*) in **جی ہاں**, "yes", from the first chapter. A hooked head,
a deep bowl, and **one dot below**.

## Writing: ج
<!-- hl-knowledge: introduces=[]; assesses=[UR-SCRIPT-C35-JIM-01] -->

- **1.** start here: place the dot below
- **2.** lift, then sweep left through the pointed hooked head
- **3.** without lifting, continue down and around the bowl — and only now lift

**Pen lifts: 1.**

> Stroke order is one attested teaching order; hands and teachers vary.
> Source: Zer o Zabar, Te, mim, jim, che, and more diacritics, independent ج handwriting animation and flat-head insight (Northwestern University Libraries Open Textbook, 2026).
