## You'll want to know: قطعة

**قطعة** — *qiṭʿa* — "a piece".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**قطعة** (*qiṭʿa*) is built on the native Arabic root *q-ṭ-ʿ*, "to cut, to sever" (Lane). *Qiṭʿa* is a cut piece.
