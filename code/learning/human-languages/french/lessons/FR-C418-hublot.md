## You'll want to know: le hublot
<!-- hl-knowledge: introduces=[FR-LEX-C418-BORD-04]; assesses=[] -->

**le hublot** — "the porthole, the window (of a plane or ship)".

> Ma fille veut toujours une place côté hublot.
>
> *My daughter always wants a window seat.*

*Côté hublot* — window seat.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

The origin of *hublot* is not settled, and EtymDB does not list it. It was first a sailors' word.
