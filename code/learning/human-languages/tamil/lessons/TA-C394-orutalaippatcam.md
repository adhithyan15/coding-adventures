# ஒருதலைப்பட்சம் (orutalaippaṭcam) — one-sidedness; bias

## You'll want to know: ஒருதலைப்பட்சம்
<!-- hl-knowledge: introduces=[TA-LEX-C394-ORUTALAIPPAT394-01]; assesses=[] -->

**ஒருதலைப்பட்சம்** — *orutalaippaṭcam* — "one-sidedness; bias".

> தீர்ப்பு ஒருதலைப்பட்சமாக இருந்தால் மக்கள் ஏற்க மாட்டார்கள்.
>
> *tīrppu orutalaippaṭcamāka iruntāl makkaḷ ēṟka māṭṭārkaḷ.*
>
> If the verdict is one-sided, people will not accept it.

ஒருதலைப்பட்சமாக, one-sidedly: taking only one side.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ஒருதலைப்பட்சம்** (*orutalaippaṭcam*) is built from native *oru*, "one" (DEDR 990), and *talai*, "head, end" (DEDR 3103), with *paṭcam*, "side", borrowed from Sanskrit *pakṣa* (Monier-Williams): taking one end only.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
