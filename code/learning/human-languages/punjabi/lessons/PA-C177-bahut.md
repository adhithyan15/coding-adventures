# ਬਹੁਤ — turn good into very good

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-GRAMMAR-ADJ-GENDER-AGREEMENT-01, PA-GRAMMAR-ADJ-PRENOMINAL-01, PA-LEX-C55-FAMILY55-03, PA-LEX-C55-FAMILY55-04] -->

[PAUSE 2s] Say **ਚੰਗਾ ਮੁੰਡਾ**, then **ਚੰਗੀ ਕੁੜੀ**. Hear the one ending that
changes and the adjective-before-noun order that stays.

## You'll want to know: ਬਹੁਤ
<!-- hl-knowledge: introduces=[PA-ADV-BAHUT-DEGREE-01]; assesses=[PA-GRAMMAR-ADJ-GENDER-AGREEMENT-01, PA-GRAMMAR-ADJ-PRENOMINAL-01, PA-LEX-CHANGA] -->

> **ਬਹੁਤ** — *bahut* — **very**

Put **ਬਹੁਤ** before the adjective. It increases the degree; it does not take
the adjective's agreement ending:

> **ਬਹੁਤ ਚੰਗਾ ਮੁੰਡਾ** — *bahut changā muṇḍā* — very good boy
>
> **ਬਹੁਤ ਚੰਗੀ ਕੁੜੀ** — *bahut changī kuṛī* — very good girl

The order is degree word + agreeing adjective + noun. Only **ਚੰਗਾ / ਚੰਗੀ**
changes with this noun pair; **ਬਹੁਤ** stays **ਬਹੁਤ**.
