# ટીકા (ṭīkā) — criticism

## You'll want to know: ટીકા
<!-- hl-knowledge: introduces=[GU-LEX-C361-TIKA361-02]; assesses=[] -->

**ટીકા** — *ṭīkā* — "criticism".

> જનતાએ સરકારની નવી નીતિની ટીકા કરી.
>
> *jantāe sarkārnī navī nītinī ṭīkā karī.*
>
> The public criticised the government's new policy.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ટીકા** (*ṭīkā*) is a tatsama, borrowed from Sanskrit *ṭīkā*, "a commentary" (Monier-Williams); Gujarati has moved it from comment to criticism.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
