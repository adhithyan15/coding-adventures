# नाम — the first A1 form label

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[HI-CONCEPT-C02-NAAM-01, HI-CONCEPT-W04-WRITE-MERA-NAAM-01] -->

Read the known word **नाम**. Say what it means, then write it once from the
word you already know.

## You'll want to know first — read the label
<!-- hl-knowledge: introduces=[HI-FORM-LABEL-NAME-01]; assesses=[HI-CONCEPT-C02-NAAM-01] -->

> **नाम: __________**

On a form, **नाम** asks for a name. The colon belongs to the form; it is not a
Devanagari letter. Point to the label, then point to the empty answer line.

## Writing — one bounded copy
<!-- hl-knowledge: introduces=[]; assesses=[HI-FORM-LABEL-NAME-01] -->
<!-- hl-writing-stage: guided-copy -->

Copy only **नाम** once. Check **न**, then **ा**, then **म**, and draw each
head-line after its letter shape. Do not add a value yet. This visible copy is
supported script practice, not independent form writing.
