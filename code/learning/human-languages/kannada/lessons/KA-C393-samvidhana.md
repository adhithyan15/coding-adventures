# ಸಂವಿಧಾನ (saṃvidhāna) — a constitution

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C393-SAMSATTU393-01, KA-LEX-C393-SAMSATTU393-02] -->

[PAUSE 2s] Before the new one: say the Kannada for a parliament, then the Kannada for a minister.

## You'll want to know: ಸಂವಿಧಾನ
<!-- hl-knowledge: introduces=[KA-LEX-C393-SAMSATTU393-03]; assesses=[] -->

**ಸಂವಿಧಾನ** — *saṃvidhāna* — "a constitution".

> ಸಂವಿಧಾನ ಎಲ್ಲರಿಗೂ ಸಮಾನ ಹಕ್ಕು ಕೊಡುತ್ತದೆ.
>
> *saṃvidhāna ellarigū samāna hakku koḍuttade.*
>
> The constitution gives everyone equal rights.

ಸಂವಿಧಾನಬದ್ಧ, constitutional.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಸಂವಿಧಾನ** (*saṃvidhāna*) is borrowed from Sanskrit *saṃvidhāna*, "arrangement, management" (Monier-Williams).
