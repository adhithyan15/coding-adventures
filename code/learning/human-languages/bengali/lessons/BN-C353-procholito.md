## You'll want to know: প্রচলিত
<!-- hl-knowledge: introduces=[BN-LEX-C353-RITI353-04]; assesses=[] -->

**প্রচলিত** — *prôchôlitô* — "current; in common use".

> এই শব্দটা এখন আর প্রচলিত নয়।
>
> *ei shôbdôṭā ekhôn ār prôchôlitô nôy.*
>
> This word is no longer in use.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**প্রচলিত** (*prôchôlitô*) is Sanskrit *pracalita*, set going and so current or customary (Monier-Williams): what is in use now.
