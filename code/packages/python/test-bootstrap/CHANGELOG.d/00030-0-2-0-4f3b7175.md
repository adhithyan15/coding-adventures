## 0.2.0 - pbt-v1 conformance

Upgrades `pbt.py` in place to the VER05c Python PBT lane (spec:
`code/specs/VER05c-python-pbt-engine.md`). There is one Python engine; no
separate `python/pbt` package exists.

### Added
- Conformance to all 25 shared `pbt-v1` cases (`code/specs/fixtures/pbt-v1/cases.json`)
  with exact generator outputs, shrink minimals and shrink step counts.
  `pbt_corpus.run_pbt_corpus(cases)` is the production runner; `tests/test_pbt_corpus.py`
  loads the committed fixture, asserts 25 cases evaluated, and carries negative
  controls for every op (a corrupted expectation, a truncated list, an unknown
  op or an engine sabotage is reported as a problem, never skipped).
- Corpus entry points `gen_primitive`, `gen_bounded`, `gen_bytes_corpus`,
  `simulate_replay`, `sub_seed`; generators `gen_i128`, `gen_constant`,
  `gen_tuple`, `frequency`, `one_of`, `gen_bounded_int` (VER05 7.2 span routing,
  k-word rejection sampling above 2^64).
- Conforming shrinkers `shrink_int(initial, target, min, max, prop, max_steps)`,
  `shrink_list`, `shrink_bytes` returning `(minimal, steps)`.
- `check_property` / `assert_property` with VER05 7.1 verdict honesty (zero
  cases is `property-exhausted`; the shrunk witness is re-verified; generator
  error is exhausted; property exception is panic), the closed failure
  vocabulary (`is_pbt_failure_id`) and CI redaction (`PbtOptions.ci`,
  `ci_from_environ`). Redaction is the default: the package is capability-free
  and cannot read `CI` itself.
- `ExhaustedError` (a `RuntimeError`) for filter exhaustion.

### Changed
- BREAKING: `shrink_int`, `shrink_list`, `shrink_bytes` no longer return
  proposal iterators; `shrink_text` and `shrink_value` are removed. Nothing else
  in the repository imported them. Shrinking is now attached to each `Gen`
  (integrated), so `for_all` never shrinks outside a generator's bounds, and
  `shrink_steps` counts accepted moves.
- Fixed-length generators and single-arm choices now consume one stream word
  (matching Rust and the reference); `for_all` streams for `gen_int(k, k)` shift.
- `Gen.filter` exhaustion raises `ExhaustedError`.
- BUILD and BUILD_windows enforce `--cov-fail-under=95` explicitly.

### Fixed
- `SplitMix64.bounded(n)` never rejected a draw because `(-n) % n` is 0 in
  Python; the threshold is now `(2^64 - n) % n` (VER05 2.2).
- `parse_tfv` accepted uppercase and odd-length hex in `X`/`S`/`D` bodies;
  TF01 requires even-length lowercase.
