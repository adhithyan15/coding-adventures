## You'll want to know: la denuncia
<!-- hl-knowledge: introduces=[ES-LEX-C625-LEGAL-05]; assesses=[] -->

**la denuncia** — "the report, the complaint".

> Puse una denuncia en la policía.
>
> *I made a report to the police.*

*Poner una denuncia* — to file a report.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*denuncia* is built on *denunciar*, a learned borrowing from Latin *denuntiare* 'to announce', from *nuntius* 'messenger' (EtymDB).
