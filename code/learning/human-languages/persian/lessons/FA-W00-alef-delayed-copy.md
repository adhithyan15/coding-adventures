# ا — one stroke with the model covered

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[FA-SCRIPT-ALEF-01] -->

Look at **ا** once and say the long *â*. Then cover it.

## Writing — delayed copy
<!-- hl-knowledge: introduces=[]; assesses=[FA-LEX-SALAM-01, FA-SCRIPT-RTL-01, FA-SCRIPT-ALEF-01] -->
<!-- hl-writing-stage: delayed-copy -->

With the model covered, wait ten seconds, then draw **ا** once from memory.

Ten seconds is long enough that your hand cannot be tracing a shape it can still
see, and short enough that a stroke you made a minute ago is still there.

Only after the stroke is finished, uncover the model and compare.

## Wrap-up recall
<!-- hl-knowledge: introduces=[]; assesses=[FA-SCRIPT-ALEF-01] -->

One stroke is the easiest shape in the script to get right and the easiest to
get **backwards**, and the page cannot tell you which you did.

So the question to ask yourself is not whether it looks right. It is: which end
did your pen start from? Alef travels **top to bottom**. A stroke drawn upward
lands in the same place and behaves differently the moment it has neighbours,
which is why a single line is worth this much attention now rather than later.
