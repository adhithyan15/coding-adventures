# (three letters) — From the letter to the word — a first pass

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[HI-SCRIPT-C128-I-SIGN-01, HI-SCRIPT-C128-I-01] -->

[PAUSE 3s] Say **शुक्रिया** (*shukriyā*), then write the letter it gave you.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[HI-SCRIPT-C128-I-SIGN-01, HI-SCRIPT-C128-I-01, HI-SCRIPT-C128-NYA-01] -->

| letter | name | the word it came from |
|---|---|---|
| ◌ि | *i kī mātrā* | **शुक्रिया** *shukriyā* |
| इ | *i* | **दिखाइए** *dikhāie* |
| ञ | *ña* | **संज्ञा** *saṁjñā* |

[PAUSE 2s each]
- [YOU WRITE: each letter in the table from memory, then check it]
- [YOU SAY: the word each one came from]
- [YOU READ: each word in the table aloud, and point at its letter]

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[HI-SCRIPT-C128-I-SIGN-01, HI-SCRIPT-C128-I-01, HI-SCRIPT-C128-NYA-01] -->

[PAUSE 3s] Which word did each letter come from? (**◌ि** from **शुक्रिया**; **इ** from **दिखाइए**; **ञ** from **संज्ञा**.)
