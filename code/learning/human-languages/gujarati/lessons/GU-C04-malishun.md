# મળીશું (maḷīshũ) — "(we) will meet"

## Warm-up

[PAUSE 2s] A future-tense verb — the other half of "see you again."

## The letters in this word

**મ** (*ma*) + **ળી** (*ḷī*, with the retroflex **ળ** *ḷ*) + **શું** (*shũ*) →
**મળીશું** (*maḷīshũ*).

## The word, taken apart

**મળીશું** (*maḷīshũ*, "we will meet") is the future of **મળવું** (*maḷvũ*, "to
meet"), from Sanskrit **મિલ્** (*mil-*, "to join, unite") — the same root as Hindi
*milnā* and Punjabi *milṇā*. Note the retroflex **ળ** (*ḷ*): Gujarati keeps this
extra letter — like Marathi and the Dravidian south, and unlike Hindi. The ending
**-શું** (*-shũ*) is the "we will" future.

## Grammar Lens: the future is an ending

Gujarati marks the future with an ending on the stem: *maḷ-* ("meet") + *-īshũ*
("we will") → *maḷīshũ*. No helper-word like English "will."
