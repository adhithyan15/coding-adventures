# ખૂટવું (khūṭvũ) — to run out

## You'll want to know: ખૂટવું
<!-- hl-knowledge: introduces=[GU-LEX-C189-ORDER189-03]; assesses=[] -->

**ખૂટવું** — *khūṭvũ* — "to run out".

> **દુકાનમાં દૂધ ખૂટ્યું.** — *dukānmā̃ dūdh khūṭyũ* — "The shop has run out of milk."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ખૂટવું** (*khūṭvũ*) is a tadbhava. CDIAL lists it, glossed "to be exhausted", under *\*khuṭṭa*, "defective", a reconstructed form (CDIAL 3895).
