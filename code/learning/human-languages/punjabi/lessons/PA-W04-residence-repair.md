# Repair one residence-field difference

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-RESIDENCE-CITY-01, PA-FORM-RESIDENCE-SPACING-01] -->

Compare **ਰਿਹਾਇਸ਼:ਸ਼ਹਿਰ** with **ਰਿਹਾਇਸ਼: ਸ਼ਹਿਰ**. The letters match; one boundary differs.

## Writing — one repair pass
<!-- hl-knowledge: introduces=[PA-FORM-RESIDENCE-REPAIR-01]; assesses=[PA-FORM-RESIDENCE-CITY-01, PA-FORM-RESIDENCE-SPACING-01] -->

Rewrite the first line with a clear space after the colon. Leave every letter unchanged.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-RESIDENCE-REPAIR-01] -->

Name the repaired dimension: selection, spelling, spacing, or placement. Stop after one repair.
