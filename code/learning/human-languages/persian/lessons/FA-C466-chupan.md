## You'll want to know: چوپان
<!-- hl-knowledge: introduces=[FA-LEX-C466-CHUPAN-02]; assesses=[] -->

**چوپان** (*chupân*) — "a shepherd".

> چوپان گوسفندها را به کوه برد.
>
> *Chupân gusfand-hâ râ be kuh bord.*
>
> The shepherd took the sheep to the mountain.

Turkish *çoban* is the same word.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*chupân* is a native word, which EtymDB lists without older forms; it is usually traced to Middle Persian *šubān* 'shepherd'.
