## You'll want to know: abmessen
<!-- hl-knowledge: introduces=[GE-LEX-C322-ZUTAT-04]; assesses=[] -->

**abmessen** — "to measure out".

> Sie maß das Mehl genau ab.
>
> *She measured out the flour exactly.*

Separable, strong: *misst ab*, *maß ab*, *hat abgemessen*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*abmessen* is built on *messen* "to measure", from Old High German *mezzen*, Proto-Germanic *metaną* (EtymDB), with *ab*.
