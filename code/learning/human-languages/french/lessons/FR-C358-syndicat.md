## You'll want to know: le syndicat
<!-- hl-knowledge: introduces=[FR-LEX-C358-GREVE-01]; assesses=[] -->

**le syndicat** — "the trade union".

> Mon père travaille pour un syndicat.
>
> *My father works for a trade union.*

*Le syndicat d'initiative* is an old name for a tourist office.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*syndicat* is built from *syndic* "representative" and *-at* (EtymDB). *syndic* comes from Late Latin *syndicus* "delegate of a body", from Greek *sýndikos* "advocate".
