## You'll want to know: das Benzin
<!-- hl-knowledge: introduces=[GE-LEX-C402-TANKEN-03]; assesses=[] -->

**das Benzin** — "petrol (US: gas)".

> In den Ferien ist das Benzin wieder teurer.
>
> *In the holidays petrol is more expensive again.*

No plural in everyday use. *Bleifrei* — unleaded.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*Benzin* is built on *Benzoe* 'benzoin', a sweet-smelling resin, with the chemist's ending *-in* (EtymDB). The name of the resin is usually traced to Arabic.
