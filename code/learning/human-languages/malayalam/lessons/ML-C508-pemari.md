# പേമാരി (pēmāri) — a downpour; torrential rain

## You'll want to know: പേമാരി
<!-- hl-knowledge: introduces=[ML-LEX-C508-CARRAL508-02]; assesses=[] -->

**പേമാരി** — *pēmāri* — "a downpour; torrential rain".

> രാത്രി മുഴുവൻ പേമാരി ആയിരുന്നു.
>
> *rātri muḻuvan pēmāri āyirunnu.*
>
> There was torrential rain all night.

Stronger than മഴ: the rain of a storm.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**പേമാരി** (*pēmāri*) is a Malayalam word for heavy rain whose second part is മാരി, heavy rain (DEDR 4819, which compares Sanskrit *māri*, rain); the origin of the first part is not settled.
