# അതുതന്നെ (atutanne) — that very one, the same

## Warm-up

[PAUSE 2s] Before the new one: say the Malayalam for nothing, then the Malayalam for oh no.

## You'll want to know: അതുതന്നെ
<!-- hl-knowledge: introduces=[ML-LEX-C122-REPLIES-04]; assesses=[] -->

**അതുതന്നെ** (*atutanne*) — "that very one, exactly that": **അത്** (*atŭ*), "that", with
**തന്നെ**, "itself".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

That, made emphatic.
