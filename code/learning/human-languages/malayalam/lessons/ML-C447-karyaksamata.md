# കാര്യക്ഷമത (kāryakṣamata) — efficiency

<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C447-NETTAM447-03, ML-LEX-C447-NETTAM447-04] -->

## You'll want to know: കാര്യക്ഷമത
<!-- hl-knowledge: introduces=[ML-LEX-C447-NETTAM447-05]; assesses=[] -->

**കാര്യക്ഷമത** — *kāryakṣamata* — "efficiency".

> പുതിയ മാനേജർ ഓഫീസിന്റെ കാര്യക്ഷമത കൂട്ടി.
>
> *putiya mānējar ōphīsinṟe kāryakṣamata kūṭṭi.*
>
> The new manager raised the office's efficiency.

The adjective is കാര്യക്ഷമമായ, efficient.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**കാര്യക്ഷമത** (*kāryakṣamata*) is a learned compound built from Sanskrit *kārya*, "business, work" (CDIAL 3078), and *kṣamatā*, "ability, fitness" (Monier-Williams): fitness for the work.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
