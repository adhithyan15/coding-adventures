# वाजिब (vājib) — reasonable, fair (of a price, a demand)

## You'll want to know: वाजिब
<!-- hl-knowledge: introduces=[HI-LEX-C366-VAJIB366-01]; assesses=[] -->

**वाजिब** — *vājib* — "reasonable, fair (of a price, a demand)".

> यह दाम वाजिब है।
>
> *yah dām vājib hai.*
>
> This price is reasonable.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**वाजिब** (*vājib*) is usually traced to Arabic *wājib*, "due, necessary", which reached Hindi through Persian.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
