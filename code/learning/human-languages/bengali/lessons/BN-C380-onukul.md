## You'll want to know: অনুকূল
<!-- hl-knowledge: introduces=[BN-LEX-C380-OPOJUKTO380-01]; assesses=[] -->

**অনুকূল** — *ônukūl* — "favourable".

> আবহাওয়া অনুকূল হলে আমরা কাল নৌকায় যাব।
>
> *ābôhāoyā ônukūl hôle āmrā kāl noukāy jābô.*
>
> If the weather is favourable, we'll go by boat tomorrow.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**অনুকূল** (*ônukūl*) is Sanskrit *anukūla*, 'along the bank', and so going with you, favourable (Monier-Williams).
