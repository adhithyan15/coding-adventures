# சம்பவம் (campavam) — an incident

## You'll want to know: சம்பவம்
<!-- hl-knowledge: introduces=[TA-LEX-C294-NIKAZHVU294-02]; assesses=[] -->

**சம்பவம்** — *campavam* — "an incident".

> நேற்று இரவு எங்கள் தெருவில் ஒரு சம்பவம் நடந்தது.
>
> *nēṟṟu iravu eṅkaḷ teruvil oru campavam naṭantatu.*
>
> Last night an incident happened on our street.

Plural: சம்பவங்கள், *campavaṅkaḷ*.

A -அம் noun takes -அத்து- before an ending: சம்பவத்தை, சம்பவத்தில்.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**சம்பவம்** (*campavam*) is borrowed from Sanskrit *sambhava*, "coming into being, an occurrence" (Monier-Williams); the Sanskrit final -a becomes Tamil -அம், and bh is written ப.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
