# ब — one new consonant

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MW-LEX-BAAP-01, MW-LEX-MAA-01, MW-SCRIPT-PA-01, MW-SCRIPT-PACHHE-MILSOO-01] -->

[PAUSE 18s] Say father and mother from meaning cues. Write **पाछे मिलसू** once,
then familiar **प**; today's voiced sound gets a different sign.

## Script — one sign
<!-- hl-knowledge: introduces=[MW-SCRIPT-BA-01]; assesses=[] -->

> **ब** — *ba*

Keep the model visible. Trace the lower turn, rise to the upright, and add the
headline. Say *ba* after the hand stops.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-BA-01, MW-LEX-BAAP-01] -->

Copy **ब** once. Cover it, wait five seconds, and write it once. Then say the
family word *bāp* that this sign will begin.
