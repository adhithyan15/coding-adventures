## You'll want to know: 名画
<!-- hl-knowledge: introduces=[ZH-LEX-C502-PAINT502-04]; assesses=[] -->

**名画** — *mínghuà* — "famous painting".

> **这些名画我都看过** *zhèxiē mínghuà wǒ dōu kàn guo* — I've seen all these famous paintings.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**名画** (*mínghuà*) is built from 名 'a name' and 画 'a painting', both inherited from Middle Chinese, *mjieng* and *hweaH* (Guangyun, in Baxter's transcription), which glosses the first 'a name' and 'a title'.
