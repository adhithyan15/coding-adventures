# குறுக்கீடு (kuṟukkīṭu) — an interruption; an interference

## You'll want to know: குறுக்கீடு
<!-- hl-knowledge: introduces=[TA-LEX-C546-THADANGAL546-03]; assesses=[] -->

**குறுக்கீடு** — *kuṟukkīṭu* — "an interruption; an interference".

> பேச்சின் நடுவில் யாரும் குறுக்கீடு செய்யவில்லை.
>
> *pēcciṉ naṭuvil yārum kuṟukkīṭu ceyyavillai.*
>
> Nobody interrupted in the middle of the speech.

With செய் (*cey*) it becomes a verb: குறுக்கீடு செய், to interrupt.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**குறுக்கீடு** (*kuṟukkīṭu*) is a native compound: குறுக்கு (*kuṟukku*), "across, crosswise", from குறு, "short" (DEDR 1851), with the noun ending *-īṭu*: something put across the way.
