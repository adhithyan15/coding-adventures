# હા — look, hide, write, compare

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[GU-SCRIPT-HA-01, GU-SCRIPT-AA-MATRA-01] -->

Look at **હા** for five seconds. Point first to **હ**, then to **ા**. Do not
copy it yet.

## Writing — delayed copy
<!-- hl-knowledge: introduces=[]; assesses=[GU-CONCEPT-C01-HAANAA-01, GU-SCRIPT-HA-01, GU-SCRIPT-AA-MATRA-01] -->
<!-- hl-writing-stage: delayed-copy -->

1. cover **હા**
2. wait five seconds
3. write it once from memory
4. uncover the model and compare the two pieces

If one piece differs, circle it and repair only that place. Repair is part of
the exercise, not a failure.
