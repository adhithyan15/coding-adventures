## You'll want to know: জ্যোতিষী
<!-- hl-knowledge: introduces=[BN-LEX-C532-BHOBITOBBO532-05]; assesses=[] -->

**জ্যোতিষী** — *jyotishī* — "an astrologer".

> জ্যোতিষী আমার হাত দেখলেন।
>
> *Jyotishī āmār hāt dekhlen.*
>
> The astrologer read my palm.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**জ্যোতিষী** (*jyotishī*) is built on Sanskrit *jyotiṣa*, which Monier-Williams glosses as "an astronomer", with the ending *-ī*, "one who does it".
