# కుతూహలం (kutūhalaṁ) — curiosity

## You'll want to know: కుతూహలం
<!-- hl-knowledge: introduces=[TE-LEX-C510-GUNAM510-05]; assesses=[] -->

**కుతూహలం** — *kutūhalaṁ* — "curiosity".

> పిల్లలు కుతూహలంతో పెట్టె తెరిచారు.
>
> *pillalu kutūhalantō peṭṭe tericāru.*
>
> The children opened the box with curiosity.

కుతూహలంగా, curiously, eagerly.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**కుతూహలం** (*kutūhalaṁ*) is borrowed from Sanskrit *kutūhala*, "curiosity, interest in anything unusual" (Monier-Williams).
