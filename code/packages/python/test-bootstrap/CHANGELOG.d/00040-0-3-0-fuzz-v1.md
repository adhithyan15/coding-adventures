## 0.3.0 - fuzz-v1 conformance

Upgrades `fuzz.py` in place to the VER06d Python fuzz lane (spec:
`code/specs/VER06d-python-fuzz-engine.md`). There is one Python engine; no
separate `python/fuzz` package exists.

### Added
- Conformance to all 25 shared `fuzz-v1` cases (`code/specs/fixtures/fuzz-v1/cases.json`).
  `fuzz_corpus.run_fuzz_corpus(cases)` is the production runner;
  `tests/test_fuzz_corpus.py` loads the committed fixture, asserts 25 cases
  evaluated, and carries per-op negative controls, engine sabotage tests and
  the CWE-400 caps the PBT runner has.
- The conforming mutator algebra: `bit_flip`/`byte_flip` applied by parity (O(len)
  for any count), `byte_arithmetic` and `boundary_insert` for widths 1/2/4/8 in
  both endiannesses with the 8/16/32/64-bit interest lists, `block_delete`,
  `block_insert`, `block_duplicate`, `splice`, `mutate_sequence` (differentially
  tested against `code/scripts/fuzz_conformance.py`).
- `CoverageBitmap` (8,192 bytes), `corpus_admit`, `calculate_energy` (half away
  from zero), `crash_signature` / `is_duplicate_crash` (sig_hash, 8 hex),
  `minimize_crashing_input`, `format_tap_failure` (sanitised, no payload),
  `is_fuzz_failure_id`, `tap_failures`.
- `fuzz_target(corpus, options, target)`: a pure, coverage-guided campaign with
  the VER06 9.1 contracts (exact iteration budget, empty corpus replaced by
  `[00]`, crashing seeds never mutated, every execution lands in a bucket,
  `FuzzReport.is_clean`, `crashes_dropped`, deduplicated + minimised crashes).
- `Harness` / `fuzz_function`: real coverage for plain Python functions via
  `sys.monitoring` (LINE + BRANCH) with a `sys.settrace` fallback, deterministic
  edge ids (basename + qualname + line pair), step-budget timeouts, `MemoryError`
  as OOM, normalised crash frames. Reports carry `coverage_tier`
  (`sys.monitoring`, `sys.settrace`, `caller-reported`,
  `black-box-uninstrumented`). Still capability-free (ca-capability-analyzer
  audit passes).
- Exports `FUZZ_FID_*` (named so they do not collide with the PBT `FID_*`).

### Changed
- BREAKING: `FuzzCrash` is replaced by `CrashRecord` (no `iteration`,
  `input_data` or message fingerprint; `minimal_input`, `signature`, `hits`).
  `fuzz_bytes`/`fuzz_text` keep their signatures and the `FuzzReport` aliases
  `iterations_run`, `corpus_size`, `unique_crashes`, `seed`, `crashes`
  (`FuzzResult` is an alias of `FuzzReport`). Campaign results differ from 0.2.
- BREAKING: an empty or missing initial corpus is now valid (replaced by one
  `00` seed) instead of an error or a built-in list.
- BREAKING: removed `byte_insert`, `byte_delete`, `byte_replace`, `crossover`,
  `mutate_bytes`, `mutate_text`. Nothing else in the repository imported them
  (only `fuzz_bytes` is used, by fenwick-tree and dsp-filters tests).
- `bit_flip`/`byte_flip` with `count <= 0` return the input; non-`bytes`-like
  input is a `TypeError`.
