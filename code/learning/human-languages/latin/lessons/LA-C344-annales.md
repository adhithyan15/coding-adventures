## You'll want to know: annālēs, annālium
<!-- hl-knowledge: introduces=[LA-LEX-C344-MAIORES-02]; assesses=[] -->

**annālēs, annālium** — "annals, a year-by-year history".

> In annālibus omnia bella scrīpta sunt.
>
> *All the wars are written in the annals.*

Masculine, plural, with *librī* understood. The priests kept a record of each year; later historians wrote *annālēs*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**annālēs** is built on *annus*, "year" (EtymDB): the yearly books. English *annals* comes from it.
