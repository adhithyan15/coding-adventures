# দীর্ঘ (dīrghô) — long-lasting; long (in time or length)

## You'll want to know: দীর্ঘ
<!-- hl-knowledge: introduces=[BN-LEX-C541-PROTIKSHA541-02]; assesses=[] -->

**দীর্ঘ** — *dīrghô* — "long-lasting; long (in time or length)".

> দীর্ঘ লাইন থাকলে আমরা কাল আবার আসব।
>
> *Dīrghô lāin thākle āmrā kāl ābār āsbô.*
>
> If there's a long queue, we'll come back tomorrow.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**দীর্ঘ** (*dīrghô*) is a tatsama, Sanskrit *dīrgha*, "long" (Monier-Williams), the formal partner of everyday লম্বা.
