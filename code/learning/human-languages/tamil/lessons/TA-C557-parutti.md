# பருத்தி (parutti) — cotton

## You'll want to know: பருத்தி
<!-- hl-knowledge: introduces=[TA-LEX-C557-KAMPALI557-01]; assesses=[] -->

**பருத்தி** — *parutti* — "cotton".

> கோடையில் பருத்தித் துணி அணிந்தால் வியர்க்காது.
>
> *kōṭaiyil paruttit tuṇi aṇintāl viyarkkātu.*
>
> If you wear cotton clothes in summer, you will not sweat.

Before a noun it doubles the next stop: பருத்திச் சேலை, பருத்தித் துணி.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**பருத்தி** (*parutti*) is native Dravidian: DEDR 3976 gives பருத்தி (*parutti*), "the Indian cotton plant; cotton".
