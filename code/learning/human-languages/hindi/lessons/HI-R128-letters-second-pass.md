# (three letters) — From the word back to the letter — a second pass

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[HI-SCRIPT-C128-I-SIGN-01, HI-SCRIPT-C128-I-01] -->

[PAUSE 3s] Write **ञ** without looking, then say the word it came from.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[HI-SCRIPT-C128-I-SIGN-01, HI-SCRIPT-C128-I-01, HI-SCRIPT-C128-NYA-01] -->

| letter | name | the word it came from |
|---|---|---|
| ◌ि | *i kī mātrā* | **शुक्रिया** *shukriyā* |
| इ | *i* | **दिखाइए** *dikhāie* |
| ञ | *ña* | **संज्ञा** *saṁjñā* |

[PAUSE 2s each]
- [YOU SAY: each word in the table, then write the letter it gave you without looking]
- [YOU WRITE: each letter once more, slowly, larger than it is printed]

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[HI-SCRIPT-C128-I-SIGN-01, HI-SCRIPT-C128-I-01, HI-SCRIPT-C128-NYA-01] -->

[PAUSE 3s] Say each word in the table once more, and name the letter you took from it.
