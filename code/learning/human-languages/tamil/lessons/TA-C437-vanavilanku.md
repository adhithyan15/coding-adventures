# வனவிலங்கு (vaṉavilaṅku) — wildlife; a wild animal

## You'll want to know: வனவிலங்கு
<!-- hl-knowledge: introduces=[TA-LEX-C437-VILANKU437-01]; assesses=[] -->

**வனவிலங்கு** — *vaṉavilaṅku* — "wildlife; a wild animal".

> இந்தக் காட்டில் நிறைய வனவிலங்குகள் இருக்கின்றன.
>
> *intak kāṭṭil niṟaiya vaṉavilaṅkukaḷ irukkiṉṟaṉa.*
>
> There are many wild animals in this forest.

வனம், a forest, + விலங்கு, an animal.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**வனவிலங்கு** (*vaṉavilaṅku*) is built from வனம், "a forest", borrowed from Sanskrit *vana* (CDIAL 11258), and native விலங்கு, "an animal".
