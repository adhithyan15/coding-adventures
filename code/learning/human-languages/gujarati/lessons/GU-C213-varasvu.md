# વરસવું (varasvũ) — to pour down, to rain

## You'll want to know: વરસવું
<!-- hl-knowledge: introduces=[GU-LEX-C213-WEATHER213-05]; assesses=[] -->

**વરસવું** — *varasvũ* — "to pour down, to rain".

> **આવતીકાલે વરસાદ વરસશે.** — *āvtīkāle varsād varasśe* — "It will pour with rain tomorrow."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**વરસવું** (*varasvũ*) is a tadbhava, a word inherited from Sanskrit and reshaped by sound change. It comes from *varṣati*, "it rains" (CDIAL 11394).
