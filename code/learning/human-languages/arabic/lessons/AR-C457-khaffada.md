# خفض (khaffaḍa) — to lower; to reduce

## You'll want to know: خفض
<!-- hl-knowledge: introduces=[AR-LEX-C457-TAKHFID457-03]; assesses=[] -->

**خفض** — *khaffaḍa* — "to lower; to reduce".

> خفض المتجر ثمن الأحذية.
>
> *khaffaḍa al-matjar thaman al-aḥdhiya.*
>
> The shop lowered the price of shoes.

Present: يخفض, *yukhaffiḍ*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**خفض** (*khaffaḍa*) is built on the native Arabic root *kh-f-ḍ*, "to be low; to lower" (Lane). It is Form II; *munkhafiḍ*, "low", shares the root.
