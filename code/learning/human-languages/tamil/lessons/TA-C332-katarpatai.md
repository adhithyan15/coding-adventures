# கடற்படை (kaṭaṟpaṭai) — a navy

## You'll want to know: கடற்படை
<!-- hl-knowledge: introduces=[TA-LEX-C332-POR332-05]; assesses=[] -->

**கடற்படை** — *kaṭaṟpaṭai* — "a navy".

> அந்த மன்னரிடம் பெரிய கடற்படை இருந்தது.
>
> *anta maṉṉariṭam periya kaṭaṟpaṭai iruntatu.*
>
> That king had a large navy.

கடல், sea + படை, army; ல் turns to ற் before ப.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**கடற்படை** (*kaṭaṟpaṭai*) is a Tamil compound built from கடல், "sea" (DEDR 1118), and படை, "army" (DEDR 3860).

## What you've built
