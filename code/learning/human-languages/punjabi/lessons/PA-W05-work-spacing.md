# Give the work value its own space

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-LABEL-WORK-01, PA-FORM-WORK-FARMING-01] -->

Read **ਕੰਮ: ਖੇਤੀ**. Point once to the label and once to the value.

## Writing — one spacing pass
<!-- hl-knowledge: introduces=[PA-FORM-WORK-SPACING-01]; assesses=[PA-FORM-LABEL-WORK-01, PA-FORM-WORK-FARMING-01] -->

Copy **ਕੰਮ:**, leave a clear space, then copy **ਖੇਤੀ**. Judge only the boundary after the colon.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-WORK-SPACING-01] -->

Cover the model and repeat once. If the boundary is unclear, repair only the space.

## Wrap-up recall
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-WORK-SPACING-01] -->
