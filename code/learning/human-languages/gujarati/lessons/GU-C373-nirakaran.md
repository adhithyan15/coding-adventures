# નિરાકરણ (nirākaraṇ) — a solution (to a problem); a settling

## You'll want to know: નિરાકરણ
<!-- hl-knowledge: introduces=[GU-LEX-C373-UPAY373-02]; assesses=[] -->

**નિરાકરણ** — *nirākaraṇ* — "a solution (to a problem); a settling".

> જો બંને બાજુ વાત કરશે તો આ વિવાદનું નિરાકરણ થશે.
>
> *jo banne bāju vāt karśe to ā vivādnũ nirākaraṇ thaśe.*
>
> If both sides talk, this dispute will be settled.

A neuter noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**નિરાકરણ** (*nirākaraṇ*) is a tatsama, borrowed from Sanskrit *nirākaraṇa*, "driving away, removing" (Monier-Williams). Gujarati uses it for clearing a problem away: its solution, a sense the source does not give.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
