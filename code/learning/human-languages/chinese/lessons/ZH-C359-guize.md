## You'll want to know: guīzé
<!-- hl-knowledge: introduces=[ZH-LEX-C359-RULES359-01]; assesses=[] -->

*guīzé* — "rules of a game; set procedure".

> *zhège bǐsài de guīzé hěn jiǎndān* — The rules of this game are simple.

Its characters come later; for now it is a word for the ear.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*guīzé* is built from *guī* and *zé*, both inherited from Middle Chinese, *kjwie* and *tsok* (Guangyun, in Baxter's transcription), which glosses the first 'round' and the second 'a rule'.
