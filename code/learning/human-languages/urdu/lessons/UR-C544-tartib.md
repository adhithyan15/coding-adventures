## You'll want to know: ترتیب
<!-- hl-knowledge: introduces=[UR-LEX-C544-AGHAZ544-05]; assesses=[] -->

**ترتیب** — *tartīb* — "order (a set sequence)".

> اگر کتابیں ترتیب سے ہوتیں تو جلدی ملتیں۔
>
> *agar kitābeṅ tartīb se hotīṅ to jaldī miltīṅ.*
>
> If the books were in order, they would be easy to find.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ترتیب** (*tartīb*) is usually traced, through Persian, to Arabic *tartīb*, "arranging in order".
