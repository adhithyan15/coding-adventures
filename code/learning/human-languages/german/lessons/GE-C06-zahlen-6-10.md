# sechs bis zehn — finishing the count

## Warm-up

[PAUSE 2s] Five more words learned one at a time. Same job as before: make them
one run, then join the two runs together.

## You'll want to know: the second run
<!-- hl-knowledge: introduces=[GE-LEX-ZAEHLEN-6-10-01]; assesses=[GE-LEX-SECHS-01, GE-LEX-SIEBEN-01, GE-LEX-ACHT-01, GE-LEX-NEUN-01, GE-LEX-ZEHN-01] -->

> **sechs, sieben, acht, neun, zehn**

Said straight through: *zeks, ZEE-ben, akht, noyn, tsayn*.

And the second five are the same story as the first — English twins, Latin only
a cousin:

| German | English | What changed |
|---|---|---|
| *sechs* | six | almost nothing; *chs* is *x* |
| *sieben* | seven | the *v* softened to a *b* |
| *acht* | eight | German still says the scrape English writes as **gh** |
| *neun* | nine | only the vowel moved |
| *zehn* | ten | an old **d** to **t**, then **t** to **ts** |
