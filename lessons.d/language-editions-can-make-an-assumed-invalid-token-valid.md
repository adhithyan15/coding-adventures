# Language editions can make an assumed invalid token valid

The D1 test-first CLI run actually returned1P7F: six failures were the intended
missing source-inventory metadata, while the assumed lexical-error control @
was wrong. ES2025 explicitly adds the AT decorator terminal. The baseline guard
caught that before implementation; do not alter the lexer to fit the test.
Preserve the consumed actual101 log and wrapper1 classification refusal. Use
the existing CV04-tested var x= followed by NUL as the ordinary LexicalError::Lex
control, and keep @ as an ES2025 available-inventory companion with earlier-
edition refusal. Scope per-edition fixtures to the editions that admit them.
