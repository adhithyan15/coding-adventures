# Changelog shards begin with their level-two heading

The CV04a two-unit carrier's first documentation check rejected two new
changelog shards because I copied the document preamble into each section.
The existing lesson already described this trap. Read the document's _meta.md
and a section shard separately; start each new shard at its level-two heading
and derive its filename digest from that exact heading. Preserve the failed
checker receipt and rerun the real checker after correction. This repair
changes documentation only; it does not invalidate the accepted Rust inputs.
