## You'll want to know: 小区
<!-- hl-knowledge: introduces=[ZH-LEX-C377-AREA377-03]; assesses=[] -->

**小区** — *xiǎoqū* — "housing estate; residential compound".

> **我觉得这个小区很好** *wǒ juéde zhège xiǎoqū hěn hǎo* — I think this estate is very nice.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**小区** (*xiǎoqū*) is built from 小 'small' and 区 'an area', both inherited from Middle Chinese, *sjewX* and *khju* (Guangyun, in Baxter's transcription), which glosses the first 'tiny'. A housing estate of many blocks behind one gate is a modern use.
