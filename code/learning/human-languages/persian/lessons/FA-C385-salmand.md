## You'll want to know: سالمند
<!-- hl-knowledge: introduces=[FA-LEX-C385-JAMEE-04]; assesses=[] -->

**سالمند** (*sâlmand*) — "elderly; an elderly person".

> پرستار هر روز به سالمندها کمک میکند.
>
> *parastâr har ruz be sâlmandhâ komak mikonad.*
>
> The nurse helps the elderly every day.

*Sâl* "year" + *-mand* "having". More respectful than *pir* "old".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**سالمند** is native Persian, built from *sâl* "year" + the suffix *-mand* "having". An elderly person is rich in years.
