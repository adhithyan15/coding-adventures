# മുൻകരുതൽ (munkarutal) — a precaution

## You'll want to know: മുൻകരുതൽ
<!-- hl-knowledge: introduces=[ML-LEX-C442-APAKATAM442-02]; assesses=[] -->

**മുൻകരുതൽ** — *munkarutal* — "a precaution".

> യാത്രയ്ക്ക് മുൻപ് അവർ എല്ലാ മുൻകരുതലുകളും എടുത്തു.
>
> *yātraykkŭ munpŭ avar ellā munkarutalukaḷuṁ eṭuttu.*
>
> Before the journey they took every precaution.

To take precautions is മുൻകരുതൽ എടുക്കുക.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**മുൻകരുതൽ** (*munkarutal*) is a native Malayalam compound: മുൻ, "before" (DEDR 5020), and കരുതൽ, "care, regard", from കരുതുക (DEDR 1283): care taken beforehand.
