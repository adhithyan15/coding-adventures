# விதிவிலக்கு (vitivilakku) — an exception

## You'll want to know: விதிவிலக்கு
<!-- hl-knowledge: introduces=[TA-LEX-C382-NIPANTANAI382-04]; assesses=[] -->

**விதிவிலக்கு** — *vitivilakku* — "an exception".

> இந்த விதிக்கு ஒரு விதிவிலக்கு இருக்கிறது.
>
> *inta vitikku oru vitivilakku irukkiṟatu.*
>
> There is one exception to this rule.

விதி, rule + விலக்கு, a setting aside.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**விதிவிலக்கு** (*vitivilakku*) is built from *viti*, "rule", borrowed from Sanskrit *vidhi* (CDIAL 11755), and native *vilakku*, "to turn aside, avert" (DEDR 5423): a rule turned aside.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
