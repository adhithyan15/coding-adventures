# ಉಲ್ಲಂಘಿಸು (ullaṅghisu) — to violate; to break a rule

## You'll want to know: ಉಲ್ಲಂಘಿಸು
<!-- hl-knowledge: introduces=[KA-LEX-C444-NIYAMA444-02]; assesses=[] -->

**ಉಲ್ಲಂಘಿಸು** — *ullaṅghisu* — "to violate; to break a rule".

> ಅವನು ಕೆಂಪು ಸಿಗ್ನಲ್ ಉಲ್ಲಂಘಿಸಿದನು.
>
> *avanu kempu signal ullaṅghisidanu.*
>
> He jumped the red light.

Past (I …): ಉಲ್ಲಂಘಿಸಿದೆ, *ullaṅghiside*.

ನಿಯಮ ಉಲ್ಲಂಘನೆ, a breach of the rules.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಉಲ್ಲಂಘಿಸು** (*ullaṅghisu*) is built from Sanskrit *ullaṅghana*, "leaping over, transgressing", from *ud-* "up, over" and *laṅgh*, "to leap over" (CDIAL 10905), with the verb ending -*isu*.
