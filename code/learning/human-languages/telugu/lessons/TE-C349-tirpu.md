# తీర్పు (tīrpu) — a verdict; a judgment

## You'll want to know: తీర్పు
<!-- hl-knowledge: introduces=[TE-LEX-C349-NYAYAM349-04]; assesses=[] -->

**తీర్పు** — *tīrpu* — "a verdict; a judgment".

> న్యాయమూర్తి నిన్న తీర్పు చెప్పాడు.
>
> *nyāyamūrti ninna tīrpu ceppāḍu.*
>
> The judge gave the verdict yesterday.

తీర్పు చెప్పు, to pronounce a verdict; it comes from తీరు, to be settled.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**తీర్పు** (*tīrpu*) is native Dravidian: DEDR 3278 lists Telugu *tīrpu*, a settling, beside *tīru*, "to be finished, set right".
