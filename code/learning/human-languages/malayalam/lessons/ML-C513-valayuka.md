# വലയുക (valayuka) — to be in distress; to be put to hardship

## You'll want to know: വലയുക
<!-- hl-knowledge: introduces=[ML-LEX-C513-CAMP513-05]; assesses=[] -->

**വലയുക** — *valayuka* — "to be in distress; to be put to hardship".

> ബസ് ഇല്ലാതെ യാത്രക്കാർ വലഞ്ഞു.
>
> *basŭ illāte yātrakkār valaññu.*
>
> With no bus, the passengers were stranded and suffered.

Past: വലഞ്ഞു, *valaññu*.

Common in the news: യാത്രക്കാർ വലഞ്ഞു, the passengers had a hard time.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**വലയുക** (*valayuka*) is native Dravidian, "to be straitened, pressed, distressed" (DEDR 5281).
