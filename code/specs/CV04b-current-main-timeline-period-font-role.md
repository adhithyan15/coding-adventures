## Bounded behavior

With Some(timeline_config), lower each TimelinePeriod's label using the
configured Timeline label clone. Its size is s, effective family follows the
existing sanitization, and weight/italic/stretch/line_height come from the
caller's label font. TemporalTitle retains the configured title clone at 2*s.
TimelineSection, separate TimelineEvent and embedded period events retain
their existing label roles. A period's rectangle, label frame (x+12,y+8,
width-24,22), colors, embedded-event frame, metadata and instruction order do
not change. No size-driven layout, padding, wrapping algorithm or new numeric
admission policy is introduced here.

With None, a directly supplied TimelinePeriod retains the original caller
title font. This explicitly preserves the existing unconfigured compatibility
path. Ordinary axis, Journey and generic temporal items keep their complete
behavior in both Some and None diagrams. The incoming unguarded ordinary-font
override is not adopted. No new manifest, dependency, serialized boundary,
source parser, semantic IR, layout formula or public API change is needed.

Both planned configured font requests remain admitted before any backend work,
including an empty diagram or a period-only diagram that no longer emits a
title query. An unrepresentable doubled title still returns
TimelineTitleFontSize; label refusal retains priority. Compatibility entry
points keep their existing explicit panic. This is a font-role change, not a
relaxation of request admission or a finite-backend/Scene/resource guarantee.
