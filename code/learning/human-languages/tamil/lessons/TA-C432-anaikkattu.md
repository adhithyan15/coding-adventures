# அணைக்கட்டு (aṇaikkaṭṭu) — a dam

[PAUSE 2s] Before the new one: say the Tamil for a body of water, then the Tamil for a canal.

## You'll want to know: அணைக்கட்டு
<!-- hl-knowledge: introduces=[TA-LEX-C432-NEER432-03]; assesses=[] -->

**அணைக்கட்டு** — *aṇaikkaṭṭu* — "a dam".

> ஆற்றின் குறுக்கே ஒரு பெரிய அணைக்கட்டு இருக்கிறது.
>
> *āṟṟiṉ kuṟukkē oru periya aṇaikkaṭṭu irukkiṟatu.*
>
> There is a big dam across the river.

அணை, an embankment, + கட்டு, to build.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**அணைக்கட்டு** (*aṇaikkaṭṭu*) is built from அணை, "an embankment, a dam" (DEDR 122), and கட்டு, "to tie, to build" (DEDR 1147).
