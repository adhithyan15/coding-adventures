## You'll want to know: inscrire
<!-- hl-knowledge: introduces=[FR-LEX-C376-FAC-02]; assesses=[] -->

**inscrire** — "to enrol, to register (mostly reflexive, s'inscrire); to write down".

> Je me suis inscrit à un cours d'anglais.
>
> *I enrolled in an English course.*

*S'inscrire à* — to sign up for. Conjugated like *écrire*: *je m'inscris*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*inscrire* is a learned borrowing from Latin *īnscrībere* "to write on, to inscribe" (EtymDB; Lewis & Short), reshaped on *écrire*; it is built on *scrībere* "to write".
