# ಮೆರವಣಿಗೆ (meravaṇige) — a procession

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C358-VICHARANE358-05, KA-LEX-C359-UTSAVA359-01] -->

[PAUSE 2s] Before the new one: say the Kannada for to confess, then the Kannada for a public festival.

## You'll want to know: ಮೆರವಣಿಗೆ
<!-- hl-knowledge: introduces=[KA-LEX-C359-UTSAVA359-02]; assesses=[] -->

**ಮೆರವಣಿಗೆ** — *meravaṇige* — "a procession".

> ಮೆರವಣಿಗೆ ಮುಖ್ಯ ರಸ್ತೆಯಲ್ಲಿ ನಿಧಾನವಾಗಿ ಸಾಗಿತು.
>
> *meravaṇige mukhya rasteyalli nidhānavāgi sāgitu.*
>
> The procession moved slowly along the main road.

Plural: ಮೆರವಣಿಗೆಗಳು, *meravaṇigegaḷu*.

A procession "moves on": ಮೆರವಣಿಗೆ ಸಾಗಿತು.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಮೆರವಣಿಗೆ** (*meravaṇige*) is native Dravidian: DEDR 5074 lists Tamil *meravaṇai*, "a procession", with Kannada *merugu*, "to shine", and *mere*, "to parade".
