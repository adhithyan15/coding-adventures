# કૌભાંડ (kaubhā̃ḍ) — a scam

## You'll want to know: કૌભાંડ
<!-- hl-knowledge: introduces=[GU-LEX-C292-KAUBHAND292-02]; assesses=[] -->

**કૌભાંડ** — *kaubhā̃ḍ* — "a scam".

> આ કૌભાંડમાં બે મોટા વેપારી હતા.
>
> *ā kaubhā̃ḍmā̃ be moṭā vepārī hatā.*
>
> Two big merchants were part of this scam.

A neuter noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**કૌભાંડ** (*kaubhā̃ḍ*) No dictionary we use records an older form, so its history is not settled. It is a large fraud, usually one with money and people in high places in it.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
