## You'll want to know: resolver
<!-- hl-knowledge: introduces=[ES-LEX-C481-ARREGLO-01]; assesses=[] -->

**resolver** — "to solve, to sort out".

> Vamos a resolver el problema hoy.
>
> *We are going to sort out the problem today.*

The o breaks into ue under stress: *resuelvo*, *resuelve*.
