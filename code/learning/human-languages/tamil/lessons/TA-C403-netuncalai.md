# நெடுஞ்சாலை (neṭuñcālai) — a highway

[PAUSE 2s] Before the new one: say the Tamil for to carry, then the Tamil for to unload.

## You'll want to know: நெடுஞ்சாலை
<!-- hl-knowledge: introduces=[TA-LEX-C403-SALAI403-01]; assesses=[] -->

**நெடுஞ்சாலை** — *neṭuñcālai* — "a highway".

> நெடுஞ்சாலையில் கார்கள் வேகமாகப் போகின்றன.
>
> *neṭuñcālaiyil kārkaḷ vēkamākap pōkiṉṟaṉa.*
>
> Cars go fast on the highway.

நெடும், long, + சாலை, road: the ம் becomes ஞ் before ச.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**நெடுஞ்சாலை** (*neṭuñcālai*) is built from *neṭu*, "long" (DEDR 3738), and சாலை, "road" (DEDR 2471): the long road.

One more word for getting around.
