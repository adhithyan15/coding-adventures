## You'll want to know: சீரமை
<!-- hl-knowledge: introduces=[TA-LEX-C390-CIRTIRUTTAM390-04]; assesses=[] -->

**சீரமை** — *cīramai* — "to restructure; to put in order".

> புதிய மேலாளர் அலுவலகத்தைச் சீரமைத்தார்.
>
> *putiya mēlāḷar aluvalakattaic cīramaittār.*
>
> The new manager reorganised the office.

Past (I …): சீரமைத்தேன், *cīramaittēṉ*.

சீர், good order + அமை, to arrange.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**சீரமை** (*cīramai*) is native: *cīr*, "excellence, fitness" (DEDR 2624), and *amai*, "to be fitted, set in place" (DEDR 162): to set in good order.
