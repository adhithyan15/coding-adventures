# ईदृशः (īdṛśaḥ) — such, of this kind

## You'll want to know: ईदृशः
<!-- hl-knowledge: introduces=[SA-LEX-C283-IDRSAH-01]; assesses=[SA-LEX-C230-WRK230-05, SA-FRAME-ROCATE-01, SA-LEX-C16-PLACE-05] -->

**ईदृशः** — *īdṛśaḥ* — "such, of this kind". It agrees with its noun: **ईदृशम्** (*īdṛśam*) for a neuter noun, **ईदृशी** (*īdṛśī*) for a feminine one.

> **ईदृशः अनुभवः मह्यं रोचते।**
>
> *īdṛśaḥ anubhavaḥ mahyaṃ rocate.* — "I like an experience like this."

> **ईदृशं नगरम् अहं न दृष्टवान्।**
>
> *īdṛśaṃ nagaram ahaṃ na dṛṣṭavān.* — "I have not seen a city like this."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ईदृशः** (*īdṛśaḥ*) is built from *ī*, "this", and the root √dṛś, "to see", the root of **द्रक्ष्यति**: "looking like this" (CDIAL 1611 gives the two parts). Monier-Williams compares its ending *-dṛśa* with the *-li-* of Latin *tālis*, "such". It lives on as Hindi *aisā*, "such, like this" (CDIAL 1611).
