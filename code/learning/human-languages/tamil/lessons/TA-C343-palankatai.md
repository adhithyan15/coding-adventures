## You'll want to know: பழங்கதை
<!-- hl-knowledge: introduces=[TA-LEX-C343-PAZHANKATHAI343-01]; assesses=[] -->

**பழங்கதை** — *paḻaṅkatai* — "a legend; an old tale".

> பாட்டி ஒரு பழங்கதை சொன்னார்.
>
> *pāṭṭi oru paḻaṅkatai coṉṉār.*
>
> Grandmother told an old legend.

பழம், old + கதை, story.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**பழங்கதை** (*paḻaṅkatai*) joins native பழ, "old" (DEDR 3999), with கதை, "story", from Sanskrit *kathā* (CDIAL 2704).
