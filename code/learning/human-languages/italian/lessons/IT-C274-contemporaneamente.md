## You'll want to know: contemporaneamente
<!-- hl-knowledge: introduces=[IT-LEX-C274-FRATTEMPO-02]; assesses=[] -->

**contemporaneamente** — "at the same time, simultaneously".

> Due telefoni hanno suonato contemporaneamente.
>
> *Two phones rang at the same time.*

Built on *contemporaneo*, ‘of the same time’.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*contemporaneamente* is built on *contemporaneo*, a learned borrowing from Latin *contemporāneus* "of the same time", from *con-* "together" and *tempus* "time" (Lewis & Short).
