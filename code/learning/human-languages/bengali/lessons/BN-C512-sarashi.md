# সাঁড়াশি (sā̃ṛāshi) — tongs

## You'll want to know: সাঁড়াশি
<!-- hl-knowledge: introduces=[BN-LEX-C512-UNUN512-03]; assesses=[] -->

**সাঁড়াশি** — *sā̃ṛāshi* — "tongs".

> আমি সাঁড়াশিতে ধরে গরম হাঁড়িটা নামালাম।
>
> *Āmi sā̃ṛāshite dhôre gôrôm hā̃ṛiṭā nāmālām.*
>
> I gripped the hot pot with the tongs and took it off the stove.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**সাঁড়াশি** (*sā̃ṛāshi*) is a tadbhava: CDIAL lists Bengali *sā̃ṛāsi*, "pincers", under Sanskrit *saṁdaṁśa*, "tongs" (CDIAL 12897).
