## You'll want to know: زاویہ
<!-- hl-knowledge: introduces=[UR-LEX-C541-SURAT541-01]; assesses=[] -->

**زاویہ** — *zāviyā* — "an angle; a point of view".

> اگر آپ اس زاویے سے سوچتے تو بات سمجھ جاتے۔
>
> *agar āp is zāviye se sochte to bāt samajh jāte.*
>
> If you looked at it from this angle, you would understand.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**زاویہ** (*zāviyā*) is usually traced, through Persian, to Arabic *zāwiya*, "a corner, an angle".
