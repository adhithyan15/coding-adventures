## You'll want to know: દહેજ
<!-- hl-knowledge: introduces=[GU-LEX-C498-VIDAY498-04]; assesses=[] -->

**દહેજ** — *dahej* — "a dowry".

> દહેજ માગવું ખોટું છે.
>
> *dahej māgvũ khoṭũ che.*
>
> Demanding a dowry is wrong.

A neuter noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**દહેજ** (*dahej*) is usually traced to Arabic *jahāz*, "equipment, a trousseau", which reached Gujarati through Persian.
