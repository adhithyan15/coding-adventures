## You'll want to know: lacrimō, lacrimāre
<!-- hl-knowledge: introduces=[LA-LEX-C491-LACR-01]; assesses=[] -->

**lacrimō, lacrimāre** — "to weep, shed tears".

> Īnfāns tōtam noctem lacrimat.
>
> *The baby cries all night.*

*lacrimō, lacrimāre, lacrimāvī, lacrimātum*, from *lacrima* — a tear. English *lachrymose* comes from the same family.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**lacrimō** is built on *lacrima* "a tear" (Lewis & Short), which EtymDB traces to a Proto-Indo-European word for "tear"; English *tear* is a cousin.
