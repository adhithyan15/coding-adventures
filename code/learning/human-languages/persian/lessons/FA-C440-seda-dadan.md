## You'll want to know: صدا دادن
<!-- hl-knowledge: introduces=[FA-LEX-C440-SARSEDA-03]; assesses=[] -->

**صدا دادن** (*sedâ dâdan*) — "to make a noise, to squeak, to rattle".

> در اتاق موقع باز شدن صدا میدهد.
>
> *Dar-e otâq mowqe'-e bâz shodan sedâ midahad.*
>
> The room's door squeaks when it opens.

*sedâ* 'sound' + *dâdan* 'to give'. Present stem *dah-*: *sedâ midahad*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*sedâ dâdan* is built from *sedâ* 'sound', which EtymDB takes from Arabic *ṣadā* 'echo', and *dâdan* 'to give', which EtymDB traces to the PIE root *deh₃-* 'to give'.
