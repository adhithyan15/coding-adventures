## You'll want to know: بدبو
<!-- hl-knowledge: introduces=[UR-LEX-C416-KURA416-04]; assesses=[] -->

**بدبو** — *badbū* — "a stink; a bad smell".

> گٹر سے بدبو آتی ہے۔
>
> *gaṭar se badbū ātī hai.*
>
> The sewer stinks.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**بدبو** (*badbū*) is built from Persian *bad*, "bad", and *bū*, "a smell": it is usually traced to Persian *badbū*.
