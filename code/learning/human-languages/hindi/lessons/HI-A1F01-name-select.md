# Two people, two known practice names

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[HI-CONCEPT-C02-MERANAAMHAI-01, HI-FORM-LABEL-NAME-01] -->

Read both names from the earlier sentence work:

> **मीरा · अरुण**

## The two words — attach one nonverbal cue to each person
<!-- hl-knowledge: introduces=[HI-FORM-NAME-MIRA-01, HI-FORM-NAME-ARUN-01, HI-FORM-NAME-CUE-MAP-01]; assesses=[HI-CONCEPT-C02-MERANAAMHAI-01] -->

For this closed practice bank only:

- **A → मीरा**
- **B → अरुण**

Look for five seconds. Cover the Devanagari names. Point to A and recall its
name; point to B and recall its name. Uncover and compare.

## Guided Practice — select, do not copy
<!-- hl-knowledge: introduces=[]; assesses=[HI-FORM-NAME-MIRA-01, HI-FORM-NAME-ARUN-01, HI-FORM-NAME-CUE-MAP-01] -->

With the bank visible, choose the value requested by B, then the value requested
by A. Do not write either one. This pass separates selection from spelling.

## Wrap-up recall
<!-- hl-knowledge: introduces=[]; assesses=[HI-FORM-NAME-CUE-MAP-01] -->
<!-- hl-activity: {"id":"HI-A1F01-name-select-b","kind":"text","assesses":["HI-FORM-NAME-CUE-MAP-01"],"prompt":"In this practice bank, select the Devanagari name paired with B.","answer":"अरुण","accepted":[],"feedback":{"correct":"B requests अरुण.","incorrect":"Reveal A → मीरा and B → अरुण, point to B, then cover the bank again."},"response_seconds":10} -->

Stop after the two-way contrast. No third name enters this field bank.
