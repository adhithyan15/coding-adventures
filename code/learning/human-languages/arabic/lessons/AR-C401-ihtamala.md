## You'll want to know: احتمل
<!-- hl-knowledge: introduces=[AR-LEX-C401-IHTIMAL401-03]; assesses=[] -->

**احتمل** — *iḥtamala* — "to tolerate; to allow for".

> لا يحتمل جدي الحر.
>
> *lā yaḥtamilu jaddī al-ḥarr.*
>
> My grandfather cannot tolerate the heat.

Present: يحتمل, *yaḥtamil*.

يحتمل أن …, it is possible that ….

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**احتمل** (*iḥtamala*) is built on the native Arabic root *ḥ-m-l*, "to carry, to bear" (Lane). It is Form VIII, to carry a load oneself: to bear, to tolerate, and so to allow for a thing.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
