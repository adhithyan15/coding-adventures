## You'll want to know: das Gebüsch
<!-- hl-knowledge: introduces=[GE-LEX-C456-LICHTUNG-02]; assesses=[] -->

**das Gebüsch** — "the bushes, the undergrowth".

> Ein Kaninchen versteckt sich im Gebüsch.
>
> *A rabbit hides in the bushes.*

Plural: *die Gebüsche*. One bush is *der Busch*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*Gebüsch* is built from *ge-*, which groups things together, and *Busch* 'bush', inherited from Old High German *busk* (EtymDB); English *bush* is a cousin.
