## You'll want to know: os patins
<!-- hl-knowledge: introduces=[PT-LEX-C507-RODAS-03]; assesses=[] -->

**os patins** — "skates".

> Recebi uns patins no meu aniversário.
>
> *I got some skates for my birthday.*

Singular *o patim*. *Patins em linha* — inline skates.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*patim* is usually traced to French *patin* "a skate", built on *patte* "paw"; the origin of *patte* is not settled.
