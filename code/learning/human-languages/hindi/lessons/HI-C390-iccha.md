## You'll want to know: इच्छा
<!-- hl-knowledge: introduces=[HI-LEX-C390-LAKSHYA390-02]; assesses=[] -->

**इच्छा** — *icchā* — "a wish, a desire".

> अगर तुम्हारी इच्छा होगी तो हम कल पहाड़ पर चलेंगे।
>
> *agar tumhārī icchā hogī to ham kal pahāṛ par caleṅge.*
>
> If you'd like to, we'll go up the mountain tomorrow.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**इच्छा** (*icchā*) is a tatsama, borrowed from Sanskrit *icchā*, "a wish, a desire" (Monier-Williams).
