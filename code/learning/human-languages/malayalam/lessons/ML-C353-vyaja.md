# വ്യാജ (vyāja) — fake; forged

## You'll want to know: വ്യാജ
<!-- hl-knowledge: introduces=[ML-LEX-C353-KIMVADANTI353-03]; assesses=[] -->

**വ്യാജ** — *vyāja* — "fake; forged".

> അവന്റെ കയ്യിൽ ഒരു വ്യാജ സർട്ടിഫിക്കറ്റ് ഉണ്ടായിരുന്നു.
>
> *avanṟe kayyil oru vyāja sarṭṭiphikkaṟṟŭ uṇṭāyirunnu.*
>
> He had a fake certificate.

It stands before the noun, unchanged: വ്യാജ വാർത്ത, fake news.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**വ്യാജ** (*vyāja*) is borrowed from Sanskrit *vyāja*, "deceit, fraud; a disguise, a pretext" (Monier-Williams). Malayalam uses the bare stem before a noun, as it does with പൊതു and സ്വകാര്യ.
