# Your first complete Malayalam A1 writing paper

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-NAMASKARAM-01, ML-PHRASE-C02-MY-NAME-IS-01, ML-PHRASE-C04-NAALE-KAANAAM-01, ML-PHRASE-C05-I-SPEAK-MALAYALAM-01, ML-CONCEPT-C39-CHAAYA-01, ML-LEX-C41-DEIXIS-06, ML-PUNCT-QUESTION-01] -->

[PAUSE 2s] This is an attempt, not a model. You will write the answers, and
this page will not show you any copyable Malayalam answer.

Put away romanization, dictionaries, translators, and spell-checkers. Set one
timer for **20 minutes**. Keep it running through both tasks. Write in
Malayalam script. Ordinary legible handwriting is enough; decorative
calligraphy is not scored.

## Writing — timed assessment production
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-NAMASKARAM-01, ML-PHRASE-C02-MY-NAME-IS-01, ML-PHRASE-C04-NAALE-KAANAAM-01, ML-PHRASE-C05-I-SPEAK-MALAYALAM-01, ML-CONCEPT-C39-CHAAYA-01, ML-LEX-C41-DEIXIS-06, ML-PUNCT-QUESTION-01] -->
<!-- hl-writing-stage: timed-assessment-production -->

### Task 1 — practical form: 7 minutes, 40 points

Complete **all six fields in Malayalam script** for a neighbourhood language
exchange. Write one short answer in every field. The example name on the paper
is not an answer you may copy. If a field feels difficult, leave room, continue
to the next one, and return only if time remains.

1. Your name
2. A language you speak
3. One greeting you would use
4. One drink you would ask for
5. One place-question word
6. One polite closing you would use

At seven minutes, move on even if a field is unfinished. Do not restart the
timer and do not polish the form with time meant for the message.

### Task 2 — message: 13 minutes, 60 points

**Reader:** Anu. **Purpose:** help Anu recognise you and arrange a first
conversation tomorrow.

Write **30–40 words in Malayalam script**. Greet Anu, introduce yourself, say
which language you speak, mention the drink you would ask for, ask where Anu
is, and close with the familiar tomorrow phrase. The instructions give
content, not sentences: choose and connect the Malayalam yourself.

When the 20-minute timer rings, **stop**, even if a line is unfinished. Record
the number of completed form fields and the message word count. An honest timed
attempt is more useful than a perfect untimed one.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-NAMASKARAM-01, ML-PHRASE-C02-MY-NAME-IS-01, ML-PHRASE-C04-NAALE-KAANAAM-01, ML-PHRASE-C05-I-SPEAK-MALAYALAM-01, ML-CONCEPT-C39-CHAAYA-01, ML-LEX-C41-DEIXIS-06, ML-PUNCT-QUESTION-01] -->

Only after you have stopped, review the same attempt. Do not rewrite it yet.
Mark one strength and one next step under each assessment criterion:

1. **Task fulfilment and relevant content** — six fields are attempted; the
   named reader, conversation purpose, and requested message points are present.
2. **Comprehensibility and organisation** — Anu can follow the message and see
   how its ideas connect.
3. **Malayalam vocabulary, grammar, and register** — familiar words and
   sentence patterns carry the intended meaning in a suitable everyday tone.
4. **Malayalam orthographic control** — vowel signs, consonant clusters, word
   spacing, and punctuation remain readable.

[PAUSE 2s] Keep the paper. On another day, repeat the same two-task shape with
new personal details. The goal is not to memorise this prompt; it is to make a
complete Malayalam attempt calmly inside the real limit.
