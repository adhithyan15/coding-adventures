## You'll want to know: semanal
<!-- hl-knowledge: introduces=[ES-LEX-C540-TEMPORADA-04]; assesses=[] -->

**semanal** — "weekly".

> El mercado semanal es los jueves.
>
> *The weekly market is on Thursdays.*

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*semanal* is built on *semana* 'week' with the ending *-al* (EtymDB). *Semana* is inherited from Late Latin *septimāna* 'a set of seven', built on *septem* 'seven'.
