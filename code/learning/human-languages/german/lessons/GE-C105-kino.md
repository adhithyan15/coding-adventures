## You'll want to know: das Kino

**das Kino** — "a cinema".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**Kino** is short for the word for the cinematograph, a modern coinage from Greek *kínēma*, "movement", and *gráphein*, "to write": the machine that records movement. EtymDB 2.1 has no source for *Kino*.
