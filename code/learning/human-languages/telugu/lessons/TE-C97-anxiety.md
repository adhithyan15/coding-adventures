# ఆందోళన (āndōḷana) — anxiety, worry

## You'll want to know: ఆందోళన
<!-- hl-knowledge: introduces=[TE-LEX-C97-MOOD-04]; assesses=[] -->

**ఆందోళన** (*āndōḷana*) — "anxiety, worry".

**ఆందోళన పడకండి** — "don't worry". Telugu *falls into* worry: **పడు** is "to fall".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

A way to tell someone not to worry.
