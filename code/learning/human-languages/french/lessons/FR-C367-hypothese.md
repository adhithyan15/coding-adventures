## You'll want to know: l'hypothèse
<!-- hl-knowledge: introduces=[FR-LEX-C367-HYPOTHESE-02]; assesses=[] -->

**l'hypothèse** — "the hypothesis".

> Dans cette hypothèse, nous partirions plus tôt.
>
> *On that hypothesis, we would leave earlier.*

*Dans l'hypothèse où* takes the conditional. Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*hypothèse* is a learned borrowing from Latin *hypothesis* (EtymDB), from Greek *hupóthesis* "a foundation, a supposition", built from *hupó* "under" and *thésis* "a placing".
