## You'll want to know: soltero
<!-- hl-knowledge: introduces=[ES-LEX-C549-CASADO-02]; assesses=[] -->

**soltero** — "single, unmarried".

> Mi tío nunca se casó; sigue soltero.
>
> *My uncle never married; he is still single.*

*Un soltero* is a single man; *la despedida de soltero* is a stag party.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*soltero* is inherited from Latin *sōlitārius* 'alone, solitary' (EtymDB), built on *sōlus* 'alone'.
