# ಪ್ರೋತ್ಸಾಹಿಸು (prōtsāhisu) — to encourage

## You'll want to know: ಪ್ರೋತ್ಸಾಹಿಸು
<!-- hl-knowledge: introduces=[KA-LEX-C404-SADASYA404-03]; assesses=[] -->

**ಪ್ರೋತ್ಸಾಹಿಸು** — *prōtsāhisu* — "to encourage".

> ಅಪ್ಪ ನನ್ನನ್ನು ಆಟದಲ್ಲಿ ಪ್ರೋತ್ಸಾಹಿಸಿದರು.
>
> *appa nannannu āṭadalli prōtsāhisidaru.*
>
> Father encouraged me in sports.

Past (I …): ಪ್ರೋತ್ಸಾಹಿಸಿದೆ, *prōtsāhiside*.

ಪ್ರೋತ್ಸಾಹ, encouragement.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಪ್ರೋತ್ಸಾಹಿಸು** (*prōtsāhisu*) is built on Sanskrit *protsāha*, "great zeal, stimulus" (Monier-Williams), with the Kannada verb ending -*isu*.
