# One sentence, one stop

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[HI-CONCEPT-C02-MERANAAMHAI-01] -->

Read **मेरा नाम मीरा है**. Count four word groups. Do not change their order.

## Writing — add only the boundary
<!-- hl-knowledge: introduces=[]; assesses=[HI-CONCEPT-C02-MERANAAMHAI-01] -->
<!-- hl-writing-stage: controlled-composition -->

Hindi can close this sentence with the vertical **पूर्ण विराम**:

> **मेरा नाम मीरा है।**

The mark **।** is not part of **है**. Leave the word intact, then place one
vertical stop after it. This lesson changes only the sentence boundary.

Write the known sentence once and add **।**. Check the four spaces first, then
the one stop.

## Wrap-up recall
