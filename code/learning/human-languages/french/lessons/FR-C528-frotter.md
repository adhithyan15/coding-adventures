## You'll want to know: frotter
<!-- hl-knowledge: introduces=[FR-LEX-C528-MENAGE-03]; assesses=[] -->

**frotter** — "to rub, to scrub".

> J'ai frotté la tache, mais elle est encore là.
>
> *I scrubbed the stain, but it is still there.*

*Se frotter les mains* — to rub one's hands.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*frotter* goes back to Old French *froter*. The origin is not settled; a link with Latin *fricāre* "to rub" is often proposed.
