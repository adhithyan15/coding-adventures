## You'll want to know: ઠાર
<!-- hl-knowledge: introduces=[GU-LEX-C437-COLD437-01]; assesses=[] -->

**ઠાર** — *ṭhār* — "a hard frost; a biting chill".

> ગઈકાલે રાત્રે ઘણો ઠાર પડ્યો.
>
> *gaīkāle rātre ghaṇo ṭhār paḍyo.*
>
> There was a hard frost last night.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ઠાર** (*ṭhār*) goes back to *\*sthāra*, "firm, firmness", a form CDIAL reconstructs; CDIAL lists the Gujarati word, "frost" (CDIAL 13765): the cold that makes things set hard.
