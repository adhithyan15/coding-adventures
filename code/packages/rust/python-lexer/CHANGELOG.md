# Changelog

All notable changes to the `coding-adventures-python-lexer` crate will be documented in this file.

## Unreleased — LANG84 phase 7c, slice 3

### Added
- `FLOAT` in the six `py-float-print` pairs (3.5.10, 3.6.0, 3.11.17,
  3.12.3, 3.13.16, 3.16.0a1), regenerated by grammar-tools: `D.D?E?`,
  `.DE?` and `DE` (`E` = `[eE][+-]?D`), with PEP 515 `_` in each digit part
  from 3.6.0, and a `FLOAT_TRAILING_DOT -> FLOAT` definition for `1.` before
  a non-word character. A float may start with zeros (`00.5`). Imaginary
  literals, `1_.5`, `1._5`, `1e` and a float running into a name stay lexer
  errors. 3.0a1 and the Python 2 pairs are unchanged.

## Unreleased — LANG84 phase 7c, slice 2

### Added
- Release tables for 2.4, 2.6, 3.5.10 and 3.6.0, regenerated by
  `grammar-tools generate-rust-compiled-grammars python`. Eleven releases
  now compile to eight token classes: 2.4 is 2.2 plus `@`; 2.6 and 2.7.18
  share one class (`as`, `with`, PEP 3127 `0o`/`0b`); 3.5.10 is 3.0a1 plus
  `@=` and the barry_as_FLUFL `<>`; 3.6.0 adds PEP 515 `_`.

### Changed
- The Python 2 pairs (2.2 and 2.7.18 too) lex every Python 2 integer
  spelling as one `INT`: octal `0[0-7]*`, hex `0x`, an `l`/`L` suffix, and
  from 2.6 `0o`/`0b`. `08`, `0x`, `1LL`, `1_0` and a literal running into a
  name stay lexer errors. Tests cover each release's spellings.

## Unreleased — LANG84 phase 7c, slice 1

### Added
- Release tables for Python 2.2 and 2.7.18 (regenerated by
  `grammar-tools generate-rust-compiled-grammars python`). They are two
  token classes: 2.7.18 adds `@` and the keywords `as` and `with`. In both,
  `print` is a keyword, `<>` lexes as `LEGACY_NOT_EQUALS` and the backquote as
  `BACKTICK`. Integers are decimal only, so octal, `L` suffixes, `_` and `00`
  are lexer errors.
- Test `python_2_pairs_lex_print_as_a_keyword_and_keep_the_old_operators`.
  `SUPPORTED_RELEASES` lists the seven pairs in inventory order.

## [0.2.0] - 2026-10-20

### Added — LANG84 phase 7a release tables
- `releases::{token_grammar, grammar_class, SUPPORTED_RELEASES}`: one compiled
  `TokenGrammar` per distinct `python<release>.tokens`, selected by exact
  `code/grammars/python/releases.csv` ID (`"3.13.16"`), `None` otherwise.
  Phase 7a pairs 3.0a1, 3.11.17, 3.12.3, 3.13.16 and 3.16.0a1. They compile to
  three classes: 3.12.3, 3.13.16 and 3.16.0a1 share one.
- Tests: inventory order, class sharing, and that release IDs and minor-line
  versions never select each other's tables.

### Changed
- `_grammar.rs` is generated as a LANG84 release family
  (`grammar-tools generate-rust-compiled-grammars python`). The legacy
  minor-line tables moved to `_grammar::legacy_versions`. `tokenize_python`,
  `create_python_lexer`, `SUPPORTED_VERSIONS` and `DEFAULT_VERSION` behave
  exactly as before.

## [0.1.0] - 2026-04-05

### Added
- `create_python_lexer(source, version)` -- factory function that loads the versioned `python{version}.tokens` grammar and returns a configured `GrammarLexer`.
- `tokenize_python(source, version)` -- convenience function that tokenizes Python source and returns `Vec<Token>`.
- Supported versions: "2.7", "3.0", "3.6", "3.8", "3.10", "3.12" (default: "3.12").
- Loads grammar files from `code/grammars/python/python{version}.tokens` using `env!("CARGO_MANIFEST_DIR")` for reliable path resolution.
- Comprehensive test suite covering simple expressions, keywords, reserved keywords, indentation, bracket suppression, operators, strings, comments, float literals, the factory function, version selection, and soft keywords (3.10+/3.12+).
