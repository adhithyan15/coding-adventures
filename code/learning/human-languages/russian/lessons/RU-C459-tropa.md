## You'll want to know: тропа
<!-- hl-knowledge: introduces=[RU-LEX-C459-POKHOD-02]; assesses=[] -->

**тропа** (*tropá*) — "a path, a trail".

> Узкая тропа ведёт к озеру.
>
> *Úzkaya tropá vedyót k ózeru.*
>
> A narrow path leads to the lake.

Feminine; plural *тропы*. *Тропинка* — a little path.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*тропа* is an old Slavic word, usually linked with a root for stamping the feet: a path trodden by feet. EtymDB lists it without a source, so the line is hedged.
