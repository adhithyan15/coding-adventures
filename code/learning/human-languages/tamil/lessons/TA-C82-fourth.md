## You'll want to know: நான்காவது
<!-- hl-knowledge: introduces=[TA-LEX-C82-ORDINAL-07]; assesses=[TA-GRAMMAR-C82-ORDINAL-04] -->

**நான்காவது** (*nāṉkāvadu*) — "**fourth**". **நான்கு** (nāṉku) takes **-ஆவது**,
and nothing else changes.

**நான்காவது நாற்காலி** (*nāṉkāvadu nāṟkāli*), the fourth chair.
