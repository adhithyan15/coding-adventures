## You'll want to know: સંસ્કાર
<!-- hl-knowledge: introduces=[GU-LEX-C357-MULYA357-02]; assesses=[] -->

**સંસ્કાર** — *sanskār* — "upbringing; values instilled in a child".

> આ બાળકમાં સારા સંસ્કાર છે.
>
> *ā bāḷakmā̃ sārā sanskār che.*
>
> This child has been well brought up.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**સંસ્કાર** (*sanskār*) is a tatsama, borrowed from Sanskrit *saṃskāra*, "putting together, forming well, perfecting" (Monier-Williams).
