# इनाम (inām) — a prize, a reward

## You'll want to know: इनाम
<!-- hl-knowledge: introduces=[HI-LEX-C394-INAAM394-01]; assesses=[] -->

**इनाम** — *inām* — "a prize, a reward".

> अगर तुम दौड़ जीतोगे तो तुम्हें इनाम मिलेगा।
>
> *agar tum dauṛ jītoge to tumhẽ inām milegā.*
>
> If you win the race, you'll get a prize.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**इनाम** (*inām*) is usually traced to Arabic *inʿām*, "a favour, a gift", which reached Hindi through Persian.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
