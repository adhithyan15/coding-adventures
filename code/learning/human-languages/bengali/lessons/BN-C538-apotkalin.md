# আপৎকালীন (āpôtkālīn) — for emergencies; emergency

## You'll want to know: আপৎকালীন
<!-- hl-knowledge: introduces=[BN-LEX-C538-DURJOG538-05]; assesses=[] -->

**আপৎকালীন** — *āpôtkālīn* — "for emergencies; emergency".

> এটা হাসপাতালের আপৎকালীন দরজা।
>
> *Eṭā hāspātāler āpôtkālīn dôrjā.*
>
> This is the hospital's emergency door.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**আপৎকালীন** (*āpôtkālīn*) is built on Sanskrit *āpatkāla*, "a time of misfortune" (Monier-Williams), with the ending *-īna*, "belonging to".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
