## You'll want to know: تخمینہ
<!-- hl-knowledge: introduces=[UR-LEX-C362-QIYAS362-01]; assesses=[] -->

**تخمینہ** — *takhmīnā* — "an estimate".

> اگر تخمینہ ٹھیک ہے تو خرچ کم ہو گا۔
>
> *agar takhmīnā ṭhīk hai to kharch kam ho gā.*
>
> If the estimate is right, the cost will be lower.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**تخمینہ** (*takhmīnā*) is usually traced to Persian *takhmīna*, built on Arabic *takhmīn*, "guessing, reckoning".
