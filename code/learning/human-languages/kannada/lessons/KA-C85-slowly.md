# ನಿಧಾನವಾಗಿ (nidhānavāgi) — slowly

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C84-BODY-04, KA-LEX-C84-BODY-05] -->

## You'll want to know: ನಿಧಾನವಾಗಿ
<!-- hl-knowledge: introduces=[KA-LEX-C85-SLOWLY-01]; assesses=[] -->

**ನಿಧಾನವಾಗಿ** (*nidhānavāgi*) — "slowly". The ending **‑ಆಗಿ** (*-āgi*) turns a
word into a manner, "in a slow way", like **ಚೆನ್ನಾಗಿ** (*cennāgi*), "well".

**ನಿಧಾನವಾಗಿ ಮಾತಾಡಿ** (*nidhānavāgi mātāḍi*) — "please speak slowly".
