## You'll want to know: જાહેરાત
<!-- hl-knowledge: introduces=[GU-LEX-C198-SIGNS198-03]; assesses=[] -->

**જાહેરાત** — *jāherāt* — "advertisement".

> **દીવાલ પર મોટી જાહેરાત છે.** — *dīvāl par moṭī jāherāt che* — "There is a big advert on the wall."

Built on **જાહેર**, *jāher*, 'public'.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**જાહેરાત** (*jāherāt*) is a loan built on Arabic *ẓāhir*, "manifest, public", which reached Gujarati through Persian. Its Arabic root is *ẓ-h-r*, "to appear" (Lane).
