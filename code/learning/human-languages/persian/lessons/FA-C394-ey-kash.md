# ای کاش (ey kâsh) — if only, I wish

## You'll want to know: ای کاش
<!-- hl-knowledge: introduces=[FA-LEX-C394-RISK-01]; assesses=[] -->

**ای کاش** (*ey kâsh*) — "if only, I wish".

> ای کاش وقت بیشتری داشتم.
>
> *ey kâsh vaqt-e bishtari dâshtam.*
>
> If only I had more time.

It takes the past for a wish about now: *ey kâsh dâshtam*. *Kâsh* alone means the same.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ای کاش** is native Persian, built from *ey* "oh", the calling word, + *kâsh* "would that". The origin of *kâsh* is not settled.
