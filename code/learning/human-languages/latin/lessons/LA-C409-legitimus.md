# lēgitimus, lēgitima, lēgitimum — lawful, legitimate; proper

## You'll want to know: lēgitimus, lēgitima, lēgitimum
<!-- hl-knowledge: introduces=[LA-LEX-C409-EDICTUM-04]; assesses=[] -->

**lēgitimus, lēgitima, lēgitimum** — "lawful, legitimate; proper".

> Hoc nōn est lēgitimum.
>
> *This is not lawful.*

*lēgitimus, lēgitima, lēgitimum*, built on *lēx, lēgis*. English *legitimate*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*lēgitimus* is built on *lēx, lēgis* "a law" (EtymDB; Lewis & Short). English *legitimate* comes from it.
