# Select one known language value

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-LABEL-LANGUAGE-01, PA-FORM-LANGUAGE-PUNJABI-01, PA-FORM-LANGUAGE-HINDI-01] -->

Read the closed bank once:

> A — **ਪੰਜਾਬੀ**
>
> B — **ਹਿੰਦੀ**

## Script — attach one cue to each value
<!-- hl-knowledge: introduces=[PA-FORM-LANGUAGE-CUE-MAP-01]; assesses=[PA-FORM-LANGUAGE-PUNJABI-01, PA-FORM-LANGUAGE-HINDI-01] -->

Point to A, then **ਪੰਜਾਬੀ**. Point to B, then **ਹਿੰਦੀ**. Cover the bank and say
which value B requests. Selection is separate from spelling.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-LANGUAGE-CUE-MAP-01] -->

Reveal, point, cover, and select once more. Do not write the form line yet.
