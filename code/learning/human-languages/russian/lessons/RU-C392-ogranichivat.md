## You'll want to know: ограничивать
<!-- hl-knowledge: introduces=[RU-LEX-C392-OGRANICHENIYA-01]; assesses=[] -->

**ограничивать** (*ograníchivat*) — "to limit, to restrict".

> Родители ограничивают время у компьютера.
>
> *Rodíteli ograníchivayut vrémya u kompyútera.*
>
> The parents limit time at the computer.

Imperfective; perfective *ограничить*. *Ограничиваться* + instrumental — to be limited to.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ограничивать** is built from *о-* and *граница* "a border", which is built on *грань* "an edge": to limit a thing is to draw a border round it.
