# సదుపాయం (sadupāyaṁ) — a facility; an amenity

## You'll want to know: సదుపాయం
<!-- hl-knowledge: introduces=[TE-LEX-C459-PHALAHARAM459-03]; assesses=[] -->

**సదుపాయం** — *sadupāyaṁ* — "a facility; an amenity".

> ఆ హోటలులో అన్ని సదుపాయాలు ఉన్నాయి.
>
> *ā hōṭalulō anni sadupāyālu unnāyi.*
>
> That hotel has every amenity.

Plural: సదుపాయాలు, *sadupāyālu*.

Plural సదుపాయాలు, the -ం noun plural. సౌకర్యం is a near twin.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**సదుపాయం** (*sadupāyaṁ*) is built from two Sanskrit words: *sat*, "good", and *upāya*, "a means, an approach" (CDIAL 2308): a good means to an end.
