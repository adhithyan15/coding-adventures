# ਮੁੱਕਣਾ (mukkṇā) — to come to an end; to run out

## You'll want to know: ਮੁੱਕਣਾ
<!-- hl-knowledge: introduces=[PA-LEX-C285-HOME285-03]; assesses=[] -->

**ਮੁੱਕਣਾ** — *mukkṇā* — "to come to an end; to run out".

> ਛੁੱਟੀ ਪਰਸੋਂ ਮੁੱਕੇਗੀ।
>
> *chhuṭṭī parsõ mukkegī.*
>
> The holiday will end the day after tomorrow.

Past (it …): ਉਹ ਸਫ਼ਰ ਮੁੱਕਿਆ, *oh safar mukkiā*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ਮੁੱਕਣਾ** (*mukkṇā*) is inherited from a reconstructed *\*mukna*, "loosed"; CDIAL lists Punjabi *mukkṇā*, "to come to an end, run short", under it (CDIAL 10157).
