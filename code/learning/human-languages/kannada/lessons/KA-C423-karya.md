## You'll want to know: ಕಾರ್ಯ
<!-- hl-knowledge: introduces=[KA-LEX-C423-HANTA423-02]; assesses=[] -->

**ಕಾರ್ಯ** — *kārya* — "a task; an act".

> ಈ ಕಾರ್ಯಕ್ಕೆ ಎಲ್ಲರ ಸಹಾಯ ಬೇಕು.
>
> *ī kāryakke ellara sahāya bēku.*
>
> This task needs everyone's help.

ಕಾರ್ಯಕ್ರಮ, a programme, is built on it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಕಾರ್ಯ** (*kārya*) is borrowed from Sanskrit *kārya*, "to be done; a task, a duty" (CDIAL 3078).
