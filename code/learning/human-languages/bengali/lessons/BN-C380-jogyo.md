# যোগ্য (jogyô) — qualified; deserving

## You'll want to know: যোগ্য
<!-- hl-knowledge: introduces=[BN-LEX-C380-OPOJUKTO380-04]; assesses=[] -->

**যোগ্য** — *jogyô* — "qualified; deserving".

> তুমি যদি যোগ্য হও, তাহলে চাকরিটা পাবে।
>
> *tumi jôdi jogyô hôo, tāhôle chākriṭā pābe.*
>
> If you're qualified, you'll get the job.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**যোগ্য** (*jogyô*) is Sanskrit *yogya*, fit for the yoke and so fit for a task (Monier-Williams). A person is যোগ্য for a post or a prize.
