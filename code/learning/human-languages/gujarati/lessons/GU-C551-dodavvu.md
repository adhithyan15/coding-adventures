## You'll want to know: દોડાવવું
<!-- hl-knowledge: introduces=[GU-LEX-C551-TALIM551-04]; assesses=[] -->

**દોડાવવું** — *doḍāvvũ* — "to make (someone) run".

> જો કોચ અમને રોજ ન દોડાવત તો અમે આટલા ઝડપી ન હોત.
>
> *jo koc amne roj na doḍāvat to ame āṭlā jhaḍpī na hot.*
>
> If the coach hadn't made us run every day, we wouldn't be this fast.

Past, with તેણે (he or she …): તેણે છોકરાઓને દોડાવ્યા, *teṇe chokrāone doḍāvyā*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**દોડાવવું** (*doḍāvvũ*) is built from **દોડવું**, "to run", with the causative *-āv-*. CDIAL files **દોડવું** under Sanskrit *drávati*, "runs" (CDIAL 6624).
