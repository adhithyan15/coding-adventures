# Please, and please don't: a four-skill payoff

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-GRAMMAR-REQUEST-O-213, PA-GRAMMAR-NEG-REQUEST-NA-213] -->

[PAUSE 2s] Say *please sit*, then *please don't sit*.

## Guided Practice: four skills
<!-- hl-knowledge: introduces=[]; assesses=[PA-GRAMMAR-REQUEST-O-213, PA-GRAMMAR-NEG-REQUEST-NA-213, PA-LEX-AJE-213, PA-LEX-C89-PLACE89-03, PA-GRAMMAR-NEG-HABITUAL-212] -->

- [YOU HEAR: *please sit here*] Say **ਇੱਥੇ ਬੈਠੋ।**
- [YOU HEAR: *don't get up yet*] Say **ਅਜੇ ਨਾ ਉੱਠੋ।**
- [YOU READ: **ਉੱਥੇ ਨਾ ਬੈਠੋ।**] Give its meaning: please don't sit there.
- [YOU WRITE: cover the line and write **ਅਜੇ ਨਾ ਉੱਠੋ।**]
- Check which no you used: **ਨਾ** for a request, **ਨਹੀਂ** for a statement.

## Wrap-up Recall

up yet.
