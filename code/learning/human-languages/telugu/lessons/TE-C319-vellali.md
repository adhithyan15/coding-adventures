# వెళ్ళాలి (veḷḷāli) — must, must not, had better

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TE-LEX-C80-WISH-01, TE-LEX-C130-THINGS130-04, TE-GRAMMAR-C318-KABATTI-01] -->

[PAUSE 2s] Say "I want a ticket". (*nāku oka ṭikkeṭṭu kāvāli*.) Then "It is raining, so I am at home."
(*varṣaṁ paḍutōndi kābaṭṭi nēnu iṇṭlō unnānu*.)

## You'll want to know: -ఆలి, must
<!-- hl-knowledge: introduces=[TE-GRAMMAR-C319-OBLIGATIVE-01]; assesses=[TE-LEX-C50-LEAVE-01, TE-LEX-C92-DOCTOR-02, TE-LEX-C34-TIISUKO-01, TE-LEX-C180-GUNAM180-03] -->

> **నేను ఇప్పుడు వెళ్ళాలి.**
>
> *nēnu ippuḍu veḷḷāli.* — "I must go now."

> **మీరు ఈ మందు ప్రతి రోజు తీసుకోవాలి.**
>
> *mīru ī mandu prati rōju tīsukōvāli.* — "You should take this medicine every day."

**-ఆలి** sits on the verb's base: **వెళ్ళు** → **వెళ్ళాలి**, **చేయు** → **చేయాలి**, **తిను** →
**తినాలి**, **చదువు** → **చదవాలి**, and **వచ్చు** → **రావాలి**. It does not change for the
person: **నేను**, **నువ్వు**, **అతను**, all **వెళ్ళాలి**. It covers both "must" and "should".

You have said this ending for a long time. **కావాలి** is **-ఆలి** on **కా-**, "to become": "it must
come to be (mine)", so "it is needed, it is wanted".

## You'll want to know: -అకూడదు, must not
<!-- hl-knowledge: introduces=[TE-GRAMMAR-C319-PROHIBITIVE-01]; assesses=[TE-LEX-C84-UNWELL-01, TE-LEX-C103-LOC103-02, TE-LEX-C119-THINGS119-05, TE-LEX-C149-ACT149-04] -->

> **జ్వరం ఉన్నప్పుడు బడికి వెళ్ళకూడదు.**
>
> *jvaraṁ unnappuḍu baḍiki veḷḷakūḍadu.* — "When you have a fever, you must not go to school."

> **ఇప్పుడు కాఫీ తాగకూడదు.**
>
> *ippuḍu kāphī tāgakūḍadu.* — "You must not drink coffee now."

**-అకూడదు**: **వెళ్ళకూడదు**, **తాగకూడదు**, **చేయకూడదు**. **ఉన్నప్పుడు** (*unnappuḍu*, "when there is") is
**ఉన్న** + **అప్పుడు**, built like **-తున్నప్పుడు**.

## You'll want to know: -తే మంచిది, had better
<!-- hl-knowledge: introduces=[TE-GRAMMAR-C319-BETTER-TO-01]; assesses=[TE-LEX-C92-DOCTOR-03, TE-LEX-C76-JUDGE-03] -->

> **మీరు ఆసుపత్రికి వెళ్తే మంచిది.**
>
> *mīru āsupatriki veḷtē mañcidi.* — "You had better go to the hospital."

Word for word, "if you go, it is good": advice, softer than **-ఆలి**. The **-తే**, "if", gets a lesson of its own
later in this core; here keep **-తే మంచిది** as one piece.
