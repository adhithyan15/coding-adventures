# Changelog

## 0.1.0 - 2026-08-26

- Add the native Python CBR01 value model, bounded checked encoder, and strict
  canonical decoder with no production dependencies.
- Preserve the complete unsigned 64-bit domain, enforce deterministic map

  closed payload-blind error taxonomy.
- Consume all 55 language-neutral vectors, add adversarial allocation,
  type-boundary, and mutability coverage, and enforce a 95% statement and
  branch-coverage gate with Ruff and strict mypy validation.
