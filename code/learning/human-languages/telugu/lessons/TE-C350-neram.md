# నేరం (nēraṁ) — a crime; an offence

## You'll want to know: నేరం
<!-- hl-knowledge: introduces=[TE-LEX-C350-NERAM350-01]; assesses=[] -->

**నేరం** — *nēraṁ* — "a crime; an offence".

> దొంగతనం పెద్ద నేరం.
>
> *doṅgatanaṁ pedda nēraṁ.*
>
> Theft is a serious crime.

Plural: నేరాలు, *nērālu*.

నేరం చేయు, to commit a crime.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**నేరం** (*nēraṁ*) is native Dravidian: DEDR 3775 lists Telugu *nēramu*, "fault, offence, crime", with Tamil *nēram*, "guilt, fault".
