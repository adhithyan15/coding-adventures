# పార్కింగు (pārkiṅgu) — parking

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TE-LEX-C449-ADDANKI449-04, TE-LEX-C449-ADDANKI449-05] -->

[PAUSE 2s] Before the new one: say the Telugu for to seize up, then the Telugu for to get blocked.

## You'll want to know: పార్కింగు
<!-- hl-knowledge: introduces=[TE-LEX-C450-PARKINGU450-01]; assesses=[] -->

**పార్కింగు** — *pārkiṅgu* — "parking".

> ఆ దుకాణం దగ్గర పార్కింగు లేదు.
>
> *ā dukāṇaṁ daggara pārkiṅgu lēdu.*
>
> There is no parking near that shop.

A parking place is పార్కింగు స్థలం.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**పార్కింగు** (*pārkiṅgu*) is a loan from English *parking*, with the Telugu final -ఉ.
