## You'll want to know: ترجیح دادن

**ترجیح دادن** — *tarjih dâdan* — "to prefer".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*tarjih dâdan* pairs *tarjih*, borrowed from Arabic *tarjīḥ*, "giving more weight, preferring" (root *r-j-ḥ*, Lane), with the Persian verb *dâdan*, "to give". *dâdan*, "to give", is an inherited verb; EtymDB takes it back to the Indo-European root *\*deh₃-*, "to give".
