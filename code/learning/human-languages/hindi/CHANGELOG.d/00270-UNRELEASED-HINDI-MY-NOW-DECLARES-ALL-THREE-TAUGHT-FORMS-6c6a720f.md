# Changelog

## Unreleased — Hindi my now declares all three taught forms

Chapter 2 already teaches that Hindi possessives agree with what is owned,
names **मेरा** (*merā*), **मेरी** (*merī*), and **मेरे** (*mere*), and asks
learners to produce all three in guided practice. The lesson headword now
declares the complete taught set so reports and generated study artifacts can
see the feminine and plural forms too.
