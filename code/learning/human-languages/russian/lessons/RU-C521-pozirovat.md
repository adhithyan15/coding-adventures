## You'll want to know: позировать
<!-- hl-knowledge: introduces=[RU-LEX-C521-PAINTING-05]; assesses=[] -->

**позировать** (*pozírovat*) — "to pose, to sit (for an artist)".

> Сестра позировала художнику три часа.
>
> *Sestrá pozírovala khudózhniku tri chasá.*
>
> My sister sat for the artist for three hours.

Imperfective; present позирую. Takes the dative.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*позировать* is built on *поза* 'a pose', which EtymDB traces through German *Pose* to French *pose*, with *-ировать*; EtymDB has no entry for the verb.
