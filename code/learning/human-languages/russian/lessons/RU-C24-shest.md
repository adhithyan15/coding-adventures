# шесть — six

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[RU-PERFORMANCE-COUNT-FIVE] -->

[PAUSE 2s] Count one to five, then five to one.

## You'll want to know first — one word
<!-- hl-knowledge: introduces=[RU-LEX-SHEST-01]; assesses=[RU-LEX-PYAT-01] -->

> **шесть** — *shest* — **six**

One syllable, ending like **пять** in the soft sign.

## The word, taken apart — six, sex, shest
<!-- hl-knowledge: introduces=[RU-ETYMON-SHEST-SWEKS]; assesses=[RU-LEX-SHEST-01] -->

**шесть** continues Indo-European \**swéḱs*, "six." English **six**, Latin
**sex** and Greek **héx** are the same word.

Notice what survived: the *s*. Hold on to it, because the very last number in
this slice is where that *s* turns into the fact that names half the
Indo-European family.
