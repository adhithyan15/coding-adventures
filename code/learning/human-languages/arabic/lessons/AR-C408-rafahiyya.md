## You'll want to know: رفاهية
<!-- hl-knowledge: introduces=[AR-LEX-C408-MASLAHA408-04]; assesses=[] -->

**رفاهية** — *rafāhiyya* — "well-being".

> تهتم الدولة برفاهية المواطنين.
>
> *tahtammu ad-dawla bi-rafāhiyyat al-muwāṭinīn.*
>
> The state cares about the well-being of citizens.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**رفاهية** (*rafāhiyya*) is built on the native Arabic root *r-f-h*, "to live in ease" (Lane). *Rafāhiyya* is an abstract noun from *rafāh*, ease of life: well-being.
