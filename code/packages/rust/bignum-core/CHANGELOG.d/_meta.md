# Changelog

All notable changes to the `bignum-core` package will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## Layout

This changelog is sharded: one file per release in this directory, named
`NNNNN-SLUG-HEX8.md` (rank, uppercase slug, 8-hex digest). Rank order is
chronological; a new entry takes the next free rank. `_meta.md` is this entry point.
