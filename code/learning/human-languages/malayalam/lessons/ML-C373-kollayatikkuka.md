# കൊള്ളയടിക്കുക (koḷḷayaṭikkuka) — to loot; to plunder

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C373-AKRAMANAM373-02, ML-LEX-C373-AKRAMANAM373-03] -->

[PAUSE 2s] Before the new one: say the Malayalam for a threat, then the Malayalam for to attack.

## You'll want to know: കൊള്ളയടിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C373-AKRAMANAM373-04]; assesses=[] -->

**കൊള്ളയടിക്കുക** — *koḷḷayaṭikkuka* — "to loot; to plunder".

> കള്ളന്മാർ രാത്രി കട കൊള്ളയടിച്ചു.
>
> *kaḷḷanmār rātri kaṭa koḷḷayaṭiccu.*
>
> The robbers looted the shop at night.

Past: കൊള്ളയടിച്ചു, *koḷḷayaṭiccu*.

കൊള്ള, plunder, + അടിക്കുക, to strike.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**കൊള്ളയടിക്കുക** (*koḷḷayaṭikkuka*) is native Dravidian: കൊള്ള, "plunder", which DEDR 2151 lists with *koḷ*, "to hold, to take", and അടിക്കുക (*aṭikkuka*), "to strike" (DEDR 77).
