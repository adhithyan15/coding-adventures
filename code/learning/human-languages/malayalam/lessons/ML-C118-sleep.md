# ഉറക്കം (uṟakkaṁ) — sleep, sleepiness

## You'll want to know: ഉറക്കം
<!-- hl-knowledge: introduces=[ML-LEX-C118-WEATHER-03]; assesses=[] -->

**ഉറക്കം** (*uṟakkaṁ*) — "sleep". **എനിക്ക് ഉറക്കം വരുന്നു** — "I'm getting sleepy",
literally "sleep is coming to me".
