# ಊಟ ಆಯ್ತಾ (ūṭa āytā) — have you eaten?

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C95-MAYBE-04, KA-LEX-C95-MAYBE-05] -->

[PAUSE 2s] Before the new one: say the Kannada for maybe, then the Kannada for certainly.

## You'll want to know: ಊಟ ಆಯ್ತಾ
<!-- hl-knowledge: introduces=[KA-LEX-C96-HELLO-01]; assesses=[] -->

**ಊಟ ಆಯ್ತಾ?** (*ūṭa āytā?*) — "have you eaten?", literally "has the meal happened?".
In the south this is a greeting as much as a question.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

The warmest everyday hello.
