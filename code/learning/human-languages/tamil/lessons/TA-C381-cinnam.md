# சின்னம் (ciṉṉam) — a symbol; an emblem

## You'll want to know: சின்னம்
<!-- hl-knowledge: introduces=[TA-LEX-C381-TECAM381-03]; assesses=[] -->

**சின்னம்** — *ciṉṉam* — "a symbol; an emblem".

> புறா அமைதியின் சின்னம்.
>
> *puṟā amaitiyiṉ ciṉṉam.*
>
> The dove is a symbol of peace.

X-இன் சின்னம், a symbol of X. In elections, each party has its சின்னம்.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**சின்னம்** (*ciṉṉam*) is borrowed from Sanskrit *cihna*, "mark, sign" (CDIAL 4833); Pali has *cinha*. Tamil reshapes the cluster hn as ன்ன.
