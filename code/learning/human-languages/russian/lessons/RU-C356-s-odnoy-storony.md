## You'll want to know: с одной стороны
<!-- hl-knowledge: introduces=[RU-LEX-C356-NESMOTRYA-04]; assesses=[] -->

**с одной стороны** (*s odnóy storoný*) — "on the one hand".

> С одной стороны, работа интересная.
>
> *S odnóy storoný, rabóta interésnaya.*
>
> On the one hand, the work is interesting.

It sets up a first view, and a second view follows. *Сторона* is a side.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**с одной стороны** is "from one side": *сторона* "a side" is inherited from Proto-Slavic *\*storna*.
