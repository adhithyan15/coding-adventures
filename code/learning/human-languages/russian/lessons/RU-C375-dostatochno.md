## You'll want to know: достаточно
<!-- hl-knowledge: introduces=[RU-LEX-C375-NEOBKHODIMO-05]; assesses=[] -->

**достаточно** (*dostátochno*) — "enough; fairly".

> У нас достаточно времени.
>
> *U nas dostátochno vrémeni.*
>
> We have enough time.

With the genitive, enough: *достаточно денег*. Before an adjective, fairly: *достаточно трудно*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**достаточно** is built on *достаток* "sufficiency", from *достать* "to reach, to be enough", on *стать*, the partner of *стоять*, Proto-Slavic *\*stojati* (EtymDB).
