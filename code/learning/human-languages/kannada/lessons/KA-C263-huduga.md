## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಹುಡುಗ** (*huḍuga*) is native Dravidian (DEDR 4259). DEDR lists *huḍuga*, "boy, child", beside *puṭṭa*, "small". DEDR 4259 compares Sanskrit *puṭṭ*.
