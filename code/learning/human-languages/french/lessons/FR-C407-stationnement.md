## You'll want to know: le stationnement
<!-- hl-knowledge: introduces=[FR-LEX-C407-STATIONNEMENT-01]; assesses=[] -->

**le stationnement** — "parking".

> Le stationnement est interdit devant l'école.
>
> *Parking is not allowed in front of the school.*

*Stationnement payant* — pay parking.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*stationnement* is built on *stationner* 'to park' with *-ment*. *Stationner* comes from *station*, a learned borrowing from Latin *statiō* 'a standing', from *stāre* 'to stand' (EtymDB).
