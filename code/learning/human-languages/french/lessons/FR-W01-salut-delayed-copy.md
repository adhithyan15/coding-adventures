# *salut* — look, hide, write, compare

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[FR-ORTHO-SALUT-01] -->

Look at **salut** for five seconds. Touch the final silent **t**. Do not copy it
yet.

## Writing — delayed copy
<!-- hl-knowledge: introduces=[]; assesses=[FR-ORTHO-SALUT-01] -->
<!-- hl-writing-stage: delayed-copy -->

1. cover **salut**
2. wait five seconds
3. write the word once from memory
4. uncover the model and compare **s-a-l-u-t**

If one letter differs, circle that place and repair only that letter. A repair
is part of the exercise, not a failure.

## Wrap-up recall
