## You'll want to know: आदर्श
<!-- hl-knowledge: introduces=[HI-LEX-C396-SANSKAR396-02]; assesses=[] -->

**आदर्श** — *ādarś* — "an ideal, a model".

> अगर तुम सच बोलोगे तो बच्चों के लिए आदर्श बनोगे।
>
> *agar tum sac bologe to baccoṁ ke liye ādarś banoge.*
>
> If you tell the truth, you'll be a model for the children.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**आदर्श** (*ādarś*) is a tatsama, borrowed from Sanskrit *ādarśa*, "a mirror" (Monier-Williams). Hindi uses it for a model to copy.
