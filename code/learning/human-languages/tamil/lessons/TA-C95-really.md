# உண்மையா? (uṇmaiyā?) — really? is it true?

## You'll want to know: உண்மையா?
<!-- hl-knowledge: introduces=[TA-LEX-C95-RIGHT-02]; assesses=[] -->

**உண்மையா?** (*uṇmaiyā?*) — "really?", literally "is it the truth?".

**உண்மை** is "truth", and **-ஆ** makes the question.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

A way to show surprise.
