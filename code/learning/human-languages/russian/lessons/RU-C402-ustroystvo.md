## You'll want to know: устройство
<!-- hl-knowledge: introduces=[RU-LEX-C402-SVYAZ-05]; assesses=[] -->

**устройство** (*ustróystvo*) — "a device; the structure, the set-up".

> Это устройство работает без интернета.
>
> *Éto ustróystvo rabótayet bez internéta.*
>
> This device works without the internet.

Neuter. *Мобильное устройство* — a mobile device. Also the way a thing is arranged: *устройство общества*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**устройство** is built on *устроить* "to arrange, to set up", from *строить* "to build", on the old Slavic root *\*stroji* "order, arrangement".
