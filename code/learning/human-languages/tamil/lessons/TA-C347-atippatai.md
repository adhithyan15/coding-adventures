# அடிப்படை (aṭippaṭai) — a basis; a foundation; basic

<!-- hl-knowledge: introduces=[]; assesses=[TA-LEX-C347-ATARAM347-02, TA-LEX-C347-ATARAM347-03] -->

[PAUSE 2s] Before the new one: say the Tamil for to prove, then the Tamil for logic.

## You'll want to know: அடிப்படை
<!-- hl-knowledge: introduces=[TA-LEX-C347-ATARAM347-04]; assesses=[] -->

**அடிப்படை** — *aṭippaṭai* — "a basis; a foundation; basic".

> இந்த முடிவின் அடிப்படை என்ன?
>
> *inta muṭiviṉ aṭippaṭai eṉṉa?*
>
> What is the basis of this decision?

Before another noun it means basic: அடிப்படை உரிமை, a basic right.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**அடிப்படை** (*aṭippaṭai*) is a native Tamil compound built from *aṭi*, "foot, base, bottom" (DEDR 72), and *paṭai*, "layer, stratum" (DEDR 3852): the bottom layer that the rest stands on.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
