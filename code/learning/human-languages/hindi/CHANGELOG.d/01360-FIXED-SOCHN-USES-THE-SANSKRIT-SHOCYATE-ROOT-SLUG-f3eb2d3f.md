## Fixed — sochnā uses the sanskrit-shocyate root slug

- **HI-C34-sochna** moves from `shoc-grieve` to `sanskrit-shocyate`, and gains `sanskrit-shuc`. `shoc-grieve` and `sanskrit-shocyate` both named the one CDIAL entry, 12621 *śōcyatē* "is made to feel pain", which the lesson cites; `sanskrit-shocyate` is the spelling the Marwadi, Punjabi and Urdu *soch-* lessons already use. Its block also names the root *śuc-* "burn, grieve", which PA-C08-sochna, UR-C07-sochna and SA-C182-sokah tag `sanskrit-shuc`. Text unchanged.
