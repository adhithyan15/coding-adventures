## You'll want to know: dēstinō, dēstināre
<!-- hl-knowledge: introduces=[LA-LEX-C393-STATUO-02]; assesses=[] -->

**dēstinō, dēstināre** — "to fix, to intend; to appoint".

> Hunc diem nūptiīs dēstināvērunt.
>
> *They fixed this day for the wedding.*

*dēstinō, dēstināre, dēstināvī, dēstinātum*: to make fast, then to set aside for a purpose. English *destine* and *destination*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*dēstinō* is built from *dē* and an old verb meaning "to set, to make stand" (EtymDB), from the root of *stō* "to stand". English *destine* and *destination* come from it.
