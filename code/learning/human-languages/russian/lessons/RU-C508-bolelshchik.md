## You'll want to know: болельщик
<!-- hl-knowledge: introduces=[RU-LEX-C508-FANS-01]; assesses=[] -->

**болельщик** (*bolélshchik*) — "a fan, a supporter".

> Болельщики пели весь матч.
>
> *Bolélshchiki péli ves match.*
>
> The fans sang throughout the match.

Masculine; feminine болельщица. *Болеть за* + accusative — to support a team.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*болельщик* is built on *болеть* 'to be ill', and so 'to suffer for, to support', with the ending *-льщик* (EtymDB).
