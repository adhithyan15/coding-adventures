# 中 — close, then pass through

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ZH-LEX-ZHONG-01] -->

[PAUSE 8s] Say **middle** in Mandarin.

## Script — the shape
<!-- hl-knowledge: introduces=[ZH-SCRIPT-ZHONG-01]; assesses=[] -->

Reuse 口's three-stroke box: left side; joined top and right; closing bottom.
Only then draw the long centre vertical through the box. Four strokes; three
lifts.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[ZH-SCRIPT-ZHONG-01] -->
<!-- hl-writing-stage: observe-trace -->
