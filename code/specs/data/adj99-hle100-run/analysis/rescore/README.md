# ADJ99 defensibility rescore

Re-grades the ADJ99 HLE-100 run under a **construct-valid** defensibility rubric (locus-exposure,
format-normalized) because the original 0–5 score measured **traceability / citation density** and was
**format-confounded** (a regex identifies the arm with 100% accuracy). Result: the framework's
defensibility advantage **grows** under the corrected rubric, and ADJ99's H2 flips from FALSIFIED to
TRUE. Full writeup: [`RESCORE_FINDINGS.md`](RESCORE_FINDINGS.md).

## Pipeline (deterministic; re-runnable from the committed batches)

```bash
# 1. Preprocess: join items_100 + batches, normalize format, emit blind per-cell
#    judge files + cell_map.json, and the deterministic confound analysis.
python3 rescore_prep.py            # regenerates judge_cells/ , cell_map.json , confound_analysis.json

# 2. Re-judge (LLM): blind Opus judge per cell, counterfactual rubric. Run via the
#    Workflow tool. Self-paced in batches of 10 to stay under the rate-limit ceiling.
#    rejudge.workflow.js       — one parallel() pass over an index array
#    rejudge_seq.workflow.js   — sequential batches of BATCH (=10) over an index array
#    -> verdicts.json  (the irreplaceable LLM output; committed)

# 3. Aggregate: join verdicts back to arm/gold/old-score, emit the corrected table.
python3 rescore_aggregate.py       # reads verdicts.json + cell_map.json -> rescore_summary.json
```

## Committed artifacts

| file | what |
|---|---|
| `rescore_prep.py` | preprocessing + format normalizer + confound analysis |
| `rejudge.workflow.js`, `rejudge_seq.workflow.js` | the blind re-judge workflows (counterfactual rubric + schema) |
| `rescore_aggregate.py` | corrected headline table + old-vs-new comparison |
| `verdicts.json` | **the 395 re-judge verdicts** (non-regenerable LLM output) |
| `confound_analysis.json` | deterministic format-confound numbers |
| `rescore_summary.json` | corrected per-arm table + fw−plain gaps |
| `RESCORE_FINDINGS.md` | the writeup |

`judge_cells/` (395 blind inputs) and `cell_map.json` (the private join, ~3 MB, contains the raw
reasoning already present in `../batches/`) are **regenerated by `rescore_prep.py`** and are not
committed. Run step 1 before step 3.
