(**सूचयति**, *sūcayati*.) Digs? (**खनति**, *khanati*.) Sows? (**वपति**, *vapati*.) Is alive? (**जीवति**, *jīvati*.) Heats? (**तपति**, *tapati*.) Forgives? (**क्षमते**, *kṣamate*.) Blames? (**निन्दति**, *nindati*.) Praises? (**प्रशंसति**, *praśaṁsati*.) Accepts? (**स्वीकरोति**, *svīkaroti*.) Blossoms? (**विकसति**, *vikasati*.) Sinks? (**मज्जति**, *majjati*.) Bathes? (**स्नाति**, *snāti*.) Frolics? (**खेलति**, *khelati*.) Shuts? (**निमीलयति**, *nimīlayati*.) Opens? (**उन्मीलयति**, *unmīlayati*.)
