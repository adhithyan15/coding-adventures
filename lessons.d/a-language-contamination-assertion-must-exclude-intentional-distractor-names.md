# A language-contamination assertion must exclude intentional distractor names

A Sanskrit listening question deliberately used Hindi and Bengali as plausible
language-name distractors. A whole-paper negative assertion treated those
valid options as evidence that content had been copied from another track, so
the focused test rejected the paper it was meant to protect.

Scope contamination checks to text that must be track-specific, or exclude
terms that are legitimate assessment content. A broad absence scan is useful
only when every match is truly forbidden in every context.
