# نمایاں (numāyāṅ) — prominent; clearly visible

## You'll want to know: نمایاں
<!-- hl-knowledge: introduces=[UR-LEX-C364-ZAHIR364-04]; assesses=[] -->

**نمایاں** — *numāyāṅ* — "prominent; clearly visible".

> اگر یہ نشان نمایاں ہوتا تو میں دیکھ لیتا۔
>
> *agar yih nishān numāyāṅ hotā to maiṅ dekh letā.*
>
> If this mark had stood out, I would have seen it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**نمایاں** (*numāyāṅ*) is usually traced to Persian *numāyān*, "appearing, visible".
