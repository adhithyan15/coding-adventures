## You'll want to know: lloviznar
<!-- hl-knowledge: introduces=[ES-LEX-C697-LLUVIA-05]; assesses=[] -->

**lloviznar** — "to drizzle".

> Está lloviznando un poco.
>
> *It is drizzling a little.*

Like *llover*, used in the third person.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*lloviznar* is built on *llover* "to rain" (EtymDB), which is inherited from Latin *pluere*.
