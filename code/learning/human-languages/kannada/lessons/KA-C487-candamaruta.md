# ಚಂಡಮಾರುತ (caṇḍamāruta) — a cyclone

## You'll want to know: ಚಂಡಮಾರುತ
<!-- hl-knowledge: introduces=[KA-LEX-C487-CANDAMARUTA487-01]; assesses=[] -->

**ಚಂಡಮಾರುತ** — *caṇḍamāruta* — "a cyclone".

> ಚಂಡಮಾರುತದಿಂದ ಮೀನುಗಾರರು ಸಮುದ್ರಕ್ಕೆ ಹೋಗಲಿಲ್ಲ.
>
> *caṇḍamārutadinda mīnugāraru samudrakke hōgalilla.*
>
> Because of the cyclone the fishermen did not go to sea.

ಚಂಡ, fierce, plus ಮಾರುತ, wind.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಚಂಡಮಾರುತ** (*caṇḍamāruta*) is built from two Sanskrit words: *caṇḍa*, "passionate, fierce" (CDIAL 4584), and *māruta*, "windy; the wind" (CDIAL 10068).
