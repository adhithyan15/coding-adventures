# অনিদ্রা (ônidrā) — sleeplessness; insomnia

## You'll want to know: অনিদ্রা
<!-- hl-knowledge: introduces=[BN-LEX-C479-GHUM479-02]; assesses=[] -->

**অনিদ্রা** — *ônidrā* — "sleeplessness; insomnia".

> চিন্তায় বাবা অনিদ্রায় ভুগছেন।
>
> *chintāy bābā ônidrāy bhugchhen.*
>
> Father is suffering from insomnia because of worry.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**অনিদ্রা** (*ônidrā*) is a tatsama, Sanskrit *anidrā*, "sleeplessness" (Monier-Williams): *a-* on *nidrā*, sleep.
