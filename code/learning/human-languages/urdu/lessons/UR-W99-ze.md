# ز (ze) — the letter that ends روز

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[UR-SCRIPT-C37-ZOE-01, UR-SCRIPT-C37-HAMZA-SEAT-01] -->

[PAUSE 2s] Before the new one: write ظ and ئ once each, and name them.

[PAUSE 2s] Now say **روز** (*roz*), "every day".
You have read it for a long time. This lesson takes one letter out of it and puts
it in your hand.

## Script you'll notice: ز
<!-- hl-knowledge: introduces=[UR-SCRIPT-C99-ZE-01]; assesses=[] -->

**ز** — *ze*, the sound *z*.

It ends **روز** (*roz*), "every day". You already write **ر**, the short curve
that drops below the line. **ز** is the same curve with **one dot above** it.
Like **ر**, it never joins the letter after it.

## Writing: ز
<!-- hl-knowledge: introduces=[]; assesses=[UR-SCRIPT-C99-ZE-01] -->

- **1.** start here: draw the independent ze downward
- **2.** continue curving to the left without lifting
- **3.** after one lift, place the dot above — and only now lift

**Pen lifts: 1.**

> Stroke order is one attested teaching order; hands and teachers vary.
> Source: Zer o Zabar, Khe, ze, zāl, swād, and zwād, independent ز calligraphic and handwriting animations and Ze instructions (Northwestern University Libraries Open Textbook, 2026).
