## You'll want to know: मेहनत
<!-- hl-knowledge: introduces=[MW-LEX-C288-KAM288-01]; assesses=[] -->

**मेहनत** — *mehnat* — "hard work".

> मेहनत चोखी बात है।
>
> *mehnat chokhī bāt hai.*
>
> Hard work is a good thing.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**मेहनत** (*mehnat*) is usually traced, through Persian *mihnat*, "labour", to Arabic *miḥna*, "trial, hardship". **मेहनती**, hard-working, is built on it.
