# നിർബന്ധിക്കുക (nirbandhikkuka) — to insist; to force

## Warm-up

[PAUSE 2s] Before the new one: say the Malayalam for to wrap up, then the Malayalam for to interfere.

## You'll want to know: നിർബന്ധിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C451-SAMMARDDAM451-02]; assesses=[] -->

**നിർബന്ധിക്കുക** — *nirbandhikkuka* — "to insist; to force".

> ഭക്ഷണം കഴിക്കാൻ അമ്മ എന്നെ നിർബന്ധിച്ചു.
>
> *bhakṣaṇaṁ kaḻikkān amma enne nirbandhiccu.*
>
> Mother insisted that I eat.

Past: നിർബന്ധിച്ചു, *nirbandhiccu*.

The noun നിർബന്ധം, insistence, is already known.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**നിർബന്ധിക്കുക** (*nirbandhikkuka*) is built from Sanskrit *nirbandha*, "perseverance, insistence" (CDIAL 7355), with the Malayalam verb ending -ിക്കുക. It is the verb of നിർബന്ധം.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
