# പുറപ്പെടൽ (puṟappeṭal) — departure

## You'll want to know: പുറപ്പെടൽ
<!-- hl-knowledge: introduces=[ML-LEX-C465-VARAVU465-01]; assesses=[] -->

**പുറപ്പെടൽ** — *puṟappeṭal* — "departure".

> വിമാനത്തിന്റെ പുറപ്പെടൽ രാത്രി പത്ത് മണിക്കാണ്.
>
> *vimānattinṟe puṟappeṭal rātri pattŭ maṇikkāṇŭ.*
>
> The flight's departure is at ten at night.

The noun of പുറപ്പെടുക, to set out: the ending -അൽ turns a verb into a noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**പുറപ്പെടൽ** (*puṟappeṭal*) is native Malayalam, the verbal noun of പുറപ്പെടുക, to set out, which is built on പുറം, the outside (DEDR 4333), with the ending -അൽ.
