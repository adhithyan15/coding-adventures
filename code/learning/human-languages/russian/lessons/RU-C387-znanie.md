## You'll want to know: знание
<!-- hl-knowledge: introduces=[RU-LEX-C387-ZNANIYA-01]; assesses=[] -->

**знание** (*znániye*) — "knowledge".

> Для этой работы нужны знания языков.
>
> *Dlya étoy rabóty nuzhný znániya yazykóv.*
>
> This job needs a knowledge of languages.

Neuter; usually plural, *знания*: *хорошие знания*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**знание** is built on *знать* "to know", inherited through Old East Slavic from Proto-Slavic *\*znati* (EtymDB).
