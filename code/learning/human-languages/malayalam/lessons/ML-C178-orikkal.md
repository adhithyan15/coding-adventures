## You'll want to know: ഒരിക്കൽ

**ഒരിക്കൽ** — *orikkal* — "once, one time". **ഞാൻ ഒരിക്കൽ ചെന്നൈയിൽ പോയിട്ടുണ്ട്** — *ñān orikkal cennaiyil pōyiṭṭuṇṭŭ* — "I have been to Chennai once."
