# ਪਿੱਤਲ (pittal) — brass

## You'll want to know: ਪਿੱਤਲ
<!-- hl-knowledge: introduces=[PA-LEX-C250-GHR250-05]; assesses=[] -->

**ਪਿੱਤਲ** — *pittal* — "brass".

> ਇਹ ਗੜਵਾ ਪਿੱਤਲ ਦਾ ਹੈ।
>
> *eh gaṛvā pittal dā hai.*
>
> This jug is made of brass.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ਪਿੱਤਲ** (*pittal*) is inherited from Sanskrit *pittala*, "brass"; CDIAL lists Punjabi *pittal*, "brass" (CDIAL 8184).
