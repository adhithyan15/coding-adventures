# સ્ક્રીન (skrīn) — screen

<!-- hl-knowledge: introduces=[]; assesses=[GU-LEX-C249-PHONE249-05, GU-LEX-C250-COMPUTER250-01] -->

[PAUSE 2s] Before the new one: say the Gujarati for to obtain, then the Gujarati for computer.

## You'll want to know: સ્ક્રીન
<!-- hl-knowledge: introduces=[GU-LEX-C250-COMPUTER250-02]; assesses=[] -->

**સ્ક્રીન** — *skrīn* — "screen".

> **કમ્પ્યૂટરની સ્ક્રીન મોટી છે.** — *kampyūṭarnī skrīn moṭī che* — "The computer's screen is big."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**સ્ક્રીન** (*skrīn*) is a loan from English *screen*, used for computers, phones and the cinema.
