## You'll want to know: دریافت
<!-- hl-knowledge: introduces=[UR-LEX-C349-TAHQIQ349-04]; assesses=[] -->

**دریافت** — *daryāft* — "a discovery".

> یہ ایک بڑی دریافت ہے۔
>
> *yih ek baṛī daryāft hai.*
>
> This is a great discovery.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**دریافت** (*daryāft*) is usually traced to Persian *daryāft*, "finding out".
