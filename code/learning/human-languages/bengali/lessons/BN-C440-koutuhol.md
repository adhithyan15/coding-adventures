# কৌতূহল (koutūhôl) — curiosity

## You'll want to know: কৌতূহল
<!-- hl-knowledge: introduces=[BN-LEX-C440-BISMOY440-02]; assesses=[] -->

**কৌতূহল** — *koutūhôl* — "curiosity".

> নতুন বাক্সটা দেখে ছেলেটার কৌতূহল হল।
>
> *nôtun bāksôṭā dekhe chheleṭār koutūhôl hôlô.*
>
> Seeing the new box, the boy grew curious.

কৌতূহলী, curious.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**কৌতূহল** (*koutūhôl*) is a tatsama, Sanskrit *kautūhala*, "curiosity, eager interest" (Monier-Williams); it shows two of the new vowel signs, ৌ and ূ, in one word.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
