# குற்றம் (kuṟṟam) — a crime; a fault

## You'll want to know: குற்றம்
<!-- hl-knowledge: introduces=[TA-LEX-C295-THUPPU295-04]; assesses=[] -->

**குற்றம்** — *kuṟṟam* — "a crime; a fault".

> திருடுவது ஒரு குற்றம்.
>
> *tiruṭuvatu oru kuṟṟam.*
>
> Stealing is a crime.

A -அம் noun: the plural is குற்றங்கள், crimes.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**குற்றம்** (*kuṟṟam*) is native Dravidian: DEDR 1851 lists it with குறு, "short, defective", so a crime is at root a fault, a falling short.
