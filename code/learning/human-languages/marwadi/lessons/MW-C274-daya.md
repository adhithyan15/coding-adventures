## You'll want to know: दया
<!-- hl-knowledge: introduces=[MW-LEX-C274-SAHARO274-04]; assesses=[] -->

**दया** — *dayā* — "mercy".

> दया करो सा।
>
> *dayā karo sā.*
>
> Have mercy, please.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**दया** (*dayā*) is a tatsama, taken from Sanskrit *dayā*, "sympathy, compassion" (Monier-Williams). **दयाळु**, kind, is built on it.
