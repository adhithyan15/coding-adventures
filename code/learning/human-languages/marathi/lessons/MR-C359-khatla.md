## You'll want to know: खटला
<!-- hl-knowledge: introduces=[MR-LEX-C359-KHATLA359-02]; assesses=[] -->

**खटला** — *khaṭlā* — "a lawsuit; a case".

> हा खटला तीन वर्षं चालला.
>
> *hā khaṭlā tīn varṣaṁ cāllā.*
>
> This case went on for three years.

Masculine. Plural: खटले, *khaṭle*.

खटला चालणे, a case is heard; खटला भरणे, to file a suit.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**खटला** (*khaṭlā*) is a Marathi noun whose origin is not settled.
