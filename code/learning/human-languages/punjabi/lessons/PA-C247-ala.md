# ਆਲਾ (ālā) — a wall niche

## You'll want to know: ਆਲਾ
<!-- hl-knowledge: introduces=[PA-LEX-C247-GHR247-01]; assesses=[] -->

**ਆਲਾ** — *ālā* — "a wall niche".

> ਆਲੇ ਵਿੱਚ ਦੀਵਾ ਹੈ।
>
> *āle vich dīvā hai.*
>
> There is a lamp in the wall niche.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ਆਲਾ** (*ālā*) is inherited from Sanskrit *ālaya*, "house, receptacle"; CDIAL lists Punjabi *ālā*, "niche in a wall" (CDIAL 1366).
