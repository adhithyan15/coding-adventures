## You'll want to know: अमर
<!-- hl-knowledge: introduces=[MR-LEX-C337-DANTKATHA337-03]; assesses=[] -->

**अमर** — *amar* — "immortal; undying".

> त्या वीराचं नाव इतिहासात अमर झालं.
>
> *tyā vīrācaṁ nāv itihāsāt amar jhālaṁ.*
>
> That hero's name became immortal in history.

अमर keeps one form: अमर कथा, अमर नाव.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**अमर** (*amar*) is a tatsama, taken from Sanskrit *amara*, 'undying, immortal' (Monier-Williams).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
