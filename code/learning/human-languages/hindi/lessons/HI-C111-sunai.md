# सुनाई नहीं दिया (sunāī nahīṁ diyā) — I could not hear it

## You'll want to know: सुनाई नहीं दिया
<!-- hl-knowledge: introduces=[HI-LEX-C111-ASK-04]; assesses=[] -->

**सुनाई नहीं दिया** (*sunāī nahīṁ diyā*) — "I could not hear it", literally "hearing was not
given".

It is built on **सुनना**, "to hear". Pair it with a fix: **ज़ोर से बोलिए**.

## What you've built
