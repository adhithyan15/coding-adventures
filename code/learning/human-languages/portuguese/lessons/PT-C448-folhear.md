## You'll want to know: folhear
<!-- hl-knowledge: introduces=[PT-LEX-C448-TABACARIA-05]; assesses=[] -->

**folhear** — "to leaf through, to flick through".

> Folheei uma revista enquanto esperava.
>
> *I leafed through a magazine while I waited.*

Built on *a folha*, the page.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*folhear* is built on *folha* 'leaf, page', which is inherited from Latin *folia*, the plural of *folium* 'leaf' (EtymDB).
