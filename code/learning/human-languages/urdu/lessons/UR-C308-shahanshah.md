## You'll want to know: شہنشاہ
<!-- hl-knowledge: introduces=[UR-LEX-C308-SHAHENSHAH308-01]; assesses=[] -->

**شہنشاہ** — *shahanshāh* — "an emperor".

> شہنشاہ ایک بڑے محل میں رہتا تھا۔
>
> *shahanshāh ek baṛe mahal meṅ rahtā thā.*
>
> The emperor lived in a great palace.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**شہنشاہ** (*shahanshāh*) is usually traced to Persian *shāhanshāh*, "king of kings", built from *shāh*, a king, the word inside **بادشاہ**.
