# el guion bajo — the hyphen that sits on the floor

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ES-ORTH-C424-07, ES-ORTH-C428-01] -->

[PAUSE 2s] Say *el guion*, the short mark that joins. Say *la arroba*. One
symbol remains before an address can be read out complete.

## The word, taken apart
<!-- hl-knowledge: introduces=[ES-ORTH-C428-02]; assesses=[] -->

**el guion bajo** — the underscore, **_**.

The name is transparent and worth admiring for it: *guion* is the hyphen you
already know, and **bajo** means *low*. It is the **low hyphen** — the same
mark, dropped to the baseline.

English names it *under-score*, from the typewriter habit of scoring a line
*under* text to underline it. Spanish names it by where it sits relative to the
mark it resembles. Two languages, two entirely reasonable descriptions of the
same key.

## Grammar Lens: the address, complete
<!-- hl-knowledge: introduces=[]; assesses=[ES-ORTH-C428-02, ES-ORTH-C428-01, ES-ORTH-C424-07] -->

Every symbol an e-mail address can contain now has a Spanish name:

| symbol | said aloud |
|---|---|
| @ | arroba |
| . | punto |
| - | guion |
| _ | guion bajo |

> ana_lopez **arroba** ejemplo **punto** es

Read that aloud and you have completed the task the source calls *dictating an
e-mail address*. It needed four words, three of which you already had.
