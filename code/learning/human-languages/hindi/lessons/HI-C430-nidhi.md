## You'll want to know: निधि
<!-- hl-knowledge: introduces=[HI-LEX-C430-DIVALA430-02]; assesses=[] -->

**निधि** — *nidhi* — "a fund; a treasure".

> गाँव के लोगों ने स्कूल के लिए एक निधि बनाई।
>
> *gā̃v ke logoṁ ne skūl ke liye ek nidhi banāī.*
>
> The villagers set up a fund for the school.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**निधि** (*nidhi*) is a tatsama, Sanskrit *nidhi*, "a place for storing; a store, a treasure" (Monier-Williams); banks and charities use it for a fund.
