# சேட்டை (cēṭṭai) — naughtiness; pranks

## You'll want to know: சேட்டை
<!-- hl-knowledge: introduces=[TA-LEX-C467-KINTAL467-02]; assesses=[] -->

**சேட்டை** — *cēṭṭai* — "naughtiness; pranks".

> வகுப்பில் அந்தப் பையன் சேட்டை செய்தான்.
>
> *vakuppil antap paiyaṉ cēṭṭai ceytāṉ.*
>
> That boy played pranks in class.

சேட்டை செய், to be naughty.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**சேட்டை** (*cēṭṭai*) is borrowed from Sanskrit *cēṣṭā*, "action, behaviour" (CDIAL 4913); Tamil narrows it to mischief.
