# ആലിപ്പഴം (ālippaḻaṁ) — hail; a hailstone

<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C509-CUTU509-05, ML-LEX-C510-MANJU510-01] -->

[PAUSE 2s] Before the new one: say the Malayalam for to get hot, then the Malayalam for fog.

## You'll want to know: ആലിപ്പഴം
<!-- hl-knowledge: introduces=[ML-LEX-C510-MANJU510-02]; assesses=[] -->

**ആലിപ്പഴം** — *ālippaḻaṁ* — "hail; a hailstone".

> ഇന്നലെ വൈകുന്നേരം ആലിപ്പഴം വീണു.
>
> *innale vaikunnēraṁ ālippaḻaṁ vīṇu.*
>
> Yesterday evening there was hail.

Literally hail fruit: ആലി, hail, plus പഴം, a fruit.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ആലിപ്പഴം** (*ālippaḻaṁ*) is native Dravidian; DEDR lists ആലി and ആലിപ്പഴം as hail (DEDR 384), with പഴം, a fruit.
