## You'll want to know: a personagem
<!-- hl-knowledge: introduces=[PT-LEX-C325-HEROI-01]; assesses=[] -->

**a personagem** — "the character (in a story)".

> A personagem principal é uma professora.
>
> *The main character is a teacher.*

In Portugal usually *a personagem*; in Brazil also *o personagem*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*personagem* came from French *personnage*, built on *personne*, from Latin *persōna* "a mask, a role in a play" (Lewis & Short).
