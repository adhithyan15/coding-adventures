# പ്രവചിക്കുക (pravacikkuka) — to predict; to forecast

## You'll want to know: പ്രവചിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C442-APAKATAM442-03]; assesses=[] -->

**പ്രവചിക്കുക** — *pravacikkuka* — "to predict; to forecast".

> അവൻ ജയിക്കുമെന്ന് എല്ലാവരും പ്രവചിച്ചു.
>
> *avan jayikkumennŭ ellāvaruṁ pravaciccu.*
>
> Everyone predicted that he would win.

Past: പ്രവചിച്ചു, *pravaciccu*.

What is predicted comes before എന്ന്: … എന്ന് പ്രവചിക്കുക.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**പ്രവചിക്കുക** (*pravacikkuka*) is built from Sanskrit *pravacana*, "speaking out, exposition" (CDIAL 8773), with the Malayalam verb ending -ിക്കുക: to speak out what is coming.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
