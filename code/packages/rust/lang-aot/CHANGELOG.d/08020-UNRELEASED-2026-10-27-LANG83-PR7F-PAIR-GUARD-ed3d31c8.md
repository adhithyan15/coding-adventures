## Unreleased — LANG83 PR7f follow-up — `car` / `cdr` of a non-pair fail closed

- `lang_matrix`: new `twig_car_and_cdr_of_a_non_pair_fail_closed_on_every_column` runs `(car 5)`, `(cdr 5)`, `(car 1000000)`, `(cdr 1000000)`, `car` of `#t` and `cdr` of `(list)` on LLVM, native x86-64, the VM, the JIT and the JVM, expecting each to fail at run time (`Expect::Trap`). Because a read of address 40 also kills the process, the LLVM and native columns are run again through the new `tagged_word_stderr` helper and their stderr must carry the C runtime's `… is not a pair` refusal; with the tag check disabled the test fails on `(car 5)` with empty stderr. WASM is not a column: it refuses a `car` with no `cons` in the program at compile time (`$LispyPair` is not registered). CLR and BEAM are left to a host that has them.
- Security review: the same test now requires the refusal to name the tag (`argument with tag …`) and forbids `0x` on the tagged-word columns' stderr, since the C runtime no longer prints the raw word.
