## You'll want to know: তত্ত্ব
<!-- hl-knowledge: introduces=[BN-LEX-C354-GOBESHONA354-03]; assesses=[] -->

**তত্ত্ব** — *tôttvô* — "a theory".

> এই তত্ত্বের কোনো প্রমাণ নেই।
>
> *ei tôttver kono prômān nei.*
>
> There is no proof for this theory.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**তত্ত্ব** (*tôttvô*) is Sanskrit *tattva*, 'thatness', the true state of things (Monier-Williams). Modern Bengali uses it for a theory, an account of how things really are.
