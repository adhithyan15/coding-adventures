# மழை பெய்தால் (maḻai peytāl) — if it rains, and if not

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TA-GRAMMAR-C292-CONDITIONAL-01, TA-GRAMMAR-C292-ENRAL-01, TA-LEX-C176-KARANAM176-02, TA-LEX-C176-KARANAM176-05] -->

[PAUSE 2s] Say "if (you) come". (*vantāl*.) Then "even though" and "otherwise". (*iruntālum*, *illāviṭṭāl*.)

## You'll want to know: if this, then that
<!-- hl-knowledge: introduces=[TA-GRAMMAR-C292-REAL-CONDITION-01]; assesses=[TA-LEX-VEEDU-01, TA-LEX-IRU-01, TA-LEX-C176-KARANAM176-02, TA-LEX-VAA-01, TA-GRAMMAR-C284-PAST-PERSON-01] -->

> **மழை பெய்தால் நான் வீட்டில் இருப்பேன்.**
>
> *maḻai peytāl nāṉ vīṭṭil iruppēṉ.* — "If it rains, I will stay at home."

The if-clause comes first. The main clause after it says what follows: a future, **இருப்பேன்** (*iruppēṉ*, "I will stay"); a request, **போங்கள்**; or **-லாம்**, **சாப்பிடலாம்**.

Add **-உம்** to the if-form and it becomes "even if":

> **மழை பெய்தாலும் நான் வருவேன்.**
>
> *maḻai peytālum nāṉ varuvēṉ.* — "Even if it rains, I will come."

You know the shape from **இருந்தாலும்**, "even so, although": the if-form of **இரு** with **-உம்**.

## You'll want to know: if not, -ஆவிட்டால்
<!-- hl-knowledge: introduces=[TA-GRAMMAR-C292-NEGATIVE-CONDITION-01]; assesses=[TA-LEX-C62-JOIN-03, TA-LEX-C69-GOING-02, TA-LEX-C176-KARANAM176-05, TA-GRAMMAR-C287-OBLIGATIVE-01] -->

> **நீங்கள் சீக்கிரம் வராவிட்டால், பேருந்து போய்விடும்.**
>
> *nīṅkaḷ cīkkiram varāviṭṭāl, pēruntu pōyviṭum.* — "If you don't come soon, the bus will leave."

Build "if not" from the to-form: **வர** → **வரா-** with **விட்டால்**: **வராவிட்டால்**. In the same way **போக** → **போகாவிட்டால்**, **சாப்பிட** → **சாப்பிடாவிட்டால்**. **போய்விடும்** (*pōyviṭum*, "it will go off").

**இல்லாவிட்டால்**, "otherwise", is the same shape on **இல்லை**: "if it is not (so)".
