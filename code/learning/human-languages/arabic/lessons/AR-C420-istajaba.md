## You'll want to know: استجاب
<!-- hl-knowledge: introduces=[AR-LEX-C420-ISTIJABA420-01]; assesses=[] -->

**استجاب** — *istajāba* — "to respond".

> استجاب المدير لطلب العمال.
>
> *istajāba al-mudīr li-ṭalab al-ʿummāl.*
>
> The manager responded to the workers' request.

Present: يستجيب, *yastajīb*.

It takes لـ: استجاب لـ ….

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**استجاب** (*istajāba*) is built on the native Arabic root *j-w-b*, "to cut through; to answer" (Lane). It is Form X, to give the answer sought: to respond. جواب, an answer, is from the same root.
