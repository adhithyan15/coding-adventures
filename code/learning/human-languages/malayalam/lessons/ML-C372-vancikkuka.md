# വഞ്ചിക്കുക (vañcikkuka) — to deceive; to betray

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C372-THATTIPPU372-01, ML-LEX-C372-THATTIPPU372-02] -->

[PAUSE 2s] Before the new one: say the Malayalam for a fraud, then the Malayalam for a swindler.

## You'll want to know: വഞ്ചിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C372-THATTIPPU372-03]; assesses=[] -->

**വഞ്ചിക്കുക** — *vañcikkuka* — "to deceive; to betray".

> അവൻ സ്വന്തം സുഹൃത്തിനെ വഞ്ചിച്ചു.
>
> *avan svantaṁ suhṛttine vañciccu.*
>
> He deceived his own friend.

Past: വഞ്ചിച്ചു, *vañciccu*.

The person deceived takes -എ: സുഹൃത്തിനെ വഞ്ചിച്ചു.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**വഞ്ചിക്കുക** (*vañcikkuka*) is built from Sanskrit *vañcana*, "cheating, deception, fraud" (Monier-Williams), with the Malayalam verb ending -ിക്കുക.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
