# ಬದ್ಧತೆ (baddhate) — commitment

## You'll want to know: ಬದ್ಧತೆ
<!-- hl-knowledge: introduces=[KA-LEX-C391-SAMANATE391-05]; assesses=[] -->

**ಬದ್ಧತೆ** — *baddhate* — "commitment".

> ಅವಳ ಕೆಲಸದಲ್ಲಿ ಬದ್ಧತೆ ಕಾಣುತ್ತದೆ.
>
> *avaḷa kelasadalli baddhate kāṇuttade.*
>
> Commitment shows in her work.

ಬದ್ಧ, bound: ಮಾತಿಗೆ ಬದ್ಧ, true to one's word.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಬದ್ಧತೆ** (*baddhate*) is built on Sanskrit *baddha*, "bound, tied" (CDIAL 9126), with -*tā*, "-ness": being bound to something.

<!-- hl-knowledge: introduces=[]; assesses=[] -->
