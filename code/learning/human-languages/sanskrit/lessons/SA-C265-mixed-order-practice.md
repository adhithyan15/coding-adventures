# Choose and order

## Warm-up

## Guided Practice — independent choice

<!-- hl-knowledge: introduces=[]; assesses=[SA-LEX-C97-LOC97-02, SA-LEX-C160-THG160-01, SA-LEX-KHADATI-EAT, SA-LEX-C29-COURTESY-01, SA-PRON-DATIVE-ME-01, SA-LEX-C72-HOUSEWORK-05, SA-LEX-ANNAM-FOOD, SA-LEX-PANIYAM-WATER, SA-LEX-KSHIRAM-MILK, SA-GRAMMAR-C265-DADATU-01, SA-PATTERN-C265-POLITE-ORDER-02] -->

No Sanskrit model is shown before you answer. Build each request from meaning.

[PAUSE 4s each]
- [YOU SAY: In a restaurant, politely ask for water.]
- [YOU SAY: Politely ask for milk.]
- [YOU SAY: Politely ask for food.]
- [YOU SAY: Name the place, name the meal, then say that someone eats food.]

## What you've built

<!-- hl-knowledge: introduces=[]; assesses=[SA-LEX-C97-LOC97-02, SA-LEX-C160-THG160-01, SA-LEX-KHADATI-EAT, SA-LEX-C29-COURTESY-01, SA-PRON-DATIVE-ME-01, SA-LEX-C72-HOUSEWORK-05, SA-LEX-ANNAM-FOOD, SA-LEX-PANIYAM-WATER, SA-LEX-KSHIRAM-MILK, SA-GRAMMAR-C265-DADATU-01, SA-PATTERN-C265-POLITE-ORDER-02] -->

Possible answers are **कृपया मह्यं पानीयं ददातु**, **कृपया मह्यं क्षीरं
ददातु**, and **कृपया मह्यम् अन्नं ददातु**. The place is **भोजनालयः**; the
meal is **भोजनम्**; “eats food” is **अन्नं खादति**.
