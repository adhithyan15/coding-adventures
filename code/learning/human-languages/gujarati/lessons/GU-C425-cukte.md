# ચૂકતે (cūkte) — paid in full; settled

## You'll want to know: ચૂકતે
<!-- hl-knowledge: introduces=[GU-LEX-C425-LOAN425-05]; assesses=[] -->

**ચૂકતે** — *cūkte* — "paid in full; settled".

> આજે મેં લોન ચૂકતે કરી.
>
> *āje mẽ lon cūkte karī.*
>
> Today I paid off the loan in full.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ચૂકતે** (*cūkte*) is built on the same stem as ચૂકવવું, to pay off, which goes back to *\*cukk*, "to fall short, to stop", a form CDIAL reconstructs (CDIAL 4848).
