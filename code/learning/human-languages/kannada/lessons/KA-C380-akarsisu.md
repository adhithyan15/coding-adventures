# ಆಕರ್ಷಿಸು (ākarṣisu) — to attract

## You'll want to know: ಆಕರ್ಷಿಸು
<!-- hl-knowledge: introduces=[KA-LEX-C380-MANAVOLISU380-05]; assesses=[] -->

**ಆಕರ್ಷಿಸು** — *ākarṣisu* — "to attract".

> ಹೊಸ ಉದ್ಯಾನ ಅನೇಕ ಜನರನ್ನು ಆಕರ್ಷಿಸಿತು.
>
> *hosa udyāna anēka janarannu ākarṣisitu.*
>
> The new park attracted many people.

Past (I …): ಆಕರ್ಷಿಸಿದೆ, *ākarṣiside*.

ಆಕರ್ಷಕ, attractive; ಆಕರ್ಷಣೆ, attraction.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಆಕರ್ಷಿಸು** (*ākarṣisu*) is built on Sanskrit *ākarṣaṇa*, "pulling, drawing near, attracting" (Monier-Williams), with the Kannada verb ending -*isu*.
