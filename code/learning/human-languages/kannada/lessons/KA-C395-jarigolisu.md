# ಜಾರಿಗೊಳಿಸು (jārigoḷisu) — to implement

## You'll want to know: ಜಾರಿಗೊಳಿಸು
<!-- hl-knowledge: introduces=[KA-LEX-C395-ADALITA395-04]; assesses=[] -->

**ಜಾರಿಗೊಳಿಸು** — *jārigoḷisu* — "to implement".

> ಸರ್ಕಾರ ಹೊಸ ಯೋಜನೆಯನ್ನು ಜಾರಿಗೊಳಿಸಿತು.
>
> *sarkāra hosa yōjaneyannu jārigoḷisitu.*
>
> The government implemented the new scheme.

Past (I …): ಜಾರಿಗೊಳಿಸಿದೆ, *jārigoḷiside*.

ಜಾರಿಗೆ ಬರು, to come into force.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಜಾರಿಗೊಳಿಸು** (*jārigoḷisu*) is built on *jārī*, "current, in force", a loan from Hindustani that comes from Arabic *jārī*, "flowing", with the Kannada ending -*goḷisu*, "to make".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
