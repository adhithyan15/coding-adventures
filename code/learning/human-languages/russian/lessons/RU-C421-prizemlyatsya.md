## You'll want to know: приземляться
<!-- hl-knowledge: introduces=[RU-LEX-C421-VZLYOT-03]; assesses=[] -->

**приземляться** (*prizemlyátsya*) — "to land".

> Самолёт приземляется поздно ночью.
>
> *Samolyót prizemlyáyetsya pózdno nóchyu.*
>
> The plane lands late at night.

Imperfective; perfective *приземлиться*. Built on *земля* — the ground.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*приземляться* is built from *при-* 'to', *земля* 'earth, the ground' and *-ся*. *Земля* is inherited from Proto-Slavic *zemľa* 'earth, land' (EtymDB).
