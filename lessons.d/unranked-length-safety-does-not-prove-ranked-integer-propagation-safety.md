# Unranked length safety does not prove ranked integer propagation safety

The existing caller-owned maximum-length control used the unranked layout path.
Rank propagation and optimizer trials still added usize distances unchecked, and
rank count added one unchecked. Sixteen bounded enabled-rank cases reproduced
panics while the unranked extreme control continued passing.

Keep the native red receipt, then use checked additions and propagate an exact
typed refusal before geometric arithmetic. Pin all four directions, optimizer
on/off, accumulation/count and private optimizer boundaries. Preserve normal
