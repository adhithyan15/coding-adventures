## Fixed — the Telugu cognate in chapter 115 is romanized granthālayaṁ

Chapter 115's cross-language table romanized Telugu గ్రంథాలయం ("library")
as *grandhālayaṁ*. The letter is థ, an aspirated *t*, so the romanization is
*granthālayaṁ*, the spelling the Telugu track itself now uses.
`equivalents.d/TA-C115-nulakam.json` carries the fix and the generated
chapter follows it.
