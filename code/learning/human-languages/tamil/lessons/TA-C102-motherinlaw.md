# மாமியார் (māmiyār) — a mother-in-law

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TA-LEX-C102-INLAWS-01, TA-LEX-C102-INLAWS-02] -->

[PAUSE 2s] Before the new one: say the Tamil for the father's elder brother, then the Tamil for the big mother.

## You'll want to know: மாமியார்
<!-- hl-knowledge: introduces=[TA-LEX-C102-INLAWS-03]; assesses=[] -->

**மாமியார்** (*māmiyār*) — "a mother-in-law", the respectful word.

It is built on the same **மாமா** root as the uncle.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

An in-law.
