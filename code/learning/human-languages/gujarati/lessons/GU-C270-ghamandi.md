# ઘમંડી (ghamanḍī) — arrogant, proud

## You'll want to know: ઘમંડી
<!-- hl-knowledge: introduces=[GU-LEX-C270-NATURE270-05]; assesses=[] -->

**ઘમંડી** — *ghamanḍī* — "arrogant, proud".

> **શું તે છોકરો ઘમંડી છે?** — *śũ te chokro ghamanḍī che?* — "Is that boy arrogant?"

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

The origin of **ઘમંડી** (*ghamanḍī*) is not settled. It is built on *ghamanḍ*, "pride", with *-ī*, but CDIAL has no entry for *ghamanḍ* and our other sources do not trace it.
