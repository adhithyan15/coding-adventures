## You'll want to know: صحيفة
<!-- hl-knowledge: introduces=[AR-LEX-C293-AKHBAR293-03]; assesses=[] -->

**صحيفة** — *ṣaḥīfa* — "a gazette, a newspaper".

> تقرأ أمي صحيفة كل صباح.
>
> *taqraʾu ummī ṣaḥīfa kulla ṣabāḥ.*
>
> My mother reads a newspaper every morning.

Plural: صحف, *ṣuḥuf*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**صحيفة** (*ṣaḥīfa*) is built on the native Arabic root *ṣ-ḥ-f* (Lane), where it names a written leaf or page. Modern Arabic gave the old word the newspaper.
