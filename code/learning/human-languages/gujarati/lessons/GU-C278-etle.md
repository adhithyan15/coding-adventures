# એટલે (eṭle) — so; that is why

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[GU-GRAMMAR-C278-VU-JOIE-01, GU-GRAMMAR-C275-ONGOING-PAST-01, GU-LEX-C101-DEF101-03] -->

[PAUSE 2s] Before the new one: say "it was raining". (*varsād paḍto hato*.) Then "that much". (**એટલું**, *eṭlũ*.)

## You'll want to know: એટલે
<!-- hl-knowledge: introduces=[GU-LEX-C278-ETLE-01]; assesses=[GU-LEX-VARSAAD-01, GU-CONCEPT-C05-RAHEVUN-01, GU-LEX-C206-ARRIVE206-02] -->

**એટલે** — *eṭle* — "so; that is why". The reason comes first, then **એટલે**, then what followed from it.

> **વરસાદ પડતો હતો, એટલે અમે ઘરે રહ્યા.**
>
> *varsād paḍto hato, eṭle ame ghare rahyā.* — "It was raining, so we stayed at home."

> **હું થાકી ગઈ હતી, એટલે હું ઘરે રહી.**
>
> *hũ thākī gaī hatī, eṭle hũ ghare rahī.* — "I was tired, so I stayed at home."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**એટલે** (*eṭle*) is probably built from **એટલું**, "that much", with the **-ે** of **સવારે**: "to that point", and so "for that reason". CDIAL lists Gujarati *eṭlũ* under Sanskrit *iyattaka*, "so little" (CDIAL 1589); it has no row for **એટલે** itself.
