## You'll want to know: bloccarsi
<!-- hl-knowledge: introduces=[IT-LEX-C404-BLOCCO-01]; assesses=[] -->

**bloccarsi** — "to freeze, to get stuck".

> Se il computer si blocca, aspetta un minuto.
>
> *If the computer freezes, wait a minute.*

Of a door or a car too: *la porta si è bloccata*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*bloccarsi* is built on *blocco* "block", which was borrowed from French *bloc* "a heavy piece, a block" (EtymDB), from Middle Dutch *blok* "a tree trunk, a log".
