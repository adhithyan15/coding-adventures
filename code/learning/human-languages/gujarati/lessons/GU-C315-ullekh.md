# ઉલ્લેખ (ullekh) — a mention

## You'll want to know: ઉલ્લેખ
<!-- hl-knowledge: introduces=[GU-LEX-C315-UDGHATAN315-04]; assesses=[] -->

**ઉલ્લેખ** — *ullekh* — "a mention".

> છાપામાં અમારા ગામનો ઉલ્લેખ હતો.
>
> *chāpāmā̃ amārā gāmno ullekh hato.*
>
> Our village got a mention in the newspaper.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ઉલ્લેખ** (*ullekh*) is a tatsama, Sanskrit *ullekha*, "mentioning, speaking of" (Monier-Williams). Something is mentioned with **કરવું**: **ઉલ્લેખ કર્યો**.
