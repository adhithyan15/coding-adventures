# சஞ்சலம் (cañcalam) — unease; wavering

## You'll want to know: சஞ்சலம்
<!-- hl-knowledge: introduces=[TA-LEX-C455-KAVALAI455-01]; assesses=[] -->

**சஞ்சலம்** — *cañcalam* — "unease; wavering".

> முடிவு செய்ய முடியாமல் அவர் சஞ்சலத்தில் இருந்தார்.
>
> *muṭivu ceyya muṭiyāmal avar cañcalattil iruntār.*
>
> Unable to decide, he was uneasy.

The oblique -அத்து-: சஞ்சலத்தில், in a state of unease.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**சஞ்சலம்** (*cañcalam*) is borrowed from Sanskrit *cañcala*, "quivering, unsteady" (CDIAL 4568), with the Tamil noun ending -அம்.
