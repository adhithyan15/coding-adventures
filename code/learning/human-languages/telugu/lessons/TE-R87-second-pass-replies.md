# Keeping a conversation going — a second pass

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TE-LEX-C86-REPAIR-01, TE-LEX-C86-REPAIR-02, TE-LEX-C86-REPAIR-03] -->

[PAUSE 3s] Someone speaks fast and quietly. Ask for three things: slowly, louder, once more.

## Grammar Lens: the ending -గా
<!-- hl-knowledge: introduces=[]; assesses=[TE-LEX-C86-REPAIR-01, TE-LEX-C86-REPAIR-03, TE-LEX-C87-ANSWER-02, TE-LEX-C87-ANSWER-05] -->

| word | built from |
|---|---|
| **నెమ్మదిగా** | slow + -గా |
| **గట్టిగా** | firm + -గా |
| **సరిగ్గా** | right + -గా |
| **నిజంగా** | truth + -గా |

One ending, four manners. It is the same **-గా** that made *nāku caligā undi*.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[TE-LEX-C86-REPAIR-01, TE-LEX-C86-REPAIR-02, TE-LEX-C86-REPAIR-03, TE-LEX-C86-REPAIR-04, TE-LEX-C86-REPAIR-05, TE-LEX-C87-ANSWER-01, TE-LEX-C87-ANSWER-02, TE-LEX-C87-ANSWER-03, TE-LEX-C87-ANSWER-04, TE-LEX-C87-ANSWER-05] -->

[PAUSE 3s] Slowly? (**నెమ్మదిగా**.) Once more? (**ఇంకోసారి**.) Louder? (**గట్టిగా**.)
One minute? (**ఒక్క నిమిషం**.) Please wait? (**ఆగండి**.) My mistake? (**నా తప్పు**.)
Exactly? (**సరిగ్గా**.) Probably? (**బహుశా**.) I see? (**అలాగా**.) Really? (**నిజంగా**.)
