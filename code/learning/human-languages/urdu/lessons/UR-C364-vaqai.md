# واقعی (vāqaī) — really; truly

## You'll want to know: واقعی
<!-- hl-knowledge: introduces=[UR-LEX-C364-ZAHIR364-03]; assesses=[] -->

**واقعی** — *vāqaī* — "really; truly".

> اگر آپ واقعی بیمار ہیں تو گھر جائیے۔
>
> *agar āp vāqaī bīmār haiṅ to ghar jāiye.*
>
> If you really are ill, go home.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**واقعی** (*vāqaī*) is usually traced, through Persian, to Arabic *wāqiʿī*, "actual", built on *wāqiʿ*, "happening, real".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
