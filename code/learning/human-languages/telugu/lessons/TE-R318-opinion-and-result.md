# Review — opinion and result

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TE-LEX-C318-ANIPINCU-01, TE-SCRIPT-RECOG-174, TE-LEX-C317-ILOGA-01] -->

[PAUSE 2s] Say "it seemed hard to me". (*nāku kaṣṭaṅgā anipiñcindi*.) Then say "in the meantime".
(*īlōgā*.)
- [YOU WRITE: **ఈ**, the first letter of **ఈలోగా**, once]

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[TE-LEX-C318-ANIPINCU-01, TE-GRAMMAR-C318-THINK-THAT-01, TE-GRAMMAR-C318-IN-MY-OPINION-01, TE-GRAMMAR-C318-KABATTI-01, TE-GRAMMAR-C318-ANDUKE-RESULT-01, TE-GRAMMAR-C317-FIRST-THEN-01, TE-GRAMMAR-C317-CONJUNCTIVE-01, TE-GRAMMAR-C317-AFTER-DOING-01, TE-SKILL-C317-READ-STORY-01, TE-GRAMMAR-C317-CIVARIKI-01] -->

[PAUSE 2s each]
- [YOU SAY: I think this book is good.]
- [YOU SAY: In my opinion Telugu is not hard.]
- [YOU SAY: It is raining, so we did not go to the town.]
- [YOU SAY: I had a fever. That is why I stayed at home.]
- [YOU SAY: First we had a meal. After that we went to a film. In the end we came home.]
- [YOU SAY: the reading's trip in two sentences, with -ఇ forms]

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[TE-LEX-C318-ANIPINCU-01, TE-GRAMMAR-C318-THINK-THAT-01, TE-GRAMMAR-C318-IN-MY-OPINION-01, TE-GRAMMAR-C318-KABATTI-01, TE-GRAMMAR-C318-ANDUKE-RESULT-01] -->

[PAUSE 3s] "I think that …"? (**… అని అనుకుంటున్నాను**.) "In my opinion"? (**నా అభిప్రాయంలో**.) "It seems
to me"? (**నాకు … అనిపిస్తుంది**.) "So", after a reason? (**కాబట్టి**.) "That is why", opening a sentence?
(**అందుకే**.)
