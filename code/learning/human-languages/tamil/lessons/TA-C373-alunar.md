## You'll want to know: ஆளுநர்
<!-- hl-knowledge: introduces=[TA-LEX-C373-ARACIYAL373-04]; assesses=[] -->

**ஆளுநர்** — *āḷunar* — "a governor".

> ஆளுநர் இன்று விழாவில் கலந்துகொண்டார்.
>
> *āḷunar iṉṟu viḻāvil kalantukoṇṭār.*
>
> The governor attended the ceremony today.

ஆள், to rule + -நர், the one who.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ஆளுநர்** (*āḷunar*) is native: *āḷ*, "to rule, govern" (DEDR 5157), with the agent ending -நர்: "one who governs".
