# ಆತಿಥ್ಯ (ātithya) — hospitality

## You'll want to know: ಆತಿಥ್ಯ
<!-- hl-knowledge: introduces=[KA-LEX-C105-WISHES-03]; assesses=[] -->

**ಆತಿಥ್ಯ** (*ātithya*) — "hospitality", from **ಅತಿಥಿ** (*atithi*), "guest".

**ನಿಮ್ಮ ಆತಿಥ್ಯಕ್ಕೆ ಧನ್ಯವಾದ** (*nimma ātithyakke dhanyavāda*) — "thank you for your
hospitality".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

What a guest thanks the host for.
