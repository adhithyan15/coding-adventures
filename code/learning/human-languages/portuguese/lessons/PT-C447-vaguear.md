## You'll want to know: vaguear
<!-- hl-knowledge: introduces=[PT-LEX-C447-PASSEIO-02]; assesses=[] -->

**vaguear** — "to roam, to wander".

> Vagueámos pela cidade sem destino.
>
> *We roamed the town with no destination.*

Thoughts can *vaguear* too.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*vaguear* is built on *vago* 'wandering, vague', which is a learned borrowing from Latin *vagus* 'wandering' (EtymDB).
