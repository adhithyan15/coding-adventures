## You'll want to know: ಕುಳಿತುಕೋ
<!-- hl-knowledge: introduces=[KA-LEX-SIT]; assesses=[] -->

**ಕುಳಿತುಕೋ** (*kuḷitukō*) — "sit".

Longer than it looks: the *-ko* on the end is a reflexive, so it is closer to 'seat yourself' than to a bare order.
