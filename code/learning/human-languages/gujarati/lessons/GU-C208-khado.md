# ખાડો (khāḍo) — pothole, pit

## You'll want to know: ખાડો
<!-- hl-knowledge: introduces=[GU-LEX-C208-HIGHWAY208-02]; assesses=[] -->

**ખાડો** — *khāḍo* — "pothole, pit".

> **રસ્તામાં મોટો ખાડો હતો.** — *rastāmā̃ moṭo khāḍo hato* — "There was a big pothole in the road."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ખાડો** (*khāḍo*) is a tadbhava. CDIAL lists it, glossed "hole", under *\*khāḍa*, "a hollow", a reconstructed form that it compares with *\*khaḍḍa*, "hole, pit" (CDIAL 3860).
