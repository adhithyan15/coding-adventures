# mosaic-emit-react

React JSX backend for the Mosaic compiler. Implements `MosaicRenderer` to
produce React functional components (`.jsx`) from `.mosaic` source files.

## Overview

`mosaic-emit-react` is one of the output backends in the Mosaic compiler
pipeline:

```
.mosaic source
     │
     ▼
mosaic-analyzer  →  MosaicFile (IR)
     │
     ▼
MosaicVM  (drives MosaicRenderer callbacks)
     │
     └── mosaic-emit-react  →  MyComponent.jsx
```

## Mosaic node → React JSX mapping

| Mosaic   | JSX element                                              |
|----------|----------------------------------------------------------|
| `Box`    | `<div>`                                                  |
| `Column` | `<div style={{ display:'flex', flexDirection:'column' }}>` |
| `Row`    | `<div style={{ display:'flex', flexDirection:'row' }}>`  |
| `Text`   | `<span>` with text content                               |
| `Image`  | `<img src={...} alt={...} />`                            |
| `Spacer` | `<div style={{ flex: 1 }}>`                              |
| `Scroll` | `<div style={{ overflow:'auto' }}>`                      |
| `Divider`| `<hr />`                                                 |
| `Stack`  | `<div style={{ position:'relative' }}>`                  |
| `Icon`   | `<span className="icon">`                                |
| `Grid`   | `<table>` with `.map()` header and row rendering         |

## Slot → prop mapping

- `text` slots → `string` props
- `number` slots → `number` props
- `bool` slots → `boolean` props
- `image` slots → `string` props (URL)
- `list<T>` slots → `Array<T>` props → rendered via `.map()`
- `node` slots → `React.ReactNode` props

## Control flow

- `when @slot { ... }` → `{slot && (<>...</>)}`
- `each @items as item { ... }` → `{items.map((item, _idx) => (<>...</>))}`

## Output format

```tsx
// Auto-generated by mosaic-emit-react. Do not edit.
import React from "react";

interface ProfileCardProps {
  avatarUrl: string;
  displayName: string;
}

export function ProfileCard({ avatarUrl, displayName }: ProfileCardProps) {
  return (
    <div style={{ display: 'flex', flexDirection: 'column' }}>
      <span>{displayName}</span>
    </div>
  );
}
```

## Usage

### Via `mosaic-compile` CLI

```bash
mosaic-compile --backend react ProfileCard.mosaic
# Writes: ProfileCard.jsx
```

### Programmatically

```rust
use mosaic_emit_react::ReactRenderer;
use mosaic_vm::MosaicVM;
use mosaic_analyzer::analyze;

let file = analyze("component Label { slot title: text; Text { content: @title; } }").unwrap();
let vm = MosaicVM::new(file);
let result = vm.run(ReactRenderer::new()).unwrap();
println!("{}", result.output);
```

## Dependencies

- `mosaic-vm` — `MosaicRenderer` trait and `MosaicVM` driver
- `mosaic-analyzer` — `MosaicSlot` and `MosaicType` types

## Development

# Build
