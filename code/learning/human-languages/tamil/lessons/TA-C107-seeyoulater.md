## You'll want to know: அப்புறம் பார்க்கலாம்
<!-- hl-knowledge: introduces=[TA-LEX-C107-LEAVE-03]; assesses=[] -->

**அப்புறம் பார்க்கலாம்** (*appuṟam pārkkalām*) — "see you later".

**அப்புறம்** is "afterwards"; **பார்க்கலாம்** is "we can see (each other)". To one friend:
**உன்னை அப்புறம் பார்க்கிறேன்** — "I'll see you later", with **உன்னை**, "you" as the one it is
done to.

<!-- hl-knowledge: introduces=[]; assesses=[] -->

A casual goodbye.
