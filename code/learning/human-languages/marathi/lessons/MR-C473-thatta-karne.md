# थट्टा करणे (thaṭṭā karṇe) — to tease; to joke

## You'll want to know: थट्टा करणे
<!-- hl-knowledge: introduces=[MR-LEX-C473-KHODKAR473-05]; assesses=[] -->

**थट्टा करणे** — *thaṭṭā karṇe* — "to tease; to joke".

> मित्रांनी माझ्या टोपीची थट्टा केली.
>
> *mitrānnī mājhyā ṭopīcī thaṭṭā kelī.*
>
> My friends teased me about my cap.

Past, with -ने (he …): त्याने थट्टा केली, *tyāne thaṭṭā kelī*.

The target takes the genitive: भावाची थट्टा करणे.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**थट्टा करणे** (*thaṭṭā karṇe*) is a Marathi phrase built on थट्टा, "a joke", which CDIAL lists under the reconstructed *\*ṭhaṭṭha*, "joke" (CDIAL 5492), with करणे.

## What you've built
