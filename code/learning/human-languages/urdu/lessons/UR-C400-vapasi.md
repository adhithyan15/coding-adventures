## You'll want to know: واپسی
<!-- hl-knowledge: introduces=[UR-LEX-C400-PARDES400-05]; assesses=[] -->

**واپسی** — *vāpasī* — "a return; the way back".

> ہماری واپسی اگلے ہفتے ہے۔
>
> *hamārī vāpasī agle hafte hai.*
>
> We come back next week.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**واپسی** (*vāpasī*) is built on *vāpas*, "back", usually traced to Persian *vāpas*, with the ending *-ī*.
