# Formal practice — *Wie geht es Ihnen?*

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[GE-LEX-GUTEN-TAG-01, GE-PRAGMATICS-WELLBEING-REGISTER-02] -->

[PAUSE 2s] Same exchange, same order, same verb. One word changes throughout —
and that is the chapter's whole argument about German politeness.

## The exchange
<!-- hl-knowledge: introduces=[]; assesses=[GE-LEX-WIE-GEHT-ES-IHNEN-01, GE-LEX-GUT-02, GE-LEX-DANKE-01, GE-LEX-UND-DIR-02, GE-LEX-ES-GEHT-01, GE-LEX-BITTE-01] -->

| German | English |
|---|---|
| *Guten Tag. Wie geht es Ihnen?* | Good day. How are you? |
| *Danke, gut. Und Ihnen?* | Well, thanks. And you? |
| *Es geht.* | So-so. |
| *Danke!* — *Bitte.* | Thanks! — You're welcome. |

Set it beside the casual version and the difference is two words, both of them
the listener:

| | Casual | Formal |
|---|---|---|
| the question | *Wie geht's?* | *Wie geht es Ihnen?* |
| the return | *und dir?* | *und Ihnen?* |

*Danke*, *gut*, *es geht* and *bitte* do not shift at all. German courtesy words
are register-neutral; the politeness is carried entirely by the pronoun.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[GE-LEX-WIE-GEHT-ES-IHNEN-01, GE-LEX-IHNEN-01, GE-PRAGMATICS-WELLBEING-REGISTER-02] -->

[PAUSE 3s] Which greeting opens the formal exchange? (*Guten Tag.*) Which
dative pronoun appears twice? (*Ihnen.*) What changes from the casual version?
(*Dir* becomes *Ihnen* — nothing else.) Where does German keep its politeness?
(In the pronoun.)
