# सुरक्षारक्षक (surakṣārakṣak) — a security guard

## You'll want to know: सुरक्षारक्षक
<!-- hl-knowledge: introduces=[MR-LEX-C547-ANIBANI547-04]; assesses=[] -->

**सुरक्षारक्षक** — *surakṣārakṣak* — "a security guard".

> इमारतीच्या दारात एक सुरक्षारक्षक उभा असतो.
>
> *imārtīcyā dārāt ek surakṣārakṣak ubhā asto.*
>
> A security guard stands at the door of the building.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**सुरक्षारक्षक** (*surakṣārakṣak*) is a compound built from सुरक्षा, "safety", and Sanskrit *rakṣaka*, "a protector" (Monier-Williams).
