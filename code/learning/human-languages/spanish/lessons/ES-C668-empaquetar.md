## You'll want to know: empaquetar
<!-- hl-knowledge: introduces=[ES-LEX-C668-EQUIPAJE-02]; assesses=[] -->

**empaquetar** — "to pack up, to wrap up".

> Empaqueto los regalos antes del viaje.
>
> *I wrap up the presents before the trip.*

Built on *el paquete*, the parcel.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*empaquetar* is built on *paquete* "parcel", which came from French *paquet* (EtymDB), from Dutch *pak* "bundle".
