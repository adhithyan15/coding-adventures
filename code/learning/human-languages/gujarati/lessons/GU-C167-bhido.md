# ભીંડો (bhī̃ḍo) — okra, lady's finger

## You'll want to know: ભીંડો
<!-- hl-knowledge: introduces=[GU-LEX-C167-OKRA167-01]; assesses=[] -->

**ભીંડો** — *bhī̃ḍo* — "okra, lady's finger".

> **મને ભીંડાનું શાક ગમે છે.** — *mane bhī̃ḍānũ śāk game che* — "I like okra curry."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ભીંડો** (*bhī̃ḍo*) is a tadbhava. It comes from Sanskrit *bhiṇḍā*, the vegetable *Abelmoschus esculentus*, and CDIAL lists the Gujarati *bhĩḍo* (CDIAL 9492).
