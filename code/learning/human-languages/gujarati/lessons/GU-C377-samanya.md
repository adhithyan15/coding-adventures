# સામાન્ય (sāmānya) — normal; ordinary

## You'll want to know: સામાન્ય
<!-- hl-knowledge: introduces=[GU-LEX-C377-DASHA377-03]; assesses=[] -->

**સામાન્ય** — *sāmānya* — "normal; ordinary".

> જો બધું સામાન્ય રહેશે તો અમે સોમવારે પાછા આવીશું.
>
> *jo badhũ sāmānya raheśe to ame somvāre pāchā āvīśũ.*
>
> If all goes normally, we will be back on Monday.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**સામાન્ય** (*sāmānya*) is a tatsama, borrowed from Sanskrit *sāmānya*, "equal, alike, common" (Monier-Williams).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
