# پختہ (pukhtā) — firm; conclusive

## You'll want to know: پختہ
<!-- hl-knowledge: introduces=[UR-LEX-C336-SABIT336-02]; assesses=[] -->

**پختہ** — *pukhtā* — "firm; conclusive".

> اس کا ارادہ پختہ ہے۔
>
> *us kā irādā pukhtā hai.*
>
> Her mind is firmly made up.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**پختہ** (*pukhtā*) is usually traced to Persian *pukhta*, "cooked, ripe": what is fully done is firm.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
