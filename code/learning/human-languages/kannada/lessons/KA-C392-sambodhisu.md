## You'll want to know: ಸಂಬೋಧಿಸು
<!-- hl-knowledge: introduces=[KA-LEX-C392-CHUNAVANE392-05]; assesses=[] -->

**ಸಂಬೋಧಿಸು** — *sambōdhisu* — "to address a crowd".

> ಚುನಾವಣೆಗೆ ಮೊದಲು ಅವಳು ಊರಿನ ಜನರನ್ನು ಸಂಬೋಧಿಸಿದಳು.
>
> *cunāvaṇege modalu avaḷu ūrina janarannu sambōdhisidaḷu.*
>
> Before the election she addressed the townspeople.

Past (I …): ಸಂಬೋಧಿಸಿದೆ, *sambōdhiside*.

The audience takes -ಅನ್ನು. ಸಂಬೋಧನೆ, an address.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಸಂಬೋಧಿಸು** (*sambōdhisu*) is built on Sanskrit *saṃbodhana*, "calling to, addressing" (Monier-Williams), with the Kannada verb ending -*isu*.
