## You'll want to know: divampare
<!-- hl-knowledge: introduces=[IT-LEX-C302-INCENDIO-02]; assesses=[] -->

**divampare** — "to flare up, to break out (of a fire)".

> Il fuoco è divampato in pochi minuti.
>
> *The fire flared up in a few minutes.*

With *essere*: *è divampato*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*divampare* is built on *vampa* "a blaze, a flame" with *di-* (EtymDB); *vampa* is usually traced to Latin *vapor* "steam, heat".
