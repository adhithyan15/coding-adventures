# வாக்களி (vākkaḷi) — to vote

## You'll want to know: வாக்களி
<!-- hl-knowledge: introduces=[TA-LEX-C374-TERTAL374-03]; assesses=[] -->

**வாக்களி** — *vākkaḷi* — "to vote".

> நான் முதல் முறையாக வாக்களித்தேன்.
>
> *nāṉ mutal muṟaiyāka vākkaḷittēṉ.*
>
> I voted for the first time.

Past (I …): வாக்களித்தேன், *vākkaḷittēṉ*.

For whom: X-க்கு வாக்களி. வாக்கு, a vote; வாக்காளர், a voter.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**வாக்களி** (*vākkaḷi*) is built from *vākku*, "word, vote", borrowed from Sanskrit *vāc*, "speech, word" (Monier-Williams), and native *aḷi*, "to show favour, to grant" (DEDR 301, where Malayalam *aḷikkuka* means "to bestow"): to grant one's word.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
