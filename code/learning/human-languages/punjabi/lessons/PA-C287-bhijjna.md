# ਭਿੱਜਣਾ (bhijjṇā) — to get wet

## You'll want to know: ਭਿੱਜਣਾ
<!-- hl-knowledge: introduces=[PA-LEX-C287-WET287-02]; assesses=[] -->

**ਭਿੱਜਣਾ** — *bhijjṇā* — "to get wet".

> ਜੇ ਮੀਂਹ ਆਵੇਗਾ ਤਾਂ ਅਸੀਂ ਭਿੱਜਾਂਗੇ।
>
> *je mīṁh āvegā tāṁ asīṁ bhijjāṅge.*
>
> If the rain comes, we will get wet.

Past (I …): ਮੈਂ ਮੀਂਹ ਵਿੱਚ ਭਿੱਜਿਆ, *maiṁ mīṁh vich bhijjiā*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ਭਿੱਜਣਾ** (*bhijjṇā*) is inherited from a reconstructed *\*bhiyajyatē*, "is smeared, gets wet"; CDIAL lists Punjabi *bhijjṇā*, "to get wet", under it (CDIAL 9502).
