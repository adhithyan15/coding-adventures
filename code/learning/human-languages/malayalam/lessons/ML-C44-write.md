<!-- hl-knowledge: introduces=[ML-LEX-WRITE]; assesses=[] -->

**എഴുതൂ** (*eḻutū*) — "write".

From *eḻuttu*, 'letter' — the writing verb is built from the thing written, which is the reverse of how Kannada does it.
