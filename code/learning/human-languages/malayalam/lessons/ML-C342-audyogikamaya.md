# ഔദ്യോഗികമായ (audyōgikamāya) — official

## You'll want to know: ഔദ്യോഗികമായ
<!-- hl-knowledge: introduces=[ML-LEX-C342-AUDYOGIKAMAYA-01]; assesses=[ML-LEX-C324-VASTU324-01, ML-LEX-C126-ABOUTYOU-03, ML-GRAMMAR-C83-OBLIQUE-AM-01, ML-GRAMMAR-C342-ANAM-01] -->

**ഔദ്യോഗികമായ** — *audyōgikamāya* — "official": of an office, done formally.

> **ഇത് ഒരു ഔദ്യോഗികമായ രേഖയാണ്.**
>
> *itŭ oru audyōgikamāya rēkhayāṇŭ.* — "This is an official document."

In set phrases it stands before its noun without **-മായ**:

> **മലയാളം കേരളത്തിന്റെ ഔദ്യോഗിക ഭാഷയാണ്.**
>
> *malayāḷaṁ kēraḷattinṟe audyōgika bhāṣayāṇŭ.* — "Malayalam is the official language of Kerala."

With **-ആയി** it becomes **ഔദ്യോഗികമായി** (*audyōgikamāyi*), "officially". Its first letter is new; the next
lesson takes it out and puts it in your hand.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ഔദ്യോഗികമായ** (*audyōgikamāya*) is a learned word built the Sanskrit way on *udyoga*,
"undertaking, exertion" (Monier-Williams), which Malayalam took up for a post in an office:
**ഉദ്യോഗസ്ഥൻ**, "an officer", is the same root. Strengthening the first vowel, *u* to *au*,
and adding *-ika* makes "having to do with" it, so "of the office". The Malayalam **-മായ** then
makes it an adjective.
