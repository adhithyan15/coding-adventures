# : ( ) - / — the four that are left, two at a time

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-PUNCT-COMMA-01, ML-PUNCT-FULL-STOP-01] -->

[PAUSE 2s] Name the three marks you already own, and say where each one stands.

## Script you'll notice: : ( )
<!-- hl-knowledge: introduces=[ML-PUNCT-COLON-01, ML-PUNCT-PARENS-01]; assesses=[] -->

Four marks are left, and all four behave the way their English counterparts
do. This lesson takes the first two; the next takes the hyphen and the slash.

| | |
|---|---|
| **:** | the colon — before a list, or before the thing you are about to spell out |
| **( )** | parentheses — a pair, around an aside |

The colon and the parentheses take no space on the inside and one on the
outside.

## Writing: the two
<!-- hl-knowledge: introduces=[]; assesses=[ML-PUNCT-COLON-01, ML-PUNCT-PARENS-01] -->

Two dots, one above the other, on the line. A pair of curves facing each other.

Neither changes the Malayalam letter beside it.
