## You'll want to know: ambicioso
<!-- hl-knowledge: introduces=[ES-LEX-C595-CARRERA-04]; assesses=[] -->

**ambicioso** — "ambitious".

> Es un proyecto muy ambicioso.
>
> *It is a very ambitious project.*

It can be good or bad: *una persona ambiciosa*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*ambicioso* is a learned borrowing from Latin *ambitiosus* (EtymDB), built on *ambitio* 'a going round to ask for votes', from *ambire* 'to go round'.
