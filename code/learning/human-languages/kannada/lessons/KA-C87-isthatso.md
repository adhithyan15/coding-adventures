# ಹೌದಾ (haudā) — is that so?

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C87-REPLIES-02, KA-LEX-C87-REPLIES-03] -->

[PAUSE 2s] Before the new one: say the Kannada for nothing, then the Kannada for oh no.

## You'll want to know: ಹೌದಾ
<!-- hl-knowledge: introduces=[KA-LEX-C87-REPLIES-04]; assesses=[] -->

**ಹೌದಾ?** (*haudā?*) — "is that so?", "really?". It is **ಹೌದು** (*haudu*), "yes",
with the question ending **‑ಆ**.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

Yes, turned into a question.
