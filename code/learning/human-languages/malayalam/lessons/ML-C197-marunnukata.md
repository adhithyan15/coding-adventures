## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**മരുന്നുകട** (*marunnukaṭa*) is native Dravidian, "medicine shop": *marunnŭ*, "medicine" (DEDR 4719, with Tamil *maruntu*), and *kaṭa*, "shop" (DEDR 1142).
