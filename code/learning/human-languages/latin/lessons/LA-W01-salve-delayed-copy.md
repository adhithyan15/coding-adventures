# salvē — look, hide, write, check

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[LA-PHONO-SALVE-01, LA-ETYMON-SALVE-02] -->

Say **salvē** once: *SAL-weh*, “be well.” Its sound and meaning are already
familiar. Today only the amount of visual help changes.

## Writing — delayed copy
<!-- hl-knowledge: introduces=[]; assesses=[LA-PHONO-SALVE-01, LA-ETYMON-SALVE-02, LA-GRAMMAR-SALVE-03] -->
<!-- hl-writing-stage: delayed-copy -->
<!-- hl-activity: {"id":"LA-W01-salve-delayed-copy-check","kind":"text","assesses":["LA-PHONO-SALVE-01","LA-ETYMON-SALVE-02","LA-GRAMMAR-SALVE-03"],"prompt":"Cover the model and write the one-person Latin greeting meaning be well. Then uncover it and check every letter and the macron.","answer":"salvē","accepted":[],"feedback":{"correct":"Yes: salvē has all five letters and the final long-vowel macron.","incorrect":"Uncover salvē, compare s-a-l-v-ē, repair only the differing feature, and cover it again."},"response_seconds":20} -->

Look at **salvē** for five seconds. Notice the five letters and the short macron
over the final **ē**. Cover the model completely. From memory, write the greeting
once. Say *SAL-weh* as you finish.

Uncover the model and compare one feature at a time: **s-a-l-v-ē**. If one feature
differs, repair only that feature. This is one gentle memory step, not a speed test.

## Wrap-up recall
<!-- hl-knowledge: introduces=[]; assesses=[LA-PHONO-SALVE-01, LA-ETYMON-SALVE-02] -->

Writing pass: **1/1** only when the covered-model attempt contains **s-a-l-v-ē**
with the macron. Saying the greeting correctly does not replace the writing point.
