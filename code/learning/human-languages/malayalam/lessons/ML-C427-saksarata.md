## You'll want to know: സാക്ഷരത
<!-- hl-knowledge: introduces=[ML-LEX-C427-DARIDRYAM427-05]; assesses=[] -->

**സാക്ഷരത** — *sākṣarata* — "literacy".

> ആ ഗ്രാമത്തിലെ സാക്ഷരത കുറവാണ്.
>
> *ā grāmattile sākṣarata kuṟavāṇŭ.*
>
> Literacy in that village is low.

A literate person is സാക്ഷരൻ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**സാക്ഷരത** (*sākṣarata*) is built from Sanskrit *sākṣara*, "containing letters" (CDIAL 13320): *sa-*, "with", and *akṣara*, "a letter", with the abstract ending -ത.
