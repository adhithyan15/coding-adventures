# తప్పు (tappu) — a mistake; wrong

## You'll want to know: తప్పు
<!-- hl-knowledge: introduces=[TE-LEX-C87-ANSWER-01]; assesses=[] -->

**తప్పు** (*tappu*) — "a mistake", and as a reply, "wrong".

**క్షమించండి, నా తప్పు** — "sorry, my mistake".

You have met it before without seeing it: **తప్పకుండా**, "certainly", is built on the verb
behind this word, "to slip, to miss". Certainly is *without slipping*.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

A word for a mistake, and the word for certainly finally explained.
