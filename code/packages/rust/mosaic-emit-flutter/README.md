# mosaic-emit-flutter

The Flutter (Dart) backend for the Mosaic UI compiler. Consumes the
three-IR triple (`.mil` + `.mll` + `.msl`) and emits a Dart source
file containing a `StatelessWidget` class. Drops directly into a
Flutter `lib/` directory.

## Where it fits in the stack

```
.mil + .mll + .msl
        │
        ▼
mosaic-emit-flutter::pipeline::from_pipeline
        │
        ▼
.dart file with:
  - import 'package:flutter/material.dart';
  - sealed class XEvent { ... } + subclasses per emit
  - class X extends StatelessWidget { build(BuildContext ctx) { ... } }
```

The crate sits alongside the other six Mosaic emit crates:
- `mosaic-emit-react`     (TSX)
- `mosaic-emit-swiftui`   (Swift)
- `mosaic-emit-qt`        (QML)
- `mosaic-emit-html`      (static HTML)
- `mosaic-emit-webcomponent` (JS + shadow DOM)
- `mosaic-emit-xaml`      (WinUI3 XAML + C# code-behind)
- **`mosaic-emit-flutter`** (Dart Flutter widgets) ← this crate

## Usage

```rust
use mosaic_emit_flutter::pipeline::from_pipeline;

let result = from_pipeline(&interface, &layout, &style)?;
std::fs::write("lib/grid.dart", &result.output)?;
```

Or via the `mosaic-compile` CLI:

```
mosaic-compile --backend flutter \
  --interface Grid.mil \
  --layout    Grid.desktop.mll \
  --style     Grid.dark.msl    \
  -o          lib/grid.dart
```

(The CLI wiring lands when `mosaic-package-artifact-builder` adds
the `Backend::Flutter` variant — see the next-PR plan in the
overnight loop notes.)

## Generated output shape

For an interface like:

```mosaic
component Greeting {
  slot name : text ;
  emit  onClick ;
}
```

`from_pipeline` produces:

```dart
// Auto-generated by mosaic-emit-flutter. Do not edit.
import 'package:flutter/material.dart';

sealed class GreetingEvent {
  const GreetingEvent();
}

class GreetingEventClick extends GreetingEvent {
  const GreetingEventClick();
}

class Greeting extends StatelessWidget {
  final String name;
  final void Function(GreetingEvent) dispatch;

  const Greeting({
    super.key,
    required this.name,
    required this.dispatch,
  });

  @override
  Widget build(BuildContext context) {
    return
      Text(name)
      ;
  }
}
```

(Whitespace and exact formatting are illustrative; the real
generator emits valid but unformatted Dart — pass through
`dart format` in the host's build pipeline if you want
indentation polish.)

## What works in v0.1 / what's deferred

See `CHANGELOG.md` for the full feature matrix. The headline:

- ✅ Containers (Box / Row / Column / Stack), leaves (Text / Image /
  Spacer / Divider / Icon), and the most-used host primitives
  (HostInput / HostButton / HostCheckbox / HostRadio / HostScroll)
  are wired with a passing test each.
- 🚧 HostDialog, HostTable, the For/If/Else meta-primitives, and
  full dispatch payload synthesis are deferred to follow-up PRs.
