## You'll want to know: предавать
<!-- hl-knowledge: introduces=[RU-LEX-C479-TRUST-03]; assesses=[] -->

**предавать** (*predavát*) — "to betray".

> Настоящий друг никогда не предаёт.
>
> *Nastoyáshchiy drug nikogdá ne predayót.*
>
> A true friend never betrays you.

Imperfective; present предаю, предаёшь (-ава- becomes -а-). Perfective предать.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*предавать* is built on *пред-* and *давать* 'to give', so to betray is to hand someone over; the root is inherited from Proto-Slavic *dati* 'to give' (EtymDB).
