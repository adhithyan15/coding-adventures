## You'll want to know: gonfiare
<!-- hl-knowledge: introduces=[IT-LEX-C409-GOMMA-05]; assesses=[] -->

**gonfiare** — "to pump up, to inflate".

> Dal benzinaio puoi gonfiare le gomme.
>
> *At the petrol station you can pump up the tyres.*

*Gonfiare un palloncino* — to blow up a balloon.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*gonfiare* is inherited from Latin *conflāre* 'to blow together, to kindle' (EtymDB), built on *flāre* 'to blow'.
