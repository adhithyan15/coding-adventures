## You'll want to know: تمتع
<!-- hl-knowledge: introduces=[AR-LEX-C408-MASLAHA408-02]; assesses=[] -->

**تمتع** — *tamattaʿa* — "to enjoy a right".

> يتمتع المواطنون بحقوق كثيرة.
>
> *yatamattaʿu al-muwāṭinūn bi-ḥuqūq kathīra.*
>
> Citizens enjoy many rights.

Present: يتمتع, *yatamattaʿ*.

It takes بـ: تمتع بـ ….

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**تمتع** (*tamattaʿa*) is built on the native Arabic root *m-t-ʿ*, "to have the use of" (Lane). It is Form V, to take the use of a thing for oneself: to enjoy it. ممتع, enjoyable, is from the same root.
