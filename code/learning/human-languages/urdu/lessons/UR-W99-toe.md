# ط (toe) — the letter that opens طرف

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[UR-SCRIPT-C37-HAMZA-SEAT-01, UR-SCRIPT-C99-ZE-01] -->

[PAUSE 2s] Before the new one: write ئ and ز once each, and name them.

[PAUSE 2s] Now say **طرف** (*taraf*), "a side, a direction".
You have read it for a long time. This lesson takes one letter out of it and puts
it in your hand.

## Script you'll notice: ط
<!-- hl-knowledge: introduces=[UR-SCRIPT-C99-TOE-01]; assesses=[] -->

**ط** — *toe*, a plain *t* sound, the same as **ت**.

It opens **طرف** (*taraf*), "a side, a direction". You already write **ظ**: a
flat loop on the line with a tall upright stroke. **ط** is that shape with **no
dot**. Urdu keeps it for words that came from Arabic.

## Writing: ط
<!-- hl-knowledge: introduces=[]; assesses=[UR-SCRIPT-C99-TOE-01] -->

- **1.** start here: draw the independent to'e-series loop
- **2.** continue through its leftward finish without lifting
- **3.** after one lift, draw the tall upright — and only now lift

**Pen lifts: 1.**

> Stroke order is one attested teaching order; hands and teachers vary.
> Source: Zer o Zabar, To’e, zo’e, se, zhe, and ġhain, independent ط handwriting animation and To’e instructions (Northwestern University Libraries Open Textbook, 2026).
