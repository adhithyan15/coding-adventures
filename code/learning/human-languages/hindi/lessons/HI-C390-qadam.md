## You'll want to know: क़दम
<!-- hl-knowledge: introduces=[HI-LEX-C390-LAKSHYA390-04]; assesses=[] -->

**क़दम** — *qadam* — "a step".

> अगर हम हर दिन एक क़दम आगे बढ़ेंगे तो एक दिन ज़रूर पहुँचेंगे।
>
> *agar ham har din ek qadam āge baṛheṅge to ek din zarūr pahuñceṅge.*
>
> If we move one step forward every day, we'll get there one day.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**क़दम** (*qadam*) is usually traced to Arabic *qadam*, "a foot, a step", which reached Hindi through Persian.
