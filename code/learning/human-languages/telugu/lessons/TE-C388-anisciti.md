# అనిశ్చితి (aniściti) — uncertainty

## You'll want to know: అనిశ్చితి
<!-- hl-knowledge: introduces=[TE-LEX-C388-SANDEHAM388-05]; assesses=[] -->

**అనిశ్చితి** — *aniściti* — "uncertainty".

> ఉద్యోగాల విషయంలో చాలా అనిశ్చితి ఉంది.
>
> *udyōgāla viṣayaṁlō cālā aniściti undi.*
>
> There is a lot of uncertainty about jobs.

అ- means not: అనిశ్చితి is the lack of నిశ్చయం.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**అనిశ్చితి** (*aniściti*) is built from Sanskrit *a-*, "not", and *niściti*, "ascertainment, settling" (Monier-Williams), a word of the same family as నిశ్చయం.

## What you've built

One more word for giving reasons and opinions.
