# عجوبہ (ajūbā) — a wonder; a marvel

## You'll want to know: عجوبہ
<!-- hl-knowledge: introduces=[UR-LEX-C442-SURPRISE442-04]; assesses=[] -->

**عجوبہ** — *ajūbā* — "a wonder; a marvel".

> یہ پرانا محل ایک عجوبہ ہے۔
>
> *yih purānā mahal ek ajūbā hai.*
>
> This old palace is a marvel.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**عجوبہ** (*ajūbā*) is usually traced, through Persian, to Arabic *uʿjūba*, "something to wonder at".

<!-- hl-knowledge: introduces=[]; assesses=[] -->
