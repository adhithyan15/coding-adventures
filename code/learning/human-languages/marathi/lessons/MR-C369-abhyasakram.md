## You'll want to know: अभ्यासक्रम
<!-- hl-knowledge: introduces=[MR-LEX-C369-VIDYAPITH369-02]; assesses=[] -->

**अभ्यासक्रम** — *abhyāsakram* — "a syllabus; a course of study".

> या वर्षी अभ्यासक्रम बदलला आहे.
>
> *yā varṣī abhyāsakram badallā āhe.*
>
> The syllabus has changed this year.

Masculine.

Built on अभ्यास, study: the order of study.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**अभ्यासक्रम** (*abhyāsakram*) is a learned compound built from Sanskrit *abhyāsa*, "repetition, study", and *krama*, "step, series" (Monier-Williams).
