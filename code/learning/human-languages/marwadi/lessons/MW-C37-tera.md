# तेरा — thirteen on the page

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MW-LEX-TERA-01, MW-LEX-IGYAARA-01, MW-SCRIPT-AAKHRI-01] -->

[PAUSE 14s]
- [YOU RECALL: say *terā* before you look at it — **R1**]
- [YOU RECALL: say *igyārā*, five lessons back — **R2**]
- [YOU RECALL: write **आखरी** — **R4**]

## You'll want to know
<!-- hl-knowledge: introduces=[MW-SCRIPT-TERA-01]; assesses=[MW-SCRIPT-TA-01, MW-SCRIPT-E-MATRA-01, MW-SCRIPT-RA-01] -->

> **ते** + **रा** → **तेरा** — *terā* — thirteen

The **े** above **त** is the mark chapter 7 taught and chapter 32 stood up as
the letter **ए**. Here it is doing its ordinary job again, riding on a
consonant.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-TERA-01, MW-SCRIPT-BAARA-01] -->
<!-- hl-writing-stage: delayed-copy -->

Write **तेरा** from memory after five seconds covered. Then write **बारा** and
**इग्यारा** beneath it and read the three down the page, ending in **रा** each
time.
