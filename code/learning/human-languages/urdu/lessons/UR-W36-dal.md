# د (dāl) — the letter inside خدا

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[UR-SCRIPT-C35-KHE-01, UR-SCRIPT-C35-CHE-01] -->

[PAUSE 2s] Before the new one: write خ and چ once each, and name them.

[PAUSE 2s] Now say **خدا** (*khudā*), "God".
You have read it for a long time. This lesson takes one letter out of it and puts
it in your hand.

## Script you'll notice: د
<!-- hl-knowledge: introduces=[UR-SCRIPT-C36-DAL-01]; assesses=[] -->

**د** — *dāl*, the sound *d*.

It is inside **خدا** (*khudā*). Like **ا** and **و**, which you already write, **د**
refuses to join leftward: it joins the letter before it, never the one after.

## Writing: د
<!-- hl-knowledge: introduces=[]; assesses=[UR-SCRIPT-C36-DAL-01] -->

- **1.** start here: begin at the independent form's upper tip and descend through the folded shoulder
- **2.** turn left along the baseline without lifting — and only now lift

**Pen lifts: 0.** The pen never leaves the paper.

> Stroke order is one attested teaching order; hands and teachers vary.
> Source: Zer o Zabar, Dāl, re, and wāw, independent د handwriting animation and Dāl instructions (Northwestern University Libraries Open Textbook, 2026).

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[UR-SCRIPT-C35-KHE-01, UR-SCRIPT-C35-CHE-01, UR-SCRIPT-C36-DAL-01] -->

[PAUSE 1s]
- [YOU LOOK: at **خدا** and point at د inside it]
- [YOU TRACE: د three times, saying *d* as you finish each one]
- [YOU WRITE: چ, then د, from memory]
- [YOU READ: **خدا** aloud once more]

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[UR-SCRIPT-C35-KHE-01, UR-SCRIPT-C35-CHE-01, UR-SCRIPT-C36-DAL-01] -->

[PAUSE 3s] Which letter is this — د? (**dāl**, *d*.) Which word did it
come from? (**خدا**, *khudā*, "God".)
