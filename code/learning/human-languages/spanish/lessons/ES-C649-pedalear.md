## You'll want to know: pedalear
<!-- hl-knowledge: introduces=[ES-LEX-C649-RUEDAS-04]; assesses=[] -->

**pedalear** — "to pedal".

> Pedaleo una hora cada mañana.
>
> *I pedal for an hour every morning.*

Built on *el pedal*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*pedalear* is built on *pedal*, a learned borrowing from Latin *pedālis* "of the foot" (EtymDB), from *pēs, pedis* "foot".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling, explaining and describing at B1.
