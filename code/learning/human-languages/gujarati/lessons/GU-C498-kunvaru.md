# કુંવારું (kunvārũ) — unmarried

## You'll want to know: કુંવારું
<!-- hl-knowledge: introduces=[GU-LEX-C498-VIDAY498-03]; assesses=[] -->

**કુંવારું** — *kunvārũ* — "unmarried".

> મારા મામા હજી કુંવારા છે.
>
> *mārā māmā hajī kunvārā che.*
>
> My uncle is still unmarried.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**કુંવારું** (*kunvārũ*) is inherited from Sanskrit *kumāra*, "a boy, a youth"; CDIAL lists the Gujarati word, "unmarried" (CDIAL 3303).
