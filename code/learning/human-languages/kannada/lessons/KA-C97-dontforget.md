# ಮರೆಯಬೇಡಿ (mareyabēḍi) — please don't forget

<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C97-GRATEFUL-02, KA-LEX-C97-GRATEFUL-03] -->

## You'll want to know: ಮರೆಯಬೇಡಿ
<!-- hl-knowledge: introduces=[KA-LEX-C97-GRATEFUL-04]; assesses=[] -->

**ಮರೆಯಬೇಡಿ** (*mareyabēḍi*) — "please don't forget", from **ಮರೆ** (*mare*), "to
forget", with the polite **‑ಬೇಡಿ** of **ಚಿಂತೆ ಮಾಡಬೇಡಿ**.
