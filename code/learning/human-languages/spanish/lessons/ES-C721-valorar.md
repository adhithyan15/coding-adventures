## You'll want to know: valorar
<!-- hl-knowledge: introduces=[ES-LEX-C721-CARACTER-05]; assesses=[] -->

**valorar** — "to value, to appreciate".

> Valoro mucho a mis amigos.
>
> *I really value my friends.*

Also to assess: *valorar los daños*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*valorar* is built on *valor* "worth", which comes from Late Latin *valor*, from *valēre* "to be strong, to be worth" (EtymDB).
