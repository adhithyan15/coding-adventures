## You'll want to know: आचरति
<!-- hl-knowledge: introduces=[SA-LEX-C330-PARAMPARA330-03]; assesses=[] -->

**आचरति** — *ācarati* — "observes; practises".

> वयम् अद्य अपि प्राचीनां रीतिम् आचरामः।
>
> *vayam adya api prācīnāṃ rītim ācarāmaḥ.*
>
> We still observe the old custom today.

Past (he …): सः प्राचीनां रीतिम् आचरितवान्, *saḥ prācīnāṃ rītim ācaritavān*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**आचरति** (*ācarati*) is built from *ā* and the root √car, "to move", as in *carati*; MW gives *ā-car* as to approach, to behave, and to act, practise, perform (MW).
