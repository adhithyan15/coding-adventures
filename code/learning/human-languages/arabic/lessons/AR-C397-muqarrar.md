## You'll want to know: مقرر
<!-- hl-knowledge: introduces=[AR-LEX-C397-SHAHADA397-04]; assesses=[] -->

**مقرر** — *muqarrar* — "a syllabus".

> هذا الكتاب جزء من المقرر.
>
> *hādhā al-kitāb juzʾ min al-muqarrar.*
>
> This book is part of the syllabus.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**مقرر** (*muqarrar*) is built on the native Arabic root *q-r-r*, "to settle, to be still" (Lane). *Muqarrar* is the Form II passive participle, what has been fixed: a set syllabus. قرار, a decision, is from the same root.
