# Return to a familiar completed action

## Warm-up

[YOU HEAR: *Aman; kamm; kiitaa*] Say **ਅਮਨ · ਕੰਮ · ਕੀਤਾ**.

## Grammar Lens
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-KAMM-05, PA-FORM-KITA-190] -->

**ਕੰਮ** is familiar “work.” **ਕੀਤਾ** is the familiar completed form in
**ਮੈਂ ਕੰਮ ਕੀਤਾ**. In that old frame it agrees with the unmarked work object.
Keep those pieces ready; the next lesson adds one small marker to a named
person's completed action.
