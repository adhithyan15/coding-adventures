## You'll want to know: امتیاز
<!-- hl-knowledge: introduces=[UR-LEX-C344-BARABAR344-02]; assesses=[] -->

**امتیاز** — *imtiyāz* — "discrimination; a distinction".

> ہمارے اسکول میں کوئی امتیاز نہیں ہوتا۔
>
> *hamāre iskūl meṅ koī imtiyāz nahīṅ hotā.*
>
> There is no discrimination in our school.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**امتیاز** (*imtiyāz*) is usually traced, through Persian, to Arabic *imtiyāz*, "being set apart, distinction".
