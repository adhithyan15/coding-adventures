### Added

- First Dart G2D00 immutable Point/Rect value types, with vector operations,
  strict sub-threshold normalization, local PHY00 angle routing, and
  half-open bounding-box behavior.
- Native tests for the G2D00 contract plus direct consumption of all four
  checked Point2D normalization fixtures from the mixed geometry corpus.
- Local trig path dependency, capability declaration, formatting/analyzer
  checks, and a 95% coverage requirement in BUILD and BUILD_windows.
