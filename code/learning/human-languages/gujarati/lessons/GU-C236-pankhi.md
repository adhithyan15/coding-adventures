## You'll want to know: પંખી
<!-- hl-knowledge: introduces=[GU-LEX-C236-NEEM236-01]; assesses=[] -->

**પંખી** — *pankhī* — "bird".

> **સવારે એક પંખી આવ્યું.** — *savāre ek pankhī āvyũ* — "A bird came in the morning."

Not **પંખો**, a fan.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**પંખી** (*pankhī*) is a tadbhava. It comes from Sanskrit *pakṣin*, "winged; bird", built on *pakṣa*, "wing" (CDIAL 7636).
