## You'll want to know: নকশা
<!-- hl-knowledge: introduces=[BN-LEX-C524-TULI524-03]; assesses=[] -->

**নকশা** — *nôkshā* — "a design; a pattern".

> শাড়িটার নকশা সুন্দর।
>
> *Shāṛiṭār nôkshā sundôr.*
>
> The sari's pattern is beautiful.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**নকশা** (*nôkshā*) is usually traced to Arabic *naqsh*, "a drawing, an engraving", through Persian *naqsha*.
