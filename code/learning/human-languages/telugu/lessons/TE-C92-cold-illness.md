# జలుబు (jalubu) — a cold, a runny nose

## You'll want to know: జలుబు
<!-- hl-knowledge: introduces=[TE-LEX-C92-DOCTOR-01]; assesses=[] -->

**జలుబు** (*jalubu*) — "a cold", the kind with a runny nose.

**నాకు జలుబు చేసింది** — "I have caught a cold", literally "a cold has done to me". Telugu
keeps this apart from **చలి**, the cold of the weather.

## What you've built

The illness, next to the weather word you already have.
