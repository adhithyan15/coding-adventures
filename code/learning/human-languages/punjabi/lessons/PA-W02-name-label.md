# ਨਾਂ — the first form label

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-SCRIPT-NA-01, PA-SCRIPT-AA-MATRA-01, PA-SCRIPT-BINDI-01] -->

Build the known pieces aloud: **ਨ + ਾ + ਂ**.

## Script — read the label
<!-- hl-knowledge: introduces=[PA-FORM-LABEL-NAME-01]; assesses=[PA-LEX-NAAM-02] -->

> **ਨਾਂ: __________**

On a form, **ਨਾਂ** asks for a name. The colon belongs to the form; it is not a
Gurmukhi letter. Point to the label, then point to the empty answer line.

## Writing — one label
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-LABEL-NAME-01] -->

Copy **ਨਾਂ** once. Check the base **ਨ**, then the long-vowel mark, then the nasal
dot. Do not add a name value yet.
