# ஒருமனதாக (orumaṉatāka) — unanimously

## You'll want to know: ஒருமனதாக
<!-- hl-knowledge: introduces=[TA-LEX-C397-MAKKALATCI397-03]; assesses=[] -->

**ஒருமனதாக** — *orumaṉatāka* — "unanimously".

> கூட்டத்தில் இந்தத் தீர்மானம் ஒருமனதாக நிறைவேறியது.
>
> *kūṭṭattil intat tīrmāṉam orumaṉatāka niṟaivēṟiyatu.*
>
> The resolution was passed unanimously at the meeting.

ஒரு, one + மனம், mind + -ஆக: with one mind.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ஒருமனதாக** (*orumaṉatāka*) is built from native *oru*, "one" (DEDR 990), and *maṉam*, "mind", borrowed from Sanskrit *manas* (CDIAL 9822), with the adverb ending -ஆக.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
