## You'll want to know: примерять
<!-- hl-knowledge: introduces=[RU-LEX-C453-PRIMERKA-02]; assesses=[] -->

**примерять** (*primeryát*) — "to try on".

> Она долго примеряла платья.
>
> *Oná dólgo primeryála plátya.*
>
> She spent a long time trying on dresses.

Imperfective; perfective *примерить* (*примерю, примеришь*).

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*примерять* is built from *при-* and *мерять*, *мерить* 'to measure', which EtymDB builds on Proto-Slavic *měra* 'a measure'.
