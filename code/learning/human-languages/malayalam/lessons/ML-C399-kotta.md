## You'll want to know: കോട്ട
<!-- hl-knowledge: introduces=[ML-LEX-C399-SAMRAJYAM399-02]; assesses=[] -->

**കോട്ട** — *kōṭṭa* — "a fort".

> കടൽത്തീരത്ത് ഒരു പഴയ കോട്ട ഉണ്ട്.
>
> *kaṭalttīrattŭ oru paḻaya kōṭṭa uṇṭŭ.*
>
> There is an old fort on the seashore.

Plural കോട്ടകൾ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**കോട്ട** (*kōṭṭa*) is native Dravidian: DEDR 2207 lists Malayalam *kōṭṭa*, "fort, residence", beside Tamil *kōṭṭai*, "fort, castle".
