## You'll want to know: piovigginare
<!-- hl-knowledge: introduces=[IT-LEX-C470-PIOGGIA-01]; assesses=[] -->

**piovigginare** — "to drizzle".

> Pioviggina, ma non serve l'ombrello.
>
> *It is drizzling, but there is no need for an umbrella.*

*La pioggerella* — drizzle.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*piovigginare* is built on *piovere* 'to rain' (EtymDB), which is inherited from Vulgar Latin *plovere*, from Latin *pluere*.
