## You'll want to know: शक्यः
<!-- hl-knowledge: introduces=[SA-LEX-C389-SHAKYA389-01]; assesses=[] -->

**शक्यः** — *śakyaḥ* — "possible; able to be done".

> यदि समयः अस्ति, तर्हि एतत् कार्यं शक्यम्।
>
> *yadi samayaḥ asti, tarhi etat kāryaṃ śakyam.*
>
> If there is time, this work can be done.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**शक्यः** (*śakyaḥ*) comes from the root √śak, "to be able"; MW gives *śakya* "able, possible, practicable" (MW).
