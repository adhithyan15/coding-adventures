# রেওয়াজ (reoyāj) — a custom; a common practice

## You'll want to know: রেওয়াজ
<!-- hl-knowledge: introduces=[BN-LEX-C353-RITI353-01]; assesses=[] -->

**রেওয়াজ** — *reoyāj* — "a custom; a common practice".

> বিয়েতে এই রেওয়াজ পুরনো।
>
> *biyete ei reoyāj purôno.*
>
> This wedding custom is old.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**রেওয়াজ** (*reoyāj*) is Persian *rivāj*, currency and so a custom in general use, usually traced to Arabic: what people commonly do.
