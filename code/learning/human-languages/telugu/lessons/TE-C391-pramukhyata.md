# ప్రాముఖ్యత (prāmukhyata) — importance; significance

## You'll want to know: ప్రాముఖ్యత
<!-- hl-knowledge: introduces=[TE-LEX-C391-PRAMUKHYATA391-01]; assesses=[] -->

**ప్రాముఖ్యత** — *prāmukhyata* — "importance; significance".

> ఆరోగ్యానికి మనం ఎక్కువ ప్రాముఖ్యత ఇవ్వాలి.
>
> *ārōgyāniki manaṁ ekkuva prāmukhyata ivvāli.*
>
> We should give more importance to health.

ప్రాముఖ్యత ఇచ్చు, to give importance; the thing takes -కి.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ప్రాముఖ్యత** (*prāmukhyata*) is built on Sanskrit *pramukha*, "facing; first, foremost, chief" (Monier-Williams), with the abstract ending -త.

## What you've built

One more word for giving reasons and opinions.
