# ಮರುಪಾವತಿ (marupāvati) — a refund; a repayment

## You'll want to know: ಮರುಪಾವತಿ
<!-- hl-knowledge: introduces=[KA-LEX-C461-ATITHI461-05]; assesses=[] -->

**ಮರುಪಾವತಿ** — *marupāvati* — "a refund; a repayment".

> ಟಿಕೆಟ್ ರದ್ದು ಮಾಡಿದ್ದರಿಂದ ನನಗೆ ಮರುಪಾವತಿ ಸಿಕ್ಕಿತು.
>
> *ṭikeṭ raddu māḍiddarinda nanage marupāvati sikkitu.*
>
> Because I cancelled the ticket I got a refund.

ಮರು-, back or again, plus ಪಾವತಿ, a payment, as in ಪಾವತಿಸು, to pay.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಮರುಪಾವತಿ** (*marupāvati*) joins the native prefix *maṟu*, "again, back" (DEDR 4766), and *pāvati*, "a payment", whose own source is not settled.
