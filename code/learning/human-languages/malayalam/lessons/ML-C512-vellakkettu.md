# വെള്ളക്കെട്ട് (veḷḷakkeṭṭŭ) — waterlogging

## You'll want to know: വെള്ളക്കെട്ട്
<!-- hl-knowledge: introduces=[ML-LEX-C512-PRALAYAM512-02]; assesses=[] -->

**വെള്ളക്കെട്ട്** — *veḷḷakkeṭṭŭ* — "waterlogging".

> മഴ പെയ്താൽ ആ വഴിയിൽ വെള്ളക്കെട്ട് ഉണ്ടാകും.
>
> *maḻa peytāl ā vaḻiyil veḷḷakkeṭṭŭ uṇṭākuṁ.*
>
> When it rains, that road gets waterlogged.

വെള്ളം, water, plus കെട്ട്, a tying up: water that cannot drain away.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**വെള്ളക്കെട്ട്** (*veḷḷakkeṭṭŭ*) is a native Dravidian compound of വെള്ളം, water, and കെട്ട്, a tying or damming (DEDR 1147).
