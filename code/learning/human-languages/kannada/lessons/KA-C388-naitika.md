# ನೈತಿಕ (naitika) — ethical; moral

## You'll want to know: ನೈತಿಕ
<!-- hl-knowledge: introduces=[KA-LEX-C388-NAITIKA388-01]; assesses=[] -->

**ನೈತಿಕ** — *naitika* — "ethical; moral".

> ಇದು ಹಣದ ಪ್ರಶ್ನೆ ಅಲ್ಲ, ನೈತಿಕ ಪ್ರಶ್ನೆ.
>
> *idu haṇada praśne alla, naitika praśne.*
>
> This is not a question of money but a moral one.

ನೈತಿಕತೆ, morality.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ನೈತಿಕ** (*naitika*) is built on Sanskrit *nīti*, "conduct, right behaviour" (CDIAL 7546), with the adjective ending -*ika*.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
