# தலைமுறை (talaimuṟai) — a generation

## You'll want to know: தலைமுறை
<!-- hl-knowledge: introduces=[TA-LEX-C494-MARAPU494-03]; assesses=[] -->

**தலைமுறை** — *talaimuṟai* — "a generation".

> எங்கள் வீட்டில் மூன்று தலைமுறைகள் ஒன்றாக வாழ்கின்றன.
>
> *eṅkaḷ vīṭṭil mūṉṟu talaimuṟaikaḷ oṉṟāka vāḻkiṉṟaṉa.*
>
> Three generations live together in our house.

Plural: தலைமுறைகள், *talaimuṟaikaḷ*.

தலை "head" + முறை "turn, order".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**தலைமுறை** (*talaimuṟai*) is a native compound of தலை *talai*, "head" (DEDR 3103), and முறை *muṟai*, "order, turn" (DEDR 5015).
