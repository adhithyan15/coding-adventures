# துரோகம் (turōkam) — betrayal

## You'll want to know: துரோகம்
<!-- hl-knowledge: introduces=[TA-LEX-C470-VICUVACAM470-02]; assesses=[] -->

**துரோகம்** — *turōkam* — "betrayal".

> அவர் நம்பிய நண்பனே அவருக்குத் துரோகம் செய்தான்.
>
> *avar nampiya naṇpaṉē avarukkut turōkam ceytāṉ.*
>
> The very friend he trusted betrayed him.

துரோகம் செய், to betray; the one betrayed takes -க்கு.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**துரோகம்** (*turōkam*) is borrowed from Sanskrit *drōha*, "injury, treachery" (Monier-Williams); Tamil opens the *dr* with a vowel.
