# ઉખેડવું (ukheḍvũ) — to uproot, to pull up

## You'll want to know: ઉખેડવું
<!-- hl-knowledge: introduces=[GU-LEX-C241-BLOOM241-04]; assesses=[] -->

**ઉખેડવું** — *ukheḍvũ* — "to uproot, to pull up".

> **મેં સૂકો છોડ ઉખેડ્યો.** — *mẽ sūko choḍ ukheḍyo* — "I pulled up the dry plant."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ઉખેડવું** (*ukheḍvũ*) is a tadbhava. It comes from *\*utskarati*, "digs out", a reconstructed form; CDIAL glosses the Gujarati verb "to root up" (CDIAL 1895).
