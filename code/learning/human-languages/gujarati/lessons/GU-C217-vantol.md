# વંટોળ (vanṭoḷ) — whirlwind

## You'll want to know: વંટોળ
<!-- hl-knowledge: introduces=[GU-LEX-C217-WIND217-04]; assesses=[] -->

**વંટોળ** — *vanṭoḷ* — "whirlwind".

> **ઉનાળામાં વંટોળ આવશે.** — *unāḷāmā̃ vanṭoḷ āvśe* — "Whirlwinds will come in summer."

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

The origin of **વંટોળ** (*vanṭoḷ*) is not settled. CDIAL has Sanskrit *vātālī*, "whirlwind", built on *vāta*, "wind", but lists no Gujarati form under it (CDIAL 11500).
