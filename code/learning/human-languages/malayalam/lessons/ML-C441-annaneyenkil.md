# അങ്ങനെയെങ്കിൽ (aṅṅaneyeṅkil) — in that case

[PAUSE 2s] Before the new one: say the Malayalam for impossible, then the Malayalam for to make possible.

## You'll want to know: അങ്ങനെയെങ്കിൽ
<!-- hl-knowledge: introduces=[ML-LEX-C441-SADHYAM441-04]; assesses=[] -->

**അങ്ങനെയെങ്കിൽ** — *aṅṅaneyeṅkil* — "in that case".

> അവൻ വരില്ലെന്ന് പറഞ്ഞു, അങ്ങനെയെങ്കിൽ നമ്മൾ നേരത്തെ പോകും.
>
> *avan varillennŭ paṟaññu, aṅṅaneyeṅkil nammaḷ nēratte pōkuṁ.*
>
> He said he won't come; in that case we will leave early.

അങ്ങനെ, like that, with -എങ്കിൽ, if: if it is like that.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**അങ്ങനെയെങ്കിൽ** (*aṅṅaneyeṅkil*) is native Dravidian: അങ്ങനെ, "in that way", from the far demonstrative അ- (DEDR 1), with -എങ്കിൽ, "if".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
