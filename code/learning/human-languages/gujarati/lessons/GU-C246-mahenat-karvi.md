# મહેનત કરવી (mahenat karvī) — to work hard

## You'll want to know: મહેનત કરવી
<!-- hl-knowledge: introduces=[GU-LEX-C246-MARKS246-05]; assesses=[] -->

**મહેનત કરવી** — *mahenat karvī* — "to work hard".

> **અમે પરિણામ માટે મહેનત કરીએ છીએ.** — *ame pariṇām māṭe mahenat karīe chīe* — "We work hard for the results."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**મહેનત કરવી** (*mahenat karvī*) is built from *mahenat*, "hard work", a loan from Arabic *miḥnat*, "trial, affliction", which reached Gujarati through Persian (Lane), and the verb *karvī*, "to do".
