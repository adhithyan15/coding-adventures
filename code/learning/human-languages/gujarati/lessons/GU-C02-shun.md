# શું (shũ) — "what"

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[GU-CONCEPT-C02-NAAM-01] -->

[PAUSE 2s] The question-word — and the one Gujarati question that does *not* start
with k-.

## The letters in this word
<!-- hl-knowledge: introduces=[GU-CONCEPT-C02-SHUN-01]; assesses=[GU-CONCEPT-C02-NAAM-01] -->

**શ** (*sha*) + the *u*-sign + nasal → **શું** (*shũ*).

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[GU-CONCEPT-C02-NAAM-01, GU-CONCEPT-C02-SHUN-01] -->

**શું** (*shũ*, "what") descends, by a winding road, from the Sanskrit
interrogative stem **ક-** (*ka-*, PIE **\*kʷo-**) — the root behind English
**what**, Latin *quis*, and Hindi *kyā*. Most of Gujarati's questions still show
that **k-** plainly — **કેમ** (*kem*, how), **કોણ** (*kōṇ*, who), **ક્યાં**
(*kyā̃*, where), **ક્યારે** (*kyāre*, when) — but "what" wore down into this
*sh-* form. So *shũ* is the odd cousin in a *k-* family.
