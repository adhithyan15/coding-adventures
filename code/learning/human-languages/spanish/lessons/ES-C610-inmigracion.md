## You'll want to know: la inmigración
<!-- hl-knowledge: introduces=[ES-LEX-C610-CONVIVIR-04]; assesses=[] -->

**la inmigración** — "the immigration".

> La inmigración cambia el país.
>
> *Immigration changes the country.*

*El inmigrante* — the immigrant.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*inmigración* is a learned word built on Latin *immigrare* 'to move into', from *migrare* 'to move house' (Lewis & Short).

<!-- hl-knowledge: introduces=[]; assesses=[] -->
