## You'll want to know: справляться
<!-- hl-knowledge: introduces=[RU-LEX-C359-OBYAZANNOSTI-05]; assesses=[] -->

**справляться** (*spravlyátsya*) — "to cope, to manage".

> Я не справляюсь с работой один.
>
> *Ya ne spravlyáyus s rabótoy odín.*
>
> I cannot cope with the work on my own.

Imperfective; perfective *справиться* (*справлюсь, справишься*). It takes *с* + instrumental.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**справляться** is built on *править* "to set straight, to steer", from *правый* "right", inherited from Proto-Slavic *\*pravŭ* "right, correct" (EtymDB). To cope is to set a thing straight.
