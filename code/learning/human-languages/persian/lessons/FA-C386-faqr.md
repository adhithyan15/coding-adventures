## You'll want to know: فقر
<!-- hl-knowledge: introduces=[FA-LEX-C386-BARABARI-04]; assesses=[] -->

**فقر** (*faqr*) — "poverty".

> فقر هنوز یک مشکل بزرگ است.
>
> *faqr hanuz yek moshkel-e bozorg ast.*
>
> Poverty is still a big problem.

*Faqir* "poor" belongs to the same family.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**فقر** was borrowed from Arabic *faqr* "poverty" (EtymDB), from the same Arabic family as *faqīr* "poor", the source of Persian *faqir*.
