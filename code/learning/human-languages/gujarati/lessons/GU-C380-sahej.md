## You'll want to know: સહેજ
<!-- hl-knowledge: introduces=[GU-LEX-C380-PURTU380-04]; assesses=[] -->

**સહેજ** — *sahej* — "slightly".

> જો તમે સહેજ ખસશો તો અમે પણ બેસી શકીશું.
>
> *jo tame sahej khasśo to ame paṇ besī śakīśũ.*
>
> If you move up slightly, we will be able to sit too.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**સહેજ** (*sahej*) is usually traced to Sanskrit *sahaja*, "born together, innate, natural" (Monier-Williams); "slightly, easily" is a Gujarati sense the source does not give.
