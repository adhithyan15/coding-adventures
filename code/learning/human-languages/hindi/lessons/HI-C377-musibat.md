# मुसीबत (musībat) — a hardship, trouble

## You'll want to know: मुसीबत
<!-- hl-knowledge: introduces=[HI-LEX-C377-HALAT377-04]; assesses=[] -->

**मुसीबत** — *musībat* — "a hardship, trouble".

> अगर तुम झूठ बोलोगे तो मुसीबत में पड़ोगे।
>
> *agar tum jhūṭh bologe to musībat meṁ paṛoge.*
>
> If you lie, you'll land in trouble.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**मुसीबत** (*musībat*) is usually traced to Arabic *muṣība*, "a misfortune", which reached Hindi through Persian.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
