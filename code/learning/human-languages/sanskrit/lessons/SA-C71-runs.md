## You'll want to know: धावति
<!-- hl-knowledge: introduces=[SA-LEX-C71-MOVE-01]; assesses=[] -->

**धावति** (*dhāvati*) — "(he, she) runs". It ends in **-ति** like **गच्छति**: one
person, doing it now.
