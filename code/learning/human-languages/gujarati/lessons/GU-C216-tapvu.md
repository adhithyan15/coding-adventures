# તપવું (tapvũ) — to blaze, to be hot

## You'll want to know: તપવું
<!-- hl-knowledge: introduces=[GU-LEX-C216-HEAT216-01]; assesses=[] -->

**તપવું** — *tapvũ* — "to blaze, to be hot".

> **બપોરે સૂરજ તપશે.** — *bapore sūraj tapśe* — "The sun will blaze at midday."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**તપવું** (*tapvũ*) is usually traced to Sanskrit *tapyati*, "is hot". CDIAL does not list *tapvũ* itself, but it lists the related Gujarati *tāpvũ*, "to warm oneself", under the same entry (CDIAL 5684).
