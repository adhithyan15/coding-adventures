## You'll want to know: પગલું
<!-- hl-knowledge: introduces=[GU-LEX-C287-PAGLU287-02]; assesses=[] -->

**પગલું** — *paglũ* — "a footstep".

> હવે બધું આ પગલાં પર આધાર રાખે છે.
>
> *have badhũ ā paglā̃ par ādhār rākhe che.*
>
> Now everything rests on these footprints.

A neuter noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**પગલું** (*paglũ*) is built on **પગ**, a foot, which CDIAL sets under Sanskrit *padga-* (CDIAL 7766), with the ending *-lũ*. It is a step, and the sound or the print a step leaves: **કોઈનાં પગલાં**, someone's footsteps.
