## You'll want to know: la tasa
<!-- hl-knowledge: introduces=[ES-LEX-C663-TEMPORADA-01]; assesses=[] -->

**la tasa** — "the tax, the fee; the rate".

> El hotel cobra una tasa turística.
>
> *The hotel charges a tourist tax.*

*La tasa turística* — the tourist tax. *La tasa de paro* — the unemployment rate.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*tasa* is built on *tasar* "to value, to set a price on", which is inherited from Latin *taxāre* "to assess, to rate" (EtymDB).
