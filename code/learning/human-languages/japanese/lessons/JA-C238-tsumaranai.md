## You'll want to know: つまらない
<!-- hl-knowledge: introduces=[JA-LEX-C238-BOOKS238-05]; assesses=[] -->

**つまらない** — *tsumaranai* — "boring; dull".

> **きのう つまらない えいがを みました。** — *kinō tsumaranai eiga o mimashita* — "Yesterday I watched a boring film."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**つまらない** (*tsumaranai*) is a native Japanese word (wago), inherited rather than borrowed: it is built from *tsumaru*, "to be packed", with the negative ending *-nai*, and it is usually written in kana (JMdict, KANJIDIC2).
