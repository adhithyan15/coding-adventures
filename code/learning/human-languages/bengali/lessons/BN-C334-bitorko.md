# বিতর্ক (bitôrkô) — a debate

## You'll want to know: বিতর্ক
<!-- hl-knowledge: introduces=[BN-LEX-C334-APOTTI334-02]; assesses=[] -->

**বিতর্ক** — *bitôrkô* — "a debate".

> কাল স্কুলে একটা বিতর্ক হবে।
>
> *kāl skule ekṭā bitôrkô hôbe.*
>
> There will be a debate at school tomorrow.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**বিতর্ক** (*bitôrkô*) is Sanskrit *vitarka*, a weighing of guesses and doubts (Monier-Williams). Bengali uses it for a formal debate between two sides; that use is modern.

<!-- hl-knowledge: introduces=[]; assesses=[] -->
