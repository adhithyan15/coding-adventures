## You'll want to know: きっぷ
<!-- hl-knowledge: introduces=[JA-LEX-ANCHOR-KIPPU]; assesses=[JA-SCRIPT-KI-01, JA-SCRIPT-SMALL-TSU-01] -->

**きっぷ** — *kippu* — "a ticket", above all the one you buy for a train.

Three beats: *ki–p–pu*. **き** and the small **っ** you already write. The
last sign is **ふ** with the small circle, so *fu* becomes *pu*. The next
lesson writes it.
