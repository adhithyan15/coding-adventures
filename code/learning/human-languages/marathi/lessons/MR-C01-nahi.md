# नाही (nāhī) — "no," a word older than English

## Warm-up

[PAUSE 2s] The partner of *ho* — built on one of the oldest words in the whole
Indo-European family.

## The letters in this word

*(Skim if you read Devanagari.)* **ना** (*nā*) + **ही** (*hī*) → **nāhī**.

## The word, taken apart

**नाही** (*nāhī*, "no / is not") sits on the ancient negative **na-** — the
*same* Proto-Indo-European **\*ne** behind English **no**, **not**, **none**,
Latin *non*, and Hindi *nahīṁ*. So Marathi's "no" and English's "no" are cousins
from before either language existed. It doubles as "there isn't": Marathi, like
Hindi, denies with this one word.
