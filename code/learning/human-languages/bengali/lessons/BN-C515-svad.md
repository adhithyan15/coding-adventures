## You'll want to know: স্বাদ
<!-- hl-knowledge: introduces=[BN-LEX-C515-PORIBESHON515-03]; assesses=[] -->

**স্বাদ** — *svād* — "a taste; a flavour".

> এই তরকারির স্বাদ ভালো।
>
> *Ei tôrkārir svād bhālo.*
>
> This curry tastes good.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**স্বাদ** (*svād*) is a tatsama, Sanskrit *svāda*, "taste, flavour" (Monier-Williams).
