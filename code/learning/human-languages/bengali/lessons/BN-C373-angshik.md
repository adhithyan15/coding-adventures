# আংশিক (āngshik) — partial; in part

## You'll want to know: আংশিক
<!-- hl-knowledge: introduces=[BN-LEX-C373-EKEBARE373-05]; assesses=[] -->

**আংশিক** — *āngshik* — "partial; in part".

> জল কম থাকলে কারখানা আংশিক বন্ধ থাকবে।
>
> *jôl kôm thākle kārkhānā āngshik bôndhô thākbe.*
>
> If water is short, the factory will be partly shut.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**আংশিক** (*āngshik*) is built on Sanskrit *aṃśa*, a share or part (Monier-Williams), with the adjective ending *-ika*: 'in part'. The adjective itself is a later formation.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
