# سواء (sawāʾ) — whether

## You'll want to know: سواء
<!-- hl-knowledge: introduces=[AR-LEX-C400-KULLAMA400-04]; assesses=[] -->

**سواء** — *sawāʾ* — "whether".

> سنخرج سواء أمطرت أم لا.
>
> *sa-nakhruju sawāʾ amṭarat am lā.*
>
> We will go out whether it rains or not.

It pairs with أم: سواء … أم ….

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**سواء** (*sawāʾ*) is built on the native Arabic root *s-w-y*, "to be equal, level" (Lane). *Sawāʾ* is equality: it is all the same, whether one thing or the other.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
