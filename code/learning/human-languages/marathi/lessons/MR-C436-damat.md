# दमट (damaṭ) — humid

## You'll want to know: दमट
<!-- hl-knowledge: introduces=[MR-LEX-C436-UKADA436-04]; assesses=[] -->

**दमट** — *damaṭ* — "humid".

> समुद्राजवळची हवा दमट असते.
>
> *samudrājavaḷcī havā damaṭ aste.*
>
> The air near the sea is humid.

It does not change: दमट हवा, दमट कपडे.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**दमट** (*damaṭ*) is a Marathi adjective for damp, sticky air; its origin is not settled.
