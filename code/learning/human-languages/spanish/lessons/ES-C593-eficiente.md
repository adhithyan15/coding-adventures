## You'll want to know: eficiente
<!-- hl-knowledge: introduces=[ES-LEX-C593-TAREA-05]; assesses=[] -->

**eficiente** — "efficient".

> Es una trabajadora muy eficiente.
>
> *She is a very efficient worker.*

The same for both genders.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*eficiente* is a learned borrowing from Latin *efficiens* 'bringing about' (EtymDB), from *efficere*, built from *ex* and *facere* 'to make'.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling, explaining and describing at B1.
