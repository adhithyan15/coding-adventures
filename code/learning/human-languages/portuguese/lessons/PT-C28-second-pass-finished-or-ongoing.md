# Finished, or still going on

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PT-GRAMMAR-TENHO-FALADO-03] -->

[PAUSE 3s] **Tenho falado.** Say what it means in English before reading on. If
your answer was "I have spoken", the page is about to disagree with you.

## Grammar Lens: the compound that means something else
<!-- hl-knowledge: introduces=[]; assesses=[PT-GRAMMAR-TENHO-FALADO-03] -->

| Portuguese | English |
|---|---|
| **falei** | I spoke — one finished event |
| **tenho falado** | I **have been** speaking — repeatedly, lately |

*Ter* + participle looks exactly like the French and Italian compound past and
does a different job. It is the single most common mistake an English speaker
makes in Portuguese, because the form invites the wrong reading and the wrong
reading is almost never corrected out loud.

The test to apply: **was it one event, or has it been going on?** One event
takes **falei**. Going on takes **tenho falado**.

## What you've built — the goodbyes draw the same line
<!-- hl-knowledge: introduces=[]; assesses=[PT-LEX-C04-PRACTICE-02, PT-NOTICE-C04-PRACTICE-03] -->

Portuguese makes the same cut where it takes its leave:

| | |
|---|---|
| **adeus** | finished — "to God", no return named |
| **até logo · até amanhã · até breve** | still going on — each names a return |

One closes the account; the others leave it open. The same instinct that keeps
**falei** apart from **tenho falado** is at work in choosing between them, and
noticing it once is easier than learning the two rules separately.
