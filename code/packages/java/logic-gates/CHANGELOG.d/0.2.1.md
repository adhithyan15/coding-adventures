## [0.2.1] — 2026-11-24

### Security
- `AND_N`, `OR_N`, `XOR_N` no longer throw `NullPointerException` on a null array; they throw the new `InvalidShapeException` (extends `IllegalArgumentException`, has `getParameter()`). CWE-476/CWE-20.
- The input array is cloned once and validated and computed from the private copy only, closing the check-then-use window where a concurrent writer could make `XOR_N` return a non-bit (CWE-367).
- Arrays longer than `LogicGates.MAX_INPUTS` (65536) are rejected with `InvalidShapeException`.
- All three gates report the first invalid element as `inputs[i]` (previously AND_N/OR_N reported "a"/"b").
