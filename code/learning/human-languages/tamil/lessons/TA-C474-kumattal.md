# குமட்டல் (kumaṭṭal) — nausea

## You'll want to know: குமட்டல்
<!-- hl-knowledge: introduces=[TA-LEX-C474-NOY474-02]; assesses=[] -->

**குமட்டல்** — *kumaṭṭal* — "nausea".

> பேருந்தில் பயணம் செய்தபோது எனக்குக் குமட்டல் வந்தது.
>
> *pēruntil payaṇam ceytapōtu eṉakkuk kumaṭṭal vantatu.*
>
> I felt sick while travelling by bus.

Dative experiencer: எனக்குக் குமட்டல் வந்தது, I felt nauseous.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**குமட்டல்** (*kumaṭṭal*) is native Dravidian, a noun from குமட்டு *kumaṭṭu*, "to retch, to feel like vomiting" (DEDR 1739).
