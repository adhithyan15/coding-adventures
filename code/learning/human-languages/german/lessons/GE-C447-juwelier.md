## You'll want to know: der Juwelier
<!-- hl-knowledge: introduces=[GE-LEX-C447-FRISEUR-05]; assesses=[] -->

**der Juwelier** — "the jeweller (US: jeweler)".

> Beim Juwelier kaufen sie die Ringe für die Hochzeit.
>
> *They buy the wedding rings at the jeweller's.*

Plural: *die Juweliere*. A woman: *die Juwelierin*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*Juwelier* is built on *Juwel* 'jewel', which came from Old French *joiel* (EtymDB), usually traced to Vulgar Latin *jocāle*, built on Latin *jocus* 'joke, play'.
