# అబ్బాయి (abbāyi) — a boy; a son

## You'll want to know: అబ్బాయి
<!-- hl-knowledge: introduces=[TE-LEX-C88-PEOPLE-02]; assesses=[] -->

**అబ్బాయి** (*abbāyi*) — "a boy", and in a family, "a son".

**మా అబ్బాయి** — "our boy", which is how a parent says "my son" out loud.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

A word for a boy that doubles as the everyday word for a son.
