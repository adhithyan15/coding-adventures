## You'll want to know: அப்போது
<!-- hl-knowledge: introduces=[TA-LEX-C79-WHEN-02]; assesses=[] -->

**அப்போது** (*appōdu*) — "then, at that time".

The third seat was empty and now it is filled:

| | | |
|---|---|---|
| **இப்போது** | *ippōdu* | now |
| **அப்போது** | *appōdu* | then |
| **எப்போது** | *eppōdu* | when? |

Near, far, question — the same three fronts you first met on இங்கே, அங்கே, எங்கே.

*Then* in Tamil means a time somebody has already named. It looks backwards, the way அதனால்
does, and for the same reason: both begin on the **a-** that means *that one, over there*.

> **நாளை. அப்போது சொல்லுங்கள்.** — "Tomorrow. Tell me then."
