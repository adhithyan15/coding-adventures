# ग — the start of heat

<!-- hl-knowledge: introduces=[]; assesses=[MW-LEX-GARMI-01, MW-SCRIPT-GHA-01, MW-LEX-MAUSAM-01, MW-SCRIPT-AU-MATRA-01, MW-SCRIPT-MHARO-01, MW-SCRIPT-WELLBEING-QUESTION-01, MW-LEX-HAATH-01] -->

and **म्हारो**.

## Script — one sign
<!-- hl-knowledge: introduces=[MW-SCRIPT-GA-01]; assesses=[] -->

> **ग** — *ga*

Compare **ग** with aspirated **घ**; this word begins with the unaspirated sign.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-GA-01] -->
<!-- hl-writing-stage: observe-trace -->

Trace once, copy once, cover the model, and write **ग** from sound.
