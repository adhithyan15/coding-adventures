## You'll want to know: feige
<!-- hl-knowledge: introduces=[GE-LEX-C477-MUT-02]; assesses=[] -->

**feige** — "cowardly".

> Es war feige, einfach wegzulaufen.
>
> *It was cowardly to simply run away.*

Not to be confused with *die Feige* — the fig.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*feige* is inherited from Old High German *feigi* "doomed to die", from Proto-Germanic *faigijaz* (EtymDB); English *fey* is a cousin.
