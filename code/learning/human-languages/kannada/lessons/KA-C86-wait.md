# ಕಾಯಿರಿ (kāyiri) — please wait

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C85-SLOWLY-05, KA-LEX-C86-WAIT-01] -->

[PAUSE 2s] Before the new one: say the Kannada for please write it, then the Kannada for one minute.

## You'll want to know: ಕಾಯಿರಿ
<!-- hl-knowledge: introduces=[KA-LEX-C86-WAIT-02]; assesses=[] -->

**ಕಾಯಿರಿ** (*kāyiri*) — "please wait", the polite form of **ಕಾಯು** (*kāyu*),
"to wait".

**ಒಂದು ನಿಮಿಷ ಕಾಯಿರಿ** (*ondu nimiṣa kāyiri*) — "please wait a minute".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

The polite ending ‑ಇರಿ asks gently.
