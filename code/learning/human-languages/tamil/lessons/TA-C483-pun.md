# புண் (puṇ) — a sore; an ulcer

## You'll want to know: புண்
<!-- hl-knowledge: introduces=[TA-LEX-C483-TOL483-01]; assesses=[] -->

**புண்** — *puṇ* — "a sore; an ulcer".

> வாயில் புண் இருந்ததால் காரமாகச் சாப்பிட முடியவில்லை.
>
> *vāyil puṇ iruntatāl kāramākac cāppiṭa muṭiyavillai.*
>
> I had a mouth ulcer, so I could not eat spicy food.

வாய்ப் புண், a mouth ulcer.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**புண்** (*puṇ*) is native Dravidian (DEDR 4268), for a wound or sore.
