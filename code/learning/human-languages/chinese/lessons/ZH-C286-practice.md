## The exchange
<!-- hl-knowledge: introduces=[ZH-PERFORMANCE-FEELING-01]; assesses=[ZH-GRAMMAR-FEELING-01, ZH-LEX-C286-GANJUE-01, ZH-GRAMMAR-DURATION-01, ZH-LEX-C286-DUOJIU-01, ZH-LEX-C286-YIHAN-01, ZH-GRAMMAR-GUO-EXPERIENCE-01, ZH-LEX-C283-ZAI-01, ZH-LEX-C47-DATE47-01, ZH-LEX-C83-WAIT83-01, ZH-LEX-ZENMEYANG-01] -->

> **A:** 你去过中国吗
>
> *nǐ qù guo Zhōngguó ma* — Have you been to China?
>
> **B:** 去过 我在中国学了一年汉语
>
> *qù guo, wǒ zài Zhōngguó xué le yì nián Hànyǔ* — I have. I studied Chinese there for a year.
>
> **A:** *nǐ gǎnjué zěnmeyàng* — How did it feel?
>
> **B:** 我感觉很好
>
> *wǒ gǎnjué hěn hǎo* — It felt good.
>
> **A:** *nǐ zài Zhōngguó zhù le duōjiǔ* — How long did you live there?
>
> **B:** 一年
>
> *yì nián* — A year.
>
> **A:** 你想再去吗
>
> *nǐ xiǎng zài qù ma* — Do you want to go again?
>
> **B:** *xiǎng, méiyǒu shíjiān, tài yíhàn le* — I do, but there's no time. What a pity.

A asks with 过, then with 感觉, then with *duōjiǔ*; B answers each in as few words as will do: 去过, 一年.

## What you've built — how it was
<!-- hl-knowledge: introduces=[]; assesses=[ZH-PERFORMANCE-FEELING-01, ZH-SCRIPT-GAN-01, ZH-LEX-C286-GANJUE-01, ZH-GRAMMAR-FEELING-01, ZH-GRAMMAR-DURATION-01, ZH-LEX-C286-DUOJIU-01, ZH-LEX-C286-YIHAN-01] -->

How it felt, how long it lasted, and how you feel about it now:

- **那天我感觉很开心** *nà tiān wǒ gǎnjué hěn kāixīn* — how it felt.
- **我学了两年汉语** *wǒ xué le liǎng nián Hànyǔ* — how long.
- *nǐ xué le duōjiǔ?* — asking how long.
- *tài yíhàn le* — a pity.

**Listen.** *Nǐ zài nàr zhù le duōjiǔ?*

**Speak.** Tell someone about a place you stayed: how long, and how it felt.
