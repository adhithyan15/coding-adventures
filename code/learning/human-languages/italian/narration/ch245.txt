Lesson 2 of 5.

You'll want to know: ruvido.
ruvido — "rough".

The word, taken apart.
ruvido from Vulgar Latin rugidus, "wrinkled", built on Latin ruga, "a wrinkle" — inherited. (EtymDB 2.1).

sconosciuto — "unknown".

The word, taken apart.
sconosciuto is s-, "un-", plus conosciuto, "known", from conoscere, "to know", which goes back to Latin cognoscere. EtymDB 2.1 has no row for it.
