## You'll want to know: gesetzlich
<!-- hl-knowledge: introduces=[GE-LEX-C385-AUSNAHME-03]; assesses=[] -->

**gesetzlich** — "legal, laid down by law".

> Der Mindestlohn ist gesetzlich geregelt.
>
> *The minimum wage is laid down by law.*

*Gesetzlich verboten* — prohibited by law. *Der gesetzliche Feiertag* — the public holiday.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*gesetzlich* is built with *-lich* on *Gesetz* "law", which EtymDB derives from *setzen* "to set", Proto-Germanic *satjaną*: what has been set down.
