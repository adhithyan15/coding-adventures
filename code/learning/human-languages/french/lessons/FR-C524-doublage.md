## You'll want to know: le doublage
<!-- hl-knowledge: introduces=[FR-LEX-C524-CINEMA-03]; assesses=[] -->

**le doublage** — "dubbing".

> Le doublage de ce dessin animé est très réussi.
>
> *The dubbing of this cartoon is very good.*

Built on *doubler* "to dub".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*le doublage* is built on *doubler* with *-age*; *doubler* comes from *double*, from Latin *duplus* "twofold", built on *duo* "two" (Lewis & Short).
