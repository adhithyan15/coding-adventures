## You'll want to know: halbieren
<!-- hl-knowledge: introduces=[GE-LEX-C323-SCHAELEN-05]; assesses=[] -->

**halbieren** — "to halve, to cut in half".

> Er halbierte die Tomaten.
>
> *He cut the tomatoes in half.*

Built on *halb* with the borrowed ending *-ieren*: *hat halbiert*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*halbieren* is built on *halb* "half", Old High German *halb*, Proto-Germanic *halbaz* (EtymDB), with the ending *-ieren*.
