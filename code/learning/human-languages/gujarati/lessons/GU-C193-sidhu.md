# સીધું (sīdhũ) — straight, straight on

## You'll want to know: સીધું
<!-- hl-knowledge: introduces=[GU-LEX-C193-WAY193-04]; assesses=[] -->

**સીધું** — *sīdhũ* — "straight, straight on".

> **સ્ટેશન સીધું આગળ છે.** — *sṭeśan sīdhũ āgaḷ che* — "The station is straight ahead."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**સીધું** (*sīdhũ*) is a tadbhava. CDIAL lists it, glossed "straightforward", under Sanskrit *siddha*, "accomplished; prepared" (CDIAL 13401).
