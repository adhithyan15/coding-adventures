# el extranjero — the world outside one's country

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ES-LEX-PAQUETE] -->

[PAUSE 2s] Recall **el paquete**. If it crosses a national border, you can send
it **al extranjero**, abroad.

## The word, taken apart
<!-- hl-knowledge: introduces=[ES-LEX-EXTRANJERO]; assesses=[] -->

The family reaches back to Latin **extraneus**, “from outside.” It travelled
through Romance in several directions; English **strange** and **stranger** are
distant relatives. Spanish **extranjero** can name a foreign person, but **el
extranjero** in the frame **al extranjero** means abroad.

## Grammar Lens: a + el
<!-- hl-knowledge: introduces=[]; assesses=[ES-LEX-EXTRANJERO, ES-LEX-PAQUETE] -->

Spanish contracts **a + el** to **al**: **enviar el paquete al extranjero**.
The place frame, not a person's nationality, is the useful meaning here.
