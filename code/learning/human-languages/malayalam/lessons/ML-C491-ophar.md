## You'll want to know: ഓഫർ
<!-- hl-knowledge: introduces=[ML-LEX-C491-KATA491-02]; assesses=[] -->

**ഓഫർ** — *ōphar* — "a special offer".

> ആ കടയിൽ ഒന്ന് വാങ്ങിയാൽ ഒന്ന് വെറുതെ എന്ന ഓഫർ ഉണ്ട്.
>
> *ā kaṭayil onnŭ vāṅṅiyāl onnŭ veṟute enna ōphar uṇṭŭ.*
>
> That shop has an offer: buy one and get one free.

Shops put up an ഓഫർ board at festival time.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ഓഫർ** (*ōphar*) was borrowed from English *offer*, a price cut for a short time.
