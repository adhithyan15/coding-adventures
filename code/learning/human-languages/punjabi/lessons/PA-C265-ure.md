# ਉਰੇ (ure) — on this side; nearer

## You'll want to know: ਉਰੇ
<!-- hl-knowledge: introduces=[PA-LEX-C265-SIDE265-01]; assesses=[] -->

**ਉਰੇ** — *ure* — "on this side; nearer".

> ਬੱਸ ਪੁਲ ਤੋਂ ਉਰੇ ਰੁਕਦੀ ਹੈ।
>
> *bass pul ton ure rukdī hai.*
>
> The bus stops on this side of the bridge.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ਉਰੇ** (*ure*) is inherited from Sanskrit *avara*, "lower, hinder, nearer"; CDIAL lists Punjabi *ure*, "on this side", under it (CDIAL 805).
