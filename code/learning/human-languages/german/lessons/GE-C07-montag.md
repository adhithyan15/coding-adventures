# Montag — "Monday"

## You'll want to know: Montag
<!-- hl-knowledge: introduces=[GE-LEX-MONTAG-01]; assesses=[GE-GRAMMAR-GOTT-PLUS-TAG-01] -->

> **Montag** — "Monday."

*Mon-* is *Mond* with its hard ending worn off inside the compound, and *-tag*
is the day. The pattern's first instance, and the easiest: English says the same
two words in the same order — *moon* and *day*.

That is what an **inherited** name looks like. Nobody translated this; both
languages were already saying it before they were separate languages.
