## Fixed — three more Punjabi root slugs name one etymon each

- **PA-C95-naum** moves from `sanskrit-nava` to `sanskrit-nava-nine`. *Nauṁ* is *náva²* "nine" (CDIAL 6984), not *náva¹* "new".
- **PA-C117-ghara** moves from `sanskrit-ghata` to `sanskrit-ghata-pot`, the slug Marathi and Marwadi use for *ghaṭa* "pot" (CDIAL 4406). `sanskrit-ghata` is *ghāta* "blow, wound" (CDIAL 4460).
- **PA-C83-patla** moves from `sanskrit-patra` to `sanskrit-pattrala`. Its hook derives *patlā* from *pattralá* "leafy" (CDIAL 7736), the slug Gujarati, Marathi and Marwadi use.
