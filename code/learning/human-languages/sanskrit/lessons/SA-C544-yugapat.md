## You'll want to know: युगपत्
<!-- hl-knowledge: introduces=[SA-LEX-C544-PARASPARA544-02]; assesses=[] -->

**युगपत्** — *yugapat* — "at the same time".

> यदि सर्वे युगपत् वदन्ति, तर्हि अहं न अवगच्छामि।
>
> *yadi sarve yugapat vadanti, tarhi ahaṃ na avagacchāmi.*
>
> If everyone talks at the same time, I don't understand.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**युगपत्** (*yugapat*) is built from *yuga*, "a yoke", and *pad*, "a foot": side by side in one yoke; MW gives *yugapad* as together, at the same time (MW).
