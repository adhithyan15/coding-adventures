## You'll want to know: अपवाद
<!-- hl-knowledge: introduces=[HI-LEX-C365-SIDDHANT365-03]; assesses=[] -->

**अपवाद** — *apvād* — "an exception".

> हर नियम का कोई अपवाद होता है।
>
> *har niyam kā koī apvād hotā hai.*
>
> Every rule has some exception.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**अपवाद** (*apvād*) is a tatsama, borrowed from Sanskrit *apavāda*, "a refutation; an exception" (Monier-Williams).
