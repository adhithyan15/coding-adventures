# ಯುಗ (yuga) — an era; an age

## You'll want to know: ಯುಗ
<!-- hl-knowledge: introduces=[KA-LEX-C331-HINDE331-05]; assesses=[] -->

**ಯುಗ** — *yuga* — "an era; an age".

> ಇದು ಕಂಪ್ಯೂಟರ್ ಯುಗ.
>
> *idu kampyūṭar yuga.*
>
> This is the computer age.

Plural: ಯುಗಗಳು, *yugagaḷu*.

ಹೊಸ ಯುಗ is a new era. In talk ಯುಗ can also mean a very long time.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಯುಗ** (*yuga*) is borrowed from Sanskrit *yuga*, "a yoke, a pair" (CDIAL 10482), which also meant "an age of the world" (Monier-Williams).
