## You'll want to know: remar
<!-- hl-knowledge: introduces=[PT-LEX-C418-BARCO-03]; assesses=[] -->

**remar** — "to row".

> Remámos durante uma hora no lago.
>
> *We rowed for an hour on the lake.*

*O remador* — the rower.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*remar* is built on *remo* 'oar', which is inherited from Latin *rēmus* (EtymDB).
