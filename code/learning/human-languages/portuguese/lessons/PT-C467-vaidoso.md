## You'll want to know: vaidoso
<!-- hl-knowledge: introduces=[PT-LEX-C467-ORGULHO-03]; assesses=[] -->

**vaidoso** — "vain".

> O meu irmão é vaidoso: compra sempre roupa cara.
>
> *My brother is vain: he keeps buying expensive clothes.*

Built on *a vaidade*; a woman is *vaidosa*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*vaidoso* is built on *vaidade* "vanity" with *-oso* "full of"; *vaidade* is inherited from Latin *vānitās* "emptiness" (EtymDB).
