# દલીલ (dalīl) — a line of argument; a reason put forward

## You'll want to know: દલીલ
<!-- hl-knowledge: introduces=[GU-LEX-C341-DALIL341-01]; assesses=[] -->

**દલીલ** — *dalīl* — "a line of argument; a reason put forward".

> મીરાની દલીલ મજબૂત હતી.
>
> *Mīrānī dalīl majbūt hatī.*
>
> Mira's argument was a strong one.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**દલીલ** (*dalīl*) is usually traced to Arabic *dalīl*, "a guide; a proof", through Persian. Gujarati uses it for a reason put forward in an argument.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
