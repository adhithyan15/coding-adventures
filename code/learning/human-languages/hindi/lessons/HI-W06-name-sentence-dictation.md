# Hear one known sentence; write it

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[HI-CONCEPT-C02-MERANAAMHAI-01] -->

Cover the answer below. The heard sentence uses only the familiar frame and the
other Chapter 2 practice name.

## Writing — sentence dictation
<!-- hl-knowledge: introduces=[]; assesses=[HI-CONCEPT-C02-MERANAAMHAI-01] -->
<!-- hl-writing-stage: dictation-transcription -->

[YOU HEAR: *merā nām Aruṇ hai* — "my name is Arun"]

Write the Hindi sentence from sound alone. Add its final sentence stop. Do not
use a visible Devanagari model or a romanized written answer.

Now uncover and compare: **मेरा नाम अरुण है।** Check word order first. If the
order is right, check spelling; if spelling is right, check **।**. Repair only
the first differing dimension.
