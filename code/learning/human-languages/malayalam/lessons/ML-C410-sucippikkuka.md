# സൂചിപ്പിക്കുക (sūcippikkuka) — to indicate; to hint

## You'll want to know: സൂചിപ്പിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C410-SUCANA410-01]; assesses=[] -->

**സൂചിപ്പിക്കുക** — *sūcippikkuka* — "to indicate; to hint".

> നാളെ മഴ വരുമെന്ന് റിപ്പോർട്ട് സൂചിപ്പിച്ചു.
>
> *nāḷe maḻa varumennŭ ṟippōrṭṭŭ sūcippiccu.*
>
> The report indicated that rain would come tomorrow.

Past: സൂചിപ്പിച്ചു, *sūcippiccu*.

The noun is സൂചന, a hint, a sign.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**സൂചിപ്പിക്കുക** (*sūcippikkuka*) is built from Sanskrit *sūcana*, "pointing out, indicating" (Monier-Williams), with the Malayalam verb ending, here -ിപ്പിക്കുക.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
