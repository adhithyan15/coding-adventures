## You'll want to know: empeorar
<!-- hl-knowledge: introduces=[ES-LEX-C732-SALUD-05]; assesses=[] -->

**empeorar** — "to get worse, to worsen".

> El tiempo va a empeorar.
>
> *The weather is going to get worse.*

The opposite of *mejorar*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*empeorar* is built on *peor* "worse", which is inherited from Latin *peior* (EtymDB).
