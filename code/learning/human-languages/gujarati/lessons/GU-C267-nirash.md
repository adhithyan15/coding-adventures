# નિરાશ (nirāś) — disappointed, hopeless

## You'll want to know: નિરાશ
<!-- hl-knowledge: introduces=[GU-LEX-C267-UPSET267-02]; assesses=[] -->

**નિરાશ** — *nirāś* — "disappointed, hopeless".

> **હું પરિણામથી નિરાશ નથી.** — *hũ pariṇāmthī nirāś nathī* — "I am not disappointed with the result."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**નિરાશ** (*nirāś*) is Sanskrit *nirāśa*, "hopeless", built from *nir-*, "without", and *āśā*, "hope", and taken over as a tatsama; CDIAL lists Gujarati *nirās* (CDIAL 7278).
