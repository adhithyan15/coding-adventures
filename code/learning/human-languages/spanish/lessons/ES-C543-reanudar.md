## You'll want to know: reanudar
<!-- hl-knowledge: introduces=[ES-LEX-C543-RETRASO-01]; assesses=[] -->

**reanudar** — "to resume, to start again".

> Después de la lluvia reanudaron el partido.
>
> *After the rain they resumed the match.*

*Reanudarse* — to start up again: *Se reanudó el servicio.*

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*reanudar* is built on *anudar* 'to tie a knot' with *re-* 'again'. *Anudar*, older *añudar* (EtymDB), is built on *nudo* 'a knot', from Latin *nōdus* 'a knot' (Lewis & Short). To resume is to tie the thread again.
