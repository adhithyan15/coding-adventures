# A short exchange: tea or milk?

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-GRAMMAR-POLAR-HABITUAL-215, PA-GRAMMAR-POLAR-ANSWER-214, PA-GRAMMAR-NEG-HABITUAL-212] -->

[PAUSE 2s] Ask *do you drink tea?* Answer it *no*, in a whole sentence.

## Grammar Lens: four lines
<!-- hl-knowledge: introduces=[PA-GRAMMAR-ASK-AND-ANSWER-215]; assesses=[PA-GRAMMAR-POLAR-HABITUAL-215, PA-GRAMMAR-POLAR-ANSWER-214, PA-GRAMMAR-NEG-HABITUAL-212, PA-LEX-DUDH] -->

A host and a guest. Hear the turns; each answer repeats the verb.

> **ਕੀ ਤੁਸੀਂ ਚਾਹ ਪੀਂਦੇ ਹੋ?** — *kī tusīṁ chāh pīnde ho?* — Do you drink tea?

> **ਨਹੀਂ ਜੀ, ਮੈਂ ਚਾਹ ਨਹੀਂ ਪੀਂਦੀ ਹਾਂ।** — *nahīṁ jī, maiṁ chāh nahīṁ pīndī hāṁ.* — No, I don't drink tea.

> **ਕੀ ਤੁਸੀਂ ਦੁੱਧ ਪੀਂਦੇ ਹੋ?** — *kī tusīṁ duddh pīnde ho?* — Do you drink milk?

> **ਹਾਂ ਜੀ, ਮੈਂ ਦੁੱਧ ਪੀਂਦੀ ਹਾਂ।** — *hāṁ jī, maiṁ duddh pīndī hāṁ.* — Yes, I drink milk.
