## You'll want to know: बेचैन
<!-- hl-knowledge: introduces=[MR-LEX-C455-DHASTI455-02]; assesses=[] -->

**बेचैन** — *becain* — "restless; uneasy".

> बाळ रात्रभर बेचैन होतं.
>
> *bāḷ rātrabhar becain hotaṁ.*
>
> The baby was restless all night.

Unchanging. The prefix बे- means without: here, without rest.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**बेचैन** (*becain*) is a loan from Persian *bechain*, "restless", built on *be-*, "without", and *chain*, "rest".
