# খুশকি (khushki) — dandruff

## You'll want to know: খুশকি
<!-- hl-knowledge: introduces=[BN-LEX-C470-TAK470-02]; assesses=[] -->

**খুশকি** — *khushki* — "dandruff".

> শীতে অরুণের মাথায় খুশকি হয়।
>
> *shīte ôruner māthāy khushki hôy.*
>
> In winter Arun gets dandruff.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**খুশকি** (*khushki*) is usually traced to Persian *khushkī*, "dryness".
