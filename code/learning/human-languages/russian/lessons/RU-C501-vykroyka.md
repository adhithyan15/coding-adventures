## You'll want to know: выкройка
<!-- hl-knowledge: introduces=[RU-LEX-C501-SEWING-04]; assesses=[] -->

**выкройка** (*výkroyka*) — "a sewing pattern".

> Мама сшила платье по старой выкройке.
>
> *Máma sshíla plátye po stároy výkroyke.*
>
> Mum made a dress from an old pattern.

Feminine. *Шить по выкройке* — to sew from a pattern.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*выкройка* is built on *выкроить* 'to cut out', from *кроить* 'to cut cloth'; EtymDB has no entry.
