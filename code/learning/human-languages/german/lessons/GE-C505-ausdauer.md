## You'll want to know: die Ausdauer
<!-- hl-knowledge: introduces=[GE-LEX-C505-TRAINING-02]; assesses=[] -->

**die Ausdauer** — "stamina, endurance".

> Für einen Marathon braucht man viel Ausdauer.
>
> *For a marathon you need a lot of stamina.*

No plural.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*Ausdauer* is built on *aus* "out" and *dauern* "to last", from Middle High German *dūren*, which came from Latin *dūrāre* "to last" (EtymDB).
