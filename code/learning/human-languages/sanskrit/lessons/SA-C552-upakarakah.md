## You'll want to know: उपकारकः
<!-- hl-knowledge: introduces=[SA-LEX-C552-PRAYASA552-05]; assesses=[] -->

**उपकारकः** — *upakārakaḥ* — "helpful".

> यदि उपायः उपकारकः अस्ति, तर्हि अहं तं करिष्यामि।
>
> *yadi upāyaḥ upakārakaḥ asti, tarhi ahaṃ taṃ kariṣyāmi.*
>
> If the method is helpful, I will use it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**उपकारकः** (*upakārakaḥ*) is built on *upa*, "towards", and the root √kṛ, "to do", with the agent ending *-aka*, like *upakāra*, "a favour"; MW gives *upakāraka* as doing a service, helping (MW).
