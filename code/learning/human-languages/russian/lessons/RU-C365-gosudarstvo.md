## You'll want to know: государство
<!-- hl-knowledge: introduces=[RU-LEX-C365-VLAST-01]; assesses=[] -->

**государство** (*gosudárstvo*) — "the state, a country".

> Государство помогает пенсионерам.
>
> *Gosudárstvo pomogáyet pensionéram.*
>
> The state helps pensioners.

Neuter. *Государственный* — state, public: *государственный язык*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**государство** is built on *государь* "a sovereign", which is usually traced to older *господарь* "a lord, a master", from *господь* "lord".
