# भांत (bhā̃t) — a sort; a kind

## You'll want to know: भांत
<!-- hl-knowledge: introduces=[MW-LEX-C210-CHOOSE210-02]; assesses=[] -->

**भांत** — *bhā̃t* — "a sort; a kind".

> दूजी भांत दिखावो।
>
> *dūjī bhā̃t dikhāvo.*
>
> Show me another kind.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**भांत** (*bhā̃t*) is inherited from Sanskrit *bhakti*, "a share; an arrangement, a manner"; CDIAL lists Old Marwari *bhā̃ti*, "manner, kind" (CDIAL 9338).
