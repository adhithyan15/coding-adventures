# పాఠకుడు (pāṭhakuḍu) — a reader

## You'll want to know: పాఠకుడు
<!-- hl-knowledge: introduces=[TE-LEX-C341-SAMPADAKUDU341-04]; assesses=[] -->

**పాఠకుడు** — *pāṭhakuḍu* — "a reader".

> చాలా మంది పాఠకులు ఉత్తరాలు రాశారు.
>
> *cālā mandi pāṭhakulu uttarālu rāśāru.*
>
> Many readers wrote letters.

Plural: పాఠకులు, *pāṭhakulu*.

Built on the root of పాఠం, a lesson: పాఠకుడు, one who reads.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**పాఠకుడు** (*pāṭhakuḍu*) is borrowed from Sanskrit *pāṭhaka*, "a reader, a teacher" (CDIAL 8036), from *paṭh*, "to read aloud", which also gives పాఠం, a lesson.
