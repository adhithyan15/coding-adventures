# அதேபோல் (atēpōl) — likewise; in the same way

## You'll want to know: அதேபோல்
<!-- hl-knowledge: introduces=[TA-LEX-C357-ENINUM357-04]; assesses=[] -->

**அதேபோல்** — *atēpōl* — "likewise; in the same way".

> அவன் கடினமாகப் படித்தான், அதேபோல் அவன் தங்கையும் படித்தாள்.
>
> *avaṉ kaṭiṉamākap paṭittāṉ, atēpōl avaṉ taṅkaiyum paṭittāḷ.*
>
> He studied hard, and likewise so did his younger sister.

அதே, that same, + போல், like: அதேபோல் செய், do it the same way.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**அதேபோல்** (*atēpōl*) is native: *atē*, "that very", from *atu*, "that" (DEDR 1), and *pōl*, "to resemble; like" (DEDR 4597).
