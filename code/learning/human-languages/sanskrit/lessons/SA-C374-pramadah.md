## You'll want to know: प्रमादः
<!-- hl-knowledge: introduces=[SA-LEX-C374-PRAMADA374-02]; assesses=[] -->

**प्रमादः** — *pramādaḥ* — "carelessness".

> यदि प्रमादः भवति, तर्हि हानिः भविष्यति।
>
> *yadi pramādaḥ bhavati, tarhi hāniḥ bhaviṣyati.*
>
> If there is carelessness, there will be a loss.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**प्रमादः** (*pramādaḥ*) is built on *pra* and the root √mad, "to be drunk"; MW gives *pra-māda* "negligence, carelessness" (MW).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
