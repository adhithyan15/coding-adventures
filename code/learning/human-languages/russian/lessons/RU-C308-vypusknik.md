## You'll want to know: выпускник
<!-- hl-knowledge: introduces=[RU-LEX-C308-VYPUSKNIK-01]; assesses=[] -->

**выпускник** (*vypuskník*) — "a school-leaver, a graduate".

> Выпускники подарили учителю цветы.
>
> *Vypusknikí podaríli uchítelyu tsvetý.*
>
> The school-leavers gave the teacher flowers.

A woman is *выпускница*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*выпускник* is built on *выпуск* "a graduating class", from *выпускать* "to let out", whose root is Proto-Slavic *pustiti* "to let go" (EtymDB).
