# വ്യവസ്ഥ (vyavastha) — a condition; a system

## You'll want to know: വ്യവസ്ഥ
<!-- hl-knowledge: introduces=[ML-LEX-C440-VYAVASTHA440-01]; assesses=[] -->

**വ്യവസ്ഥ** — *vyavastha* — "a condition; a system".

> നീയും വന്നാൽ മാത്രം ഞാൻ വരാം, അതാണ് എന്റെ വ്യവസ്ഥ.
>
> *nīyuṁ vannāl mātraṁ ñān varāṁ, atāṇŭ enṟe vyavastha.*
>
> I will come only if you come too; that is my condition.

It is also an order of things, a system: സാമ്പത്തിക വ്യവസ്ഥ, the economic system.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**വ്യവസ്ഥ** (*vyavastha*) is borrowed from Sanskrit *vyavasthā*, from the verb *vy-ava-sthā*, "to stand apart; to be settled, fixed" (Monier-Williams): a condition is a thing settled in advance.
