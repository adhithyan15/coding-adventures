# ಕಂತು (kantu) — an instalment

## You'll want to know: ಕಂತು
<!-- hl-knowledge: introduces=[KA-LEX-C417-KANTU417-01]; assesses=[] -->

**ಕಂತು** — *kantu* — "an instalment".

> ನಾನು ಪ್ರತಿ ತಿಂಗಳು ಸಾಲದ ಕಂತು ಕಟ್ಟುತ್ತೇನೆ.
>
> *nānu prati tiṅgaḷu sālada kantu kaṭṭuttēne.*
>
> I pay an instalment of the loan every month.

ಕಂತು ಕಟ್ಟು, to pay an instalment.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಕಂತು** (*kantu*) is native Dravidian: DEDR 1209 lists Kannada *kanta*, *kantu*, "an instalment, a fixed term of payment".
