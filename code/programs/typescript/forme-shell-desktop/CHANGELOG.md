# Changelog — forme-shell-desktop

## Unreleased

### Added

- Added the FM-B072 supported-platform release composition, which runs the
  checked-in desktop product front beside the live-site, API-v2, benchmark,
  browser-budget, and external exact-head security-review policy on Linux,
  macOS, and Windows and contributes one bounded host attestation to the
  aggregate technical verdict.
- Added the FM09 Tauri v2 product boundary and restrictive main-window CSP.
- Added contained, crash-safe native project storage with opaque
  compare-and-swap revisions, full persisted-state validation, and canonical
  UUIDv7 identity creation.
- Added a reproducible authoring product pipeline using the real Forme
  orchestrator, router, renderer, reviewed classless theme, and emitter.
- Added the bounded, closed product-worker protocol plus a version-pinned
  single-executable worker with deterministic artifact metadata.
- Added native worker identity and contained output-tree validation, including
  path, size, digest, revision, build, and exact-key protocol checks.
- Added the audited macOS Seatbelt launcher with per-run worker and launcher
  re-verification, RSS/CPU/wall/fd limits, parent-death retirement, bounded
  scratch trees, and sticky workspace poisoning after uncertain outcomes.
- Added a capability-token loopback preview URL with exact Host validation and
  byte re-verification before a snapshot becomes visible.
- Added native storage, IPC-shape, capability, and product parity tests.
- Added native-only local target selection, bounded target reviews, stale
  directory and unsafe-permission detection, owner-only complete-tree staging,
  descriptor-relative atomic publication, and exact-revision acknowledgement.
- Added macOS extended-ACL rejection, identity-bound publication cleanup,
  per-file and aggregate worker output limits, and shared disposal admission
  across storage, preview, publication, and native target state.
- Added one TypeScript/Rust persisted-state parity corpus, including exact
  ECMAScript whitespace and JavaScript safe-integer behavior.
- Added the React host adapter for target discovery/configuration, closed
  publication results, and durable `lastPublication` recording only after the
  native commit succeeds.

### Fixed

- Fixed macOS single-executable worker assembly for thin Node distributions by
  copying matching thin Mach-O executables directly while retaining universal
  binary thinning and rejecting architecture mismatches.
- Added a portable-only Windows build front so unsupported macOS native gates
  are never parsed or invoked by Windows package builds.
