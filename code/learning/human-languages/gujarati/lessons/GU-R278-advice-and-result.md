# Review — should, must, and so

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[GU-GRAMMAR-C277-LAGE-CHE-KE-01, GU-GRAMMAR-C277-NE-LIDHE-01] -->

[PAUSE 2s] Say "I think it will rain". (*mane lāge che ke varsād paḍśe*.) Then "because of the rain". (*varsādne līdhe*.)

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[GU-GRAMMAR-C278-VU-JOIE-01, GU-GRAMMAR-C278-VU-PADE-01, GU-LEX-C278-ETLE-01, GU-GRAMMAR-C278-SO-RESULT-01, GU-GRAMMAR-C278-REASON-TURN-01, GU-GRAMMAR-C277-OPINION-ASK-01, GU-LEX-C49-CARE-02, GU-LEX-C85-TRAVEL-01, GU-LEX-C48-BODY3-04] -->

[PAUSE 2s each]
- [YOU SAY: You should go to the doctor. You should take the medicine.]
- [YOU SAY: He should rest. I should write a letter.]
- [YOU SAY: I have to go by bus every day. Tomorrow I'll have to go early.]
- [YOU SAY: What do you think? I think you have a fever, so you should rest.]
- [YOU SAY: The train was late, so I came late. Now turn it round, with kāraṇ ke.]

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[GU-GRAMMAR-C278-VU-JOIE-01, GU-GRAMMAR-C278-VU-PADE-01, GU-LEX-C278-ETLE-01, GU-GRAMMAR-C278-SO-RESULT-01, GU-GRAMMAR-C278-REASON-TURN-01] -->

[PAUSE 3s] "I should go"? (**મારે જવું જોઈએ**.) "I had to go"? (**મારે જવું પડ્યું**.) Turn **હું મોડો આવ્યો, કારણ કે ટ્રેન મોડી હતી** round with **એટલે**. (**ટ્રેન મોડી હતી, એટલે હું મોડો આવ્યો**.)
