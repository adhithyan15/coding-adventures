# A short Malayalam A1 writing checkpoint

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-NAMASKARAM-01, ML-PHRASE-C02-MY-NAME-IS-01, ML-PHRASE-C04-NAALE-KAANAAM-01, ML-PHRASE-C05-I-SPEAK-MALAYALAM-01, ML-CONCEPT-C39-CHAAYA-01, ML-LEX-C41-DEIXIS-06, ML-PUNCT-QUESTION-01] -->

[PAUSE 2s] This is a short independent attempt, not a model. You will write the answers, and
this page will not show you any copyable Malayalam answer.

Put away romanization, dictionaries, translators, and spell-checkers. Keep a
blank page ready and set a **three-minute timer**. Write in Malayalam script.
Ordinary legible handwriting is enough; decorative calligraphy is not scored.

## Writing — timed assessment production
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-NAMASKARAM-01, ML-PHRASE-C02-MY-NAME-IS-01, ML-PHRASE-C04-NAALE-KAANAAM-01, ML-PHRASE-C05-I-SPEAK-MALAYALAM-01, ML-CONCEPT-C39-CHAAYA-01, ML-LEX-C41-DEIXIS-06, ML-PUNCT-QUESTION-01] -->
<!-- hl-writing-stage: timed-assessment-production -->

**One practical form — three minutes**

Complete **all six fields in Malayalam script** for a neighbourhood language
exchange. Write one short answer in every field. Start the timer when you begin
the first field; leave any unfinished field as evidence when it rings.

1. Your name
2. A language you speak
3. One greeting you would use
4. One drink you would ask for
5. One place-question word
6. One polite closing you would use

When the three-minute timer rings, **stop**. Record the number of completed
fields. An honest short attempt is more useful than a perfect untimed one.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-NAMASKARAM-01, ML-PHRASE-C02-MY-NAME-IS-01, ML-PHRASE-C04-NAALE-KAANAAM-01, ML-PHRASE-C05-I-SPEAK-MALAYALAM-01, ML-CONCEPT-C39-CHAAYA-01, ML-LEX-C41-DEIXIS-06, ML-PUNCT-QUESTION-01] -->

Spend at most one minute looking at this first attempt. Note one field you
completed clearly and one field to practise next; do not rewrite the timed
answer. Keep the page as evidence.

This checkpoint is **not** the complete A1 writing paper. On another day,
close this lesson and open the separate
[A1 mock 1 learner paper](../mocks/a1/mock-1.md) for the authentic form and
named-reader message under one 20-minute assessment clock. That paper and its
later rubric review are a separate assessment session, not work inside this
four-minute lesson. The second mock is a separate repeat, not a model to copy.
