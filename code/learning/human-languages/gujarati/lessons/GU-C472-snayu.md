## You'll want to know: સ્નાયુ
<!-- hl-knowledge: introduces=[GU-LEX-C472-NAS472-02]; assesses=[] -->

**સ્નાયુ** — *snāyu* — "a muscle".

> કસરતથી સ્નાયુ મજબૂત બને છે.
>
> *kasratthī snāyu majbūt bane che.*
>
> Exercise makes the muscles strong.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**સ્નાયુ** (*snāyu*) is a tatsama, Sanskrit *snāyu*, which Monier-Williams gives as "any sinew or ligament", "tendon, muscle, nerve"; modern Gujarati uses it for a muscle.
