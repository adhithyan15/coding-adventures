## HL-C193 — बाप and माँ join the Hindi parent headword

After **बजना**, the ranked Hindi queue reaches **बाप** and **माँ**, two
independent everyday words taught together in the same parent lesson. Rows
before them are already classified script pieces, historical ancestors, or the
inflectional stem **बज**.

Chapter 12 defines respectable **पिता / माता** and everyday spoken **बाप /
माँ** as a register contrast. Guided practice asks learners to produce both
pairs, and wrap-up recall asks specifically for the everyday forms and their
different historical paths. The old headword named only **पिता माता**, hiding
the pair learners are told they will hear most often.

The headword is now **पिता / माता / बाप / माँ**, with a gloss that identifies
the register of each pair. This repairs metadata for existing teaching rather
than adding new vocabulary. Rerun the ranked report next and continue the
evidence-first audit after the explicitly classified script, morphology, and
historical-source rows.
