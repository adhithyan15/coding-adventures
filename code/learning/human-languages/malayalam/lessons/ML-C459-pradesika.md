# പ്രാദേശിക (prādēśika) — local; regional

## You'll want to know: പ്രാദേശിക
<!-- hl-knowledge: introduces=[ML-LEX-C459-NIKUTI459-04]; assesses=[] -->

**പ്രാദേശിക** — *prādēśika* — "local; regional".

> അവൻ ഒരു പ്രാദേശിക പത്രത്തിൽ ജോലി ചെയ്യുന്നു.
>
> *avan oru prādēśika patrattil jōli ceyyunnu.*
>
> He works for a local newspaper.

It stands before a noun: പ്രാദേശിക ഭാഷ, a regional language.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**പ്രാദേശിക** (*prādēśika*) is borrowed from Sanskrit *prādeśika*, "local, limited" (Monier-Williams), made from *pradeśa*, "a spot, a region".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
