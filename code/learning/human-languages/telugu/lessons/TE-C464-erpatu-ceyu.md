# ఏర్పాటు చేయు (ērpāṭu cēyu) — to organise; to set up

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TE-LEX-C464-SEVA464-01, TE-LEX-C464-SEVA464-02] -->

[PAUSE 2s] Before the new one: say the Telugu for to provide, then the Telugu for to gather together.

## You'll want to know: ఏర్పాటు చేయు
<!-- hl-knowledge: introduces=[TE-LEX-C464-SEVA464-03]; assesses=[] -->

**ఏర్పాటు చేయు** — *ērpāṭu cēyu* — "to organise; to set up".

> గ్రామంలో వైద్య శిబిరం ఏర్పాటు చేశారు.
>
> *grāmaṁlō vaidya śibiraṁ ērpāṭu cēśāru.*
>
> They set up a medical camp in the village.

Past (I …): ఏర్పాటు చేశాను, *ērpāṭu cēśānu*.

ఏర్పాటు, an arrangement, + చేయు. ఏర్పాట్లు, the arrangements for an event.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ఏర్పాటు చేయు** (*ērpāṭu cēyu*) is native Dravidian: ఏర్పాటు, "an arrangement", the noun of ఏర్పడు, "to be arranged, to be established" (DEDR 905), with చేయు, "to do" (DEDR 1957).
