## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**கத்தரிக்கோல்** (*kattarikkōl*) is *kattari*, "scissors", from Sanskrit *kartari*, "scissors, knife" (CDIAL 2858), with native *kōl*, "stick, rod" (DEDR 2237).
