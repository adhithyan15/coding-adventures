# HL111 — Punjabi A2 standalone `ਨੇ` agent-marker prerequisite

Issue: #18561 (dependency of #18536; blocks #17739)

The unpublished Punjabi A2 mock draft contains the exact standalone Gurmukhi
token **ਨੇ** 21 times across learner and examiner text. The public Punjabi
lessons do not yet own that standalone token. Substrings in other words and the
homographic plural auxiliary are not evidence that the agent marker has been
taught. This tranche closes only the agent-marker gap; it does not publish or
certify either confidential mock artifact.

Chapter 210 will introduce **ਨੇ** in one bounded third-person completed-action
frame: **ਅਮਨ ਨੇ ਕੰਮ ਕੀਤਾ** (“Aman did the work”). **ਅਮਨ**, **ਕੰਮ**, and
**ਕੀਤਾ** are already owned in public Punjabi lessons; Chapter 190 has already
explained why **ਕੀਤਾ** agrees with the unmarked masculine-singular object
**ਕੰਮ** in the completed transitive frame. A voice-first opener retrieves
those prior pieces without exposing **ਨੇ**. One direct grammar owner then
places **ਨੇ** after the named agent. Immediate listening/script/meaning
retrieval, a single frame-building task, and a four-skill payoff follow it.
Each lesson must remain at or below 300 seconds. The target must have one
direct knowledge owner and later explicit retrievals; the authored lesson,
generated book, and narration must not leak it before its owner.

Punjabi University Patiala's *A Start in Punjabi*, lesson 14, sections
14.8–14.9, contrasts past clauses with and without agent **ਨੇ**, states that
the past verb agrees with the object when the postposition is used, and gives
**ਲੋਕਾਂ ਨੇ ਆਦਰ ਕੀਤਾ** as a model. The university explicitly warns that usage
varies by sentence; its learner rule restricts **ਨੇ** to past, third-person
verb examples. The same lesson distinguishes this postposition from the
homographic present-tense auxiliary at clause end. Source:
<https://pt.learnpunjabi.org/lesson14.aspx?l=14>.

Consequently this chapter teaches only the named-agent, third-person,
completed transitive frame. It must not claim that every past tense takes
**ਨੇ**, introduce a general ergative paradigm, conflate the marker with the
auxiliary, or introduce pronoun contractions. Its source note should make that
boundary clear without overwhelming the learner. No etymology is asserted
without a primary lexical source. All Gurmukhi codepoints in **ਨੇ** are
already taught, so the chapter adds no script owner.

Add a focused exact-token provenance test, preserving the mock's strict
closure gate and non-disclosure boundary. Verify source order, chapter
duration, generated-book and narration consistency, and one direct owner.
Local automated validation and independent security review are required
before publication; qualified Punjabi review remains required for release.
