## You'll want to know: સરસ
<!-- hl-knowledge: introduces=[GU-LEX-C387-BAHETAR387-04]; assesses=[] -->

**સરસ** — *saras* — "lovely; fine".

> જો કાલે તડકો હશે તો ઉજાણીનો સરસ દિવસ હશે.
>
> *jo kāle taḍko haśe to ujāṇīno saras divas haśe.*
>
> If it is sunny tomorrow, it will be a lovely day for a picnic.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**સરસ** (*saras*) is inherited from Sanskrit *sárasa*, "juicy; moist, beautiful"; CDIAL lists the Gujarati word, "juicy, excellent" (CDIAL 13255).
