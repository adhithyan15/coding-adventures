## You'll want to know: بہرحال
<!-- hl-knowledge: introduces=[UR-LEX-C542-KHAIR542-01]; assesses=[] -->

**بہرحال** — *baharhāl* — "anyway; in any case".

> بہرحال، اگر آپ آئے تو ہمیں خوشی ہو گی۔
>
> *baharhāl, agar āp āe to hameṅ khushī ho gī.*
>
> Anyway, if you come, we will be glad.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**بہرحال** (*baharhāl*) is usually traced to Persian *ba-har-ḥāl*, "in every state", built from *ba*, "in", *har*, "every", and Arabic *ḥāl*, "a state".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
