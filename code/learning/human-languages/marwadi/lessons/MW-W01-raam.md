# राम — your first whole written word

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-RA-01, MW-SCRIPT-AA-MATRA-01] -->

[PAUSE 3s] Write **रा** after looking away from the model. Check it, then begin.

## Script — add म
<!-- hl-knowledge: introduces=[MW-SCRIPT-MA-01, MW-SCRIPT-RAAM-01, MW-LEX-RAAM-01]; assesses=[] -->

> **म** — *ma*

Join it to the piece you know:

> **रा** *rā* + **म** *ma* = **राम** *rām*

At the end of this word, the built-in vowel of **म** is not pronounced in
ordinary speech. Read the whole word *rām*. **राम** is the name *Ram*. The
Marwadi greeting you are building will repeat this name. Today you only need
the one word **राम**; the complete greeting still comes later.

## Writing — from copy to memory
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-MA-01, MW-SCRIPT-RAAM-01, MW-LEX-RAAM-01] -->
<!-- hl-writing-stage: delayed-copy -->

1. copy **म** twice
2. copy **राम** once while looking
3. hide the model for ten seconds
4. write **राम** from memory, then compare

If the memory copy stalls, return only to the missing sign.

## Wrap-up recall
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-RAAM-01, MW-LEX-RAAM-01] -->
<!-- hl-activity: {"id":"MW-W01-raam-build","kind":"text","assesses":["MW-SCRIPT-RAAM-01","MW-LEX-RAAM-01"],"prompt":"Build and name the written word rām from its three visible pieces.","answer":"राम — Ram","accepted":["राम","र + ा + म","रा + म"],"feedback":{"correct":"Right: र + ा + म makes राम, the name Ram.","incorrect":"Start with र, add ा on its right, then म: राम, Ram."},"response_seconds":12} -->

write it once more.
