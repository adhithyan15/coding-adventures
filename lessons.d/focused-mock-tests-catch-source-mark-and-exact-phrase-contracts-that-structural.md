# Focused mock tests catch source-mark and exact-phrase contracts that structural counts miss

Manual token and item counts passed, but the focused B1 mock contract found
that one public-information source lacked the required avagraha evidence and
that Markdown wrapping split an exact rubric phrase. Run the focused test as
soon as every bundle exists, then fix semantic markers in the source and keep
contractual phrases contiguous when tests intentionally pin their wording.

The next focused run found the same missing source marker in a second reading
part. When a contract applies to every part, audit every part in one pass
instead of fixing only the first failure reported by the test runner.
