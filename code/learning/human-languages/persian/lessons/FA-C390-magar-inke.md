## You'll want to know: مگر اینکه
<!-- hl-knowledge: introduces=[FA-LEX-C390-SHART-04]; assesses=[] -->

**مگر اینکه** (*magar inke*) — "unless".

> فردا میرویم، مگر اینکه برف بیاید.
>
> *fardâ miravim, magar inke barf biyâyad.*
>
> We will go tomorrow, unless it snows.

It takes the subjunctive: *magar inke* + *biyâyad*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**مگر اینکه** is native Persian, built from *magar*, which EtymDB traces to a Middle Persian phrase glossed "perhaps; lest", + *inke* "that", from *in* "this" and *ke* "that".
