## You'll want to know: l'imperatore
<!-- hl-knowledge: introduces=[IT-LEX-C328-IMPERO-02]; assesses=[] -->

**l'imperatore** — "the emperor".

> L'imperatore ha costruito un grande palazzo.
>
> *The emperor built a great palace.*

An empress is *l'imperatrice*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*imperatore* is inherited from Latin *imperātor* "a commander" (EtymDB).
