## You'll want to know: порядок
<!-- hl-knowledge: introduces=[RU-LEX-C390-PORYADOK-03]; assesses=[] -->

**порядок** (*poryádok*) — "order".

> В его комнате всегда порядок.
>
> *V yegó kómnate vsegdá poryádok.*
>
> His room is always tidy.

Masculine; genitive *порядка*. *Всё в порядке* — everything is all right. *По порядку* — in order.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**порядок** is built from *по-* and *ряд* "a row, a line", inherited from Proto-Slavic *\*rędŭ*: order is things set in rows.
