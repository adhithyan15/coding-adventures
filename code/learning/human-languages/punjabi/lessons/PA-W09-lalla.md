# ਲ — the last piece of a four-letter greeting

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-SCRIPT-SA-01, PA-SCRIPT-MA-01, PA-LEX-SALAAM] -->

[PAUSE 2s] Write **ਸ** and **ਮ** once each. Say *salām* aloud. Of its four
letters you can already write three; one is missing.

## Script — one letter
<!-- hl-knowledge: introduces=[PA-SCRIPT-LA-01]; assesses=[PA-SCRIPT-SA-01] -->

Trace **ਲ** twice and say *la*. A loop that starts at the top line, drops, and
comes back up to meet it.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-SCRIPT-LA-01] -->
<!-- hl-writing-stage: observe-trace -->

Cover the model. Write **ਲ** once. Compare only whether the loop closes back on
the top line.
