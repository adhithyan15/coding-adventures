## You'll want to know: عدل
<!-- hl-knowledge: introduces=[AR-LEX-C427-TAKHTIT427-03]; assesses=[] -->

**عدل** — *ʿaddala* — "to adjust; to modify".

> عدلنا خطة الرحلة بسبب المطر.
>
> *ʿaddalnā khuṭṭat ar-riḥla bi-sabab al-maṭar.*
>
> We adjusted the trip plan because of the rain.

Present: يعدل, *yuʿaddil*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**عدل** (*ʿaddala*) is built on the native Arabic root *ʿ-d-l*, "to be even, balanced" (Lane). It is Form II, "to make even, to set straight".
