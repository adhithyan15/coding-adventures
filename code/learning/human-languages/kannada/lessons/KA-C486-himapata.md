# ಹಿಮಪಾತ (himapāta) — snowfall

## You'll want to know: ಹಿಮಪಾತ
<!-- hl-knowledge: introduces=[KA-LEX-C486-HINGARU486-05]; assesses=[] -->

**ಹಿಮಪಾತ** — *himapāta* — "snowfall".

> ಹಿಮಪಾತದಿಂದ ಬೆಟ್ಟದ ರಸ್ತೆ ಮುಚ್ಚಿತು.
>
> *himapātadinda beṭṭada raste muccitu.*
>
> The mountain road was closed by snowfall.

ಹಿಮ, snow, plus ಪಾತ, a fall.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಹಿಮಪಾತ** (*himapāta*) is built from two Sanskrit words: *hima*, "cold, frost, snow" (CDIAL 14096), and *pāta*, "a fall" (CDIAL 8052).
