# தீயணைப்பான் (tīyaṇaippāṉ) — a fire extinguisher

## You'll want to know: தீயணைப்பான்
<!-- hl-knowledge: introduces=[TA-LEX-C552-PATHUKAPPU552-01]; assesses=[] -->

**தீயணைப்பான்** — *tīyaṇaippāṉ* — "a fire extinguisher".

> சமையலறையில் தீப்பிடித்தால் அப்பா தீயணைப்பானைப் பயன்படுத்துவார்.
>
> *camaiyalaṟaiyil tīppiṭittāl appā tīyaṇaippāṉaip payaṉpaṭuttuvār.*
>
> If the kitchen catches fire, Father will use the fire extinguisher.

தீ "fire" + அணைப்பான் "that which puts out", from அணை (*aṇai*).

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**தீயணைப்பான்** (*tīyaṇaippāṉ*) is a modern native compound: தீ (*tī*), "fire" (DEDR 3266), and அணைப்பான் (*aṇaippāṉ*), "that which puts out", from அணை, "to quench" (DEDR 121).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
