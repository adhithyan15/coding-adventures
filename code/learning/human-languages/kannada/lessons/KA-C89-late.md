# ತಡವಾಯಿತು (taḍavāyitu) — it's late, it got late

## You'll want to know: ತಡವಾಯಿತು
<!-- hl-knowledge: introduces=[KA-LEX-C89-CARE-03]; assesses=[] -->

**ತಡವಾಯಿತು** (*taḍavāyitu*) — "it's late", literally "it has become late".
**ತಡ** (*taḍa*) is "delay, lateness".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

The reason people stand up to leave.
