# cargo-llvm-cov requires the rustup LLVM tools component

A temporary `cargo-llvm-cov` binary is not sufficient by itself: it delegates profile merging and reporting to the active Rust toolchain's `llvm-profdata` and `llvm-cov` binaries. Before starting a coverage run in a fresh environment, check `rustup component list --installed` for `llvm-tools`; install `llvm-tools-preview` when absent, then run coverage. In an environment with multiple Rust installations, installing the component for an ambient `stable` toolchain does not prove the workspace compiler can see it. Resolve `rustc --print sysroot` through the same workspace command environment and, when necessary, set `LLVM_COV` and `LLVM_PROFDATA` to the binaries beneath that exact sysroot. This keeps a missing or mismatched toolchain component from interrupting validation after the coverage frontend has already been compiled.
