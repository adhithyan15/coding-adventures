## You'll want to know: riavviare
<!-- hl-knowledge: introduces=[IT-LEX-C404-BLOCCO-02]; assesses=[] -->

**riavviare** — "to restart, to reboot".

> Se non funziona, riavvia il telefono.
>
> *If it does not work, restart the phone.*

*Avviare* is to start; *ri-* is again.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*riavviare* is built from *ri-* "again" and *avviare* "to start off", from *a* and *via* "way, road", inherited from Latin *via* (Lewis & Short): to set something on its way again.
