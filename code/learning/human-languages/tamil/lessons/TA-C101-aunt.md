# அத்தை (attai) — aunt, the father's sister

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TA-LEX-C101-GRAND-02, TA-LEX-C101-GRAND-03] -->

[PAUSE 2s] Before the new one: say the Tamil for a grandmother, then the Tamil for an uncle.

## You'll want to know: அத்தை
<!-- hl-knowledge: introduces=[TA-LEX-C101-GRAND-04]; assesses=[] -->

**அத்தை** (*attai*) — "aunt", your father's sister; also "mother-in-law".

**மாமா** and **அத்தை** pair up across the two sides of the family.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

An aunt, named by side.
