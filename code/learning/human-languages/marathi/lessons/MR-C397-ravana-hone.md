# रवाना होणे (ravānā hoṇe) — to set off; to depart

## You'll want to know: रवाना होणे
<!-- hl-knowledge: introduces=[MR-LEX-C397-VILAMB397-05]; assesses=[] -->

**रवाना होणे** — *ravānā hoṇe* — "to set off; to depart".

> शेवटी बस पुण्याकडे रवाना झाली.
>
> *śevṭī bas puṇyākaḍe ravānā jhālī.*
>
> At last the bus set off for Pune.

Past (he …): तो रवाना झाला, *to ravānā jhālā*.

The place you head for takes -कडे or -ला: पुण्याला रवाना होणे.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**रवाना होणे** (*ravānā hoṇe*) joins **रवाना**, "sent off, on the way", a loan usually traced to Persian *ravāna*, to the light verb **होणे**, "to become".
