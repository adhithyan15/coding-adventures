# تضاعف (taḍāʿafa) — to double

## You'll want to know: تضاعف
<!-- hl-knowledge: introduces=[AR-LEX-C412-IZDIYAD412-03]; assesses=[] -->

**تضاعف** — *taḍāʿafa* — "to double".

> تضاعف عدد الزوار في الصيف.
>
> *taḍāʿafa ʿadad az-zuwwār fī aṣ-ṣayf.*
>
> The number of visitors doubled in summer.

Present: يتضاعف, *yataḍāʿaf*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**تضاعف** (*taḍāʿafa*) is built on the native Arabic root *ḍ-ʿ-f*, "the like of a thing; to double" (Lane). It is Form VI, to be multiplied by itself: to double.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
