Arabic, chapter 52: Face, Blood, Knee, Back, Heart.
5 lessons. All 5 can be done entirely by ear.


Lesson 1 of 5.
وجه (wajh) — a face.

Warm-up.
[pause 2 seconds]
Before the new one: say the Arabic for a shoulder, then the Arabic for the neck.

You'll want to know: وجه.
وجه — wajh — "a face".

The word, taken apart.
وجه (wajh) is built on the native Arabic root w-j-h, "the face; to face toward" (Lane). The same root gives ittijāh, "a direction", the way one faces.

Warm-up.
[pause 2 seconds]

You'll want to know: ركبة.
ركبة — rukba — "a knee".

The word, taken apart.
ركبة (rukba) is built on the native Arabic root r-k-b, "to ride, to mount" (Lane). Rukba is the knee; the verb rakiba, "to ride", is on the same root.

Warm-up.
[pause 2 seconds]

You'll want to know: ظهر.

The word, taken apart.
ظهر (ẓahr) is built on the native Arabic root ẓ-h-r, "the back; to appear, to be outward" (Lane). The same root gives ẓuhr, "noon", when the sun stands out plainly.
