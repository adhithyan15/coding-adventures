# Changelog — coding_adventures_logic_gates

## 0.1.0 — 2026-07-13

- Add the seven primitive gates and NAND-only derivations.
- Add multi-input gates, multiplexers, demultiplexers, encoders, decoders, and
  tri-state outputs.
- Add SR/D latches, edge-triggered D flip-flops, registers, shift registers,
  and counters with explicit immutable state.
- Add validation and truth-table, circuit, state-transition, and error tests.
