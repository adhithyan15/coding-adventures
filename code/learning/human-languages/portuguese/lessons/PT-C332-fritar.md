## You'll want to know: fritar
<!-- hl-knowledge: introduces=[PT-LEX-C332-FRITAR-01]; assesses=[] -->

**fritar** — "to fry".

> Ela fritou dois ovos para o pequeno-almoço.
>
> *She fried two eggs for breakfast.*

*Batatas fritas* — chips, crisps.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*fritar* is built on *frito* "fried" (EtymDB), which goes back to Latin *frīctus*, from *frīgere* "to roast, to fry".
