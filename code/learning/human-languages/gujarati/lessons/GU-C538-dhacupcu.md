# ઢચુપચુ (ḍhacupcu) — undecided (in two minds)

## You'll want to know: ઢચુપચુ
<!-- hl-knowledge: introduces=[GU-LEX-C538-SANSAY538-02]; assesses=[] -->

**ઢચુપચુ** — *ḍhacupcu* — "undecided (in two minds)".

> જો તમે ઢચુપચુ રહેશો તો કોઈ તમારો વિશ્વાસ નહીં કરે.
>
> *jo tame ḍhacupcu raheśo to koī tamāro viśvās nahī̃ kare.*
>
> If you stay undecided, nobody will trust you.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ઢચુપચુ** (*ḍhacupcu*) is an expressive, jingling word, its sound swinging like the mind it describes. No dictionary we use records an older form, so its history is not settled.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
