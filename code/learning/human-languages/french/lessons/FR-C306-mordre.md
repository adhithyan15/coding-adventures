## You'll want to know: mordre
<!-- hl-knowledge: introduces=[FR-LEX-C306-PIQURES-04]; assesses=[] -->

**mordre** — "to bite".

> Le chien du voisin a mordu le facteur.
>
> *The neighbour's dog bit the postman.*

*Se faire mordre* — to get bitten.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*mordre* is inherited from Latin *mordēre* "to bite" (EtymDB).
