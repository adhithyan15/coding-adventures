# مساواة (musāwāh) — equality

## You'll want to know: مساواة
<!-- hl-knowledge: introduces=[AR-LEX-C380-ADALA380-02]; assesses=[] -->

**مساواة** — *musāwāh* — "equality".

> نريد المساواة بين الرجل والمرأة.
>
> *nurīdu al-musāwāh bayna ar-rajul wa-l-marʾa.*
>
> We want equality between men and women.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**مساواة** (*musāwāh*) is built on the native Arabic root *s-w-y*, "to be equal, level" (Lane). *Musāwāh* is the Form III verbal noun, making equal: equality.
