## You'll want to know: одновременно
<!-- hl-knowledge: introduces=[RU-LEX-C274-POSTEPENNO-02]; assesses=[] -->

**одновременно** (*odnovreménno*) — "at the same time, simultaneously".

> Они пришли одновременно.
>
> *Oní prishlí odnovreménno.*
>
> They arrived at the same time.

*Одновременно с* + instrumental means "at the same time as": *одновременно с нами*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*одновременно* joins *один* "one", inherited from Proto-Slavic *edinŭ* (EtymDB), and *время* "time", usually taken as a Church Slavonic shape beside Old Russian *веремя*; EtymDB lists *время* with no parent.
