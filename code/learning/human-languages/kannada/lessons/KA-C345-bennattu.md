# ಬೆನ್ನಟ್ಟು (bennaṭṭu) — to chase

## You'll want to know: ಬೆನ್ನಟ್ಟು
<!-- hl-knowledge: introduces=[KA-LEX-C345-ADAGU345-03]; assesses=[] -->

**ಬೆನ್ನಟ್ಟು** — *bennaṭṭu* — "to chase".

> ಪೊಲೀಸರು ಕಳ್ಳನ ಕಾರನ್ನು ಬೆನ್ನಟ್ಟಿದರು.
>
> *polīsaru kaḷḷana kārannu bennaṭṭidaru.*
>
> The police chased the thief's car.

Past (I …): ಬೆನ್ನಟ್ಟಿದೆ, *bennaṭṭide*.

ಬೆನ್ನು, back, and ಅಟ್ಟು, to run after: to run at someone's back.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಬೆನ್ನಟ್ಟು** (*bennaṭṭu*) is a native Dravidian compound: *bennu*, "the back" (DEDR 5488), and *aṭṭu*, "to follow, to run after, to pursue", which DEDR 79 lists for Kannada.
