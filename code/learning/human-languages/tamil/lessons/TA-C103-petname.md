## You'll want to know: செல்லப்பெயர்
<!-- hl-knowledge: introduces=[TA-LEX-C103-NEXTGEN-05]; assesses=[] -->

**செல்லப்பெயர்** (*cellappeyar*) — "a pet name", literally "darling-name".

**செல்லம்** is "darling, pet".
