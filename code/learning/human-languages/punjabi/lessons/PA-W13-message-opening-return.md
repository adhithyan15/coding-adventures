# Return to the named reader and opening

Keep the earlier three-minute message unchanged. This small rehearsal returns
to its reader and first two chunks; it is not a second scored message.

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-A1-MESSAGE-PACING-01, PA-A1-MESSAGE-TIMED-01] -->

Close earlier message pages. Recall the known reader, Manan, and the two
opening jobs: greet him and ask about his wellbeing. Use known Punjabi only.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-A1-MESSAGE-PACING-01, PA-A1-MESSAGE-TIMED-01] -->

Set a one-minute practice timer. As Aman, write a Gurmukhi greeting to Manan
and one wellbeing question. Stop when the minute ends. On a separate line,
record whether the reader was named and the question ended with a question
mark. Do not change the clocked lines while checking them.

If one element slipped, write one corrected line on another page. A later
repair helps you learn, but it cannot replace either original timed attempt.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[PA-A1-MESSAGE-PACING-01, PA-A1-MESSAGE-TIMED-01] -->

Cover your practice lines. [PAUSE 4s] Say the two opening jobs in order and
name the reader. The full message also needs its familiar purpose and close;
the two complete A1 mocks have not been attempted here.
