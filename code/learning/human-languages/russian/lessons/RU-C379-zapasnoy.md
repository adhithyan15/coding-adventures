## You'll want to know: запасной
<!-- hl-knowledge: introduces=[RU-LEX-C379-ZAPASNOY-01]; assesses=[] -->

**запасной** (*zapasnóy*) — "spare, reserve".

> У меня есть запасной ключ.
>
> *U menyá yest zapasnóy klyuch.*
>
> I have a spare key.

*Запасной выход* — an emergency exit. *Запасной план* — a fallback plan.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**запасной** is built on *запас* "a store, a supply", which is usually traced to *пасти* "to guard, to keep": what is kept in reserve.
