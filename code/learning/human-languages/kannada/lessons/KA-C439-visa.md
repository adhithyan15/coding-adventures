## You'll want to know: ವೀಸಾ
<!-- hl-knowledge: introduces=[KA-LEX-C439-GADI439-01]; assesses=[] -->

**ವೀಸಾ** — *vīsā* — "a visa".

> ವಿದೇಶಕ್ಕೆ ಹೋಗಲು ಪಾಸ್ಪೋರ್ಟ್ ಮತ್ತು ವೀಸಾ ಬೇಕು.
>
> *vidēśakke hōgalu pāspōrṭ mattu vīsā bēku.*
>
> To go abroad you need a passport and a visa.

ವೀಸಾ ಸಿಕ್ಕಿತು, the visa came through.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ವೀಸಾ** (*vīsā*) is a loan from English *visa*.
