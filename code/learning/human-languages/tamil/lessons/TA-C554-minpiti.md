# மீன்பிடி (mīṉpiṭi) — to go fishing; to fish

## You'll want to know: மீன்பிடி
<!-- hl-knowledge: introduces=[TA-LEX-C554-VARAIRUTHI554-04]; assesses=[] -->

**மீன்பிடி** — *mīṉpiṭi* — "to go fishing; to fish".

> நேரம் இருந்தால் ஏரியில் மீன்பிடிப்போம்.
>
> *nēram iruntāl ēriyil mīṉpiṭippōm.*
>
> If there is time, we will fish in the lake.

Past (I …): மீன்பிடித்தேன், *mīṉpiṭittēṉ*.

Word for word "to catch fish": மீன் (*mīṉ*) + பிடி (*piṭi*).

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**மீன்பிடி** (*mīṉpiṭi*) is a native compound: மீன் (*mīṉ*), "a fish" (DEDR 4885), and பிடி (*piṭi*), "to catch".
