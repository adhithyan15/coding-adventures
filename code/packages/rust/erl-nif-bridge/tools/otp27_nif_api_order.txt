# The order of the Windows NIF callback table (TWinDynNifCallbacks), one name per line.
#
# Source: erl_nif_api_funcs.h of Erlang/OTP 27 (ERTS 15.2.7.8), the version the
# repository's Windows CI installs with erlef/setup-beam.  The file was read off a
# real windows-2025 runner by a throwaway probe PR, because there is no Erlang in
# the dev sandbox.  The header says: "Add new ERL_NIF_API_FUNC_DECL entries at the
# bottom of the list to keep compatibility on Windows", so the order is append-only
# across OTP releases.
#
# It lists every ERL_NIF_API_FUNC_DECL between '#ifdef ERL_NIF_API_FUNC_DECL' and its
# '#endif', INCLUDING the four int64 entries inside '#if SIZEOF_LONG != 8' (C long is
# 32 bits on Windows, so they are compiled in there).  After the last entry the struct
# has one more pointer, 'void* erts_alc_test'.  tools/gen_win_dyn.py consumes this
# file; to refresh it for a newer OTP, re-extract the names from that header.
