# Human Languages

A personal, etymology-driven curriculum for learning spoken languages,
delivered as ~5-minute units meant to be consumed by ear during a daily car
commute. Framework and rationale live in [`HL00`](../../specs/HL00-human-language-curriculum-framework.md) —
read that first; this page is just an index.

Every track shares the same shape:

```
<language>/
  README.md          what this track is, how to use it, current progress
  CHANGELOG.md        per-week content additions
  roadmap.md          year-long phase skeleton (topics per week)
  session-map.md      how units compose into commute sessions + review schedule
  units/*.md           the actual ~5-minute lesson files
```
