# மோசடி (mōcaṭi) — a fraud; a scam

## You'll want to know: மோசடி
<!-- hl-knowledge: introduces=[TA-LEX-C548-SIKKANAM548-04]; assesses=[] -->

**மோசடி** — *mōcaṭi* — "a fraud; a scam".

> பரிசு விழுந்ததாக வரும் குறுஞ்செய்தி ஒரு மோசடி.
>
> *paricu viḻuntatāka varum kuṟuñceyti oru mōcaṭi.*
>
> A text message saying you have won a prize is a scam.

With செய் (*cey*): மோசடி செய், to commit fraud.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

The origin of **மோசடி** (*mōcaṭi*) is not settled: no dictionary we can check gives its source.
