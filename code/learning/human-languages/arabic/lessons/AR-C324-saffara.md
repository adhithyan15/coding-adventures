# صفارة (ṣaffāra) — a whistle; a siren

## You'll want to know: صفارة
<!-- hl-knowledge: introduces=[AR-LEX-C324-KHATAR324-04]; assesses=[] -->

**صفارة** — *ṣaffāra* — "a whistle; a siren".

> سمعنا صفارة سيارة الإسعاف.
>
> *samiʿnā ṣaffārat sayyārat al-isʿāf.*
>
> We heard the ambulance siren.

صفارة الإنذار: an alarm siren.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**صفارة** (*ṣaffāra*) is built on the native Arabic root *ṣ-f-r* (Lane), where *ṣafara* is "to whistle". The *faʿʿāla* pattern names a tool that does a thing again and again.
