## You'll want to know: il capolavoro
<!-- hl-knowledge: introduces=[IT-LEX-C523-MOSTRA-02]; assesses=[] -->

**il capolavoro** — "masterpiece".

> Questo quadro è un capolavoro.
>
> *This painting is a masterpiece.*

Literally "head work": the best work.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*capolavoro* is built from *capo* "head", from Latin *caput* (Lewis & Short), and *lavoro* "work", from Latin *labor*.
