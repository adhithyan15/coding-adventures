## Grammar Lens
<!-- hl-knowledge: introduces=[]; assesses=[PA-GRAMMAR-BAARE-203, PA-LEX-C71-HOME71-02] -->

> **ਕਿਤਾਬ ਬਾਰੇ** — *kitāb bāre* — about the book

Punjabi puts this postposition after the familiar noun: book first, then
“about.” This chapter owns only that relationship word in this one gentle
frame; the book noun remains old.
