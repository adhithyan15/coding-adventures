# Objective answer keys need a non-predictable label distribution

The first Sanskrit A2 key faithfully followed the draft options but placed too
few correct answers under C, while the second draft placed every answer under
A. Even when every item has a correct option, that label pattern teaches test
taking instead of comprehension. Reorder plausible distractors before review
and make the owned mock test require a meaningful minimum count for A, B, and C
in each objective paper.
