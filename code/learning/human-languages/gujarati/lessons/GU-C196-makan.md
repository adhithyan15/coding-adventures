## You'll want to know: મકાન
<!-- hl-knowledge: introduces=[GU-LEX-C196-STOREY196-01]; assesses=[] -->

**મકાન** — *makān* — "building, house".

> **આ મકાન જૂનું છે.** — *ā makān jūnũ che* — "This building is old."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**મકાન** (*makān*) is a loan from Arabic *makān*, "place", which reached Gujarati through Persian. Its Arabic root is *k-w-n*, "to be" (Lane).
