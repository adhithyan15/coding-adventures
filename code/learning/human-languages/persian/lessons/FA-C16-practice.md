# Payoff — one to five, out of order

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[FA-LEX-PANJ, FA-LEX-YEK] -->

[PAUSE 2s] Say **panj**, then **yek**.

## Guided Practice
<!-- hl-knowledge: introduces=[FA-PERFORMANCE-COUNT-FIVE]; assesses=[FA-LEX-YEK, FA-LEX-DO, FA-LEX-SE, FA-LEX-CHAHAR, FA-LEX-PANJ, FA-ETYMON-YEK, FA-ETYMON-DO, FA-ETYMON-SE, FA-ETYMON-CHAHAR, FA-ETYMON-PANJ, FA-SCRIPT-SIN-01, FA-SCRIPT-HE-01] -->

A run learned forwards is a rhyme. Break it four ways.

1. Hear each of the five named singly and out of order, and say what it is.
2. Count backwards from **panj** to **yek**.
3. Read the five printed shuffled — **پنج، یک، چهار، سه، دو** — and say each.
4. Write **سه**, the one of the five whose letters are already yours.

Then say each number's English cousin: **one, two, three, four, five**. Every
one of the five has one, and that is not a coincidence — it is the same set of
words, five thousand years apart.
