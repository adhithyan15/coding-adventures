## You'll want to know: अनुकूल
<!-- hl-knowledge: introduces=[MR-LEX-C556-ANUKUL556-01]; assesses=[] -->

**अनुकूल** — *anukūl* — "favourable".

> हवामान अनुकूल असेल तर आम्ही उद्या निघू.
>
> *havāmān anukūl asel tar āmhī udyā nighū.*
>
> If the weather is favourable we will set out tomorrow.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**अनुकूल** (*anukūl*) is a tatsama, taken from Sanskrit *anukūla*, "following the bank or slope" (Monier-Williams), so going with the stream.
