## You'll want to know: అదే
<!-- hl-knowledge: introduces=[TE-LEX-C98-REPLY-05]; assesses=[] -->

**అదే** (*adē*) — "that's the one", "the same one".

It is **అది**, "that", with the same **-ఏ**. When someone finally names what you meant, **అదే!**
