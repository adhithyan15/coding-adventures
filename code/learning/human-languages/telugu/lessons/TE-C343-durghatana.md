# దుర్ఘటన (durghaṭana) — a tragic accident; a disaster

## You'll want to know: దుర్ఘటన
<!-- hl-knowledge: introduces=[TE-LEX-C343-TRUTILO343-02]; assesses=[] -->

**దుర్ఘటన** — *durghaṭana* — "a tragic accident; a disaster".

> ఆ దుర్ఘటన నిన్న సాయంత్రం జరిగింది.
>
> *ā durghaṭana ninna sāyantraṁ jarigindi.*
>
> That tragic accident happened yesterday evening.

దుర్-, ill, with ఘటన, a happening: compare సంఘటన.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**దుర్ఘటన** (*durghaṭana*) is built from Sanskrit *dur-*, "ill, bad", and *ghaṭana*, "a joining, a coming together" (Monier-Williams).
