# സ്വാതന്ത്ര്യം (svātantryaṁ) — freedom

## You'll want to know: സ്വാതന്ത്ര്യം
<!-- hl-knowledge: introduces=[ML-LEX-C415-SAMUHAM415-05]; assesses=[] -->

**സ്വാതന്ത്ര്യം** — *svātantryaṁ* — "freedom".

> കുട്ടികൾക്ക് കളിക്കാൻ കുറച്ച് സ്വാതന്ത്ര്യം വേണം.
>
> *kuṭṭikaḷkkŭ kaḷikkān kuṟaccŭ svātantryaṁ vēṇaṁ.*
>
> Children need some freedom to play.

A free country: സ്വതന്ത്ര രാജ്യം.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**സ്വാതന്ത്ര്യം** (*svātantryaṁ*) is borrowed from Sanskrit *svātantrya*, "following one's own will, freedom" (Monier-Williams), made from *svatantra*, "under one's own rule".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
