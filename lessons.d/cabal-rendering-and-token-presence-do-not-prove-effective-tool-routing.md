Preserve the failed rendering-based validator and the real executable receipts; do not infer routing from serialization. Conversely, a healthy default build does not prove configured compiler identity: require exact missing-driver refusals, selected hsc2hs wrapper source traces and complete argument tails before publication. Bind each refusal to its actual could-not-execute diagnostic; a driver name elsewhere in a verbose command is insufficient. Normalize Cabal names, comments and guarded section syntax before detecting existing overrides.
