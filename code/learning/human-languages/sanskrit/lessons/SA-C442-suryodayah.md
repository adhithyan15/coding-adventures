## You'll want to know: सूर्योदयः
<!-- hl-knowledge: introduces=[SA-LEX-C442-UDAYA442-01]; assesses=[] -->

**सूर्योदयः** — *sūryodayaḥ* — "sunrise".

> वयं सूर्योदयात् पूर्वं प्रतिष्ठामहे।
>
> *vayaṃ sūryodayāt pūrvaṃ pratiṣṭhāmahe.*
>
> We set out before sunrise.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**सूर्योदयः** (*sūryodayaḥ*) is built from *sūrya*, "the sun", and *udaya*, "rising", from *ud* and the root √i, "to go"; MW gives the compound as sunrise (MW).
