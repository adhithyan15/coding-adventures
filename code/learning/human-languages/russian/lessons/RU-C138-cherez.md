## You'll want to know: через
<!-- hl-knowledge: introduces=[RU-LEX-C138-FUT138-02]; assesses=[] -->

**через** (*chérez*) — "in (a week), after". Counted from now: **через неделю** — *chérez nedélyu* — "in a week". **неделя** changes to **неделю** after it.
