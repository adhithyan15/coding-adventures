## You'll want to know: la recuperación
<!-- hl-knowledge: introduces=[ES-LEX-C739-CURAR-03]; assesses=[] -->

**la recuperación** — "recovery".

> Le deseo una pronta recuperación.
>
> *I wish you a speedy recovery.*

*Pronta recuperación* — get well soon.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*recuperación* is usually described as a learned borrowing from Latin *recuperātiō*, built on *recuperāre* "to get back".
