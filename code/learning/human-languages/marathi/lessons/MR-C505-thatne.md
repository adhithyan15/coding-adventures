## You'll want to know: थाटणे
<!-- hl-knowledge: introduces=[MR-LEX-C505-KARAGIR505-05]; assesses=[] -->

**थाटणे** — *thāṭṇe* — "to set up; to lay out with care".

> विणकराने बाजारात नवीन दुकान थाटलं.
>
> *viṇkarāne bājārāt navīn dukān thāṭlaṁ.*
>
> The weaver set up a new shop in the market.

Past, with -ने (he …): त्याने दुकान थाटलं, *tyāne dukān thāṭlaṁ*.

थाटणे is said of a shop or a home set up with some show; थाट is the show itself.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**थाटणे** (*thāṭṇe*) is built on थाट, "pomp, a fine arrangement"; CDIAL sets Hindi *ṭhāṭh*, "pomp", and Marathi *thaṭṇẽ*, "to act pompously", under *\*thaṭṭha*, "pomp, ceremony" (CDIAL 6090).
