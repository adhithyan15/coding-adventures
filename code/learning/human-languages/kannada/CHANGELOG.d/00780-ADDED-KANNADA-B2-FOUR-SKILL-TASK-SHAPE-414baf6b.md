## Added — Kannada B2 four-skill task shape

- Published the project-defined Kannada B2 performance target as four
  independently passing papers: argument, reporting, instruction, and cultural
  reading; one-play multi-speaker listening with two documented regional
  voices; independent interaction and extended writing; and presentation,
  collaborative problem-solving, and defended discussion.
- Kept the writing target in Kannada script and scored the three script controls
  named by the assessment contract: rounded letterforms, vowel-sign placement,
  and the subscript ottakshara below its base letter.
- Added an independently owned zero reading-reach floor. It makes the B2 target
  measurable without claiming that the current corpus reaches it.
