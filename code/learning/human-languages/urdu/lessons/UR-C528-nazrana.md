## You'll want to know: نذرانہ
<!-- hl-knowledge: introduces=[UR-LEX-C528-BARKAT528-04]; assesses=[] -->

**نذرانہ** — *nazrānā* — "an offering (to someone revered)".

> اگر ہم استاد کے گھر گئے تو نذرانہ دیں گے۔
>
> *agar ham ustād ke ghar gae to nazrānā deṅ ge.*
>
> If we go to our teacher's house, we will make an offering.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**نذرانہ** (*nazrānā*) is usually traced to Persian *nazrāna*, built on Arabic *nadhr*, "a vow, an offering".
