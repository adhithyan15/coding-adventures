## You'll want to know: ಮೀಸಲಿಡು
<!-- hl-knowledge: introduces=[KA-LEX-C387-SAVALU387-02]; assesses=[] -->

**ಮೀಸಲಿಡು** — *mīsaliḍu* — "to set aside".

> ನಾನು ಪ್ರತಿ ತಿಂಗಳು ಸ್ವಲ್ಪ ಹಣ ಮೀಸಲಿಟ್ಟೆ.
>
> *nānu prati tiṅgaḷu svalpa haṇa mīsaliṭṭe.*
>
> I set aside a little money every month.

Past (I …): ಮೀಸಲಿಟ್ಟೆ, *mīsaliṭṭe*.

ಮೀಸಲು (kept apart) + ಇಡು (to put).

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಮೀಸಲಿಡು** (*mīsaliḍu*) is native Dravidian, built from *mīsal*, "something set apart and left untouched" (DEDR 4841), and *iḍu*, "to put" (DEDR 442).
