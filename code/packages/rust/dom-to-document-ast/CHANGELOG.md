# Changelog

## [0.1.0] - 2026-05-08

### Added
- `dom_to_document_ast()` adapter from `dom-core::Document` to
  `document_ast::DocumentNode`.
- Mosaic-era mappings for headings, paragraphs, lists, list items, blockquotes,
  preformatted text, thematic breaks, links, images, emphasis, strong text,
  code spans, and hard breaks.
