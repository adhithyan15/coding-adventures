# 晚上好 (wǎnshang hǎo) — good evening

## Warm-up

[PAUSE 2s] Before the new one: say the Mandarin for evening, then the Mandarin for afternoon.

## You'll want to know: 晚上好
<!-- hl-knowledge: introduces=[ZH-LEX-C49-DAY49-05]; assesses=[] -->

**晚上好** — *wǎnshang hǎo* — "good evening".

> **大家晚上好** *dàjiā wǎnshang hǎo* — Good evening, everyone.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**晚上好** (*wǎnshang hǎo*) is built from 晚上 'evening' and 好 'good', the same shape as 早上好.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for times and partings.
