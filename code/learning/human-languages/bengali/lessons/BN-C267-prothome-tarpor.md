# প্রথমে … তারপর … শেষে (prôthôme … tārpôr … sheshe) — the order of a story

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[BN-GRAMMAR-C267-CONJUNCTIVE-01, BN-LEX-C156-SOMOY156-02, BN-LEX-C265-SHESH-01] -->

[PAUSE 2s] Say "I went home and ate". (*āmi bāṛi giye khelām*.) Then say **প্রথমে**, "at first", and **শেষ**, "the end".

## You'll want to know: first, then
<!-- hl-knowledge: introduces=[BN-GRAMMAR-C267-FIRST-THEN-01]; assesses=[BN-LEX-C156-SOMOY156-02, BN-LEX-C80-TIME80-03, BN-LEX-C10-CHA-01, BN-LEX-C84-TOWN84-03, BN-GRAMMAR-C264-PAST-PERSON-01] -->

> **প্রথমে আমরা চা খেলাম। তারপর বাজারে গেলাম।**
>
> *prôthôme āmrā chā khelām. tārpôr bājāre gelām.* — "First we had tea. After that we went to the market."

**প্রথমে**, which you know, opens a story. **তারপর** (*tārpôr*), "after that, then", is new: **তার**, "of that", and **পর**, "after", the word inside **পরে**. **তারপর** starts each new step; **পরে**, "later", says the step came some time after.

## You'll want to know: in the end
<!-- hl-knowledge: introduces=[BN-GRAMMAR-C267-FINALLY-01]; assesses=[BN-LEX-C265-SHESH-01, BN-LEX-C59-FOOD59-04, BN-LEX-C106-ACT106-04] -->

**শেষে** (*sheshe*) is **শেষ** with **-এ**: "at the end, finally". It closes the story.

> **শেষে আমরা বাড়ি ফিরলাম।**
>
> *sheshe āmrā bāṛi phirlām.* — "In the end we came back home."
