## You'll want to know: कार्यकर्ता
<!-- hl-knowledge: introduces=[MR-LEX-C364-SANSTHA364-05]; assesses=[] -->

**कार्यकर्ता** — *kāryakartā* — "an activist; a worker for a cause".

> कार्यकर्त्यांनी गावात झाडं लावली.
>
> *kāryakartyānnī gāvāt jhāḍaṁ lāvlī.*
>
> The activists planted trees in the village.

Masculine. Plural: कार्यकर्ते, *kāryakarte*.

Plural कार्यकर्ते; oblique कार्यकर्त्या-.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**कार्यकर्ता** (*kāryakartā*) is a learned compound built from Sanskrit *kārya*, "what is to be done", and *kartṛ*, "doer" (Monier-Williams).
