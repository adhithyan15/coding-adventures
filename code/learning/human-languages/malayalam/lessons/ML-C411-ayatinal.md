# ആയതിനാൽ (āyatināl) — hence; therefore

## You'll want to know: ആയതിനാൽ
<!-- hl-knowledge: introduces=[ML-LEX-C411-KARANAM411-02]; assesses=[] -->

**ആയതിനാൽ** — *āyatināl* — "hence; therefore".

> അവന് പനിയാണ്, ആയതിനാൽ ഇന്ന് വരില്ല.
>
> *avanŭ paniyāṇŭ, āyatināl innŭ varilla.*
>
> He has a fever; hence he will not come today.

Formal, common in letters and notices.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ആയതിനാൽ** (*āyatināl*) is a native Malayalam formation: ആയത്, "that which became", from ആകുക, "to become" (DEDR 333), with the instrumental ending -ഇനാൽ.
