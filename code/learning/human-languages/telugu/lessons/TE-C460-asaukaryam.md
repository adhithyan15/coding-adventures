# అసౌకర్యం (asaukaryaṁ) — inconvenience

## You'll want to know: అసౌకర్యం
<!-- hl-knowledge: introduces=[TE-LEX-C460-ASAUKARYAM460-01]; assesses=[] -->

**అసౌకర్యం** — *asaukaryaṁ* — "inconvenience".

> ఆలస్యం వల్ల కలిగిన అసౌకర్యానికి క్షమించండి.
>
> *ālasyaṁ valla kaligina asaukaryāniki kṣamiñcaṇḍi.*
>
> We are sorry for the inconvenience caused by the delay.

అ-, not, + సౌకర్యం, comfort. Station announcements use this sentence.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**అసౌకర్యం** (*asaukaryaṁ*) is built from Sanskrit *a-*, "not", and *saukarya*, "ease, practicability" (Monier-Williams).
