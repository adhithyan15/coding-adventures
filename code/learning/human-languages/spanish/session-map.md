# Session Map — Chapter 1 (First Words)

How Chapter 1's ten deep lessons compose into car-ride sessions, with the
spaced-repetition schedule. Mechanics in
[`HL00`](../../../specs/HL00-human-language-curriculum-framework.md); this is
the worked example for the redesigned one-word-per-lesson model.

Reviews are scheduled in **session-counts, not calendar days**: a word
introduced in session *N* is resurfaced at *N+1*, *N+3*, *N+7*, *N+15*.
Because each lesson is now a single word (a few minutes), a session can hold
**two or three new lessons** plus its due reviews and still fit a commute —
each new lesson is still exactly one *thing*.

## Session-by-session

| Session | Reviews due | New lessons |
|---|---|---|
| 1 | — (bootstrap) | `L01` hola · `L02` buenos días |
| 2 | `L01`, `L02` (N+1) | `L03` buenas tardes · `L04` buenas noches |
| 3 | `L02` (N+3), `L03`, `L04` (N+1) | `L05` gracias · `L06` por favor |
| 4 | `L01` (N+3 wave), `L05`, `L06` (N+1) | `L07` adiós |
| 5 | `L03` (N+3), `L07` (N+1) | `L08` ¿cómo estás? |
| 6 | `L04` (N+3), `L08` (N+1) | `L09` me llamo |
| 7 | `L05` (N+3), `L09` (N+1) | `L10` quiero |
| 8 | `L06` (N+3), `L10` (N+1), `L01` (N+7) | *(practice-mix: the full intro — "Hola, me llamo ___. ¿Cómo estás?")* |

The practice-mix at session 8 recombines the chapter into the running
dialogue every lesson has been building toward: greeting → name → question →
request (*por favor*) → thanks → *adiós*. Review lessons (fresh-combination
resurfacings, not verbatim repeats) are generated from the due column as each
session is reached, per HL00.

## Bonus queue

On a longer drive, append the nearest not-yet-due reviews and re-listen to
any lesson whose cousin web or cultural note you want to re-cement — the
etymology is the part worth over-reviewing, since it's what makes the word
stick.
