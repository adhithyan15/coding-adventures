## You'll want to know: abgießen
<!-- hl-knowledge: introduces=[GE-LEX-C328-SIEB-02]; assesses=[] -->

**abgießen** — "to drain (by pouring off)".

> Sie goss die Kartoffeln ab.
>
> *She drained the potatoes.*

Separable, strong: *goss ab*, *hat abgegossen*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*abgießen* is built on *gießen* "to pour", Old High German *giozan*, Proto-Germanic *geutaną* (EtymDB), with *ab* "off".
