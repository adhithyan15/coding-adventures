# غلط فہمی (ghalat-fahmī) — a misunderstanding

## You'll want to know: غلط فہمی
<!-- hl-knowledge: introduces=[UR-LEX-C337-TASDIQ337-05]; assesses=[] -->

**غلط فہمی** — *ghalat-fahmī* — "a misunderstanding".

> یہ ایک غلط فہمی تھی، کوئی جھوٹ نہیں۔
>
> *yih ek ghalat-fahmī thī, koī jhūṭ nahīṅ.*
>
> It was a misunderstanding, not a lie.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**غلط فہمی** (*ghalat-fahmī*) is usually traced to Persian *ghalat-fahmī*, "a mistaken understanding": **غلط**, "wrong", with *fahmī*, "understanding".
