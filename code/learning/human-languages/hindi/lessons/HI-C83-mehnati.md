# मेहनती — an ending that makes a person out of a thing

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[HI-LEX-C83-CHAR-02] -->

[PAUSE 2s] Say **होशियार**. It ends in a consonant and stays put. This word ends
in **-ई**, which is a third shape, and it also stays put — for a different
reason.

## You'll want to know: मेहनती
<!-- hl-knowledge: introduces=[HI-LEX-C83-CHAR-03]; assesses=[] -->

**मेहनती** (*mehnatī*) — "hard-working, industrious."

It is built out of a noun you can see inside it: **मेहनत** (*mehnat*), "hard
work, toil," plus the ending **-ई**.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**मेहनत** is Arabic *miḥna*, which did not start out meaning honest labour. It
meant a **trial, an ordeal, a testing** — the thing that puts a person through
it. Work became the name for the ordeal, which is a judgement about work that
several languages independently agreed on.

The **-ई** on the end is one of the most useful endings in Hindi. Attach it to a
noun and you get *the person characterised by that thing*:

| noun | the person |
|---|---|
| मेहनत — toil | मेहनती — one who toils |
| शरम — shame | शर्मीला — one who feels it |
| ज़रूरत — need | ज़रूरी — necessary |

It is the same job English does with **-y** in *wealthy*, *greedy*, *speedy* —
and, in fact, the very same job Persian does with **-ī** in *Hindī*, "belonging
to Hind."

## Grammar Lens: the third shape, and why it also stays put
<!-- hl-knowledge: introduces=[]; assesses=[HI-LEX-C83-CHAR-03, HI-LEX-C83-CHAR-02, HI-GRAMMAR-C41-ADJ-SYSTEM] -->

| ending | example | changes for a woman? |
|---|---|---|
| **-आ** | बुरा | yes, to **-ई** |
| consonant | होशियार | no |
| **-ई** | मेहनती | no |

The reason the third row does not move is worth seeing rather than memorising:
the feminine ending an **-आ** adjective changes *to* is **-ई**. A word that
already ends in **-ई** has nowhere to go. It is not an exception — it is the
rule arriving at a word that is already there.
