# உறவினர் (uṟaviṉar) — a relative

## You'll want to know: உறவினர்
<!-- hl-knowledge: introduces=[TA-LEX-C100-FAMILY-05]; assesses=[] -->

**உறவினர்** (*uṟaviṉar*) — "a relative".

**உறவு** is "a tie, a relationship"; a relative is one who has one with you.
