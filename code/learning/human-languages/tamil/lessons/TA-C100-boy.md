# பையன் (paiyaṉ) — a boy; a son

## You'll want to know: பையன்
<!-- hl-knowledge: introduces=[TA-LEX-C100-FAMILY-02]; assesses=[] -->

**பையன்** (*paiyaṉ*) — "a boy", and in a family, "a son".

**என் பையன்** — "my boy", "my son".
