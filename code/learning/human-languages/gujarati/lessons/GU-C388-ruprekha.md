# રૂપરેખા (rūprekhā) — an outline

## You'll want to know: રૂપરેખા
<!-- hl-knowledge: introduces=[GU-LEX-C388-UPAKRAM388-01]; assesses=[] -->

**રૂપરેખા** — *rūprekhā* — "an outline".

> જો રૂપરેખા તૈયાર હશે તો કામ ઝડપી થશે.
>
> *jo rūprekhā taiyār haśe to kām jhaḍpī thaśe.*
>
> If the outline is ready, the work will go faster.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**રૂપરેખા** (*rūprekhā*) is built from Sanskrit *rūpa*, "form, shape", and *rekhā*, "a line" (Monier-Williams): the lines of a shape.
