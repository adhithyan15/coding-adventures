## You'll want to know: سلسلہ
<!-- hl-knowledge: introduces=[UR-LEX-C544-AGHAZ544-04]; assesses=[] -->

**سلسلہ** — *silsilā* — "a series; a run (of events)".

> اگر بارش کا سلسلہ جاری رہا تو سیلاب آئے گا۔
>
> *agar bārish kā silsilā jārī rahā to sailāb āe gā.*
>
> If the rain keeps on, there will be a flood.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**سلسلہ** (*silsilā*) is usually traced, through Persian, to Arabic *silsila*, "a chain".
