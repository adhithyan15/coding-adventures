# ぴ — ひ, with the circle

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[JA-LEX-ANCHOR-ENPITSU, JA-LEX-C135-DEGUCHI, JA-LEX-C128-QUAL128-05] -->

[PAUSE 15s] Three recalls, then the sign.

- [YOU RECALL: say *a pencil* — **R1**, one lesson back]
- [YOU RECALL: say *an exit* — **R3**, twenty lessons back]
- [YOU RECALL: say *ugly* — **R4**, eighty lessons back]

## Script — the change
<!-- hl-knowledge: introduces=[JA-SCRIPT-PI-01]; assesses=[JA-SCRIPT-HI-01, JA-SCRIPT-HANDAKUTEN-01] -->

> **ひ** *hi* + **゜** → **ぴ** *pi*

Write **ひ** in full: one stroke, a short rise, the deep bowl, and up again.
Then add the small circle at the upper right, beside the end of the stroke.
Keep it small and open.

The circle makes a *p* again: *hi* becomes *pi*. The voicing mark on the same
sign gives **び**, *bi*, so one base sign now has three readings.

With **えん** in front and **つ** after it, you can now write the word from the
last lesson: **えんぴつ**, *enpitsu*, a pencil.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[JA-SCRIPT-PI-01, JA-SCRIPT-HI-01, JA-SCRIPT-HANDAKUTEN-01, JA-LEX-ANCHOR-ENPITSU] -->

1. Write **ひ**, then **び**, then **ぴ**, and say *hi*, *bi*, *pi*.
2. Write **は ぱ** and **ひ ぴ** in pairs, and say each one.
3. Write **えんぴつ** from memory and say *enpitsu*.
