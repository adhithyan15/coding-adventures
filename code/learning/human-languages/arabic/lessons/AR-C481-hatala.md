# هطل (haṭala) — to pour down (of rain)

## You'll want to know: هطل
<!-- hl-knowledge: introduces=[AR-LEX-C481-MATAR481-04]; assesses=[] -->

**هطل** — *haṭala* — "to pour down (of rain)".

> هطل المطر في الليل.
>
> *haṭala al-maṭar fī al-layl.*
>
> The rain poured down in the night.

Present: يهطل, *yahṭil*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**هطل** (*haṭala*) is built on the native Arabic root *h-ṭ-l*, "to pour (of water)" (Lane). It is the plain verb.
