## You'll want to know: आकांक्षा
<!-- hl-knowledge: introduces=[SA-LEX-C383-SANKALPA383-02]; assesses=[] -->

**आकांक्षा** — *ākāṅkṣā* — "an ambition; a longing".

> यदि आकांक्षा महती, तर्हि प्रयत्नः अपि महान् भवेत्।
>
> *yadi ākāṅkṣā mahatī, tarhi prayatnaḥ api mahān bhavet.*
>
> If the ambition is great, the effort should be great too.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**आकांक्षा** (*ākāṅkṣā*) is built on *ā* and the root √kāṅkṣ, "to desire"; MW gives *ā-kāṅkṣā* "desire, wish" (MW).
