# പ്രതികരിക്കുക (pratikarikkuka) — to respond; to react

## You'll want to know: പ്രതികരിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C453-PINTUNA453-05]; assesses=[] -->

**പ്രതികരിക്കുക** — *pratikarikkuka* — "to respond; to react".

> ആ വാർത്തയോട് മന്ത്രി ഉടനെ പ്രതികരിച്ചു.
>
> *ā vārttayōṭŭ mantri uṭane pratikariccu.*
>
> The minister responded to that news at once.

Past: പ്രതികരിച്ചു, *pratikariccu*.

To something: -ഓട് പ്രതികരിക്കുക. The noun is പ്രതികരണം, a response.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**പ്രതികരിക്കുക** (*pratikarikkuka*) is built from Sanskrit *prati-kṛ*, "to act back", whose noun *pratikāra* means "requital, counteraction" (Monier-Williams), with the Malayalam verb ending -ിക്കുക.

## What you've built
