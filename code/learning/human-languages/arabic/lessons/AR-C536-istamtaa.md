## You'll want to know: استمتع
<!-- hl-knowledge: introduces=[AR-LEX-C536-SAYD536-05]; assesses=[] -->

**استمتع** — *istamtaʿa* — "to enjoy".

> استمتعنا بالنزهة كثيرا.
>
> *istamtaʿnā bi-n-nuzha kathīran.*
>
> We enjoyed the outing very much.

Present: يستمتع, *yastamtiʿ*.

It takes بـ for what you enjoy.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**استمتع** (*istamtaʿa*) is built on the native Arabic root *m-t-ʿ*, "to enjoy, to profit by" (Lane). Mumtiʿ, enjoyable, which you know, is from the same root.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
