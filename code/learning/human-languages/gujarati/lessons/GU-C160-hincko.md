# હિંચકો (hincko) — swing

## You'll want to know: હિંચકો
<!-- hl-knowledge: introduces=[GU-LEX-C160-BED160-03]; assesses=[] -->

**હિંચકો** — *hincko* — "swing".

> **ઓસરીમાં હિંચકો છે.** — *osrīmā̃ hincko che* — "There is a swing on the veranda."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**હિંચકો** (*hincko*) is built on the inherited verb *hĩcvũ*, "to swing", which CDIAL lists with *hicakvũ* under *\*hicc*, "draw back", a reconstructed form (CDIAL 14083).
