# ત્યાગ (tyāg) — giving something up (for others)

## You'll want to know: ત્યાગ
<!-- hl-knowledge: introduces=[GU-LEX-C358-SEVA358-02]; assesses=[] -->

**ત્યાગ** — *tyāg* — "giving something up (for others)".

> માતાએ બાળકો માટે ઘણો ત્યાગ કર્યો.
>
> *mātāe bāḷko māṭe ghaṇo tyāg karyo.*
>
> The mother gave up a great deal for her children.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ત્યાગ** (*tyāg*) is a tatsama, borrowed from Sanskrit *tyāga*, "leaving, abandoning, giving up" (Monier-Williams).
