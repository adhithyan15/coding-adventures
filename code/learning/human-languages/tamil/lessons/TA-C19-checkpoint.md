# Chapter 19 checkpoint — two ways to ask an age, and சரி from sound

## Guided Practice — the age question
<!-- hl-knowledge: introduces=[]; assesses=[TA-LEX-VAYATHU-01, TA-GRAMMAR-AGE-REGISTER-GRAMMAR-01, TA-GRAMMAR-AGE-REGISTER-GRAMMAR-02] -->

[PAUSE 1s]
- [YOU SAY: the casual question, to a friend]
- [YOU SAY: the formal question, to someone you would address with care]
- [YOU ANSWER: in the formal shape, giving twenty as the age]

(*Un vayasu enna?* — *Unakku ettanai vayathu aakirathu?* — *Enakku irupathu
vayathu aakirathu.*)

- Where does *vayathu* come from? (Sanskrit *vayas*, "age, vigor", which all
  four Dravidian languages here borrowed.)
- Which shape uses the dative and *aakirathu*, "becomes"? (The formal one; the
  casual one is a plain possessive with no verb.)

## Script — ◌ி, ச and ◌ே
<!-- hl-knowledge: introduces=[]; assesses=[TA-SCRIPT-DRIZZLE-09, TA-SCRIPT-CA-ONE-LETTER-01, TA-SCRIPT-WRITE-SARI-02, TA-SCRIPT-RECOG-123] -->

- Does **◌ி** add a vowel or replace one? (It replaces the built-in *a*:
  **ற** is *ṟa*, **றி** is *ṟi*.)
- Which sounds does **ச** cover on its own? (*s* or *ch* at the start of a
  word, softened between vowels, *j* after a nasal.)
- Which two pieces build **சரி**? (**ச** · **ரி**: ர carrying the i-sign.)
- In **பேசு**, *pēsu*, "to speak", which mark gives the first consonant its
  *ē*? (**◌ே**.)

[YOU READ: **சரி** and **பேசு** aloud, and point to the ◌ே]
