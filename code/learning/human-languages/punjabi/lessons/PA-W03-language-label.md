# ਭਾਸ਼ਾ — assemble the language label

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-SCRIPT-BHA-01, PA-SCRIPT-SHA-01, PA-SCRIPT-AA-MATRA-01] -->

Touch the two new bases in order: **ਭ**, then **ਸ਼**. The long-vowel mark is already familiar.

## Script — one tiny step
<!-- hl-knowledge: introduces=[PA-FORM-LABEL-LANGUAGE-01]; assesses=[PA-SCRIPT-BHA-01, PA-SCRIPT-SHA-01, PA-SCRIPT-AA-MATRA-01] -->

Build **ਭਾ + ਸ਼ਾ = ਭਾਸ਼ਾ**. On a form, **ਭਾਸ਼ਾ** asks which language belongs on the line. Copy the label once, then leave the answer line empty.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-LABEL-LANGUAGE-01] -->

Complete one careful attempt. Compare only the new shape or word, repair one
difference, and stop.
