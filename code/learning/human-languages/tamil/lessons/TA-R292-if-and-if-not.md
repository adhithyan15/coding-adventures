# Review — if, and if not

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TA-GRAMMAR-C292-CONDITIONAL-01, TA-GRAMMAR-C292-NEGATIVE-CONDITION-01, TA-LEX-C285-IRAM-01, TA-SCRIPT-RECOG-141] -->

[PAUSE 2s] Say "if you come" and "if you don't come". Then read **ஈரம்** aloud. (*īram*.)

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[TA-GRAMMAR-C292-CONDITIONAL-01, TA-GRAMMAR-C292-ENRAL-01, TA-GRAMMAR-C292-REAL-CONDITION-01, TA-GRAMMAR-C292-NEGATIVE-CONDITION-01, TA-GRAMMAR-C287-OBLIGATIVE-01, TA-GRAMMAR-C291-THAN-01, TA-GRAMMAR-C291-SPAN-01, TA-LEX-C285-IRAM-01, TA-SCRIPT-RECOG-141] -->

[PAUSE 2s each]
- [YOU SAY: If you come tomorrow, we can go to the sea.]
- [YOU SAY: If it is a holiday, I will sleep until nine.]
- [YOU SAY: If by any chance it rains, take an umbrella.]
- [YOU SAY: Even if the bus is late, I will come.]
- [YOU SAY: one if, one even if and one if not, about tomorrow]
