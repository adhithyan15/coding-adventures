# ముగింపు (mugimpu) — an ending; a conclusion

## You'll want to know: ముగింపు
<!-- hl-knowledge: introduces=[TE-LEX-C376-SPANDANA376-03]; assesses=[] -->

**ముగింపు** — *mugimpu* — "an ending; a conclusion".

> కానీ కథ ముగింపు నాకు నచ్చలేదు.
>
> *kānī katha mugimpu nāku naccalēdu.*
>
> But I did not like the story's ending.

The noun of ముగించు, to finish.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ముగింపు** (*mugimpu*) is native Dravidian: DEDR 4891 lists Telugu *mugimpu*, "finishing, end", with *mugincu*, "to finish", and Tamil *muki*, "to end".
