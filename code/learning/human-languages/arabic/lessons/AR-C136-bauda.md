## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**بعوضة** (*baʿūḍa*) is built on the native Arabic root *b-ʿ-ḍ*, "gnats; to cut into parts" (Lane). *Baʿūḍa* is one gnat, a mosquito.
