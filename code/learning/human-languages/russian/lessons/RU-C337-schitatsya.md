## You'll want to know: считаться
<!-- hl-knowledge: introduces=[RU-LEX-C337-TOCHKAZRENIYA-05]; assesses=[] -->

**считаться** (*schitátsya*) — "to be considered, to be regarded as".

> Этот район считается самым тихим в городе.
>
> *Étot rayón schitáyetsya sámym tíkhim v górode.*
>
> This district is considered the quietest in the city.

An imperfective verb. It takes the instrumental: *считается лучшим*. *Считаться с* + instrumental — to take into account.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**считаться** is the reflexive of *считать*, built from *с-* and *читать*. *Читать* shares its root with *число* "number", from Proto-Slavic *\*čislo*, built on *\*čisti* (EtymDB): to be considered is to be counted as something.
