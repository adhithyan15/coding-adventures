## You'll want to know: ಯಾವಾಗ
<!-- hl-knowledge: introduces=[KA-LEX-C71-MORE-04]; assesses=[] -->

**ಯಾವಾಗ** (*yāvāga*) — "when?"

The question set is nearly complete: who, where, what, why, and now when. This
is the last one an everyday exchange keeps reaching for.

**ಯಾವಾಗ ಬರುತ್ತೀರಾ?** (*yāvāga baruttīrā?*) — "when will you come?" Notice the
question ending on the end of it, doing the same job it did on ಗೊತ್ತಾ.

The answers are already yours: ಈಗ (*īga*, "now"), ನಾಳೆ, ನಾಡಿದ್ದು
(*nāḍiddu*, "the day after tomorrow"). Ask ಯಾವಾಗ and you can understand what
comes back.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

Five question words. Who, where, what, why, when — and a reason and an
opinion to answer them with.
