## You'll want to know: o emigrante
<!-- hl-knowledge: introduces=[PT-LEX-C317-REFORMA-05]; assesses=[] -->

**o emigrante** — "the emigrant".

> O emigrante volta à aldeia todos os verões.
>
> *The emigrant comes back to the village every summer.*

The same form for a woman: *a emigrante*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*emigrante* is a learned borrowing from Latin *ēmigrāns* "moving out" (EtymDB), from *ēmigrāre*, built on *migrāre* "to move".
