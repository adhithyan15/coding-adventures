# ശവപ്പെട്ടി (śavappeṭṭi) — a coffin

## You'll want to know: ശവപ്പെട്ടി
<!-- hl-knowledge: introduces=[ML-LEX-C391-SAVAM391-03]; assesses=[] -->

**ശവപ്പെട്ടി** — *śavappeṭṭi* — "a coffin".

> ആറ് പേർ ശവപ്പെട്ടി പള്ളിയിലേക്ക് ചുമന്നു.
>
> *āṟŭ pēr śavappeṭṭi paḷḷiyilēkkŭ cumannu.*
>
> Six men carried the coffin to the church.

ശവം, a body, + പെട്ടി, a box.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ശവപ്പെട്ടി** (*śavappeṭṭi*) joins Sanskrit *śava*, "a corpse" (CDIAL 12356), and the native പെട്ടി (*peṭṭi*), "a box" (DEDR 4388).
