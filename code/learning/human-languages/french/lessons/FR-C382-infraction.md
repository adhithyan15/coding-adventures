## You'll want to know: l'infraction
<!-- hl-knowledge: introduces=[FR-LEX-C382-INFRACTION-02]; assesses=[] -->

**l'infraction** — "the offence, the violation".

> Conduire sans permis est une infraction grave.
>
> *Driving without a licence is a serious offence.*

Feminine: *une infraction au code de la route*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*infraction* is a learned borrowing from Latin *infractiō* "a breaking" (EtymDB), built on *frangere* "to break" (Lewis & Short).
