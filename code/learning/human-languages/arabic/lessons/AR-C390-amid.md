## You'll want to know: عميد
<!-- hl-knowledge: introduces=[AR-LEX-C390-KULLIYYA390-03]; assesses=[] -->

**عميد** — *ʿamīd* — "a dean".

> تكلم العميد مع الطلاب الجدد.
>
> *takallama al-ʿamīd maʿa aṭ-ṭullāb al-judud.*
>
> The dean spoke with the new students.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**عميد** (*ʿamīd*) is built on the native Arabic root *ʿ-m-d*, "to prop up, to support" (Lane). An *ʿamīd* is a support, the one others lean on: a chief, and now a dean.
