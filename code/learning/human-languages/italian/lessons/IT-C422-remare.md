## You'll want to know: remare
<!-- hl-knowledge: introduces=[IT-LEX-C422-BARCA-04]; assesses=[] -->

**remare** — "to row".

> Abbiamo remato fino all'altra riva.
>
> *We rowed to the other bank.*

Figuratively, *remare contro* — to work against someone.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*remare* is built on *remo* 'oar' (EtymDB), which is inherited from Latin *rēmus* 'oar'.

## What you've built
