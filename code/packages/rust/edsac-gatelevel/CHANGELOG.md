# Changelog

## 0.1.0 — 2026-10-24

- Added the complete 1949 EDSAC order-code engine using repository Boolean
  gates, ripple-carry arithmetic, partial-product multiplication, and DFF
  clocks.
- Added the exact 18,095-DFF persistent topology, including asymmetric
  17-/18-bit short storage and unpadded 71-/35-bit arithmetic registers.
- Added complete checked transport, state restoration, paper-tape and
  teleprinter state, atomic stepping, transactional execution, typed faults,
  and functional full-state differential tests.
