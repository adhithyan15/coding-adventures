# دوست — friend, and everything this tranche has built

## Warm-up

tranche, and it is a word this track has half-taught already.

## You'll want to know first — one word, already half-known
<!-- hl-knowledge: introduces=[FA-LEX-DUST]; assesses=[] -->

> **دوست** — *dust* — **friend**

Four letters, all already yours: **د و س ت** — *d*, long *u*, *s*, *t*. The
compound verb for "to love" already ran on this exact word; here it stands
alone, as the person it names.

## The word, taken apart — the one chosen
<!-- hl-knowledge: introduces=[FA-ETYMON-DUST]; assesses=[] -->

**دوست** goes back through Old Persian **dauštā** to Indo-European
\**ǵews-*, "to taste, to choose" — a friend is *the one chosen*. English
inherited the root directly as **choose**; Latin took it as **gustus**,
"taste," giving English **gusto** and **disgust**. The compound-verb lesson
that first taught this root only ever used **دوست** glued to **داشتن**; this
is its first lesson as a free-standing noun.
