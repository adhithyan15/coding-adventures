## You'll want to know: 到时候
<!-- hl-knowledge: introduces=[ZH-LEX-C391-PLANS391-05]; assesses=[] -->

**到时候** — *dào shíhou* — "when the time comes".

> **到时候我一定来** *dào shíhou wǒ yídìng lái* — When the time comes, I'll be there for sure.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**到时候** (*dào shíhou*) is built from 到 'to arrive' and 时候 'the time', all inherited from Middle Chinese, *tawH*, *dzyi* and *huwH* (Guangyun, in Baxter's transcription), which glosses the last 'to wait for'.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what would happen.
