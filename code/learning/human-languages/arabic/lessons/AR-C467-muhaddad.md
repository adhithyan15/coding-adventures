# مهدد (muhaddad) — endangered; threatened

## You'll want to know: مهدد
<!-- hl-knowledge: introduces=[AR-LEX-C467-MAHMIYYA467-02]; assesses=[] -->

**مهدد** — *muhaddad* — "endangered; threatened".

> النمر حيوان مهدد في هذه المنطقة.
>
> *an-namir ḥayawān muhaddad fī hādhihi al-minṭaqa.*
>
> The tiger is an endangered animal in this area.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**مهدد** (*muhaddad*) is built on the native Arabic root *h-d-d*, "to threaten; to pull down" (Lane). It is the Form II passive participle, "threatened".
