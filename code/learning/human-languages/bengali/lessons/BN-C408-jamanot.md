## You'll want to know: জামানত
<!-- hl-knowledge: introduces=[BN-LEX-C408-BASA408-04]; assesses=[] -->

**জামানত** — *jāmānôt* — "a security deposit".

> ঘর ছাড়ার সময় মালিক জামানতের টাকা ফিরিয়ে দিলেন।
>
> *ghôr chhāṛār sômôy mālik jāmānôter ṭākā phiriye dilen.*
>
> When we left the room, the owner gave back the deposit.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**জামানত** (*jāmānôt*) is usually traced to Persian *zamānat*, "surety, a guarantee", from Arabic *ḍamāna*.
