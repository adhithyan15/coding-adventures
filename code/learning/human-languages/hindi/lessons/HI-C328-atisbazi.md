# आतिशबाज़ी (ātiśbāzī) — fireworks

## You'll want to know: आतिशबाज़ी
<!-- hl-knowledge: introduces=[HI-LEX-C328-ROSHNI328-05]; assesses=[] -->

**आतिशबाज़ी** — *ātiśbāzī* — "fireworks".

> आतिशबाज़ी से आसमान रंगों से भर गया।
>
> *ātiśbāzī se āsmān raṅgoṁ se bhar gayā.*
>
> The fireworks filled the sky with colour.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**आतिशबाज़ी** (*ātiśbāzī*) is usually traced to Persian *ātišbāzī*, built from *ātiš*, fire, and *bāzī*, play: playing with fire, for a festival.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
