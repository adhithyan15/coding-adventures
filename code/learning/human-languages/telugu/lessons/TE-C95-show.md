# చూపించండి (cūpiñcaṇḍi) — please show me

## You'll want to know: చూపించండి
<!-- hl-knowledge: introduces=[TE-LEX-C95-ASK-04]; assesses=[] -->

**చూపించండి** (*cūpiñcaṇḍi*) — "please show me".

It is built on **చూడు**, "see": to show is to *make someone see*. When a word will not come,
point and say **చూపించండి**.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

A request for when words run out.
