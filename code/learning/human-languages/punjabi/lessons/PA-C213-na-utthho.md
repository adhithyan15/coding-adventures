# ਨਾ ਉੱਠੋ — please don't get up

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-GRAMMAR-REQUEST-O-213, PA-LEX-NA, PA-GRAMMAR-NEG-HABITUAL-212] -->

[PAUSE 2s] Say *please get up*. Then *don't*, **ਨਾ**. Then *I don't drink tea*.

## Grammar Lens: ਨਾ for a request, ਨਹੀਂ for a statement
<!-- hl-knowledge: introduces=[PA-GRAMMAR-NEG-REQUEST-NA-213]; assesses=[PA-LEX-NA, PA-GRAMMAR-REQUEST-O-213, PA-GRAMMAR-NEG-HABITUAL-212] -->

A request takes **ਨਾ**, directly before it:

> **ਨਾ ਉੱਠੋ।** — *nā uṭṭho.* — Please don't get up.

> **ਉੱਥੇ ਨਾ ਬੈਠੋ।** — *utthe nā baiṭho.* — Please don't sit there.

> **ਹੁਣ ਕੰਮ ਨਾ ਕਰੋ।** — *huṇ kamm nā karo.* — Don't work now.

A statement keeps **ਨਹੀਂ**: **ਮੈਂ ਚਾਹ ਨਹੀਂ ਪੀਂਦਾ ਹਾਂ**. So the short **ਨਾ** asks,
and the long **ਨਹੀਂ** tells.
