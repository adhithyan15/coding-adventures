# documents recall two — one complete instruction

## Warm-up

printed form, action. (*Cliente, documento, dato, impreso, rellenar*.)

- [YOU SAY: *el cliente rellena el impreso*]
- [YOU SAY: *el cliente rellena el impreso con los datos*]
