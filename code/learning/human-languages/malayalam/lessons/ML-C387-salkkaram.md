# സൽക്കാരം (salkkāraṁ) — a banquet

## You'll want to know: സൽക്കാരം
<!-- hl-knowledge: introduces=[ML-LEX-C387-SALKKARAM387-01]; assesses=[] -->

**സൽക്കാരം** — *salkkāraṁ* — "a banquet".

> മാനേജർ ജീവനക്കാർക്ക് ഒരു സൽക്കാരം നടത്തി.
>
> *mānējar jīvanakkārkkŭ oru salkkāraṁ naṭatti.*
>
> The manager held a banquet for the staff.

A banquet is held: സൽക്കാരം നടത്തുക.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**സൽക്കാരം** (*salkkāraṁ*) is borrowed from Sanskrit *satkāra*, "kind treatment, hospitality" (CDIAL 13108), from *sat*, "good", and *kāra*, "a doing".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
