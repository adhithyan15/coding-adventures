# mosaic-emit-swiftui

SwiftUI backend for the Mosaic three-language UI compiler. Consumes the
output of `mosmodel-compiler`, `moslayout-compiler`, and `mosstyle-compiler`
and emits a `.swift` source file containing a SwiftUI `View` struct.

This is **WB4** of the UI28 backend matrix.

## Overview

```
.mil + .mll + .msl
        │
        ├── mosmodel-compiler  → MosmodelComponent
        ├── moslayout-compiler → LayoutDef
        └── mosstyle-compiler  → StyleDef
                   │
                   ▼
        mosaic-emit-swiftui::from_pipeline(...)
                   │
                   ▼
              <Name>View.swift
```

## Generated file shape

For a component named `ProfileCard` with slots `display-name: text`,
`avatar-url: image`, and emit `onTap`, the crate produces:

```swift
// Auto-generated by mosaic-emit-swiftui. Do not edit.
import SwiftUI

enum ProfileCardEvent {
    case tap
}

struct ProfileCardView: View {
    let displayName: String
    let avatarUrl: String
    let dispatch: (ProfileCardEvent) -> Void

    var body: some View {
        VStack {
            Text(displayName)
        }
    }
}
```

## Primitive lowering

| Mosaic primitive | SwiftUI                                       |
|------------------|-----------------------------------------------|
| `Box`            | `Group { ... }`                               |
| `Row`            | `HStack { ... }`                              |
| `Column`         | `VStack { ... }` *(UI14 legacy — see TODO)*   |
| `Text`           | `Text("literal")` or `Text(slotName)`         |
| `Spacer`         | `Spacer()`                                    |
| `Image`          | `Image(systemName: "...")` placeholder        |
| `Divider`        | `Divider()`                                   |

## Slot type mapping

| mosmodel slot type | Swift type                  |
|--------------------|-----------------------------|
| `text`             | `String`                    |
| `number`           | `Double`                    |
| `bool`             | `Bool`                      |
| `image`            | `String` (asset / URL)      |
| `color`            | `String` (hex)              |
| `node`             | `AnyView`                   |
| `list<T>`          | `[<inner Swift type>]`      |
| `<Component>`      | `AnyView`                   |

## Event dispatch

Each component carries a single `dispatch: (NameEvent) -> Void` closure
property; the event type is a Swift `enum` with one case per emit. Empty
emit lists produce an uninhabitable enum `enum NameEvent {}`, the SwiftUI
analog of TypeScript's `type NameEvent = never` in the React backend.

## What is NOT yet supported

- `Cell` / `Column` (UI28 metadata) / `Grid` v3 — tracked as a follow-up PR.
  Per UI28 §4.4 the SwiftUI lowering is
  `Grid → SwiftUI.Table { TableColumn(...) }` with each `Column` becoming
  a `TableColumn` definition.
- `Scroll`, `Stack`, `Icon`, `Grid` (v2), `Input` — return
  `UnknownPrimitive` errors today; each lands in its own follow-up.
- `connects` wiring (gesture / event modifiers).
- `mosstyle::StyleDef` inlining (accepted in the signature so callers can
  build against the stable interface, not yet applied).

See the crate doc-comment for the full deferred list.
