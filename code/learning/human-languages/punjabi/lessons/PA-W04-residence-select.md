# Select one known residence value

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-LABEL-RESIDENCE-01, PA-FORM-RESIDENCE-VILLAGE-01, PA-FORM-RESIDENCE-CITY-01] -->

Read the closed bank once:

> A — **ਪਿੰਡ**
>
> B — **ਸ਼ਹਿਰ**

## Script — attach one cue to each value
<!-- hl-knowledge: introduces=[PA-FORM-RESIDENCE-CUE-MAP-01]; assesses=[PA-FORM-RESIDENCE-VILLAGE-01, PA-FORM-RESIDENCE-CITY-01] -->

Point to A, then **ਪਿੰਡ**. Point to B, then **ਸ਼ਹਿਰ**. Cover the bank and say which value B requests. Selection is separate from spelling.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-RESIDENCE-CUE-MAP-01] -->

Reveal, point, cover, and select once more. Do not write the form line yet.
