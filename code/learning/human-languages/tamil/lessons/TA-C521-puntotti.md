# பூந்தொட்டி (pūntoṭṭi) — a flowerpot

## You'll want to know: பூந்தொட்டி
<!-- hl-knowledge: introduces=[TA-LEX-C521-VEEDU521-05]; assesses=[] -->

**பூந்தொட்டி** — *pūntoṭṭi* — "a flowerpot".

> பால்கனியில் மூன்று பூந்தொட்டிகள் இருக்கின்றன.
>
> *pālkaṉiyil mūṉṟu pūntoṭṭikaḷ irukkiṉṟaṉa.*
>
> There are three flowerpots on the balcony.

Plural: பூந்தொட்டிகள், *pūntoṭṭikaḷ*.

பூ "a flower" + தொட்டி (*toṭṭi*) "a tub": பூ adds ந் before தொட்டி.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**பூந்தொட்டி** (*pūntoṭṭi*) is a native compound: பூ (*pū*), "a flower" (DEDR 4345), and தொட்டி (*toṭṭi*), "a tub, a tank".
