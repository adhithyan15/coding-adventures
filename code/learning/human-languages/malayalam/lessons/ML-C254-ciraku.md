## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ചിറക്** (*ciṟakŭ*) is native Dravidian, one word with Tamil *ciṟai*, Kannada *eṟake* and Telugu *eṟaka* (DEDR 2591).
