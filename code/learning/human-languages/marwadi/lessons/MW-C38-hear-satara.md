## You'll want to know
<!-- hl-knowledge: introduces=[MW-LEX-SATARA-01]; assesses=[MW-LEX-SAAT-01] -->

> *satarā* — **seventeen**

Seven is *sāt*. Seventeen is *satarā*, and this is the clearest one in the whole
set: **सात** is still visible inside it, with only its long vowel shortened
before the **-arā** ending arrives.

If you have been listening for the shape rather than learning the words, this is
the one that proves the shape works.
