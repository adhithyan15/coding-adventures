# இளவரசன் (iḷavaracaṉ) — a prince

## You'll want to know: இளவரசன்
<!-- hl-knowledge: introduces=[TA-LEX-C328-MANNAR328-03]; assesses=[] -->

**இளவரசன்** — *iḷavaracaṉ* — "a prince".

> இளவரசன் குதிரையில் காட்டுக்குப் போனான்.
>
> *iḷavaracaṉ kutiraiyil kāṭṭukkup pōṉāṉ.*
>
> The prince rode to the forest on a horse.

இள, young + அரசன், king.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**இளவரசன்** (*iḷavaracaṉ*) is a Tamil compound built from இள, "young" (DEDR 513), and அரசன், "king", which DEDR 201 traces to Sanskrit *rājan*.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
