## You'll want to know: अक्कल
<!-- hl-knowledge: introduces=[MR-LEX-C471-SAHANA471-05]; assesses=[] -->

**अक्कल** — *akkal* — "common sense; wits".

> या कामाला थोडी अक्कल लागते.
>
> *yā kāmālā thoḍī akkal lāgte.*
>
> This job takes a little common sense.

Feminine.

अक्कल लढवणे, to use one's wits; अक्कलहुशार, quick-witted.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**अक्कल** (*akkal*) is a loan from Persian *aql*, "reason", usually traced to Arabic.
