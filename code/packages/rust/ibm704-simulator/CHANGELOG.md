# Changelog

All notable changes to this package will be documented in this file.

## [0.1.0] - 2026-08-27

### Added

- Complete v1 IBM 704 functional simulator with 42 Type A and Type B
  instructions.
- Sign-magnitude integer, 70-bit multiply/divide, excess-128 floating-point,
  index-register, trigger, and effective-address behavior.
- Strict canonical transport loading, typed fail-closed errors, bounded
  execution, instruction traces, and owned full-machine snapshots.
- Architecture-level tests for FORTRAN-style loops, LISP cons fields, and
  floating-point numeric programs.
