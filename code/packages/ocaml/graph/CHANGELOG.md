# Changelog

All notable changes to this package will be documented in this file.

## [0.1.0] - 2026-09-05

### Added

- Added generic adjacency-list and dense adjacency-matrix representations.
- Added deterministic mutation, property, traversal, connectivity, cycle,
  shortest-path, and minimum-spanning-tree operations.
- Added typed validation for missing nodes and edges, disconnected graphs, and
  invalid weights.
- Added Alcotest coverage for representation parity, matrix rebuilding,
  property synchronization, and 1,000-node iterative traversal.
