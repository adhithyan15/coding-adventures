## You'll want to know: प्रत्येकम्
<!-- hl-knowledge: introduces=[SA-LEX-C550-AMSA550-02]; assesses=[] -->

**प्रत्येकम्** — *pratyekam* — "each one; one by one".

> यदि दश फलानि सन्ति, तर्हि प्रत्येकं बालः एकं लभते।
>
> *yadi daśa phalāni santi, tarhi pratyekaṃ bālaḥ ekaṃ labhate.*
>
> If there are ten fruits, each child gets one.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**प्रत्येकम्** (*pratyekam*) is built from *prati*, "towards, for each", and *eka*, "one"; MW gives *pratyekam* as one by one, singly, for every single one (MW).
