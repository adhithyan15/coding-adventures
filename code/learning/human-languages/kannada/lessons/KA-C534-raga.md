## You'll want to know: ರಾಗ
<!-- hl-knowledge: introduces=[KA-LEX-C534-SANGITA534-01]; assesses=[] -->

**ರಾಗ** — *rāga* — "a melody; a raga".

> ಆ ಗಾಯಕ ಸಂಜೆಯ ರಾಗವನ್ನು ಹಾಡಿದರು.
>
> *ā gāyaka sañjeya rāgavannu hāḍidaru.*
>
> That singer sang an evening raga.

Each ರಾಗ has its own set of notes and mood.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ರಾಗ** (*rāga*) is borrowed from Sanskrit *rāga*, "colour", and "passion, love" (CDIAL 10674): a melody that colours the mind.
