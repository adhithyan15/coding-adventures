## You'll want to know: સામ્રાજ્ય
<!-- hl-knowledge: introduces=[GU-LEX-C324-SAMRAT324-01]; assesses=[] -->

**સામ્રાજ્ય** — *sāmrājya* — "an empire".

> આ સામ્રાજ્ય દરિયાથી પર્વત સુધી હતું.
>
> *ā sāmrājya dariyāthī parvat sudhī hatũ.*
>
> This empire stretched from the sea to the mountains.

A neuter noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**સામ્રાજ્ય** (*sāmrājya*) is a tatsama, Sanskrit *sāmrājya*, "complete sovereignty, an empire" (Monier-Williams), built on *samrāj*, a supreme ruler.
