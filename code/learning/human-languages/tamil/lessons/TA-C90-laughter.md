## You'll want to know: சிரிப்பு
<!-- hl-knowledge: introduces=[TA-LEX-C90-MOOD-01]; assesses=[] -->

**சிரிப்பு** (*sirippu*) — "laughter", and "a smile".

**சிரிப்பு வருகிறது** — "I feel like laughing", literally "laughter is coming".
