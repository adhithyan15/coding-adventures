# അനുഗ്രഹിക്കുക (anugrahikkuka) — to bless

[PAUSE 2s] Before the new one: say the Malayalam for to make ready, then the Malayalam for a gratuity.

## You'll want to know: അനുഗ്രഹിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C388-ASAMSA388-02]; assesses=[] -->

**അനുഗ്രഹിക്കുക** — *anugrahikkuka* — "to bless".

> മുത്തശ്ശി വധുവിനെയും വരനെയും അനുഗ്രഹിച്ചു.
>
> *muttaśśi vadhuvineyuṁ varaneyuṁ anugrahiccu.*
>
> Grandmother blessed the bride and the groom.

Past: അനുഗ്രഹിച്ചു, *anugrahiccu*.

The noun is അനുഗ്രഹം, a blessing.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**അനുഗ്രഹിക്കുക** (*anugrahikkuka*) is built from Sanskrit *anugraha*, "favour, kindness" (CDIAL 314), the source of അനുഗ്രഹം (*anugrahaṁ*), with the Malayalam verb ending -ിക്കുക.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
