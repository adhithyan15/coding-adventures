# मन्यते (manyate) — thinks

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[SA-GRAMMAR-C278-OPINION-02, SA-GRAMMAR-C278-EXPLANATION-01] -->

[PAUSE 2s] Before the new one: say "I think that it will rain". (*ahaṃ manye yat varṣā bhaviṣyati*.) You have said this verb's "I" form.

## You'll want to know: मन्यते
<!-- hl-knowledge: introduces=[SA-LEX-C278-MANYATE-01]; assesses=[SA-LEX-KIM, SA-LEX-C27-REPLY-04, SA-LEX-C241-WHY241-04] -->

**मन्यते** — *manyate* — "thinks". **मन्ये** (*manye*) is its "I".

> **सः किं मन्यते?**
>
> *saḥ kiṃ manyate?* — "What does he think?"

> **मीरा मन्यते यत् एतत् सत्यम्।**
>
> *mīrā manyate yat etat satyam.* — "Mira thinks that this is true."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**मन्यते** (*manyate*) is built on the root √man, "to think", which Monier-Williams lists in the fourth class with the middle ending *-te*. **मतम्** (*matam*), "an opinion", is its *-ta* form: what is thought. It lives on as Hindi *mānnā*, "to respect, obey" (CDIAL 9857).
