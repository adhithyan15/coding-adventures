## You'll want to know: പ്രചാരണം
<!-- hl-knowledge: introduces=[ML-LEX-C420-VIJAYAM420-01]; assesses=[] -->

**പ്രചാരണം** — *pracāraṇaṁ* — "a campaign".

> തിരഞ്ഞെടുപ്പ് പ്രചാരണം ഇന്നലെ അവസാനിച്ചു.
>
> *tiraññeṭuppŭ pracāraṇaṁ innale avasāniccu.*
>
> The election campaign ended yesterday.

Campaigning is പ്രചാരണം നടത്തുക.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**പ്രചാരണം** (*pracāraṇaṁ*) is a learned word built on Sanskrit *pracāra*, "coming forth, showing oneself; currency, usage" (Monier-Williams), with the Sanskrit action-noun ending *-aṇa*: a campaign makes an idea current. Monier-Williams lists *pracāraṇa* itself only as "scattering, strewing", so the campaign sense is a modern one.
