## You'll want to know: verantwortlich
<!-- hl-knowledge: introduces=[GE-LEX-C348-VERANTWORTUNG-02]; assesses=[] -->

**verantwortlich** — "responsible".

> Mein Bruder ist heute für die Küche verantwortlich.
>
> *My brother is responsible for the kitchen today.*

*Verantwortlich für* + accusative.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*verantwortlich* is built with *-lich* on *verantworten* "to answer for", from *Antwort* "answer", Old High German *antwurti* (EtymDB): someone who must answer for a thing.
