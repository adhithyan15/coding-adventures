# புராணம் (purāṇam) — a myth; a sacred legend

## You'll want to know: புராணம்
<!-- hl-knowledge: introduces=[TA-LEX-C343-PAZHANKATHAI343-02]; assesses=[] -->

**புராணம்** — *purāṇam* — "a myth; a sacred legend".

> இந்த ஊருக்கு ஒரு பழைய புராணம் இருக்கிறது.
>
> *inta ūrukku oru paḻaiya purāṇam irukkiṟatu.*
>
> This town has an old myth about it.

Plural புராணங்கள்.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**புராணம்** (*purāṇam*) is borrowed from Sanskrit *purāṇa*, "ancient" (CDIAL 8283): an old tale.
