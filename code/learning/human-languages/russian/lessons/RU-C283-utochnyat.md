## You'll want to know: уточнять
<!-- hl-knowledge: introduces=[RU-LEX-C283-UTVERZHDAT-03]; assesses=[] -->

**уточнять** (*utochnyát*) — "to clarify, to check (details)".

> Я позвонил, чтобы уточнить время.
>
> *Ya pozvoníl, shtóby utochnít vrémya.*
>
> I phoned to check the time.

Imperfective; perfective *уточнить* (*utochnít*).

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*уточнять* is built on *у-* and *точный* "exact", which EtymDB derives from Church Slavonic *tŭčĭnŭ*; it is usually traced further to the root of *ткнуть* "to poke", so "hitting the spot".
