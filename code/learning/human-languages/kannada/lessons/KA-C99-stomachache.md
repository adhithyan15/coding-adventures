## You'll want to know: ಹೊಟ್ಟೆನೋವು
<!-- hl-knowledge: introduces=[KA-LEX-C99-BODY2-04]; assesses=[] -->

**ಹೊಟ್ಟೆನೋವು** (*hoṭṭenōvu*) — "a stomach ache", built exactly like **ತಲೆನೋವು**:
**ಹೊಟ್ಟೆ** (*hoṭṭe*), "stomach", with **ನೋವು**, "pain".
