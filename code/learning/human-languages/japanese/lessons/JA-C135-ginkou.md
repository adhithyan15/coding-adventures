## You'll want to know: ぎんこう
<!-- hl-knowledge: introduces=[JA-LEX-ANCHOR-GINKOU]; assesses=[JA-SCRIPT-N-01, JA-SCRIPT-KO-01, JA-SCRIPT-U-01] -->

**ぎんこう** — *ginkō* — "a bank", where money is kept.

Four beats: *gi–n–ko–o*. **ん**, **こ** and **う** you already write, and the
**う** stretches the *o*. The first sign is **き** with the voicing mark, so *ki*
becomes *gi*. The next lesson writes it.
