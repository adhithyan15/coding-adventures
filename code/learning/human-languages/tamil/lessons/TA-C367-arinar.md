# அறிஞர் (aṟiñar) — a scholar

## You'll want to know: அறிஞர்
<!-- hl-knowledge: introduces=[TA-LEX-C367-NANAM367-03]; assesses=[] -->

**அறிஞர்** — *aṟiñar* — "a scholar".

> அவர் ஒரு பெரிய தமிழ் அறிஞர்.
>
> *avar oru periya tamiḻ aṟiñar.*
>
> He is a great Tamil scholar.

-ஞர், one who: கலைஞர், an artist, has the same ending.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**அறிஞர்** (*aṟiñar*) is native: *aṟi*, "to know" (DEDR 314), with the ending -ஞர், "one who", as in கலைஞர்: "one who knows".
