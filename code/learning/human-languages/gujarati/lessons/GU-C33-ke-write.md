# કે reaches the page

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[GU-JOIN-KE-01, GU-LEX-SHAALAA-01] -->

[PAUSE 3s] Say the swallowing word. Then a long reach back, to a word taught
many chapters ago and not asked for since: what is **શાળા**?

- [YOU RECALL: *shāḷā* — school]

## Script — two signs, neither new
<!-- hl-knowledge: introduces=[GU-SCRIPT-KE-01]; assesses=[GU-SCRIPT-KA-01, GU-SCRIPT-E-MATRA-01] -->

> **ક** — *ka* · **ે** — the *e* stroke

Uncover **કે** and name both pieces. Like **અને** last chapter, this word costs
the hand nothing it did not already have.

## Writing — guided copy, model in view
<!-- hl-knowledge: introduces=[]; assesses=[GU-SCRIPT-KE-01] -->
<!-- hl-writing-stage: guided-copy -->

Copy **કે** once with the model in view. Then write **અને** beside it from
memory and compare the two **ે** strokes: the same sign, sitting on different
letters.
