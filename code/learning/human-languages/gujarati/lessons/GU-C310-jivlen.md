# જીવલેણ (jīvleṇ) — deadly

## You'll want to know: જીવલેણ
<!-- hl-knowledge: introduces=[GU-LEX-C310-TUKDI310-02]; assesses=[] -->

**જીવલેણ** — *jīvleṇ* — "deadly".

> આ જંગલમાં જીવલેણ સાપ છે.
>
> *ā jangalmā̃ jīvleṇ sāp che.*
>
> There are deadly snakes in this forest.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**જીવલેણ** (*jīvleṇ*) is built from *jīv*, life, from Sanskrit *jīvá*, "living; life" (CDIAL 5239), and *leṇ*, a taking, from **લેવું**: what takes a life. **જીવલેણ સાપ**, a deadly snake.
