## You'll want to know: بازیافت کردن
<!-- hl-knowledge: introduces=[FA-LEX-C388-ALUDEGI-03]; assesses=[] -->

**بازیافت کردن** (*bâzyâft kardan*) — "to recycle".

> ما بطریهای پلاستیکی را بازیافت میکنیم.
>
> *mâ bottrihâ-ye plâstiki râ bâzyâft mikonim.*
>
> We recycle plastic bottles.

*Bâzyâft* + *kardan* (stem *kon-*). The object takes *râ*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**بازیافت کردن** is native Persian, built from *bâzyâft* "recycling", from *bâz* "again" and *yâft* "found", with *kardan* "to do".
