# இன்னொரு முறை (iṉṉoru muṟai) — one more time

## You'll want to know: இன்னொரு முறை
<!-- hl-knowledge: introduces=[TA-LEX-C94-LOST-03]; assesses=[] -->

**இன்னொரு முறை** (*iṉṉoru muṟai*) — "one more time".

**இன்னொரு** is "another", and **முறை** is "a time, a turn".
