# ಪ್ರಾಚೀನ (prācīna) — ancient

## You'll want to know: ಪ್ರಾಚೀನ
<!-- hl-knowledge: introduces=[KA-LEX-C331-HINDE331-04]; assesses=[] -->

**ಪ್ರಾಚೀನ** — *prācīna* — "ancient".

> ಇದು ಒಂದು ಪ್ರಾಚೀನ ದೇವಸ್ಥಾನ.
>
> *idu ondu prācīna dēvasthāna.*
>
> This is an ancient temple.

It stands before a noun as it is: ಪ್ರಾಚೀನ ಕಾಲ, ancient times.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಪ್ರಾಚೀನ** (*prācīna*) is borrowed from Sanskrit *prācīna*, "turned to the front, eastern" (CDIAL 8920), which also came to mean "former, ancient".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
