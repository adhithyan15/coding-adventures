# شش — six, and the short vowel you cannot see

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[FA-PERFORMANCE-COUNT-FIVE] -->

[PAUSE 2s] Count one to five, then five to one.

## You'll want to know first — one word
<!-- hl-knowledge: introduces=[FA-LEX-SHESH]; assesses=[FA-SCRIPT-SHORT-VOWELS-01] -->

> **شش** — *shesh* — **six**

Two letters, and they are the same letter. The vowel between them is short, so
Persian does not write it — which is the script chapter's rule doing exactly what it
said it would: a Persian word can be read only once you have heard it.

## The word, taken apart — six, with the s moved
<!-- hl-knowledge: introduces=[FA-ETYMON-SHESH]; assesses=[FA-LEX-SHESH] -->

**شش** continues Middle Persian **shash**, from Indo-European \**swéḱs*,
"six." English **six**, Latin **sex**, Greek **héx** and Sanskrit **ṣaṣ** are
the same word.
