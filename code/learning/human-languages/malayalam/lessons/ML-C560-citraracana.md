# ചിത്രരചന (citraracana) — painting

## You'll want to know: ചിത്രരചന
<!-- hl-knowledge: introduces=[ML-LEX-C560-SILPAM560-02]; assesses=[] -->

**ചിത്രരചന** — *citraracana* — "painting".

> അനിയത്തിക്ക് ചിത്രരചനയിൽ സമ്മാനം കിട്ടി.
>
> *aniyattikkŭ citraracanayil sammānaṁ kiṭṭi.*
>
> My little sister won a prize for painting.

ചിത്രം a picture + രചന a making, a composition.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ചിത്രരചന** (*citraracana*) is a learned compound built from Sanskrit *citra*, "bright, variegated", the source of ചിത്രം (CDIAL 4803), and *racana*, "making, composing" (Monier-Williams).
