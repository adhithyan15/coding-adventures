## You'll want to know: colecionar
<!-- hl-knowledge: introduces=[PT-LEX-C504-OLARIA-02]; assesses=[] -->

**colecionar** — "to collect".

> O meu filho coleciona cromos de futebol.
>
> *My son collects football stickers.*

Before AO90 spelled *coleccionar*. Built on *a coleção*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*colecionar* is built on *coleção* "collection", a learned borrowing from Latin *collēctiō* (EtymDB).
