# অবিস্মরণীয় (ôbismôrônīyô) — unforgettable

## You'll want to know: অবিস্মরণীয়
<!-- hl-knowledge: introduces=[BN-LEX-C329-SHESHPATA329-04]; assesses=[] -->

**অবিস্মরণীয়** — *ôbismôrônīyô* — "unforgettable".

> সেই রাতের গল্পগুলো ছিল অবিস্মরণীয়।
>
> *sei rāter gôlpogulo chhilô ôbismôrônīyô.*
>
> The stories of that night were unforgettable.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**অবিস্মরণীয়** (*ôbismôrônīyô*) puts Sanskrit *a-*, 'not', before *vismaraṇīya*, 'to be forgotten' (Monier-Williams): not to be forgotten.
