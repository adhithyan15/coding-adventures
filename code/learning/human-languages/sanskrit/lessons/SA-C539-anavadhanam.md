## You'll want to know: अनवधानम्
<!-- hl-knowledge: introduces=[SA-LEX-C539-AVAHITA539-02]; assesses=[] -->

**अनवधानम्** — *anavadhānam* — "inattention".

> यदि अनवधानं भवति, तर्हि हानिः अपि भवति।
>
> *yadi anavadhānaṃ bhavati, tarhi hāniḥ api bhavati.*
>
> Where there is inattention, there is loss too.

A neuter noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**अनवधानम्** (*anavadhānam*) is built on *an*, "not", and *avadhāna*, "attention", from *ava* and the root √dhā, "to put"; MW gives *anavadhāna* as inattention, inadvertence (MW).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
