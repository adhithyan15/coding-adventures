## You'll want to know: તબક્કો
<!-- hl-knowledge: introduces=[GU-LEX-C529-TABAKKO529-01]; assesses=[] -->

**તબક્કો** — *tabakko* — "a stage (of a process)".

> જો પહેલો તબક્કો સારો જશે તો આપણે બીજો તબક્કો શરૂ કરીશું.
>
> *jo pahelo tabakko sāro jaśe to āpaṇe bījo tabakko śarū karīśũ.*
>
> If the first stage goes well, we will start the second stage.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**તબક્કો** (*tabakko*) is usually traced to Arabic *ṭabaqa*, "a layer, a stage", through Persian.
