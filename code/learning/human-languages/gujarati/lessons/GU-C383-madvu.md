## You'll want to know: માંડવું
<!-- hl-knowledge: introduces=[GU-LEX-C383-PRAYATNA383-04]; assesses=[] -->

**માંડવું** — *mā̃ḍvũ* — "to set about".

> જો આપણે આજથી કામ માંડીશું તો મહિનામાં ઘર તૈયાર થશે.
>
> *jo āpaṇe ājthī kām mā̃ḍīśũ to mahināmā̃ ghar taiyār thaśe.*
>
> If we set to work today, the house will be ready within a month.

Past, with તેણે (he or she …): તેણે નવો ધંધો માંડ્યો, *teṇe navo dhandho mā̃ḍyo*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**માંડવું** (*mā̃ḍvũ*) is inherited from Sanskrit *maṇḍáyati*, "adorns, decorates"; CDIAL lists the Gujarati verb, "to arrange, to begin" (CDIAL 9741).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
