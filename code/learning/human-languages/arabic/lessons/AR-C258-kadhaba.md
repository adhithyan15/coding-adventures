**كذب** — *kadhaba* — "to lie, to tell a lie".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**كذب** (*kadhaba*) is built on the native Arabic root *k-dh-b*, "to lie" (Lane). *Kadhaba* is the plain verb, "he lied".
