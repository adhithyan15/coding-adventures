# উপযুক্ত (upôjuktô) — suitable; fitting

## You'll want to know: উপযুক্ত
<!-- hl-knowledge: introduces=[BN-LEX-C380-OPOJUKTO380-03]; assesses=[] -->

**উপযুক্ত** — *upôjuktô* — "suitable; fitting".

> উপযুক্ত লোক পেলে আমরা কাজটা দেব।
>
> *upôjuktô lok pele āmrā kājṭā debô.*
>
> If we find a suitable person, we'll give them the job.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**উপযুক্ত** (*upôjuktô*) is Sanskrit *upayukta*, suitable or appropriate (Monier-Williams).
