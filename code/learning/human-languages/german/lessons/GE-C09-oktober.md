# der Oktober — "October"

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[GE-LEX-SEPTEMBER-01, GE-LEX-ACHT-01] -->

[PAUSE 2s] The same trick as September, one number along.

## You'll want to know: der Oktober
<!-- hl-knowledge: introduces=[GE-LEX-OKTOBER-01]; assesses=[GE-CULTURE-ROMAN-YEAR-BEGAN-IN-MARCH-01] -->

> **der Oktober** — "October."

Latin *october*, from ***octo*** — **eight**. Eighth from *März*, tenth on the
calendar you use.

Notice the spelling. English writes *Oc-*, keeping the Latin *c*. German writes
*Ok-*, because German spells that sound with a **k** and applies its own rule to
a borrowed word. Same word, same origin, one letter of local habit.

## Sounds you'll need
<!-- hl-knowledge: introduces=[]; assesses=[GE-LEX-OKTOBER-01] -->

- `vowel-o-german` — a clean rounded *o*, held steady rather than gliding as
  English *oh* does.
- `r-final` — and the soft closing *r*.

*ok-TOH-ber*, weight in the middle.
