## You'll want to know: prever
<!-- hl-knowledge: introduces=[ES-LEX-C481-ARREGLO-04]; assesses=[] -->

**prever** — "to foresee, to expect".

> Se prevé lluvia para el fin de semana.
>
> *Rain is expected for the weekend.*

Built on *ver*, and conjugated like it: *preveo*, *prevé*.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for reading notices, forms and messages.
