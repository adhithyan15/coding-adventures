# അനന്തരഫലം (anantaraphalaṁ) — a consequence

## You'll want to know: അനന്തരഫലം
<!-- hl-knowledge: introduces=[ML-LEX-C442-APAKATAM442-05]; assesses=[] -->

**അനന്തരഫലം** — *anantaraphalaṁ* — "a consequence".

> ആ തീരുമാനത്തിന്റെ അനന്തരഫലം വളരെ മോശമായിരുന്നു.
>
> *ā tīrumānattinṟe anantaraphalaṁ vaḷare mōśamāyirunnu.*
>
> The consequence of that decision was very bad.

ഫലം, a result, with അനന്തര-, following.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**അനന്തരഫലം** (*anantaraphalaṁ*) is built from Sanskrit *anantara*, "with no interval, immediately after" (CDIAL 287), and *phala*, "fruit" (CDIAL 9051): the fruit that follows.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
