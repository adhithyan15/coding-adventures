# HL80 — Punjabi A2 place-reference prerequisite

## Status

Implementation plan for issue #17774. This is a third prerequisite for Punjabi
A2 mock 1 (#17739), not a mock or a readiness decision.

## Scope and sequence

After chapter 179, add one practical-place chapter with seven lessons, each at
most 300 seconds. Teach exactly five previously unsupported forms from the
preserved mock draft, one new atom per lesson: **ਲੋਕ** (people), **ਉਸ** (that,
before a place noun), **ਥਾਂ** (place), **ਕਮਰੇ** (room in this location phrase),
and **ਵੱਡੇ** (big in this location phrase). Build from the already taught
**ਕਮਰਾ** and **ਵੱਡਾ**, without claiming a general case/agreement paradigm.

The first five lessons introduce one form each. An atom-free guided review and
an atom-free four-skill payoff provide two later retrievals of every form. The
payoff is the bounded sentence **ਲੋਕ ਉਸ ਥਾਂ ਦੇ ਵੱਡੇ ਕਮਰੇ ਵਿੱਚ ਹਨ।** Learners
hear and say it, read it, then write it only after covering the model. Its
supporting Punjabi must occur in earlier lessons or have been introduced in
the current chapter before use. Keep the opening voice-drivable.

Use direct chapter, lesson, curriculum, membership, session-map, modality,
narration, book, hash, focused-test, and changelog owners. The focused owner
must pin single atom ownership, source-before-use order, supporting-token
closure, the published seven-lesson order and duration, two later retrievals,
four-skill payoff, A2 practical-text placement, and non-readiness boundaries.
Run normal shard, documentation-shard, narration, modality, book-generation,
assessment-artifact, focused corpus, and full package checks.

## Evidence boundary

This chapter does not close the remaining Punjabi A2 mock-1 language gap. It
is not a completed mock, A2 readiness or attainment, external equivalence,
recording-quality evidence, or qualified-human validation.

## Language evidence used

The Punjabi University RCPLT Punjabi–English dictionary supports the lexical
forms **ਲੋਕ**, **ਉਸ**, and **ਥਾਂ**. A Punjabi University library description
uses **ਕਮਰੇ ਵਿੱਚ**, and a UK Government Punjabi fire-safety guide uses
**ਵੱਡੇ ... ਵਿੱਚ**. These are evidence for the bounded teaching phrases, not
for a general case or agreement paradigm; each lesson links its relevant
source. Do not generalize the inflectional pattern beyond this sentence
without separate evidence.
