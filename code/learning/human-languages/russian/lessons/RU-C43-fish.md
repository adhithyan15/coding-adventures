## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**рыба** ← Proto-Slavic *\*ryba* — inherited, but its deeper origin is unclear. Vasmer thought it was probably a taboo stand-in for an older word, the cousin of Lithuanian *žuvìs*, "fish", which fishermen avoided because it sounded like *звать*, "to call". A comparison with Old High German *rûppa*, "caterpillar", is also reported.
