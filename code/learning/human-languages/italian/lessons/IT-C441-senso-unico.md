## You'll want to know: il senso unico
<!-- hl-knowledge: introduces=[IT-LEX-C441-VICOLI-05]; assesses=[] -->

**il senso unico** — "the one-way street".

> Non puoi entrare, è senso unico.
>
> *You cannot go in, it is one-way.*

*Il senso vietato* — no entry.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*senso unico* is built from *senso* 'sense, direction', inherited from Latin *sēnsus*, and *unico* 'only', inherited from Latin *ūnicus*, from *ūnus* 'one' (EtymDB).
