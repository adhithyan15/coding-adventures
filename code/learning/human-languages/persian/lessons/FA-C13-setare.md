# ستاره — star

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[FA-LEX-MAH, FA-ETYMON-MAH] -->

[PAUSE 2s] Say **ماه**, and the two English words its root split into. One
more light in the sky, and a new small spelling habit.

## You'll want to know first — one word, one small spelling habit
<!-- hl-knowledge: introduces=[FA-LEX-SETARE]; assesses=[] -->

> **ستاره** — *setâre* — **star**

Five letters, all already yours: **س ت ا ر ه** — *s*, *t*, long *â*, *r*,
and a final **ه** read as the vowel *-e* rather than as a consonant — the
first time this track has met **ه** doing that particular job.

## The word, taken apart — a cognate this well attested is rare
<!-- hl-knowledge: introduces=[FA-ETYMON-SETARE]; assesses=[] -->

**ستاره** continues Old Persian **star-**, from Indo-European \**h₂stḗr*,
"star." Few Indo-European roots survive this cleanly across the whole
family: English **star**, Latin **stella** (→ **stellar**, **constellation**),
Greek **astron** (→ **astronomy**, **disaster** — "ill-starred"), and
Persian's own **ستاره** all continue the identical ancient word, alongside
**در**'s door and **ماه**'s moon as the tranche's clearest cousins.
