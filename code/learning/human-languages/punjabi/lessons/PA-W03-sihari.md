# ਿ — a mark written before, read after

## Warm-up

## Script — one tiny step
<!-- hl-knowledge: introduces=[PA-SCRIPT-SIHARI-01]; assesses=[PA-FORM-LANGUAGE-PUNJABI-01, PA-SCRIPT-HA-01] -->

Add **ਿ** to make **ਹਿ**. Sihari is drawn to the left of its base but read after it: *hi*.
