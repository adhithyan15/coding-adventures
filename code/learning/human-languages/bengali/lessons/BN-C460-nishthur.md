# নিষ্ঠুর (nishṭhur) — cruel

## You'll want to know: নিষ্ঠুর
<!-- hl-knowledge: introduces=[BN-LEX-C460-NISHTHUR460-01]; assesses=[] -->

**নিষ্ঠুর** — *nishṭhur* — "cruel".

> নিষ্ঠুর লোকটা কুকুরটাকে মারল।
>
> *nishṭhur lokṭā kukurṭāke mārlô.*
>
> The cruel man beat the dog.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**নিষ্ঠুর** (*nishṭhur*) is a tatsama, Sanskrit *niṣṭhura*, "hard, rough, harsh, cruel" (Monier-Williams).
