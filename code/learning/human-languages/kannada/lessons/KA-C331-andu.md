## You'll want to know: ಅಂದು
<!-- hl-knowledge: introduces=[KA-LEX-C331-HINDE331-02]; assesses=[] -->

**ಅಂದು** — *andu* — "on that day; then".

> ಅಂದು ಊರಿನಲ್ಲಿ ದೊಡ್ಡ ಹಬ್ಬ ಇತ್ತು.
>
> *andu ūrinalli doḍḍa habba ittu.*
>
> On that day there was a big festival in the village.

ಇಂದು is today, ಅಂದು is that day. Stories often begin ಅಂದು …

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಅಂದು** (*andu*) is native Dravidian: it is built on the pointing base *a-*, "that, yonder" (DEDR 1), as ಇಂದು, "today", is built on *i-*, "this".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
