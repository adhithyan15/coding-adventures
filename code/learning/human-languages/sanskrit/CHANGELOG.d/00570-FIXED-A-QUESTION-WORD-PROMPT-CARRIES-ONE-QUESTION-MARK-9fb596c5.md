## Fixed — a question-word prompt carries one question mark

SA-R190's recall run turned the glosses "How much?" and "Of what kind?" into
"How much?? (**कियत्**…)" and "Of what kind?? (**कीदृशः**…)", one question mark
from the gloss and one from the prompt. They now read "Asking how much?" and
"Asking of what kind?", which says that the answer is a question word and
prints one mark.
