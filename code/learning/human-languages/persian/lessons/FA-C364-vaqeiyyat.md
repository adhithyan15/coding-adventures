## You'll want to know: واقعیت
<!-- hl-knowledge: introduces=[FA-LEX-C364-VAQEIYYAT-01]; assesses=[] -->

**واقعیت** (*vâqe'iyat*) — "a fact; reality".

> این یک واقعیت است، نه یک نظر.
>
> *in yek vâqe'iyat ast, na yek nazar.*
>
> This is a fact, not an opinion.

Plural *vâqe'iyathâ*. *Dar vâqe'* "in fact" shares its base.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**واقعیت** is built on Arabic *wāqi'* "happening, real" with the abstract ending *-iyat*; it is usually traced to Arabic *wāqi'iyya* "reality".
