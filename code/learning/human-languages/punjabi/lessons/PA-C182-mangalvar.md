# ਮੰਗਲਵਾਰ — Tuesday

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-WEEKDAY-SOMVAR-01] -->

[PAUSE 2s] Retrieve Monday: **ਸੋਮਵਾਰ**.

## Grammar Lens: one weekday by ear
<!-- hl-knowledge: introduces=[PA-WEEKDAY-MANGALVAR-01]; assesses=[PA-WEEKDAY-SOMVAR-01] -->

[YOU HEAR: *mangalvaar*; YOU SAY: **ਮੰਗਲਵਾਰ**]

> **ਮੰਗਲਵਾਰ** — *maṅgalvār* — Tuesday

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*Maṅgalvār* joins Sanskrit *maṅgala*, the name of Mars, with *vāra*, "day of the week" (CDIAL 11547).
