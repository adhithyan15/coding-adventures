## You'll want to know: désapprouver
<!-- hl-knowledge: introduces=[FR-LEX-C345-PARTISAN-02]; assesses=[] -->

**désapprouver** — "to disapprove (of)".

> Le maire désapprouve ce projet.
>
> *The mayor disapproves of this project.*

*Dés-* + *approuver*: the opposite.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*désapprouver* is built from *dés-* "not" and *approuver*, which comes from Latin *approbāre* "to approve", on *probāre* "to test" (Lewis & Short).
