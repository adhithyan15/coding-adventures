# પખવાડિયું (pakhvāḍiyũ) — fortnight

## You'll want to know: પખવાડિયું
<!-- hl-knowledge: introduces=[GU-LEX-C173-WEEK173-02]; assesses=[] -->

**પખવાડિયું** — *pakhvāḍiyũ* — "fortnight".

> **તે એક પખવાડિયું રજા લેશે.** — *te ek pakhvāḍiyũ rajā leśe* — "She will take a fortnight off."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**પખવાડિયું** (*pakhvāḍiyũ*) is built like *aṭhvāḍiyũ*, "week", on *pakh*, "side, half". CDIAL lists Gujarati *pākh*, "side", under Sanskrit *pakṣa*, "wing, side", but not this compound, so its path is not settled (CDIAL 7627).
