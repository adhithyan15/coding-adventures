# నవ్వు (navvu) — a laugh, a smile

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TE-LEX-C96-NAMES-04, TE-LEX-C96-NAMES-05] -->

[PAUSE 2s] Before the new one: say the Telugu for a birthday, then the Telugu for a signature.

## You'll want to know: నవ్వు
<!-- hl-knowledge: introduces=[TE-LEX-C97-MOOD-01]; assesses=[] -->

**నవ్వు** (*navvu*) — "a laugh", and "a smile": Telugu uses one word for both.

**నవ్వండి** — "smile!", with the polite ending, what a photographer says.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

A laugh and a smile, in one word.
