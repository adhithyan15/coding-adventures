## You'll want to know: compenser
<!-- hl-knowledge: introduces=[FR-LEX-C353-REMEDE-05]; assesses=[] -->

**compenser** — "to make up for, to compensate".

> Il travaille le samedi pour compenser.
>
> *He works on Saturdays to make up for it.*

*Compenser le temps perdu* — to make up for lost time.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*compenser* is a learned borrowing from Latin *compēnsāre* "to weigh one thing against another" (EtymDB; Lewis & Short), built on *pēnsāre* "to weigh".
