# തൊഴിലുടമ (toḻiluṭama) — an employer

## You'll want to know: തൊഴിലുടമ
<!-- hl-knowledge: introduces=[ML-LEX-C543-NIYAMANAM543-05]; assesses=[] -->

**തൊഴിലുടമ** — *toḻiluṭama* — "an employer".

> തൊഴിലുടമ ശമ്പളം കൃത്യസമയത്ത് കൊടുത്തു.
>
> *toḻiluṭama śampaḷaṁ kṛtyasamayattŭ koṭuttu.*
>
> The employer paid the wages on time.

തൊഴിൽ work + ഉടമ an owner.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**തൊഴിലുടമ** (*toḻiluṭama*) is native Dravidian, a compound of തൊഴിൽ, "an occupation" (DEDR 3524), and ഉടമ, "property, an owner" (DEDR 593).
