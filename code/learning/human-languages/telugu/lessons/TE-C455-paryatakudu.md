# పర్యాటకుడు (paryāṭakuḍu) — a tourist

## You'll want to know: పర్యాటకుడు
<!-- hl-knowledge: introduces=[TE-LEX-C455-PARYATANA455-01]; assesses=[] -->

**పర్యాటకుడు** — *paryāṭakuḍu* — "a tourist".

> వేసవిలో ఆ కొండ మీద పర్యాటకులు ఎక్కువగా ఉంటారు.
>
> *vēsavilō ā koṇḍa mīda paryāṭakulu ekkuvagā uṇṭāru.*
>
> In summer there are a lot of tourists on that hill.

Plural: పర్యాటకులు, *paryāṭakulu*.

Plural పర్యాటకులు. పర్యాటక ప్రదేశం is a tourist spot.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**పర్యాటకుడు** (*paryāṭakuḍu*) is borrowed from Sanskrit *paryaṭaka*, which Monier-Williams glosses as a wanderer, a vagabond, from *pari-aṭ*, "to roam about". Telugu gave the roamer a camera.
