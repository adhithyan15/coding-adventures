## You'll want to know: 回去
<!-- hl-knowledge: introduces=[ZH-LEX-C191-BACK191-02]; assesses=[] -->

**回去** — *huíqù* — "to go back there".

> **我不想回去** *wǒ bù xiǎng huíqù* — I don't want to go back.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**回去** (*huíqù*) is built from 回 'to turn back' and 去 'to go', both inherited from Middle Chinese, *hwoj* and *khjoH* (Guangyun, in Baxter's transcription), which glosses the second 'to leave'.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for talking about plans.
