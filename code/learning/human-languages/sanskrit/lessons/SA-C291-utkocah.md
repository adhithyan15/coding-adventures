## You'll want to know: उत्कोचः
<!-- hl-knowledge: introduces=[SA-LEX-C291-VANCANA291-03]; assesses=[] -->

**उत्कोचः** — *utkocaḥ* — "a bribe".

> यदि सः उत्कोचं याचते, तर्हि धूर्तः।
>
> *yadi saḥ utkocaṃ yācate, tarhi dhūrtaḥ.*
>
> If he asks for a bribe, then he is a cheat.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**उत्कोचः** (*utkocaḥ*) is built from *ut* and the root √kuc, "to bend, contract"; MW's senses run from unwinding to bribery and corruption (MW).
