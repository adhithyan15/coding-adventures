## You'll want to know: The word
<!-- hl-knowledge: introduces=[IT-LEX-OTTAVO-02]; assesses=[] -->

> **ottavo** (masculine) · **ottava** (feminine) — **eighth**.
> **l'ottavo piano** — the eighth floor. **l'ottava volta** — the eighth time.

*Otto* is eight. By now you would expect *otto* with the ending the last four
took, and it is not that: this one ends in **-avo**, and it is the only one of the
ten that does.

## The word, taken apart: an octave is a count
<!-- hl-knowledge: introduces=[IT-ETYMON-OTTAVO-03]; assesses=[] -->

Latin *octāvus* already had the odd **-āvus**, and Italian inherited the oddity
rather than tidying it away — which is what usually happens to a word that is used
too often to be regularised.

**L'ottava** in music is the **eighth** note: *do re mi fa sol la si* and then *do*
again, where the names come round. The interval is named for the count that closes
it, and Italian named the notes too — *do, re, mi* are the opening syllables of a
mediaeval hymn, set down by an Italian monk.

So the word for a musical octave and the word for the eighth floor are the same
word, and the music is the one that explains the name.
