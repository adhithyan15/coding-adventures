### Changed — the printed ledger drops the letters only a dictation or composition strip used

The filmstrip ledger holds the frames of every letter some printed strip
draws. A Writing block whose stage is a dictation or a composition no longer
takes a strip (HL06, human-language-data), so letters drawn only by those
strips leave the ledger: Arabic و (AR-W04-arbaa-sutur) and Latin b, d, e, n,
p, q, r, w, y (buenos días, parce que, ayer, weil, quia). Their stroke
records and citations are unchanged; a lesson that prints one again brings
it back. The Devanagari words test no longer expects the मम and मम नाम
dictations among the shared-headline candidates, and the tallest-strip line
(1,801.14 units, GU-R13-doorway-nine-r3, now a dictation without a strip)
stays where it was.
