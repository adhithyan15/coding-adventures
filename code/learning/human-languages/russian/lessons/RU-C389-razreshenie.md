# разрешение (razreshéniye) — permission, a permit

## You'll want to know: разрешение
<!-- hl-knowledge: introduces=[RU-LEX-C389-ZAPRET-04]; assesses=[] -->

**разрешение** (*razreshéniye*) — "permission, a permit".

> Для этого нужно разрешение.
>
> *Dlya étogo núzhno razreshéniye.*
>
> You need permission for this.

Neuter. *Разрешение на работу* — a work permit. It is also the resolution of a screen.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**разрешение** is built on *разрешить* "to allow" with the noun suffix *-ение*; the root is Proto-Slavic *\*rěšiti* "to untie".
