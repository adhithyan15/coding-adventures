# Unit 4: Numbers 0-10

## Warm-up

[PAUSE 2s] Out loud: say "I am" and "we are" in Spanish. Good. Today's set —
numbers — is one of the richest etymology units so far: almost every one of
these words still has living cognates in English.

## New Material

**uno, dos, tres, cuatro, cinco** — 1, 2, 3, 4, 5
> ← Latin *unus, duos, tres, quattuor, quinque*. Cognates: *unus* → English
> *unit*, *unite*, *unanimous*. *duos* → *dual*, *duo*. *tres* → *triple*,
> *trio*. *quattuor* → *quart*, *quarter*, *quadrant*. *quinque* → *quintet*,
> *quintuple*.

**seis, siete, ocho, nueve, diez** — 6, 7, 8, 9, 10
> ← Latin *sex, septem, octo, novem, decem*. These are the real prize: the
> Latin words for 7 through 10 are the same roots buried in our month names,
> because September–December used to be the 7th–10th months of the old Roman
> calendar (before January/February were added to the front). *septem* →
> *September*, *septet*. *octo* → *October*, *octopus*, *octagon*. *novem* →
> *November*, *novena*. *decem* → *December*, *decade*, *decimal*. *sex* →
> *sextet*, *sextuple*, *sextant*.

**cero** — 0
> ← Italian *zero*, ultimately from Arabic *ṣifr* ("empty," the source
> concept of zero as we use it). The *same* Arabic root, through a different
> path, gives English *cipher*. This is your first taste of the
> Arabic-through-Spanish thread — much more of this is coming (see the
> roadmap's Week 35 deep-dive).

## Wrap-up Recall

[PAUSE 3s] Which Latin number word is hiding inside "October"? ... *octo*
(8) — because October used to be the 8th month.
