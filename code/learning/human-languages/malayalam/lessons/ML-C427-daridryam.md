# ദാരിദ്ര്യം (dāridryaṁ) — poverty

## You'll want to know: ദാരിദ്ര്യം
<!-- hl-knowledge: introduces=[ML-LEX-C427-DARIDRYAM427-01]; assesses=[] -->

**ദാരിദ്ര്യം** — *dāridryaṁ* — "poverty".

> ദാരിദ്ര്യം കാരണം ആ കുടുംബം നഗരത്തിലേക്ക് മാറി.
>
> *dāridryaṁ kāraṇaṁ ā kuṭumbaṁ nagarattilēkkŭ māṟi.*
>
> Because of poverty, that family moved to the city.

Below the poverty line: ദാരിദ്ര്യരേഖയ്ക്ക് താഴെ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ദാരിദ്ര്യം** (*dāridryaṁ*) is borrowed from Sanskrit *dāridrya*, "poverty" (CDIAL 6297), made from *daridra*, "poor".
