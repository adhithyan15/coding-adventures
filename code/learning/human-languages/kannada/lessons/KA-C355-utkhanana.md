# ಉತ್ಖನನ (utkhanana) — an excavation

## You'll want to know: ಉತ್ಖನನ
<!-- hl-knowledge: introduces=[KA-LEX-C355-UTKHANANA355-01]; assesses=[] -->

**ಉತ್ಖನನ** — *utkhanana* — "an excavation".

> ಉತ್ಖನನದಲ್ಲಿ ಹಳೆಯ ಮಡಕೆಗಳು ಸಿಕ್ಕಿದವು.
>
> *utkhananadalli haḷeya maḍakegaḷu sikkidavu.*
>
> Old pots were found in the excavation.

The careful digging done to find old things.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಉತ್ಖನನ** (*utkhanana*) is borrowed from Sanskrit *utkhanana*, "digging or tearing out" (Monier-Williams).
