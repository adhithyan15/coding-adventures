## You'll want to know: die Sicherheitskontrolle
<!-- hl-knowledge: introduces=[GE-LEX-C417-ZOLL-01]; assesses=[] -->

**die Sicherheitskontrolle** — "the security check".

> An der Sicherheitskontrolle muss er seinen Gürtel ausziehen.
>
> *At the security check he has to take off his belt.*

Plural: *die Sicherheitskontrollen*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*Sicherheitskontrolle* is built from *Sicherheit* 'safety, security', from *sicher*, which goes back to Latin *sēcūrus* (Lewis & Short), and *Kontrolle* 'check', borrowed from French *contrôle* (EtymDB).
