## You'll want to know: ಅಂತರರಾಷ್ಟ್ರೀಯ
<!-- hl-knowledge: introduces=[KA-LEX-C440-PARAVANAGI440-05]; assesses=[] -->

**ಅಂತರರಾಷ್ಟ್ರೀಯ** — *antararāṣṭrīya* — "international".

> ಈ ನಗರದಲ್ಲಿ ಒಂದು ಅಂತರರಾಷ್ಟ್ರೀಯ ವಿಮಾನ ನಿಲ್ದಾಣ ಇದೆ.
>
> *ī nagaradalli ondu antararāṣṭrīya vimāna nildāṇa ide.*
>
> This city has an international airport.

ರಾಷ್ಟ್ರ is a nation and ರಾಷ್ಟ್ರೀಯ national; ಅಂತರ- adds between.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಅಂತರರಾಷ್ಟ್ರೀಯ** (*antararāṣṭrīya*) is a modern compound built from Sanskrit words: *antara*, "inside, between" (CDIAL 357), and *rāṣṭra*, "a kingdom, a country" (CDIAL 10721), with the adjective ending -*īya*.
