# ভাইঝি (bhāijhi) — a brother's daughter; a niece

## You'll want to know: ভাইঝি
<!-- hl-knowledge: introduces=[BN-LEX-C482-JETHA482-04]; assesses=[] -->

**ভাইঝি** — *bhāijhi* — "a brother's daughter; a niece".

> ভাইঝির জন্মদিনে আমি একটা পুতুল কিনলাম।
>
> *bhāijhir jônmôdine āmi ekṭā putul kinlām.*
>
> I bought a doll for my niece's birthday.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ভাইঝি** (*bhāijhi*) puts ভাই (taught), brother, with *jhi*, "daughter", which CDIAL lists for Bengali under Sanskrit *duhitṛ*, "daughter" (CDIAL 6481).
