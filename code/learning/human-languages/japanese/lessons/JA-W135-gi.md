# ぎ — き, voiced

## Script — the change
<!-- hl-knowledge: introduces=[JA-SCRIPT-GI-01]; assesses=[JA-SCRIPT-KI-01, JA-SCRIPT-DAKUTEN-01] -->

> **き** *ki* + **゛** → **ぎ** *gi*

Write **き** in full: the two bars, the long diagonal with its hook, then the
separate curve. Then add the two short strokes of the voicing mark at the
upper right, beside the ends of the bars, the left one first.

That completes the *g* row: **が**, **ぎ**, **ぐ**, **げ**, **ご**.

With **んこう** after it, you can now write the word from the last lesson:
**ぎんこう**, *ginkō*, a bank.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[JA-SCRIPT-GI-01, JA-SCRIPT-KI-01, JA-SCRIPT-DAKUTEN-01, JA-LEX-ANCHOR-GINKOU] -->

1. Write **き**, then **ぎ**, and say *ki*, *gi*.
2. Write **が ぎ ぐ げ ご** in a row, and say it.
3. Write **ぎんこう** from memory and say *ginkō*.
