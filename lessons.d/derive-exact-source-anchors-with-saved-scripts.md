# Derive exact source anchors with saved scripts

The period-role publisher deriver expected spaces around A / in the retained
core_path assignment, whose actual bytes used A/. Its uniqueness guard refused
before creating a publisher or writing repository source. Inspect the complete
assignment bytes and retain an exact uniquely matched substitution.

An inline Python repair then embedded nested quotes in PowerShell and failed
with SyntaxError before writing anything. Use a saved Python repair script for
literal substitutions, retain the original failed deriver and outcomes, and
compile/hash the bounded successor. Do not remove the match guard or infer a
successful earlier command from a later command's shell exit. Neither failure
is a Rust test failure, semantic red, publication attempt or accepted publisher.

The lesson was staged externally while an actual Rust producer held the source
freeze, then added through lessons.py new after those holds were released.
