## You'll want to know: পৌঁছানো
<!-- hl-knowledge: introduces=[BN-LEX-C280-UDDHAR280-01]; assesses=[] -->

**পৌঁছানো** — *poũchhāno* — "to arrive; to reach".

> আমরা কত তাড়াতাড়ি পৌঁছাব, সেটা তোমার ওপর নির্ভর করে।
>
> *āmrā kôtô tāṛātāṛi poũchhābô, seṭā tomār opôr nirbhôr kôre.*
>
> How fast we get there is up to you.

Past (he/she …): সেই দমকল পৌঁছাল, *sei dômkôl poũchhālô*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**পৌঁছানো** (*poũchhāno*) is filed in CDIAL 8716 under Sanskrit *prabhūta*, 'much, great', which lists Bengali *paũchā*, 'to arrive'; how the sense moved is not set out there. Past: পৌঁছাল, arrived.
