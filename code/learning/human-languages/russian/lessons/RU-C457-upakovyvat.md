## You'll want to know: упаковывать
<!-- hl-knowledge: introduces=[RU-LEX-C457-DOSTAVKA-01]; assesses=[] -->

**упаковывать** (*upakóvyvat*) — "to pack, to wrap".

> Продавец упаковывает подарок в красивую бумагу.
>
> *Prodavéts upakóvyvayet podárok v krasívuyu bumágu.*
>
> The seller wraps the present in nice paper.

Imperfective; perfective *упаковать* (*упакую, упакуешь*).

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*упаковывать* is built from *у-* and *паковать* 'to pack', which is usually traced to German *packen*. EtymDB does not list the verb, so the line is hedged.
