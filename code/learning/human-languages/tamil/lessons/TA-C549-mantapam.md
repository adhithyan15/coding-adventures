# மண்டபம் (maṇṭapam) — a function hall

## You'll want to know: மண்டபம்
<!-- hl-knowledge: introduces=[TA-LEX-C549-VIZHA549-01]; assesses=[] -->

**மண்டபம்** — *maṇṭapam* — "a function hall".

> மண்டபம் கிடைத்தால் திருமணம் அடுத்த மாதம் நடக்கும்.
>
> *maṇṭapam kiṭaittāl tirumaṇam aṭutta mātam naṭakkum.*
>
> If we get the hall, the wedding will be next month.

Weddings in South India are often held in a திருமண மண்டபம்.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**மண்டபம்** (*maṇṭapam*) is borrowed from Sanskrit *maṇḍapa*, "an open temporary shed, a pavilion" (CDIAL 9740).
