# Guten Abend — good evening

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[] -->

[PAUSE 2s] The evening member of the set. Same *guten*, one more masculine
noun.

- [Guten Tag](./GE-C01-guten-tag.md) · [Abend](./GE-C01-abend.md)

## The word, taken apart — by assembling it
<!-- hl-knowledge: introduces=[GE-LEX-GUTEN-ABEND-01]; assesses=[GE-GRAMMAR-ADJ-ACC-MASC-02] -->

**Guten Abend** = **gut** + **Abend** (masculine) = "good evening," *GOO-ten
AH-bent*. *guten* again — the third masculine day-part in a row.

You now have the daytime arc: **Guten Morgen** (morning) → **Guten Tag**
(midday/afternoon) → **Guten Abend** (evening). All *guten*, all masculine.
Only bedtime is left — and it breaks the pattern.
