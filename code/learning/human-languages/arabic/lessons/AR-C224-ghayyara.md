## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**غير** (*ghayyara*) is built on the native Arabic root *gh-y-r*, "other; to change" (Lane). *Ghayyara* is Form II, built on *ghayr*, "other": to make other.
