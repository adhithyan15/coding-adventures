## You'll want to know: улучшать
<!-- hl-knowledge: introduces=[RU-LEX-C354-BOLSHE-01]; assesses=[] -->

**улучшать** (*uluchshát*) — "to improve, to make better".

> Чтение улучшает память.
>
> *Chténiye uluchsháyet pámyat.*
>
> Reading improves your memory.

Imperfective; perfective *улучшить*. *Улучшаться* — to get better.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**улучшать** is built on *лучший* "better", which is usually traced to Old Russian *лучии* "better, more fitting".
