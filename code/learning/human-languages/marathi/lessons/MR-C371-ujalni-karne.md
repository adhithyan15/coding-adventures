# उजळणी करणे (ujaḷṇī karṇe) — to revise

## You'll want to know: उजळणी करणे
<!-- hl-knowledge: introduces=[MR-LEX-C371-PARIKSHA371-03]; assesses=[] -->

**उजळणी करणे** — *ujaḷṇī karṇe* — "to revise".

> परीक्षेआधी मी सगळ्या धड्यांची उजळणी केली.
>
> *parīkṣeādhī mī sagaḷyā dhaḍyāñcī ujaḷṇī kelī.*
>
> Before the exam I revised all the lessons.

Past, with -ने (he …): त्याने उजळणी केली, *tyāne ujaḷṇī kelī*.

What is revised takes -ची: धड्यांची उजळणी.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**उजळणी करणे** (*ujaḷṇī karṇe*) joins उजळणी, "brightening up again", built on the Marathi verb उजळणे, "to polish, kindle", inherited from Sanskrit *ujjvalati*, "blazes up" (CDIAL 1671), to करणे.
