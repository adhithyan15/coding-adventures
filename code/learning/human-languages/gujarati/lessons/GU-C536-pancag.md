# પંચાંગ (pancā̃g) — a Hindu almanac

## You'll want to know: પંચાંગ
<!-- hl-knowledge: introduces=[GU-LEX-C536-MUHURT536-03]; assesses=[] -->

**પંચાંગ** — *pancā̃g* — "a Hindu almanac".

> જો તમે પંચાંગ જોશો તો તમને તહેવારની તારીખ મળશે.
>
> *jo tame pancā̃g jośo to tamne tahevārnī tārīkh maḷśe.*
>
> If you look in the almanac, you'll find the date of the festival.

A neuter noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**પંચાંગ** (*pancā̃g*) is a tatsama, taken from Sanskrit *pañcāṅga*, "having five parts" (Monier-Williams); the almanac gives five things for each day.
