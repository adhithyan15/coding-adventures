# പുഴയോരം (puḻayōraṁ) — a riverbank

## You'll want to know: പുഴയോരം
<!-- hl-knowledge: introduces=[ML-LEX-C477-KATAVU477-02]; assesses=[] -->

**പുഴയോരം** — *puḻayōraṁ* — "a riverbank".

> പുഴയോരത്ത് ധാരാളം തെങ്ങുകൾ ഉണ്ട്.
>
> *puḻayōrattŭ dhārāḷaṁ teṅṅukaḷ uṇṭŭ.*
>
> There are many coconut palms on the riverbank.

Built like വഴിയോരം: പുഴ, a river, plus ഓരം, an edge.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**പുഴയോരം** (*puḻayōraṁ*) is a native Dravidian compound of പുഴ, a river (DEDR 4318), and ഓരം, an edge (DEDR 1060).
