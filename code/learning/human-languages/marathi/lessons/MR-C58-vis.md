## You'll want to know: वीस
<!-- hl-knowledge: introduces=[MR-LEX-VIS]; assesses=[MR-LEX-NUMBERS-ONE-TO-FIVE] -->

> **वीस** — *vīs* — **20**

Sanskrit **विंशति** (*viṁśati*) — the same word as Latin *viginti* and, further
along, English *-ty*. It is the first number in this run that is not built out of
ten and something else — and the next lesson will build *nineteen* backwards
from it, which is why it comes out of order.
