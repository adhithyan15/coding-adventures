## You'll want to know: لالچ
<!-- hl-knowledge: introduces=[UR-LEX-C346-KHIDMAT346-03]; assesses=[] -->

**لالچ** — *lālach* — "greed".

> لالچ بری بات ہے۔
>
> *lālach burī bāt hai.*
>
> Greed is a bad thing.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**لالچ** (*lālach*) is inherited: CDIAL lists the Hindi cousin *lālac*, "cupidity", under Sanskrit *lālitya*, "amorousness" (CDIAL 11029); **لالچی**, "greedy", is built on it.
