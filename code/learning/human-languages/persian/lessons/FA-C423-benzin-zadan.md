## You'll want to know: بنزین زدن
<!-- hl-knowledge: introduces=[FA-LEX-C423-BENZIN-02]; assesses=[] -->

**بنزین زدن** (*benzin zadan*) — "to fill up (with petrol), to get petrol".

> قبل از سفر بنزین زدیم.
>
> *Qabl az safar benzin zadim.*
>
> We filled up before the trip.

*benzin* + *zadan*. Present stem *zan-*: *benzin mizanim* — we fill up.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*benzin zadan* is built from *benzin* 'petrol', usually traced to French *benzine*, and the native verb *zadan* 'to strike'.

## What you've built
