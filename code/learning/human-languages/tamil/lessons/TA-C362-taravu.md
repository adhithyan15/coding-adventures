## You'll want to know: தரவு
<!-- hl-knowledge: introduces=[TA-LEX-C362-ARAYCCI362-03]; assesses=[] -->

**தரவு** — *taravu* — "data".

> இந்தத் தரவுகளை எங்கிருந்து பெற்றீர்கள்?
>
> *intat taravukaḷai eṅkiruntu peṟṟīrkaḷ?*
>
> Where did you get this data?

Plural: தரவுகள், *taravukaḷ*.

Plural தரவுகள், the pieces of data.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**தரவு** (*taravu*) is a modern Tamil coinage for "data", usually read as built on native *taru*, "to give" (DEDR 3098): "what is given", which is also what Latin *data* means.
