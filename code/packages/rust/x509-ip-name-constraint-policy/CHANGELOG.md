# Changelog

All notable changes to this package will be documented in this file.

## [0.1.0] - 2026-10-29

### Added

- Bounded RFC 5280 IPv4 and IPv6 address-plus-mask policy.
- Contiguous CIDR-mask validation with address-family separation.
- Permitted and excluded subnet evaluation with exclusion precedence.
- Fixed collection ceilings, redacted indexed failures, portable build fronts,
  integration tests, and capability metadata.
