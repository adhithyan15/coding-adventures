# ముందుజాగ్రత్త (mundujāgratta) — a precaution

## You'll want to know: ముందుజాగ్రత్త
<!-- hl-knowledge: introduces=[TE-LEX-C421-APAYAM421-02]; assesses=[] -->

**ముందుజాగ్రత్త** — *mundujāgratta* — "a precaution".

> ముందుజాగ్రత్తగా నేను గొడుగు తీసుకెళ్ళాను.
>
> *mundujāgrattagā nēnu goḍugu tīsukeḷḷānu.*
>
> As a precaution I took an umbrella.

ముందు, before, + జాగ్రత్త, care, which you know.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ముందుజాగ్రత్త** (*mundujāgratta*) is built from native *mundu*, "in front, before" (DEDR 5020), and జాగ్రత్త, "care", from Sanskrit *jāgrat*, "waking, watchful" (CDIAL 5174).
