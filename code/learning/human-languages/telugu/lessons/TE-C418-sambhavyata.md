# సంభావ్యత (sambhāvyata) — probability; likelihood

## You'll want to know: సంభావ్యత
<!-- hl-knowledge: introduces=[TE-LEX-C418-SADHYAM418-03]; assesses=[] -->

**సంభావ్యత** — *sambhāvyata* — "probability; likelihood".

> రేపు వర్షం పడే సంభావ్యత ఎక్కువ.
>
> *rēpu varṣaṁ paḍē sambhāvyata ekkuva.*
>
> The likelihood of rain tomorrow is high.

A careful, technical word; in talk, అవకాశం, which you know.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**సంభావ్యత** (*sambhāvyata*) is built on Sanskrit *sambhāvya*, "to be supposed or expected; possible, probable" (Monier-Williams), with the abstract ending -త.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
