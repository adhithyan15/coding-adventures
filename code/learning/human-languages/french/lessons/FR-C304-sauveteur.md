## You'll want to know: le sauveteur
<!-- hl-knowledge: introduces=[FR-LEX-C304-NOYADE-03]; assesses=[] -->

**le sauveteur** — "the rescuer".

> Les sauveteurs ont travaillé toute la nuit.
>
> *The rescuers worked all night.*

Feminine: *la sauveteuse*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*sauveteur* is built on *sauver* "to save", which is inherited from Late Latin *salvāre*, built on *salvus* "safe" (Lewis & Short).
