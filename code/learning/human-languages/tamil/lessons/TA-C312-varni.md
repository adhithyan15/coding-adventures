## You'll want to know: வர்ணி
<!-- hl-knowledge: introduces=[TA-LEX-C312-VIRIVAKA312-03]; assesses=[] -->

**வர்ணி** — *varṇi* — "to describe vividly".

> தாத்தா அந்தப் பழைய திருவிழாவை அழகாக வர்ணித்தார்.
>
> *tāttā antap paḻaiya tiruviḻāvai aḻakāka varṇittār.*
>
> Grandfather described that old festival beautifully.

Past (I …): வர்ணித்தேன், *varṇittēṉ*.

The noun வர்ணனை is a description or a sports commentary.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**வர்ணி** (*varṇi*) is a Tamil verb built on Sanskrit *varṇana*, "painting, description" (Monier-Williams).
