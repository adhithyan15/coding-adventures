## You'll want to know: సమర్థవంతమైన
<!-- hl-knowledge: introduces=[TE-LEX-C431-PRAMANAM431-04]; assesses=[] -->

**సమర్థవంతమైన** — *samarthavantamaina* — "effective; efficient".

> ఆమె సమర్థవంతమైన అధికారి.
>
> *āme samarthavantamaina adhikāri.*
>
> She is an efficient officer.

సమర్థ, capable, + -వంత, having, + -మైన. సమర్థవంతంగా, effectively.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**సమర్థవంతమైన** (*samarthavantamaina*) is built on Sanskrit *samartha*, "appropriate; capable" (CDIAL 13189), with *-vant*, "having", and Telugu -మైన for an adjective.
