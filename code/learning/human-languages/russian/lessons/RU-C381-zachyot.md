## You'll want to know: зачёт
<!-- hl-knowledge: introduces=[RU-LEX-C381-SESSIYA-02]; assesses=[] -->

**зачёт** (*zachyót*) — "a pass-or-fail test, a credit".

> Завтра у меня зачёт по истории.
>
> *Závtra u menyá zachyót po istórii.*
>
> Tomorrow I have a pass-or-fail test in history.

Masculine. A test graded pass or fail, without a mark. *Получить зачёт* — to pass it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**зачёт** is built on *зачесть* "to count in, to credit", on the old root of *считать* and *число* "number": a test that is counted in or not.
