## You'll want to know: संबंध
<!-- hl-knowledge: introduces=[MR-LEX-C348-SAMBANDH348-01]; assesses=[] -->

**संबंध** — *sambandh* — "a connection; a relationship".

> या दोन घटनांचा एकमेकांशी काही संबंध नाही.
>
> *yā don ghaṭnāñcā ekmekāṁśī kāhī sambandh nāhī.*
>
> These two events have no connection with each other.

Masculine.

X चा Y शी संबंध असणे, X is connected with Y.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**संबंध** (*sambandh*) is a tatsama, taken from Sanskrit *sambandha*, "binding together, connection" (Monier-Williams).
