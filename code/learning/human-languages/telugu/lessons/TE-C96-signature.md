# సంతకం (santakaṁ) — a signature

## You'll want to know: సంతకం
<!-- hl-knowledge: introduces=[TE-LEX-C96-NAMES-05]; assesses=[] -->

**సంతకం** (*santakaṁ*) — "a signature".

**ఇక్కడ సంతకం చేయండి** — "please sign here". A signature is something you *do*, with the
**చేయు** of **పని చేయు**.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

Surname, nickname, age, birthday, signature: every box on a form.
