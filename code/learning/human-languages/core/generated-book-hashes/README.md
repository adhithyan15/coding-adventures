# Chapter-owned book hash ledgers

These files are generated by `human-language-data`'s `generate:books` command.
Each `<language>.d/` directory contains document-wide fields in `_meta.json`
and one chapter record in each zero-padded `NNNN.json` owner. Changing chapter
7 therefore updates `0007.json`; it does not rewrite another chapter, a
language manifest, or a corpus-wide manifest.

Do not edit generated JSON by hand. CI's `check:books` gate derives the exact
owner set in memory and compares every file byte for byte. Missing, stale,
unexpected, malformed, symlinked, non-regular, duplicate, mismatched, or unsafe
owners fail closed. The former flat `<language>.json` manifests are forbidden;
there is no tracked aggregate to regenerate or merge.
