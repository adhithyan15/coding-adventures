# ਬਿਲਕੁਲ (bilkul) — absolutely; completely

## You'll want to know: ਬਿਲਕੁਲ
<!-- hl-knowledge: introduces=[PA-LEX-C340-AGREE340-03]; assesses=[] -->

**ਬਿਲਕੁਲ** — *bilkul* — "absolutely; completely".

> ਕੀ ਤੁਸੀਂ ਬਿਲਕੁਲ ਤਿਆਰ ਹੋ?
>
> *kī tusī̃ bilkul tiār ho?*
>
> Are you completely ready?

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ਬਿਲਕੁਲ** (*bilkul*) is a loan, usually traced through Persian to Arabic *bil-kull*, "with the whole".
