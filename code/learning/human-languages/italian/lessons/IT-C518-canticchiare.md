## You'll want to know: canticchiare
<!-- hl-knowledge: introduces=[IT-LEX-C518-CANTO-05]; assesses=[] -->

**canticchiare** — "to hum, to sing softly".

> Canticchio mentre cucino.
>
> *I hum while I cook.*

Built on *cantare* with *-icchiare*, for a light, repeated action.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*canticchiare* is built on *cantare* "to sing" (EtymDB), inherited from Latin *cantāre*.
