# facētus, facēta, facētum — witty, clever

## You'll want to know: facētus, facēta, facētum
<!-- hl-knowledge: introduces=[LA-LEX-C502-IOCU-05]; assesses=[] -->

**facētus, facēta, facētum** — "witty, clever".

> Hospes facētus multa rīdicula dīcit.
>
> *The witty guest says many funny things.*

Elegant, good-humoured wit. English *facetious* comes from *facētiae* — jokes.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**facētus** is a native Latin adjective; Lewis & Short and EtymDB link it with *fax* "torch" and a root meaning "to shine", but the origin is not settled. English *facetious* comes from *facētiae* "jokes", built on it.
