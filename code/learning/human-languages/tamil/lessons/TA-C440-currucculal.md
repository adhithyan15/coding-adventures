# சுற்றுச்சூழல் (cuṟṟuccūḻal) — the environment

## You'll want to know: சுற்றுச்சூழல்
<!-- hl-knowledge: introduces=[TA-LEX-C440-MASU440-02]; assesses=[] -->

**சுற்றுச்சூழல்** — *cuṟṟuccūḻal* — "the environment".

> தொழிற்சாலைகள் சுற்றுச்சூழலைக் கெடுக்கின்றன.
>
> *toḻiṟcālaikaḷ cuṟṟuccūḻalaik keṭukkiṉṟaṉa.*
>
> Factories damage the environment.

சுற்று, around, + சூழல், surroundings.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**சுற்றுச்சூழல்** (*cuṟṟuccūḻal*) is built from சுற்று, "around" (DEDR 2715), and சூழல், "surroundings" (DEDR 2698).
