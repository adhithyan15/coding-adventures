# おめでとう (omedetō) — congratulations

## You'll want to know: おめでとう
<!-- hl-knowledge: introduces=[JA-LEX-C286-AKACHAN286-04]; assesses=[] -->

**おめでとう** — *omedetō* — "congratulations".

> **たんじょうび、おめでとう。** — *tanjōbi, omedetō* — "Happy birthday!"

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**おめでとう** (*omedetō*) is a native Japanese word (wago), inherited rather than borrowed from Chinese, and it is usually written in kana (JMdict).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
