# ۰ ۱ — two digits, and a direction that reverses

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[FA-SCRIPT-RTL-01, FA-LEX-YEK] -->

[PAUSE 2s] Which way does a Persian line run? Say **yek**.

## Script — the shapes, and the direction
<!-- hl-knowledge: introduces=[FA-SCRIPT-DIGIT-ZERO, FA-SCRIPT-DIGIT-ONE, FA-SCRIPT-DIGITS-LTR]; assesses=[FA-SCRIPT-RTL-01, FA-LEX-DAH] -->

> **۰** — *sefr*, zero  **۱** — *yek*, one

Persian has its own ten digit signs, and every price ticket, telephone number
and page number in Iran is written in them. A reader who can say **yek** and
cannot read **۱** still cannot read a price.

**۰** is a **dot**, not a ring. Fix that first, because a European eye reads a
dot as a decimal point — and Persian's nine is the ring.

Now the part no earlier chapter has had to say: **numbers run left to right,
inside a line that runs right to left.** Ten is **۱۰** — one, then zero, in the
European order — while the words around it move the other way. The page changes
direction at the number and changes back after it.
