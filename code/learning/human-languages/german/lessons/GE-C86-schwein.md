## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**Schwein** ← Old High German *swīn* ← Proto-Germanic *\*swīną*, "swine, pig" — inherited, the same word as English *swine*. (EtymDB 2.1)
