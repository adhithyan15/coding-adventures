## You'll want to know: મીઠાઈ
<!-- hl-knowledge: introduces=[GU-LEX-C170-SWEET170-01]; assesses=[] -->

**મીઠાઈ** — *mīṭhāī* — "sweets, sweetmeat".

> **દિવાળીમાં અમે મીઠાઈ ખાઈએ છીએ.** — *divāḷīmā̃ ame mīṭhāī khāīe chīe* — "We eat sweets at Diwali."

Built on **મીઠું**, *mīṭhũ*, sweet.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**મીઠાઈ** (*mīṭhāī*) is built on the inherited *mīṭhũ*, "sweet", with the noun ending *-āī*; EtymDB derives it from that word. CDIAL traces *mīṭhũ* to Sanskrit *miṣṭa*, "dainty, sweet" (CDIAL 10299).
