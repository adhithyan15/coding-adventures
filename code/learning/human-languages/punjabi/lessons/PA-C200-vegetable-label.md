## Grammar Lens
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-SABZI-200, PA-DEM-EH-01, PA-LEX-HAI-02, PA-GRAMMAR-VERB-LAST-02] -->

> **ਇਹ ਸਬਜ਼ੀ ਹੈ** — *eh sabzī hai* — this is a vegetable / cooked vegetable dish

Keep the new whole noun between familiar **ਇਹ** and **ਹੈ**. Familiar **ਹੈ**
stays last in the already-owned identity frame. This chapter teaches only this
one label; it does not add a form rule or a wider construction.
