# பேரரசு (pēraracu) — an empire

## You'll want to know: பேரரசு
<!-- hl-knowledge: introduces=[TA-LEX-C330-PERARASU330-01]; assesses=[] -->

**பேரரசு** — *pēraracu* — "an empire".

> அந்தப் பேரரசு கடல் வரை பரவியது.
>
> *antap pēraracu kaṭal varai paraviyatu.*
>
> That empire spread as far as the sea.

பேர், great + அரசு, kingdom.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**பேரரசு** (*pēraracu*) is a Tamil compound built from பேர், "great" (DEDR 4411), and அரசு, "kingdom", which DEDR 201 traces to Sanskrit *rājan*.
