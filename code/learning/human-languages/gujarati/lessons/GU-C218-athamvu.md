# આથમવું (āthamvũ) — to set

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[GU-LEX-C218-SUN218-01, GU-LEX-C218-SUN218-02] -->

[PAUSE 2s] Before the new one: say the Gujarati for to rise, then the Gujarati for sunrise.

## You'll want to know: આથમવું
<!-- hl-knowledge: introduces=[GU-LEX-C218-SUN218-03]; assesses=[] -->

**આથમવું** — *āthamvũ* — "to set".

> **સાંજે સૂરજ મોડો આથમશે.** — *sā̃je sūraj moḍo āthamśe* — "The sun will set late in the evening."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**આથમવું** (*āthamvũ*) is a tadbhava. It comes from the Sanskrit phrase *astam eti*, "goes home, sets (of the sun)", built on *asta*, "home" (CDIAL 976).
