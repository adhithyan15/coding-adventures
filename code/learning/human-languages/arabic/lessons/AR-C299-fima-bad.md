# فيما بعد (fīmā baʿd) — later on, afterwards

## You'll want to know: فيما بعد
<!-- hl-knowledge: introduces=[AR-LEX-C299-ATHNA299-02]; assesses=[] -->

**فيما بعد** — *fīmā baʿd* — "later on, afterwards".

> عرفت السبب فيما بعد.
>
> *ʿaraftu as-sabab fīmā baʿd.*
>
> I found out the reason later on.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**فيما بعد** (*fīmā baʿd*) is *fī*, "in", *mā*, "what", and *baʿd*, "after", which is built on the native Arabic root *b-ʿ-d*, "to be far" (Lane).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
