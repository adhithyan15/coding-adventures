# اسٹاپ (isṭāp) — a bus stop

## You'll want to know: اسٹاپ
<!-- hl-knowledge: introduces=[UR-LEX-C392-STAND392-02]; assesses=[] -->

**اسٹاپ** — *isṭāp* — "a bus stop".

> اگلا اسٹاپ اسکول کے پاس ہے۔
>
> *aglā isṭāp iskūl ke pās hai.*
>
> The next stop is near the school.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**اسٹاپ** (*isṭāp*) is borrowed from English *stop*.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for getting around.
