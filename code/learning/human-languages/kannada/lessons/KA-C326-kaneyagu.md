## You'll want to know: ಕಾಣೆಯಾಗು
<!-- hl-knowledge: introduces=[KA-LEX-C326-KANE326-01]; assesses=[] -->

**ಕಾಣೆಯಾಗು** — *kāṇeyāgu* — "to go missing".

> ಒಂದು ವೇಳೆ ಮಗು ಕಾಣೆಯಾದರೆ ಅಪ್ಪ ಅಮ್ಮ ತಕ್ಷಣ ದೂರು ಕೊಡುತ್ತಾರೆ.
>
> *ondu vēḷe magu kāṇeyādare appa amma takṣaṇa dūru koḍuttāre.*
>
> If a child goes missing, the parents report it at once.

Past (it …): ಕಾಣೆಯಾಯಿತು, *kāṇeyāyitu*.

ಕಾಣೆ, not to be seen, and ಆಗು, to become.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಕಾಣೆಯಾಗು** (*kāṇeyāgu*) is a native Dravidian compound: ಕಾಣೆ, "not seen", from *kāṇ* "to see" (DEDR 1443), and *āgu* "to become" (DEDR 333).
