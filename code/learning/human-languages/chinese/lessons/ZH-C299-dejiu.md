## You'll want to know: 得救
<!-- hl-knowledge: introduces=[ZH-LEX-C299-RESCUE299-01]; assesses=[] -->

**得救** — *déjiù* — "to be rescued; to be saved from danger".

> **事故发生以后大家都得救了** *shìgù fāshēng yǐhòu, dàjiā dōu déjiù le* — After the accident, everyone was rescued.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**得救** (*déjiù*) is built from 得 'to get' and 救 'to save', both inherited from Middle Chinese, *tok* and *kjuwH* (Guangyun, in Baxter's transcription), which glosses the first 'to gain': to get saved.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
