# ആരോപണം (ārōpaṇaṁ) — an allegation; a charge

## You'll want to know: ആരോപണം
<!-- hl-knowledge: introduces=[ML-LEX-C355-PATRAPRAVARTTAKAN355-02]; assesses=[] -->

**ആരോപണം** — *ārōpaṇaṁ* — "an allegation; a charge".

> അവന് എതിരെ ഒരു ആരോപണം ഉണ്ട്.
>
> *avanŭ etire oru ārōpaṇaṁ uṇṭŭ.*
>
> There is an allegation against him.

Against takes എതിരെ: അവന് എതിരെ, against him.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ആരോപണം** (*ārōpaṇaṁ*) is borrowed from Sanskrit *āropaṇa*, "causing to mount, raising up" (Monier-Williams). An allegation lays a charge upon someone.
