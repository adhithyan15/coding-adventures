# ਟਿਕਟ — ticket

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-TRAVEL-RAIL-01] -->

## Grammar Lens: one travel item
<!-- hl-knowledge: introduces=[PA-TRAVEL-TICKET-01]; assesses=[PA-TRAVEL-RAIL-01] -->

> **ਟਿਕਟ** — *ṭikaṭ* — ticket

> **ਰੇਲ ਦੀ ਟਿਕਟ** — *rel dī ṭikaṭ* — a train ticket

Use the whole short phrase first; it adds no new possession table.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ਟਿਕਟ** (*ṭikaṭ*) is a loan from English *ticket*.
