# लाज़िमी (lāzimī) — bound to happen, inevitable

## You'll want to know: लाज़िमी
<!-- hl-knowledge: introduces=[HI-LEX-C376-ZAHIR376-04]; assesses=[] -->

**लाज़िमी** — *lāzimī* — "bound to happen, inevitable".

> अगर तुम बहुत ज़्यादा काम करोगे तो थकान होना लाज़िमी है।
>
> *agar tum bahut zyādā kām karoge to thakān honā lāzimī hai.*
>
> If you work far too much, you're bound to get tired.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**लाज़िमी** (*lāzimī*) is usually traced to Persian *lāzimī*, "necessary", which is built on Arabic *lāzim*, "binding, necessary".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
