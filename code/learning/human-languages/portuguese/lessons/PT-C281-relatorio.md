## You'll want to know: o relatório
<!-- hl-knowledge: introduces=[PT-LEX-C281-RELATAR-04]; assesses=[] -->

**o relatório** — "the written report".

> O chefe pediu um relatório até sexta-feira.
>
> *The boss asked for a report by Friday.*

A formal document at work; *a reportagem* belongs to the news.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*relatório* is built on *relato* "an account" with the ending *-ório* (EtymDB), and goes back to Latin *relātus* "a telling".

## What you've built
