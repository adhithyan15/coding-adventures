# ತೆರೆಯಿರಿ (tereyiri) — please open

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C100-FIND-04, KA-LEX-C100-FIND-05] -->

[PAUSE 2s] Before the new one: say the Kannada for a station, then the Kannada for near.

## You'll want to know: ತೆರೆಯಿರಿ
<!-- hl-knowledge: introduces=[KA-LEX-C101-OPEN-01]; assesses=[] -->

**ತೆರೆಯಿರಿ** (*tereyiri*) — "please open", the polite **‑ಇರಿ** form, like
**ಕಾಯಿರಿ**, "please wait".

**ಬಾಗಿಲು ತೆರೆಯಿರಿ** (*bāgilu tereyiri*) — "please open the door".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

A polite command on a known ending.
