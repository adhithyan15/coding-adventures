## You'll want to know: آنفولانزا
<!-- hl-knowledge: introduces=[FA-LEX-C490-COLD-02]; assesses=[] -->

**آنفولانزا** (*ânfolânzâ*) — "flu, influenza".

> این زمستان خیلی از بچه ها آنفولانزا گرفتند.
>
> *in zemestân kheyli az bachchehâ ânfolânzâ gereftand.*
>
> This winter a lot of children caught flu.

*ânfolânzâ gereftan* — to catch flu.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*ânfolânzâ* is a modern loan, usually traced to French *influenza*, which French took from Italian. EtymDB has no entry for the Persian word.
