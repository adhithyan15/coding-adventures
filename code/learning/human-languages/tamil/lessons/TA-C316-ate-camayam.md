# அதே சமயம் (atē camayam) — at the same time

## You'll want to know: அதே சமயம்
<!-- hl-knowledge: introduces=[TA-LEX-C316-ANNAAL316-05]; assesses=[] -->

**அதே சமயம்** — *atē camayam* — "at the same time".

> அதே சமயம், வெளியே ஒரு சத்தம் கேட்டது.
>
> *atē camayam, veḷiyē oru cattam kēṭṭatu.*
>
> At the same time, a noise was heard outside.

அதே, that same + சமயம், time.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**அதே சமயம்** (*atē camayam*) joins அதே, "that same", with சமயம், "time, occasion", borrowed from Sanskrit *samaya*, "meeting, time" (CDIAL 13185).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->
