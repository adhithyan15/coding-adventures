# തകരാറ് (takarāṟŭ) — a fault; a breakdown

## You'll want to know: തകരാറ്
<!-- hl-knowledge: introduces=[ML-LEX-C471-VANDI471-03]; assesses=[] -->

**തകരാറ്** — *takarāṟŭ* — "a fault; a breakdown".

> എഞ്ചിന് എന്തോ തകരാറുണ്ട്.
>
> *eñcinŭ entō takarāṟuṇṭŭ.*
>
> There is some fault in the engine.

The thing with the fault takes -ന് / -ക്ക്: വണ്ടിക്ക് തകരാറുണ്ട്, the vehicle has a fault.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**തകരാറ്** (*takarāṟŭ*) is usually traced to Arabic *takrār*, "repetition, dispute", which came south through Hindustani; in Malayalam it names a fault in a machine.
