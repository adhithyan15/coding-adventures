# A human-language lesson heading must name a book-renderer block type

The meal-ordering chapter first used descriptive `##` headings such as
“Independent practice” and “Check after speaking.” Corpus loading accepted
them, but book generation failed with `generated books require known body
blocks`. Use the established renderer headings — for example `Warm-up`,
`Grammar Lens`, `Guided Practice`, `What you've built`, and `Wrap-up Recall` —
and put the descriptive detail after a colon or dash.
