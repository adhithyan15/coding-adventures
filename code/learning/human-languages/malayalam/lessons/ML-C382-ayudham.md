# ആയുധം (āyudhaṁ) — a weapon

## You'll want to know: ആയുധം
<!-- hl-knowledge: introduces=[ML-LEX-C382-KALAPAM382-02]; assesses=[] -->

**ആയുധം** — *āyudhaṁ* — "a weapon".

> പോലീസ് കള്ളന്റെ കയ്യിൽ നിന്ന് ആയുധം പിടിച്ചെടുത്തു.
>
> *pōlīsŭ kaḷḷanṟe kayyil ninnŭ āyudhaṁ piṭicceṭuttu.*
>
> The police seized a weapon from the robber's hand.

Plural: ആയുധങ്ങൾ, *āyudhaṅṅaḷ*.

A tool is ഉപകരണം; a weapon is ആയുധം.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ആയുധം** (*āyudhaṁ*) is borrowed from Sanskrit *āyudha*, "a weapon" (CDIAL 1291), from the root *yudh*, "to fight", the root of യുദ്ധം (*yuddhaṁ*).
