# ದಟ್ಟಣೆ (daṭṭaṇe) — congestion; crowding

## You'll want to know: ದಟ್ಟಣೆ
<!-- hl-knowledge: introduces=[KA-LEX-C443-SANCHARA443-04]; assesses=[] -->

**ದಟ್ಟಣೆ** — *daṭṭaṇe* — "congestion; crowding".

> ರಸ್ತೆಯಲ್ಲಿ ವಾಹನ ದಟ್ಟಣೆ ಇತ್ತು.
>
> *rasteyalli vāhana daṭṭaṇe ittu.*
>
> There was a traffic jam on the road.

ವಾಹನ ದಟ್ಟಣೆ, a traffic jam; ದಟ್ಟ means dense or thick.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ದಟ್ಟಣೆ** (*daṭṭaṇe*) is native Dravidian, built on Kannada *daṭṭa*, "thick, crowded, dense" (DEDR 3020).
