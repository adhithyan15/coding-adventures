# আপত্তি (āpôtti) — an objection

## You'll want to know: আপত্তি
<!-- hl-knowledge: introduces=[BN-LEX-C334-APOTTI334-01]; assesses=[] -->

**আপত্তি** — *āpôtti* — "an objection".

> তোমার কোনো আপত্তি আছে?
>
> *tomār kono āpôtti āchhe?*
>
> Do you have any objection?

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**আপত্তি** (*āpôtti*) is Sanskrit *āpatti*, something that befalls one, a mishap (Monier-Williams). The Bengali sense, an objection someone raises, is not one the dictionary gives.

<!-- hl-knowledge: introduces=[]; assesses=[] -->
