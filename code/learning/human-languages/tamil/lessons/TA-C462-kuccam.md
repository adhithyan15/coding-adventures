# கூச்சம் (kūccam) — bashfulness; ticklishness

## You'll want to know: கூச்சம்
<!-- hl-knowledge: introduces=[TA-LEX-C462-VETKAM462-03]; assesses=[] -->

**கூச்சம்** — *kūccam* — "bashfulness; ticklishness".

> புதியவர்களிடம் பேச என் மகனுக்குக் கூச்சம்.
>
> *putiyavarkaḷiṭam pēca eṉ makaṉukkuk kūccam.*
>
> My son is shy about talking to new people.

Also being ticklish: கூச்சமாக இருக்கிறது, it tickles.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**கூச்சம்** (*kūccam*) is native Dravidian, from கூசு *kūcu*, "to be shy, to be ticklish, to shrink back" (DEDR 1876).
