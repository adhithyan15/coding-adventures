# ਮੁਲਾਇਮ (mulāim) — smooth; soft to the touch

## You'll want to know: ਮੁਲਾਇਮ
<!-- hl-knowledge: introduces=[PA-LEX-C297-TOUCH297-01]; assesses=[] -->

**ਮੁਲਾਇਮ** — *mulāim* — "smooth; soft to the touch".

> ਇਹ ਕੱਪੜਾ ਬਹੁਤ ਮੁਲਾਇਮ ਹੈ।
>
> *eh kappṛā bahut mulāim hai.*
>
> This cloth is very smooth.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ਮੁਲਾਇਮ** (*mulāim*) is a loan, usually traced through Persian to Arabic *mulāyim*, "gentle, soft".
