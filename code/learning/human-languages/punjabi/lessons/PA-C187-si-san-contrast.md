# One was; more than one were

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-SI-187, PA-FORM-SAN-187] -->

[PAUSE 2s] Say the pair once without looking.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-SI-187, PA-FORM-SAN-187, PA-FORM-NAME-AMAN-01, PA-LEX-C67-FOOD67-03, PA-POSTPOSITION-VICH-01, PA-LEX-C73-SCHOOL73-04, PA-LEX-C84-ADJ84-02] -->

- [YOU HEAR: *Aman ghar vich sii*; YOU SAY: **ਅਮਨ ਘਰ ਵਿੱਚ ਸੀ**]
- [YOU HEAR: *phull laal san*; YOU SAY: **ਫੁੱਲ ਲਾਲ ਸਨ**]
- [YOU READ: **ਸੀ · ਸਨ**]
- [YOU WRITE: cover the pair and write **ਸੀ, ਸਨ**]

Keep the time past in both lines. Change the copula when the subject changes
from singular to plural.
