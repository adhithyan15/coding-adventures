- [YOU READ: **しんぱい** — worry]
- [YOU READ: **えんぴつ** — a pencil]
- [YOU READ: **いっぴき** — one small animal]
- [YOU READ: **きっぷ** — a ticket]
- [YOU READ: **てんぷら** — tempura]
- [YOU READ: **ぺらぺら** — fluent]

Each of these words holds one of the four signs this chapter wrote. With
them, and **ぽ** from chapter 18, the book writes every sign of the *p* row,
**ぱ ぴ ぷ ぺ ぽ**.
