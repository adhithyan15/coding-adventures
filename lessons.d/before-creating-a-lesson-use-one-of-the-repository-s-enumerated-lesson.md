# Before creating a lesson, use one of the repository's enumerated lesson categories instead of inventing a shorthand category.

The first attempt to record a tooling lesson used a made-up `tooling` category, so the lesson command rejected it and printed the repository's allowed categories. Use the exact category names exposed by `lessons.py`—for workflow mistakes, `Repo policy / workflow reminders`—and record the failed lesson attempt as well when strict failure logging applies.
