# HL62 — Bengali A2 connected composition

## Status

Proposed for issue #17638 under the Indian-language C2 programme #13295.

## Problem

The Bengali assessment contract requires `connected-composition` from A2 onward,
but the authored curriculum currently proves only the earlier controlled and timed
A1 writing stages. The planner therefore reports one cumulative Bengali A2 writing
gap. Closing that machine-measured gap must not be confused with learner attainment,
mock passage, readiness, or human validation.

## Required learner experience

Add one chapter-addressable, untimed writing lesson after the existing A2 curriculum.
The lesson must:

- name one reader and one practical purpose;
- ask for a 70–90 word connected message in Bengali script;
- use a content-only plan with a greeting, reason for writing, familiar-day route,
  sequence, preference, reason, direct question, and close;
- provide no copyable Bengali model, sentence bank, romanization, or answer;
- introduce no new language or script knowledge;
- reuse already-taught everyday actions, time anchors, connectors, preference,
  reason, and location-question knowledge;
- separate review into task fulfilment, organisation, Bengali language control,
  and Bengali-script control; and
- say explicitly that one curriculum attempt does not prove A2 attainment,
  readiness, mock passage, or human validation.

## Ownership and publication

The lesson, chapter, curriculum path, extension, membership, book target, generated
book chapter, narration, hashes, modality evidence, test, changelog, and session-map
entry each use their direct shard owner. Ordinary authoring must not edit a shared
track aggregate.

## Verification

A focused Bengali corpus test must prove that exactly one
`connected-composition` block exists, contains the named reader, purpose, length,
content constraints, no-model rules, four review passes, and honest scope language,
and contains no Bengali learner answer. It must also prove that the chapter payoff
owns the new lesson and that Bengali A2 has no missing writing stage or defect.

Run the Bengali corpus, writing-stage, chapter, curriculum, integration, generated
artifact, document-shard, progress, book, narration, lesson-shard, and package gates,
then run the full affected package suite before the pull request is marked ready.
