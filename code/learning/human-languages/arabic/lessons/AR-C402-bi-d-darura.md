# بالضرورة (bi-ḍ-ḍarūra) — necessarily

## You'll want to know: بالضرورة
<!-- hl-knowledge: introduces=[AR-LEX-C402-HATMAN402-02]; assesses=[] -->

**بالضرورة** — *bi-ḍ-ḍarūra* — "necessarily".

> الغالي ليس بالضرورة أفضل.
>
> *al-ghālī laysa bi-ḍ-ḍarūra afḍal.*
>
> Expensive is not necessarily better.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**بالضرورة** (*bi-ḍ-ḍarūra*) is built on the native Arabic root *ḍ-r-r*, "to harm; to compel" (Lane). *Ḍarūra* is necessity, what one is compelled to; *bi-ḍ-ḍarūra* is by necessity. ضروري, necessary, is from the same root.
