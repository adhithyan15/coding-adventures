## You'll want to know: ঢেউ
<!-- hl-knowledge: introduces=[BN-LEX-C290-DHEU290-01]; assesses=[] -->

**ঢেউ** — *ḍheu* — "a wave".

> বড় একটা ঢেউ এসে নৌকাটা উল্টে দিল।
>
> *bôṛo ekṭā ḍheu ese noukāṭā ulṭe dilô.*
>
> A big wave came and overturned the boat.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ঢেউ** (*ḍheu*) is filed in CDIAL 5580 under a Middle Indo-Aryan *ḍhappa-*, 'lump', where a Bengali *ḍheu*, 'a swelling', appears; how it became a wave is not set out there. It opens with ঢ, the breathy *ḍh*.

<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
