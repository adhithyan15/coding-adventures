# பொம்மலாட்டம் (pommalāṭṭam) — a puppet show

## Warm-up

[PAUSE 2s] Before the new one: say the Tamil for trekking, then the Tamil for to go fishing.

## You'll want to know: பொம்மலாட்டம்
<!-- hl-knowledge: introduces=[TA-LEX-C554-VARAIRUTHI554-05]; assesses=[] -->

**பொம்மலாட்டம்** — *pommalāṭṭam* — "a puppet show".

> குழந்தைகள் விரும்பினால் பொம்மலாட்டம் பார்க்கப் போகலாம்.
>
> *kuḻantaikaḷ virumpiṉāl pommalāṭṭam pārkkap pōkalām.*
>
> If the children want to, we can go and see a puppet show.

பொம்மை (*pommai*) "a doll" + ஆட்டம் "a dance, a play".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**பொம்மலாட்டம்** (*pommalāṭṭam*) is a native compound: பொம்மை (*pommai*), "a puppet, a doll" (DEDR 4530), and ஆட்டம் (*āṭṭam*), "a dance, a play".
