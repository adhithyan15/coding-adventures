# സംരംഭം (saṁrambhaṁ) — a venture; an enterprise

## You'll want to know: സംരംഭം
<!-- hl-knowledge: introduces=[ML-LEX-C544-SAMRAMBHAM544-02]; assesses=[] -->

**സംരംഭം** — *saṁrambhaṁ* — "a venture; an enterprise".

> അവൾ ഒരു ചെറിയ ബേക്കറി സംരംഭം തുടങ്ങി.
>
> *avaḷ oru ceṟiya bēkkaṟi saṁrambhaṁ tuṭaṅṅi.*
>
> She started a small bakery venture.

A word of business news; സംരംഭം തുടങ്ങുക, to start a venture.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**സംരംഭം** (*saṁrambhaṁ*) is borrowed from Sanskrit *saṁrambha*, which CDIAL glosses as vehemence (CDIAL 12993); Malayalam uses it for an undertaking pursued with zeal.
