# अट्टहासः (aṭṭahāsaḥ) — a loud laugh

## You'll want to know: अट्टहासः
<!-- hl-knowledge: introduces=[SA-LEX-C457-HASA457-04]; assesses=[] -->

**अट्टहासः** — *aṭṭahāsaḥ* — "a loud laugh".

> पिता अट्टहासं करोति, बालाः अपि हसन्ति।
>
> *pitā aṭṭahāsaṃ karoti, bālāḥ api hasanti.*
>
> Father lets out a loud laugh, and the children laugh too.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**अट्टहासः** (*aṭṭahāsaḥ*) is built from *aṭṭa*, "high, lofty", and *hāsa*, "laughter", from the root √has, "to laugh" (MW).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
