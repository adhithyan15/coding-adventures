# ಚುನಾವಣೆ (cunāvaṇe) — an election

## You'll want to know: ಚುನಾವಣೆ
<!-- hl-knowledge: introduces=[KA-LEX-C392-CHUNAVANE392-01]; assesses=[] -->

**ಚುನಾವಣೆ** — *cunāvaṇe* — "an election".

> ಮುಂದಿನ ತಿಂಗಳು ನಮ್ಮ ಊರಿನಲ್ಲಿ ಚುನಾವಣೆ ಇದೆ.
>
> *mundina tiṅgaḷu namma ūrinalli cunāvaṇe ide.*
>
> There is an election in our town next month.

ಚುನಾವಣೆಗೆ ನಿಲ್ಲು, to stand for election.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಚುನಾವಣೆ** (*cunāvaṇe*) is a loan from Hindustani *cunāv*, "a choosing, an election", from *cunnā*, "to pick", with a Kannada noun ending.
