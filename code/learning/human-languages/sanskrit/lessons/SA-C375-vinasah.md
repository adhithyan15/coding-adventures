## You'll want to know: विनाशः
<!-- hl-knowledge: introduces=[SA-LEX-C375-VIPATTI375-03]; assesses=[] -->

**विनाशः** — *vināśaḥ* — "destruction; ruin".

> यदि युद्धं भवति, तर्हि विनाशः भविष्यति।
>
> *yadi yuddhaṃ bhavati, tarhi vināśaḥ bhaviṣyati.*
>
> If there is a war, there will be destruction.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**विनाशः** (*vināśaḥ*) is built on *vi* and the root √naś, "to perish"; MW gives *vi-nāśa* "utter loss, annihilation, destruction, decay" (MW).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
