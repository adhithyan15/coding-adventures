# ઝરમર (jharmar) — a drizzle

## You'll want to know: ઝરમર
<!-- hl-knowledge: introduces=[GU-LEX-C434-SHOWER434-02]; assesses=[] -->

**ઝરમર** — *jharmar* — "a drizzle".

> સવારથી ઝરમર વરસે છે.
>
> *savārthī jharmar varse che.*
>
> It has been drizzling since the morning.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ઝરમર** (*jharmar*) goes back to Sanskrit *jhara*, "a waterfall, a stream"; CDIAL lists the Gujarati word, "a drizzle" (CDIAL 5343). Its doubled sound is like the rain itself.
