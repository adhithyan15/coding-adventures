# ं — a small dot for the nasal ending

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-BHA-01, MW-SCRIPT-AABHAAR-01, MW-LEX-AABHAAR-01, MW-SCRIPT-HA-01, MW-SCRIPT-AA-MATRA-01] -->

[PAUSE 5s] Write **ह**, then **भ**, from memory. Add the familiar long-*ā* mark
to **ह**: **हा**. Read it once.

## Script — one small new mark
<!-- hl-knowledge: introduces=[MW-SCRIPT-ANUSVARA-01]; assesses=[] -->

> **ं** — a dot above

In the source spelling **हां**, this dot cues the nasal ending. Say *hā(n)* slowly:
the vowel is long and the ending resonates through the nose. Speakers vary, so
listen for the whole word rather than forcing one exaggerated sound.

## Writing — add only the mark
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-HA-01, MW-SCRIPT-AA-MATRA-01, MW-SCRIPT-ANUSVARA-01] -->
<!-- hl-writing-stage: guided-copy -->

1. copy **हा** once
2. look at **हां**
3. add **ं** above the end of your copy
4. compare the dot's position, then say *hā(n)*
