# ચિડાવું (ciḍāvũ) — to get irritated, to get cross

## You'll want to know: ચિડાવું
<!-- hl-knowledge: introduces=[GU-LEX-C267-UPSET267-04]; assesses=[] -->

**ચિડાવું** — *ciḍāvũ* — "to get irritated, to get cross".

> **મારા પિતા ક્યારેય નથી ચિડાતા.** — *mārā pitā kyārey nathī ciḍātā* — "My father never gets irritated."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ચિડાવું** (*ciḍāvũ*) is a tadbhava. It comes from *\*ciḍ*, "be angry", a reconstructed form; CDIAL glosses the Gujarati verb "to be provoked" (CDIAL 4794).
