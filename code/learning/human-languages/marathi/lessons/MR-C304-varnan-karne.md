# वर्णन करणे (varṇan karṇe) — to describe

## You'll want to know: वर्णन करणे
<!-- hl-knowledge: introduces=[MR-LEX-C304-VARNAN304-01]; assesses=[] -->

**वर्णन करणे** — *varṇan karṇe* — "to describe".

> तिने सहलीचं सुंदर वर्णन केलं.
>
> *tine sahlīcaṁ sundar varṇan kelaṁ.*
>
> She described the trip beautifully.

Past, with -ने (he …): त्याने वर्णन केलं, *tyāne varṇan kelaṁ*.

What is described takes -चं: गावाचं वर्णन करणे.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**वर्णन करणे** (*varṇan karṇe*) joins *varṇan*, 'a description', a tatsama taken from Sanskrit *varṇana*, 'depicting, describing' (Monier-Williams), to *karṇe*, 'to do'.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
