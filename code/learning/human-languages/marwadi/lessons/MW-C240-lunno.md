# लूणणो (lūṇṇo) — to reap

## You'll want to know: लूणणो
<!-- hl-knowledge: introduces=[MW-LEX-C240-HARV240-02]; assesses=[] -->

**लूणणो** — *lūṇṇo* — "to reap".

> हूं काल बाजरो लूणसूं।
>
> *hū̃ kāl bājro lūṇsū̃.*
>
> Tomorrow I'll reap the millet.

Past (I …): म्हैं बाजरो लूण्यो, *mhaĩ bājro lūṇyo*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**लूणणो** (*lūṇṇo*) is inherited from Sanskrit *lunāti*, "cuts, reaps"; CDIAL lists Hindi *lunnā*, "to reap". CDIAL gives no Marwari form in this entry (CDIAL 11082).
