# coding-adventures-neural-network

Graph-native neural network authoring primitives for Python.

This package owns neural-network primitives and metadata authoring. The graph
storage itself is provided by the generic
`coding-adventures-multi-directed-graph` package, so the graph substrate stays
domain-neutral.

This package mirrors the TypeScript `@coding-adventures/neural-network` surface:
inputs, constants, weighted sums, activations, outputs, and an explicit XOR
teaching network.
