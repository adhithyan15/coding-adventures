## You'll want to know: le verglas
<!-- hl-knowledge: introduces=[FR-LEX-C463-FROID-01]; assesses=[] -->

**le verglas** — "the black ice".

> Avec le verglas, les voitures roulent très lentement.
>
> *Because of the black ice, cars are going very slowly.*

*Une route verglacée* — an icy road.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*verglas* is built from *verre* 'glass', from Latin *vitrum*, and *glace* 'ice', from Latin *glaciēs* (EtymDB): ice as smooth as glass.
