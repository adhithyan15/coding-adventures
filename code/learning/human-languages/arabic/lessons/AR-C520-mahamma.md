# مهمة (mahamma) — a task, a mission

## You'll want to know: مهمة
<!-- hl-knowledge: introduces=[AR-LEX-C520-DAWAM520-04]; assesses=[] -->

**مهمة** — *mahamma* — "a task, a mission".

> عندي مهمة صعبة اليوم.
>
> *ʿindī mahamma ṣaʿba al-yawm.*
>
> I have a difficult task today.

Plural: مهام, *mahāmm*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**مهمة** (*mahamma*) is built on the native Arabic root *h-m-m*, "to care about, to be concerned" (Lane). Muhimm, important, which you know, is from the same root.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
