## You'll want to know: ثواب
<!-- hl-knowledge: introduces=[UR-LEX-C528-BARKAT528-02]; assesses=[] -->

**ثواب** — *savāb* — "spiritual merit (for a good deed)".

> اگر آپ مدد کرتے ہیں تو ثواب ملتا ہے۔
>
> *agar āp madad karte haiṅ to savāb miltā hai.*
>
> If you help someone, you earn merit.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ثواب** (*savāb*) is usually traced, through Persian, to Arabic *thawāb*, "a reward", especially for a good deed.
