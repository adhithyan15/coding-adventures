## You'll want to know: favorecer
<!-- hl-knowledge: introduces=[PT-LEX-C353-OBSTACULO-05]; assesses=[] -->

**favorecer** — "to favour, to help along".

> O bom tempo favoreceu o turismo este verão.
>
> *The good weather helped tourism this summer.*

*Ser favorecido* — to be favoured.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*favorecer* is built on *favor* "favour", from Latin *favor* "favour, goodwill, inclination" (Lewis & Short), with the verb ending *-ecer*.
