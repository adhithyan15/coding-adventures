## Chapters 23-27 — the oblique, and what stands on it *(authored)*

- **Ch. 23 — Before a Postposition, Everything Changes**: کمرہ, a room to be
  inside → the direct/oblique split, taught as a rule before any postposition
  that needs it → کو, the postposition already fused inside *mujhe* → میں, spelled
  like the pronoun *I* and told apart by position → پر, which is also *but* →
  review. **Authored.** Empties SPINE-NAME-EVERYDAY-THINGS's omission ledger.
- **Ch. 24 — Here, There, and Where**: اس and ان, the oblique demonstratives,
  with ان carrying respect as well as number → یہاں → وہاں, predictable before it
  is shown → review. **Authored.** Closes the ک- / یہ- / وہ- place frame and gives
  کہاں its first possible answer.
- **Ch. 25 — More Than One**: the plural, which collides with the oblique
  singular on purpose → the oblique plural -وں, the one unambiguous ending → ہم →
  ہمارا, where میرا turns out to be a fusion → review. **Authored.**
- **Ch. 26 — Whose, and Who To**: اس کا → اپنا, which English has no equivalent
  for → ہے نا؟, assembled from chapters two and nineteen → the vocative → review.
  **Authored.**
- **Ch. 27 — Where You Are From**: شہر → ملک → لاہور, the book's first place name
  in 108 lessons → the nisba -ی → review. **Authored.**

Every headword in these five chapters was chosen from the fifteen letters the
script ladder has taught, and the worked examples were tested too. The whole time
column — آج, دن, رات, وقت, کب — was rejected on that test: it needs five letters
the ladder has not reached, so it is a script tranche before it is a vocabulary
one, and it is recorded that way in the inventory.
