## You'll want to know: la pente
<!-- hl-knowledge: introduces=[FR-LEX-C455-RANDONNEE-03]; assesses=[] -->

**la pente** — "the slope, the incline".

> La pente est raide, alors nous montons doucement.
>
> *The slope is steep, so we go up slowly.*

*En pente* — sloping.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*pente* goes back to Vulgar Latin *pendita*, from Latin *pendēre* 'to hang' (EtymDB).
