## You'll want to know: تقلبی
<!-- hl-knowledge: introduces=[FA-LEX-C459-JENS-04]; assesses=[] -->

**تقلبی** (*taqallobi*) — "fake, counterfeit".

> این ساعت تقلبی است.
>
> *In sâ'at taqallobi ast.*
>
> This watch is a fake.

Built on *taqallob* 'cheating' + *-i*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*taqallobi* is built from *taqallob* 'cheating, fraud', a loan usually traced to Arabic *taqallub* 'turning over', and the Persian ending *-i*. EtymDB does not list it.
