## Chapter 5 — the pre-A1 writing ladder, on the first letter

Telugu had **no writing-stage evidence at all**: forty-nine script lessons and
not one directive, so every writing-stage debt read as outstanding while lessons
that could discharge them sat unmarked. The script ladder now carries all four
stages, all on **త**, the first letter the book teaches.

- **observe-trace** — the existing `TE-S01-letter-ta` already did this work
  ("*YOU TRACE త three times*", model visible). Only the marker was missing, and
  the Gujarati precedent settles what the stage means here: trace with the model
  visible, and claim no stroke direction. This book still does not tell you
  where to start the character or which way to travel, because that varies from
  school to school and is not written down until it can be cited.
- **guided-copy** — new, and it does something the first lesson does not: copy
  **త** once alone, then again **beside the letter that follows it in సంతోషం**,
  same size and same gap as the printed pair. A letter traced alone teaches the
  hand one shape; a letter copied beside its neighbour teaches it where the
  shape has to **stop**.
- **delayed-copy** — new. Model covered, ten seconds, write from memory, then
  repair exactly one thing.
- **dictation-transcription** — new. Write the letter from *ta*, and notice what
  was asked for: not *t*, **ta**. The vowel is already inside the letter and
  nobody wrote it.
