## You'll want to know: ಪರಿಹಾರ
<!-- hl-knowledge: introduces=[KA-LEX-C429-ASHISU429-05]; assesses=[] -->

**ಪರಿಹಾರ** — *parihāra* — "a solution; compensation".

> ಈ ಸಮಸ್ಯೆಗೆ ಸುಲಭ ಪರಿಹಾರ ಇಲ್ಲ.
>
> *ī samasyege sulabha parihāra illa.*
>
> There is no easy solution to this problem.

Also compensation: ಬೆಳೆ ನಷ್ಟಕ್ಕೆ ಪರಿಹಾರ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಪರಿಹಾರ** (*parihāra*) is borrowed from Sanskrit *parihāra*, "leading round, avoiding; a remedy" (CDIAL 7901).
