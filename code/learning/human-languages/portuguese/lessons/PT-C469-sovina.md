## You'll want to know: sovina
<!-- hl-knowledge: introduces=[PT-LEX-C469-TEIMOSIA-05]; assesses=[] -->

**sovina** — "stingy; skinflint".

> O meu tio é sovina: nunca paga um café a ninguém.
>
> *My uncle is stingy: he never buys anyone a coffee.*

Informal. The same form for a man and a woman.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

The origin of *sovina* is not settled; dictionaries offer several guesses and none is certain.
