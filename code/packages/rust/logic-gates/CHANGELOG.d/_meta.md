# Changelog

All notable changes to the `logic-gates` package will be documented in this file.

## Layout

This changelog is sharded: one file per entry in this directory, named
`NNNNN-SLUG-HEX8.md` (rank, uppercase slug, 8-hex digest). Rank order is
chronological; a new entry takes the next free rank. `_meta.md` is this entry point.
`00010-HISTORY-*.md` is the former monolithic `CHANGELOG.md`, moved unchanged.
