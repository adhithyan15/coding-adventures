## You'll want to know: কেরানি
<!-- hl-knowledge: introduces=[BN-LEX-C493-OPHIS493-02]; assesses=[] -->

**কেরানি** — *kerāni* — "a clerk".

> কেরানি ফাইলটা টেবিলে রাখল।
>
> *Kerāni phāilṭā ṭebile rākhlô.*
>
> The clerk put the file on the table.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**কেরানি** (*kerāni*) is probably from Sanskrit *karaṇa*, which Monier-Williams glosses as "a writer, a scribe"; how the ending arose is not settled.
