## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**occasione** ← Latin *occasio*, "an opportunity" — a learned borrowing. (EtymDB 2.1) The same Latin word, passed down by speech, became *cagione*, "a cause".
