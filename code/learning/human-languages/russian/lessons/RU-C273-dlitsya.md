## You'll want to know: длиться
<!-- hl-knowledge: introduces=[RU-LEX-C273-PROISKHODIT-03]; assesses=[] -->

**длиться** (*dlítsya*) — "to last".

> Фильм длился два часа.
>
> *Film dlílsya dva chasá.*
>
> The film lasted two hours.

Imperfective; perfective *продлиться* (*prodlítsya*). The time is in the accusative: *урок длится час*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*длиться* is built on *длина* "length", from the same Slavic root as *долгий* "long", Proto-Slavic *dĭlgŭ* (EtymDB).
