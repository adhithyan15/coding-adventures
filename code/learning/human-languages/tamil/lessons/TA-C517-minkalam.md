## You'll want to know: மின்கலம்
<!-- hl-knowledge: introduces=[TA-LEX-C517-MIN517-01]; assesses=[] -->

**மின்கலம்** — *miṉkalam* — "a battery".

> கடிகாரத்தின் மின்கலம் தீர்ந்துவிட்டது.
>
> *kaṭikārattiṉ miṉkalam tīrntuviṭṭatu.*
>
> The clock's battery has run down.

மின் "electric" + கலம் "a vessel": a vessel of electricity.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**மின்கலம்** (*miṉkalam*) is a modern native compound: மின் (*miṉ*), "lightning, electric" (DEDR 4876), and கலம் (*kalam*), "a vessel" (DEDR 1305).
