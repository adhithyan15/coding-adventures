## You'll want to know: la ricorrenza
<!-- hl-knowledge: introduces=[IT-LEX-C315-AUGURI-02]; assesses=[] -->

**la ricorrenza** — "the recurring occasion, the anniversary date".

> Il compleanno è una ricorrenza importante.
>
> *A birthday is an important occasion.*

Built on *ricorrere*, ‘to come round again’.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*ricorrenza* is built on *ricorrere* "to recur", from Latin *recurrere* "to run back" (Lewis & Short).
