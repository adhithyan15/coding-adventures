# ಡೀಸೆಲ್ (ḍīsel) — diesel

## You'll want to know: ಡೀಸೆಲ್
<!-- hl-knowledge: introduces=[KA-LEX-C448-INDHANA448-02]; assesses=[] -->

**ಡೀಸೆಲ್** — *ḍīsel* — "diesel".

> ಈ ಬಸ್ ಡೀಸೆಲ್ನಿಂದ ಓಡುತ್ತದೆ.
>
> *ī bas ḍīselninda ōḍuttade.*
>
> This bus runs on diesel.

ಪೆಟ್ರೋಲ್ and ಡೀಸೆಲ್ are sold side by side.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಡೀಸೆಲ್** (*ḍīsel*) is a loan from English *diesel*.
