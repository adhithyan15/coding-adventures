# ಪೀಡಿಸು (pīḍisu) — to pester; to torment

## You'll want to know: ಪೀಡಿಸು
<!-- hl-knowledge: introduces=[KA-LEX-C353-UYILU353-05]; assesses=[] -->

**ಪೀಡಿಸು** — *pīḍisu* — "to pester; to torment".

> ಮನೆಗಾಗಿ ಸಂಬಂಧಿಕರು ಅಜ್ಜಿಯನ್ನು ತುಂಬಾ ಪೀಡಿಸಿದರು.
>
> *manegāgi sambandhikaru ajjiyannu tumbā pīḍisidaru.*
>
> The relatives pestered Grandmother a lot for the house.

Past (I …): ಪೀಡಿಸಿದೆ, *pīḍiside*.

The person troubled takes -ಅನ್ನು. Illness too ಪೀಡಿಸು: ರೋಗ ಪೀಡಿಸಿತು.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಪೀಡಿಸು** (*pīḍisu*) is built on Sanskrit *pīḍā*, "pain, damage" (CDIAL 8227), from the root *pīḍ*, "to press, to hurt", with the Kannada verb ending -*isu*.

One more word for telling what happened.
