## You'll want to know: 病因
<!-- hl-knowledge: introduces=[ZH-LEX-C481-SERIOUS481-03]; assesses=[] -->

**病因** — *bìngyīn* — "cause of an illness".

> **牙医看了半天还没找到病因** *yáyī kàn le bàntiān hái méi zhǎo dào bìngyīn* — The dentist has been looking for ages and still hasn't found the cause.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**病因** (*bìngyīn*) is built from 病 'illness' and 因 'a cause', both inherited from Middle Chinese, *bjaengH* and *'jin* (Guangyun, in Baxter's transcription), which glosses the second 'to rely on' and 'a cause'.
