## You'll want to know: a cura
<!-- hl-knowledge: introduces=[PT-LEX-C488-CURA-03]; assesses=[] -->

**a cura** — "cure".

> Ainda não há cura para esta doença.
>
> *There is still no cure for this disease.*

Also a stay for health: *uma cura de águas*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*cura* is inherited from Latin *cūra* "care, concern" (EtymDB).
