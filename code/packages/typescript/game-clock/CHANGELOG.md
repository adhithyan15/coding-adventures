# Changelog

All notable changes to `@coding-adventures/game-clock` are documented here.

## [0.1.0] - 2026-11-18

### Added

- Initial TypeScript GAME10 API for the standard 60 Hz constructor, frequency constructor, clock
  constructor, state validator, and frame advance operation.
- Exact `bigint` `u64` arithmetic, bounded `number` `u32` checks, native semantic error variants,
  immutable inputs, and fresh frozen result records.
- Shared GAME10 v1 corpus consumer using the repository Python validator on original bytes,
  non-vacuity controls, seeded property and mutation campaigns, and a bounded SAT model comparison.
