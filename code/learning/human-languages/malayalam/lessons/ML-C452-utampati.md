# ഉടമ്പടി (uṭampaṭi) — a treaty; a pact

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C452-SAMADHANAM452-01, ML-LEX-C452-SAMADHANAM452-02] -->

[PAUSE 2s] Before the new one: say the Malayalam for to compromise, then the Malayalam for a settlement.

## You'll want to know: ഉടമ്പടി
<!-- hl-knowledge: introduces=[ML-LEX-C452-SAMADHANAM452-03]; assesses=[] -->

**ഉടമ്പടി** — *uṭampaṭi* — "a treaty; a pact".

> രണ്ട് രാജ്യങ്ങളും ഒരു ഉടമ്പടിയിൽ ഒപ്പുവെച്ചു.
>
> *raṇṭŭ rājyaṅṅaḷuṁ oru uṭampaṭiyil oppuveccu.*
>
> The two countries signed a treaty.

To sign one is ഉടമ്പടിയിൽ ഒപ്പുവെക്കുക.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ഉടമ്പടി** (*uṭampaṭi*) is native Dravidian: DEDR 945 lists Malayalam *uṭam-paṭi*, "agreement, contract", beside *uṭan*, "together with".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
