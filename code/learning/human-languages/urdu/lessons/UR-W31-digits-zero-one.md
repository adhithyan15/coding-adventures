# ۰ ۱ — two digits, and a direction that reverses

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[UR-SCRIPT-RTL-01, UR-PERFORMANCE-COUNT-ALOUD] -->

[PAUSE 2s] Which way does an Urdu line run? Count aloud to ten.

## Script — the shapes, and the direction
<!-- hl-knowledge: introduces=[UR-SCRIPT-DIGIT-ZERO, UR-SCRIPT-DIGIT-ONE, UR-SCRIPT-DIGITS-LTR]; assesses=[UR-SCRIPT-RTL-01, UR-LEX-EK, UR-LEX-DAS] -->

> **۰** — *sifr*, zero  **۱** — *ek*, one

Urdu has its own ten digit signs, and a price ticket, a bus number, a page
number and a telephone number in Pakistan are written in them. A reader who can
say **ek** and cannot read **۱** still cannot read a price.

**۰** is a **dot**, not a ring. Fix that first: a European eye reads a dot as a
decimal point, and Urdu's nine is the ring.

Now the part no earlier chapter of this book has had to say. **Numbers run left
to right, inside a line that runs right to left.** Ten is **۱۰** — one, then
zero, in the order English uses — while the words on either side of it move the
other way. The page changes direction at the number and changes back after it.
