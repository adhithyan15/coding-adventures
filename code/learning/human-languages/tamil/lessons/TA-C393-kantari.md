# கண்டறி (kaṇṭaṟi) — to find out; to discover

## You'll want to know: கண்டறி
<!-- hl-knowledge: introduces=[TA-LEX-C393-ARIKKAI393-03]; assesses=[] -->

**கண்டறி** — *kaṇṭaṟi* — "to find out; to discover".

> காரணத்தைக் கண்டறிந்தால் தீர்வு கிடைக்கும்.
>
> *kāraṇattaik kaṇṭaṟintāl tīrvu kiṭaikkum.*
>
> If we find out the cause, we will find a solution.

Past (I …): கண்டறிந்தேன், *kaṇṭaṟintēṉ*.

What is found takes -ஐ. A more formal word than கண்டுபிடி.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**கண்டறி** (*kaṇṭaṟi*) is native: *kaṇṭu*, "having seen", from *kāṇ* (DEDR 1443), and *aṟi*, "to know" (DEDR 314): to see and come to know.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
