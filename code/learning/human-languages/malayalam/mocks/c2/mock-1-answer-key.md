## Writing

Task 1 must mediate all three sources for the named residents' assembly, distinguish
measurement from legitimacy, preserve each source's limit, and produce an independent
220–280-word Malayalam synthesis. Task 2 must sustain a 420–520-word literary-public
essay whose register contrasts with task 1, analyse rather than decorate the governing
metaphor, answer a credible objection, and reach a qualified conclusion.

## Speaking

Allow keyword and relationship-diagram notes only. The presentation must mediate all
three positions and make disagreement usable for the named committee. Negotiation must
show stakeholder reframing, implicit-resistance repair, and a conditional joint decision.
Use all six follow-ups, naming the second audience in each, to elicit defence,
qualification, and genuine register change. Score the complete recording against the
shared criteria.
