## You'll want to know: tan pronto como
<!-- hl-knowledge: introduces=[ES-LEX-C536-MIENTRAS-05]; assesses=[] -->

**tan pronto como** — "the moment that, as soon as".

> Tan pronto como sonó la alarma, salimos.
>
> *As soon as the alarm went off, we went out.*

The same as *en cuanto*, a little more formal.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*tan pronto como* is built on *tan*, from Latin *tam* 'so', and *pronto*, which comes from Latin *promptus* 'brought forth, ready' (EtymDB).
