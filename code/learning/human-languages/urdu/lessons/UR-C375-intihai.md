## You'll want to know: انتہائی
<!-- hl-knowledge: introduces=[UR-LEX-C375-BAHUT375-02]; assesses=[] -->

**انتہائی** — *intihāī* — "extreme; extremely".

> اگر مریض کی حالت انتہائی نازک ہے تو ہسپتال جائیے۔
>
> *agar marīz kī hālat intihāī nāzuk hai to haspatāl jāiye.*
>
> If the patient is in a very bad way, go to the hospital.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**انتہائی** (*intihāī*) is built on *intihā*, usually traced, through Persian, to Arabic *intihāʾ*, "the end, the furthest point", with the ending *-ī*: as far as a thing can go.
