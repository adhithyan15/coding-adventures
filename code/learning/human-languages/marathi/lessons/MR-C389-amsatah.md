## You'll want to know: अंशतः
<!-- hl-knowledge: introduces=[MR-LEX-C389-PRAMANE389-01]; assesses=[] -->

**अंशतः** — *aṁśataḥ* — "partly".

> तुमचं म्हणणं अंशतः खरं आहे.
>
> *tumcaṁ mhaṇṇaṁ aṁśataḥ kharaṁ āhe.*
>
> What you say is partly true.

Formal; अंश, a part.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**अंशतः** (*aṁśataḥ*) is a learned adverb built from Sanskrit *aṁśa*, "share, part" (CDIAL 2), with the ending *-taḥ*, "by, in".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->
