# હકીકત (hakīkat) — a fact

## You'll want to know: હકીકત
<!-- hl-knowledge: introduces=[GU-LEX-C351-HAKIKAT351-01]; assesses=[] -->

**હકીકત** — *hakīkat* — "a fact".

> આ વાર્તા નથી, હકીકત છે.
>
> *ā vārtā nathī, hakīkat che.*
>
> This isn't a story; it's a fact.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**હકીકત** (*hakīkat*) is usually traced to Arabic *ḥaqīqa*, "truth, reality", through Persian.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
