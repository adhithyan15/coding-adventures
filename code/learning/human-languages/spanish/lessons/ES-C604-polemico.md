## You'll want to know: polémico
<!-- hl-knowledge: introduces=[ES-LEX-C604-PROTESTA-03]; assesses=[] -->

**polémico** — "controversial".

> Es un tema muy polémico.
>
> *It is a very controversial subject.*

*La polémica* — the controversy.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*polémico* is a learned word usually traced to Greek *polemikos* 'warlike', built on *polemos* 'war', probably through French *polémique*; EtymDB does not list it.
