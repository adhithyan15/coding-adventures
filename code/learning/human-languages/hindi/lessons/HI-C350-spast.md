## You'll want to know: स्पष्ट
<!-- hl-knowledge: introduces=[HI-LEX-C350-MISAAL350-04]; assesses=[] -->

**स्पष्ट** — *spaṣṭ* — "clear, explicit".

> नियम बिलकुल स्पष्ट है।
>
> *niyam bilkul spaṣṭ hai.*
>
> This rule is perfectly clear.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**स्पष्ट** (*spaṣṭ*) is a tatsama, borrowed from Sanskrit *spaṣṭa*, "plainly seen, evident" (Monier-Williams).

## What you've built

One more word for giving reasons and opinions.
