- **GU-C07-hovun** gains `sanskrit-bhavati`, the slug Bengali, Hindi, Marathi, Punjabi and Urdu already use for *bhavati*, so *hovũ* joins their cousin panels. `sanskrit-akseti` stays: the lesson uses it for **છે** *chhe*, the verb of dwelling it takes apart, not for *bhavati*.
