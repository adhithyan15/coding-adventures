## 0.1.0

- Initial Java `test-bootstrap` package (spec VER05e, PT-JAVA-PBT).
- `prng`: `SplitMix64` on `long` with unsigned bounded draws (rejection
  threshold `(2^64 - n) mod n` via `Long.remainderUnsigned`), `boundedBig`
  k-word rejection for spans above 2^64, `fnv1a64`, `subSeed` (VER05 section 2.3,
  with the final scramble). `bounded(1)` consumes one stream word.
- `pbt`: generator algebra (`Gens`), integrated shrinkers with exact pbt-v1
  step counts, the honest runner with the closed failure vocabulary, CI
  redaction that fails closed, and `Corpus`, the strict pbt-v1 corpus runner.
- `corpusjson`: a hand-written strict JSON reader (duplicate keys, trailing data,
  depth and size caps), strict value decoding, kind-sensitive equality and
  bounded rendering.
- `tfv`: strict TFV v1 validator so `corpus_reject` cases are checked by a real
  parser.
- Tests replay all 25 committed pbt-v1 cases, include per-case negative controls
  (every case corrupted in every way its op allows, each required to fail and
  name that case), engine sabotage hooks, a forced rejection-branch test, and
  CWE-400 caps. JaCoCo gate: 95% line coverage in `check`.
