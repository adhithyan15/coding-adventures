# ۷ ۸ ۹ — a mirror pair, and the ring

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[FA-SCRIPT-DIGIT-FOUR, FA-SCRIPT-DIGIT-FIVE, FA-SCRIPT-DIGIT-SIX] -->

[PAUSE 2s] Write **۴**, **۵**, **۶** — the three Arabic draws differently.

## Script — the shapes
<!-- hl-knowledge: introduces=[FA-SCRIPT-DIGIT-SEVEN, FA-SCRIPT-DIGIT-EIGHT, FA-SCRIPT-DIGIT-NINE]; assesses=[FA-LEX-HAFT, FA-LEX-HASHT, FA-LEX-NOH, FA-SCRIPT-DIGIT-ZERO] -->

> **۷** — *haft*, seven  **۸** — *hasht*, eight  **۹** — *noh*, nine

**۷** and **۸** are mirror images of each other, one opening upward and one
downward. Write them as a pair, every time, and the mirror stops being a
problem — the same trick that worked on **۲** and **۳**.

**۹** is a **ring** with a tail, and this is where a dot-shaped zero pays off.
Had **۰** been a ring too, the page would carry two rings and no way to
separate them.

Ten signs, four lessons. The set is closed.
