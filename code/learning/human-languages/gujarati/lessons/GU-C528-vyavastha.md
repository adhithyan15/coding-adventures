## You'll want to know: વ્યવસ્થા
<!-- hl-knowledge: introduces=[GU-LEX-C528-YOJVU528-03]; assesses=[] -->

**વ્યવસ્થા** — *vyavasthā* — "an arrangement".

> જો મહેમાનો વધારે હશે તો આપણે જમવાની વ્યવસ્થા બદલવી પડશે.
>
> *jo mahemāno vadhāre haśe to āpaṇe jamvānī vyavasthā badalvī paḍśe.*
>
> If there are more guests, we will have to change the dinner arrangements.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**વ્યવસ્થા** (*vyavasthā*) is a tatsama, from Sanskrit *vy-ava-sthā*, "to stand apart, to be settled" (Monier-Williams): things set each in its place.
