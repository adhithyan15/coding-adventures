## You'll want to know: আগেই
<!-- hl-knowledge: introduces=[BN-LEX-C145-ATIT145-02]; assesses=[] -->

**আগেই** — *āgei* — "already". It is **আগে**, "before", with the emphatic **-ই**: **আমি আগেই খেয়েছি** — *āmi āgei kheyechhi* — "I have already eaten."
