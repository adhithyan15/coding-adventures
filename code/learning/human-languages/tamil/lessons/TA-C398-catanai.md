## You'll want to know: சாதனை
<!-- hl-knowledge: introduces=[TA-LEX-C398-POKKU398-03]; assesses=[] -->

**சாதனை** — *cātaṉai* — "an achievement; a record".

> இந்த முறை வென்றால் அவள் புதிய சாதனை படைப்பாள்.
>
> *inta muṟai veṉṟāl avaḷ putiya cātaṉai paṭaippāḷ.*
>
> If she wins this time, she will set a new record.

சாதனை படை, to set a record; சாதனையாளர், an achiever.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**சாதனை** (*cātaṉai*) is borrowed from Sanskrit *sādhana*, "furthering, accomplishing, completion" (CDIAL 13334), with the Tamil ending -ஐ.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
