# ट — the curled *t* in flatbread

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MW-LEX-ROTI-01, MW-PERFORMANCE-TRANSPORT-THREE-FOUR-SKILL-01, MW-SCRIPT-HAATH-01] -->

[PAUSE 20s] Say flatbread, recall the three-word transport payoff, then write
hand.

## Script — one sign
<!-- hl-knowledge: introduces=[MW-SCRIPT-TTA-01]; assesses=[] -->

> **ट** — *ṭa*

A single closed loop hanging under the headline. Set it beside the **ठ** of
**ठेला**: **ठ** carries a second inner ring and a puff of breath, **ट** has
neither.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-TTA-01, MW-SCRIPT-TTHA-01] -->
<!-- hl-writing-stage: observe-trace -->

Trace **ट** once. Copy it once. Write **ठ** beside it and say which one has the
extra ring. Cover both, wait five seconds, and write **ट** from the curled
sound cue.
