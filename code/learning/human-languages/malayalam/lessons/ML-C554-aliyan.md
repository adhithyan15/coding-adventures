# അളിയൻ (aḷiyan) — a brother-in-law

## You'll want to know: അളിയൻ
<!-- hl-knowledge: introduces=[ML-LEX-C554-MATAPITA554-03]; assesses=[] -->

**അളിയൻ** — *aḷiyan* — "a brother-in-law".

> എന്റെ അളിയൻ ഒരു എഞ്ചിനീയറാണ്.
>
> *enṟe aḷiyan oru eñcinīyaṟāṇŭ.*
>
> My brother-in-law is an engineer.

A wife's brother or a sister's husband.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**അളിയൻ** (*aḷiyan*) is native Dravidian: DEDR 2410 gives it as a wife's brother or a sister's husband (DEDR 2410).
