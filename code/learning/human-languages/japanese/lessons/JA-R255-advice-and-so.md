# Review — advice, and so

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[JA-GRAMMAR-C255-SHOULD-01, JA-LEX-C255-DAKARA-01] -->

[PAUSE 2s] Say "you had better rest". (*yasunda hō ga ii desu*.) Then "so I won't go", to a friend. (*dakara, ikimasen*.)

[PAUSE 2s each]
- [YOU SAY: You had better take some medicine.]
- [YOU SAY: You had better not drink cold water.]
- [YOU SAY: It is raining. So I won't go. — to a friend]
- [YOU SAY: The train stopped. And so I was late.]
- [YOU SAY: I think you had better go to the hospital.]
- [YOU SAY: I asked my teacher's opinion.]
