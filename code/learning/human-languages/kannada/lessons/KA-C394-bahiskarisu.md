# ಬಹಿಷ್ಕರಿಸು (bahiṣkarisu) — to boycott

## You'll want to know: ಬಹಿಷ್ಕರಿಸು
<!-- hl-knowledge: introduces=[KA-LEX-C394-RAJAKIYA394-04]; assesses=[] -->

**ಬಹಿಷ್ಕರಿಸು** — *bahiṣkarisu* — "to boycott".

> ಕೆಲಸಗಾರರು ಸಭೆಯನ್ನು ಬಹಿಷ್ಕರಿಸಿದರು.
>
> *kelasagāraru sabheyannu bahiṣkarisidaru.*
>
> The workers boycotted the meeting.

Past (I …): ಬಹಿಷ್ಕರಿಸಿದೆ, *bahiṣkariside*.

ಬಹಿಷ್ಕಾರ, a boycott.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಬಹಿಷ್ಕರಿಸು** (*bahiṣkarisu*) is built on Sanskrit *bahiṣkāra*, "expulsion, removal" (Monier-Williams), with the Kannada verb ending -*isu*.
