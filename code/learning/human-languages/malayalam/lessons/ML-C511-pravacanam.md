# പ്രവചനം (pravacanaṁ) — a forecast; a prediction

## You'll want to know: പ്രവചനം
<!-- hl-knowledge: introduces=[ML-LEX-C511-PRAVACANAM511-01]; assesses=[] -->

**പ്രവചനം** — *pravacanaṁ* — "a forecast; a prediction".

> നാളെ കനത്ത മഴ ഉണ്ടാകുമെന്നാണ് പ്രവചനം.
>
> *nāḷe kanatta maḻa uṇṭākumennāṇŭ pravacanaṁ.*
>
> The forecast is that there will be heavy rain tomorrow.

A weather forecast is a കാലാവസ്ഥാ പ്രവചനം.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**പ്രവചനം** (*pravacanaṁ*) is borrowed from Sanskrit *pravacana*, "speaking out, announcement" (Monier-Williams).
