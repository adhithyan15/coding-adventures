## You'll want to know: consumir
<!-- hl-knowledge: introduces=[ES-LEX-C607-AMBIENTE-03]; assesses=[] -->

**consumir** — "to consume, to use".

> Este coche consume poca gasolina.
>
> *This car uses little petrol.*

Regular -ir verb.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*consumir* is a learned borrowing from Latin *consumere* 'to use up', built from *con* and *sumere* 'to take' (EtymDB).
