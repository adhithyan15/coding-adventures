## You'll want to know: discriminer
<!-- hl-knowledge: introduces=[FR-LEX-C365-PAUVRETE-04]; assesses=[] -->

**discriminer** — "to discriminate (against)".

> Cette entreprise discrimine les femmes.
>
> *This company discriminates against women.*

*Être discriminé* — to be discriminated against.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*discriminer* is a learned borrowing from Latin *discrīmināre* "to divide, to separate" (Lewis & Short), from *discrīmen* "a dividing line", built on *cernere* "to separate".
