# பட்டினி (paṭṭiṉi) — starvation; going hungry

## You'll want to know: பட்டினி
<!-- hl-knowledge: introduces=[TA-LEX-C488-EDAI488-05]; assesses=[] -->

**பட்டினி** — *paṭṭiṉi* — "starvation; going hungry".

> வறட்சியால் பல குடும்பங்கள் பட்டினி கிடந்தன.
>
> *vaṟaṭciyāl pala kuṭumpaṅkaḷ paṭṭiṉi kiṭantaṉa.*
>
> Because of the drought many families went hungry.

பட்டினி கிட, to go without food.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**பட்டினி** (*paṭṭiṉi*) is native Dravidian (DEDR 3872), for fasting and starvation alike.
