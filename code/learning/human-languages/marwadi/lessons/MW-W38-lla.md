## Script — a second l
<!-- hl-knowledge: introduces=[MW-SCRIPT-LLA-01]; assesses=[MW-SCRIPT-LA-01] -->

> **ळ** — *ḷa* — the retroflex l

**ल** has been in the hand since chapter 7. **ळ** is a second l made with the
tongue curled back to the roof of the mouth, and it is a real difference in
Marwari, not a spelling variant.

It is worth knowing whose letter this is. Standard Hindi has no **ळ**; Marwari,
Marathi, Gujarati, Rajasthani more widely and the southern languages all do. A
page with **ळ** on it is announcing that it is not Hindi.

Sixteen is the number that needs it.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-LLA-01, MW-SCRIPT-LA-01] -->
<!-- hl-writing-stage: observe-trace -->

Trace **ळ** three times. Write **ल** beside it and say which one curls the
tongue back. Say both aloud twice, listening for the difference rather than
looking for it.
