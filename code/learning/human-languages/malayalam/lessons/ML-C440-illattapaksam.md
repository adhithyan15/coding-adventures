# ഇല്ലാത്തപക്ഷം (illāttapakṣaṁ) — if not; failing that

## You'll want to know: ഇല്ലാത്തപക്ഷം
<!-- hl-knowledge: introduces=[ML-LEX-C440-VYAVASTHA440-04]; assesses=[] -->

**ഇല്ലാത്തപക്ഷം** — *illāttapakṣaṁ* — "if not; failing that".

> ഫീസ് ഇന്ന് അടയ്ക്കണം, ഇല്ലാത്തപക്ഷം പേര് വെട്ടും.
>
> *phīsŭ innŭ aṭaykkaṇaṁ, illāttapakṣaṁ pērŭ veṭṭuṁ.*
>
> The fee must be paid today; if not, the name will be struck off.

A formal partner of ഇല്ലെങ്കിൽ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ഇല്ലാത്തപക്ഷം** (*illāttapakṣaṁ*) is a Malayalam compound: ഇല്ലാത്ത, "that is not", native Dravidian (DEDR 2559), and പക്ഷം, "a side; a case", from Sanskrit *pakṣa* (CDIAL 7627): in the case that it is not.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
