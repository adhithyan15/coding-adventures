## You'll want to know: बिनती
<!-- hl-knowledge: introduces=[MW-LEX-C198-OFFICE198-04]; assesses=[] -->

**बिनती** — *bintī* — "a request".

> म्हारी बिनती सुणो।
>
> *mhārī bintī suṇo.*
>
> Please hear my request.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**बिनती** (*bintī*) is inherited from Sanskrit *vijñapti*, "a request to a superior"; CDIAL lists Old Marwari *bīnatī*, "request" (CDIAL 11706).
