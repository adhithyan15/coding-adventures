## You'll want to know: قافية
<!-- hl-knowledge: introduces=[AR-LEX-C545-SHIR545-02]; assesses=[] -->

**قافية** — *qāfiya* — "a rhyme".

> كل بيت في القصيدة له نفس القافية.
>
> *kull bayt fī al-qaṣīda lahu nafs al-qāfiya.*
>
> Every line in the poem has the same rhyme.

بيت is a line of verse as well as a house.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**قافية** (*qāfiya*) is built on the native Arabic root *q-f-w*, "to follow" (Lane). The qāfiya is the end of the line that follows the same sound each time.
