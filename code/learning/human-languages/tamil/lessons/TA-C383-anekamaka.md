# அநேகமாக (anēkamāka) — probably

## You'll want to know: அநேகமாக
<!-- hl-knowledge: introduces=[TA-LEX-C383-CATTIYAM383-03]; assesses=[] -->

**அநேகமாக** — *anēkamāka* — "probably".

> அநேகமாக அவர் நாளை வருவார்.
>
> *anēkamāka avar nāḷai varuvār.*
>
> He will probably come tomorrow.

அநேக, many + -ஆக: in most ways, probably.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**அநேகமாக** (*anēkamāka*) is built on Sanskrit *aneka*, "not one, many" (Monier-Williams), with the adverb ending -ஆக: "in many ways", so "most likely".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
