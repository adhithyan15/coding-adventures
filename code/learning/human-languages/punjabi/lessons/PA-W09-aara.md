# ਆ — a letter you can already build

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-SCRIPT-INDEPENDENT-A-01, PA-SCRIPT-AA-MATRA-01] -->

[PAUSE 2s] Write the standalone **ਅ** once. Then write the upright stroke **ਾ**
that lengthens a vowel — the one that turned **ਹ** into **ਹਾ**.

## Script — one letter
<!-- hl-knowledge: introduces=[PA-SCRIPT-INDEPENDENT-AA-01]; assesses=[PA-SCRIPT-INDEPENDENT-A-01, PA-SCRIPT-AA-MATRA-01] -->

Put the two together and you have **ਆ**, the standalone long *ā*. Trace it
twice. This is the shape a word starting with *ā-* opens on, where **ਅ** opens a
word starting with short *a-*.

Nothing new has to be memorised here: two shapes you already own, standing side
by side and read as one letter.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-SCRIPT-INDEPENDENT-AA-01, PA-SCRIPT-INDEPENDENT-A-01] -->
<!-- hl-writing-stage: observe-trace -->

Cover the models. Write **ਅ**, then **ਆ**. Compare only the added upright.
