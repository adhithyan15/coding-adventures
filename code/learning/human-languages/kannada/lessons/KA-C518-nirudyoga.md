# ನಿರುದ್ಯೋಗ (nirudyōga) — unemployment

## You'll want to know: ನಿರುದ್ಯೋಗ
<!-- hl-knowledge: introduces=[KA-LEX-C518-NEMAKA518-03]; assesses=[] -->

**ನಿರುದ್ಯೋಗ** — *nirudyōga* — "unemployment".

> ಹಳ್ಳಿಗಳಲ್ಲಿ ನಿರುದ್ಯೋಗ ದೊಡ್ಡ ಸಮಸ್ಯೆ.
>
> *haḷḷigaḷalli nirudyōga doḍḍa samasye.*
>
> Unemployment is a big problem in the villages.

ನಿರ್, without + ಉದ್ಯೋಗ, a job. ನಿರುದ್ಯೋಗಿ, an unemployed person.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ನಿರುದ್ಯೋಗ** (*nirudyōga*) is a learned compound built from Sanskrit *nir-*, "without", and *udyoga*, "undertaking, exertion" (Monier-Williams).
