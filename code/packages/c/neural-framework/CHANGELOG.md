# Changelog

## 0.1.0 (NN48 in progress)

- Add native C17 owned dense network construction, deterministic initialization,
  prediction, full backpropagation traces, atomic candidate SGD and exact fit.
- Add copied inspection/snapshots and a strict V1 loader using bounded-json's
  public typed views; emit owned finite locale-independent JSON text.
- Add strict shared ISO BUILD fronts, paper/shared schema/numerical/ownership/
  boundary/allocation-fault tests, an actual installed static-library consumer,
  bounded native command and shell-free full-state baseline/resume validator.
- Local library, command and validator coverage exceed their targets. Final
  BUILD/CI wiring, review, publication and exact-head repository CI are pending.
- Native C is independent training, not a Rust binding or six-native exchange.
