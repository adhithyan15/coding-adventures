> ई

The same job as the last lesson, for the vowel you learned two lessons ago: this is
**ī** standing on its own, for a word that begins with it.

The pattern is now visible and it is worth naming, because it repeats for every
vowel in the script:

> every vowel has **two** forms — one **independent**, for the start of a word, and
> one **mātrā**, for riding on a consonant.

That is not two alphabets. It is one alphabet with a positional rule, and you have
now met it three times.
