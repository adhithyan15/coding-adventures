# ఆర్థిక (ārthika) — economic; financial

## You'll want to know: ఆర్థిక
<!-- hl-knowledge: introduces=[TE-LEX-C405-ARTHIKA405-01]; assesses=[] -->

**ఆర్థిక** — *ārthika* — "economic; financial".

> దేశం ఆర్థిక సమస్యల్లో ఉంది.
>
> *dēśaṁ ārthika samasyallō undi.*
>
> The country is in economic trouble.

Before a noun: ఆర్థిక సహాయం, financial help. ఆర్థికంగా, financially.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ఆర్థిక** (*ārthika*) is borrowed from Sanskrit *ārthika*, "significant; wise; rich" (Monier-Williams), from *artha*, "aim, wealth"; Telugu uses it for money matters.
