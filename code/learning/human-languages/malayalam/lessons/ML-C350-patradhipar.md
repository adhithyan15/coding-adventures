# പത്രാധിപർ (patrādhipar) — an editor

## You'll want to know: പത്രാധിപർ
<!-- hl-knowledge: introduces=[ML-LEX-C350-PATRAM350-02]; assesses=[] -->

**പത്രാധിപർ** — *patrādhipar* — "an editor".

> പത്രാധിപർ ലേഖകന്റെ റിപ്പോർട്ട് വായിച്ചു.
>
> *patrādhipar lēkhakanṟe ṟippōrṭṭŭ vāyiccu.*
>
> The editor read the correspondent's report.

The -ർ ending marks respect, so one editor is പത്രാധിപർ; the plainer പത്രാധിപൻ is heard too.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**പത്രാധിപർ** (*patrādhipar*) is built from two Sanskrit words: *patra*, "a leaf, a written sheet", which gave പത്രം (*patraṁ*), "a newspaper", and *adhipa*, "a ruler, a commander" (Monier-Williams). The editor is the chief of the paper.
