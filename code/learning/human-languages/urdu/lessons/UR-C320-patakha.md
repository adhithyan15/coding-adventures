## You'll want to know: پٹاخا
<!-- hl-knowledge: introduces=[UR-LEX-C320-ATISHBAZI320-02]; assesses=[] -->

**پٹاخا** — *paṭākhā* — "a firecracker".

> بچوں نے گلی میں پٹاخے چلائے۔
>
> *bachchoṅ ne galī meṅ paṭākhe chalāe.*
>
> The children set off firecrackers in the lane.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**پٹاخا** (*paṭākhā*) No dictionary we use records an older form, so its history is not settled; it is probably imitative of the crack it makes.

## What you've built

One more word for telling what happened.
