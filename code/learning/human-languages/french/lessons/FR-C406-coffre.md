## You'll want to know: le coffre
<!-- hl-knowledge: introduces=[FR-LEX-C406-CARROSSERIE-04]; assesses=[] -->

**le coffre** — "the boot (of a car); the chest".

> Les valises sont dans le coffre.
>
> *The suitcases are in the boot.*

*Un coffre* is also a big wooden box.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*coffre* is inherited from Latin *cophinus* 'basket', which came from Greek *kóphinos* (EtymDB).
