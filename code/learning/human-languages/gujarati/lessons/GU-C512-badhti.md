## You'll want to know: બઢતી
<!-- hl-knowledge: introduces=[GU-LEX-C512-NOKRI512-05]; assesses=[] -->

**બઢતી** — *baḍhtī* — "a promotion (at work)".

> અરુણને આ વરસે બઢતી મળી.
>
> *Aruṇne ā varse baḍhtī maḷī.*
>
> Arun got a promotion this year.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**બઢતી** (*baḍhtī*) is probably borrowed from Hindi *baṛhtī*, "an increase", built on *baṛhnā*, "to increase", which CDIAL lists under Sanskrit *várdhatē*, "grows" (CDIAL 11376). CDIAL gives Gujarati's own verb from the same root, **વધવું**, there too.
