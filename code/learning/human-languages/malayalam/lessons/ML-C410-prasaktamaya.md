## You'll want to know: പ്രസക്തമായ
<!-- hl-knowledge: introduces=[ML-LEX-C410-SUCANA410-04]; assesses=[] -->

**പ്രസക്തമായ** — *prasaktamāya* — "relevant".

> അത് വളരെ പ്രസക്തമായ ഒരു ചോദ്യമാണ്.
>
> *atŭ vaḷare prasaktamāya oru cōdyamāṇŭ.*
>
> That is a very relevant question.

The noun is പ്രസക്തി, relevance.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**പ്രസക്തമായ** (*prasaktamāya*) is built from Sanskrit *prasakta*, "attached to, connected with" (Monier-Williams), with the adjective ending -ആയ: what is relevant is attached to the matter in hand.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->
