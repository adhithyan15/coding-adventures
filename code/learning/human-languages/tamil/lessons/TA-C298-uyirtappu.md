# உயிர்தப்பு (uyirtappu) — to escape alive

## You'll want to know: உயிர்தப்பு
<!-- hl-knowledge: introduces=[TA-LEX-C298-VIBATHU298-04]; assesses=[] -->

**உயிர்தப்பு** — *uyirtappu* — "to escape alive".

> அதிர்ஷ்டவசமாக, எல்லோரும் உயிர்தப்பினார்கள்.
>
> *atirṣṭavacamāka, ellōrum uyirtappiṉārkaḷ.*
>
> Luckily, everyone escaped alive.

Past (I …): உயிர்தப்பினேன், *uyirtappiṉēṉ*.

Built from உயிர், life, and தப்பு, to escape.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**உயிர்தப்பு** (*uyirtappu*) is a Tamil compound built from உயிர், "life" (DEDR 645), and தப்பு, "to escape, be saved" (DEDR 3071).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
