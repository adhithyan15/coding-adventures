# ಶ್ಲಾಘಿಸು (ślāghisu) — to commend

## You'll want to know: ಶ್ಲಾಘಿಸು
<!-- hl-knowledge: introduces=[KA-LEX-C389-SHLAGHISU389-01]; assesses=[] -->

**ಶ್ಲಾಘಿಸು** — *ślāghisu* — "to commend".

> ಊರಿನ ಜನರು ಆ ಹುಡುಗನ ಧೈರ್ಯವನ್ನು ಶ್ಲಾಘಿಸಿದರು.
>
> *ūrina janaru ā huḍugana dhairyavannu ślāghisidaru.*
>
> The villagers commended the boy's courage.

Past (I …): ಶ್ಲಾಘಿಸಿದೆ, *ślāghiside*.

What is commended takes -ಅನ್ನು. ಶ್ಲಾಘನೀಯ, praiseworthy.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಶ್ಲಾಘಿಸು** (*ślāghisu*) is built on Sanskrit *ślāghā*, "boasting; praise" (CDIAL 12736), with the Kannada verb ending -*isu*.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
