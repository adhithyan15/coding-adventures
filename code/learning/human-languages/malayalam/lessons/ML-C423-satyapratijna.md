# സത്യപ്രതിജ്ഞ (satyapratijña) — an oath

[PAUSE 2s] Before the new one: say the Malayalam for to pass a law, then the Malayalam for to amend.

## You'll want to know: സത്യപ്രതിജ്ഞ
<!-- hl-knowledge: introduces=[ML-LEX-C423-NAYAM423-05]; assesses=[] -->

**സത്യപ്രതിജ്ഞ** — *satyapratijña* — "an oath".

> പുതിയ മന്ത്രിമാർ ഇന്ന് സത്യപ്രതിജ്ഞ ചെയ്തു.
>
> *putiya mantrimār innŭ satyapratijña ceytu.*
>
> The new ministers took the oath today.

To take an oath is സത്യപ്രതിജ്ഞ ചെയ്യുക.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**സത്യപ്രതിജ്ഞ** (*satyapratijña*) is built from Sanskrit *satya*, "true; truth" (CDIAL 13112), and *pratijñā*, "a promise" (CDIAL 8563): a promise of truth.
