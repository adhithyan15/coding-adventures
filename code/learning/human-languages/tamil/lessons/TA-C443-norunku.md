# நொறுங்கு (noṟuṅku) — to shatter; to be smashed

## You'll want to know: நொறுங்கு
<!-- hl-knowledge: introduces=[TA-LEX-C443-VIRISAL443-02]; assesses=[] -->

**நொறுங்கு** — *noṟuṅku* — "to shatter; to be smashed".

> கண்ணாடி கீழே விழுந்து நொறுங்கியது.
>
> *kaṇṇāṭi kīḻē viḻuntu noṟuṅkiyatu.*
>
> The glass fell down and shattered.

Past (it …): நொறுங்கியது, *noṟuṅkiyatu*.

நொறுக்கு is to smash something.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**நொறுங்கு** (*noṟuṅku*) is native Dravidian (DEDR 3728), "to be broken, crushed, smashed".
