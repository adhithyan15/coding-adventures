# আয়োজন (āyojôn) — preparations (for an event); the organising

## You'll want to know: আয়োজন
<!-- hl-knowledge: introduces=[BN-LEX-C378-AYOJON378-01]; assesses=[] -->

**আয়োজন** — *āyojôn* — "preparations (for an event); the organising".

> বিয়ের আয়োজন সময়মতো শেষ না হলে খুব ঝামেলা হবে।
>
> *biyer āyojôn sômôymôto shesh nā hôle khub jhāmelā hôbe.*
>
> If the wedding preparations aren't finished in time, there will be a lot of trouble.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**আয়োজন** (*āyojôn*) is Sanskrit *āyojana*, a joining or collecting (Monier-Williams). The Bengali sense, all the preparations and arrangements for an event, is not one the dictionary gives; it goes with করা: বিয়ের আয়োজন করা.
