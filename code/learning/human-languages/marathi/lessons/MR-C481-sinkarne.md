# शिंकरणे (śiṅkarṇe) — to blow one's nose

## You'll want to know: शिंकरणे
<!-- hl-knowledge: introduces=[MR-LEX-C481-SARDI481-04]; assesses=[] -->

**शिंकरणे** — *śiṅkarṇe* — "to blow one's nose".

> त्याने रुमालात नाक शिंकरलं.
>
> *tyāne rumālāt nāk śiṅkarlaṁ.*
>
> He blew his nose into a handkerchief.

Past, with -ने (he …): त्याने नाक शिंकरलं, *tyāne nāk śiṅkarlaṁ*.

The object is नाक: नाक शिंकरणे.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**शिंकरणे** (*śiṅkarṇe*) is a Marathi verb whose origin is not settled.
