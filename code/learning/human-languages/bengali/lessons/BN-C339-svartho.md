## You'll want to know: স্বার্থ
<!-- hl-knowledge: introduces=[BN-LEX-C339-ODHIKAR339-03]; assesses=[] -->

**স্বার্থ** — *svārthô* — "self-interest; one's own interest".

> এই কাজে তার কোনো স্বার্থ নেই।
>
> *ei kāje tār kono svārthô nei.*
>
> He has no personal interest in this work.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**স্বার্থ** (*svārthô*) is Sanskrit *svārtha*, *sva* 'own' with *artha* 'aim, gain': one's own advantage (Monier-Williams).
