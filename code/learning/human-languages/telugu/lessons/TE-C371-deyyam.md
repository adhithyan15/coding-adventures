# దెయ్యం (deyyaṁ) — a ghost

## You'll want to know: దెయ్యం
<!-- hl-knowledge: introduces=[TE-LEX-C371-MAYA371-03]; assesses=[] -->

**దెయ్యం** — *deyyaṁ* — "a ghost".

> ఆ పాత ఇంట్లో దెయ్యం ఉందని పిల్లలు అనుకుంటారు.
>
> *ā pāta iṇṭlō deyyaṁ undani pillalu anukuṇṭāru.*
>
> The children think there is a ghost in that old house.

Plural: దెయ్యాలు, *deyyālu*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**దెయ్యం** (*deyyaṁ*) is usually traced to Sanskrit *daitya*, "a demon" (Monier-Williams).
