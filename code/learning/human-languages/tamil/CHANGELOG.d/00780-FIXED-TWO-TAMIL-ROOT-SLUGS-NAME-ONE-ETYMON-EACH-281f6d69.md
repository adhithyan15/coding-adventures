## Fixed — two Tamil root slugs name one etymon each

- **TA-C118-pattiram** moves from `sanskrit-patra` to `sanskrit-patra-vessel`. *Pāttiram* is *pātra* "vessel" (CDIAL 8055); `sanskrit-patra` is *pattra* "leaf" (CDIAL 7733).
- **TA-C240-caturamana** moves from `sanskrit-catura` to `sanskrit-caturasra`, the slug Telugu *caturasraṁ* uses. Its hook derives *caturam* from *caturasra* "four-cornered" (CDIAL 4598), not *catura*.
