# ಸೌಹಾರ್ದ (sauhārda) — goodwill; harmony

## You'll want to know: ಸೌಹಾರ್ದ
<!-- hl-knowledge: introduces=[KA-LEX-C404-SADASYA404-05]; assesses=[] -->

**ಸೌಹಾರ್ದ** — *sauhārda* — "goodwill; harmony".

> ಎರಡು ಊರುಗಳ ನಡುವೆ ಸೌಹಾರ್ದ ಇದೆ.
>
> *eraḍu ūrugaḷa naḍuve sauhārda ide.*
>
> There is goodwill between the two towns.

ಸೌಹಾರ್ದದಿಂದ, amicably.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಸೌಹಾರ್ದ** (*sauhārda*) is borrowed from Sanskrit *sauhārda*, "good-heartedness, friendship" (Monier-Williams), from *suhṛd*, "a friend".
