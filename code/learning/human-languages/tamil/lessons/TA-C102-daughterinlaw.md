# மருமகள் (marumakaḷ) — a daughter-in-law

## You'll want to know: மருமகள்
<!-- hl-knowledge: introduces=[TA-LEX-C102-INLAWS-04]; assesses=[] -->

**மருமகள்** (*marumakaḷ*) — "a daughter-in-law".

**மகள்** is "daughter"; **மரு-** marks the relation by marriage.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

A daughter by marriage.
