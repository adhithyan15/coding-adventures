# Marwadi pre-A1 mock 1 — confidential examiner and recording script

Do not give this file to the learner. Keep the answer key and rubric confidential
too. A qualified
Marwadi speaker must check the forms and record every named audio file before
use. Document the pronunciation variety and use it consistently. Speak at
70–90 words per minute without translation, spelling, or coaching. Play each
file twice with an eight-second answer pause after each play. A technical
restart replaces the affected play; it does not authorize a third play.

Measure each audio file from start to end, including natural silence. Pad short
stimuli with silence rather than stretching or repeating speech. Reject and
rerecord any file outside its part's duration band. Give only the current skill
packet; collect Reading before Listening, Listening before Writing, and Writing
before Speaking. Never return a collected packet.

### Part 3 — personal details

Each file must last 2–8 seconds, including silence padding.

11. `mock-1-l11`: **म्हारो नाम राम है।**
12. `mock-1-l12`: **नाम: राम।**
13. `mock-1-l13`: **परिवार: मां।**
14. `mock-1-l14`: **घर: गांव।**

The last three are short spoken form-field labels and values, not invented
conversation. A qualified speaker must confirm their natural administration
before the form is used with learners.

## Writing prompt master

Show each delayed-recall card for ten seconds and remove it completely before
the learner writes. Record and play each dictation file under the listening

1. Card W1: **म्हारो**
2. Card W2: **बाप**
3. `mock-1-w03`: **पाणी**
4. `mock-1-w04`: **चाय**
5. `mock-1-w05`: **रोटी**
6. `mock-1-w06`: **मां**

## Speaking — live interlocutor

Use 2–8 seconds for each prompt and allow 2–15 seconds for each response.
The interlocutor may repeat a prompt once slowly, without giving an answer.

1. Say **राम-राम सा।** The learner returns an appropriate greeting.
2. Ask **थारो नाम कांई है?** The learner supplies a chosen name.
3. Ask **आप कैसो हो?** The learner answers how they are.
4. In the support language ask for one family member in Marwadi.
5. In the support language ask for one familiar kind of place where the learner
   lives, in Marwadi.
6. Show an unlabeled picture of tea. In the support language ask the learner to
   request it in Marwadi. **चाय लावो** is one acceptable response; never show or
   say that model to the learner.

Record the speaking paper for independent scoring. This script supplies a
structural form only; it does not establish examiner calibration or readiness.
