## You'll want to know: أنفق
<!-- hl-knowledge: introduces=[AR-LEX-C457-TAKHFID457-05]; assesses=[] -->

**أنفق** — *anfaqa* — "to spend money".

> أنفقنا كل مالنا في السوق.
>
> *anfaqnā kulla mālinā fī as-sūq.*
>
> We spent all our money at the market.

Present: ينفق, *yunfiq*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**أنفق** (*anfaqa*) is built on the native Arabic root *n-f-q*, "to pass away, to run out" (Lane). It is Form IV, "to make money run out"; Lane gives *nafaq*, "a tunnel", on the same root.
