# ശിലാലിഖിതം (śilālikhitaṁ) — a stone inscription

## You'll want to know: ശിലാലിഖിതം
<!-- hl-knowledge: introduces=[ML-LEX-C393-SMARAKAM393-04]; assesses=[] -->

**ശിലാലിഖിതം** — *śilālikhitaṁ* — "a stone inscription".

> ക്ഷേത്രത്തിന്റെ ഭിത്തിയിൽ ഒരു പഴയ ശിലാലിഖിതം ഉണ്ട്.
>
> *kṣētrattinṟe bhittiyil oru paḻaya śilālikhitaṁ uṇṭŭ.*
>
> There is an old stone inscription on the temple's wall.

ശില, stone, + ലിഖിതം, something written.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ശിലാലിഖിതം** (*śilālikhitaṁ*) is built from two Sanskrit words, *śilā*, "a rock, a crag" (CDIAL 12459), and *likhita*, "scraped; written" (CDIAL 11050): writing cut into stone.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
