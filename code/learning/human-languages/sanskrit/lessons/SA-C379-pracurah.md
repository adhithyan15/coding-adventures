## You'll want to know: प्रचुरः
<!-- hl-knowledge: introduces=[SA-LEX-C379-ADHIKA379-03]; assesses=[] -->

**प्रचुरः** — *pracuraḥ* — "plentiful".

> यदि वर्षा प्रचुरा, तर्हि धान्यम् अपि प्रचुरं भविष्यति।
>
> *yadi varṣā pracurā, tarhi dhānyam api pracuraṃ bhaviṣyati.*
>
> If the rain is plentiful, the grain will be plentiful too.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**प्रचुरः** (*pracuraḥ*) MW gives *pracura* "much, many, abundant, plentiful" and gives no derivation, so its origin is uncertain (MW).
