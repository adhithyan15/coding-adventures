# ശതമാനം (śatamānaṁ) — per cent; a percentage

## You'll want to know: ശതമാനം
<!-- hl-knowledge: introduces=[ML-LEX-C414-TATVAM414-05]; assesses=[] -->

**ശതമാനം** — *śatamānaṁ* — "per cent; a percentage".

> എഴുപത് ശതമാനം കുട്ടികളും പരീക്ഷ ജയിച്ചു.
>
> *eḻupatŭ śatamānaṁ kuṭṭikaḷuṁ parīkṣa jayiccu.*
>
> Seventy per cent of the children passed the exam.

The number comes first: പത്ത് ശതമാനം, ten per cent.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ശതമാനം** (*śatamānaṁ*) is built from Sanskrit *śata*, "a hundred" (CDIAL 12278), and *māna*, "a measure" (CDIAL 10041): a measure out of a hundred.
