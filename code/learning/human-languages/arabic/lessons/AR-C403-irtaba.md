# ارتاب (irtāba) — to be suspicious

## You'll want to know: ارتاب
<!-- hl-knowledge: introduces=[AR-LEX-C403-IRTIYAB403-02]; assesses=[] -->

**ارتاب** — *irtāba* — "to be suspicious".

> ارتاب الحارس في الرجل.
>
> *irtāba al-ḥāris fī ar-rajul.*
>
> The guard grew suspicious of the man.

Present: يرتاب, *yartāb*.

It takes في: ارتاب في ….

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ارتاب** (*irtāba*) is built on the native Arabic root *r-y-b*, "to disquiet, to raise doubt" (Lane). It is Form VIII, to be filled with disquiet: to doubt, to be suspicious.
