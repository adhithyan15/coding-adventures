## You'll want to know: सिद्धांत
<!-- hl-knowledge: introduces=[MR-LEX-C372-SANSHODHAN372-05]; assesses=[] -->

**सिद्धांत** — *siddhānt* — "a theory; a doctrine".

> हा सिद्धांत अजून सिद्ध झालेला नाही.
>
> *hā siddhānt ajūn siddha jhālelā nāhī.*
>
> This theory has not been proved yet.

Masculine.

सिद्ध, proved, + अंत, end: a settled conclusion.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**सिद्धांत** (*siddhānt*) is a tatsama, taken from Sanskrit *siddhānta*, "established end, doctrine" (CDIAL 13404).
