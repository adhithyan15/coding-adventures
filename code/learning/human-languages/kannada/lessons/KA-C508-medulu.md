# ಮೆದುಳು (meduḷu) — the brain

## You'll want to know: ಮೆದುಳು
<!-- hl-knowledge: introduces=[KA-LEX-C508-DEHA508-01]; assesses=[] -->

**ಮೆದುಳು** — *meduḷu* — "the brain".

> ಮೆದುಳು ದೇಹದ ಎಲ್ಲಾ ಕೆಲಸಗಳನ್ನು ನಡೆಸುತ್ತದೆ.
>
> *meduḷu dēhada ellā kelasagaḷannu naḍesuttade.*
>
> The brain runs all the work of the body.

Also written ಮಿದುಳು.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಮೆದುಳು** (*meduḷu*) is native Dravidian: DEDR 5062 lists Kannada *miduḷ* and *meduḷ*, "brain, marrow", beside Telugu *medaḍu*.
