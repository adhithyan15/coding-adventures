# கட்டாயம் (kaṭṭāyam) — compulsion; compulsory

## You'll want to know: கட்டாயம்
<!-- hl-knowledge: introduces=[TA-LEX-C384-AVACIYAM384-02]; assesses=[] -->

**கட்டாயம்** — *kaṭṭāyam* — "compulsion; compulsory".

> இந்தக் கூட்டத்துக்கு எல்லோரும் கட்டாயம் வர வேண்டும்.
>
> *intak kūṭṭattukku ellōrum kaṭṭāyam vara vēṇṭum.*
>
> Everyone must come to this meeting.

As an adverb, for sure: கட்டாயம் வருவேன், I will definitely come. கட்டாயமாக, compulsorily.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**கட்டாயம்** (*kaṭṭāyam*) is native Dravidian: DEDR 1157 lists Tamil *kaṭṭāyam*, "force, compulsion, constraint; certainly", with Kannada *kaḍḍāya*, "force".
