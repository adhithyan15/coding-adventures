# Independent service locations: round one

## Warm-up

<!-- hl-knowledge: introduces=[]; assesses=[SA-LEX-C14-DEIXIS-03, SA-LEX-C14-DEIXIS-04, SA-LEX-C14-DEIXIS-06, SA-LEX-ASTI] -->

[PAUSE 2s] Recall the four small location pieces: here, there, where, is.

## Guided Practice: one small map

<!-- hl-knowledge: introduces=[]; assesses=[SA-LEX-C120-THINGS120-02, SA-LEX-C268-SERVICE-01, SA-LEX-C84-PLACES-02, SA-LEX-C238-PPL238-04, SA-LEX-C14-DEIXIS-03, SA-LEX-C14-DEIXIS-04, SA-LEX-C14-DEIXIS-06, SA-LEX-ASTI, SA-PATTERN-C268-SERVICE-LOCATION-02] -->

No Sanskrit model is shown before you answer.

[PAUSE 12s] Ask where each of these is: the post office, hospital, financial
bank, and policeman. Answer “there” for the post office and bank, and “here”
for the hospital and policeman.

## What you've built: boundary

<!-- hl-knowledge: introduces=[]; assesses=[SA-PATTERN-C268-SERVICE-LOCATION-02] -->

You can complete one small four-service location round. You have not yet
learned directions, transactions, emergency requests, or institutional
systems.

[PAUSE 3s] Name the four referents again without looking.
