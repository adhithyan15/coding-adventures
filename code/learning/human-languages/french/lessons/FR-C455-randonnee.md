## You'll want to know: la randonnée
<!-- hl-knowledge: introduces=[FR-LEX-C455-RANDONNEE-01]; assesses=[] -->

**la randonnée** — "the hike, the long walk".

> Le dimanche, nous faisons une randonnée en montagne.
>
> *On Sundays we go for a hike in the mountains.*

In speech, *la rando*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*randonnée* is built on *randonner* 'to walk a long way' (EtymDB), from Old French *randonner* 'to run headlong', usually traced to a Germanic word.
