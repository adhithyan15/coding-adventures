# ಸಂಭವನೀಯ (sambhavanīya) — probable; likely

## Warm-up

## You'll want to know: ಸಂಭವನೀಯ
<!-- hl-knowledge: introduces=[KA-LEX-C412-APAYA412-03]; assesses=[] -->

**ಸಂಭವನೀಯ** — *sambhavanīya* — "probable; likely".

> ಮಳೆ ಬಂದರೆ ಪ್ರವಾಹ ಬರುವುದು ಸಂಭವನೀಯ.
>
> *maḷe bandare pravāha baruvudu sambhavanīya.*
>
> If it rains, a flood is likely.

ಸಂಭವ, a possibility or an event.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಸಂಭವನೀಯ** (*sambhavanīya*) is built on Sanskrit *saṃbhava*, "coming together, coming into being" (Monier-Williams), with -*anīya*, "that may be".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
