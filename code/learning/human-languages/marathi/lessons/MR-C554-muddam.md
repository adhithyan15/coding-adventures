# मुद्दाम (muddām) — on purpose

## You'll want to know: मुद्दाम
<!-- hl-knowledge: introduces=[MR-LEX-C554-VEL554-01]; assesses=[] -->

**मुद्दाम** — *muddām* — "on purpose".

> मी मुद्दाम उशिरा आलो नाही.
>
> *mī muddām uśirā ālo nāhī.*
>
> I did not come late on purpose.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**मुद्दाम** (*muddām*) is a Marathi adverb for something done deliberately; its origin is not settled.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
