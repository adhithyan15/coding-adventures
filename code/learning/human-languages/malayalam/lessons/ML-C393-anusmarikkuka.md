# അനുസ്മരിക്കുക (anusmarikkuka) — to commemorate

## You'll want to know: അനുസ്മരിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C393-SMARAKAM393-05]; assesses=[] -->

**അനുസ്മരിക്കുക** — *anusmarikkuka* — "to commemorate".

> ഗ്രാമം ആ കവിയെ അനുസ്മരിച്ചു.
>
> *grāmaṁ ā kaviye anusmariccu.*
>
> The village commemorated that poet.

Past: അനുസ്മരിച്ചു, *anusmariccu*.

The person remembered takes -എ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**അനുസ്മരിക്കുക** (*anusmarikkuka*) is built on അനുസ്മരണം (*anusmaraṇaṁ*), from Sanskrit *anusmaraṇa*, "remembering" (Monier-Williams), with the Malayalam verb ending -ിക്കുക.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
