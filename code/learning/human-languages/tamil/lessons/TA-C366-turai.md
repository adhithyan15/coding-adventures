## You'll want to know: துறை
<!-- hl-knowledge: introduces=[TA-LEX-C366-TURAI366-01]; assesses=[] -->

**துறை** — *tuṟai* — "a field; a department".

> நீங்கள் எந்தத் துறையில் வேலை செய்கிறீர்கள்?
>
> *nīṅkaḷ entat tuṟaiyil vēlai ceykiṟīrkaḷ?*
>
> Which field do you work in?

The same word names a landing place on a river; துறைமுகம், a harbour, is built on it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**துறை** (*tuṟai*) is native Dravidian: DEDR 3370 lists Tamil *tuṟai*, "place, way, branch, section, category; landing place, harbour".
