## You'll want to know: cupidus, cupida, cupidum
<!-- hl-knowledge: introduces=[LA-LEX-C500-CUPI-02]; assesses=[] -->

**cupidus, cupida, cupidum** — "eager, desirous".

> Discipulus cupidus litterārum est.
>
> *The pupil is eager for learning.*

With the genitive: *cupidus pecūniae* — greedy for money.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**cupidus** is built on *cupiō* "to desire" with the adjective ending *-idus* (Lewis & Short; EtymDB).

## What you've built
