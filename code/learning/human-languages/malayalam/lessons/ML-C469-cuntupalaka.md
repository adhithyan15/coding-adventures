# ചൂണ്ടുപലക (cūṇṭupalaka) — a signpost

## You'll want to know: ചൂണ്ടുപലക
<!-- hl-knowledge: introduces=[ML-LEX-C469-NATAPPU469-03]; assesses=[] -->

**ചൂണ്ടുപലക** — *cūṇṭupalaka* — "a signpost".

> ചൂണ്ടുപലകയിൽ ഗ്രാമത്തിലേക്കുള്ള ദൂരം ഉണ്ടായിരുന്നു.
>
> *cūṇṭupalakayil grāmattilēkkuḷḷa dūraṁ uṇṭāyirunnu.*
>
> The signpost gave the distance to the village.

Literally a pointing board: ചൂണ്ടുക, to point, and പലക, a board.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ചൂണ്ടുപലക** (*cūṇṭupalaka*) is a Malayalam compound built from ചൂണ്ടുക, to point, which is native Dravidian (DEDR 2658), and പലക, a board, from Sanskrit *phalaka*.
