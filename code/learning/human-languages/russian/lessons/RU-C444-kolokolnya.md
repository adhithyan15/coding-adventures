## You'll want to know: колокольня
<!-- hl-knowledge: introduces=[RU-LEX-C444-RATUSHA-03]; assesses=[] -->

**колокольня** (*kolokólnya*) — "a bell tower".

> С колокольни виден весь город.
>
> *S kolokólni víden ves górod.*
>
> The whole town can be seen from the bell tower.

Feminine. Built on *колокол* — a bell.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*колокольня* is built from *колокол* 'a bell' and *-ня*, an ending for places (EtymDB). *Колокол* is inherited from Proto-Slavic *kolkolŭ* 'a bell' (EtymDB).
