# విహరించు (vihariñcu) — to stroll; to roam for pleasure

## You'll want to know: విహరించు
<!-- hl-knowledge: introduces=[TE-LEX-C456-SHIKARU456-02]; assesses=[] -->

**విహరించు** — *vihariñcu* — "to stroll; to roam for pleasure".

> పర్యాటకులు తోటలో హాయిగా విహరించారు.
>
> *paryāṭakulu tōṭalō hāyigā vihariñcāru.*
>
> The tourists strolled happily in the garden.

Past (I …): విహరించాను, *vihariñcānu*.

A rather literary verb; విహారయాత్ర, an excursion, holds the same root.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**విహరించు** (*vihariñcu*) is built from Sanskrit *vihāra*, "roaming, pleasure" (CDIAL 12033), from *vi-hṛ*, "to roam about", with the Telugu verb ending -ఇంచు.
