# ಧಾವಿಸು (dhāvisu) — to rush; to hasten

## You'll want to know: ಧಾವಿಸು
<!-- hl-knowledge: introduces=[KA-LEX-C375-SHIBIRA375-05]; assesses=[] -->

**ಧಾವಿಸು** — *dhāvisu* — "to rush; to hasten".

> ಸುದ್ದಿ ಕೇಳಿ ವೈದ್ಯರು ಶಿಬಿರಕ್ಕೆ ಧಾವಿಸಿದರು.
>
> *suddi kēḷi vaidyaru śibirakke dhāvisidaru.*
>
> Hearing the news, the doctors rushed to the camp.

Past (I …): ಧಾವಿಸಿದೆ, *dhāviside*.

Where one rushes takes -ಗೆ: ನೆರವಿಗೆ ಧಾವಿಸು, to rush to help.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಧಾವಿಸು** (*dhāvisu*) is built on Sanskrit *dhāv*, "to run, to flow" (Monier-Williams), with the Kannada verb ending -*isu*.
