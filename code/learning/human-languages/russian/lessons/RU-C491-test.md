## You'll want to know: тесть
<!-- hl-knowledge: introduces=[RU-LEX-C491-INLAWS-04]; assesses=[] -->

**тесть** (*test*) — "a wife's father, a father-in-law".

> Мой тесть — бывший лётчик.
>
> *Moy test — bývshiy lyótchik.*
>
> My father-in-law is a former pilot.

Masculine. The wife's father.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*тесть* is inherited from Proto-Slavic *tьstь* (EtymDB).
