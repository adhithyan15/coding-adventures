# ઈંડું (ī̃ḍũ) — egg

## You'll want to know: ઈંડું
<!-- hl-knowledge: introduces=[GU-LEX-C167-OKRA167-03]; assesses=[] -->

**ઈંડું** — *ī̃ḍũ* — "egg".

> **તે નાસ્તામાં ઈંડું ખાય છે.** — *te nāstāmā̃ ī̃ḍũ khāy che* — "He eats an egg for breakfast."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ઈંડું** (*ī̃ḍũ*) is a tadbhava. It comes from Sanskrit *āṇḍa*, "egg", and CDIAL lists the Gujarati *ĩḍũ*, "egg" (CDIAL 1111).
