# जेणेकरून (jeṇekarūn) — so that

## You'll want to know: जेणेकरून
<!-- hl-knowledge: introduces=[MR-LEX-C381-JOPARYANT381-04]; assesses=[] -->

**जेणेकरून** — *jeṇekarūn* — "so that".

> मी लवकर निघालो, जेणेकरून गाडी चुकू नये.
>
> *mī lavkar nighālo, jeṇekarūn gāḍī cukū naye.*
>
> I left early so that I wouldn't miss the train.

Followed by a should-form or a future: जेणेकरून … होईल.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**जेणेकरून** (*jeṇekarūn*) is built from जेणे, "by which", an old instrumental form of the relative जो, "which", and करून, "having done": done in such a way that. Sanskrit had the same pair, the relative *ya-* and its instrumental *yena* (CDIAL 10391).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
