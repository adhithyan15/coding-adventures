# ఆమోదించు (āmōdiñcu) — to approve; to pass (a bill)

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TE-LEX-C402-MANTRI402-03, TE-LEX-C402-MANTRI402-04] -->

[PAUSE 2s] Before the new one: say the Telugu for power, then the Telugu for to govern.

## You'll want to know: ఆమోదించు
<!-- hl-knowledge: introduces=[TE-LEX-C402-MANTRI402-05]; assesses=[] -->

**ఆమోదించు** — *āmōdiñcu* — "to approve; to pass (a bill)".

> శాసనసభ కొత్త చట్టాన్ని ఆమోదించింది.
>
> *śāsanasabha kotta caṭṭānni āmōdiñcindi.*
>
> The assembly passed the new law.

Past (I …): ఆమోదించాను, *āmōdiñcānu*.

The noun is ఆమోదం, approval.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ఆమోదించు** (*āmōdiñcu*) is built on Sanskrit *āmoda*, "joy, serenity, pleasure" (Monier-Williams), with the Telugu verb ending -ఇంచు; Telugu uses it for giving approval.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
