# വേണോ (vēṇō) — "do you want?"

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C58-WANT-01, ML-CONCEPT-C70-O-01] -->

[PAUSE 2s] Say *wanted*. Then say the one letter Malayalam puts on the end of
something to turn it into a question.

[PAUSE 2s] Put them together before you read on.

## You'll want to know: വേണോ
<!-- hl-knowledge: introduces=[ML-LEX-C76-VENO-01]; assesses=[ML-CONCEPT-C39-CHAAYA-01] -->

> **ചായ വേണോ?**
>
> *cāya vēṇō?* — "**Do you want tea?**"

If you built **വേണോ** in the warm-up, this lesson taught you nothing, which is
the point. **വേണം** loses its ending and takes the question letter you already
had, and that is the whole derivation.

## Grammar Lens: a three-way set you now own
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C76-VENO-01, ML-LEX-C58-WANT-01, ML-LEX-C58-ANSWER-04] -->

| | |
|---|---|
| **വേണോ?** | do you want it? |
| **വേണം** | yes — wanted |
| **വേണ്ട** | no — not wanted |

**That is a whole exchange.** One person offers, the other accepts or declines,
and every word in it is a form of the same root.

Notice which one arrived first. The track gave you **the refusal** long before
the request, so for a while you could say no to an offer you had no way of
making. Both halves are yours now.
