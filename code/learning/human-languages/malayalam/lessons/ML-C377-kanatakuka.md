# കാണാതാകുക (kāṇātākuka) — to go missing

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C377-BHUKAMPAM377-03, ML-LEX-C377-BHUKAMPAM377-04] -->

[PAUSE 2s] Before the new one: say the Malayalam for to be washed away, then the Malayalam for to be cut off.

## You'll want to know: കാണാതാകുക
<!-- hl-knowledge: introduces=[ML-LEX-C377-BHUKAMPAM377-05]; assesses=[] -->

**കാണാതാകുക** — *kāṇātākuka* — "to go missing".

> മൂന്ന് ദിവസം മുൻപ് ഒരു കുട്ടിയെ കാണാതായി.
>
> *mūnnŭ divasaṁ munpŭ oru kuṭṭiye kāṇātāyi.*
>
> A child went missing three days ago.

Past: കാണാതായി, *kāṇātāyi*.

The missing person takes -എ: അവനെ കാണാതായി, literally it became not seeing him.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**കാണാതാകുക** (*kāṇātākuka*) is native Dravidian: the negative of കാണുക (*kāṇuka*), "to see" (DEDR 1443), with ആകുക, "to become": someone comes to be not seen.
