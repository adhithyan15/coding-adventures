# ಅಡಚಣೆ (aḍacaṇe) — a hindrance; a disruption

## You'll want to know: ಅಡಚಣೆ
<!-- hl-knowledge: introduces=[KA-LEX-C432-HATTIKKU432-04]; assesses=[] -->

**ಅಡಚಣೆ** — *aḍacaṇe* — "a hindrance; a disruption".

> ಮಳೆಯಿಂದ ಪಂದ್ಯಕ್ಕೆ ಅಡಚಣೆ ಆಯಿತು.
>
> *maḷeyinda pandyakke aḍacaṇe āyitu.*
>
> The rain disrupted the match.

ಅಡಚಣೆ ಮಾಡು, to disturb.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಅಡಚಣೆ** (*aḍacaṇe*) is built on native *aḍacu*, "to press in, to cram" (DEDR 63).
