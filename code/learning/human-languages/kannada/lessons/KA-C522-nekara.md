# ನೇಕಾರ (nēkāra) — a weaver

## You'll want to know: ನೇಕಾರ
<!-- hl-knowledge: introduces=[KA-LEX-C522-KASUBU522-03]; assesses=[] -->

**ನೇಕಾರ** — *nēkāra* — "a weaver".

> ನೇಕಾರರು ಕೈಮಗ್ಗದಲ್ಲಿ ರೇಷ್ಮೆ ಸೀರೆ ನೇಯುತ್ತಾರೆ.
>
> *nēkāraru kaimaggadalli rēṣme sīre nēyuttāre.*
>
> Weavers weave silk saris on hand looms.

Plural: ನೇಕಾರರು, *nēkāraru*.

The verb is ನೇಯು, to weave.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ನೇಕಾರ** (*nēkāra*) is native Dravidian: DEDR 3745 lists Kannada *nēy*, *nēyu*, "to weave", and agent nouns such as *nēyikāṟa*, "a weaver".
