## You'll want to know: справедливость
<!-- hl-knowledge: introduces=[RU-LEX-C345-SPRAVEDLIVO-03]; assesses=[] -->

**справедливость** (*spravedlívost*) — "fairness, justice".

> Люди хотят справедливости.
>
> *Lyúdi khotyát spravedlívosti.*
>
> People want justice.

Feminine. After *хотеть* in this sense it takes the genitive.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**справедливость** is built on *справедливый* "fair" with the abstract suffix *-ость*; the root is that of *право*, Proto-Slavic *\*pravŭ* (EtymDB).
