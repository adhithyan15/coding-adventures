# உருக்குலை (urukkulai) — to be wrecked

[PAUSE 2s] Before the new one: say the Tamil for an accident, then the Tamil for to be badly hurt.

## You'll want to know: உருக்குலை
<!-- hl-knowledge: introduces=[TA-LEX-C298-VIBATHU298-03]; assesses=[] -->

**உருக்குலை** — *urukkulai* — "to be wrecked".

> விபத்தில் கார் முழுவதும் உருக்குலைந்தது.
>
> *vipattil kār muḻuvatum urukkulaintatu.*
>
> The car was completely wrecked in the accident.

Past (it …): உருக்குலைந்தது, *urukkulaintatu*.

உரு, shape + குலை, to be upset: to lose its shape.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**உருக்குலை** (*urukkulai*) is a Tamil compound built from உரு, "form, shape" (DEDR 657, which asks whether it comes from Sanskrit *rūpa*), and குலை, "to be upset, thrown into disorder" (DEDR 1806).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
