# One no-model Hindi name field

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[HI-FORM-LABEL-NAME-01, HI-FORM-NAME-MIRA-01, HI-FORM-NAME-CUE-MAP-01] -->

Close the preceding lessons. Keep only the two learned identity symbols in
memory. There is no Devanagari value bank, support-language name, romanization,
or completed model below.

## Writing — independent controlled choice
<!-- hl-knowledge: introduces=[HI-FORM-NAME-NO-MODEL-01]; assesses=[HI-FORM-LABEL-NAME-01, HI-FORM-NAME-MIRA-01, HI-FORM-NAME-CUE-MAP-01] -->
<!-- hl-writing-stage: controlled-composition -->

Complete the requested field:

> A — **नाम: __________**

Choose the known value attached to A and write it from memory. Do not open an
earlier lesson until the attempt is complete.

## Guided Practice — separate repair passes
<!-- hl-knowledge: introduces=[]; assesses=[HI-FORM-NAME-MIRA-01, HI-FORM-NAME-NO-MODEL-01] -->

After writing, compare in four bounded passes: requested person, spelling,
vowel marks/headline, then label-value placement. Repair only the first
differing dimension.
