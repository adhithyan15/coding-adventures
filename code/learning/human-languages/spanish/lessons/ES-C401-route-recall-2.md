# route recall two — rebuild it from the change

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ES-LEX-AVENIDA, ES-LEX-SEGUIR, ES-LEX-RECTO, ES-LEX-CAMBIAR] -->

[PAUSE 2s] Start with *change*, then say *avenue*, *follow*, and *straight*.
(*Cambiar, la avenida, seguir, recto*.)

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[ES-LEX-AVENIDA, ES-LEX-SEGUIR, ES-LEX-RECTO, ES-LEX-CAMBIAR] -->

Someone says **cambiar**. Ask which road: **¿Qué avenida?** Then recover the
instruction **seguir recto**. The same four words now survive a different cue.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[ES-LEX-AVENIDA, ES-LEX-SEGUIR, ES-LEX-RECTO, ES-LEX-CAMBIAR] -->

[PAUSE 1s]
- [YOU SAY: *cambiar*]
- [YOU SAY: *¿Qué avenida?*]
- [YOU SAY: *seguir recto*]
- [YOU SAY: *cambiar y seguir recto por la avenida*]

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[ES-LEX-AVENIDA, ES-LEX-SEGUIR, ES-LEX-RECTO, ES-LEX-CAMBIAR] -->

[PAUSE 3s] Without looking back, name and use all four direction words.
(*La avenida; seguir recto; cambiar de dirección*.)
