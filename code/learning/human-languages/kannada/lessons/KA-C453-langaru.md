# ಲಂಗರು (laṅgaru) — an anchor

## You'll want to know: ಲಂಗರು
<!-- hl-knowledge: introduces=[KA-LEX-C453-HADAGU453-03]; assesses=[] -->

**ಲಂಗರು** — *laṅgaru* — "an anchor".

> ಹಡಗು ಬಂದರಿನ ಹೊರಗೆ ಲಂಗರು ಹಾಕಿತು.
>
> *haḍagu bandarina horage laṅgaru hākitu.*
>
> The ship dropped anchor outside the harbour.

ಲಂಗರು ಹಾಕು, to drop anchor.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಲಂಗರು** (*laṅgaru*) is usually traced to Persian *langar*, "an anchor", which reached Kannada through Hindustani.
