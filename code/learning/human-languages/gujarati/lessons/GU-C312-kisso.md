# કિસ્સો (kisso) — a case (to tell); an incident

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[GU-LEX-C312-PATRAKAR312-01, GU-LEX-C312-PATRAKAR312-02] -->

[PAUSE 2s] Before the new one: say the Gujarati for a journalist, then the Gujarati for an incident.

## You'll want to know: કિસ્સો
<!-- hl-knowledge: introduces=[GU-LEX-C312-PATRAKAR312-03]; assesses=[] -->

**કિસ્સો** — *kisso* — "a case (to tell); an incident".

> પત્રકારે છાપામાં આ કિસ્સો લખ્યો.
>
> *patrakāre chāpāmā̃ ā kisso lakhyo.*
>
> The journalist wrote this story up in the paper.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**કિસ્સો** (*kisso*) is usually traced, through Persian, to Arabic *qiṣṣa*, "a story". It is an incident told as a story: **એક કિસ્સો**, a case, something that happened to someone.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
