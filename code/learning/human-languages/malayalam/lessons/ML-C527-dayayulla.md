# ദയയുള്ള (dayayuḷḷa) — kind-hearted; kind

[PAUSE 2s] Before the new one: say the Malayalam for to be amused, then the Malayalam for to grow weary.

## You'll want to know: ദയയുള്ള
<!-- hl-knowledge: introduces=[ML-LEX-C527-SVABHAVAM527-01]; assesses=[] -->

**ദയയുള്ള** — *dayayuḷḷa* — "kind-hearted; kind".

> ദയയുള്ള ഒരു സ്ത്രീ എനിക്ക് വഴി പറഞ്ഞുതന്നു.
>
> *dayayuḷḷa oru strī enikkŭ vaḻi paṟaññutannu.*
>
> A kind woman told me the way.

ദയ, kindness, + ഉള്ള, having. ദയവായി, please, holds the same noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ദയയുള്ള** (*dayayuḷḷa*) is built from ദയ, from Sanskrit *dayā*, "sympathy, compassion" (CDIAL 6185), and the native ending -ഉള്ള, "having" (DEDR 697).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
