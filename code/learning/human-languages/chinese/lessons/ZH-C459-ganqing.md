## You'll want to know: 感情
<!-- hl-knowledge: introduces=[ZH-LEX-C459-MIND459-03]; assesses=[] -->

**感情** — *gǎnqíng* — "affection between people; feelings for each other".

> *wǒmen rènshi le shí nián gǎnqíng hěn hǎo* — We've known each other for ten years, and we're very close.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**感情** (*gǎnqíng*) is built from 感 'to move' and 情 'feeling', both inherited from Middle Chinese, *komX* and *dzjeng* (Guangyun, in Baxter's transcription), which glosses the first 'to move'.
