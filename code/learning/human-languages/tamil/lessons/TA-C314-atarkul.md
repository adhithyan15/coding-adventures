# அதற்குள் (ataṟkuḷ) — by then; by that time

## You'll want to know: அதற்குள்
<!-- hl-knowledge: introduces=[TA-LEX-C314-NINAIVU314-04]; assesses=[] -->

**அதற்குள்** — *ataṟkuḷ* — "by then; by that time".

> நான் நிலையத்துக்கு வந்தேன், ஆனால் அதற்குள் ரயில் போய்விட்டது.
>
> *nāṉ nilaiyattukku vantēṉ, āṉāl ataṟkuḷ rayil pōyviṭṭatu.*
>
> I got to the station, but by then the train had gone.

அது + -க்கு + உள், within that; after a verb, வருவதற்குள், before … could come.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**அதற்குள்** (*ataṟkuḷ*) is built from அது, "that" (DEDR 1), and உள், "inside" (DEDR 698): within that time.
