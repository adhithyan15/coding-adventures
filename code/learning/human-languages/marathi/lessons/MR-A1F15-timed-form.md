# A full practical form under a timer

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MR-A1-FORM-LABEL-NAAV, MR-A1-FORM-LABEL-SHAHAR, MR-A1-FORM-LABEL-BHASHA, MR-A1-FORM-LABEL-AVDATE-PEY, MR-A1-FORM-AGREEMENT-NEUTER, MR-A1-FORM-LABEL-AVADTI-KRUTI, MR-A1-FORM-AGREEMENT-FEMININE, MR-A1-FORM-LABEL-MITRACHE-NAAV, MR-A1-FORM-POSSESSIVE-NEUTER] -->

Profile C gives these meanings: **name Arun; city Pune; language Marathi;
favorite drink milk; favorite activity writing; friend Mira**. Use the six
printed Marathi labels from the earlier form. There is no value bank or
completed model.

## Writing — full task timer
<!-- hl-knowledge: introduces=[]; assesses=[MR-A1-FORM-LABEL-NAAV, MR-A1-FORM-LABEL-SHAHAR, MR-A1-FORM-LABEL-BHASHA, MR-A1-FORM-LABEL-AVDATE-PEY, MR-A1-FORM-AGREEMENT-NEUTER, MR-A1-FORM-LABEL-AVADTI-KRUTI, MR-A1-FORM-AGREEMENT-FEMININE, MR-A1-FORM-LABEL-MITRACHE-NAAV, MR-A1-FORM-POSSESSIVE-NEUTER] -->
<!-- hl-writing-stage: timed-assessment-production -->

Set **two minutes**. Write all **six fields** in Marathi Devanagari from
the meanings alone. Stop at the bell and keep the first attempt before
checking any values.

Score **task fulfilment** (all requested values), **organisation** (right
row for each value), **Marathi control** (familiar noun and agreement forms),
and **orthographic control** (Devanagari spelling) separately. Make one
20-second **repair** on another line; do not overwrite the stopped attempt.
This is not a full A1 mock or a readiness claim.
