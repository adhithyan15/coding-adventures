# ആശംസകൾ (āśaṁsakaḷ) — good wishes

## You'll want to know: ആശംസകൾ
<!-- hl-knowledge: introduces=[ML-LEX-C124-WELCOME-05]; assesses=[] -->

**ആശംസകൾ** (*āśaṁsakaḷ*) — "good wishes". Like **അഭിനന്ദനങ്ങൾ**, it is said in the plural.

## What you've built

Wishes, many of them.
