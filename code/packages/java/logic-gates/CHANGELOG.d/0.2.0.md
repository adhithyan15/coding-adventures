## [0.2.0] — 2026-11-24

### Added
- `InvalidBitException` (extends `IllegalArgumentException`) with `getParameter()` / `getValue()`; thrown for any argument outside {0, 1}.
- `LogicGatesExhaustiveTest`: literal truth tables for all 11 gates, NAND-built == direct, rejection of every int in [-1024, 1024] other than 0/1 plus the int extremes in every argument position, char/byte/short widening tests.
- JaCoCo coverage report and a 0.95 line-coverage verification rule wired into `gradle test`.

### Changed
- JaCoCo tool version pinned to 0.8.12, matching the other Java packages.
- Every one of the 11 gate functions validates each of its own arguments (first invalid parameter reported). Previously `nandOR(1, 2)` reported the parameter as "a" (from the inner `nandNOT`); it now reports "b".
- Documented that char/byte/short widen to int (runtime rejection) while long/double/boolean do not compile.
