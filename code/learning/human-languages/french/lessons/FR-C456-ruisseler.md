## You'll want to know: ruisseler
<!-- hl-knowledge: introduces=[FR-LEX-C456-RUISSEAU-05]; assesses=[] -->

**ruisseler** — "to stream, to run down (of water)".

> La pluie ruisselle sur les vitres.
>
> *The rain is streaming down the windows.*

*Le ruissellement* — run-off water.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*ruisseler* is built on *ruissel*, an old form of *ruisseau* 'stream' (EtymDB lists it), from Latin *rīvus*.
