# முன்பணம் (muṉpaṇam) — an advance payment; a deposit

## You'll want to know: முன்பணம்
<!-- hl-knowledge: introduces=[TA-LEX-C447-THAVANAI447-01]; assesses=[] -->

**முன்பணம்** — *muṉpaṇam* — "an advance payment; a deposit".

> அறைக்கு ஆயிரம் ரூபாய் முன்பணம் கொடுத்தோம்.
>
> *aṟaikku āyiram rūpāy muṉpaṇam koṭuttōm.*
>
> We paid a thousand rupees in advance for the room.

முன், before, + பணம், money.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**முன்பணம்** (*muṉpaṇam*) is built from முன், "before" (DEDR 5020), and பணம், "money".
