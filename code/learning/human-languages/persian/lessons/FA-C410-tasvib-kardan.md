# تصویب کردن (tasvib kardan) — to pass (a law), to approve

## You'll want to know: تصویب کردن
<!-- hl-knowledge: introduces=[FA-LEX-C410-LAYEHE-03]; assesses=[] -->

**تصویب کردن** (*tasvib kardan*) — "to pass (a law), to approve".

> مجلس این لایحه را تصویب کرد.
>
> *majles in lâyehe râ tasvib kard.*
>
> Parliament passed this bill.

*Tasvib* "approval" + *kardan*. *Tasvib shodan* — to be passed.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**تصویب** is usually traced to Arabic *taṣwīb* "approving as right"; with *kardan* "to do" it means to pass a law.
