# சாகசம் (cākacam) — an adventure; a daring feat

## You'll want to know: சாகசம்
<!-- hl-knowledge: introduces=[TA-LEX-C544-SOOTHU544-03]; assesses=[] -->

**சாகசம்** — *cākacam* — "an adventure; a daring feat".

> மலையில் ஏறுவது அவனுக்கு ஒரு சாகசம்.
>
> *malaiyil ēṟuvatu avaṉukku oru cākacam.*
>
> For him, climbing a mountain is an adventure.

Daring stunts in a circus or a film are சாகசங்கள்.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**சாகசம்** (*cākacam*) is borrowed from Sanskrit *sāhasa*, "boldness, daring" (CDIAL 13378); Tamil writes the *h* as க.
