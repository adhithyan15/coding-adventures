## You'll want to know: la guérison
<!-- hl-knowledge: introduces=[FR-LEX-C485-GUERIR-02]; assesses=[] -->

**la guérison** — "recovery, cure".

> Les médecins sont contents de sa guérison.
>
> *The doctors are pleased with his recovery.*

Built on *guérir*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*la guérison* is built on *guérir* "to heal", which comes from Frankish *warjan* "to protect" (EtymDB).
