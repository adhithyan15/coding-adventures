## Warm-up

[PAUSE 3s] One chapter back you wrote **કે**. Write it once from memory before
anything is uncovered.

## Script — the word is its own pattern
<!-- hl-knowledge: introduces=[GU-SCRIPT-KEMKE-01]; assesses=[GU-SCRIPT-KA-01, GU-SCRIPT-MA-01, GU-SCRIPT-E-MATRA-01] -->

Uncover **કેમકે**. Read it in two halves rather than four signs:

> **કે** · **મ** · **કે**

The **કે** you wrote last chapter appears twice, with **મ** between them. Nothing
here is new to the hand — the whole word is one old syllable, a known letter,
and that syllable again.

## Writing — guided copy, model in view
<!-- hl-knowledge: introduces=[]; assesses=[GU-SCRIPT-KEMKE-01] -->
<!-- hl-writing-stage: guided-copy -->

Copy **કેમકે** once with the model in view. Check that both **ે** strokes sit at
the same height.
