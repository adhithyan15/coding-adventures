# പുരസ്കാരം (puraskāraṁ) — an award

## You'll want to know: പുരസ്കാരം
<!-- hl-knowledge: introduces=[ML-LEX-C396-PURASKARAM396-01]; assesses=[] -->

**പുരസ്കാരം** — *puraskāraṁ* — "an award".

> ആ ഗായകന് ഒരു വലിയ പുരസ്കാരം കിട്ടി.
>
> *ā gāyakanŭ oru valiya puraskāraṁ kiṭṭi.*
>
> That singer got a big award.

A formal word; സമ്മാനം is the everyday prize.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**പുരസ്കാരം** (*puraskāraṁ*) is borrowed from Sanskrit *puraskāra*, "placing in front, honouring, distinction" (Monier-Williams).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
