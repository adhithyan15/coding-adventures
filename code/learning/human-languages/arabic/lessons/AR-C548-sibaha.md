# سباحة (sibāḥa) — swimming

## You'll want to know: سباحة
<!-- hl-knowledge: introduces=[AR-LEX-C548-HALABA548-01]; assesses=[] -->

**سباحة** — *sibāḥa* — "swimming".

> السباحة رياضة صحية.
>
> *as-sibāḥa riyāḍa ṣiḥḥiyya.*
>
> Swimming is a healthy sport.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**سباحة** (*sibāḥa*) is built on the native Arabic root *s-b-ḥ*, "to swim, to float" (Lane). Sabaḥa, to swim, which you know, is from the same root.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
