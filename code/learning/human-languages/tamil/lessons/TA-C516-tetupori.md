# தேடுபொறி (tēṭupoṟi) — a search engine

## You'll want to know: தேடுபொறி
<!-- hl-knowledge: introduces=[TA-LEX-C516-INAIYAM516-02]; assesses=[] -->

**தேடுபொறி** — *tēṭupoṟi* — "a search engine".

> நான் தேடுபொறியில் அந்தப் பாடலைத் தேடினேன்.
>
> *nāṉ tēṭupoṟiyil antap pāṭalait tēṭiṉēṉ.*
>
> I looked for that song on a search engine.

தேடு "to search" + பொறி "a device".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**தேடுபொறி** (*tēṭupoṟi*) is a modern compound: the native தேடு (*tēṭu*), "to search" (DEDR 3456), and பொறி (*poṟi*), "a machine, a device"; the origin of the device sense of பொறி is not settled.
