# தனிப்பட்ட (taṉippaṭṭa) — personal; private

## You'll want to know: தனிப்பட்ட
<!-- hl-knowledge: introduces=[TA-LEX-C397-MAKKALATCI397-04]; assesses=[] -->

**தனிப்பட்ட** — *taṉippaṭṭa* — "personal; private".

> உங்களுக்குத் தனிப்பட்ட பிரச்சினை இருந்தால் என்னிடம் சொல்லலாம்.
>
> *uṅkaḷukkut taṉippaṭṭa piracciṉai iruntāl eṉṉiṭam collalām.*
>
> If you have a personal problem, you can tell me.

Before a noun only: தனிப்பட்ட முறையில், personally, in private.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**தனிப்பட்ட** (*taṉippaṭṭa*) is native: *taṉi*, "singleness, solitude" (DEDR 3196), with *paṭṭa*, the adjectival past of *paṭu*: "that has become separate".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
