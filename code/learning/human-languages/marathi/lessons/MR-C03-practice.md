## What you've built — atoms banked this chapter
<!-- hl-knowledge: introduces=[]; assesses=[MR-LEX-KASA, MR-GRAMMAR-HOW-AGREES-WITH-ADDRESSEE, MR-LEX-MI, MR-ETYMON-MI-AHAM-EGO, MR-GRAMMAR-ADJECTIVE-TAKES-PERSON-GENDER, MR-PHRASE-KAAHI-HARKAT-NAHI, MR-ETYMON-HARKAT-ARABIC, MR-GRAMMAR-COPULA-PERSON] -->

- **कसा / कशी / कसं** (*kasā/kaśī/kasaṁ*) — how; the *k-* question family,
  gender-agreeing.
- **मी** (*mī*) — I; Sanskrit *aham* → Latin **ego**, English **I**.
- **बरा / बरी / बरं** (*barā/barī/baraṁ*) — well/fine, now gendered.
- **काही हरकत नाही** (*kāhī harkat nāhī*) — no problem; *nāhī* ← PIE *\*ne*,
  *harkat* ← Arabic.
- Copula forms: **मी आहे / तू आहेस / तुम्ही आहात** (*mī āhe / tū āhes / tumhī
  āhāt*) — one verb, reshaped per person.
