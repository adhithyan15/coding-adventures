## Chapter 1 — the pre-A1 writing ladder, on the first letter

Kannada had **no writing-stage evidence at all**: fifty script lessons and not
one directive, so every writing-stage debt read as outstanding while lessons
that could discharge them sat unmarked. Chapter 1 now carries all four stages,
all on **ನ**, the first letter the book teaches.

- **observe-trace** — the existing `KA-S01-letter-na` already did this work
  ("*YOU TRACE ನ three times*", model visible). Only the marker was missing, and
  the Gujarati precedent settles what the stage means here: trace with the model
  visible, and claim no stroke direction. This book still does not tell you
  where to start the character or which way to travel, because that varies from
  school to school and is not written down until it can be cited.
- **guided-copy** — new, and it does something the first lesson does not: copy
  **ನ** once alone, then again **beside the letter that follows it in ನಮಸ್ಕಾರ**,
  same size and same gap as the printed pair. A letter traced alone teaches the
  hand one shape; a letter copied beside its neighbour teaches it where the
  shape has to **stop**. A hand that has only drawn letters alone writes them
  too large and too far apart the first time it writes a word.
- **delayed-copy** — new. Model covered, ten seconds, write from memory. What to
  check is not whether the letter is beautiful but whether it is the *same*
  letter, which in this script usually comes down to one curve closing where the
  model's closes. A hand drawing from memory rounds off what it is unsure of.
- **dictation-transcription** — new. Write the letter from *na*, and then notice
  what was asked for: not *n*, **na**. The vowel is already inside the letter and
  nobody wrote it. That is the fact the first three lessons showed and this one
  makes you act on, and it is the whole difference between an alphabet and what
  this script is.
