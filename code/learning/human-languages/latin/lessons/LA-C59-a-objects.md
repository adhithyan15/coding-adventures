# aqua -> aquam — when the action reaches the thing

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[LA-SKILL-CONNECTED-READING, LA-LEX-AQUA-VINUM-02] -->

[PAUSE 2s] You already know **aqua**: water. Read one new sentence.

**Aquam bibō.** — I drink water.

[PAUSE 2s] Nothing new has happened to the water. Its ending changed because
it is now the thing the action reaches.

## You'll want to know: -a becomes -am
<!-- hl-knowledge: introduces=[LA-GRAMMAR-C59-OBJECT-A-01]; assesses=[LA-LEX-C44-HOUSE-02, LA-LEX-C51-CITY-05] -->

[PAUSE 2s] Latin marks the direct object with the accusative case. For the
familiar nouns ending in **-a**, the first useful move is small:

- **aqua -> aquam** — I drink **aquam**
- **epistula -> epistulam** — I write **epistulam**
- **porta -> portam** — I open **portam**

[PAUSE 2s] The **-m** is a reading signal. It tells you that this word receives
the action even if Latin moves the word somewhere English would not.

## Grammar Lens: actor, action, object
<!-- hl-knowledge: introduces=[]; assesses=[LA-GRAMMAR-C59-OBJECT-A-01] -->

[PAUSE 2s] In **epistulam scrībō**, the verb **scrībō** already says "I write."
The ending **-am** tells you what I write.

[PAUSE 2s] Read from the endings rather than from position: **portam aperiō**
and **aperiō portam** mean the same basic thing.
