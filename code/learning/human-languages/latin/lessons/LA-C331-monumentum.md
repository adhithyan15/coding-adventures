## You'll want to know: monumentum, monumentī
<!-- hl-knowledge: introduces=[LA-LEX-C331-LUCTUS-04]; assesses=[] -->

**monumentum, monumentī** — "a memorial, a monument".

> Fīliī patrī monumentum ad viam posuērunt.
>
> *The sons set up a memorial to their father by the road.*

Neuter, from *moneō*, 'to remind' (taught): anything that keeps a memory alive, a tomb, a statue or a book. English *monument*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**monumentum** is built on *moneō*, "to remind", with the ending *-mentum* (EtymDB): a reminder. English *monument* comes from it.
