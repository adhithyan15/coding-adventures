# ಕೊರತೆ (korate) — a shortage; a lack

## You'll want to know: ಕೊರತೆ
<!-- hl-knowledge: introduces=[KA-LEX-C421-BEDIKE421-03]; assesses=[] -->

**ಕೊರತೆ** — *korate* — "a shortage; a lack".

> ಬೇಸಿಗೆಯಲ್ಲಿ ನೀರಿನ ಕೊರತೆ ಇರುತ್ತದೆ.
>
> *bēsigeyalli nīrina korate iruttade.*
>
> In summer there is a shortage of water.

What is lacking takes -ದ / -ಇನ: ಹಣದ ಕೊರತೆ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಕೊರತೆ** (*korate*) is native Dravidian: DEDR 1851, the "short, small" family, lists Kannada *koṟate*, "a deficiency".
