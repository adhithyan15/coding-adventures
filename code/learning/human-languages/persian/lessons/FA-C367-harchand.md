# هرچند (harchand) — although, even though

## You'll want to know: هرچند
<!-- hl-knowledge: introduces=[FA-LEX-C367-AMMA-05]; assesses=[] -->

**هرچند** (*harchand*) — "although, even though".

> هرچند خسته بودم، تا آخر فیلم را دیدم.
>
> *harchand khaste budam, tâ âkhar film râ didam.*
>
> Although I was tired, I watched the film to the end.

Takes an indicative clause, like *agarche*; the main clause follows without a linking word.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**هرچند** is a native Persian compound built from *har* "every" and *chand* "how many, however much": however much that is so, the main clause still holds.
