## You'll want to know: proponerse
<!-- hl-knowledge: introduces=[ES-LEX-C615-PLAN-05]; assesses=[] -->

**proponerse** — "to set out to, to resolve".

> Me propongo correr cada mañana.
>
> *I have resolved to run every morning.*

*Proponerse* + infinitive is to make it your goal.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*proponerse* is built on *proponer*, a learned borrowing from Latin *proponere* 'to put forward' and rebuilt on *poner* (EtymDB).
