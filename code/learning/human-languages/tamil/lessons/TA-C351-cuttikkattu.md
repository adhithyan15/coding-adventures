# சுட்டிக்காட்டு (cuṭṭikkāṭṭu) — to indicate; to point out

## You'll want to know: சுட்டிக்காட்டு
<!-- hl-knowledge: introduces=[TA-LEX-C351-KURIPPITU351-02]; assesses=[] -->

**சுட்டிக்காட்டு** — *cuṭṭikkāṭṭu* — "to indicate; to point out".

> ஆசிரியர் என் தவறுகளைச் சுட்டிக்காட்டினார்.
>
> *āciriyar eṉ tavaṟukaḷaic cuṭṭikkāṭṭiṉār.*
>
> The teacher pointed out my mistakes.

Past (I …): சுட்டிக்காட்டினேன், *cuṭṭikkāṭṭiṉēṉ*.

What is pointed out takes -ஐ: தவறைச் சுட்டிக்காட்டு.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**சுட்டிக்காட்டு** (*cuṭṭikkāṭṭu*) is native: *cuṭṭi*, "having indicated", from *cuṭṭu*, "to point out, designate" (DEDR 2658), joined to *kāṭṭu*, "to show" (DEDR 1443).

## What you've built
