## You'll want to know: بناء
<!-- hl-knowledge: introduces=[AR-LEX-C526-HIRAF526-04]; assesses=[] -->

**بناء** — *bannāʾ* — "a builder".

> بنى البناء جدارا حول الحديقة.
>
> *banā al-bannāʾ jidāran ḥawla al-ḥadīqa.*
>
> The builder built a wall around the garden.

Without the doubled n the same letters read bināʾ, a building.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**بناء** (*bannāʾ*) is built on the native Arabic root *b-n-y*, "to build" (Lane). Banā, to build, which you know, is from the same root.
