## You'll want to know: el visado
<!-- hl-knowledge: introduces=[ES-LEX-C656-FRONTERA-03]; assesses=[] -->

**el visado** — "the visa".

> Para este país necesitas visado.
>
> *You need a visa for this country.*

Spain says *el visado*; Latin America says *la visa*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*visado* is built on *visar* "to endorse, to stamp as seen", which is usually linked to *visa*; Spanish *visa* was borrowed from French *visa*, from Latin *vīsa* "things seen" (EtymDB), built on *vidēre* "to see".
