# સૂજવું (sūjvũ) — to swell

## You'll want to know: સૂજવું
<!-- hl-knowledge: introduces=[GU-LEX-C228-SKIN228-02]; assesses=[] -->

**સૂજવું** — *sūjvũ* — "to swell".

> **મારો હાથ નથી સૂજતો.** — *māro hāth nathī sūjto* — "My hand is not swelling."

The swelling itself is **સોજો**.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**સૂજવું** (*sūjvũ*) is a tadbhava. CDIAL lists it, glossed "to swell", under Sanskrit *śūyate*, "is swollen" (CDIAL 12568).
