## You'll want to know: el liderazgo
<!-- hl-knowledge: introduces=[ES-LEX-C594-EQUIPO-01]; assesses=[] -->

**el liderazgo** — "the leadership".

> Necesitamos un buen liderazgo.
>
> *We need good leadership.*

Built on *el líder* — the leader.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*liderazgo* is built on *líder*, which was borrowed from English *leader* (EtymDB), with the ending *-azgo*.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling, explaining and describing at B1.
