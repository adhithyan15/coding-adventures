## You'll want to know: しんぶん
<!-- hl-knowledge: introduces=[JA-LEX-ANCHOR-SHINBUN]; assesses=[JA-SCRIPT-SHI-01, JA-SCRIPT-N-01] -->

**しんぶん** — *shinbun* — "a newspaper".

Four beats: *shi–n–bu–n*. **し** and both **ん** you already write. The third
sign is **ふ** with the voicing mark, so *fu* becomes *bu*. The next lesson
writes it.
