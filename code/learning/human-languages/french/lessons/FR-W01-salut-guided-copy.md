# *salut* — one supported copy

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[FR-ORTHO-SALUT-01] -->

Point to the last letter in **salut**. It is written **t** and said as silence.
Keep the model on the page for the whole lesson.

## Writing — guided copy
<!-- hl-knowledge: introduces=[]; assesses=[FR-ORTHO-SALUT-01] -->
<!-- hl-writing-stage: guided-copy -->

Copy **salut** once. You may look back after every letter.

When you finish, touch **s-a-l-u-t** in your copy and say *sa-LU*. The eye
checks five letters; the voice does not add a final *t* sound.

## Wrap-up recall
<!-- hl-knowledge: introduces=[]; assesses=[FR-ORTHO-SALUT-01] -->
<!-- hl-activity: {"id":"FR-W01-salut-guided-copy-check","kind":"text","assesses":["FR-ORTHO-SALUT-01"],"prompt":"Copy the visible word salut once, then report how many letters you wrote.","answer":"salut — five letters","accepted":["salut","5","five"],"feedback":{"correct":"Good: one supported five-letter copy is enough today.","incorrect":"Look back at the model and copy s-a-l-u-t once."},"response_seconds":15} -->

Compare only the order and presence of the five letters. Repair one letter if
needed, then stop. The model stays visible today.
