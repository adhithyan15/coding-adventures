# நிலைத்தன்மை (nilaittaṉmai) — stability

## You'll want to know: நிலைத்தன்மை
<!-- hl-knowledge: introduces=[TA-LEX-C398-POKKU398-04]; assesses=[] -->

**நிலைத்தன்மை** — *nilaittaṉmai* — "stability".

> அரசியலில் நிலைத்தன்மை இருந்தால் நாடு வளரும்.
>
> *araciyalil nilaittaṉmai iruntāl nāṭu vaḷarum.*
>
> If there is political stability, the country will grow.

நிலை, a firm standing + தன்மை, nature.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**நிலைத்தன்மை** (*nilaittaṉmai*) is native: *nilai*, "a standing, firmness" (DEDR 3675), and *taṉmai*, "nature, quality" (DEDR 3196): the quality of standing firm.
