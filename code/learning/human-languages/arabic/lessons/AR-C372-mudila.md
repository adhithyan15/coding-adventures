## You'll want to know: معضلة
<!-- hl-knowledge: introduces=[AR-LEX-C372-AQABA372-03]; assesses=[] -->

**معضلة** — *muʿḍila* — "a dilemma".

> واجهت الأسرة معضلة صعبة.
>
> *wājahat al-usra muʿḍila ṣaʿba.*
>
> The family faced a hard dilemma.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**معضلة** (*muʿḍila*) is built on the native Arabic root *ʿ-ḍ-l*, "to hinder, to make hard" (Lane). *Muʿḍila* is a Form IV active participle, feminine: a matter that baffles, a dilemma. عضلة, a muscle, is from the same root.
