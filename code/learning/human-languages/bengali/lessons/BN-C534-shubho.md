## You'll want to know: শুভ
<!-- hl-knowledge: introduces=[BN-LEX-C534-BAJI534-04]; assesses=[] -->

**শুভ** — *shubhô* — "auspicious; good".

> বিয়ের জন্য এটা একটা শুভ দিন।
>
> *Biyer jônyô eṭā ekṭā shubhô din.*
>
> This is an auspicious day for a wedding.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**শুভ** (*shubhô*) is a tatsama, Sanskrit *śubha*, "bright, beautiful, auspicious" (Monier-Williams).
