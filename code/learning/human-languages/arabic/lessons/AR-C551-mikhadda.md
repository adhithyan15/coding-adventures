# مخدة (mikhadda) — a cushion; a pillow

## You'll want to know: مخدة
<!-- hl-knowledge: introduces=[AR-LEX-C551-GHURFA551-02]; assesses=[] -->

**مخدة** — *mikhadda* — "a cushion; a pillow".

> وضعت المخدة تحت رأسي.
>
> *waḍaʿtu al-mikhadda taḥta raʾsī.*
>
> I put the cushion under my head.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**مخدة** (*mikhadda*) is built on the native Arabic root *kh-d-d*, "to furrow; the cheek" (Lane). Lane gives mikhadda as a pillow, so called because it is put under the cheek, khadd, which you know.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
