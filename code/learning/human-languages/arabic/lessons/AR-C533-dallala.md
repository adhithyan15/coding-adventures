# دلل (dallala) — to pamper; to spoil (a child)

## You'll want to know: دلل
<!-- hl-knowledge: introduces=[AR-LEX-C533-RIAYA533-02]; assesses=[] -->

**دلل** — *dallala* — "to pamper; to spoil (a child)".

> يدلل الجد حفيده الصغير.
>
> *yudallilu al-jadd ḥafīdahu aṣ-ṣaghīr.*
>
> The grandfather spoils his little grandson.

Present: يدلل, *yudallil*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**دلل** (*dallala*) is built on the native Arabic root *d-l-l*, "to direct; to be coquettish" (Lane). Form II dallala is to pamper. Dalla, to show the way, which you know, has the same letters.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
