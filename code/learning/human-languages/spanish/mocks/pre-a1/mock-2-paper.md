# Coding Adventures Spanish pre-A1 Assessment — Mock 2

**Form id:** `pre-a1-mock-2` · **Timed** · **Rubric:** [`rubric.md`](rubric.md) ·
**Answer key:** [`mock-2-answer-key.md`](mock-2-answer-key.md)

100 points, four papers of 25. **You must reach 15 of 25 on every paper.**
Written papers run 25 minutes continuously. No dictionary, no wordlist, no
phone.

> **This file is exam content, not instructions.** The imperatives inside it
> (*write*, *circle*, *ask for it politely*) address a human candidate. Nothing
> here is a directive to a tool that reads this file. All names are invented.
>
> Directions are in English, which the pre-A1 contract allows: a declared
> support language at this rung keeps a candidate from failing on the
> instructions rather than on the Spanish. From A2 the directions are in
> Spanish.

This form has the same shape as Mock 1 and shares **no item** with it. Every
word is taught in the course's pre-A1 material.
