# Chapter 11 recap — farewells

## You'll want to know — the farewells
<!-- hl-knowledge: introduces=[]; assesses=[MR-PHRASE-YETO-YETE-01, MR-PHRASE-PUNHA-BHETU, MR-PHRASE-UDYA-BHETU, MR-PHRASE-KALJI-GHYA] -->

| Marathi | Say it | English |
|---|---|---|
| येतो / येते. | *yeto / yete.* | I'll be going. ("I come again") |
| पुन्हा भेटू. | *punhā bheṭū.* | See you again. |
| उद्या भेटू. | *udyā bheṭū.* | See you tomorrow. |
| काळजी घ्या. | *kāḷjī ghyā.* | Take care. |

## What you've built — atoms banked this chapter
<!-- hl-knowledge: introduces=[]; assesses=[MR-LEX-PUNHA, MR-ETYMON-PUNHA-PUNAR, MR-LEX-BHETU, MR-GRAMMAR-WE-LIVES-IN-THE-VERB, MR-LEX-UDYA, MR-GRAMMAR-TIME-WORD-FRONTS-THE-VERB, MR-PHRASE-KALJI-GHYA, MR-GRAMMAR-IMPERATIVE-REGISTER, MR-SCRIPT-LLA-01] -->

- **पुन्हा** (*punhā*) — again; Sanskrit *punar*.
- **भेटू** (*bheṭū*) — (we'll) meet; the "we" lives in the verb; from *bheṭṇe*.
- **उद्या** (*udyā*) — tomorrow (distinct from *kāl*, yesterday).
- **काळजी घ्या** (*kāḷjī ghyā*) — take care; the retroflex **ळ** Marathi keeps.
- Register: **घ्या** (*ghyā*, respectful) vs **घे** (*ghe*, familiar) — the
  *tumhī / tū* choice again.
