# வீணாக்கு (vīṇākku) — to waste

## You'll want to know: வீணாக்கு
<!-- hl-knowledge: introduces=[TA-LEX-C448-SEMI448-03]; assesses=[] -->

**வீணாக்கு** — *vīṇākku* — "to waste".

> தண்ணீரை வீணாக்கக் கூடாது.
>
> *taṇṇīrai vīṇākkak kūṭātu.*
>
> You must not waste water.

Past (I …): வீணாக்கினேன், *vīṇākkiṉēṉ*.

வீண், useless, + ஆக்கு, to make.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**வீணாக்கு** (*vīṇākku*) is built from வீண், "uselessness" (DEDR 5454), and ஆக்கு, "to make" (DEDR 333).
