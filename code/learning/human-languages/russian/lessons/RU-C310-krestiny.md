## You'll want to know: крестины
<!-- hl-knowledge: introduces=[RU-LEX-C310-YUBILEY-04]; assesses=[] -->

**крестины** (*krestíny*) — "a christening (party)".

> На крестины пригласили всех родственников.
>
> *Na krestíny priglasíli vsekh ródstvennikov.*
>
> All the relatives were invited to the christening.

Plural only; genitive *крестин*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*крестины* is built on *крест* "a cross", from Church Slavonic *krĭstŭ*, which EtymDB traces ultimately to Greek *Khristós* "the anointed".
