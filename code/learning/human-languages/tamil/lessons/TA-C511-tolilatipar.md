# தொழிலதிபர் (toḻilatipar) — a businessman; an industrialist

## You'll want to know: தொழிலதிபர்
<!-- hl-knowledge: introduces=[TA-LEX-C511-VANIKAM511-04]; assesses=[] -->

**தொழிலதிபர்** — *toḻilatipar* — "a businessman; an industrialist".

> அந்தத் தொழிலதிபர் ஒரு புதிய தொழிற்சாலையைத் தொடங்கினார்.
>
> *antat toḻilatipar oru putiya toḻiṟcālaiyait toṭaṅkiṉār.*
>
> That businessman started a new factory.

தொழில் "a trade" + அதிபர் "a head, a chief": the head of a trade.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**தொழிலதிபர்** (*toḻilatipar*) joins the native தொழில் (*toḻil*), "work, a trade" (DEDR 3524), and அதிபர் (*atipar*), "a chief", from Sanskrit *adhipa*, "a ruler" (Monier-Williams).
