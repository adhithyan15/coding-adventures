## You'll want to know: चलेगा
<!-- hl-knowledge: introduces=[HI-LEX-C127-NOTATALL-05]; assesses=[] -->

**चलेगा** (*calegā*) — "that'll do", "that works", literally "it will go".

It is **चलना**, "to go", in the future. Offered a choice, **चलेगा** accepts it without fuss.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

Don't know, not at all, truly, is that so, that'll do.
