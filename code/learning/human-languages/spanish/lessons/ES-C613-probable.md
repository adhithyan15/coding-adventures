## You'll want to know: probable
<!-- hl-knowledge: introduces=[ES-LEX-C613-REQUIERE-04]; assesses=[] -->

**probable** — "likely, probable".

> Es probable que llueva.
>
> *It is likely to rain.*

*Es probable que* + subjunctive.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*probable* is a learned borrowing from Latin *probabilis* 'credible, that can be proved', built on *probare* 'to test' (EtymDB).
