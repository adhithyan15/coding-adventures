## You'll want to know: अनुक्रमः
<!-- hl-knowledge: introduces=[SA-LEX-C545-ANUKRAMA545-01]; assesses=[] -->

**अनुक्रमः** — *anukramaḥ* — "a sequence".

> यदि अनुक्रमः सम्यक् अस्ति, तर्हि कार्यं सुकरं भवति।
>
> *yadi anukramaḥ samyak asti, tarhi kāryaṃ sukaraṃ bhavati.*
>
> If the order is right, the work is easy.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**अनुक्रमः** (*anukramaḥ*) is built on *anu*, "after", and *krama*, "a step", from the root √kram, "to step"; MW gives *anukrama* as succession, arrangement, order (MW).
