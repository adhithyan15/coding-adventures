# বৈষম্য (boishômyô) — discrimination; inequality

## You'll want to know: বৈষম্য
<!-- hl-knowledge: introduces=[BN-LEX-C352-BOISHOMMO352-01]; assesses=[] -->

**বৈষম্য** — *boishômyô* — "discrimination; inequality".

> মেয়েদের সঙ্গে বৈষম্য করা অন্যায়।
>
> *meyeder sôngge boishômyô kôrā ônyāy.*
>
> Discriminating against girls is wrong.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**বৈষম্য** (*boishômyô*) is Sanskrit *vaiṣamya*, unevenness (Monier-Williams), from *viṣama* 'uneven'. Bengali uses it for unequal treatment; it is done with -এর সঙ্গে.
