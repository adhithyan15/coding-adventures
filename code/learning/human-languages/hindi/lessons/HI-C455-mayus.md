## You'll want to know: मायूस
<!-- hl-knowledge: introduces=[HI-LEX-C455-GAM455-03]; assesses=[] -->

**मायूस** — *māyūs* — "dejected; downcast".

> टीम हार गई, इसलिए सब खिलाड़ी मायूस थे।
>
> *ṭīm hār gaī, isliye sab khilāṛī māyūs the.*
>
> The team lost, so all the players were downcast.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**मायूस** (*māyūs*) is usually traced to Arabic *maʾyūs*, "one given up as hopeless", which reached Hindi through Persian.
