# este — pointing at what is in your hand

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ES-GRAMMAR-DEFINITE-ARTICLES, ES-LEX-LIBRO] -->

[PAUSE 2s] *El libro* names a book. But which one?

[PAUSE 1s] If it is in your hand, you need a word that **points**.

## The word, taken apart: este
<!-- hl-knowledge: introduces=[ES-GRAMMAR-DEMONSTRATIVE-ESTE, ES-ETYMON-ESTE-ISTE]; assesses=[ES-GRAMMAR-NOUN-GENDER] -->

**este libro** — *this book*, the one right here.

[PAUSE 2s] It agrees like any other word that leans on a noun:

| | |
|---|---|
| ***este*** *libro* | this book |
| ***esta*** *casa* | this house |
| ***estos*** *libros* | these books |
| ***estas*** *casas* | these houses |

[PAUSE 2s] Latin's word was ***iste***, and it did not mean *this*. It meant
**that of yours** — it pointed at the person being spoken to. Spanish walked it
one step closer, off the listener and onto the speaker's own hand, and it has
stayed there ever since.

## Why it's said this way
<!-- hl-knowledge: introduces=[ES-GRAMMAR-DEMONSTRATIVE-BEFORE-NOUN]; assesses=[ES-GRAMMAR-DEFINITE-ARTICLES] -->

Now the part English speakers get wrong, and it is a rule rather than a habit.

> *este libro* — never *el este libro*.

[PAUSE 2s] The pointing word goes **in front** of the noun, and it takes the
article's place. It does not stand beside it. You cannot have both, because both
are doing the same job — saying *which one* — and Spanish only lets one word do
that job at a time.

[PAUSE 2s] So the moment you reach for *este*, the *el* you were about to say is
already spoken for.
