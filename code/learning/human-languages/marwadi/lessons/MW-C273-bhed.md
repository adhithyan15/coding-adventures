## You'll want to know: भेद
<!-- hl-knowledge: introduces=[MW-LEX-C273-CHUP273-03]; assesses=[] -->

**भेद** — *bhed* — "a secret".

> यो भेद है, चुप रैवो।
>
> *yo bhed hai, chup raivo.*
>
> This is a secret: keep quiet.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**भेद** (*bhed*) is a tatsama, taken from Sanskrit *bheda*, "breaking open", and so "disclosing (a secret)" (Monier-Williams). Here it names the secret itself, a sense Monier-Williams does not list.
