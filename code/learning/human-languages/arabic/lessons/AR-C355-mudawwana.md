## You'll want to know: مدونة
<!-- hl-knowledge: introduces=[AR-LEX-C355-AJIL355-02]; assesses=[] -->

**مدونة** — *mudawwana* — "a blog".

> تكتب أختي مدونة عن الطبخ.
>
> *taktubu ukhtī mudawwana ʿan aṭ-ṭabkh.*
>
> My sister writes a blog about cooking.

Also a code of law: مدونة الأسرة.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**مدونة** (*mudawwana*) is built on the native Arabic root *d-w-n* (Lane), where *dawwana* is "to write into a register", a *dīwān*. *Mudawwana* is "a thing written down"; the blog is its modern sense.
