## You'll want to know: उलझना
<!-- hl-knowledge: introduces=[HI-LEX-C359-MUDDA359-04]; assesses=[] -->

**उलझना** — *ulajhnā* — "to get tangled, to get bogged down".

> यह धागा हमेशा उलझता है।
>
> *yah dhāgā hameśā ulajhtā hai.*
>
> This thread always gets tangled.

Past (it …): वह धागा उलझ गया, *vah dhāgā ulajh gayā*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**उलझना** (*ulajhnā*) is a tadbhava, inherited from Sanskrit *uparundhati*, "obstructs" (CDIAL 2221).
