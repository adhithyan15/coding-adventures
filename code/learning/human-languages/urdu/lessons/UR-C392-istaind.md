# اسٹینڈ (isṭainḍ) — a stand (for taxis or rickshaws)

## You'll want to know: اسٹینڈ
<!-- hl-knowledge: introduces=[UR-LEX-C392-STAND392-01]; assesses=[] -->

**اسٹینڈ** — *isṭainḍ* — "a stand (for taxis or rickshaws)".

> رکشہ اسٹینڈ بازار کے سامنے ہے۔
>
> *rikshā isṭainḍ bāzār ke sāmne hai.*
>
> The rickshaw stand is opposite the market.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**اسٹینڈ** (*isṭainḍ*) is borrowed from English *stand*.
