## You'll want to know: die Hüfte
<!-- hl-knowledge: introduces=[GE-LEX-C485-GELENKE-05]; assesses=[] -->

**die Hüfte** — "hip".

> Meine Oma bekommt eine neue Hüfte.
>
> *My grandma is getting a new hip.*

Plural: *die Hüften*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*Hüfte* is usually traced to Old High German *huf*, which EtymDB derives from Proto-Germanic *hupiz* "hip"; EtymDB sets *Hüfte* beside English *hip*, a cousin.
