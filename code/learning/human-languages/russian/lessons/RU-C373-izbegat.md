## You'll want to know: избегать
<!-- hl-knowledge: introduces=[RU-LEX-C373-OSTOROZHNO-03]; assesses=[] -->

**избегать** (*izbegát*) — "to avoid".

> Он избегает трудных разговоров.
>
> *On izbegáyet trúdnykh razgovórov.*
>
> He avoids difficult conversations.

Imperfective; perfective *избежать*, conjugated like *бежать*. It takes the genitive: *избегать ошибок*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**избегать** is built from *из-* "out of" and *бегать* "to run", from Proto-Slavic *\*běžati*: to run out of a thing’s way.
