## You'll want to know: ಆಡಳಿತ
<!-- hl-knowledge: introduces=[KA-LEX-C395-ADALITA395-01]; assesses=[] -->

**ಆಡಳಿತ** — *āḍaḷita* — "administration".

> ಊರಿನ ಆಡಳಿತ ಚೆನ್ನಾಗಿ ನಡೆಯುತ್ತಿದೆ.
>
> *ūrina āḍaḷita cennāgi naḍeyuttide.*
>
> The town's administration is running well.

ಆಡಳಿತ ಪಕ್ಷ, the ruling party.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಆಡಳಿತ** (*āḍaḷita*) is usually traced to the native Dravidian *āḷ*, "to possess, to rule, to manage" (DEDR 5157); DEDR does not list *āḍaḷita* itself, so how the word was formed is not settled.
