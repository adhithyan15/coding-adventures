# നിക്ഷേപം (nikṣēpaṁ) — a security deposit; a deposit

## You'll want to know: നിക്ഷേപം
<!-- hl-knowledge: introduces=[ML-LEX-C482-VATAKA482-02]; assesses=[] -->

**നിക്ഷേപം** — *nikṣēpaṁ* — "a security deposit; a deposit".

> മുറിക്ക് ആയിരം രൂപ നിക്ഷേപം കൊടുക്കണം.
>
> *muṟikkŭ āyiraṁ rūpa nikṣēpaṁ koṭukkaṇaṁ.*
>
> You must pay a thousand rupees as a deposit for the room.

The noun of നിക്ഷേപിക്കുക, to deposit. In a bank it also means a savings deposit.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**നിക്ഷേപം** (*nikṣēpaṁ*) is borrowed from Sanskrit *nikṣepa*, "putting down", and so a thing placed in trust (Monier-Williams).
