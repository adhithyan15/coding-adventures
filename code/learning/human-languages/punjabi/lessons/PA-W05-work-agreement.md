# Keep the field and value together

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-LABEL-WORK-01, PA-FORM-WORK-FARMING-01, PA-FORM-WORK-JOB-01] -->

Read **ਕੰਮ**, then **ਖੇਤੀ** and **ਨੌਕਰੀ**. Both values answer the work label in this closed bank.

## Writing — one agreement pass
<!-- hl-knowledge: introduces=[PA-FORM-WORK-AGREEMENT-01]; assesses=[PA-FORM-LABEL-WORK-01, PA-FORM-WORK-FARMING-01, PA-FORM-WORK-JOB-01] -->

Choose the line whose value agrees with the work label: **ਕੰਮ: ਨੌਕਰੀ** or **ਕੰਮ: ਸ਼ਹਿਰ**. Copy only the agreeing line. This checks field-value meaning, not grammatical gender.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-WORK-AGREEMENT-01] -->

Point to the label, say “work,” then point to the chosen value and say its meaning. Ignore handwriting neatness.
