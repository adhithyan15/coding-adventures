**klingeln** — "to ring".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**klingeln** is built on the verb "to sound", Old High German *klingan* ← Proto-Germanic *\*klinganą* (EtymDB 2.1), with *-eln*, an ending for small repeated actions.
