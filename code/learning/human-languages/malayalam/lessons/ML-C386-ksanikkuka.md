# ക്ഷണിക്കുക (kṣaṇikkuka) — to invite

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C386-ATHITHEYAN386-02, ML-LEX-C386-ATHITHEYAN386-03] -->

[PAUSE 2s] Before the new one: say the Malayalam for hospitality, then the Malayalam for a reception.

## You'll want to know: ക്ഷണിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C386-ATHITHEYAN386-04]; assesses=[] -->

**ക്ഷണിക്കുക** — *kṣaṇikkuka* — "to invite".

> അവർ ഞങ്ങളെ വിവാഹത്തിന് ക്ഷണിച്ചു.
>
> *avar ñaṅṅaḷe vivāhattinŭ kṣaṇiccu.*
>
> They invited us to the wedding.

Past: ക്ഷണിച്ചു, *kṣaṇiccu*.

The guest takes -എ, the event -ക്ക് or -ന്: എന്നെ പാർട്ടിക്ക് ക്ഷണിച്ചു.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ക്ഷണിക്കുക** (*kṣaṇikkuka*) is built on ക്ഷണം (*kṣaṇaṁ*), "an invitation", from Sanskrit *kṣaṇa* (CDIAL 3642), with the Malayalam verb ending -ിക്കുക.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
