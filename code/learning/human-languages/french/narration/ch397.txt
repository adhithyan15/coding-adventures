French, chapter 397: Les fichiers.
6 lessons. All 6 can be done entirely by ear.


Lesson 1 of 6.
le fichier — the file (on a computer).

Warm-up.
[pause 2 seconds]
Before the new one: say the French for the software, then the French for the update.

You'll want to know: le fichier.
le fichier — "the file (on a computer)".
Je t'ai envoyé le fichier par courriel. I sent you the file by email.
A paper file is un dossier.

The word, taken apart.
fichier is built on fiche "an index card", from ficher "to fasten, to fix in" (EtymDB), usually traced to a Vulgar Latin fīgicāre, from fīgere "to fix" (Lewis & Short).

You'll want to know: copier.
copier — "to copy".
Il a copié le texte dans un nouveau document. He copied the text into a new document.
At school, copier also means to cheat by copying.

The word, taken apart.
copier comes from Medieval Latin copiāre "to transcribe" (EtymDB), from cōpia "plenty, abundance" (Lewis & Short): to make more of a text.

Lesson 4 of 6.

[pause 2 seconds]

You'll want to know: coller.
coller — "to paste; to stick".
Elle a collé le texte dans son message. She pasted the text into her message.
Copier-coller — copy and paste. Informal: être collé à un examen — to fail it.

The word, taken apart.
coller is built on colle "glue", which comes through Vulgar Latin from Greek kólla "glue" (EtymDB).
