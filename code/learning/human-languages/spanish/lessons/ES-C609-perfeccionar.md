## You'll want to know: perfeccionar
<!-- hl-knowledge: introduces=[ES-LEX-C609-PROGRESO-02]; assesses=[] -->

**perfeccionar** — "to perfect, to polish".

> Quiero perfeccionar mi español.
>
> *I want to perfect my Spanish.*

Built on *la perfección* — perfection.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*perfeccionar* is built on *perfección*, a learned borrowing from Latin *perfectio* 'completion', from *perficere* 'to finish', built on *facere* 'to make' (Lewis & Short).
