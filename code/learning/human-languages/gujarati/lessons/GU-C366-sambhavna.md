# સંભાવના (sambhāvnā) — a likelihood

## You'll want to know: સંભાવના
<!-- hl-knowledge: introduces=[GU-LEX-C366-SHARAT366-03]; assesses=[] -->

**સંભાવના** — *sambhāvnā* — "a likelihood".

> જો વાદળ છવાશે તો વરસાદની સંભાવના છે.
>
> *jo vādaḷ chavāśe to varsādnī sambhāvnā che.*
>
> If clouds gather, there is a chance of rain.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**સંભાવના** (*sambhāvnā*) is a tatsama, borrowed from Sanskrit *sambhāvanā*, "bringing together; supposing" (Monier-Williams).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
