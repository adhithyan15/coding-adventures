# ವ್ಯವಸ್ಥಾಪಕ (vyavasthāpaka) — a manager

## You'll want to know: ವ್ಯವಸ್ಥಾಪಕ
<!-- hl-knowledge: introduces=[KA-LEX-C519-HANAKASU519-02]; assesses=[] -->

**ವ್ಯವಸ್ಥಾಪಕ** — *vyavasthāpaka* — "a manager".

> ಬ್ಯಾಂಕಿನ ವ್ಯವಸ್ಥಾಪಕರು ನನ್ನ ಅರ್ಜಿಯನ್ನು ಪರಿಶೀಲಿಸಿದರು.
>
> *byāṅkina vyavasthāpakaru nanna arjiyannu pariśīlisidaru.*
>
> The bank manager checked my application.

Everyday talk also says ಮ್ಯಾನೇಜರ್. ವ್ಯವಸ್ಥೆ is an arrangement.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ವ್ಯವಸ್ಥಾಪಕ** (*vyavasthāpaka*) is borrowed from Sanskrit *vyavasthāpaka*, "settling, arranging, establishing" (Monier-Williams): the one who puts things in order.
