# Changelog

## 0.1.0 — 2026-10-18

- Added allocation-free comparison of ordered RDN sequences and unordered RDN
  attribute sets from already decoded bounded X.509 Names.
- Required exact canonical attribute-type OIDs while keeping attribute-value
  equivalence caller supplied and data driven.
- Added coverage for sequence, set-size, OID, repeated-type, reordered-encoding,
  unmatched-value, and empty-name behavior.
