## You'll want to know: સંડાસ
<!-- hl-knowledge: introduces=[GU-LEX-C410-BATH410-02]; assesses=[] -->

**સંડાસ** — *sanḍās* — "a toilet; a lavatory".

> સંડાસ ક્યાં છે?
>
> *sanḍās kyā̃ che?*
>
> Where is the toilet?

A neuter noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**સંડાસ** (*sanḍās*) No dictionary we use records an older form, so its history is not settled.
