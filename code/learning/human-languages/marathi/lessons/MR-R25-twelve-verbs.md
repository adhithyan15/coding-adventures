# The twelve, further apart

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MR-LEX-DENE, MR-LEX-PINE, MR-LEX-ANNE, MR-LEX-THEVNE] -->

[PAUSE 5s] The four you ask for: **देणे, पिणे, आणणे, ठेवणे**. Say them without
looking anywhere.

(**Dyā**.) Then stop.
