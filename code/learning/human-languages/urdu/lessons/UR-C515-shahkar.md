## You'll want to know: شاہکار
<!-- hl-knowledge: introduces=[UR-LEX-C515-TASVIR515-04]; assesses=[] -->

**شاہکار** — *shāhkār* — "a masterpiece".

> یہ تصویر اس مصور کا شاہکار ہے۔
>
> *yih tasvīr is musavvir kā shāhkār hai.*
>
> This picture is the painter's masterpiece.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**شاہکار** (*shāhkār*) is usually traced to Persian *shāhkār*, built from *shāh*, "a king", and *kār*, "work": a work fit for a king.
