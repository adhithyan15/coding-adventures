# നനയുക (nanayuka) — to get wet

## You'll want to know: നനയുക
<!-- hl-knowledge: introduces=[ML-LEX-C508-CARRAL508-03]; assesses=[] -->

**നനയുക** — *nanayuka* — "to get wet".

> കുട ഇല്ലാത്തതുകൊണ്ട് ഞാൻ നനഞ്ഞു.
>
> *kuṭa illāttatukoṇṭŭ ñān nanaññu.*
>
> Because I had no umbrella, I got wet.

Past: നനഞ്ഞു, *nanaññu*.

The person who gets wet is the subject: ഞാൻ നനഞ്ഞു, I got wet.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**നനയുക** (*nanayuka*) is native Dravidian, "to become wet, to be soaked" (DEDR 3630).
