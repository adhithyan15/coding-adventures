## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**سريع** (*sarīʿ*) is built on the native Arabic root *s-r-ʿ*, "to be quick" (Lane). *Sarīʿ* is the *faʿīl* adjective, "fast".
