# دو — two, and a spelling that has been hiding in plain sight

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[UR-LEX-EK, UR-ETYMON-EK-INHERITED, UR-LEX-DOST] -->

[PAUSE 2s] Say **ek** and which road it came by. Then say *friend*.

## You'll want to know first — one word
<!-- hl-knowledge: introduces=[UR-LEX-DO]; assesses=[UR-LEX-DOST] -->

> **دو** — *do* — **two**

Two letters, and both of them have been on the page since the friend lesson — they
open *dost*, "friend". A search of this whole book for **دو** finds it twice
and both times inside *dost*, which is exactly why a machine could
report the word as present when the number had never been taught.

## The word, taken apart — the same word as English two
<!-- hl-knowledge: introduces=[UR-ETYMON-DO-TWO-PIE]; assesses=[UR-LEX-DO, UR-LEX-EK] -->

**دو** continues Sanskrit *dvi* through Prakrit **do**, from
Indo-European \**dwóh₁*, "two." English **two**, Latin **duo** and Greek
**dýo** are the same word.

Say *do* and *two* one after the other. Nothing there has to be learned; it has
to be recognised.
