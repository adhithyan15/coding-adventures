## You'll want to know: l'onomastico
<!-- hl-knowledge: introduces=[IT-LEX-C320-FIERA-04]; assesses=[] -->

**l'onomastico** — "the name day".

> Oggi è il mio onomastico.
>
> *Today is my name day.*

The feast of the saint whose name you bear.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*onomastico* is usually traced to Greek *onomastikós* "of names", built on *ónoma* "name" (EtymDB has no Italian entry).
