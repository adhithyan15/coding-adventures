## You'll want to know: वेंधळा
<!-- hl-knowledge: introduces=[MR-LEX-C474-SHISTA474-03]; assesses=[] -->

**वेंधळा** — *vendhḷā* — "scatterbrained".

> वेंधळा अरुण पुन्हा किल्ली विसरला.
>
> *vendhḷā aruṇ punhā killī visarlā.*
>
> Scatterbrained Arun forgot the key again.

Agrees; वेंधळेपणा, scatterbrained ways.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**वेंधळा** (*vendhḷā*) is a Marathi adjective whose origin is not settled.

## What you've built
