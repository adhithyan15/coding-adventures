# منحصر (munhasir) — dependent

## Warm-up

## You'll want to know: منحصر
<!-- hl-knowledge: introduces=[UR-LEX-C275-MUNHASIR-01]; assesses=[UR-LEX-C94-TIME94-02, UR-GRAMMAR-PAR, UR-LEX-C89-DEF89-01, UR-LEX-C89-DEF89-04] -->

**منحصر** — *munhasir* — "dependent".

> **یہ موسم پر منحصر ہے۔**
>
> *yih mausam par munhasir hai.* — "It depends on the weather."

What it depends on takes **پر** (*par*), "on", and **ہے** closes it.

> **سب کچھ آپ پر منحصر ہے۔**
>
> *sab kuchh āp par munhasir hai.* — "Everything depends on you."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**منحصر** (*munhasir*) is usually traced, through Persian, to Arabic *munḥaṣir*, "confined, limited". Urdu uses it with **پر** for "dependent on".
