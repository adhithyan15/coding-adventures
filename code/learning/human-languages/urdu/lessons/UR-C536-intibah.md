# انتباہ (intibāh) — a warning

## You'll want to know: انتباہ
<!-- hl-knowledge: introduces=[UR-LEX-C536-MOHTAT536-03]; assesses=[] -->

**انتباہ** — *intibāh* — "a warning".

> اگر انتباہ ملا تو ہم سفر نہیں کریں گے۔
>
> *agar intibāh milā to ham safar nahīṅ kareṅ ge.*
>
> If we get a warning, we won't travel.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**انتباہ** (*intibāh*) is usually traced, through Persian, to Arabic *intibāh*, "waking up, attention".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
