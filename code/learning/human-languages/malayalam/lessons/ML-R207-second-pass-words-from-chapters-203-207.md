(**പാവം**, *pāvaṁ*.) Dirty? (**അഴുക്കുള്ള**, *aḻukkuḷḷa*.) Smooth? (**മിനുസമുള്ള**, *minusamuḷḷa*.) Rough? (**പരുക്കൻ**, *parukkan*.) Round? (**ഉരുണ്ട**, *uruṇṭa*.) Simple?
