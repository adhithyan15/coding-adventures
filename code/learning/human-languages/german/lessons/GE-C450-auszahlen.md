## You'll want to know: auszahlen
<!-- hl-knowledge: introduces=[GE-LEX-C450-GELDAUTOMAT-05]; assesses=[] -->

**auszahlen** — "to pay out".

> Der Automat zahlt nur Scheine aus.
>
> *The machine only pays out notes.*

Separable: *zahlt aus*, *hat ausgezahlt*. *Sich auszahlen* — to pay off, to be worth it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*auszahlen* is built from *aus* 'out' and *zahlen* 'to pay', from *Zahl* 'number', inherited from Old High German *zala* (EtymDB).
