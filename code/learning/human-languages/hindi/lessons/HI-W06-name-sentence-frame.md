# One frame, one small choice

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[HI-CONCEPT-W04-WRITE-MERA-NAAM-01] -->

Write the two known words **मेरा नाम** once. Leave an ordinary space after each
word. Today adds no new letter and no new grammar.

## Writing — complete the visible frame
<!-- hl-knowledge: introduces=[]; assesses=[HI-CONCEPT-W04-WRITE-MERA-NAAM-01, HI-CONCEPT-C02-MERANAAMHAI-01] -->
<!-- hl-writing-stage: controlled-composition -->

> **मेरा नाम ___ है**

Choose one name already used in Chapter 2: **मीरा** or **अरुण**. Put it in the
gap, then write **है**. The order stays:

1. **मेरा नाम** — my name
2. the chosen practice name
3. **है** — is

Write only one sentence. Keep four visible word groups; punctuation comes in
the next tiny lesson.
