## You'll want to know: نظریہ
<!-- hl-knowledge: introduces=[UR-LEX-C353-NAZARIYA353-01]; assesses=[] -->

**نظریہ** — *nazariyā* — "a theory".

> یہ نظریہ ابھی ثابت نہیں ہوا۔
>
> *yih nazariyā abhī sābit nahīṅ huā.*
>
> This theory has not been proved yet.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**نظریہ** (*nazariyā*) is usually traced, through Persian, to Arabic *naẓariyya*, "a theory", built on *naẓar*, "looking, consideration".
