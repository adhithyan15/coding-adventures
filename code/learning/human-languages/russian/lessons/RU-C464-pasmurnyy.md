## You'll want to know: пасмурный
<!-- hl-knowledge: introduces=[RU-LEX-C464-PROGNOZ-04]; assesses=[] -->

**пасмурный** (*pásmurnyy*) — "overcast, cloudy, gloomy".

> Был пасмурный и холодный день.
>
> *Byl pásmurnyy i kholódnyy den.*
>
> It was an overcast, cold day.

*Пасмурно* — it is overcast.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*пасмурный* is usually linked with the old word *смурый* 'dark grey, gloomy'. EtymDB does not list it, so the line is hedged.
