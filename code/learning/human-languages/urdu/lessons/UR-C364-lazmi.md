# لازمی (lāzmī) — compulsory; bound to happen

## You'll want to know: لازمی
<!-- hl-knowledge: introduces=[UR-LEX-C364-ZAHIR364-02]; assesses=[] -->

**لازمی** — *lāzmī* — "compulsory; bound to happen".

> اگر آپ گاڑی چلاتے ہیں تو لائسنس لازمی ہے۔
>
> *agar āp gāṛī chalāte haiṅ to lāisans lāzmī hai.*
>
> If you drive a car, a licence is compulsory.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**لازمی** (*lāzmī*) is usually traced to Persian *lāzimī*, "necessary", built on Arabic *lāzim*, "binding".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
