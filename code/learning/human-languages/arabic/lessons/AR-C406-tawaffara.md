# توفر (tawaffara) — to be available

## You'll want to know: توفر
<!-- hl-knowledge: introduces=[AR-LEX-C406-TATALLUB406-02]; assesses=[] -->

**توفر** — *tawaffara* — "to be available".

> تتوفر الغرف في الفندق هذا الأسبوع.
>
> *tatawaffaru al-ghuraf fī al-funduq hādhā al-usbūʿ.*
>
> Rooms are available at the hotel this week.

Present: يتوفر, *yatawaffar*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**توفر** (*tawaffara*) is built on the native Arabic root *w-f-r*, "to be abundant, ample" (Lane). It is Form V, to become ample: to be available. وفر, to save, is from the same root.
