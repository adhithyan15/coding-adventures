## You'll want to know: сражаться
<!-- hl-knowledge: introduces=[RU-LEX-C323-VOYNA-04]; assesses=[] -->

**сражаться** (*srazhátsya*) — "to fight".

> Солдаты сражались всю ночь.
>
> *Soldáty srazhális vsyu noch.*
>
> The soldiers fought all night.

Imperfective; perfective *сразиться* (*srazítsya*). *Сражаться с* + instrumental — against; *за* + accusative — for.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*сражаться* is built on *с-* and *разить* "to strike" (EtymDB), with the reflexive *-ся*: to strike at each other.
