# An old word for lifting

The next familiar action is **to lift**. This small return asks for
one old word, with time to pause before each model.

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-C148-ACT148-04] -->

Hear **to lift**. [PAUSE 4s] Recall **ਚੁੱਕਣਾ** (*cukkṇā*).

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-C148-ACT148-04] -->

Look at **ਚੁੱਕਣਾ** and remember **to lift**. [PAUSE 4s]
Look away. Hear **to lift** and say **ਚੁੱਕਣਾ** before the spoken
model. Stay with the old word; no new action is being taught.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-C148-ACT148-04] -->

Hear **to lift** one final time. [PAUSE 4s] Say **ਚੁੱਕਣਾ**.
Listen and retry once if needed. This is an untimed vocabulary
return, separate from the scored A1 writing tasks.
