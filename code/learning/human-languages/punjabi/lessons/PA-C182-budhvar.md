# ਬੁੱਧਵਾਰ — Wednesday

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-WEEKDAY-SOMVAR-01, PA-WEEKDAY-MANGALVAR-01] -->

[PAUSE 2s] Say **ਸੋਮਵਾਰ**, then **ਮੰਗਲਵਾਰ**.

## Grammar Lens: one weekday by ear
<!-- hl-knowledge: introduces=[PA-WEEKDAY-BUDHVAR-01]; assesses=[PA-WEEKDAY-MANGALVAR-01] -->

[YOU HEAR: *budhvaar*; YOU SAY: **ਬੁੱਧਵਾਰ**]

> **ਬੁੱਧਵਾਰ** — *budhvār* — Wednesday

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*Budhvār* joins Sanskrit *budha*, the name of Mercury, with *vāra*, "day of the week" (CDIAL 11547).
