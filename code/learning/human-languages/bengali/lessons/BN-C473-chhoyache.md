# ছোঁয়াচে (chhõyāche) — contagious; catching

## You'll want to know: ছোঁয়াচে
<!-- hl-knowledge: introduces=[BN-LEX-C473-SONGKROMON473-03]; assesses=[] -->

**ছোঁয়াচে** — *chhõyāche* — "contagious; catching".

> এই রোগটা ছোঁয়াচে, তাই রোগীকে আলাদা রাখতে হবে।
>
> *ei rogṭā chhõyāche, tāi rogīke ālādā rākhte hôbe.*
>
> This disease is contagious, so the patient must be kept apart.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ছোঁয়াচে** (*chhõyāche*) is built on *chhõyā*, "to touch", which CDIAL lists for Bengali under Sanskrit *chupati*, "touches" (CDIAL 5055), with an adjective ending: caught by touching.
