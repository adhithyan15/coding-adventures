# Repeated compact identity decodes each need a prepaid work charge

Independent D3a source review found that the first shape gate charged the
preflight text once but decoded the same compact ID again in both shape passes
without charging those scans. Traversal was finite and linear, yet the declared
work contract was not met. Route every decoder call through a charged adapter
and prepay canonicality and conversion scans. Add an independently derived
small ordinary-graph schedule and storage expectation; measuring the gate's own
counter alone cannot establish that all visits were charged.
