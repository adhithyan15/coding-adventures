# രാജകുമാരൻ (rājakumāran) — a prince

## You'll want to know: രാജകുമാരൻ
<!-- hl-knowledge: introduces=[ML-LEX-C397-RAJAVU397-03]; assesses=[] -->

**രാജകുമാരൻ** — *rājakumāran* — "a prince".

> രാജകുമാരൻ കുതിരപ്പുറത്ത് കാട്ടിലേക്ക് പോയി.
>
> *rājakumāran kutirappuṟattŭ kāṭṭilēkkŭ pōyi.*
>
> The prince rode into the forest on horseback.

രാജ-, king, + കുമാരൻ, a boy: the king's son.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**രാജകുമാരൻ** (*rājakumāran*) is built from Sanskrit *rāja-*, "king" (CDIAL 10679), and *kumāra*, "a boy; a prince" (CDIAL 3303).
