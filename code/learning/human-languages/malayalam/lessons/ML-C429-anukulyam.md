# ആനുകൂല്യം (ānukūlyaṁ) — a benefit; a concession

## You'll want to know: ആനുകൂല്യം
<!-- hl-knowledge: introduces=[ML-LEX-C429-KSEMAM429-04]; assesses=[] -->

**ആനുകൂല്യം** — *ānukūlyaṁ* — "a benefit; a concession".

> പ്രായമായവർക്ക് ബസിൽ ചില ആനുകൂല്യങ്ങൾ ഉണ്ട്.
>
> *prāyamāyavarkkŭ basil cila ānukūlyaṅṅaḷ uṇṭŭ.*
>
> Elderly people get some concessions on the bus.

Plural: ആനുകൂല്യങ്ങൾ, benefits.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ആനുകൂല്യം** (*ānukūlyaṁ*) is borrowed from Sanskrit *ānukūlya*, "conformity, suitableness, favour" (Monier-Williams), made from *anukūla*, "favourable".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
