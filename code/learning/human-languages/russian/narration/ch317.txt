Russian, chapter 317: The birthday party.
5 lessons. All 5 can be done entirely by ear.


Lesson 1 of 5.
именинник (imenínnik) — the birthday boy, the person celebrating.

Warm-up.
[pause 2 seconds]
Before the new one: say the Russian for a procession, then the Russian for a fair.

You'll want to know: именинник.
именинник (imenínnik) — "the birthday boy, the person celebrating".
Именинник получил много подарков. Imenínnik poluchíl mnógo podárkov. The birthday boy got a lot of presents.
A girl or woman is именинница.

The word, taken apart.
именинник (imenínnik) is built on именины (imeníny) "a name day", from имя "name", stem имен-, which goes back to the PIE word for a name (EtymDB), the source of Latin nōmen as well.

You'll want to know: загадывать.
загадывать (zagádyvat) — "to make (a wish); to set (a riddle)".
Девочка загадала желание. Dévochka zagadála zhelániye. The girl made a wish.
Imperfective; perfective загадать (zagadát). Загадать загадку — to ask a riddle.

The word, taken apart.
загадывать (zagádyvat) is built on за- and гадать "to guess, to tell fortunes", inherited from Proto-Slavic gadati (EtymDB).
