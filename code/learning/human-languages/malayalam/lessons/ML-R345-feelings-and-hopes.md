# Review — feelings and hopes

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C345-DUHKHAM-01, ML-SCRIPT-C345-VISARGA-01] -->

[PAUSE 2s] Say "grief, sorrow". (*duḥkhaṁ*.) Write **ഃ** once from memory, then **ദുഃഖം**.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C345-DUHKHAM-01, ML-SCRIPT-C345-VISARGA-01, ML-GRAMMAR-C345-FELT-01, ML-GRAMMAR-C345-FEELING-SCENE-EVENT-01, ML-GRAMMAR-C345-AAN-AGRAHAM-01, ML-GRAMMAR-C345-ENNANU-AGRAHAM-01, ML-LEX-C344-SAUKARYAM-01, ML-GRAMMAR-C344-LOST-REPORT-01] -->

[PAUSE 2s each]
- [YOU SAY: "When I heard the news, I felt happy."]
- [YOU SAY: "When I heard that news, I felt deep sorrow."]
- [YOU SAY: "Yesterday I was very sad. Then he got angry."]
- [YOU SAY: "I would like to see Kerala. I want to become a teacher."]
- [YOU SAY: "My wish is to start a small shop."]
- [YOU SAY: "My bag got lost, and I felt very sad." — *enṟe bāgŭ naṣṭappeṭṭupōyi, enikkŭ valiya saṅkaṭaṁ tōnni.*]
- [YOU SAY: "Is tomorrow convenient for you?" — *nāḷe niṅṅaḷkkŭ saukaryamāṇō?*]
