## You'll want to know: ingiusto
<!-- hl-knowledge: introduces=[IT-LEX-C365-GIUSTIZIA-02]; assesses=[] -->

**ingiusto** — "unfair, unjust".

> È ingiusto dare la colpa a tutta la classe per un errore.
>
> *It is unfair to blame the whole class for one mistake.*

*In-* "not" + *giusto*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*ingiusto* comes from Latin *iniūstus* "unjust" (Lewis & Short), built from *in-* "not" and *iūstus* "fair, right".
