## You'll want to know: आश्चर्य
<!-- hl-knowledge: introduces=[MR-LEX-C450-MAN450-04]; assesses=[] -->

**आश्चर्य** — *āścarya* — "surprise; astonishment".

> मीराला पाहून मला खूप आश्चर्य वाटलं.
>
> *mīrālā pāhūn malā khūp āścarya vāṭlaṁ.*
>
> I was very surprised to see Meera.

Neuter.

आश्चर्य वाटणे, to be surprised, with the dative: मला आश्चर्य वाटलं. आश्चर्यकारक, amazing.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**आश्चर्य** (*āścarya*) is a tatsama, taken from Sanskrit *āścarya*, "wonderful" (CDIAL 1464); in Marathi it is a neuter noun, "surprise".
