## You'll want to know: गळती
<!-- hl-knowledge: introduces=[MR-LEX-C520-NAL520-03]; assesses=[] -->

**गळती** — *gaḷtī* — "a leak".

> छपरातून पाण्याची गळती होते.
>
> *chaprātūn pāṇyācī gaḷtī hote.*
>
> Water leaks through the roof.

Feminine.

Built on गळणे: गळती होणे, there is a leak.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**गळती** (*gaḷtī*) is built on गळणे, "to drip", inherited from Sanskrit *galati*, "drips" (CDIAL 4074).
