## You'll want to know: જવાબદારી
<!-- hl-knowledge: introduces=[GU-LEX-C252-DUTY252-02]; assesses=[] -->

**જવાબદારી** — *javābdārī* — "responsibility".

> **ઘરની જવાબદારી મારા પિતા પાસે છે.** — *gharnī javābdārī mārā pitā pāse che* — "My father has the responsibility for the house."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**જવાબદારી** (*javābdārī*) is built on *javābdār*, "answerable", with *-ī* (EtymDB). *Javāb*, "answer", is a loan from Arabic *jawāb*, root *j-w-b* (Lane), and *-dār*, "holder", is usually traced to Persian.
