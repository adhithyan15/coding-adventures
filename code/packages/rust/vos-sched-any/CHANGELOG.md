# Changelog

All notable changes to this package are documented here.

## [0.1.0] - Unreleased

### Added

- VOS-012a: the most-general scheduler (`code/specs/VOS10-scheduler-contract.md` section 11.2).
  `impl Sched for AnySched` at `N = 8`: a ready-set byte plus a private oracle byte `choice`;
  `dispatch` proposes the thread the oracle names, validates it and defaults to `Idle`;
  `insert` and `remove` never read the oracle. Sound and covering. Class K, kind `any`.
  `no_std`, `forbid(unsafe_code)`, no loop, no division, no panic path.
- The ghost face (the only oracle write path): feature `ghost`, a public-field `Image`
  (`mask`, `choice`), `AbsW`, `CfgN` and `vos_ghost_*` wrappers.
- `vos.toml` (kind `any`, obligations `any` and `safety`, no `canonical`),
  `warrant/impl.part`, `evidence.bindings`, `required_capabilities.json` (empty).
- `code/specs/vos-sched-any.warrant`, generated by `vos-link gen-doc`, and `check-doc` with the
  R6 rules for kind `any` in BUILD.
- The VER04h evidence: 7 exhaustive claims, 262,912 cases, all passing, with 18 negative controls
  and the regeneration check and sabotage lines in BUILD.
- `tests/behaviour.rs`: every mask and every oracle value against a reference, and a mutation
  sanity check of the soundness and coverage predicates. 100% line coverage measured once by hand.

### Changed

- WD-HARN1/WD-HARN1b: `tests/generated/warrant_evidence.rs` regenerated with `gen_evidence` for the
  current Warrant prelude (it now carries `lock_or_recover`); the checked-in harness had been
  generated from the pre-WD-HARN1 prelude, so `gen_evidence --check` and the warrant-grammar
  `v0_compat` regeneration test failed. The evidence manifest is unchanged.
- The sabotage lines in `BUILD` and `BUILD_windows` now fail when the sabotaged run prints
  `Bail out!`, not only when it lacks a `not ok ` line (a hang after an intended failure no longer
  passes silently).
