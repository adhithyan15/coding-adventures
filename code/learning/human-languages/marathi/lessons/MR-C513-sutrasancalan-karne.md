## You'll want to know: सूत्रसंचालन करणे
<!-- hl-knowledge: introduces=[MR-LEX-C513-KARYASHALA513-05]; assesses=[] -->

**सूत्रसंचालन करणे** — *sūtrasañcālan karṇe* — "to host a programme".

> शाळेच्या कार्यक्रमाचं सूत्रसंचालन अरुणने केलं.
>
> *śāḷecyā kāryakramācaṁ sūtrasañcālan aruṇne kelaṁ.*
>
> Arun hosted the school programme.

Past, with -ने (he …): त्याने सूत्रसंचालन केलं, *tyāne sūtrasañcālan kelaṁ*.

The event takes -चं: कार्यक्रमाचं सूत्रसंचालन करणे.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**सूत्रसंचालन करणे** (*sūtrasañcālan karṇe*) is a learned compound built from Sanskrit *sūtra*, "thread" (Monier-Williams), and संचालन, "running": the host holds the thread of the programme.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
