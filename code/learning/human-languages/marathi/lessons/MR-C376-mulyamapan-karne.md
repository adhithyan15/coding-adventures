# मूल्यमापन करणे (mūlyamāpan karṇe) — to evaluate

## You'll want to know: मूल्यमापन करणे
<!-- hl-knowledge: introduces=[MR-LEX-C376-MULYAMAPAN376-03]; assesses=[] -->

**मूल्यमापन करणे** — *mūlyamāpan karṇe* — "to evaluate".

> शिक्षक वर्षभर मुलांच्या कामाचं मूल्यमापन करतात.
>
> *śikṣak varṣabhar mulāñcyā kāmācaṁ mūlyamāpan kartāt.*
>
> Teachers evaluate the children's work all year round.

Past, with -ने (he …): त्याने मूल्यमापन केलं, *tyāne mūlyamāpan kelaṁ*.

What is evaluated takes -चं: कामाचं मूल्यमापन.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**मूल्यमापन करणे** (*mūlyamāpan karṇe*) joins मूल्यमापन, a learned compound built from Sanskrit *mūlya*, "value", and *māpana*, "measuring" (Monier-Williams), to करणे, "to do".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
