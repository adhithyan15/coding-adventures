## You'll want to know: нигде
<!-- hl-knowledge: introduces=[RU-LEX-C136-NEG136-03]; assesses=[] -->

**нигде** (*nigdé*) — "nowhere". It is **где** with **ни-**: **Нигде нет такси.** — *nigdé nyet taksí* — "There are no taxis anywhere."
