# অনুষ্ঠান (ônushṭhān) — a ceremony; a function

## You'll want to know: অনুষ্ঠান
<!-- hl-knowledge: introduces=[BN-LEX-C312-ONUSHTHAN312-01]; assesses=[] -->

**অনুষ্ঠান** — *ônushṭhān* — "a ceremony; a function".

> বিয়ের অনুষ্ঠান সন্ধ্যায় শুরু হল।
>
> *biyer ônushṭhān sôndhyāy shuru hôlô.*
>
> The wedding ceremony began in the evening.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**অনুষ্ঠান** (*ônushṭhān*) is Sanskrit *anuṣṭhāna*, 'carrying out, performance' (Monier-Williams), as of a rite; today it is any ceremony or programme.

## What you've built

One more word for telling what happened.
