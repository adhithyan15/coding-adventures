## You'll want to know: нарушитель
<!-- hl-knowledge: introduces=[RU-LEX-C392-OGRANICHENIYA-04]; assesses=[] -->

**нарушитель** (*narushítel*) — "an offender, a violator".

> Полиция остановила нарушителя.
>
> *Polítsiya ostanovíla narushítelya.*
>
> The police stopped the offender.

Masculine. *Нарушитель порядка* — someone disturbing the peace.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**нарушитель** is built on *нарушить* "to violate", from *на-* and *рушить* "to pull down", with the agent suffix *-тель*.
