# सा — reuse a mark instead of learning a new rule

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-SA-01, MW-SCRIPT-AA-MATRA-01] -->

[PAUSE 2s] What did **ा** do to **र**? Apply the same change to **स**.

## Script — assemble
<!-- hl-knowledge: introduces=[MW-SCRIPT-SAA-01]; assesses=[] -->

> **स** *sa* + **ा** *ā* = **सा** *sā*

The writing rule is old; only the combination is new. In the greeting you are
building, **सा** is a respectful form of address.

## Writing — delayed copy
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-SAA-01, MW-SCRIPT-RAAM-01] -->

Copy **सा** once. Look away for ten seconds, say *sā*, and write it again.
Then copy the two pieces with a space:

> **राम सा**
