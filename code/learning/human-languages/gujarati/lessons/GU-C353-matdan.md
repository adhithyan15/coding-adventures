# મતદાન (matdān) — voting

## You'll want to know: મતદાન
<!-- hl-knowledge: introduces=[GU-LEX-C353-MATDAN353-03]; assesses=[] -->

**મતદાન** — *matdān* — "voting".

> રવિવારે ગામમાં મતદાન થશે.
>
> *ravivāre gāmmā̃ matdān thaśe.*
>
> The village votes on Sunday.

A neuter noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**મતદાન** (*matdān*) is built from **મત** (*mat*), "an opinion, a vote", and Sanskrit *dāna*, "giving" (Monier-Williams): the giving of votes.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
