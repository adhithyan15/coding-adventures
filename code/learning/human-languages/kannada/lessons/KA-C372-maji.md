# ಮಾಜಿ (māji) — former; ex-

## You'll want to know: ಮಾಜಿ
<!-- hl-knowledge: introduces=[KA-LEX-C372-VANAVASA372-04]; assesses=[] -->

**ಮಾಜಿ** — *māji* — "former; ex-".

> ಮಾಜಿ ಸೈನಿಕರು ಸ್ಮಾರಕದ ಬಳಿ ಸೇರಿದರು.
>
> *māji sainikaru smārakada baḷi sēridaru.*
>
> Former soldiers gathered near the memorial.

It stands before a noun: ಮಾಜಿ ಶಿಕ್ಷಕ, a former teacher.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಮಾಜಿ** (*māji*) is a loan from Arabic *māḍī*, "past, gone by", which came through Persian and Hindustani *mājī*.
