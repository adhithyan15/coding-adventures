# নিশ্চিত (nishchitô) — sure; certain

## You'll want to know: নিশ্চিত
<!-- hl-knowledge: introduces=[BN-LEX-C337-PROMAN337-02]; assesses=[] -->

**নিশ্চিত** — *nishchitô* — "sure; certain".

> আমি নিশ্চিত, মীরা আসবে।
>
> *āmi nishchitô, mīrā āsbe.*
>
> I'm sure Mira will come.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**নিশ্চিত** (*nishchitô*) is Sanskrit *niścita*, settled or ascertained (Monier-Williams). A person can be নিশ্চিত, and so can a fact.
