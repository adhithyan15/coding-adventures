## You'll want to know: راسته
<!-- hl-knowledge: introduces=[FA-LEX-C457-RASTE-01]; assesses=[] -->

**راسته** (*râste*) — "a row (of the bazaar given to one trade)".

> در راسته فرش فروشها قدم زدیم.
>
> *Dar râste-ye farsh-forush-hâ qadam zadim.*
>
> We walked along the carpet sellers' row.

Each *râste* of an old bazaar belongs to one trade: gold, copper, cloth, spices.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*râste* is a native word, which EtymDB lists; it is built on *râst* 'straight', usually traced to Middle Persian *rāst*: a straight line of shops.
