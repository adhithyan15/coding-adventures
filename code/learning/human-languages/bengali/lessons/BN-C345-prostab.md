## You'll want to know: প্রস্তাব
<!-- hl-knowledge: introduces=[BN-LEX-C345-SONGSOD345-03]; assesses=[] -->

**প্রস্তাব** — *prôstāb* — "a proposal; a motion".

> আমার একটা প্রস্তাব আছে।
>
> *āmār ekṭā prôstāb āchhe.*
>
> I have a proposal.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**প্রস্তাব** (*prôstāb*) is Sanskrit *prastāva*, an introduction or prelude (Monier-Williams). Bengali uses it for what is put forward first in a meeting, a proposal or a motion; that use is a later one.
