## You'll want to know: 改期
<!-- hl-knowledge: introduces=[ZH-LEX-C392-NEWPLAN392-02]; assesses=[] -->

**改期** — *gǎiqī* — "to change the date (of an event)".

> **要是下雨晚会就改期** *yàoshi xiàyǔ wǎnhuì jiù gǎiqī* — If it rains, the party will be moved to another date.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**改期** (*gǎiqī*) is built from 改 'to alter' and 期 'a set time', both inherited from Middle Chinese, *kojX* and *gi* (Guangyun, in Baxter's transcription), which glosses the second 'an appointed meeting'.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what would happen.
