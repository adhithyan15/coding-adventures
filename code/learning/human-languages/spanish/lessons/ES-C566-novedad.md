## You'll want to know: la novedad
<!-- hl-knowledge: introduces=[ES-LEX-C566-AVENTURA-05]; assesses=[] -->

**la novedad** — "the novelty; the news, the change".

> ¿Hay alguna novedad sobre el caso?
>
> *Is there any news about the case?*

*Sin novedad* — nothing new to report.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*novedad* is inherited from Latin *novitās*, *novitātem* 'newness' (EtymDB), built on *novus* 'new'.
