## You'll want to know: загадывать
<!-- hl-knowledge: introduces=[RU-LEX-C317-IMENINNIK-03]; assesses=[] -->

**загадывать** (*zagádyvat*) — "to make (a wish); to set (a riddle)".

> Девочка загадала желание.
>
> *Dévochka zagadála zhelániye.*
>
> The girl made a wish.

Imperfective; perfective *загадать* (*zagadát*). *Загадать загадку* — to ask a riddle.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*загадывать* is built on *за-* and *гадать* "to guess, to tell fortunes", inherited from Proto-Slavic *gadati* (EtymDB).
