## You'll want to know: el divorcio
<!-- hl-knowledge: introduces=[ES-LEX-C550-DIVORCIO-01]; assesses=[] -->

**el divorcio** — "the divorce".

> El divorcio fue difícil para los niños.
>
> *The divorce was hard for the children.*

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*divorcio* is a learned borrowing from Latin *dīvortium* 'a separation, a divorce' (EtymDB), built on *dīvertere* 'to turn aside'.
