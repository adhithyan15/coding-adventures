## You'll want to know: ಉಸಿರು
<!-- hl-knowledge: introduces=[KA-LEX-C99-BODY2-01]; assesses=[] -->

**ಉಸಿರು** (*usiru*) — "breath".

**ಉಸಿರು ತೆಗೆದುಕೊಳ್ಳಿ** (*usiru tegedukoḷḷi*) — "take a breath", with **ತೆಗೆದುಕೊ**,
"take", as in **ವಿಶ್ರಾಂತಿ ತೆಗೆದುಕೊಳ್ಳಿ**.
