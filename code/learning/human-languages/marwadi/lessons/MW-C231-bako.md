# बांको (bā̃ko) — crooked; bent

## You'll want to know: बांको
<!-- hl-knowledge: introduces=[MW-LEX-C231-SHAPE231-01]; assesses=[] -->

**बांको** — *bā̃ko* — "crooked; bent".

> डूंगर माथै गेलो बांको है।
>
> *ḍū̃gar māthai gelo bā̃ko hai.*
>
> On the hill the path is crooked.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**बांको** (*bā̃ko*) is inherited from Sanskrit *vaṅka*, "bent, crooked"; CDIAL lists Marwari *bā̃ko* (CDIAL 11191).
