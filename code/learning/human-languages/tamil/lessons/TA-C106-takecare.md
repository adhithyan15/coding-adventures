## You'll want to know: பார்த்துக்கொள்ளுங்கள்
<!-- hl-knowledge: introduces=[TA-LEX-C106-CARE-01]; assesses=[] -->

**பார்த்துக்கொள்ளுங்கள்** (*pārttukkoḷḷuṅkaḷ*) — "take care", literally "look after (yourself)".

It is built on **பார்**, "to see, to look".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

The kindest goodbye.
