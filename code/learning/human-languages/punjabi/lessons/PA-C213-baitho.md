# ਬੈਠੋ, ਉੱਠੋ — please sit, please get up

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-MAAF, PA-LEX-C56-FAMILY56-04, PA-LEX-C57-VERBS57-01] -->

[PAUSE 2s] Say **ਮਾਫ਼ ਕਰੋ**. Then *to sit* and *to get up*.

## Grammar Lens: stem + ੋ
<!-- hl-knowledge: introduces=[PA-GRAMMAR-REQUEST-O-213]; assesses=[PA-LEX-C56-FAMILY56-04, PA-LEX-C57-VERBS57-01, PA-LEX-MAAF, PA-POSTPOSITION-NAAL-COMITATIVE-01] -->

**ਕਰੋ** is the stem **ਕਰ** with the sign **ੋ**. Other stems that end in a
consonant work the same way:

> **ਬੈਠ** + **ੋ** → **ਬੈਠੋ**

> **ਇੱਥੇ ਬੈਠੋ।** — *itthe baiṭho.* — Please sit here.

> **ਸਵੇਰੇ ਜਲਦੀ ਉੱਠੋ।** — *savere jaldī uṭṭho.* — Get up early in the morning.

> **ਕਿਤਾਬ ਪੜ੍ਹੋ।** — *kitāb paṛho.* — Read the book.

It is the polite form, the one you say to **ਤੁਸੀਂ**.
