# A block assessment must also be declared in practises knowledge

The Punjabi student-noun owner used a warm-up to retrieve three familiar
identity-frame atoms. Its block-level directive assessed those atoms, but the
lesson's `practises.knowledge` listed only the new noun. Focused content tests
passed; integration and CLI validation correctly rejected all three support
assessments as undeclared practice.

The two declarations are a bidirectional honesty contract. A practised atom
needs a real assessing block, and every assessed atom must be admitted as
practice in frontmatter. When a warm-up retrieves prior knowledge, copy those
atom IDs into both the block's `assesses` list and the lesson's
`practises.knowledge`. Run integration and CLI validation alongside the focused
corpus test before generation is considered final.
