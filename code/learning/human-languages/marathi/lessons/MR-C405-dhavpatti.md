## You'll want to know: धावपट्टी
<!-- hl-knowledge: introduces=[MR-LEX-C405-VIMAN405-03]; assesses=[] -->

**धावपट्टी** — *dhāvpaṭṭī* — "a runway".

> विमान धावपट्टीवर उभं आहे.
>
> *vimān dhāvpaṭṭīvar ubhaṁ āhe.*
>
> The plane is standing on the runway.

Feminine.

धाव is a run and पट्टी a strip: the strip planes run along.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**धावपट्टी** (*dhāvpaṭṭī*) is a Marathi compound of **धाव**, "a run", inherited from *\*dhāva* (CDIAL 6800), and **पट्टी**, "a strip".
