## You'll want to know: pueritia, pueritiae
<!-- hl-knowledge: introduces=[LA-LEX-C324-PUER-04]; assesses=[] -->

**pueritia, pueritiae** — "childhood, boyhood".

> In pueritiā multās fābulās audiēbam.
>
> *In my childhood I used to hear many stories.*

Feminine, from *puer*; up to about the seventeenth year.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**pueritia** is built on *puer*, "boy, child", with the ending *-itia* for a state (EtymDB).

## What you've built
