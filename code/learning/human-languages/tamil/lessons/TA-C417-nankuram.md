# நங்கூரம் (naṅkūram) — an anchor

## You'll want to know: நங்கூரம்
<!-- hl-knowledge: introduces=[TA-LEX-C417-MALUMI417-02]; assesses=[] -->

**நங்கூரம்** — *naṅkūram* — "an anchor".

> கப்பல் துறைமுகத்துக்கு வெளியே நங்கூரம் போட்டது.
>
> *kappal tuṟaimukattukku veḷiyē naṅkūram pōṭṭatu.*
>
> The ship dropped anchor outside the harbour.

நங்கூரம் போடு is to drop anchor.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**நங்கூரம்** (*naṅkūram*) is usually traced to Persian *langar*, "an anchor".
