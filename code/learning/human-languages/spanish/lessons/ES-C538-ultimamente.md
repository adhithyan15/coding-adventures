## You'll want to know: últimamente
<!-- hl-knowledge: introduces=[ES-LEX-C538-ANTES-05]; assesses=[] -->

**últimamente** — "lately".

> Últimamente duermo mal.
>
> *Lately I have been sleeping badly.*

Usually with the present or the present perfect.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*últimamente* is built on *último* and the ending *-mente* (EtymDB). *Último* is a learned word from Latin *ultimus* 'farthest, last'.
