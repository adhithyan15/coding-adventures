## You'll want to know: la piste
<!-- hl-knowledge: introduces=[FR-LEX-C510-GLACE-05]; assesses=[] -->

**la piste** — "slope, run; track".

> Cette piste noire est trop difficile pour moi.
>
> *This black run is too difficult for me.*

Also a running track, a dance floor, or a clue: *une bonne piste*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*la piste* was borrowed from Italian *pista* "a beaten track" (EtymDB), built on *pistare* "to pound", which goes back to Latin *pinsere* "to pound" (Lewis & Short).
