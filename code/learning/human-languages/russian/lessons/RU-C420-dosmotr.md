## You'll want to know: досмотр
<!-- hl-knowledge: introduces=[RU-LEX-C420-DOSMOTR-01]; assesses=[] -->

**досмотр** (*dosmótr*) — "a security check, an inspection".

> Перед посадкой все проходят досмотр.
>
> *Péred posádkoy vse prokhódyat dosmótr.*
>
> Before boarding everyone goes through the security check.

Masculine. *Таможенный досмотр* — a customs inspection.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*досмотр* is built from *до-* 'thoroughly, to the end' and *смотр* 'a review', on *смотреть* 'to look', which EtymDB relates to Proto-Slavic *motriti* 'to watch'.
