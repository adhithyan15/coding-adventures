## You'll want to know: નોંધવું
<!-- hl-knowledge: introduces=[GU-LEX-C248-OFFICE248-05]; assesses=[] -->

**નોંધવું** — *nõdhvũ* — "to note down".

> **હું બેઠકમાં બધું નોંધું છું.** — *hũ beṭhakmā̃ badhũ nõdhũ chũ* — "I note down everything in the meeting."

Its causative **નોંધાવવું** means to register.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**નોંધવું** (*nõdhvũ*) is a tadbhava. It comes from *\*nibandhati*, beside Sanskrit *níbadhnāti*, "binds on; writes down"; CDIAL glosses the Gujarati verb "to note down, enter in a book" (CDIAL 7223).
