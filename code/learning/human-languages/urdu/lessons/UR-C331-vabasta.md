## You'll want to know: وابستہ
<!-- hl-knowledge: introduces=[UR-LEX-C331-SABAB331-05]; assesses=[] -->

**وابستہ** — *vābastā* — "connected (with); tied (to)".

> اس کا نام اس شہر سے وابستہ ہے۔
>
> *us kā nām is shahr se vābastā hai.*
>
> His name is bound up with this city.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**وابستہ** (*vābastā*) is usually traced to Persian *vābasta*, "tied back, attached", built on *basta*, "tied".
