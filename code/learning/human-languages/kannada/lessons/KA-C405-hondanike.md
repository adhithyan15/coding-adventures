# ಹೊಂದಾಣಿಕೆ (hondāṇike) — a compromise; an adjustment

## You'll want to know: ಹೊಂದಾಣಿಕೆ
<!-- hl-knowledge: introduces=[KA-LEX-C405-SANDHANA405-04]; assesses=[] -->

**ಹೊಂದಾಣಿಕೆ** — *hondāṇike* — "a compromise; an adjustment".

> ಸ್ವಲ್ಪ ಹೊಂದಾಣಿಕೆ ಮಾಡಿಕೊಂಡರೆ ಸಮಸ್ಯೆ ಮುಗಿಯುತ್ತದೆ.
>
> *svalpa hondāṇike māḍikoṇḍare samasye mugiyuttade.*
>
> If we compromise a little, the problem ends.

ಹೊಂದಾಣಿಕೆ ಮಾಡಿಕೊ, to adjust, to compromise.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಹೊಂದಾಣಿಕೆ** (*hondāṇike*) is native Dravidian, built on *hondu*, "to come together, to suit" (DEDR 4541).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
