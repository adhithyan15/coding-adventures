## You'll want to know: রাজস্ব
<!-- hl-knowledge: introduces=[BN-LEX-C348-RAJOSHO348-01]; assesses=[] -->

**রাজস্ব** — *rājôsvô* — "public revenue".

> রাজস্বের টাকায় নতুন হাসপাতাল হবে।
>
> *rājôsver ṭākāy nôtun hāspātāl hôbe.*
>
> A new hospital will be built with revenue money.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**রাজস্ব** (*rājôsvô*) is Sanskrit *rājasva*, a king's own property (Monier-Williams). The sense 'public revenue' is the modern one, the state having taken the king's place.
