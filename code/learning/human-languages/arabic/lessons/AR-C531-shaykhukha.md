# شيخوخة (shaykhūkha) — old age

## You'll want to know: شيخوخة
<!-- hl-knowledge: introduces=[AR-LEX-C531-KIBAR531-04]; assesses=[] -->

**شيخوخة** — *shaykhūkha* — "old age".

> في الشيخوخة يحتاج الإنسان إلى الراحة.
>
> *fī ash-shaykhūkha yaḥtāju al-insān ilā ar-rāḥa.*
>
> In old age a person needs rest.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**شيخوخة** (*shaykhūkha*) is built on the native Arabic root *sh-y-kh*, "to grow old" (Lane). Shaykh, an old man and an elder, is from the same root.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
