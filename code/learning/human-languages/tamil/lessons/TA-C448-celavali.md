# செலவழி (celavaḻi) — to spend money; to spend

## You'll want to know: செலவழி
<!-- hl-knowledge: introduces=[TA-LEX-C448-SEMI448-02]; assesses=[] -->

**செலவழி** — *celavaḻi* — "to spend money; to spend".

> விடுமுறையில் நாங்கள் நிறைய பணம் செலவழித்தோம்.
>
> *viṭumuṟaiyil nāṅkaḷ niṟaiya paṇam celavaḻittōm.*
>
> We spent a lot of money on holiday.

Past (I …): செலவழித்தேன், *celavaḻittēṉ*.

செலவு, an expense, + அழி, to use up.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**செலவழி** (*celavaḻi*) is built from செலவு, "going, expenditure" (DEDR 2781), and அழி, "to perish, to be used up" (DEDR 277).
