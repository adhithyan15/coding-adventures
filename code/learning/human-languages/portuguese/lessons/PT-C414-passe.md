## You'll want to know: o passe
<!-- hl-knowledge: introduces=[PT-LEX-C414-BILHETEIRA-02]; assesses=[] -->

**o passe** — "the travel pass, the season ticket; the pass (in football)".

> Compro o passe todos os meses.
>
> *I buy the travel pass every month.*

*O passe* covers buses, trams and the metro for a month.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*passe* is built on *passar* 'to pass' (EtymDB), which is inherited from Vulgar Latin *passāre*, on Latin *passus* 'step'.
