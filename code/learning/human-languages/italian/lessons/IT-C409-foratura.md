## You'll want to know: la foratura
<!-- hl-knowledge: introduces=[IT-LEX-C409-GOMMA-02]; assesses=[] -->

**la foratura** — "the puncture".

> Per una foratura siamo arrivati tardi.
>
> *Because of a puncture we arrived late.*

*Riparare una foratura* — to fix a puncture.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*foratura* is built on *forare* 'to pierce', which is inherited from Latin *forāre* 'to bore' (EtymDB).
