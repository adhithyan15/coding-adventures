# జీవితచరిత్ర (jīvitacaritra) — a biography

## You'll want to know: జీవితచరిత్ర
<!-- hl-knowledge: introduces=[TE-LEX-C373-ATMAKATHA373-02]; assesses=[] -->

**జీవితచరిత్ర** — *jīvitacaritra* — "a biography".

> పిల్లలు ఆ వీరుడి జీవితచరిత్ర చదివారు.
>
> *pillalu ā vīruḍi jīvitacaritra cadivāru.*
>
> The children read the hero's biography.

జీవితం, a life, and చరిత్ర, a history.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**జీవితచరిత్ర** (*jīvitacaritra*) is built from Sanskrit *jīvita*, "living, life" (CDIAL 5252), and *caritra*, "behaviour, conduct" (CDIAL 4691).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
