## You'll want to know: a la larga
<!-- hl-knowledge: introduces=[ES-LEX-C535-FINAL-02]; assesses=[] -->

**a la larga** — "in the long run".

> A la larga, fue lo mejor para todos.
>
> *In the long run, it was the best thing for everyone.*

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*a la larga* is built on *largo* 'long', which is inherited from Latin *largus* 'abundant, generous' (EtymDB). Spanish moved the sense from plenty to length.
