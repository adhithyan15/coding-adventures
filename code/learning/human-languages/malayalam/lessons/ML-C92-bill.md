## You'll want to know: ബിൽ
<!-- hl-knowledge: introduces=[ML-LEX-C92-BILL-01]; assesses=[] -->

**ബിൽ** — *bil* — the bill.

Another borrowing, and this one **kept its meaning intact** — which is the point
of meeting it right after one that did not. **Borrowed words are not all alike;
you have to check each one.**

The asking costs nothing new. **എത്ര** has been yours since the distance
chapter, and **വില** since the shopping chapter:

| | |
|---|---|
| **എത്ര രൂപ?** | how many rupees? |
| **ബിൽ** | the bill |
