## You'll want to know: लिहाज़
<!-- hl-knowledge: introduces=[HI-LEX-C471-VINAMRA471-03]; assesses=[] -->

**लिहाज़** — *lihāz* — "consideration; regard".

> बूढ़े लोगों का लिहाज़ करना चाहिए।
>
> *būṛhe logoṁ kā lihāz karnā cāhiye.*
>
> One should show consideration for old people.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**लिहाज़** (*lihāz*) is usually traced to Arabic *liḥāẓ*, "a look, regard", which reached Hindi through Persian: having regard for someone.
