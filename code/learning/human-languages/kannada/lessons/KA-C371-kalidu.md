# ಕಾಲಿಡು (kāliḍu) — to set foot

## Warm-up

## You'll want to know: ಕಾಲಿಡು
<!-- hl-knowledge: introduces=[KA-LEX-C371-PALLAKKI371-05]; assesses=[] -->

**ಕಾಲಿಡು** — *kāliḍu* — "to set foot".

> ಹತ್ತು ವರ್ಷದ ನಂತರ ಅವನು ತನ್ನ ಊರಿಗೆ ಕಾಲಿಟ್ಟನು.
>
> *hattu varṣada nantara avanu tanna ūrige kāliṭṭanu.*
>
> After ten years he set foot in his home town.

Past (I …): ಕಾಲಿಟ್ಟೆ, *kāliṭṭe*.

Where one steps takes -ಗೆ. It also means to enter a new stage: ಹೊಸ ವರ್ಷಕ್ಕೆ ಕಾಲಿಡು.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಕಾಲಿಡು** (*kāliḍu*) is a native Dravidian compound: *kāl*, "foot, leg" (DEDR 1479), and *iḍu*, "to put, to place" (DEDR 442).
