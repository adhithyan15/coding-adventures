# привет — look, hide, write, compare

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[RU-LEX-PRIVET, RU-SCRIPT-P-01, RU-SCRIPT-R-01, RU-SCRIPT-I-01, RU-SCRIPT-V-01, RU-SCRIPT-E-01, RU-SCRIPT-T-01] -->

Look at **привет** for five seconds. Touch the three chunks **при · ве · т**.
Do not copy while the model is visible.

## Writing — delayed copy
<!-- hl-knowledge: introduces=[]; assesses=[RU-LEX-PRIVET, RU-SCRIPT-P-01, RU-SCRIPT-R-01, RU-SCRIPT-I-01, RU-SCRIPT-V-01, RU-SCRIPT-E-01, RU-SCRIPT-T-01] -->
<!-- hl-writing-stage: delayed-copy -->

- cover **привет**
- wait five seconds
- write it once from memory
- uncover the model and compare one chunk at a time

Circle and repair one differing letter if needed. Repair is part of retrieval.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[RU-LEX-PRIVET, RU-SCRIPT-P-01, RU-SCRIPT-R-01, RU-SCRIPT-I-01, RU-SCRIPT-V-01, RU-SCRIPT-E-01, RU-SCRIPT-T-01] -->
<!-- hl-activity: {"id":"RU-W05-privet-delayed-copy-check","kind":"text","assesses":["RU-LEX-PRIVET","RU-SCRIPT-P-01","RU-SCRIPT-R-01","RU-SCRIPT-I-01","RU-SCRIPT-V-01","RU-SCRIPT-E-01","RU-SCRIPT-T-01"],"prompt":"After hiding the model for five seconds, write the Russian word for informal hi and then compare it.","answer":"привет","accepted":[],"feedback":{"correct":"Yes: привет, recovered after a short delay.","incorrect":"Uncover the model, repair only the differing letter, and try once more tomorrow."},"response_seconds":18} -->
