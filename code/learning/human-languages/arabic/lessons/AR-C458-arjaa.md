## You'll want to know: أرجع
<!-- hl-knowledge: introduces=[AR-LEX-C458-DAMAN458-04]; assesses=[] -->

**أرجع** — *arjaʿa* — "to take back; to return (something)".

> أرجعت الحذاء إلى المتجر.
>
> *arjaʿtu al-ḥidhāʾ ilā al-matjar.*
>
> I took the shoes back to the shop.

Present: يرجع, *yurjiʿ*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**أرجع** (*arjaʿa*) is built on the native Arabic root *r-j-ʿ*, "to return" (Lane). It is Form IV, "to make go back".
