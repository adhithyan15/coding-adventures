# ਨੱਸਣਾ (nassṇā) — to run away

## You'll want to know: ਨੱਸਣਾ
<!-- hl-knowledge: introduces=[PA-LEX-C311-LOST311-03]; assesses=[] -->

**ਨੱਸਣਾ** — *nassṇā* — "to run away".

> ਚੋਰ ਰਾਤ ਨੂੰ ਪਿਛਲੇ ਦਰਵਾਜ਼ੇ ਤੋਂ ਨੱਸਿਆ।
>
> *chor rāt nū̃ pichhle darvāze ton nassiā.*
>
> The thief ran away through the back door at night.

Past (I …): ਮੈਂ ਕੁੱਤੇ ਤੋਂ ਨੱਸਿਆ, *maiṁ kutte ton nassiā*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ਨੱਸਣਾ** (*nassṇā*) is inherited from Sanskrit *naśyati*, "is lost, perishes, runs away"; CDIAL lists Punjabi *nassṇā*, "to flee", under it (CDIAL 7027).
