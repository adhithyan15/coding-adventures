# ಟ್ಯಾಕ್ಸಿ (ṭyāksi) — a taxi

## You'll want to know: ಟ್ಯಾಕ್ಸಿ
<!-- hl-knowledge: introduces=[KA-LEX-C451-VAHANA451-03]; assesses=[] -->

**ಟ್ಯಾಕ್ಸಿ** — *ṭyāksi* — "a taxi".

> ರಾತ್ರಿ ತಡವಾದ್ದರಿಂದ ನಾವು ಟ್ಯಾಕ್ಸಿ ಹಿಡಿದೆವು.
>
> *rātri taḍavāddarinda nāvu ṭyāksi hiḍidevu.*
>
> Because it was late at night we took a taxi.

ಟ್ಯಾಕ್ಸಿ ಹಿಡಿ, to catch a taxi.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಟ್ಯಾಕ್ಸಿ** (*ṭyāksi*) is a loan from English *taxi*.
