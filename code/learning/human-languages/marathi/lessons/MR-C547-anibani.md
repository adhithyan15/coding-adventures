# आणीबाणी (āṇībāṇī) — an emergency

## You'll want to know: आणीबाणी
<!-- hl-knowledge: introduces=[MR-LEX-C547-ANIBANI547-01]; assesses=[] -->

**आणीबाणी** — *āṇībāṇī* — "an emergency".

> आणीबाणीच्या वेळी हा दरवाजा उघडतात.
>
> *āṇībāṇīcyā veḷī hā darvājā ughaḍtāt.*
>
> This door is opened in an emergency.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**आणीबाणी** (*āṇībāṇī*) is a Marathi word for a moment of crisis; its origin is not settled.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
