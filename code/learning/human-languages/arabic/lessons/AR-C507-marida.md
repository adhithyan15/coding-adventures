# مرض (mariḍa) — to fall ill

## You'll want to know: مرض
<!-- hl-knowledge: introduces=[AR-LEX-C507-MARAD507-01]; assesses=[] -->

**مرض** — *mariḍa* — "to fall ill".

> مرض أخي في الشتاء الماضي.
>
> *mariḍa akhī fī ash-shitāʾ al-māḍī.*
>
> My brother fell ill last winter.

Present: يمرض, *yamraḍ*.

The noun مرض, read maraḍ, is an illness.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**مرض** (*mariḍa*) is built on the native Arabic root *m-r-ḍ*, "to be sick" (Lane). Marīḍ, sick, which you know, is from the same root.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
