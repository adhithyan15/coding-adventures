# మొరపెట్టుకో (morapeṭṭukō) — to petition; to plead

## You'll want to know: మొరపెట్టుకో
<!-- hl-knowledge: introduces=[TE-LEX-C379-BADHITUDU379-04]; assesses=[] -->

**మొరపెట్టుకో** — *morapeṭṭukō* — "to petition; to plead".

> బాధితులు అధికారులకు మొరపెట్టుకున్నారు.
>
> *bādhitulu adhikārulaku morapeṭṭukunnāru.*
>
> The victims pleaded with the officials.

Past (I …): మొరపెట్టుకున్నాను, *morapeṭṭukunnānu*.

To whom takes -కు: అధికారులకు మొరపెట్టుకో.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**మొరపెట్టుకో** (*morapeṭṭukō*) is a native compound: *moṟa*, "a cry, a scream" (DEDR 5013), and *peṭṭukō*, "to put for oneself" (DEDR 4390).
