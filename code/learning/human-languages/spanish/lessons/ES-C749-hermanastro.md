## You'll want to know: el hermanastro
<!-- hl-knowledge: introduces=[ES-LEX-C749-EDADES-02]; assesses=[] -->

**el hermanastro** — "the stepbrother".

> Mi hermanastro vive con nosotros.
>
> *My stepbrother lives with us.*

*La hermanastra* — stepsister.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*hermanastro* is built on *hermano* with the ending *-astro* (EtymDB); *hermano* is inherited from Latin *germānus* "of the same parents".
