# આવશ્યક (āvaśyak) — essential

## Warm-up

## You'll want to know: આવશ્યક
<!-- hl-knowledge: introduces=[GU-LEX-C375-JARURI375-01]; assesses=[] -->

**આવશ્યક** — *āvaśyak* — "essential".

> જો તમે બેંકમાં ખાતું ખોલશો તો ઓળખપત્ર આવશ્યક છે.
>
> *jo tame beṅkmā̃ khātũ kholśo to oḷakhpatra āvaśyak che.*
>
> If you open a bank account, an identity card is essential.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**આવશ્યક** (*āvaśyak*) is a tatsama, borrowed from Sanskrit *āvaśyaka*, "necessary, inevitable" (Monier-Williams).

One more word for saying what happens if.
