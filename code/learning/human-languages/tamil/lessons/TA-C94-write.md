# எழுதுங்கள் (eḻutuṅkaḷ) — please write it

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TA-LEX-C93-ASK-05, TA-LEX-C94-LOST-01] -->

[PAUSE 2s] Before the new one: say the Tamil for I did not hear it, then the Tamil for I don't understand.

## You'll want to know: எழுதுங்கள்
<!-- hl-knowledge: introduces=[TA-LEX-C94-LOST-02]; assesses=[] -->

**எழுதுங்கள்** (*eḻutuṅkaḷ*) — "please write (it)".

It shares its root with **எழுத்து**, "a letter of the script". **இங்கே எழுதுங்கள்** — "please
write it here".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

A request to see the word.
