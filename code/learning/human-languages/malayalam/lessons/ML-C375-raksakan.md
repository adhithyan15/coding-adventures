# രക്ഷകൻ (rakṣakan) — a rescuer; a saviour

## You'll want to know: രക്ഷകൻ
<!-- hl-knowledge: introduces=[ML-LEX-C375-RAKSHA375-01]; assesses=[] -->

**രക്ഷകൻ** — *rakṣakan* — "a rescuer; a saviour".

> ആ ചെറുപ്പക്കാരൻ ഗ്രാമത്തിന്റെ രക്ഷകനായി.
>
> *ā ceṟuppakkāran grāmattinṟe rakṣakanāyi.*
>
> That young man became the village's saviour.

The noun രക്ഷ means protection; a woman rescuer is രക്ഷക.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**രക്ഷകൻ** (*rakṣakan*) is borrowed from Sanskrit *rakṣaka*, "protecting, guarding" (Monier-Williams), with the Malayalam masculine ending -ൻ.
