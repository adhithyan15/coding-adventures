# சரணாலயம் (caraṇālayam) — a sanctuary

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TA-LEX-C436-KATAL436-05, TA-LEX-C437-VILANKU437-01] -->

[PAUSE 2s] Before the new one: say the Tamil for coral, then the Tamil for wildlife.

## You'll want to know: சரணாலயம்
<!-- hl-knowledge: introduces=[TA-LEX-C437-VILANKU437-02]; assesses=[] -->

**சரணாலயம்** — *caraṇālayam* — "a sanctuary".

> இந்தச் சரணாலயத்தில் பல நாடுகளிலிருந்து வந்த பறவைகள் இருக்கின்றன.
>
> *intac caraṇālayattil pala nāṭukaḷiliruntu vanta paṟavaikaḷ irukkiṉṟaṉa.*
>
> In this sanctuary there are birds that came from many countries.

பறவைகள் சரணாலயம் is a bird sanctuary.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**சரணாலயம்** (*caraṇālayam*) is built from two words borrowed from Sanskrit: *śaraṇa*, "shelter" (CDIAL 12326), + *ālaya*, "a house, a dwelling" (CDIAL 1366).
