# બાકી (bākī) — remaining, left over

## You'll want to know: બાકી
<!-- hl-knowledge: introduces=[GU-LEX-C178-START178-04]; assesses=[] -->

**બાકી** — *bākī* — "remaining, left over".

> **હજી કામ બાકી છે.** — *hajī kām bākī che* — "There is still work left."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**બાકી** (*bākī*) is a loan from Arabic *bāqī*, "remaining, lasting", which reached Gujarati through Persian. Its Arabic root is *b-q-y*, "to remain" (Lane).
