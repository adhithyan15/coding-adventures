## You'll want to know: goutter
<!-- hl-knowledge: introduces=[FR-LEX-C428-FUITE-04]; assesses=[] -->

**goutter** — "to drip".

> Le robinet goutte toute la nuit.
>
> *The tap drips all night.*

*Une goutte* — a drop.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*goutter* is built on *goutte* 'drop', which is inherited from Latin *gutta* (Lewis & Short). EtymDB does not list the verb.
