# ಕಾಲುದಾರಿ (kāludāri) — a footpath

## You'll want to know: ಕಾಲುದಾರಿ
<!-- hl-knowledge: introduces=[KA-LEX-C446-DARI446-01]; assesses=[] -->

**ಕಾಲುದಾರಿ** — *kāludāri* — "a footpath".

> ಹೊಲಗಳ ನಡುವೆ ಒಂದು ಕಾಲುದಾರಿ ಇದೆ.
>
> *holagaḷa naḍuve ondu kāludāri ide.*
>
> There is a footpath between the fields.

ಕಾಲು, foot, plus ದಾರಿ, way: a way for feet only.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಕಾಲುದಾರಿ** (*kāludāri*) is a native Kannada compound of *kāl*, "foot, leg" (DEDR 1479), and ದಾರಿ, "a way" (DEDR 3170).
