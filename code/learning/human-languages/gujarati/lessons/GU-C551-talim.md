## You'll want to know: તાલીમ
<!-- hl-knowledge: introduces=[GU-LEX-C551-TALIM551-01]; assesses=[] -->

**તાલીમ** — *tālīm* — "training".

> જો તમે સારી તાલીમ લેશો તો તમે ઝડપી દોડી શકશો.
>
> *jo tame sārī tālīm leśo to tame jhaḍpī doḍī śakśo.*
>
> If you get good training, you'll be able to run fast.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**તાલીમ** (*tālīm*) is usually traced to Arabic *taʿlīm*, "teaching, instruction", through Persian.
