## You'll want to know: le braqueur
<!-- hl-knowledge: introduces=[FR-LEX-C296-BRAQUAGE-02]; assesses=[] -->

**le braqueur** — "the armed robber".

> Les braqueurs sont partis avec l'argent.
>
> *The robbers left with the money.*

Feminine: *la braqueuse*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*braqueur* is built with the agent suffix *-eur* on the verb meaning "to aim a gun"; the origin is not settled (EtymDB lists no parent).
