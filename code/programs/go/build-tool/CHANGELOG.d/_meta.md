# Changelog

This directory is the committed changelog. Each numbered Markdown file is one
entry; a higher ordinal is a newer entry. Add a new file per change instead of
editing an existing one, so concurrent branches never collide on a shared file.

Converted from the former monolithic `CHANGELOG.md` on 2026-11-12; each of its
top-level sections became one file, verbatim, numbered in its original order.
