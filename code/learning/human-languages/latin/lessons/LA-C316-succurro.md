## You'll want to know: succurrō, succurrere
<!-- hl-knowledge: introduces=[LA-LEX-C316-ERIPIO-04]; assesses=[] -->

**succurrō, succurrere** — "to run to help".

> Puellae in aquā clāmantī duo nautae succurrērunt.
>
> *Two sailors ran to help the girl who was shouting in the water.*

*succurrō, succurrere, succurrī, succursum*, with the dative. English *succour*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**succurrō** is built on *currō*, "to run", with *sub-* (EtymDB): to run up to someone. English *succour* comes from it through French.
