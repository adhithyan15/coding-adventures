## You'll want to know: विक्रेता
<!-- hl-knowledge: introduces=[SA-LEX-C430-HATTA430-02]; assesses=[] -->

**विक्रेता** — *vikretā* — "a seller".

> विक्रेता उच्चैः वदति।
>
> *vikretā uccaiḥ vadati.*
>
> The seller calls out loudly.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**विक्रेता** (*vikretā*) is built from *vi* and the root √krī, "to buy", which with *vi* means to sell, as in *vikrīṇāti*, "sells", with the agent ending *-tṛ*; MW gives *vikretṛ* as a seller (MW).
