## You'll want to know: герой
<!-- hl-knowledge: introduces=[RU-LEX-C319-LEGENDA-03]; assesses=[] -->

**герой** (*geróy*) — "a hero; a main character".

> Главный герой книги — маленький мальчик.
>
> *Glávnyy geróy knígi — málenkiy málchik.*
>
> The main character of the book is a little boy.

*Главный герой* — the main character.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*герой* came through French *héros* and Latin *hērōs* from Greek *hḗrōs* "a hero, a demigod" (EtymDB).
