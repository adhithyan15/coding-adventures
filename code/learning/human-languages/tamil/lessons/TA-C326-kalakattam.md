# காலகட்டம் (kālakaṭṭam) — a period; an era

## You'll want to know: காலகட்டம்
<!-- hl-knowledge: introduces=[TA-LEX-C326-VARALARU326-04]; assesses=[] -->

**காலகட்டம்** — *kālakaṭṭam* — "a period; an era".

> அந்தக் காலகட்டத்தில் கார்கள் குறைவு.
>
> *antak kālakaṭṭattil kārkaḷ kuṟaivu.*
>
> In that period there were few cars.

A -அம் noun: காலகட்டத்தில், in that period.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**காலகட்டம்** (*kālakaṭṭam*) is a Tamil compound built from காலம், "time", borrowed from Sanskrit *kāla* (CDIAL 3084), and கட்டம், "a stage, a block".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
