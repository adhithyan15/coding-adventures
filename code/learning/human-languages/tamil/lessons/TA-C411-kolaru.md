# கோளாறு (kōḷāṟu) — a fault; a malfunction

## You'll want to know: கோளாறு
<!-- hl-knowledge: introduces=[TA-LEX-C411-KOLARU411-01]; assesses=[] -->

**கோளாறு** — *kōḷāṟu* — "a fault; a malfunction".

> இயந்திரத்தில் ஏதோ கோளாறு இருக்கிறது.
>
> *iyantirattil ētō kōḷāṟu irukkiṟatu.*
>
> There is some fault in the engine.

Of the body too: வயிற்றுக் கோளாறு, a stomach upset.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**கோளாறு** (*kōḷāṟu*), "a fault, a disorder", is an everyday Tamil word whose origin is not settled.
