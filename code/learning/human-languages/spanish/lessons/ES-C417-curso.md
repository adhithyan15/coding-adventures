# el curso — a path of learning

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ES-LEX-APRENDER] -->

[PAUSE 2s] Recall **aprender**, to learn. A planned path for learning something
is **un curso**, a course or class.

## The word, taken apart
<!-- hl-knowledge: introduces=[ES-LEX-CURSO]; assesses=[] -->

Latin **cursus** meant a running or a course, from **currere**, to run. English
**course** keeps the same idea of a route, while **current** is something
running onward. A learning course is a route followed from lesson to lesson.

## Grammar Lens: name the subject
<!-- hl-knowledge: introduces=[]; assesses=[ES-LEX-CURSO] -->

The noun is masculine: **el curso**, **un curso**. Use **de** to name its
subject: **un curso de natación**, a swimming course.
