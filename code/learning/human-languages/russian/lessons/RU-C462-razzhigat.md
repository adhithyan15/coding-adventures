## You'll want to know: разжигать
<!-- hl-knowledge: introduces=[RU-LEX-C462-KOSTYOR-04]; assesses=[] -->

**разжигать** (*razzhigát*) — "to light (a fire), to kindle".

> Папа разжигает костёр одной спичкой.
>
> *Pápa razzhigáyet kostyór odnóy spíchkoy.*
>
> Dad lights the campfire with one match.

Imperfective; perfective *разжечь* (*разожгу, разожжёшь*).

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*разжигать* is built from *раз-* and *-жигать*, from *жечь* 'to burn', the same root as *зажигать* 'to light'. EtymDB lists *разжигать* without a deeper source.
