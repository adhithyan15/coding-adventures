# Session Map — German Chapters 1–2

How the lessons compose into commute sessions. Mechanics in
[`HL00`](../../../specs/HL00-human-language-curriculum-framework.md); same
spaced-repetition schedule as the other tracks (a word from session *N*
resurfaces at *N+1, N+3, N+7, N+15*). Lessons named by slug; this map is the
authoritative order.

Both chapters are now **generated from the lessons** rather than hand-written
LaTeX, so this table and the book are the same object seen twice: the order
below is the `sequence:` order the generator reads.

## Chapter 1 — Greetings

| Session | New lesson(s) | Introduces |
|---|---|---|
| 1 | hallo · Hallo (guided copy) | informal "hi" (a real English cousin); one copy with the model visible |
| 2 | gut | "good"/"well"; the High German Consonant Shift (d→t) |
| 3 | der / die / das | **three** genders (kept the neuter) |
| 4 | Tag | first noun (masc.); ≠ Latin *dies* |
| 5 | Guten Tag | assembled; the *-en* ending |
| 6 | Morgen · Guten Morgen | morning (masc.); *morning/tomorrow* |
| 7 | Abend · Guten Abend | evening (masc.); ← English *eve* |
| 8 | Nacht · Gute Nacht | night (fem.); the four-way *Nacht/night/noche/nuit*; *-e* vs *-en* |
| 9 | die (plural) | one article for every plural; *Tage/Morgen/Abende/Nächte* and the umlaut |
| 10 | practice | the greetings together |

## Chapter 2 — Introducing Yourself

| Session | New lesson(s) | Introduces |
|---|---|---|
| 11 | ich | "I" (← *\*ik*; Latin *ego*, English *I*) |
| 12 | du / Sie | familiar / formal **"you"**; *Sie* = capitalized "they" |
| 13 | heißen | "to be called" (← *\*haitaną*; English *hight*, *behest*) |
| 14 | ich heiße / du heißt / Sie heißen | one verb, three endings — the machine every German verb runs |
| 15 | ich heiße… | **"my name is…"** ("I am called"; + literal *mein Name ist*) |
| 16 | wie | "how" (← *\*hwī*; English *how/what/who*) |
| 17 | wie heißen Sie? | **"what's your name?"**; verb-second word order |
| 18 | mich | "me," the object form of *ich* (← *\*mek*; English *me*, French *me*) |
| 19 | freut mich | "pleased to meet you" ("it gladdens me"; ← *froh*) |
| 20 | practice | the whole introduction dialogue |

*du / Sie* moved ahead of *heißen* so the ending lesson can name the people it
conjugates for without borrowing them from a later session, and *mich* was
lifted out of *freut mich* so the phrase no longer uses a word it has not
taught.

Reviews of earlier words fold into each session per the interval schedule.
