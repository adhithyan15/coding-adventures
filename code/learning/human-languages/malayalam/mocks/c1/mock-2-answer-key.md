## Writing

Task 1 must synthesise the two visitor-management sources, distinguish ecological,
economic, and access outcomes, surface what each source leaves unmeasured, and
produce an independent 180–220-word Malayalam text. Task 2 must develop a
300–380-word critical argument with examples from two domains, a serious objection
and reply, an explicit decision rule, acknowledged limits, and a balanced conclusion.

## Speaking

Allow keyword notes only. Reward a distinction between portable academic access
and coerced assimilation, accurate integration of both sources, and a policy whose
limits are explicit. Collaboration must include comparison, challenge, repair,
and a conditional joint conclusion. Use all six follow-ups to test defence and
reformulation, then score the complete recording against the shared criteria.
