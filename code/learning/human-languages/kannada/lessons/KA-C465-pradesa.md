# ಪ್ರದೇಶ (pradēśa) — a region; an area

## You'll want to know: ಪ್ರದೇಶ
<!-- hl-knowledge: introduces=[KA-LEX-C465-PATTANA465-03]; assesses=[] -->

**ಪ್ರದೇಶ** — *pradēśa* — "a region; an area".

> ಈ ಪ್ರದೇಶದಲ್ಲಿ ತುಂಬಾ ಕಾಡು ಇದೆ.
>
> *ī pradēśadalli tumbā kāḍu ide.*
>
> There is a lot of forest in this region.

ಗ್ರಾಮೀಣ ಪ್ರದೇಶ, a rural area.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಪ್ರದೇಶ** (*pradēśa*) is borrowed from Sanskrit *pradēśa*, "a region, a country" (CDIAL 8668), built on *dēśa*, the source of ದೇಶ.
