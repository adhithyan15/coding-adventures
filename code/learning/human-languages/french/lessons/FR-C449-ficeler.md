## You'll want to know: ficeler
<!-- hl-knowledge: introduces=[FR-LEX-C449-BURALISTE-05]; assesses=[] -->

**ficeler** — "to tie up (with string)".

> Le vendeur a ficelé le paquet avec soin.
>
> *The shop assistant tied up the parcel carefully.*

*La ficelle* — string; also a thin baguette.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*ficeler* is built on *ficelle* 'string' (EtymDB lists the verb), which is usually traced to Vulgar Latin *fūnicella*, a small *fūnis* 'rope'.
