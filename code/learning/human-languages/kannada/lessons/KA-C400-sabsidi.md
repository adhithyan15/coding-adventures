# ಸಬ್ಸಿಡಿ (sabsiḍi) — a subsidy

## You'll want to know: ಸಬ್ಸಿಡಿ
<!-- hl-knowledge: introduces=[KA-LEX-C400-BAJET400-03]; assesses=[] -->

**ಸಬ್ಸಿಡಿ** — *sabsiḍi* — "a subsidy".

> ರೈತರಿಗೆ ಗೊಬ್ಬರದ ಮೇಲೆ ಸಬ್ಸಿಡಿ ಸಿಗುತ್ತದೆ.
>
> *raitarige gobbarada mēle sabsiḍi siguttade.*
>
> Farmers get a subsidy on fertiliser.

The Kannada word is ಸಹಾಯಧನ, help money.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಸಬ್ಸಿಡಿ** (*sabsiḍi*) is a loan from English *subsidy*.
