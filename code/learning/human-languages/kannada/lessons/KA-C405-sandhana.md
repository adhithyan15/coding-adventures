# ಸಂಧಾನ (sandhāna) — a negotiation

## You'll want to know: ಸಂಧಾನ
<!-- hl-knowledge: introduces=[KA-LEX-C405-SANDHANA405-02]; assesses=[] -->

**ಸಂಧಾನ** — *sandhāna* — "a negotiation".

> ಎರಡು ಕುಟುಂಬಗಳ ನಡುವೆ ಸಂಧಾನ ನಡೆಯಿತು.
>
> *eraḍu kuṭumbagaḷa naḍuve sandhāna naḍeyitu.*
>
> Talks took place between the two families.

ಸಂಧಾನಕಾರ, a negotiator.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಸಂಧಾನ** (*sandhāna*) is borrowed from Sanskrit *saṃdhāna*, "joining, uniting" (Monier-Williams): bringing two sides together.
