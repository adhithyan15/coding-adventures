# கர்ப்பம் (karppam) — pregnancy

## You'll want to know: கர்ப்பம்
<!-- hl-knowledge: introduces=[TA-LEX-C496-PIRAPPU496-01]; assesses=[] -->

**கர்ப்பம்** — *karppam* — "pregnancy".

> என் அக்கா இப்போது ஆறு மாதக் கர்ப்பமாக இருக்கிறாள்.
>
> *eṉ akkā ippōtu āṟu mātak karppamāka irukkiṟāḷ.*
>
> My elder sister is six months pregnant now.

கர்ப்பமாக இரு, to be pregnant.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**கர்ப்பம்** (*karppam*) is borrowed from Sanskrit *garbha*, "womb, foetus" (CDIAL 4055); Tamil writes the *g* and *bh* with க and ப.
