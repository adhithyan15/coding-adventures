# ನಿಬಂಧನೆ (nibandhane) — a stipulation; a regulation

## You'll want to know: ನಿಬಂಧನೆ
<!-- hl-knowledge: introduces=[KA-LEX-C430-SANDARBHA430-04]; assesses=[] -->

**ನಿಬಂಧನೆ** — *nibandhane* — "a stipulation; a regulation".

> ಸಾಲದ ನಿಬಂಧನೆಗಳನ್ನು ನಾನು ಗಮನವಿಟ್ಟು ಓದಿದೆ.
>
> *sālada nibandhanegaḷannu nānu gamanaviṭṭu ōdide.*
>
> I read the terms of the loan carefully.

Plural: ನಿಬಂಧನೆಗಳು, *nibandhanegaḷu*.

Mostly plural: ನಿಬಂಧನೆಗಳು.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ನಿಬಂಧನೆ** (*nibandhane*) is borrowed from Sanskrit *nibandhana*, "binding, fastening" (Monier-Williams).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
