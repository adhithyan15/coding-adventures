## You'll want to know: मुक्त करणे
<!-- hl-knowledge: introduces=[MR-LEX-C333-MOHIM333-04]; assesses=[] -->

**मुक्त करणे** — *mukta karṇe* — "to set free".

> राजाने सगळ्या कैद्यांना मुक्त केलं.
>
> *rājāne sagaḷyā kaidyānnā mukta kelaṁ.*
>
> The king set all the prisoners free.

Past, with -ने (he …): त्याने मुक्त केलं, *tyāne mukta kelaṁ*.

The one freed takes -ला; मुक्त होणे, to become free.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**मुक्त करणे** (*mukta karṇe*) joins *mukta*, a tatsama taken from Sanskrit *mukta*, 'loosed, set free' (Monier-Williams), to *karṇe*, 'to do'.
