## You'll want to know: مترجم
<!-- hl-knowledge: introduces=[FA-LEX-C528-BOOKS-05]; assesses=[] -->

**مترجم** (*motarjem*) — "a translator".

> مترجم این کتاب را از انگلیسی ترجمه کرد.
>
> *motarjem in ketâb râ az engelisi tarjome kard.*
>
> The translator translated this book from English.

Plural *motarjemân*. It shares its root with *tarjome* 'translation'.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*motarjem* comes from Arabic *mutarjim*, 'translator' (EtymDB), from the same root as *tarjome*, 'translation'.
