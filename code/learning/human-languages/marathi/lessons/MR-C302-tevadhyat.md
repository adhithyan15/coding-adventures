## You'll want to know: तेवढ्यात
<!-- hl-knowledge: introduces=[MR-LEX-C302-KSHAN302-04]; assesses=[] -->

**तेवढ्यात** — *tevaḍhyāt* — "at that very moment; meanwhile".

> मी निघणार होतो, तेवढ्यात पाऊस सुरू झाला.
>
> *mī nighṇār hoto, tevaḍhyāt pāūs surū jhālā.*
>
> I was about to leave when, at that very moment, it started to rain.

Built on तेवढा, that much, with -त: in that much time.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**तेवढ्यात** (*tevaḍhyāt*) is built from *tevaḍhā*, 'that much', with the locative ending *-t*: within that much time. The origin of *tevaḍhā* is not settled.
