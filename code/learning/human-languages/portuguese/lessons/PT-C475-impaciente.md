## You'll want to know: impaciente
<!-- hl-knowledge: introduces=[PT-LEX-C475-NERVOS-03]; assesses=[] -->

**impaciente** — "impatient".

> Fico impaciente quando o autocarro se atrasa.
>
> *I get impatient when the bus is late.*

The same form for a man and a woman.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*impaciente* is a learned borrowing from Latin *impatiēns* "unable to bear" (EtymDB), built on *patī* "to suffer, to bear".
