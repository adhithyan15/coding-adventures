## You'll want to know: congelar
<!-- hl-knowledge: introduces=[ES-LEX-C777-ENCHUFAR-01]; assesses=[] -->

**congelar** — "to freeze".

> Si no vas a comerlo hoy, congélalo.
>
> *If you aren't going to eat it today, freeze it.*

*Congelado* — frozen. *Los congelados* — frozen food.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*congelar* is a learned borrowing from Latin *congelāre* 'to cause to freeze' (EtymDB), built on *gelū* 'frost', the word that gave *hielo*.
