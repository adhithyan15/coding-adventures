# shopping recall one — rebuild the counter exchange

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ES-LEX-COSTAR, ES-LEX-CAMISA, ES-LEX-CAMISETA, ES-LEX-TALLA, ES-LEX-GORRO] -->

[PAUSE 2s] Give the five-word chain. (*Costar, la camisa, la camiseta, la
talla, el gorro*.)

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[ES-LEX-COSTAR, ES-LEX-CAMISA, ES-LEX-CAMISETA, ES-LEX-TALLA, ES-LEX-GORRO] -->

You can distinguish **camisa** from **camiseta**, ask **¿Qué talla?**, name
**el gorro**, and ask **¿Cuánto cuesta?**

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[ES-LEX-COSTAR, ES-LEX-CAMISA, ES-LEX-CAMISETA, ES-LEX-TALLA, ES-LEX-GORRO] -->

[PAUSE 1s]
- [YOU SAY: *la camisa y la camiseta*]
- [YOU SAY: *¿Qué talla?*]
- [YOU SAY: *el gorro*]
- [YOU SAY: *¿Cuánto cuesta?*]

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[ES-LEX-COSTAR, ES-LEX-CAMISETA, ES-LEX-TALLA] -->

[PAUSE 3s] Ask the size and cost of the T-shirt. (*¿Qué talla tiene la
camiseta? ¿Cuánto cuesta?*)
