# ఉద్దేశపూర్వకంగా (uddēśapūrvakaṅgā) — deliberately; on purpose

## You'll want to know: ఉద్దేశపూర్వకంగా
<!-- hl-knowledge: introduces=[TE-LEX-C426-ARAMBHAM426-04]; assesses=[] -->

**ఉద్దేశపూర్వకంగా** — *uddēśapūrvakaṅgā* — "deliberately; on purpose".

> అతను ఉద్దేశపూర్వకంగా ఆ విషయం దాచాడు.
>
> *atanu uddēśapūrvakaṅgā ā viṣayaṁ dācāḍu.*
>
> He hid the matter on purpose.

ఉద్దేశం, an intention, + పూర్వకంగా, with ... in front.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ఉద్దేశపూర్వకంగా** (*uddēśapūrvakaṅgā*) is built from Sanskrit *uddeśa*, "aim, direction", and *pūrvaka*, "earlier, preceded by" (Monier-Williams), with the adverb ending -గా: with the aim already in front.
