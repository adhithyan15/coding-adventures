## Fixed — two Marwadi root slugs name one etymon each

- **MW-C73-nuvo** moves from `sanskrit-nava` to `sanskrit-nava-new` (*náva¹* "new", CDIAL 6983). Bare `sanskrit-nava` was also used for *náva²* "nine".
- **MW-C05-hear-hai** moves from `sanskrit-akshati` to `sanskrit-akseti`, the spelling the Bengali and Gujarati lessons use for the same *ākṣēti* (CDIAL 1031) its hook cites.
