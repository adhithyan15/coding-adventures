## Fixed — Sanskrit root slugs name one etymon each

- **SA-C44-yellow** moves from `sanskrit-pita-drunk` to `sanskrit-pita-yellow`. CDIAL gives *pītá¹* "drunk" (8229) and *pīta²* "yellow" (8230) separate entries, and MW lists them as separate homonyms.
- **SA-C25-foot** and **SA-C104-padatranam** move from `sanskrit-pada` to `sanskrit-pada-foot`. *Pāda* "foot" is CDIAL 8056; `sanskrit-pada` stays with *padá* "step, word" (CDIAL 7747) in SA-C168, SA-C193 and SA-C195.
- **SA-C148-malakarah** moves from `sanskrit-mala` to `sanskrit-mala-garland`, the slug SA-C30-garland uses. Bare `sanskrit-mala` also named *mala* "dirt".
- **SA-C152-kalah** moves from `sanskrit-kala-time` to `sanskrit-kaala-time`, the spelling eleven Bengali, Malayalam, Marathi, Tamil and Telugu lessons use for *kālá²* "time" (CDIAL 3084).
