# குடி — a word with nothing new in it

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TA-LEX-C65-DOING-01, TA-SCRIPT-TTA-01] -->

[PAUSE 2s] Two lessons ago you learned to say *kuḍi*, and a walking word came
between. Now look at it on the page.

## Script you'll notice: nothing new
<!-- hl-knowledge: introduces=[TA-SCRIPT-READ-KUDI-01]; assesses=[TA-SCRIPT-ABUGIDA-VA-KA-02, TA-SCRIPT-U-SIGN-01, TA-SCRIPT-TTA-01, TA-SCRIPT-I-SIGN-WRITE-NANDRI-01] -->

Every lesson in this strand so far has arrived carrying a letter you had not
met. This one arrives carrying none. All four pieces of **குடி** are already
yours, and the work is putting them together.

| piece | | |
|---|---|---|
| **கு** | *ku* — **க** with the **ு** sign | **க** from the very first writing lesson; the **ு** hook from *uṇavu* |
| **டி** | *ḍi* — **ட** with the **ி** sign | **ட** from *eppaḍi*; the **ி** sign from *naṉṟi* |

> **கு · டி → குடி**

Two letters, two signs riding them, and a word you have been saying since the
drinking lesson. Nothing here is a new shape; the only new thing is that these
four now sit together.

## Script you'll notice: the letter you can hear moving
<!-- hl-knowledge: introduces=[]; assesses=[TA-SCRIPT-TTA-01] -->

**ட** is the letter this book writes as *ḍ* here and as *ṭ* elsewhere, because
Tamil does not mark the difference on the page — the position in the word
decides it. Inside **எப்படி** you say *eppaḍi*, and inside **குடி** you say
*kuḍi*: in both, **ட** sits between vowels and softens. The same shape, read by
where it stands.
