# ஏற்றம் (ēṟṟam) — an ascent; a rise

## You'll want to know: ஏற்றம்
<!-- hl-knowledge: introduces=[TA-LEX-C408-VALAIVU408-03]; assesses=[] -->

**ஏற்றம்** — *ēṟṟam* — "an ascent; a rise".

> இந்த ஏற்றத்தில் மிதிவண்டி ஓட்டுவது கடினம்.
>
> *inta ēṟṟattil mitivaṇṭi ōṭṭuvatu kaṭiṉam.*
>
> Riding a bicycle up this climb is hard.

Its opposite is இறக்கம், a descent.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ஏற்றம்** (*ēṟṟam*) is built from ஏறு, "to climb, to rise" (DEDR 916), with the noun ending *-am* and the doubled stop.
