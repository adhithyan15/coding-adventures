# അനുശോചിക്കുക (anuśōcikkuka) — to offer condolences

## You'll want to know: അനുശോചിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C392-ANUSOCHANAM392-05]; assesses=[] -->

**അനുശോചിക്കുക** — *anuśōcikkuka* — "to offer condolences".

> അയൽക്കാർ ആ മരണത്തിൽ അനുശോചിച്ചു.
>
> *ayalkkār ā maraṇattil anuśōciccu.*
>
> The neighbours offered condolences on that death.

Past: അനുശോചിച്ചു, *anuśōciccu*.

The death takes -ഇൽ: മരണത്തിൽ അനുശോചിച്ചു.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**അനുശോചിക്കുക** (*anuśōcikkuka*) is built on അനുശോചനം (*anuśōcanaṁ*), from Sanskrit *anuśocana*, "sorrow" (Monier-Williams), with the Malayalam verb ending -ിക്കുക.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
