# തൊപ്പി (toppi) — a cap

## You'll want to know
<!-- hl-knowledge: introduces=[ML-LEX-C100-CAP-01]; assesses=[] -->

**തൊപ്പി** — *toppi* — **a cap.**

> **ഇത് പുതിയ തൊപ്പിയാണ്.** — *itŭ putiya toppiyāṇŭ* — "This is a new cap."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C100-CAP-01, ML-LEX-C100-SARI-01, ML-LEX-C100-SANDAL-01, ML-LEX-AANU-01] -->

**Four things worn, and only two endings between them.** **തൊപ്പി** ends in
**ഇ**, so it joins the way **സാരി** does:

| ends in | word | joined to **ആണ്** |
|---|---|---|
| half-u | **മുണ്ട്** | **മുണ്ടാണ്** (*muṇṭāṇŭ*) |
| half-u | **ചെരുപ്പ്** | **ചെരുപ്പാണ്** (*ceruppāṇŭ*) |
| **ഇ** | **സാരി** | **സാരിയാണ്** (*sāriyāṇŭ*) |
| **ഇ** | **തൊപ്പി** | **തൊപ്പിയാണ്** (*toppiyāṇŭ*) |

**Nothing in this chapter asked you to learn a join.** Both were already yours —
the half-u from the song word, the **യ** from the game and the beauty words.
What the chapter gave you is four things to wear.
