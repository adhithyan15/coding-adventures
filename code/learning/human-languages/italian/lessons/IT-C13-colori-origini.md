# The colour paths — five colours, three roads

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[IT-ETYMON-ROSSO-BLU-02, IT-ETYMON-ROSSO-BLU-03] -->

[PAUSE 2s] Say **rosso** and **blu**. One came down from Latin; the other walked in
from the north. Which is which?

## What you've built: the colour paths
<!-- hl-knowledge: introduces=[IT-NOTICE-ROSSO-BLU-05]; assesses=[] -->

| Italian | source |
|---|---|
| nero | Latin *niger* |
| **bianco** | **Germanic** *blank* |
| rosso | Latin *russus* (ancient PIE root) |
| **blu** | **Germanic** *blāo* |
| **azzurro** | **Arabic** *lāzaward* |
