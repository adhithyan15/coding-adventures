# દુકાળ (dukāḷ) — drought, famine

## You'll want to know: દુકાળ
<!-- hl-knowledge: introduces=[GU-LEX-C221-DROUGHT221-01]; assesses=[] -->

**દુકાળ** — *dukāḷ* — "drought, famine".

> **આ વરસે દુકાળ પડશે.** — *ā varase dukāḷ paḍśe* — "There will be a drought this year."

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**દુકાળ** (*dukāḷ*) is a tadbhava. It comes from Sanskrit *duṣkāla*, "evil time", built from *duṣ-*, "bad", and *kāla*, "time"; CDIAL glosses the Gujarati word "famine" (CDIAL 6470).
