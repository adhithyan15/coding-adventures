## You'll want to know: эвакуатор
<!-- hl-knowledge: introduces=[RU-LEX-C409-POLOMKA-02]; assesses=[] -->

**эвакуатор** (*evakuátor*) — "a tow truck".

> Эвакуатор приехал через час.
>
> *Evakuátor priyékhal chérez chas.*
>
> The tow truck came an hour later.

Masculine. Built on *эвакуировать* — to evacuate, to remove.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*эвакуатор* is built on *эвакуировать* 'to evacuate, to clear away', which EtymDB lists without a source; it is usually traced to Latin *ēvacuāre* 'to empty out', on *vacuus* 'empty' (Lewis & Short).
