# Chapter-owned narration hash ledgers

These files are generated by `human-language-data`'s `generate:narration`
command. Each `<language>.d/` directory contains document-wide fields in
`_meta.json` and one chapter record in each zero-padded `NNNN.json` owner.
Changing one lesson or voice script therefore updates only its chapter owner,
even when other agents are regenerating other chapters of the same language.

Do not edit generated JSON by hand. CI's `check:narration` gate derives the
exact owner set in memory and compares every file byte for byte. Missing,
stale, unexpected, malformed, symlinked, non-regular, duplicate, mismatched, or
unsafe owners fail closed. The former flat `<language>.json` manifests are
forbidden; there is no tracked aggregate to regenerate or merge.
