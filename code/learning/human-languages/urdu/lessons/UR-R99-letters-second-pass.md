# (two letters) — From the word back to the letter — a second pass

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[UR-SCRIPT-C99-ZE-01, UR-SCRIPT-C99-TOE-01] -->

[PAUSE 3s] Write **ط** without looking, then say the word it came from.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[UR-SCRIPT-C99-ZE-01, UR-SCRIPT-C99-TOE-01] -->

| letter | name | the word it came from |
|---|---|---|
| ز | *ze* | **روز** *roz* |
| ط | *toe* | **طرف** *taraf* |

[PAUSE 2s each]
- [YOU SAY: each word in the table, then write the letter it gave you without looking]
- [YOU WRITE: each letter once more, slowly, larger than it is printed]

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[UR-SCRIPT-C99-ZE-01, UR-SCRIPT-C99-TOE-01] -->

[PAUSE 3s] Say each word in the table once more, and name the letter you took from it.
