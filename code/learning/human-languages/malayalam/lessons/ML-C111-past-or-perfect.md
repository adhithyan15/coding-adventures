# വന്നു — വന്നിട്ടുണ്ട്

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-CONCEPT-C32-VARUKA-02, ML-GRAMMAR-C111-PERFECT-01] -->

[PAUSE 2s] Say *he came*, then *he has come*.

## Grammar Lens: which one a situation asks for
<!-- hl-knowledge: introduces=[]; assesses=[ML-GRAMMAR-C111-PERFECT-01, ML-CONCEPT-C32-VARUKA-02] -->

| | |
|---|---|
| **അവൻ വന്നു** | reports the event |
| **അവൻ വന്നിട്ടുണ്ട്** | reports where that leaves things |

**Both are true of the same arrival.** Which you pick depends on what the person
listening needs: whether you are telling them what happened, or telling them how
matters stand because of it.

A useful test while the difference is settling: if you could follow your sentence
with *…so he is here now* without repeating yourself, the second form was the one
you wanted.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[ML-GRAMMAR-C111-PERFECT-01, ML-CONCEPT-C32-VARUKA-02] -->

[PAUSE 3s] Which form reports the event itself? (**വന്നു**.) Which reports how
things stand now? (**വന്നിട്ടുണ്ട്**.) How many new words did choosing between
them need? (**None.**)
