## You'll want to know: enquêter
<!-- hl-knowledge: introduces=[FR-LEX-C389-ENQUETE-02]; assesses=[] -->

**enquêter** — "to investigate".

> Deux policiers enquêtent sur l'accident.
>
> *Two police officers are investigating the accident.*

*Enquêter sur quelque chose*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*enquêter* is built on *enquête* "inquiry", from Old French *enqueste*, from Latin *inquīrere* "to search into" (Lewis & Short), built on *quaerere* "to seek".
