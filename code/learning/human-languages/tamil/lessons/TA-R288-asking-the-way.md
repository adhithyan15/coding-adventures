# Review — asking the way

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TA-GRAMMAR-C288-ASK-WAY-01, TA-GRAMMAR-C287-OBLIGATIVE-01, TA-LEX-C285-IRAM-01, TA-SCRIPT-RECOG-141] -->

[PAUSE 2s] Ask how to get to the hospital. Then read **ஈரம்** aloud, and name its first letter. (**ஈ**, *ī*.)

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[TA-GRAMMAR-C288-ASK-WAY-01, TA-GRAMMAR-C288-HOW-FAR-01, TA-GRAMMAR-C288-GIVE-WAY-01, TA-GRAMMAR-C288-LANDMARK-01, TA-GRAMMAR-C287-OBLIGATIVE-01, TA-GRAMMAR-C287-BECAUSE-DID-01, TA-LEX-C285-IRAM-01, TA-SCRIPT-RECOG-141] -->

[PAUSE 2s each]
- [YOU SAY: Excuse me, where is the bank? How far is it from here?]
- [YOU SAY: Go straight on, then turn right. It is opposite the temple.]
- [YOU SAY: It is near. You can walk.]
- [YOU SAY: Because it rained, the street is wet. Go slowly.]
- [YOU SAY: the way from the bus station to your house, for a visitor]

## Wrap-up Recall
