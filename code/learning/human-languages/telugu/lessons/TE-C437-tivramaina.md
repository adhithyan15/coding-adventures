## You'll want to know: తీవ్రమైన
<!-- hl-knowledge: introduces=[TE-LEX-C437-SANKLISTAM437-04]; assesses=[] -->

**తీవ్రమైన** — *tīvramaina* — "serious; severe".

> ఆ ప్రాంతంలో తీవ్రమైన నీటి సమస్య ఉంది.
>
> *ā prāntaṁlō tīvramaina nīṭi samasya undi.*
>
> There is a serious water problem in that area.

తీవ్రంగా, seriously, severely.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**తీవ్రమైన** (*tīvramaina*) is built on Sanskrit *tīvra*, "strong, severe, violent, intense" (Monier-Williams), with Telugu -మైన.
