## You'll want to know: നയിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C546-VYAVASAYAM546-05]; assesses=[] -->

**നയിക്കുക** — *nayikkuka* — "to lead; to guide".

> പരിചയമുള്ള ആ മാനേജർ ടീമിനെ നന്നായി നയിച്ചു.
>
> *paricayamuḷḷa ā mānējar ṭīmine nannāyi nayiccu.*
>
> That experienced manager led the team well.

Past: നയിച്ചു, *nayiccu*.

A leader is നേതാവ്, from the same Sanskrit root.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**നയിക്കുക** (*nayikkuka*) is built from Sanskrit *naya*, from *nayati*, "leads" (CDIAL 6966), with the Malayalam verb ending -ിക്കുക.
