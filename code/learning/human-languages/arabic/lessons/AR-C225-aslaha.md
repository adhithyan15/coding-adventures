## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**أصلح** (*aṣlaḥa*) is built on the native Arabic root *ṣ-l-ḥ*, "to be good, to be sound" (Lane). *Aṣlaḥa* is Form IV, "to make sound", to repair.
