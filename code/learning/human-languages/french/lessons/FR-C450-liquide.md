## You'll want to know: le liquide
<!-- hl-knowledge: introduces=[FR-LEX-C450-CAISSE-05]; assesses=[] -->

**le liquide** — "cash; the liquid".

> Le petit café accepte seulement le liquide.
>
> *The little café only takes cash.*

*Payer en liquide* — to pay cash.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*liquide* is a learned borrowing from Latin *liquidus* 'fluid' (EtymDB), from *liquēre* 'to be fluid': money that flows freely.
