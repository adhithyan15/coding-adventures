# സങ്കേതം (saṅkētaṁ) — a sanctuary; a refuge

## You'll want to know: സങ്കേതം
<!-- hl-knowledge: introduces=[ML-LEX-C499-VANAM499-03]; assesses=[] -->

**സങ്കേതം** — *saṅkētaṁ* — "a sanctuary; a refuge".

> ആ പക്ഷിസങ്കേതത്തിൽ പല തരം പക്ഷികൾ ഉണ്ട്.
>
> *ā pakṣisaṅkētattil pala taraṁ pakṣikaḷ uṇṭŭ.*
>
> That bird sanctuary has many kinds of birds.

A protected place: പക്ഷിസങ്കേതം, a bird sanctuary; വന്യജീവിസങ്കേതം, a wildlife sanctuary.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**സങ്കേതം** (*saṅkētaṁ*) is borrowed from Sanskrit *saṅketa*, "an agreed sign; an appointed place" (Monier-Williams); in Malayalam it came to mean a place set aside.
