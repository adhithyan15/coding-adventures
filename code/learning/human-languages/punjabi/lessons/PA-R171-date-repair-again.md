# One old date-form repair

Stop before looking at or marking the printed form. This is a short return to
the same two fictional cards, not a real personal date or a scored A1 mock.

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-DATE-REPAIR-01] -->

The old bank is still here: **ਕ** chooses A **੧੫/੦੧/੨੦੨੫**, and **ਖ** chooses B
**੨੫/੦੨/੨੦੨੫**. The label is **ਤਾਰੀਖ਼**. Check one dimension at a time:
selector, day, month, year, slash marks, then label spelling and spacing.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-DATE-REPAIR-01] -->
<!-- hl-writing-stage: guided-copy -->

Keep the bank visible. For **ਕ**, the printed value **੧੫/੦੧੨੦੨੫** lacks only
one slash. Copy it with that slash after **੦੧**: **੧੫/੦੧/੨੦੨੫**. Do not change
any digit. For **ਖ**, the value in **ਤਾਰੀਖ: ੨੫/੦੨/੨੦੨੫** is already right;
copy only the repaired label **ਤਾਰੀਖ਼** with its final dot beneath **ਖ਼**.
Leave the date untouched and keep the space after the colon.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-DATE-REPAIR-01] -->

Cover the two repairs for a few seconds. Point to the one missing mark in
each, then uncover the bank and compare. If one mark differs, repair that
mark alone. The model stays available; this is not independent timed writing.
