## The word, taken apart
<!-- hl-knowledge: introduces=[LA-LEX-C47-TABLE-05]; assesses=[] -->

**piscis** — "**a fish**."

Keep this word. It is the cleanest single demonstration in this book of how a
Latin word and an English one can be the same word.

Latin ***p***\-*iscis*. English ***f***\-*ish*. Same word.

The change is not random. Around two thousand years ago the Germanic branch
shifted every inherited **p** to **f**, and it did so *without exception*. That
is **Grimm's Law**, and you have already been shown its results without being
told the name:

- *pater* → **father**
- *pēs*, *pedis* → **foot**
- *piscis* → **fish**

Three pairs, one rule. Once you have it, you can run it yourself: Latin *plēnus*
against English **full**, Latin *prō* against **for**.

The loans came separately and kept the *p*: **Pisces** the constellation,
something **piscine**, a **piscina**. So English holds both the inherited form
and the borrowed one, and now you can tell which is which by looking at a single
letter.
