# ಬಾಯಾರಿಕೆ (bāyārike) — thirst

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C83-FEELINGS-04, KA-LEX-C83-FEELINGS-05] -->

[PAUSE 2s] Before the new one: say the Kannada for anger, then the Kannada for laughter.

## You'll want to know: ಬಾಯಾರಿಕೆ
<!-- hl-knowledge: introduces=[KA-LEX-C84-BODY-01]; assesses=[] -->

**ಬಾಯಾರಿಕೆ** (*bāyārike*) — "thirst". It begins with **ಬಾಯಿ** (*bāyi*), "mouth",
which you already know: thirst is a dry mouth.

**ನನಗೆ ಬಾಯಾರಿಕೆ** (*nanage bāyārike*) — "I am thirsty".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

Hunger's partner: the body asking for water.
