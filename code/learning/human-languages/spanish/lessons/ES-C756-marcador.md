## You'll want to know: el marcador
<!-- hl-knowledge: introduces=[ES-LEX-C756-PARTIDO-03]; assesses=[] -->

**el marcador** — "the scoreboard, the score".

> El marcador final fue dos a uno.
>
> *The final score was two-one.*

In Latin America *un marcador* is also a marker pen.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*marcador* is built on *marcar* with the ending *-dor*; *marcar* comes from Italian *marcare*, built on Germanic *marka* "boundary, sign".
