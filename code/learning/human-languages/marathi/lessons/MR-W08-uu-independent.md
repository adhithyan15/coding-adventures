# ऊ — long *ū* standing on its own

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more, and this runway is finished. It is the long partner of the letter you wrote a moment ago.

## Script
<!-- hl-knowledge: introduces=[MR-SCRIPT-UU-INDEPENDENT-01]; assesses=[MR-SCRIPT-U-INDEPENDENT-01, MR-SCRIPT-UU-MATRA-01] -->

> ऊ

**ऊ** is the independent long *ū*: **उ** with a tail carried down and to the
right, the same extra travel the long mark asked for below the line.

Four forms, one vowel: **उ** and **ऊ** when it stands alone, the short and long
marks when a consonant carries it. That symmetry is the whole vowel system of
this script, and you now write all of it.

## Writing — delayed copy
<!-- hl-knowledge: introduces=[]; assesses=[MR-SCRIPT-UU-INDEPENDENT-01] -->
<!-- hl-writing-stage: delayed-copy -->

Look at **ऊ** for five seconds, cover it, and write it once. Uncover and set the
four *u* forms in a row: **उ ऊ** and the two marks. Repair only one.
