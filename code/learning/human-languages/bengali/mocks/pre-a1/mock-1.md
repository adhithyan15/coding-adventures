# Bengali pre-A1 mock 1 — learner paper and examiner script

Administer reading for 10 minutes, listening for 10, writing for 12, and
speaking for 8. Support-language directions may explain an action but must not
translate an answer-bearing Bengali prompt. Give learners only the learner-facing
sections. Keep the examiner-only script and model cards at the end out of view.
Each listening item is read twice at 70–90 words per minute, with an eight-second
answer pause. No transcript, romanization, dictionary, or coaching is allowed.
Print Reading, Listening, and Writing as separate skill sheets; never hand out
this combined source file. Collect each completed sheet before giving the next
one. In particular, remove the Reading and Listening sheets before Writing, so
earlier Bengali words cannot serve as copyable spelling models. Give Speaking
prompts orally, without returning any earlier sheet.

## Reading — 10 minutes

Choose A, B, or C. The first six prompts are single Bengali words.

### Signs and words — items 1–6

1. **নমস্কার** — A greeting / B refusal / C name
2. **ধন্যবাদ** — A water / B thanks / C home
3. **হ্যাঁ** — A yes / B tea / C no
4. **না** — A name / B yes / C no
5. **নাম** — A school / B name / C bus
6. **পানি** — A water / B greeting / C language

### Phrases and notices — items 7–10

7. **আমার নাম মীরা।** — A My name is Mira. / B I live with Mira. / C Mira wants water.
8. **তুমি কেমন আছো?** — A What is your name? / B How are you? / C Where is the bus?
9. **আমি ভালো আছি।** — A I am well. / B I speak Bengali. / C I am leaving.
10. **কাল দেখা হবে।** — A Thank you. / B Please sit. / C See you tomorrow.

### Personal details — items 11–14

11. Form field **নাম: রবি** — A age Ravi / B name Ravi / C city Ravi
12. Form field **বয়স: ৯** — A age nine / B language nine / C nine books
13. Form field **শহর: ঢাকা** — A name Dhaka / B language Dhaka / C city Dhaka
14. Form field **ভাষা: বাংলা** — A city Bengali / B language Bengali / C name Bengali

## Listening — 10 minutes

The examiner reads script L1–L14 below, twice each. Learners see only these
choices; they do not see the script. Choose A, B, or C.

### Sounds and words — items 1–6

1. A name / B water / C thanks
2. A tea / B home / C water
3. A bus / B tea / C school
4. A home / B name / C language
5. A no / B yes / C thank you
6. A hello / B name / C no

### Greeting responses — items 7–10

7. A নমস্কার। / B না। / C পানি।
8. A আমার নাম মীরা। / B কোনো ব্যাপার না। / C চা।
9. A কাল দেখা হবে। / B আমার নাম রবি। / C আমি ভালো আছি।
10. A ধন্যবাদ। / B কাল দেখা হবে। / C না।

### Personal details — items 11–14

11. A the speaker's name is Sita / B the speaker lives in Sita / C the speaker wants tea
12. A the speaker is leaving Dhaka / B the speaker is named Dhaka / C the speaker lives in Dhaka
13. A the speaker reads Bengali / B the speaker speaks Bengali / C the speaker writes a name
14. A the speaker is nine years old / B the speaker has nine books / C the speaker is named Nine

## Writing — 12 minutes

The examiner shows each model card for ten seconds, takes it away, and only then
asks the learner to write. For dictation, play or read each word twice without
showing its spelling. The learner may not consult a visible answer model.

### Delayed recall — items 1–2

1. View examiner card W1 for ten seconds. After it is removed, write the word.
2. View examiner card W2 for ten seconds. After it is removed, write the word.

### Dictation — items 3–6

3. Write the word read from examiner card D3.
4. Write the word read from examiner card D4.
5. Write the word read from examiner card D5.
6. Write the word read from examiner card D6.

### Independent production — items 7–8

7. Beside a nonverbal picture of a person, write a chosen name in Bengali script.
8. Beside a nonverbal picture of two people meeting, write a Bengali greeting.

## Speaking — 8 minutes

The interlocutor may repeat each prompt once slowly. No written answer script is
shown to the learner.

1. Interlocutor: **নমস্কার।** Return a greeting.
2. Interlocutor: **তোমার নাম কি?** Give a chosen name.
3. Interlocutor: **তুমি কেমন আছো?** Give a short relevant answer.
4. Interlocutor: **তুমি কোথায় থাকো?** Give a place.
5. Interlocutor: **তুমি বাংলা বলো?** Give a relevant yes/no answer.
6. Situation: you want water. Make a short polite request in Bengali.
