## You'll want to know: turístico
<!-- hl-knowledge: introduces=[ES-LEX-C676-TURISMO-03]; assesses=[] -->

**turístico** — "tourist (as an adjective); touristy".

> Es una zona muy turística.
>
> *It is a very touristy area.*

*Clase turista* — economy class.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*turístico* is built on *turista* "tourist", which comes from English *tourist*, from French *tour* "a turn".
