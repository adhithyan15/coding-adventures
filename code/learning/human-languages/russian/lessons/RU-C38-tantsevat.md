**танцевать** (*tantsevát*) — "to dance".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**танцевать** is built on *танец*, "a dance", which came through Polish *taniec* from Middle High German *tanz*, "a dance" (Vasmer).
