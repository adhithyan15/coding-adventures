# ਮਨਜ਼ੂਰ (manzūr) — approved; accepted

## You'll want to know: ਮਨਜ਼ੂਰ
<!-- hl-knowledge: introduces=[PA-LEX-C338-PERM338-03]; assesses=[] -->

**ਮਨਜ਼ੂਰ** — *manzūr* — "approved; accepted".

> ਕੀ ਮੇਰੀ ਅਰਜ਼ੀ ਮਨਜ਼ੂਰ ਹੈ?
>
> *kī merī arzī manzūr hai?*
>
> Has my application been approved?

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ਮਨਜ਼ੂਰ** (*manzūr*) is a loan, usually traced through Persian to Arabic *manẓūr*, "looked at".
