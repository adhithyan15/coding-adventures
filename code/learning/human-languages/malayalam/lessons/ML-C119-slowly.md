# പതുക്കെ (patukke) — slowly

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C118-WEATHER-04, ML-LEX-C118-WEATHER-05] -->

[PAUSE 2s] Before the new one: say the Malayalam for mist, then the Malayalam for thunder and lightning.

## You'll want to know: പതുക്കെ
<!-- hl-knowledge: introduces=[ML-LEX-C119-SLOWLY-01]; assesses=[] -->

**പതുക്കെ** (*patukke*) — "slowly". **പതുക്കെ പറയൂ** (*patukke paṟayū*) — "please say it
slowly".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**പതുക്കെ** (*patukke*) is native Dravidian, from the verb "to crouch, move stealthily"; DEDR 3912 lists the root with Tamil *patuṅku* and Kannada *padugu*.
