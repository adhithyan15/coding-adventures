## You'll want to know: હોબાળો
<!-- hl-knowledge: introduces=[GU-LEX-C421-NOISE421-02]; assesses=[] -->

**હોબાળો** — *hobāḷo* — "an uproar; an outcry".

> ભાવ વધ્યા એટલે બજારમાં હોબાળો થયો.
>
> *bhāv vadhyā eṭle bajārmā̃ hobāḷo thayo.*
>
> Prices went up, so there was an uproar in the market.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**હોબાળો** (*hobāḷo*) No dictionary we use records an older form, so its history is not settled.
