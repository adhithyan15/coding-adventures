# অনুতপ্ত (ônutôptô) — repentant; contrite

## You'll want to know: অনুতপ্ত
<!-- hl-knowledge: introduces=[BN-LEX-C447-APHSOS447-03]; assesses=[] -->

**অনুতপ্ত** — *ônutôptô* — "repentant; contrite".

> চোরটা অনুতপ্ত হয়ে টাকা ফিরিয়ে দিল।
>
> *chorṭā ônutôptô hôye ṭākā phiriye dilô.*
>
> The thief, repentant, gave the money back.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**অনুতপ্ত** (*ônutôptô*) is a tatsama, Sanskrit *anutapta*, "heated" and so "filled with regret" (Monier-Williams): burning afterwards.

<!-- hl-knowledge: introduces=[]; assesses=[] -->
