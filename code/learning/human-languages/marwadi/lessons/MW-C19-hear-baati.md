# Hear *bāṭī* — hard wheat rolls

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-ROTI-01, MW-LEX-RIKSHA-01, MW-SCRIPT-PAISA-01] -->

[PAUSE 18s] Write flatbread and money, then say rickshaw.

## You'll want to know
<!-- hl-knowledge: introduces=[MW-LEX-BAATI-01]; assesses=[] -->

> *bāṭī* — **hard wheat rolls**

Two beats, both long, with the same curled middle consonant heard in *roṭī*.
These are baked hard rather than soft, which is why they take a different name
from ordinary flatbread. Hear it twice and say it once.
