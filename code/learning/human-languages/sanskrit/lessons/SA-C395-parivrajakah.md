## You'll want to know: परिव्राजकः
<!-- hl-knowledge: introduces=[SA-LEX-C395-SARTHA395-05]; assesses=[] -->

**परिव्राजकः** — *parivrājakaḥ* — "a wandering ascetic".

> परिव्राजकः ग्रामे एकां रात्रिं वसति।
>
> *parivrājakaḥ grāme ekāṃ rātriṃ vasati.*
>
> The wandering ascetic stays one night in a village.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**परिव्राजकः** (*parivrājakaḥ*) is built from *pari*, "around", and the root √vraj, "to walk, to go", with the agent ending *-aka*; MW gives *parivrājaka* as a wandering religious mendicant (MW).
