# লটারি (lôṭāri) — a lottery

## You'll want to know: লটারি
<!-- hl-knowledge: introduces=[BN-LEX-C533-DOIBAT533-05]; assesses=[] -->

**লটারি** — *lôṭāri* — "a lottery".

> লটারিতে জিতলে মামা একটা নতুন গাড়ি কিনবেন।
>
> *Lôṭārite jitle māmā ekṭā nôtun gāṛi kinben.*
>
> If my uncle wins the lottery, he will buy a new car.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**লটারি** (*lôṭāri*) is borrowed from English *lottery*.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
