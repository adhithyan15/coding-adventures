## You'll want to know: ধরন
<!-- hl-knowledge: introduces=[BN-LEX-C536-ROKOM536-04]; assesses=[] -->

**ধরন** — *dhôrôn* — "a manner; a style; a type".

> এই বাড়ির ধরন পুরনো।
>
> *Ei bāṛir dhôrôn purôno.*
>
> This house is old in style.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ধরন** (*dhôrôn*) is probably built on ধরা, "to hold" (CDIAL 6747): the way a thing is held or shaped.
