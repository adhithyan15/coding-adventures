## You'll want to know: सारांश
<!-- hl-knowledge: introduces=[MR-LEX-C345-NISHKARSH345-04]; assesses=[] -->

**सारांश** — *sārāṁś* — "a summary".

> मीराने धड्याचा सारांश सांगितला.
>
> *mīrāne dhaḍyācā sārāṁś sāṅgitlā.*
>
> Meera gave a summary of the lesson.

Masculine.

X चा सारांश, a summary of X.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**सारांश** (*sārāṁś*) is a learned compound built from Sanskrit *sāra*, "essence, best part", and *aṁśa*, "part" (Monier-Williams): the essential part.
