## You'll want to know: సరిగ్గా
<!-- hl-knowledge: introduces=[TE-LEX-C87-ANSWER-02]; assesses=[] -->

**సరిగ్గా** (*sariggā*) — "exactly, properly".

Said alone, **సరిగ్గా!** is "exactly!". It shares its start with **సరే**, "okay": both lean on
**సరి**, "right, even".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

Wrong and exactly right, as a pair.
