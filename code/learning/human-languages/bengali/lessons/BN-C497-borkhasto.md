# বরখাস্ত (bôrkhāstô) — dismissed (from a job)

## You'll want to know: বরখাস্ত
<!-- hl-knowledge: introduces=[BN-LEX-C497-ISTOPHA497-04]; assesses=[] -->

**বরখাস্ত** — *bôrkhāstô* — "dismissed (from a job)".

> কোম্পানি চোরটাকে বরখাস্ত করল।
>
> *Kompāni chorṭāke bôrkhāstô kôrlô.*
>
> The company dismissed the thief.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**বরখাস্ত** (*bôrkhāstô*) is usually traced to Persian *barkhāst*, "risen up, done away with".
