## You'll want to know: la objeción
<!-- hl-knowledge: introduces=[ES-LEX-C577-DEFIENDE-02]; assesses=[] -->

**la objeción** — "the objection".

> ¿Alguien tiene alguna objeción?
>
> *Does anyone have any objection?*

*Poner una objeción* — to raise an objection.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*objeción* is a learned borrowing from Latin *obiectio* 'a throwing against, an objection', built on *obicere*, from *ob* and *iacere* 'to throw' (EtymDB).
