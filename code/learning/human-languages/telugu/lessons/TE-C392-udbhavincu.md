# ఉద్భవించు (udbhaviñcu) — to originate; to spring from

## You'll want to know: ఉద్భవించు
<!-- hl-knowledge: introduces=[TE-LEX-C392-MULAM392-02]; assesses=[] -->

**ఉద్భవించు** — *udbhaviñcu* — "to originate; to spring from".

> ఆ ఆచారం చాలా పాత కాలంలో ఉద్భవించింది.
>
> *ā ācāraṁ cālā pāta kālaṁlō udbhaviñcindi.*
>
> That custom arose in very old times.

Past (it …): ఉద్భవించింది, *udbhaviñcindi*.

Formal: for customs, ideas, languages and rivers, so its past is shown as ఉద్భవించింది, it arose.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ఉద్భవించు** (*udbhaviñcu*) is built on Sanskrit *udbhava*, "origin, birth" (CDIAL 2039), from the root *bhū*, "to become", with the Telugu verb ending -ఇంచు.
