# കുഴപ്പം (kuḻappaṁ) — trouble; a problem

## You'll want to know: കുഴപ്പം
<!-- hl-knowledge: introduces=[ML-LEX-C380-NILAVILI380-02]; assesses=[] -->

**കുഴപ്പം** — *kuḻappaṁ* — "trouble; a problem".

> ഒന്നും കുഴപ്പമില്ല, എല്ലാവരും സുരക്ഷിതരാണ്.
>
> *onnuṁ kuḻappamilla, ellāvaruṁ surakṣitarāṇŭ.*
>
> Nothing is wrong, everyone is safe.

കുഴപ്പമില്ല means no problem, it is all right.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**കുഴപ്പം** (*kuḻappaṁ*) is native Dravidian: DEDR 1817 sets it beside Tamil *kuḻappam*, "confusion, agitation, disturbance", from a verb meaning to mix up, to stir.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
