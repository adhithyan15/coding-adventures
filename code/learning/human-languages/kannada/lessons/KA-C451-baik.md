# ಬೈಕ್ (baik) — a motorbike

## You'll want to know: ಬೈಕ್
<!-- hl-knowledge: introduces=[KA-LEX-C451-VAHANA451-04]; assesses=[] -->

**ಬೈಕ್** — *baik* — "a motorbike".

> ನನ್ನ ತಮ್ಮ ಬೈಕ್ನಲ್ಲಿ ಕಚೇರಿಗೆ ಹೋಗುತ್ತಾನೆ.
>
> *nanna tamma baiknalli kacērige hōguttāne.*
>
> My younger brother goes to the office on a motorbike.

A bicycle is a ಸೈಕಲ್; a ಬೈಕ್ has an engine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಬೈಕ್** (*baik*) is a loan from English *bike*, which in India names a motorbike.
