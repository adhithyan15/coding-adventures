# ಸುಮ್ಮನೆ (summane) — for no reason, idly

## You'll want to know: ಸುಮ್ಮನೆ
<!-- hl-knowledge: introduces=[KA-LEX-C102-THISWAY-05]; assesses=[] -->

**ಸುಮ್ಮನೆ** (*summane*) — "for no reason, idly, quietly".

**ಸುಮ್ಮನೆ** answers **ಯಾಕೆ?**, "why?", when there is no reason at all.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

The answer to why when there is none.
