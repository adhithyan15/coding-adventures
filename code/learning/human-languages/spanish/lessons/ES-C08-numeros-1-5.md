# uno, dos, tres, cuatro, cinco — counting to five

## Warm-up

[PAUSE 2s] Numbers are the most reused words in any language — and Spanish
counts almost exactly like Latin, which means you already half-know them from
English. Here are **1 to 5**, each with the English words it planted.

## Sounds you'll need

- `diphthong-ue` — **cuatro** = *KWA-tro* (the *cu-* is a *kw* glide).
- `r-tap` — soft taps in *tres, cuatro*.

## The numbers, taken apart

| Spanish | ← Latin | English cousins |
|---|---|---|
| **uno** (1) | *ūnus* | **unit, union, unique, unanimous, universe** (and *a/an*, *one*) |
| **dos** (2) | *duo* | **duo, dual, duet, double, duplex** |
| **tres** (3) | *trēs* | **trio, triple, trinity, trident, triangle** |
| **cuatro** (4) | *quattuor* | **quart, quarter, quadrant, square** (Latin *qu-* → Spanish *cu-*) |
| **cinco** (5) | *quīnque* | **quintet, quintessence, quintuplet** (Latin *qu-* → Spanish *c-*) |

So *cinco* and *quintet* are the same number — Latin *quīnque* just softened its
*qu-* to a Spanish *c-*. Count the family on your fingers: *unit, duo, trio,
quart, quint.*

## Grammar Lens: uno → un / una

**uno** shrinks before a noun: **un** (masc.) / **una** (fem.) — and these double
as "a/an" (Spanish makes no difference between "one" and "a"): *un café* = "a
coffee / one coffee." The others (*dos, tres…*) don't change.
