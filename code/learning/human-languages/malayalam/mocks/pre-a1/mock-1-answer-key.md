## Writing

1. **നമസ്കാരം**
2. **പേര്**
3. **ഞാൻ**
4. **വീട്**
5. **മലയാളം**
6. **നന്ദി**
7. Accept the learner's chosen name when it is independently written in
   recognizable Malayalam script; do not require the name **രവി**.
8. Accept an appropriate independently written Malayalam greeting such as
   **നമസ്കാരം**. Do not accept a romanized or visibly copied answer.

## Speaking

1. Accept **നമസ്കാരം** or an equally appropriate taught Malayalam greeting.
2. Accept a chosen identity in a comprehensible frame such as
   **എന്റെ പേര് … ആണ്.**
3. Accept a relevant state such as **എനിക്ക് സുഖമാണ്.**
4. Accept a comprehensible place response such as **ഞാൻ കൊച്ചിയിൽ താമസിക്കുന്നു.**
5. Accept a relevant yes/no response or a short Malayalam-speaking frame.
6. Accept a comprehensible polite water request containing **വെള്ളം** and an
   appropriate request signal.

Apply the speaking rubric to the whole part; the examples above are not scripts
the learner must reproduce word for word.
