# Practice — eleven to sixteen

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[] -->

[PAUSE 2s] Six words, learned one at a time. Run them as a block, then take each
one apart again from memory.

## Guided Practice: the run
<!-- hl-knowledge: introduces=[]; assesses=[FR-LEX-ONZE-01, FR-LEX-DOUZE-02, FR-LEX-TREIZE-04, FR-LEX-QUATORZE-05, FR-LEX-QUINZE-06, FR-LEX-SEIZE-07] -->

[PAUSE 1s]
- [YOU SAY: "onze, douze, treize, quatorze, quinze, seize"]
- [YOU SAY: from ten — "dix, onze, douze, treize, quatorze, quinze, seize"]
- [YOU SAY: backwards — "seize, quinze, quatorze, treize, douze, onze"]

[REPEAT x2] "onze, douze, treize, quatorze, quinze, seize"

## Guided Practice: surface the digit

[PAUSE 1s]
- [YOU SAY: each pair — "un/onze, deux/douze, trois/treize"]
- [YOU SAY: the harder three — "quatre/quatorze, cinq/quinze, six/seize"]
- [YOU SAY: the one that needs English — "cinq, quintet, quinze"]

## Guided Practice: the ten on the end
<!-- hl-knowledge: introduces=[]; assesses=[FR-ETYMON-ZE-DECEM-03] -->

[PAUSE 1s]
- [YOU SAY: the three disguises — "dix, décembre, -ze"]
- [YOU SAY: one sum aloud — "trei- is three, -ze is ten, treize is thirteen"]

## What you've built this chapter
<!-- hl-knowledge: introduces=[]; assesses=[FR-ETYMON-ZE-DECEM-03, FR-GRAM-DIGIT-FIRST-08] -->

- **six numbers**, eleven to sixteen.
- **one ending explained** — the **-ze** is *decem*, the same ten you already had
  in **dix** and **décembre**. Three disguises, one root.
- **the order** — digit in front, ten behind. *Treize* is "three-ten."
- **a way in when a word refuses** — *cinq* and *quinze* do not look alike, and
  English **quintet** stands between them. Reach for the long formal English word
  whenever the short French one has worn past recognition.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[FR-LEX-ONZE-01, FR-LEX-SEIZE-07, FR-ETYMON-ZE-DECEM-03, FR-GRAM-DIGIT-FIRST-08] -->

[PAUSE 3s] Count eleven to sixteen without stopping. (*Onze, douze, treize,
quatorze, quinze, seize*.) What is the **-ze**? (Latin **decem**, "ten".) Which
comes first in these words, the digit or the ten? (The **digit**.) Which digit
is in *quatorze*? (***quatre***.) Were any of these built out of *dix* plus a
digit? (**No** — all six arrived from Latin already **fused**.)
