Malayalam, chapter 11: Four Core Colours.
2 lessons. You can do the first one in the car; after that you will want to have stopped.


Lesson 1 of 2.
കറുപ്പ്, വെള്ള, ചുവപ്പ്, നീല — the same split as Tamil.

Warm-up.
[pause 2 seconds]
You've seen Malayalam and Tamil share day-names almost word-for-word. Their colors follow the exact same family pattern.

You'll want to know.
കറുപ്പ് (karuppŭ) = "black" — matches Tamil karuppu almost exactly.
വെള്ള (veḷḷa) = "white" — the same veḷ- "bright/silvery" root as Tamil veḷḷai.
ചുവപ്പ് (cuvappŭ) = "red" — a related word from the same Dravidian root family as Tamil sivappu, though the two differ in both their opening consonant's sound and their vowel — a looser cousin than karuppŭ/karuppu or veḷḷa/veḷḷai, which match almost exactly.

The word, taken apart.
നീല (nīla) = "blue" — the same Sanskrit loan Tamil uses (nīlam), and the same one Hindi uses (nīlā). Blue is where Malayalam, Tamil, and Hindi all converge on one shared Sanskrit word, even though Malayalam and Tamil otherwise built their own native words for black, white, and red.

Guided Practice.
[pause 1 second]
[your turn — say: "karuppŭ, veḷḷa, cuvappŭ" — black, white, red]
[pause 8 seconds for the answer]
[your turn — say: "nīla" — blue, shared with Tamil and Hindi]
[pause 8 seconds for the answer]
[your turn — say: the family match — "karuppŭ/karuppu, veḷḷa/veḷḷai, cuvappŭ/sivappu"]
[pause 8 seconds for the answer]

Wrap-up Recall.
[pause 3 seconds]
Which three Malayalam colors closely match Tamil's own words? (Karuppŭ, veḷḷa, cuvappŭ — black, white, red.) Which color is a shared Sanskrit loan across Malayalam, Tamil, and Hindi? (Blue — நீல nīla / நீலம் nīlam / नीला nīlā.)

Script you'll notice: മ.
മ — ma.
It is a consonant, and in this script a consonant is never bare: it comes with an a already in it. So it is not m, it is ma.
You already say these, and every one of them has മ (ma) somewhere inside it:
നമസ്കാരം namaskāraṁ — hello / greetings (namaskāraṁ — "a making of a bow").
സാരമില്ല sāramilla — it doesn't matter / no problem / you're welcome.
താമസിക്കുക tāmasikkuka — to live, to stay.
എനിക്ക് മലയാളം അറിയാം enikkŭ malayāḷaṁ aṟiyāṁ — 'I know Malayalam'.
