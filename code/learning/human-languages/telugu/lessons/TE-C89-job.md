# ఉద్యోగం (udyōgaṁ) — a job

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TE-LEX-C88-PEOPLE-04, TE-LEX-C88-PEOPLE-05] -->

[PAUSE 2s] Before the new one: say the Telugu for a person, then the Telugu for a relative.

## You'll want to know: ఉద్యోగం
<!-- hl-knowledge: introduces=[TE-LEX-C89-ABOUT-01]; assesses=[] -->

**ఉద్యోగం** (*udyōgaṁ*) — "a job".

**మీ ఉద్యోగం ఏమిటి?** — "what is your job?". It is built exactly like **మీ పేరు ఏమిటి?**, with
the job where the name was.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

The second question of an introduction, on the frame of the first.
