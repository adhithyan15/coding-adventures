# એડી (eḍī) — heel

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[GU-LEX-C229-LIMBS229-02, GU-LEX-C229-LIMBS229-03] -->

[PAUSE 2s] Before the new one: say the Gujarati for thumb, then the Gujarati for ankle.

## You'll want to know: એડી
<!-- hl-knowledge: introduces=[GU-LEX-C229-LIMBS229-04]; assesses=[] -->

**એડી** — *eḍī* — "heel".

> **મારી એડી નથી દુખતી.** — *mārī eḍī nathī dukhtī* — "My heel does not hurt."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**એડી** (*eḍī*) comes from *\*aḍḍi*, "heel", a reconstructed form; CDIAL notes J. Bloch's view that it was borrowed from Dravidian, as in Tamil *aḍi* (CDIAL 191).
