# ചടങ്ങ് (caṭaṅṅŭ) — a ceremony; a function

## You'll want to know: ചടങ്ങ്
<!-- hl-knowledge: introduces=[ML-LEX-C387-SALKKARAM387-03]; assesses=[] -->

**ചടങ്ങ്** — *caṭaṅṅŭ* — "a ceremony; a function".

> വിവാഹത്തിന്റെ ചടങ്ങ് രാവിലെ പത്ത് മണിക്ക് തുടങ്ങി.
>
> *vivāhattinṟe caṭaṅṅŭ rāvile pattŭ maṇikkŭ tuṭaṅṅi.*
>
> The wedding ceremony began at ten in the morning.

Also a mere formality: അത് ഒരു ചടങ്ങ് മാത്രം, it is only a formality.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ചടങ്ങ്** (*caṭaṅṅŭ*) is a native Malayalam word whose origin is not settled. It names any ceremony, from a wedding to the opening of a shop.
