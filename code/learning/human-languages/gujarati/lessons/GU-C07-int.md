## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ઈંટ** (*ĩṭ*) is a tadbhava, a word inherited from Sanskrit and reshaped by sound change. It comes from *iṣṭakā*, "brick" (CDIAL 1600).
