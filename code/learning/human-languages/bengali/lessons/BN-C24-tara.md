# তারা (tārā) — they

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[BN-LEX-C24-TOMRA-01, BN-LEX-C23-SHE-01] -->

[PAUSE 2s] Say **you, all of you**. Then say **he is well**, plainly.

## You'll want to know: তারা
<!-- hl-knowledge: introduces=[BN-LEX-C24-TARA-01]; assesses=[BN-LEX-C23-SHE-01, BN-GRAMMAR-C22-PLURAL-RA-01] -->

> **তারা ভালো** — *tārā bhālo* — **they are well.**

The stem of **সে** is **তা-** — you saw it last chapter inside **তার** — and
with the living plural on the end it is **তারা**. The careful form does what you
would now expect: **তাঁরা**, with the moon-dot.

That completes the grid. Six persons, in a language that spent thirty-three
chapters able to talk about two:

| | one | more than one |
|---|---|---|
| I | **আমি** | **আমরা** |
| you, plainly | **তুমি** | **তোমরা** |
| you, carefully | **আপনি** | **আপনারা** |
| he, she, plainly | **সে** | **তারা** |
| he, she, carefully | **তিনি** | **তাঁরা** |

## Grammar Lens: one ending did all of it
<!-- hl-knowledge: introduces=[]; assesses=[BN-LEX-C24-TARA-01, BN-GRAMMAR-C22-PLURAL-RA-01, BN-LEX-C11-BHAI-01] -->

Read the right-hand column downwards and every entry ends the same way. There is
no irregular plural anywhere in the Bengali pronoun system — no *I/we*, no
*he/they*, nothing to memorise as a pair.

And it is the same **-রা** that pluralises **ভাই** and **বোন**. One rule, learned
once, for people and for pronouns alike, because Bengali does not think those
are different kinds of word.
