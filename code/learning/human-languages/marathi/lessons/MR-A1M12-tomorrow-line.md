# The dated farewell line

## Warm-up
<!-- hl-knowledge: introduces=[MR-A1-MESSAGE-LINE-SEE-TOMORROW]; assesses=[MR-A1-MESSAGE-LINE-SEE-AGAIN] -->

Swap only the first known word: **पुन्हा भेटू** becomes **उद्या भेटू**. The
message now says when the next meeting happens.

## Writing — delayed copy
<!-- hl-knowledge: introduces=[]; assesses=[MR-A1-MESSAGE-LINE-SEE-AGAIN, MR-A1-MESSAGE-LINE-SEE-TOMORROW] -->
<!-- hl-writing-stage: delayed-copy -->

Study **उद्या भेटू.**, cover it, wait ten seconds, and write it. Compare
**उद्या** first; **भेटू** was retrieved yesterday.
