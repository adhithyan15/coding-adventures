# സ്ഥിരീകരിക്കുക (sthirīkarikkuka) — to confirm

[PAUSE 2s] Before the new one: say the Malayalam for to uphold, then the Malayalam for to be convinced.

## You'll want to know: സ്ഥിരീകരിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C454-UNNAYAM454-05]; assesses=[] -->

**സ്ഥിരീകരിക്കുക** — *sthirīkarikkuka* — "to confirm".

> യോഗം നാളെയാണെന്ന് പ്രിൻസിപ്പൽ സ്ഥിരീകരിച്ചു.
>
> *yōgaṁ nāḷeyāṇennŭ prinsippal sthirīkariccu.*
>
> The principal confirmed that the meeting is tomorrow.

Past: സ്ഥിരീകരിച്ചു, *sthirīkariccu*.

The noun is സ്ഥിരീകരണം, confirmation.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**സ്ഥിരീകരിക്കുക** (*sthirīkarikkuka*) is built from Sanskrit *sthira*, "firm, hard, durable" (CDIAL 13771), with -ീകരിക്കുക, "to make into": to make a thing firm.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
