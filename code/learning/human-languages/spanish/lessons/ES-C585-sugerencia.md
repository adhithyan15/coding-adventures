## You'll want to know: la sugerencia
<!-- hl-knowledge: introduces=[ES-LEX-C585-PROPONE-03]; assesses=[] -->

**la sugerencia** — "the suggestion".

> ¿Tienes alguna sugerencia?
>
> *Do you have any suggestions?*

Built on *sugerir* — to suggest.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*sugerencia* is built on *sugerir*, a learned borrowing from Latin *suggerere* 'to bring up, to supply', *sub* + *gerere* 'to carry' (EtymDB).
