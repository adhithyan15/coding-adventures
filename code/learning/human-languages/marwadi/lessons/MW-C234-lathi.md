# लाठी (lāṭhī) — a long stick

## You'll want to know: लाठी
<!-- hl-knowledge: introduces=[MW-LEX-C234-HERD234-02]; assesses=[] -->

**लाठी** — *lāṭhī* — "a long stick".

> एवाळियो लाठी राखै है।
>
> *evāḷiyo lāṭhī rākhai hai.*
>
> The shepherd carries a long stick.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**लाठी** (*lāṭhī*) is inherited from a reconstructed *\*laṣṭi*, "a stick", beside Sanskrit *yaṣṭi*; CDIAL lists Marwari *lāṭhī* (CDIAL 10991).
