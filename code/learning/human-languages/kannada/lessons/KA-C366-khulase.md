# ಖುಲಾಸೆ (khulāse) — an acquittal

## You'll want to know: ಖುಲಾಸೆ
<!-- hl-knowledge: introduces=[KA-LEX-C366-GHANATE366-01]; assesses=[] -->

**ಖುಲಾಸೆ** — *khulāse* — "an acquittal".

> ಕೊನೆಗೆ ನ್ಯಾಯಾಲಯದಿಂದ ಅವನಿಗೆ ಖುಲಾಸೆ ಸಿಕ್ಕಿತು.
>
> *konege nyāyālayadinda avanige khulāse sikkitu.*
>
> In the end he was acquitted by the court.

ಖುಲಾಸೆ ಆಗು, to be acquitted: ಆರೋಪಿ ಖುಲಾಸೆ ಆದನು.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಖುಲಾಸೆ** (*khulāse*) came into Kannada through Hindustani and is usually traced to Arabic; the exact Arabic source word is not settled.

One more word for telling what happened.
