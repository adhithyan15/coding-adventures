## [0.1.0] - 2026-11-24

### Added

- Pure ISO C17 logic gates (LGE-C1): `lg_not`, `lg_and`, `lg_or`, `lg_xor`,
  `lg_nand`, `lg_nor`, `lg_xnor`, plus the NAND-only constructions
  `lg_nand_not`, `lg_nand_and`, `lg_nand_or`, `lg_nand_xor` (4-NAND XOR).
- Status-code error model: every function returns `LG_INVALID` (-1) if any
  argument is not exactly 0 or 1 (VER04i section 5, C row).
- No pointers, arrays, allocation, I/O, globals, shifts or signed overflow.
- Tests: literal truth tables, NAND-vs-direct equivalence, exhaustive rejection
  over [-1024, 1024] plus INT_MIN/INT_MAX neighbours in every argument
  position, and a no-valid-input-is-invalid check. Run under the ISO harness,
  with `-Wconversion -Wsign-conversion`, and under ASan+UBSan when available.
- Spec 10 gains a "C lane API" section.
