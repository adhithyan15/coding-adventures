# वित्तकोषः (vittakoṣaḥ) — a financial bank

## You'll want to know: वित्तकोषः

<!-- hl-knowledge: introduces=[SA-LEX-C268-SERVICE-01]; assesses=[] -->

**वित्तकोषः** — *vittakoṣaḥ* — “a financial bank.” This is the institution
that handles money, **not the riverbank** **तीरम्** that you already know.

The modern financial sense is explicitly attested in the [Kosha Sanskrit
Today “Places — Bank” glossary](https://kosha.sanskrit.today/glossary/places-bank)
and in the [Sanskrit Documents combined
dictionary](https://sanskritdocuments.org/dict/dictallcheck.pdf). This lesson
teaches only that sourced financial-institution sense.

## The word, taken apart

<!-- hl-knowledge: introduces=[]; assesses=[SA-LEX-C268-SERVICE-01] -->

**वित्तकोषः** is transparently formed from **वित्त**, “wealth, money,” and
**कोष**, “treasury, store.” The compound names the financial institution; it
does not change the older water-edge meaning of **तीरम्**.
