# புழுங்கு (puḻuṅku) — to be sultry; to be stuffy

## You'll want to know: புழுங்கு
<!-- hl-knowledge: introduces=[TA-LEX-C427-VEPPAM427-05]; assesses=[] -->

**புழுங்கு** — *puḻuṅku* — "to be sultry; to be stuffy".

> மழைக்கு முன்பு மிகவும் புழுங்கியது.
>
> *maḻaikku muṉpu mikavum puḻuṅkiyatu.*
>
> Before the rain it was very sultry.

Past (it …): புழுங்கியது, *puḻuṅkiyatu*.

Of food, to be steamed; புழுங்கல் அரிசி is parboiled rice.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**புழுங்கு** (*puḻuṅku*) is native Dravidian (DEDR 4315), "to be steamed, parboiled; to be sultry".
