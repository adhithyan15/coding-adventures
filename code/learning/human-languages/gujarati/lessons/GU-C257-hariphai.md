# હરીફાઈ (harīphāī) — competition, contest

## You'll want to know: હરીફાઈ
<!-- hl-knowledge: introduces=[GU-LEX-C257-TEAM257-03]; assesses=[] -->

**હરીફાઈ** — *harīphāī* — "competition, contest".

> **તે હરીફાઈમાં જીતી.** — *te harīphāīmā̃ jītī* — "She won the competition."

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**હરીફાઈ** (*harīphāī*) is built on *harīph*, "rival", with *-āī*. *Harīph* is a loan from Arabic *ḥarīf*, "a fellow-worker, an associate" (Lane), which reached Gujarati through Persian.
