# ಸಮಬಲ (samabala) — a draw; a tie

## You'll want to know: ಸಮಬಲ
<!-- hl-knowledge: introduces=[KA-LEX-C539-SPARDHE539-03]; assesses=[] -->

**ಸಮಬಲ** — *samabala* — "a draw; a tie".

> ಎರಡು ತಂಡಗಳ ಪಂದ್ಯ ಸಮಬಲದಲ್ಲಿ ಮುಗಿಯಿತು.
>
> *eraḍu taṇḍagaḷa pandya samabaladalli mugiyitu.*
>
> The match between the two teams ended in a draw.

ಸಮ, equal + ಬಲ, strength.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಸಮಬಲ** (*samabala*) is a learned compound built from Sanskrit *sama*, "same, equal" (Monier-Williams), and *bala*, "power, strength" (CDIAL 9161).
