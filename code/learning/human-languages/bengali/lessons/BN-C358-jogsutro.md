## You'll want to know: যোগসূত্র
<!-- hl-knowledge: introduces=[BN-LEX-C358-MIL358-03]; assesses=[] -->

**যোগসূত্র** — *jogsūtrô* — "a link; a connection".

> এই দুই ঘটনার কোনো যোগসূত্র আছে?
>
> *ei dui ghôṭônār kono jogsūtrô āchhe?*
>
> Is there any link between these two events?

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**যোগসূত্র** (*jogsūtrô*) is Sanskrit *yoga*, joining, with *sūtra*, a thread (Monier-Williams): the thread that ties two things together.
