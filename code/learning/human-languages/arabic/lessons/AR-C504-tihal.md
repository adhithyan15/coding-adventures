# طحال (ṭiḥāl) — the spleen

## You'll want to know: طحال
<!-- hl-knowledge: introduces=[AR-LEX-C504-BATN504-02]; assesses=[] -->

**طحال** — *ṭiḥāl* — "the spleen".

> الطحال عضو صغير في البطن.
>
> *aṭ-ṭiḥāl ʿuḍw ṣaghīr fī al-baṭn.*
>
> The spleen is a small organ in the belly.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**طحال** (*ṭiḥāl*) is built on the native Arabic root *ṭ-ḥ-l*, "to hurt the spleen" (Lane). Lane gives ṭaḥala as to strike or hurt the ṭiḥāl.

## What you've built
