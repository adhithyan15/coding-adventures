# মর্যাদা (môrjādā) — dignity; standing

## You'll want to know: মর্যাদা
<!-- hl-knowledge: introduces=[BN-LEX-C352-BOISHOMMO352-02]; assesses=[] -->

**মর্যাদা** — *môrjādā* — "dignity; standing".

> সব মানুষের মর্যাদা সমান।
>
> *sôb mānusher môrjādā sômān.*
>
> Every person has equal dignity.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**মর্যাদা** (*môrjādā*) is Sanskrit *maryādā*, a boundary and so the proper limits of conduct (Monier-Williams). Bengali uses it for the dignity or standing those limits protect.
