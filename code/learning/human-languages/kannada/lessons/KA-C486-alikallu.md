# ಆಲಿಕಲ್ಲು (ālikallu) — hail; a hailstone

## You'll want to know: ಆಲಿಕಲ್ಲು
<!-- hl-knowledge: introduces=[KA-LEX-C486-HINGARU486-02]; assesses=[] -->

**ಆಲಿಕಲ್ಲು** — *ālikallu* — "hail; a hailstone".

> ಬಿರುಗಾಳಿಯ ಜೊತೆಗೆ ಆಲಿಕಲ್ಲು ಬಿದ್ದಿತು.
>
> *birugāḷiya jotege ālikallu bidditu.*
>
> Hail fell along with the storm.

ಆಲಿ, hail, plus ಕಲ್ಲು, a stone: stones of ice.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಆಲಿಕಲ್ಲು** (*ālikallu*) is native Dravidian: DEDR 384 lists Kannada *āli-kal*, *āle-kallu*, "a hailstone", built with ಕಲ್ಲು, "a stone" (DEDR 1298).
