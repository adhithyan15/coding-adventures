# tarde / boa tarde — "afternoon" and "good afternoon"

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[] -->

[PAUSE 2s] The afternoon greeting — named, like its Spanish twin, after
*lateness*.

## The word, taken apart
<!-- hl-knowledge: introduces=[PT-ETYMON-TARDE-02]; assesses=[] -->

**a tarde** (fem.) ← Latin **tardus** ("slow, late") — the same *tardus* behind
English **tard**y and re**tard** ("to slow"). Portuguese named the afternoon
after its *lateness*, exactly as Spanish did with the identical *tarde*.
**boa tarde** = "good afternoon" (*boa*, feminine, because *tarde* is feminine).
