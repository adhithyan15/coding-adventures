## You'll want to know: মোড়ক
<!-- hl-knowledge: introduces=[BN-LEX-C423-THONGA423-02]; assesses=[] -->

**মোড়ক** — *moṛôk* — "a wrapper; packaging".

> আমি উপহারের মোড়ক খুললাম।
>
> *āmi uphārer moṛôk khullām.*
>
> I opened the wrapping of the present.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**মোড়ক** (*moṛôk*) is built on **মোড়া**, "to wrap", which CDIAL sets beside *mōṭati*, "twists" (CDIAL 10186), with the noun ending -ক: the thing that wraps.
