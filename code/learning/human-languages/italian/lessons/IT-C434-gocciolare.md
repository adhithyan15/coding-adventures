## You'll want to know: gocciolare
<!-- hl-knowledge: introduces=[IT-LEX-C434-BAGNO-02]; assesses=[] -->

**gocciolare** — "to drip".

> Il rubinetto gocciola tutta la notte.
>
> *The tap drips all night.*

*La goccia* — a drop.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*gocciolare* is built on *goccia* 'drop', which is inherited from Latin *gutta* 'drop' (Lewis & Short).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->
