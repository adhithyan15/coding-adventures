# ಪೈಪೋಟಿ (paipōṭi) — rivalry; stiff competition

## You'll want to know: ಪೈಪೋಟಿ
<!-- hl-knowledge: introduces=[KA-LEX-C521-DUDIME521-05]; assesses=[] -->

**ಪೈಪೋಟಿ** — *paipōṭi* — "rivalry; stiff competition".

> ಎರಡು ಅಂಗಡಿಗಳ ನಡುವೆ ತುಂಬಾ ಪೈಪೋಟಿ ಇದೆ.
>
> *eraḍu aṅgaḍigaḷa naḍuve tumbā paipōṭi ide.*
>
> There is fierce rivalry between the two shops.

Closer and fiercer than ಸ್ಪರ್ಧೆ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಪೈಪೋಟಿ** (*paipōṭi*) is built on the native *pōṭi*, "competition, rivalry", which DEDR 4583 lists for Kannada beside Tamil *pōṭṭi*; the origin of the first part, *pai-*, is not settled.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
