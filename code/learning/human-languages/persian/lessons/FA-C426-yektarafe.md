## You'll want to know: یک طرفه
<!-- hl-knowledge: introduces=[FA-LEX-C426-RAHBANDAN-04]; assesses=[] -->

**یک طرفه** (*yektarafe*) — "one-way (of a street)".

> این کوچه یک طرفه است.
>
> *In kuche yektarafe ast.*
>
> This lane is one-way.

*yek* 'one' + *taraf* 'side' + *-e*. A two-way street is *dotarafe*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*yektarafe* is built from native *yek* 'one' and *taraf* 'side', a loan from Arabic *ṭaraf* 'side, edge', with the ending *-e*.
