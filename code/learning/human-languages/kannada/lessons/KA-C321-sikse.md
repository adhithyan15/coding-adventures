# ಶಿಕ್ಷೆ (śikṣe) — a punishment; a sentence

## You'll want to know: ಶಿಕ್ಷೆ
<!-- hl-knowledge: introduces=[KA-LEX-C321-NYAYA321-05]; assesses=[] -->

**ಶಿಕ್ಷೆ** — *śikṣe* — "a punishment; a sentence".

> ಕಳ್ಳನಿಗೆ ಎರಡು ವರ್ಷದ ಶಿಕ್ಷೆ ಆಯಿತು.
>
> *kaḷḷanige eraḍu varṣada śikṣe āyitu.*
>
> The thief got a two-year sentence.

The one punished takes -ಗೆ: ಕಳ್ಳನಿಗೆ ಶಿಕ್ಷೆ ಆಯಿತು, the thief was punished.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಶಿಕ್ಷೆ** (*śikṣe*) is borrowed from Sanskrit *śikṣā*, which meant "learning, study" and also "punishment, correction" (CDIAL 12432). Kannada kept the second sense.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
