# குதிரைவீரன் (kutiraivīraṉ) — a horseman

## You'll want to know: குதிரைவீரன்
<!-- hl-knowledge: introduces=[TA-LEX-C334-THER334-03]; assesses=[] -->

**குதிரைவீரன்** — *kutiraivīraṉ* — "a horseman".

> ஒரு குதிரைவீரன் செய்தியுடன் வேகமாக வந்தான்.
>
> *oru kutiraivīraṉ ceytiyuṭaṉ vēkamāka vantāṉ.*
>
> A horseman came quickly with the news.

குதிரை, horse + வீரன், warrior.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**குதிரைவீரன்** (*kutiraivīraṉ*) joins native குதிரை, "horse" (DEDR 1711), with வீரன், from Sanskrit *vīra*, "hero" (CDIAL 12056).
