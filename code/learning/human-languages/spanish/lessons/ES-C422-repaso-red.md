# cuatro palabras de internet — four words, four different ways in

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ES-LEX-C422-TECH-01, ES-LEX-INTERNET] -->

[PAUSE 2s] Name the four things you can now talk about on a screen. Say them
with their articles before reading the table.

## Grammar Lens: borrowed, translated, or built
<!-- hl-knowledge: introduces=[]; assesses=[ES-LEX-C422-TECH-01, ES-LEX-INTERNET, ES-LEX-ORDENADOR, ES-LEX-CORREO-ELECTRONICO] -->

English named all four of these things first. Spanish did something different
with each one, and that is the pattern worth carrying away:

| Spanish | English source | what Spanish did |
|---|---|---|
| internet | internet | took it whole |
| el ordenador | computer | **refused** it and used a French word instead |
| el correo electrónico | e-mail | translated both halves |
| la página web | web page | translated one half and kept the other |

Four things, four strategies, and no rule decided which. *Ordenador* is the
interesting one: Spain went to French *ordinateur*, "the thing that puts in
order," rather than to the Latin *computare*, "to count." A machine that orders
is a different idea about what the machine is for than a machine that counts.
