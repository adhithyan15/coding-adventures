## You'll want to know: 如期
<!-- hl-knowledge: introduces=[ZH-LEX-C390-AGREE390-04]; assesses=[] -->

**如期** — *rúqī* — "as planned (on the agreed date)".

> **要是不下雨我们就如期去山里** *yàoshi bú xiàyǔ wǒmen jiù rúqī qù shān lǐ* — If it doesn't rain, we'll go to the hills as planned.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**如期** (*rúqī*) is built from 如 'as' and 期 'a set time', both inherited from Middle Chinese, *nyo* and *gi* (Guangyun, in Baxter's transcription), which glosses the first 'like' and the second 'an appointed meeting'.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what would happen.
