## You'll want to know: ایمرجنسی
<!-- hl-knowledge: introduces=[UR-LEX-C536-MOHTAT536-05]; assesses=[] -->

**ایمرجنسی** — *emarjansī* — "an emergency".

> اگر ایمرجنسی ہوئی تو یہ نمبر ملائیے۔
>
> *agar emarjansī huī to yih nambar milāiye.*
>
> If there is an emergency, dial this number.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ایمرجنسی** (*emarjansī*) is borrowed from English *emergency*.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
