## You'll want to know: el lector
<!-- hl-knowledge: introduces=[ES-LEX-C762-PRENSA-03]; assesses=[] -->

**el lector** — "the reader".

> Es un gran lector de novelas.
>
> *He is a great reader of novels.*

*La lectora* for a woman. *Un lector de libros electrónicos* — an e-reader.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*lector* is a learned borrowing from Latin *lēctor* "reader" (EtymDB), from *legere* "to read".
