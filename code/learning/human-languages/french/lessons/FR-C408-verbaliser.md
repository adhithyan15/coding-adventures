## You'll want to know: verbaliser
<!-- hl-knowledge: introduces=[FR-LEX-C408-RADAR-04]; assesses=[] -->

**verbaliser** — "to fine, to write up (a driver)".

> Le policier a verbalisé le conducteur.
>
> *The police officer fined the driver.*

Formal and official.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*verbaliser* is built on *verbal*, as in *procès-verbal* 'official written report', a learned word from Late Latin *verbālis*, from *verbum* 'word' (Lewis & Short).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->
