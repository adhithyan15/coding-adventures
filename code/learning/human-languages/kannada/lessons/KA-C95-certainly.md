# ಖಚಿತವಾಗಿ (khacitavāgi) — certainly, for sure

## You'll want to know: ಖಚಿತವಾಗಿ
<!-- hl-knowledge: introduces=[KA-LEX-C95-MAYBE-05]; assesses=[] -->

**ಖಚಿತವಾಗಿ** (*khacitavāgi*) — "certainly, for sure", with the **‑ಆಗಿ** ending of
**ನಿಧಾನವಾಗಿ**. **ಖಂಡಿತ** (*khaṇḍita*) says the same with more force.
