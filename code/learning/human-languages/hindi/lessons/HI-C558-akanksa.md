# आकांक्षा (ākāṅkṣā) — an ambition; an aspiration

## You'll want to know: आकांक्षा
<!-- hl-knowledge: introduces=[HI-LEX-C558-KHVAHISH558-04]; assesses=[] -->

**आकांक्षा** — *ākāṅkṣā* — "an ambition; an aspiration".

> उसकी आकांक्षा एक बड़ा लेखक बनने की है।
>
> *Uskī ākāṅkṣā ek baṛā lekhak banne kī hai.*
>
> His ambition is to become a great writer.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**आकांक्षा** (*ākāṅkṣā*) is a tatsama, taken whole from Sanskrit *ākāṅkṣā*, "desire, wish" (Monier-Williams).
