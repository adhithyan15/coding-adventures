# തടവുകാരൻ (taṭavukāran) — a prisoner

## Warm-up

[PAUSE 2s] Before the new one: say the Malayalam for a jail, then the Malayalam for imprisonment.

## You'll want to know: തടവുകാരൻ
<!-- hl-knowledge: introduces=[ML-LEX-C371-JAIL371-03]; assesses=[] -->

**തടവുകാരൻ** — *taṭavukāran* — "a prisoner".

> തടവുകാർ ജയിലിൽ കൃഷി ചെയ്യുന്നു.
>
> *taṭavukār jayilil kṛṣi ceyyunnu.*
>
> The prisoners farm in the jail.

Plural: തടവുകാർ, *taṭavukār*.

തടവ്, confinement, + -കാരൻ, one in it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**തടവുകാരൻ** (*taṭavukāran*) is native Dravidian: തടവ് (*taṭavŭ*), "confinement", whose Tamil twin *taṭavu*, "prison", stands in DEDR 3031, with the ending -കാരൻ.
