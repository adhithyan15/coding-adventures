## You'll want to know: la traversée
<!-- hl-knowledge: introduces=[FR-LEX-C422-TRAVERSEE-02]; assesses=[] -->

**la traversée** — "the crossing (by sea)".

> La traversée dure quatre heures.
>
> *The crossing takes four hours.*

Built on *traverser* 'to cross'.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*traversée* is built on *traverser* 'to cross', which goes back to Latin *trānsversus* 'lying across', from *vertere* 'to turn' (Lewis & Short). EtymDB does not list the noun.
