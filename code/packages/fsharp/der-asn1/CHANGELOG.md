# Changelog

All notable changes to this package will be documented in this file.

## [0.1.0] - 2026-09-20

### Added

- Added bounded typed decoding for the portable DER ASN.1 value contract.
- Added transactional constructed-value cursors with shared depth and work budgets.
- Added immutable values and payload-blind stable error identifiers.
- Added all 122 portable fixture cases, including 46 delegated DER-TLV checks.
- Added hardened Linux and Windows build fronts with a 95% line-coverage gate.
