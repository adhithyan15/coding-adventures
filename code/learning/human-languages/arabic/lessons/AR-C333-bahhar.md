# بحار (baḥḥār) — a sailor

## You'll want to know: بحار
<!-- hl-knowledge: introduces=[AR-LEX-C333-BAHR333-02]; assesses=[] -->

**بحار** — *baḥḥār* — "a sailor".

> عمل جدي بحارا ثلاثين سنة.
>
> *ʿamila jaddī baḥḥāran thalāthīn sana.*
>
> My grandfather worked as a sailor for thirty years.

Plural: بحارة, *baḥḥāra*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**بحار** (*baḥḥār*) is built on the native Arabic root *b-ḥ-r* (Lane), the root of the taught *baḥr*, the sea. The *faʿʿāl* pattern names a trade: "the man of the sea".
