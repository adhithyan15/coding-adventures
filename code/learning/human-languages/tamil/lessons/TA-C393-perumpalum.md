# பெரும்பாலும் (perumpālum) — mostly; usually

## You'll want to know: பெரும்பாலும்
<!-- hl-knowledge: introduces=[TA-LEX-C393-ARIKKAI393-05]; assesses=[] -->

**பெரும்பாலும்** — *perumpālum* — "mostly; usually".

> மழை பெய்தால் பெரும்பாலும் நான் வீட்டிலேயே இருப்பேன்.
>
> *maḻai peytāl perumpālum nāṉ vīṭṭilēyē iruppēṉ.*
>
> If it rains, I mostly stay at home.

பெரும், great + பால், part + -உம்: for the greater part.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**பெரும்பாலும்** (*perumpālum*) is native: *perum*, "great" (DEDR 4411), *pāl*, "part, portion" (DEDR 4097), and the particle -உம்: for the greater part.
