## [0.2.1] - 2026-11-24

### Fixed

- `types.validate_bit` (used by every `evaluate_digital`) now rejects the
  floats `1.0`/`0.0`/`-0.0`, NaN and infinities: only the integers 0 and 1 are
  valid (`1.0 == 1` is true in Lua 5.3+). The error string keeps the
  `"<name> must be 0 or 1"` prefix and never invokes a hostile value's
  `__tostring`.

### Added

- `tests/test_validate_bit_strict.lua` covering the reject matrix.
