## You'll want to know: వ్యతిరేకత
<!-- hl-knowledge: introduces=[TE-LEX-C386-ABHYANTARAM386-04]; assesses=[] -->

**వ్యతిరేకత** — *vyatirēkata* — "opposition; resistance".

> ఆ ప్రతిపాదనకు చాలా వ్యతిరేకత వచ్చింది.
>
> *ā pratipādanaku cālā vyatirēkata vaccindi.*
>
> That proposal met a lot of opposition.

The noun of వ్యతిరేకించు, to oppose, which you know; -త makes an abstract noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**వ్యతిరేకత** (*vyatirēkata*) is built on Sanskrit *vyatireka*, "distinction, separateness; contrast" (Monier-Williams), with the abstract ending -త; the verb వ్యతిరేకించు comes from the same word.
