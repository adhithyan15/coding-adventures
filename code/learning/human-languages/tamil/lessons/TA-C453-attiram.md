## You'll want to know: ஆத்திரம்
<!-- hl-knowledge: introduces=[TA-LEX-C453-KOPAM453-01]; assesses=[] -->

**ஆத்திரம்** — *āttiram* — "rage; fury".

> அவன் ஆத்திரத்தில் கத்தினான்.
>
> *avaṉ āttirattil kattiṉāṉ.*
>
> He shouted in a rage.

A -அம் noun takes the oblique -அத்து- before an ending. In a rage: ஆத்திரத்தில்.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

The origin of **ஆத்திரம்** (*āttiram*) is not settled. It is often set beside Sanskrit *ātura*, "suffering, distressed" (Monier-Williams), but the link is uncertain.
