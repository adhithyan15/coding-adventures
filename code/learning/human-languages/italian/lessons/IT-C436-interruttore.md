## You'll want to know: l'interruttore
<!-- hl-knowledge: introduces=[IT-LEX-C436-LUCE-02]; assesses=[] -->

**l'interruttore** — "the switch (for a light)".

> L'interruttore è dietro la porta.
>
> *The switch is behind the door.*

Built on *interrompere*: it interrupts the current.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*interruttore* is a learned borrowing from Latin *interruptor* 'an interrupter', from *interrumpere* 'to break off', built on *rumpere* 'to break' (Lewis & Short).
