# Reacting and answering — a second pass

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[HI-LEX-C112-RIGHT-01, HI-LEX-C112-RIGHT-02] -->

[PAUSE 3s] Someone gives an answer. Tell them it is right; then tell them it is wrong.

## Grammar Lens: two words you already had, joined
<!-- hl-knowledge: introduces=[]; assesses=[HI-LEX-C112-RIGHT-04, HI-LEX-C113-NOTHING-01, HI-LEX-C113-NOTHING-02, HI-LEX-C113-NOTHING-04] -->

| answer | built from |
|---|---|
| **कुछ नहीं** | something + not |
| **अभी नहीं** | right now + not |
| **सच में?** | truth + in |
| **वही** | that + exactly |

Most short answers are two small words you already own, put side by side.

[PAUSE 2s each]
- [YOU SAY: react to surprising news: oh, really?]
- [YOU SAY: ask if someone is sure; answer "definitely"]
- [YOU SAY: asked what happened, say nothing; asked if you have finished, say not yet]
- [YOU SAY: say that's enough; say "that's the one"; say maybe]
- [YOU SAY: answer a request with "by all means", then with a polite no]
