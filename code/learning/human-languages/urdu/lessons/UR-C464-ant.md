## You'll want to know: آنت
<!-- hl-knowledge: introduces=[UR-LEX-C464-ORGAN464-04]; assesses=[] -->

**آنت** — *āṅt* — "an intestine".

> پیٹ میں لمبی آنتیں ہوتی ہیں۔
>
> *peṭ meṅ lambī āṅteṅ hotī haiṅ.*
>
> There are long intestines inside the belly.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**آنت** (*āṅt*) is inherited from Sanskrit *āntrá*, "entrails" (CDIAL 1182).
