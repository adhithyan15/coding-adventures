## You'll want to know: il soccorritore
<!-- hl-knowledge: introduces=[IT-LEX-C301-SOCCORSO-03]; assesses=[] -->

**il soccorritore** — "the rescuer, the paramedic".

> I soccorritori hanno lavorato tutta la notte.
>
> *The rescuers worked all night.*

A woman is *la soccorritrice*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*soccorritore* is *soccorrere* with the agent ending *-tore*; the root is Latin *currere* "to run" (EtymDB).
