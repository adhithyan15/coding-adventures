## You'll want to know: منظوری
<!-- hl-knowledge: introduces=[UR-LEX-C383-MANZURI383-01]; assesses=[] -->

**منظوری** — *manzūrī* — "approval; sanction".

> اگر منظوری مل گئی تو کام کل ہو گا۔
>
> *agar manzūrī mil gaī to kām kal ho gā.*
>
> If approval comes through, the work will be done tomorrow.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**منظوری** (*manzūrī*) is built on *manzūr*, usually traced, through Persian, to Arabic *manẓūr*, "looked at; accepted", with the noun ending *-ī*.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
