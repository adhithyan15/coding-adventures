# മുങ്ങിമരിക്കുക (muṅṅimarikkuka) — to drown

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C376-JEEVAN376-03, ML-LEX-C376-JEEVAN376-04] -->

[PAUSE 2s] Before the new one: say the Malayalam for a dead body, then the Malayalam for to get hurt.

## You'll want to know: മുങ്ങിമരിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C376-JEEVAN376-05]; assesses=[] -->

**മുങ്ങിമരിക്കുക** — *muṅṅimarikkuka* — "to drown".

> ഭാഗ്യത്തിന് ആരും മുങ്ങിമരിച്ചില്ല.
>
> *bhāgyattinŭ āruṁ muṅṅimariccilla.*
>
> Luckily nobody drowned.

Past: മുങ്ങിമരിച്ചു, *muṅṅimariccu*.

മുങ്ങുക, to sink, + മരിക്കുക, to die.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**മുങ്ങിമരിക്കുക** (*muṅṅimarikkuka*) joins മുങ്ങുക (*muṅṅuka*), "to sink, to go under", and മരിക്കുക (*marikkuka*), "to die", which is built from Sanskrit *maraṇa*, "dying" (CDIAL 9869).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
