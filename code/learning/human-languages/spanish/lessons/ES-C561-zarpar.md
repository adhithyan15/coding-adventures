## You'll want to know: zarpar
<!-- hl-knowledge: introduces=[ES-LEX-C561-PARTIDA-02]; assesses=[] -->

**zarpar** — "to set sail, to leave port".

> El barco zarpó a las ocho.
>
> *The ship set sail at eight.*

Only for ships and boats.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*zarpar* comes from old Italian *sarpare* 'to weigh anchor' (EtymDB). Where the Italian word came from is not settled.
