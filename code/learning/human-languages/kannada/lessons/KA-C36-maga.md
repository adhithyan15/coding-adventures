# ಮಗ (maga) — "son," the same root with one vowel doing the work

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C36-MAGU-01, KA-ETYMON-C36-MAGU-02] -->

[PAUSE 2s] *Maga*, *magu* — hold the root steady and change almost nothing.

## You'll want to know: ಮಗ
<!-- hl-knowledge: introduces=[KA-LEX-C36-MAGA-01]; assesses=[KA-LEX-C36-MAGU-01] -->

> **ಮಗ** — *maga* — **son**

> **ಇವನು ನನ್ನ ಮಗ.** — *ivanu nanna maga.* — "He is my son."

Set beside *magu*: **ಮಗು** *magu* → **ಮಗ** *maga*. The same three letters,
minus the length on the final vowel — the plain, inherent *-a* now standing
for "male."

## The word, taken apart: one shape, worn from an older one
<!-- hl-knowledge: introduces=[KA-ETYMON-C36-MAGA-02]; assesses=[] -->

*Maga* descends from the same Proto-Dravidian **\*maka** as *magu*. The
sisters carry a longer form for "son" — reconstructed as **\*magan** — and
Kannada is the branch that wore the ending down to a single open vowel.
Tamil keeps more of the shape: **மகன்** (*makaṉ*), "son."
