# ડાળી (ḍāḷī) — branch, twig

## You'll want to know: ડાળી
<!-- hl-knowledge: introduces=[GU-LEX-C236-NEEM236-03]; assesses=[] -->

**ડાળી** — *ḍāḷī* — "branch, twig".

> **ગઈકાલે લીમડાની ડાળી પડી.** — *gaīkāle līmḍānī ḍāḷī paḍī* — "Yesterday a branch of the neem tree fell."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ડાળી** (*ḍāḷī*) is inherited from the late Sanskrit *ḍāla*, "branch"; CDIAL lists Gujarati *ḍāḷī*, "branch", and notes that the many shapes of the word point to a non-Aryan, perhaps Munda, source (CDIAL 5546).
