# ಸಮಯಪಾಲನೆ (samayapālane) — punctuality

## You'll want to know: ಸಮಯಪಾಲನೆ
<!-- hl-knowledge: introduces=[KA-LEX-C520-TANDA520-05]; assesses=[] -->

**ಸಮಯಪಾಲನೆ** — *samayapālane* — "punctuality".

> ಸಮಯಪಾಲನೆ ಒಳ್ಳೆಯ ನೌಕರನ ಗುಣ.
>
> *samayapālane oḷḷeya naukarana guṇa.*
>
> Punctuality is the mark of a good employee.

ಸಮಯ, time + ಪಾಲನೆ, keeping.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಸಮಯಪಾಲನೆ** (*samayapālane*) is a learned compound built from Sanskrit *samaya*, "a meeting, an agreed time" (Monier-Williams), and *pālana*, "protecting, keeping" (CDIAL 8128).
