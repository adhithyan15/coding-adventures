# ઊપડવું (ūpaḍvũ) — to start off, to depart

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[GU-LEX-C204-TIMES204-02, GU-LEX-C204-TIMES204-03] -->

[PAUSE 2s] Before the new one: say the Gujarati for enquiry, then the Gujarati for platform.

## You'll want to know: ઊપડવું
<!-- hl-knowledge: introduces=[GU-LEX-C204-TIMES204-04]; assesses=[] -->

**ઊપડવું** — *ūpaḍvũ* — "to start off, to depart".

> **ટ્રેન સવારે ઊપડી.** — *ṭren savāre ūpaḍī* — "The train left in the morning."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ઊપડવું** (*ūpaḍvũ*) is a tadbhava. CDIAL lists it as *upaṛvũ*, "to move away, depart, be lifted, rise", under Sanskrit *útpatati*, "flies up, ascends" (CDIAL 1810).
