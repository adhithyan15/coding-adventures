# பிரதேசம் (piratēcam) — a region; a territory

## You'll want to know: பிரதேசம்
<!-- hl-knowledge: introduces=[TA-LEX-C452-VEEDU452-03]; assesses=[] -->

**பிரதேசம்** — *piratēcam* — "a region; a territory".

> இந்தப் பிரதேசத்தில் மழை குறைவு.
>
> *intap piratēcattil maḻai kuṟaivu.*
>
> There is little rain in this region.

A -அம் noun: பிரதேசத்தில், in the region.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**பிரதேசம்** (*piratēcam*) is borrowed from Sanskrit *pradeśa*, "a region, a country" (CDIAL 8668).
