## Script
<!-- hl-knowledge: introduces=[MR-SCRIPT-NA-01]; assesses=[MR-SCRIPT-HA-01, MR-SCRIPT-O-MATRA-01] -->

> न

**na**, with the same inherent **a** inside it — the *n* of English *net*, then the
vowel nobody wrote.

Nothing new in the machinery. This is simply another consonant, and every rule you
already have applies to it unchanged. That is the payoff of learning the system
rather than the words: **every consonant from here behaves exactly like the two you
already know.** New shapes are coming; new rules are not.

Write it beside the first, and notice both hang from the same head-line.
