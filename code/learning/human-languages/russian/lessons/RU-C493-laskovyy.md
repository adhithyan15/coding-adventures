## You'll want to know: ласковый
<!-- hl-knowledge: introduces=[RU-LEX-C493-SWEETHEARTS-05]; assesses=[] -->

**ласковый** (*láskovyy*) — "affectionate".

> У нашей кошки ласковый характер.
>
> *U náshey kóshki láskovyy kharákter.*
>
> Our cat has an affectionate nature.

Built on *ласка* — a caress.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*ласковый* is built on *ласка* 'a caress, kindness'; EtymDB lists *ласковый* without a source.
