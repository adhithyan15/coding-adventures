# யதார்த்தம் (yatārttam) — reality

## You'll want to know: யதார்த்தம்
<!-- hl-knowledge: introduces=[TA-LEX-C551-VADIVAM551-05]; assesses=[] -->

**யதார்த்தம்** — *yatārttam* — "reality".

> கனவு வேறு, யதார்த்தம் வேறு.
>
> *kaṉavu vēṟu, yatārttam vēṟu.*
>
> A dream is one thing, reality is another.

With -ஆக: யதார்த்தமாகப் பேசு, to speak realistically.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**யதார்த்தம்** (*yatārttam*) is borrowed from Sanskrit *yathārtha*, "accordant with reality, true" (Monier-Williams), with the Tamil ending -அம்.
