# storage-wal-reopen

`Reopen` selects the durable checkpoint procedure. A Ready checkpoint replays the accepted WAL prefix and retains its exact replay boundary. A Resetting checkpoint resumes the authorized clear and Ready publication for that same epoch without replaying the old log. Call the admitted initializer explicitly before reopening vacant checkpoint media; `Reopen` preserves its capture refusal without writing. Results preserve the exact lower replay and resume reports.

The device and layouts are caller-supplied and form one exclusive sequential restart interval. A lower refusal is returned with the same typed identity; no additional recovery policy is applied.

Run `sh BUILD` on Unix. `BUILD_windows` lists the direct Go commands for Windows.
