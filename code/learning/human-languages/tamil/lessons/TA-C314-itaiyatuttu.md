# இதையடுத்து (itaiyaṭuttu) — following this

## You'll want to know: இதையடுத்து
<!-- hl-knowledge: introduces=[TA-LEX-C314-NINAIVU314-05]; assesses=[] -->

**இதையடுத்து** — *itaiyaṭuttu* — "following this".

> இதையடுத்து, காவல்துறை புலனாய்வைத் தொடங்கியது.
>
> *itaiyaṭuttu, kāvaltuṟai pulaṉāyvait toṭaṅkiyatu.*
>
> Following this, the police began an investigation.

A news-style link: இதை + அடுத்து, next to this.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**இதையடுத்து** (*itaiyaṭuttu*) is built from இதை, "this", and அடுத்து, "next to", from native அடு, "to be next, near" (DEDR 79).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
