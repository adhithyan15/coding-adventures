# તે reaches the page

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[GU-SCRIPT-KE-01, GU-PRON-TE-01] -->

[PAUSE 3s] Three chapters back you wrote **કે**. Write it once from memory.

## Script — the same stroke, a third time
<!-- hl-knowledge: introduces=[GU-SCRIPT-TE-01]; assesses=[GU-SCRIPT-TA-01, GU-SCRIPT-E-MATRA-01] -->

> **ત** — *ta* · **ે** — the *e* stroke

Set **અને**, **કે** and **તે** in a row and look only at the stroke on top. It is
the same **ે** in all three, sitting on three different letters. Learning one
stroke has now spelled three of this book's most useful words.

## Writing — guided copy, model in view
<!-- hl-knowledge: introduces=[]; assesses=[GU-SCRIPT-TE-01] -->
<!-- hl-writing-stage: guided-copy -->

Copy **તે** once with the model in view. Then write the row — **અને કે તે** —
and check the three strokes sit at one height.

**અને**? (The **ે** above.)
