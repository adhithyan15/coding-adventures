# ચોકડી (cokḍī) — a crossroads (on a highway)

## You'll want to know: ચોકડી
<!-- hl-knowledge: introduces=[GU-LEX-C415-LANDMARK415-01]; assesses=[] -->

**ચોકડી** — *cokḍī* — "a crossroads (on a highway)".

> ચોકડી પરથી જમણી બાજુ વળો.
>
> *cokḍī parthī jamṇī bāju vaḷo.*
>
> Turn right at the crossroads.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ચોકડી** (*cokḍī*) is built on ચોક, a square, from Sanskrit *catuṣka*, "a set of four" (CDIAL 4629): the place where four roads meet.
