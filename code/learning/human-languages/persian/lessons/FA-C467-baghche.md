## You'll want to know: باغچه
<!-- hl-knowledge: introduces=[FA-LEX-C467-BAGH-02]; assesses=[] -->

**باغچه** (*bâghche*) — "a flower bed, a small garden (in a courtyard)".

> مادرم در باغچه حیاط گل کاشت.
>
> *Mâdaram dar bâghche-ye hayât gol kâsht.*
>
> My mother planted flowers in the courtyard bed.

*bâgh* + *-che* 'little'.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*bâghche* is a native word, which EtymDB lists with the sense 'small garden'; it is built from *bâgh* 'garden' and *-che* 'little'.
