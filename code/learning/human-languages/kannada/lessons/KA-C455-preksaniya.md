# ಪ್ರೇಕ್ಷಣೀಯ (prēkṣaṇīya) — worth seeing

## You'll want to know: ಪ್ರೇಕ್ಷಣೀಯ
<!-- hl-knowledge: introduces=[KA-LEX-C455-PRAVASA455-05]; assesses=[] -->

**ಪ್ರೇಕ್ಷಣೀಯ** — *prēkṣaṇīya* — "worth seeing".

> ಈ ಊರಿನಲ್ಲಿ ತುಂಬಾ ಪ್ರೇಕ್ಷಣೀಯ ದೇವಸ್ಥಾನಗಳಿವೆ.
>
> *ī ūrinalli tumbā prēkṣaṇīya dēvasthānagaḷive.*
>
> There are many temples worth seeing in this town.

ಪ್ರೇಕ್ಷಕ, a viewer, comes from the same root.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಪ್ರೇಕ್ಷಣೀಯ** (*prēkṣaṇīya*) is borrowed from Sanskrit *prēkṣaṇīya*, "to be seen, visible" (Monier-Williams), on *prēkṣaṇa*, "viewing, a show" (CDIAL 8991).
