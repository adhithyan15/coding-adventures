## You'll want to know: مخلب
<!-- hl-knowledge: introduces=[AR-LEX-C476-AQRAB476-04]; assesses=[] -->

**مخلب** — *mikhlab* — "a claw; a talon".

> أمسك الصقر السمكة بمخالبه.
>
> *amsaka aṣ-ṣaqr as-samaka bi-makhālibihi.*
>
> The falcon held the fish in its talons.

Plural: مخالب, *makhālib*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**مخلب** (*mikhlab*) is built on the native Arabic root *kh-l-b*, "to wound with the claws" (Lane). The tool pattern *mifʿal* makes it the thing one claws with.
