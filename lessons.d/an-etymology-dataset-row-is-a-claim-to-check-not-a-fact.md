# An etymology dataset row is a claim to check, not a fact: EtymDB mislabels loans as inherited and links homographs

Filling Italian etymologies from EtymDB 2.1, two reviews caught errors the
dataset itself carried: homograph links (*volere* ← *volare* "to fly"),
the wrong Latin word (*vecchio* ← *vitulus* for *vetulus*), loans labelled
inherited (*burro*, *albergo*, *limone*, *mestiere*), and a Greek loan run
backwards (*gonna*). Outside Europe it is worse (Telugu రోజు ← *rājan*).

Do: cross-check every row against a second source or a sure derivation,
reject on doubt, and cite only the source that actually supports the line.
Do not: let "not recorded" stand for a textbook origin (*fame* < *famēs*);
trace it through the dataset's rows for sister words, or a dictionary of
the ancestor language, and say which. A reviewer reading ~120 entries per
batch caught what the author's 40-entry self-review missed.
