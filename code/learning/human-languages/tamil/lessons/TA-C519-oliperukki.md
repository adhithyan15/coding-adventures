# ஒலிபெருக்கி (oliperukki) — a loudspeaker

## You'll want to know: ஒலிபெருக்கி
<!-- hl-knowledge: introduces=[TA-LEX-C519-OLI519-01]; assesses=[] -->

**ஒலிபெருக்கி** — *oliperukki* — "a loudspeaker".

> கோயில் திருவிழாவில் ஒலிபெருக்கி மிகவும் சத்தமாக இருந்தது.
>
> *kōyil tiruviḻāvil oliperukki mikavum cattamāka iruntatu.*
>
> At the temple festival the loudspeaker was very loud.

ஒலி "sound" + பெருக்கி "that which multiplies".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ஒலிபெருக்கி** (*oliperukki*) is a modern native compound: ஒலி (*oli*), "sound", and பெருக்கி (*perukki*), "that which makes it great", from பெரு (*peru*), "great" (DEDR 4411).
