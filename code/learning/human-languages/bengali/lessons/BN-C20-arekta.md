# আরেকটা (ārekṭā) — another one

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[BN-GRAMMAR-C20-EKTA-01, BN-LEX-C17-AR-01] -->

[PAUSE 2s] Say **a shirt**. Then say the joiner from chapter twenty-eight that
means **and**.

## You'll want to know: আরেকটা
<!-- hl-knowledge: introduces=[BN-LEX-C20-AREKTA-01]; assesses=[BN-GRAMMAR-C20-EKTA-01, BN-LEX-C10-CHA-01] -->

> **আরেকটা চা** — *ārekṭā chā* — **another tea.**

Take the word apart and it is already three things you own:

**আর** (and) + **এক** (one) + **টা** (the classifier) → **আরেকটা**

Which is why it does not merely mean *a different one*. It means **one more**,
with the *and* still inside it.

## Grammar Lens: the pair that hands things out one at a time
<!-- hl-knowledge: introduces=[]; assesses=[BN-LEX-C20-AREKTA-01, BN-GRAMMAR-C20-EKTA-01, BN-LEX-C14-LAL-01, BN-LEX-C14-KALO-01] -->

Bengali uses **একটা … আরেকটা** as a fixed pair to run down a list of things one
by one, the way English uses *one … another*:

> **একটা লাল, আরেকটা কালো** — *ekṭā lāl, ārekṭā kālo* — **one red, another
> black.**

This is the first time in this book that two things can be picked out and set
side by side as separate items. Before the classifier existed there was no way
to say **one** of anything, so there was no way to say **another** either.
