# సరళమైన (saraḷamaina) — uncomplicated; plain

## You'll want to know: సరళమైన
<!-- hl-knowledge: introduces=[TE-LEX-C437-SANKLISTAM437-02]; assesses=[] -->

**సరళమైన** — *saraḷamaina* — "uncomplicated; plain".

> అతను సరళమైన భాషలో వివరించాడు.
>
> *atanu saraḷamaina bhāṣalō vivariñcāḍu.*
>
> He explained in plain language.

సరళంగా, plainly.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**సరళమైన** (*saraḷamaina*) is built on Sanskrit *sarala*, "straight; upright, artless" (Monier-Williams), with Telugu -మైన.
