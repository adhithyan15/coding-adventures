# పారిశుద్ధ్యం (pāriśuddhyaṁ) — sanitation

## You'll want to know: పారిశుద్ధ్యం
<!-- hl-knowledge: introduces=[TE-LEX-C468-MURUGU468-02]; assesses=[] -->

**పారిశుద్ధ్యం** — *pāriśuddhyaṁ* — "sanitation".

> పురపాలక సంఘం పారిశుద్ధ్యం మీద శ్రద్ధ పెట్టాలి.
>
> *purapālaka saṅghaṁ pāriśuddhyaṁ mīda śraddha peṭṭāli.*
>
> The municipality must pay attention to sanitation.

An official word for keeping a town clean: drains, rubbish, toilets.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**పారిశుద్ధ్యం** (*pāriśuddhyaṁ*) is built from Sanskrit *pariśuddha*, "cleaned, purified" (Monier-Williams), as an abstract noun: the state of being clean.

One more word for getting around.
