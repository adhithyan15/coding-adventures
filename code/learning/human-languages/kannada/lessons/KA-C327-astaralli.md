# ಅಷ್ಟರಲ್ಲಿ (aṣṭaralli) — meanwhile; by then

## You'll want to know: ಅಷ್ಟರಲ್ಲಿ
<!-- hl-knowledge: introduces=[KA-LEX-C327-THATKSHANA327-01]; assesses=[] -->

**ಅಷ್ಟರಲ್ಲಿ** — *aṣṭaralli* — "meanwhile; by then".

> ನಾನು ಬಾಗಿಲು ತೆರೆದೆ. ಅಷ್ಟರಲ್ಲಿ ಕಳ್ಳ ಓಡಿಹೋಗಿದ್ದನು.
>
> *nānu bāgilu terede. aṣṭaralli kaḷḷa ōḍihōgiddanu.*
>
> I opened the door. By then the thief had run away.

ಅಷ್ಟು, that much, with -ಅಲ್ಲಿ, in: "within that much time".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಅಷ್ಟರಲ್ಲಿ** (*aṣṭaralli*) is native Dravidian: *aṣṭu*, "that much", is built on the pointing base *a-*, "that, yonder" (DEDR 1), with the ending -*alli*, "in".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
