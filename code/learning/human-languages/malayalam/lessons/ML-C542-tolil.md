# തൊഴിൽ (toḻil) — a trade; an occupation

## You'll want to know: തൊഴിൽ
<!-- hl-knowledge: introduces=[ML-LEX-C542-TOZHIL542-01]; assesses=[] -->

**തൊഴിൽ** — *toḻil* — "a trade; an occupation".

> അച്ഛന്റെ തൊഴിൽ കൃഷി ആയിരുന്നു.
>
> *acchanṟe toḻil kṛṣi āyirunnu.*
>
> Father's occupation was farming.

തൊഴിലാളി, a worker, is built on it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**തൊഴിൽ** (*toḻil*) is native Dravidian: DEDR 3524 gives it as business or an occupation (DEDR 3524).
