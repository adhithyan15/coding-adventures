# மனைவி (maṉaivi) — a wife

## You'll want to know: மனைவி
<!-- hl-knowledge: introduces=[TA-LEX-C100-FAMILY-04]; assesses=[] -->

**மனைவி** (*maṉaivi*) — "a wife".

It shares its start with **மனை**, "a house", from the hospital word: the wife is named from the
home.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

Husband and wife.
