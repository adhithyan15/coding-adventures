## The roots, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-SAMSAARIKKUKA-01, ML-PHRASE-C05-I-SPEAK-MALAYALAM-01, ML-LEX-TAAMASIKKUKA-01, ML-LEX-JOLI-CEYYUKA-01, ML-CONCEPT-C05-VERB-NEVER-AGREES-01, ML-CONCEPT-C05-POSTPOSITION-IL-01, ML-CONCEPT-C05-NOUN-PLUS-CEYYUKA-01] -->

[PAUSE 2s]
- *saṁsārikkuka* "to speak" (Sanskrit-derived; native twin *paṟayuka*)
- *tāmasikkuka* "to live" (Sanskrit-derived; where Tamil uses native *vāḻ*)
- *ceyyuka* "to do" → *jōli ceyyuka* "to work" — the *same root* as Tamil *sey*
- *malayāḷaṁ* = *mala* "mountain" + *āḷaṁ* "place" — "the mountain land"
