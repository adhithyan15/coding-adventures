# வெளிப்படையாக (veḷippaṭaiyāka) — frankly; openly

## You'll want to know: வெளிப்படையாக
<!-- hl-knowledge: introduces=[TA-LEX-C392-ULAL392-03]; assesses=[] -->

**வெளிப்படையாக** — *veḷippaṭaiyāka* — "frankly; openly".

> பிரச்சினை இருந்தால் அவர் வெளிப்படையாகச் சொல்வார்.
>
> *piracciṉai iruntāl avar veḷippaṭaiyākac colvār.*
>
> If there is a problem, he will say so frankly.

வெளிப்படை, open + -ஆக; வெளிப்படைத்தன்மை, transparency.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**வெளிப்படையாக** (*veḷippaṭaiyāka*) is native: *veḷippaṭai*, "openness", built on *veḷi*, "outside, open" (DEDR 5498), with the adverb ending -ஆக.

## What you've built
