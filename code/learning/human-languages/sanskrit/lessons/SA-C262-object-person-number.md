# Who is seen, and how many?

## Warm-up

<!-- hl-knowledge: introduces=[]; assesses=[SA-GRAMMAR-C260-SINGULAR-OBJECTS-03, SA-GRAMMAR-C261-DUAL-OBJECTS-03, SA-PRON-C262-ASMAN-01, SA-PRON-C262-YUSMAN-02] -->

[PAUSE 2s] Give the singular pair, then the dual pair, then the several-person
pair. (*Mām, tvām; āvām, yuvām; asmān, yuṣmān.*)

## Grammar Lens: person first, then number

<!-- hl-knowledge: introduces=[SA-GRAMMAR-C262-OBJECT-PERSON-NUMBER-03]; assesses=[] -->

Choose in two small steps.

First ask who the object is:

- first person includes the speaker;
- second person is the familiar person or people addressed.

Then count the people:

- one person: **माम्** / **त्वाम्** (*mām / tvām*);
- two people: **आवाम्** / **युवाम्** (*āvām / yuvām*);
- several people: **अस्मान्** / **युष्मान्** (*asmān / yuṣmān*).

The six are independent full forms. Choose person, choose number, then place
the chosen object before the known verb.

[PAUSE 2s each]
- [YOU SAY: first person, one — *mām*; first person, two — *āvām*; first person, several — *asmān*]
- [YOU SAY: second person, one — *tvām*; second person, two — *yuvām*; second person, several — *yuṣmān*]
- [YOU SAY: “he sees us two” — *saḥ āvām paśyati*]
- [YOU SAY: “he sees you all” — *saḥ yuṣmān paśyati*]
