## You'll want to know: গোঙানো
<!-- hl-knowledge: introduces=[BN-LEX-C477-JBOLUNI477-05]; assesses=[] -->

**গোঙানো** — *gongāno* — "to moan".

> ব্যথায় বুড়ো লোকটা গোঙাচ্ছিল।
>
> *bæthāy buṛo lokṭā gongāchchhilô.*
>
> The old man was moaning with pain.

Past (he/she …): তিনি ব্যথায় গোঙালেন, *tini bæthāy gongālen*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**গোঙানো** (*gongāno*) is an imitative verb for a low, wordless moan; it shows the new letter ঙ. No dictionary we use records an older form, so its history is not settled.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
