## You'll want to know: عجله کردن
<!-- hl-knowledge: introduces=[FA-LEX-C433-SAK-05]; assesses=[] -->

**عجله کردن** (*'ajale kardan*) — "to hurry, to be in a hurry".

> عجله کردیم ولی قطار رفته بود.
>
> *'Ajale kardim vali qatâr rafte bud.*
>
> We hurried, but the train had gone.

*'ajale* 'haste' + *kardan*. *'Ajale dâshtan* — to be in a hurry.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*'ajale kardan* is built from *'ajale* 'haste', a loan usually traced to Arabic *ʿajala* 'haste', and *kardan* 'to do', inherited from Middle Persian *kardan* (EtymDB).
