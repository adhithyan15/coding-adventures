# Japanese pre-A1 mock 1 — learner packets

This project-defined JLPT/JF Standard precursor is practice below A1. It does not establish readiness, attainment, or equivalence to an external examination. Allow 20 written minutes plus 5 speaking minutes and 1 preparation minute. This is a timed assessment, not a lesson.

Print the four skill sections as separate packets. Give only the current packet: collect Reading before giving Listening; collect Listening before Writing; collect Writing before Speaking. Never return a collected packet. Do not give the learner the examiner script, answer key, rubric, recording text, card model, or an answer-bearing cue.

## Reading — 5 minutes

Choose A, B, or C. No dictionary or other aid.

<!-- mock-part:prea1-reading-kana-and-doorway-words -->
1. **コーヒー** — A coffee / B an ear / C a mouth
2. **なまえ** — A yes / B a name / C a hand
3. **あし** — A a face / B an eye / C a foot
4. **口** — A a mouth / B a nose / C an ear
5. **め** — A a face / B an eye / C a foot
<!-- /mock-part:prea1-reading-kana-and-doorway-words -->

## Listening — 5 minutes

Listen to each numbered recording twice. Choose A, B, or C. The recording is not printed here. Do not show the Reading packet during this section.

<!-- mock-part:prea1-listening-greetings-and-one-turn-details -->
1. A a daytime greeting / B a refusal / C a request
2. A no / B yes / C thank you
3. A please / B no / C Japanese language
4. A an ear / B a hand / C a name
5. A please / B a name / C thank you
<!-- /mock-part:prea1-listening-greetings-and-one-turn-details -->

## Writing — 10 minutes

Write in Japanese script from memory. No copying, visible model during response, dictionary, or tracing guide.

<!-- mock-part:prea1-writing-delayed-kana-recall -->
1. View the examiner's word card for ten seconds. Once it is covered, write the word: __________
<!-- /mock-part:prea1-writing-delayed-kana-recall -->

<!-- mock-part:prea1-writing-dictation -->
Listen to each numbered recording twice; write the word you hear.

1. Recording W1: __________
2. Recording W2: __________
<!-- /mock-part:prea1-writing-dictation -->

<!-- mock-part:prea1-writing-bounded-production -->
Write one taught Japanese word or memorised chunk for each English cue. Do not copy from another packet.

1. Write the polite daytime greeting: __________
2. Write the taught word meaning “Japanese language”: __________
<!-- /mock-part:prea1-writing-bounded-production -->

## Speaking — 5 minutes

You have one preparation minute. The examiner gives five short prompts. Respond in Japanese within 2–15 seconds per prompt; one slow repeat may be requested. A single chosen name is enough for the identity prompt. No written answer script is supplied.

<!-- mock-part:prea1-speaking-doorway-exchange -->
1. Return a greeting.
2. Answer a yes-or-no doorway question.
3. Give a chosen personal name only.
4. Give a memorised polite request.
5. Give a courteous response to help received.
<!-- /mock-part:prea1-speaking-doorway-exchange -->
