# з — a letter shaped like the digit 3

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[RU-SCRIPT-U-01] -->

[PAUSE 2s] Write the letter from the previous lesson, and say which of the three
kinds it is.

## Script
<!-- hl-knowledge: introduces=[RU-SCRIPT-Z-01]; assesses=[RU-SCRIPT-U-01] -->

> з

**z**, the *z* of English *zoo*. And the shape is exactly what it looks like: **the
digit 3**.

That is not a coincidence to memorise around — it is simply a convenient hook, and
a rare piece of luck in this alphabet. Nothing in Latin looks like this, so nothing
can mislead you.

Write it as you would write a 3, and read it as *z*.
