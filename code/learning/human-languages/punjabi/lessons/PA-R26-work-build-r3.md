# Rebuild one work row at R3

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-THREE-LABEL-ORDER-01] -->

Read the three labels in order: **ਭਾਸ਼ਾ · ਰਿਹਾਇਸ਼ · ਕੰਮ**. Point to the work label and stop.

## Script and value recall
<!-- hl-knowledge: introduces=[]; assesses=[PA-SCRIPT-AU-MATRA-01, PA-FORM-WORK-JOB-01] -->

Trace **ੌ** once above **ਨ**, making **ਨੌ**. Then read the known value **ਨੌਕਰੀ** once.

## Writing — one supported work row
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-WORK-CUE-MAP-01, PA-FORM-WORK-SUPPORTED-ENTRY-01] -->
<!-- hl-writing-stage: controlled-composition -->

The old bank is A — **ਖੇਤੀ**, B — **ਨੌਕਰੀ**. For B, complete **ਕੰਮ: __________**. Keep the bank visible for this one attempt.
