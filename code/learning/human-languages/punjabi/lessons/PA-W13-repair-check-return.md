# Check a second pair without changing the first attempt

The first timed six-field form still shows what happened then. This small
return uses two other taught lines and keeps the later repair separate.

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-A1-FORM-MIXED-CUES-01] -->

Close the old card banks. [PAUSE 4s] Read the A · ਕ and B · ਖ marks aloud.
Each mark chooses a familiar value, not a new person or word.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-A1-FORM-MIXED-CUES-01, PA-A1-FORM-TIMED-01, PA-A1-TIMED-REPAIR-01] -->

Use a one-minute practice timer. Write these two lines without a model, then
stop. This is a retrieval rehearsal, not another scored checkpoint.

> ਰਿਹਾਇਸ਼ (A · ਕ): ______
>
> ਕੰਮ (B · ਖ): ______

Check after the clock: **ਰਿਹਾਇਸ਼: ਪਿੰਡ** and **ਕੰਮ: ਨੌਕਰੀ**. If a value or
letter slipped, write one corrected line on another page. Name the one thing
you changed: card choice, Gurmukhi spelling, or spacing. Keep the clocked
practice and the earlier timed form as they were.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[PA-A1-FORM-MIXED-CUES-01, PA-A1-FORM-TIMED-01, PA-A1-TIMED-REPAIR-01] -->

Cover the answers. [PAUSE 4s] Recall the two marked values, then say why a
later corrected line must not be counted as the first timed response. Full
form-and-message mocks and human review still lie ahead.
