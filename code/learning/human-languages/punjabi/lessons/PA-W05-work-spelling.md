# Check only the work-value spelling

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-WORK-FARMING-01, PA-FORM-WORK-JOB-01] -->

Read **ਖੇਤੀ** and **ਨੌਕਰੀ** once. Touch each script piece without writing a form line.

## Writing — one spelling pass
<!-- hl-knowledge: introduces=[PA-FORM-WORK-SPELLING-CHECK-01]; assesses=[PA-FORM-WORK-FARMING-01, PA-FORM-WORK-JOB-01] -->

Cover both models and write **ਨੌਕਰੀ** once. Reveal it and compare **ਨੌ**, then **ਕ**, then **ਰੀ**. Ignore the field label and spacing today.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-WORK-SPELLING-CHECK-01] -->

If a piece differs, rewrite only that piece before copying the whole value once more.
