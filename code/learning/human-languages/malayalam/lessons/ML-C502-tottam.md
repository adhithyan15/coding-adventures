# തോട്ടം (tōṭṭaṁ) — a plantation; a garden

## You'll want to know: തോട്ടം
<!-- hl-knowledge: introduces=[ML-LEX-C502-TOTTAM502-01]; assesses=[] -->

**തോട്ടം** — *tōṭṭaṁ* — "a plantation; a garden".

> മലയിൽ വലിയ തേയിലത്തോട്ടങ്ങൾ ഉണ്ട്.
>
> *malayil valiya tēyilattōṭṭaṅṅaḷ uṇṭŭ.*
>
> There are big tea plantations in the hills.

Plural: തോട്ടങ്ങൾ, *tōṭṭaṅṅaḷ*.

You met it in പൂന്തോട്ടം, a flower garden.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**തോട്ടം** (*tōṭṭaṁ*) is native Dravidian, "a garden", from a root that means to dig (DEDR 3549).
