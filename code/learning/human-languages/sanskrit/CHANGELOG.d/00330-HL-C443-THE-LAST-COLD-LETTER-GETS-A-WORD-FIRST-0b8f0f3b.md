## HL-C443: the last cold letter gets a word first

Gentle writing asks for every letter to be taken from a word the reader
already says. One Sanskrit letter lesson came before any such word: the vowel
sign ौ, in chapter 15. The first word holding it was नौका, in chapter 75.

**मौन** (*mauna*, "silence") is now a short word lesson placed just before the
letter lesson, in the same path segment. The letter lesson and the lesson after
it each revisit the word, so its atom gets its two retrievals.

    sanskrit cold letter lessons   1  ->  0 (ceiling ratcheted)
