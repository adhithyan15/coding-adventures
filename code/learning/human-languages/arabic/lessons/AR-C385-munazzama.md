## You'll want to know: منظمة
<!-- hl-knowledge: introduces=[AR-LEX-C385-MUNAZZAMA385-01]; assesses=[] -->

**منظمة** — *munaẓẓama* — "an organization".

> تساعد المنظمة الأطفال.
>
> *tusāʿidu al-munaẓẓama al-aṭfāl.*
>
> The organization helps children.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**منظمة** (*munaẓẓama*) is built on the native Arabic root *n-ẓ-m*, "to string pearls, to put in order" (Lane). *Munaẓẓama* is a Form II passive participle, feminine, something put in order: an organization.
