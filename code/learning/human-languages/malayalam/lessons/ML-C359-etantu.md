# ഏതാണ്ട് (ētāṇṭŭ) — nearly; roughly

## You'll want to know: ഏതാണ്ട്
<!-- hl-knowledge: introduces=[ML-LEX-C359-VAIKATHE359-03]; assesses=[] -->

**ഏതാണ്ട്** — *ētāṇṭŭ* — "nearly; roughly".

> ഗ്രാമം ഏതാണ്ട് മുഴുവൻ വെള്ളത്തിൽ ആയിരുന്നു.
>
> *grāmaṁ ētāṇṭŭ muḻuvan veḷḷattil āyirunnu.*
>
> The village was nearly all under water.

Before a number it means about: ഏതാണ്ട് നൂറ് ആളുകൾ, about a hundred people.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ഏതാണ്ട്** (*ētāṇṭŭ*) is a native Malayalam adverb whose origin is not settled. It softens a number or a statement: almost, roughly.
