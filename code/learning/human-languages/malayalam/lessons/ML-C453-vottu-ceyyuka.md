# വോട്ട് ചെയ്യുക (vōṭṭŭ ceyyuka) — to vote

## You'll want to know: വോട്ട് ചെയ്യുക
<!-- hl-knowledge: introduces=[ML-LEX-C453-PINTUNA453-01]; assesses=[] -->

**വോട്ട് ചെയ്യുക** — *vōṭṭŭ ceyyuka* — "to vote".

> ഞാൻ ഇന്നലെ ആദ്യമായി വോട്ട് ചെയ്തു.
>
> *ñān innale ādyamāyi vōṭṭŭ ceytu.*
>
> Yesterday I voted for the first time.

Past: വോട്ട് ചെയ്തു, *vōṭṭŭ ceytu*.

For someone: -ന് വോട്ട് ചെയ്യുക.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**വോട്ട് ചെയ്യുക** (*vōṭṭŭ ceyyuka*) is a phrase verb built on വോട്ട്, which was borrowed from English *vote*, with ചെയ്യുക, "to do".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
