# હું જવાનો છું — a plan already made

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[GU-GRAMMAR-C149-JAISH-01, GU-GRAMMAR-C149-ISH-01, GU-GRAMMAR-VU-NEUTER-INFINITIVE] -->

[PAUSE 2s] Say *I'll go to the market tomorrow*. Then name the ending every
verb's name wears: **-વું**, as in **જવું**.

## Grammar Lens: -વાનો and the copula
<!-- hl-knowledge: introduces=[GU-GRAMMAR-C150-VAANO-01]; assesses=[GU-LEX-JAVU, GU-GRAMMAR-VU-NEUTER-INFINITIVE, GU-CONCEPT-C05-HUNGUJARATIBOLUNCHHUN-01, GU-CONCEPT-C04-KAALE-01] -->

**હું જઈશ** says *I will go*. **હું જવાનો છું** says *I'm going to go*: the
plan is already made.

> **હું કાલે જવાનો છું.** — *hũ kāle javāno chũ.* — I'm going tomorrow. (a man)
> **હું કાલે જવાની છું.** — *hũ kāle javānī chũ.* — the same, said by a woman.

The pieces: the verb's name **જવું**, with **-વું** turned into **-વાનો**, then
the present copula, **છું**, **છે**, **છીએ** or **છો**.

**-વાનો** agrees like *my*: **-વાનો**, **-વાની**, **-વાનું**, **-વાના**. So a
group says **અમે જવાના છીએ**, *we're going to go*.
