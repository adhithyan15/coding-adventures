# பேன் (pēṉ) — a louse

## You'll want to know: பேன்
<!-- hl-knowledge: introduces=[TA-LEX-C484-MUTI484-02]; assesses=[] -->

**பேன்** — *pēṉ* — "a louse".

> பள்ளியிலிருந்து வந்த குழந்தையின் தலையில் பேன் இருந்தது.
>
> *paḷḷiyiliruntu vanta kuḻantaiyiṉ talaiyil pēṉ iruntatu.*
>
> The child back from school had lice in her hair.

Plural: பேன்கள், *pēṉkaḷ*.

Plural பேன்கள்.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**பேன்** (*pēṉ*) is native Dravidian (DEDR 4449); Malayalam, Kota and Kannada have the same word.
