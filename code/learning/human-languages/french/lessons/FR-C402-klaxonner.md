## You'll want to know: klaxonner
<!-- hl-knowledge: introduces=[FR-LEX-C402-VITRES-04]; assesses=[] -->

**klaxonner** — "to honk, to sound the horn".

> Le chauffeur a klaxonné devant la maison.
>
> *The driver honked outside the house.*

Regular *-er* verb: *je klaxonne*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*klaxonner* is built on *klaxon* 'car horn' (EtymDB), which was borrowed from English *klaxon*.
