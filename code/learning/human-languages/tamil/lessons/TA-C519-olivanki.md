## You'll want to know: ஒலிவாங்கி
<!-- hl-knowledge: introduces=[TA-LEX-C519-OLI519-02]; assesses=[] -->

**ஒலிவாங்கி** — *olivāṅki* — "a microphone".

> பாடகர் ஒலிவாங்கியைக் கையில் எடுத்தார்.
>
> *pāṭakar olivāṅkiyaik kaiyil eṭuttār.*
>
> The singer picked up the microphone.

ஒலி "sound" + வாங்கி "that which takes in", from வாங்கு (*vāṅku*).

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ஒலிவாங்கி** (*olivāṅki*) is a modern native compound: ஒலி (*oli*), "sound", and வாங்கி (*vāṅki*), "that which receives", from வாங்கு, "to take, to get" (DEDR 5336).
