# Review — how it felt, and what I hope for

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[JA-GRAMMAR-C258-FEELING-01, JA-GRAMMAR-C258-AMBITION-01] -->

[PAUSE 2s] Say "the trip was fun". (*ryokō wa tanoshikatta desu*.) Then "I want to become a teacher". (*sensei ni naritai desu*.)
