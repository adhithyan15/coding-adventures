## You'll want to know: व्याख्या
<!-- hl-knowledge: introduces=[MR-LEX-C374-PRAKRIYA374-04]; assesses=[] -->

**व्याख्या** — *vyākhyā* — "a definition".

> शब्दकोशात या शब्दाची व्याख्या दिली आहे.
>
> *śabdakośāt yā śabdācī vyākhyā dilī āhe.*
>
> The dictionary gives the definition of this word.

Feminine.

X ची व्याख्या करणे, to define X.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**व्याख्या** (*vyākhyā*) is a tatsama, taken from Sanskrit *vyākhyā*, "explanation, exposition" (Monier-Williams).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
