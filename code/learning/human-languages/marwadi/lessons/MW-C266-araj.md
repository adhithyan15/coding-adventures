## You'll want to know: अरज
<!-- hl-knowledge: introduces=[MW-LEX-C266-HAJAR266-04]; assesses=[] -->

**अरज** — *araj* — "a petition".

> आप म्हारी अरज सुणो सा।
>
> *āp mhārī araj suṇo sā.*
>
> Please hear my petition.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**अरज** (*araj*) is usually traced, through Persian *ʿarz*, to Arabic *ʿarḍ*, "presenting": a request set before someone. It is feminine: **म्हारी अरज**.
