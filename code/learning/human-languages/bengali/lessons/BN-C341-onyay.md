## You'll want to know: অন্যায়
<!-- hl-knowledge: introduces=[BN-LEX-C341-ONYAY341-05]; assesses=[] -->

**অন্যায়** — *ônyāy* — "unfair; an injustice".

> এই শাস্তিটা অন্যায়।
>
> *ei shāstiṭā ônyāy.*
>
> This punishment is unfair.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**অন্যায়** (*ônyāy*) is Sanskrit *anyāya*, *a-* 'not' with *nyāya* 'what is right': unjust action (Monier-Williams). It works as a noun, a wrong, and as an adjective, unfair.
