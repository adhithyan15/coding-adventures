## You'll want to know: સગવડ
<!-- hl-knowledge: introduces=[GU-LEX-C409-LODGE409-03]; assesses=[] -->

**સગવડ** — *sagvaḍ* — "a convenience; a facility".

> આ હોટેલમાં બધી સગવડ છે.
>
> *ā hoṭelmā̃ badhī sagvaḍ che.*
>
> This hotel has every convenience.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**સગવડ** (*sagvaḍ*) No dictionary we use records an older form, so its history is not settled.
