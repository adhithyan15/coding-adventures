## You'll want to know: jardiner
<!-- hl-knowledge: introduces=[FR-LEX-C503-JARDIN-02]; assesses=[] -->

**jardiner** — "to garden".

> Ma mère jardine tous les samedis.
>
> *My mother gardens every Saturday.*

A regular *-er* verb.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*jardiner* is built on *jardin* "garden", which goes back to Frankish *gardo* "an enclosure".
