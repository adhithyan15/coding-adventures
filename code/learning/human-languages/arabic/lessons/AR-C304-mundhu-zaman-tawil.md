# منذ زمن طويل (mundhu zaman ṭawīl) — long ago; for a long time

## You'll want to know: منذ زمن طويل
<!-- hl-knowledge: introduces=[AR-LEX-C304-ZAMAN304-02]; assesses=[] -->

**منذ زمن طويل** — *mundhu zaman ṭawīl* — "long ago; for a long time".

> منذ زمن طويل كانت هنا غابة كبيرة.
>
> *mundhu zaman ṭawīl kānat hunā ghāba kabīra.*
>
> Long ago there was a big forest here.

It opens a story set in the past, or says how long a thing has lasted.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**منذ زمن طويل** (*mundhu zaman ṭawīl*) is "since a long time": the taught *mundhu*, "since", with *zaman*, built on the native Arabic root *z-m-n* (Lane), and *ṭawīl*, long.
