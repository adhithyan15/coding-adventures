## You'll want to know: प्रतीक्षा
<!-- hl-knowledge: introduces=[MR-LEX-C551-YADI551-01]; assesses=[] -->

**प्रतीक्षा** — *pratīkṣā* — "waiting; expectation".

> पाहुण्यांची आम्ही खूप वेळ प्रतीक्षा केली.
>
> *pāhuṇyāñcī āmhī khūp veḷ pratīkṣā kelī.*
>
> We waited a long time for the guests.

Feminine.

The one awaited takes -ची: पाहुण्यांची प्रतीक्षा करणे.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**प्रतीक्षा** (*pratīkṣā*) is a tatsama, taken from Sanskrit *pratīkṣā*, "expectation" (Monier-Williams).
