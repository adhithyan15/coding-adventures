# Four ways of saying no

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MR-JOIN-NAA-NAA, MR-JOIN-PAN] -->

[PAUSE 5s] You now hold four different noes: the answer **नाही**, the doubled
**ना … ना**, the sentence-final **नाही**, and **नको**. Only one of them can
refuse a cup of tea.
