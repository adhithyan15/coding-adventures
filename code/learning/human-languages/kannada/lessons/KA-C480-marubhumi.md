# ಮರುಭೂಮಿ (marubhūmi) — a desert

## You'll want to know: ಮರುಭೂಮಿ
<!-- hl-knowledge: introduces=[KA-LEX-C480-BAYALU480-02]; assesses=[] -->

**ಮರುಭೂಮಿ** — *marubhūmi* — "a desert".

> ಮರುಭೂಮಿಯಲ್ಲಿ ಒಂಟೆಗಳು ನೀರಿಲ್ಲದೆ ತುಂಬಾ ದಿನ ಇರುತ್ತವೆ.
>
> *marubhūmiyalli oṇṭegaḷu nīrillade tumbā dina iruttave.*
>
> In the desert camels go many days without water.

ಮರು, a wilderness, plus ಭೂಮಿ, land.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಮರುಭೂಮಿ** (*marubhūmi*) is built from two Sanskrit words: *maru*, "a wilderness" (CDIAL 9876a), and *bhūmi*, "earth, ground" (CDIAL 9557).
