## You'll want to know: பெயர்சூட்டு
<!-- hl-knowledge: introduces=[TA-LEX-C321-SADANGU321-03]; assesses=[] -->

**பெயர்சூட்டு** — *peyarcūṭṭu* — "to name a child".

> பாட்டி குழந்தைக்குப் பெயர்சூட்டினார்.
>
> *pāṭṭi kuḻantaikkup peyarcūṭṭiṉār.*
>
> Grandmother named the baby.

Past (I …): பெயர்சூட்டினேன், *peyarcūṭṭiṉēṉ*.

The child takes -க்கு: குழந்தைக்குப் பெயர்சூட்டு.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**பெயர்சூட்டு** (*peyarcūṭṭu*) is a Tamil compound built from பெயர், "name" (DEDR 4410), and சூட்டு, "to adorn, crown, invest with" (DEDR 2721).

## What you've built
