# ਹਾਂ — look, hide, write, compare

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-SCRIPT-HA-01, PA-SCRIPT-AA-MATRA-01, PA-SCRIPT-BINDI-01, PA-SCRIPT-HAAN-01] -->

Look at **ਹਾਂ** for five seconds. Point to its three pieces. Do not copy it yet.

## Writing — delayed copy
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-HAAN-NAHIN-01, PA-SCRIPT-HA-01, PA-SCRIPT-AA-MATRA-01, PA-SCRIPT-BINDI-01, PA-SCRIPT-HAAN-01] -->
<!-- hl-writing-stage: delayed-copy -->

1. cover **ਹਾਂ**
2. wait five seconds
3. write it once from memory
4. uncover the model and compare **ਹ**, **ਾ**, then **ਂ**

Circle and repair only a differing piece. Repair is part of the exercise, not a
failure.
