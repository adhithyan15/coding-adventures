# 大 — one bar, two falls

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ZH-LEX-DA-01] -->

[PAUSE 8s] Say **big** in Mandarin.

## Script — the shape
<!-- hl-knowledge: introduces=[ZH-SCRIPT-DA-01]; assesses=[] -->

> **一** + **丿** + **㇏** → **大**

Write the horizontal first. Start the left-falling stroke above it and cross
through it. Lift once more, return to the crossing, and fall long to the right.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[ZH-SCRIPT-DA-01] -->
<!-- hl-writing-stage: observe-trace -->

Trace **大** once. Copy it once while saying **bar, left, right**.
