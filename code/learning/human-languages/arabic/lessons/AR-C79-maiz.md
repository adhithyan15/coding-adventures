## You'll want to know: ماعز

**ماعز** — *māʿiz* — "a goat".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ماعز** (*māʿiz*) is built on the native Arabic root *m-ʿ-z*, "goats" (Lane). *Māʿiz* is one goat; *maʿz* is the collective.
