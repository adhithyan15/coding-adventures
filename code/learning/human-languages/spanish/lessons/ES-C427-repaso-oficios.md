# cinco personas y un lugar — sorted by how each name was built

## Grammar Lens: four ways to name a person
<!-- hl-knowledge: introduces=[]; assesses=[ES-LEX-C427-AGENT-01, ES-LEX-C427-AGENT-02, ES-LEX-C427-AGENT-03, ES-LEX-C427-AGENT-04, ES-LEX-C427-AGENT-05, ES-LEX-C423-CHAR-03] -->

| word | built from |
|---|---|
| el vendedor | the verb *vender*, plus **-dor** |
| el comprador | the verb *comprar*, plus **-dor** |
| el bombero | the noun *bomba*, plus **-ero** |
| el policía | the institution, *la policía* |
| el abogado | nothing in Spanish — inherited whole from Latin |

Four different methods for five words, which is the honest summary: Spanish does
not have one way of naming a profession. What it has is a small set of methods,
and knowing them lets you **take a profession apart** even when you could not
have predicted it.

The **-dor** pair is the only one that is productive for you: give it any verb
you know and it gives you back the person — which is how *trabajar* gave
*trabajador* in the character chapter, before you had any use for the ending.

## Grammar Lens: which ones change, and how
<!-- hl-knowledge: introduces=[]; assesses=[ES-LEX-C427-AGENT-01, ES-LEX-C427-AGENT-03, ES-LEX-C427-AGENT-05, ES-LEX-C427-AGENT-06] -->

| masculine | feminine |
|---|---|
| el vendedor | la vendedora |
| el bombero | la bombera |
| el abogado | la abogada |
| **el policía** | **la policía** — and the word also means the force |

Three behave ordinarily. **Policía** is the exception worth remembering,
because the article is carrying a distinction no ending marks.

And **la empresa** is not a person at all — it is where several of these people
work, which is why a form asks for it on its own line.
