# Criss-cross merges require every merge base in an independent tree proof

The first Venn typography frame used one merge-base and manufactured25 textual
conflicts across371 overlapping paths. Git's actual recursive merge was clean:
the histories have two independent merge bases. Build the virtual base from
both and their common ancestor, then reconstruct the final tree per object or
independent merge-file output. This proved6 virtual-base/6 final reconstructions
and the exact31-path combined tree, with native runtime inputs unchanged.

Represent absent add/add bases as empty input, and retain or verify immutable
partial artifacts when a preflight fails. The initial helper assumed every base
path existed and then collided with its partial snapshot on retry; both stopped
before source mutation. Compare object IDs first, so identical or one-sided
paths need no repeated large-blob subprocess reads. Consume the helper before
mutating its fixed source. Never substitute an apparent clean merge for a
complete ownership/input proof.
