# சிறுநீரகம் (ciṟunīrakam) — a kidney

## You'll want to know: சிறுநீரகம்
<!-- hl-knowledge: introduces=[TA-LEX-C478-UTAL478-04]; assesses=[] -->

**சிறுநீரகம்** — *ciṟunīrakam* — "a kidney".

> நிறைய தண்ணீர் குடிப்பது சிறுநீரகத்துக்கு நல்லது.
>
> *niṟaiya taṇṇīr kuṭippatu ciṟunīrakattukku nallatu.*
>
> Drinking plenty of water is good for the kidneys.

சிறுநீர் "urine" + அகம் "place".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**சிறுநீரகம்** (*ciṟunīrakam*) is a native compound built from சிறு *ciṟu*, "small" (DEDR 1594), நீர் *nīr*, "water" (DEDR 3690), and அகம், "place".
