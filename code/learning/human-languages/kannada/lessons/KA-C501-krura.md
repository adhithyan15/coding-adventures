# ಕ್ರೂರ (krūra) — cruel; fierce

## You'll want to know: ಕ್ರೂರ
<!-- hl-knowledge: introduces=[KA-LEX-C501-SAUMYA501-03]; assesses=[] -->

**ಕ್ರೂರ** — *krūra* — "cruel; fierce".

> ಆ ಕ್ರೂರ ಮನುಷ್ಯ ನಾಯಿಯನ್ನು ಹೊಡೆದನು.
>
> *ā krūra manuṣya nāyiyannu hoḍedanu.*
>
> That cruel man beat the dog.

ಕ್ರೂರ ಪ್ರಾಣಿ, a fierce animal.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಕ್ರೂರ** (*krūra*) is borrowed whole from Sanskrit *krūra*, "bloody, cruel" (CDIAL 3602).
