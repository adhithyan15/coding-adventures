# അർബുദം (arbudaṁ) — cancer

## You'll want to know: അർബുദം
<!-- hl-knowledge: introduces=[ML-LEX-C535-VATAM535-01]; assesses=[] -->

**അർബുദം** — *arbudaṁ* — "cancer".

> പുകവലി അർബുദത്തിന് കാരണമാകും.
>
> *pukavali arbudattinŭ kāraṇamākuṁ.*
>
> Smoking can cause cancer.

In speech many say ക്യാൻസർ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**അർബുദം** (*arbudaṁ*) is borrowed from Sanskrit *arbuda*, "a long round mass; a tumour" (CDIAL 686).
