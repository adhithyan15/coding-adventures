## You'll want to know: شعب
<!-- hl-knowledge: introduces=[AR-LEX-C329-THAWRA329-05]; assesses=[] -->

**شعب** — *shaʿb* — "a country’s people; a nation".

> شعب هذا البلد كريم جدا.
>
> *shaʿb hādhā al-balad karīm jiddan.*
>
> The people of this country are very generous.

Plural: شعوب, *shuʿūb*.

The adjective شعبي is popular, folk: أكلة شعبية.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**شعب** (*shaʿb*) is built on the native Arabic root *sh-ʿ-b* (Lane), which means both "to branch apart" and "to gather"; Lane gives *shaʿb* as a great tribe from which smaller ones branch.
