# பரிவர்த்தனை (parivarttaṉai) — a transaction; an exchange

## You'll want to know: பரிவர்த்தனை
<!-- hl-knowledge: introduces=[TA-LEX-C449-ELAM449-03]; assesses=[] -->

**பரிவர்த்தனை** — *parivarttaṉai* — "a transaction; an exchange".

> இணையத்தில் பணப் பரிவர்த்தனை செய்வது எளிது.
>
> *iṇaiyattil paṇap parivarttaṉai ceyvatu eḷitu.*
>
> Making money transactions on the internet is easy.

பணப் பரிவர்த்தனை is a money transaction.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**பரிவர்த்தனை** (*parivarttaṉai*) is borrowed from Sanskrit *parivartana*, "turning round, moving to and fro" (Monier-Williams), used for exchange.
