## You'll want to know: dünsten
<!-- hl-knowledge: introduces=[GE-LEX-C327-KOECHELN-03]; assesses=[] -->

**dünsten** — "to steam, to braise".

> Er dünstete das Gemüse in wenig Wasser.
>
> *He steamed the vegetables in a little water.*

Gentle cooking with little liquid.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*dünsten* is built on *Dunst* "vapour, steam" (EtymDB), an inherited Germanic word.
