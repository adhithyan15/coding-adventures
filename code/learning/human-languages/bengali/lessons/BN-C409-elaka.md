# এলাকা (elākā) — an area; a locality

## You'll want to know: এলাকা
<!-- hl-knowledge: introduces=[BN-LEX-C409-ELAKA409-01]; assesses=[] -->

**এলাকা** — *elākā* — "an area; a locality".

> এই এলাকায় অনেক দোকান আছে।
>
> *ei elākāy ônek dokān āchhe.*
>
> There are many shops in this area.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**এলাকা** (*elākā*) is usually traced to Arabic *ʿalāqa*, "a connection, a holding", which in Persian came to mean a district.
