## You'll want to know: कपटी
<!-- hl-knowledge: introduces=[MR-LEX-C469-KATHOR469-05]; assesses=[] -->

**कपटी** — *kapṭī* — "deceitful".

> त्या कपटी माणसावर विश्वास ठेवू नये.
>
> *tyā kapṭī māṇsāvar viśvās ṭhevū naye.*
>
> One should not trust that deceitful man.

From कपट, deceit. Unchanging.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**कपटी** (*kapṭī*) is a tatsama, taken from Sanskrit *kapaṭin*, "deceitful" (Monier-Williams), built on *kapaṭa*, "fraud".
