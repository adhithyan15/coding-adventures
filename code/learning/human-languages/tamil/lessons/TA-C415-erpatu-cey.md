## You'll want to know: ஏற்பாடு செய்
<!-- hl-knowledge: introduces=[TA-LEX-C415-AVANAM415-05]; assesses=[] -->

**ஏற்பாடு செய்** — *ēṟpāṭu cey* — "to arrange; to organise".

> அப்பா பயணத்துக்கு எல்லாம் ஏற்பாடு செய்தார்.
>
> *appā payaṇattukku ellām ēṟpāṭu ceytār.*
>
> Father arranged everything for the trip.

Past (I …): ஏற்பாடு செய்தேன், *ēṟpāṭu ceytēṉ*.

What it is arranged for takes -க்கு: பயணத்துக்கு ஏற்பாடு செய், to make arrangements for a trip.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ஏற்பாடு செய்** (*ēṟpāṭu cey*) joins ஏற்பாடு, "an arrangement", which is native Dravidian (DEDR 905), to செய், "to do".
