## You'll want to know: تدهور
<!-- hl-knowledge: introduces=[AR-LEX-C486-TAQALLUB486-02]; assesses=[] -->

**تدهور** — *tadahwara* — "to get worse; to deteriorate".

> تدهور الطقس فعدنا إلى الفندق.
>
> *tadahwara aṭ-ṭaqs fa-ʿudnā ilā al-funduq.*
>
> The weather got worse, so we went back to the hotel.

Present: يتدهور, *yatadahwar*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**تدهور** (*tadahwara*) is a verb with four root letters; the origin is not settled.
