# உத்தரவாதம் (uttaravātam) — a guarantee; a warranty

## You'll want to know: உத்தரவாதம்
<!-- hl-knowledge: introduces=[TA-LEX-C542-UTHTHARAVATHAM542-01]; assesses=[] -->

**உத்தரவாதம்** — *uttaravātam* — "a guarantee; a warranty".

> இந்தக் கைப்பேசிக்கு ஒரு வருட உத்தரவாதம் இருக்கிறது.
>
> *intak kaippēcikku oru varuṭa uttaravātam irukkiṟatu.*
>
> This phone has a one-year guarantee.

With கொடு (*koṭu*): உத்தரவாதம் கொடு, to give a guarantee.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**உத்தரவாதம்** (*uttaravātam*) is usually traced to Sanskrit *uttara*, "an answer, a reply", and *vāda*, "a statement" (Monier-Williams): an answering for something.
