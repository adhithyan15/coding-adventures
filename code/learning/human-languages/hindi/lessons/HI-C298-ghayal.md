# घायल (ghāyal) — injured; wounded

## You'll want to know: घायल
<!-- hl-knowledge: introduces=[HI-LEX-C298-GHAYAL298-02]; assesses=[] -->

**घायल** — *ghāyal* — "injured; wounded".

> हादसे में दस लोग घायल हुए।
>
> *hādse meṁ das log ghāyal hue.*
>
> Ten people were injured in the accident.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**घायल** (*ghāyal*) is built on *ghāy*, a wound, which CDIAL 4460 lists for Hindi under Sanskrit *ghāta*, "a blow". **घायल होना** is to be injured: **दस लोग घायल हुए**.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
