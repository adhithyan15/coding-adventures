# അല്ലാത്തപക്ഷം (allāttapakṣaṁ) — or else; otherwise

## You'll want to know: അല്ലാത്തപക്ഷം
<!-- hl-knowledge: introduces=[ML-LEX-C440-VYAVASTHA440-05]; assesses=[] -->

**അല്ലാത്തപക്ഷം** — *allāttapakṣaṁ* — "or else; otherwise".

> അവൻ വേഗം ഇറങ്ങി, അല്ലാത്തപക്ഷം ബസ് പോകുമായിരുന്നു.
>
> *avan vēgaṁ iṟaṅṅi, allāttapakṣaṁ basŭ pōkumāyirunnu.*
>
> He left quickly; otherwise the bus would have gone.

It joins a clause and the bad result that would follow without it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**അല്ലാത്തപക്ഷം** (*allāttapakṣaṁ*) is a Malayalam compound: അല്ലാത്ത, "that is not so", native Dravidian (DEDR 234), and പക്ഷം, "a case", from Sanskrit *pakṣa* (CDIAL 7627).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
