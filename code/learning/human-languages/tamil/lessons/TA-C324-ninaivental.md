# நினைவேந்தல் (niṉaivēntal) — a memorial meeting

[PAUSE 2s] Before the new one: say the Tamil for a memorial day, then the Tamil for to cremate.

## You'll want to know: நினைவேந்தல்
<!-- hl-knowledge: introduces=[TA-LEX-C324-ANJALI324-05]; assesses=[] -->

**நினைவேந்தல்** — *niṉaivēntal* — "a memorial meeting".

> பள்ளியில் ஒரு நினைவேந்தல் கூட்டம் நடந்தது.
>
> *paḷḷiyil oru niṉaivēntal kūṭṭam naṭantatu.*
>
> A memorial meeting was held at the school.

நினைவு, memory + ஏந்தல், holding up.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**நினைவேந்தல்** (*niṉaivēntal*) is a Tamil compound built from நினைவு, "remembrance" (DEDR 3683), and ஏந்தல், "holding up", from ஏந்து, "to hold up in the hands" (DEDR 894).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
