# বিশ্বস্ত (bishvôstô) — trustworthy; loyal

## You'll want to know: বিশ্বস্ত
<!-- hl-knowledge: introduces=[BN-LEX-C458-SOT458-03]; assesses=[] -->

**বিশ্বস্ত** — *bishvôstô* — "trustworthy; loyal".

> আমাদের পুরনো দারোয়ান বিশ্বস্ত লোক।
>
> *āmāder purôno dāroyān bishvôstô lok.*
>
> Our old gatekeeper is a trustworthy man.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**বিশ্বস্ত** (*bishvôstô*) is a tatsama, Sanskrit *viśvasta*, "trusted, faithful" (Monier-Williams), from the same root as বিশ্বাস করা (taught), to trust.
