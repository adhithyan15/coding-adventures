# Objective stems must name the same deliverable as their keyed source fact

An objective listening item asked when a "report" was due, while its source
distinguished a summary due that day from the full report due the next morning.
That made two options defensible even though the key intended only the summary.
Name the exact deliverable in the learner-facing stem, and pin the stem, source
fact, and answer-key label together in the owned test so future edits cannot
silently separate them.
