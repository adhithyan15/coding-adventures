# തുറക്കുക (thuṟakkuka) — to open

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C52-WELCOME-01] -->

[PAUSE 2s] Say *door*. You have been able to name it for a long time and have
never been able to do anything to it.

## You'll want to know
<!-- hl-knowledge: introduces=[ML-LEX-C95-OPEN-01]; assesses=[] -->

**തുറക്കുക** — *thuṟakkuka* — **to open.**

> **ഞാൻ വാതിൽ തുറക്കുന്നു.** — *ñān vātil thuṟakkunnu* — "I open the door."

Look at what the sentence asked of you. **Nothing new but the verb.** The doer
in front, the thing in the middle, the verb at the end — and **വാതിൽ** takes no
ending, because it is a thing and not a person.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C95-OPEN-01, ML-CONCEPT-C32-POKUKA-02] -->

The verb behaves like every other verb you own. It takes the same three endings,
in the same three places:

| | |
|---|---|
| **തുറക്കുന്നു** *thuṟakkunnu* | opens |
| **തുറന്നു** *thuṟannu* | opened |
| **തുറക്കും** *thuṟakkuṁ* | will open |

**You did not have to learn those.** You learned them once, on a different verb,
and this one arrived already knowing them.
