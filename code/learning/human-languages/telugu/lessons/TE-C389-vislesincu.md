# విశ్లేషించు (viślēṣiñcu) — to analyse

## You'll want to know: విశ్లేషించు
<!-- hl-knowledge: introduces=[TE-LEX-C389-VISLESANA389-01]; assesses=[] -->

**విశ్లేషించు** — *viślēṣiñcu* — "to analyse".

> మేము పరీక్ష ఫలితాలను విశ్లేషించాము.
>
> *mēmu parīkṣa phalitālanu viślēṣiñcāmu.*
>
> We analysed the exam results.

Past (I …): విశ్లేషించాను, *viślēṣiñcānu*.

To take a question apart to find out how it works.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**విశ్లేషించు** (*viślēṣiñcu*) is built on Sanskrit *viśleṣa*, "loosening, separation, dissolution" (Monier-Williams), with the Telugu verb ending -ఇంచు.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
