# सो — a hundred on the page

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MW-LEX-KITNO-01, MW-SCRIPT-BEES-01] -->

[PAUSE 16s] Say how much, then write twenty.

## You'll want to know
<!-- hl-knowledge: introduces=[MW-SCRIPT-SO-01]; assesses=[MW-SCRIPT-SA-01, MW-SCRIPT-O-MATRA-01, MW-SCRIPT-NO-NINE-01, MW-SCRIPT-DO-TWO-01, MW-LEX-SO-01] -->

> **स** + **ो** → **सो** — *so* — a hundred

Now write the three short ones in a column: **दो**, **नो**, **सो**. The mark on
the right never changes. The letter on the left is the entire difference
between two, nine and a hundred.

That column is worth keeping. It is the one place in this book where a single
mistaken stroke changes a price by a factor of fifty.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-SO-01, MW-SCRIPT-NO-NINE-01, MW-SCRIPT-DO-TWO-01] -->
<!-- hl-writing-stage: dictation-transcription -->

Write **दो**, **नो**, **सो** from dictation, given out of order, three times
over. Then read your own column back and say each amount.
