# Malayalam C2 mock 2 — learner paper and examiner script

Administration: Reading 90 minutes, Listening 60 minutes, Writing 90 minutes,
and Speaking 25 minutes with 15 minutes preparation. Play each listening text
once at 165–200 words per minute. Each form uses a documented regional Malayalam voice:
the rapid discussion uses Kochi urban Malayalam, and the media extract uses Kasaragod
Malayalam. Malayalam stimuli contain no romanization.

## Reading — 90 minutes

### Stylistically marked specialist argument — items 1–10

**പുതിയ നിർമ്മാണത്തിന് ഫീത മുറിക്കുന്ന ചിത്രം ഉണ്ടാകും; പരിപാലനത്തിന് സാധാരണ
ചിത്രമില്ല. ഈ ദൃശ്യ അസമത്വം ബജറ്റിലും ആവർത്തിക്കുന്നു. പാലം പണിത തുക “നിക്ഷേപം”,
അത് വർഷംതോറും പരിശോധിക്കുന്ന തുക “ചെലവ്”. ഭാഷ കണക്കിന്റെ അലങ്കാരമല്ല: ഒന്ന്
ഭാവി നിർമ്മിക്കുന്നതായി കേൾക്കുന്നു, മറ്റൊന്ന് കഴിഞ്ഞകാലത്തിന്റെ ഭാരമായി.

പരിപാലനത്തെ വെറും സാങ്കേതിക ചക്രമായി തിരുത്തിയാൽ പ്രശ്നം പകുതി മാത്രം പരിഹരിക്കും.
ഏത് പൊട്ടലാണ് ആദ്യം നന്നാക്കേണ്ടത് എന്നത് എഞ്ചിനീയറിങ് ചോദ്യം മാത്രമല്ല. ചെറിയ
പൊട്ടൽ കാരണം വീൽചെയർ തടയുന്ന നടപ്പാതയും, വലിയ പൊട്ടൽ ഉള്ള പക്ഷേ പകരംവഴിയുള്ള
വാഹനപാതയും ഒരേ അപകടക്രമത്തിൽ വരണമെന്നില്ല. “ആസ്തിയുടെ മൂല്യം” മാത്രം മാനദണ്ഡമാക്കിയാൽ
ഏറ്റവും വിലകൂടിയ പ്രദേശം ഏറ്റവും അടിയന്തരമാകും; ഉപയോഗത്തിന്റെ അസമത്വം കാണാതാകും.

ഇപ്പോൾ ചില നഗരങ്ങൾ പ്രവചനപരിപാലനത്തിന് സെൻസറും യന്ത്രപഠനവും ഉപയോഗിക്കുന്നു.
തകരുന്നതിന് മുമ്പ് സൂചന കിട്ടുന്നത് നേട്ടമാണ്. പക്ഷേ പഴയ അറ്റകുറ്റപ്പണി രേഖകൾ
ഏത് പ്രദേശത്ത് വിശദമാണോ അവിടെയാണ് മാതൃകയ്ക്ക് പഠിക്കാൻ കൂടുതൽ തെളിവ്. പരാതികൾ
രേഖപ്പെടുത്താത്ത കോളനിയുടെ നിശ്ശബ്ദത നല്ല അവസ്ഥയായി വായിക്കപ്പെടാം. പഴയ അവഗണന
ഭാവിയുടെ കുറഞ്ഞ അപകടമായി മടങ്ങിവരും—കണക്കിന്റെ സുന്ദരമായ വൃത്തം.

അതിനാൽ പരിപാലനനയം രണ്ടു ഓർമ്മകൾ വേണം: വസ്തുവിന്റെ ക്ഷയവും സ്ഥാപനത്തിന്റെ
കാണാതിരിക്കലും. പരിശോധനാ പട്ടികയിൽ പൊട്ടലിന്റെ നീളം മാത്രമല്ല, തടസ്സത്തിന്
പകരംവഴിയുണ്ടോ, പരാതി പറയാനുള്ള വഴി ആരെ ഒഴിവാക്കുന്നു, മുമ്പ് എത്ര തവണ തീരുമാനം
മാറ്റിവെച്ചു എന്നിവയും വേണം. ഈ വിപുലീകരണം “രാഷ്ട്രീയം സാങ്കേതികതയിൽ കലർത്തുന്നു”
എന്ന് വിമർശിക്കാം. യഥാർഥത്തിൽ രാഷ്ട്രീയം ഇതിനകം കലർന്നിരുന്നു; വിലയുടെ നിരയും
രേഖയുടെ സമൃദ്ധിയും അതിനെ നിഷ്പക്ഷമായി വേഷമിട്ടു. പരിപാലനം പഴയത് നിലനിർത്തൽ
മാത്രമല്ല. ആരുടെ ദൈനംദിനം ഭാവിയിലേക്കു കൊണ്ടുപോകണമെന്നുള്ള ആവർത്തിച്ച തീരുമാനം.
അതിനാൽ അതിന് ചിത്രം ഇല്ലാത്തതല്ല പ്രശ്നം; നാം നോക്കാൻ പരിശീലിക്കാത്തതാണ്.**

1. “ദൃശ്യ അസമത്വം” എന്തിനെ സൂചിപ്പിക്കുന്നു? A പാലത്തിന് ചിത്രം ഇല്ല / B ബജറ്റ് രഹസ്യം / C പുതിയ നിർമ്മാണം ഭാവിയായി, പരിപാലനം ഭാരമായി അവതരിപ്പിക്കുന്നു
2. “ഭാഷ കണക്കിന്റെ അലങ്കാരമല്ല” എന്നതിന്റെ അർത്ഥം? A വാക്കുകൾ നീളം കൂടുന്നു / B വിഭാഗനാമങ്ങൾ വിഭവത്തെക്കുറിച്ചുള്ള വിധിയെ രൂപപ്പെടുത്തുന്നു / C കണക്ക് വേണ്ട
3. നടപ്പാത/വാഹനപാത ഉദാഹരണം തെളിയിക്കുന്നത്? A പൊട്ടലിന്റെ വലുപ്പം മാത്രം സാമൂഹിക അടിയന്തരതയല്ല / B വാഹനപാത വേണ്ട / C നടപ്പാത വിലകൂടിയതാണ്
4. ആസ്തിമൂല്യം മാത്രം ഉപയോഗിക്കുന്നതിലെ അപകടം? A വില കുറയും / B എല്ലാ പ്രദേശവും തുല്യം / C വിലകൂടിയ ഇടം സ്വയം മുൻഗണന നേടി ഉപയോഗഅസമത്വം മറയും
5. പ്രവചനമാതൃകയിലെ data bias? A സെൻസർ പ്രവർത്തിക്കില്ല / B സമൃദ്ധ രേഖയുള്ള പ്രദേശം കൂടുതൽ പഠനയോഗ്യമാകുന്നു / C പരാതി എല്ലായ്പ്പോഴും തെറ്റാണ്
6. “സുന്ദരമായ വൃത്തം” ഏത്? A പഴയ അവഗണന കുറവ് ഡാറ്റയായി, അത് ഭാവിയിലെ കുറഞ്ഞ മുൻഗണനയായി / B എല്ലാ പാലവും വൃത്തമാണ് / C ബജറ്റ് ആവർത്തിക്കുന്നു
7. നയത്തിന് വേണ്ട രണ്ടു ഓർമ്മകൾ? A വിലയും നിറവും / B മഴയും വേനലും / C വസ്തുവിന്റെ ക്ഷയവും സ്ഥാപനത്തിന്റെ കാണാതിരിക്കലും
8. വിമർശനത്തിന് എഴുത്തുകാരന്റെ മറുപടി? A രാഷ്ട്രീയം ഒഴിവാക്കാം / B രാഷ്ട്രീയം മുൻപേ മാനദണ്ഡങ്ങളിൽ മറഞ്ഞിരുന്നു / C സാങ്കേതികത വേണ്ട
9. അവസാനത്തെ “നോക്കാൻ പരിശീലിക്കാത്തത്” എന്ത് ചെയ്യുന്നു? A ചിത്രമെടുക്കാൻ പറയുന്നു / B എഞ്ചിനീയറെ കുറ്റപ്പെടുത്തുന്നു / C ദൈനംദിന പരിപാലനത്തിന്റെ രാഷ്ട്രീയ മൂല്യം കാണാനുള്ള സംസ്കാരക്കുറവ് ചൂണ്ടുന്നു
10. വാദത്തിന്റെ കേന്ദ്രം? A പഴയതെല്ലാം മാറ്റണം / B പരിപാലനം ഭൗതികവും സ്ഥാപനപരവുമായ അസമത്വം തിരുത്തുന്ന ഭാവിതീരുമാനമാണ് / C സെൻസർ മാത്രം മതിയാകും

### Varied public discourse with competing voices — items 11–20

**കടൽത്തീര “ശാന്തമേഖല”യെക്കുറിച്ചുള്ള അറിയിപ്പിൽ പുലർച്ചെ അഞ്ചുമുതൽ എട്ടുവരെ
വാണിജ്യപ്രവർത്തനം നിരോധിക്കും എന്ന് പറഞ്ഞു. വിനോദസഞ്ചാരവകുപ്പ് അത് ആമകളുടെ
മുട്ടയിടൽ സംരക്ഷണമായി അവതരിപ്പിച്ചു. മീൻവിൽപ്പനക്കാരി ജമീല ചോദിച്ചു: “ആമയ്ക്ക്
ശാന്തി വേണം; ഞങ്ങളുടെ ലേലം ശബ്ദം മാത്രം മലിനീകരണമാകുന്നത് എങ്ങനെ? രാത്രി മുഴുവൻ
ഹോട്ടൽ ജനറേറ്റർ കടലിന്റെ താലോലിപ്പാട്ടാണോ?”

ഹോട്ടൽ ഉടമ വിവേക് ജനറേറ്റർ പുതിയ ശബ്ദമതിലിനകത്താണെന്ന് പറഞ്ഞു; ലേലം മറ്റൊരു
സ്ഥലത്തേക്ക് മാറ്റിയാൽ ശുചിത്വവും പാർക്കിംഗും മെച്ചപ്പെടുമെന്നും. മത്സ്യതൊഴിലാളി
സോമൻ മറുപടി നൽകി: “കടലിൽ നിന്നെത്തുന്ന സമയം പട്ടിക നോക്കില്ല. ലേലം അകത്തേക്ക്
മാറ്റുമ്പോൾ മീനിന്റെ ചൂടും വാങ്ങുന്നവന്റെ സമയവും മാറും.” പരിസ്ഥിതി ഗവേഷക മായ
ഡാറ്റയിലെ വിടവ് സമ്മതിച്ചു. പ്രകാശവും വാഹനവും അളന്നെങ്കിലും ജനറേറ്ററിന്റെ താഴ്ന്ന
ആവൃത്തി ശബ്ദം അളന്നിട്ടില്ല; ലേലം നടക്കുന്ന മൂന്നു ആഴ്ച മാത്രമാണ് സർവേ ചെയ്തത്.

യുവ ഹോട്ടൽതൊഴിലാളി അലൻ വേറൊരു ചോദ്യമുയർത്തി. നിരോധനത്തിന് ശേഷം അതിഥികളുടെ
“നിശ്ശബ്ദ സൂര്യോദയ” പാക്കേജ് കൂടും; അതിനായി തന്റെ ഷിഫ്റ്റ് നാലരയ്ക്ക് തുടങ്ങും.
ശാന്തമേഖല ആരുടെ ശരീരത്തിൽ നിന്നാണ് നിർമ്മിക്കുന്നത്? യോഗത്തിൽ വകുപ്പ് ഒരു
പരീക്ഷണം നിർദേശിച്ചു: ലേലം രണ്ടു ചെറിയ മേഖലകളായി പിരിക്കുക, ജനറേറ്ററിനും
വാഹനത്തിനും ഒരേ ശബ്ദപരിധി, ആമനിരീക്ഷണം സ്വതന്ത്രസംഘത്തിന്. ജമീല സമ്മതിച്ചില്ല;
പക്ഷേ പരീക്ഷണം തടഞ്ഞുമില്ല. ഔദ്യോഗിക കുറിപ്പ് അതിനെ “സമൂഹത്തിന്റെ സമ്മതം” എന്നു
വിളിച്ചു. അവൾ പിന്നീട് പറഞ്ഞു: “എന്റെ വാതിൽ തുറന്നുവെച്ചതിനെ അവർ അകത്തു
കയറിയ ക്ഷണമാക്കി.”**

### Literary and intertextual prose — items 31–40

**അമ്മയുടെ വീട്ടുതാക്കോൽ എനിക്ക് കിട്ടിയപ്പോൾ വീട് ഇതിനകം മറ്റൊരാൾക്ക് വിറ്റിരുന്നു.

നൽകാമെന്ന് സഹോദരൻ പറഞ്ഞു; വീട് സ്വാതന്ത്ര്യസമരകാലത്ത് രഹസ്യയോഗങ്ങൾക്ക് ഉപയോഗിച്ചിരുന്നുവെന്ന്
കുടുംബകഥ. തെളിവായി താക്കോൽ മതിയാകില്ലെന്ന് മ്യൂസിയം പറഞ്ഞു. എനിക്ക് ആശ്വാസമായി:
ചരിത്രം ഞങ്ങളുടെ അലമാരയിൽ തന്നെ തുടരാം.

“കുട്ടികൾ ഉറങ്ങുന്നതുവരെ ഞാൻ പാത്രം കഴുകുന്നതുപോലെ നടിച്ചു.” ധീരതയും ഭയവും
ഒരേ പാത്രത്തിൽ ശബ്ദിച്ചു.

മ്യൂസിയം വീണ്ടും താൽപര്യം കാണിച്ചു. പ്രദർശനത്തിന് “തുറന്ന വാതിൽ” എന്ന പേര്

അവകാശമായിരിക്കാം. അവൾ ഒരു പ്രതീകമാകാൻ ജീവിച്ചില്ല; വാതിൽ തുറക്കാനും അടയ്ക്കാനും
