# কষ্ট (kôshṭô) — suffering; hardship

## You'll want to know: কষ্ট
<!-- hl-knowledge: introduces=[BN-LEX-C439-SUKH439-02]; assesses=[] -->

**কষ্ট** — *kôshṭô* — "suffering; hardship".

> গরমে বাসে যেতে আমার কষ্ট হয়।
>
> *gôrôme bāse jete āmār kôshṭô hôy.*
>
> Travelling by bus in the heat is hard for me.

কষ্ট হওয়া, to be hard for someone: আমার কষ্ট হয়. কষ্ট পাওয়া, to suffer, to be hurt.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**কষ্ট** (*kôshṭô*) is a tatsama, Sanskrit *kaṣṭa*, "bad, ill, painful" (Monier-Williams); Bengali uses it as a noun, the hardship itself.
