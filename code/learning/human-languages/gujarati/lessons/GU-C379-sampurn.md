# સંપૂર્ણ (sampūrṇ) — complete

## Warm-up

## You'll want to know: સંપૂર્ણ
<!-- hl-knowledge: introduces=[GU-LEX-C379-ATYANT379-03]; assesses=[] -->

**સંપૂર્ણ** — *sampūrṇ* — "complete".

> જો કામ સંપૂર્ણ થશે તો અમે પગાર ચૂકવીશું.
>
> *jo kām sampūrṇ thaśe to ame pagār cūkvīśũ.*
>
> If the work is completed, we will pay the wages.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**સંપૂર્ણ** (*sampūrṇ*) is a tatsama, borrowed from Sanskrit *sampūrṇa*, "completely filled, full" (Monier-Williams).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
