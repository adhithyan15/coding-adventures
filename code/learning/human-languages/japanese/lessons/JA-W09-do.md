# ど — voice a sign you already own

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[JA-SCRIPT-TO-01, JA-SCRIPT-DAKUTEN-01, JA-LEX-WAKARIMASEN] -->

[PAUSE 12s] Write **と**. Add the two-stroke dakuten beside it. Say
*wakarimasen* once as the reason a repetition may be needed.

## Script — carry the voicing mark
<!-- hl-knowledge: introduces=[JA-SCRIPT-DO-01]; assesses=[] -->

> **と** *to* + **゛** → **ど** *do*

The base shape does not change. Write **と** first, then add the two short
dakuten strokes at the upper right. The mark voices the opening consonant: *t*
becomes *d* while the vowel stays *o*.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[JA-SCRIPT-DO-01, JA-SCRIPT-TO-01, JA-SCRIPT-DAKUTEN-01] -->

1. Copy **と → ど** once.
2. Cover the model and write the voiced sign from the heard mora *do*.
3. Read **と / ど** as *to / do* without changing the vowel.
