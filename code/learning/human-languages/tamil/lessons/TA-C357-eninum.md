# எனினும் (eṉiṉum) — nevertheless; however

## You'll want to know: எனினும்
<!-- hl-knowledge: introduces=[TA-LEX-C357-ENINUM357-01]; assesses=[] -->

**எனினும்** — *eṉiṉum* — "nevertheless; however".

> மழை பெய்தது, எனினும் போட்டி நடந்தது.
>
> *maḻai peytatu, eṉiṉum pōṭṭi naṭantatu.*
>
> It rained. Nevertheless, the match took place.

A formal written word; the everyday one is இருந்தாலும். It opens the second sentence, with a comma.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**எனினும்** (*eṉiṉum*) is native: it is *eṉ*, "to say" (DEDR 868), with the concessive ending -இனும், "even if": "even if it is said so".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
