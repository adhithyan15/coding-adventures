# ગળ્યું (gaḷyũ) — sweet

## You'll want to know: ગળ્યું
<!-- hl-knowledge: introduces=[GU-LEX-C171-TASTE171-05]; assesses=[] -->

**ગળ્યું** — *gaḷyũ* — "sweet".

> **ગુજરાતી દાળ ગળી છે.** — *gujarātī dāḷ gaḷī che* — "Gujarati dal is sweet."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ગળ્યું** (*gaḷyũ*) is a tadbhava. CDIAL lists it, glossed "sweet", among the words built on Sanskrit *guḍa*, "boiled sugarcane juice, molasses" (CDIAL 4182).
