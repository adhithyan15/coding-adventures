# फिर आइएगा (phir āiegā) — do come again

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[HI-LEX-C121-CARE-02, HI-LEX-C121-CARE-03] -->

[PAUSE 2s] Before the new one: say the Hindi for carefully, then the Hindi for a good journey.

## You'll want to know: फिर आइएगा
<!-- hl-knowledge: introduces=[HI-LEX-C121-CARE-04]; assesses=[] -->

**फिर आइएगा** (*phir āiegā*) — "do come again".

**फिर** is "again", and **आइएगा** is an extra-polite **आइए**, a request for later rather than now.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

An invitation to return.
