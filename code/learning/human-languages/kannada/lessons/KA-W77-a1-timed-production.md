# A short Kannada A1 writing checkpoint

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C01-NAMASKARA-01, KA-LEX-C02-NANNA-HESARU-01, KA-GRAMMAR-C02-NANNA-HESARU-02, KA-LEX-C04-MATTE-SIGONA-01, KA-LEX-C05-MATANADU-01, KA-LEX-C05-KANNADA-01, KA-GRAMMAR-C05-KANNADA-02, KA-LEX-C39-CHAHA-01, KA-LEX-C41-DEIXIS-06, KA-GRAMMAR-C69-ASK-02, KA-SCRIPT-RECOG-153] -->

[PAUSE 2s] This is a short independent attempt, not a model. You will write the answers, and
this page will not show you any copyable Kannada answer.

Put away romanization, dictionaries, translators, and spell-checkers. Set a
**three-minute timer**. Write in Kannada script. Short, legible answers are
enough.

## Writing — timed assessment production
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C01-NAMASKARA-01, KA-LEX-C02-NANNA-HESARU-01, KA-GRAMMAR-C02-NANNA-HESARU-02, KA-LEX-C04-MATTE-SIGONA-01, KA-LEX-C05-MATANADU-01, KA-LEX-C05-KANNADA-01, KA-GRAMMAR-C05-KANNADA-02, KA-LEX-C39-CHAHA-01, KA-LEX-C41-DEIXIS-06, KA-GRAMMAR-C69-ASK-02, KA-SCRIPT-RECOG-153] -->
<!-- hl-writing-stage: timed-assessment-production -->

**One practical form — three minutes**

Complete **all six fields in Kannada script** for a neighbourhood language
exchange. Write one short answer in every field. Start the timer when you
begin the first field; leave any unfinished field as evidence when it rings.

1. Your name
2. A language you speak
3. One greeting you would use
4. One drink you would ask for
5. One short question asking where a new member lives
6. One polite closing you would use

When the three-minute timer rings, **stop**. Record the number of completed
fields. An honest short attempt is more useful than a perfect untimed one.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C01-NAMASKARA-01, KA-LEX-C02-NANNA-HESARU-01, KA-GRAMMAR-C02-NANNA-HESARU-02, KA-LEX-C04-MATTE-SIGONA-01, KA-LEX-C05-MATANADU-01, KA-LEX-C05-KANNADA-01, KA-GRAMMAR-C05-KANNADA-02, KA-LEX-C39-CHAHA-01, KA-LEX-C41-DEIXIS-06, KA-GRAMMAR-C69-ASK-02, KA-SCRIPT-RECOG-153] -->

Spend at most one minute looking at this first attempt. Note one field you
completed clearly and one field to practise next; do not rewrite the timed
answer. Keep the page as evidence.

This checkpoint is **not** the complete A1 writing paper. On another day,
close this lesson and open the separate
[A1 writing-only learner paper](../mocks/a1/writing-paper-1.md) for the
authentic form and named-reader message under one 20-minute assessment clock.
That paper and its later rubric review are a separate assessment session, not
work inside this under-five-minute lesson. It is writing practice only; it does
not establish full A1 exam readiness.
