## You'll want to know: encenar
<!-- hl-knowledge: introduces=[PT-LEX-C520-TEATRO-02]; assesses=[] -->

**encenar** — "to stage (a play)".

> O professor encenou a peça com os alunos.
>
> *The teacher staged the play with the pupils.*

Built on *a cena* "a scene".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*encenar* is built on *cena* "a scene", from Latin *scaena* (EtymDB), which goes back to Greek *skēnḗ* "a stage building".
