# సహకరించు (sahakariñcu) — to cooperate; to help

## You'll want to know: సహకరించు
<!-- hl-knowledge: introduces=[TE-LEX-C526-NIRVAHANA526-04]; assesses=[] -->

**సహకరించు** — *sahakariñcu* — "to cooperate; to help".

> అందరూ సహకరిస్తే పని త్వరగా అవుతుంది.
>
> *andarū sahakaristē pani tvaragā avutundi.*
>
> If everyone cooperates, the work gets done quickly.

Past (I …): సహకరించాను, *sahakariñcānu*.

-కి సహకరించు, to cooperate with someone.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**సహకరించు** (*sahakariñcu*) is built on Sanskrit *sahakāra*, "assistance" (CDIAL 13299), from *saha*, "with", and *kāra*, "doing".
