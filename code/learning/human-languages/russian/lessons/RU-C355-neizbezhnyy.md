## You'll want to know: неизбежный
<!-- hl-knowledge: introduces=[RU-LEX-C355-SLUCHAYNO-04]; assesses=[] -->

**неизбежный** (*neizbézhnyy*) — "inevitable".

> Изменения неизбежны.
>
> *Izmenéniya neizbézhny.*
>
> Changes are inevitable.

Short forms *неизбежен, неизбежна*. Built on *избежать*, to avoid: what cannot be avoided.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**неизбежный** is built from *не-* "not", *из-* "out of" and *бежать* "to run", inherited from Proto-Slavic *\*běžati*: what you cannot run away from.
