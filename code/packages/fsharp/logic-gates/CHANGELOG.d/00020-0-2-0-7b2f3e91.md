## 0.2.0

### Changed

- Bit rejection now raises `InvalidBitException`, a subclass of `ArgumentOutOfRangeException` exposing `Parameter` and `Value`. Existing `catch ArgumentOutOfRangeException` callers keep working; exact-type `Assert.Throws<ArgumentOutOfRangeException>` assertions must become `ThrowsAny`.
- All eleven gates (`notGate`, `andGate`, `orGate`, `xorGate`, `nand`, `nor`, `xnor`, `nandNot`, `nandAnd`, `nandOr`, `nandXor`) validate every argument up front and report the first invalid parameter under its public name (`a`/`b`), never an inner gate's.

### Added

- `LogicGatesExhaustiveTests`: literal truth tables for all 11 gates, NAND-built equals direct, every int in [-1024, 1024] other than 0/1 plus Int32 extremes rejected in every argument position, null-list guards. Line and branch coverage 100%; BUILD threshold raised from 80 to 95.
