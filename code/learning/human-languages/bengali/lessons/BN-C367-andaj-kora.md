# আন্দাজ করা (āndāj kôrā) — to estimate; to make a rough guess

## You'll want to know: আন্দাজ করা
<!-- hl-knowledge: introduces=[BN-LEX-C367-ANUMAN367-02]; assesses=[] -->

**আন্দাজ করা** — *āndāj kôrā* — "to estimate; to make a rough guess".

> আন্দাজ করো, ট্যাক্সিতে গেলে কত খরচ হবে?
>
> *āndāj kôro, ṭæksite gele kôtô khôrôch hôbe?*
>
> Have a guess: how much will it cost if we go by taxi?

Past (he/she …): তিনি দামটা আন্দাজ করলেন, *tini dāmṭā āndāj kôrlen*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**আন্দাজ করা** (*āndāj kôrā*) is usually traced to Persian *andāz*, a measure or estimate, with করা: to judge an amount by eye.
