# ં — the nasal mark anusvara

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[GU-SCRIPT-O-MATRA-01] -->

Write the attached o sign once from memory. Check the right bar, then the mark above.

## Script — meet one form
<!-- hl-knowledge: introduces=[GU-SCRIPT-ANUSVARA-01]; assesses=[] -->

Keep **ં** visible. It is the nasal mark anusvara, pronounced *ṃ*. This is anusvāra, a single dot above the syllable. It marks nasal sound; it is small, but its position above the writing line is part of the spelling.

## Writing — notice and trace
<!-- hl-knowledge: introduces=[]; assesses=[GU-SCRIPT-ANUSVARA-01] -->
<!-- hl-writing-stage: observe-trace -->

Finger-trace **ં** once, then air-trace it once. Notice a single high dot; one dot placed above.

## Writing — copy with the model
<!-- hl-knowledge: introduces=[]; assesses=[GU-SCRIPT-ANUSVARA-01] -->
<!-- hl-writing-stage: guided-copy -->

Copy visible **ં** once. Compare only the landmark named above and repair it once if needed.

## Writing — recall after hiding
<!-- hl-knowledge: introduces=[]; assesses=[GU-SCRIPT-ANUSVARA-01] -->
<!-- hl-writing-stage: delayed-copy -->
<!-- hl-activity: {"id":"GU-W03-anusvara-recall","kind":"text","assesses":["GU-SCRIPT-ANUSVARA-01"],"prompt":"Hide the model and write the nasal mark anusvara from memory.","answer":"ં","accepted":[],"feedback":{"correct":"ં — the taught form is intact.","incorrect":"Look once at ં, hide it, and repair only the differing landmark."},"response_seconds":20} -->

Hide the model and write *ṃ* once. Uncover **ં**, compare, and stop after one repair.
