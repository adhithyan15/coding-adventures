## You'll want to know: convocar
<!-- hl-knowledge: introduces=[ES-LEX-C560-ENCUENTRO-03]; assesses=[] -->

**convocar** — "to call (a meeting, a strike)".

> Los trabajadores convocaron una huelga.
>
> *The workers called a strike.*

It takes *qu* before *e*: *convoqué*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*convocar* is a learned borrowing from Latin *convocāre* 'to call together' (Lewis & Short), built on *con-* and *vocāre* 'to call'.
