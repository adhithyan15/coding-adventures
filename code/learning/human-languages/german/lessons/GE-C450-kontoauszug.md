## You'll want to know: der Kontoauszug
<!-- hl-knowledge: introduces=[GE-LEX-C450-GELDAUTOMAT-03]; assesses=[] -->

**der Kontoauszug** — "the bank statement".

> Auf dem Kontoauszug sieht sie alle Zahlungen.
>
> *She can see all the payments on her bank statement.*

Plural: *die Kontoauszüge*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*Kontoauszug* is built from *Konto* 'account', borrowed from Italian *conto* 'calculation' (EtymDB), which goes back to Latin *computāre* 'to reckon', and *Auszug* 'extract', from *ausziehen* 'to pull out'.
