## You'll want to know: carimbar
<!-- hl-knowledge: introduces=[PT-LEX-C423-CONTROLO-05]; assesses=[] -->

**carimbar** — "to stamp (a document)".

> O polícia carimbou o meu passaporte.
>
> *The officer stamped my passport.*

*O carimbo* — the rubber stamp.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*carimbar* is built on *carimbo* 'stamp', which EtymDB traces to Kimbundu, a language of Angola (*ka'rima*).
