# ممنوع (mamnū) — forbidden; not allowed

## You'll want to know: ممنوع
<!-- hl-knowledge: introduces=[UR-LEX-C399-HIFAZAT399-04]; assesses=[] -->

**ممنوع** — *mamnū* — "forbidden; not allowed".

> سرحد پر یہ چیز ممنوع ہے۔
>
> *sarhad par yih chīz mamnū hai.*
>
> This item is not allowed across the border.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ممنوع** (*mamnū*) is usually traced, through Persian, to Arabic *mamnūʿ*, "forbidden"; signs at airports and borders use it.
