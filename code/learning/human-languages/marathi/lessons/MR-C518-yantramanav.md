## You'll want to know: यंत्रमानव
<!-- hl-knowledge: introduces=[MR-LEX-C518-YANTRA518-03]; assesses=[] -->

**यंत्रमानव** — *yantramānav* — "a robot".

> हा यंत्रमानव घर झाडतो.
>
> *hā yantramānav ghar jhāḍto.*
>
> This robot sweeps the house.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**यंत्रमानव** (*yantramānav*) is a modern tatsama coinage from Sanskrit *yantra*, "machine", and *mānava*, "human" (Monier-Williams).
