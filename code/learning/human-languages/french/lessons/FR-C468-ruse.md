## You'll want to know: rusé
<!-- hl-knowledge: introduces=[FR-LEX-C468-FRANCHISE-04]; assesses=[] -->

**rusé** — "cunning, crafty".

> Le renard est rusé : il trouve toujours une sortie.
>
> *The fox is cunning: it always finds a way out.*

The noun *une ruse* is a trick.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*rusé* comes from *ruser*, first said of a hunted animal that doubles back. *Ruser* is inherited from Latin *recūsāre* "to refuse, to draw back" (Lewis & Short), itself built on *causa*.
