# இறுதிமரியாதை (iṟutimariyātai) — last respects

## You'll want to know: இறுதிமரியாதை
<!-- hl-knowledge: introduces=[TA-LEX-C324-ANJALI324-02]; assesses=[] -->

**இறுதிமரியாதை** — *iṟutimariyātai* — "last respects".

> ஊர் மக்கள் அவருக்கு இறுதிமரியாதை செலுத்தினார்கள்.
>
> *ūr makkaḷ avarukku iṟutimariyātai celuttiṉārkaḷ.*
>
> The villagers paid him their last respects.

இறுதி, last + மரியாதை, respect.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**இறுதிமரியாதை** (*iṟutimariyātai*) joins native இறுதி, "end" (DEDR 514), with மரியாதை, "respect", borrowed from Sanskrit *maryādā*, "boundary, propriety" (CDIAL 9895).

## What you've built
