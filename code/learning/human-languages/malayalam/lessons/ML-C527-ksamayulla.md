# ക്ഷമയുള്ള (kṣamayuḷḷa) — patient by nature

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C526-RASAM526-05, ML-LEX-C527-SVABHAVAM527-01] -->

[PAUSE 2s] Before the new one: say the Malayalam for to grow weary, then the Malayalam for kind-hearted.

## You'll want to know: ക്ഷമയുള്ള
<!-- hl-knowledge: introduces=[ML-LEX-C527-SVABHAVAM527-02]; assesses=[] -->

**ക്ഷമയുള്ള** — *kṣamayuḷḷa* — "patient by nature".

> ക്ഷമയുള്ള അധ്യാപകൻ ചോദ്യം വീണ്ടും വിശദീകരിച്ചു.
>
> *kṣamayuḷḷa adhyāpakan cōdyaṁ vīṇṭuṁ viśadīkariccu.*
>
> The patient teacher explained the question again.

ക്ഷമ, patience, + ഉള്ള; ക്ഷമിക്കണം, sorry, comes from the same Sanskrit word.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ക്ഷമയുള്ള** (*kṣamayuḷḷa*) is built from ക്ഷമ, from Sanskrit *kṣamā*, "patience, forbearance" (CDIAL 3659), and the native ending -ഉള്ള, "having" (DEDR 697).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
