# फिर से (phir se) — once more, over again

## You'll want to know: फिर से
<!-- hl-knowledge: introduces=[HI-LEX-C126-WHAT-01]; assesses=[] -->

**फिर से** (*phir se*) — "once more", "from the start again".

**फिर से बोलिए** — "please say it again", a softer cousin of **दोबारा**.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

A second way to ask again.
