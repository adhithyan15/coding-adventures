## You'll want to know: нападение
<!-- hl-knowledge: introduces=[RU-LEX-C289-OGRABLENIYE-04]; assesses=[] -->

**нападение** (*napadéniye*) — "an attack".

> Нападение было неожиданным.
>
> *Napadéniye býlo neozhídannym.*
>
> The attack was unexpected.

*Нападение на* + accusative — an attack on.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*нападение* is built on *нападать* "to attack", from *на-* "on" and *падать* "to fall", inherited from Proto-Slavic *padati* (EtymDB): a falling upon.
