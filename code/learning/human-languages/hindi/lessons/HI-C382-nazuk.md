## You'll want to know: नाज़ुक
<!-- hl-knowledge: introduces=[HI-LEX-C382-JALDBAZI382-05]; assesses=[] -->

**नाज़ुक** — *nāzuk* — "delicate, fragile".

> यह शीशा नाज़ुक है, अगर गिरेगा तो टूट जाएगा।
>
> *yah śīśā nāzuk hai, agar giregā to ṭūṭ jāegā.*
>
> This glass is fragile; if it falls, it will break.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**नाज़ुक** (*nāzuk*) is usually traced to Persian *nāzuk*, "delicate, slender".
