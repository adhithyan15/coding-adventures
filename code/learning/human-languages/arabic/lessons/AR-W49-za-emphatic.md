# ظ (ẓāʾ) — the letter inside الظهر

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[AR-SCRIPT-C48-GHAYN-01, AR-SCRIPT-C49-TA-EMPHATIC-01] -->

[PAUSE 2s] Before the new one: write غ and ط once each, and name them.

[PAUSE 2s] Now say **الظهر** (*aẓ-ẓuhr*), "noon".
You have read it for a long time. This lesson takes one letter out of it and puts
it in your hand.

## Script you'll notice: ظ
<!-- hl-knowledge: introduces=[AR-SCRIPT-C49-ZA-EMPHATIC-01]; assesses=[] -->

**ظ** — *ẓāʾ*, a heavy *dh*.

It is inside **الظهر** (*aẓ-ẓuhr*), "noon". It is **ط**, from the last lesson, with
**one dot above**.

## Writing: ظ
<!-- hl-knowledge: introduces=[]; assesses=[AR-SCRIPT-C49-ZA-EMPHATIC-01] -->

- **1.** start here: loop counterclockwise around the closed oval
- **2.** finish left along the baseline without lifting
- **3.** lift once, then place the upper dot
- **4.** lift again, then draw the tall upright top-to-bottom — and only now lift

**Pen lifts: 2.**

> Stroke order is one attested teaching order; hands and teachers vary.
> Source: Introduction to Arabic: Egyptian Arabic for first-year students, Alphabet ط ظ, independent emphatic DHaa at 00:01.3–00:02.8 (University of Oregon Libraries Open Textbook, 2023; accessed 2026-08-23).
