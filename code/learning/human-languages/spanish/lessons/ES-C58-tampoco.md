# tampoco — the same frame, the other half

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ES-LEX-TAMBIEN, ES-LEX-TAN] -->

[PAUSE 2s] *Yo también* agrees with somebody who said a **yes**.

[PAUSE 1s] But what do you say to somebody who said a **no**? English changes
word there too — *me too* becomes *me neither*.

## Sounds you'll need
<!-- hl-knowledge: introduces=[]; assesses=[] -->

- `k-hard` — the *c* before *o* is a plain *k*. **tampoco** = *tam-PO-ko*, with
  no accent to write, because the stress already falls where Spanish expects it.

## The word, taken apart: tampoco
<!-- hl-knowledge: introduces=[ES-LEX-TAMPOCO, ES-LEX-POCO, ES-ETYMON-TAMPOCO-TAN-POCO]; assesses=[ES-ETYMON-TAMBIEN-TAN-BIEN] -->

**tampoco** = **tan** + **poco**.

[PAUSE 2s] The same *tan* you met yesterday. The new half is ***poco***, which
means *little* — a small amount of something.

| | | |
|---|---|---|
| *también* | tan + **bien** | so **well** |
| *tampoco* | tan + **poco** | so **little** |

[PAUSE 2s] One frame, two fillings. You are not learning a second word here so
much as turning the first one over.

## Why it's said this way
<!-- hl-knowledge: introduces=[]; assesses=[ES-LEX-TAMPOCO] -->

> — *No estoy cansado.*
> — ***Yo tampoco.***

[PAUSE 2s] The rule is simple and it is about the **other** person's sentence,
not yours. If what they said was positive, you answer *yo también*. If it had a
*no* in it, you answer *yo tampoco*.

[PAUSE 2s] Getting this wrong is one of the most audible mistakes a learner can
make, and it is entirely avoidable: listen for the *no*. If you heard one, use
the *poco* word.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[ES-LEX-TAMPOCO, ES-LEX-POCO] -->

[PAUSE 2s] *Tan* + *bien* is *so well*. What is *tan* + *poco*? (**So little** —
***tampoco***.)

[PAUSE 2s] And what in the other person's sentence decides between the two?
(A ***no***.)
