## You'll want to know: மருத்துவர்
<!-- hl-knowledge: introduces=[TA-LEX-C46-ROLE-03]; assesses=[] -->

**மருத்துவர்** (*maruttuvar*) — "a doctor".

This one is Tamil's own. It stands on மருந்து (*marundu*), 'medicine', and takes the same respectful *-ar*: the person who deals in medicine.

Beside it sits *vaittiyar*, from Sanskrit *vaidya*, doing the same work with borrowed material. Where a language has both, it usually has a preference, and modern Tamil leans on *maruttuvar* — the signboard on the hospital says so.
