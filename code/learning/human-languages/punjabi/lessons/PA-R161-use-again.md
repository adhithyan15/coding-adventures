# An old word for using

First retrieve **to use** on its own. Then hear four already-taught
action meanings in a small shuffled mix. Pause before each model.
There is no new Punjabi and no scored mock here.

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-C149-ACT149-04] -->

Hear **to use**. [PAUSE 4s] Say the old word before the model:
**ਵਰਤਣਾ** (*vartṇā*).

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-C149-ACT149-01, PA-LEX-C149-ACT149-02, PA-LEX-C149-ACT149-03, PA-LEX-C149-ACT149-04] -->

Pause after each familiar meaning, then hear its model:

- **to call** — [PAUSE 4s] **ਬੁਲਾਉਣਾ** (*bulāuṇā*).
- **to swim** — [PAUSE 4s] **ਤਰਨਾ** (*tarnā*).
- **to use** — [PAUSE 4s] **ਵਰਤਣਾ** (*vartṇā*).
- **to climb** — [PAUSE 4s] **ਚੜ੍ਹਨਾ** (*caṛhnā*).

Only the order of these four old words has changed.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-C149-ACT149-01, PA-LEX-C149-ACT149-02, PA-LEX-C149-ACT149-03, PA-LEX-C149-ACT149-04] -->

Hear **to climb**, **to use**, **to call**, then **to swim**.
Pause after each cue and recall its Punjabi word before the model:
**ਚੜ੍ਹਨਾ**, **ਵਰਤਣਾ**, **ਬੁਲਾਉਣਾ**, **ਤਰਨਾ**.
Revisit only the old word you missed.
