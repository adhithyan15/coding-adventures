# സഹകരണം (sahakaraṇaṁ) — cooperation

## You'll want to know: സഹകരണം
<!-- hl-knowledge: introduces=[ML-LEX-C452-SAMADHANAM452-05]; assesses=[] -->

**സഹകരണം** — *sahakaraṇaṁ* — "cooperation".

> നാട്ടുകാരുടെ സഹകരണം കൊണ്ട് പണി വേഗം തീർന്നു.
>
> *nāṭṭukāruṭe sahakaraṇaṁ koṇṭŭ paṇi vēgaṁ tīrnnu.*
>
> With the local people's cooperation, the work finished quickly.

As an adjective it comes first: സഹകരണ ബാങ്ക്, a cooperative bank.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**സഹകരണം** (*sahakaraṇaṁ*) is borrowed from Sanskrit *sahakaraṇa*, "acting together" (Monier-Williams): *saha*, "together", and *karaṇa*, "doing".
