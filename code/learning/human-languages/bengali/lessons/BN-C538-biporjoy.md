# বিপর্যয় (bipôrjôy) — a disaster; a calamity

## You'll want to know: বিপর্যয়
<!-- hl-knowledge: introduces=[BN-LEX-C538-DURJOG538-02]; assesses=[] -->

**বিপর্যয়** — *bipôrjôy* — "a disaster; a calamity".

> বন্যা হলে গ্রামে বড় বিপর্যয় হবে।
>
> *Bônyā hôle grāme bôṛo bipôrjôy hôbe.*
>
> If there is a flood, it will be a great calamity for the village.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**বিপর্যয়** (*bipôrjôy*) is Sanskrit *viparyaya*, "reversed, turned the wrong way" (Monier-Williams): everything turned upside down.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
