# ಪುರಾವೆ (purāve) — proof; evidence

## You'll want to know: ಪುರಾವೆ
<!-- hl-knowledge: introduces=[KA-LEX-C376-PURAVE376-01]; assesses=[] -->

**ಪುರಾವೆ** — *purāve* — "proof; evidence".

> ಅವನ ಮಾತಿಗೆ ಯಾವುದೇ ಪುರಾವೆ ಇರಲಿಲ್ಲ.
>
> *avana mātige yāvudē purāve iralilla.*
>
> There was no proof for what he said.

With ಇದೆ and ಇಲ್ಲ: ಪುರಾವೆ ಇದೆ, there is proof.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಪುರಾವೆ** (*purāve*) has no entry in DEDR or CDIAL, so its origin is not settled. Marathi uses a close form, *purāvā*, for evidence.
