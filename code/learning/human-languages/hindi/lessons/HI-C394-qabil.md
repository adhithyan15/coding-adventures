# क़ाबिल (qābil) — capable, able

## You'll want to know: क़ाबिल
<!-- hl-knowledge: introduces=[HI-LEX-C394-INAAM394-04]; assesses=[] -->

**क़ाबिल** — *qābil* — "capable, able".

> अगर वह क़ाबिल होता तो उसे यह पद मिलता।
>
> *agar vah qābil hotā to use yah pad miltā.*
>
> If he were capable, he would get this post.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**क़ाबिल** (*qābil*) is usually traced to Arabic *qābil*, "receiving, capable", which reached Hindi through Persian.

<!-- hl-knowledge: introduces=[]; assesses=[] -->
