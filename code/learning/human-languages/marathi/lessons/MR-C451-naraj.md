## You'll want to know: नाराज
<!-- hl-knowledge: introduces=[MR-LEX-C451-MOOD451-04]; assesses=[] -->

**नाराज** — *nārāj* — "displeased; upset".

> मी उशिरा आलो म्हणून वडील नाराज झाले.
>
> *mī uśirā ālo mhaṇūn vaḍīl nārāj jhāle.*
>
> Father was displeased because I came late.

Unchanging. The person one is upset with takes -वर: ती माझ्यावर नाराज आहे.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**नाराज** (*nārāj*) is a loan from Persian *nārāz*, "displeased", built with the Persian negative *nā-*.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
