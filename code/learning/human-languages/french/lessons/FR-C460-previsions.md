## You'll want to know: les prévisions
<!-- hl-knowledge: introduces=[FR-LEX-C460-METEO-02]; assesses=[] -->

**les prévisions** — "the forecast, the outlook".

> Les prévisions pour le week-end ne sont pas bonnes.
>
> *The forecast for the weekend is not good.*

Mostly plural: *les prévisions météo*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*prévision* is built on *prévoir* 'to foresee', from Latin *praevidēre*, built on *vidēre* 'to see' (Lewis & Short). EtymDB does not list the noun.
