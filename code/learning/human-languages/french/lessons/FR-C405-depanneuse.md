## You'll want to know: la dépanneuse
<!-- hl-knowledge: introduces=[FR-LEX-C405-DEPANNEUSE-02]; assesses=[] -->

**la dépanneuse** — "the tow truck, the breakdown lorry".

> La dépanneuse est arrivée après une heure.
>
> *The tow truck arrived after an hour.*

Built on *dépanner* with the ending *-euse*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*dépanneuse* is built on *dépanner* 'to get going again' with the ending *-euse*. *Dépanner* is built from *dé-* and *panne* 'breakdown' (EtymDB).
