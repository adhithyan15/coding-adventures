## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ابتلع** (*ibtalaʿa*) is built on the native Arabic root *b-l-ʿ*, "to swallow" (Lane). *Ibtalaʿa* is Form VIII, "to swallow".
