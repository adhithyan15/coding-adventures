# ಪರಿಚಯ (paricaya) — an introduction, acquaintance

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C96-HELLO-05, KA-LEX-C97-GRATEFUL-01] -->

[PAUSE 2s] Before the new one: say the Kannada for are you well, then the Kannada for pardon.

## You'll want to know: ಪರಿಚಯ
<!-- hl-knowledge: introduces=[KA-LEX-C97-GRATEFUL-02]; assesses=[] -->

**ಪರಿಚಯ** (*paricaya*) — "an introduction, acquaintance".

**ನಿಮ್ಮ ಪರಿಚಯ ಸಂತೋಷ** (*nimma paricaya santōṣa*) — "pleased to meet you",
literally "your acquaintance is a joy".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

A formal pleased to meet you.
