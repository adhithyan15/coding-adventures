# Changelog

## 0.1.0

- Initial release of `coding_adventures_starlark_compiler`.
- Pure in-memory Dart implementation of the Starlark opcode provider and operator mappings.
- Complete support for 61 canonical opcodes, 12 categories, 34 operator mappings, and 195 byte holes.
- 100% compliance with Standing Rule #20 (centralized diagnostics, sealed exception hierarchy, payload blindness).
- STP01 conformance validation with 5-class security showcase, PRNG property tests, and mutation fuzzing.
