## You'll want to know: evacuar
<!-- hl-knowledge: introduces=[ES-LEX-C524-FUEGO-05]; assesses=[] -->

**evacuar** — "to evacuate".

> Evacuaron el edificio en diez minutos.
>
> *They evacuated the building in ten minutes.*

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*evacuar* is a learned borrowing from Latin *ēvacuāre* 'to empty out' (EtymDB), built on *vacuus* 'empty'. To evacuate a building is to empty it.
