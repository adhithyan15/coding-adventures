# आओगे — the तुम row, and a vowel that has shown up before

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[HI-LEX-C85-IMP-01, HI-LEX-C88-FUT-04] -->

[PAUSE 2s] Say the command you would give a friend using **तुम**. Hold on to
the vowel at its end — the future is about to reuse it.

## You'll want to know: आओगे
<!-- hl-knowledge: introduces=[HI-LEX-C88-FUT-05]; assesses=[] -->

**आओगे** (*āoge*) — "you will come," to somebody you address as **तुम**.
**करोगे** (*karoge*) — "you will do," at the same level.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[HI-LEX-C88-FUT-05, HI-LEX-C85-IMP-01] -->

The **तुम** level has a vowel of its own, and you have already used it:

| where | form |
|---|---|
| the command | बोल**ो** |
| the future | आ**ओ**गे |

Both are **-ओ**. That is not two facts to learn — it is one vowel that belongs
to **तुम** wherever it appears, and you have had it since the commands chapter.

## Grammar Lens: where the full letter shows up again
<!-- hl-knowledge: introduces=[]; assesses=[HI-LEX-C88-FUT-05, HI-SCRIPT-RECOG-129] -->

The same writing question as the first person, and the same answer:

| stem | you will |
|---|---|
| कर- | करोगे |
| आ- | आओगे |

**करोगे** carries the *o* as a mark on the consonant. **आओगे** cannot, because
**आ-** is a vowel, so the *o* is written as the full letter **ओ** — the one built
on **आ** with an arc above it.

Two vowel-stem words in one chapter, two full letters, and the same rule
producing both.

<!-- hl-knowledge: introduces=[]; assesses=[HI-LEX-C88-FUT-05, HI-SCRIPT-RECOG-129] -->
