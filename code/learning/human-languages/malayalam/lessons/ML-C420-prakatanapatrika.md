# പ്രകടനപത്രിക (prakaṭanapatrika) — a manifesto

## You'll want to know: പ്രകടനപത്രിക
<!-- hl-knowledge: introduces=[ML-LEX-C420-VIJAYAM420-02]; assesses=[] -->

**പ്രകടനപത്രിക** — *prakaṭanapatrika* — "a manifesto".

> ഓരോ പാർട്ടിയും പ്രകടനപത്രിക പുറത്തിറക്കി.
>
> *ōrō pārṭṭiyuṁ prakaṭanapatrika puṟattiṟakki.*
>
> Each party released a manifesto.

പ്രകടനം alone is a show, a demonstration.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**പ്രകടനപത്രിക** (*prakaṭanapatrika*) is a Malayalam compound built from Sanskrit *prakaṭana*, "bringing to light" (CDIAL 8429), and *pattrikā*, "a leaf; a letter, a document" (Monier-Williams): a paper that brings plans to light.
