## You'll want to know: têtu
<!-- hl-knowledge: introduces=[FR-LEX-C467-DEFAUTS-01]; assesses=[] -->

**têtu** — "stubborn".

> Mon grand-père est têtu : il ne change jamais d'avis.
>
> *My grandfather is stubborn: he never changes his mind.*

Built on *la tête*: someone with a hard head. Feminine *têtue*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*têtu* is built on Old French *teste* "head" (EtymDB), now *tête*, which is inherited from Latin *testa* "an earthen pot, a shell" (Lewis & Short).
