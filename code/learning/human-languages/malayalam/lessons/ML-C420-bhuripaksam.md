# ഭൂരിപക്ഷം (bhūripakṣaṁ) — a majority

## You'll want to know: ഭൂരിപക്ഷം
<!-- hl-knowledge: introduces=[ML-LEX-C420-VIJAYAM420-03]; assesses=[] -->

**ഭൂരിപക്ഷം** — *bhūripakṣaṁ* — "a majority".

> അവർക്ക് വലിയ ഭൂരിപക്ഷം കിട്ടി.
>
> *avarkkŭ valiya bhūripakṣaṁ kiṭṭi.*
>
> They got a big majority.

An absolute majority is കേവല ഭൂരിപക്ഷം.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ഭൂരിപക്ഷം** (*bhūripakṣaṁ*) is built from Sanskrit *bhūri*, "much, many" (Monier-Williams), and *pakṣa*, "a wing, a side" (CDIAL 7627): the side with many.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
