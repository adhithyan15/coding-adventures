# دلیر (diler) — bold

## You'll want to know: دلیر
<!-- hl-knowledge: introduces=[UR-LEX-C460-BRAVE460-01]; assesses=[] -->

**دلیر** — *diler* — "bold".

> وہ دلیر لڑکی اکیلی پہاڑ پر چڑھی۔
>
> *voh diler laṛkī akelī pahāṛ par chaṛhī.*
>
> That bold girl climbed the mountain alone.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**دلیر** (*diler*) is usually traced to Persian *dilēr*, "bold", a word built on *dil*, "heart" (**دل**).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
