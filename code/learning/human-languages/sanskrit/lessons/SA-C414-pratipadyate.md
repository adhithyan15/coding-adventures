## You'll want to know: प्रतिपद्यते
<!-- hl-knowledge: introduces=[SA-LEX-C414-DIGBHRAMA414-03]; assesses=[] -->

**प्रतिपद्यते** — *pratipadyate* — "finds the way; reaches".

> पथिकः शनैः मार्गं प्रतिपद्यते।
>
> *pathikaḥ śanaiḥ mārgaṃ pratipadyate.*
>
> Slowly the wayfarer finds the road.

Past (he …): सः मार्गं प्रतिपन्नवान्, *saḥ mārgaṃ pratipannavān*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**प्रतिपद्यते** (*pratipadyate*) is built from *prati*, "towards", and the root √pad, "to go, to step"; MW gives *prati-pad* as to set foot upon, arrive at, reach, with the participle *pratipanna*, "arrived, found" (MW).
