## Grammar Lens
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-SUCHNA-199, PA-DEM-EH-01, PA-LEX-HAI-02, PA-GRAMMAR-VERB-LAST-02] -->

> **ਇਹ ਸੂਚਨਾ ਹੈ** — *eh sūchnā hai* — this is information / a notice

Keep the new whole noun between familiar **ਇਹ** and **ਹੈ**. Familiar **ਹੈ**
stays last in the already-owned identity frame. This chapter teaches only this
one label; it does not add an inflection rule or a wider construction.
