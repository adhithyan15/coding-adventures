## You'll want to know: intervistare
<!-- hl-knowledge: introduces=[IT-LEX-C283-REDAZIONE-05]; assesses=[] -->

**intervistare** — "to interview".

> Ci hanno intervistato per strada.
>
> *They interviewed us in the street.*

Built on *intervista*, the same way as in English.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*intervistare* is built on *intervista*, which is usually traced to English *interview*; the root is Latin *vidēre* "to see" (Lewis & Short).
