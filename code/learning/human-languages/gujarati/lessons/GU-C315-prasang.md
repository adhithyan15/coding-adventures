# પ્રસંગ (prasang) — an occasion

## You'll want to know: પ્રસંગ
<!-- hl-knowledge: introduces=[GU-LEX-C315-UDGHATAN315-02]; assesses=[] -->

**પ્રસંગ** — *prasang* — "an occasion".

> આ પ્રસંગે ગામના બધા લોકો ભેગા થયા.
>
> *ā prasange gāmnā badhā loko bhegā thayā.*
>
> Everyone in the village gathered for the occasion.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**પ્રસંગ** (*prasang*) is a tatsama, Sanskrit *prasaṅga*, "connection", and also "an event, a case" (Monier-Williams). In Gujarati it is a special occasion: **આ પ્રસંગે**, on this occasion.
