## You'll want to know: सरू

**सरू** — *sarū* — "begun; the start".

> पाठ सरू करो।
>
> *pāṭh sarū karo.*
>
> Start the lesson.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**सरू** (*sarū*) is usually traced, through Persian *shurūʿ*, to Arabic *shurūʿ*, "a beginning". With **करो** it asks someone to start.
