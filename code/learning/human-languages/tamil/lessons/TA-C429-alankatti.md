# ஆலங்கட்டி (ālaṅkaṭṭi) — hailstones; hail

## You'll want to know: ஆலங்கட்டி
<!-- hl-knowledge: introduces=[TA-LEX-C429-PUYAL429-03]; assesses=[] -->

**ஆலங்கட்டி** — *ālaṅkaṭṭi* — "hailstones; hail".

> நேற்று மாலை ஆலங்கட்டி மழை பெய்தது.
>
> *nēṟṟu mālai ālaṅkaṭṭi maḻai peytatu.*
>
> Yesterday evening there was a hailstorm.

ஆலங்கட்டி மழை is a hailstorm.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ஆலங்கட்டி** (*ālaṅkaṭṭi*) is native Dravidian: DEDR 384 lists it, "hail", with ஆலம், "water, rain", and கட்டி, "a lump".
