## You'll want to know: مول
<!-- hl-knowledge: introduces=[AR-LEX-C384-TANMIYA384-01]; assesses=[] -->

**مول** — *mawwala* — "to fund".

> مولت الدولة المشروع.
>
> *mawwalat ad-dawla al-mashrūʿ.*
>
> The state funded the project.

Present: يمول, *yumawwil*.

The noun تمويل, *tamwīl*, funding.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**مول** (*mawwala*) is built on the native Arabic root *m-w-l*, "wealth, property" (Lane). It is Form II of the root of *māl*, money: to provide with money, to fund.
