# выгодный (výgodnyy) — profitable, a good deal

## You'll want to know: выгодный
<!-- hl-knowledge: introduces=[RU-LEX-C397-OPLATA-05]; assesses=[] -->

**выгодный** (*výgodnyy*) — "profitable, a good deal".

> Это очень выгодное предложение.
>
> *Éto óchen výgodnoye predlozhéniye.*
>
> This is a very good deal.

*Выгодно* — it pays, it is worth it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**выгодный** is built on *выгода* "benefit, gain", from *вы-* and the root of *годиться* "to be fit" and *год*, Proto-Slavic *\*godŭ* "a fitting time": what suits you well.
