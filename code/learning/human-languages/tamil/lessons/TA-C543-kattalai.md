# கட்டளை (kaṭṭaḷai) — an official order; a command

## You'll want to know: கட்டளை
<!-- hl-knowledge: introduces=[TA-LEX-C543-KATTALAI543-01]; assesses=[] -->

**கட்டளை** — *kaṭṭaḷai* — "an official order; a command".

> அதிகாரியின் கட்டளையை எல்லோரும் பின்பற்றினார்கள்.
>
> *atikāriyiṉ kaṭṭaḷaiyai ellōrum piṉpaṟṟiṉārkaḷ.*
>
> Everyone followed the officer's order.

In computing it also means a command. To give an order is கட்டளை இடு.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**கட்டளை** (*kaṭṭaḷai*) is native Dravidian: DEDR 1147, under கட்டு (*kaṭṭu*), "to tie, to bind", gives கட்டளை (*kaṭṭaḷai*), "a code, a rule, regulations".
