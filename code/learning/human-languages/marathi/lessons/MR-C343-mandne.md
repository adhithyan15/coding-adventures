# मांडणे (māṇḍṇe) — to put forward; to set out

## You'll want to know: मांडणे
<!-- hl-knowledge: introduces=[MR-LEX-C343-MUDDA343-04]; assesses=[] -->

**मांडणे** — *māṇḍṇe* — "to put forward; to set out".

> मीराने बैठकीत आपलं मत मांडलं.
>
> *mīrāne baiṭhkīt āplaṁ mat māṇḍlaṁ.*
>
> Meera put forward her view at the meeting.

Past, with -ने (he …): त्याने मुद्दा मांडला, *tyāne muddā māṇḍlā*.

मत मांडणे, to state one's view; also to set things out in order, as on a table.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**मांडणे** (*māṇḍṇe*) is a Marathi verb whose origin is not settled; its first sense is to set things out in order, and from there to set out a view.
