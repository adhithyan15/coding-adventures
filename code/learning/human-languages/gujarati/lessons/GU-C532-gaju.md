# ગજું (gajũ) — one's capacity

## You'll want to know: ગજું
<!-- hl-knowledge: introduces=[GU-LEX-C532-POSAVU532-02]; assesses=[] -->

**ગજું** — *gajũ* — "one's capacity".

> જો મારું ગજું હોત તો હું મોટું ઘર ખરીદત.
>
> *jo mārũ gajũ hot to hũ moṭũ ghar kharīdat.*
>
> If I had the means, I would buy a big house.

A neuter noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ગજું** (*gajũ*) is what a person can manage or afford: **મારું ગજું નથી**, it is beyond me. No dictionary we use records an older form, so its history is not settled.
