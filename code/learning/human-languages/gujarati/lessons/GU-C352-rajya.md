## You'll want to know: રાજ્ય
<!-- hl-knowledge: introduces=[GU-LEX-C352-SARKAR352-02]; assesses=[] -->

**રાજ્ય** — *rājya* — "a state (of a country)".

> ગુજરાત એક મોટું રાજ્ય છે.
>
> *gujrāt ek moṭũ rājya che.*
>
> Gujarat is a big state.

A neuter noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**રાજ્ય** (*rājya*) is a tatsama, borrowed from Sanskrit *rājya*, "kingship, a kingdom" (Monier-Williams).
