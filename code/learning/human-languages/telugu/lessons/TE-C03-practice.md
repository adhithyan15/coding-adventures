# Chapter 3 — The how-are-you exchange

## Warm-up

## The exchange
<!-- hl-knowledge: introduces=[]; assesses=[TE-LEX-C03-BAAGAA-01, TE-LEX-C03-ELAA-01, TE-LEX-C03-MIIRU-ELAA-UNNAARU-01, TE-LEX-C03-NENU-01] -->

Read the whole cycle off the page first — Telugu, then the sound, then the sense:

| Telugu | | English |
|---|---|---|
| **మీరు ఎలా ఉన్నారు?** | *mīru elā unnāru* | How are you? |
| **నేను బాగున్నాను, ధన్యవాదములు.** | *nēnu bāgunnānu, dhanyavādamulu* | I'm well, thank you. |
| **పరవాలేదు.** | *paravālēdu* | No problem / you're welcome. |

A few of these characters have not had their own lesson yet. They are here to
be **recognised**, not decoded — the romanization beside each line is what
you read from. The letters catch up in the chapters ahead.

[PAUSE 1s each]
- [YOU SAY: "How are you?" (respectful) — *mīru elā unnāru?*]
- [YOU SAY: "I'm well, thank you." — *nēnu bāgunnānu, dhanyavādamulu.*]
- [YOU SAY: "No problem / you're welcome." — *paravālēdu.*]
- [YOU SAY: the familiar version of the question — *nuvvu elā unnāvu?*]

## The words, taken apart — roots you now carry
<!-- hl-knowledge: introduces=[]; assesses=[TE-ETYMON-C03-BAAGAA-02, TE-ETYMON-C03-ELAA-02, TE-ETYMON-C03-MIIRU-ELAA-UNNAARU-02, TE-ETYMON-C03-NENU-02] -->
[PAUSE 2s]

**Roots you now carry:**

- *elā* ← the interrogative *e-* (native Dravidian, like Tamil *eppaḍi*)
- *nēnu* ← Proto-Dravidian (unrelated to English *me*); possessive *nā*
- *bāgā* ← *bāgu* "goodness"; *nēnu bāgunnānu* "I'm well"
- *lēdu* — Telugu's "is-not," where its sisters use *illa(i)*
