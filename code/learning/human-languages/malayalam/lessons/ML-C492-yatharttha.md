## You'll want to know: യഥാർത്ഥ
<!-- hl-knowledge: introduces=[ML-LEX-C492-GUNAM492-04]; assesses=[] -->

**യഥാർത്ഥ** — *yathārttha* — "genuine; real".

> ഇത് യഥാർത്ഥ തുകൽ ആണോ?
>
> *itŭ yathārttha tukal āṇō?*
>
> Is this real leather?

An adjective before a noun. The adverb is യഥാർത്ഥത്തിൽ, in fact.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**യഥാർത്ഥ** (*yathārttha*) is borrowed from Sanskrit *yathārtha*, "as the thing is", true to reality (Monier-Williams).
