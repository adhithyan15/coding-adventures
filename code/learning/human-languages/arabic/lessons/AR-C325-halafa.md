# حلف (ḥalafa) — to take an oath

## You'll want to know: حلف
<!-- hl-knowledge: introduces=[AR-LEX-C325-SHAHID325-03]; assesses=[] -->

**حلف** — *ḥalafa* — "to take an oath".

> حلف الموظف أمام المحكمة.
>
> *ḥalafa al-muwaẓẓaf amāma al-maḥkama.*
>
> The employee took an oath before the court.

Present: يحلف, *yaḥlif*.

An ally, one bound by oath, is حليف.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**حلف** (*ḥalafa*) is built on the native Arabic root *ḥ-l-f* (Lane), "to swear"; *ḥilf* is a pact sworn between tribes, and *ḥalīf* an ally.
