# பரிதாபம் (paritāpam) — pitifulness; pity

## You'll want to know: பரிதாபம்
<!-- hl-knowledge: introduces=[TA-LEX-C457-KARUNAI457-04]; assesses=[] -->

**பரிதாபம்** — *paritāpam* — "pitifulness; pity".

> மழையில் நனைந்த நாயைப் பார்க்கப் பரிதாபமாக இருந்தது.
>
> *maḻaiyil naṉainta nāyaip pārkkap paritāpamāka iruntatu.*
>
> The dog soaked in the rain was a pitiful sight.

பரிதாபமாக இருக்கிறது, it is a sorry sight.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**பரிதாபம்** (*paritāpam*) is borrowed from Sanskrit *paritāpa*, "scorching heat; pain, grief" (Monier-Williams).

## What you've built

One more word for describing what you lived and felt.
