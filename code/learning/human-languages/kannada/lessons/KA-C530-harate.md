# ಹರಟೆ (haraṭe) — a chat; idle talk

## You'll want to know: ಹರಟೆ
<!-- hl-knowledge: introduces=[KA-LEX-C530-BIDUVU530-03]; assesses=[] -->

**ಹರಟೆ** — *haraṭe* — "a chat; idle talk".

> ಸಂಜೆ ಅಜ್ಜಂದಿರು ಜಗಲಿಯ ಮೇಲೆ ಹರಟೆ ಹೊಡೆಯುತ್ತಾರೆ.
>
> *sañje ajjandiru jagaliya mēle haraṭe hoḍeyuttāre.*
>
> In the evening the old men chat on the veranda.

ಹರಟೆ ಹೊಡೆ, to chat away the time.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಹರಟೆ** (*haraṭe*) is native Dravidian: DEDR 4031 lists Kannada *haraṭu*, "to talk idly", and *haraṭe*, "idle talk", beside Tamil *paṟai*, "to say".
