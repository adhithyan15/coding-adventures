# દાક્તર (dāktar) — doctor

## You'll want to know: દાક્તર
<!-- hl-knowledge: introduces=[GU-LEX-C224-DOCTOR224-01]; assesses=[] -->

**દાક્તર** — *dāktar* — "doctor".

> **શું દાક્તર આજે અહીં છે?** — *śũ dāktar āje ahī̃ che?* — "Is the doctor here today?"

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**દાક્તર** (*dāktar*) is a loan, usually traced to English *doctor*; EtymDB lists Persian *dāktar* as the go-between.
