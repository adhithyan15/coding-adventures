## You'll want to know: acelerar
<!-- hl-knowledge: introduces=[PT-LEX-C401-AUTOESTRADA-05]; assesses=[] -->

**acelerar** — "to speed up, to accelerate".

> Ela acelera para ultrapassar o autocarro.
>
> *She speeds up to overtake the bus.*

*O acelerador* — the accelerator.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*acelerar* is a learned borrowing from Latin *accelerāre* 'to hasten' (EtymDB), built on *celer* 'swift' (Lewis & Short).
