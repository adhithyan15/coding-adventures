## You'll want to know: incursiō, incursiōnis
<!-- hl-knowledge: introduces=[LA-LEX-C339-PROELIUM-04]; assesses=[] -->

**incursiō, incursiōnis** — "a raid, an attack".

> Hostēs incursiōnem in agrōs nostrōs fēcērunt.
>
> *The enemy made a raid on our fields.*

Feminine, 3rd declension, from *incurrō*, 'to run against'. English *incursion*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**incursiō** is built on *incurrō*, "to run against", from *in* and *currō*, "to run" (Lewis & Short). English *incursion* comes from it.
