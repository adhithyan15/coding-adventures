## You'll want to know: отправляться
<!-- hl-knowledge: introduces=[RU-LEX-C415-OTPRAVLYATSYA-01]; assesses=[] -->

**отправляться** (*otpravlyátsya*) — "to set off, to depart".

> Поезд отправляется в восемь утра.
>
> *Póyezd otpravlyáyetsya v vósem utrá.*
>
> The train departs at eight in the morning.

Imperfective; perfective *отправиться*. *Отправлять* is to send; with *-ся*, to set off oneself.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*отправляться* is *отправлять* 'to send off' with *-ся* 'oneself'. *Отправлять* is built from *от-* 'off' and *править* 'to steer, to set right'; EtymDB lists the noun *отправление* 'departure'.
