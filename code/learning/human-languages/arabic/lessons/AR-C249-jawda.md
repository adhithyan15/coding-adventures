## You'll want to know: جودة

**جودة** — *jawda* — "quality".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**جودة** (*jawda*) is built on the native Arabic root *j-w-d*, "to be good, to be excellent" (Lane). *Jawda* is goodness, quality.
