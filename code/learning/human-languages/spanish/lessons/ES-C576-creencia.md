## You'll want to know: la creencia
<!-- hl-knowledge: introduces=[ES-LEX-C576-OPINA-03]; assesses=[] -->

**la creencia** — "the belief".

> Es una creencia muy antigua.
>
> *It is a very old belief.*

*Las creencias* — beliefs, often religious ones.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*creencia* is built on *creer* with the ending *-encia*; *creer* is inherited from Latin *credere* 'to trust, to believe' (EtymDB).
