## You'll want to know: மெட்ரோ
<!-- hl-knowledge: introduces=[TA-LEX-C405-METRO405-02]; assesses=[] -->

**மெட்ரோ** — *meṭrō* — "a metro; an underground railway".

> மெட்ரோவில் போனால் சீக்கிரம் போய்ச் சேரலாம்.
>
> *meṭrōvil pōṉāl cīkkiram pōyc cēralām.*
>
> If you go by metro, you can get there quickly.

A final -ஓ takes the glide வ் before a case ending: மெட்ரோவில்.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**மெட்ரோ** (*meṭrō*) is a loan from English *metro*.
