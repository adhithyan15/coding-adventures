# ಬುರುಜು (buruju) — a bastion; a tower

## You'll want to know: ಬುರುಜು
<!-- hl-knowledge: introduces=[KA-LEX-C361-SMARAKA361-04]; assesses=[] -->

**ಬುರುಜು** — *buruju* — "a bastion; a tower".

> ಕೋಟೆಯ ಬುರುಜಿನ ಮೇಲೆ ಸೈನಿಕರ ಸ್ಮಾರಕ ಇದೆ.
>
> *kōṭeya burujina mēle sainikara smāraka ide.*
>
> There is a soldiers' memorial on the fort's bastion.

Plural: ಬುರುಜುಗಳು, *burujugaḷu*.

The round towers on a fort wall where guns stood.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಬುರುಜು** (*buruju*) is a loan from Arabic *burj*, "a tower", which came through Persian and Hindustani.
