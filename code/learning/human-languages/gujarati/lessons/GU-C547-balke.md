# બલકે (balke) — rather (on the contrary)

## You'll want to know: બલકે
<!-- hl-knowledge: introduces=[GU-LEX-C547-CHATA547-04]; assesses=[] -->

**બલકે** — *balke* — "rather (on the contrary)".

> જો તમે આરામ કરશો તો કામ નહીં બગડે, બલકે વધારે સારું થશે.
>
> *jo tame ārām karśo to kām nahī̃ bagḍe, balke vadhāre sārũ thaśe.*
>
> If you rest, the work won't suffer; rather, it will go better.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**બલકે** (*balke*) is usually traced to Persian *balki*, "but rather".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
