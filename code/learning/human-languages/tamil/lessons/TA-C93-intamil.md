## You'll want to know: தமிழில்
<!-- hl-knowledge: introduces=[TA-LEX-C93-ASK-02]; assesses=[] -->

**தமிழில்** (*tamiḻil*) — "in Tamil".

**-இல்** is "in", added to the name of the language. **ஆங்கிலத்தில்** would be "in English".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

A way to name the language you want.
