# ജനസംഖ്യ (janasaṁkhya) — population

## You'll want to know: ജനസംഖ്യ
<!-- hl-knowledge: introduces=[ML-LEX-C415-SAMUHAM415-03]; assesses=[] -->

**ജനസംഖ്യ** — *janasaṁkhya* — "population".

> നഗരത്തിലെ ജനസംഖ്യ വർഷം തോറും കൂടുന്നു.
>
> *nagarattile janasaṁkhya varṣaṁ tōṟuṁ kūṭunnu.*
>
> The city's population grows every year.

Population is counted, so it goes up, കൂടുക, or down, കുറയുക.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ജനസംഖ്യ** (*janasaṁkhya*) is built from Sanskrit *jana*, "people" (CDIAL 5098), and *saṁkhyā*, "number, counting" (CDIAL 12841): the number of the people.
