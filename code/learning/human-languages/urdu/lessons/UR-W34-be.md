# ب (be) — the letter that opens بولنا

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[UR-SCRIPT-PE-01, UR-SCRIPT-VAO-01] -->

[PAUSE 2s] Before the new one: write پ and و once each, and name them.

[PAUSE 2s] Now say **بولنا** (*bolnā*), "to speak".
You have read it for a long time. This lesson takes one letter out of it and puts
it in your hand.

## Script you'll notice: ب
<!-- hl-knowledge: introduces=[UR-SCRIPT-C34-BE-01]; assesses=[] -->

**ب** — *be*, the sound *b*.

It opens **بولنا** (*bolnā*), "to speak". You already write **پ**, the shallow
boat with three dots beneath it. **ب** is the same boat with **one dot below**.

## Writing: ب
<!-- hl-knowledge: introduces=[]; assesses=[UR-SCRIPT-C34-BE-01] -->

- **1.** start here: sweep the independent be-series bowl from right to left
- **2.** after one lift, place the single dot below — and only now lift

**Pen lifts: 1.**

> Stroke order is one attested teaching order; hands and teachers vary.
> Source: Zer o Zabar, Be, kāf, and short vowels, independent ب handwriting animation and Be instructions (Northwestern University Libraries Open Textbook, 2026).

- [YOU LOOK: at **بولنا** and point at ب inside it]

- [YOU WRITE: و, then ب, from memory]
