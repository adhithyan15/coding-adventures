## You'll want to know: peatonal
<!-- hl-knowledge: introduces=[ES-LEX-C682-CALLE-05]; assesses=[] -->

**peatonal** — "pedestrian (as an adjective)".

> Esta calle es peatonal.
>
> *This is a pedestrian street.*

*Calle peatonal* or *zona peatonal* — no cars.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*peatonal* is built on *peatón* "pedestrian", which came from French *piéton*, built on *pied* "foot", from Latin *pēs*.
