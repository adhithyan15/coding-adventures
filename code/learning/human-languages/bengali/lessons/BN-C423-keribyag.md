# ক্যারিব্যাগ (kæribyāg) — a carrier bag; a plastic bag

## You'll want to know: ক্যারিব্যাগ
<!-- hl-knowledge: introduces=[BN-LEX-C423-THONGA423-03]; assesses=[] -->

**ক্যারিব্যাগ** — *kæribyāg* — "a carrier bag; a plastic bag".

> দোকানদার একটা ক্যারিব্যাগে জিনিসগুলো দিলেন।
>
> *dokāndār ekṭā kæribyāge jinisgulo dilen.*
>
> The shopkeeper gave me the things in a carrier bag.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ক্যারিব্যাগ** (*kæribyāg*) is borrowed from English *carry bag*, the Indian English name for a shop's plastic bag, written as one word; ব্যাগ inside it is already taught.
