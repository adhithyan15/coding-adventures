# ಏನೂ ಇಲ್ಲ (ēnū illa) — nothing

## You'll want to know: ಏನೂ ಇಲ್ಲ
<!-- hl-knowledge: introduces=[KA-LEX-C87-REPLIES-02]; assesses=[] -->

**ಏನೂ ಇಲ್ಲ** (*ēnū illa*) — "nothing", literally "anything, there isn't".
**ಏನು** (*ēnu*), "what", takes **‑ಊ** to become "anything".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->
