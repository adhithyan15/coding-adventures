# ప్రతిఫలం (pratiphalaṁ) — a reward; a return

## You'll want to know: ప్రతిఫలం
<!-- hl-knowledge: introduces=[TE-LEX-C423-PRATIPHALAM423-01]; assesses=[] -->

**ప్రతిఫలం** — *pratiphalaṁ* — "a reward; a return".

> కష్టానికి ప్రతిఫలం తప్పకుండా వస్తుంది.
>
> *kaṣṭāniki pratiphalaṁ tappakuṇḍā vastundi.*
>
> Hard work is sure to bring its reward.

ప్రతి, in return, + ఫలం, fruit.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ప్రతిఫలం** (*pratiphalaṁ*) is built from Sanskrit *prati-*, "back, in return", and *phala*, "fruit, result" (Monier-Williams).
