# Hear *dàxué* — university

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ZH-LEX-DA-01, ZH-LEX-XUE-01] -->

[PAUSE 10s] Say **big**, then **study**.

## You'll want to know
<!-- hl-knowledge: introduces=[ZH-LEX-DAXUE-01]; assesses=[] -->

> *dàxué* — **university; college**

Let *dà* fall, then let *xué* rise. Together they name a university or college.
