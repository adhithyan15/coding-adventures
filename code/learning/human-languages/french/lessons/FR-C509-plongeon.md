## You'll want to know: le plongeon
<!-- hl-knowledge: introduces=[FR-LEX-C509-EAU-02]; assesses=[] -->

**le plongeon** — "dive".

> Il a fait un beau plongeon dans la piscine.
>
> *He did a nice dive into the pool.*

*Faire un plongeon* — to dive in.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*le plongeon* is built on *plonger* "to dive" (EtymDB), from Vulgar Latin *plumbicāre* "to sink like lead", built on *plumbum* "lead" (Lewis & Short).
