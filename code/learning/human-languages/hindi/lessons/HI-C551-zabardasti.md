# ज़बरदस्ती (zabardastī) — force, coercion

## You'll want to know: ज़बरदस्ती
<!-- hl-knowledge: introduces=[HI-LEX-C551-MAJBUR551-05]; assesses=[] -->

**ज़बरदस्ती** — *zabardastī* — "force, coercion".

> बच्चे से ज़बरदस्ती मत कीजिए।
>
> *Bacce se zabardastī mat kījiye.*
>
> Don't force the child.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ज़बरदस्ती** (*zabardastī*) is usually traced to Persian *zabardastī*, "force, having the upper hand".
