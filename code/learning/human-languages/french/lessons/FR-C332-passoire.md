## You'll want to know: la passoire
<!-- hl-knowledge: introduces=[FR-LEX-C332-ASSAISONNER-01]; assesses=[] -->

**la passoire** — "the colander, the sieve".

> Il met les pâtes dans la passoire.
>
> *He puts the pasta in the colander.*

Informal: *une mémoire comme une passoire* — a memory like a sieve.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*passoire* is built on *passer* "to pass", which is inherited from Vulgar Latin *passāre*, built on Latin *passus* "a step" (Lewis & Short).
