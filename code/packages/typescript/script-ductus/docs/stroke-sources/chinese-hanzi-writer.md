# Hanzi Writer Data as a source (Chinese)

Chinese 尔 cites [Hanzi Writer Data's pinned `尔.json`](https://raw.githubusercontent.com/chanind/hanzi-writer-data/68d10a4b21150cae5e1ebbd223eed289cf32d90c/data/%E5%B0%94.json),
updated from Make Me a Hanzi on 22 June 2019. Its five ordered medians are the
same five strokes that already close 你: a left-falling top stroke, a horizontal
with an unbroken down-left hook, a central vertical with an unbroken left hook,
then the lower-left and lower-right dots. The learner path fits that order and
those directions to the standalone Noto Sans SC 尔 rather than copying the
Arphic-derived source proportions; the two hooks stay unbroken and four lifts
remain between the five runs.
