# di — the verb that changed families in the past

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ES-GRAMMAR-VER-PRETERITE, ES-ORTHOGRAPHY-ONE-SYLLABLE-NO-ACCENT] -->

[PAUSE 2s] *Vi*, *viste*, *vio* — bare, because one syllable has nowhere else
to put the beat.

[PAUSE 1s] A second verb does the same, and it is one you have never met.

## Grammar Lens: dar, which behaves like an -er verb
<!-- hl-knowledge: introduces=[ES-LEX-DAR, ES-GRAMMAR-DAR-PRETERITE]; assesses=[ES-GRAMMAR-ER-IR-PRETERITE-PLURAL, ES-GRAMMAR-ER-PRETERITE-SINGULAR] -->

***Dar*** means *to give*. It is an *-ar* verb — and in the preterite it flatly
refuses to behave like one:

> *dar* → ***di***, ***diste***, ***dio***, ***dimos***, ***disteis***,
> ***dieron***

[PAUSE 2s] Those are the *-er* endings, on an *-ar* verb, with the same
one-syllable forms going bare. *Ver* does the same in the plural: *vimos*,
*visteis*, *vieron*.

[PAUSE 2s] Two verbs, one shared oddity, and now the last two named irregulars
of the preterite are yours.
