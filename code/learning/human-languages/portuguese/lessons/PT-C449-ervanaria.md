## You'll want to know: a ervanária
<!-- hl-knowledge: introduces=[PT-LEX-C449-LOJAS-04]; assesses=[] -->

**a ervanária** — "the herbalist's shop".

> Na ervanária vendem chás para dormir.
>
> *At the herbalist's they sell teas to help you sleep.*

Built on *a erva*, the herb.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*ervanária* is built on *erva* 'herb, grass', which is inherited from Latin *herba* (EtymDB).
