## You'll want to know: zhuǎnjī
<!-- hl-knowledge: introduces=[ZH-LEX-C416-STORM416-04]; assesses=[] -->

*zhuǎnjī* — "to change planes".

> *wǒmen yào zài Běijīng zhuǎnjī* — We have to change planes in Beijing.

Its characters come later; for now it is a word for the ear.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*zhuǎnjī* is built from *zhuǎn* 'to turn' and 机 'a plane', both inherited from Middle Chinese, *trjwenX* and *kj+j* (Guangyun, in Baxter's transcription), which glosses the first 'to move, to turn'.
