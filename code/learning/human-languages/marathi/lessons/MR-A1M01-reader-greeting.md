# Write to one named reader

## Warm-up
<!-- hl-knowledge: introduces=[MR-A1-MESSAGE-LINE-GREETING]; assesses=[MR-LEX-NAMASKAR-01] -->

You already know **नमस्कार**. A message needs to show who receives that
greeting. Today the reader is **मीरा**, the familiar practice name.

## Writing — observe and trace one complete line
<!-- hl-knowledge: introduces=[]; assesses=[MR-LEX-NAMASKAR-01, MR-A1-MESSAGE-LINE-GREETING] -->
<!-- hl-writing-stage: observe-trace -->

Trace **नमस्कार मीरा.** once. Leave one space between the greeting and the
name. Touch the full stop; it closes this first line.

<!-- hl-knowledge: introduces=[]; assesses=[MR-A1-MESSAGE-LINE-GREETING] -->
