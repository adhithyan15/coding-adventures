# ખાતું (khātũ) — bank account, account

## You'll want to know: ખાતું
<!-- hl-knowledge: introduces=[GU-LEX-C190-BANK190-01]; assesses=[] -->

**ખાતું** — *khātũ* — "bank account, account".

> **મારું બેંકમાં ખાતું છે.** — *mārũ bẽkmā̃ khātũ che* — "I have an account at the bank."

A neuter noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ખાતું** (*khātũ*) is a tadbhava. CDIAL lists it under Sanskrit *kṣatrá*, "might, rule", with the Gujarati senses "administrative department, account, account book" (CDIAL 3648).
