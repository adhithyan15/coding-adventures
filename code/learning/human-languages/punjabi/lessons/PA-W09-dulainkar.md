# ੂ — a mark that hangs underneath

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-SCRIPT-NA-01, PA-SCRIPT-TIPPI-WRITING-01, PA-SCRIPT-RECOG-DULAINKAR-01] -->

[PAUSE 2s] Write **ਨ** once. Then put the small tippi **ੰ** above it, the way
you did for **ਪੰਜਾਬੀ**. Every vowel mark so far has sat on the line or above it.

## Script — one mark
<!-- hl-knowledge: introduces=[PA-SCRIPT-DULAINKAR-01]; assesses=[PA-SCRIPT-NA-01] -->

The **dulaiṅkaṛ** goes the other way. Trace **ਨੂ** twice: write **ਨ**, then hook
the mark on underneath it, and say *nū*. The vowel is a long *ū*, the sound in
English *food*.

This is the second mark in this book to hang below a letter rather than above
it. The **ਹ** tucked under its neighbour in *paṛhnā* was the first.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-SCRIPT-DULAINKAR-01, PA-SCRIPT-TIPPI-WRITING-01] -->
<!-- hl-writing-stage: observe-trace -->

Cover the model. Write **ਨੂੰ** once — letter, mark below, tippi above — then
compare only whether the mark sits under the letter and not beside it.
