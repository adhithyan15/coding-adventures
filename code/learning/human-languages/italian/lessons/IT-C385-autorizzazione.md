## You'll want to know: l'autorizzazione
<!-- hl-knowledge: introduces=[IT-LEX-C385-VIETATO-05]; assesses=[] -->

**l'autorizzazione** — "the authorisation, the permit".

> Senza autorizzazione non puoi entrare.
>
> *Without authorisation you cannot go in.*

Built on *autorizzare*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*autorizzazione* is built on *autorizzare*, which was borrowed from French *autoriser*, from Medieval Latin *auctōrizāre* (EtymDB), on Latin *auctor* "guarantor".
