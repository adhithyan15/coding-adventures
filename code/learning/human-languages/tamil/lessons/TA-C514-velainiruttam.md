# வேலைநிறுத்தம் (vēlainiṟuttam) — a strike

## You'll want to know: வேலைநிறுத்தம்
<!-- hl-knowledge: introduces=[TA-LEX-C514-SANKAM514-02]; assesses=[] -->

**வேலைநிறுத்தம்** — *vēlainiṟuttam* — "a strike".

> வேலைநிறுத்தத்தால் இன்று பேருந்துகள் ஓடவில்லை.
>
> *vēlainiṟuttattāl iṉṟu pēruntukaḷ ōṭavillai.*
>
> Because of the strike the buses did not run today.

Word for word "a stopping of work": வேலை + நிறுத்தம், from நிறுத்து (*niṟuttu*), to stop.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**வேலைநிறுத்தம்** (*vēlainiṟuttam*) is a native compound: வேலை (*vēlai*), "work" (DEDR 5540), and நிறுத்தம் (*niṟuttam*), "a stopping", from நில் (*nil*), "to stand, to stop" (DEDR 3675).
