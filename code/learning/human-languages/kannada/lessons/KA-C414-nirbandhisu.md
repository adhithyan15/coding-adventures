# ನಿರ್ಬಂಧಿಸು (nirbandhisu) — to restrict

## You'll want to know: ನಿರ್ಬಂಧಿಸು
<!-- hl-knowledge: introduces=[KA-LEX-C414-GARISHTHA414-05]; assesses=[] -->

**ನಿರ್ಬಂಧಿಸು** — *nirbandhisu* — "to restrict".

> ಸರ್ಕಾರ ಪ್ಲಾಸ್ಟಿಕ್ ಬಳಕೆಯನ್ನು ನಿರ್ಬಂಧಿಸಿತು.
>
> *sarkāra plāsṭik baḷakeyannu nirbandhisitu.*
>
> The government restricted the use of plastic.

Past (I …): ನಿರ್ಬಂಧಿಸಿದೆ, *nirbandhiside*.

ನಿರ್ಬಂಧ, a restriction.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ನಿರ್ಬಂಧಿಸು** (*nirbandhisu*) is built on Sanskrit *nirbandha*, "perseverance, insistence" (CDIAL 7355), from *bandh*, "to bind", with the Kannada verb ending -*isu*.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
