## Fixed — Telugu root slugs name one etymon each

- **TE-C288-malabaddhakam** moves from `sanskrit-mala` to `sanskrit-mala-dirt`, the slug Sanskrit and Urdu use for *mala* "dirt" (CDIAL 9899). Bare `sanskrit-mala` also named *mālā* "garland".
- **TE-C249-bharincu** moves from `sanskrit-bhara` to `sanskrit-bhara-carrying`. Its block cites *bhára* "carrying; weight" (CDIAL 9393); `sanskrit-bhara` is *bhārá* "burden" (CDIAL 9459).
- **TE-C272-kandam** moves from `sanskrit-kanda` to `sanskrit-kanda-stem`. *Kāṇḍaṁ* is *kā́ṇḍa* "joint of a plant" (CDIAL 3023); `sanskrit-kanda` is *kanda* "bulbous root" (CDIAL 2723).
- **TE-C156-kalapattika** moves from `sanskrit-patta-slab` to `sanskrit-pattika`, the slug Kannada, Malayalam and Sanskrit use for *paṭṭikā* "tablet" (CDIAL 7699).
- **TE-C275-kalakarudu** and **TE-C311-kalasala** move from `sanskrit-kala` to `sanskrit-kala-art` (*kalā*, CDIAL 2927), the slug every other track's "art" lessons use.
