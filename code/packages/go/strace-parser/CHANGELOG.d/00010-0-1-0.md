## [0.1.0] - 2026-11-16

### Added

- `ParseLine` and `ParseLineTokens`: parse one strace line with the grammar in
  `code/grammars/strace/strace.grammar`, compiled once at package load with
  `parser.CompileGrammar`. Syntax only; a typed `*LineError` says whether a
  failure was syntax, an `ERR_*` token, a bad annotation, a leading or trailing
  space, a newline, or a resource limit.
- `DefaultOptions`: bracket nesting 64, 65,536 tokens, a memo bound.
- `BodyKind`, `RawArgs`, `TextAfterClose`: read the tree and cut raw text out of
  the line by token column.
- Tests: grammar drift against `strace.grammar`, token references only, every
  fixture line, the corpus of lines from kiln's tests with the refused set
  pinned, the stricter-only divergences from the old scanner, depth and token
  limits, a fuzz target; benchmarks for lex plus parse of the fixtures.
