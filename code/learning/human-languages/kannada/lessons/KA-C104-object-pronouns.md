# ನನ್ನನ್ನು, ನಿಮ್ಮನ್ನು, ಅವನನ್ನು — familiar pronouns in the object seat

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[] -->

[PAUSE 2s] Say **ನಾನು**, **ನೀನು**, **ನೀವು**, **ಅವನು**, **ಅವಳು**, **ಅದು**,
**ಅವರು**. Those are the pronouns when they do the action. Now move each one to
the place where the action reaches it.

## Grammar Lens: the same -ಅನ್ನು, on changed pronoun bodies
<!-- hl-knowledge: introduces=[KA-GRAMMAR-C104-OBJECT-PRONOUNS-07]; assesses=[KA-GRAMMAR-C104-ACCUSATIVE-ANNU-06, KA-LEX-C101-OPEN-04] -->

| the pronoun | as the object |
|---|---|
| ನಾನು *nānu* — I | ನನ್ನನ್ನು *nannannu* — me |
| ನೀನು *nīnu* — familiar you | ನಿನ್ನನ್ನು *ninnannu* — you |
| ನೀವು *nīvu* — respectful you | ನಿಮ್ಮನ್ನು *nimmannu* — you |
| ಅವನು *avanu* — he | ಅವನನ್ನು *avanannu* — him |
| ಅವಳು *avaḷu* — she | ಅವಳನ್ನು *avaḷannu* — her |
| ಅದು *adu* — it / that | ಅದನ್ನು *adannu* — it / that |
| ಅವರು *avaru* — they or respected he/she | ಅವರನ್ನು *avarannu* — them or that respected person |

The pronoun body changes before **-ಅನ್ನು** lands. Do not try to glue the ending
onto the full dictionary form. Learn each left-to-right pair, then hear the one
shared ending at the right edge.

> **ನನ್ನನ್ನು ಕರೆಯಿರಿ** — *nannannu kareyiri* — please call me
>
> **ಅವರನ್ನು ಕರೆಯಿರಿ** — *avarannu kareyiri* — please call them, or that respected person

The respectful/plural choice stays intact: **ನೀವು → ನಿಮ್ಮನ್ನು** and
**ಅವರು → ಅವರನ್ನು** still carry respect as well as number.
