# सत्यसन्धः (satyasandhaḥ) — true to one's word

## You'll want to know: सत्यसन्धः
<!-- hl-knowledge: introduces=[SA-LEX-C535-SATYASANDHA535-02]; assesses=[] -->

**सत्यसन्धः** — *satyasandhaḥ* — "true to one's word".

> यदि सः सत्यसन्धः अस्ति, तर्हि सः अवश्यम् आगच्छति।
>
> *yadi saḥ satyasandhaḥ asti, tarhi saḥ avaśyam āgacchati.*
>
> If he keeps his word, he will surely come.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**सत्यसन्धः** (*satyasandhaḥ*) is built from *satya*, "true", and *saṃdhā*, "a compact, a promise"; MW gives *satyasaṃdha* as true to engagements, keeping one's promise (MW).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
