# ವಿರೋಧಿಸು (virōdhisu) — to oppose

## You'll want to know: ವಿರೋಧಿಸು
<!-- hl-knowledge: introduces=[KA-LEX-C379-OMMATA379-04]; assesses=[] -->

**ವಿರೋಧಿಸು** — *virōdhisu* — "to oppose".

> ಹಲವರು ಹೊಸ ತೆರಿಗೆಯನ್ನು ವಿರೋಧಿಸಿದರು.
>
> *halavaru hosa terigeyannu virōdhisidaru.*
>
> Many people opposed the new tax.

Past (I …): ವಿರೋಧಿಸಿದೆ, *virōdhiside*.

What you oppose takes -ಅನ್ನು. ವಿರೋಧ, opposition.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ವಿರೋಧಿಸು** (*virōdhisu*) is built on Sanskrit *virodha*, "opposition, hostility" (Monier-Williams), with the Kannada verb ending -*isu*.

One more word for giving reasons and opinions.
