## You'll want to know: o noivado
<!-- hl-knowledge: introduces=[PT-LEX-C312-NOIVADO-01]; assesses=[] -->

**o noivado** — "the engagement".

> O noivado durou dois anos.
>
> *The engagement lasted two years.*

Built on *noivo*, ‘fiancé, groom’.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*noivado* is built on *noivo* (EtymDB), which goes back to Vulgar Latin *novius* "newly wed", from Latin *novus* "new".
