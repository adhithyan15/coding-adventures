# ಮನಸ್ಸಾಕ್ಷಿ (manassākṣi) — a conscience

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C388-NAITIKA388-01, KA-LEX-C388-NAITIKA388-02] -->

[PAUSE 2s] Before the new one: say the Kannada for ethical, then the Kannada for a sacrifice.

## You'll want to know: ಮನಸ್ಸಾಕ್ಷಿ
<!-- hl-knowledge: introduces=[KA-LEX-C388-NAITIKA388-03]; assesses=[] -->

**ಮನಸ್ಸಾಕ್ಷಿ** — *manassākṣi* — "a conscience".

> ನನ್ನ ಮನಸ್ಸಾಕ್ಷಿ ಸುಳ್ಳು ಹೇಳಲು ಬಿಡಲಿಲ್ಲ.
>
> *nanna manassākṣi suḷḷu hēḷalu biḍalilla.*
>
> My conscience did not let me lie.

ಮನಸ್ಸು (mind) + ಸಾಕ್ಷಿ (witness).

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಮನಸ್ಸಾಕ್ಷಿ** (*manassākṣi*) is built from Sanskrit *manas*, "mind" (CDIAL 9822), and *sākṣin*, "a witness" (CDIAL 13321): the mind as witness.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
