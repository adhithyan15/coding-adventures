# നിഷ്പക്ഷമായ (niṣpakṣamāya) — impartial; neutral

## You'll want to know: നിഷ്പക്ഷമായ
<!-- hl-knowledge: introduces=[ML-LEX-C409-KURRAM409-04]; assesses=[] -->

**നിഷ്പക്ഷമായ** — *niṣpakṣamāya* — "impartial; neutral".

> അന്വേഷണം നിഷ്പക്ഷമായിരിക്കണം.
>
> *anvēṣaṇaṁ niṣpakṣamāyirikkaṇaṁ.*
>
> The inquiry must be impartial.

The noun is നിഷ്പക്ഷത, impartiality.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**നിഷ്പക്ഷമായ** (*niṣpakṣamāya*) is built from Sanskrit *niṣ-*, "without", and *pakṣa*, "a wing, a side" (CDIAL 7627), with the adjective ending -ആയ: taking no side.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
