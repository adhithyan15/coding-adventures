## You'll want to know: erleben
<!-- hl-knowledge: introduces=[GE-LEX-C300-SCHEIDUNG-05]; assesses=[] -->

**erleben** — "to go through, to experience".

> In diesem Jahr erlebte die Familie viel.
>
> *That year the family went through a lot.*

*Das Erlebnis*, already known, is built on it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*erleben* is built on *leben* "to live", from Proto-Germanic *libjaną* (EtymDB), with *er-*: to live through.
