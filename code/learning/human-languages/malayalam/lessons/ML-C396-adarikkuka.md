# ആദരിക്കുക (ādarikkuka) — to honour

## You'll want to know: ആദരിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C396-PURASKARAM396-04]; assesses=[] -->

**ആദരിക്കുക** — *ādarikkuka* — "to honour".

> പള്ളിക്കൂടം പഴയ അധ്യാപകരെ ആദരിച്ചു.
>
> *paḷḷikkūṭaṁ paḻaya adhyāpakare ādariccu.*
>
> The school honoured its old teachers.

Past: ആദരിച്ചു, *ādariccu*.

The person honoured takes -എ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ആദരിക്കുക** (*ādarikkuka*) is built from Sanskrit *ādara*, "respect" (CDIAL 1142), with the Malayalam verb ending -ിക്കുക.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
