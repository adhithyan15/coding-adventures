## You'll want to know: cercano
<!-- hl-knowledge: introduces=[ES-LEX-C671-LEJOS-01]; assesses=[] -->

**cercano** — "nearby, close".

> Busco una farmacia cercana.
>
> *I am looking for a nearby chemist.*

*Un amigo cercano* — a close friend.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*cercano* is built on *cerca* "near" (EtymDB), which comes from Latin *circā* "around".
