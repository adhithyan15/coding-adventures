# முக்கியத்துவம் (mukkiyattuvam) — importance

## You'll want to know: முக்கியத்துவம்
<!-- hl-knowledge: introduces=[TA-LEX-C354-MUKKIYATTUVA354-01]; assesses=[] -->

**முக்கியத்துவம்** — *mukkiyattuvam* — "importance".

> கல்விக்கு அதிக முக்கியத்துவம் கொடுக்க வேண்டும்.
>
> *kalvikku atika mukkiyattuvam koṭukka vēṇṭum.*
>
> We must give more importance to education.

X-க்கு முக்கியத்துவம் கொடு, to give importance to X. The adjective is முக்கியமான.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**முக்கியத்துவம்** (*mukkiyattuvam*) is built on Sanskrit *mukhya*, "chief, principal" (CDIAL 10174), the source of முக்கியமான, with the Sanskrit abstract suffix *-tva*, "-ness", which Tamil writes -த்துவம்.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
