## You'll want to know: transcurrir
<!-- hl-knowledge: introduces=[ES-LEX-C541-DURAR-05]; assesses=[] -->

**transcurrir** — "to go by, to pass (of time); to take place".

> Transcurrieron dos horas sin noticias.
>
> *Two hours went by without news.*

A written word; the story *transcurre en Sevilla* is set in Seville.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*transcurrir* is a learned borrowing from Latin *trānscurrere* 'to run across' (EtymDB), built on *trāns* 'across' and *currere* 'to run'.
