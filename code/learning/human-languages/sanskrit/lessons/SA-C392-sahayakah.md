## You'll want to know: सहायकः
<!-- hl-knowledge: introduces=[SA-LEX-C392-SAHAYAKA392-02]; assesses=[] -->

**सहायकः** — *sahāyakaḥ* — "an assistant; a helper".

> यदि कार्यं बहु, तर्हि एकं सहायकम् आनयतु।
>
> *yadi kāryaṃ bahu, tarhi ekaṃ sahāyakam ānayatu.*
>
> If there is a lot of work, bring an assistant.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**सहायकः** (*sahāyakaḥ*) is built on *sahāya*, "a companion"; MW gives *sahāyaka* as the same as *sahāya*, a companion who helps (MW).
