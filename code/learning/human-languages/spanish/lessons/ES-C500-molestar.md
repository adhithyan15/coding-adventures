## You'll want to know: molestar
<!-- hl-knowledge: introduces=[ES-LEX-C500-NORMAS-02]; assesses=[] -->

**molestar** — "to bother, to disturb".

> No molestar.
>
> *Do not disturb.*

It works like *gustar*: *¿te molesta el ruido?*
