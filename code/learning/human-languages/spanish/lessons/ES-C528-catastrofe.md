## You'll want to know: la catástrofe
<!-- hl-knowledge: introduces=[ES-LEX-C528-DESASTRE-02]; assesses=[] -->

**la catástrofe** — "the catastrophe".

> El huracán fue una catástrofe para la isla.
>
> *The hurricane was a catastrophe for the island.*

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*catástrofe* is a learned borrowing that comes from Greek *katastrophḗ* 'an overturning' (EtymDB), built on *katá* 'down' and *stréphein* 'to turn'.
