## You'll want to know: किफायतशीर
<!-- hl-knowledge: introduces=[MR-LEX-C428-SHILLAK428-05]; assesses=[] -->

**किफायतशीर** — *kiphāyatśīr* — "economical; good value".

> बसचा प्रवास किफायतशीर असतो.
>
> *bascā pravās kiphāyatśīr asto.*
>
> Travelling by bus is economical.

It does not change: किफायतशीर दर, किफायतशीर गाडी.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**किफायतशीर** (*kiphāyatśīr*) is a loan built on Arabic *kifāyat*, "sufficiency, thrift", with the Persian adjective ending *-śīr*; the exact path into Marathi is not settled.
