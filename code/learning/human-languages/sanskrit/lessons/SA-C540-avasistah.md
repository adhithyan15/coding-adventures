# अवशिष्टः (avaśiṣṭaḥ) — left over

## You'll want to know: अवशिष्टः
<!-- hl-knowledge: introduces=[SA-LEX-C540-ASANNA540-02]; assesses=[] -->

**अवशिष्टः** — *avaśiṣṭaḥ* — "left over".

> यदि किञ्चित् अन्नम् अवशिष्टम् अस्ति, तर्हि श्वः खादिष्यामः।
>
> *yadi kiñcit annam avaśiṣṭam asti, tarhi śvaḥ khādiṣyāmaḥ.*
>
> If any food is left over, we'll eat it tomorrow.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**अवशिष्टः** (*avaśiṣṭaḥ*) is built on *ava* and the root √śiṣ, "to leave", as its past participle; MW gives *avaśiṣṭa* as left, remaining (MW).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
