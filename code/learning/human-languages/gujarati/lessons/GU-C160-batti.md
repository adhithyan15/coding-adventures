# બત્તી (battī) — electric light, lamp

## You'll want to know: બત્તી
<!-- hl-knowledge: introduces=[GU-LEX-C160-BED160-04]; assesses=[] -->

**બત્તી** — *battī* — "electric light, lamp".

> **આ બત્તી નવી છે.** — *ā battī navī che* — "This light is new."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**બત્તી** (*battī*) is usually traced to Sanskrit *varti*, "wick", and EtymDB derives it from that word, but its path is not settled. CDIAL lists the kindred Gujarati *vāṭ*, "lamp", and *vātī* under that Sanskrit word, but not *battī* itself (CDIAL 11359).
