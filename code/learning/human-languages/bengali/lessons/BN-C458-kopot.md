## You'll want to know: কপট
<!-- hl-knowledge: introduces=[BN-LEX-C458-SOT458-02]; assesses=[] -->

**কপট** — *kôpôṭ* — "insincere; two-faced; feigned".

> লোকটার কপট হাসি দেখে মীরা তাকে বিশ্বাস করল না।
>
> *lokṭār kôpôṭ hāsi dekhe mīrā tāke bishvās kôrlô nā.*
>
> Seeing the man's false smile, Mira did not trust him.

কপট রাগ, pretended anger: the kind a grandmother puts on.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**কপট** (*kôpôṭ*) is a tatsama, Sanskrit *kapaṭa*, a noun for fraud and deceit (Monier-Williams); Bengali uses it as an adjective, for a smile or a feeling put on to mislead. It is a different word from Sanskrit *kapāṭa*, a door leaf.
