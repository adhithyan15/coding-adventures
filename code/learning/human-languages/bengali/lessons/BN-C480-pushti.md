# পুষ্টি (pushṭi) — nutrition; nourishment

## You'll want to know: পুষ্টি
<!-- hl-knowledge: introduces=[BN-LEX-C480-PUSHTI480-01]; assesses=[] -->

**পুষ্টি** — *pushṭi* — "nutrition; nourishment".

> শিশুদের পুষ্টির জন্য দুধ আর ডিম দরকার।
>
> *shishuder pushṭir jônyô dudh ār ḍim dôrkār.*
>
> Children need milk and eggs for nourishment.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**পুষ্টি** (*pushṭi*) is a tatsama, Sanskrit *puṣṭi*, "a well-nourished condition, growth, thriving" (Monier-Williams).
