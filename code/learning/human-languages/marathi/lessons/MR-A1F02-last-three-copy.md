# Copy the last three rows

## Warm-up

Say the three meanings once: favorite drink, favorite activity, friend's name.
Listen for the one small job each label performs.

## Writing — guided copy
<!-- hl-knowledge: introduces=[]; assesses=[MR-A1-FORM-LABEL-AVDATE-PEY, MR-A1-FORM-AGREEMENT-NEUTER, MR-A1-FORM-LABEL-AVADTI-KRUTI, MR-A1-FORM-AGREEMENT-FEMININE, MR-A1-FORM-LABEL-MITRACHE-NAAV, MR-A1-FORM-POSSESSIVE-NEUTER] -->

Copy exactly three rows:

> **आवडते पेय: चहा**
>
> **आवडती कृती: वाचणे**
> **मित्राचे नाव: अरुण**

On the first two, underline only **-ते / -ती**. On the third, circle only
**-चे**. One visible contrast, then stop.
