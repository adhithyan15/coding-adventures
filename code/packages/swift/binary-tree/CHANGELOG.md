# Changelog — BinaryTree (Swift)

All notable changes to this package are documented here.

## 0.1.0 — Initial release

- Add immutable identity-based binary-tree nodes and a validated tree wrapper.
- Add iterative inorder, preorder, postorder, and level-order traversal.
- Add identity-based membership, child, and depth queries plus iterative size,
  height, full, complete, and perfect predicates.
- Add tagged nullable-safe positional slots, sparse orphan rejection, canonical
  trailing gaps, checked indices, and a 1,048,575-position resource ceiling.
- Reject shared or cyclic supplied nodes, retain payloads shallowly, and expose
  distinct stable validation errors without partial publication.
- Add package-native tests, coverage and release build fronts, documentation,
  and an empty capability profile.
