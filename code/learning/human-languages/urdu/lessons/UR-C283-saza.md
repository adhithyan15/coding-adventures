## You'll want to know: سزا
<!-- hl-knowledge: introduces=[UR-LEX-C283-ADALAT283-04]; assesses=[] -->

**سزا** — *sazā* — "a punishment; a sentence".

> اگر ثبوت ہے تو سزا ملے گی۔
>
> *agar subūt hai to sazā mile gī.*
>
> If there is proof, there will be a sentence.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**سزا** (*sazā*) is usually traced to Persian *sazā*, "what is fitting, what one deserves". It is feminine: **سزا ملے گی**.
