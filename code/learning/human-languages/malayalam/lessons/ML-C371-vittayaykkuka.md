# വിട്ടയയ്ക്കുക (viṭṭayaykkuka) — to release; to set free

## You'll want to know: വിട്ടയയ്ക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C371-JAIL371-04]; assesses=[] -->

**വിട്ടയയ്ക്കുക** — *viṭṭayaykkuka* — "to release; to set free".

> പോലീസ് നിരപരാധിയെ വിട്ടയച്ചു.
>
> *pōlīsŭ niraparādhiye viṭṭayaccu.*
>
> The police released the innocent man.

Past: വിട്ടയച്ചു, *viṭṭayaccu*.

വിട്ട്, letting go, + അയയ്ക്കുക, to send.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**വിട്ടയയ്ക്കുക** (*viṭṭayaykkuka*) is a native Dravidian compound of വിടുക (*viṭuka*), "to let go, to release" (DEDR 5393), and അയയ്ക്കുക (*ayaykkuka*), "to send": to let someone go and send them off.
