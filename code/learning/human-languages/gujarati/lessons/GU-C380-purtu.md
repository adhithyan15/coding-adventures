## You'll want to know: પૂરતું
<!-- hl-knowledge: introduces=[GU-LEX-C380-PURTU380-01]; assesses=[] -->

**પૂરતું** — *pūrtũ* — "enough".

> જો પૂરતો વરસાદ પડશે તો પાણીની ચિંતા નહીં રહે.
>
> *jo pūrto varsād paḍśe to pāṇīnī cintā nahī̃ rahe.*
>
> If there is enough rain, there will be no worry about water.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**પૂરતું** (*pūrtũ*) is built on *pūrũ*, "full", which CDIAL traces to Sanskrit *pūra*, "filling" (CDIAL 8330): as much as fills the need.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
