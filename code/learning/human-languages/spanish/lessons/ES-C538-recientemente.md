## You'll want to know: recientemente
<!-- hl-knowledge: introduces=[ES-LEX-C538-ANTES-04]; assesses=[] -->

**recientemente** — "recently".

> Recientemente abrieron un museo nuevo.
>
> *A new museum opened recently.*

Before a participle it shortens to *recién*: *recién llegado*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*recientemente* is built on *reciente* and the ending *-mente* (EtymDB). *Reciente* is a learned word from Latin *recēns* 'fresh, new'.
