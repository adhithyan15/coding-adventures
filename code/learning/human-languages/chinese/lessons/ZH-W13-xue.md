# 学 — top, cover, child

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ZH-LEX-XUE-01, ZH-SCRIPT-ZI-CHAR] -->

[PAUSE 12s] Say **study**, then write 子.

## Script — the shape
<!-- hl-knowledge: introduces=[ZH-SCRIPT-XUE-01]; assesses=[] -->

> **⺍** + **冖** + **子** → **学**

Place the three short marks across the top. Add the covering dot and hooked
line. Finish with the familiar three strokes of 子 below. Eight strokes total;
do not let the top marks crowd the child.
