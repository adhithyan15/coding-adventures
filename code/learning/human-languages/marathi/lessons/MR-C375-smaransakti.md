## You'll want to know: स्मरणशक्ती
<!-- hl-knowledge: introduces=[MR-LEX-C375-BUDDHI375-02]; assesses=[] -->

**स्मरणशक्ती** — *smaraṇśaktī* — "memory power; memory".

> आजीची स्मरणशक्ती अजूनही चांगली आहे.
>
> *ājīcī smaraṇśaktī ajūnhī cāṅglī āhe.*
>
> Grandmother's memory is still good.

Feminine.

स्मरण + शक्ती, remembering + power.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**स्मरणशक्ती** (*smaraṇśaktī*) is a learned compound built from Sanskrit *smaraṇa*, "remembering", and *śakti*, "power" (Monier-Williams).
