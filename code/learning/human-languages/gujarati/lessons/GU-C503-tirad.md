## You'll want to know: તિરાડ
<!-- hl-knowledge: introduces=[GU-LEX-C503-RANDO503-04]; assesses=[] -->

**તિરાડ** — *tirāḍ* — "a crack".

> જૂના બારણામાં એક મોટી તિરાડ છે.
>
> *jūnā bārṇāmā̃ ek moṭī tirāḍ che.*
>
> There is a big crack in the old door.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**તિરાડ** (*tirāḍ*) is perhaps related to *taraṛ*, "a crack", which CDIAL files under *traṭ* (CDIAL 5988), but CDIAL does not list this form, so its history is not settled.
