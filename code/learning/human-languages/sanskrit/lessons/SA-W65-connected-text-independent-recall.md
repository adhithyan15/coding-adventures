# Meanings only — recall the complete Devanagari text

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[SA-LEX-NAMASTE, SA-PATTERN-I-SPEAK-SANSKRIT] -->

Put every Sanskrit model away. The prompt below gives meanings only. Nothing
new is being composed or translated: these are the same two old sentences in
the same order.

## Writing — independent connected-text recall
<!-- hl-knowledge: introduces=[]; assesses=[SA-LEX-NAMASTE, SA-PATTERN-I-SPEAK-SANSKRIT, SA-SCRIPT-DANDA-01, SA-SKILL-CONNECTED-READING] -->

Write in Devanagari:

1. “Hello.” Literally, “a bow to you.”
2. “I speak Sanskrit.”

Put a danda after each sentence. Stop after one complete attempt; do not use a
visible Devanagari model or a romanized cue.

Now uncover the answer: **नमस्ते। अहं संस्कृतं वदामि।** Award credit only if
both known sentences are complete, ordered, separated, and closed with danda
marks in Devanagari. Romanization earns no credit. If one feature differs,
repair that feature and write the whole two-sentence text once more from memory.

## Wrap-up recall
<!-- hl-knowledge: introduces=[]; assesses=[SA-SKILL-CONNECTED-READING] -->

The runway began with one traced **न**. What can you now produce without a
model? (**A complete two-sentence Devanagari text from meaning alone.**)
