# രക്ഷാപ്രവർത്തനം (rakṣāpravarttanaṁ) — a rescue operation

## You'll want to know: രക്ഷാപ്രവർത്തനം
<!-- hl-knowledge: introduces=[ML-LEX-C374-DURANTHAM374-03]; assesses=[] -->

**രക്ഷാപ്രവർത്തനം** — *rakṣāpravarttanaṁ* — "a rescue operation".

> രാത്രി മുഴുവൻ രക്ഷാപ്രവർത്തനം നടന്നു.
>
> *rātri muḻuvan rakṣāpravarttanaṁ naṭannu.*
>
> The rescue operation went on all night.

രക്ഷ, protection, + പ്രവർത്തനം, work, activity.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**രക്ഷാപ്രവർത്തനം** (*rakṣāpravarttanaṁ*) is built from two Sanskrit words: *rakṣā*, "protection, care" (CDIAL 10551), and *pravartana*, "moving forward, setting in motion" (Monier-Williams).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
