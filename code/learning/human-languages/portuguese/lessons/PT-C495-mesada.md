## You'll want to know: a mesada
<!-- hl-knowledge: introduces=[PT-LEX-C495-EDUCAR-04]; assesses=[] -->

**a mesada** — "(monthly) pocket money, allowance".

> Recebo uma mesada de vinte euros.
>
> *I get twenty euros pocket money a month.*

Built on *o mês*: money given each month. Weekly money is *a semanada*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*mesada* is built on *mês* "month", which is inherited from Latin *mēnsis* "month" (Lewis & Short).
