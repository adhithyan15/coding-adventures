# વાટાઘાટ (vāṭāghāṭ) — negotiations

## You'll want to know: વાટાઘાટ
<!-- hl-knowledge: introduces=[GU-LEX-C542-SAMADHAN542-02]; assesses=[] -->

**વાટાઘાટ** — *vāṭāghāṭ* — "negotiations".

> જો વાટાઘાટ સારી ચાલશે તો કાલે કારખાનું ફરી ખૂલશે.
>
> *jo vāṭāghāṭ sārī cālśe to kāle kārkhānũ pharī khūlśe.*
>
> If the talks go well, the factory will open again tomorrow.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**વાટાઘાટ** (*vāṭāghāṭ*) is a jingling pair of words for talk back and forth between two sides. No dictionary we use records an older form, so its history is not settled.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
