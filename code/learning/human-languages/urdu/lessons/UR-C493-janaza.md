# جنازہ (janāzā) — a funeral

## You'll want to know: جنازہ
<!-- hl-knowledge: introduces=[UR-LEX-C493-MOURNING493-02]; assesses=[] -->

**جنازہ** — *janāzā* — "a funeral".

> جنازے میں سب رشتہ دار آئے۔
>
> *janāze meṅ sab rishte dār āe.*
>
> All the relatives came to the funeral.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**جنازہ** (*janāzā*) is usually traced, through Persian, to Arabic *janāza*, "a bier, a funeral".
