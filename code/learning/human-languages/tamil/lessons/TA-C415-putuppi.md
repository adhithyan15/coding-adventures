# புதுப்பி (putuppi) — to renew; to renovate

## You'll want to know: புதுப்பி
<!-- hl-knowledge: introduces=[TA-LEX-C415-AVANAM415-02]; assesses=[] -->

**புதுப்பி** — *putuppi* — "to renew; to renovate".

> நேற்று நான் என் கடவுச்சீட்டைப் புதுப்பித்தேன்.
>
> *nēṟṟu nāṉ eṉ kaṭavuccīṭṭaip putuppittēṉ.*
>
> Yesterday I renewed my passport.

Past (I …): புதுப்பித்தேன், *putuppittēṉ*.

Built on புது, new: to make new again.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**புதுப்பி** (*putuppi*) is built from புது, "new" (DEDR 4275), with a verb-making ending: to make new.
