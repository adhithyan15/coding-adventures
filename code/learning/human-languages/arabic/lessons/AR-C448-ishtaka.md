## You'll want to know: اشتكى
<!-- hl-knowledge: introduces=[AR-LEX-C448-DAJIJ448-05]; assesses=[] -->

**اشتكى** — *ishtakā* — "to complain".

> اشتكى النزيل من الضجيج.
>
> *ishtakā an-nazīl min aḍ-ḍajīj.*
>
> The guest complained about the noise.

Present: يشتكي, *yashtakī*.

It takes *min* before the cause: *ishtakā min*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**اشتكى** (*ishtakā*) is built on the native Arabic root *sh-k-w*, "to complain" (Lane). It is Form VIII.
