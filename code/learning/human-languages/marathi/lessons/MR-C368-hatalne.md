## You'll want to know: हाताळणे
<!-- hl-knowledge: introduces=[MR-LEX-C368-PALAN368-05]; assesses=[] -->

**हाताळणे** — *hātāḷṇe* — "to handle".

> मीराने तो प्रश्न शांतपणे हाताळला.
>
> *mīrāne to praśna śāntpaṇe hātāḷlā.*
>
> Meera handled the issue calmly.

Past, with -ने (he …): त्याने हाताळलं, *tyāne hātāḷlaṁ*.

Built on हात, hand.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**हाताळणे** (*hātāḷṇe*) is a Marathi verb built on हात, "hand", which is inherited from Sanskrit *hasta*, "hand" (CDIAL 14024).
