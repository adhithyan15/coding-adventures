# علاوہ (alāvā) — besides; apart from (کے علاوہ)

## You'll want to know: علاوہ
<!-- hl-knowledge: introduces=[UR-LEX-C359-BAVUJUD359-02]; assesses=[] -->

**علاوہ** — *alāvā* — "besides; apart from (کے علاوہ)".

> اس کے علاوہ کوئی راستہ نہیں ہے۔
>
> *is ke alāvā koī rāstā nahīṅ hai.*
>
> Apart from this there is no way.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**علاوہ** (*alāvā*) is usually traced, through Persian, to Arabic *ʿalāwa*, "an addition".

## What you've built
