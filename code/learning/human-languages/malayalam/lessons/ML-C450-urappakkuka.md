# ഉറപ്പാക്കുക (uṟappākkuka) — to ensure; to make sure

## You'll want to know: ഉറപ്പാക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C450-SAMRAKSANAM450-02]; assesses=[] -->

**ഉറപ്പാക്കുക** — *uṟappākkuka* — "to ensure; to make sure".

> എല്ലാ കുട്ടികൾക്കും ഭക്ഷണം കിട്ടി എന്ന് അധ്യാപകൻ ഉറപ്പാക്കി.
>
> *ellā kuṭṭikaḷkkuṁ bhakṣaṇaṁ kiṭṭi ennŭ adhyāpakan uṟappākki.*
>
> The teacher made sure that all the children got food.

Past: ഉറപ്പാക്കി, *uṟappākki*.

Built on ഉറപ്പ്, firmness, certainty.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ഉറപ്പാക്കുക** (*uṟappākkuka*) is a native Malayalam compound: ഉറപ്പ്, "firmness, assurance" (DEDR 721), and ആക്കുക, "to make" (DEDR 333): to make a thing firm.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
