French, chapter 462: L'orage gronde.
5 lessons. All 5 can be done entirely by ear.


Lesson 1 of 5.
orageux — stormy, thundery.

Warm-up.
[pause 2 seconds]
Before the new one: say the French for the bright spell, then the French for to clear.

You'll want to know: orageux.
orageux — "stormy, thundery".
Le temps est orageux depuis ce matin. The weather has been thundery since this morning.
Feminine orageuse. Figurative: une discussion orageuse.

The word, taken apart.
orageux is built on orage 'storm' (EtymDB lists it), from Old French ore 'wind', which goes back to Latin aura 'breeze'.

Lesson 3 of 5.
la grêle — the hail.

Warm-up.
[pause 2 seconds]
Before the new one: say the French for stormy, then the French for the lightning.

You'll want to know: la grêle.
la grêle — "the hail".
La grêle a abîmé les voitures dans la rue. The hail damaged the cars in the street.
Il grêle — it is hailing; un grêlon — a hailstone.

The word, taken apart.
grêle 'hail' is built on grêler 'to hail', which is usually traced to a Frankish verb; the origin is not settled. It is not the same word as the adjective grêle 'thin'.
