# Chapter 1 — recap

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MR-LEX-NAMASKAR-01, MR-LEX-DHANYAVAD-01, MR-LEX-HO-01, MR-LEX-BARAM-01, MR-LEX-NAHI-01, MR-PHRASE-YETO-YETE-01] -->

| Marathi | | Meaning |
|---|---|---|
| **नमस्कार** | *namaskār* | hello / goodbye |
| **धन्यवाद** | *dhanyavād* | thank you |
| **हो** | *ho* | yes |
| **नाही** | *nāhī* | no |
| **बरं** | *baraṃ* | okay / fine |
| **येतो / येते** | *yeto / yete* | "I'll be going" (m./f.) |

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[MR-LEX-NAMASKAR-01, MR-LEX-DHANYAVAD-01, MR-LEX-HO-01, MR-LEX-BARAM-01, MR-LEX-NAHI-01, MR-PHRASE-YETO-YETE-01] -->

- It prefers **namaskār** as the everyday greeting (Hindi leans on *namaste*).
- It keeps **three** genders — masculine, feminine, neuter — where Hindi kept
  two.
- It marks **gender on the verb**, even in the present: *yeto* (m.) / *yete*
  (f.).
- It has an **extra letter, ळ** (retroflex *ḷ*), shared with the Dravidian
  south and absent from Hindi.

Shared with Hindi/Sanskrit: the Devanagari script, the negative *nā-* (← PIE
*\*ne*, English *no*), and much formal vocabulary (*dhanyavād*).
