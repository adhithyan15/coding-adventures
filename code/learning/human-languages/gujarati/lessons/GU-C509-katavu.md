## You'll want to know: કટાવું
<!-- hl-knowledge: introduces=[GU-LEX-C509-DHAMAN509-05]; assesses=[] -->

**કટાવું** — *kaṭāvũ* — "to rust".

> વરસાદમાં બધાં ઓજારો કટાઈ ગયાં.
>
> *varsādmā̃ badhā̃ ojāro kaṭāī gayā̃.*
>
> All the tools rusted in the rain.

Past (it …): તે છરી કટાઈ ગઈ, *te charī kaṭāī gaī*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**કટાવું** (*kaṭāvũ*) is built on **કાટ**, "rust", which CDIAL files under Sanskrit *kiṭṭa*, "dross" (CDIAL 3156). It is intransitive: **છરી કટાઈ ગઈ**.
