## You'll want to know: پیچیدہ
<!-- hl-knowledge: introduces=[UR-LEX-C529-JHAMELA529-04]; assesses=[] -->

**پیچیدہ** — *pechīdā* — "complicated".

> اگر سوال پیچیدہ ہے تو استاد سے پوچھیے۔
>
> *agar savāl pechīdā hai to ustād se pūchhiye.*
>
> If the question is complicated, ask the teacher.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**پیچیدہ** (*pechīdā*) is usually traced to Persian *pēchīda*, "twisted", built on *pēch*, "a twist, a coil".
