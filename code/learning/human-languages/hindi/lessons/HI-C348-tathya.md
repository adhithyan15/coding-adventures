## You'll want to know: तथ्य
<!-- hl-knowledge: introduces=[HI-LEX-C348-PRAMAN348-03]; assesses=[] -->

**तथ्य** — *tathya* — "a fact".

> यह राय नहीं, तथ्य है।
>
> *yah rāy nahīṃ, tathya hai.*
>
> This is not an opinion; it is a fact.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**तथ्य** (*tathya*) is a tatsama, borrowed from Sanskrit *tathya*, "true; the truth" (Monier-Williams).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
