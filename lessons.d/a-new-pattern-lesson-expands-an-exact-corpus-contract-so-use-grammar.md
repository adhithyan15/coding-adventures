# A new pattern lesson expands an exact corpus contract, so use grammar for a local composition rule

The first-person future slice labelled its time-plus-action composition lesson
as `type: pattern`. Focused track tests passed, but the full suite pins the
complete list of canonical pattern lessons and rejected the extra entry. In
this corpus, `pattern` is not a prose synonym for any reusable construction;
it is a narrow cross-track contract.

Use `type: grammar` for a language-local composition rule unless the change is
deliberately extending the canonical pattern inventory and its consumers.
Run the full package suite when adding a lesson type that a focused track test
does not enumerate.
