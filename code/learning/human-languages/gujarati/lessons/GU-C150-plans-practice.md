## The exchange: sure, planned, possible
<!-- hl-knowledge: introduces=[]; assesses=[GU-GRAMMAR-C150-VAANO-01, GU-GRAMMAR-C150-VAANO-Q-01, GU-GRAMMAR-C150-VAANO-NEG-01, GU-LEX-C150-FUT150-01, GU-GRAMMAR-C149-JAISH-01, GU-GRAMMAR-C149-ISHUN-01] -->

> **— તમે આવતીકાલે શું કરવાના છો?**
> **— હું બજાર જવાની છું. તમે?**
> **— હું ઘરે રહેવાનો છું. હું બજાર નથી જવાનો.**
> **— કદાચ મારી બહેન આવશે.**
> **— તો સાંજે આપણે ચા પીશું.**

[PAUSE 1s]
- [YOU SAY: the exchange aloud, taking each part in turn]
- [YOU SAY: which line is a plan, which is a guess, and which is a promise]

**જવાની છું** and **રહેવાનો છું** are plans already made. **કદાચ … આવશે** is a
guess. **પીશું** is a plain future, close to a promise.
