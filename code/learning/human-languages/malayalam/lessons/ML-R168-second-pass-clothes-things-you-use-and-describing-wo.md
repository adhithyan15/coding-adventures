[PAUSE 3s] Aviyal? (**അവിയൽ**, *aviyal*.) A pappadam? (**പപ്പടം**, *pappaṭaṁ*.) Hot? (**ചൂടുള്ള**, *cūṭuḷḷa*.) Cold? (**തണുപ്പുള്ള**, *taṇuppuḷḷa*.) Long? (**നീളമുള്ള**, *nīḷamuḷḷa*.) Clean? (**വൃത്തിയുള്ള**, *vṛttiyuḷḷa*.) Sweet? (**മധുരമുള്ള**, *madhuramuḷḷa*.) Bitter? (**കയ്പുള്ള**, *kaypuḷḷa*.) Spicy? (**എരിവുള്ള**, *erivuḷḷa*.) Sour? (**പുളിയുള്ള**, *puḷiyuḷḷa*.) Heavy? (**ഭാരമുള്ള**, *bhāramuḷḷa*.) Fast? (**വേഗമുള്ള**, *vēgamuḷḷa*.) Thick? (**കട്ടിയുള്ള**, *kaṭṭiyuḷḷa*.) Soft? (**മൃദുവായ**, *mṛduvāya*.) Hard? (**കഠിനമായ**, *kaṭhinamāya*.) Wet? (**നനവുള്ള**, *nanavuḷḷa*.) Dry? (**ഉണങ്ങിയ**, *uṇaṅṅiya*.) Dark? (**ഇരുണ്ട**, *iruṇṭa*.) Clear? (**തെളിഞ്ഞ**, *teḷiñña*.) Deep? (**ആഴമുള്ള**, *āḻamuḷḷa*.) Wide? (**വീതിയുള്ള**, *vītiyuḷḷa*.) Narrow? (**ഇടുങ്ങിയ**, *iṭuṅṅiya*.) Low? (**താഴ്ന്ന**, *tāḻnna*.) Ripe? (**പഴുത്ത**, *paḻutta*.) Brave? (**ധൈര്യമുള്ള**, *dhairyamuḷḷa*.)
