## You'll want to know: からて

**からて** — *karate* — "karate".

> **からての しあいで かちました。** — *karate no shiai de kachimashita* — "I won a karate match."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**からて** (*karate*) is a native Japanese compound (wago), inherited rather than borrowed from Chinese: *kara* and *te*, "hand". JMdict gives two spellings, one writing *kara* with the kanji for "empty" and one with the kanji for "China" (KANJIDIC2), so which *kara* it holds is not settled (JMdict, KANJIDIC2).
