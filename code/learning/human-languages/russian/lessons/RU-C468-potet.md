## You'll want to know: потеть
<!-- hl-knowledge: introduces=[RU-LEX-C468-ZHARA-04]; assesses=[] -->

**потеть** (*potét*) — "to sweat".

> В жару я сильно потею.
>
> *V zharú ya sílno potéyu.*
>
> In hot weather I sweat a lot.

Imperfective; perfective *вспотеть*. Present *потею, потеешь*. *Окна потеют* — the windows mist up.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*потеть* is built on *пот* 'sweat', which is inherited from Proto-Slavic *potŭ* 'sweat' (EtymDB); EtymDB lists *потеть* itself without a source.
