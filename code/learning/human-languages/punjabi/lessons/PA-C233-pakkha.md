## You'll want to know: ਪੱਖਾ
<!-- hl-knowledge: introduces=[PA-LEX-C233-DIN233-05]; assesses=[] -->

**ਪੱਖਾ** — *pakkhā* — "a fan".

> ਗਰਮੀ ਵਿੱਚ ਅਸੀਂ ਪੱਖਾ ਚਲਾਉਂਦੇ ਹਾਂ।
>
> *garmī vich asīṁ pakkhā chalāunde hāṁ.*
>
> In the hot season we run the fan.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ਪੱਖਾ** (*pakkhā*) is inherited from Sanskrit *pakṣa*, "wing, feather"; CDIAL lists Punjabi *pakkhā*, "fan" (CDIAL 7627).
