## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**caisse** ← Old Provençal *caissa* ← Latin *capsa*, "a box" — borrowed from the south: an inherited form would begin with *ch-*. (EtymDB 2.1 records the Latin word.)
