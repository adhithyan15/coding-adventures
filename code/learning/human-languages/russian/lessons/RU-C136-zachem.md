## You'll want to know: зачем
<!-- hl-knowledge: introduces=[RU-LEX-C136-NEG136-05]; assesses=[] -->

**зачем** (*zachém*) — "what for". It asks about the purpose; **почему** asks about the cause. **Зачем?** — "What for?"
