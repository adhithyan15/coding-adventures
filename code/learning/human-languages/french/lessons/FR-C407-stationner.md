## You'll want to know: stationner
<!-- hl-knowledge: introduces=[FR-LEX-C407-STATIONNEMENT-02]; assesses=[] -->

**stationner** — "to park, to be parked".

> Les camions ne peuvent pas stationner ici.
>
> *Lorries cannot park here.*

More formal than *se garer*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*stationner* is built on *station*, a learned borrowing from Latin *statiō* 'a standing', from *stāre* 'to stand' (EtymDB).
