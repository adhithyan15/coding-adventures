# ಸ್ವಾವಲಂಬನೆ (svāvalambane) — self-reliance

## You'll want to know: ಸ್ವಾವಲಂಬನೆ
<!-- hl-knowledge: introduces=[KA-LEX-C403-SAMAJA403-02]; assesses=[] -->

**ಸ್ವಾವಲಂಬನೆ** — *svāvalambane* — "self-reliance".

> ಹಳ್ಳಿಯ ಹೆಂಗಸರು ಹೊಲಿಗೆ ಕಲಿತು ಸ್ವಾವಲಂಬನೆ ಸಾಧಿಸಿದರು.
>
> *haḷḷiya heṅgasaru holige kalitu svāvalambane sādhisidaru.*
>
> The village women learned tailoring and became self-reliant.

ಸ್ವ (self) + ಅವಲಂಬನೆ (leaning on).

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಸ್ವಾವಲಂಬನೆ** (*svāvalambane*) is built from Sanskrit *sva*, "self", and *avalambana*, "leaning on, depending upon" (Monier-Williams): depending on oneself.
