## You'll want to know: हिंदी में
<!-- hl-knowledge: introduces=[HI-LEX-C111-ASK-01]; assesses=[] -->

**हिंदी में** (*hindī meṁ*) — "in Hindi".

It is **में**, "in", the word you met on **रहना**, after the name of the language.
**अंग्रेज़ी में** — "in English".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

A way to name the language you want an answer in.
