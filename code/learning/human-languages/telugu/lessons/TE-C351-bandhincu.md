# బంధించు (bandhiñcu) — to capture; to lock up

## You'll want to know: బంధించు
<!-- hl-knowledge: introduces=[TE-LEX-C351-BANDI351-03]; assesses=[] -->

**బంధించు** — *bandhiñcu* — "to capture; to lock up".

> సైనికులు శత్రువులను ఒక గదిలో బంధించారు.
>
> *sainikulu śatruvulanu oka gadilō bandhiñcāru.*
>
> The soldiers locked the enemies up in a room.

Past (I …): బంధించాను, *bandhiñcānu*.

From బంధం, a bond: to bind someone.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**బంధించు** (*bandhiñcu*) is built on Sanskrit *bandha*, "a bond; custody" (CDIAL 9136), with the Telugu verb ending *-iñcu*.
