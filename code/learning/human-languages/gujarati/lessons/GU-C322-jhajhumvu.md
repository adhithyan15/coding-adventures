# ઝઝૂમવું (jhajhūmvũ) — to fight on; to struggle

## You'll want to know: ઝઝૂમવું
<!-- hl-knowledge: introduces=[GU-LEX-C322-HUMLO322-05]; assesses=[] -->

**ઝઝૂમવું** — *jhajhūmvũ* — "to fight on; to struggle".

> સૈનિકો છેલ્લી પળ સુધી ઝઝૂમ્યા.
>
> *sainiko chellī paḷ sudhī jhajhūmyā.*
>
> The soldiers fought on to the very last moment.

Past (he …): તે ખૂબ ઝઝૂમ્યો, *te khūb jhajhūmyo*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ઝઝૂમવું** (*jhajhūmvũ*) probably belongs with *jhujhvũ*, to fight, which CDIAL lists for Gujarati under Sanskrit *yúdhyatē*, "fights against" (CDIAL 10502); CDIAL does not list this longer form, so the link is not settled. It is to keep fighting against long odds: **છેલ્લી પળ સુધી ઝઝૂમ્યા**.
