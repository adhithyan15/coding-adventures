## You'll want to know: अपवाद
<!-- hl-knowledge: introduces=[MR-LEX-C378-ATI378-02]; assesses=[] -->

**अपवाद** — *apvād* — "an exception".

> हा नियम सगळ्यांना लागू आहे, कोणीही अपवाद नाही.
>
> *hā niyam sagaḷyānnā lāgū āhe, koṇīhī apvād nāhī.*
>
> This rule applies to everyone; nobody is an exception.

Masculine.

अपवादाने, as an exception; X चा अपवाद, the exception to X.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**अपवाद** (*apvād*) is a tatsama, taken from Sanskrit *apavāda*, "evil speaking", which grammarians also used for a special rule that sets a general one aside, an exception (Monier-Williams). The same head gave the inherited Marathi *avāī*, "rumour" (CDIAL 456).
