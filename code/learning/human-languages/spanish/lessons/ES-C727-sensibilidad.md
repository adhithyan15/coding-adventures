## You'll want to know: la sensibilidad
<!-- hl-knowledge: introduces=[ES-LEX-C727-SENSIBLE-02]; assesses=[] -->

**la sensibilidad** — "sensitivity".

> Tiene mucha sensibilidad para la música.
>
> *She has a great feel for music.*

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*sensibilidad* comes from Latin *sēnsibilitās* (EtymDB), built on *sēnsibilis*, from *sentīre* "to feel".
