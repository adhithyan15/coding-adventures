## You'll want to know: राग
<!-- hl-knowledge: introduces=[MW-LEX-C277-BHAJAN277-02]; assesses=[] -->

**राग** — *rāg* — "a melody".

> यो राग जूनो है।
>
> *yo rāg jūno hai.*
>
> This melody is old.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**राग** (*rāg*) is a tatsama, taken from Sanskrit *rāga*, which Monier-Williams gives as "a musical note, harmony, melody" (Monier-Williams).
