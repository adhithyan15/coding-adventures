# બેચેન (becen) — restless; uneasy

## You'll want to know: બેચેન
<!-- hl-knowledge: introduces=[GU-LEX-C454-UCAT454-03]; assesses=[] -->

**બેચેન** — *becen* — "restless; uneasy".

> પરિણામ પહેલાં મીરા બેચેન હતી.
>
> *pariṇām pahelā̃ Mīrā becen hatī.*
>
> Mira was uneasy before the result.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**બેચેન** (*becen*) is usually traced to Persian *bē-čain*, "without rest", from *bē*, "without", and *čain*, "rest, ease".
