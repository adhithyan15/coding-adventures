## You'll want to know: कालखंड
<!-- hl-knowledge: introduces=[MR-LEX-C307-ANT307-04]; assesses=[] -->

**कालखंड** — *kālkhaṇḍ* — "a period; an era".

> तो कालखंड देशासाठी फार कठीण होता.
>
> *to kālkhaṇḍ deśāsāṭhī phār kaṭhīṇ hotā.*
>
> That period was very hard for the country.

Masculine.

Built from काल, time, and खंड, a piece.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**कालखंड** (*kālkhaṇḍ*) is a learned compound built from Sanskrit *kāla*, 'time', and *khaṇḍa*, 'a piece, a section' (Monier-Williams).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
