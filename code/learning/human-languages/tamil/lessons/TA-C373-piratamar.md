# பிரதமர் (piratamar) — a prime minister

## You'll want to know: பிரதமர்
<!-- hl-knowledge: introduces=[TA-LEX-C373-ARACIYAL373-03]; assesses=[] -->

**பிரதமர்** — *piratamar* — "a prime minister".

> பிரதமர் இன்று நாட்டு மக்களிடம் பேசினார்.
>
> *piratamar iṉṟu nāṭṭu makkaḷiṭam pēciṉār.*
>
> The prime minister spoke to the nation today.

பிரதம, chief, first + -அர், the person.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**பிரதமர்** (*piratamar*) is built on Sanskrit *prathama*, "first" (CDIAL 8648), with the personal ending -அர்: the first minister.
