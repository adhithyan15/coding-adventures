## You'll want to know: l'inquiétude
<!-- hl-knowledge: introduces=[FR-LEX-C476-INQUIETUDE-01]; assesses=[] -->

**l'inquiétude** — "worry, anxiety".

> Elle attend le résultat avec inquiétude.
>
> *She is waiting for the result with worry.*

Built on *inquiet* "worried". Feminine: *une inquiétude*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*l'inquiétude* is a learned borrowing from Latin *inquiētūdō* "restlessness" (EtymDB), built on *quiēs* "rest" with the negative *in-* (Lewis & Short).
