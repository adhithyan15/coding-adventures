## You'll want to know: لكم
<!-- hl-knowledge: introduces=[AR-LEX-C548-HALABA548-05]; assesses=[] -->

**لكم** — *lakama* — "to punch".

> لكم الملاكم خصمه.
>
> *lakama al-mulākim khaṣmahu.*
>
> The boxer punched his opponent.

Present: يلكم, *yalkum*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**لكم** (*lakama*) is built on the native Arabic root *l-k-m*, "to strike with the fist" (Lane). Lane gives lakma as a blow with the fist; mulākama, boxing, is from the same root.
