## You'll want to know: le gréviste
<!-- hl-knowledge: introduces=[FR-LEX-C358-GREVE-03]; assesses=[] -->

**le gréviste** — "the striker".

> Les grévistes demandent de meilleurs salaires.
>
> *The strikers are asking for better wages.*

The same form for a man or a woman.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*gréviste* is built from *grève* "strike" and *-iste*. *grève* first meant a sandy shore; its origin is not settled.
