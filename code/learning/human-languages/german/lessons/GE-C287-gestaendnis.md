## You'll want to know: das Geständnis
<!-- hl-knowledge: introduces=[GE-LEX-C287-GEFAENGNIS-02]; assesses=[] -->

**das Geständnis** — "the confession".

> Sein Geständnis überraschte alle.
>
> *His confession surprised everyone.*

Plural: *die Geständnisse*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*Geständnis* is built on *gestehen* "to confess", from *stehen* "to stand" (EtymDB), with the noun ending *-nis*.
