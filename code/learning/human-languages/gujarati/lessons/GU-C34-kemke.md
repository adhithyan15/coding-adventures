# કેમકે (kemke) — because

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[GU-PERFORMANCE-KE-FRAMES-01, GU-CONCEPT-C03-KEM-01, GU-JOIN-KE-01] -->

[PAUSE 2s] One chapter back, the frames that report a thought. Three chapters
back — and also thirty chapters back — the word for **why**.

- [YOU RECALL: *vichārũ chhũ ke*, then *kem*]

Since the third chapter of this book you have been able to ask **કેમ?**. You
have never once been able to answer it.

## The word, taken apart
<!-- hl-knowledge: introduces=[GU-JOIN-KEMKE-01]; assesses=[GU-CONCEPT-C03-KEM-01, GU-JOIN-KE-01] -->

The answer is the question with the swallowing word stuck to it:

> **કેમ** (*why*) + **કે** (*that*) = **કેમકે** — **because**

Both halves are already yours; nothing here is new except the join. Gujarati
answers *why* by saying, in effect, "why-that" — and then the reason follows as
a whole sentence.

> *(what happened)* **કેમકે** *(the reason)*
