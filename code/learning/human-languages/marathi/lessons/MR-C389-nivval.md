## You'll want to know: निव्वळ
<!-- hl-knowledge: introduces=[MR-LEX-C389-PRAMANE389-04]; assesses=[] -->

**निव्वळ** — *nivvaḷ* — "purely; sheer".

> हा निव्वळ वेडेपणा आहे.
>
> *hā nivvaḷ veḍepṇā āhe.*
>
> This is sheer madness.

Before a noun, sheer: निव्वळ खोटं, an outright lie.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**निव्वळ** (*nivvaḷ*) is a Marathi word whose origin is not settled.
