# ব্যবস্থা (bæbôsthā) — an arrangement; a system

## You'll want to know: ব্যবস্থা
<!-- hl-knowledge: introduces=[BN-LEX-C381-BYOBOSTHA381-01]; assesses=[] -->

**ব্যবস্থা** — *bæbôsthā* — "an arrangement; a system".

> তুমি এলে থাকার ব্যবস্থা আমি করব।
>
> *tumi ele thākār bæbôsthā āmi kôrbô.*
>
> If you come, I'll arrange a place for you to stay.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ব্যবস্থা** (*bæbôsthā*) is Sanskrit *vyavasthā*, an arrangement or settled order (Monier-Williams). ব্যবস্থা করা is to arrange something.
