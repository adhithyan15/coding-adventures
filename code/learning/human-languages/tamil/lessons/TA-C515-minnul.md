# மின்னூல் (miṉṉūl) — an e-book

## You'll want to know: மின்னூல்
<!-- hl-knowledge: introduces=[TA-LEX-C515-KANINI515-05]; assesses=[] -->

**மின்னூல்** — *miṉṉūl* — "an e-book".

> நான் இப்போது மின்னூல்களைக் கைப்பேசியில் படிக்கிறேன்.
>
> *nāṉ ippōtu miṉṉūlkaḷaik kaippēciyil paṭikkiṟēṉ.*
>
> These days I read e-books on my phone.

Plural: மின்னூல்கள், *miṉṉūlkaḷ*.

மின் "electric" + நூல் "a book" (a literary word for புத்தகம்).

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**மின்னூல்** (*miṉṉūl*) is built from native parts: மின் (*miṉ*), "a flash, lightning", now "electric" (DEDR 4876), and நூல் (*nūl*), "a book"; after ன் the ந of நூல் is written ன: மின் + நூல் = மின்னூல்.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
