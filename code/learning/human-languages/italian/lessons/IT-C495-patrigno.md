## You'll want to know: il patrigno
<!-- hl-knowledge: introduces=[IT-LEX-C495-FAMIGLIE-03]; assesses=[] -->

**il patrigno** — "stepfather".

> Il mio patrigno è un uomo gentile.
>
> *My stepfather is a kind man.*

Built on Latin *pater* "father".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*patrigno* is usually traced to Late Latin *patrignus*, built on *pater* "father" (Lewis & Short).
