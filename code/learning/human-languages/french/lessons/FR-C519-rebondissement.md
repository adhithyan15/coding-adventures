## You'll want to know: le rebondissement
<!-- hl-knowledge: introduces=[FR-LEX-C519-ROMAN-04]; assesses=[] -->

**le rebondissement** — "twist, new development".

> Le roman est plein de rebondissements.
>
> *The novel is full of twists.*

Built on *rebondir* "to bounce back".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*le rebondissement* is built on *rebondir* "to bounce back", from *bondir* "to leap", which first meant "to resound" and goes back to Vulgar Latin *bombitīre*, from Latin *bombus* "a booming sound".
