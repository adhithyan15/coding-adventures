# ಗ್ರಾಮೀಣ (grāmīṇa) — rural

## You'll want to know: ಗ್ರಾಮೀಣ
<!-- hl-knowledge: introduces=[KA-LEX-C399-BADATANA399-05]; assesses=[] -->

**ಗ್ರಾಮೀಣ** — *grāmīṇa* — "rural".

> ಗ್ರಾಮೀಣ ಪ್ರದೇಶಗಳಲ್ಲಿ ಆಸ್ಪತ್ರೆಗಳು ಕಡಿಮೆ.
>
> *grāmīṇa pradēśagaḷalli āspatregaḷu kaḍime.*
>
> There are few hospitals in rural areas.

ಗ್ರಾಮ, a village.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಗ್ರಾಮೀಣ** (*grāmīṇa*) is borrowed from Sanskrit *grāmīṇa*, "of a village, rustic" (Monier-Williams), from *grāma*, "a village".
