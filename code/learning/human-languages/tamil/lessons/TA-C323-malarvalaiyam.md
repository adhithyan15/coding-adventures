# மலர்வளையம் (malarvaḷaiyam) — a wreath

## You'll want to know: மலர்வளையம்
<!-- hl-knowledge: introduces=[TA-LEX-C323-IRUTHI323-03]; assesses=[] -->

**மலர்வளையம்** — *malarvaḷaiyam* — "a wreath".

> நண்பர்கள் ஒரு மலர்வளையம் வைத்தார்கள்.
>
> *naṇparkaḷ oru malarvaḷaiyam vaittārkaḷ.*
>
> Friends laid a wreath.

மலர்வளையம் வை, to lay a wreath.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**மலர்வளையம்** (*malarvaḷaiyam*) is a Tamil compound built from மலர், "flower" (DEDR 4739), and வளையம், "ring, circle" (DEDR 5313).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
