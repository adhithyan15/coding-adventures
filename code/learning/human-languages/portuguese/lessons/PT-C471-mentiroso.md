## You'll want to know: mentiroso
<!-- hl-knowledge: introduces=[PT-LEX-C471-MENTIRA-04]; assesses=[] -->

**mentiroso** — "liar; lying".

> Ninguém acredita nele, porque é um mentiroso.
>
> *Nobody believes him, because he is a liar.*

Built on *mentir* "to lie"; also an adjective: *uma resposta mentirosa*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*mentiroso* is inherited from Old Portuguese *mentiroso*, built on *mentir* "to lie" (EtymDB), from Latin *mentīrī*.
