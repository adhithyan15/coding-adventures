# Changelog — CodingAdventures.HistoricalWeb.FSharp

## [0.1.0] — 2026-11-28

### Added

- F# HTTP/0.9 request encoding/parsing and ASCII response decoding over spans.
- HTML Tags 1992 scanner with UTF-16 validation, CRLF normalization, archived
  entity decoding, implied ends, raw text, and deterministic recovery.
- Immutable flat document and attribute arenas with indexed links and typed
  source-offset diagnostics.
- Documentation comparing the archive with XML and modern WHATWG parsing.
