# ચીકણું (cīkṇũ) — fussy; sticky

## You'll want to know: ચીકણું
<!-- hl-knowledge: introduces=[GU-LEX-C465-SAKHAT465-02]; assesses=[] -->

**ચીકણું** — *cīkṇũ* — "fussy; sticky".

> મારી સાસુ ઘરકામમાં ઘણી ચીકણી છે.
>
> *mārī sāsu gharkāmmā̃ ghaṇī cīkṇī che.*
>
> My mother-in-law is very fussy about the housework.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ચીકણું** (*cīkṇũ*) goes back to Sanskrit *cikkaṇa*, "slippery, unctuous"; CDIAL lists the Gujarati word, "sticky" (CDIAL 4782), and Gujarati also uses it for a fussy person.
