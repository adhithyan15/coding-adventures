## You'll want to know: ಭ್ರಮೆ
<!-- hl-knowledge: introduces=[KA-LEX-C382-VASTAVA382-03]; assesses=[] -->

**ಭ್ರಮೆ** — *bhrame* — "an illusion".

> ನೀರು ಇದೆ ಅನ್ನುವುದು ಬರೀ ಭ್ರಮೆ ಆಗಿತ್ತು.
>
> *nīru ide annuvudu barī bhrame āgittu.*
>
> That there was water was only an illusion.

ಭ್ರಮೆಯಲ್ಲಿ ಇರು, to be under an illusion.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಭ್ರಮೆ** (*bhrame*) is borrowed from Sanskrit *bhrama*, "wandering about", and so "confusion, error" (CDIAL 9646).
