## Fixed — Kannada root slugs name one etymon each

- **KA-C140-pada** moves from `sanskrit-pada` to `sanskrit-pada-foot`. *Pāda* "foot" is CDIAL 8056; `sanskrit-pada` is *padá* "footstep, word" (CDIAL 7747), which KA-C270-pada keeps.
- **KA-C52-garland** moves from `sanskrit-mala` to `sanskrit-mala-garland` (*mālā*, CDIAL 10092). Bare `sanskrit-mala` also named *mala* "dirt".
- **KA-C226-kale** and **KA-C305-kalavida** move from `sanskrit-kala` to `sanskrit-kala-art` (*kalā*, CDIAL 2927), the slug every other track's "art" lessons use. No lesson uses bare `sanskrit-kala` any more.
