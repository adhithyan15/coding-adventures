## You'll want to know: именинник
<!-- hl-knowledge: introduces=[RU-LEX-C317-IMENINNIK-01]; assesses=[] -->

**именинник** (*imenínnik*) — "the birthday boy, the person celebrating".

> Именинник получил много подарков.
>
> *Imenínnik poluchíl mnógo podárkov.*
>
> The birthday boy got a lot of presents.

A girl or woman is *именинница*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*именинник* is built on *именины* "a name day", from *имя* "name", stem *имен-*, which goes back to the PIE word for a name (EtymDB), the source of Latin *nōmen* as well.
