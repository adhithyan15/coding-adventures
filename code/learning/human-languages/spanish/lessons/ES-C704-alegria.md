## You'll want to know: la alegría
<!-- hl-knowledge: introduces=[ES-LEX-C704-ALEGRIA-01]; assesses=[] -->

**la alegría** — "joy, happiness".

> Tu visita es una alegría.
>
> *Your visit is a joy.*

*¡Qué alegría!* — How lovely! It is built on *alegre*, cheerful.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*alegría* is built on *alegre* "cheerful", which is usually traced to Latin *alacer* "lively, brisk" through a spoken form *alecrem*; English *alacrity* comes from the same Latin word.
