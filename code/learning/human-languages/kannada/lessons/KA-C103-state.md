## You'll want to know: ರಾಜ್ಯ
<!-- hl-knowledge: introduces=[KA-LEX-C103-HOME-05]; assesses=[] -->

**ರಾಜ್ಯ** (*rājya*) — "state". **ಕರ್ನಾಟಕ ರಾಜ್ಯ** (*karnāṭaka rājya*) is the state
where Kannada is spoken.

## What you've built
