# বিজ্ঞপ্তি (bigyôpti) — an official notice; an announcement

## You'll want to know: বিজ্ঞপ্তি
<!-- hl-knowledge: introduces=[BN-LEX-C300-PATHOK300-03]; assesses=[] -->

**বিজ্ঞপ্তি** — *bigyôpti* — "an official notice; an announcement".

> স্টেশনে একটা বিজ্ঞপ্তি ছিল যে ট্রেন দেরিতে আসবে।
>
> *sṭeshône ekṭā bigyôpti chhilô je ṭren derite āsbe.*
>
> There was a notice at the station saying the train would be late.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**বিজ্ঞপ্তি** (*bigyôpti*) is Sanskrit *vijñapti*, 'information, a report' (Monier-Williams). Its জ্ঞ is read *gy*, as in **জ্ঞান**.
