# സത്യാവസ്ഥ (satyāvastha) — the real facts; the actual truth

## You'll want to know: സത്യാവസ്ഥ
<!-- hl-knowledge: introduces=[ML-LEX-C352-PRESS352-03]; assesses=[] -->

**സത്യാവസ്ഥ** — *satyāvastha* — "the real facts; the actual truth".

> ലേഖകൻ സംഭവത്തിന്റെ സത്യാവസ്ഥ കണ്ടെത്തി.
>
> *lēkhakan sambhavattinṟe satyāvastha kaṇṭetti.*
>
> The correspondent found out the real facts of the incident.

Literally the state of the truth: സത്യം, truth, + അവസ്ഥ, a state.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**സത്യാവസ്ഥ** (*satyāvastha*) is built from two Sanskrit words: *satya*, "true; the truth" (CDIAL 13112), and *avasthā*, "a state, a condition" (CDIAL 872). It names how things really stand, as against what people say.
