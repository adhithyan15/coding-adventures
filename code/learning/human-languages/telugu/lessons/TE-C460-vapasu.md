# వాపసు (vāpasu) — a refund; a return

## You'll want to know: వాపసు
<!-- hl-knowledge: introduces=[TE-LEX-C460-ASAUKARYAM460-04]; assesses=[] -->

**వాపసు** — *vāpasu* — "a refund; a return".

> రద్దు చేసిన టిక్కెట్టుకు సగం డబ్బు వాపసు వచ్చింది.
>
> *raddu cēsina ṭikkeṭṭuku sagaṁ ḍabbu vāpasu vaccindi.*
>
> For the cancelled ticket half the money came back as a refund.

వాపసు ఇచ్చు, to give back; వాపసు వచ్చు, to come back.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**వాపసు** (*vāpasu*) is a loan from Persian *vāpas*, "back, returned", which reached Telugu through Hindustani.
