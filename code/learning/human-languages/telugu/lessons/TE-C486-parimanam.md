# పరిమాణం (parimāṇaṁ) — size; quantity

## You'll want to know: పరిమాణం
<!-- hl-knowledge: introduces=[TE-LEX-C486-KOLATA486-02]; assesses=[] -->

**పరిమాణం** — *parimāṇaṁ* — "size; quantity".

> ఆ పెట్టె పరిమాణం చాలా పెద్దది.
>
> *ā peṭṭe parimāṇaṁ cālā peddadi.*
>
> That box is very big in size.

Size of a thing, or an amount: నీటి పరిమాణం, the quantity of water.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**పరిమాణం** (*parimāṇaṁ*) is borrowed from Sanskrit *parimāṇa*, "measure, size, quantity" (Monier-Williams), from *pari-mā*, "to measure out".
