# நெடுங்காலம் (neṭuṅkālam) — a long time; ages

## Warm-up

[PAUSE 2s] Before the new one: say the Tamil for a dynasty, then the Tamil for to settle.

## You'll want to know: நெடுங்காலம்
<!-- hl-knowledge: introduces=[TA-LEX-C327-MUNNOR327-04]; assesses=[] -->

**நெடுங்காலம்** — *neṭuṅkālam* — "a long time; ages".

> இந்தக் கோயில் நெடுங்காலமாக இங்கே இருக்கிறது.
>
> *intak kōyil neṭuṅkālamāka iṅkē irukkiṟatu.*
>
> This temple has been here for a long time.

With -ஆக, for a long time: நெடுங்காலமாக.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**நெடுங்காலம்** (*neṭuṅkālam*) joins native நெடு, "long" (DEDR 3738), with காலம், "time", borrowed from Sanskrit *kāla* (CDIAL 3084).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
