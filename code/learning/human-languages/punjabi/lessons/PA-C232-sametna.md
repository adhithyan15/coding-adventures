# ਸਮੇਟਣਾ (sameṭṇā) — to gather up; to roll up

## You'll want to know: ਸਮੇਟਣਾ
<!-- hl-knowledge: introduces=[PA-LEX-C232-DIN232-02]; assesses=[] -->

**ਸਮੇਟਣਾ** — *sameṭṇā* — "to gather up; to roll up".

> ਸਵੇਰੇ ਮੈਂ ਰਜਾਈ ਸਮੇਟਦਾ ਹਾਂ।
>
> *savere maiṁ rajāī sameṭdā hāṁ.*
>
> In the morning I roll up the quilt.

Past (I …): ਮੈਂ ਕੱਪੜੇ ਸਮੇਟੇ, *maiṁ kappṛe sameṭe*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ਸਮੇਟਣਾ** (*sameṭṇā*) is inherited from Sanskrit *saṁvēṣṭayati*, "wraps up"; CDIAL lists Punjabi *sameṭṇā*, "to roll up" (CDIAL 13026).
