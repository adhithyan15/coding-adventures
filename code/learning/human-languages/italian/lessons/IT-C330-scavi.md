## You'll want to know: gli scavi
<!-- hl-knowledge: introduces=[IT-LEX-C330-SCAVI-04]; assesses=[] -->

**gli scavi** — "the excavations, the dig".

> Negli scavi hanno trovato monete antiche.
>
> *At the dig they found ancient coins.*

Singular *lo scavo*, built on *scavare*, ‘to dig’.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*scavi* is built on *scavare* "to dig out", from Late Latin *excavāre* "to hollow out", built on *cavus* "hollow" (Lewis & Short).
