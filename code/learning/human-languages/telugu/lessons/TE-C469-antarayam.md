# అంతరాయం (antarāyaṁ) — a disruption; an interruption

## You'll want to know: అంతరాయం
<!-- hl-knowledge: introduces=[TE-LEX-C469-SAMME469-03]; assesses=[] -->

**అంతరాయం** — *antarāyaṁ* — "a disruption; an interruption".

> కరెంటు సరఫరాలో అంతరాయం కలిగింది.
>
> *kareṇṭu sarapharālō antarāyaṁ kaligindi.*
>
> There was a disruption in the power supply.

అంతరాయం కలుగు, a disruption occurs. The TV says it when a programme breaks off.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**అంతరాయం** (*antarāyaṁ*) is borrowed from Sanskrit *antarāya*, "an intervention, an obstacle", from *antar-i*, "to come between" (Monier-Williams).
