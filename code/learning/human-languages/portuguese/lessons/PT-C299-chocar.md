## You'll want to know: chocar
<!-- hl-knowledge: introduces=[PT-LEX-C299-ACIDENTE-03]; assesses=[] -->

**chocar** — "to crash, to run into; to shock".

> O autocarro chocou contra um muro.
>
> *The bus crashed into a wall.*

*Chocar com* or *chocar contra*. Also ‘to shock’: *a notícia chocou o país*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*chocar* is built on *choque* "an impact" (EtymDB), from French *choc*, with the verb ending *-ar*.
