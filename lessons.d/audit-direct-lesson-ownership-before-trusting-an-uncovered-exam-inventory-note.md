# Audit direct lesson ownership before trusting an uncovered exam inventory note

The Sanskrit A1 inventory said that meals and restaurants were uncovered
because the track taught foodstuffs but no meal or eating place. A direct
owner search showed that later additive vocabulary chapters had already added
`bhojanam` (meal) and `bhojanālayaḥ` (restaurant), while the A1 mock sources
already used the untaught productive request `kṛpayā mahyaṁ ... dadātu`.

Treat an uncovered inventory note as a historical lead, not current corpus
truth. Before opening or scoping a teaching issue, search the current lesson
owners and mock sources for every claimed missing exponent. Separate atoms
that already exist from the functional composition that is genuinely absent,
then write the issue around that exact gap. This prevents redundant vocabulary
and makes a gentle bridge reuse the learner's real prerequisites.
