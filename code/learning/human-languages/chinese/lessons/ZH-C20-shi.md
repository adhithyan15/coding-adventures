# 十 — ten

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ZH-SCRIPT-NUM-SHI, ZH-LEX-NUM-JIU] -->

[PAUSE 2s] Write 十, then say nine.

## Sounds you'll need
<!-- hl-knowledge: introduces=[ZH-LEX-NUM-SHI]; assesses=[ZH-TONE-LEXICAL, ZH-LEX-NUM-QI, ZH-LEX-NUM-BA] -->

**十** *shí* means **ten**.

**shí** is **second tone**, the rise — the pitch starts in the middle and goes
up, as if asking. It is the first number in the whole run of ten to use it.

The **sh** curls the tongue back, further than an English *sh*. Keep the tip
high and behind the ridge.

Say the whole run once: **yī èr sān sì wǔ liù qī bā jiǔ shí**. Level, fall,
level, fall, dip, fall, level, level, dip, rise.

## What you've built — the last of the ten
<!-- hl-knowledge: introduces=[]; assesses=[ZH-LEX-NUM-SHI, ZH-LEX-NUM-JIU] -->

Ten is not simply the tenth word. It is the last one this book needs before
**every number up to ninety-nine falls out of the ten it already has** — and the
next chapter spends it.
