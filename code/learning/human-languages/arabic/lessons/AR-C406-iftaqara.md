# افتقر (iftaqara) — to lack

## You'll want to know: افتقر
<!-- hl-knowledge: introduces=[AR-LEX-C406-TATALLUB406-04]; assesses=[] -->

**افتقر** — *iftaqara* — "to lack".

> تفتقر القرية إلى طبيب.
>
> *taftaqiru al-qarya ilā ṭabīb.*
>
> The village lacks a doctor.

Present: يفتقر, *yaftaqir*.

It takes إلى: افتقر إلى ….

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**افتقر** (*iftaqara*) is built on the native Arabic root *f-q-r*, "to be needy, poor" (Lane). It is Form VIII, to become needy of a thing: to lack it.
