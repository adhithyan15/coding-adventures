# A familiar message, a fresh first attempt

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-A1-MESSAGE-TIMED-01] -->

Close the earlier message pages. Put out a blank page and a three-minute
timer. This is a fresh use of already-taught words: there is no model,
romanization, word bank, dictionary, or copyable answer during the clock.

## Writing — independent timed return
<!-- hl-knowledge: introduces=[]; assesses=[PA-A1-MESSAGE-TIMED-01] -->
<!-- hl-writing-stage: timed-assessment-production -->

As Manan, write Aman a **30–40-word** Gurmukhi message. Greet Aman and ask
how he is. Say that you like reading Punjabi and that you are well. Suggest
meeting again and close in a fitting tone. Add only familiar words if you
need them to reach the band; choose and order your own sentences.

Start the timer and stop after three minutes, even if the message is not
finished. Record the word count and elapsed time on a separate line. Keep
this first attempt unchanged for the next short lesson.

## Guided Practice — observe, do not repair yet
<!-- hl-knowledge: introduces=[]; assesses=[PA-A1-MESSAGE-TIMED-01] -->

Without reopening an earlier page, note whether Aman is clearly the reader,
the reading purpose is present, and the message is within 30–40 words. Do
not rewrite the clocked page now.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[PA-A1-MESSAGE-TIMED-01] -->

This short return is not a complete A1 mock. The later two full papers and
human validation remain separate from this one timed message.
