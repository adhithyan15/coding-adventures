# ವರ್ಣಿಸು (varṇisu) — to describe vividly

## You'll want to know: ವರ್ಣಿಸು
<!-- hl-knowledge: introduces=[KA-LEX-C343-NIRUPANE343-02]; assesses=[] -->

**ವರ್ಣಿಸು** — *varṇisu* — "to describe vividly".

> ಅವಳು ಹಳ್ಳಿಯ ಜಾತ್ರೆಯನ್ನು ಸುಂದರವಾಗಿ ವರ್ಣಿಸಿದಳು.
>
> *avaḷu haḷḷiya jātreyannu sundaravāgi varṇisidaḷu.*
>
> She described the village fair beautifully.

Past (I …): ವರ್ಣಿಸಿದೆ, *varṇiside*.

ವಿವರಿಸು is to explain; ವರ್ಣಿಸು is to paint in words.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ವರ್ಣಿಸು** (*varṇisu*) is built on Sanskrit *varṇana*, "description" (CDIAL 11340), from *varṇa*, "colour", with the Kannada verb ending -*isu*.

## What you've built
