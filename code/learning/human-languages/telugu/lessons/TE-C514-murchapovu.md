# మూర్ఛపోవు (mūrchapōvu) — to faint

## You'll want to know: మూర్ఛపోవు
<!-- hl-knowledge: introduces=[TE-LEX-C514-NOPPI514-05]; assesses=[] -->

**మూర్ఛపోవు** — *mūrchapōvu* — "to faint".

> ఎండలో నిలబడి ఒక విద్యార్థి మూర్ఛపోయాడు.
>
> *eṇḍalō nilabaḍi oka vidyārthi mūrchapōyāḍu.*
>
> Standing in the sun, a student fainted.

Past (I …): మూర్ఛపోయాను, *mūrchapōyānu*.

మూర్ఛ, a faint or a fit, + పోవు, to go.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**మూర్ఛపోవు** (*mūrchapōvu*) is built from మూర్ఛ, from Sanskrit *mūrchā*, "fainting, stupor" (CDIAL 10242) and *pōvu*, "to go" (DEDR 4572).

## What you've built
