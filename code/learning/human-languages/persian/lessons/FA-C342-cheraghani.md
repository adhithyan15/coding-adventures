## You'll want to know: چراغانی
<!-- hl-knowledge: introduces=[FA-LEX-C342-TAZYIN-02]; assesses=[] -->

**چراغانی** (*cherâghâni*) — "festive lights, illuminations".

> خیابان ها برای جشن چراغانی بود.
>
> *Khiyâbân-hâ barâ-ye jashn cherâghâni bud.*
>
> The streets were lit up for the celebration.

From *cherâgh* "lamp": strings of lights for a festival.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*cherâghâni* is built on *cherâgh* "lamp", a Persian word, with the suffix *-âni*; EtymDB lists no entry.
