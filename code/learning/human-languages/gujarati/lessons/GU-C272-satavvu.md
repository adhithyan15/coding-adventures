# સતાવવું (satāvvũ) — to pester, to bother

## You'll want to know: સતાવવું
<!-- hl-knowledge: introduces=[GU-LEX-C272-PROMISE272-04]; assesses=[] -->

**સતાવવું** — *satāvvũ* — "to pester, to bother".

> **મારો ભાઈ મને નથી સતાવતો.** — *māro bhāī mane nathī satāvto* — "My brother does not bother me."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**સતાવવું** (*satāvvũ*) is a tadbhava. It comes from Sanskrit *saṁtāpayati*, "causes to be heated; torments"; CDIAL glosses the Gujarati verb "to tease, vex" (CDIAL 12886).
