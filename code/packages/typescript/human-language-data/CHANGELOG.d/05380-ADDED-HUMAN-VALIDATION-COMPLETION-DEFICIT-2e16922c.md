### Added

- Made human validation of timed assessment mocks first-class, migration-safe completion debt. Contracts may now declare a safe relative `humanValidation` evidence file per mock; declared files join the strict artifact audit, missing or dangling evidence becomes an ordered `human-validation/<language>/<level>` work item, and external capstones remain incomplete until their mocks carry the same evidence. Existing contracts stay loadable while this evidence is authored, and the five-minute lesson ceiling is unchanged.
