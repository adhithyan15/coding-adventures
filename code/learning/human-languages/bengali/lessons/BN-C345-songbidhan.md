## You'll want to know: সংবিধান
<!-- hl-knowledge: introduces=[BN-LEX-C345-SONGSOD345-02]; assesses=[] -->

**সংবিধান** — *sôngbidhān* — "a constitution".

> সংবিধান সব নাগরিককে সমান অধিকার দেয়।
>
> *sôngbidhān sôb nāgôrikke sômān ôdhikār dey.*
>
> The constitution gives every citizen equal rights.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**সংবিধান** (*sôngbidhān*) is Sanskrit *saṃvidhāna*, an arrangement (Monier-Williams). The sense 'a constitution', the arrangement a state is built on, is a modern coinage.
