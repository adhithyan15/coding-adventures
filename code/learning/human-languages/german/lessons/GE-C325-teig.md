## You'll want to know: der Teig
<!-- hl-knowledge: introduces=[GE-LEX-C325-TEIG-01]; assesses=[] -->

**der Teig** — "the dough, the batter".

> Der Teig muss eine Stunde ruhen.
>
> *The dough has to rest for an hour.*

Plural: *die Teige*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*Teig* is inherited from Old High German *teig*, from Proto-Germanic *daigaz* (EtymDB), the same source as English *dough*.
