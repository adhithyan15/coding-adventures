# അന്നുമുതൽ (annumutal) — ever since; from that day

## You'll want to know: അന്നുമുതൽ
<!-- hl-knowledge: introduces=[ML-LEX-C357-PINNITU357-04]; assesses=[] -->

**അന്നുമുതൽ** — *annumutal* — "ever since; from that day".

> അന്നുമുതൽ അവൾ രാവിലെ നടക്കുന്നു.
>
> *annumutal avaḷ rāvile naṭakkunnu.*
>
> Ever since that day she has walked in the mornings.

അന്ന്, that day, + മുതൽ, from: the time a change began.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**അന്നുമുതൽ** (*annumutal*) is native Dravidian: അന്ന് (*annŭ*), "on that day", and മുതൽ (*mutal*), "from, beginning with", which DEDR 4950 sets beside Tamil *mutal*, "beginning, first".
