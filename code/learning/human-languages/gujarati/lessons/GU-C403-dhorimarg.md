## You'll want to know: ધોરીમાર્ગ
<!-- hl-knowledge: introduces=[GU-LEX-C403-HIGHWAY403-01]; assesses=[] -->

**ધોરીમાર્ગ** — *dhorīmārg* — "a highway; a main road".

> આ ધોરીમાર્ગ પર ઘણી ટ્રકો ચાલે છે.
>
> *ā dhorīmārg par ghaṇī ṭrako cāle che.*
>
> Many trucks run on this highway.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ધોરીમાર્ગ** (*dhorīmārg*) is built from ધોરી, "main", which CDIAL lists under Sanskrit *dhaurēya*, "a beast of burden; foremost" (CDIAL 6884), and Sanskrit *mārga*, "a road": the road that carries the load.

## What you've built

One more word for getting around.
