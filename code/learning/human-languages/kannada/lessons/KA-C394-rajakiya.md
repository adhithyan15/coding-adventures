# ರಾಜಕೀಯ (rājakīya) — politics; political

## You'll want to know: ರಾಜಕೀಯ
<!-- hl-knowledge: introduces=[KA-LEX-C394-RAJAKIYA394-01]; assesses=[] -->

**ರಾಜಕೀಯ** — *rājakīya* — "politics; political".

> ನನ್ನ ಅಜ್ಜನಿಗೆ ರಾಜಕೀಯದಲ್ಲಿ ಆಸಕ್ತಿ ಇಲ್ಲ.
>
> *nanna ajjanige rājakīyadalli āsakti illa.*
>
> My grandfather has no interest in politics.

As an adjective: ರಾಜಕೀಯ ಸುದ್ದಿ, political news.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ರಾಜಕೀಯ** (*rājakīya*) is borrowed from Sanskrit *rājakīya*, "belonging to a king, royal" (Monier-Williams); Kannada uses it for politics.
