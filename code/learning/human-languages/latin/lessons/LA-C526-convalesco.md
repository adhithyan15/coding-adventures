## You'll want to know: convalēscō, convalēscere
<!-- hl-knowledge: introduces=[LA-LEX-C526-SANO-03]; assesses=[] -->

**convalēscō, convalēscere** — "to recover, get well".

> Post longum morbum avus convalēscit.
>
> *After a long illness grandfather is getting well.*

*convalēscō, convalēscere, convaluī*, built on *valeō* — to be well. English *convalesce*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**convalēscō** is built on *con-* and *valēscō*, the inceptive of *valeō* "to be well, strong" (Lewis & Short). English *convalesce* comes from it.
