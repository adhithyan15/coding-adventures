# Two turns: why, and because

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MR-JOIN-KAA-WHY, MR-GRAMMAR-QUESTION-KAA] -->

[PAUSE 5s] **का** at the end asks yes-or-no. **का** at the front asks why. Say
one of each before you go on.
