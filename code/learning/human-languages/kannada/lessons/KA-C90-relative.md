# ಸಂಬಂಧಿಕ (sambandhika) — a relative

## You'll want to know: ಸಂಬಂಧಿಕ
<!-- hl-knowledge: introduces=[KA-LEX-C90-KIN-03]; assesses=[] -->

**ಸಂಬಂಧಿಕ** (*sambandhika*) — "a relative", from **ಸಂಬಂಧ** (*sambandha*),
"connection, relationship".

**ಅವರು ನಮ್ಮ ಸಂಬಂಧಿಕರು** (*avaru namma sambandhikaru*) — "they are our relatives".

## What you've built

The word for everyone the family tree connects.
