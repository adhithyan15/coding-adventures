# Malayalam pre-A1 mock 2 — learner paper and examiner script

This is an independent parallel form, not a rehearsal copy of mock 1. Total
administration: 32 written minutes plus 8 speaking minutes. Remove all visible
models before writing begins.

## Reading — 10 minutes

1. **മലയാളം** — A Malayalam / B water / C school
2. **നന്ദി** — A thanks / B bus / C home
3. **അതെ** — A no / B yes / C name
4. **ഇല്ല** — A tea / B yes / C no
5. **കൊച്ചി** — A Kochi / B Malayalam / C Ravi
6. **കേരളം** — A water / B Kerala / C school
7. **സുഖമാണോ?** — A Are you well? / B What is your name? / C Where is the bus?
8. **എന്റെ പേര് രവി ആണ്.** — A My name is Ravi. / B I am from Ravi. / C Ravi is fine.
9. **എനിക്ക് സുഖമാണ്.** — A I am fine. / B I speak Malayalam. / C I want tea.
10. **സാരമില്ല.** — A It is all right. / B Thank you. / C Goodbye.
11. Form field **നഗരം: കൊച്ചി** — A city Kochi / B name Kochi / C language Kochi
12. Form field **ഭാഷ: മലയാളം** — A city Malayalam / B language Malayalam / C name Malayalam
13. **ഞാൻ മലയാളം സംസാരിക്കുന്നു.** — A The speaker speaks Malayalam. / B The speaker asks a name. / C The speaker wants water.
14. **വീണ്ടും കാണാം.** — A See you again. / B Please sit. / C No, thank you.

## Listening — 10 minutes

Read each line twice and pause eight seconds.

1. **മലയാളം**. A Malayalam / B tea / C bus
2. **നന്ദി**. A thanks / B home / C no
3. **അതെ**. A yes / B no / C name
4. **ഇല്ല**. A water / B no / C school
5. **കൊച്ചി**. A Kerala / B Kochi / C Malayalam
6. **കേരളം**. A Kerala / B Ravi / C water
7. **നമസ്കാരം.** A നമസ്കാരം. / B ഇല്ല. / C ചായ.
8. **നന്ദി.** A സാരമില്ല. / B എന്റെ പേര്. / C വീട്.
9. **നിന്റെ പേര് എന്താണ്?** A എന്റെ പേര് അമൻ ആണ്. / B എനിക്ക് സുഖമാണ്. / C വെള്ളം.
10. **സുഖമാണോ?** A വീണ്ടും കാണാം. / B എനിക്ക് സുഖമാണ്. / C എന്റെ പേര്.
11. **എന്റെ പേര് അമൻ ആണ്.** A name Aman / B city Aman / C language Aman
12. **ഞാൻ കേരളത്തിൽ താമസിക്കുന്നു.** A named Kerala / B lives in Kerala / C speaks Kerala
13. **ഞാൻ മലയാളം സംസാരിക്കുന്നു.** A speaks Malayalam / B wants tea / C is at school
14. **എന്റെ പേര് ലീല ആണ്.** A city Lila / B name Lila / C language Lila

## Writing — 12 minutes

1. Ten-second delayed recall: **നന്ദി**.
2. Ten-second delayed recall: **മലയാളം**.
3. Dictation, twice: **പേര്**.
4. Dictation, twice: **വെള്ളം**.
5. Dictation, twice: **നമസ്കാരം**.
6. Dictation, twice: **വീട്**.
7. Independently write one Malayalam place name you know after a nonverbal place cue.
8. Independently write one Malayalam thanks expression. No visible model remains.

## Speaking — 8 minutes

1. Return the interlocutor's **നമസ്കാരം.**
2. Answer **നിന്റെ പേര് എന്താണ്?** with a chosen identity.
3. Answer **സുഖമാണോ?**
4. Answer **നിങ്ങൾ എവിടെ താമസിക്കുന്നു?**
5. Answer **നിങ്ങൾ മലയാളം സംസാരിക്കുമോ?**
6. Situation: you want tea. Make one short polite request in Malayalam.

The interlocutor may repeat once slowly. No answer script, romanization,
dictionary, translator, or coaching is allowed.
