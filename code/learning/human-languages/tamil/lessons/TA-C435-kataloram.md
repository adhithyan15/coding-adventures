# கடலோரம் (kaṭalōram) — the coast; the seaside

## You'll want to know: கடலோரம்
<!-- hl-knowledge: introduces=[TA-LEX-C435-KATALORAM435-01]; assesses=[] -->

**கடலோரம்** — *kaṭalōram* — "the coast; the seaside".

> கடலோரக் கிராமங்களில் மீனவர்கள் வாழ்கிறார்கள்.
>
> *kaṭalōrak kirāmaṅkaḷil mīṉavarkaḷ vāḻkiṟārkaḷ.*
>
> Fishermen live in the coastal villages.

As a modifier it drops -ம்: கடலோரக் கிராமம், a coastal village.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**கடலோரம்** (*kaṭalōram*) is built from கடல், "the sea" (DEDR 1118), and ஓரம், "an edge, a border" (DEDR 1060).
