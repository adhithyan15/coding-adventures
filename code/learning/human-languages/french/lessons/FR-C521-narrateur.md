## You'll want to know: le narrateur
<!-- hl-knowledge: introduces=[FR-LEX-C521-AUTEURS-02]; assesses=[] -->

**le narrateur** — "narrator".

> Dans ce roman, le narrateur est un enfant.
>
> *In this novel the narrator is a child.*

A woman is *la narratrice*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*le narrateur* is a learned borrowing from Latin *narrātor* "a storyteller" (EtymDB), from *narrāre* "to tell" (Lewis & Short).
