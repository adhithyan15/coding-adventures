# अडथळा (aḍthaḷā) — an obstacle

## You'll want to know: अडथळा
<!-- hl-knowledge: introduces=[MR-LEX-C548-ADTHALA548-01]; assesses=[] -->

**अडथळा** — *aḍthaḷā* — "an obstacle".

> रस्त्यात पडलेलं झाड हा मोठा अडथळा होता.
>
> *rastyāt paḍlelaṁ jhāḍ hā moṭhā aḍthaḷā hotā.*
>
> The tree lying on the road was a big obstacle.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**अडथळा** (*aḍthaḷā*) begins with अड, "obstruction": CDIAL lists Marathi *aḍ*, "obstruction", and *aḍṇẽ*, "to be stopped", under *\*aḍ*, "obstruct, stop" (CDIAL 187). The second part is not settled.
