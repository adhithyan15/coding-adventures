## You'll want to know: шлюпка
<!-- hl-knowledge: introduces=[RU-LEX-C426-VESLO-02]; assesses=[] -->

**шлюпка** (*shlyúpka*) — "a ship's boat, a lifeboat".

> На корабле есть шлюпки для всех пассажиров.
>
> *Na korablé yest shlyúpki dlya vsekh passazhírov.*
>
> There are lifeboats on the ship for all the passengers.

Feminine. *Спасательная шлюпка* — a lifeboat.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*шлюпка* is a diminutive of *шлюп* 'a sloop' (EtymDB lists *шлюп*), which is usually traced to Dutch *sloep*, a word EtymDB links with a Middle Dutch verb for gliding.
