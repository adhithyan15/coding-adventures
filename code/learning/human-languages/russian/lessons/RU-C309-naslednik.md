## You'll want to know: наследник
<!-- hl-knowledge: introduces=[RU-LEX-C309-POKHORONY-05]; assesses=[] -->

**наследник** (*naslédnik*) — "an heir".

> Сын стал единственным наследником.
>
> *Syn stal yedínstvennym naslédnikom.*
>
> The son became the only heir.

A woman is *наследница*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*наследник* is built on *наследовать* "to inherit", from *на-* and *след* "a track" (EtymDB), with the ending *-ник* for a person.
