# মুলতুবি (multubi) — adjourned; put off

## You'll want to know: মুলতুবি
<!-- hl-knowledge: introduces=[BN-LEX-C530-BATIL530-01]; assesses=[] -->

**মুলতুবি** — *multubi* — "adjourned; put off".

> ঝড় হলে মিটিং মুলতুবি হবে।
>
> *Jhôṛ hôle miṭing multubi hôbe.*
>
> If there is a storm, the meeting will be put off.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**মুলতুবি** (*multubi*) is usually traced to Arabic *multawī*, "deferred", through Persian.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
