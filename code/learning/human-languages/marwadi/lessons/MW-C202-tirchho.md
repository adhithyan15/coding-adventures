# तिरछो (tirchho) — slanting

## You'll want to know: तिरछो
<!-- hl-knowledge: introduces=[MW-LEX-C202-WAY202-05]; assesses=[] -->

**तिरछो** — *tirchho* — "slanting".

> ये गेलो तिरछो है।
>
> *ye gelo tirchho hai.*
>
> This path runs at a slant.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**तिरछो** (*tirchho*) is inherited from Sanskrit *tiraśca*, "slanting, crosswise". CDIAL gives no Marwari form in this entry, but lists Hindi *tirchā*, "slanting" (CDIAL 5822).
