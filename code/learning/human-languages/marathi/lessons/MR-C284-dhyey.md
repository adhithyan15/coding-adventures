# ध्येय (dhyey) — a goal

## You'll want to know: ध्येय
<!-- hl-knowledge: introduces=[MR-LEX-C284-DHYEY-01]; assesses=[MR-LEX-MAJHE, MR-LEX-MOTHA] -->

**ध्येय** — *dhyey* — "a goal, an aim".

> **माझं ध्येय मोठं आहे.**
>
> *mājhaṁ dhyey moṭhaṁ āhe.* — "My goal is a big one."

**ध्येय** is neuter: **माझं ध्येय**. A wish can stay a wish; a goal is what you work toward.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ध्येय** (*dhyey*) is a tatsama: Sanskrit *dhyeya*, "to be meditated on, to be pondered" (Monier-Williams), from the root of *dhyāna*, "meditation". Marathi uses it for the aim one keeps the mind fixed on.
