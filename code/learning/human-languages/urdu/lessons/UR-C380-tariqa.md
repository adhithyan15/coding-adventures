## You'll want to know: طریقہ
<!-- hl-knowledge: introduces=[UR-LEX-C380-MASHQ380-01]; assesses=[] -->

**طریقہ** — *tarīqā* — "a method; a way (of doing)".

> اگر یہ طریقہ نہیں چلا تو ہم دوسرا سوچیں گے۔
>
> *agar yih tarīqā nahīṅ chalā to ham dūsrā socheṅ ge.*
>
> If this method does not work, we will think of another.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**طریقہ** (*tarīqā*) is usually traced, through Persian, to Arabic *ṭarīqa*, "a path, a way".
