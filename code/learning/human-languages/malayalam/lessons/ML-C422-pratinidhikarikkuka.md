# പ്രതിനിധീകരിക്കുക (pratinidhīkarikkuka) — to represent

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C422-SABHA422-02, ML-LEX-C422-SABHA422-03] -->

[PAUSE 2s] Before the new one: say the Malayalam for a member, then the Malayalam for a representative.

## You'll want to know: പ്രതിനിധീകരിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C422-SABHA422-04]; assesses=[] -->

**പ്രതിനിധീകരിക്കുക** — *pratinidhīkarikkuka* — "to represent".

> അവൾ ഞങ്ങളുടെ കോളേജിനെ പ്രതിനിധീകരിച്ചു.
>
> *avaḷ ñaṅṅaḷuṭe kōḷējine pratinidhīkariccu.*
>
> She represented our college.

Past: പ്രതിനിധീകരിച്ചു, *pratinidhīkariccu*.

What is represented takes -നെ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**പ്രതിനിധീകരിക്കുക** (*pratinidhīkarikkuka*) is built from Sanskrit *pratinidhi*, "a representative" (Monier-Williams), with -ീകരിക്കുക, "to make into": to be made the representative.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
