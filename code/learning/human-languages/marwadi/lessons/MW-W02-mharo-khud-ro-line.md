# My own line — the first writing with no model

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MW-SKILL-READ-NOTICE] -->

[PAUSE 2s] You have read signs and notices. Now write one.

[PAUSE 1s] Everything you have written so far had something to reach for. This
does not.

## Writing — controlled composition
<!-- hl-knowledge: introduces=[]; assesses=[MW-SKILL-READ-NOTICE, MW-SKILL-READ-SIGNBOARD] -->
<!-- hl-writing-stage: controlled-composition -->

[PAUSE 2s] Write **one line** about yourself, choosing the words yourself from a
supply that is closed: only what this book has taught you.

[PAUSE 2s] One thing to decide deliberately before you start. The letters hang
from a line drawn across the top, and that line belongs to the **word**, not to
each letter. Draw the bodies first and the top line last, running it across the
whole word.

[PAUSE 3s] Write the line. Then read it back and check that top line **before**
you check anything else — one long stroke, not a row of short ones.

## Wrap-up recall
<!-- hl-knowledge: introduces=[]; assesses=[MW-SKILL-READ-SIGNBOARD] -->

[PAUSE 2s] Does the top line belong to a letter or to a word? (**To the word.**)

[PAUSE 2s] And what did you have to choose here that the earlier lessons chose
for you? (**The words.**)
