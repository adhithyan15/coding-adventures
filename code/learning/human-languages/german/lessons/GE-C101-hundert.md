## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**hundert** ← Old High German *hundert* ← Proto-Germanic *\*hundaradą*, built from *\*hundą*, "hundred", and *\*radą*, "count" (EtymDB 2.1). English *hundred* is the same word.
