## You'll want to know: le décor
<!-- hl-knowledge: introduces=[FR-LEX-C514-THEATRE-03]; assesses=[] -->

**le décor** — "set, scenery; decor".

> Le décor représente une petite cuisine.
>
> *The set shows a small kitchen.*

In a theatre, often plural: *les décors*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*le décor* is built on *décorer*, a learned borrowing from Latin *decorāre* "to adorn", from *decus* "ornament, honour" (EtymDB; Lewis & Short).
