# ಬಿಕ್ಕಳಿಕೆ (bikkaḷike) — hiccups

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C507-SADDU507-02, KA-LEX-C507-SADDU507-03] -->

[PAUSE 2s] Before the new one: say the Kannada for to blink, then the Kannada for to pant.

## You'll want to know: ಬಿಕ್ಕಳಿಕೆ
<!-- hl-knowledge: introduces=[KA-LEX-C507-SADDU507-04]; assesses=[] -->

**ಬಿಕ್ಕಳಿಕೆ** — *bikkaḷike* — "hiccups".

> ಬೇಗ ಬೇಗ ತಿಂದಿದ್ದರಿಂದ ನನಗೆ ಬಿಕ್ಕಳಿಕೆ ಬಂದಿತು.
>
> *bēga bēga tindiddarinda nanage bikkaḷike banditu.*
>
> Because I ate too fast, I got hiccups.

Hiccups "come": ಬಿಕ್ಕಳಿಕೆ ಬರು.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಬಿಕ್ಕಳಿಕೆ** (*bikkaḷike*) is native Dravidian: DEDR 5383 sets Kannada *bikkaḷike* beside Tamil *vikku*, "to hiccup".
