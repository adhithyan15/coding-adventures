## You'll want to know: અજવાળું
<!-- hl-knowledge: introduces=[GU-LEX-C218-SUN218-05]; assesses=[] -->

**અજવાળું** — *ajvāḷũ* — "daylight, light".

> **પરોઢે અજવાળું થશે.** — *paroḍhe ajvāḷũ thaśe* — "It will get light at dawn."

A neuter noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**અજવાળું** (*ajvāḷũ*) is usually linked to Sanskrit *ujjvala*, "blazing up, bright". CDIAL lists the related Gujarati *ujḷũ*, "bright", there, but not *ajvāḷũ* itself, so the exact path is not settled (CDIAL 1670).
