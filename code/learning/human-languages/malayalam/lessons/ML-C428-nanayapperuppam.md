# നാണയപ്പെരുപ്പം (nāṇayapperuppaṁ) — inflation

## You'll want to know: നാണയപ്പെരുപ്പം
<!-- hl-knowledge: introduces=[ML-LEX-C428-VARUMANAM428-03]; assesses=[] -->

**നാണയപ്പെരുപ്പം** — *nāṇayapperuppaṁ* — "inflation".

> നാണയപ്പെരുപ്പം കാരണം പണത്തിന്റെ വില കുറഞ്ഞു.
>
> *nāṇayapperuppaṁ kāraṇaṁ paṇattinṟe vila kuṟaññu.*
>
> Because of inflation, the value of money fell.

A technical word of the news; in talk people say വിലക്കയറ്റം.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**നാണയപ്പെരുപ്പം** (*nāṇayapperuppaṁ*) is a Malayalam compound: നാണയം, "a coin", from Sanskrit *nāṇaka*, "a coin" (CDIAL 7050), and പെരുപ്പം, "a swelling, an increase", native Dravidian (DEDR 4411): the swelling of money.

## What you've built

One more word for giving reasons and opinions.
