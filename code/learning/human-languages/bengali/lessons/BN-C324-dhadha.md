# ধাঁধা (dhā̃dhā) — a riddle; a puzzle

## You'll want to know: ধাঁধা
<!-- hl-knowledge: introduces=[BN-LEX-C324-KOUSHOL324-01]; assesses=[] -->

**ধাঁধা** — *dhā̃dhā* — "a riddle; a puzzle".

> রাক্ষস রাজকুমারকে একটা ধাঁধা জিজ্ঞাসা করল।
>
> *rākkhôs rājkumārke ekṭā dhā̃dhā jigyāsā kôrlô.*
>
> The ogre asked the prince a riddle.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ধাঁধা** (*dhā̃dhā*) is a riddle or a puzzle; its origin is not settled. ধাঁধায় পড়া is to be puzzled.
