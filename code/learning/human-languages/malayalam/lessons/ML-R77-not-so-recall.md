# (not there, not so) — from cold

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-ILLA-01, ML-LEX-C77-ALLA-01] -->

[PAUSE 3s] Close the lessons before this one. Say both negatives, and say which
question each one answers.

## Grammar Lens: one English word, two Malayalam ones
<!-- hl-knowledge: introduces=[]; assesses=[ML-CONCEPT-C77-NEGATION-SPLIT-01, ML-LEX-ILLA-01, ML-LEX-C77-ALLA-01, ML-LEX-AANU-01] -->

| | denies | pairs with |
|---|---|---|
| **ഇല്ല** | that it is **there** | *is there any?* |
| **അല്ല** | that it is **so** | *is it that?* |

**English spends one word where Malayalam spends two**, so the choice is a
decision English never made you make. Make it by looking at the question, not
at the word you would use at home.

**അല്ല** is the negative of **ആണ്**, which is why it closes a sentence in the
same place ആണ് does.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C77-ALLE-01, ML-LEX-C48-ROLE-01] -->

The ability to say what something **is not** — and, from that same word, to
check something you think you already know.

> **നിങ്ങൾ അധ്യാപകൻ ആണ്, അല്ലേ?**

**അല്ലേ** carries **അല്ല** at its front, and hangs *"or is it not so?"* on a
statement. It invites agreement where **-ഓ** asks for an answer.
