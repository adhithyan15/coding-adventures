# Unit 0C: Stress & Written Accents

## Warm-up

[PAUSE 2s] Say *hola* and *perro* out loud. Every Spanish word has one
syllable that's stressed harder than the others — same as English — but
unlike English, Spanish has a small, reliable rule set for *predicting*
which syllable, plus a written mark for when the rule gets overridden. This
is one of the highest-leverage rules in the whole language: three small
facts, and you can correctly stress almost any word you read.

## New Material

**Rule 1**: if a word ends in a vowel, or in *n* or *s*, stress falls on the
**second-to-last** syllable. *ca-SA* (house), *ha-BLAN* (they speak),
*li-BROS* (books).

**Rule 2**: if a word ends in any *other* consonant, stress falls on the
**last** syllable. *ha-BLAR* (to speak), *es-pa-ÑOL* (Spanish), *ciu-DAD*
(city).

**Rule 3**: a written accent mark (´) on a vowel overrides both rules above
— stress goes exactly where the mark is, no exceptions. *ha-BLÓ* (he
spoke) would, by Rule 1, want stress on *ha*- (ends in a vowel) — the
accent mark forces it onto the last syllable instead, and also changes the
meaning (*hablo* "I speak" vs. *habló* "he/she spoke" — the accent mark is
carrying real grammatical weight, not decoration).

> Etymology aside: this is also why *días* (from Unit 1's *buenos días*)
> carries an accent — *día* ← Latin *dies* picked up a written accent
> because *í* and *a* next to each other would otherwise default-stress
> incorrectly per Rule 1's syllable-counting.

## Guided Practice

[PAUSE 1s]
- [YOU SAY: "casa" — stress the second-to-last syllable, per Rule 1]
- [YOU SAY: "hablar" — stress the last syllable, per Rule 2]
- [YOU SAY: "hablo" then "habló" — notice the accent mark moves the stress
  and changes the meaning]

[REPEAT x2] *ca-SA, ha-BLAR, HA-blo, ha-BLÓ.*

## Wrap-up Recall

[PAUSE 3s] A word ends in *s* with no written accent — which syllable gets
the stress, by default? ... The second-to-last (Rule 1) — *s*-endings fall
under the "vowel/n/s" group.
