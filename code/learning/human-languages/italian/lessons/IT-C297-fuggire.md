## You'll want to know: fuggire
<!-- hl-knowledge: introduces=[IT-LEX-C297-MANETTE-05]; assesses=[] -->

**fuggire** — "to flee, to run away".

> Il rapinatore è fuggito dalla finestra.
>
> *The robber fled through the window.*

More formal than *scappare*: *è fuggito*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*fuggire* is inherited from Latin *fugere* "to flee" (EtymDB), through a Vulgar Latin *fugīre*.
