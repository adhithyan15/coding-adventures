# Three places in four skills

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[GU-LEX-BAJAR-01, GU-LEX-GHAR-01, GU-LEX-MANDIR-01] -->

[PAUSE 12s] Say market, home, and temple from their meaning cues.

## Guided Practice
<!-- hl-knowledge: introduces=[GU-PERFORMANCE-PLACES-THREE-FOUR-SKILL-01]; assesses=[GU-LEX-BAJAR-01, GU-SCRIPT-BAJAR-01, GU-LEX-GHAR-01, GU-SCRIPT-GHAR-01, GU-LEX-MANDIR-01, GU-SCRIPT-MANDIR-01] -->

meaning, read three printed cards, and write one heard word. Reach full marks
in each skill; repair only the failed part.
