# இடிபாடு (iṭipāṭu) — rubble; debris

## You'll want to know: இடிபாடு
<!-- hl-knowledge: introduces=[TA-LEX-C301-MEETPU301-02]; assesses=[] -->

**இடிபாடு** — *iṭipāṭu* — "rubble; debris".

> இடிபாடுகளுக்குள் ஒரு குழந்தை இருந்தது.
>
> *iṭipāṭukaḷukkuḷ oru kuḻantai iruntatu.*
>
> There was a child under the rubble.

Plural: இடிபாடுகள், *iṭipāṭukaḷ*.

Usually plural: இடிபாடுகள், the debris.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**இடிபாடு** (*iṭipāṭu*) is a Tamil compound built from இடி, "to crumble, be in ruins" (DEDR 432), and பாடு, "fall, ruin" (DEDR 3852).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
