# പ്രയാസം (prayāsaṁ) — difficult

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C96-EASY-01] -->

[PAUSE 2s] Say *this is easy*. All of it, in one breath.

## You'll want to know
<!-- hl-knowledge: introduces=[ML-LEX-C96-DIFFICULT-01]; assesses=[] -->

**പ്രയാസം** — *prayāsaṁ* — **difficult.**

> **ഇത് പ്രയാസമാണ്.** — *itŭ prayāsamāṇŭ* — "**This is difficult.**"

**It ends in ം as well**, so it behaves the way the last one did, and you did
not have to be told a second time.

| | |
|---|---|
| **ഇത് എളുപ്പമാണ്** | this is easy |
| **ഇത് പ്രയാസമാണ്** | this is difficult |

**One word apart, and the sentence is the opposite.** Everything around it holds
still.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C96-DIFFICULT-01, ML-LEX-C96-EASY-01, ML-LEX-AANU-01] -->

This is a pair you can say about anything you can point at — a word, a letter,
a road, a lesson. It is also the first thing most learners want to say about the
language itself, and **you can now say it in the language**, which is a better
place to complain from.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C96-DIFFICULT-01, ML-LEX-C96-EASY-01] -->

[PAUSE 3s] Easy and difficult? (**എളുപ്പം, പ്രയാസം**.) Did the second one need a
new rule? (**No** — it ends the same way, so it behaves the same way.)
