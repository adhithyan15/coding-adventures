## You'll want to know: la machine à laver
<!-- hl-knowledge: introduces=[FR-LEX-C526-LINGE-01]; assesses=[] -->

**la machine à laver** — "washing machine".

> La machine à laver tourne depuis une heure.
>
> *The washing machine has been running for an hour.*

Also *le lave-linge*. *Faire une machine* — to do a load of washing.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*la machine à laver* joins *machine*, a learned borrowing from Latin *māchina* "a device", and *laver* "to wash", inherited from Latin *lavāre* (Lewis & Short).
