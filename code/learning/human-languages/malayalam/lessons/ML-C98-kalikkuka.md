# കളിക്കുക (kaḷikkuka) — to play

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C98-GAME-01, ML-CONCEPT-C33-VAAYIKKUKA-01] -->

## You'll want to know
<!-- hl-knowledge: introduces=[ML-LEX-C98-PLAY-01]; assesses=[] -->

**കളിക്കുക** — *kaḷikkuka* — **to play.**

> **ഞാൻ കളിക്കുന്നു.** — *ñān kaḷikkunnu* — "I play."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C98-PLAY-01, ML-LEX-C98-GAME-01, ML-CONCEPT-C33-VAAYIKKUKA-01, ML-LEX-SAMSAARIKKUKA-01, ML-CONCEPT-C34-CODIKKUKA-01, ML-LEX-C85-DRINK-01] -->

**The noun is sitting inside the verb.** **കളി** is the game; **കളിക്കുക** is
doing it.

And the shape is one you have had for a long time. Put it beside the reading
verb:

| | |
|---|---|
| **വായിക്കുക** → **വായിക്കുന്നു** | reads |
| **കളിക്കുക** → **കളിക്കുന്നു** | plays |

**Verb after verb in this book already ends in -ിക്കുക** — **സംസാരിക്കുക**,
**വായിക്കുക**, **ചോദിക്കുക**, **കുടിക്കുക** — so this one arrives asking
nothing new of you. The only new part is the two syllables at the front.
