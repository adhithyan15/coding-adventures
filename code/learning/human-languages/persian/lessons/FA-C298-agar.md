# اگر … باشد (agar ... bâshad) — if it is

## Grammar Lens: the condition first, in the subjunctive
<!-- hl-knowledge: introduces=[FA-GRAMMAR-AGAR-SUBJ-01]; assesses=[FA-LEX-C208-CHIZ208-01, FA-LEX-C87-LOC87-03, FA-LEX-C129-QUAL129-01, FA-GRAMMAR-PRESENT-MI-01, FA-GRAMMAR-BEHTAR-AST-SUBJ-01] -->

**اگر**, *agar*, opens the condition. The condition usually comes first, then a
pause, then what follows from it:

> **اگر هوا خوب باشد، به پارک میرویم.** — *agar havâ khub bâshad, be pârk
> miravim* — If the weather is good, we'll go to the park.

The condition is about later, and it may not come true, so its verb is in
the subjunctive: *bâshad*, not *ast*. The second half is a plain present,
which in Persian also covers the future.

> **اگر خسته باشی، بهتر است بخوابی.** — *agar khaste bâshi, behtar ast bekhâbi*
> — If you're tired, you'd better sleep.

*Agar* can also sit after the person it is about: *to agar khaste bâshi...*.
Either way, *agar* stays inside the condition half.

## Grammar Lens: vagarna, the other branch
<!-- hl-knowledge: introduces=[]; assesses=[FA-GRAMMAR-POLITE-IMPERATIVE-01, FA-LEX-AZ-DAST-DADAN-01] -->

*Vagarna*, "otherwise", is the condition turned round, "and if not":

> **زود بروید، وگرنه قطار را از دست میدهید.** — *zud beravid, vagarna qatâr râ
> az dast midahid* — Leave early, otherwise you'll miss the train.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*agar* continues Middle Persian *agar*, "if" (EtymDB 2.1). *Vagarna* is *va*,
"and", *agar*, and *na*, "not", run together: the same "if" with "not" on the
end.
