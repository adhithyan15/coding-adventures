## You'll want to know: ಮನರಂಜನೆ
<!-- hl-knowledge: introduces=[KA-LEX-C530-BIDUVU530-02]; assesses=[] -->

**ಮನರಂಜನೆ** — *manarañjane* — "entertainment".

> ಟೀವಿ ಅಜ್ಜಿಯ ಮುಖ್ಯ ಮನರಂಜನೆ.
>
> *ṭīvi ajjiya mukhya manarañjane.*
>
> The television is grandmother's main entertainment.

ಮನ, mind + ರಂಜನೆ, delighting.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಮನರಂಜನೆ** (*manarañjane*) is a learned compound built from Sanskrit *manas*, "mind", and *rañjana*, "pleasing" (CDIAL 10587).
