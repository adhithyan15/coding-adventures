# ಬಾಧ್ಯತೆ (bādhyate) — an obligation

## You'll want to know: ಬಾಧ್ಯತೆ
<!-- hl-knowledge: introduces=[KA-LEX-C411-SHARATTU411-05]; assesses=[] -->

**ಬಾಧ್ಯತೆ** — *bādhyate* — "an obligation".

> ಸಾಲ ತೀರಿಸುವುದು ನನ್ನ ಬಾಧ್ಯತೆ.
>
> *sāla tīrisuvudu nanna bādhyate.*
>
> Paying off the loan is my obligation.

ಬಾಧ್ಯತೆ ಇರು, to be bound to do.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಬಾಧ್ಯತೆ** (*bādhyate*) is built on Sanskrit *bādhya*, "to be pressed hard" (Monier-Williams), with -*tā*, "-ness": what presses on one.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
