# രക്ഷപ്പെടുക (rakṣappeṭuka) — to escape; to be saved

[PAUSE 2s] Before the new one: say the Malayalam for a volunteer, then the Malayalam for to rescue.

## You'll want to know: രക്ഷപ്പെടുക
<!-- hl-knowledge: introduces=[ML-LEX-C375-RAKSHA375-04]; assesses=[] -->

**രക്ഷപ്പെടുക** — *rakṣappeṭuka* — "to escape; to be saved".

> തീപിടിത്തത്തിൽ നിന്ന് എല്ലാവരും രക്ഷപ്പെട്ടു.
>
> *tīpiṭittattil ninnŭ ellāvaruṁ rakṣappeṭṭu.*
>
> Everyone escaped from the fire.

Past: രക്ഷപ്പെട്ടു, *rakṣappeṭṭu*.

From what takes -ഇൽ നിന്ന്. -പ്പെടുക makes the saving happen to the subject.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**രക്ഷപ്പെടുക** (*rakṣappeṭuka*) is built from Sanskrit *rakṣā*, "protection" (CDIAL 10551), with -പ്പെടുക, "to come to be": to come into safety.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
