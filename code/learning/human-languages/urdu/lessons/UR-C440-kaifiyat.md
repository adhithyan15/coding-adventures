## You'll want to know: کیفیت
<!-- hl-knowledge: introduces=[UR-LEX-C440-FEEL440-04]; assesses=[] -->

**کیفیت** — *kaifiyat* — "a state of mind; a state of body".

> آج اس کی کیفیت بہتر ہے۔
>
> *āj us kī kaifiyat behtar hai.*
>
> She is in a better state today.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**کیفیت** (*kaifiyat*) is usually traced, through Persian, to Arabic *kayfiyya*, "how a thing is"; Urdu uses it for the state a person is in.
