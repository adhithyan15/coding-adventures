## You'll want to know: дружить
<!-- hl-knowledge: introduces=[RU-LEX-C498-FRIENDS-01]; assesses=[] -->

**дружить** (*druzhít*) — "to be friends".

> Мы дружим с детства.
>
> *My drúzhim s détstva.*
>
> We've been friends since childhood.

Imperfective; present дружу, дружишь. *Дружить с кем*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*дружить* is built on *друг* 'friend', which is inherited from Proto-Slavic *drugъ* 'friend' (EtymDB).
