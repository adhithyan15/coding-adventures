# கட்டுமரம் (kaṭṭumaram) — a catamaran; a log raft

## You'll want to know: கட்டுமரம்
<!-- hl-knowledge: introduces=[TA-LEX-C416-PATAKU416-04]; assesses=[] -->

**கட்டுமரம்** — *kaṭṭumaram* — "a catamaran; a log raft".

> கட்டுமரம் அலைகளின் மேல் மிதந்தது.
>
> *kaṭṭumaram alaikaḷiṉ mēl mitantatu.*
>
> The log raft floated on the waves.

English catamaran comes from this word.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**கட்டுமரம்** (*kaṭṭumaram*) is built from கட்டு, "to tie" (DEDR 1147), and மரம், "a tree, wood" (DEDR 4711): logs tied together.
