## You'll want to know: مصروف
<!-- hl-knowledge: introduces=[UR-LEX-C527-MASRUF527-01]; assesses=[] -->

**مصروف** — *masrūf* — "busy".

> اگر آپ مصروف ہیں تو میں کل آؤں گا۔
>
> *agar āp masrūf haiṅ to maiṅ kal āūṅ gā.*
>
> If you're busy, I'll come tomorrow.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**مصروف** (*masrūf*) is usually traced, through Persian, to Arabic *maṣrūf*, "turned towards something, taken up with it".
