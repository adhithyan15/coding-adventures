## You'll want to know: feierlich
<!-- hl-knowledge: introduces=[GE-LEX-C305-FEIER-02]; assesses=[] -->

**feierlich** — "solemn, festive".

> Die Stimmung war sehr feierlich.
>
> *The mood was very solemn.*

*Feierlich* is for a grand, serious occasion.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*feierlich* is built on *Feier* "celebration", which came from Latin *fēriae* "holidays" (EtymDB), with the ending *-lich*.
