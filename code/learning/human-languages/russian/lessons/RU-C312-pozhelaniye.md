## You'll want to know: пожелание
<!-- hl-knowledge: introduces=[RU-LEX-C312-POZDRAVLYAT-03]; assesses=[] -->

**пожелание** (*pozhelániye*) — "a wish".

> Бабушка написала добрые пожелания в открытке.
>
> *Bábushka napisála dóbryye pozhelániya v otkrýtke.*
>
> Grandma wrote kind wishes in the card.

Neuter. *С наилучшими пожеланиями* — with best wishes.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*пожелание* is built on *пожелать*, from *желать* "to wish", inherited from Proto-Slavic *želati* (EtymDB).
