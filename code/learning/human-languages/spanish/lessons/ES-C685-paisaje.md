## You'll want to know: el paisaje
<!-- hl-knowledge: introduces=[ES-LEX-C685-PAISAJE-01]; assesses=[] -->

**el paisaje** — "the landscape, the scenery".

> El paisaje es precioso.
>
> *The scenery is beautiful.*

*Un paisaje de montaña* — a mountain landscape.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*paisaje* was borrowed from French *paysage*, built on *pays* "country", which goes back to Latin *pāgus* "a district, the countryside".
