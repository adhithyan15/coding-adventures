# Review — what was going on

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[GU-GRAMMAR-C273-PERFECT-01, GU-GRAMMAR-C274-WAS-GOING-01] -->

[PAUSE 2s] Say "Arun has gone home". (*Aruṇ ghare gayo che*.) Then "I was going to go, but it rained". (*hũ javāno hato, paṇ varsād paḍyo*.)

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[GU-GRAMMAR-C275-ONGOING-PAST-01, GU-GRAMMAR-C275-SCENE-EVENT-01, GU-LEX-C275-BANVU-01, GU-LEX-C86-JOURNEY-04, GU-LEX-C55-HOUSEWORK-01, GU-LEX-C54-MOVE-02] -->

[PAUSE 2s each]
- [YOU SAY: I was reading a book. Mira was drinking tea.]
- [YOU SAY: I was reading when the phone rang.]
- [YOU SAY: When Arun got home, Mira was cooking.]
- [YOU SAY: Arun used to walk every day.]
- [YOU SAY: What happened last night? Arun became a doctor.]
