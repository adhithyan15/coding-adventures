# ನಿರ್ಮಿಸು (nirmisu) — to construct; to build

## You'll want to know: ನಿರ್ಮಿಸು
<!-- hl-knowledge: introduces=[KA-LEX-C362-NIRMANA362-03]; assesses=[] -->

**ನಿರ್ಮಿಸು** — *nirmisu* — "to construct; to build".

> ಕೆಲಸಗಾರರು ನದಿಗೆ ಹೊಸ ಸೇತುವೆ ನಿರ್ಮಿಸಿದರು.
>
> *kelasagāraru nadige hosa sētuve nirmisidaru.*
>
> The workers built a new bridge over the river.

Past (I …): ನಿರ್ಮಿಸಿದೆ, *nirmiside*.

A formal partner of ಕಟ್ಟು. Films are "made" with it too: ಸಿನಿಮಾ ನಿರ್ಮಿಸು.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ನಿರ್ಮಿಸು** (*nirmisu*) is built on Sanskrit *nirmāṇa*, "measuring, making, creating" (CDIAL 7368), with the Kannada verb ending -*isu*.

## What you've built

One more word for telling what happened.
