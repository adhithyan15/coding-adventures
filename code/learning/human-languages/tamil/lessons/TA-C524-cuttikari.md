## You'll want to know: சுத்திகரி
<!-- hl-knowledge: introduces=[TA-LEX-C524-SAMAIYAL524-05]; assesses=[] -->

**சுத்திகரி** — *cuttikari* — "to purify".

> இந்த இயந்திரம் குடிநீரைச் சுத்திகரிக்கிறது.
>
> *inta iyantiram kuṭinīraic cuttikarikkiṟatu.*
>
> This machine purifies drinking water.

Past (I …): சுத்திகரித்தேன், *cuttikarittēṉ*.

What is purified takes -ஐ: நீரைச் சுத்திகரி.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**சுத்திகரி** (*cuttikari*) is built on Sanskrit *śuddhi*, "cleansing, purity" (CDIAL 12523), with -கரி, "to make", from Sanskrit *kṛ*: "to make pure".
