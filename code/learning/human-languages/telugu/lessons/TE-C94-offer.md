# కావాలా? (kāvālā?) — do you want it?

[PAUSE 2s] Before the new one: say the Telugu for pardon me, then the Telugu for an apology.

## You'll want to know: కావాలా?
<!-- hl-knowledge: introduces=[TE-LEX-C94-POLITE-03]; assesses=[] -->

**కావాలా?** (*kāvālā?*) — "do you want it?".

It is **కావాలి**, "is wanted", with the question **-ఆ**. **టీ కావాలా?** — "would you like tea?".
The answer is **కావాలి** or **వద్దు**, both yours already.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

An offer, and both of its answers.
