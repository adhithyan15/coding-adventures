## You'll want to know: umbuchen
<!-- hl-knowledge: introduces=[GE-LEX-C420-STORNO-03]; assesses=[] -->

**umbuchen** — "to rebook, to change a booking".

> Die Fluggesellschaft hat uns auf einen späteren Flug umgebucht.
>
> *The airline has rebooked us onto a later flight.*

Separable: *ich buche um*, *ich habe umgebucht*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*umbuchen* is built from *um* 'over, round' and *buchen* 'to book', first 'to enter in a book', from *Buch* 'book' (EtymDB).
