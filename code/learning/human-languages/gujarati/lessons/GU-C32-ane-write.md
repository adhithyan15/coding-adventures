# અને reaches the page

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[GU-JOIN-ANE-01, GU-SCRIPT-SHAHAR-01] -->

[PAUSE 3s] Say the joining word before anything is uncovered. Then a long reach
back — read the word for **city**, written many chapters ago and not read since.

- [YOU READ: **શહેર**]

That word has been waiting a long time for a second look; this is it.

## Script — three signs, none of them new
<!-- hl-knowledge: introduces=[GU-SCRIPT-ANE-01]; assesses=[GU-SCRIPT-INDEPENDENT-A-01, GU-SCRIPT-NA-01, GU-SCRIPT-E-MATRA-01] -->

Uncover **અને** once. Name its pieces in order:

> **અ** — the independent *a* · **ન** — *na* · **ે** — the *e* stroke above

Every one of the three was taught long before this chapter. This is worth
saying plainly: the word this book most needed was never a writing problem. It
was never written down.

## Writing — guided copy, model in view
<!-- hl-knowledge: introduces=[]; assesses=[GU-SCRIPT-ANE-01] -->
<!-- hl-writing-stage: guided-copy -->

Keep the model in view and copy **અને** once. Check the **ે** sits above and to
the right of **ન**, not over **અ**.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[GU-SCRIPT-ANE-01, GU-JOIN-ANE-01] -->

[PAUSE 3s] Write **અને** from memory once, then uncover and compare. How many of
its three signs were new today? (None.)
