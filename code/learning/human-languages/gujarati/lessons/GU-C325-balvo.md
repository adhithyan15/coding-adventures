## You'll want to know: બળવો
<!-- hl-knowledge: introduces=[GU-LEX-C325-AZADI325-05]; assesses=[] -->

**બળવો** — *baḷvo* — "a revolt".

> એક રાત્રે સૈનિકોનો બળવો શરૂ થયો.
>
> *ek rātre sainikono baḷvo śarū thayo.*
>
> One night the soldiers' revolt began.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**બળવો** (*baḷvo*) No dictionary we use records an older form, so its history is not settled. It is masculine: **બળવો થયો**, there was a revolt; **બળવો કર્યો**, they rose up.
