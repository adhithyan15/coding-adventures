# ತುಂತುರು (tunturu) — drizzle; spray

## You'll want to know: ತುಂತುರು
<!-- hl-knowledge: introduces=[KA-LEX-C485-MUNGARU485-03]; assesses=[] -->

**ತುಂತುರು** — *tunturu* — "drizzle; spray".

> ಬೆಳಗ್ಗೆಯಿಂದ ತುಂತುರು ಮಳೆ ಬರುತ್ತಿದೆ.
>
> *beḷaggeyinda tunturu maḷe baruttide.*
>
> There has been a drizzle since the morning.

ತುಂತುರು ಮಳೆ, a light drizzle.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ತುಂತುರು** (*tunturu*) is native Dravidian: DEDR 3398 lists Kannada *tuntuṟ*, *tuntuṟi*, "drizzling, spray, a drop".
