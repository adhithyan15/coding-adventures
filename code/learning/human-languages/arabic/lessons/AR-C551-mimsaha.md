## You'll want to know: ممسحة
<!-- hl-knowledge: introduces=[AR-LEX-C551-GHURFA551-04]; assesses=[] -->

**ممسحة** — *mimsaḥa* — "a mop".

> نظفت الأرض بالممسحة.
>
> *naẓẓaftu al-arḍ bi-l-mimsaḥa.*
>
> I cleaned the floor with the mop.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ممسحة** (*mimsaḥa*) is built on the native Arabic root *m-s-ḥ*, "to wipe" (Lane). Masaḥa, to wipe, which you know, is from the same root; the pattern mifʿala names a tool.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
