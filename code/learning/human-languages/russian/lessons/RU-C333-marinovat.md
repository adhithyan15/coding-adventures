## You'll want to know: мариновать
<!-- hl-knowledge: introduces=[RU-LEX-C333-SOLIT-05]; assesses=[] -->

**мариновать** (*marinovát*) — "to marinate; to pickle".

> Мясо для шашлыка маринуют всю ночь.
>
> *Myáso dlya shashlyká marinúyut vsyu noch.*
>
> The meat for kebabs is marinated all night.

Imperfective; the perfective is *замариновать* (*zamarinovát*). Present *мариную*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*мариновать* is usually traced through French *mariner* "to pickle in brine", built on *marin* "of the sea", from Latin *mare* "sea"; EtymDB lists no parent.
