# いちど — one time, all known signs

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[JA-LEX-MOU, JA-SCRIPT-I-01, JA-SCRIPT-CHI-01, JA-SCRIPT-TO-01, JA-SCRIPT-DAKUTEN-01, JA-SCRIPT-ME-01] -->

[PAUSE 15s] Write **い**, **ち**, and **と**. Add the dakuten to **と** and read
the result *do*. Write **め** once as a review pulse.

## You'll want to know
<!-- hl-knowledge: introduces=[JA-LEX-ICHIDO]; assesses=[] -->

> **いちど** — *i-chi-do* — one time; once

The word is built transparently: *ichi* is “one,” and *do* counts one
occurrence. All four visible marks are already yours: **い + ち + と + ゛**.

Now join it to the previous word:

> **もういちど** — *mō ichido* — one more time

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[JA-LEX-ICHIDO, JA-LEX-MOU] -->
1. Hear *i | chi | do* without looking.
2. Write **いちど** from the three morae.
3. Read **もういちど**, keeping the two beats in **もう**.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[JA-LEX-ICHIDO] -->
