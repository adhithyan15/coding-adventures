## You'll want to know: postare
<!-- hl-knowledge: introduces=[IT-LEX-C530-ONLINE-04]; assesses=[] -->

**postare** — "to post (online)".

> Ha postato una foto delle vacanze.
>
> *She posted a holiday photo.*

Informal; more formal *pubblicare*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*postare* is built on English *post* (EtymDB), with the Italian verb ending *-are*.
