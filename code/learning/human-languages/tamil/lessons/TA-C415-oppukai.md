# ஒப்புகை (oppukai) — an acknowledgement; a receipt slip

## You'll want to know: ஒப்புகை
<!-- hl-knowledge: introduces=[TA-LEX-C415-AVANAM415-04]; assesses=[] -->

**ஒப்புகை** — *oppukai* — "an acknowledgement; a receipt slip".

> அலுவலகம் என் விண்ணப்பத்துக்கு ஒப்புகை கொடுத்தது.
>
> *aluvalakam eṉ viṇṇappattukku oppukai koṭuttatu.*
>
> The office gave an acknowledgement for my application.

ஒப்புகைச் சீட்டு is the slip you keep.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ஒப்புகை** (*oppukai*) is built from ஒப்பு, "to agree, to accept" (DEDR 924), with the noun ending *-kai*.
