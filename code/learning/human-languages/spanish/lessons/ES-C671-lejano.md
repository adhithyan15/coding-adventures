## You'll want to know: lejano
<!-- hl-knowledge: introduces=[ES-LEX-C671-LEJOS-02]; assesses=[] -->

**lejano** — "distant, far-off".

> Viven en un pueblo lejano.
>
> *They live in a far-off village.*

The adverb is *lejos*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*lejano* is built on *lejos* "far" (EtymDB), which is usually traced to Latin *laxius* "more loosely, more widely", from *laxus* "loose".
