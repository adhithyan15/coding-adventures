## You'll want to know: auparavant
<!-- hl-knowledge: introduces=[FR-LEX-C272-JADIS-03]; assesses=[] -->

**auparavant** — "before, previously".

> Elle est médecin; auparavant, elle était professeur.
>
> *She is a doctor; before that, she was a teacher.*

An adverb that stands alone. Before a noun, French uses *avant*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*auparavant* is built from *au*, *par* and *avant*; *avant* is inherited from Late Latin *abante*, built on Latin *ante* "before" (Lewis & Short).
