# Return to a familiar did

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-KITA-190, PA-LEX-KAMM-05, PA-LEX-MAIN-03] -->

[YOU HEAR: *maiṁ kamm kītā*] Say **ਮੈਂ ਕੰਮ ਕੀਤਾ**, "I did the work".

## Grammar Lens
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-KITA-190, PA-LEX-C56-FAMILY56-02, PA-LEX-KHANA] -->

In **ਮੈਂ ਕੰਮ ਕੀਤਾ**, **ਕੀਤਾ** agrees with the work, **ਕੰਮ**, not with the
speaker: a woman says it the same way. Hold that next to two verbs that are also
done to something: **ਪੀਣਾ**, **ਖਾਣਾ**.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-KITA-190, PA-LEX-C56-FAMILY56-02, PA-LEX-KHANA] -->

- [YOU HEAR: *I did the work*] Say **ਮੈਂ ਕੰਮ ਕੀਤਾ**.
- [YOU HEAR: *to drink*] Say **ਪੀਣਾ**.
- [YOU HEAR: *to eat*] Say **ਖਾਣਾ**.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-KITA-190] -->

[PAUSE 3s] Who decides the ending of **ਕੀਤਾ**? (The work, **ਕੰਮ**.)
