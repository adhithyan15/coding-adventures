# ضعف (ḍaʿufa) — to grow weak

## You'll want to know: ضعف
<!-- hl-knowledge: introduces=[AR-LEX-C513-MUZMIN513-04]; assesses=[] -->

**ضعف** — *ḍaʿufa* — "to grow weak".

> ضعف جدي بعد المرض.
>
> *ḍaʿufa jaddī baʿda al-maraḍ.*
>
> My grandfather grew weak after his illness.

Present: يضعف, *yaḍʿuf*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ضعف** (*ḍaʿufa*) is built on the native Arabic root *ḍ-ʿ-f*, "to be weak" (Lane). Ḍaʿīf, weak, which you know, is from the same root.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
