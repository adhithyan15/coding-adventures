## You'll want to know: la targa
<!-- hl-knowledge: introduces=[IT-LEX-C415-NOLEGGIO-03]; assesses=[] -->

**la targa** — "the number plate; the plaque".

> Hai visto la targa di quella macchina?
>
> *Did you see that car's number plate?*

Also a plaque on a wall, in memory of someone.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*targa* first meant a shield. It is usually traced to a Germanic word for a shield, but the exact path is not settled.
