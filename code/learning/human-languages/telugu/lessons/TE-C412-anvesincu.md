# అన్వేషించు (anvēṣiñcu) — to explore; to search for

## You'll want to know: అన్వేషించు
<!-- hl-knowledge: introduces=[TE-LEX-C412-PARISODHANA412-05]; assesses=[] -->

**అన్వేషించు** — *anvēṣiñcu* — "to explore; to search for".

> వాళ్ళు నీళ్ళ కోసం కొత్త చోట్లు అన్వేషించారు.
>
> *vāḷḷu nīḷḷa kōsaṁ kotta cōṭlu anvēṣiñcāru.*
>
> They searched new places for water.

Past (I …): అన్వేషించాను, *anvēṣiñcānu*.

The noun is అన్వేషణ, a search.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**అన్వేషించు** (*anvēṣiñcu*) is built on Sanskrit *anveṣaṇa*, "seeking for, searching, investigating" (Monier-Williams), with the Telugu verb ending -ఇంచు.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
