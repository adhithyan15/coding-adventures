# சந்தர்ப்பம் (cantarppam) — an occasion; an opportunity

[PAUSE 2s] Before the new one: say the Tamil for probability, then the Tamil for probably.

## You'll want to know: சந்தர்ப்பம்
<!-- hl-knowledge: introduces=[TA-LEX-C383-CATTIYAM383-04]; assesses=[] -->

**சந்தர்ப்பம்** — *cantarppam* — "an occasion; an opportunity".

> சந்தர்ப்பம் கிடைத்தால் நான் அவரிடம் பேசுவேன்.
>
> *cantarppam kiṭaittāl nāṉ avariṭam pēcuvēṉ.*
>
> If I get the chance, I will speak to him.

சந்தர்ப்பம் கிடை, to get the chance; இந்தச் சந்தர்ப்பத்தில், on this occasion.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**சந்தர்ப்பம்** (*cantarppam*) is borrowed from Sanskrit *saṃdarbha*, "stringing or binding together, arranging" (Monier-Williams); Tamil uses it for the moment when things come together.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
