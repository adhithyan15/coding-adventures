# चौदा — fourteen on the page

## You'll want to know
<!-- hl-knowledge: introduces=[MW-SCRIPT-CHAUDA-01]; assesses=[MW-SCRIPT-CHA-01, MW-SCRIPT-AU-MATRA-01, MW-SCRIPT-DA-01, MW-SCRIPT-AA-MATRA-01] -->

> **चौ** + **दा** → **चौदा** — *caudā* — fourteen

The **ौ** is the mark **मौसम** taught, and **द** has been in the hand since
*do*. Nothing here is new; what is new is the pairing.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-CHAUDA-01, MW-SCRIPT-TERA-01, MW-SCRIPT-BAARA-01] -->
<!-- hl-writing-stage: delayed-copy -->

Write **चौदा** from memory after five seconds. Then write **तेरा** beside it and
ring the two different last letters — **र** and **द** — so the eye records the
break the ear heard.
