## You'll want to know: बहुमत
<!-- hl-knowledge: introduces=[MR-LEX-C356-LOKSHAHI356-02]; assesses=[] -->

**बहुमत** — *bahumat* — "a majority".

> वर्गाच्या मतदानात मीराला बहुमत मिळालं.
>
> *vargācyā matdānāt mīrālā bahumat miḷālaṁ.*
>
> Meera got a majority in the class vote.

Neuter.

बहु + मत, many + votes.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**बहुमत** (*bahumat*) is a learned compound built from Sanskrit *bahu*, "much, many", and *mata*, "opinion" (Monier-Williams).
