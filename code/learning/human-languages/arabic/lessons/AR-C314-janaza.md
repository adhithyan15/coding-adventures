## You'll want to know: جنازة
<!-- hl-knowledge: introduces=[AR-LEX-C314-JANAZA314-01]; assesses=[] -->

**جنازة** — *janāza* — "a funeral".

> حضر الجيران جنازة الرجل العجوز.
>
> *ḥaḍara al-jīrān janāzat ar-rajul al-ʿajūz.*
>
> The neighbours attended the old man’s funeral.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**جنازة** (*janāza*) is built on the native Arabic root *j-n-z* (Lane), where *janāza* is the bier with the dead person upon it, and then the procession that carries it.
