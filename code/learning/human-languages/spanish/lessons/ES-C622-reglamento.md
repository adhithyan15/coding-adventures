## You'll want to know: el reglamento
<!-- hl-knowledge: introduces=[ES-LEX-C622-REGLA-02]; assesses=[] -->

**el reglamento** — "the regulations, the rules".

> Lee el reglamento antes de empezar.
>
> *Read the regulations before you start.*

The written set of rules of a club, a building or a game.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*reglamento* is built on *reglar*, a learned borrowing from Latin *regulare* 'to direct', from *regula* 'rule' (EtymDB).
