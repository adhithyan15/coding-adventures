## You'll want to know: la sécheresse
<!-- hl-knowledge: introduces=[FR-LEX-C464-CANICULE-02]; assesses=[] -->

**la sécheresse** — "the drought".

> À cause de la sécheresse, les rivières sont presque vides.
>
> *Because of the drought the rivers are almost empty.*

Built on *sec* 'dry'.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*sécheresse* is built on *sec, sèche* 'dry' (EtymDB lists it), which is inherited from Latin *siccus*.
