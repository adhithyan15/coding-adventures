# ಸ್ಟೆಪ್ನಿ (sṭepni) — a spare tyre

## You'll want to know: ಸ್ಟೆಪ್ನಿ
<!-- hl-knowledge: introduces=[KA-LEX-C449-CAKRA449-03]; assesses=[] -->

**ಸ್ಟೆಪ್ನಿ** — *sṭepni* — "a spare tyre".

> ನಮ್ಮ ಕಾರಿನಲ್ಲಿ ಸ್ಟೆಪ್ನಿ ಇರಲಿಲ್ಲ.
>
> *namma kārinalli sṭepni iralilla.*
>
> There was no spare tyre in our car.

Indian English for the spare wheel carried in a vehicle.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಸ್ಟೆಪ್ನಿ** (*sṭepni*) is a loan from English *stepney*, in Indian use, "a spare wheel".
