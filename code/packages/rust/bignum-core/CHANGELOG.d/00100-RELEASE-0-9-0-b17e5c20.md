## [0.9.0] - 2026-11-23

### Added

- **Bitwise operations on `BigInteger` with Lean 4 `Nat` semantics** (KRN-002a, the trusted
  numeric surface of the `lean-kernel` proof checker, VER11a section 4.2): `and`, `or`, `xor`
  (`Nat.land`/`lor`/`xor`), `shl` and `try_shl` (`Nat.shiftLeft`, the latter with a
  pre-allocation size ceiling), `shr` (`Nat.shiftRight`) and `log2` (`Nat.log2`, with
  `log2(0) = 0` as Lean defines it).
- `BitwiseError` (`NegativeOperand`, `ResultTooLarge`). Negative operands are refused rather
  than given two's-complement meaning.
- `tests/bitwise.rs`: differential tests against a naive bit-by-bit `Vec<bool>` reference
  over limb-boundary edge values and large random values, plus identities and refusals.

### Changed

- The changelog is now sharded into `CHANGELOG.d/` (one file per release) per the repo split-changelog
  convention; the old `CHANGELOG.md` content is preserved verbatim.
