## You'll want to know: plausível
<!-- hl-knowledge: introduces=[PT-LEX-C368-HIPOTESE-05]; assesses=[] -->

**plausível** — "plausible, believable".

> A explicação dele é plausível.
>
> *His explanation is plausible.*

*Pouco plausível* — hardly believable.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*plausível* is a learned borrowing from Latin *plausibilis* "deserving applause, acceptable" (EtymDB, Lewis & Short), built on *plaudere* "to clap": first praiseworthy, then believable.
