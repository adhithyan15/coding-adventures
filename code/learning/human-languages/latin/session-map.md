# Session Map — Latin Chapter 1 (Greetings)

Same spaced-repetition schedule as the other tracks (a word from session *N*
resurfaces at *N+1, N+3, N+7, N+15*). Lessons named by slug; this map is the
authoritative order.

Latin uses the alphabet you already read, so there is no script to decode — the
work is the words and the endings. Each lesson's *"Sounds you'll need"* box
handles classical pronunciation.

## Chapter 1 — Greetings

| Session | Lesson | Word | Root / hook |
|---|---|---|---|
| 1 | salve | salvē / salvēte | "be well" ← *salvus*; hub for *save/safe/salute*; the *-ē/-ēte* ending |
| 2 | ave | avē / avēte | "hail" (formal) ← *avēre*; *Ave Maria* |
| 3 | vale | valē / valēte | "be strong" ← *valēre*; hub for *value/valid/prevail* |
| 4 | gratias | grātiās (tibi) agō | "I give thanks" ← *grātia*; parent of *grazie/gracias*; *-ō* = "I" |
| 5 | ita-non | ita / nōn | no plain "yes" (*ita/sīc/certē*); *sīc*→*sí/sì*; *nōn*←*ne-*→*no/not* |
| 6 | practice | (recap) | greetings + the taproot's English & Romance children |
