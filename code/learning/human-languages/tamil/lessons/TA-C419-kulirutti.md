# குளிரூட்டி (kuḷirūṭṭi) — an air conditioner

## You'll want to know: குளிரூட்டி
<!-- hl-knowledge: introduces=[TA-LEX-C419-ARAI419-01]; assesses=[] -->

**குளிரூட்டி** — *kuḷirūṭṭi* — "an air conditioner".

> அறையில் குளிரூட்டி இருந்ததால் நன்றாகத் தூங்கினோம்.
>
> *aṟaiyil kuḷirūṭṭi iruntatāl naṉṟākat tūṅkiṉōm.*
>
> Because there was an air conditioner in the room, we slept well.

குளிர், cold, + ஊட்டி, a feeder: a thing that feeds cold.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**குளிரூட்டி** (*kuḷirūṭṭi*) is a modern coinage built from குளிர், "cold" (DEDR 1834), and ஊட்டி, "a feeder", from ஊட்டு, "to feed" (DEDR 600).
