# अनावृष्टिः (anāvṛṣṭiḥ) — a drought

## You'll want to know: अनावृष्टिः
<!-- hl-knowledge: introduces=[SA-LEX-C375-VIPATTI375-04]; assesses=[] -->

**अनावृष्टिः** — *anāvṛṣṭiḥ* — "a drought".

> यदि अनावृष्टिः भवति, तर्हि कृषकः दुःखी भविष्यति।
>
> *yadi anāvṛṣṭiḥ bhavati, tarhi kṛṣakaḥ duḥkhī bhaviṣyati.*
>
> If there is a drought, the farmer will suffer.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**अनावृष्टिः** (*anāvṛṣṭiḥ*) is built from *an-*, "not", and *ā-vṛṣṭi*, "rain", from the root √vṛṣ, "to rain"; MW gives *an-āvṛṣṭi* "want of rain, drought" (MW).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
