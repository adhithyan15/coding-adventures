# فراخ دل (farākh-dil) — generous; big-hearted

## You'll want to know: فراخ دل
<!-- hl-knowledge: introduces=[UR-LEX-C384-TARBIYAT384-02]; assesses=[] -->

**فراخ دل** — *farākh-dil* — "generous; big-hearted".

> اگر وہ فراخ دل ہوتا تو مدد کرتا۔
>
> *agar voh farākh-dil hotā to madad kartā.*
>
> If he were generous, he would help.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**فراخ دل** (*farākh-dil*) is built from Persian *farākh*, "wide", and **دل**, "heart", usually traced to Persian *dil*: a wide heart.
