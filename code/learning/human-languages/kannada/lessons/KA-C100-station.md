# ನಿಲ್ದಾಣ (nildāṇa) — a station, a stop

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C100-FIND-02, KA-LEX-C100-FIND-03] -->

[PAUSE 2s] Before the new one: say the Kannada for a ticket, then the Kannada for a bus.

## You'll want to know: ನಿಲ್ದಾಣ
<!-- hl-knowledge: introduces=[KA-LEX-C100-FIND-04]; assesses=[] -->

**ನಿಲ್ದಾಣ** (*nildāṇa*) — "a station, a stop", from **ನಿಲ್ಲು** (*nillu*), "to stop,
to stand", which you know.

**ಬಸ್ ನಿಲ್ದಾಣ ಎಲ್ಲಿ?** (*bas nildāṇa elli?*) — "where is the bus stop?"

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

Where the bus stands.
