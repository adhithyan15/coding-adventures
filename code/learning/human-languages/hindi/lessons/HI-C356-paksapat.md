## You'll want to know: पक्षपात
<!-- hl-knowledge: introduces=[HI-LEX-C356-BARABAR356-03]; assesses=[] -->

**पक्षपात** — *pakṣapāt* — "bias, favouritism".

> जज को पक्षपात नहीं करना चाहिए।
>
> *jaj ko pakṣapāt nahīṃ karnā cāhiye.*
>
> A judge should not show bias.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**पक्षपात** (*pakṣapāt*) is a tatsama, borrowed from Sanskrit *pakṣapāta*, "taking a side, partiality" (Monier-Williams).
