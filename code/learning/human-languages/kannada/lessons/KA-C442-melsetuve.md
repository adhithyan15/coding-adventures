# ಮೇಲ್ಸೇತುವೆ (mēlsētuve) — a flyover

## You'll want to know: ಮೇಲ್ಸೇತುವೆ
<!-- hl-knowledge: introduces=[KA-LEX-C442-HEDDARI442-03]; assesses=[] -->

**ಮೇಲ್ಸೇತುವೆ** — *mēlsētuve* — "a flyover".

> ಹೊಸ ಮೇಲ್ಸೇತುವೆಯ ಮೇಲೆ ಕಾರುಗಳು ಓಡುತ್ತವೆ.
>
> *hosa mēlsētuveya mēle kārugaḷu ōḍuttave.*
>
> Cars run along the new flyover.

ಮೇಲ್, above, plus ಸೇತುವೆ, a bridge: a bridge over a road.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಮೇಲ್ಸೇತುವೆ** (*mēlsētuve*) is a Kannada compound of native *mēl*, "upper, above", and ಸೇತುವೆ, "a bridge", which is built on Sanskrit *sētu*, "a bond, a dam, a bridge" (Monier-Williams).
