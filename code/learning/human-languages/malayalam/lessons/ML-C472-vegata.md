## You'll want to know: വേഗത
<!-- hl-knowledge: introduces=[ML-LEX-C472-GATAGATAM472-03]; assesses=[] -->

**വേഗത** — *vēgata* — "speed".

> ഇവിടെ വണ്ടികളുടെ വേഗത കുറവാണ്.
>
> *iviṭe vaṇṭikaḷuṭe vēgata kuṟavāṇŭ.*
>
> The speed of vehicles is low here.

വേഗം is quickness; വേഗത is speed as a measure. Fast is വേഗത്തിൽ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**വേഗത** (*vēgata*) is built from Sanskrit *vega*, "a rush, speed" (Monier-Williams), with the ending *-tā*, which makes an abstract noun.
