# 生 — five measured strokes

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ZH-LEX-XUESHENG-01] -->

## Script — the shape
<!-- hl-knowledge: introduces=[ZH-SCRIPT-SHENG-01]; assesses=[] -->

Begin with the short left-fall. Add the upper horizontal and the shorter middle
horizontal. Draw the vertical through their centres, then anchor everything
with the long bottom horizontal. Five strokes; four lifts.
