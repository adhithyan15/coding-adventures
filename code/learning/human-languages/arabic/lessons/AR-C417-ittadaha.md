# اتضح (ittaḍaḥa) — to become evident

## You'll want to know: اتضح
<!-- hl-knowledge: introduces=[AR-LEX-C417-WUDUH417-04]; assesses=[] -->

**اتضح** — *ittaḍaḥa* — "to become evident".

> اتضح أن الطريق مغلق.
>
> *ittaḍaḥa anna aṭ-ṭarīq mughlaq.*
>
> It became evident that the road was closed.

Present: يتضح, *yattaḍiḥ*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**اتضح** (*ittaḍaḥa*) is built on the native Arabic root *w-ḍ-ḥ*, "to be clear, plain" (Lane). It is Form VIII, to make itself plain: to become evident. واضح, clear, is from the same root.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
