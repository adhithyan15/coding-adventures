## You'll want to know: настраивать
<!-- hl-knowledge: introduces=[RU-LEX-C515-INSTRUMENTS-05]; assesses=[] -->

**настраивать** (*nastráivat*) — "to tune; to set up".

> Перед концертом скрипач настраивает скрипку.
>
> *Péred kontsértom skripách nastráivayet skrípku.*
>
> Before the concert the violinist tunes his violin.

Imperfective; perfective настроить. Also to set up a device.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*настраивать* is built on *на-* and *строить* 'to build, to arrange'; EtymDB lists the verb without a source.
