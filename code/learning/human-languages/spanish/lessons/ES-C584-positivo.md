## You'll want to know: positivo
<!-- hl-knowledge: introduces=[ES-LEX-C584-VENTAJA-04]; assesses=[] -->

**positivo** — "positive".

> Tiene una actitud positiva.
>
> *She has a positive attitude.*

*Lo positivo* — the good side.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*positivo* is a learned borrowing from Latin *positivus* 'set down, settled', built on *ponere* 'to put' (EtymDB).
