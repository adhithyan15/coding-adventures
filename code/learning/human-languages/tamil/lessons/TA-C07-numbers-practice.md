# One to ten — the cumulative payoff

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TA-LEX-NUMBERS-1-5-01, TA-LEX-NUMBERS-6-10-01] -->

[PAUSE 2s] Count from *onru* to *pattu* once without looking. No new word or
shape appears in this lesson.

## Guided Practice — read, not recite
<!-- hl-knowledge: introduces=[]; assesses=[TA-LEX-NUMBERS-1-5-01, TA-LEX-NUMBERS-6-10-01] -->

Read these shuffled numerals:

- First row: **௭ ௨ ௰ ௫ ௮**
- Second row: **௩ ௯ ௧ ௬ ௪**

Now check against **௧ ௨ ௩ ௪ ௫ ௬ ௭ ௮ ௯ ௰**.
