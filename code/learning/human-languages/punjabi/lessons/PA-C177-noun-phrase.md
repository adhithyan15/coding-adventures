## Grammar Lens: the words work as one noun phrase
<!-- hl-knowledge: introduces=[PA-GRAMMAR-MULTIWORD-NP-01]; assesses=[PA-GRAMMAR-NOUN-GENDER-01, PA-GRAMMAR-ADJ-PRENOMINAL-01, PA-GRAMMAR-ADJ-GENDER-AGREEMENT-01, PA-ADV-BAHUT-DEGREE-01, PA-DEM-EH-01, PA-LEX-C55-FAMILY55-04, PA-LEX-CHANGA, PA-LEX-HAI-02, PA-GRAMMAR-VERB-LAST-02] -->

> **ਇਹ ਬਹੁਤ ਚੰਗੀ ਕੁੜੀ ਹੈ।**
>
> *eh bahut changī kuṛī hai.*
>
> This is a very good girl.

Before **ਹੈ**, the words **ਬਹੁਤ ਚੰਗੀ ਕੁੜੀ** travel together as a multiword
noun phrase: degree word + agreeing adjective + noun. The noun is feminine, so
the variable adjective is **ਚੰਗੀ**. The verb remains last.

This proves only this one bounded singular direct pattern. It does not add noun
plural, genitive, an article, or a rule for every Punjabi adjective.
