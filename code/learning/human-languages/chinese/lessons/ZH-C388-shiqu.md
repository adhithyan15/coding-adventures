## You'll want to know: 时区
<!-- hl-knowledge: introduces=[ZH-LEX-C388-DATE388-05]; assesses=[] -->

**时区** — *shíqū* — "time zone".

> **我们不在一个时区所以要先约好时间** *wǒmen bú zài yí ge shíqū suǒyǐ yào xiān yuē hǎo shíjiān* — We're not in the same time zone, so we need to fix a time first.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**时区** (*shíqū*) is built from 时 'time' and 区 'an area', both inherited from Middle Chinese, *dzyi* and *khju* (Guangyun, in Baxter's transcription), which glosses the first 'an hour of the day'. The word is modern.
