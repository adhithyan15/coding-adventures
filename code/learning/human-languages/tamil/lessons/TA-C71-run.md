## You'll want to know: ஓடு
<!-- hl-knowledge: introduces=[TA-LEX-C71-DAY-03]; assesses=[] -->

**ஓடு** (*ōḍu*) — "to run".

"To run" — and the first word in this book that **begins** with the letter you met one lesson
ago.

It is not only for people. Water runs, and so does a வண்டி on a சாலை: Tamil uses this same
verb for all three, where English would want "flow" for one of them.

Two letters, one sign, and you can read every part of it.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

Three, and something is moving.
