## You'll want to know: el ciudadano
<!-- hl-knowledge: introduces=[ES-LEX-C600-SOCIEDAD-04]; assesses=[] -->

**el ciudadano** — "the citizen".

> Todos los ciudadanos pueden votar.
>
> *All citizens can vote.*

A woman is *la ciudadana*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*ciudadano* is built on *ciudad*, inherited from Latin *civitatem* 'city, state', built on *civis* 'citizen' (EtymDB).
