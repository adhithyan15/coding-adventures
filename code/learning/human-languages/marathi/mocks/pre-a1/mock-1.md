# Marathi pre-A1 mock 1 — learner paper

Give this paper to the learner. Keep
[`mock-1-examiner-script.md`](mock-1-examiner-script.md) separate. Total
administration is 32 written minutes plus 8 speaking minutes. Support-language
directions may explain the action but may not translate answer-bearing Marathi.

## Reading — 10 minutes

Choose the English meaning or situation.

<!-- mock-part:prea1-reading-signs-and-words -->
1. **नाव** — A name / B water / C book
2. **पाणी** — A school / B water / C home
3. **पुस्तक** — A book / B greeting / C name
4. **घर** — A water / B home / C school
5. **शाळा** — A teacher / B book / C school
6. **नमस्कार** — A greeting / B refusal / C place
<!-- /mock-part:prea1-reading-signs-and-words -->
<!-- mock-part:prea1-reading-phrases-and-notices -->
7. **धन्यवाद.** — A thanks / B a name / C a question
8. **बसा.** — A Please sit. / B Please speak. / C Please leave.
9. **पुन्हा भेटू.** — A See you again. / B I am well. / C My name is Mira.
10. **उद्या भेटू.** — A Please sit. / B Thank you. / C See you tomorrow.
<!-- /mock-part:prea1-reading-phrases-and-notices -->
<!-- mock-part:prea1-reading-personal-details -->
11. **माझं नाव मीरा आहे.** — A The name is Mira. / B The city is Mira. / C Mira wants water.
12. **मी पुण्यात राहतो.** — A I live in Pune. / B I am leaving Pune. / C My name is Pune.
13. **मी बरा आहे.** — A I am well. / B I am at home. / C I am a teacher.
14. Form field **शहर: पुणे** — A name Pune / B city Pune / C language Pune
<!-- /mock-part:prea1-reading-personal-details -->

## Listening — 10 minutes

Listen to each numbered item twice. Choose A, B, or C. The examiner's Marathi
lines stay in the separate script.

<!-- mock-part:prea1-listening-sounds-and-words -->
1. A name / B water / C tea
2. A tea / B home / C water
3. A book / B school / C greeting
4. A water / B home / C name
5. A school / B teacher / C city
6. A name / B greeting / C water
<!-- /mock-part:prea1-listening-sounds-and-words -->
<!-- mock-part:prea1-listening-greeting-responses -->
7. A return the greeting / B request water / C state a place
8. A say thanks / B state a name / C ask for a book
9. A state a name / B state how you are / C request tea
10. A return the farewell / B introduce yourself / C ask a question
<!-- /mock-part:prea1-listening-greeting-responses -->
<!-- mock-part:prea1-listening-personal-details -->
11. A name Sima / B city Sima / C school Sima
12. A lives in Pune / B going to Pune / C named Pune
13. A speaks Marathi / B reads a name / C wants water
14. A is well / B is at school / C says no
<!-- /mock-part:prea1-listening-personal-details -->

## Writing — 12 minutes

<!-- mock-part:prea1-writing-delayed-recall -->
1. Look at the examiner's first word card for ten seconds. After it is covered,
   write the word once: ____________________
2. Look at the second word card for ten seconds. After it is covered, write the
   word once: ____________________
<!-- /mock-part:prea1-writing-delayed-recall -->
<!-- mock-part:prea1-writing-dictation -->
3. Listen to item W3 twice and write the word: ____________________
4. Listen to item W4 twice and write the word: ____________________
5. Listen to item W5 twice and write the word: ____________________
6. Listen to item W6 twice and write the word: ____________________
<!-- /mock-part:prea1-writing-dictation -->
<!-- mock-part:prea1-writing-bounded-production -->
7. Write your own name in Devanagari after **नाव:**. No answer model is shown.
8. Write one Marathi greeting appropriate for meeting a person. No answer
   model is shown.
<!-- /mock-part:prea1-writing-bounded-production -->

## Speaking — 8 minutes

Answer each prompt in Marathi. The examiner may repeat each prompt once slowly.
The spoken prompts stay in the separate script.

<!-- mock-part:prea1-speaking-greeting-and-identity -->
1. Return the examiner's greeting.
2. State your chosen identity.
<!-- /mock-part:prea1-speaking-greeting-and-identity -->
<!-- mock-part:prea1-speaking-familiar-questions -->
3. Answer a familiar question about how you are.
4. Answer a familiar question about where you live.
5. Answer a familiar question about speaking Marathi.
<!-- /mock-part:prea1-speaking-familiar-questions -->
<!-- mock-part:prea1-speaking-short-request -->
6. Make one short polite request for water in the situation the examiner gives.
<!-- /mock-part:prea1-speaking-short-request -->

No written answer script, dictionary, translator, or coaching is allowed.
