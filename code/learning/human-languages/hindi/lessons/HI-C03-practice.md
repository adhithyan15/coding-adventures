# Chapter 3 — The how-are-you exchange

## Warm-up

[PAUSE 2s] No new words. The whole responding cycle, assembled from atoms you now
own.

## The exchange

[PAUSE 1s each]
- [YOU SAY: "How are you?" (respectful) — *āp kaise haiṁ?*]
- [YOU SAY: "I'm fine, thank you." — *maiṁ ṭhīk hūṁ, dhanyavād.*]
- [YOU SAY: "You're welcome." — *āpkā svāgat hai.*]
- [YOU SAY: the familiar version of the question — *tum kaise ho?*]

## The atoms

[PAUSE 2s]
- [YOU SAY: the k- question-word for "how" (*kaise*)]
- [YOU SAY: "I" and "am" (*maiṁ*, *hūṁ*)]
- [YOU SAY: the copula trio you now hold (*hūṁ / hai / haiṁ*)]

## Roots you now carry

[PAUSE 2s]
- *kaise* ← the interrogative *k-* (PIE *\*kʷo-*), cousin of English *how/what*
- *maiṁ* ← *ma-* (PIE *\*me-*), cousin of English *me/my*
- *hūṁ* ← Sanskrit *asmi*, cousin of English **am**
- *svāgat* ← *su* + *āgata* = "well come," matching English **welcome**

## Wrap-up Recall

[PAUSE 3s] A stranger asks *āp kaise haiṁ?* — give a complete, polite reply, then
thank-and-welcome the exchange back. (*Maiṁ ṭhīk hūṁ, dhanyavād.* — and if
thanked, *āpkā svāgat hai.*)
