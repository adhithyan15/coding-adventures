## Grammar Lens
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-YATRI-202, PA-DEM-EH-01, PA-LEX-HAI-02, PA-GRAMMAR-VERB-LAST-02] -->

> **ਇਹ ਯਾਤਰੀ ਹੈ** — *eh yātrī hai* — this person is a traveller

Keep the new whole noun between familiar **ਇਹ** and **ਹੈ**. Familiar **ਹੈ**
stays last in the already-owned identity frame. This chapter teaches only this
one person label; it does not add a form rule or a wider construction.
