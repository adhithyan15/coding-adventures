# ँ — the moon holding a dot

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[] -->

You already write one nasal mark above the headline. Here is its second, softer cousin.

## Script
<!-- hl-knowledge: introduces=[MR-SCRIPT-CANDRABINDU-01]; assesses=[MR-SCRIPT-RU-MATRA-01, MR-SCRIPT-ANUSVARA-01] -->

> ँ

The **candrabindu** is one dot cradled in a small upward crescent — a moon
holding a dot, which is exactly what its name says.

Set it beside the anusvāra you already write:

**ं** closes the vowel onto a nasal consonant. **ँ** leaves the vowel open and
sends the air through the nose while you are still saying it. Draw the crescent
first, sitting on the headline, then place the single dot inside it.

## Writing — observe and trace
<!-- hl-knowledge: introduces=[]; assesses=[MR-SCRIPT-CANDRABINDU-01] -->
<!-- hl-writing-stage: observe-trace -->

Trace **ँ** twice, then trace **ं** once beside it. Point at which of the two
carries a crescent. Repair only the mark that came out wrong.
