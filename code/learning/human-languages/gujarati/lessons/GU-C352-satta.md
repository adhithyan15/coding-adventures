# સત્તા (sattā) — power to rule

## You'll want to know: સત્તા
<!-- hl-knowledge: introduces=[GU-LEX-C352-SARKAR352-03]; assesses=[] -->

**સત્તા** — *sattā* — "power to rule".

> નિયમ બદલવાની સત્તા ફક્ત સરકાર પાસે છે.
>
> *niyam badalvānī sattā phakt sarkār pāse che.*
>
> Only the government has the power to change the rules.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**સત્તા** (*sattā*) is borrowed from Sanskrit *sattā*, "existence, being" (Monier-Williams); "power, authority" is the sense it has taken in Gujarati.
