## You'll want to know: पत्रिका
<!-- hl-knowledge: introduces=[HI-LEX-C397-VISHAY397-02]; assesses=[] -->

**पत्रिका** — *patrikā* — "a magazine".

> अगर तुम पढ़ोगे तो यह पत्रिका तुम्हें बहुत अच्छी लगेगी।
>
> *agar tum paṛhoge to yah patrikā tumhẽ bahut acchī lagegī.*
>
> If you read it, you'll like this magazine a lot.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**पत्रिका** (*patrikā*) is a tatsama, borrowed from Sanskrit *pattrikā*, "a leaf; a letter, a document" (Monier-Williams).
