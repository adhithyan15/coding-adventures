# लिख दीजिए (likh dījie) — please write it down

## Warm-up

## You'll want to know: लिख दीजिए
<!-- hl-knowledge: introduces=[HI-LEX-C111-ASK-05]; assesses=[] -->

**लिख दीजिए** (*likh dījie*) — "please write it down (for me)".

**लिखना** is "to write"; **दीजिए** adds "for me", as in **एक चाय दीजिए**.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

In Hindi, how do you say it, show me, I could not hear, write it down.
