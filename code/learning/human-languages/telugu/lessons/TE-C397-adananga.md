# అదనంగా (adanaṅgā) — in addition; extra

## You'll want to know: అదనంగా
<!-- hl-knowledge: introduces=[TE-LEX-C397-SANKSIPTAM397-02]; assesses=[] -->

**అదనంగా** — *adanaṅgā* — "in addition; extra".

> ఆదివారం పని చేస్తే అదనంగా డబ్బు ఇస్తారు.
>
> *ādivāraṁ pani cēstē adanaṅgā ḍabbu istāru.*
>
> If you work on Sunday they pay extra.

Before a noun: అదనపు ఖర్చు, an extra cost.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**అదనంగా** (*adanaṅgā*) is native Dravidian: DEDR 136 lists Telugu *adanamu*, "exceeding, much, excessive"; -గా makes the adverb.
