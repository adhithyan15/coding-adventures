## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**حلق** (*ḥalq*) is built on the native Arabic root *ḥ-l-q*, "the throat; to shave" (Lane). *Ḥalq* is the throat.
