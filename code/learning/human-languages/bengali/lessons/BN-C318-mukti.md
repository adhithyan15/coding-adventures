## You'll want to know: মুক্তি
<!-- hl-knowledge: introduces=[BN-LEX-C318-BIPLOB318-05]; assesses=[] -->

**মুক্তি** — *mukti* — "liberation; release".

> যুদ্ধের পরে কয়েদিরা মুক্তি পেল।
>
> *juddher pôre kôyedirā mukti pelô.*
>
> After the war the prisoners were set free.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**মুক্তি** (*mukti*) is Sanskrit *mukti*, 'setting free, release' (Monier-Williams). মুক্তি পাওয়া, to be set free.
