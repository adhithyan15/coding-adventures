# Repair endings before values

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MR-A1-FORM-AGREEMENT-NEUTER, MR-A1-FORM-AGREEMENT-FEMININE, MR-A1-FORM-POSSESSIVE-NEUTER] -->

Cover the values. Look only at the labels and say: neuter drink **-ते**,
feminine activity **-ती**, neuter name **-चे**.

value spelling.
