## You'll want to know: survoler
<!-- hl-knowledge: introduces=[FR-LEX-C419-DECOLLAGE-05]; assesses=[] -->

**survoler** — "to fly over".

> Pendant le vol, nous avons survolé les montagnes.
>
> *During the flight we flew over the mountains.*

Figurative: *survoler un texte* — to skim a text.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*survoler* is built from *sur* 'over' and *voler* 'to fly', which is inherited from Latin *volāre* (Lewis & Short). EtymDB does not list the compound.
