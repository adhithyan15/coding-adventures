# ತಾತ್ಕಾಲಿಕ (tātkālika) — temporary

## You'll want to know: ತಾತ್ಕಾಲಿಕ
<!-- hl-knowledge: introduces=[KA-LEX-C418-PARYAYA418-03]; assesses=[] -->

**ತಾತ್ಕಾಲಿಕ** — *tātkālika* — "temporary".

> ಇದು ತಾತ್ಕಾಲಿಕ ಕೆಲಸ, ಮೂರು ತಿಂಗಳು ಮಾತ್ರ.
>
> *idu tātkālika kelasa, mūru tiṅgaḷu mātra.*
>
> This is temporary work, only three months.

ತಾತ್ಕಾಲಿಕವಾಗಿ, for the time being.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ತಾತ್ಕಾಲಿಕ** (*tātkālika*) is borrowed from Sanskrit *tātkālika*, "lasting that time" (Monier-Williams), from *tat-kāla*, "that time".
