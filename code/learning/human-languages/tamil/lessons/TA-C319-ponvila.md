# பொன்விழா (poṉviḻā) — a golden jubilee

## You'll want to know: பொன்விழா
<!-- hl-knowledge: introduces=[TA-LEX-C319-AANDU319-02]; assesses=[] -->

**பொன்விழா** — *poṉviḻā* — "a golden jubilee".

> கடையின் பொன்விழாவைப் பெரிதாகக் கொண்டாடினார்கள்.
>
> *kaṭaiyiṉ poṉviḻāvaip peritākak koṇṭāṭiṉārkaḷ.*
>
> They celebrated the shop's golden jubilee in a big way.

பொன், gold: fifty years; வெள்ளிவிழா, silver, is twenty-five.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**பொன்விழா** (*poṉviḻā*) is a Tamil compound built from பொன், "gold" (DEDR 4570), and விழா, "festival" (DEDR 5427).
