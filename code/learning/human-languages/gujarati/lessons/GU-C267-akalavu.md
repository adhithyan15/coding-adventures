# અકળાવું (akḷāvũ) — to feel restless, to be fed up

## You'll want to know: અકળાવું
<!-- hl-knowledge: introduces=[GU-LEX-C267-UPSET267-03]; assesses=[] -->

**અકળાવું** — *akḷāvũ* — "to feel restless, to be fed up".

> **શું તમે ગરમીમાં અકળાઓ છો?** — *śũ tame garmīmā̃ akḷāo cho?* — "Do you feel restless in the heat?"

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**અકળાવું** (*akḷāvũ*) is a tadbhava. CDIAL lists it, glossed "to be perplexed", under Sanskrit *ākula*, "confused; crowded" (CDIAL 1012).
