# पुरेसा (puresā) — enough

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MR-LEX-THODA, MR-LEX-KHUP] -->

[PAUSE 2s] A little and a lot are both amounts. Neither one says the amount is
right.

## You'll want to know: पुरेसा
<!-- hl-knowledge: introduces=[MR-LEX-PURESA]; assesses=[MR-GRAMMAR-ADJ-AGREEMENT, MR-LEX-PAANI, MR-LEX-CHAHA] -->

> **पुरेसा** — *puresā* — **enough, sufficient**

> **पुरेसं पाणी**
> — *puresaṁ pāṇī* — **enough water**

Another **-आ** word, so it agrees and you already have all three forms:
**पुरेसा चहा**, **पुरेसं पाणी**.

Said on its own it closes a transaction. **पुरे!** is *that's enough*, and a
Marathi host pouring tea will stop when you say it — which is a more useful
thing to own than it sounds, because the alternative is **नको**, and **नको**
refuses the whole offer rather than the next spoonful.

That **पुरे** is the word underneath **पुरेसा**, and it comes from the Sanskrit
root **पूर्** (*pūr-*), "**to fill**." Enough is *filled*. The same ancient
root gives Latin *plenus* and English **full**, so the idea has travelled a
long way without changing.
