# પ્રવાહ (pravāh) — a current; a flow

## You'll want to know: પ્રવાહ
<!-- hl-knowledge: introduces=[GU-LEX-C440-STREAM440-02]; assesses=[] -->

**પ્રવાહ** — *pravāh* — "a current; a flow".

> ચોમાસામાં નદીનો પ્રવાહ ઘણો ઝડપી છે.
>
> *comāsāmā̃ nadīno pravāh ghaṇo jhaḍpī che.*
>
> In the monsoon the river's current is very fast.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**પ્રવાહ** (*pravāh*) is a tatsama, Sanskrit *pravāha*, "a stream, a current" (Monier-Williams), built on *vah*, to carry: what carries things along.
