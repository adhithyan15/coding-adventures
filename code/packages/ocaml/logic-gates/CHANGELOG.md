# Changelog

All notable changes to this package will be documented in this file.

## [0.1.0] - 2026-09-05

### Added

- Added validated primitive, NAND-derived, and n-ary gates.
- Added deterministic combinational circuits with LSB-first selector ordering.
- Added explicit-state latches, flip-flops, registers, shift registers, and
  wrapping counters.
- Added Alcotest coverage for valid behavior, malformed inputs, and invalid
  state shapes.
