# One visible message from old blocks

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-SKILL-CONNECTED-READING] -->

Every line below has already been practised alone or in a short pair.
Today the only new demand is assembly for Manan. Read the opening and closing
first, then find the small body blocks between them.

## Reading — one supported order
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-NAMASTE-01, PA-PHRASE-HOW-ARE-YOU-03, PA-GRAMMAR-DATIVE-LIKING, PA-LEX-JALDI, PA-PHRASE-SEE-YOU-AGAIN-04] -->

> ਨਮਸਤੇ ਮਨਨ। ਤੁਸੀਂ ਕਿਵੇਂ ਹੋ?
>
> ਮੇਰਾ ਨਾਂ ਅਮਨ ਹੈ। ਮੈਂ ਪੰਜਾਬੀ ਬੋਲਦਾ ਹਾਂ। ਮੈਂ ਠੀਕ-ਠਾਕ ਹਾਂ।
>
> ਮੈਨੂੰ ਪੰਜਾਬੀ ਪਸੰਦ ਹੈ। ਮੈਨੂੰ ਪੜ੍ਹਨਾ ਪਸੰਦ ਹੈ।
>
> ਅਸੀਂ ਜਲਦੀ ਮਿਲਾਂਗੇ। ਧੰਨਵਾਦ। ਫਿਰ ਮਿਲਾਂਗੇ।

Count the space-separated words: **30**. The greeting and question face the
reader; the middle shares familiar facts and interests; the meeting plan
leads into thanks and goodbye.

## Writing — supported assembly
<!-- hl-knowledge: introduces=[]; assesses=[PA-SKILL-CONNECTED-READING, PA-GRAMMAR-DATIVE-LIKING] -->
<!-- hl-writing-stage: guided-copy -->

Copy one line at a time, pausing after each line. Keep the reader's question
mark distinct from the Gurmukhi sentence marks. Check meaning and order
before spelling. This is a visible model, not independent composition.
