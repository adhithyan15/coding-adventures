# ఆహ్వానం (āhvānaṁ) — an invitation

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TE-LEX-C99-WELCOME-03, TE-LEX-C99-WELCOME-04] -->

[PAUSE 2s] Before the new one: say the Telugu for congratulations, then the Telugu for a gift.

## You'll want to know: ఆహ్వానం
<!-- hl-knowledge: introduces=[TE-LEX-C99-WELCOME-05]; assesses=[] -->

**ఆహ్వానం** (*āhvānaṁ*) — "an invitation".

**పెళ్ళికి ఆహ్వానం** — "an invitation to the wedding", with **-కి**, "to". It is the reason for
most of the visits this book has taught you to make.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

Namaste, delight, congratulations, a gift, an invitation: the way into a visit.
