# Changelog — coding_adventures_image_geometric_transforms

## 0.1.0 — 2026-07-13

- Add exact horizontal/vertical flips, right-angle rotations, crop, and pad.
- Add scale, arbitrary rotation, affine transforms, and perspective warps.
- Add nearest, bilinear, and Catmull-Rom bicubic sampling.
- Add zero, replicate, reflect, and wrap out-of-bounds policies.
- Blend interpolated RGB channels in linear light and alpha linearly.
