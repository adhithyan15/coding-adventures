## You'll want to know: கல்லூரி
<!-- hl-knowledge: introduces=[TA-LEX-C105-WORK-03]; assesses=[] -->

**கல்லூரி** (*kallūri*) — "a college".

It is built on **கல்**, "to learn": a college is a *learning-place*.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

Where a student studies.
