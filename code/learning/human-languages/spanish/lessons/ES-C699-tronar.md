## You'll want to know: tronar
<!-- hl-knowledge: introduces=[ES-LEX-C699-TORMENTA-05]; assesses=[] -->

**tronar** — "to thunder".

> Truena mucho esta noche.
>
> *It is thundering a lot tonight.*

The o becomes ue: *truena*. *El trueno* is thunder.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*tronar* is inherited from Latin *tonāre* "to thunder" (EtymDB), like *trueno* "thunder".
