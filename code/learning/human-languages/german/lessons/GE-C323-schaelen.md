## You'll want to know: schälen
<!-- hl-knowledge: introduces=[GE-LEX-C323-SCHAELEN-01]; assesses=[] -->

**schälen** — "to peel".

> Zuerst schälte er die Kartoffeln.
>
> *First he peeled the potatoes.*

Built on *die Schale* — peel, skin; also a bowl.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*schälen* is built on *Schale* "peel, shell", an inherited Germanic word from Old High German *scāla* "shell, bowl" (EtymDB).
