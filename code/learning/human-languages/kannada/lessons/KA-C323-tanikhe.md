# ತನಿಖೆ (tanikhe) — an investigation

## You'll want to know: ತನಿಖೆ
<!-- hl-knowledge: introduces=[KA-LEX-C323-APARADHA323-04]; assesses=[] -->

**ತನಿಖೆ** — *tanikhe* — "an investigation".

> ಪೊಲೀಸರು ಆ ಘಟನೆಯ ತನಿಖೆ ಶುರು ಮಾಡಿದರು.
>
> *polīsaru ā ghaṭaneya tanikhe śuru māḍidaru.*
>
> The police began an investigation into that incident.

ತನಿಖೆ ಮಾಡು, to investigate. What is investigated takes the possessive -ಅ: ಘಟನೆಯ ತನಿಖೆ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ತನಿಖೆ** (*tanikhe*) is usually traced to Hindustani *tanqīh*, "an inquiry, an investigation", a word of Arabic origin; the path into Kannada is not settled.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->
