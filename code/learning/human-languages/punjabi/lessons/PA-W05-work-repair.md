# Repair one work-field difference

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-WORK-JOB-01, PA-FORM-WORK-SPACING-01, PA-FORM-WORK-AGREEMENT-01] -->

Compare **ਕੰਮ:ਨੌਕਰੀ** with **ਕੰਮ: ਨੌਕਰੀ**. The selection, letters, and field-value meaning match; one boundary differs.

## Writing — one repair pass
<!-- hl-knowledge: introduces=[PA-FORM-WORK-REPAIR-01]; assesses=[PA-FORM-WORK-JOB-01, PA-FORM-WORK-SPACING-01, PA-FORM-WORK-AGREEMENT-01] -->

Rewrite the first line with a clear space after the colon. Leave every letter unchanged.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-WORK-REPAIR-01] -->

Name the repaired dimension: selection, spelling, spacing, agreement, or placement. Stop after one repair.
