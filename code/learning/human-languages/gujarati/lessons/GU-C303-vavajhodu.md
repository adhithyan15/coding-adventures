## You'll want to know: વાવાઝોડું
<!-- hl-knowledge: introduces=[GU-LEX-C303-VAVAZODU303-01]; assesses=[] -->

**વાવાઝોડું** — *vāvājhoḍũ* — "a cyclone".

> ગઈકાલે રાત્રે દરિયા કિનારે મોટું વાવાઝોડું આવ્યું.
>
> *gaīkāle rātre dariyā kināre moṭũ vāvājhoḍũ āvyũ.*
>
> Last night a big cyclone hit the coast.

A neuter noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

is probably built on *vā*, wind, which CDIAL lists for Gujarati under Sanskrit *vāyú*, "wind" (CDIAL 11544); no dictionary we use records the rest of the word, so its history is not settled. It is neuter, and it **આવે છે**, comes: **વાવાઝોડું આવ્યું**. **તોફાન** is any storm; a **વાવાઝોડું** is a whirling one.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
