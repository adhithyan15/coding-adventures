# CodingAdventures.WasmModuleEncoder.FSharp

A pure F# encoder for the WebAssembly 1.0 binary module format. It serializes
the shared `WasmModule` IR into canonical section order, groups adjacent local
types, emits unsigned LEB128 lengths and indices, and validates import
descriptors before writing bytes.

```fsharp
open CodingAdventures.WasmModuleEncoder.FSharp
open CodingAdventures.WasmTypes.FSharp

let moduleValue = WasmModule()
moduleValue.Types.Add(WasmTypes.makeFuncType [] [])
moduleValue.Functions.Add(0)
moduleValue.Code.Add(FunctionBody([], [| 0x0Buy |]))

let binary = WasmModuleEncoder.encodeModule moduleValue
```

The package depends only on the sibling pure-F# `wasm-leb128` and `wasm-types`
packages. Tests round-trip the generated bytes through the sibling
`wasm-module-parser` package.
