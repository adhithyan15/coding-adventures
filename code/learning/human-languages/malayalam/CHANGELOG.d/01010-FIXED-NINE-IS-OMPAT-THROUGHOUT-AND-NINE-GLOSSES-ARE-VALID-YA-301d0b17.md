## Fixed — nine is ompatŭ throughout, and nine glosses are valid YAML

- **ഒമ്പത് "nine" is *ompatŭ* everywhere.** The track spelled it *ombatŭ* in ML-C07-numbers-6-10 (headword, table, blocks and recall), ML-C07-numbers-practice, ML-W07-digits-9-10, ML-W07-number-words-6-10, ML-W07-numbers-6-10-dictation and ML-C75-umbol, and *ompatŭ* / *ompatāṁ* in ML-C68-ninth, ML-C68-tenth, ML-R69 and ML-R70. Every occurrence was checked against its codepoints (U+0D12 U+0D2E U+0D4D U+0D2A U+0D24 U+0D4D): the cluster is മ് + പ, so it takes the letter value for പ, *p*, that most of the track already uses for this cluster, as in *pāmpŭ*, *kompŭ*, *sampattŭ*, *nampar* and *uṟumpŭ*. The compound പത്തൊമ്പത് "nineteen" in ML-C20-pathinonnu-irupathu follows, *pattombatŭ* → *pattompatŭ*; *ompatāṁ* "ninth" already matched. The README, roadmap and session map do not spell the word, so they are unchanged. The book chapters and narration are regenerated to match. Four other words still write മ്പ as *mb* (*māmbaḻaṁ*, *viḷambuka*, *gōtambŭ*, *śambaḷaṁ*); they are left for a separate pass.
- **Nine glosses are one YAML scalar each.** ML-C23-divasam, ML-C24-rathri, ML-C25-shubha-rathri, ML-C26-raavile, ML-C27-vaikunneram, ML-C28-uchakazhinju, ML-C29-suprabhaatham, ML-C30-shubha-sayaahnam and ML-C31-shubha-madhyaahnam had a `gloss:` that opened with a quoted English word and went on past the closing quote (`gloss: "day" — …`), which a strict YAML parser rejects. Each is now single-quoted, with an apostrophe written `''`. The wording is unchanged, and the repository's reader and PyYAML return the same text the reader returned before.
