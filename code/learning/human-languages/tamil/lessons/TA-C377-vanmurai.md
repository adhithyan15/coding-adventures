# வன்முறை (vaṉmuṟai) — violence

## You'll want to know: வன்முறை
<!-- hl-knowledge: introduces=[TA-LEX-C377-VANMURAI377-01]; assesses=[] -->

**வன்முறை** — *vaṉmuṟai* — "violence".

> நாங்கள் வன்முறையை ஏற்றுக்கொள்ள மாட்டோம்.
>
> *nāṅkaḷ vaṉmuṟaiyai ēṟṟukkoḷḷa māṭṭōm.*
>
> We will not accept violence.

வல், hard + முறை, way: the hard way.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**வன்முறை** (*vaṉmuṟai*) is native: *val*, "strong, hard, forceful" (DEDR 5276), whose l becomes ன் before m, and *muṟai*, "order, way" (DEDR 5015).
