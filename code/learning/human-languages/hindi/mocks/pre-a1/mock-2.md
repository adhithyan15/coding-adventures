# Hindi pre-A1 mock 2 — learner paper and examiner script

This is an independent parallel form, not a rehearsal copy of mock 1. Total
administration: 32 written minutes plus 8 speaking minutes. Remove all visible
models before writing begins.

## Reading — 10 minutes

1. **हिंदी** — A Hindi / B water / C school
2. **शुक्रिया** — A thanks / B bus / C home
3. **हाँ** — A no / B yes / C name
4. **नहीं** — A tea / B yes / C no
5. **दिल्ली** — A Delhi / B Hindi / C Ravi
6. **आगरा** — A water / B Agra / C school
7. **आप कैसे हैं?** — A How are you? / B What is your name? / C Where is the bus?
8. **मेरा नाम रवि है।** — A My name is Ravi. / B I am from Ravi. / C Ravi is fine.
9. **मैं ठीक हूँ।** — A I am fine. / B I speak Hindi. / C I want tea.
10. **आपका स्वागत है।** — A You are welcome. / B Thank you. / C Goodbye.
11. Form field **शहर: आगरा** — A city Agra / B name Agra / C language Agra
12. Form field **भाषा: हिंदी** — A city Hindi / B language Hindi / C name Hindi
13. **मैं हिंदी बोलती हूँ।** — A A woman says she speaks Hindi. / B A man asks a name. / C Someone wants water.
14. **फिर मिलेंगे।** — A See you again. / B Please sit. / C No, thank you.

## Listening — 10 minutes

Read each line twice at 70–90 words per minute and pause eight seconds.

1. **हिंदी**. A Hindi / B tea / C bus
2. **शुक्रिया**. A thanks / B home / C no
3. **हाँ**. A yes / B no / C name
4. **नहीं**. A water / B no / C school
5. **दिल्ली**. A Agra / B Delhi / C Hindi
6. **आगरा**. A Agra / B Ravi / C water
7. **नमस्ते।** A नमस्ते। / B नहीं। / C चाय।
8. **शुक्रिया।** A आपका स्वागत है। / B मेरा नाम। / C घर।
9. **आपका नाम क्या है?** A मेरा नाम अमन है। / B मैं ठीक हूँ। / C पानी।
10. **आप कैसे हैं?** A फिर मिलेंगे। / B मैं ठीक हूँ। / C मेरा नाम।
11. **मेरा नाम अमन है।** A name Aman / B city Aman / C language Aman
12. **मैं जयपुर से हूँ।** A named Jaipur / B from Jaipur / C speaks Jaipur
13. **मैं हिंदी बोलती हूँ।** A woman speaks Hindi / B man wants tea / C person is at school
14. **मेरा नाम लीला है।** A city Lila / B name Lila / C language Lila

## Writing — 12 minutes

1. Five-second delayed recall: **शुक्रिया**.
2. Five-second delayed recall: **हिंदी**.
3. Dictation, twice: **नाम**.
4. Dictation, twice: **पानी**.
5. Dictation, twice: **नमस्ते**.
6. Dictation, twice: **ठीक**.
7. Independently write one Devanagari place name you know after **शहर:**.
8. Independently write one Hindi thanks expression. No visible model remains.

## Speaking — 8 minutes

1. Return the interlocutor's **नमस्ते।**
2. Answer **आपका नाम क्या है?** with a chosen identity.
3. Answer **आप कैसे हैं?**
4. Answer **आप कहाँ से हैं?**
5. Answer **क्या आप हिंदी बोलते हैं?** or **क्या आप हिंदी बोलती हैं?** as appropriate.
6. Situation: you want tea. Make one short polite request in Hindi.

The interlocutor may repeat once slowly. No answer script or romanization is
shown.
