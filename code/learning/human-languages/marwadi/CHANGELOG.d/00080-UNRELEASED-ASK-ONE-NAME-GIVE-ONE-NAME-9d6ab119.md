## Unreleased — ask one name, give one name

- Added an eighteen-session Chapters 5–6 runway for **थारो नाम कांई है?** and
  **म्हारो नाम राम है।**, beginning each lexical chunk by ear.
- Isolated the seven new signs — **्, ो, न, ै, थ, क, ई** — in separate
  <=2.5-minute steps before any complete word asks the learner to read them.
- Reused known **राम** as the first writable name, then allowed a chosen name in
  speech so script difficulty does not block personal expression.
- Realized `SPINE-EXCHANGE-NAMES` with separately scored listening, speaking,
  reading, and independent writing instead of counting a level label as mastery.
- Named regional variation explicitly: these are documented central-Marwari
  Devanagari forms, not a claim that every Marwadi variety uses one pair.
