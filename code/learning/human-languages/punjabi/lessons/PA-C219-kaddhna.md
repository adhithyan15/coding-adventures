# ਕੱਢਣਾ (kaḍḍhṇā) — to take out

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-GRAMMAR-PAST-KHADHA-219, PA-LEX-C71-HOME71-02] -->

[PAUSE 2s] Before the new one: say *I ate a roti*, then *a book*.

## You'll want to know: ਕੱਢਣਾ
<!-- hl-knowledge: introduces=[PA-LEX-KADDHNA-219]; assesses=[PA-LEX-C71-HOME71-02, PA-GRAMMAR-PAST-OBJECT-219] -->

**ਕੱਢਣਾ** — *kaḍḍhṇā* — "to take out". It is done to something, so its past
agrees with the thing:

> **ਮੈਂ ਕਿਤਾਬ ਕੱਢੀ।** — *maiṁ kitāb kaḍḍhī.* — I took out the book.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ਕੱਢਣਾ** (*kaḍḍhṇā*) is inherited: CDIAL lists Punjabi *kaḍḍhṇā*, "to pull out",
under a reconstructed *\*kaḍḍhati*, "pulls, draws" (CDIAL 2660).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for talking about the past.
