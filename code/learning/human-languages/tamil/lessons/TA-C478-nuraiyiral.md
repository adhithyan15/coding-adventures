# நுரையீரல் (nuraiyīral) — a lung

## You'll want to know: நுரையீரல்
<!-- hl-knowledge: introduces=[TA-LEX-C478-UTAL478-02]; assesses=[] -->

**நுரையீரல்** — *nuraiyīral* — "a lung".

> புகை நுரையீரலுக்குக் கெடுதல்.
>
> *pukai nuraiyīralukkuk keṭutal.*
>
> Smoke is harmful to the lungs.

Literally the frothy inner organ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**நுரையீரல்** (*nuraiyīral*) is a native compound of நுரை *nurai*, "froth" (DEDR 3710), and *īral*, "an inner organ, the liver" (DEDR 546).
