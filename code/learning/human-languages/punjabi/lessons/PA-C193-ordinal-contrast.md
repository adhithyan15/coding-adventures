# Put both ordinal contrasts side by side

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-PAHILA-01, PA-LEX-DUJA-01] -->

[PAUSE 2s] Retrieve **ਪਹਿਲਾ** and **ਦੂਜਾ** without a following noun.

## Grammar Lens
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-PAHILE-ORDINAL-193, PA-FORM-DUJE-ORDINAL-193, PA-LEX-PAHILA-01, PA-LEX-DUJA-01, PA-LEX-C71-HOME71-01, PA-PLACE-KAMRE-ROOM-01, PA-POSTPOSITION-VICH-01] -->

| Direct room frame | Oblique room frame |
|---|---|
| **ਪਹਿਲਾ ਕਮਰਾ** | **ਪਹਿਲੇ ਕਮਰੇ ਵਿੱਚ** |
| **ਦੂਜਾ ਕਮਰਾ** | **ਦੂਜੇ ਕਮਰੇ ਵਿੱਚ** |

Read down one column before crossing to the other. The ending change belongs
to this bounded masculine room contrast.
