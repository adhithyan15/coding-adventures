## You'll want to know: навык
<!-- hl-knowledge: introduces=[RU-LEX-C362-POVYSHENIYE-03]; assesses=[] -->

**навык** (*návyk*) — "a skill".

> Для этой работы нужны компьютерные навыки.
>
> *Dlya étoy rabóty nuzhný kompyúternyye návyki.*
>
> This job needs computer skills.

Masculine; usually plural, *навыки*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**навык** is built from *на-* and the root of *привыкать* "to get used to" and *отвыкать* "to lose a habit": a skill is something you have grown used to doing.
