# falei — the past Portuguese kept

## Warm-up

[PAUSE 2s] Portuguese's everyday past tense. Its interest isn't its endings —
it's that Portuguese still **has** it in daily speech, when several sisters do not.

## The forms

| | |
|---|---|
| (eu) | **falei** |
| (tu) | **falaste** |
| (ele/ela/você) | **falou** |
| (nós) | **falámos** (Portugal) / **falamos** (Brazil) |
| (vocês/eles) | **falaram** |

One word. No auxiliary, no participle — the verb carries the past by itself.

The *nós* form is worth a note: Portugal writes **falámos** with an accent to
separate it from the present *falamos*, while Brazil writes both **falamos** and
lets context decide. Same word, one accent, two spelling conventions.

**falei** ← Vulgar Latin perfect **\*fabulāvī**, the same source as Spanish *hablé*. The
Latin *-āv-* dissolved and left a **stressed final vowel** behind, which is why
*falei* and *falou* end where they do.

## The tense the others gave up

Now the point of the chapter:

| language | this tense | where it lives now |
|---|---|---|
| **Portuguese** | *falou* | **everyday speech** |
| **Spanish** | *habló* | **everyday speech** |
| Italian | *parlò* | **south** yes, north literary |
| German | *sagte* | retreating, standard in **writing** |
| French | *il parla* | **literature only** |

All five inherited the same thing. French, German and northern Italy each built a
compound past out of "have" and let it push the old simple past out of
conversation. **Portuguese and Spanish, at the western edge of the map, didn't.**

Portuguese has all the parts to build a compound — *ter* from Chapter 14, and a
participle (*falado*). It simply doesn't use them for this job. The next lesson
shows what it uses them for instead.
