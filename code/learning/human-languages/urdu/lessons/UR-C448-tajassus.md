## You'll want to know: تجسس
<!-- hl-knowledge: introduces=[UR-LEX-C448-CURIOUS448-03]; assesses=[] -->

**تجسس** — *tajassus* — "curiosity".

> بچے کی آنکھوں میں تجسس تھا۔
>
> *bachche kī āṅkhoṅ meṅ tajassus thā.*
>
> There was curiosity in the child's eyes.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**تجسس** (*tajassus*) is usually traced, through Persian, to Arabic *tajassus*, "prying"; Urdu uses it for plain curiosity.
