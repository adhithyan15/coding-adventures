# அவசியம் (avaciyam) — necessity; necessary

## You'll want to know: அவசியம்
<!-- hl-knowledge: introduces=[TA-LEX-C384-AVACIYAM384-01]; assesses=[] -->

**அவசியம்** — *avaciyam* — "necessity; necessary".

> தேர்வுக்கு முன் நன்றாகத் தூங்குவது அவசியம்.
>
> *tērvukku muṉ naṉṟākat tūṅkuvatu avaciyam.*
>
> It is necessary to sleep well before an exam.

அவசியமான, necessary; அவசியமில்லை, it is not necessary.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**அவசியம்** (*avaciyam*) is borrowed from Sanskrit *avaśya-*, as in *avaśyam*, "necessarily, inevitably" (Monier-Williams). Tamil writes the ś as ச.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
