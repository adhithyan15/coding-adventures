# One step later — retrieve मित्र

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MR-LEX-MITRA] -->

[PAUSE 3s] Say the Marathi word for **friend** before you uncover it: **मित्र**
(*mitra*).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[MR-ETYMON-MITRA-BIND, MR-GRAMMAR-TATSAMA-BORROWING] -->

Its old root meant **to bind**. Marathi took the Sanskrit form up whole, so it
is a **tatsama**, not a word worn down through ordinary sound change.
