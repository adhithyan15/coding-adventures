## You'll want to know: പൊതുവേ
<!-- hl-knowledge: introduces=[ML-LEX-C412-CURUKKAM412-04]; assesses=[] -->

**പൊതുവേ** — *potuvē* — "generally".

> പൊതുവേ കുട്ടികൾക്ക് മധുരം ഇഷ്ടമാണ്.
>
> *potuvē kuṭṭikaḷkkŭ madhuraṁ iṣṭamāṇŭ.*
>
> Children generally like sweets.

The ending -ഏ makes an adverb: പൊതു, common, പൊതുവേ, in general.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**പൊതുവേ** (*potuvē*) is native Dravidian: പൊതു, "common, general" (DEDR 4507), with the adverb ending -ഏ.
