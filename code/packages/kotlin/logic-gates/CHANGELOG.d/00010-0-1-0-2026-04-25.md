## [0.1.0] — 2026-04-25

### Added
- Initial implementation of all seven fundamental logic gates as an idiomatic Kotlin `object`.
- `NOT`, `AND`, `OR`, `XOR`, `NAND`, `NOR`, `XNOR`; NAND-only `nandNOT`, `nandAND`, `nandOR`, `nandXOR`.
- `AND_N`, `OR_N` (>= 2 inputs) and `XOR_N` (parity, any number of inputs).
- Input validation via `require()`; literate source with truth tables; 48 unit tests.
