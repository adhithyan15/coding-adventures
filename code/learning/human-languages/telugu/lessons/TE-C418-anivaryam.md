# అనివార్యం (anivāryaṁ) — unavoidable

## You'll want to know: అనివార్యం
<!-- hl-knowledge: introduces=[TE-LEX-C418-SADHYAM418-04]; assesses=[] -->

**అనివార్యం** — *anivāryaṁ* — "unavoidable".

> ఆ మార్పు అనివార్యం.
>
> *ā mārpu anivāryaṁ.*
>
> That change is unavoidable.

అనివార్యంగా, unavoidably.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**అనివార్యం** (*anivāryaṁ*) is borrowed from Sanskrit *anivārya*, "not to be warded off, unavoidable, irresistible" (Monier-Williams).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
