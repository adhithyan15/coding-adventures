# Return to the six familiar fields

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-A1-FORM-MIXED-CUES-01] -->

Close the value banks and earlier forms. Have a blank page and a three-minute
timer ready. The marks below select only old values. Do not look at a model
while the timer runs.

## Writing — independent timed form
<!-- hl-knowledge: introduces=[]; assesses=[PA-A1-FORM-MIXED-CUES-01, PA-A1-FORM-TIMED-01] -->
<!-- hl-writing-stage: timed-assessment-production -->

Start the timer. Write all six marked fields in Gurmukhi; use Gurmukhi digits
for age and phone. Stop at three minutes, leaving unfinished lines as they
are. Keep this first attempt unchanged.

> ਨਾਂ (B · ਖ): ______
>
> ਭਾਸ਼ਾ (A · ਕ): ______
>
> ਰਿਹਾਇਸ਼ (B · ਖ): ______
>
> ਕੰਮ (A · ਕ): ______
>
> ਉਮਰ (B · ਖ): ______
>
> ਫ਼ੋਨ (A · ਕ): ______

## Guided Practice — repair separately
<!-- hl-knowledge: introduces=[]; assesses=[PA-A1-FORM-TIMED-01] -->

After stopping, reopen the old banks and check values, spelling, spacing,
digit order, and phone grouping one at a time. Repair on another page; it
does not replace the clocked evidence. This return is not a complete A1 mock.

## Wrap-up recall
<!-- hl-knowledge: introduces=[]; assesses=[PA-A1-FORM-TIMED-01] -->

Record how many lines were complete at the stop. The full form-plus-message
condition belongs to the later two complete mocks.
