## You'll want to know: كبر
<!-- hl-knowledge: introduces=[AR-LEX-C531-KIBAR531-02]; assesses=[] -->

**كبر** — *kabira* — "to get older; to grow up".

> كبر الأطفال وسافروا إلى المدينة.
>
> *kabira al-aṭfāl wa-sāfarū ilā al-madīna.*
>
> The children grew up and went off to the city.

Present: يكبر, *yakbar*.

Kabira, yakbaru, is to grow older; kabura, yakburu, with the same letters, is to be big or great.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**كبر** (*kabira*) is built on the native Arabic root *k-b-r*, "to be big, great" (Lane). Kabīr, big, which you know, is from the same root.

## What you've built
