## You'll want to know: राजमुद्रा
<!-- hl-knowledge: introduces=[MR-LEX-C327-PRAJA327-02]; assesses=[] -->

**राजमुद्रा** — *rājmudrā* — "a royal seal".

> जुन्या पत्रांवर राजमुद्रा आहे.
>
> *junyā patrāṁvar rājmudrā āhe.*
>
> There is a royal seal on the old letters.

Feminine.

राज-, royal, + मुद्रा, a seal.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**राजमुद्रा** (*rājmudrā*) is built from Sanskrit *rāja-*, 'royal', and *mudrā*, 'a seal, a stamp' (Monier-Williams).
