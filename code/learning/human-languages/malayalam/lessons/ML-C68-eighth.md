## You'll want to know: എട്ടാം
<!-- hl-knowledge: introduces=[ML-LEX-C68-ORDINAL-03]; assesses=[ML-GRAMMAR-C67-ORDINAL-02, ML-CONCEPT-C07-NUMBERS-6-10-01] -->

**എട്ടാം** (*eṭṭāṁ*) — "**eighth**".

**എട്ട്** has a doubled retroflex **ṭṭ**, written as ട stacked under ട with the
virama between them. The ending lands after all of that, so the stack is
untouched: **എട്ടാം**.

**എട്ടാം ദിവസം** (*eṭṭāṁ divasam*), the eighth day.
