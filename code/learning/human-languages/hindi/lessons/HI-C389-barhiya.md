# बढ़िया (baṛhiyā) — excellent, first-rate

## You'll want to know: बढ़िया
<!-- hl-knowledge: introduces=[HI-LEX-C389-BEHTAR389-03]; assesses=[] -->

**बढ़िया** — *baṛhiyā* — "excellent, first-rate".

> अगर तुम यह पराठा खाओगे तो कहोगे कि बहुत बढ़िया है।
>
> *agar tum yah parāṭhā khāoge to kahoge ki bahut baṛhiyā hai.*
>
> If you eat this paratha, you'll say it's excellent.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**बढ़िया** (*baṛhiyā*) is a tadbhava, inherited from Sanskrit *vardhita*, "grown, increased" (CDIAL 11384).

<!-- hl-knowledge: introduces=[]; assesses=[] -->
