# Payoff — ten words in four skills

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[GU-PERFORMANCE-TRAVEL-FIVE-FOUR-SKILL-01, GU-PERFORMANCE-ROUTE-THREE-FOUR-SKILL-01] -->

[PAUSE 20s] Name the first five words, then the five new map words.

## Guided Practice
<!-- hl-knowledge: introduces=[GU-PERFORMANCE-MAP-TEN-FOUR-SKILL-01]; assesses=[GU-LEX-GAAM-01, GU-SCRIPT-GAAM-01, GU-LEX-DUKAAN-01, GU-SCRIPT-DUKAAN-01] -->
<!-- hl-writing-stage: dictation-transcription -->

Identify ten heard words, produce ten words from meaning cues, match ten printed
cards, and write four words named aloud. Pass listening, speaking, reading, and
writing separately; one strong skill cannot compensate for another.
