# Return to a familiar request

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-MAAF, PA-POSTPOSITION-NAAL-COMITATIVE-01] -->

[YOU HEAR: *māf karo*] Say **ਮਾਫ਼ ਕਰੋ**, "excuse me". Then *work with Aman*:
**ਅਮਨ ਨਾਲ ਕੰਮ ਕਰੋ**.

## Grammar Lens
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-MAAF, PA-LEX-NA, PA-LEX-C56-FAMILY56-04, PA-LEX-C57-VERBS57-01] -->

Both requests end in **ਕਰੋ**, "do", said to someone politely. You also know
**ਨਾ**, the short "no; don't", and two verbs for the body: **ਬੈਠਣਾ**, "to sit",
and **ਉੱਠਣਾ**, "to get up".

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-NA, PA-LEX-C56-FAMILY56-04, PA-LEX-C57-VERBS57-01] -->

- [YOU HEAR: *don't*] Say **ਨਾ**.
- [YOU HEAR: *to sit*] Say **ਬੈਠਣਾ**.
- [YOU HEAR: *to get up*] Say **ਉੱਠਣਾ**.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-MAAF, PA-LEX-NA] -->

[PAUSE 3s] Say *excuse me*, then *don't*. Keep both ready.
