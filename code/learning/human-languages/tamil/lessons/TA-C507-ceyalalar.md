# செயலாளர் (ceyalāḷar) — a secretary

## You'll want to know: செயலாளர்
<!-- hl-knowledge: introduces=[TA-LEX-C507-ALUVALAKAM507-03]; assesses=[] -->

**செயலாளர்** — *ceyalāḷar* — "a secretary".

> சங்கத்தின் செயலாளர் கூட்டத்தை நடத்தினார்.
>
> *caṅkattiṉ ceyalāḷar kūṭṭattai naṭattiṉār.*
>
> The association's secretary ran the meeting.

Plural: செயலாளர்கள், *ceyalāḷarkaḷ*.

Built like உதவியாளர் (*utaviyāḷar*): செயல் "work, action" + -ஆளர் "one who …".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**செயலாளர்** (*ceyalāḷar*) is built from native parts: செயல் (*ceyal*), "action", from செய் (*cey*), "to do" (DEDR 1957), and -ஆளர், "one who does it".

## What you've built
