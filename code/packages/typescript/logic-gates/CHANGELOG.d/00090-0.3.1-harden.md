## 0.3.1

- Security: `validateBit` only interpolates a primitive string `name` of at
  most `MAX_NAME_LENGTH` (64) characters; anything else is replaced by
  "argument", so caller `toString`/`Symbol.toPrimitive` hooks never run and
  error messages cannot be turned into a different error.
- `mux` and `dmux` now reject extra/missing arguments like the other gates.
- The seven unchecked `as Bit` casts of transistor-layer results are replaced
  by `assertBitResult`, which throws the new `InternalGateError` (distinct
  from the TypeError/RangeError input rejections) if the dependency ever
  returns a non-bit.
- `andN`/`orN`/`xorN` cap arity at `MAX_WIDTH` before iterating and work on a
  private index-copy of the arguments.
- BUILD/BUILD_windows run `npx tsc --noEmit` before the tests.
- New `tests/hardening.test.ts`: type-confusion matrix (Proxy,
  `Symbol.toPrimitive`, getters, null-prototype, padded/hex/exponent strings,
  2**32, 2**32+1) over all gates incl. mux/dmux/n-ary with spy counters.
