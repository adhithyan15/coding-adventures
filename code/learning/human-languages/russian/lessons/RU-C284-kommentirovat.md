## You'll want to know: комментировать
<!-- hl-knowledge: introduces=[RU-LEX-C284-INTERVYU-04]; assesses=[] -->

**комментировать** (*kommentírovat*) — "to comment on".

> Тренер не стал комментировать игру.
>
> *Tréner ne stal kommentírovat igrú.*
>
> The coach would not comment on the game.

Imperfective; perfective *прокомментировать* (*prokommentírovat*). It takes the accusative, with no preposition.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*комментировать* is usually traced through German *kommentieren* to Latin *commentārī* "to think over, to write about" (Lewis & Short); EtymDB lists no parent for the Russian word.
