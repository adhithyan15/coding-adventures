## You'll want to know: प्रक्रिया
<!-- hl-knowledge: introduces=[MR-LEX-C374-PRAKRIYA374-01]; assesses=[] -->

**प्रक्रिया** — *prakriyā* — "a process".

> प्रवेशाची प्रक्रिया एका आठवड्यात पूर्ण होईल.
>
> *praveśācī prakriyā ekā āṭhvaḍyāt pūrṇa hoīl.*
>
> The admission process will be complete in a week.

Feminine.

Feminine: X ची प्रक्रिया.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**प्रक्रिया** (*prakriyā*) is a tatsama, taken from Sanskrit *prakriyā*, "producing; procedure" (Monier-Williams).
