## You'll want to know: مذياع
<!-- hl-knowledge: introduces=[AR-LEX-C297-IDHAA297-03]; assesses=[] -->

**مذياع** — *midhyāʿ* — "a radio set".

> كان جدي يسمع المذياع كل صباح.
>
> *kāna jaddī yasmaʿu al-midhyāʿ kulla ṣabāḥ.*
>
> My grandfather used to listen to the radio every morning.

Many speakers say راديو; مذياع is the standard word.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**مذياع** (*midhyāʿ*) is usually traced to the native Arabic root *dh-y-ʿ*, "to spread, to become known". The *mifʿāl* pattern names a tool, so *midhyāʿ* is "the spreader": a modern coinage for the radio set.
