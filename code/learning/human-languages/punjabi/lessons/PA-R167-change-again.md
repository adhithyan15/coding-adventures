# An old word for changing

First retrieve **to change** alone. Then hear two familiar actions in a small
shuffled mix. Pause before each model. This is not a scored mock.

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-C152-ACT152-05] -->

Hear **to change**. [PAUSE 4s] Recall **ਬਦਲਣਾ** (*badalṇā*).

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-C152-ACT152-04, PA-LEX-C152-ACT152-05] -->

Pause after each familiar meaning, then hear its model:

- **to change** — [PAUSE 4s] **ਬਦਲਣਾ** (*badalṇā*).
- **to believe, to agree** — [PAUSE 4s] **ਮੰਨਣਾ** (*mannṇā*).

Only the order of these old words has changed.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-C152-ACT152-04, PA-LEX-C152-ACT152-05] -->

Hear **to believe, to agree**, then **to change**. Pause after each cue and
recall its Punjabi word before the model: **ਮੰਨਣਾ**, **ਬਦਲਣਾ**.
Revisit only the old word you missed.
