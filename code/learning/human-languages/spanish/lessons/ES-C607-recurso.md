## You'll want to know: el recurso
<!-- hl-knowledge: introduces=[ES-LEX-C607-AMBIENTE-04]; assesses=[] -->

**el recurso** — "the resource; the appeal".

> El agua es un recurso limitado.
>
> *Water is a limited resource.*

*Recursos humanos* — human resources. In law, an appeal.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*recurso* is a learned borrowing from Latin *recursus* 'a return, a running back', built on *currere* 'to run' (EtymDB).
