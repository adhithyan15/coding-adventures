## You'll want to know: मर्यादा
<!-- hl-knowledge: introduces=[MR-LEX-C379-MARYADA379-01]; assesses=[] -->

**मर्यादा** — *maryādā* — "a limit".

> प्रत्येक गोष्टीला एक मर्यादा असते.
>
> *pratyek goṣṭīlā ek maryādā aste.*
>
> Everything has a limit.

Feminine.

मर्यादा घालणे, to set a limit; मर्यादा ओलांडणे, to overstep it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**मर्यादा** (*maryādā*) is a tatsama, taken from Sanskrit *maryādā*, "region, boundary" (CDIAL 9895).
