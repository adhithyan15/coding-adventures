## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**मेहनती** (*mehantī*) is *mehnat*, "toil", with the ending *-ī*. *Mehnat* is usually traced, through Persian, to Arabic *miḥna*, "trial, ordeal", whose root is *m-ḥ-n* (Lane).
