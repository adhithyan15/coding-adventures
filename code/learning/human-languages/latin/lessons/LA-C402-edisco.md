## You'll want to know: ēdiscō, ēdiscere
<!-- hl-knowledge: introduces=[LA-LEX-C402-EDISCO-01]; assesses=[] -->

**ēdiscō, ēdiscere** — "to learn by heart".

> Puerī carmina poētae ēdiscunt.
>
> *The boys learn the poet's poems by heart.*

*ēdiscō, ēdiscere, ēdidicī*: *ē* + *discō*, to learn out to the end.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*ēdiscō* is built from *ē* "out, to the end" and *discō* "to learn" (Lewis & Short): to learn right through.

## What you've built
