## Fixed — four more words romanize മ്പ as mp, and two glosses are valid YAML

- **മ്പ is *mp* in four more words.** ML-C149-mambalam **മാമ്പഴം** *māmbaḻaṁ* → *māmpaḻaṁ*, ML-C224-vilambuka **വിളമ്പുക** *viḷambuka* → *viḷampuka*, ML-C249-gotambu **ഗോതമ്പ്** *gōtambŭ* → *gōtampŭ* and ML-C298-sambalam **ശമ്പളം** *śambaḷaṁ* → *śampaḷaṁ*. Each headword was checked against its codepoints: the cluster is U+0D2E U+0D4D U+0D2A, മ് + പ, so it takes the letter value for പ, *p*, that the rest of the track uses for this cluster, as in *pāmpŭ*, *kompŭ*, *sampattŭ* and *ompatŭ*. The romanization, etymology hook, body, practice and recall of each lesson change, and so does the word's line in the review lessons ML-R150, ML-R231, ML-R249 and ML-R301. Lesson ids and file names keep *mb*. The etymologies still agree with their sources: *māmpaḻaṁ* is *mā* + *paḻaṁ* (DEDR 4782, DEDR 4004), *viḷampuka* is one word with Tamil *viḷampu* (DEDR 5434), and *gōtampŭ* and *śampaḷaṁ* stay tadbhavas of Sanskrit *gōdhūma* (CDIAL 4287) and *śambala* (CDIAL 12315). Words spelled with ം + ബ, such as *kuṭumbaṁ*, *sambandhiccŭ* and *āmbulansŭ*, keep *mb*. The book chapters and narration pick this up when they are regenerated.
- ML-C20-kalavastha and ML-R114-letters-second-pass had an unquoted `gloss:` with a colon and a space inside it (`gloss: … "state of TIME": kaala ("time") + …`), which a strict YAML parser reads as the start of a second key and rejects. Each is now one single-quoted scalar, with an apostrophe written `''`. The wording is unchanged.
- For every value that was only requoted, the repository's reader returns exactly the text it returned before, and PyYAML now returns that same text.
