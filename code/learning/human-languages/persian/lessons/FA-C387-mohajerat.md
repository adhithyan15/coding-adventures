## You'll want to know: مهاجرت
<!-- hl-knowledge: introduces=[FA-LEX-C387-MOHAJERAT-01]; assesses=[] -->

**مهاجرت** (*mohâjerat*) — "migration, emigration".

> مهاجرت به خارج برای او آسان نبود.
>
> *mohâjerat be khârej barâye u âsân nabud.*
>
> Moving abroad was not easy for her.

*Mohâjerat kardan* — to emigrate.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**مهاجرت** is usually traced to Arabic *muhājara* "emigration", from the same Arabic family as *hijra* "departure", which EtymDB lists.
