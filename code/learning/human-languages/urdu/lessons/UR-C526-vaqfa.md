## You'll want to know: وقفہ
<!-- hl-knowledge: introduces=[UR-LEX-C526-MIAD526-04]; assesses=[] -->

**وقفہ** — *vaqfā* — "a break; an interval".

> اگر وقفہ ہوا تو ہم چائے پئیں گے۔
>
> *agar vaqfā huā to ham chāy pieṅ ge.*
>
> If there is a break, we will have some tea.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**وقفہ** (*vaqfā*) is usually traced, through Persian, to Arabic *waqfa*, "a stop, a pause".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
