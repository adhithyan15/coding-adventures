# ◌ൈ (ai sign) — the ai sign in കൈ

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-SCRIPT-C114-CHILLU-RR-01, ML-SCRIPT-C114-CHHA-01] -->

[PAUSE 2s] Before the new one: write ർ and ഛ once each, and name them.

[PAUSE 2s] Now say **കൈ** (*kai*), "hand".
You have read it for a long time. This lesson takes one letter out of it and puts
it in your hand.

## Script you'll notice: ◌ൈ
<!-- hl-knowledge: introduces=[ML-SCRIPT-C114-AI-SIGN-01]; assesses=[] -->

**ൈ** — the *ai* sign.

It is in **കൈ** (*kai*), "hand". Like **െ** and **േ**, which you already read, it is
written **before** the consonant and said **after** it.

## Writing: ◌ൈ
<!-- hl-knowledge: introduces=[]; assesses=[ML-SCRIPT-C114-AI-SIGN-01] -->

Follow the numbered strip: start where movement 1 begins, and let each panel
show you the next movement before your pen makes it. Then write ◌ൈ yourself —
slowly, and larger than it is printed.

> The strip shows **where to start this sign and which way to travel**, in one
> attested order, and names its source beneath it. Teachers vary, so treat it as
> a sound way in, not the only one.
