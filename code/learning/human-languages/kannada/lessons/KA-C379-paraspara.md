## You'll want to know: ಪರಸ್ಪರ
<!-- hl-knowledge: introduces=[KA-LEX-C379-OMMATA379-05]; assesses=[] -->

**ಪರಸ್ಪರ** — *paraspara* — "mutual; each other".

> ಅವರು ಪರಸ್ಪರ ಸಹಾಯ ಮಾಡುತ್ತಾರೆ.
>
> *avaru paraspara sahāya māḍuttāre.*
>
> They help each other.

Before a verb it means each other: ಪರಸ್ಪರ ಮಾತಾಡು, to talk to each other.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಪರಸ್ಪರ** (*paraspara*) is borrowed from Sanskrit *paraspara*, "mutual, each other" (Monier-Williams), a doubling of *para*, "other".
