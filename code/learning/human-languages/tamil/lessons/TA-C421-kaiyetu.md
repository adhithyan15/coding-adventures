# கையேடு (kaiyēṭu) — a handbook; a guidebook

## You'll want to know: கையேடு
<!-- hl-knowledge: introduces=[TA-LEX-C421-VAZHIKATTI421-02]; assesses=[] -->

**கையேடு** — *kaiyēṭu* — "a handbook; a guidebook".

> அந்தக் கையேட்டில் நல்ல உணவகங்களின் பட்டியல் இருக்கிறது.
>
> *antak kaiyēṭṭil nalla uṇavakaṅkaḷiṉ paṭṭiyal irukkiṟatu.*
>
> That guidebook has a list of good restaurants.

A -டு noun doubles before a case: கையேட்டில், in the handbook.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**கையேடு** (*kaiyēṭu*) is built from கை, "hand" (DEDR 2023), and ஏடு, "a palm leaf for writing, a book" (DEDR 884): a book for the hand.
