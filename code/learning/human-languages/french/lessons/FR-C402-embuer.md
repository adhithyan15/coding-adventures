## You'll want to know: embuer
<!-- hl-knowledge: introduces=[FR-LEX-C402-VITRES-05]; assesses=[] -->

**embuer** — "to mist up (mostly reflexive: s’embuer)".

> Quand il fait froid, les vitres s'embuent.
>
> *When it is cold, the windows mist up.*

Mostly reflexive: *les vitres s'embuent*. *Embué* — misty.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*embuer* is built on *buée* 'mist, condensation'. *Buée* is usually traced to an old verb *buer* 'to do the washing', of Germanic origin: the steam that rose from the washing tubs. EtymDB does not list the word.
