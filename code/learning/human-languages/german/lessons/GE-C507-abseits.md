## You'll want to know: das Abseits
<!-- hl-knowledge: introduces=[GE-LEX-C507-SPIEL-05]; assesses=[] -->

**das Abseits** — "offside".

> Das Tor zählte nicht, weil der Spieler im Abseits stand.
>
> *The goal didn't count because the player was offside.*

*Im Abseits stehen* — to be offside; also to be left out.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*Abseits* is built on *ab* "off" and *seits* "on the side"; EtymDB links the football sense to English *offside*, which it renders.
