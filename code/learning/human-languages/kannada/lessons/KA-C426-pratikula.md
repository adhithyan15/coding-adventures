# ಪ್ರತಿಕೂಲ (pratikūla) — adverse; unfavourable

## You'll want to know: ಪ್ರತಿಕೂಲ
<!-- hl-knowledge: introduces=[KA-LEX-C426-HIMMETTU426-05]; assesses=[] -->

**ಪ್ರತಿಕೂಲ** — *pratikūla* — "adverse; unfavourable".

> ಪ್ರತಿಕೂಲ ಹವಾಮಾನದಿಂದ ವಿಮಾನ ತಡವಾಯಿತು.
>
> *pratikūla havāmānadinda vimāna taḍavāyitu.*
>
> The flight was delayed by bad weather.

ಅನುಕೂಲ is its opposite.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಪ್ರತಿಕೂಲ** (*pratikūla*) is borrowed from Sanskrit *pratikūla*, "against the bank", so "contrary, adverse" (CDIAL 8545).
