# Sanskrit pre-A1 mock 2 — learner paper

This is an independent parallel form, not a rehearsal copy of mock 1. Give this
paper to the learner and keep
[`mock-2-examiner-script.md`](mock-2-examiner-script.md) separate. Total
administration is 32 written minutes plus 8 speaking minutes. Keep word
boundaries unjoined; correct external sandhi is accepted but not required.

## Reading — 10 minutes

Choose the English meaning or situation.

1. **संस्कृतम्** — A Sanskrit / B fruit / C friend
2. **फलम्** — A book / B fruit / C school
3. **मित्रम्** — A teacher / B name / C friend
4. **शिक्षकः** — A student / B teacher / C home
5. **छात्रः** — A student / B city / C water
6. **पुस्तिका** — A greeting / B notebook / C thanks
7. **शुभप्रभातम्।** — A Good morning. / B Thank you. / C Please sit.
8. **स्वागतम्।** — A You are welcome. / B Goodbye. / C I am well.
9. **कृपया वदतु।** — A Please speak. / B Please sit. / C Please write.
10. **पुनः मिलामः।** — A We meet again. / B My name is Ravi. / C I want fruit.
11. **मम नाम अर्जुनः अस्ति।** — A The name is Arjuna. / B The city is Arjuna. / C Arjuna is a school.
12. **अहं काशी-नगरात् आगच्छामि।** — A I come from Kashi. / B I am going to Kashi. / C My name is Kashi.
13. **अहं संस्कृतम् वदामि।** — A I speak Sanskrit. / B I read a notebook. / C I want fruit.
14. Form field **नगरम्: उज्जयिनी** — A language Ujjayini / B city Ujjayini / C name Ujjayini
