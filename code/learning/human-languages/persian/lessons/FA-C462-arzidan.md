## You'll want to know: ارزیدن
<!-- hl-knowledge: introduces=[FA-LEX-C462-HARAJ-02]; assesses=[] -->

**ارزیدن** (*arzidan*) — "to be worth".

> این کفش به این قیمت نمیارزد.
>
> *In kafsh be in qeymat nemiarzad.*
>
> These shoes aren't worth this price.

Present stem *arz-*: *miarzad*. Built on the same root as *arzân* 'cheap'.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*arzidan* is inherited: EtymDB traces it through Proto-Iranian *Hárǰati* to the PIE root *h₂elgʷʰ-* 'to be worth, value'.
