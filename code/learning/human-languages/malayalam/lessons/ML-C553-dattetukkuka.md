## You'll want to know: ദത്തെടുക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C553-SAHODARAN553-02]; assesses=[] -->

**ദത്തെടുക്കുക** — *datteṭukkuka* — "to adopt".

> ആ ദമ്പതികൾ ഒരു കുഞ്ഞിനെ ദത്തെടുത്തു.
>
> *ā dampatikaḷ oru kuññine datteṭuttu.*
>
> That couple adopted a baby.

Past: ദത്തെടുത്തു, *datteṭuttu*.

ദത്ത് given + എടുക്കുക to take: to take a child as given.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ദത്തെടുക്കുക** (*datteṭukkuka*) is a Malayalam compound built from ദത്ത്, from Sanskrit *datta*, "given" (CDIAL 6140), and എടുക്കുക, "to take up", which is native (DEDR 851).
