# ભોળવવું (bhoḷavvũ) — to beguile; to mislead

## You'll want to know: ભોળવવું
<!-- hl-knowledge: introduces=[GU-LEX-C468-JUTHU468-05]; assesses=[] -->

**ભોળવવું** — *bhoḷavvũ* — "to beguile; to mislead".

> લુચ્ચો વેપારી ગ્રાહકોને ખોટા વચનથી ભોળવે છે.
>
> *lucco vepārī grāhkone khoṭā vacanthī bhoḷve che.*
>
> The sly trader beguiles customers with false promises.

Past, with તેણે (he or she …): તેણે બાળકને ભોળવ્યું, *teṇe bāḷakne bhoḷavyũ*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ભોળવવું** (*bhoḷavvũ*) is built on **ભોળું** (*bhoḷũ*), "trusting", which goes back to a reconstructed *\*bhulla-* (CDIAL 9539): to make someone trusting, and so to fool them.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
