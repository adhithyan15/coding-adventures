# Assessment backlog summaries must follow the actual CEFR level sequence

After adding an A2 inventory, a status line accidentally described the next
unbuilt range as “A3-C2.” The project uses the CEFR sequence pre-A1, A1, A2,
B1, B2, C1, C2; A3 is not a level.

When advancing a level boundary, derive the next backlog label from the
repository's declared level order rather than incrementing the letter-number
text mechanically. Re-read the complete status sentence before treating it as
an authoritative queue summary.
