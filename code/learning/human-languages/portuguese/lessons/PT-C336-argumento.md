## You'll want to know: o argumento
<!-- hl-knowledge: introduces=[PT-LEX-C336-DEBATE-05]; assesses=[] -->

**o argumento** — "the argument (a reason given); the plot".

> É um bom argumento, mas não me convence.
>
> *It is a good argument, but it does not convince me.*

An *argumento* is a reason you give; a quarrel is *uma discussão*. It is also the plot or script of a film.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*argumento* is a learned borrowing from Latin *argūmentum* "proof, evidence" (EtymDB), built on *arguere* "to make clear, to prove" (Lewis & Short).
