## You'll want to know: la riqueza
<!-- hl-knowledge: introduces=[ES-LEX-C633-RIQUEZA-03]; assesses=[] -->

**la riqueza** — "the wealth".

> La riqueza no lo es todo.
>
> *Wealth is not everything.*

Built on *rico* with *-eza*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*riqueza* is built on *rico*, which was borrowed from Gothic *reiks* 'mighty' (EtymDB), with the ending *-eza*.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling, explaining and describing at B1.
