## You'll want to know: شفقة
<!-- hl-knowledge: introduces=[AR-LEX-C493-NADAM493-03]; assesses=[] -->

**شفقة** — *shafaqa* — "pity".

> شعرت بالشفقة على الحصان المتعب.
>
> *shaʿartu bi-sh-shafaqa ʿalā al-ḥiṣān al-mutʿab.*
>
> I felt pity for the tired horse.

It takes على for the one pitied.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**شفقة** (*shafaqa*) is built on the native Arabic root *sh-f-q*, "to be anxious for, to pity" (Lane). Shafaqa is a tender worry for someone.

## What you've built

One more word for describing what you lived and felt.
