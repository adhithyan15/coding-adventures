## You'll want to know: 上路
<!-- hl-knowledge: introduces=[ZH-LEX-C410-COACH410-05]; assesses=[] -->

**上路** — *shànglù* — "to set out on a journey; to hit the road".

> **我们早上六点上路** *wǒmen zǎoshang liù diǎn shànglù* — We set off at six in the morning.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**上路** (*shànglù*) is built from 上 'to go up' and 路 'a road', both inherited from Middle Chinese, *dzyangX* and *luH* (Guangyun, in Baxter's transcription), which glosses the first 'to climb'.
