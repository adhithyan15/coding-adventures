# Give each word its space

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-NAMASTE-01] -->

The greeting and name were copied separately earlier. Today only the spaces
are wrong; do not change a letter or sentence mark.

## Reading — find the crowded places
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-NAMASTE-01, PA-SKILL-CONNECTED-READING] -->

> ਨਮਸਤੇਮਨਨ। ਮੇਰਾਨਾਂ ਅਮਨ ਹੈ।

Point after the greeting and after **ਮੇਰਾ**. Those are two word boundaries,
not two spelling errors.

## Writing — repair only spaces
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-NAMASTE-01] -->
<!-- hl-writing-stage: guided-copy -->

Insert one space in each crowded place. Keep the sentence marks attached to
the preceding words. Compare with the old supported greeting only afterward.
