# દત્તક (dattak) — adopted

## You'll want to know: દત્તક
<!-- hl-knowledge: introduces=[GU-LEX-C500-VARSO500-04]; assesses=[] -->

**દત્તક** — *dattak* — "adopted".

> તેમણે એક અનાથ બાળકને દત્તક લીધું.
>
> *temṇe ek anāth bāḷakne dattak līdhũ.*
>
> They adopted an orphaned child.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**દત્તક** (*dattak*) is a tatsama, Sanskrit *dattaka*, which Monier-Williams gives, with *putra*, "son", as an adopted son.
