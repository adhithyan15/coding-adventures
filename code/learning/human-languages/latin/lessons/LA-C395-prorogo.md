## You'll want to know: prōrogō, prōrogāre
<!-- hl-knowledge: introduces=[LA-LEX-C395-DIFFERO-03]; assesses=[] -->

**prōrogō, prōrogāre** — "to extend, to prolong (a term of office)".

> Senātus imperium eī prōrogāvit.
>
> *The senate extended his command.*

*prōrogō, prōrogāre, prōrogāvī, prōrogātum*, built on *rogō*: to ask the people for more time. English *prorogue*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*prōrogō* is built from *prō* "forward" and *rogō* "to ask" (EtymDB; Lewis & Short): to ask for a term to run on. English *prorogue* comes from it.
