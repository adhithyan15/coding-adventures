## You'll want to know: സമ്പ്രദായം
<!-- hl-knowledge: introduces=[ML-LEX-C431-VIKASANAM431-05]; assesses=[] -->

**സമ്പ്രദായം** — *sampradāyaṁ* — "a system; a tradition".

> പഴയ സമ്പ്രദായം മാറ്റാൻ സമയമായി.
>
> *paḻaya sampradāyaṁ māṟṟān samayamāyi.*
>
> It is time to change the old system.

Plural: സമ്പ്രദായങ്ങൾ, customs.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**സമ്പ്രദായം** (*sampradāyaṁ*) is borrowed from Sanskrit *sampradāya*, "tradition, a doctrine handed down from one teacher to the next" (Monier-Williams).
