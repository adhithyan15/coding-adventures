## You'll want to know: ഏഴാം
<!-- hl-knowledge: introduces=[ML-LEX-C68-ORDINAL-02]; assesses=[ML-GRAMMAR-C67-ORDINAL-02, ML-CONCEPT-C07-NUMBERS-6-10-02] -->

**ഏഴാം** (*ēḻāṁ*) — "**seventh**".

**ഏഴ്** carries the curled **ḻ**, the sound in the name *Malayāḷam* itself and
the one this language shares with Tamil while Kannada and Telugu hardened it
away. Adding the ending does not soften it: **ഏഴാം**, with the tongue still
curled back.

**ഏഴാം ദിവസം** (*ēḻāṁ divasam*), the seventh day.

One honest warning about the page. This word begins with **ഏ**, the independent
long **ē**, and that is a letter this book has taught you to *recognise* but not
yet to *write* — no stroke order for it has been sourced, so none is offered.
Read it; do not copy it yet. That is why this lesson is headed by its
romanization rather than by the Malayalam word, the way the counting lessons
were.
