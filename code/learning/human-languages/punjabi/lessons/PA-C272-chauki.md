# ਚੌਕੀ (chaukī) — a police post; a guard post

## You'll want to know: ਚੌਕੀ
<!-- hl-knowledge: introduces=[PA-LEX-C272-CROWD272-03]; assesses=[] -->

**ਚੌਕੀ** — *chaukī* — "a police post; a guard post".

> ਪੁਲਿਸ ਦੀ ਚੌਕੀ ਪੁਲ ਦੇ ਨੇੜੇ ਹੈ।
>
> *pulis dī chaukī pul de neṛe hai.*
>
> The police post is near the bridge.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ਚੌਕੀ** (*chaukī*) is inherited from Sanskrit *catuṣka*, "a set of four"; CDIAL lists Punjabi *caukī*, "chair", under it (CDIAL 4629). The sense "a police post" is not given there.
