## You'll want to know: срок
<!-- hl-knowledge: introduces=[RU-LEX-C276-DESYATILETIYE-05]; assesses=[] -->

**срок** (*srok*) — "a deadline, a time limit; a term".

> Срок сдачи проекта — пятница.
>
> *Srok sdáchi proyékta — pyátnitsa.*
>
> The deadline for the project is Friday.

*В срок* — on time; *срок годности* — shelf life.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*срок* is usually traced to *с-* and the root of *речь* "speech", Proto-Slavic *rekti* "to say" (EtymDB lists *речь*), so "what was agreed"; EtymDB lists no parent, and the origin is not fully settled.
