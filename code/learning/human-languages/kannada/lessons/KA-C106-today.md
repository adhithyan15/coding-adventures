# ಇವತ್ತು (ivattu) — today

## You'll want to know: ಇವತ್ತು
<!-- hl-knowledge: introduces=[KA-LEX-C106-SOON-02]; assesses=[] -->

**ಇವತ್ತು** (*ivattu*) — "today". **ನಾಳೆ** (*nāḷe*) is "tomorrow".

## What you've built

The day before tomorrow.
