## You'll want to know: la vetrina
<!-- hl-knowledge: introduces=[IT-LEX-C451-PASSEGGIATA-05]; assesses=[] -->

**la vetrina** — "the shop window".

> Ho visto delle scarpe in vetrina.
>
> *I saw some shoes in the window.*

*Guardare le vetrine* — to go window-shopping.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*vetrina* is built on *vetro* 'glass', which is inherited from Latin *vitrum* (Lewis & Short).
