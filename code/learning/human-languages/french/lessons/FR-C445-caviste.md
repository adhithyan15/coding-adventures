## You'll want to know: le caviste
<!-- hl-knowledge: introduces=[FR-LEX-C445-BOUTIQUES-05]; assesses=[] -->

**le caviste** — "the wine merchant".

> Le caviste nous a conseillé un vin de la région.
>
> *The wine merchant recommended a local wine.*

Built on *la cave* 'cellar'.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*caviste* is built on *cave* 'cellar' with *-iste* (EtymDB); *cave* goes back to Latin *cavus* 'hollow'.
