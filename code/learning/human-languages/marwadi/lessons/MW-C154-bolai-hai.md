# वो बोलै है — what he does

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MW-GRAMMAR-C154-PRES-1SG-01, MW-LEX-C105-ACT105-02, MW-LEX-C57-VERBS57-04, MW-GRAMMAR-C153-BE-HAI-01] -->

[PAUSE 2s] Say *I listen to songs*. Then *to read* and *to write*: **बांचणो**,
**लिखणो**.

## Grammar Lens: -ै and है
<!-- hl-knowledge: introduces=[MW-GRAMMAR-C154-PRES-3SG-01]; assesses=[MW-GRAMMAR-C152-VO-HE-01, MW-GRAMMAR-C153-BE-HAI-01, MW-LEX-RAAM-01] -->

For **वो**, for **राम**, for anyone you talk about, the stem takes **-ै** and the
sentence ends on **है**:

> **वो थोड़ु बोलै है।**
>
> *vo thoṛu bolai hai.* — He speaks a little.

> **राम रोज अखबार बांचै है।**
>
> *rām roj akhbār bā̃chai hai.* — Ram reads the newspaper every day.

Nothing changes for a woman: **मां गीत सुणै है।** (*mā̃ gīt suṇai hai.*), mother
listens to songs. Old Marwari wrote the same ending *-aï*: *karaï*, "does"
(CDIAL 2814).

[PAUSE 1s]
- [YOU SAY: **हूं रोज अखबार बांचूं हूं।** — *hū̃ roj akhbār bā̃chū̃ hū̃.* — I read the newspaper every day.]
- [YOU SAY: **राम रोज अखबार बांचै है।** — *rām roj akhbār bā̃chai hai.* — Ram reads it every day.]
- [YOU SAY: **मां चिट्ठी लिखै है।** — *mā̃ chiṭṭhī likhai hai.* — Mother writes a letter.]
