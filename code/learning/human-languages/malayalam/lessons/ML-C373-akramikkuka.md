# ആക്രമിക്കുക (ākramikkuka) — to attack

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C373-AKRAMANAM373-01, ML-LEX-C373-AKRAMANAM373-02] -->

[PAUSE 2s] Before the new one: say the Malayalam for an attack, then the Malayalam for a threat.

## You'll want to know: ആക്രമിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C373-AKRAMANAM373-03]; assesses=[] -->

**ആക്രമിക്കുക** — *ākramikkuka* — "to attack".

> ഒരു നായ കുട്ടിയെ ആക്രമിച്ചു.
>
> *oru nāya kuṭṭiye ākramiccu.*
>
> A dog attacked the child.

Past: ആക്രമിച്ചു, *ākramiccu*.

The one attacked takes -എ: അവനെ ആക്രമിച്ചു.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ആക്രമിക്കുക** (*ākramikkuka*) is built on the Sanskrit verb *ā-kram*, "to step upon", whose noun *ākramaṇa* (CDIAL 1016) gave ആക്രമണം (*ākramaṇaṁ*), with the Malayalam verb ending -ിക്കുക.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
