## You'll want to know: carinhoso
<!-- hl-knowledge: introduces=[PT-LEX-C496-CARINHO-02]; assesses=[] -->

**carinhoso** — "affectionate, loving".

> O meu filho é muito carinhoso.
>
> *My son is very affectionate.*

Built on *o carinho* — affection, a caress.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*carinhoso* is built on *carinho* "affection", which is usually traced to Spanish *cariño* (EtymDB); the deeper origin is not settled.
