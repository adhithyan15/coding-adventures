## You'll want to know: ожидание
<!-- hl-knowledge: introduces=[RU-LEX-C374-OZHIDANIYA-03]; assesses=[] -->

**ожидание** (*ozhidániye*) — "an expectation; waiting".

> Результат превзошёл все ожидания.
>
> *Rezultát prevzoshyól vse ozhidániya.*
>
> The result exceeded all expectations.

Neuter. *Зал ожидания* — a waiting room.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ожидание** is built on *ожидать* "to expect" with the noun suffix *-ание*; the root is that of *ждать* "to wait".
