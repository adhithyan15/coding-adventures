## You'll want to know: la tendencia
<!-- hl-knowledge: introduces=[ES-LEX-C608-AUMENTA-05]; assesses=[] -->

**la tendencia** — "the trend, the tendency".

> Es una tendencia nueva.
>
> *It is a new trend.*

*Tener tendencia a* — to tend to.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*tendencia* is a learned borrowing from Medieval Latin *tendentia*, built on *tendere* 'to stretch, to aim at' (EtymDB).
