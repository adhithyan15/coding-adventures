# منظم (munaẓẓam) — organized, tidy

## You'll want to know: منظم
<!-- hl-knowledge: introduces=[AR-LEX-C503-TABA503-04]; assesses=[] -->

**منظم** — *munaẓẓam* — "organized, tidy".

> مكتب أختي منظم ونظيف.
>
> *maktab ukhtī munaẓẓam wa-naẓīf.*
>
> My sister's desk is tidy and clean.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**منظم** (*munaẓẓam*) is built on the native Arabic root *n-ẓ-m*, "to string pearls in order" (Lane). Munaẓẓam is the passive participle of Form II: set in order.
