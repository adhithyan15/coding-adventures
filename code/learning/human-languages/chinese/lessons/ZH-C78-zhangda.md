## You'll want to know: 长大
<!-- hl-knowledge: introduces=[ZH-LEX-C78-AGE78-02]; assesses=[] -->

**长大** — *zhǎngdà* — "to grow up".

> **他们长大了** *tāmen zhǎngdà le* — They've grown up.

The character you wrote for cháng, long, is read zhǎng here, to grow.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**长大** (*zhǎngdà*) is built from zhǎng 'to grow' and 大 'big', both inherited from Middle Chinese, *trjangX* and *dajH* (Guangyun, in Baxter's transcription). The dictionary glosses the first as 'big' and 'elder'; growing is not given there, so how it got that sense is not settled.
