# આપત્તિ (āpatti) — a misfortune; a calamity

## You'll want to know: આપત્તિ
<!-- hl-knowledge: introduces=[GU-LEX-C370-KHATRO370-03]; assesses=[] -->

**આપત્તિ** — *āpatti* — "a misfortune; a calamity".

> જો આ વરસે પણ દુકાળ પડશે તો ગામ પર મોટી આપત્તિ આવશે.
>
> *jo ā varse paṇ dukāḷ paḍśe to gām par moṭī āpatti āvśe.*
>
> If there is a drought again this year, a great calamity will strike the village.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**આપત્તિ** (*āpatti*) is a tatsama, borrowed from Sanskrit *āpatti*, "happening, occurring; misfortune" (Monier-Williams).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
