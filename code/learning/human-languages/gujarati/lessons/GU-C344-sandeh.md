## You'll want to know: સંદેહ
<!-- hl-knowledge: introduces=[GU-LEX-C344-SABITI344-04]; assesses=[] -->

**સંદેહ** — *sandeh* — "uncertainty; a lingering doubt".

> આ પરિણામ સાચું છે તેમાં કોઈ સંદેહ નથી.
>
> *ā pariṇām sācũ che temā̃ koī sandeh nathī.*
>
> There is no doubt that this result is right.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**સંદેહ** (*sandeh*) is a tatsama, borrowed from Sanskrit *saṃdeha*, "a doubt, uncertainty" (Monier-Williams).
