# ಏರ್ಪಡಿಸು (ērpaḍisu) — to set up; to arrange

## You'll want to know: ಏರ್ಪಡಿಸು
<!-- hl-knowledge: introduces=[KA-LEX-C333-NERAVERU333-04]; assesses=[] -->

**ಏರ್ಪಡಿಸು** — *ērpaḍisu* — "to set up; to arrange".

> ಅಪ್ಪ ಮದುವೆಗೆ ಊಟ ಏರ್ಪಡಿಸಿದರು.
>
> *appa maduvege ūṭa ērpaḍisidaru.*
>
> Father arranged the meal for the wedding.

Past (I …): ಏರ್ಪಡಿಸಿದೆ, *ērpaḍiside*.

ಏರ್ಪಡು is to come about; ಏರ್ಪಡಿಸು is to make it come about. The noun is ಏರ್ಪಾಡು, an arrangement.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಏರ್ಪಡಿಸು** (*ērpaḍisu*) is native Dravidian: DEDR 905 lists Kannada *ērpaḍu*, "to come about", and *ērpaḍisu*, beside Tamil *ēl*, "to happen, to be suitable".
