## You'll want to know: оплата
<!-- hl-knowledge: introduces=[RU-LEX-C455-OPLATA-02]; assesses=[] -->

**оплата** (*opláta*) — "payment".

> Оплата только наличными.
>
> *Opláta tólko nalíchnymi.*
>
> Payment is in cash only.

Feminine. *Оплата картой* — payment by card.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*оплата* is built from *о-* and *плата* 'pay', the root of *платить* 'to pay', which EtymDB takes from Proto-Slavic *platiti*.
