# Practice — hello to goodbye, in one conversation

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[GE-LEX-AUF-WIEDERSEHEN-01, GE-LEX-TSCHUESS-01] -->

[PAUSE 2s] No new words. This is the first conversation you can run from the
first word to the last — everything in it has had its own lesson.

## Grammar Lens: which farewell, when
<!-- hl-knowledge: introduces=[]; assesses=[GE-LEX-AUF-WIEDERSEHEN-01, GE-LEX-TSCHUESS-01, GE-LEX-BIS-BALD-01, GE-LEX-BIS-MORGEN-01, GE-LEX-BIS-SPAETER-01] -->

| You are… | Say |
|---|---|
| formal, to a stranger | *Auf Wiedersehen.* |
| casual, to a friend | *Tschüss.* |
| meeting again soon | *Bis bald.* |
| making no promises | *Bis später.* |
| leaving for the day | *Bis morgen.* |

## The exchange
<!-- hl-knowledge: introduces=[]; assesses=[GE-LEX-HALLO-01, GE-LEX-ICH-HEISSE-01, GE-LEX-WIE-HEISSEN-SIE-01, GE-LEX-FREUT-MICH-02, GE-LEX-WIE-GEHT-ES-IHNEN-01, GE-LEX-SEHR-01, GE-LEX-GUT-02, GE-LEX-DANKE-01, GE-LEX-BIS-MORGEN-01, GE-LEX-AUF-WIEDERSEHEN-01] -->

Everything from chapter 1 to here, in one conversation:

| German | English |
|---|---|
| *Hallo! Ich heiße Anna. Wie heißen Sie?* | Hello! My name is Anna. What is your name? |
| *Ich heiße Peter. Freut mich.* | My name is Peter. Pleased to meet you. |
| *Wie geht es Ihnen?* | How are you? |
| *Danke, gut. Und Ihnen?* | Well, thanks. And you? |
| *Sehr gut. Bis morgen, Peter.* | Very well. See you tomorrow, Peter. |
| *Bis morgen, Anna. Auf Wiedersehen!* | See you tomorrow, Anna. Goodbye! |

Between friends, that last line becomes *Tschüss, bis morgen!* — and note that
the whole exchange stayed formal because it opened formally with *Sie*.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[GE-LEX-AUF-WIEDERSEHEN-01, GE-LEX-TSCHUESS-01, GE-LEX-BIS-MORGEN-01] -->

[PAUSE 3s] Run the whole conversation without looking. Which goodbye promises a
re-seeing? (*Auf Wiedersehen*.) Which one is secretly "to God"? (*Tschüss*.)
Which would you use leaving a class you both attend tomorrow? (*Bis morgen*.)
