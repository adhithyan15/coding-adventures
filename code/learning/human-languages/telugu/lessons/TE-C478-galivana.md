# గాలివాన (gālivāna) — a rainstorm

## You'll want to know: గాలివాన
<!-- hl-knowledge: introduces=[TE-LEX-C478-PEDAGALI478-04]; assesses=[] -->

**గాలివాన** — *gālivāna* — "a rainstorm".

> నిన్న రాత్రి పెద్ద గాలివాన వచ్చింది.
>
> *ninna rātri pedda gālivāna vaccindi.*
>
> There was a big rainstorm last night.

గాలి, wind, + వాన, rain: wind and rain together.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**గాలివాన** (*gālivāna*) is native Dravidian: గాలి, "wind" (DEDR 1499), and వాన, "rain" (DEDR 5381).
