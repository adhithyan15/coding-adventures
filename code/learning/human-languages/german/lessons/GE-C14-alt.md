# alt — "old"

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[GE-GRAMMAR-SEIN-ICH-BIN-01, GE-LEX-MUEDE-01] -->

[PAUSE 2s] You can say *ich bin müde*. Here is a second adjective to put in the
same slot, and it opens a sentence you will be asked for constantly.

## You'll want to know: alt
<!-- hl-knowledge: introduces=[GE-LEX-ALT-01]; assesses=[GE-GRAMMAR-SEIN-ICH-BIN-01] -->

> **alt** — "old."

One syllable. It behaves exactly as *müde* did: after *sein* an adjective takes
no ending at all, so *ich bin alt* needs nothing added.

It is the same word as English **old**, and you can nearly hear it — German
kept the *a* where English rounded it.

## Sounds you'll need
<!-- hl-knowledge: introduces=[]; assesses=[GE-LEX-ALT-01] -->

- `vowel-a` — short and clipped, the *a* of English *hat*.
- `d-t-final` — the *-lt* closes crisply, both consonants sounded.
