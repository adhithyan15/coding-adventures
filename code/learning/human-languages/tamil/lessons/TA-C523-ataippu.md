# அடைப்பு (aṭaippu) — a blockage

## You'll want to know: அடைப்பு
<!-- hl-knowledge: introduces=[TA-LEX-C523-PAZHUDHU523-03]; assesses=[] -->

**அடைப்பு** — *aṭaippu* — "a blockage".

> குழாயில் அடைப்பு இருப்பதால் தண்ணீர் வரவில்லை.
>
> *kuḻāyil aṭaippu iruppatāl taṇṇīr varavillai.*
>
> Because there is a blockage in the pipe, no water is coming.

From அடை, to shut, to block. A blocked nose is மூக்கடைப்பு.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**அடைப்பு** (*aṭaippu*) is native Dravidian: DEDR 83 gives அடை (*aṭai*), "to shut, to block a passage", and அடைப்பு, "closing, an obstruction, a plug".
