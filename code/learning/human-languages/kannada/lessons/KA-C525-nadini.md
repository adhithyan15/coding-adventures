# ನಾದಿನಿ (nādini) — husband's sister

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C524-BANDHU524-05, KA-LEX-C525-NENTARU525-01] -->

[PAUSE 2s] Before the new one: say the Kannada for a nephew, then the Kannada for a brother-in-law.

## You'll want to know: ನಾದಿನಿ
<!-- hl-knowledge: introduces=[KA-LEX-C525-NENTARU525-02]; assesses=[] -->

**ನಾದಿನಿ** — *nādini* — "husband's sister".

> ನನ್ನ ನಾದಿನಿ ನಮ್ಮ ಮನೆಯ ಹತ್ತಿರ ಇರುತ್ತಾಳೆ.
>
> *nanna nādini namma maneya hattira iruttāḷe.*
>
> My husband's sister lives near our house.

Also used for a wife's sister in some families.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ನಾದಿನಿ** (*nādini*) is native Dravidian: DEDR 3644 lists Kannada *nādani*, *nādini*, "husband's sister, brother's wife".
