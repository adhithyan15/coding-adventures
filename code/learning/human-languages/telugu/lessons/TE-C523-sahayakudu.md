# సహాయకుడు (sahāyakuḍu) — an assistant; a helper

## You'll want to know: సహాయకుడు
<!-- hl-knowledge: introduces=[TE-LEX-C523-PANIVARU523-04]; assesses=[] -->

**సహాయకుడు** — *sahāyakuḍu* — "an assistant; a helper".

> డాక్టరుకు ఒక సహాయకుడు ఉన్నాడు.
>
> *ḍākṭaruku oka sahāyakuḍu unnāḍu.*
>
> The doctor has an assistant.

Feminine సహాయకురాలు; built on సహాయం, help.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**సహాయకుడు** (*sahāyakuḍu*) is built on Sanskrit *sahāya*, "companion, helper" (CDIAL 13309), with the Telugu masculine ending -డు.
