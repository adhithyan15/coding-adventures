## You'll want to know: রেকর্ড
<!-- hl-knowledge: introduces=[BN-LEX-C520-PODOK520-03]; assesses=[] -->

**রেকর্ড** — *rekôrḍ* — "a sporting record; a best result".

> সাঁতারে ছেলেটা একটা নতুন রেকর্ড গড়ল।
>
> *Sā̃tāre chheleṭā ekṭā nôtun rekôrḍ gôṛlô.*
>
> The boy set a new swimming record.

With গড়া: রেকর্ড গড়া, to set a record.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**রেকর্ড** (*rekôrḍ*) is borrowed from English *record*.
