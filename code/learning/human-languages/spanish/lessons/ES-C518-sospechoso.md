## You'll want to know: el sospechoso
<!-- hl-knowledge: introduces=[ES-LEX-C518-ROBO-03]; assesses=[] -->

**el sospechoso** — "the suspect; suspicious".

> La policía busca a dos sospechosos.
>
> *The police are looking for two suspects.*

As an adjective: *un coche sospechoso* — a suspicious car.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*sospechoso* is built on *sospecha* 'suspicion' with the ending *-oso*. *Sospecha* is built on *sospechar*, which is inherited from Latin *suspectāre* 'to look up at, to suspect' (EtymDB), from *suspicere*.
