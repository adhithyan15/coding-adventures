# शहर — the city box

## Warm-up
<!-- hl-knowledge: introduces=[MR-A1-FORM-LABEL-SHAHAR]; assesses=[] -->

The known sentence **मी पुण्यात राहतो / राहते** put the practice person in
Pune. A short form asks for that place with **शहर** — “city.”

## Writing — observe and trace one pair
<!-- hl-knowledge: introduces=[]; assesses=[MR-A1-FORM-LABEL-SHAHAR] -->
<!-- hl-writing-stage: observe-trace -->

Trace only **शहर: पुणे**. Say “city, Pune” once. Do not add an address; this box
asks for one small thing.
