## You'll want to know: تلف
<!-- hl-knowledge: introduces=[AR-LEX-C460-ATAL460-04]; assesses=[] -->

**تلف** — *talifa* — "to go bad; to be damaged".

> تلفت الفاكهة بسبب الحرارة.
>
> *talifat al-fākiha bi-sabab al-ḥarāra.*
>
> The fruit spoiled because of the heat.

Present: يتلف, *yatlaf*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**تلف** (*talifa*) is built on the native Arabic root *t-l-f*, "to perish, to be destroyed" (Lane). It is the plain verb.
