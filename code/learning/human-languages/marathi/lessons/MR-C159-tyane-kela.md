# त्याने काम केलं (tyāne kām kelaṁ) — who did it, and what was done

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MR-GRAMMAR-C159-PAST-PERSON-01, MR-POSTP-NE-INSTR, MR-LEX-KARNE] -->

[PAUSE 2s] Say "I went", then the **-ने** that can mean "by", then **करणे**.

## You'll want to know: -ने on a past doer
<!-- hl-knowledge: introduces=[MR-GRAMMAR-C159-ERGATIVE-NE-01]; assesses=[MR-LEX-TO-TI-TE, MR-POSTP-NE-INSTR, MR-LEX-KARNE] -->

> **त्याने काम केलं.**
>
> *tyāne kām kelaṁ.* — "He did the work."

With a past action done to something, the third-person doer takes **-ने**:
**तो → त्याने**, **ती → तिने**, **मीरा → मीराने**. The first and second person
stay **मी** and **तू** in ordinary Marathi: **मी काम केलं**.

## You'll want to know: the verb follows the object
<!-- hl-knowledge: introduces=[MR-GRAMMAR-C159-OBJECT-AGREEMENT-01]; assesses=[MR-LEX-C89-FOOD89-01, MR-LEX-C136-THINGS136-03, MR-LEX-C93-HOME93-03, MR-LEX-C99-NATURE99-04, MR-LEX-KHANE, MR-LEX-VACHNE, MR-LEX-PAHNE] -->

The ending now follows what was acted on: **त्याने आंबा खाल्ला**, because
**आंबा** is masculine; **मी पोळी खाल्ली**, because **पोळी** is feminine;
**त्याने पुस्तक वाचलं**, because **पुस्तक** is neuter. So **त्याने कुत्रा
पाहिला** has **पाहिला** following masculine **कुत्रा**.
