## You'll want to know: பாசி
<!-- hl-knowledge: introduces=[TA-LEX-C439-MULAI439-02]; assesses=[] -->

**பாசி** — *pāci* — "moss; algae".

> குளத்தின் படிகளில் பாசி இருந்ததால் வழுக்கியது.
>
> *kuḷattiṉ paṭikaḷil pāci iruntatāl vaḻukkiyatu.*
>
> It was slippery because there was moss on the steps of the pond.

From the same root as பச்சை, green.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**பாசி** (*pāci*) is native Dravidian (DEDR 3821), "that which is green; moss, lichen, seaweed".
