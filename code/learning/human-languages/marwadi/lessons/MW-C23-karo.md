# करो — make it, on the page

## Warm-up
<!-- hl-knowledge: introduces=[MW-SCRIPT-KARO-01]; assesses=[MW-LEX-KARO-01, MW-SCRIPT-RAAM-01, MW-SCRIPT-KHA-01, MW-SCRIPT-KITNO-01, MW-SCRIPT-GHANO-01] -->

[PAUSE 22s] Say *make it*, write **राम**, write **ख**, then write *how much*
and *very*.

## You'll want to know
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-KA-01, MW-SCRIPT-RA-01, MW-SCRIPT-O-MATRA-01] -->

> **क** + **रो** → **करो** — *karo* — make it

Three signs, and the middle one is **र**, the very first sign this book taught.
Set **करो** beside **ख** and say both: **क** and **ख** differ only by breath,
and only one of them belongs in this word.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-KARO-01, MW-SCRIPT-KA-01] -->
<!-- hl-writing-stage: delayed-copy -->

Look at **करो**, cover it, wait five seconds, and write it from the sound.
Check that you wrote **क** and not **ख**.
