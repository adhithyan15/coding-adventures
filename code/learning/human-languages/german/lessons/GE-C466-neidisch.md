## You'll want to know: neidisch
<!-- hl-knowledge: introduces=[GE-LEX-C466-NEID-03]; assesses=[] -->

**neidisch** — "envious".

> Meine Schwester ist neidisch auf mein neues Fahrrad.
>
> *My sister is envious of my new bike.*

*Neidisch auf* + accusative — envious of.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*neidisch* is built on *Neid* "envy" with the adjective ending *-isch*; *Neid* is usually traced to Old High German *nīd* "hatred, envy" (EtymDB lists both German words).
