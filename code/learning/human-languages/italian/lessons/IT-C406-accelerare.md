## You'll want to know: accelerare
<!-- hl-knowledge: introduces=[IT-LEX-C406-GUIDA-01]; assesses=[] -->

**accelerare** — "to speed up, to accelerate".

> Non accelerare, c'è la nebbia.
>
> *Do not speed up, it is foggy.*

*L'acceleratore* is the accelerator pedal.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*accelerare* is a learned borrowing from Latin *accelerāre* 'to hasten' (EtymDB), built on *celer* 'swift'.
