# વેઠવું (veṭhvũ) — to put up with (hardship)

## You'll want to know: વેઠવું
<!-- hl-knowledge: introduces=[GU-LEX-C370-KHATRO370-05]; assesses=[] -->

**વેઠવું** — *veṭhvũ* — "to put up with (hardship)".

> જો તમે અત્યારે મહેનત કરશો તો પછી દુઃખ વેઠવું નહીં પડે.
>
> *jo tame atyāre mahenat karśo to pachī duḥkh veṭhvũ nahī̃ paḍe.*
>
> If you work hard now, you will not have to suffer later.

Past, with તેણે (he or she …): તેણે ઘણું દુઃખ વેઠ્યું, *teṇe ghaṇũ duḥkh veṭhyũ*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**વેઠવું** (*veṭhvũ*) is built on *veṭh*, "forced labour", which CDIAL traces to Sanskrit *viṣṭi* (CDIAL 11989); "to endure hardship" is the verb's sense, which CDIAL does not give.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
