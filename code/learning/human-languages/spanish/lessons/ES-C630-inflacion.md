## You'll want to know: la inflación
<!-- hl-knowledge: introduces=[ES-LEX-C630-ECONOMIA-04]; assesses=[] -->

**la inflación** — "the inflation".

> La inflación está muy alta este año.
>
> *Inflation is very high this year.*

When inflation goes up, everything costs more.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*inflación* is a learned borrowing from Latin *inflatio* 'a swelling', built on *inflare* 'to blow into', from *flare* 'to blow' (EtymDB).
