# વિઘ્ન (vighna) — a hindrance

## You'll want to know: વિઘ્ન
<!-- hl-knowledge: introduces=[GU-LEX-C374-AVRODH374-02]; assesses=[] -->

**વિઘ્ન** — *vighna* — "a hindrance".

> જો કોઈ વિઘ્ન આવશે તો અમે લગ્ન મુલતવી રાખીશું.
>
> *jo koī vighna āvśe to ame lagna mulatvī rākhīśũ.*
>
> If some hitch comes up, we will put off the wedding.

A neuter noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**વિઘ્ન** (*vighna*) is a tatsama, borrowed from Sanskrit *vighna*, "a breaker; an obstacle" (Monier-Williams).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
