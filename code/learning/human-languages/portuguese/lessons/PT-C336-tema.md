## You'll want to know: o tema
<!-- hl-knowledge: introduces=[PT-LEX-C336-DEBATE-01]; assesses=[] -->

**o tema** — "the topic, the subject; the theme".

> Qual é o tema da reunião de hoje?
>
> *What is the topic of today's meeting?*

*Mudar de tema* — to change the subject.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*tema* is a learned borrowing from Latin *thema* (EtymDB), which took it from Greek *théma* "something set down, a proposition", built on *tithénai* "to put".

<!-- hl-knowledge: introduces=[]; assesses=[] -->
