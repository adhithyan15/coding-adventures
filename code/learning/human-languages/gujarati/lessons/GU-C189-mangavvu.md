# મંગાવવું (mangāvvũ) — to order, to send for

## You'll want to know: મંગાવવું
<!-- hl-knowledge: introduces=[GU-LEX-C189-ORDER189-02]; assesses=[] -->

**મંગાવવું** — *mangāvvũ* — "to order, to send for".

> **અમે હોટેલમાંથી ચા મંગાવીએ છીએ.** — *ame hoṭelmā̃thī cā mangāvīe chīe* — "We order tea from the hotel."

**માગવું** asks for a thing; **મંગાવવું** has it brought.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**મંગાવવું** (*mangāvvũ*) is built on *māgvũ*, "to ask for", with the causative ending *-āvvũ*: "to have something brought". *māgvũ* is a tadbhava from Sanskrit *mā́rgati*, "seeks, requests" (CDIAL 10074).
