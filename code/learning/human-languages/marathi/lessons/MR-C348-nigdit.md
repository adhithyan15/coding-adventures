## You'll want to know: निगडित
<!-- hl-knowledge: introduces=[MR-LEX-C348-SAMBANDH348-04]; assesses=[] -->

**निगडित** — *nigḍit* — "linked (with)".

> आरोग्य आणि आहार एकमेकांशी निगडित आहेत.
>
> *ārogya āṇi āhār ekmekāṁśī nigḍit āhet.*
>
> Health and diet are linked with each other.

Takes -शी: X शी निगडित. Invariable.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**निगडित** (*nigḍit*) is a tatsama, taken from Sanskrit *nigaḍita*, "chained, fettered" (Monier-Williams). Marathi uses it for things bound up with each other.
