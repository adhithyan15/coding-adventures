## You'll want to know: एक बार और
<!-- hl-knowledge: introduces=[HI-LEX-C126-WHAT-05]; assesses=[] -->

**एक बार और** (*ek bār aur*) — "one more time".

**एक**, "one", **बार**, "time", **और**, "more". **एक बार और बोलिए** — "say it one more time".

## What you've built

Once more, didn't understand, what did you say, don't know, one more time.
