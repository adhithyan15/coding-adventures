# సాధ్యం (sādhyaṁ) — possible; feasible

## You'll want to know: సాధ్యం
<!-- hl-knowledge: introduces=[TE-LEX-C418-SADHYAM418-01]; assesses=[] -->

**సాధ్యం** — *sādhyaṁ* — "possible; feasible".

> ఒక్క రోజులో ఆ పని సాధ్యం కాదు.
>
> *okka rōjulō ā pani sādhyaṁ kādu.*
>
> That job is not possible in a single day.

సాధ్యం కాదు, it is not possible; సాధ్యమైనంత, as much as possible.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**సాధ్యం** (*sādhyaṁ*) is borrowed from Sanskrit *sādhya*, "to be mastered, won or managed" (Monier-Williams), from *sādh*, "to accomplish".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
