# సూటిగా (sūṭigā) — straight on, directly

(*ūru*.)

## You'll want to know: సూటిగా
<!-- hl-knowledge: introduces=[TE-LEX-C320-SUTIGA-01]; assesses=[TE-LEX-C05-MAATLAADU-01] -->

**సూటిగా** — *sūṭigā* — "straight on, directly".

> **సూటిగా వెళ్ళండి.**
>
> *sūṭigā veḷḷaṇḍi.* — "Go straight on."

> **అతను సూటిగా మాట్లాడతాడు.**
>
> *atanu sūṭigā māṭlāḍatāḍu.* — "He speaks plainly, straight to the point."

Like **నెమ్మదిగా** and **త్వరగా**, it is a word with **-గా** on the end, and it answers "how?". On a road
it is "straight on"; about speech it is "straight to the point".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**సూటిగా** (*sūṭigā*) is native Dravidian: **సూటి**, *sūṭi*, "aim", which DEDR 2658 lists with Tamil *cuṭṭu*, "to
point out, to aim at", and the adverb ending **-గా**. Going straight is going where you aim.
