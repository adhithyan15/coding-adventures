## You'll want to know: खबरदारी
<!-- hl-knowledge: introduces=[MR-LEX-C541-SAVADH541-02]; assesses=[] -->

**खबरदारी** — *khabardārī* — "a precaution; care".

> आपण खबरदारी घेतली तर अपघात टळतात.
>
> *āpaṇ khabardārī ghetlī tar apghāt ṭaḷtāt.*
>
> If we take care, accidents are avoided.

Feminine.

खबरदारी घेणे, to take precautions.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**खबरदारी** (*khabardārī*) is a loan from Persian *khabardārī*, "alertness", built on *khabar*, "news", which goes back to Arabic.
