# ശപിക്കുക (śapikkuka) — to curse

## You'll want to know: ശപിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C403-PRETHAM403-05]; assesses=[] -->

**ശപിക്കുക** — *śapikkuka* — "to curse".

> ദേഷ്യം വന്ന മാന്ത്രികൻ രാജാവിനെ ശപിച്ചു.
>
> *dēṣyaṁ vanna māntrikan rājāvine śapiccu.*
>
> The angry magician cursed the king.

Past: ശപിച്ചു, *śapiccu*.

The one cursed takes -എ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ശപിക്കുക** (*śapikkuka*) is built on ശാപം (*śāpaṁ*), "a curse", borrowed from Sanskrit *śāpa* (CDIAL 12393), with the Malayalam verb ending -ിക്കുക.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
