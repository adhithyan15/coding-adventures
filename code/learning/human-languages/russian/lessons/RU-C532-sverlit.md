## You'll want to know: сверлить
<!-- hl-knowledge: introduces=[RU-LEX-C532-DIY-03]; assesses=[] -->

**сверлить** (*sverlít*) — "to drill".

> Сосед с утра сверлит стену.
>
> *Soséd s utrá sverlít sténu.*
>
> The neighbour has been drilling the wall since the morning.

Imperfective; perfective просверлить. The drill bit is a *сверло*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*сверлить* is built on *сверло* 'a drill bit', which is inherited from Proto-Slavic *svьrdьlo* (EtymDB); EtymDB has no entry for the verb.
