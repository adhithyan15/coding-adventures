## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**مناسب** (*munāsib*) is built on the native Arabic root *n-s-b*, "to be related, to be suitable" (Lane). *Munāsib* is the Form III participle, "suiting".
