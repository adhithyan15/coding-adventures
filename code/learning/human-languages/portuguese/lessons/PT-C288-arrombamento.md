## You'll want to know: o arrombamento
<!-- hl-knowledge: introduces=[PT-LEX-C288-ASSALTO-05]; assesses=[] -->

**o arrombamento** — "the break-in".

> Houve um arrombamento no prédio esta noite.
>
> *There was a break-in in the building last night.*

Built on *arrombar*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*arrombamento* is built on *arrombar* "to break open" with the noun ending *-mento*; the origin of the verb is not settled (EtymDB has no entry).
