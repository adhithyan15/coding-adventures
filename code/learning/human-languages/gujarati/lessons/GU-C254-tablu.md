## You'll want to know: તબલું
<!-- hl-knowledge: introduces=[GU-LEX-C254-MUSIC254-05]; assesses=[] -->

**તબલું** — *tablũ* — "tabla drum".

> **મારા ભાઈએ તબલું વગાડ્યું.** — *mārā bhāīe tablũ vagāḍyũ* — "My brother played the tabla."

The pair is **તબલાં**, *tablā̃*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**તબલું** (*tablũ*) is a loan from Arabic *ṭabl*, "drum", which reached Gujarati through Persian. Its Arabic root is *ṭ-b-l*, "to beat a drum" (Lane).
