# Changelog

## Unreleased

- LANG84 phase 2b: the tests read `releases.csv` by header name through the
  new `inventory_rows` helper. The 18 per-release checks that matched a
  `,partial` row ending now call `assert_partial_row`, which requires
  `grammar_status=partial`, `grammar_stage=P` and
  `grammar_subset=pl-decimal-print`. New `inventory_rows_use_the_lang84_header`
  pins the 14 columns and checks that the compiled releases are exactly the
  stage-P rows. `compiled_tables_match_every_inventoried_pair` compares the
  generated `INVENTORY` with the CSV's own `grammar_stage` column (grammar-tools
  reads that column now, instead of deriving it from `grammar_status`).
  Regenerated in the new date order, and the tables are unchanged.

- LANG84 phase 4b: regenerated for the new `perl5.38.0` partial pair
  (118 checked releases, 2 parser tables). New
  `perl_5_38_0_has_its_own_partial_pair_grounded_in_its_tag` checks the
  pair's cited tag and blob IDs and probes CR whitespace, the 250/251-digit
  bound, and refusal of octal, `_`, float, exponent, radix, FF/VT, comment,
  POD, `__END__`, decrement and other out-of-subset forms. 5.38.0 joins the
  shared leading-zero, unknown-character and digit-bound probe lists.

- LANG84 phase 4a: compile every checked release pair (117 pairs, 2 distinct
  parser tables, generated by grammar-tools' generic LANG84 release-family
  path) and export `INVENTORY` (`(release, grammar_stage)` for all 776 rows),
  `SUPPORTED_RELEASES`, `grammar_class(id)`, `release_parser_grammar(id)`,
  `unversioned_parser_grammar()` and
  `MAX_RULE_DEPTH`. `parse_perl` still uses the unversioned LANG81 grammar.
  New tests pin the tables against the inventory and each pair, and run the
  shared probe through every compiled release.
