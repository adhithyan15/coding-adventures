## [0.1.1] - 2026-11-24

### Fixed

- CWE-252 (LGE-C2): every `lg_*` is now declared `LG_NODISCARD` (C23
  `[[nodiscard]]`, GCC/Clang `warn_unused_result`, MSVC `_Check_return_`), so
  dropping a result, including `LG_INVALID` (-1, truthy), is diagnosed.
  Header, README and spec 10 document the `== 1` / `!= LG_INVALID` usage.
  `tools/run.sh` adds a negative control that asserts a discarding TU fails
  to compile under `-Werror`.
- LGE-C3: the sanitizer pass no longer vanishes silently. With `CI` set and no
  compiler able to run ASan+UBSan, `tools/run.sh` exits non-zero; locally it
  prints a prominent warning. Both scripts end with a one-line summary of the
  builds that ran. `run.ps1` runs MSVC `/fsanitize=address` when available
  (best-effort on Windows, outcome always printed).
