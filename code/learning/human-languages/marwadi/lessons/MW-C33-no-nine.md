# नो — nine on the page

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-YE-01, MW-SCRIPT-AATH-01] -->

[PAUSE 16s] Write this one, then write eight.

## You'll want to know
<!-- hl-knowledge: introduces=[MW-SCRIPT-NO-NINE-01]; assesses=[MW-SCRIPT-NA-01, MW-SCRIPT-O-MATRA-01, MW-SCRIPT-DO-TWO-01, MW-LEX-NO-NINE-01] -->

> **न** + **ो** → **नो** — *no* — nine

Write **दो** and **नो** one under the other. The mark on the right is the same
in both. Only the letter carrying it changes, and with it the number.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-NO-NINE-01, MW-SCRIPT-DO-TWO-01] -->
<!-- hl-writing-stage: delayed-copy -->

Look at **नो**, cover it, wait five seconds, write it. Then write **दो** beside
it and read the pair aloud without looking.
