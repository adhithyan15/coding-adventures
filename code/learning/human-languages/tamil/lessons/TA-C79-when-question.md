## You'll want to know: எப்போது
<!-- hl-knowledge: introduces=[TA-LEX-C79-WHEN-01]; assesses=[] -->

**எப்போது** (*eppōdu*) — "when?"

You have had **இப்போது**, "now", since chapter forty-eight, and you have had the pattern
behind it since chapter forty: **i-** for near, **a-** for far, **e-** for a question.

So this word was already half yours:

| word | | |
|---|---|---|
| **இப்போது** | *ippōdu* | now — this time |
| **எப்போது** | *eppōdu* | when? — which time |

The shared piece is **போது**, a word meaning *a time, an occasion*. Change only the front and
you have walked from a statement to a question, exactly as இங்கே walked to எங்கே.

> **எப்போது வேண்டும்?** — "When do you want it?"

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

The question word for time, and the small word போது that sits inside it.
