# വിവേചനം (vivēcanaṁ) — discrimination

## You'll want to know: വിവേചനം
<!-- hl-knowledge: introduces=[ML-LEX-C416-NITI416-05]; assesses=[] -->

**വിവേചനം** — *vivēcanaṁ* — "discrimination".

> ജോലിയിൽ സ്ത്രീകളോട് വിവേചനം പാടില്ല.
>
> *jōliyil strīkaḷōṭŭ vivēcanaṁ pāṭilla.*
>
> There must be no discrimination against women at work.

Against a group: -ഓട് വിവേചനം.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**വിവേചനം** (*vivēcanaṁ*) is borrowed from Sanskrit *vivecana*, "discriminating, distinguishing" (Monier-Williams). The Sanskrit word is neutral, telling things apart; Malayalam uses it for treating people unequally.
