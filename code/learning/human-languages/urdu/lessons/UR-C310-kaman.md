## You'll want to know: کمان
<!-- hl-knowledge: introduces=[UR-LEX-C310-DHAL310-04]; assesses=[] -->

**کمان** — *kamān* — "a bow for arrows".

> سپاہی کمان چلانا جانتا تھا۔
>
> *sipāhī kamān chalānā jāntā thā.*
>
> The soldier knew how to use a bow.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**کمان** (*kamān*) is usually traced to Persian *kamān*, "a bow". It is feminine.
