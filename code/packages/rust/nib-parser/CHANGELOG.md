# Changelog

## 0.2.0 — 2026-05-20 (NIB04 step 3)

- Grammar rule `while_stmt = "while" expr block;` added to the `stmt`
  alternation (after `for_stmt`).  Required for Nib programs targeting
  the LANG VM AOT chain, where unbounded loops are valid (unlike the
  4004 backend, which still rejects them at type-check / codegen time).
- `_grammar.rs` regenerated by hand to mirror the .grammar change.

## 0.1.0

- Initial Rust port of the Nib parser with compiled grammar support.
