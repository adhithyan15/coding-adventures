## [0.1.1] - 2026-11-16

### Changed (review fixes)

- `ParseLine` and `ParseLineTokens` take this package's `Options` (embedding
  `parser.Options`, plus `MaxLineBytes` and `LenientQuoted`). Each zero limit is
  filled from `DefaultOptions()` on its own.
- A line over `MaxLineBytes` (1 MiB) is refused before lexing (`KindLimit`).
- Every quoted string is decoded strictly by default (`KindBadQuoted`).
- The killed-at-entry lines are exact: `???() = 0` and every other spelling is
  refused, and `<... ??? resumed>)  = ?` is its own body kind
  (`dead_resumed_line`); `???` is no longer an ordinary resume name.

### Added

- `PrefixBeforeUnfinished(line, ast)`.
- Tests for each of the above, the signed-pid and resume-seam divergences, and a
  signal line over the token cap.
