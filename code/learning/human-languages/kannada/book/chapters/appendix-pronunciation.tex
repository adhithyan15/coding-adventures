\section*{The three facts}

\begin{enumerate}
  \item \textbf{Consonants carry a built-in ``a.''} \kn{ಕ} = ka, \kn{ಮ} = ma,
    \kn{ರ} = ra.
  \item \textbf{A vowel sign changes that built-in vowel.} \kn{ಕಾ} = kā,
    \kn{ಕಿ} = ki, \kn{ಕೀ} = kī, \kn{ಕು} = ku, \kn{ಕೂ} = kū, \kn{ಕೆ} = ke,
    \kn{ಕೇ} = kē, \kn{ಕೊ} = ko, \kn{ಕೋ} = kō, \kn{ಕೌ} = kau.
  \item \textbf{A \emph{virama} strips the built-in vowel, and the bare
    consonant \emph{stacks under} the next as a conjunct} (\emph{ottakṣara}):
    \kn{ಸ} + \kn{ಕ} $\to$ \kn{ಸ್ಕ} (ska), \kn{ನ} + \kn{ಯ} $\to$ \kn{ನ್ಯ} (nya),
    \kn{ಲ} + \kn{ಲ} $\to$ \kn{ಲ್ಲ} (lla). This stacking is a signature of the
    Kannada--Telugu scripts.
\end{enumerate}

\section*{Worth flagging}

\begin{itemize}
  \item \textbf{Aspiration is written.} \kn{ಕ} k / \kn{ಖ} kh, \kn{ದ} d /
    \kn{ಧ} dh --- the ``h'' is a real puff. (Unlike Tamil, Kannada keeps
    separate letters for the Sanskrit aspirates and voiced stops, because it
    borrowed so many Sanskrit words.)
  \item \textbf{Round forms.} Kannada letters are rounded and looping ---
    developed for writing on palm-leaf, where straight strokes would split the
    leaf. Telugu, its closest script-sister, shares the look.
\end{itemize}

\section*{Kannada in the Dravidian family}

Kannada is one of the four literary \textbf{Dravidian} languages (with Tamil,
Telugu, Malayalam) --- a family entirely separate from the Indo-European one
(English, Latin, Sanskrit). It shares the grammar and much native vocabulary
with its sisters, but --- like Telugu, and unlike Tamil --- it borrowed
\emph{heavily} from Sanskrit. The lessons trace, word by word, which Kannada
words are home-grown (\emph{haudu}, \emph{illa}, \emph{sari}) and which came
from Sanskrit (\emph{namaskāra}, \emph{dhanyavāda}).
