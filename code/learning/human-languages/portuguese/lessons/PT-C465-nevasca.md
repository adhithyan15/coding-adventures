## You'll want to know: a nevasca
<!-- hl-knowledge: introduces=[PT-LEX-C465-TEMPORAL-05]; assesses=[] -->

**a nevasca** — "the blizzard, the snowstorm".

> A nevasca fechou a estrada da serra.
>
> *The blizzard closed the mountain road.*

Built on *a neve*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*nevasca* is built on *neve* 'snow', which is inherited from Latin *nix, nivis* (EtymDB).
