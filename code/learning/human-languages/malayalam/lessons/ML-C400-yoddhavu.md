## You'll want to know: യോദ്ധാവ്
<!-- hl-knowledge: introduces=[ML-LEX-C400-SATRU400-02]; assesses=[] -->

**യോദ്ധാവ്** — *yōddhāvŭ* — "a warrior".

> ആ യോദ്ധാവ് ഒറ്റയ്ക്ക് ശത്രുക്കളോട് യുദ്ധം ചെയ്തു.
>
> *ā yōddhāvŭ oṟṟaykkŭ śatrukkaḷōṭŭ yuddhaṁ ceytu.*
>
> That warrior fought the enemies alone.

From the same root as യുദ്ധം, war.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**യോദ്ധാവ്** (*yōddhāvŭ*) is borrowed from Sanskrit *yoddhṛ*, "a fighter, a warrior, a soldier" (Monier-Williams), from the root *yudh*, "to fight", the root of യുദ്ധം (*yuddhaṁ*).
