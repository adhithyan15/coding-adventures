# ਕਾਬਲ (kābal) — capable; able

## You'll want to know: ਕਾਬਲ
<!-- hl-knowledge: introduces=[PA-LEX-C362-SKILL362-01]; assesses=[] -->

**ਕਾਬਲ** — *kābal* — "capable; able".

> ਮੇਰਾ ਭਰਾ ਬਹੁਤ ਕਾਬਲ ਹੈ।
>
> *merā bharā bahut kābal hai.*
>
> My brother is very capable.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ਕਾਬਲ** (*kābal*) is a loan, usually traced through Persian to Arabic *qābil*, "able".
