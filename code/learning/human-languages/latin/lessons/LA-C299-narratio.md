## You'll want to know: nārrātiō, nārrātiōnis
<!-- hl-knowledge: introduces=[LA-LEX-C299-NARRATIO-01]; assesses=[] -->

**nārrātiō, nārrātiōnis** — "a narrative, a telling".

> Nārrātiō senis longa sed iūcunda erat.
>
> *The old man's story was long but pleasant.*

Feminine, 3rd declension, from *nārrō* (taught). In a Roman speech, the *nārrātiō* set out the facts. English *narration*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**nārrātiō** is built on *nārrō*, "to tell, to relate" (EtymDB), which Lewis & Short link with *gnārus*, "knowing": making known. English *narration* comes from it.
