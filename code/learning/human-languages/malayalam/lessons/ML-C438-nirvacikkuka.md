# നിർവചിക്കുക (nirvacikkuka) — to define

## You'll want to know: നിർവചിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C438-GRAHANAM438-05]; assesses=[] -->

**നിർവചിക്കുക** — *nirvacikkuka* — "to define".

> അധ്യാപകൻ ആ വാക്ക് ലളിതമായി നിർവചിച്ചു.
>
> *adhyāpakan ā vākkŭ laḷitamāyi nirvaciccu.*
>
> The teacher defined that word in plain words.

Past: നിർവചിച്ചു, *nirvaciccu*.

The noun is നിർവചനം, a definition.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**നിർവചിക്കുക** (*nirvacikkuka*) is built from Sanskrit *nirvacana*, "speaking out; interpretation, explanation" (Monier-Williams), with the Malayalam verb ending -ിക്കുക.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
