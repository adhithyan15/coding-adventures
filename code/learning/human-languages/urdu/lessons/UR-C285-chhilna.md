# چھلنا (chhilnā) — to be grazed; to be scraped

## You'll want to know: چھلنا
<!-- hl-knowledge: introduces=[UR-LEX-C285-PHISAL285-04]; assesses=[] -->

**چھلنا** — *chhilnā* — "to be grazed; to be scraped".

> میرا گھٹنا چھل گیا۔
>
> *merā ghuṭnā chhil gayā.*
>
> I grazed my knee.

Past (it …): وہ گھٹنا چھل گیا, *voh ghuṭnā chhil gayā*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

belongs with *chīlnā*, "to peel", which CDIAL lists for Hindi under *\*chilla*, a form it reconstructs (CDIAL 5051); **چھلنا** is the skin coming off by itself, in a fall.
