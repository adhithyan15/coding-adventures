# পাত্র (pātrô) — a container; a vessel

## You'll want to know: পাত্র
<!-- hl-knowledge: introduces=[BN-LEX-C511-BASON511-03]; assesses=[] -->

**পাত্র** — *pātrô* — "a container; a vessel".

> আমি চালটা একটা বড় পাত্রে রাখলাম।
>
> *Āmi chālṭā ekṭā bôṛo pātre rākhlām.*
>
> I kept the rice in a big container.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**পাত্র** (*pātrô*) is a tatsama, Sanskrit *pātra*, "a drinking vessel, a dish" (Monier-Williams).
