## You'll want to know: مورخ
<!-- hl-knowledge: introduces=[FA-LEX-C353-DOWRAN-03]; assesses=[] -->

**مورخ** (*movarrekh*) — "a historian".

> مورخ ها درباره این جنگ زیاد نوشته اند.
>
> *Movarrekh-hâ darbâre-ye in jang ziyâd neveshte-and.*
>
> Historians have written a lot about this war.

Also plural *movarrekhân*. The same Arabic root gives *târikh* "history".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*movarrekh* is usually traced to Arabic *mu'arrikh*, "historian", of the same root as *ta'rīkh* "history"; EtymDB lists no entry.
