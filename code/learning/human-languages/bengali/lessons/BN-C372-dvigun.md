# দ্বিগুণ (dvigun) — double; twice as much

[PAUSE 2s] Before the new one: say the Bengali for to grow, then the Bengali for to decrease.

## You'll want to know: দ্বিগুণ
<!-- hl-knowledge: introduces=[BN-LEX-C372-BARA372-03]; assesses=[] -->

**দ্বিগুণ** — *dvigun* — "double; twice as much".

> রাতে গেলে ভাড়া দ্বিগুণ হবে।
>
> *rāte gele bhāṛā dvigun hôbe.*
>
> If you go at night, the fare will be double.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**দ্বিগুণ** (*dvigun*) is Sanskrit *dviguṇa*, *dvi* 'two' with *guṇa* 'a fold': twofold (Monier-Williams).
