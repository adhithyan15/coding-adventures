## You'll want to know: ਸੰਵਾਰਨਾ
<!-- hl-knowledge: introduces=[PA-LEX-C363-WORK363-04]; assesses=[] -->

**ਸੰਵਾਰਨਾ** — *saṁvārnā* — "to tidy up; to set in order".

> ਮੈਂ ਸਵੇਰੇ ਦੁਕਾਨ ਸੰਵਾਰਦਾ ਹਾਂ।
>
> *maiṁ savere dukān saṁvārdā hāṁ.*
>
> I set the shop in order in the morning.

Past (I …): ਮੈਂ ਕਮਰਾ ਸੰਵਾਰਿਆ, *maiṁ kamrā saṁvāriā*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ਸੰਵਾਰਨਾ** (*saṁvārnā*) is inherited from a reconstructed *\*śodhakāra*, "making clean"; CDIAL lists Punjabi *savārṇā*, "to adorn, improve, prepare, adjust", under it (CDIAL 12628); the spelling with the nasal is not listed there.
