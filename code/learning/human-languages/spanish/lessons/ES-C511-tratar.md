## You'll want to know: tratar
<!-- hl-knowledge: introduces=[ES-LEX-C511-HACER-03]; assesses=[] -->

**tratar** — "to treat; to be about".

> La película trata de una familia.
>
> *The film is about a family.*

*Tratar de* + infinitive — to try to.
