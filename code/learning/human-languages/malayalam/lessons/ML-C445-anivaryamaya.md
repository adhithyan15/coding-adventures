## You'll want to know: അനിവാര്യമായ
<!-- hl-knowledge: introduces=[ML-LEX-C445-GAURAVAM445-01]; assesses=[] -->

**അനിവാര്യമായ** — *anivāryamāya* — "inevitable; essential".

> ആ മാറ്റം അനിവാര്യമായിരുന്നു.
>
> *ā māṟṟaṁ anivāryamāyirunnu.*
>
> That change was inevitable.

As a predicate: അത് അനിവാര്യമാണ്.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**അനിവാര്യമായ** (*anivāryamāya*) is built from Sanskrit *anivārya*, "not to be warded off, unavoidable" (Monier-Williams), with the adjective ending -ആയ.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
