# എതിർപ്പ് (etirppŭ) — an objection; resistance

## You'll want to know: എതിർപ്പ്
<!-- hl-knowledge: introduces=[ML-LEX-C453-PINTUNA453-03]; assesses=[] -->

**എതിർപ്പ്** — *etirppŭ* — "an objection; resistance".

> പുതിയ നികുതിക്കെതിരെ വലിയ എതിർപ്പ് ഉണ്ടായി.
>
> *putiya nikutikketire valiya etirppŭ uṇṭāyi.*
>
> There was strong resistance to the new tax.

The noun of എതിർക്കുക, to oppose.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**എതിർപ്പ്** (*etirppŭ*) is native Dravidian, the noun of എതിർക്കുക, from *etir*, "that which is opposite, in front" (DEDR 795).
