# प्रतिबंध करणे (pratibandh karṇe) — to prevent

## You'll want to know: प्रतिबंध करणे
<!-- hl-knowledge: introduces=[MR-LEX-C386-PRATIBANDH386-01]; assesses=[] -->

**प्रतिबंध करणे** — *pratibandh karṇe* — "to prevent".

> स्वच्छतेमुळे आजारांना प्रतिबंध करता येतो.
>
> *svacchatemuḷe ājārānnā pratibandh kartā yeto.*
>
> Cleanliness can prevent illness.

Past, with -ने (he …): त्याने प्रतिबंध केला, *tyāne pratibandh kelā*.

What is prevented takes -ला; प्रतिबंधक, preventive.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**प्रतिबंध करणे** (*pratibandh karṇe*) joins the tatsama प्रतिबंध, Sanskrit *pratibandha*, "connexion, hindrance" (CDIAL 8580), to करणे, "to do".
