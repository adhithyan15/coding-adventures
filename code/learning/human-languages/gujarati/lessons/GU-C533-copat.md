# ચોપાટ (copāṭ) — chaupat (a dice board game)

## You'll want to know: ચોપાટ
<!-- hl-knowledge: introduces=[GU-LEX-C533-PASO533-02]; assesses=[] -->

**ચોપાટ** — *copāṭ* — "chaupat (a dice board game)".

> જો બહાર વરસાદ પડશે તો આપણે ઘરમાં ચોપાટ રમીશું.
>
> *jo bahār varsād paḍśe to āpaṇe gharmā̃ copāṭ ramīśũ.*
>
> If it rains outside, we'll play chaupat indoors.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ચોપાટ** (*copāṭ*) comes from *\*catuṣpaṭṭa*, "a four-sided tablet", a form CDIAL reconstructs, and CDIAL lists the Gujarati word as a dice board (CDIAL 4639).

One more word for saying what happens if.
