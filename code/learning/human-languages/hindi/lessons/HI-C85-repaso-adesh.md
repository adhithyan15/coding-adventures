# tīn star, ek kriyā — three levels running through everything

## Grammar Lens: the same choice, made four times
<!-- hl-knowledge: introduces=[]; assesses=[HI-LEX-C85-IMP-01, HI-LEX-C85-IMP-02, HI-LEX-C85-IMP-03, HI-LEX-C84-POSS-03] -->

The level is not a fact about the verb. It is a fact about **who you are talking
to**, and every part of the sentence agrees to it:

| level | possessive | copula |
|---|---|---|
| तू | तेरा | है |
| तुम | तुम्हारा | **हो** |
| आप | आपका | हैं |

| level | command | negative command |
|---|---|---|
| तू | बोल | मत बोल |
| तुम | **बोलो** | मत बोलो |
| आप | **बोलिए** | मत बोलिए |

Read each row straight across. Choosing a person picks the whole row, and every
cell in it follows. That is the saving: one decision, not four.

The **तू** column is there for recognition. A learner should read it and not
produce it — it is intimate between close friends and insulting to anyone else,
and the risk of getting it wrong is much larger than the benefit of using it.

## Grammar Lens: how each command is built
<!-- hl-knowledge: introduces=[]; assesses=[HI-LEX-C85-IMP-01, HI-LEX-C85-IMP-02, HI-LEX-C85-IMP-04, HI-CONCEPT-C05-BOLNA-01] -->

| level | from *bolnā* | ending |
|---|---|---|
| तू | बोल | the bare stem |
| तुम | बोलो | **-o** |
| आप | बोलिए | **-iye** |

Three endings, one stem. And as the table above showed, **मत** is the same word
at every level — the negative does not change with politeness, only the verb
does.
