## You'll want to know: آزمون
<!-- hl-knowledge: introduces=[FA-LEX-C399-KONKUR-02]; assesses=[] -->

**آزمون** (*âzmun*) — "a test, an examination".

> آزمون زبان را دیروز دادم.
>
> *âzmun-e zabân râ diruz dâdam.*
>
> I took the language test yesterday.

Formal; in speech *emtehân*. *Âzmun dâdan* — to sit a test.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**آزمون** is native Persian, built on *âzmudan* "to test, to try": a test is a trying.
