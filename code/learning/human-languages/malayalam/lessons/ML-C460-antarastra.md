# അന്താരാഷ്ട്ര (antārāṣṭra) — international

## You'll want to know: അന്താരാഷ്ട്ര
<!-- hl-knowledge: introduces=[ML-LEX-C460-AGOLAM460-01]; assesses=[] -->

**അന്താരാഷ്ട്ര** — *antārāṣṭra* — "international".

> നഗരത്തിൽ ഒരു അന്താരാഷ്ട്ര സമ്മേളനം നടന്നു.
>
> *nagarattil oru antārāṣṭra sammēḷanaṁ naṭannu.*
>
> An international conference was held in the city.

It stands before a noun: അന്താരാഷ്ട്ര വിമാനത്താവളം, an international airport.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**അന്താരാഷ്ട്ര** (*antārāṣṭra*) is a modern word built from Sanskrit *antar*, "between, within" (CDIAL 356), and *rāṣṭra*, "a kingdom, a country" (CDIAL 10721): between countries.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
