# म्हारो नाम राम है। — say one name

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MW-LEX-MHARO-01, MW-LEX-NAAM-01, MW-LEX-RAAM-01, MW-LEX-HAI-01] -->

[PAUSE 10s] Hear *mhāro, nām, rām, hai* in mixed order. Give each meaning.

## You'll want to know
<!-- hl-knowledge: introduces=[MW-SCRIPT-HAI-01, MW-PHRASE-MY-NAME-IS-01]; assesses=[MW-SCRIPT-MHARO-01, MW-SCRIPT-NAAM-01, MW-SCRIPT-RAAM-01, MW-SCRIPT-HA-01, MW-SCRIPT-AI-MATRA-01] -->

> **म्हारो | नाम | राम | है।**
>
> *mhāro nām rām hai* — My name is Ram.

The written line adds no new sign. **है** is known **ह** plus **ै**. Replace
**राम** with your chosen name when speaking; keep Ram for the first writing
attempt because every sign is already yours.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[MW-PHRASE-MY-NAME-IS-01, MW-SCRIPT-HAI-01] -->

1. hear the line and point to the person naming themself
2. say the line once with *rām*
3. read the four groups without romanization

repair one group, not the whole sentence.
