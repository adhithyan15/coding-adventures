1 lesson. It can be done entirely by ear.


Lesson 1 of 1.
Review — the whole thing, at last.

Warm-up.
[pause 2 seconds]
Nothing new in this chapter. Say "we speak", then "they speak."

Grammar Lens: the table this book has been withholding.
Six forms. Every one of them built separately, on its own, in its own lesson.
[a table of 6 rows, read aloud]
who: yo. hablar, which gives:: hablo.
who: tú. hablar, which gives:: hablas.
who: él, ella, usted. hablar, which gives:: habla.
who: nosotros. hablar, which gives:: hablamos.
who: vosotros (Spain). hablar, which gives:: habláis.
who: ellos, ellas, ustedes. hablar, which gives:: hablan.
Most Spanish courses open with this table. This one has spent thirty-two chapters refusing to show it, because a table you cannot yet fill is a picture of work still to do, and a table you can fill is a picture of ground you hold.
Run through it now and there should be no surprises in it. That is the point.
And it is not one verb. Every regular -ar verb in Spanish — thousands of them — runs on these six endings, so this table is the present tense of a large part of the language.
