# ખુલ્લું (khullũ) — not closed

## You'll want to know: ખુલ્લું
<!-- hl-knowledge: introduces=[GU-LEX-C151-READ151-02]; assesses=[GU-LEX-DUKAAN-01, GU-LEX-C129-THINGS129-03, GU-LEX-BAARI-01, GU-GRAMMAR-C147-HATO-01, GU-LEX-C138-ACT138-04] -->

**ખુલ્લું** (*khullũ*) — "not closed, open".

It describes a door, a window or a shop that stands open, and it bends like
*my*:

> **દુકાન ખુલ્લી છે.** — *dukān khullī che.* — The shop is open.
> **દરવાજો ખુલ્લો છે.** — *darvājo khullo che.* — The gate is open.
> **બારી ખુલ્લી હતી.** — *bārī khullī hatī.* — The window was open.

**ખોલવું** is the act, *to open*; **ખુલ્લું** is the state it leaves behind.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ખુલ્લું** (*khullũ*) is inherited. CDIAL sets **ખોલવું** *kholvũ*, "to open",
and *khulvũ*, "to be open", under a reconstructed Indo-Aryan *khōll-* and
*khull-* (CDIAL 3945); **ખુલ્લું** is the adjective of that second verb.
