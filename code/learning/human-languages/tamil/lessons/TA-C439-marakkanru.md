# மரக்கன்று (marakkaṉṟu) — a sapling

## You'll want to know: மரக்கன்று
<!-- hl-knowledge: introduces=[TA-LEX-C439-MULAI439-03]; assesses=[] -->

**மரக்கன்று** — *marakkaṉṟu* — "a sapling".

> பள்ளி மாணவர்கள் நூறு மரக்கன்றுகளை நட்டார்கள்.
>
> *paḷḷi māṇavarkaḷ nūṟu marakkaṉṟukaḷai naṭṭārkaḷ.*
>
> The schoolchildren planted a hundred saplings.

மரம், a tree, + கன்று, a young one: மரம் drops -ம் and doubles க்.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**மரக்கன்று** (*marakkaṉṟu*) is built from மரம், "a tree" (DEDR 4711), and கன்று, "a calf, a sapling, a young tree" (DEDR 1411).
