## You'll want to know

> *do* — **two**

Chapter 29 taught *do* as an asking word: **hand it over**. This is the same
sound and it will be the same two signs, with a second job.

Nothing marks which one is meant except where it stands. Before a thing, *do*
counts it. After a thing, in a request, *do* asks for it. A learner who has met
both hears the difference from the shape of the sentence, not from the word.

Rajasthani also prints **बे** (*be*) for two, alongside *do*. Both are in use;
this book counts with *do* and names *be* so a printed page holding it is not a
surprise.
