\chapter*{How to use this starter edition}
\addcontentsline{toc}{chapter}{How to use this starter edition}

Begin with no assumed Russian or Cyrillic. Each numbered section is a short,
resumable lesson. It introduces only the word, letters, grammar, or contrast
needed at that point, connects the expression to history you may already know,
and ends with retrieval. Read in order: every checkpoint uses only earlier
sections plus the expression just introduced.

Stress matters in Russian but ordinary Cyrillic does not print it. Romanization
marks the stressed vowel with an acute accent in this starter edition, then
gradually yields to the script. Cyrillic letters appear inside useful words;
there is no alphabet exam before the first greeting. Separate companion writing
lessons break the same letters into strokes for the Language Ladder app.

The companion Markdown curriculum still contains known five- and six-minute
estimates. The shared migration backlog records that debt explicitly. This book
uses shorter micro-sections; it does not pretend the future one-source duration
gate has already been completed.
