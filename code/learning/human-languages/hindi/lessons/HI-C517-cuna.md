## You'll want to know: चूना
<!-- hl-knowledge: introduces=[HI-LEX-C517-EENT517-02]; assesses=[] -->

**चूना** — *cūnā* — "lime (for whitewash)".

> दीवारों पर नया चूना लगा है, इसलिए कमरा साफ़ दिखता है।
>
> *Dīvāroṁ par nayā cūnā lagā hai, isliye kamrā sāf dikhtā hai.*
>
> The walls have fresh whitewash, so the room looks clean.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**चूना** (*cūnā*) is a tadbhava, inherited from Sanskrit *cūrṇa*, "powder", which already meant lime in Sanskrit (CDIAL 4889).
