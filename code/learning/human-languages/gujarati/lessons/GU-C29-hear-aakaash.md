# આકાશ — hear sky

## Warm-up
<!-- hl-knowledge: introduces=[GU-LEX-AAKAASH-01]; assesses=[GU-LEX-CHANDRA-01] -->

[PAUSE 3s] Say the words for sun and for moon. Now listen twice: **ākāsh**. It means
**sky** — the thing that holds both the *sūraj* and the *chandra*.
