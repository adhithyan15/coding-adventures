# പാഴാക്കുക (pāḻākkuka) — to waste

[PAUSE 2s] Before the new one: say the Malayalam for to make use of, then the Malayalam for to allocate funds.

## You'll want to know: പാഴാക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C458-VAYPA458-03]; assesses=[] -->

**പാഴാക്കുക** — *pāḻākkuka* — "to waste".

> അവൻ സമയം ഒട്ടും പാഴാക്കിയില്ല.
>
> *avan samayaṁ oṭṭuṁ pāḻākkiyilla.*
>
> He did not waste any time at all.

Past: പാഴാക്കി, *pāḻākki*.

പാഴ്, waste, with ആക്കുക, to make.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**പാഴാക്കുക** (*pāḻākkuka*) is a native Malayalam compound: പാഴ്, "an empty place; waste, useless" (DEDR 4110), and ആക്കുക, "to make" (DEDR 333): to make a thing useless.
