# ਹੈਰਾਨ (hairān) — surprised

## You'll want to know: ਹੈਰਾਨ
<!-- hl-knowledge: introduces=[PA-LEX-C326-FEAR326-03]; assesses=[] -->

**ਹੈਰਾਨ** — *hairān* — "surprised".

> ਮੈਂ ਉਸ ਖ਼ਬਰ ਤੋਂ ਬਹੁਤ ਹੈਰਾਨ ਸੀ।
>
> *maiṁ us khabar ton bahut hairān sī.*
>
> I was very surprised by that news.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ਹੈਰਾਨ** (*hairān*) is a loan, usually traced through Persian to Arabic *ḥayrān*, "bewildered".
