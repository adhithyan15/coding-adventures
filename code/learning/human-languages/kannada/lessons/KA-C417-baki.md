# ಬಾಕಿ (bāki) — arrears; the balance due

## You'll want to know: ಬಾಕಿ
<!-- hl-knowledge: introduces=[KA-LEX-C417-KANTU417-02]; assesses=[] -->

**ಬಾಕಿ** — *bāki* — "arrears; the balance due".

> ಅಂಗಡಿಗೆ ಇನ್ನೂ ನೂರು ರೂಪಾಯಿ ಬಾಕಿ ಇದೆ.
>
> *aṅgaḍige innū nūru rūpāyi bāki ide.*
>
> A hundred rupees are still owed to the shop.

ಬಾಕಿ ಇರು, to be outstanding.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಬಾಕಿ** (*bāki*) is a loan from Arabic *bāqī*, "remaining", which reached Kannada through Hindustani.
