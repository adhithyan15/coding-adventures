## You'll want to know: el método
<!-- hl-knowledge: introduces=[ES-LEX-C599-INVESTIGA-05]; assesses=[] -->

**el método** — "the method".

> Es un buen método para estudiar.
>
> *It is a good method for studying.*

*Método de pago* — payment method.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*método* is a learned borrowing from Latin *methodus*, taken from Greek *methodos* 'a following after, a way of inquiry', built from *meta* and *hodos* 'way' (EtymDB).
