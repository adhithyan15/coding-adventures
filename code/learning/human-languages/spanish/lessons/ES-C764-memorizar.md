## You'll want to know: memorizar
<!-- hl-knowledge: introduces=[ES-LEX-C764-RECUERDO-03]; assesses=[] -->

**memorizar** — "to memorize, to learn by heart".

> Tengo que memorizar estos números.
>
> *I have to learn these numbers by heart.*

*Aprender de memoria* means the same.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*memorizar* is built on *memoria* "memory" with the ending *-izar*; *memoria* is a learned borrowing from Latin *memoria*, from *memor* "mindful".
