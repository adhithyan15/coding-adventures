# ફિકર (phikar) — concern; worry about someone

<!-- hl-knowledge: introduces=[]; assesses=[GU-LEX-C453-BIK453-05, GU-LEX-C454-UCAT454-01] -->

## You'll want to know: ફિકર
<!-- hl-knowledge: introduces=[GU-LEX-C454-UCAT454-02]; assesses=[] -->

**ફિકર** — *phikar* — "concern; worry about someone".

> તમે મારી ફિકર ન કરો.
>
> *tame mārī phikar na karo.*
>
> Don't worry about me.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ફિકર** (*phikar*) is usually traced to Arabic *fikr*, "thought, reflection", which reached Gujarati through Persian with the sense "worry".
