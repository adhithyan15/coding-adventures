## You'll want to know: programmer
<!-- hl-knowledge: introduces=[FR-LEX-C371-ANNULER-05]; assesses=[] -->

**programmer** — "to schedule, to plan; to program".

> Nous avons programmé la fête pour samedi.
>
> *We scheduled the party for Saturday.*

Also to program a machine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*programmer* is built on *programme*, from Late Latin *programma* "a proclamation, an edict" (EtymDB; Lewis & Short), from Greek *prógramma* "a written public notice", built from *pró* "before" and *gráphein* "to write".
