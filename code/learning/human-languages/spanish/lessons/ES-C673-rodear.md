## You'll want to know: rodear
<!-- hl-knowledge: introduces=[ES-LEX-C673-DIRIGIRSE-04]; assesses=[] -->

**rodear** — "to go round; to surround".

> Rodeamos el lago a pie.
>
> *We walked round the lake.*

*Rodeado de* — surrounded by.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*rodear* is built on *rueda* "wheel", which is inherited from Latin *rota*: to go round as a wheel does.
