## You'll want to know: మాట్లాడు
<!-- hl-knowledge: introduces=[TE-LEX-SPEAK]; assesses=[] -->

**మాట్లాడు** (*māṭlāḍu*) — "speak".

From *māṭa*, 'word', plus *āḍu*, 'to play' — the same construction as Kannada's *mātāḍu*, built from the same two pieces.
