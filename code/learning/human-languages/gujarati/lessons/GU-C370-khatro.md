## You'll want to know: ખતરો
<!-- hl-knowledge: introduces=[GU-LEX-C370-KHATRO370-01]; assesses=[] -->

**ખતરો** — *khatro* — "a peril".

> જો આ જૂના પુલ પર ભારે ગાડીઓ ચાલશે તો ખતરો છે.
>
> *jo ā jūnā pul par bhāre gāḍīo cālśe to khatro che.*
>
> If heavy vehicles use this old bridge, it is dangerous.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ખતરો** (*khatro*) is usually traced to Arabic *khaṭar*, "danger, risk", through Persian.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
