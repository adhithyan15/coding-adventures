# ਮਨਨ — two familiar pieces, one repeated

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-SCRIPT-MA-01, PA-SCRIPT-NA-01] -->

Write **ਮ** once and **ਨ** once. No new letter appears today.

## Script — assemble the second practice name
<!-- hl-knowledge: introduces=[PA-FORM-NAME-MANAN-01]; assesses=[PA-SCRIPT-MA-01, PA-SCRIPT-NA-01] -->

> **ਮ** + **ਨ** + **ਨ** → **ਮਨਨ**

This is the second and final value in the first name-field bank. Notice the two
adjacent **ਨ** letters; neither may disappear.

## Writing — guided copy
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-NAME-MANAN-01] -->

Keep **ਮਨਨ** visible. Copy it once. Tap three positions after writing:
**ਮ | ਨ | ਨ**. If there are only two positions, restore the final **ਨ**.

## Wrap-up recall
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-NAME-MANAN-01] -->
<!-- hl-activity: {"id":"PA-W02-manan-read","kind":"text","assesses":["PA-FORM-NAME-MANAN-01"],"prompt":"Read the practice name ਮਨਨ and type the same three-letter Gurmukhi name.","answer":"ਮਨਨ","accepted":[],"feedback":{"correct":"ਮਨਨ keeps both final ਨ letters.","incorrect":"Tap the three positions: ਮ, ਨ, ਨ."},"response_seconds":12} -->

Contrast once: **ਅਮਨ** begins with **ਅ**; **ਮਨਨ** begins with **ਮ**.
