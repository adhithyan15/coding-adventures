# CodingAdventures.DerTlv.FSharp

Bounded, authority-free DER identifier and definite-length framing for F#.
The library exposes exact and one-element decoding, caller-memory views,
transactional sibling cursors, explicit resource limits, and the portable
17-error taxonomy.

Run `BUILD` or `BUILD_windows` to execute all 54 language-neutral fixture cases
with the 95% production line-coverage gate.
