# சூட்கேஸ் (cūṭkēs) — a suitcase

## You'll want to know: சூட்கேஸ்
<!-- hl-knowledge: introduces=[TA-LEX-C402-SUMAI402-02]; assesses=[] -->

**சூட்கேஸ்** — *cūṭkēs* — "a suitcase".

> அவள் சூட்கேஸை மெதுவாகத் தூக்கினாள்.
>
> *avaḷ cūṭkēsai metuvākat tūkkiṉāḷ.*
>
> She lifted the suitcase slowly.

A loan in native letters: before -ஐ the final ஸ் takes the vowel, சூட்கேஸை.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**சூட்கேஸ்** (*cūṭkēs*) is a loan from English *suitcase*, written with the grantha letter ஸ.
