## You'll want to know: le fichier
<!-- hl-knowledge: introduces=[FR-LEX-C397-FICHIER-01]; assesses=[] -->

**le fichier** — "the file (on a computer)".

> Je t'ai envoyé le fichier par courriel.
>
> *I sent you the file by email.*

A paper file is *un dossier*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*fichier* is built on *fiche* "an index card", from *ficher* "to fasten, to fix in" (EtymDB), usually traced to a Vulgar Latin *fīgicāre*, from *fīgere* "to fix" (Lewis & Short).
