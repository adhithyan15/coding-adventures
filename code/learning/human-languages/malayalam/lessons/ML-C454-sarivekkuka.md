# ശരിവെക്കുക (śarivekkuka) — to uphold; to endorse

## You'll want to know: ശരിവെക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C454-UNNAYAM454-03]; assesses=[] -->

**ശരിവെക്കുക** — *śarivekkuka* — "to uphold; to endorse".

> മേൽക്കോടതി ആ വിധി ശരിവെച്ചു.
>
> *mēlkkōṭati ā vidhi śariveccu.*
>
> The higher court upheld that verdict.

Past: ശരിവെച്ചു, *śariveccu*.

ശരി, right, with വെക്കുക, to put: to set a thing down as right.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ശരിവെക്കുക** (*śarivekkuka*) is a Malayalam compound: ശരി, "right, correct", whose origin is uncertain (often traced to Sanskrit *sadṛśa*, "alike", CDIAL 13120), and വെക്കുക, "to put", native Dravidian (DEDR 5549).
