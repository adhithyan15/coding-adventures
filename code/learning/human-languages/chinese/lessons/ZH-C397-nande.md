## You'll want to know: 难得
<!-- hl-knowledge: introduces=[ZH-LEX-C397-SURELY397-03]; assesses=[] -->

**难得** — *nándé* — "rare; hard to come by".

> **我们难得有时间一起吃饭** *wǒmen nándé yǒu shíjiān yìqǐ chī fàn* — We seldom get time to eat together.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**难得** (*nándé*) is built from 难 'hard' and 得 'to get', both inherited from Middle Chinese, *nan* and *tok* (Guangyun, in Baxter's transcription), which glosses the first 'difficult'.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what would happen.
