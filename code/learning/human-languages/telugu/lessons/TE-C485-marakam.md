## You'll want to know: మారకం
<!-- hl-knowledge: introduces=[TE-LEX-C485-NAGADU485-04]; assesses=[] -->

**మారకం** — *mārakaṁ* — "an exchange rate".

> ఇవాళ డాలరు మారకం రేటు పెరిగింది.
>
> *ivāḷa ḍālaru mārakaṁ rēṭu perigindi.*
>
> Today the dollar exchange rate went up.

మారకం రేటు, the exchange rate. మారు, to change, is in the word.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**మారకం** (*mārakaṁ*) is native Dravidian, built on మారు, "to change, to be exchanged" (DEDR 4834).
