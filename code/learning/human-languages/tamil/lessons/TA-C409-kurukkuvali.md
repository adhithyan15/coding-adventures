# குறுக்குவழி (kuṟukkuvaḻi) — a shortcut

## You'll want to know: குறுக்குவழி
<!-- hl-knowledge: introduces=[TA-LEX-C409-KUZHI409-04]; assesses=[] -->

**குறுக்குவழி** — *kuṟukkuvaḻi* — "a shortcut".

> குறுக்குவழியில் போனதால் சீக்கிரம் வந்தோம்.
>
> *kuṟukkuvaḻiyil pōṉatāl cīkkiram vantōm.*
>
> We arrived early because we took a shortcut.

குறுக்கு, across, + வழி, way.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**குறுக்குவழி** (*kuṟukkuvaḻi*) is built from குறுக்கு, "to shorten; a short distance, across" (DEDR 1851), and வழி, "a way" (DEDR 5297).
