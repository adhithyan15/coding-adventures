# Keep both pieces of thinking

## Warm-up
<!-- hl-knowledge: introduces=[MR-A1-MESSAGE-LINE-THINK]; assesses=[MR-LEX-VICHAR-KARNE, MR-GRAMMAR-PRESENT-GENDER] -->

Retrieve the known pair **विचार करणे**. In the sentence, **विचार** stays beside
the light verb: **मी विचार करतो.**

verb pieces first; check the full stop second.
