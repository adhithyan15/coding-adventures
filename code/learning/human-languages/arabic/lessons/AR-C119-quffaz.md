## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**قفاز** (*quffāz*) is built on the native Arabic root *q-f-z*, "to leap" (Lane). Lane's *quffāz* is a thing worn on the hand, stuffed with cotton.
