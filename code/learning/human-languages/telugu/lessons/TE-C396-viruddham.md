# విరుద్ధం (viruddhaṁ) — contrary; opposed

## You'll want to know: విరుద్ధం
<!-- hl-knowledge: introduces=[TE-LEX-C396-VIRUDDHAM396-04]; assesses=[] -->

**విరుద్ధం** — *viruddhaṁ* — "contrary; opposed".

> అది నియమాలకు విరుద్ధం.
>
> *adi niyamālaku viruddhaṁ.*
>
> That is against the rules.

The thing opposed takes -కి: నియమానికి విరుద్ధం.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**విరుద్ధం** (*viruddhaṁ*) is borrowed from Sanskrit *viruddha*, "opposed, hindered" (CDIAL 11864).
