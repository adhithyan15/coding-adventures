# பற்றாக்குறை (paṟṟākkuṟai) — a deficit; a shortage

## You'll want to know: பற்றாக்குறை
<!-- hl-knowledge: introduces=[TA-LEX-C391-PORULATARAM391-03]; assesses=[] -->

**பற்றாக்குறை** — *paṟṟākkuṟai* — "a deficit; a shortage".

> மழை இல்லாவிட்டால் தண்ணீர்ப் பற்றாக்குறை ஏற்படும்.
>
> *maḻai illāviṭṭāl taṇṇīrp paṟṟākkuṟai ēṟpaṭum.*
>
> If there is no rain, there will be a water shortage.

பற்றா, not enough + குறை, a lack.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**பற்றாக்குறை** (*paṟṟākkuṟai*) is native: *paṟṟā*, "not sufficing", the negative of *paṟṟu* (DEDR 4034), and *kuṟai*, "deficiency, lack" (DEDR 1851).
