# પ્રસન્ન (prasann) — pleased; cheerful

## You'll want to know: પ્રસન્ન
<!-- hl-knowledge: introduces=[GU-LEX-C449-ATUR449-05]; assesses=[] -->

**પ્રસન્ન** — *prasann* — "pleased; cheerful".

> ગુરુ મારા જવાબથી પ્રસન્ન થયા.
>
> *guru mārā javābthī prasann thayā.*
>
> The teacher was pleased with my answer.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**પ્રસન્ન** (*prasann*) is a tatsama, Sanskrit *prasanna*, "clear, bright, pure", as Monier-Williams records it; Gujarati uses it for a clear, pleased mind.
