## You'll want to know: 传话
<!-- hl-knowledge: introduces=[ZH-LEX-C328-LEGEND328-05]; assesses=[] -->

**传话** — *chuánhuà* — "to carry messages between people".

> **他们两个人不说话他在中间传话** *tāmen liǎng ge rén bù shuōhuà tā zài zhōngjiān chuánhuà* — Those two aren't speaking, so he carries messages between them.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**传话** (*chuánhuà*) is built from 传 'to pass on' and 话 'words', both inherited from Middle Chinese, *drjwen* and *hwaejH* (Guangyun, in Baxter's transcription), which glosses the second 'talk'.
