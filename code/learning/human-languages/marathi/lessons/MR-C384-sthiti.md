## You'll want to know: स्थिती
<!-- hl-knowledge: introduces=[MR-LEX-C384-PARISTHITI384-02]; assesses=[] -->

**स्थिती** — *sthitī* — "a state; a condition".

> रस्त्यांची स्थिती पावसाळ्यात खराब होते.
>
> *rastyāñcī sthitī pāvsāḷyāt kharāb hote.*
>
> The state of the roads gets bad in the monsoon.

Feminine.

Feminine: X ची स्थिती, the state of X.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**स्थिती** (*sthitī*) is a tatsama, taken from Sanskrit *sthiti*, "standing upright, continued existence" (CDIAL 13769).
