## You'll want to know: விடுமுறை
<!-- hl-knowledge: introduces=[TA-LEX-C106-CARE-05]; assesses=[] -->

**விடுமுறை** (*viṭumuṟai*) — "a holiday", "leave".

**இன்று விடுமுறை** — "today is a holiday".
