## You'll want to know

> *ughaṇīs* — **nineteen**

Every other teen has been the small number plus an ending. This one is not.

Nine is *no*, and there is no *no* in *ughaṇīs*. What is in it is **-ṇīs**, which
is *bīs*, **twenty**, worn down — and *ugha-*, which means **one short of**. So
nineteen in Marwari is not "nine-and-ten". It is **one less than twenty**, and it
is built on the number *above* it.

That is why twenty was taught before the teens rather than after them. A course
that counted straight up would have printed *bīs* inside nineteen before it had
taught *bīs*. The language counts down here, so the book did too.

Turner records the same habit further up: *ekuṇcālīs*, one short of forty, for
thirty-nine.
