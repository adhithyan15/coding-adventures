## You'll want to know: il rinfresco
<!-- hl-knowledge: introduces=[IT-LEX-C318-RICEVIMENTO-04]; assesses=[] -->

**il rinfresco** — "the refreshments, the drinks party".

> Dopo il concerto c'è un piccolo rinfresco.
>
> *After the concert there are some refreshments.*

Built on *fresco*, ‘fresh’.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*rinfresco* is built on *rinfrescare* "to refresh", from *fresco* "fresh", which EtymDB traces through Medieval Latin *friscus* to a Germanic word.
