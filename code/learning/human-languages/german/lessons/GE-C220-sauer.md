## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**sauer** ← Middle High German *sūr* ← Old High German *sūr* (EtymDB 2.1) — inherited, the same word as English *sour*. "Annoyed" is a soured mood.
