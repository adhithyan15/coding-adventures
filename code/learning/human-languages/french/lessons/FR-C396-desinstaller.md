## You'll want to know: désinstaller
<!-- hl-knowledge: introduces=[FR-LEX-C396-LOGICIEL-02]; assesses=[] -->

**désinstaller** — "to uninstall".

> J'ai désinstallé ce jeu : il prenait trop de place.
>
> *I uninstalled that game: it took up too much space.*

*Dés-* + *installer*: the opposite.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*désinstaller* is built from *dés-* and *installer*, which is usually traced to Medieval Latin *installāre* "to put into a stall", built on a Germanic word for a stall.
