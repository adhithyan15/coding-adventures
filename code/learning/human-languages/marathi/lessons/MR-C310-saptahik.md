## You'll want to know: साप्ताहिक
<!-- hl-knowledge: introduces=[MR-LEX-C310-VRUTTAPATRA310-03]; assesses=[] -->

**साप्ताहिक** — *sāptāhik* — "a weekly".

> हे साप्ताहिक दर गुरुवारी येतं.
>
> *he sāptāhik dar guruvārī yetaṁ.*
>
> This weekly comes out every Thursday.

Neuter.

Built on सप्ताह, a week; compare मासिक, a monthly.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**साप्ताहिक** (*sāptāhik*) is built on Sanskrit *saptāha*, 'a week' (Monier-Williams), with the adjective ending *-ika*.
