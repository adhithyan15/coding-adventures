## You'll want to know: યથાર્થ
<!-- hl-knowledge: introduces=[GU-LEX-C351-HAKIKAT351-04]; assesses=[] -->

**યથાર્થ** — *yathārth* — "true to the facts".

> આ ફોટો ગામની યથાર્થ પરિસ્થિતિ બતાવે છે.
>
> *ā phoṭo gāmnī yathārth paristhiti batāve che.*
>
> This photo shows the true state of the village.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**યથાર્થ** (*yathārth*) is a tatsama, borrowed from Sanskrit *yathārtha*, "in accordance with reality" (Monier-Williams).
