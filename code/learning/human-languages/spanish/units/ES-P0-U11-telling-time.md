# Unit 11: Telling Time

## Warm-up

[PAUSE 2s] Give the *ser* form for "it is" (*es*) and "they are" (*son*).
Today both get used for a single idea: the time.

## New Material

**la hora** (fem.) — hour
> ← Latin *hora* (→ English *hour*, *horoscope* — literally "watcher of the
> hour").

**es la una** — it's one o'clock
**son las dos** — it's two o'clock
> Built from *ser*, already known.

**y media** — half past
> *medio* ← Latin *medius* (→ English *medium*, *median*, *mediate*).

**y cuarto** — quarter past
**menos cuarto** — quarter to
> *cuarto* ← Latin *quartus* ("fourth" — same root as *cuatro*).

## Grammar Lens

Spanish switches between singular and plural "to be" depending on the hour:
*es la una* (singular *es*, because "the one [hour]" is grammatically
singular) but *son las dos, son las tres...* (plural *son* from two
onward, because "the two/three [hours]" is plural). English "it is two
o'clock" always uses singular "is," no matter the hour — the hour count
never changes the verb. This is the same *ser*-agrees-with-its-subject
logic from Chapter 1, just applied somewhere English speakers wouldn't
expect it.

## Wrap-up Recall

[PAUSE 3s] Why does Spanish say *es la una* but *son las dos*? ... Because
*ser* agrees with the hour count — "the one hour" is singular, "the two
hours" is plural.
