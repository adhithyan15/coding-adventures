# പ്രസംഗം (prasaṁgaṁ) — a speech

## You'll want to know: പ്രസംഗം
<!-- hl-knowledge: introduces=[ML-LEX-C354-PRASAMGAM354-01]; assesses=[] -->

**പ്രസംഗം** — *prasaṁgaṁ* — "a speech".

> പ്രിൻസിപ്പലിന്റെ പ്രസംഗം വളരെ നീണ്ടതായിരുന്നു.
>
> *prinsippalinṟe prasaṁgaṁ vaḷare nīṇṭatāyirunnu.*
>
> The principal's speech was very long.

A speech is given: പ്രസംഗം നടത്തുക.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**പ്രസംഗം** (*prasaṁgaṁ*) is borrowed from Sanskrit *prasaṅga*, "adherence, attachment, connection" (Monier-Williams). Malayalam narrowed it to a talk given to an audience.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
