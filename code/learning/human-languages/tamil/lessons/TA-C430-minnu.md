# மின்னு (miṉṉu) — to glitter; to flash

## You'll want to know: மின்னு
<!-- hl-knowledge: introduces=[TA-LEX-C430-VANAM430-04]; assesses=[] -->

**மின்னு** — *miṉṉu* — "to glitter; to flash".

> இரவில் நட்சத்திரங்கள் மின்னின.
>
> *iravil naṭcattiraṅkaḷ miṉṉiṉa.*
>
> At night the stars glittered.

Past (it …): மின்னியது, *miṉṉiyatu*.

மின்னல், lightning, is built on it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**மின்னு** (*miṉṉu*) is native Dravidian (DEDR 4876), "to emit lightning, to shine, to glitter".
