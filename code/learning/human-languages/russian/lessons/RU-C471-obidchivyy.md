## You'll want to know: обидчивый
<!-- hl-knowledge: introduces=[RU-LEX-C471-HURT-04]; assesses=[] -->

**обидчивый** (*obídchivyy*) — "touchy".

> С обидчивым человеком трудно шутить.
>
> *S obídchivym chelovékom trúdno shutít.*
>
> It's hard to joke with a touchy person.

Easily offended. Short forms: обидчив, обидчива.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*обидчивый* is built on *обида* 'offence' with the ending *-чивый*, which marks a habit; *обида* is inherited from Proto-Slavic *obvida* (EtymDB).
