## You'll want to know: le randonneur
<!-- hl-knowledge: introduces=[FR-LEX-C455-RANDONNEE-02]; assesses=[] -->

**le randonneur** — "the hiker".

> Les randonneurs se reposent près du lac.
>
> *The hikers are resting by the lake.*

Feminine *la randonneuse*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*randonneur* is built on *randonner* 'to hike' with *-eur* (EtymDB).
