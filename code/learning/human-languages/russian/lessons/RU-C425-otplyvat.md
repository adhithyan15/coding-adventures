## You'll want to know: отплывать
<!-- hl-knowledge: introduces=[RU-LEX-C425-KACHKA-01]; assesses=[] -->

**отплывать** (*otplyvát*) — "to sail off, to set sail".

> Корабль отплывает ровно в полдень.
>
> *Korábl otplyváyet róvno v pólden.*
>
> The ship sets sail at exactly noon.

Imperfective; perfective *отплыть* (*отплыву, отплывёшь*).

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*отплывать* is built from *от-* 'away' and *-плывать*, from *плыть* 'to swim, to sail', which is inherited from Proto-Slavic *plyti* (EtymDB).
