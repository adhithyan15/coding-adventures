## You'll want to know: вероятно
<!-- hl-knowledge: introduces=[RU-LEX-C372-VEROYATNO-01]; assesses=[] -->

**вероятно** (*veroyátno*) — "probably, likely".

> Он, вероятно, опоздает.
>
> *On, veroyátno, opozdáyet.*
>
> He will probably be late.

More bookish than *наверное*; set off by commas inside the sentence.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**вероятно** is built on *вероятный* "likely", which is usually explained as *вера* "belief" with the old verb *ять* "to take": what may be taken on belief. *Вера* is inherited from Proto-Slavic *\*věra* (EtymDB).
