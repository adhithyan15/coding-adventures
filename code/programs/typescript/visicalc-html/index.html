VisiCalc · Mosaic HTML demo

A1
Live. Click a cell, then type a value or a formula (e.g. =SUM(A1:A4)) in the formula bar — or double-click a cell to edit it in place — and press Enter. Every dependent cell recomputes. The UI shell (FormulaBar + Grid) is generated by mosaic-compile --backend html from code/programs/mosaic/visicalc/*; the behaviour is the generic spreadsheet-core engine written in Rust and compiled to WebAssembly (vendor/spreadsheet-engine-wasm.js), which owns the cells, dependency graph, recalc, and formula evaluation. This file is thin glue — it holds no spreadsheet logic of its own — and the page still opens directly from disk via file:// (the .wasm is embedded as base64).
