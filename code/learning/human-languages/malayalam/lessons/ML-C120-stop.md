# നിർത്തൂ (nirttū) — please stop

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C120-HELP-03, ML-LEX-C120-HELP-04] -->

[PAUSE 2s] Before the new one: say the Malayalam for I didn't understand, then the Malayalam for please help.

## You'll want to know: നിർത്തൂ
<!-- hl-knowledge: introduces=[ML-LEX-C120-HELP-05]; assesses=[] -->

**നിർത്തൂ** (*nirttū*) — "please stop (it)", said to a driver or about a noise.
**ഇവിടെ നിർത്തൂ** — "please stop here", with **ഇവിടെ**, "here".
