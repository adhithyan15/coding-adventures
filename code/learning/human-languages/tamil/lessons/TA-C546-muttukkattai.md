# முட்டுக்கட்டை (muṭṭukkaṭṭai) — a stumbling block

## You'll want to know: முட்டுக்கட்டை
<!-- hl-knowledge: introduces=[TA-LEX-C546-THADANGAL546-04]; assesses=[] -->

**முட்டுக்கட்டை** — *muṭṭukkaṭṭai* — "a stumbling block".

> பணப் பற்றாக்குறை திட்டத்துக்கு முட்டுக்கட்டையாக இருக்கிறது.
>
> *paṇap paṟṟākkuṟai tiṭṭattukku muṭṭukkaṭṭaiyāka irukkiṟatu.*
>
> The shortage of money is a stumbling block for the plan.

Word for word "a prop-log", a block put under a wheel to stop it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**முட்டுக்கட்டை** (*muṭṭukkaṭṭai*) is a native compound: முட்டு (*muṭṭu*), "a hindrance, an obstacle" (DEDR 4933), and கட்டை (*kaṭṭai*), "a log, a block".
