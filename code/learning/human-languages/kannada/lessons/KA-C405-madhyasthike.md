# ಮಧ್ಯಸ್ಥಿಕೆ (madhyasthike) — mediation

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C405-SANDHANA405-01, KA-LEX-C405-SANDHANA405-02] -->

[PAUSE 2s] Before the new one: say the Kannada for an alliance, then the Kannada for a negotiation.

## You'll want to know: ಮಧ್ಯಸ್ಥಿಕೆ
<!-- hl-knowledge: introduces=[KA-LEX-C405-SANDHANA405-03]; assesses=[] -->

**ಮಧ್ಯಸ್ಥಿಕೆ** — *madhyasthike* — "mediation".

> ಊರಿನ ಹಿರಿಯರ ಮಧ್ಯಸ್ಥಿಕೆಯಿಂದ ಜಗಳ ಮುಗಿಯಿತು.
>
> *ūrina hiriyara madhyasthikeyinda jagaḷa mugiyitu.*
>
> The quarrel ended through the village elders' mediation.

ಮಧ್ಯಸ್ಥ, a mediator.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಮಧ್ಯಸ್ಥಿಕೆ** (*madhyasthike*) is built on Sanskrit *madhyastha*, "being in the middle" (Monier-Williams), with the Kannada noun ending -*ike*.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
