# ઉછીનું (uchīnũ) — borrowed for a while

## You'll want to know: ઉછીનું
<!-- hl-knowledge: introduces=[GU-LEX-C428-DEBT428-03]; assesses=[] -->

**ઉછીનું** — *uchīnũ* — "borrowed for a while".

> મેં મિત્ર પાસેથી સો રૂપિયા ઉછીના લીધા.
>
> *mẽ mitra pāsethī so rūpiyā uchīnā līdhā.*
>
> I borrowed a hundred rupees from a friend.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ઉછીનું** (*uchīnũ*) goes back to *\*ut-śrita-*, "raised", a form CDIAL reconstructs beside Sanskrit *ucchrita*; CDIAL lists the Gujarati word, "borrowed" (CDIAL 1862).
