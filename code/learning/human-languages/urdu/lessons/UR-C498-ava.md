## You'll want to know: آوا
<!-- hl-knowledge: introduces=[UR-LEX-C498-AVA498-03]; assesses=[] -->

**آوا** — *āvā* — "a potter's kiln".

> کمہار نے برتن آوے میں رکھے۔
>
> *kumhār ne bartan āve meṅ rakhe.*
>
> The potter put the pots in the kiln.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**آوا** (*āvā*) is inherited from Sanskrit *āpāka*, "a baking oven, a potter's kiln" (CDIAL 1202).
