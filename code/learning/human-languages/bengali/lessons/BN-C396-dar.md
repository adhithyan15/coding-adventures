# দাঁড় (dā̃ṛ) — an oar

## You'll want to know: দাঁড়
<!-- hl-knowledge: introduces=[BN-LEX-C396-MAJHI396-02]; assesses=[] -->

**দাঁড়** — *dā̃ṛ* — "an oar".

> মাঝি দুই হাতে দাঁড় টানল।
>
> *mājhi dui hāte dā̃ṛ ṭānlô.*
>
> The boatman pulled at the oar with both hands.

Not দাঁড়ানো, to stand: the same letters, a different word.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**দাঁড়** (*dā̃ṛ*) is inherited: CDIAL lists Bengali *dā̃ṛ*, "an oar", under Sanskrit *daṇḍá*, "a stick, a staff" (CDIAL 6128): an oar is a stick with a blade.
