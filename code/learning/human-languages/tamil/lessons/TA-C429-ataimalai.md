# அடைமழை (aṭaimaḻai) — a downpour; continuous rain

## You'll want to know: அடைமழை
<!-- hl-knowledge: introduces=[TA-LEX-C429-PUYAL429-04]; assesses=[] -->

**அடைமழை** — *aṭaimaḻai* — "a downpour; continuous rain".

> மூன்று நாட்களாக அடைமழை பெய்கிறது.
>
> *mūṉṟu nāṭkaḷāka aṭaimaḻai peykiṟatu.*
>
> It has been pouring for three days.

அடைமழை is heavy rain that does not stop.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**அடைமழை** (*aṭaimaḻai*) is built from அடை and மழை, "rain" (DEDR 4753); how the first part should be read is not settled.
