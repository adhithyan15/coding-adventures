## You'll want to know: جزئیات
<!-- hl-knowledge: introduces=[FA-LEX-C311-MANBA-04]; assesses=[] -->

**جزئیات** (*joz'iyât*) — "details, the details".

> پلیس جزئیات بیشتری نگفت.
>
> *Polis joz'iyât-e bishtari nagoft.*
>
> The police gave no further details.

An Arabic plural built on *joz'i* "partial, minor" (from *joz'* "a part"), written with the hamza seat ئ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*joz'iyât* is borrowed from Arabic *juz'iyyāt*, "details" (EtymDB), a plural built on *juz'* "a part".
