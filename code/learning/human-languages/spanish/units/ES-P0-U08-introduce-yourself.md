## New Material

Two small connector words to stitch the week together:

**de** — of/from
> ← Latin *de* ("from, down from"). Same root as English *de-* prefixes
> (*depart*, *descend*) and, distantly, French *de*.

**hoy** — today
> ← Latin *hodie* (a fusion of *hoc* ["this"] + *die* ["day"] — literally
> "this day," the same *dies* root you met in Unit 1's *buenos días*).

Now the full script — every piece is from a unit you've already done this
week:

> "**Hola, buenos días.**" *(Unit 1)*
> "**Me llamo [your name].**" *(Unit 1)*
> "**Yo soy de [your city/country].**" *(Units 2 + 3 + "de")*
> "**Hoy es [day of the week].**" *(Unit 7 + "hoy")*
> "**¿Cómo estás?**" *(Unit 1, built on Unit 5's *estar*)*
