# Punjabi pre-A1 mock 1 — learner paper

This is a project-defined practice mock. It does not establish readiness,
attainment, accreditation, or equivalence to an external examination.

Give this paper to the learner. Keep the examiner script, answer key, and
rubric separate. Total administration is 32 written minutes plus 8 speaking
minutes. Written Punjabi answers must use Gurmukhi. No dictionary, translator,
romanization, transcript, or answer model is allowed unless a task explicitly
provides a nonverbal cue.

For secure administration, print the four skill sections as separate packets
and give the learner only the current packet. Collect the Reading packet before
giving Listening; collect Listening before Writing; collect Writing before
Speaking. Never return an earlier packet during the sitting.

## Reading — 10 minutes

Choose A, B, or C.

2. **ਨਹੀਂ** — A name / B no / C bread
3. **ਨਾਂ** — A name / B water / C friend
4. **ਪਾਣੀ** — A bread / B water / C tea
5. **ਰੋਟੀ** — A friend / B milk / C bread
6. **ਦੋਸਤ** — A friend / B sister / C brother
<!-- /mock-part:prea1-reading-signs-and-words -->

<!-- mock-part:prea1-reading-phrases-and-notices -->
### Part 2 — phrases and notices

7. **ਸਤਿ ਸ੍ਰੀ ਅਕਾਲ।** — A a greeting / B a request for water / C a name
8. **ਧੰਨਵਾਦ।** — A sorry / B thank you / C no
9. **ਮਾਫ਼ ਕਰੋ।** — A excuse me / B welcome / C I am fine
10. **ਫਿਰ ਮਿਲਾਂਗੇ।** — A what is your name? / B we will meet again / C I speak Punjabi
<!-- /mock-part:prea1-reading-phrases-and-notices -->

<!-- mock-part:prea1-reading-personal-details -->
### Part 3 — personal details

11. **ਮੇਰਾ ਨਾਂ ਮੀਰਾ ਹੈ।** — A The name is Mira. / B Mira wants water. / C Mira is a friend.
12. **ਮੈਂ ਠੀਕ ਹਾਂ।** — A I am fine. / B I am Mira. / C I am at home.
13. **ਮੈਂ ਪੰਜਾਬੀ ਬੋਲਦੀ ਹਾਂ।** — A I read Punjabi. / B I speak Punjabi. / C I like bread.
14. Form field **ਨਾਂ: ਅਮਨ** — A name Aman / B city Aman / C language Aman

### Part 3 — bounded independent writing

## Speaking — 8 minutes

The interlocutor gives six prompts. Answer each in Punjabi. The interlocutor
may repeat each prompt once slowly. No written answer script, romanization,
dictionary, translator, or coaching is allowed.

<!-- mock-part:prea1-speaking-greeting-and-identity -->
### Part 1 — greeting and identity

Respond to one greeting, then give your name when asked.
<!-- /mock-part:prea1-speaking-greeting-and-identity -->

<!-- mock-part:prea1-speaking-familiar-questions -->
### Part 2 — familiar questions

Give three short personal responses: how you are, a language you speak, and a
place where you live.
<!-- /mock-part:prea1-speaking-familiar-questions -->

<!-- mock-part:prea1-speaking-short-request -->
### Part 3 — short request

Use the picture cue to make one short polite request.
<!-- /mock-part:prea1-speaking-short-request -->
