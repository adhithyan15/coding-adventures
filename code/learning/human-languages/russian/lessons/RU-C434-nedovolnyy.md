## You'll want to know: недовольный
<!-- hl-knowledge: introduces=[RU-LEX-C434-ZHALOBA-04]; assesses=[] -->

**недовольный** (*nedovólnyy*) — "dissatisfied, displeased".

> Недовольный клиент долго спорил с кассиром.
>
> *Nedovólnyy kliyént dólgo spóril s kassírom.*
>
> The dissatisfied customer argued with the cashier for a long time.

Takes the instrumental: *недоволен номером* — unhappy with the room.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*недовольный* is built from *не-* 'not' and *довольный* 'content, satisfied' (EtymDB lists both); *довольный* goes with *довольно* 'enough'.
