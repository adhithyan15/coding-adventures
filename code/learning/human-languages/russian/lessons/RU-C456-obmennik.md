## You'll want to know: обменник
<!-- hl-knowledge: introduces=[RU-LEX-C456-OBMENNIK-01]; assesses=[] -->

**обменник** (*obménnik*) — "a bureau de change".

> В аэропорту есть обменник.
>
> *V aeroportú yest obménnik.*
>
> There is a bureau de change at the airport.

Colloquial; officially *пункт обмена*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*обменник* is built on *обмен* 'an exchange' with *-ник*, from *менять* 'to change', on *мена* 'an exchange', which is inherited from Proto-Slavic *měna* (EtymDB).
