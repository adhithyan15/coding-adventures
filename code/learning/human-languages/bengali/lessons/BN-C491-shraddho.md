# শ্রাদ্ধ (shrāddhô) — a memorial rite for the dead

## You'll want to know: শ্রাদ্ধ
<!-- hl-knowledge: introduces=[BN-LEX-C491-SHRADDHO491-03]; assesses=[] -->

**শ্রাদ্ধ** — *shrāddhô* — "a memorial rite for the dead".

> দাদুর শ্রাদ্ধে আত্মীয়রা গ্রামে এলেন।
>
> *dādur shrāddhe ātmīyôrā grāme elen.*
>
> The relatives came to the village for my grandfather's memorial rite.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**শ্রাদ্ধ** (*shrāddhô*) is a tatsama, Sanskrit *śrāddha*, from *śraddhā*, "faith": a ceremony offered in faith for dead relatives (Monier-Williams).
