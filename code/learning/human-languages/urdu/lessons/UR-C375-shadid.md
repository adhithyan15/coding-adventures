# شدید (shadīd) — severe; intense

## You'll want to know: شدید
<!-- hl-knowledge: introduces=[UR-LEX-C375-BAHUT375-05]; assesses=[] -->

**شدید** — *shadīd* — "severe; intense".

> اگر درد شدید ہے تو دوا لیجیے۔
>
> *agar dard shadīd hai to davā lījiye.*
>
> If the pain is severe, take some medicine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**شدید** (*shadīd*) is usually traced, through Persian, to Arabic *shadīd*, "strong, intense".

<!-- hl-knowledge: introduces=[]; assesses=[] -->
