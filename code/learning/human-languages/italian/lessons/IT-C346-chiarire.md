## You'll want to know: chiarire
<!-- hl-knowledge: introduces=[IT-LEX-C346-MALINTESO-03]; assesses=[] -->

**chiarire** — "to clarify, to clear up".

> Vorrei chiarire una cosa prima di cominciare.
>
> *I would like to clarify one thing before we start.*

Conjugated with *-isc-*: *chiarisco, chiarisci*. *Chiarirsi* — to sort things out with someone.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*chiarire* is built on *chiaro* "clear", which is inherited from Latin *clārus* "bright, loud, clear" (Lewis & Short): to make something clear.
