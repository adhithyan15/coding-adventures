# પહેલેથી (pahelethī) — beforehand, in advance

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[GU-LEX-C179-PLAN179-02, GU-LEX-C179-PLAN179-03] -->

[PAUSE 2s] Before the new one: say the Gujarati for to decide, then the Gujarati for programme.

## You'll want to know: પહેલેથી
<!-- hl-knowledge: introduces=[GU-LEX-C179-PLAN179-04]; assesses=[] -->

**પહેલેથી** — *pahelethī* — "beforehand, in advance".

> **હું પહેલેથી ટિકિટ લઈશ.** — *hũ pahelethī ṭikiṭ laīś* — "I will get the ticket in advance."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**પહેલેથી** (*pahelethī*) is built on the inherited *pahelũ*, "first", with *-thī*, "from", so it means from the first.
