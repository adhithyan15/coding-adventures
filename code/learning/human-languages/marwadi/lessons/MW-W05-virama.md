# ् — stop the built-in vowel

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MW-LEX-MHARO-01, MW-SCRIPT-MA-01, MW-SCRIPT-SA-01] -->

[PAUSE 5s] Write known **स** once, then read **म** as *ma*. Hear *mhāro* once.
Today one tiny mark lets
**म** close onto the next consonant without *a* between them.

## Script
<!-- hl-knowledge: introduces=[MW-SCRIPT-VIRAMA-01]; assesses=[MW-SCRIPT-MA-01] -->

> ्

This is the **virāma**. Under **म**, it removes the built-in *a*: **म्** is *m*,
not *ma*. Keep the model visible; no joined form is required yet.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-VIRAMA-01] -->
<!-- hl-writing-stage: observe-trace -->

Finger-trace **्** once beneath a printed **म**, then trace one pencil model.
Say "vowel off" as your hand stops.
