# കുരുങ്ങുക (kuruṅṅuka) — to get tangled; to get caught

[PAUSE 2s] Before the new one: say the Malayalam for compensation, then the Malayalam for a hardship.

## You'll want to know: കുരുങ്ങുക
<!-- hl-knowledge: introduces=[ML-LEX-C515-KETU515-04]; assesses=[] -->

**കുരുങ്ങുക** — *kuruṅṅuka* — "to get tangled; to get caught".

> പട്ടത്തിന്റെ നൂല് മരത്തിൽ കുരുങ്ങി.
>
> *paṭṭattinṟe nūlŭ marattil kuruṅṅi.*
>
> The kite string got tangled in the tree.

Past: കുരുങ്ങി, *kuruṅṅi*.

What it gets caught in takes -ഇൽ: വലയിൽ കുരുങ്ങി, caught in the net.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**കുരുങ്ങുക** (*kuruṅṅuka*) is a Malayalam verb related to കുരുക്ക്, a knot or noose; its origin is not settled.
