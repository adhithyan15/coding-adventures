## You'll want to know: 多谢
<!-- hl-knowledge: introduces=[ZH-LEX-C457-HELP457-03]; assesses=[] -->

**多谢** — *duōxiè* — "many thanks; thanks a lot".

> **多谢你我找到地图了** *duōxiè nǐ wǒ zhǎodào dìtú le* — Thanks so much: I've found my map.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**多谢** (*duōxiè*) is built from 多 'many' and 谢 'to thank', both inherited from Middle Chinese, *ta* and *zjaeH* (Guangyun, in Baxter's transcription), which glosses the second 'to decline'; the sense 'to thank' is not given there.
