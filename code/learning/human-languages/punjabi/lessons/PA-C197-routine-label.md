## Grammar Lens
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-DINCHARIYA-197, PA-DEM-EH-01, PA-LEX-HAI-02, PA-GRAMMAR-VERB-LAST-02] -->

> **ਇਹ ਦਿਨਚਰਿਆ ਹੈ** — *eh dinchariā hai* — this is a daily routine

Keep the new whole noun between familiar **ਇਹ** and **ਹੈ**. Familiar **ਹੈ**
stays last in the already-owned identity frame. This chapter teaches only this
one label; it does not add an inflection rule or a full routine narrative.
