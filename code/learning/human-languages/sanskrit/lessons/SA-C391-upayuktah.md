# उपयुक्तः (upayuktaḥ) — suitable; useful

## You'll want to know: उपयुक्तः
<!-- hl-knowledge: introduces=[SA-LEX-C391-PARAMA391-04]; assesses=[] -->

**उपयुक्तः** — *upayuktaḥ* — "suitable; useful".

> यदि वस्त्रम् उपयुक्तम्, तर्हि उत्सवे धारयतु।
>
> *yadi vastram upayuktam, tarhi utsave dhārayatu.*
>
> If the garment is suitable, wear it at the festival.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**उपयुक्तः** (*upayuktaḥ*) is built on *upa*, "towards", and the root √yuj, "to join"; MW gives *upa-yukta* "suitable, fit, appropriate, useful" (MW).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
