## You'll want to know: le gérant
<!-- hl-knowledge: introduces=[FR-LEX-C432-GERANT-01]; assesses=[] -->

**le gérant** — "the manager".

> Le gérant de l'hôtel est venu voir la chambre.
>
> *The hotel manager came to check the room.*

Feminine *la gérante*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*gérant* is built on *gérer* 'to manage', a learned borrowing from Latin *gerere* 'to carry on, to run' (Lewis & Short). EtymDB lists it without a source.
