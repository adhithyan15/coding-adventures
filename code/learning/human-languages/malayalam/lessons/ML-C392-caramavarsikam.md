# ചരമവാർഷികം (caramavārṣikaṁ) — a death anniversary

## You'll want to know: ചരമവാർഷികം
<!-- hl-knowledge: introduces=[ML-LEX-C392-ANUSOCHANAM392-03]; assesses=[] -->

**ചരമവാർഷികം** — *caramavārṣikaṁ* — "a death anniversary".

> ഇന്ന് മുത്തച്ഛന്റെ ചരമവാർഷികം ആണ്.
>
> *innŭ muttacchanṟe caramavārṣikaṁ āṇŭ.*
>
> Today is grandfather's death anniversary.

ചരമം, a death, + വാർഷികം, an anniversary.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ചരമവാർഷികം** (*caramavārṣikaṁ*) is built from ചരമം (*caramaṁ*), "a death", from Sanskrit *carama*, "last" (Monier-Williams), and വാർഷികം (*vārṣikaṁ*), "an anniversary", from *vārṣika*, "lasting a year, annual" (CDIAL 11571).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
