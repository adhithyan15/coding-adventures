# ટેમ્પો (ṭempo) — a tempo (a small goods van)

## You'll want to know: ટેમ્પો
<!-- hl-knowledge: introduces=[GU-LEX-C402-CART402-02]; assesses=[] -->

**ટેમ્પો** — *ṭempo* — "a tempo (a small goods van)".

> અમે ટેમ્પોમાં બધો સામાન ભર્યો.
>
> *ame ṭempomā̃ badho sāmān bharyo.*
>
> We loaded all the luggage into a tempo.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ટેમ્પો** (*ṭempo*) is borrowed from Indian English *tempo*, which comes from the name of a firm whose three-wheeled goods vans were common in India.
