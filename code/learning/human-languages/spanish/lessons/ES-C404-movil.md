# el móvil — the phone named for moving

## Sounds you'll need
<!-- hl-knowledge: introduces=[]; assesses=[] -->

- *MO-vil*: the written accent keeps the stress on **mó**.

## The word, taken apart
<!-- hl-knowledge: introduces=[ES-LEX-MOVIL]; assesses=[] -->

**el móvil** — “the mobile phone,” especially in Spain. Across much of Latin
America, **el celular** is more usual.

Latin **mōbilis** meant “movable.” Spanish **teléfono móvil** is literally a
mobile telephone; **el móvil** leaves the noun unstated because the movable
device is understood.
