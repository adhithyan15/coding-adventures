## You'll want to know: casado
<!-- hl-knowledge: introduces=[ES-LEX-C549-CASADO-01]; assesses=[] -->

**casado** — "married".

> Mi hermano está casado con una francesa.
>
> *My brother is married to a Frenchwoman.*

*Estar casado con* — to be married to.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*casado* is built on the participle of *casar* 'to marry', which comes from *casa* 'house', inherited from Latin *casa* 'a hut' (Lewis & Short). To marry was to set up house.
