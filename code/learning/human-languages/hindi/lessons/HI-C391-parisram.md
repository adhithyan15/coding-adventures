## You'll want to know: परिश्रम
<!-- hl-knowledge: introduces=[HI-LEX-C391-PRAYAS391-02]; assesses=[] -->

**परिश्रम** — *pariśram* — "hard work, toil (formal)".

> अगर तुम परिश्रम करोगे तो उसका फल ज़रूर मिलेगा।
>
> *agar tum pariśram karoge to uskā phal zarūr milegā.*
>
> If you work hard, you'll certainly reap the reward.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**परिश्रम** (*pariśram*) is a tatsama, borrowed from Sanskrit *pariśrama*, "fatigue, exertion, labour" (Monier-Williams).
