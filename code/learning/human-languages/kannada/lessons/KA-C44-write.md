<!-- hl-knowledge: introduces=[KA-LEX-WRITE]; assesses=[] -->

**ಬರೆ** (*bare*) — "write".

An old Dravidian stem, unrelated to the Sanskrit words for writing. It is the same root behind *baraha*, 'writing'.
