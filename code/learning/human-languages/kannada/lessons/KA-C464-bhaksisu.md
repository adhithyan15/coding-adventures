# ಭಕ್ಷೀಸು (bhakṣīsu) — a gratuity; a tip

## You'll want to know: ಭಕ್ಷೀಸು
<!-- hl-knowledge: introduces=[KA-LEX-C464-UPAHARA464-04]; assesses=[] -->

**ಭಕ್ಷೀಸು** — *bhakṣīsu* — "a gratuity; a tip".

> ನಾವು ಪರಿಚಾರಕನಿಗೆ ಹತ್ತು ರೂಪಾಯಿ ಭಕ್ಷೀಸು ಕೊಟ್ಟೆವು.
>
> *nāvu paricārakanige hattu rūpāyi bhakṣīsu koṭṭevu.*
>
> We gave the waiter a ten rupee tip.

ಭಕ್ಷೀಸು ಕೊಡು, to tip.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಭಕ್ಷೀಸು** (*bhakṣīsu*) is usually traced to Persian *bakhshish*, "a gift, a present", which reached Kannada through Hindustani.
