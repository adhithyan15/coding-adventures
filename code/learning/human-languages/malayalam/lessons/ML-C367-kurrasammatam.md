# കുറ്റസമ്മതം (kuṟṟasammataṁ) — a confession

## You'll want to know: കുറ്റസമ്മതം
<!-- hl-knowledge: introduces=[ML-LEX-C367-KURRAM367-02]; assesses=[] -->

**കുറ്റസമ്മതം** — *kuṟṟasammataṁ* — "a confession".

> ഒടുവിൽ കള്ളൻ കുറ്റസമ്മതം നടത്തി.
>
> *oṭuvil kaḷḷan kuṟṟasammataṁ naṭatti.*
>
> At last the thief made a confession.

കുറ്റം, an offence, + സമ്മതം, consent: agreeing that you did it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**കുറ്റസമ്മതം** (*kuṟṟasammataṁ*) joins കുറ്റം (*kuṟṟaṁ*), "an offence" (DEDR 1851), and സമ്മതം (*sammataṁ*), "consent", borrowed from Sanskrit *sammata*, "agreed" (CDIAL 12973).
