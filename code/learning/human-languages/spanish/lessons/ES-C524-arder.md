## You'll want to know: arder
<!-- hl-knowledge: introduces=[ES-LEX-C524-FUEGO-03]; assesses=[] -->

**arder** — "to burn, to be on fire".

> El edificio ardió toda la noche.
>
> *The building burned all night.*

*Arder* is to be burning; to burn something is *quemar*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*arder* is inherited from Latin *ārdēre* 'to be on fire, to blaze' (EtymDB). English *ardent* comes from the same verb.
