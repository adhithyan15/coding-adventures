## You'll want to know: مقصد
<!-- hl-knowledge: introduces=[UR-LEX-C333-MAQSAD333-01]; assesses=[] -->

**مقصد** — *maqsad* — "a purpose; an aim".

> اس میٹنگ کا مقصد کیا ہے؟
>
> *is mīṭing kā maqsad kyā hai?*
>
> What is the purpose of this meeting?

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**مقصد** (*maqsad*) is usually traced, through Persian, to Arabic *maqṣad*, "a place aimed at": in Urdu, the end a thing is done for.
