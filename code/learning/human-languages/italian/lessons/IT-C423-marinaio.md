## You'll want to know: il marinaio
<!-- hl-knowledge: introduces=[IT-LEX-C423-TRAGHETTO-03]; assesses=[] -->

**il marinaio** — "the sailor".

> Un marinaio ci aiuta con le valigie.
>
> *A sailor helps us with the suitcases.*

From *marina*, the sea and the navy.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*marinaio* is built on *marina*, from *mare* 'sea', which is inherited from Latin *mare* (EtymDB).
