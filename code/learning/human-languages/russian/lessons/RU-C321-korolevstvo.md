## You'll want to know: королевство
<!-- hl-knowledge: introduces=[RU-LEX-C321-KOROL-05]; assesses=[] -->

**королевство** (*korolévstvo*) — "a kingdom".

> В маленьком королевстве все знали друг друга.
>
> *V málenkom korolévstve vse ználi drug drúga.*
>
> In the little kingdom everyone knew each other.

Neuter.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*королевство* is built on *король* "king", inherited from Proto-Slavic *korľĭ* (EtymDB), with the ending *-ство*.
