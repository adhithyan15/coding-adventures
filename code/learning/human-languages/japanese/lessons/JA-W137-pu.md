# ぷ — ふ, with the circle

- [YOU RECALL: say *well*, as in healthy — **R3**, twenty lessons back]
- [YOU RECALL: say *noisy* — **R4**, eighty lessons back]

## Script — the change
<!-- hl-knowledge: introduces=[JA-SCRIPT-PU-01]; assesses=[JA-SCRIPT-FU-01, JA-SCRIPT-HANDAKUTEN-01] -->

> **ふ** *fu* + **゜** → **ぷ** *pu*

Write **ふ** in full, in the order you learned it. Then add the small circle
at the upper right, above the dot on the right. Keep it small and open.

The sign is read *pu*. The *f* of *fu* goes, and the lips close for a *p*.
With the voicing mark the same sign gives **ぶ**, *bu*.

With **きっ** in front of it, you can now write the word from the last lesson:
**きっぷ**, *kippu*, a ticket.

## Guided Practice

1. Write **ふ**, then **ぶ**, then **ぷ**, and say *fu*, *bu*, *pu*.
2. Write **ぱ**, **ぴ**, **ぷ** and **ぽ**, and say each one.
3. Write **きっぷ** from memory and say *kippu*.
