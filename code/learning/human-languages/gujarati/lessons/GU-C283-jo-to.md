# જો …, તો … (jo …, to …) — if, then

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[GU-JOIN-JO-01, GU-JOIN-JO-TO-01, GU-GRAMMAR-C278-VU-JOIE-01, GU-LEX-C48-BODY3-04] -->

[PAUSE 2s] Say "if", then "if … then", from A2. (**જો**, **જો … તો …**.) Then "you should rest". (*tamāre ārām karvo joīe*.)

## Grammar Lens: two halves
<!-- hl-knowledge: introduces=[GU-GRAMMAR-C283-JO-TO-01]; assesses=[GU-LEX-C49-CARE-03, GU-LEX-C224-DOCTOR224-01, GU-LEX-C102-CAN102-02] -->

> **જો તમને તાવ છે, તો તમારે આરામ કરવો જોઈએ.**
>
> *jo tamne tāv che, to tamāre ārām karvo joīe.* — "If you have a fever, then you should rest."

**જો** (*jo*) opens the condition, and **તો** (*to*), "then", opens what follows from it. Each half is a whole sentence with its own verb. In quick speech **તો** can drop, but written down it marks where the second half begins.

## You'll want to know: if it is so now
<!-- hl-knowledge: introduces=[GU-GRAMMAR-C283-JO-PRESENT-01]; assesses=[GU-LEX-C49-CARE-04, GU-LEX-KHAAVU, GU-LEX-C213-WEATHER213-03] -->

> **જો તમને ભૂખ છે, તો ખાઈ લો.**
>
> *jo tamne bhūkh che, to khāī lo.* — "If you're hungry, then go ahead and eat."

When the condition is about now, it takes the present: **જો તમને ભૂખ છે**, **જો તે ઘરે છે**. The second half can be advice, a request with **-ઓ**, or a plain statement: **જો ઠંડી છે, તો હું ઘરે રહીશ** (*jo ṭhanḍī che, to hũ ghare rahīś*).
