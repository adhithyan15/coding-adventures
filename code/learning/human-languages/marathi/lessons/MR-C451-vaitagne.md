# वैतागणे (vaitāgṇe) — to get fed up; to be exasperated

## You'll want to know: वैतागणे
<!-- hl-knowledge: introduces=[MR-LEX-C451-MOOD451-05]; assesses=[] -->

**वैतागणे** — *vaitāgṇe* — "to get fed up; to be exasperated".

> दिवसभर पाऊस पडत होता, म्हणून मुलं वैतागली.
>
> *divasbhar pāūs paḍat hotā, mhaṇūn mulaṁ vaitāglī.*
>
> It rained all day, so the children got fed up.

Past (he …): तो वैतागला, *to vaitāglā*.

What one is fed up with takes -ला: कामाला वैतागणे. The noun वैताग, exasperation.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**वैतागणे** (*vaitāgṇe*) is a Marathi verb built on वैताग, "exasperation"; the origin of वैताग is not settled.
