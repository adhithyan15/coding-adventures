## You'll want to know: रूढी
<!-- hl-knowledge: introduces=[MR-LEX-C367-PRATHA367-02]; assesses=[] -->

**रूढी** — *rūḍhī* — "a convention; a tradition".

> काही जुन्या रूढी आता बदलत आहेत.
>
> *kāhī junyā rūḍhī ātā badlat āhet.*
>
> Some old conventions are now changing.

Feminine.

Plural रूढी; रूढ, current, established.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**रूढी** (*rūḍhī*) is a tatsama, taken from Sanskrit *rūḍhi*, "rise, increase" (CDIAL 10802); the same entry lists an inherited Marathi *rūḍh*, "prevalence".
