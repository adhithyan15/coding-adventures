# ऊंचो (ū̃cho) — high; tall

## You'll want to know: ऊंचो
<!-- hl-knowledge: introduces=[MW-LEX-C226-DUNE226-02]; assesses=[] -->

**ऊंचो** — *ū̃cho* — "high; tall".

> टीबो घणो ऊंचो है।
>
> *ṭībo ghaṇo ū̃cho hai.*
>
> The sand hill is very high.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ऊंचो** (*ū̃cho*) is inherited from Sanskrit *ucca*, "tall, lofty"; CDIAL lists Old Marwari *uco*, "high" (CDIAL 1634). **नीचो**, low, is its opposite.
