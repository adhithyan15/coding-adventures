# സഹിഷ്ണുത (sahiṣṇuta) — tolerance

## You'll want to know: സഹിഷ്ണുത
<!-- hl-knowledge: introduces=[ML-LEX-C529-VIVEKAM529-05]; assesses=[] -->

**സഹിഷ്ണുത** — *sahiṣṇuta* — "tolerance".

> മറ്റുള്ളവരുടെ അഭിപ്രായത്തോട് സഹിഷ്ണുത വേണം.
>
> *maṟṟuḷḷavaruṭe abhiprāyattōṭŭ sahiṣṇuta vēṇaṁ.*
>
> One needs tolerance towards other people's opinions.

From സഹിഷ്ണു, able to bear, the same root as സഹിക്കുക.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**സഹിഷ്ണുത** (*sahiṣṇuta*) is borrowed from Sanskrit *sahiṣṇutā*, the noun of *sahiṣṇu*, "patient, enduring" (Monier-Williams), from the root *sah*, "to bear".
