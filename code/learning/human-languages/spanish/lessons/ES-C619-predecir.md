## You'll want to know: predecir
<!-- hl-knowledge: introduces=[ES-LEX-C619-QUIZA-05]; assesses=[] -->

**predecir** — "to predict".

> Nadie puede predecir el futuro.
>
> *Nobody can predict the future.*

Like *decir*: *predigo, predije*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*predecir* is a learned borrowing from Latin *praedicere* 'to say beforehand', built from *prae* and *dicere* 'to say', rebuilt on *decir* (EtymDB).
