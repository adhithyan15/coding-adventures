## You'll want to know: मनोरथः
<!-- hl-knowledge: introduces=[SA-LEX-C531-VANCHATI531-02]; assesses=[] -->

**मनोरथः** — *manorathaḥ* — "a heart's wish".

> यदि मनोरथः दृढः अस्ति, तर्हि मार्गः अपि भवति।
>
> *yadi manorathaḥ dṛḍhaḥ asti, tarhi mārgaḥ api bhavati.*
>
> If your wish is strong, a way appears too.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**मनोरथः** (*manorathaḥ*) is built from *manas*, "the mind, the heart", and *ratha*, which MW here takes as "joy": a heart's joy, a wish, a desire (MW).
