## You'll want to know: wánchéng
<!-- hl-knowledge: introduces=[ZH-LEX-C395-RESULT395-04]; assesses=[] -->

*wánchéng* — "to complete; to get (a job) done".

> *rúguǒ jīntiān néng wánchéng míngtiān jiù kěyǐ xiūxi* — If we can finish today, we can rest tomorrow.

Its characters come later; for now it is a word for the ear.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*wánchéng* is built from *wán* 'whole' and 成 'to complete', both inherited from Middle Chinese, *hwan* and *dzyeng* (Guangyun, in Baxter's transcription), which glosses the first 'complete'.

## What you've built
