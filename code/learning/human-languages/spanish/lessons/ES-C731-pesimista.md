**pesimista** — "pessimistic; the pessimist".

> No seas tan pesimista.
>
> *Do not be so pessimistic.*

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*pesimista* is usually traced to French *pessimiste*, built on Latin *pessimus* "worst".
