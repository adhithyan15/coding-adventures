## You'll want to know: सुहृद्
<!-- hl-knowledge: introduces=[SA-LEX-C453-VIRAHA453-04]; assesses=[] -->

**सुहृद्** — *suhṛd* — "a dear friend; a well-wisher".

> सुहृद् दुःखे अपि मित्रं न त्यजति।
>
> *suhṛd duḥkhe api mitraṃ na tyajati.*
>
> A true friend does not abandon you even in trouble.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**सुहृद्** (*suhṛd*) is built from *su*, "good", and *hṛd*, "heart": MW gives "good-hearted, well-disposed; a friend, ally" (MW).
