## You'll want to know: o aquecedor
<!-- hl-knowledge: introduces=[PT-LEX-C431-AQUECIMENTO-02]; assesses=[] -->

**o aquecedor** — "the heater".

> Pedimos um aquecedor porque o quarto estava frio.
>
> *We asked for a heater because the room was cold.*

*Um aquecedor elétrico* — an electric heater.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*aquecedor* is built on *aquecer* 'to warm', which goes back to Latin *calēscere* 'to grow warm', on *calēre* 'to be warm' (Lewis & Short).
