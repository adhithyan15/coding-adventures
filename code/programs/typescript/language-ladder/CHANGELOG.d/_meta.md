# Changelog

This directory is the committed changelog. Each numbered Markdown file is one
level-2 entry, ordered newest-first by descending rank. Add a unique fragment;
do not edit or commit `CHANGELOG.md`. To render a temporary single-file view,
build `@coding-adventures/human-language-data` and run its `unshard:docs` script
with `code/programs/typescript/language-ladder/CHANGELOG.md` as the argument.
