# ಶರಣಾಗು (śaraṇāgu) — to surrender

## You'll want to know: ಶರಣಾಗು
<!-- hl-knowledge: introduces=[KA-LEX-C342-MUTTIGE342-04]; assesses=[] -->

**ಶರಣಾಗು** — *śaraṇāgu* — "to surrender".

> ಊಟ ಇಲ್ಲದೆ ಕೋಟೆಯ ಸೈನಿಕರು ಶರಣಾದರು.
>
> *ūṭa illade kōṭeya sainikaru śaraṇādaru.*
>
> With no food, the soldiers in the fort surrendered.

Past (I …): ಶರಣಾದೆ, *śaraṇāde*.

The one surrendered to takes -ಗೆ: ಪೊಲೀಸರಿಗೆ ಶರಣಾಗು.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಶರಣಾಗು** (*śaraṇāgu*) is built from Sanskrit *śaraṇa*, "protecting, shelter" (CDIAL 12326), and native *āgu*, "to become" (DEDR 333): to seek shelter with the stronger side.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
