## Grammar Lens: the wardrobe, complete
<!-- hl-knowledge: introduces=[]; assesses=[ES-LEX-C430-VIDA-02, ES-LEX-C430-VIDA-03, ES-LEX-C430-VIDA-04, ES-LEX-C360-REF-19, ES-LEX-CAMISA, ES-LEX-C360-REF-18, ES-LEX-C373-REF-54] -->

| garment | already yours |
|---|---|
| el pantalón | yes |
| la falda | yes |
| la camisa | yes |
| el zapato | yes |
| los vaqueros | new |
| el jersey | new |
| el bolso | new |

Four were taught across earlier chapters and three arrived here. The list an
exam works from is now covered end to end, which is what the three were for.

## Grammar Lens: each one's own trap
<!-- hl-knowledge: introduces=[]; assesses=[ES-LEX-C430-VIDA-01, ES-LEX-C430-VIDA-02, ES-LEX-C430-VIDA-03, ES-LEX-C430-VIDA-04] -->

| word | what to watch |
|---|---|
| estar en paro | takes *estar*, and *paro* means the halt |
| los vaqueros | plural every time |
| el jersey | plural *jerséis*, with a written accent |
| el bolso | *la bolsa* is a different object |

## Grammar Lens: where each word came from
<!-- hl-knowledge: introduces=[]; assesses=[ES-LEX-C430-VIDA-01, ES-LEX-C430-VIDA-02, ES-LEX-C430-VIDA-03, ES-LEX-C430-VIDA-04] -->

| word | named after |
|---|---|
| el paro | the stopping |
| los vaqueros | the cowherd |
| el jersey | an island |
| el bolso | a leather hide |

Three of the four are named after something other than themselves — a person, a
place, a material. That is a habit worth noticing, because it is how a reader
guesses at a word they have not met.
