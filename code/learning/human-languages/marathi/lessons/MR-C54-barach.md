# बराच (barāch) — quite a lot

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MR-LEX-THODA, MR-LEX-PURESA] -->

[PAUSE 2s] A little, enough, a lot. There is a step between *enough* and *a
lot* that Marathi bothers to name.

## You'll want to know: बराच
<!-- hl-knowledge: introduces=[MR-LEX-BARACH]; assesses=[MR-LEX-BARAM-01, MR-GRAMMAR-ADJ-PRENOMINAL, MR-LEX-PAANI] -->

> **बराच** — *barāch* — **quite a lot, a fair amount, rather**

> **बरंच पाणी**
> — *baraṁch pāṇī* — **quite a lot of water**

You already own both halves of this word. **बरा** is the *fine, all right* of
chapter four — the **बरं** you answer *how are you* with — and **-च** is
Marathi's little emphatic tail, the one that means *precisely that*. Glue them
together and *a fair amount* is literally *a good-ish bit*.

It agrees, because the **बरा** underneath it ends in **-आ**: **बराच चहा**,
**बरंच पाणी**.

Set the four amounts in order and the scale is complete:

> **थोडं** a little · **पुरेसं** enough · **बरंच** quite a lot · **खूप** a lot.
