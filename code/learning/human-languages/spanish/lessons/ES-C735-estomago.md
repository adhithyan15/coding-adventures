## You'll want to know: el estómago
<!-- hl-knowledge: introduces=[ES-LEX-C735-HUESO-03]; assesses=[] -->

**el estómago** — "the stomach".

> Me duele el estómago.
>
> *My stomach hurts.*

*Dolor de estómago* — stomach ache.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*estómago* is a learned borrowing from Latin *stomachus*, which came from Greek *stómakhos*, built on *stóma* "mouth" (EtymDB).
