# കരിയുക (kariyuka) — to get scorched; to wither

## You'll want to know: കരിയുക
<!-- hl-knowledge: introduces=[ML-LEX-C514-VARALCA514-03]; assesses=[] -->

**കരിയുക** — *kariyuka* — "to get scorched; to wither".

> കടുത്ത വെയിലിൽ ചെടികൾ കരിഞ്ഞു.
>
> *kaṭutta veyilil ceṭikaḷ kariññu.*
>
> In the fierce sun the plants were scorched.

Past: കരിഞ്ഞു, *kariññu*.

For plants and food: ചോറ് കരിഞ്ഞു, the rice got burnt.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**കരിയുക** (*kariyuka*) is native Dravidian, "to be scorched, to be singed", from the same root as കരി, charcoal (DEDR 1278).
