# മേൽപ്പാലം (mēlppālaṁ) — a flyover; an overbridge

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C468-PATA468-02, ML-LEX-C468-PATA468-03] -->

[PAUSE 2s] Before the new one: say the Malayalam for a toll, then the Malayalam for a tunnel.

## You'll want to know: മേൽപ്പാലം
<!-- hl-knowledge: introduces=[ML-LEX-C468-PATA468-04]; assesses=[] -->

**മേൽപ്പാലം** — *mēlppālaṁ* — "a flyover; an overbridge".

> നഗരത്തിൽ ഒരു പുതിയ മേൽപ്പാലം പണിയുന്നു.
>
> *nagarattil oru putiya mēlppālaṁ paṇiyunnu.*
>
> A new flyover is being built in the city.

Built from മേൽ, above, and പാലം, a bridge: a bridge that goes over the road.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**മേൽപ്പാലം** (*mēlppālaṁ*) is a native Dravidian compound of മേൽ, above (DEDR 5086), and പാലം, a bridge (DEDR 4099).
