## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[RU-SCRIPT-C81-YO-01] -->

## Guided Practice

|---|---|---|
| ё | *yo* | **ребёнок** *rebyónok* |

[PAUSE 2s each]

- [YOU READ: each word in the table aloud, and point at its letter]
