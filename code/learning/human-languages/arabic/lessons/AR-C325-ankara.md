## You'll want to know: أنكر
<!-- hl-knowledge: introduces=[AR-LEX-C325-SHAHID325-05]; assesses=[] -->

**أنكر** — *ankara* — "to deny".

> أنكر المتهم كل شيء.
>
> *ankara al-muttaham kull shayʾ.*
>
> The defendant denied everything.

Present: ينكر, *yunkir*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**أنكر** (*ankara*) is built on the native Arabic root *n-k-r* (Lane), "not to know a thing"; *nakira* is "to find strange". It is Form IV, "to disown".
