## You'll want to know: বিঘ্ন
<!-- hl-knowledge: introduces=[BN-LEX-C539-BIGHNO539-01]; assesses=[] -->

**বিঘ্ন** — *bighnô* — "an obstacle; a hindrance".

> বৃষ্টি হলে আমাদের যাত্রায় বিঘ্ন ঘটবে।
>
> *Brishṭi hôle āmāder jātrāy bighnô ghôṭbe.*
>
> If it rains, our journey will be held up.

With ঘটা: বিঘ্ন ঘটা, to be disrupted; বিঘ্ন ঘটানো, to disrupt.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**বিঘ্ন** (*bighnô*) is a tatsama, Sanskrit *vighna*, "a breaker", and so "an obstacle" (Monier-Williams).
