## You'll want to know: نظریه
<!-- hl-knowledge: introduces=[FA-LEX-C360-AQIDE-05]; assesses=[] -->

**نظریه** (*nazariye*) — "a theory".

> این نظریه خیلی قدیمی است.
>
> *in nazariye kheyli qadimi ast.*
>
> This theory is very old.

Built on *nazar* "view" with the suffix *-iye*. Plural *nazariyehâ*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**نظریه** comes from Arabic *naẓariyya* "theory" (EtymDB), built on *naẓar* "a look, a view", the same word that gave Persian *nazar*. A theory is a way of viewing the facts.
