## You'll want to know: ausparken
<!-- hl-knowledge: introduces=[GE-LEX-C406-PARKEN-02]; assesses=[] -->

**ausparken** — "to pull out (of a parking space)".

> Beim Ausparken fährt er fast gegen eine Mauer.
>
> *When pulling out he almost drives into a wall.*

Separable: *ich parke aus*, *ich habe ausgeparkt*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*ausparken* is built from *aus* 'out' and *parken* 'to park', which is usually traced to English *to park*; EtymDB does not list the German verb.
