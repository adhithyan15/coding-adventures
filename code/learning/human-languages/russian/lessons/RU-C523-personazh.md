## You'll want to know: персонаж
<!-- hl-knowledge: introduces=[RU-LEX-C523-PLOT-02]; assesses=[] -->

**персонаж** (*personázh*) — "a character (in a story)".

> Мой любимый персонаж — старый капитан.
>
> *Moy lyubímyy personázh — stáryy kapitán.*
>
> My favourite character is the old captain.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*персонаж* is usually traced to French *personnage*, built on *personne*, from Latin *persōna* 'a mask, a part in a play'; EtymDB has no entry.
