# வாசகர் (vācakar) — a reader

## You'll want to know: வாசகர்
<!-- hl-knowledge: introduces=[TA-LEX-C309-VASAKAR309-01]; assesses=[] -->

**வாசகர்** — *vācakar* — "a reader".

> பல வாசகர்கள் ஆசிரியருக்குக் கடிதம் எழுதினார்கள்.
>
> *pala vācakarkaḷ āciriyarukkuk kaṭitam eḻutiṉārkaḷ.*
>
> Many readers wrote letters to the editor.

Plural வாசகர்கள்.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**வாசகர்** (*vācakar*) is built on Sanskrit *vācaka*, "speaking, telling" (Monier-Williams), with the Tamil -அர் of persons.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
