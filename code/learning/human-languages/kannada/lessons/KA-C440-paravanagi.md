# ಪರವಾನಗಿ (paravānagi) — a permit; a licence

## You'll want to know: ಪರವಾನಗಿ
<!-- hl-knowledge: introduces=[KA-LEX-C440-PARAVANAGI440-01]; assesses=[] -->

**ಪರವಾನಗಿ** — *paravānagi* — "a permit; a licence".

> ಕಾರು ಓಡಿಸಲು ಪರವಾನಗಿ ಬೇಕು.
>
> *kāru ōḍisalu paravānagi bēku.*
>
> You need a licence to drive a car.

ಚಾಲನಾ ಪರವಾನಗಿ is a driving licence; in speech many say ಲೈಸೆನ್ಸ್.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಪರವಾನಗಿ** (*paravānagi*) is usually traced to Persian *parvānagī*, "permission", built on *parvāna*, "a written order, a pass", which reached Kannada through Hindustani.
