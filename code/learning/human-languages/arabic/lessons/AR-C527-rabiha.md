## You'll want to know: ربح
<!-- hl-knowledge: introduces=[AR-LEX-C527-MAL527-03]; assesses=[] -->

**ربح** — *rabiḥa* — "to make a profit".

> ربح التاجر كثيرا هذه السنة.
>
> *rabiḥa at-tājir kathīran hādhihi as-sana.*
>
> The merchant made a big profit this year.

Present: يربح, *yarbaḥ*.

In a game it also means to win.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ربح** (*rabiḥa*) is built on the native Arabic root *r-b-ḥ*, "to gain in trade" (Lane). The noun ribḥ is a profit.
