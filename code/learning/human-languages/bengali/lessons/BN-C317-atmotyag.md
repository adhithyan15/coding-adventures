# আত্মত্যাগ (ātmôtyāg) — self-sacrifice

## You'll want to know: আত্মত্যাগ
<!-- hl-knowledge: introduces=[BN-LEX-C317-BIR317-02]; assesses=[] -->

**আত্মত্যাগ** — *ātmôtyāg* — "self-sacrifice".

> দেশের জন্য সৈন্যদের আত্মত্যাগ আমরা মনে রাখব।
>
> *desher jônyô soinyôder ātmôtyāg āmrā mône rākhbô.*
>
> We will remember the soldiers' sacrifice for their country.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**আত্মত্যাগ** (*ātmôtyāg*) joins Sanskrit *ātman*, 'self', to *tyāga*, 'giving up, abandoning' (Monier-Williams): giving up oneself.
