## You'll want to know: پرواز کردن
<!-- hl-knowledge: introduces=[FA-LEX-C431-PARVAZ-02]; assesses=[] -->

**پرواز کردن** (*parvâz kardan*) — "to fly".

> هواپیما بالای ابرها پرواز میکند.
>
> *Havâpeymâ bâlâ-ye abr-hâ parvâz mikonad.*
>
> The plane flies above the clouds.

*parvâz* + *kardan*. Birds and planes both *parvâz mikonand*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*parvâz kardan* is built from native *parvâz* 'flight', which EtymDB lists, and *kardan* 'to do', inherited from Middle Persian *kardan* (EtymDB).
