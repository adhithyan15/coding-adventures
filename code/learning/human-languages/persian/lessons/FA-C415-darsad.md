## You'll want to know: درصد
<!-- hl-knowledge: introduces=[FA-LEX-C415-MAKHAREJ-04]; assesses=[] -->

**درصد** (*darsad*) — "a percent, a percentage".

> پنجاه درصد مردم رای دادند.
>
> *panjâh darsad-e mardom ra'y dâdand.*
>
> Fifty percent of the people voted.

*Dar* "in" + *sad* "hundred": per hundred.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**درصد** is a native Persian compound, literally "in a hundred": *dar* "in" + *sad* "hundred", which EtymDB lists without a parent and which is usually traced to PIE *\*kmtom* "hundred".
