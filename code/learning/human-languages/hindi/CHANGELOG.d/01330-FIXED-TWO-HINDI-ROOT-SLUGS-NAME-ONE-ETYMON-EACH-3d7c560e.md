## Fixed — two Hindi root slugs name one etymon each

- **HI-C36-darvaaza** moves from `persian-dar` to `persian-dar-door`, the slug Persian's *darvâze* and Punjabi's *darvāzā* use. `persian-dar` also named *-dār* "holder" (now `persian-dar-holder`) and *dar* "in" (now `persian-dar-in`), and no lesson uses it any more.
- **HI-C11-kaalaa-safed** moves from `sanskrit-kala` to `sanskrit-kala-black`. *Kālā* is *kāla* "black" (CDIAL 3083), the slug the Gujarati, Marathi, Marwadi, Punjabi and Urdu black lessons use; `sanskrit-kala` now names only *kalā* "art" (CDIAL 2927).
