## You'll want to know: पत्नी
<!-- hl-knowledge: introduces=[HI-LEX-C118-SPOUSE-04]; assesses=[] -->

**पत्नी** (*patnī*) — "a wife".

It is built on **पति**, with the **-ई** that marks a woman. **मेरी पत्नी** — "my wife".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

Husband and wife, one built on the other.
