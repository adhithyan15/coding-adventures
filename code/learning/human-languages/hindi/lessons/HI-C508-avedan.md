## You'll want to know: आवेदन
<!-- hl-knowledge: introduces=[HI-LEX-C508-NAUKRI508-03]; assesses=[] -->

**आवेदन** — *āvedan* — "an application (formal)".

> मैंने नौकरी के लिए आवेदन भेजा।
>
> *Maiṁne naukrī ke liye āvedan bhejā.*
>
> I sent an application for the job.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**आवेदन** (*āvedan*) is a tatsama, taken whole from Sanskrit *āvedana*, "announcing, informing" (Monier-Williams). Hindi uses it for a written request, an application.
