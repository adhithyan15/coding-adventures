# బంధువు (bandhuvu) — a relative

## You'll want to know: బంధువు
<!-- hl-knowledge: introduces=[TE-LEX-C88-PEOPLE-05]; assesses=[] -->

**బంధువు** (*bandhuvu*) — "a relative".

**అతను మా బంధువు** — "he is our relative", with no word for *is*, the same way **నా పేరు ...**
needs none.
