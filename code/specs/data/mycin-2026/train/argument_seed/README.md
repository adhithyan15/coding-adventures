# Argument-decomposer seed set (AD-2)

Generated by [`../gen_argument_data.py`](../gen_argument_data.py) — the deterministic gold
builder for the prose→`argument` decomposer ([`ADJ-ARGUMENT-DECOMPOSER.md`](../../../../ADJ-ARGUMENT-DECOMPOSER.md)).
Regenerate with `python3 gen_argument_data.py --emit argument_seed` (from `../`).

Each seed is a paragraph of prose decomposed into a gold `argument` program whose premises
cite **verbatim byte slices** of the paragraph and whose thesis the engine **derives**. All
three pass the spec's three-part correctness gate — they compile, `adj-lang-cli` derives the
thesis, and `adj-verify --snapshots` byte-anchors every citation (`python3 gen_argument_data.py
--self-check`).

| id | domain | `<id>.source.txt` → `<id>.adj` |
|---|---|---|
| `arg-axle-fatigue` | materials science | the ADR-5 worked example (reused byte-for-byte) — 4 premises + 2 inferences derive `failed_by(axle, fatigue)` |
| `arg-pump-outbreak` | epidemiology | 2 premises + 1 inference derive `source_of(pump, outbreak)`; carries a near-miss **discard** |
| `arg-galaxy-redshift` | astronomy | 2 premises + 1 inference derive `receding(galaxy)` |

The three domains have **disjoint predicate vocabularies** — the point: the surface is
open-vocab, so the decomposer's target is not a fixed relation list.

## Files

- `<id>.source.txt` — the pinned source paragraph (its SHA-256 is the snapshot the `.adj` pins).
- `<id>.adj` — the gold argument program (premises + inferences + `? thesis`).
- `argument_seed.jsonl` — the training rows (one per seed), in the
  [`ADJ-ARGUMENT-DECOMPOSER.md`](../../../../ADJ-ARGUMENT-DECOMPOSER.md) §3.2 schema: the
  paragraph (`note`) and the gold argument (premises / inferences / thesis / near-miss `discard`
  spans) a model must learn to emit from it.

These are the first rows of the AD-2..5 training/eval loop: AD-3 scores a model's emitted
argument against this gold (fidelity + thesis-derivation + near-miss/fabrication vetoes), AD-4
holds out an eval set, AD-5 drives the full decompose→emit→verify→explain pipeline.
