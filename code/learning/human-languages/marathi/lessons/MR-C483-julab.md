## You'll want to know: जुलाब
<!-- hl-knowledge: introduces=[MR-LEX-C483-PACAN483-03]; assesses=[] -->

**जुलाब** — *julāb* — "diarrhoea".

> शिळं अन्न खाल्ल्याने बाळाला जुलाब झाले.
>
> *śiḷaṁ anna khāllyāne bāḷālā julāb jhāle.*
>
> The baby got diarrhoea from eating stale food.

Masculine.

Usually plural: जुलाब होणे, with the dative.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**जुलाब** (*julāb*) is a loan from Persian *julāb*, "a purgative drink", usually traced to Arabic.
