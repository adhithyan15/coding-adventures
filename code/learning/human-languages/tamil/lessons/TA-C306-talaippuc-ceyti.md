# தலைப்புச் செய்தி (talaippuc ceyti) — a headline

## You'll want to know: தலைப்புச் செய்தி
<!-- hl-knowledge: introduces=[TA-LEX-C306-THALAIPPU306-01]; assesses=[] -->

**தலைப்புச் செய்தி** — *talaippuc ceyti* — "a headline".

> இன்றைய தலைப்புச் செய்தி அந்த விபத்துதான்.
>
> *iṉṟaiya talaippuc ceyti anta vipattutāṉ.*
>
> Today's headline is that very accident.

The ச் is the doubled stop of sandhi before செய்தி, news.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**தலைப்புச் செய்தி** (*talaippuc ceyti*) is a Tamil phrase built from தலைப்பு, "beginning, title", from தலை, "head" (DEDR 3103), and செய்தி, "news", at root "a deed" (DEDR 1957).
