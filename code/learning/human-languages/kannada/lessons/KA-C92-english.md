# ಇಂಗ್ಲಿಷ್ (iṅgliṣ) — English (the language)

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[KA-LEX-C92-WORK-03, KA-LEX-C92-WORK-04] -->

## You'll want to know: ಇಂಗ್ಲಿಷ್
<!-- hl-knowledge: introduces=[KA-LEX-C92-WORK-05]; assesses=[] -->

**ಇಂಗ್ಲಿಷ್** (*iṅgliṣ*) — "English".

**ನನಗೆ ಇಂಗ್ಲಿಷ್ ಗೊತ್ತು** (*nanage iṅgliṣ gottu*) — "I know English", built
like **ನನಗೆ ಕನ್ನಡ ಗೊತ್ತು**.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

The language you already speak, in Kannada.
