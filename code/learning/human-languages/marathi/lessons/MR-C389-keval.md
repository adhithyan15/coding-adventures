## You'll want to know: केवळ
<!-- hl-knowledge: introduces=[MR-LEX-C389-PRAMANE389-03]; assesses=[] -->

**केवळ** — *kevaḷ* — "merely; only".

> हे काम केवळ एका दिवसात झालं.
>
> *he kām kevaḷ ekā divsāt jhālaṁ.*
>
> This work got done in only one day.

Formal for फक्त.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**केवळ** (*kevaḷ*) is a tatsama, taken from Sanskrit *kevala*, "alone, sole, entire" (Monier-Williams).
