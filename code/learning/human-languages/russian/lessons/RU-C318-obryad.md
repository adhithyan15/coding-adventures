## You'll want to know: обряд
<!-- hl-knowledge: introduces=[RU-LEX-C318-TRADITSIYA-03]; assesses=[] -->

**обряд** (*obryád*) — "a rite, a ritual".

> Это очень старый обряд.
>
> *Éto óchen stáryy obryád.*
>
> This is a very old rite.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*обряд* is usually traced to *об-* and *ряд* "a row, order": a set order of acts. EtymDB lists no parent.
