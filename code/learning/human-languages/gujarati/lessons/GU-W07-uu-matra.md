# ૂ — the long-ū sign

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[GU-SCRIPT-U-MATRA-01, GU-SCRIPT-MA-01] -->

Write **મુ** once with the short-*u* hook below **મ**. Put it away. Long *ū*
uses a longer below-hook, but it still needs a consonant host.

## Script — meet one form
<!-- hl-knowledge: introduces=[GU-SCRIPT-UU-MATRA-01]; assesses=[] -->

Keep **મૂ** visible. The sign **ૂ** attaches below the consonant as a longer
hook. Read **મૂ** as *mū*: consonant first, then long vowel.

## Writing — notice and trace
<!-- hl-knowledge: introduces=[]; assesses=[GU-SCRIPT-UU-MATRA-01] -->
<!-- hl-writing-stage: observe-trace -->

Finger-trace only the longer below-hook in **મૂ**, then air-trace it once. Keep
the hook below the host and make its extra length visible.

## Writing — copy with the model
<!-- hl-knowledge: introduces=[]; assesses=[GU-SCRIPT-UU-MATRA-01, GU-SCRIPT-MA-01] -->
<!-- hl-writing-stage: guided-copy -->

Copy visible **મૂ** once. Compare **મુ / મૂ** and repair only the hook length if
the two forms look alike.

## Writing — recall after hiding
<!-- hl-knowledge: introduces=[]; assesses=[GU-SCRIPT-UU-MATRA-01, GU-SCRIPT-MA-01] -->
<!-- hl-writing-stage: delayed-copy -->
<!-- hl-activity: {"id":"GU-W07-uu-matra-recall","kind":"text","assesses":["GU-SCRIPT-UU-MATRA-01","GU-SCRIPT-MA-01"],"prompt":"Hide the model and write mū with the long-ū sign.","answer":"મૂ","accepted":[],"feedback":{"correct":"મૂ — the longer below-hook is attached to ma.","incorrect":"Look once at મૂ, hide it, and repair only the below-hook."},"response_seconds":20} -->

Hide the model and write *mū* once. Uncover **મૂ**, compare, and stop after one
repair.

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[GU-SCRIPT-UU-MATRA-01, GU-SCRIPT-U-MATRA-01] -->

[PAUSE 3s] Point to long *ū* in **મુ મૂ**, then write only its dependent sign.
