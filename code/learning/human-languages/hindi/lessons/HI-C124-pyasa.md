# प्यासा (pyāsā) — thirsty

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[HI-LEX-C123-HAAL-05, HI-LEX-C124-BODY-01] -->

## You'll want to know: प्यासा
<!-- hl-knowledge: introduces=[HI-LEX-C124-BODY-02]; assesses=[] -->

**प्यासा** (*pyāsā*) — "thirsty". A woman says **प्यासी**.

The same move: **प्यास**, "thirst", becomes **प्यासा**.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

Thirst, made into how you are.
