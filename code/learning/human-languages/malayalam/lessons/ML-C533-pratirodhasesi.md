# പ്രതിരോധശേഷി (pratirōdhaśēṣi) — immunity

## You'll want to know: പ്രതിരോധശേഷി
<!-- hl-knowledge: introduces=[ML-LEX-C533-VAKSIN533-02]; assesses=[] -->

**പ്രതിരോധശേഷി** — *pratirōdhaśēṣi* — "immunity".

> നല്ല ഭക്ഷണം പ്രതിരോധശേഷി കൂട്ടും.
>
> *nalla bhakṣaṇaṁ pratirōdhaśēṣi kūṭṭuṁ.*
>
> Good food builds up immunity.

പ്രതിരോധം resistance + ശേഷി strength, capacity.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**പ്രതിരോധശേഷി** (*pratirōdhaśēṣi*) is a learned compound built from Sanskrit *pratirodha*, "opposition, obstruction" (Monier-Williams), and ശേഷി, "capacity", whose own origin is not settled.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
