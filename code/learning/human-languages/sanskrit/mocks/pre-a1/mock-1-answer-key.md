7. Accept the learner's chosen name when it is independently written in

## Speaking

<!-- mock-part:prea1-speaking-greeting-and-identity -->
1. Accept **नमस्ते**, **नमः**, or an equally appropriate taught greeting.
2. Accept a chosen identity in a comprehensible frame such as
   **मम नाम … अस्ति।**
<!-- /mock-part:prea1-speaking-greeting-and-identity -->
<!-- mock-part:prea1-speaking-familiar-questions -->
3. Accept a relevant state such as **अहं कुशली अस्मि।**
4. Accept a comprehensible place response such as **अहं काशी-नगरे वसामि।**
5. Accept a relevant yes/no response or a short Sanskrit-speaking frame.
<!-- /mock-part:prea1-speaking-familiar-questions -->
<!-- mock-part:prea1-speaking-short-request -->
6. Accept a comprehensible polite water request containing **जलम्** and an
   appropriate request signal such as **कृपया**.

Apply the speaking rubric to the whole part. These examples are not scripts the
learner must reproduce word for word. Consistent taught pronunciation variants
remain acceptable.
<!-- /mock-part:prea1-speaking-short-request -->
