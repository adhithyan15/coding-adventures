## You'll want to know: أجر
<!-- hl-knowledge: introduces=[AR-LEX-C521-MUKAFAA521-01]; assesses=[] -->

**أجر** — *ajr* — "a wage, pay".

> يأخذ العامل أجره كل أسبوع.
>
> *yaʾkhudhu al-ʿāmil ajrahu kull usbūʿ.*
>
> The worker takes his pay every week.

Plural: أجور, *ujūr*.

راتب is a monthly salary; أجر is pay for work done. Read ajara, the same letters are a verb, to reward.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**أجر** (*ajr*) is built on the native Arabic root *ʾ-j-r*, "to reward, to hire" (Lane). Ījār, rent, which you know, is from the same root.
