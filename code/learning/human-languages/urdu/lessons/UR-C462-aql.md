## You'll want to know: عقل
<!-- hl-knowledge: introduces=[UR-LEX-C462-SENSE462-01]; assesses=[] -->

**عقل** — *aql* — "sense; wits".

> اس لڑکے میں بڑی عقل ہے۔
>
> *is laṛke meṅ baṛī aql hai.*
>
> This boy has a lot of sense.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**عقل** (*aql*) is usually traced, through Persian, to Arabic *ʿaql*, "reason, intelligence".
