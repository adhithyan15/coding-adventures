# ഫർണിച്ചർ (pharṇiccar) — furniture

## You'll want to know: ഫർണിച്ചർ
<!-- hl-knowledge: introduces=[ML-LEX-C570-VITTUPAKARANAM570-01]; assesses=[] -->

**ഫർണിച്ചർ** — *pharṇiccar* — "furniture".

> പുതിയ വീട്ടിലേക്ക് ഞങ്ങൾ കുറച്ച് ഫർണിച്ചർ വാങ്ങി.
>
> *putiya vīṭṭilēkkŭ ñaṅṅaḷ kuṟaccŭ pharṇiccar vāṅṅi.*
>
> We bought some furniture for the new house.

Like the English word, it has no plural.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ഫർണിച്ചർ** (*pharṇiccar*) was borrowed from English *furniture*.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
