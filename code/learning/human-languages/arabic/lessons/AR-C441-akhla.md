## You'll want to know: أخلى
<!-- hl-knowledge: introduces=[AR-LEX-C441-ISTIQBAL441-05]; assesses=[] -->

**أخلى** — *akhlā* — "to vacate; to evacuate".

> أخلينا الغرفة قبل الظهر.
>
> *akhlaynā al-ghurfa qabla aẓ-ẓuhr.*
>
> We vacated the room before noon.

Present: يخلي, *yukhlī*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**أخلى** (*akhlā*) is built on the native Arabic root *kh-l-w*, "to be empty, to be alone" (Lane). It is Form IV, "to make empty".
