# ਪਿਛਲੇ — last or previous in a time phrase

## Grammar Lens: point backward instead of forward
<!-- hl-knowledge: introduces=[PA-FORM-PICHHLE-184]; assesses=[] -->

> **ਪਿਛਲੇ** — *pichhle* — last or previous, in a masculine time phrase

Keep one compact contrast: **ਅਗਲੇ ਮਹੀਨੇ** points forward; **ਪਿਛਲੇ ਹਫ਼ਤੇ** points backward.
