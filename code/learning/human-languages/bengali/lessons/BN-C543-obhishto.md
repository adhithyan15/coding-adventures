# অভীষ্ট (ôbhīshṭô) — a desired goal; what one wished for

## You'll want to know: অভীষ্ট
<!-- hl-knowledge: introduces=[BN-LEX-C543-SIDDHI543-05]; assesses=[] -->

**অভীষ্ট** — *ôbhīshṭô* — "a desired goal; what one wished for".

> দলটা শেষে তার অভীষ্ট পুরস্কার পেল।
>
> *Dôlṭā sheshe tār ôbhīshṭô purôskār pelô.*
>
> In the end the team won the prize it had wished for.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**অভীষ্ট** (*ôbhīshṭô*) is a tatsama, Sanskrit *abhīṣṭa*, "wished for, dear" (Monier-Williams).
