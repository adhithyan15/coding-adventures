# മുറ്റം (muṟṟaṁ) — the yard

## You'll want to know: മുറ്റം
<!-- hl-knowledge: introduces=[ML-LEX-C128-HOME-05]; assesses=[] -->

**മുറ്റം** (*muṟṟaṁ*) — "the yard", the swept ground in front of a Kerala house where
the **കോലം** is drawn.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

Outside, but still home.
