## You'll want to know: mīror, mīrārī
<!-- hl-knowledge: introduces=[LA-LEX-C495-MIRA-02]; assesses=[] -->

**mīror, mīrārī** — "to wonder, marvel at".

> Puer elephantum mīrātur.
>
> *The boy marvels at the elephant.*

Deponent: *mīror, mīrārī, mīrātus sum*. With the accusative, or with *quod* — I am surprised that. English *miracle* belongs to the same family.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**mīror** is built on *mīrus* "wonderful", which EtymDB traces through Proto-Italic to a Proto-Indo-European root meaning "to smile". English *admire* and *miracle* belong to the same family.
