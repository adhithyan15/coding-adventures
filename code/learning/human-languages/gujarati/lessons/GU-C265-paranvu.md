# પરણવું (paraṇvũ) — to marry, to get married

## You'll want to know: પરણવું
<!-- hl-knowledge: introduces=[GU-LEX-C265-LOVE265-02]; assesses=[] -->

**પરણવું** — *paraṇvũ* — "to marry, to get married".

> **શું તમારો ભાઈ આ વરસે પરણે છે?** — *śũ tamāro bhāī ā varse paraṇe che?* — "Is your brother getting married this year?"

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**પરણવું** (*paraṇvũ*) is a tadbhava. It comes from Sanskrit *páriṇayati*, "leads round" the fire, and so "marries" (CDIAL 7819).
