## You'll want to know: honesto
<!-- hl-knowledge: introduces=[ES-LEX-C636-VERDAD-04]; assesses=[] -->

**honesto** — "honest".

> Es una persona honesta.
>
> *She is an honest person.*

In Spain *honrado* is also common for honest.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*honesto* is a learned borrowing from Latin *honestus* 'honourable', built on *honor* 'honour' (EtymDB).
