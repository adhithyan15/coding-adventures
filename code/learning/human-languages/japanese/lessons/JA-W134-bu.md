# ぶ — ふ, voiced to bu

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[JA-LEX-ANCHOR-SHINBUN, JA-LEX-C134-BASHO, JA-LEX-C133-KINOU, JA-LEX-C123-QUAL123-03] -->

[PAUSE 20s] Four recalls, then the sign.

- [YOU RECALL: say *a newspaper* — **R1**, one lesson back]
- [YOU RECALL: say *a place* — **R2**, five lessons back]
- [YOU RECALL: say *yesterday* — **R3**, twenty lessons back]
- [YOU RECALL: say *frustrating* — **R4**, eighty lessons back]

## Script — the change
<!-- hl-knowledge: introduces=[JA-SCRIPT-BU-01]; assesses=[JA-SCRIPT-FU-01, JA-SCRIPT-DAKUTEN-01] -->

> **ふ** *fu* + **゛** → **ぶ** *bu*

Write **ふ** in full, in the order you learned it. Then add the two short
strokes of the voicing mark at the upper right, the left one first.

The sign is read *bu*: the whole *h* row voices to *b*, as **は** did to **ば**
and **へ** to **べ**.

With **しん** in front and **ん** after it, you can now write the word from the
last lesson: **しんぶん**, *shinbun*, a newspaper.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[JA-SCRIPT-BU-01, JA-SCRIPT-FU-01, JA-SCRIPT-DAKUTEN-01, JA-LEX-ANCHOR-SHINBUN] -->

1. Write **ふ**, then **ぶ**, and say *fu*, *bu*.
2. Write **ば**, **ぶ**, **べ** and **ぼ**, and say each one.
3. Write **しんぶん** from memory and say *shinbun*.
