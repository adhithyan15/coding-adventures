# ஆவணப்படம் (āvaṇappaṭam) — a documentary

## You'll want to know: ஆவணப்படம்
<!-- hl-knowledge: introduces=[TA-LEX-C310-OODAKAM310-03]; assesses=[] -->

**ஆவணப்படம்** — *āvaṇappaṭam* — "a documentary".

> காடுகள் பற்றிய ஒரு ஆவணப்படம் பார்த்தேன்.
>
> *kāṭukaḷ paṟṟiya oru āvaṇappaṭam pārttēṉ.*
>
> I watched a documentary about forests.

ஆவணம், a record + படம், a film.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ஆவணப்படம்** (*āvaṇappaṭam*) is a Tamil compound built from ஆவணம், "a document", and படம், "a picture, a film", usually traced to Sanskrit *paṭa*, "cloth" (CDIAL 7692).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
