# Six lines with the old banks visible

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-SIX-ORDER-01, PA-FORM-SIX-CUE-01] -->

Return to the six blank labels. Point to the first three lines, pause, then
point to the last three. Today the old A and ਕ values stay visible.

## Writing — supported entry
<!-- hl-knowledge: introduces=[PA-FORM-SIX-SUPPORTED-01]; assesses=[PA-FORM-SIX-CUE-01] -->
<!-- hl-writing-stage: guided-copy -->

For A · ਕ, use the old visible word bank: **ਅਮਨ · ਪੰਜਾਬੀ · ਪਿੰਡ · ਖੇਤੀ**.
Use the old visible digit bank: **੧੫ · ੦੧੨ ੨੫੧**. Copy one selected value
beside each familiar label in the fixed order. Stop after the first three
lines and check only which value belongs to which label; then do the rest.

> ਨਾਂ: ______
>
> ਭਾਸ਼ਾ: ______
>
> ਰਿਹਾਇਸ਼: ______
>
> ਕੰਮ: ______
>
> ਉਮਰ: ______
>
> ਫ਼ੋਨ: ______

## Guided Practice — one boundary at a time
<!-- hl-knowledge: introduces=[]; assesses=[PA-FORM-SIX-SUPPORTED-01] -->

Check each colon has one readable space after it. The phone number also
keeps its old single group space. This is visible-bank practice, not
independent writing evidence.
