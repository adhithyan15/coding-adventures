# Changelog

All notable changes to this package will be documented in this file.

## [0.1.0] - 2026-05-08

### Added

- Smart-home worker capability profiles with integration, bridge, and worker
  identity.
- OS-level worker needs projected into generic `capability-cage` manifests.
- Built-in helper profiles for local HTTP, MQTT subscription, serial adapters,
  cloud APIs, webhooks, and sidecar execution.
- Separate D23 smart-home capability hints for read and command permissions.
- Payload-free worker need and cage profile summaries for host-side policy
  review before launching workers.
