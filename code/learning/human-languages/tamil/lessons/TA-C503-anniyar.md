# அந்நியர் (anniyar) — a stranger; an outsider

## You'll want to know: அந்நியர்
<!-- hl-knowledge: introduces=[TA-LEX-C503-NATPU503-02]; assesses=[] -->

**அந்நியர்** — *anniyar* — "a stranger; an outsider".

> அந்நியர்களிடம் குழந்தைகள் பேசக் கூடாது.
>
> *anniyarkaḷiṭam kuḻantaikaḷ pēcak kūṭātu.*
>
> Children must not talk to strangers.

Plural: அந்நியர்கள், *anniyarkaḷ*.

Respectful -அர்; plural அந்நியர்கள்.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**அந்நியர்** (*anniyar*) is borrowed from Sanskrit *anya*, "other" (CDIAL 399), with the Tamil -அர் of a person.
