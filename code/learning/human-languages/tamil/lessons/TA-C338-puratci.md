# புரட்சி (puraṭci) — a revolution

## You'll want to know: புரட்சி
<!-- hl-knowledge: introduces=[TA-LEX-C338-VIDUTHALAI338-03]; assesses=[] -->

**புரட்சி** — *puraṭci* — "a revolution".

> அந்தப் புரட்சி நாட்டின் வரலாற்றை மாற்றியது.
>
> *antap puraṭci nāṭṭiṉ varalāṟṟai māṟṟiyatu.*
>
> That revolution changed the country's history.

The adjective is புரட்சிகரமான, revolutionary.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**புரட்சி** (*puraṭci*) is native Dravidian: DEDR 4285 gives it under புரள், "to be upset, roll over", as "upsetting, disorder".
