## You'll want to know: восторг
<!-- hl-knowledge: introduces=[RU-LEX-C475-PRIDE-01]; assesses=[] -->

**восторг** (*vostórg*) — "delight, rapture".

> Дети были в восторге от цирка.
>
> *Déti býli v vostórge ot tsírka.*
>
> The children were delighted with the circus.

Masculine. *Быть в восторге от* + genitive — to be thrilled with.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*восторг* is built on *вос-* 'up' and a root usually linked to the one in *исторгнуть* 'to tear out', so rapture is being carried away; EtymDB has no entry, so the link is not settled.
