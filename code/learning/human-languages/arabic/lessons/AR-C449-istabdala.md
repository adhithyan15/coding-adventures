## You'll want to know: استبدل
<!-- hl-knowledge: introduces=[AR-LEX-C449-SHAKWA449-05]; assesses=[] -->

**استبدل** — *istabdala* — "to swap; to exchange (for another)".

> استبدلت القميص بقميص أكبر.
>
> *istabdaltu al-qamīṣ bi-qamīṣ akbar.*
>
> I swapped the shirt for a bigger one.

Present: يستبدل, *yastabdil*.

In modern use the new thing takes *bi-*; classical usage put *bi-* on the thing given up.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**استبدل** (*istabdala*) is built on the native Arabic root *b-d-l*, "to change, to replace" (Lane). It is Form X.
