# പരീക്ഷണം (parīkṣaṇaṁ) — an experiment

## You'll want to know: പരീക്ഷണം
<!-- hl-knowledge: introduces=[ML-LEX-C436-PARIKSANAM436-02]; assesses=[] -->

**പരീക്ഷണം** — *parīkṣaṇaṁ* — "an experiment".

> ആദ്യത്തെ പരീക്ഷണം വിജയിച്ചില്ല.
>
> *ādyatte parīkṣaṇaṁ vijayiccilla.*
>
> The first experiment did not succeed.

To experiment is പരീക്ഷണം നടത്തുക.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**പരീക്ഷണം** (*parīkṣaṇaṁ*) is borrowed from Sanskrit *parīkṣaṇa*, "trying, testing, an experiment" (Monier-Williams), a sister of പരീക്ഷ, an exam.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
