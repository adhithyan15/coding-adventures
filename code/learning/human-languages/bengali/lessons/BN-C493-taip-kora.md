# টাইপ করা (ṭāip kôrā) — to type

## You'll want to know: টাইপ করা
<!-- hl-knowledge: introduces=[BN-LEX-C493-OPHIS493-05]; assesses=[] -->

**টাইপ করা** — *ṭāip kôrā* — "to type".

> কেরানি চিঠিটা টাইপ করল।
>
> *Kerāni chiṭhiṭā ṭāip kôrlô.*
>
> The clerk typed the letter.

Past (he/she …): তিনি ফর্মটা টাইপ করলেন, *tini phôrmṭā ṭāip kôrlen*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**টাইপ করা** (*ṭāip kôrā*) joins *type*, borrowed from English, to করা, "to do".
