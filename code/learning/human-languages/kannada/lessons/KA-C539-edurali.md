# ಎದುರಾಳಿ (edurāḷi) — an opponent

## You'll want to know: ಎದುರಾಳಿ
<!-- hl-knowledge: introduces=[KA-LEX-C539-SPARDHE539-01]; assesses=[] -->

**ಎದುರಾಳಿ** — *edurāḷi* — "an opponent".

> ಚದುರಂಗದಲ್ಲಿ ನನ್ನ ಎದುರಾಳಿ ತುಂಬಾ ಜಾಣ.
>
> *caduraṅgadalli nanna edurāḷi tumbā jāṇa.*
>
> My chess opponent is very clever.

Plural: ಎದುರಾಳಿಗಳು, *edurāḷigaḷu*.

ಎದುರು, facing + ಆಳು, a man: the man facing you.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಎದುರಾಳಿ** (*edurāḷi*) is a native Dravidian compound: *edur*, "that which is opposite" (DEDR 795), and *āḷ*, "a man, a soldier" (DEDR 399).
