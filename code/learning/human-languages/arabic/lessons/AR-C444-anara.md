## You'll want to know: أنار
<!-- hl-knowledge: introduces=[AR-LEX-C444-KAHRABA444-05]; assesses=[] -->

**أنار** — *anāra* — "to light up".

> أنار المصباح الممر الطويل.
>
> *anāra al-miṣbāḥ al-mamarr aṭ-ṭawīl.*
>
> The lamp lit up the long corridor.

Present: ينير, *yunīr*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**أنار** (*anāra*) is built on the native Arabic root *n-w-r*, "light" (Lane). It is Form IV, "to give light".
