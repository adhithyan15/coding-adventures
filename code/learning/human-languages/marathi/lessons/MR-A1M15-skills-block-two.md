# Order the second three skills

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MR-A1-MESSAGE-LINE-SPEAK, MR-A1-MESSAGE-LINE-THINK, MR-A1-MESSAGE-LINE-UNDERSTAND-MARATHI] -->

Retrieve the three jobs: speak, think, understand Marathi. The middle job keeps
two verb pieces; the last job returns to **मला**.
