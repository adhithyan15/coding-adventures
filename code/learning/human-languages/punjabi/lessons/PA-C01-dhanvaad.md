# *dhannavād* — “thank you,” the Sanskrit way

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-NAMASTE-01, PA-LEX-HAAN-NAHIN-01] -->

[PAUSE 2s] You can greet and answer yes or no. Add one spoken thanks. The
Gurmukhi above is a label, not a word you must decode.

## You'll want to know first — listen and use
<!-- hl-knowledge: introduces=[PA-LEX-DHANVAAD-01]; assesses=[PA-LEX-NAMASTE-01, PA-LEX-HAAN-NAHIN-01] -->

[YOU HEAR: *dhannavād*] — **thank you**. Return it once: [YOU SAY:
*dhannavād*].

It descends from Sanskrit *dhanya*, “worthy” or “blessed,” plus *vāda*, “a
saying.” This is Punjabi’s Sanskritic thanks. The next session adds a
Perso-Arabic choice with the same everyday function.
