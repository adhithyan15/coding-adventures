## You'll want to know: chuviscar
<!-- hl-knowledge: introduces=[PT-LEX-C466-CHUVA-01]; assesses=[] -->

**chuviscar** — "to drizzle".

> Está a chuviscar, mas não preciso de guarda-chuva.
>
> *It is drizzling, but I do not need an umbrella.*

*O chuvisco* — drizzle.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*chuviscar* is built on *chuva* 'rain', which is inherited from Latin *pluvia* (EtymDB).
