## You'll want to know: il copione
<!-- hl-knowledge: introduces=[IT-LEX-C520-RECITARE-02]; assesses=[] -->

**il copione** — "script".

> Devo imparare il copione a memoria.
>
> *I have to learn the script by heart.*

Also a set pattern: *seguire il copione*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*copione* is built on *copia* "copy" (EtymDB), from Latin *cōpia* "plenty": the big copy each actor works from.
