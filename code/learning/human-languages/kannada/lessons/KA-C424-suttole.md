## You'll want to know: ಸುತ್ತೋಲೆ
<!-- hl-knowledge: introduces=[KA-LEX-C424-AVALOKISU424-03]; assesses=[] -->

**ಸುತ್ತೋಲೆ** — *suttōle* — "a circular".

> ರಜೆಯ ಬಗ್ಗೆ ಶಾಲೆ ಒಂದು ಸುತ್ತೋಲೆ ಕಳುಹಿಸಿತು.
>
> *rajeya bagge śāle ondu suttōle kaḷuhisitu.*
>
> The school sent a circular about the holiday.

ಸುತ್ತು (to go round) + ಓಲೆ (a letter).

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಸುತ್ತೋಲೆ** (*suttōle*) is native Dravidian, built from *suttu*, "to go round" (DEDR 2715), and *ōle*, "a palm leaf written on, a letter" (DEDR 1070).
