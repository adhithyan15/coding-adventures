## You'll want to know: استهلك
<!-- hl-knowledge: introduces=[AR-LEX-C465-TAQA465-05]; assesses=[] -->

**استهلك** — *istahlaka* — "to consume; to use up".

> تستهلك السيارة الكبيرة بنزينا كثيرا.
>
> *tastahliku as-sayyāra al-kabīra banzīnan kathīran.*
>
> The big car uses a lot of petrol.

Present: يستهلك, *yastahlik*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**استهلك** (*istahlaka*) is built on the native Arabic root *h-l-k*, "to perish" (Lane). It is Form X, "to make perish, to use up".
