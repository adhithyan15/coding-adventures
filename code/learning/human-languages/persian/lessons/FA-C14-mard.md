# مرد — man, but its root says "mortal"

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[FA-LEX-PESAR, FA-ETYMON-PESAR] -->

[PAUSE 2s] Say **پسر** (*pesar*), and the Sanskrit word it shares a root with. This
lesson's word looks like it should be an easy English cousin. It is not.

## You'll want to know first — one word
<!-- hl-knowledge: introduces=[FA-LEX-MARD]; assesses=[] -->

> **مرد** — *mard* — **man**

Three letters, all already yours: **م ر د** — *m*, *r*, *d*.

## The word, taken apart — a false friend worth naming
<!-- hl-knowledge: introduces=[FA-ETYMON-MARD]; assesses=[] -->

**مرد** continues Middle Persian **mard**, from Indo-European \**mer-*, "to
die." Its literal sense is not "man" at all — it is "mortal," "one who
dies." The same root gives Latin **mortuus**, "dead" (→ English **mortal**,
**mortician**), Greek **brotós** (→ **ambrosia**, "not mortal"), and
Sanskrit **martya**. English **man** looks like an obvious match for
**مرد** and is not one — it descends from a completely different root — so
this is one place where guessing a cousin from sound alone would mislead
rather than help.
