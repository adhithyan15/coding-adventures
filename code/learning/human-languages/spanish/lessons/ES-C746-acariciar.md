## You'll want to know: acariciar
<!-- hl-knowledge: introduces=[ES-LEX-C746-ENGANO-01]; assesses=[] -->

**acariciar** — "to stroke, to caress".

> Le gusta acariciar al gato.
>
> *She likes stroking the cat.*

*Una caricia* — a caress.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*acariciar* is built on *caricia*, which was borrowed from Italian *carezza* (EtymDB), from *caro* "dear", Latin *cārus*.
