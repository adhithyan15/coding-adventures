# மலையேற்றம் (malaiyēṟṟam) — trekking; hill climbing

## You'll want to know: மலையேற்றம்
<!-- hl-knowledge: introduces=[TA-LEX-C554-VARAIRUTHI554-03]; assesses=[] -->

**மலையேற்றம்** — *malaiyēṟṟam* — "trekking; hill climbing".

> வானிலை நன்றாக இருந்தால் சனிக்கிழமை மலையேற்றம் போவோம்.
>
> *vāṉilai naṉṟāka iruntāl caṉikkiḻamai malaiyēṟṟam pōvōm.*
>
> If the weather is good, we will go trekking on Saturday.

மலை (*malai*) "a hill" + ஏற்றம் "a climb".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**மலையேற்றம்** (*malaiyēṟṟam*) is a native compound: மலை (*malai*), "a hill, a mountain" (DEDR 4742), and ஏற்றம் (*ēṟṟam*), "a climb, an ascent", from ஏறு, "to climb" (DEDR 916).
