# ఏడుపు (ēḍupu) — crying, tears

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TE-LEX-C96-NAMES-05, TE-LEX-C97-MOOD-01] -->

[PAUSE 2s] Before the new one: say the Telugu for a signature, then the Telugu for a laugh.

## You'll want to know: ఏడుపు
<!-- hl-knowledge: introduces=[TE-LEX-C97-MOOD-02]; assesses=[] -->

**ఏడుపు** (*ēḍupu*) — "crying".

**నాకు ఏడుపు వచ్చింది** — "I felt like crying", literally "crying came to me", on the pattern of
**కోపం వచ్చింది**.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

Crying, which comes to you like anger does.
