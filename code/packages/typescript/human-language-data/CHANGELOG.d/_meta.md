# Changelog

## Unreleased

This directory is the committed changelog. Each numbered Markdown file is one
detailed entry, ordered newest-first by its descending ordinal. To build a
temporary single-file view, run the `unshard:docs` package script with
`code/packages/typescript/human-language-data/CHANGELOG.md` as the argument.
The rendered `CHANGELOG.md` is intentionally ignored so independent curriculum
branches do not collide on a generated aggregate.
