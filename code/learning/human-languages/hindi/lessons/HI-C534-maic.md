## You'll want to know: मैच
<!-- hl-knowledge: introduces=[HI-LEX-C534-MAICH534-01]; assesses=[] -->

**मैच** — *maic* — "a match (a game)".

> कल शाम को क्रिकेट का मैच है।
>
> *Kal śām ko krikeṭ kā maic hai.*
>
> There is a cricket match tomorrow evening.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**मैच** (*maic*) is a loan from English *match*.
