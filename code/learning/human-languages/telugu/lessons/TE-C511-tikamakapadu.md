# తికమకపడు (tikamakapaḍu) — to be confused; to be muddled

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TE-LEX-C510-GUNAM510-05, TE-LEX-C511-GNAPAKAM511-01] -->

[PAUSE 2s] Before the new one: say the Telugu for curiosity, then the Telugu for wits.

## You'll want to know: తికమకపడు
<!-- hl-knowledge: introduces=[TE-LEX-C511-GNAPAKAM511-02]; assesses=[] -->

**తికమకపడు** — *tikamakapaḍu* — "to be confused; to be muddled".

> కొత్త నగరంలో దారి తెలియక నేను తికమకపడ్డాను.
>
> *kotta nagaraṁlō dāri teliyaka nēnu tikamakapaḍḍānu.*
>
> Not knowing the way in the new city, I got muddled.

Past (I …): తికమకపడ్డాను, *tikamakapaḍḍānu*.

తికమక, a muddle: తికమకగా ఉంది, it is confusing.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**తికమకపడు** (*tikamakapaḍu*) is native Dravidian: DEDR 3207 lists Telugu *tikamaka*, "intricacy, confusion", and *tikamakalāḍu*, "to be puzzled", with Tamil *tikai*, "to be perplexed"; the native verb *paḍu*, "to feel, to suffer" (DEDR 3853) completes the verb.
