## You'll want to know: मागील
<!-- hl-knowledge: introduces=[MR-LEX-C305-GATVARSH305-02]; assesses=[] -->

**मागील** — *māgīl* — "previous; the last".

> मागील बैठकीत हा प्रश्न आला होता.
>
> *māgīl baiṭhkīt hā praśna ālā hotā.*
>
> This question came up at the previous meeting.

Formal; it keeps one form: मागील आठवडा, मागील बैठक.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**मागील** (*māgīl*) is built on *māg*, 'a track; behind', which CDIAL lists as Marathi 'road, track' under Sanskrit *mārga* (CDIAL 10071), with the ending *-īl*.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
