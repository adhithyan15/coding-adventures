# ये कितणे कू है? — the price question on the page

## Warm-up
<!-- hl-knowledge: introduces=[MW-SCRIPT-PRICE-QUESTION-01]; assesses=[MW-LEX-PRICE-QUESTION-01, MW-LEX-DUKAN-01, MW-SCRIPT-DUKAN-01, MW-SCRIPT-U-MATRA-01] -->

[PAUSE 20s] Say *how much is this*, write shop, then write **ु** on its own.

## You'll want to know
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-YE-01, MW-SCRIPT-KITNO-01, MW-SCRIPT-UU-MATRA-01, MW-SCRIPT-KA-01, MW-SCRIPT-E-MATRA-01, MW-SCRIPT-HAI-01] -->

> **ये | कितणे | कू | है?**

Four written words. **ये** and **है** you have written before; **कितणे** is last
lesson's **कितणो** with **े** where **ो** stood; **कू** is **क** carrying the
long **ू** you first drew for **मिलसू**.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-PRICE-QUESTION-01] -->
<!-- hl-writing-stage: delayed-copy -->

Read the line once. Cover it for ten seconds and write all four words. Open the
model and repair only the word that changed, then rewrite that word alone.
