# Hindi pre-A1 mock 1 — learner paper and examiner script

Use support-language directions only to explain the action. Never translate an
answer-bearing Hindi stimulus. Total administration: 32 written minutes plus 8
speaking minutes. Remove all visible models before writing begins.

## Reading — 10 minutes

Choose the English meaning or situation.

1. **नाम** — A name / B tea / C bus
2. **पानी** — A school / B water / C home
3. **चाय** — A tea / B no / C Hindi
4. **घर** — A bus / B home / C thanks
5. **बस** — A water / B name / C bus
6. **स्कूल** — A school / B tea / C yes
7. **नमस्ते** — A greeting / B refusal / C request for water
8. **धन्यवाद** — A thanks / B name question / C goodbye
9. **कृपया बैठिए।** — A Please sit. / B Please speak. / C Please leave.
10. **फिर मिलेंगे।** — A See you again. / B I am fine. / C What is your name?
11. **मेरा नाम मीरा है।** — A The name is Mira. / B The name is Tara. / C The city is Mira.
12. **मैं दिल्ली से हूँ।** — A I am from Delhi. / B I am in Delhi. / C I speak Delhi.
13. **मैं ठीक हूँ।** — A I am fine. / B I am Mira. / C I am at home.
14. Form field **नाम: रवि** — A age Ravi / B name Ravi / C city Ravi

## Listening — 10 minutes

The examiner reads each numbered line twice. Pause eight seconds after each
play. The learner chooses A, B, or C from the printed choices.

1. Script: **नाम**. A name / B water / C tea
2. Script: **पानी**. A tea / B home / C water
3. Script: **चाय**. A tea / B bus / C school
4. Script: **घर**. A school / B home / C Hindi
5. Script: **हाँ**. A yes / B no / C thanks
6. Script: **नहीं**. A name / B yes / C no
7. Script: **नमस्ते।** A नमस्ते। / B पानी। / C नहीं।
8. Script: **धन्यवाद।** A मेरा नाम। / B आपका स्वागत है। / C बस।
9. Script: **आप कैसे हैं?** A मैं ठीक हूँ। / B मेरा नाम रवि है। / C पानी।
10. Script: **फिर मिलेंगे।** A नमस्ते। / B फिर मिलेंगे। / C मेरा नाम।
11. Script: **मेरा नाम सीमा है।** A name Sima / B city Sima / C language Sima
12. Script: **मैं आगरा से हूँ।** A from Agra / B going to Agra / C named Agra
13. Script: **मैं हिंदी बोलता हूँ।** A speaks Hindi / B reads a name / C wants tea
14. Script: **मैं ठीक हूँ।** A is fine / B is at school / C says no

## Writing — 12 minutes

1. Look at **नमस्ते** for five seconds. The examiner covers it. Write it once.
2. Look at **नाम** for five seconds. The examiner covers it. Write it once.
3. Dictation, twice: **मैं**.
4. Dictation, twice: **आप**.
5. Dictation, twice: **हिंदी**.
6. Dictation, twice: **धन्यवाद**.
7. Write your own name in Devanagari after **नाम:**. No answer model is shown.
8. Write one Hindi greeting appropriate for meeting a person. No answer model is shown.

## Speaking — 8 minutes

1. Interlocutor: **नमस्ते।** Learner returns a greeting.
2. Interlocutor: **आपका नाम क्या है?** Learner states a chosen identity.
3. Interlocutor: **आप कैसे हैं?**
4. Interlocutor: **आप कहाँ से हैं?**
5. Interlocutor: **क्या आप हिंदी बोलते हैं?**
6. Situation: you want water. Make one short polite request in Hindi.

The interlocutor may repeat each prompt once slowly. No written answer script,
romanization, dictionary, translator, or coaching is allowed.
