# അതുവരെ (atuvare) — until then

## You'll want to know: അതുവരെ
<!-- hl-knowledge: introduces=[ML-LEX-C357-PINNITU357-03]; assesses=[] -->

**അതുവരെ** — *atuvare* — "until then".

> അച്ഛൻ ആറ് മണിക്ക് വന്നു, അതുവരെ ഞങ്ങൾ കാത്തിരുന്നു.
>
> *acchan āṟŭ maṇikkŭ vannu, atuvare ñaṅṅaḷ kāttirunnu.*
>
> Father came at six, and until then we waited.

Built like ഇതുവരെ, so far: അത്, that, + വരെ, up to.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**അതുവരെ** (*atuvare*) is native Dravidian: അത് (*atŭ*), "that", and വരെ, "up to, until". It mirrors ഇതുവരെ, "until now", with the far "that" (DEDR 1) in place of the near "this".
