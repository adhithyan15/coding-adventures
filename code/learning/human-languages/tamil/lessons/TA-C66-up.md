# மேலே (mēlē) — up, above

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TA-LEX-C65-DOING-05] -->

[PAUSE 2s] One word back from last chapter first: what did *mūḍu* mean?

## You'll want to know: மேலே
<!-- hl-knowledge: introduces=[TA-LEX-C66-WHICHWAY-01]; assesses=[] -->

**மேலே** (*mēlē*) — "up, above".

It sits in front of the verb, where every Tamil adverb sits: **மேலே பார்**
(*mēlē pār*) — "look up". You already have பார் from the seeing lesson, so this
is one new word buying you a whole instruction.

Underneath it is **மேல்** (*mēl*), the bare word for "the top", a native
Dravidian positional word. Kannada says **ಮೇಲೆ** (*mēle*) for the same idea, and
it is the same word, worn the same way.

## Why it's said this way: you have met this ending before
<!-- hl-knowledge: introduces=[]; assesses=[TA-LEX-C66-WHICHWAY-01] -->

Listen to the end of the word, and then say the two pointing words you already
have. **இங்கே** (*iṅgē*, "here") and **அங்கே** (*aṅgē*, "there") end the same
way. That **-ஏ**
is Tamil's way of turning a bare place-word into "**at** that place, **to** that
place" — and **மேல்** plus **-ஏ** is **மேலே**, "at the top, upward".

So this is not a new machine. It is a machine you already own, running on a new
word.
