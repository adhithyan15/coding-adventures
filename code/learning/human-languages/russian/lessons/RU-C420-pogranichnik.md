## You'll want to know: пограничник
<!-- hl-knowledge: introduces=[RU-LEX-C420-DOSMOTR-03]; assesses=[] -->

**пограничник** (*pograníchnik*) — "a border guard".

> Пограничник долго проверял мой паспорт.
>
> *Pograníchnik dólgo proveryál moy pásport.*
>
> The border guard checked my passport for a long time.

Masculine. Built on *граница* — a border.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*пограничник* is built on *пограничный* 'of the border', from *граница* 'a border', which is inherited from Proto-Slavic *granica* (EtymDB).
