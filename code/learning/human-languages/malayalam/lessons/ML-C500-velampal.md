# വേഴാമ്പൽ (vēḻāmpal) — a hornbill

## You'll want to know: വേഴാമ്പൽ
<!-- hl-knowledge: introduces=[ML-LEX-C500-PAKSI500-01]; assesses=[] -->

**വേഴാമ്പൽ** — *vēḻāmpal* — "a hornbill".

> വേഴാമ്പൽ ഉയരമുള്ള മരങ്ങളിൽ താമസിക്കുന്നു.
>
> *vēḻāmpal uyaramuḷḷa maraṅṅaḷil tāmasikkunnu.*
>
> The hornbill lives in tall trees.

A big forest bird with a heavy beak; it is the state bird.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**വേഴാമ്പൽ** (*vēḻāmpal*) is a Malayalam bird name whose origin is not settled.
