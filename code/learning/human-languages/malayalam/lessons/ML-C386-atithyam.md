# ആതിഥ്യം (ātithyaṁ) — hospitality

## You'll want to know: ആതിഥ്യം
<!-- hl-knowledge: introduces=[ML-LEX-C386-ATHITHEYAN386-02]; assesses=[] -->

**ആതിഥ്യം** — *ātithyaṁ* — "hospitality".

> അവരുടെ ആതിഥ്യം ഞങ്ങൾ ഒരിക്കലും മറക്കില്ല.
>
> *avaruṭe ātithyaṁ ñaṅṅaḷ orikkaluṁ maṟakkilla.*
>
> We will never forget their hospitality.

Also from അതിഥി: what a good host gives.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ആതിഥ്യം** (*ātithyaṁ*) is borrowed from Sanskrit *ātithya*, "proper for a guest" (Monier-Williams), the noun of *atithi*, "a guest".
