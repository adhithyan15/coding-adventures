# தள்ளாடு (taḷḷāṭu) — to stagger; to totter

## You'll want to know: தள்ளாடு
<!-- hl-knowledge: introduces=[TA-LEX-C401-PERUNTU401-04]; assesses=[] -->

**தள்ளாடு** — *taḷḷāṭu* — "to stagger; to totter".

> பேருந்து திடீரென்று நின்றதால் நான் தள்ளாடினேன்.
>
> *pēruntu tiṭīreṉṟu niṉṟatāl nāṉ taḷḷāṭiṉēṉ.*
>
> I staggered because the bus stopped suddenly.

Past (I …): தள்ளாடினேன், *taḷḷāṭiṉēṉ*.

The second part is ஆடு, to move or sway, as in நடனமாடு.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**தள்ளாடு** (*taḷḷāṭu*) is native Dravidian: DEDR 3128 lists it, "to totter", built with ஆடு, "to move, to sway".
