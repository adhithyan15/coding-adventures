## You'll want to know: जनमत
<!-- hl-knowledge: introduces=[MR-LEX-C356-LOKSHAHI356-04]; assesses=[] -->

**जनमत** — *janmat* — "public opinion".

> जनमत या निर्णयाच्या बाजूने होतं.
>
> *janmat yā nirṇayācyā bājūne hotaṁ.*
>
> Public opinion was in favour of this decision.

Neuter.

जन + मत, people + opinion; neuter, so होतं.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**जनमत** (*janmat*) is a learned compound built from Sanskrit *jana*, "people", and *mata*, "opinion" (Monier-Williams).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
