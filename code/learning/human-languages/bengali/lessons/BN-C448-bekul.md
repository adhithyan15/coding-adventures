# ব্যাকুল (bækul) — anxious with longing; eager

## You'll want to know: ব্যাকুল
<!-- hl-knowledge: introduces=[BN-LEX-C448-BIROHO448-04]; assesses=[] -->

**ব্যাকুল** — *bækul* — "anxious with longing; eager".

> ছেলের ফোনের জন্য বাবা ব্যাকুল হয়ে আছেন।
>
> *chheler phoner jônyô bābā bækul hôye āchhen.*
>
> Father is waiting anxiously for a call from his son.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ব্যাকুল** (*bækul*) is a tatsama, Sanskrit *vyākula*, "filled with" and "troubled, perplexed" (Monier-Williams).
