# شكوى (shakwā) — a complaint

## You'll want to know: شكوى
<!-- hl-knowledge: introduces=[AR-LEX-C449-SHAKWA449-01]; assesses=[] -->

**شكوى** — *shakwā* — "a complaint".

> كتب أبي شكوى إلى المدير.
>
> *kataba abī shakwā ilā al-mudīr.*
>
> My father wrote a complaint to the manager.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**شكوى** (*shakwā*) is built on the native Arabic root *sh-k-w*, "to complain" (Lane).
