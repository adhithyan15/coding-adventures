## You'll want to know: el delantero
<!-- hl-knowledge: introduces=[ES-LEX-C756-PARTIDO-01]; assesses=[] -->

**el delantero** — "the forward, the striker".

> Nuestro delantero es muy rápido.
>
> *Our striker is very fast.*

As an adjective: *la parte delantera* — the front.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*delantero* is built on *delante* "in front", which comes from Old Spanish *denante* (EtymDB), from Latin *dē*, *in* and *ante* "before".
