# ಮಾರಾಟ (mārāṭa) — a sale; selling

## You'll want to know: ಮಾರಾಟ
<!-- hl-knowledge: introduces=[KA-LEX-C467-MARUKATTE467-04]; assesses=[] -->

**ಮಾರಾಟ** — *mārāṭa* — "a sale; selling".

> ಹಬ್ಬದ ಮುಂಚೆ ಸೀರೆಗಳ ಮಾರಾಟ ಹೆಚ್ಚಾಗುತ್ತದೆ.
>
> *habbada muñce sīregaḷa mārāṭa heccāguttade.*
>
> Before a festival the sale of saris goes up.

ಮಾರಾಟಕ್ಕೆ ಇದೆ, it is for sale; ಮಾರಾಟಗಾರ, a seller.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಮಾರಾಟ** (*mārāṭa*) is native Dravidian, a noun built on *māṟu*, "to sell, to barter" (DEDR 4834).
