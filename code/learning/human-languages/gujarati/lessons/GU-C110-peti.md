## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**પેટી** (*peṭī*) is a tadbhava. CDIAL lists it under *\*peṭṭa*, one of several forms beside Sanskrit *piṭaka*, "basket, box", which it calls non-Aryan (CDIAL 8164).
