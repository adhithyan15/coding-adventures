# ബാധിക്കുക (bādhikkuka) — to affect

## You'll want to know: ബാധിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C443-PARIDHI443-01]; assesses=[] -->

**ബാധിക്കുക** — *bādhikkuka* — "to affect".

> പനി ഗ്രാമത്തിലെ പല കുട്ടികളെയും ബാധിച്ചു.
>
> *pani grāmattile pala kuṭṭikaḷeyuṁ bādhiccu.*
>
> The fever affected many children in the village.

Past: ബാധിച്ചു, *bādhiccu*.

What is affected takes -നെ. Usually something bad: an illness, a flood, a price rise.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ബാധിക്കുക** (*bādhikkuka*) is built from the Sanskrit root *bādh*, "to press hard, to harass", whose noun *bādha* is "affliction, hurt, damage" (Monier-Williams), with the Malayalam verb ending -ിക്കുക.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
