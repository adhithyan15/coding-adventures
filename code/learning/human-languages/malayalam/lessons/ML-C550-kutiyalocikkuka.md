# കൂടിയാലോചിക്കുക (kūṭiyālōcikkuka) — to consult; to confer

## You'll want to know: കൂടിയാലോചിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C550-NETTAM550-04]; assesses=[] -->

**കൂടിയാലോചിക്കുക** — *kūṭiyālōcikkuka* — "to consult; to confer".

> തീരുമാനം എടുക്കും മുൻപ് മാനേജർ ടീമുമായി കൂടിയാലോചിച്ചു.
>
> *tīrumānaṁ eṭukkuṁ munpŭ mānējar ṭīmumāyi kūṭiyālōciccu.*
>
> Before deciding, the manager consulted the team.

Past: കൂടിയാലോചിച്ചു, *kūṭiyālōciccu*.

കൂടി together + ആലോചിക്കുക to think over. The noun is കൂടിയാലോചന.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**കൂടിയാലോചിക്കുക** (*kūṭiyālōcikkuka*) is a Malayalam compound built from കൂടി, "together", which is native (DEDR 1882), and ആലോചിക്കുക, from Sanskrit *ālocana*, "considering, reflection" (Monier-Williams).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
