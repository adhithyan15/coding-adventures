# ਮੋਕਲਾ (moklā) — roomy; loose-fitting

## You'll want to know: ਮੋਕਲਾ
<!-- hl-knowledge: introduces=[PA-LEX-C230-DIN230-01]; assesses=[] -->

**ਮੋਕਲਾ** — *moklā* — "roomy; loose-fitting".

> ਇਹ ਕੁੜਤਾ ਮੋਕਲਾ ਹੈ ਪਰ ਉਹ ਕਮੀਜ਼ ਭੀੜੀ ਹੈ।
>
> *eh kuṛtā moklā hai par oh kamīz bhīṛī hai.*
>
> This kurta is roomy, but that shirt is tight.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ਮੋਕਲਾ** (*moklā*) is inherited from a reconstructed *\*mukna*, "loosed"; CDIAL lists Punjabi *moklā*, "loose" (CDIAL 10157).
