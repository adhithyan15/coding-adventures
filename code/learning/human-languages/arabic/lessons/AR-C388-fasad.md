## You'll want to know: فساد
<!-- hl-knowledge: introduces=[AR-LEX-C388-FASAD388-01]; assesses=[] -->

**فساد** — *fasād* — "corruption".

> تحدث الناس كثيرا عن الفساد.
>
> *taḥaddatha an-nās kathīran ʿan al-fasād.*
>
> People talked a lot about corruption.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**فساد** (*fasād*) is built on the native Arabic root *f-s-d*, "to go bad, to be corrupt" (Lane). *Fasād* is going bad: decay, and so corruption.
