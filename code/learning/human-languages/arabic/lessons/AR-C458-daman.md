# ضمان (ḍamān) — a guarantee; a warranty

## You'll want to know: ضمان
<!-- hl-knowledge: introduces=[AR-LEX-C458-DAMAN458-01]; assesses=[] -->

**ضمان** — *ḍamān* — "a guarantee; a warranty".

> للجهاز ضمان لمدة سنة.
>
> *li-l-jihāz ḍamān li-muddat sana.*
>
> The device has a one-year guarantee.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ضمان** (*ḍamān*) is built on the native Arabic root *ḍ-m-n*, "to be answerable for" (Lane).
