## You'll want to know: o roupão
<!-- hl-knowledge: introduces=[PT-LEX-C429-QUARTO-05]; assesses=[] -->

**o roupão** — "the bathrobe, the dressing gown".

> No hotel há um roupão branco para cada hóspede.
>
> *At the hotel there is a white bathrobe for each guest.*

Built on *a roupa* with *-ão*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*roupão* is built on *roupa* 'clothes' with the big-size ending *-ão*; *roupa* comes from Gothic *raupa* (EtymDB).
