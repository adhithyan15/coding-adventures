## You'll want to know: le cambrioleur
<!-- hl-knowledge: introduces=[FR-LEX-C287-CAMBRIOLAGE-02]; assesses=[] -->

**le cambrioleur** — "the burglar".

> Le cambrioleur est entré par la fenêtre.
>
> *The burglar got in through the window.*

Feminine: *la cambrioleuse*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*cambrioleur* is built on *cambrioler* "to burgle" with the agent suffix *-eur* (EtymDB); the verb goes back to slang *cambriole* "a small room".
