# సంక్షేమం (saṅkṣēmaṁ) — welfare

## You'll want to know: సంక్షేమం
<!-- hl-knowledge: introduces=[TE-LEX-C403-PARIPALANA403-05]; assesses=[] -->

**సంక్షేమం** — *saṅkṣēmaṁ* — "welfare".

> పిల్లల సంక్షేమం కోసం ఆ సంస్థ పని చేస్తుంది.
>
> *pillala saṅkṣēmaṁ kōsaṁ ā saṁstha pani cēstundi.*
>
> That organisation works for the welfare of children.

సం-, wholly, + క్షేమం, well-being, which you know.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**సంక్షేమం** (*saṅkṣēmaṁ*) is built from Sanskrit *saṁ-*, "together, wholly", and *kṣema*, "ease, security, prosperity" (Monier-Williams), the word Telugu has as క్షేమం.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
