# পুঁজি (pũji) — capital (money to start a business)

## You'll want to know: পুঁজি
<!-- hl-knowledge: introduces=[BN-LEX-C498-UDYOG498-03]; assesses=[] -->

**পুঁজি** — *pũji* — "capital (money to start a business)".

> নতুন দোকানের জন্য আমার পুঁজি দরকার।
>
> *Nôtun dokāner jônyô āmār pũji dôrkār.*
>
> I need capital for the new shop.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**পুঁজি** (*pũji*) is a tadbhava: CDIAL lists Bengali *pũji*, "a heap, capital", under Sanskrit *puñja*, "a heap" (CDIAL 8251).
