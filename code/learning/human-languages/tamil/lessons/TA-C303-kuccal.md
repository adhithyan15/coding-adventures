# கூச்சல் (kūccal) — an uproar; an outcry

## You'll want to know: கூச்சல்
<!-- hl-knowledge: introduces=[TA-LEX-C303-KOOCHAL303-01]; assesses=[] -->

**கூச்சல்** — *kūccal* — "an uproar; an outcry".

> வெளியே பெரிய கூச்சல் கேட்டது.
>
> *veḷiyē periya kūccal kēṭṭatu.*
>
> A loud uproar was heard outside.

கூச்சல் போடு, to make a racket.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**கூச்சல்** (*kūccal*) is native Dravidian (DEDR 1868), from the cry கூ, as in a call or a shout.
