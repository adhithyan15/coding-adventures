## You'll want to know: a encenação
<!-- hl-knowledge: introduces=[PT-LEX-C520-TEATRO-03]; assesses=[] -->

**a encenação** — "staging, production".

> A encenação foi moderna e original.
>
> *The staging was modern and original.*

Built on *encenar*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*encenação* is built on *encenar* "to stage", from *cena* "a scene", which goes back through Latin *scaena* to Greek *skēnḗ* (EtymDB).
