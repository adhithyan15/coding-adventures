# उलटो (ulṭo) — reversed; the wrong way round

## You'll want to know: उलटो
<!-- hl-knowledge: introduces=[MW-LEX-C202-WAY202-03]; assesses=[] -->

**उलटो** — *ulṭo* — "reversed; the wrong way round".

> म्हारो कुरतो उलटो है।
>
> *mhāro kurto ulṭo hai.*
>
> My kurta is inside out.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**उलटो** (*ulṭo*) is inherited from a reconstructed *\*ullaṭati*, "turns over"; CDIAL lists Old Marwari *ulaṭo*, "reversed" (CDIAL 2368).
