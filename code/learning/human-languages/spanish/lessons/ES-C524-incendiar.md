## You'll want to know: incendiar
<!-- hl-knowledge: introduces=[ES-LEX-C524-FUEGO-02]; assesses=[] -->

**incendiar** — "to set on fire".

> Alguien incendió el coche de noche.
>
> *Someone set the car on fire at night.*

*Incendiarse* is to catch fire: *La casa se incendió.*

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*incendiar* is built on *incendio* 'a fire', a learned word from Latin *incendium*, built on *incendere* 'to set on fire' (Lewis & Short).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling, explaining and describing at B1.
