# ನಿಷ್ಠುರ (niṣṭhura) — harshly frank; unsparing

## You'll want to know: ನಿಷ್ಠುರ
<!-- hl-knowledge: introduces=[KA-LEX-C501-SAUMYA501-04]; assesses=[] -->

**ನಿಷ್ಠುರ** — *niṣṭhura* — "harshly frank; unsparing".

> ಅವನು ನಿಷ್ಠುರವಾಗಿ ಸತ್ಯ ಹೇಳಿದನು.
>
> *avanu niṣṭhuravāgi satya hēḷidanu.*
>
> He told the truth bluntly.

ನಿಷ್ಠುರ ಕಟ್ಟಿಕೊ, to make enemies by plain speaking.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ನಿಷ್ಠುರ** (*niṣṭhura*) is borrowed from Sanskrit *niṣṭhura*, "hard, cruel" (CDIAL 7505); Kannada uses it most for hard, frank words.
