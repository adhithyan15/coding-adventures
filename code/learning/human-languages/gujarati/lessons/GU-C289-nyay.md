# ન્યાય (nyāy) — justice

## You'll want to know: ન્યાય
<!-- hl-knowledge: introduces=[GU-LEX-C289-ADALAT289-03]; assesses=[] -->

**ન્યાય** — *nyāy* — "justice".

> અદાલતે ગરીબ માણસને ન્યાય આપ્યો.
>
> *adālte garīb māṇasne nyāy āpyo.*
>
> The court gave the poor man justice.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ન્યાય** (*nyāy*) is a tatsama, Sanskrit *nyāya*, "rule, manner, method" (CDIAL 7614); in Gujarati it is above all what is fair and right, the thing a court gives.
