# ಬಾಂಧವ್ಯ (bāndhavya) — a bond; close ties

## You'll want to know: ಬಾಂಧವ್ಯ
<!-- hl-knowledge: introduces=[KA-LEX-C528-SNEHA528-02]; assesses=[] -->

**ಬಾಂಧವ್ಯ** — *bāndhavya* — "a bond; close ties".

> ಎರಡು ಕುಟುಂಬಗಳ ನಡುವೆ ಒಳ್ಳೆಯ ಬಾಂಧವ್ಯ ಇದೆ.
>
> *eraḍu kuṭumbagaḷa naḍuve oḷḷeya bāndhavya ide.*
>
> There is a good bond between the two families.

Related to ಬಂಧು, kin.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಬಾಂಧವ್ಯ** (*bāndhavya*) is a learned abstract noun built on Sanskrit *bāndhava*, "kinsman" (CDIAL 9208): the state of being bound as kin.
