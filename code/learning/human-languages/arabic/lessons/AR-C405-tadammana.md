# تضمن (taḍammana) — to contain

## You'll want to know: تضمن
<!-- hl-knowledge: introduces=[AR-LEX-C405-ISTITHNA405-04]; assesses=[] -->

**تضمن** — *taḍammana* — "to contain".

> يتضمن الكتاب صورا جميلة.
>
> *yataḍammanu al-kitāb ṣuwaran jamīla.*
>
> The book contains beautiful pictures.

Present: يتضمن, *yataḍamman*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**تضمن** (*taḍammana*) is built on the native Arabic root *ḍ-m-n*, "to be surety for" (Lane). It is Form V, to take a thing within oneself: to contain.
