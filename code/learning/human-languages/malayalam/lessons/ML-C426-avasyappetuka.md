# ആവശ്യപ്പെടുക (āvaśyappeṭuka) — to demand; to request

## You'll want to know: ആവശ്യപ്പെടുക
<!-- hl-knowledge: introduces=[ML-LEX-C426-NIVEDANAM426-02]; assesses=[] -->

**ആവശ്യപ്പെടുക** — *āvaśyappeṭuka* — "to demand; to request".

> തൊഴിലാളികൾ കൂടുതൽ ശമ്പളം ആവശ്യപ്പെട്ടു.
>
> *toḻilāḷikaḷ kūṭutal śampaḷaṁ āvaśyappeṭṭu.*
>
> The workers demanded more pay.

Past: ആവശ്യപ്പെട്ടു, *āvaśyappeṭṭu*.

Built on ആവശ്യം, a need, with -പ്പെടുക.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ആവശ്യപ്പെടുക** (*āvaśyappeṭuka*) is built on ആവശ്യം, "a need", from Sanskrit *āvaśyaka*, "necessary" (Monier-Williams), with -പ്പെടുക from native പെടുക (DEDR 3853): to declare a thing needed.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
