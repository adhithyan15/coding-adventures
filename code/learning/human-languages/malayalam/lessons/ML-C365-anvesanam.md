# അന്വേഷണം (anvēṣaṇaṁ) — an investigation; an inquiry

[PAUSE 2s] Before the new one: say the Malayalam for a complaint, then the Malayalam for a criminal.

## You'll want to know: അന്വേഷണം
<!-- hl-knowledge: introduces=[ML-LEX-C365-POLICE365-03]; assesses=[] -->

**അന്വേഷണം** — *anvēṣaṇaṁ* — "an investigation; an inquiry".

> പോലീസ് ആ മോഷണത്തെക്കുറിച്ച് അന്വേഷണം തുടങ്ങി.
>
> *pōlīsŭ ā mōṣaṇattekkuṟiccŭ anvēṣaṇaṁ tuṭaṅṅi.*
>
> The police started an investigation into the theft.

An investigation is held: അന്വേഷണം നടത്തുക.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**അന്വേഷണം** (*anvēṣaṇaṁ*) is borrowed from Sanskrit *anveṣaṇa*, "seeking for, searching, investigating" (Monier-Williams).

## What you've built

One more word for telling what happened.
