# ફરજિયાત (pharjiyāt) — compulsory

## You'll want to know: ફરજિયાત
<!-- hl-knowledge: introduces=[GU-LEX-C375-JARURI375-03]; assesses=[] -->

**ફરજિયાત** — *pharjiyāt* — "compulsory".

> જો તમે આ શાળામાં ભણશો તો ગણવેશ ફરજિયાત છે.
>
> *jo tame ā śāḷāmā̃ bhaṇśo to gaṇveś pharjiyāt che.*
>
> If you study at this school, the uniform is compulsory.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ફરજિયાત** (*pharjiyāt*) is built on **ફરજ** (*pharaj*), "a duty", usually traced to Arabic *farḍ*, "obligation", with the ending *-iyāt*: what duty requires.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
