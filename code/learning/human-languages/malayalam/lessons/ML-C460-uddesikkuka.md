# ഉദ്ദേശിക്കുക (uddēśikkuka) — to intend; to mean

[PAUSE 2s] Before the new one: say the Malayalam for global, then the Malayalam for practical.

## You'll want to know: ഉദ്ദേശിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C460-AGOLAM460-04]; assesses=[] -->

**ഉദ്ദേശിക്കുക** — *uddēśikkuka* — "to intend; to mean".

> ഞാൻ നിന്നെ വേദനിപ്പിക്കാൻ ഉദ്ദേശിച്ചില്ല.
>
> *ñān ninne vēdanippikkān uddēśiccilla.*
>
> I did not mean to hurt you.

Past: ഉദ്ദേശിച്ചു, *uddēśiccu*.

What is meant takes -ആൻ. ഉദ്ദേശ്യം, a purpose, is the same family.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ഉദ്ദേശിക്കുക** (*uddēśikkuka*) is built from Sanskrit *uddeśa*, "pointing to, direction, aim" (Monier-Williams), with the Malayalam verb ending -ിക്കുക.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
