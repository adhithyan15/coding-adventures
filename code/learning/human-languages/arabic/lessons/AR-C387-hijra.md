## You'll want to know: هجرة
<!-- hl-knowledge: introduces=[AR-LEX-C387-UMMA387-01]; assesses=[] -->

**هجرة** — *hijra* — "migration".

> زادت الهجرة إلى المدن.
>
> *zādat al-hijra ilā al-mudun.*
>
> Migration to the cities increased.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**هجرة** (*hijra*) is built on the native Arabic root *h-j-r*, "to leave, to cut off" (Lane). *Hijra* is leaving one's land for another: migration.
