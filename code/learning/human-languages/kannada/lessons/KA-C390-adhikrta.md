# ಅಧಿಕೃತ (adhikṛta) — official

## You'll want to know: ಅಧಿಕೃತ
<!-- hl-knowledge: introduces=[KA-LEX-C390-KANUNU390-04]; assesses=[] -->

**ಅಧಿಕೃತ** — *adhikṛta* — "official".

> ಇದು ಅಧಿಕೃತ ಸುದ್ದಿ ಅಲ್ಲ.
>
> *idu adhikṛta suddi alla.*
>
> This is not official news.

ಅಧಿಕೃತವಾಗಿ, officially.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ಅಧಿಕೃತ** (*adhikṛta*) is borrowed from Sanskrit *adhikṛta*, "placed at the head of, appointed" (Monier-Williams).
