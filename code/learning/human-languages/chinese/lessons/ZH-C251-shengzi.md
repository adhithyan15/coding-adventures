## You'll want to know: 生字
<!-- hl-knowledge: introduces=[ZH-LEX-C251-ESSAY251-04]; assesses=[] -->

**生字** — *shēngzì* — "new character; a character not yet learned".

> **这些生字我都会写** *zhèxiē shēngzì wǒ dōu huì xiě* — I can write all these new characters.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**生字** (*shēngzì*) is built from 生 and 字 'a character', both inherited from Middle Chinese, *srjaeng* and *dziH* (Guangyun, in Baxter's transcription), which glosses the first 'to grow'. Its sense 'raw, not yet known' is not given there, so how it came is not settled.
