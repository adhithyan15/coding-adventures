## You'll want to know: negativo
<!-- hl-knowledge: introduces=[ES-LEX-C584-VENTAJA-05]; assesses=[] -->

**negativo** — "negative".

> No seas tan negativo.
>
> *Do not be so negative.*

*Lo negativo* — the bad side.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*negativo* is a learned borrowing from Latin *negativus*, built on *negare* 'to deny' (EtymDB).
