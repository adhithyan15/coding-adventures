# மேலே — the same sign twice

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TA-LEX-C66-WHICHWAY-01, TA-LEX-C66-WHICHWAY-02] -->

[PAUSE 2s] Two lessons ago you learned to say *mēlē*, and *kīḻē* came between.
Now look at it on the page.

## Script you'll notice: two letters, one sign, used twice
<!-- hl-knowledge: introduces=[TA-SCRIPT-READ-MELE-01]; assesses=[TA-SCRIPT-READ-KUDI-01] -->

Like **குடி** before it, **மேலே** brings no new shape. It brings something
better: the same vowel sign riding two different letters, one after the other.

| piece | | |
|---|---|---|
| **மே** | *mē* — **ம** with the **ே** sign | **ம** from the letter-*ma* lesson; the **ே** sign from the vowel-sign lesson, and again inside *pēsu* |
| **லே** | *lē* — **ல** with the **ே** sign | **ல** from the letter-*la* lesson; the **same** **ே** again |

> **மே · லே → மேலே**

Read it once as two beats. Both beats are long, and both are long for the same
reason: the **ே** hook in front of each letter.

## Script you'll notice: the hook goes in front, the sound comes after
<!-- hl-knowledge: introduces=[]; assesses=[TA-SCRIPT-READ-MELE-01] -->

The **ே** sits to the **left** of the letter it belongs to, and is said
**after** it. **மே** is written hook-then-**ம** and read *mē*. That is not a
quirk of this word — it is how this sign has always worked, and **மேலே** shows
it twice in a row so you can watch the eye do it.
