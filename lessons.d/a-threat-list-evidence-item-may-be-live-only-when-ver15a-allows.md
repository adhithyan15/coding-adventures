# A threat-list evidence item may be live only when VER15a allows it, and reached labels come only from the row's own evidence

In the per-lane threat lists, an evidence item may be labelled `live` only when VER15a section 5.2 allows it, which is not before LGE-W1 and LGE-S3v exist; until then it is `claimed` or `tested`. A `reached` label comes only from the row's own evidence, never from a neighbouring row or the registry default. Reviews downgraded live to claimed for Rust and re-labelled several `tested` rows that rested on corpus claims; check labels against the section before folding a lane list.
