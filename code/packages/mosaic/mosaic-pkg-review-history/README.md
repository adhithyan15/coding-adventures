# mosaic-pkg-review-history

Reusable Mosaic controls for Anki-style review history summaries.

Engram owns the Rust review log and summary calculations. This package owns the
portable UI contract for review counts, accuracy, per-rating totals, and
first/last review labels so HTML, React, Electron, SwiftUI, Qt, XAML, and
Flutter shells can share one history surface.
