## Unreleased - [D73] chunk `calls` sum, R106 `Bytes<N>` length, R108 consumer-side `types` checks (CV2-F17, VER04r 16.21)

- **[D73]: `calls` must sum to `expected_calls`.** `conformance.check_chunk_file` (the one reader behind `derive_chunk`, `v2-chunk` and the kit build)
  now refuses `chunk-file` a file whose chunks' `calls` do not sum to the row's `expected_calls`, even when `chunks_sha256` was recomputed for the altered
  file (the per-chunk digests do not cover `calls`). `verify-v2` is unaffected: it recomputes every chunk line and compares the file byte for byte. No
  committed outcome moves: the 108 committed suites sum correctly, and the 74 committed `v2-chunk` cases are unchanged (`make_conformance.py --check`:
  958 cases in 7 files identical).
- **R106: a `Bytes<N>` value of another length is `W0701`.** `stream.make_encoder` for `Bytes<N>` (a reference suite's expected stream at any depth) and
  `corpus_v2._check_value` (an example's arguments and expected value) refuse `generation` / `W0701: a stream value does not have the declared Bytes<N>
  length`. `N` is read after static-width substitution; plain `Bytes` and a still-named width have no length to check, and an omitted example is never
  evaluated this far. The examples rows and TFV of all adopter specs are identical on base and head.
- **R108: consumer-side `types` checks.** `conformance.check_type_table(types, code)` (iterative, so a hostile table cannot recurse) refuses a recursive or
  mutually recursive record or variant, a repeated field or constructor name, and a field whose type is not declared. `derive_value` refuses with `type`
  (after `malformed-json`, before the type or a value is read) and `check_corpus_and_row` with `corpus` (before any descriptor is read). Two crashes become
  clean refusals: a record containing itself through `Option` ended `derive_value` in `RecursionError`, and an undeclared field type in a record the value
  does not use raised an uncaught `Refused` from `_encoder_spec`. `v2-domain` has no `types` field; `v2-ir` and `v2-fault` (`ill-typed`) are not changed.
- Tests: `tests/test_cv2_16_21_checks.py`. No committed fixture, dump, corpus or kit byte moves.
