## You'll want to know: むしろ
<!-- hl-knowledge: introduces=[JA-LEX-C321-ZETTAI321-04]; assesses=[] -->

**むしろ** — *mushiro* — "rather; if anything".

> **でんしゃより むしろ じてんしゃが はやいと おもいます。** — *densha yori mushiro jitensha ga hayai to omoimasu* — "I think a bicycle is, if anything, faster than the train."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**むしろ** (*mushiro*) is a native Japanese word (wago), inherited rather than borrowed from Chinese, and its older origin is not settled. JMdict notes that it is usually written in kana (JMdict).
