## You'll want to know: জেনারেটর
<!-- hl-knowledge: introduces=[BN-LEX-C504-JONTRO504-03]; assesses=[] -->

**জেনারেটর** — *jenāreṭôr* — "a generator".

> বিদ্যুৎ গেলে আমরা জেনারেটর চালাই।
>
> *Bidyut gele āmrā jenāreṭôr chālāi.*
>
> When the power goes, we run the generator.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**জেনারেটর** (*jenāreṭôr*) is borrowed from English *generator*.
