# மருமகன் (marumakaṉ) — a son-in-law

## You'll want to know: மருமகன்
<!-- hl-knowledge: introduces=[TA-LEX-C102-INLAWS-05]; assesses=[] -->

**மருமகன்** (*marumakaṉ*) — "a son-in-law".

**மகன்** is "son"; the same **மரு-** makes him family by marriage.
