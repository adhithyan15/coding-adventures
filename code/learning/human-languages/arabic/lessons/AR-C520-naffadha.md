## You'll want to know: نفذ
<!-- hl-knowledge: introduces=[AR-LEX-C520-DAWAM520-05]; assesses=[] -->

**نفذ** — *naffadha* — "to carry out".

> نفذ العمال الخطة بسرعة.
>
> *naffadha al-ʿummāl al-khuṭṭa bi-surʿa.*
>
> The workers carried out the plan quickly.

Present: ينفذ, *yunaffidh*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**نفذ** (*naffadha*) is built on the native Arabic root *n-f-dh*, "to pass through, to go through" (Lane). Form II naffadha is to make a plan go through.
