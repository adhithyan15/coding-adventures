## You'll want to know: آغاز
<!-- hl-knowledge: introduces=[UR-LEX-C544-AGHAZ544-01]; assesses=[] -->

**آغاز** — *āghāz* — "a beginning".

> اگر آغاز اچھا ہوا تو آخر بھی اچھا ہو گا۔
>
> *agar āghāz achchhā huā to ākhir bhī achchhā ho gā.*
>
> If it starts well, it will end well too.

Masculine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**آغاز** (*āghāz*) is usually traced to Persian *āghāz*, "a beginning".
