## You'll want to know: generar
<!-- hl-knowledge: introduces=[ES-LEX-C583-INFLUYE-05]; assesses=[] -->

**generar** — "to generate, to create".

> La nueva fábrica genera empleo.
>
> *The new factory creates jobs.*

Common in news: *generar dinero, generar problemas*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*generar* is a learned borrowing from Latin *generare* 'to beget, to produce', built on *genus* 'birth, kind' (EtymDB).
