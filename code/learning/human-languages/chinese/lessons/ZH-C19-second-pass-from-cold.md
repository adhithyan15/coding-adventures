# From cold, eight chapters on

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ZH-DIALOGUE-GREET] -->

from memory. If it came back without effort, that is the point of this
page; if it did not, that is the point of this page.

## You'll want to know: what a second pass is for
<!-- hl-knowledge: introduces=[]; assesses=[ZH-DIALOGUE-GREET, ZH-DIALOGUE-NEGATE, ZH-DIALOGUE-IDENTIFY, ZH-DIALOGUE-PART] -->

The first four exchanges were practised once, in the chapter that taught them,
and not since. That is long enough ago to be a real test rather than a
rehearsal:

| | |
|---|---|
| greet | both voices, 你好 |
| negate | answering that it is not so |
| identify | answering that it is |
| part | 再见 |

Retrieval after a gap is what makes something stay. Running them again the week
you learned them proves only that you had not yet forgotten.

## Script and tone, the two that were taught once
<!-- hl-knowledge: introduces=[]; assesses=[ZH-SCRIPT-HAO-BUILD-01, ZH-LEX-HAO-FOND] -->

> 女 + 子 → 好

Build **好** from its two halves without looking, then say it in both tones —
*hǎo*, good, and *hào*, to be fond of. Two words, one set of six strokes, and
the only thing separating them is the tone.
