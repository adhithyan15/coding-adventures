## You'll want to know: সংখ্যা
<!-- hl-knowledge: introduces=[BN-LEX-C300-PATHOK300-05]; assesses=[] -->

**সংখ্যা** — *sôngkhyā* — "an issue (of a paper); a number".

> পত্রিকার নতুন সংখ্যায় একটা লম্বা গল্প আছে।
>
> *pôtrikār nôtun sôngkhyāy ekṭā lômbā gôlpo āchhe.*
>
> The new issue of the magazine has a long story in it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**সংখ্যা** (*sôngkhyā*) is Sanskrit *saṃkhyā*, 'a number, a reckoning' (Monier-Williams); a magazine's issues are counted, so each is a সংখ্যা.
