# び — ひ, voiced to bi

## Script — the change
<!-- hl-knowledge: introduces=[JA-SCRIPT-BI-01]; assesses=[JA-SCRIPT-HI-01, JA-SCRIPT-DAKUTEN-01] -->

> **ひ** *hi* + **゛** → **び** *bi*

Write **ひ** in full, in the order you learned it. Then add the two short
strokes of the voicing mark at the upper right, beside the high right end,
the left one first.

The *h* row voices to *b* here too. With **び**, you write all five:
**ば**, **び**, **ぶ**, **べ** and **ぼ**.

With a small **ょ** and **ういん** after it, you can now write the word from the
last lesson: **びょういん**, *byōin*, a hospital.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[JA-SCRIPT-BI-01, JA-SCRIPT-HI-01, JA-SCRIPT-DAKUTEN-01, JA-LEX-ANCHOR-BYOUIN] -->

1. Write **ひ**, then **び**, and say *hi*, *bi*.
2. Write **ば び ぶ べ ぼ** in a row, and say it.
3. Write **びょういん** from memory and say *byōin*.
