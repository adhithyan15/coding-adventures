## You'll want to know: простыня
<!-- hl-knowledge: introduces=[RU-LEX-C430-POSTEL-02]; assesses=[] -->

**простыня** (*prostynyá*) — "a sheet (on a bed)".

> В шкафу лежат чистые простыни.
>
> *V shkafú lezhát chístyye próstyni.*
>
> There are clean sheets in the wardrobe.

Feminine; plural *простыни*, genitive plural *простынь*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*простыня* is usually linked with *простой* 'plain, simple': a plain piece of cloth. EtymDB does not list the word, so the line is hedged.
