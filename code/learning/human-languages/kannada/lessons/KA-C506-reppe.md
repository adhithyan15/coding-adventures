# ರೆಪ್ಪೆ (reppe) — an eyelid; an eyelash

## You'll want to know: ರೆಪ್ಪೆ
<!-- hl-knowledge: introduces=[KA-LEX-C506-NIDDE506-05]; assesses=[] -->

**ರೆಪ್ಪೆ** — *reppe* — "an eyelid; an eyelash".

> ಮಗುವಿನ ರೆಪ್ಪೆಗಳು ನಿಧಾನವಾಗಿ ಮುಚ್ಚಿದವು.
>
> *maguvina reppegaḷu nidhānavāgi muccidavu.*
>
> The baby's eyelids slowly closed.

Plural: ರೆಪ್ಪೆಗಳು, *reppegaḷu*.

ಕಣ್ಣುರೆಪ್ಪೆ is the full form.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ರೆಪ್ಪೆ** (*reppe*) is native Dravidian: DEDR 5169 lists Kannada *ṟeppe*, "eyelid", beside Tamil *imai* forms and Telugu *ṟeppa*.
