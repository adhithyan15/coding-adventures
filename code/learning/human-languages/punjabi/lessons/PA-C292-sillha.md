# ਸਿੱਲ੍ਹਾ (sillhā) — damp

## You'll want to know: ਸਿੱਲ੍ਹਾ
<!-- hl-knowledge: introduces=[PA-LEX-C292-DAMP292-01]; assesses=[] -->

**ਸਿੱਲ੍ਹਾ** — *sillhā* — "damp".

> ਬਰਸਾਤ ਵਿੱਚ ਕੰਧਾਂ ਸਿੱਲ੍ਹੀਆਂ ਹੁੰਦੀਆਂ ਹਨ।
>
> *barsāt vich kandhāṁ sillhīāṁ hundīāṁ han.*
>
> In the rainy season the walls are damp.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ਸਿੱਲ੍ਹਾ** (*sillhā*) is inherited from Sanskrit *śītala*, "cold"; CDIAL lists Punjabi *sillhā*, "damp", under it (CDIAL 12487).
