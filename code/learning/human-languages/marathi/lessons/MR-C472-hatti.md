## You'll want to know: हट्टी
<!-- hl-knowledge: introduces=[MR-LEX-C472-HATTI472-01]; assesses=[] -->

**हट्टी** — *haṭṭī* — "stubborn".

> हट्टी बाळ खेळण्यासाठी रडत राहिलं.
>
> *haṭṭī bāḷ kheḷṇyāsāṭhī raḍat rāhilaṁ.*
>
> The stubborn baby kept crying for the toy.

From हट्ट, insistence: हट्ट करणे, to insist like a child. Unchanging.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**हट्टी** (*haṭṭī*) is a Marathi adjective built on हट्ट, "insistence", which goes back to Sanskrit *haṭha*, "force; obstinacy" (Monier-Williams).
