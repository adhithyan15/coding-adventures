## You'll want to know: كهرباء
<!-- hl-knowledge: introduces=[AR-LEX-C444-KAHRABA444-01]; assesses=[] -->

**كهرباء** — *kahrabāʾ* — "electricity".

> تعمل الثلاجة بالكهرباء.
>
> *taʿmalu ath-thallāja bi-l-kahrabāʾ.*
>
> The fridge runs on electricity.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**كهرباء** (*kahrabāʾ*) goes back to Persian *kahrubā*, "amber" (EtymDB), a name usually read as "straw-robber", since rubbed amber draws straw to it; the old name passed to electricity.
