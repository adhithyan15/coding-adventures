5 lessons. All 5 can be done entirely by ear.


Lesson 1 of 5.
ಮೈತ್ರಿ (maitri) — an alliance; friendship.

Warm-up.
[pause 2 seconds]
Before the new one: say the Kannada for to coordinate, then the Kannada for goodwill.

You'll want to know: ಮೈತ್ರಿ.
ಮೈತ್ರಿ — maitri — "an alliance; friendship".
ಎರಡು ಊರುಗಳ ನಡುವೆ ಹಳೆಯ ಮೈತ್ರಿ ಇದೆ. eraḍu ūrugaḷa naḍuve haḷeya maitri ide. There is an old friendship between the two towns.
Formal; between groups or countries.

The word, taken apart.
ಮೈತ್ರಿ (maitri) is borrowed from Sanskrit maitrī, "friendship, goodwill" (Monier-Williams), from mitra, "a friend".

ಸ್ವಲ್ಪ ಹೊಂದಾಣಿಕೆ ಮಾಡಿಕೊಂಡರೆ ಸಮಸ್ಯೆ ಮುಗಿಯುತ್ತದೆ. svalpa hondāṇike māḍikoṇḍare samasye mugiyuttade. If we compromise a little, the problem ends.

The word, taken apart.
ಹೊಂದಾಣಿಕೆ (hondāṇike) is native Dravidian, built on hondu, "to come together, to suit" (DEDR 4541).

Past (I …): ಪ್ರಚೋದಿಸಿದೆ, pracōdiside.
The person takes -ಅನ್ನು, the aim -ಗೆ. ಪ್ರಚೋದನೆ, provocation.

The word, taken apart.
ಪ್ರಚೋದಿಸು (pracōdisu) is built on Sanskrit pracodana, "instigating, urging" (Monier-Williams), with the Kannada verb ending -isu.
