# అసాధ్యం (asādhyaṁ) — impossible

## You'll want to know: అసాధ్యం
<!-- hl-knowledge: introduces=[TE-LEX-C418-SADHYAM418-02]; assesses=[] -->

**అసాధ్యం** — *asādhyaṁ* — "impossible".

> కష్టపడితే ఏదీ అసాధ్యం కాదు.
>
> *kaṣṭapaḍitē ēdī asādhyaṁ kādu.*
>
> If you work hard, nothing is impossible.

అ-, not, + సాధ్యం, possible.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**అసాధ్యం** (*asādhyaṁ*) is borrowed from Sanskrit *asādhya*, "not to be effected or accomplished" (Monier-Williams): *a-*, "not", with *sādhya*.
