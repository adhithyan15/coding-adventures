## You'll want to know: تدريب
<!-- hl-knowledge: introduces=[AR-LEX-C397-SHAHADA397-05]; assesses=[] -->

**تدريب** — *tadrīb* — "training".

> يحتاج الموظفون الجدد إلى تدريب.
>
> *yaḥtāju al-muwaẓẓafūn al-judud ilā tadrīb.*
>
> New employees need training.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**تدريب** (*tadrīb*) is built on the native Arabic root *d-r-b*, "to be used to, practised" (Lane). *Tadrīb* is the Form II verbal noun, making someone practised: training. مدرب, a coach, is from the same root.
