# অগ্রগতি (ôgrôgôti) — progress (towards a goal)

## You'll want to know: অগ্রগতি
<!-- hl-knowledge: introduces=[BN-LEX-C377-UNNOTI377-02]; assesses=[] -->

**অগ্রগতি** — *ôgrôgôti* — "progress (towards a goal)".

> কাজের অগ্রগতি ভালো হলে আমরা আগেই শেষ করব।
>
> *kājer ôgrôgôti bhālo hôle āmrā āgei shesh kôrbô.*
>
> If the work makes good progress, we'll finish early.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**অগ্রগতি** (*ôgrôgôti*) is Sanskrit *agra*, the front, with *gati*, going (Monier-Williams): going forward. It measures how far a job has come.
