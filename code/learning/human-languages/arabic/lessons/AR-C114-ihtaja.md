## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**احتاج** (*iḥtāja*) is built on the native Arabic root *ḥ-w-j*, "to need" (Lane). *Iḥtāja* is Form VIII, "to be in need".
