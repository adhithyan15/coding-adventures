## You'll want to know: el adaptador
<!-- hl-knowledge: introduces=[ES-LEX-C773-COBERTURA-02]; assesses=[] -->

**el adaptador** — "the adapter".

> Necesito un adaptador para el enchufe del hotel.
>
> *I need an adapter for the hotel socket.*

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*adaptador* is built on *adaptar* with the ending *-dor*. *Adaptar* comes from Latin *adaptāre* 'to fit to' (EtymDB), built on *aptus* 'fitted'.
