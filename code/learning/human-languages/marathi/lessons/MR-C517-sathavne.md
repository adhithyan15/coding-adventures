## You'll want to know: साठवणे
<!-- hl-knowledge: introduces=[MR-LEX-C517-JAL517-05]; assesses=[] -->

**साठवणे** — *sāṭhavṇe* — "to store; to save up".

> मी सगळी छायाचित्रं संगणकात साठवली.
>
> *mī sagḷī chāyācitraṁ saṅgaṇakāt sāṭhavlī.*
>
> I stored all the photos on the computer.

Past, with -ने (he …): त्याने पाणी साठवलं, *tyāne pāṇī sāṭhavlaṁ*.

Where things go takes -त: संगणकात साठवणे.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**साठवणे** (*sāṭhavṇe*) is a tadbhava: CDIAL lists Marathi *sā̃ṭhaviṇẽ*, "to heap up", under Sanskrit *saṁsthāpayati*, "sets up, establishes" (CDIAL 13051).
