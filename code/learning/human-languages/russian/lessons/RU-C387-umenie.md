## You'll want to know: умение
<!-- hl-knowledge: introduces=[RU-LEX-C387-ZNANIYA-02]; assesses=[] -->

**умение** (*uméniye*) — "an ability, know-how".

> Умение слушать — редкий дар.
>
> *Uméniye slúshat — rédkiy dar.*
>
> The ability to listen is a rare gift.

Neuter. From *уметь*, to know how.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**умение** is built on *уметь* "to know how", which is usually linked with *ум* "mind", inherited from Proto-Slavic *\*umŭ* (EtymDB).
