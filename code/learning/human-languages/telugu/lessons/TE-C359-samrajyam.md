# సామ్రాజ్యం (sāmrājyaṁ) — an empire

## You'll want to know: సామ్రాజ్యం
<!-- hl-knowledge: introduces=[TE-LEX-C359-SAMRAJYAM359-01]; assesses=[] -->

**సామ్రాజ్యం** — *sāmrājyaṁ* — "an empire".

> ఆ సామ్రాజ్యం సముద్రం వరకు ఉండేది.
>
> *ā sāmrājyaṁ samudraṁ varaku uṇḍēdi.*
>
> That empire stretched as far as the sea.

Rule over all: built like రాజ్యం, a kingdom.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**సామ్రాజ్యం** (*sāmrājyaṁ*) is borrowed from Sanskrit *sāmrājya*, "complete sovereignty, an empire" (Monier-Williams).
