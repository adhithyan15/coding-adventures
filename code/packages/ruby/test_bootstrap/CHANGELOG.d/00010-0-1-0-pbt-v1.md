## 0.1.0

- Initial Ruby `test_bootstrap` gem (spec VER05h, PT-RB-PBT).
- `Prng`: `SplitMix64` with explicit 64-bit masking after every add and multiply,
  unbiased `bounded` (threshold `(2**64 - n) % n`; `bounded(1)` consumes a word),
  `bounded_big` k-word rejection above 2^64, `fnv1a64`, `sub_seed`.
- `Pbt`: generator algebra (`Gens`), integrated shrinkers with exact pbt-v1 step
  counts, the honest runner with the closed failure vocabulary and fail-closed CI
  redaction, and `Corpus`, the strict pbt-v1 corpus runner.
- Hierarchical shrink budget (`ShrinkBudget`) from the first version: one tree per
  top-level check, one Mutex at the outermost root, all-or-nothing charging,
  Fiber-storage ambient carrier.
- `CorpusJson`: strict JSON reader (depth 64, 8 MiB, 200k nodes, duplicate keys,
  invalid UTF-8, leading zeros, trailing data), strict value decoding, total
  bounded `Canon` rendering.
- `Tfv`: strict TFV v1 validator for the `corpus_reject` cases.
