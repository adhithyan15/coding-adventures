# வேலையின்மை (vēlaiyiṉmai) — unemployment

<!-- hl-knowledge: introduces=[]; assesses=[TA-LEX-C370-VARUMAI370-02, TA-LEX-C370-VARUMAI370-03] -->

[PAUSE 2s] Before the new one: say the Tamil for wealth, then the Tamil for inequality.

## You'll want to know: வேலையின்மை
<!-- hl-knowledge: introduces=[TA-LEX-C370-VARUMAI370-04]; assesses=[] -->

**வேலையின்மை** — *vēlaiyiṉmai* — "unemployment".

> இந்த ஊரில் வேலையின்மை ஒரு பெரிய பிரச்சினை.
>
> *inta ūril vēlaiyiṉmai oru periya piracciṉai.*
>
> Unemployment is a big problem in this town.

வேலை, work + இன்மை, absence: -இன்மை makes nouns of not having.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**வேலையின்மை** (*vēlaiyiṉmai*) is built from *vēlai*, "work", and native *iṉmai*, "non-existence, absence", from *il*, "not to be" (DEDR 2559).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
