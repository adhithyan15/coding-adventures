## You'll want to know: हबकणे
<!-- hl-knowledge: introduces=[MR-LEX-C452-DHAKKA452-05]; assesses=[] -->

**हबकणे** — *habakṇe* — "to be stunned".

> तो अपघात पाहून सगळे हबकले.
>
> *to apghāt pāhūn sagḷe habakle.*
>
> Everyone was stunned to see that accident.

Past (he …): तो हबकला, *to habaklā*.

हबकून जाणे, to be struck dumb with shock.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**हबकणे** (*habakṇe*) is a Marathi verb whose origin is not settled.
