## You'll want to know: camper
<!-- hl-knowledge: introduces=[FR-LEX-C425-CAMPING-04]; assesses=[] -->

**camper** — "to camp".

> L'été dernier, nous avons campé près d'une rivière.
>
> *Last summer we camped near a river.*

*Le campeur* — the camper.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*camper* is built on *camp* (EtymDB), which goes back to Latin *campus* 'field, open plain'.
