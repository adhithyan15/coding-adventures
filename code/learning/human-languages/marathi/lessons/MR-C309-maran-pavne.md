# मरण पावणे (maraṇ pāvṇe) — to pass away

## You'll want to know: मरण पावणे
<!-- hl-knowledge: introduces=[MR-LEX-C309-MRUTYU309-04]; assesses=[] -->

**मरण पावणे** — *maraṇ pāvṇe* — "to pass away".

> ते महान लेखक गतवर्षी मरण पावले.
>
> *te mahān lekhak gatvarṣī maraṇ pāvle.*
>
> That great writer passed away last year.

Past (he …): तो मरण पावला, *to maraṇ pāvlā*.

Formal, for news: X मरण पावला. मरणे is the plain verb.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**मरण पावणे** (*maraṇ pāvṇe*) is built from *maraṇ*, 'death', from Sanskrit *maraṇa*, 'dying' (CDIAL 9869), and *pāvṇe*, 'to reach, obtain': to reach death.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
