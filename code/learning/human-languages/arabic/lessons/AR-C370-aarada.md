## You'll want to know: عارض
<!-- hl-knowledge: introduces=[AR-LEX-C370-NAQD370-02]; assesses=[] -->

**عارض** — *ʿāraḍa* — "to oppose".

> عارض بعض السكان المشروع الجديد.
>
> *ʿāraḍa baʿḍ as-sukkān al-mashrūʿ al-jadīd.*
>
> Some residents opposed the new project.

Present: يعارض, *yuʿāriḍ*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**عارض** (*ʿāraḍa*) is built on the native Arabic root *ʿ-r-ḍ*, "to be broad; to lie across" (Lane). It is Form III, to set oneself across from: to oppose.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
