## You'll want to know: નકલ
<!-- hl-knowledge: introduces=[GU-LEX-C544-TAPHAVAT544-04]; assesses=[] -->

**નકલ** — *nakal* — "a copy (an imitation)".

> જો આ ચિત્ર નકલ હશે તો તેની કિંમત ઓછી હશે.
>
> *jo ā citra nakal haśe to tenī kimmat ochī haśe.*
>
> If this painting is a copy, it will be worth less.

A feminine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**નકલ** (*nakal*) is usually traced to Arabic *naql*, "a transcript, a copy", which reached Gujarati through Persian.

<!-- hl-knowledge: introduces=[]; assesses=[] -->
