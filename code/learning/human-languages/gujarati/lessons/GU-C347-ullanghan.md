# ઉલ્લંઘન (ullanghan) — a violation

## You'll want to know: ઉલ્લંઘન
<!-- hl-knowledge: introduces=[GU-LEX-C347-KAYDO347-02]; assesses=[] -->

**ઉલ્લંઘન** — *ullanghan* — "a violation".

> લાલ સિગ્નલ ઓળંગવું એ કાયદાનું ઉલ્લંઘન છે.
>
> *lāl signal oḷangvũ e kāydānũ ullanghan che.*
>
> Going through a red light is a breach of the law.

A neuter noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ઉલ્લંઘન** (*ullanghan*) is a tatsama, borrowed from Sanskrit *ullaṅghana*, "leaping over, passing beyond" (Monier-Williams): stepping over a line one should not cross.
