# બહેરું (baherũ) — deaf

## You'll want to know: બહેરું
<!-- hl-knowledge: introduces=[GU-LEX-C475-SENSES475-02]; assesses=[] -->

**બહેરું** — *baherũ* — "deaf".

> દાદા એક કાને બહેરા છે.
>
> *dādā ek kāne baherā che.*
>
> Grandfather is deaf in one ear.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**બહેરું** (*baherũ*) is inherited from Sanskrit *badhira*, "deaf"; CDIAL lists the Gujarati word (CDIAL 9130).
