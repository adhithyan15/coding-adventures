# രക്തപരിശോധന (raktapariśōdhana) — a blood test

## You'll want to know: രക്തപരിശോധന
<!-- hl-knowledge: introduces=[ML-LEX-C536-RAKTAM536-01]; assesses=[] -->

**രക്തപരിശോധന** — *raktapariśōdhana* — "a blood test".

> രാവിലെ ഒന്നും കഴിക്കാതെ രക്തപരിശോധന നടത്തണം.
>
> *rāvile onnuṁ kaḻikkāte raktapariśōdhana naṭattaṇaṁ.*
>
> The blood test has to be done in the morning before eating.

രക്തം blood + പരിശോധന a check; the verb പരിശോധിക്കുക is already familiar.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**രക്തപരിശോധന** (*raktapariśōdhana*) is a learned compound built from Sanskrit *rakta*, "red; blood" (CDIAL 10539), and *pariśodhana*, "cleaning, purifying" (Monier-Williams), which Malayalam uses for a check.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for describing what you lived and felt.
