## You'll want to know: વણાટ
<!-- hl-knowledge: introduces=[GU-LEX-C506-TANTANO506-03]; assesses=[] -->

**વણાટ** — *vaṇāṭ* — "a weave".

> આ સાડીનો વણાટ ઘણો સુંદર છે.
>
> *ā sāḍīno vaṇāṭ ghaṇo sundar che.*
>
> The weave of this sari is very beautiful.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**વણાટ** (*vaṇāṭ*) is built on *vaṇvũ*, "to weave", which CDIAL lists under *\*vināti* (CDIAL 11773), with the ending *-āṭ*: the way a cloth is woven.

## What you've built
