## You'll want to know: el votante
<!-- hl-knowledge: introduces=[ES-LEX-C602-VOTO-04]; assesses=[] -->

**el votante** — "the voter".

> Muchos votantes no fueron a votar.
>
> *Many voters did not go to vote.*

The same form for a woman: *la votante*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*votante* is built on *votar*, which comes from *voto*, a learned borrowing from Latin *votum* 'a vow' (EtymDB).
