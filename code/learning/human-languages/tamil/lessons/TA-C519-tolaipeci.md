# தொலைபேசி (tolaipēci) — a telephone; a landline

## You'll want to know: தொலைபேசி
<!-- hl-knowledge: introduces=[TA-LEX-C519-OLI519-03]; assesses=[] -->

**தொலைபேசி** — *tolaipēci* — "a telephone; a landline".

> அலுவலகத் தொலைபேசி காலை முதல் அடிக்கிறது.
>
> *aluvalakat tolaipēci kālai mutal aṭikkiṟatu.*
>
> The office telephone has been ringing since morning.

தொலை "far" + பேசி "that which speaks". A mobile is a கைப்பேசி (*kaippēci*).

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**தொலைபேசி** (*tolaipēci*) is a modern native compound: தொலை (*tolai*), "far, distant", and பேசி (*pēci*), "the speaker", from பேசு (*pēcu*), "to speak" (DEDR 4430).
