## You'll want to know: مزهرية
<!-- hl-knowledge: introduces=[AR-LEX-C550-SIYANA550-02]; assesses=[] -->

**مزهرية** — *mazhariyya* — "a vase".

> وضعت أمي الورد في المزهرية.
>
> *waḍaʿat ummī al-ward fī al-mazhariyya.*
>
> My mother put the roses in the vase.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**مزهرية** (*mazhariyya*) is built on the native Arabic root *z-h-r*, "to shine; a flower" (Lane). Zahra, a flower, which you know, is from the same root: a mazhariyya is a thing for flowers.

## What you've built
