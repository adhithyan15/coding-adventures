## You'll want to know: le criminel
<!-- hl-knowledge: introduces=[FR-LEX-C290-CRIME-02]; assesses=[] -->

**le criminel** — "the criminal".

> Le criminel a été arrêté deux jours plus tard.
>
> *The criminal was arrested two days later.*

Also an adjective: *un acte criminel*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*criminel* is a learned borrowing from Latin *crīminālis* (EtymDB), built on *crīmen* "a charge, a crime".
