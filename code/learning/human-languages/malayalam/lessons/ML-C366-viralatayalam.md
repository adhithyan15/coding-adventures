# വിരലടയാളം (viralaṭayāḷaṁ) — a fingerprint

## You'll want to know: വിരലടയാളം
<!-- hl-knowledge: introduces=[ML-LEX-C366-SUCHANA366-04]; assesses=[] -->

**വിരലടയാളം** — *viralaṭayāḷaṁ* — "a fingerprint".

> പോലീസ് വാതിലിൽ നിന്ന് വിരലടയാളം എടുത്തു.
>
> *pōlīsŭ vātilil ninnŭ viralaṭayāḷaṁ eṭuttu.*
>
> The police took fingerprints from the door.

വിരൽ, finger, + അടയാളം, a mark.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**വിരലടയാളം** (*viralaṭayāḷaṁ*) is a native Dravidian compound of വിരൽ (*viral*), "finger" (DEDR 5409), and അടയാളം (*aṭayāḷaṁ*), "a mark" (DEDR 89).
