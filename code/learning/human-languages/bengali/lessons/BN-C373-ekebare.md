# একেবারে (ekebāre) — completely; absolutely

## You'll want to know: একেবারে
<!-- hl-knowledge: introduces=[BN-LEX-C373-EKEBARE373-01]; assesses=[] -->

**একেবারে** — *ekebāre* — "completely; absolutely".

> এই রাস্তায় গেলে আমরা একেবারে ঠিক সময়ে পৌঁছাব।
>
> *ei rāstāy gele āmrā ekebāre ṭhik sômôye poũchhābô.*
>
> If we take this road, we'll arrive exactly on time.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**একেবারে** (*ekebāre*) is এক, one (CDIAL 2462), with বার, a time or turn, and the Bengali -এ: 'all at one go', so completely. With না it means 'not at all'.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
