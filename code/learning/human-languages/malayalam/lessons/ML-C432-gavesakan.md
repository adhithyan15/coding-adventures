## You'll want to know: ഗവേഷകൻ
<!-- hl-knowledge: introduces=[ML-LEX-C432-GAVESANAM432-02]; assesses=[] -->

**ഗവേഷകൻ** — *gavēṣakan* — "a researcher".

> ആ ഗവേഷകൻ പത്ത് വർഷം കാട്ടിൽ ജീവിച്ചു.
>
> *ā gavēṣakan pattŭ varṣaṁ kāṭṭil jīviccu.*
>
> That researcher lived in the forest for ten years.

Plural: ഗവേഷകർ, *gavēṣakar*.

Plural: ഗവേഷകർ.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ഗവേഷകൻ** (*gavēṣakan*) is built on the same Sanskrit word as ഗവേഷണം, *gaveṣaṇa*, "searching" (Monier-Williams), with the agent ending -കൻ, "one who".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for giving reasons and opinions.
