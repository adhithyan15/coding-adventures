# विशेषतः (viśeṣataḥ) — especially

## You'll want to know: विशेषतः
<!-- hl-knowledge: introduces=[MR-LEX-C352-ULLEKH352-04]; assesses=[] -->

**विशेषतः** — *viśeṣataḥ* — "especially".

> हिवाळ्यात, विशेषतः सकाळी, खूप थंडी असते.
>
> *hivāḷyāt, viśeṣataḥ sakāḷī, khūp thaṇḍī aste.*
>
> In winter, especially in the mornings, it is very cold.

Formal; in speech खास करून.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**विशेषतः** (*viśeṣataḥ*) is a tatsama, taken from Sanskrit *viśeṣatas*, "especially, particularly" (Monier-Williams).
