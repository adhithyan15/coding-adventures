## You'll want to know: सहकारः
<!-- hl-knowledge: introduces=[SA-LEX-C392-SAHAYAKA392-04]; assesses=[] -->

**सहकारः** — *sahakāraḥ* — "co-operation".

> यदि सहकारः अस्ति, तर्हि कठिनं कार्यम् अपि सुकरम्।
>
> *yadi sahakāraḥ asti, tarhi kaṭhinaṃ kāryam api sukaram.*
>
> If there is co-operation, even hard work is easy.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**सहकारः** (*sahakāraḥ*) is built from *saha*, "with", and *kāra*, "a doing"; MW gives *saha-kāra* "acting with, co-operation, assistance" (MW).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
