# ವಿಮರ್ಶಿಸು (vimarśisu) — to critique

## You'll want to know: ವಿಮರ್ಶಿಸು
<!-- hl-knowledge: introduces=[KA-LEX-C424-AVALOKISU424-02]; assesses=[] -->

**ವಿಮರ್ಶಿಸು** — *vimarśisu* — "to critique".

> ಪತ್ರಿಕೆ ಹೊಸ ಪುಸ್ತಕವನ್ನು ವಿಮರ್ಶಿಸಿತು.
>
> *patrike hosa pustakavannu vimarśisitu.*
>
> The newspaper reviewed the new book.

Past (I …): ವಿಮರ್ಶಿಸಿದೆ, *vimarśiside*.

ವಿಮರ್ಶೆ, a review; ವಿಮರ್ಶಕ, a critic.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ವಿಮರ್ಶಿಸು** (*vimarśisu*) is built on Sanskrit *vimarśa*, "consideration, critical test" (Monier-Williams), with the Kannada verb ending -*isu*.

## What you've built

One more word for saying what happens if.
