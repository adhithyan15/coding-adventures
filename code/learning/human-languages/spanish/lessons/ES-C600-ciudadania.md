## You'll want to know: la ciudadanía
<!-- hl-knowledge: introduces=[ES-LEX-C600-SOCIEDAD-01]; assesses=[] -->

**la ciudadanía** — "the citizenship; the citizens".

> Tiene la ciudadanía española.
>
> *He has Spanish citizenship.*

It also means all the citizens together: *la ciudadanía decide*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*ciudadanía* is built on *ciudadano*, from *ciudad*, inherited from Latin *civitatem* 'city, state' (EtymDB).
