# उत्कृष्टः (utkṛṣṭaḥ) — excellent

## You'll want to know: उत्कृष्टः
<!-- hl-knowledge: introduces=[SA-LEX-C542-UTKRSTA542-03]; assesses=[] -->

**उत्कृष्टः** — *utkṛṣṭaḥ* — "excellent".

> यदि एतत् वस्त्रम् उत्कृष्टम् अस्ति, तर्हि अहं तत् क्रीणामि।
>
> *yadi etat vastram utkṛṣṭam asti, tarhi ahaṃ tat krīṇāmi.*
>
> If this cloth is excellent, I'll buy it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**उत्कृष्टः** (*utkṛṣṭaḥ*) is built on *ud*, "up", and the root √kṛṣ, "to draw", which also gives *karṣati*, as its past participle: drawn up high; MW gives *utkṛṣṭa* as excellent, eminent (MW).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
