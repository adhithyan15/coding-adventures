## You'll want to know: 解说
<!-- hl-knowledge: introduces=[ZH-LEX-C431-OUTING431-01]; assesses=[] -->

**解说** — *jiěshuō* — "to give a running commentary".

> *dǎoyóu zhèngzài gěi wǒmen jiěshuō* — The guide is giving us a commentary.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**解说** (*jiěshuō*) is built from 解 'to explain' and 说 'to speak', both inherited from Middle Chinese, *keaX* and *sywet* (Guangyun, in Baxter's transcription), which glosses the first 'to explain' and the second 'to tell'.
