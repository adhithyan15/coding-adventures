# خورشید — sun, a word built from two old pieces

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[FA-LEX-ASEMAN, FA-ETYMON-ASEMAN] -->

[PAUSE 2s] Say **آسمان** (*âsemân*), and the root sense it once carried. Look up, and
this lesson names what is in it.

## You'll want to know first — one word
<!-- hl-knowledge: introduces=[FA-LEX-KHORSHID]; assesses=[] -->

> **خورشید** — *khorshid* — **sun**

Six letters, all already yours: **خ و ر ش ی د** — *kh*, **و** carrying its
learned *o* value, *r*, *sh*, long *i*, *d*.

## The word, taken apart — one distant cousin, one unrelated partner
<!-- hl-knowledge: introduces=[FA-ETYMON-KHORSHID]; assesses=[] -->

**خورشید** is a compound, not a single old root. Its first half, **خور**
*khor*, "sun," descends from the ancient Indo-European word for the sun,
\**sóh₂wl* — the same distant root behind English **sun**, Latin **sol**
(→ **solar**), Greek **hḗlios** (→ **heliotrope**), and Sanskrit **sūrya**,
though it reached Persian by a completely different branch of the family.
Its second half, **شید** *shid*, "shining," is an unrelated word that
Avestan had already paired with **خور** long before Persian existed.
