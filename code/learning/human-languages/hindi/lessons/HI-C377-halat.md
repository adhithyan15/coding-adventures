## You'll want to know: हालत
<!-- hl-knowledge: introduces=[HI-LEX-C377-HALAT377-02]; assesses=[] -->

**हालत** — *hālat* — "a state (of health, repair), a condition".

> अगर गाड़ी की हालत ठीक होती तो हम आज निकलते।
>
> *agar gāṛī kī hālat ṭhīk hotī to ham āj nikalte.*
>
> If the car were in good condition, we'd set off today.

Feminine.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**हालत** (*hālat*) is usually traced to Arabic *ḥāla*, "a state, a condition", which reached Hindi through Persian.
