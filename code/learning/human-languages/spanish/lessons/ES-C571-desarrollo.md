## You'll want to know: el desarrollo
<!-- hl-knowledge: introduces=[ES-LEX-C571-DESCUBRIR-05]; assesses=[] -->

**el desarrollo** — "the development".

> El desarrollo de la ciudad fue muy rápido.
>
> *The city's development was very fast.*

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*desarrollo* is built on *desarrollar* 'to unroll, to develop', from *des-* and *arrollar* 'to roll up', built on *rollo* 'a roll', which is usually traced to Latin *rotulus* 'a little wheel'.
