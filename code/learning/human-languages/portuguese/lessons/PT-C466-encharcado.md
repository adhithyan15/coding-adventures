## You'll want to know: encharcado
<!-- hl-knowledge: introduces=[PT-LEX-C466-CHUVA-04]; assesses=[] -->

**encharcado** — "soaked, drenched".

> Cheguei a casa encharcado.
>
> *I got home soaked.*

Built on *o charco*, a pool of water.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*encharcado* is built from *en-* and *charco* 'pool, puddle', which was borrowed from Spanish *charco* (EtymDB); the Spanish word's origin is not settled.
