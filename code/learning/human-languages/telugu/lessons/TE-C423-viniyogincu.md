# వినియోగించు (viniyōgiñcu) — to make use of; to utilise

## You'll want to know: వినియోగించు
<!-- hl-knowledge: introduces=[TE-LEX-C423-PRATIPHALAM423-05]; assesses=[] -->

**వినియోగించు** — *viniyōgiñcu* — "to make use of; to utilise".

> మనం నీటిని జాగ్రత్తగా వినియోగించాలి.
>
> *manaṁ nīṭini jāgrattagā viniyōgiñcāli.*
>
> We must use water carefully.

Past (I …): వినియోగించాను, *viniyōgiñcānu*.

Formal beside ఉపయోగించు, which you know.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**వినియోగించు** (*viniyōgiñcu*) is built on Sanskrit *viniyoga*, "distribution; employment, use, application" (Monier-Williams), with the Telugu verb ending -ఇంచు.
