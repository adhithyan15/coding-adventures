## You'll want to know: el aburrimiento
<!-- hl-knowledge: introduces=[ES-LEX-C713-DIVERTIDO-05]; assesses=[] -->

**el aburrimiento** — "boredom".

> ¡Qué aburrimiento de película!
>
> *What a boring film!*

*¡Qué aburrimiento!* — How boring!

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*aburrimiento* is built on *aburrir* with the ending *-miento* (EtymDB); the verb comes from Latin *abhorrēre* "to shrink from".
