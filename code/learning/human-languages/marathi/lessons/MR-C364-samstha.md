## You'll want to know: संस्था
<!-- hl-knowledge: introduces=[MR-LEX-C364-SANSTHA364-01]; assesses=[] -->

**संस्था** — *saṁsthā* — "an institution; an organization".

> ही संस्था गरीब मुलांना शिकवते.
>
> *hī saṁsthā garīb mulānnā śikavte.*
>
> This organization teaches poor children.

Feminine.

Feminine: ही संस्था; शिक्षणसंस्था, an educational institution.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**संस्था** (*saṁsthā*) is a tatsama, taken from Sanskrit *saṁsthā*, "standing together, an establishment" (Monier-Williams).
