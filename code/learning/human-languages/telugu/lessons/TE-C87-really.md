# నిజంగా (nijaṁgā) — really, truly

## You'll want to know: నిజంగా
<!-- hl-knowledge: introduces=[TE-LEX-C87-ANSWER-05]; assesses=[] -->

**నిజంగా** (*nijaṁgā*) — "really, truly".

**నిజం** is "the truth", and **-గా** turns it into a manner, as it did for *nemmadigā*. As a
question, **నిజంగా?** is "really?".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

Five replies: wrong, exactly, probably, I see, really.
