# பின்னர் (piṉṉar) — later on; afterwards

## You'll want to know: பின்னர்
<!-- hl-knowledge: introduces=[TA-LEX-C316-ANNAAL316-01]; assesses=[] -->

**பின்னர்** — *piṉṉar* — "later on; afterwards".

> முதலில் நாங்கள் சாப்பிட்டோம், பின்னர் கடைக்குப் போனோம்.
>
> *mutalil nāṅkaḷ cāppiṭṭōm, piṉṉar kaṭaikkup pōṉōm.*
>
> First we ate, and later on we went to the shop.

A more formal word for பிறகு.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**பின்னர்** (*piṉṉar*) is native Dravidian: it is built on பின், "back, what comes after" (DEDR 4205).

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
