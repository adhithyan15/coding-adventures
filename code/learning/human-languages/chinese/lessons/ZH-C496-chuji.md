## You'll want to know: chūjí
<!-- hl-knowledge: introduces=[ZH-LEX-C496-LEVELS496-04]; assesses=[] -->

*chūjí* — "elementary; for beginners".

> *wǒ xué guo chūjí Hànyǔ* — I've done elementary Chinese.

Its characters come later; for now it is a word for the ear.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*chūjí* is built from *chū* 'the start' and 级 'a grade', both inherited from Middle Chinese, *tsrhjo* and *kip* (Guangyun, in Baxter's transcription), which glosses the first 'the beginning'.
