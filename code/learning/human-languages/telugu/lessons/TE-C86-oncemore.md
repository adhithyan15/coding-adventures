# ఇంకోసారి (iṅkōsāri) — once more

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TE-LEX-C85-FEEL-05, TE-LEX-C86-REPAIR-01] -->

[PAUSE 2s] Before the new one: say the Telugu for sorrow, then the Telugu for slowly.

## You'll want to know: ఇంకోసారి
<!-- hl-knowledge: introduces=[TE-LEX-C86-REPAIR-02]; assesses=[] -->

**ఇంకోసారి** (*iṅkōsāri*) — "once more, one more time".

**ఇంకోసారి చెప్పండి** — "please say it once more". **సారి** is "a time, an occasion", and
**ఇంకో** is "another".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

A way to hear it again without saying you did not understand.
