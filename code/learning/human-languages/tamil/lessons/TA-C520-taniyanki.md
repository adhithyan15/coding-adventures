# தானியங்கி (tāṉiyaṅki) — automatic; an automatic machine

## You'll want to know: தானியங்கி
<!-- hl-knowledge: introduces=[TA-LEX-C520-KARUVI520-02]; assesses=[] -->

**தானியங்கி** — *tāṉiyaṅki* — "automatic; an automatic machine".

> வங்கியின் தானியங்கி இயந்திரத்தில் பணம் எடுத்தேன்.
>
> *vaṅkiyiṉ tāṉiyaṅki iyantirattil paṇam eṭuttēṉ.*
>
> I took money out of the bank's automatic machine.

It stands before a noun: தானியங்கி இயந்திரம், an automatic machine; தானியங்கிக் கதவு, an automatic door.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**தானியங்கி** (*tāṉiyaṅki*) is a modern native compound: தான் (*tāṉ*), "oneself, itself" (DEDR 3196), and இயங்கி (*iyaṅki*), "that which moves", from இயங்கு, "to move" (DEDR 469).
