# Marwadi (Marwari), Step by Step, Sign by Sign

This is the Marwadi track the project matrix was missing. Official and
linguistic sources commonly call the language **Marwari**; many speakers and
learners also write **Marwadi**, the name requested for this track. The title
keeps both visible instead of pretending the spelling choice is a language
difference.

The track starts at absolute zero. Its first seven lessons make one authentic
greeting usable and writable: **राम-राम सा** (*rām-rām sā*). A learner first
notices and copies one Devanagari sign, then a vowel mark, then a whole word.
Only after the hand can make **राम** does the book add **स**, build **सा**, and
ask for the complete greeting from memory. Every lesson is at most five minutes.

## What this starter edition can honestly claim

After Chapter 1, a learner can recognise, read, say, copy, and write the polite
greeting **राम-राम सा**, and can answer it with the same greeting. That is a
small pre-A1 capability, not completion of pre-A1 and not exam readiness. The
curriculum map records every untouched spine concept explicitly so the remaining
work stays measurable.

Marwadi has no single external pre-A1-to-C2 examination ladder suitable for the
book's completion contract. The project therefore maps it to CEFR and will define
a four-skill Marwadi assessment equivalent with timed papers, rubrics, pass
thresholds, and full mocks. Until that contract lands, this starter is evidence
of a writing-first ramp, not a pass-ready course.

## Variety and sources

The initial variety is contemporary central Marwari written in Devanagari.
Regional forms will be labelled rather than silently flattened into one supposed
standard. Rajasthan's official language page lists Marwari among the major forms
of Rajasthani, and the Rajasthan State Archives publishes Rajasthani/Marwari
learning material. The opening exchange is attested in the Rajasthan Sahitya
Akademi magazine *Jāgtī Jot* as **राम-राम सा। — राम-राम सा, राम-राम।**
