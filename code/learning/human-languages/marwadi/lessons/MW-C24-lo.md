# लो — take it, on the page

## Warm-up
<!-- hl-knowledge: introduces=[MW-SCRIPT-LO-01]; assesses=[MW-LEX-LO-01, MW-LEX-BAADAL-01, MW-SCRIPT-BAADAL-01, MW-SCRIPT-THELA-01] -->

[PAUSE 20s] Say *take it*, then write cloud and cart.

## You'll want to know
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-LA-01, MW-SCRIPT-O-MATRA-01, MW-SCRIPT-KARO-01] -->

> **ल** + **ो** → **लो** — *lo* — take it

Two signs. The **ल** ends **बादल** and opens **ठेला**; here it stands alone with
the **ो** you put on the end of **करो**.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[MW-SCRIPT-LO-01] -->
<!-- hl-writing-stage: delayed-copy -->

Look at **लो**, cover it, wait five seconds, and write it from the sound. Write
**करो** beneath it and check that both end with the same mark.
