## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**مطاط** (*maṭṭāṭ*) is built on the native Arabic root *m-ṭ-ṭ*, "to stretch" (Lane). *Maṭṭāṭ* is a modern *faʿʿāl* word, "the stretchy".
