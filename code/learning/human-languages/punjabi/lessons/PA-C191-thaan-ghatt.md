## Grammar Lens: second familiar noun
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-GHATT-191, PA-PLACE-THAAN-LOCATION-01, PA-LEX-HAI-02] -->

> **ਥਾਂ ਘੱਟ ਹੈ** — *thā̃ ghaṭṭ hai* — there is not much space

The quantity word stays unchanged. Only the familiar noun changes from time to
place or space.
