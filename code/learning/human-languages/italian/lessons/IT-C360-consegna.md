## You'll want to know: la consegna
<!-- hl-knowledge: introduces=[IT-LEX-C360-REPARTO-05]; assesses=[] -->

**la consegna** — "the delivery, the handing in".

> La consegna del progetto è fissata per lunedì.
>
> *The handing in of the project is set for Monday.*

*La data di consegna* — the delivery date, the deadline. *Consegna a domicilio* — home delivery.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*consegna* is built on *consegnare* "to hand over", inherited from Latin *cōnsignāre* "to seal, to put on record" (Lewis & Short), built on *signum* "a mark, a seal".
