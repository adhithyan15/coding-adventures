# குறிக்கோள் (kuṟikkōḷ) — an aim; a goal

[PAUSE 2s] Before the new one: say the Tamil for a draft, then the Tamil for to take forward.

## You'll want to know: குறிக்கோள்
<!-- hl-knowledge: introduces=[TA-LEX-C386-UTTI386-05]; assesses=[] -->

**குறிக்கோள்** — *kuṟikkōḷ* — "an aim; a goal".

> என் குறிக்கோள் ஒரு மருத்துவர் ஆவது.
>
> *eṉ kuṟikkōḷ oru maruttuvar āvatu.*
>
> My aim is to become a doctor.

குறி, a mark, a target + கோள், a holding.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**குறிக்கோள்** (*kuṟikkōḷ*) is native: *kuṟi*, "a mark; to aim at" (DEDR 1847), and *kōḷ*, "taking, holding" (DEDR 2151): the mark one holds to.
