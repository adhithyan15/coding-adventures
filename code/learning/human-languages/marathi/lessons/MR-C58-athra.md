## You'll want to know: अठरा
<!-- hl-knowledge: introduces=[MR-LEX-ATHRA]; assesses=[MR-LEX-NUMBERS-ONE-TO-FIVE] -->

> **अठरा** — *aṭhrā* — **18**

Sanskrit **अष्टादश** (*aṣṭādaśa*), *eight-ten*. **अठ-** is the **आठ** you met in
chapter fifty-five, retroflex and all, and **-रा** is the ten for the last
time: nineteen is built a completely different way.
