## You'll want to know: valer
<!-- hl-knowledge: introduces=[ES-LEX-C631-REBAJAS-05]; assesses=[] -->

**valer** — "to be worth; to cost".

> ¿Cuánto vale este libro?
>
> *How much is this book?*

Irregular: *valgo, valdré*. *Vale* — OK, in Spain. *No vale la pena* — it is not worth it.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*valer* is inherited from Latin *valere* 'to be strong, to be worth' (EtymDB).
