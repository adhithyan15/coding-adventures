# ప్రాధాన్యం (prādhānyaṁ) — priority; precedence

## You'll want to know: ప్రాధాన్యం
<!-- hl-knowledge: introduces=[TE-LEX-C391-PRAMUKHYATA391-02]; assesses=[] -->

**ప్రాధాన్యం** — *prādhānyaṁ* — "priority; precedence".

> అమ్మ పిల్లల చదువుకు ప్రాధాన్యం ఇస్తుంది.
>
> *amma pillala caduvuku prādhānyaṁ istundi.*
>
> Mother gives priority to the children’s studies.

Close to ప్రాముఖ్యత, but it puts one thing ahead of the others.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ప్రాధాన్యం** (*prādhānyaṁ*) is borrowed from Sanskrit *prādhānya*, "predominance, supremacy" (Monier-Williams), from *pradhāna*, "chief"; the Telugu adjective ప్రధాన, main, is the same word.
