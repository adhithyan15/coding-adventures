## You'll want to know: उद्यमः
<!-- hl-knowledge: introduces=[SA-LEX-C384-UDYAMA384-01]; assesses=[] -->

**उद्यमः** — *udyamaḥ* — "perseverance; exertion".

> यदि उद्यमः अस्ति, तर्हि सफलता अपि भविष्यति।
>
> *yadi udyamaḥ asti, tarhi saphalatā api bhaviṣyati.*
>
> If there is perseverance, success will follow.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**उद्यमः** (*udyamaḥ*) is built on *ud*, "up", and the root √yam, "to hold"; MW gives *ud-yama* "undertaking" and "exertion, strenuous and continued effort, perseverance" (MW).
