**كعب** — *kaʿb* — "a heel".

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**كعب** (*kaʿb*) is built on the native Arabic root *k-ʿ-b*, "the ankle-bone; a cube" (Lane). The same root gives the Kaʿba, the cube-shaped shrine at Mecca.
