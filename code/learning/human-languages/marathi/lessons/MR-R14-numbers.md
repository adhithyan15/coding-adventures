# Count, then notice

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[MR-LEX-NUMBERS-ONE-TO-FIVE, MR-SOUND-CHA-TSAA, MR-HISTORY-SELECTIVE-RETENTION] -->

[PAUSE 6s] Count one through five. Then say **चार** with Marathi **tsā-**, and
remember that a language can innovate in one place while retaining an older
feature in another.
