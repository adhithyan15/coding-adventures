## You'll want to know: naguère
<!-- hl-knowledge: introduces=[FR-LEX-C272-JADIS-02]; assesses=[] -->

**naguère** — "not long ago; formerly (literary)".

> Naguère, ce village était très calme.
>
> *Not long ago, this village was very quiet.*

From *n'a guère*: it is hardly (long) ago. Many writers now use it for 'formerly'.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*naguère* comes from *n'a guère* "it is hardly (long)". *Guère* is usually traced to a Frankish word meaning "much"; the origin is not fully settled (EtymDB lists no parent).
