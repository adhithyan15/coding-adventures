## You'll want to know: klauen
<!-- hl-knowledge: introduces=[GE-LEX-C281-EINBRUCH-04]; assesses=[] -->

**klauen** — "to pinch, to nick (colloquial)".

> Jemand hat mein Fahrrad geklaut.
>
> *Someone has nicked my bike.*

Colloquial for *stehlen*. Regular: *klaute*, *hat geklaut*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*klauen* is usually linked to *Klaue* "claw", from an older verb meaning "to grab with the claws"; EtymDB lists no parent, so the link is not settled.
