# అలవాటుపడు (alavāṭupaḍu) — to get used to

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[TE-LEX-C457-VASATI457-05, TE-LEX-C458-GADI458-01] -->

[PAUSE 2s] Before the new one: say the Telugu for to stay overnight, then the Telugu for to settle in.

## You'll want to know: అలవాటుపడు
<!-- hl-knowledge: introduces=[TE-LEX-C458-GADI458-02]; assesses=[] -->

**అలవాటుపడు** — *alavāṭupaḍu* — "to get used to".

> చల్లని వాతావరణానికి నెమ్మదిగా అలవాటుపడ్డాను.
>
> *callani vātāvaraṇāniki nemmadigā alavāṭupaḍḍānu.*
>
> I slowly got used to the cold weather.

Past (I …): అలవాటుపడ్డాను, *alavāṭupaḍḍānu*.

What you get used to takes -కి: వాతావరణానికి. అలవాటు, a habit, + పడు.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**అలవాటుపడు** (*alavāṭupaḍu*) is native Dravidian: అలవాటు, "a habit, a practice" (DEDR 249), with పడు, "to undergo" (DEDR 3853).
