## You'll want to know: ರಸ್ತೆ

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ರಸ್ತೆ** (*rastē*) is a loan from Persian *rāsta*, "road, way", which came through Hindustani.
