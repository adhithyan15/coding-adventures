# তোমার নাম কি? (tomār nām ki?) — "what's your name?"

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[BN-CONCEPT-C02-TUMIAPNI-01, BN-CONCEPT-C02-KI-01, BN-CONCEPT-C02-NAAM-01] -->

[PAUSE 2s] Turn the introduction around — ask, instead of tell.

## The two words — assembled
<!-- hl-knowledge: introduces=[BN-CONCEPT-C02-TOMARNAAMKI-01]; assesses=[BN-CONCEPT-C02-TUMIAPNI-01, BN-CONCEPT-C02-KI-01, BN-CONCEPT-C02-NAAM-01] -->

**তোমার** (*tomār*, "your," from *tumi*) + **নাম** (name) + **কি** (what) →
literally "**your name what?**" And note — still **no "is."** The zero copula
holds here too: Bengali simply lays "your name" beside "what," and the question is
complete.

## Grammar Lens: answering, and the respectful form
<!-- hl-knowledge: introduces=[]; assesses=[BN-CONCEPT-C02-KI-01, BN-CONCEPT-C02-NAAM-01, BN-CONCEPT-C02-TOMARNAAMKI-01, BN-CONCEPT-C02-TUMIAPNI-01] -->

Answer with the sentence you built: *Āmār nām Arun.* The respectful version swaps
*tomār* (from *tumi*) for **আপনার** (*āpnār*, "your," from *āpni*): *āpnār nām
ki?* — the one to use with a stranger.
