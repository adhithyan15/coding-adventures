# વીતવું (vītvũ) — to go by, to pass (of time)

## You'll want to know: વીતવું
<!-- hl-knowledge: introduces=[GU-LEX-C178-START178-05]; assesses=[] -->

**વીતવું** — *vītvũ* — "to go by, to pass (of time)".

> **સમય જલદી વીતશે.** — *samay jaldī vītśe* — "Time will pass quickly."

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**વીતવું** (*vītvũ*) is a tadbhava. It comes from Sanskrit *vṛtta*, "turned; passed, elapsed (of time)", and CDIAL glosses the Gujarati verb "to pass (of time)" (CDIAL 12069).
