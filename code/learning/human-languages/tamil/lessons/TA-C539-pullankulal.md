# புல்லாங்குழல் (pullāṅkuḻal) — a flute

## You'll want to know: புல்லாங்குழல்
<!-- hl-knowledge: introduces=[TA-LEX-C539-ISAI539-01]; assesses=[] -->

**புல்லாங்குழல்** — *pullāṅkuḻal* — "a flute".

> இடையன் மரத்தடியில் புல்லாங்குழல் ஊதினான்.
>
> *iṭaiyaṉ marattaṭiyil pullāṅkuḻal ūtiṉāṉ.*
>
> The herdsman played the flute under a tree.

A flute is blown, so it takes ஊது (*ūtu*): புல்லாங்குழல் ஊது.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**புல்லாங்குழல்** (*pullāṅkuḻal*) ends in the native குழல் (*kuḻal*), "a tube, a flute, a pipe" (DEDR 1818); the origin of the first part is not settled.
