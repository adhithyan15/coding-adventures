## You'll want to know: prōpositum, prōpositī
<!-- hl-knowledge: introduces=[LA-LEX-C393-STATUO-03]; assesses=[] -->

**prōpositum, prōpositī** — "a plan, a purpose, an aim".

> Prōpositum meum est librum scrībere.
>
> *My aim is to write a book.*

*prōpositum, prōpositī* n., the participle of *prōpōnō*, to set before: what you have set before yourself. English *purpose* goes back to it through French.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*prōpositum* is the participle of *prōpōnō* "to set before" (Lewis & Short), from *prō* "before" and *pōnō* "to put". English *purpose* goes back to the same verb through French.
