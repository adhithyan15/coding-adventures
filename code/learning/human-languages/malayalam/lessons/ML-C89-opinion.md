# നല്ലതാണ് എന്ന് ഞാൻ ചിന്തിക്കുന്നു — I think it is good

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C89-EVAL-01, ML-GRAMMAR-C72-ENNU-VERBS-01] -->

[PAUSE 2s] Say *it is bad*. Then say the marker that turns any sentence into
something you can report.

## Grammar Lens: nothing new is needed
<!-- hl-knowledge: introduces=[ML-CONCEPT-C89-OPINION-01]; assesses=[] -->

An opinion is **a sentence with your own judgement wrapped around it**, and you
now have both halves.

> **അത് നല്ലതാണ് എന്ന് ഞാൻ ചിന്തിക്കുന്നു.**
>
> *atŭ nallathāṇŭ ennŭ ñān cintikkunnu* — **I think it is good.**

Take it apart and **every piece is already yours**:

| piece | where it came from |
|---|---|
| **അത് നല്ലതാണ്** | this chapter — *it is good* |
| **എന്ന്** | the quoting marker |
| **ഞാൻ ചിന്തിക്കുന്നു** | the thinking verb, already paired with that marker |

**The quoting chapter did the hard part.** It showed that the marker takes
whatever sentence you can build and hands it to a verb of saying, thinking,
knowing or asking — so an opinion needed **no new grammar at all**, only
something worth having an opinion about.

Swap the inner sentence and the frame does not move:

**അത് മോശമാണ് എന്ന് ഞാൻ ചിന്തിക്കുന്നു** — I think it is bad.

**This is what a well-built system looks like from the inside.** Two vocabulary
words arrived, and a whole function — giving an opinion — came with them,
because the machinery was already in place and waiting for something to carry.
