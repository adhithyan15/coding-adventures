# മോചിപ്പിക്കുക (mōcippikkuka) — to free; to liberate

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ML-LEX-C371-JAIL371-03, ML-LEX-C371-JAIL371-04] -->

[PAUSE 2s] Before the new one: say the Malayalam for a prisoner, then the Malayalam for to release.

## You'll want to know: മോചിപ്പിക്കുക
<!-- hl-knowledge: introduces=[ML-LEX-C371-JAIL371-05]; assesses=[] -->

**മോചിപ്പിക്കുക** — *mōcippikkuka* — "to free; to liberate".

> പോലീസ് കുട്ടിയെ മോചിപ്പിച്ചു.
>
> *pōlīsŭ kuṭṭiye mōcippiccu.*
>
> The police freed the child.

Past: മോചിപ്പിച്ചു, *mōcippiccu*.

The noun is മോചനം, release, freedom.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**മോചിപ്പിക്കുക** (*mōcippikkuka*) is built from Sanskrit *mocana*, "releasing, setting free" (Monier-Williams), with the Malayalam causative ending -ിപ്പിക്കുക.

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
