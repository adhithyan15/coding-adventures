# ഉഷ്ണതരംഗം (uṣṇataraṁgaṁ) — a heatwave

## You'll want to know: ഉഷ്ണതരംഗം
<!-- hl-knowledge: introduces=[ML-LEX-C511-PRAVACANAM511-03]; assesses=[] -->

**ഉഷ്ണതരംഗം** — *uṣṇataraṁgaṁ* — "a heatwave".

> ഉഷ്ണതരംഗം കാരണം പള്ളിക്കൂടങ്ങൾ അടച്ചു.
>
> *uṣṇataraṁgaṁ kāraṇaṁ paḷḷikkūṭaṅṅaḷ aṭaccu.*
>
> Because of the heatwave the schools were closed.

ഉഷ്ണം, heat, plus തരംഗം, a wave.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ഉഷ്ണതരംഗം** (*uṣṇataraṁgaṁ*) is a modern Malayalam compound built from two Sanskrit words, *uṣṇa*, "hot", and *taraṅga*, "a wave" (Monier-Williams).
