## You'll want to know: el aprendizaje
<!-- hl-knowledge: introduces=[ES-LEX-C597-APRENDE-01]; assesses=[] -->

**el aprendizaje** — "the learning; the apprenticeship".

> El aprendizaje de un idioma lleva tiempo.
>
> *Learning a language takes time.*

A noun for the process of learning.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*aprendizaje* is built on *aprendiz* 'apprentice', from *aprender*, inherited from Latin *apprehendere* 'to seize, to grasp' (EtymDB).
