## You'll want to know: ভাসানো
<!-- hl-knowledge: introduces=[BN-LEX-C308-BISORJON308-02]; assesses=[] -->

**ভাসানো** — *bhāsāno* — "to set afloat; to immerse".

> সন্ধ্যায় তারা প্রতিমা নদীতে ভাসাল।
>
> *sôndhyāy tārā prôtimā nôdīte bhāsālô.*
>
> In the evening they set the image afloat on the river.

Past (he/she …): সেই শিশু কাগজের নৌকা ভাসাল, *sei shishu kāgôjer noukā bhāsālô*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ভাসানো** (*bhāsāno*) is **ভাসা**, to float — CDIAL 9654, Sanskrit *bhráśyati*, 'falls', which lists Bengali *bhāsā*, 'to float, drift along' — with the -ānō ending: to set something afloat.
