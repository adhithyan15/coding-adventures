## You'll want to know: पाठ
<!-- hl-knowledge: introduces=[MW-LEX-C285-AKHAR285-03]; assesses=[] -->

**पाठ** — *pāṭh* — "a lesson".

> यो पाठ सोरो है।
>
> *yo pāṭh soro hai.*
>
> This lesson is easy.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**पाठ** (*pāṭh*) is a tatsama, taken from Sanskrit *pāṭha*, "recitation, study" (Monier-Williams).
