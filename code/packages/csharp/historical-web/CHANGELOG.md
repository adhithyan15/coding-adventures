# Changelog — CodingAdventures.HistoricalWeb (C#)

## [0.1.0] — 2026-11-28

### Added

- .NET 9 in-memory HTTP/0.9 request encoding/parsing and ASCII response decoding.
- HTML Tags 1992 scanner with UTF-16 scalar validation, CRLF normalization,
  archived entity expansion, implied ends, raw text, and deterministic recovery.
- An immutable flat node/attribute arena with typed parse errors and source
  offsets, built and released without recursive document ownership.
- Documentation comparing the archived tag list with XML and modern WHATWG
  parsing.
