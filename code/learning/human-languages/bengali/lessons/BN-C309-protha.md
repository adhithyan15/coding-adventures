# প্রথা (prôthā) — a custom; a tradition

[PAUSE 2s] Before the new one: say the Bengali for the new year, then the Bengali for a new account book.

## You'll want to know: প্রথা
<!-- hl-knowledge: introduces=[BN-LEX-C309-GHURI309-05]; assesses=[] -->

**প্রথা** — *prôthā* — "a custom; a tradition".

> নতুন বছরে হালখাতা খোলা একটা পুরনো প্রথা।
>
> *nôtun bôchhôre hālkhātā kholā ekṭā purôno prôthā.*
>
> Opening a new ledger for the new year is an old custom.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**প্রথা** (*prôthā*) is Sanskrit *prathā*, 'a spreading out; fame' (Monier-Williams); the sense 'a custom', a practice that has spread, is the later one.
