# ഓവർടൈം (ōvarṭaiṁ) — overtime

## You'll want to know: ഓവർടൈം
<!-- hl-knowledge: introduces=[ML-LEX-C544-SAMRAMBHAM544-01]; assesses=[] -->

**ഓവർടൈം** — *ōvarṭaiṁ* — "overtime".

> പണി തീർക്കാൻ അവൻ ഇന്നലെ ഓവർടൈം ചെയ്തു.
>
> *paṇi tīrkkān avan innale ōvarṭaiṁ ceytu.*
>
> He worked overtime yesterday to finish the job.

ഓവർടൈം ചെയ്യുക, to work overtime.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**ഓവർടൈം** (*ōvarṭaiṁ*) was borrowed from English *overtime*.
