# అంతకుముందు (antakumundu) — before that

## You'll want to know: అంతకుముందు
<!-- hl-knowledge: introduces=[TE-LEX-C380-KRITAM380-02]; assesses=[] -->

**అంతకుముందు** — *antakumundu* — "before that".

> అంతకుముందు అతను ఎప్పుడూ ఇక్కడికి రాలేదు.
>
> *antakumundu atanu eppuḍū ikkaḍiki rālēdu.*
>
> Before that he had never come here.

అంత, that, -కు, to, and ముందు, before.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**అంతకుముందు** (*antakumundu*) is native Telugu: *anta*, "that much" (DEDR 1), with *-ku* and *mundu*, "before" (DEDR 5020).
