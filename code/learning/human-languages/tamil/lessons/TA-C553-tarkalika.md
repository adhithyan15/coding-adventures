# தற்காலிக (taṟkālika) — temporary

## You'll want to know: தற்காலிக
<!-- hl-knowledge: introduces=[TA-LEX-C553-THARKALIKAM553-01]; assesses=[] -->

**தற்காலிக** — *taṟkālika* — "temporary".

> இது ஒரு தற்காலிக வேலை, மூன்று மாதங்கள் மட்டுமே.
>
> *itu oru taṟkālika vēlai, mūṉṟu mātaṅkaḷ maṭṭumē.*
>
> This is a temporary job, only for three months.

It stands before a noun. As an adverb: தற்காலிகமாக, for the time being.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**தற்காலிக** (*taṟkālika*) is borrowed from a Sanskrit adjective built on *tatkāla*, "happening at that same time, immediately" (Monier-Williams).
