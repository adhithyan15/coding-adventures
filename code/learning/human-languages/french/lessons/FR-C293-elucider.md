## You'll want to know: élucider
<!-- hl-knowledge: introduces=[FR-LEX-C293-MYSTERE-02]; assesses=[] -->

**élucider** — "to solve, to clear up".

> La police n'a jamais élucidé ce crime.
>
> *The police never solved this crime.*

Formal; in speech, *résoudre*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*élucider* is a learned borrowing from Late Latin *ēlūcidāre* "to make clear" (EtymDB), built on *lūx* "light".
