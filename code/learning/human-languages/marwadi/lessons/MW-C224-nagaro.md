# नगाड़ो (nagāṛo) — a kettledrum

## You'll want to know: नगाड़ो
<!-- hl-knowledge: introduces=[MW-LEX-C224-FUN224-05]; assesses=[] -->

**नगाड़ो** — *nagāṛo* — "a kettledrum".

> म्हैं नगाड़ो सुण्यो।
>
> *mhaĩ nagāṛo suṇyo.*
>
> I heard the kettledrum.

A masculine noun.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**नगाड़ो** (*nagāṛo*) is usually traced to Persian *naqqāra*, "a kettledrum", which Persian took from Arabic; Marwadi says *g* for its *q*.
