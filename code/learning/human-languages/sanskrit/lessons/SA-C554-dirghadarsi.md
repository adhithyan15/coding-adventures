## You'll want to know: दीर्घदर्शी
<!-- hl-knowledge: introduces=[SA-LEX-C554-BHAVI554-02]; assesses=[] -->

**दीर्घदर्शी** — *dīrghadarśī* — "far-sighted".

> यदि नायकः दीर्घदर्शी अस्ति, तर्हि देशः सुरक्षितः भवति।
>
> *yadi nāyakaḥ dīrghadarśī asti, tarhi deśaḥ surakṣitaḥ bhavati.*
>
> If the leader is far-sighted, the country is safe.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**दीर्घदर्शी** (*dīrghadarśī*) is built from *dīrgha*, "long, far", and *darśin*, "seeing", from the root √dṛś, "to see"; MW gives *dīrghadarśin* as the same as *dīrghadarśa*, far-sighted (MW).
