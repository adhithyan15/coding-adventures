# விடுதி (viṭuti) — a lodge; a hostel

## You'll want to know: விடுதி
<!-- hl-knowledge: introduces=[TA-LEX-C418-VIDUTHI418-01]; assesses=[] -->

**விடுதி** — *viṭuti* — "a lodge; a hostel".

> நாங்கள் ஒரு சிறிய விடுதியில் தங்கினோம்.
>
> *nāṅkaḷ oru ciṟiya viṭutiyil taṅkiṉōm.*
>
> We stayed in a small lodge.

மாணவர் விடுதி is a students' hostel.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**விடுதி** (*viṭuti*) is native Dravidian: DEDR 5393 lists it under விடு, "to leave, to let go", as "a lodging".
