# ਮੈਂ ਪੰਜਾਬੀ ਬੋਲਦਾ ਹਾਂ (maiṁ panjābī boldā hāṁ) — "I speak Punjabi"

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[PA-LEX-MAIN-03, PA-LEX-PANJABI-05, PA-LEX-BOLNA-05] -->

[PAUSE 2s] Three words you already own — "I," the language, the verb. Here they
become your first complete, moving sentence.

## The sentence, taken apart
<!-- hl-knowledge: introduces=[PA-PHRASE-I-SPEAK-PUNJABI-05]; assesses=[PA-GRAMMAR-MAIN-HAAN-03, PA-GRAMMAR-VERB-LAST-02, PA-GRAMMAR-VERB-STEM-05] -->

**ਮੈਂ ਪੰਜਾਬੀ ਬੋਲਦਾ ਹਾਂ** = **ਮੈਂ** (*maiṁ*, "I") + **ਪੰਜਾਬੀ** (*panjābī*, the
object) + **ਬੋਲਦਾ** (*boldā*, "speak," m.) + **ਹਾਂ** (*hāṁ*, "am") — literally "**I
Punjabi speaking am**," with the verb-frame last, exactly as *hai* first showed
you.

**ਬੋਲਦਾ** (*boldā*) is the stem *bol-* plus **-ਦਾ** (*-dā*). Nothing new has been
added to the verb but an ending.

## Grammar Lens: the present habitual, gendered
<!-- hl-knowledge: introduces=[PA-GRAMMAR-PRESENT-HABITUAL-GENDER-05]; assesses=[] -->

To say "I do X," Punjabi uses **stem + -dā/-dī + the copula**, and the participle
**agrees with the speaker's gender**:

- a man: **ਮੈਂ ਪੰਜਾਬੀ ਬੋਲਦਾ ਹਾਂ** (*boldā hāṁ*)
- a woman: **ਮੈਂ ਪੰਜਾਬੀ ਬੋਲਦੀ ਹਾਂ** (*boldī hāṁ*)

The *-dā/-dī* marks the speaker — a feature English has no trace of.
