# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [0.1.0] - 2026-11-21

### Added
- Initial pure Dart grammar-driven lexical analyzer for Starlark.
- Python-compatible significant indentation tracking (`INDENT`, `DEDENT`, `NEWLINE`).
- Centralized, payload-blind diagnostic catalog conforming to Standing Rule #20.
- Shared neutral conformance testing against `language-frontends-v1`.
