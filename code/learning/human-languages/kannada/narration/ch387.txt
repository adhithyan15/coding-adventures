Kannada, chapter 387: Priorities and Values.
5 lessons. All 5 can be done entirely by ear.


Lesson 1 of 5.
ಸವಾಲು (savālu) — a challenge.

Warm-up.
[pause 2 seconds]
Before the new one: say the Kannada for to portray, then the Kannada for blame.

You'll want to know: ಸವಾಲು.
ಸವಾಲು — savālu — "a challenge".
ಹೊಸ ಊರಿನಲ್ಲಿ ಕೆಲಸ ಹುಡುಕುವುದು ದೊಡ್ಡ ಸವಾಲು. hosa ūrinalli kelasa huḍukuvudu doḍḍa savālu. Finding work in a new town is a big challenge.
ಸವಾಲು (savālu) ಹಾಕು, to throw down a challenge.

The word, taken apart.
ಸವಾಲು (savālu) is a loan from Hindustani savāl, which comes from Arabic suʾāl, "a question"; Kannada uses it for a challenge.

Lesson 2 of 5.
ಮೀಸಲಿಡು (mīsaliḍu) — to set aside.

Warm-up.
[pause 2 seconds]
Before the new one: say the Kannada for blame, then the Kannada for a challenge.

You'll want to know: ಮೀಸಲಿಡು.
ಮೀಸಲಿಡು — mīsaliḍu — "to set aside".
ನಾನು ಪ್ರತಿ ತಿಂಗಳು ಸ್ವಲ್ಪ ಹಣ ಮೀಸಲಿಟ್ಟೆ. nānu prati tiṅgaḷu svalpa haṇa mīsaliṭṭe. I set aside a little money every month.
Past (I …): ಮೀಸಲಿಟ್ಟೆ, mīsaliṭṭe.
ಮೀಸಲು (kept apart) + ಇಡು (to put).

The word, taken apart.
ಮೀಸಲಿಡು (mīsaliḍu) is native Dravidian, built from mīsal, "something set apart and left untouched" (DEDR 4841), and iḍu, "to put" (DEDR 442).

Lesson 3 of 5.
ಸಮತೋಲನ (samatōlana) — balance.

Warm-up.
[pause 2 seconds]
Before the new one: say the Kannada for a challenge, then the Kannada for to set aside.

You'll want to know: ಸಮತೋಲನ.
ಸಮತೋಲನ — samatōlana — "balance".
ಕೆಲಸ ಮತ್ತು ಮನೆಯ ನಡುವೆ ಸಮತೋಲನ ಬೇಕು. kelasa mattu maneya naḍuve samatōlana bēku. We need a balance between work and home.
ಸಮ (even) + ತೋಲನ (weighing).

The word, taken apart.
ಸಮತೋಲನ (samatōlana) is built from Sanskrit sama, "even, equal", and tolana, "weighing" (Monier-Williams).

Lesson 4 of 5.

Warm-up.
[pause 2 seconds]

You'll want to know: ಆದ್ಯತೆ.
ಆದ್ಯತೆ — ādyate — "a priority".
ನನ್ನ ಮೊದಲ ಆದ್ಯತೆ ಮಕ್ಕಳ ಓದು. nanna modala ādyate makkaḷa ōdu. My first priority is the children's studies.

The word, taken apart.
ಆದ್ಯತೆ (ādyate) is built on Sanskrit ādya, "being at the beginning, first" (Monier-Williams), with -tā, "-ness": firstness.

You'll want to know: ಮೌಲ್ಯ.
ಮೌಲ್ಯ — maulya — "a value; worth".
ಹಳೆಯ ನಾಣ್ಯಗಳಿಗೆ ಈಗ ಹೆಚ್ಚು ಮೌಲ್ಯ ಇದೆ. haḷeya nāṇyagaḷige īga heccu maulya ide. Old coins are worth more now.
ಮೌಲ್ಯಗಳು, values (moral or social).

The word, taken apart.
ಮೌಲ್ಯ (maulya) is borrowed from Sanskrit maulya, "price" (CDIAL 10373), a form of mūlya, "worth".
