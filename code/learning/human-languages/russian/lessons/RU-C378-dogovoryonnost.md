## You'll want to know: договорённость
<!-- hl-knowledge: introduces=[RU-LEX-C378-DOGOVORILIS-02]; assesses=[] -->

**договорённость** (*dogovoryónnost*) — "an arrangement, an understanding".

> У нас есть договорённость с директором.
>
> *U nas yest dogovoryónnost s diréktorom.*
>
> We have an arrangement with the director.

Feminine. An arrangement in words; a written agreement is *договор*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**договорённость** is built on the participle of *договориться* "to agree", from *говорить* "to speak", with the abstract suffix *-ость*.
