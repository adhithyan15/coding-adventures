# முற்றுகையிடு (muṟṟukaiyiṭu) — to besiege

## You'll want to know: முற்றுகையிடு
<!-- hl-knowledge: introduces=[TA-LEX-C335-KOTTAI335-01]; assesses=[] -->

**முற்றுகையிடு** — *muṟṟukaiyiṭu* — "to besiege".

> படை கோட்டையை ஒரு மாதம் முற்றுகையிட்டது.
>
> *paṭai kōṭṭaiyai oru mātam muṟṟukaiyiṭṭatu.*
>
> The army besieged the fort for a month.

Past (I …): முற்றுகையிட்டேன், *muṟṟukaiyiṭṭēṉ*.

முற்றுகை, a siege + இடு, to put.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**முற்றுகையிடு** (*muṟṟukaiyiṭu*) is built on native முற்றுகை, "blockade, siege", from முற்று, "to surround, besiege" (DEDR 5018), with இடு, "to put".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for telling what happened.
