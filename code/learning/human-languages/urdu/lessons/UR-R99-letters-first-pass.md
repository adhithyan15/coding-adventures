# (two letters) — From the letter to the word — a first pass

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[UR-SCRIPT-C99-ZE-01, UR-SCRIPT-C99-TOE-01] -->

[PAUSE 3s] Say **روز** (*roz*), then write the letter it gave you.

## Guided Practice
<!-- hl-knowledge: introduces=[]; assesses=[UR-SCRIPT-C99-ZE-01, UR-SCRIPT-C99-TOE-01] -->

| letter | name | the word it came from |
|---|---|---|
| ز | *ze* | **روز** *roz* |
| ط | *toe* | **طرف** *taraf* |

[PAUSE 2s each]
- [YOU WRITE: each letter in the table from memory, then check it]
- [YOU SAY: the word each one came from]
- [YOU READ: each word in the table aloud, and point at its letter]

## Wrap-up Recall
<!-- hl-knowledge: introduces=[]; assesses=[UR-SCRIPT-C99-ZE-01, UR-SCRIPT-C99-TOE-01] -->

[PAUSE 3s] Which word did each letter come from? (**ز** from **روز**; **ط** from **طرف**.)
