# Changelog

All notable changes to the Python perceptron package will be documented in this
file.

## [0.2.0] - 2026-09-30

### Added

- Direct constructor, pre-training prediction, AND-learning, output-range,
  weight-shape, and bounded-logging tests.
- Cross-platform repository BUILD fronts with explicit internal build edges,
  coverage, and Ruff validation.
- Package documentation and publishable Hatch metadata.

## [0.1.0] - 2026-03-20

### Added

- Initial sigmoid perceptron implementation.
