## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**Schlange** ← Old High German *slango* ← Proto-Germanic *\*slangô*, "snake" — inherited. (EtymDB 2.1) A queue is a line that winds like a snake.
