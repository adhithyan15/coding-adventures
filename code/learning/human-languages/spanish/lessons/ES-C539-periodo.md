## You'll want to know: el período
<!-- hl-knowledge: introduces=[ES-LEX-C539-ANYO-05]; assesses=[] -->

**el período** — "the period".

> Fue un período difícil para la familia.
>
> *It was a difficult period for the family.*

*Periodo* without the accent is also correct.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*período* is a learned borrowing from Latin *periodus*, which comes from Greek *períodos* 'a going round, a cycle' (EtymDB), built on *perí* 'around' and *hodós* 'way'.
