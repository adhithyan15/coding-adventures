## You'll want to know: вдохновлять
<!-- hl-knowledge: introduces=[RU-LEX-C522-SCULPTURE-05]; assesses=[] -->

**вдохновлять** (*vdokhnovlyát*) — "to inspire".

> Море вдохновляет художников.
>
> *Móre vdokhnovlyáyet khudózhnikov.*
>
> The sea inspires artists.

Imperfective; perfective вдохновить (вдохновлю). The noun is *вдохновение* — inspiration.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*вдохновлять* is built on *вдохнуть* 'to breathe in', from the root of *дух* 'breath, spirit', which EtymDB traces to Proto-Slavic *duxъ*.
