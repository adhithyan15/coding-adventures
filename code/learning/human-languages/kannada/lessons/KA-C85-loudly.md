## You'll want to know: ಜೋರಾಗಿ
<!-- hl-knowledge: introduces=[KA-LEX-C85-SLOWLY-03]; assesses=[] -->

**ಜೋರಾಗಿ** (*jōrāgi*) — "loudly". It has the same **‑ಆಗಿ** ending as
**ನಿಧಾನವಾಗಿ**.

**ಸ್ವಲ್ಪ ಜೋರಾಗಿ** (*svalpa jōrāgi*) — "a little louder", with **ಸ್ವಲ್ಪ**, "a little".
