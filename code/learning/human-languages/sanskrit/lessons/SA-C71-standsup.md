# उत्तिष्ठति (uttiṣṭhati) — stands up, gets up

## You'll want to know: उत्तिष्ठति
<!-- hl-knowledge: introduces=[SA-LEX-C71-MOVE-04]; assesses=[] -->

**उत्तिष्ठति** (*uttiṣṭhati*) — "(he, she) gets up": **उत्**, "up", with **तिष्ठति**,
"stands", which you know.
