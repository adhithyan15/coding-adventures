# వీరుడు (vīruḍu) — a brave man; a hero

## You'll want to know: వీరుడు
<!-- hl-knowledge: introduces=[TE-LEX-C364-VIMUKTI364-05]; assesses=[] -->

**వీరుడు** — *vīruḍu* — "a brave man; a hero".

> ఆ వీరుడు ఒంటరిగా శత్రువులతో పోరాడాడు.
>
> *ā vīruḍu oṇṭarigā śatruvulatō pōrāḍāḍu.*
>
> That brave man fought the enemies alone.

Plural: వీరులు, *vīrulu*.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**వీరుడు** (*vīruḍu*) is borrowed from Sanskrit *vīra*, "a man, a hero" (CDIAL 12056), with the Telugu masculine ending *-uḍu*.
