## You'll want to know: o combustível
<!-- hl-knowledge: introduces=[PT-LEX-C404-BOMBA-02]; assesses=[] -->

**o combustível** — "fuel".

> O combustível está muito caro este mês.
>
> *Fuel is very expensive this month.*

Also an adjective: *um material combustível*, something that burns.

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

*combustível* came from French *combustible*, which is built on Latin *combūrere* 'to burn up' (EtymDB).
