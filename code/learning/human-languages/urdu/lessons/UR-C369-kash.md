## You'll want to know: کاش
<!-- hl-knowledge: introduces=[UR-LEX-C369-KASH369-01]; assesses=[] -->

**کاش** — *kāsh* — "if only; I wish".

> کاش میرے پاس وقت ہوتا!
>
> *kāsh mere pās vaqt hotā!*
>
> If only I had the time!

## The word, taken apart
<!-- hl-knowledge: introduces=[]; assesses=[] -->

**کاش** (*kāsh*) is usually traced to Persian *kāsh*, "would that".

## What you've built
<!-- hl-knowledge: introduces=[]; assesses=[] -->

One more word for saying what happens if.
