# 六 — six, and the run starts again

## Warm-up
<!-- hl-knowledge: introduces=[]; assesses=[ZH-SCRIPT-NUM-LIU, ZH-LEX-NUM-WU] -->

[PAUSE 2s] Write 六, then count aloud to five.

## Sounds you'll need
<!-- hl-knowledge: introduces=[ZH-LEX-NUM-LIU]; assesses=[ZH-TONE-LEXICAL, ZH-LEX-NUM-SI] -->

**六** *liù* means **six**.

**liù** is **fourth tone** — the sharp fall, the same shape as *sì*, four. Say
them together and only the mouth changes: **sì, liù**.

The vowel is worth a moment. Pinyin writes *iu*, and what you say is closer to
*ioū*: there is a faint **o** in the middle that the spelling does not print.

## What you've built — the run starts again
<!-- hl-knowledge: introduces=[]; assesses=[ZH-LEX-NUM-LIU, ZH-LEX-NUM-YI, ZH-LEX-NUM-WU] -->

This book taught 一 二 三 四 五 in chapter 3 and then stopped. For seventeen
chapters it could name a family, a school and a greeting and could not count to
six — could not give an age, a price, a floor or a date. **六** is where that
starts being paid back.
